Status: `READY / FREE-RESEARCH EXACT FINITE PATH JET`

## Frozen inputs and scope

- one intrinsic `Q_S` signed-C6 frame cycle;
- six macro edges;
- exactly two shortest native branches per macro edge;
- 64 labeled branch words in `{I,O}^6`;
- concrete primitive signed-axis step sequences.

Use

\[
S_k(\gamma)=\sum_{r_1<\cdots<r_k}s_{r_1}\otimes\cdots\otimes s_{r_k}
\]

and the exact concatenation identity already checked. Do not reinterpret the tensor coefficients as probabilities or amplitudes.

The current finite checker has already established class counts `1 / 27 / 64`. Do not rerun this only as a numerical curiosity; convert it into an exact structural proof and typed reusable interface.

## Hard target and required outputs

Hard target: `TRIADIC_SHORTEST_CYCLE_PATH_JET_FIRST_LOSSLESS_ORDER_EQUALS_THREE`.

Deliver an exact package that:

1. Proves the finite Chen-type concatenation law for `S_k` on primitive Cell step words.
2. Defines the truncated observer `J_{<=d}` and its exact composition law.
3. Proves that all 64 full-cycle branch words have the same degree-one jet.
4. Proves that degree two factors exactly through
   `n_r = 1_{beta_r=O}+1_{beta_{r+3}=O}` for `r=0,1,2`, giving exactly `3^3=27` classes.
5. Proves that degree three separates all 64 branch words.
6. Shows the result is covariant under relabeling to every oriented native three-axis selection generated by the current signed-X6 triadic frame skeleton.
7. States the minimal observer/future-operation lease: branch recovery on this finite population is safe at order three and unsafe at order two.
8. Separates this exact finite theorem from any claim about arbitrary path lengths or universal finite-order sufficiency.
9. Reuses or explicitly compares the existing path-jet cyclicity tools before introducing a broader general-purpose jet mechanism.
