# RS-X6-NATIVE-TIME-DYNAMICS

Status: `PUBLISHED_REGISTERED / CLAIMABLE / DIRECT_USER_DIRECTION`

## Mother question

What is the minimum native time object that orders actual relational changes of Cell, path, rotation, force and internal state without being confused with another spatial coordinate or with precision refinement?

## Hard target

- Define time-indexed decorated states and transition events above `X6_NATIVE_SPATIAL`.
- Separate at least physical event count, periodic phase, branch/history memory and precision/refinement address.
- Prove when two clocks admit a homomorphism/semiconjugacy and when synchronization is impossible.
- Re-express current C6/C12 phase, half-turn root lineage and BRC path histories inside the common time typing.
- Determine the minimal Markov state for rotation/triadic dynamics; if memory cannot be finite, prove the exact obstruction or lower bound.
- Return a reusable finite-state/graded-time tool or a sharp no-go.

## Hard boundaries

Time is not a seventh spatial axis. Precision level is not physical elapsed time. Path count is event count and is not automatically physical duration. Periodic phase tokens do not identify full state unless observer/future-operation safety is proved.
