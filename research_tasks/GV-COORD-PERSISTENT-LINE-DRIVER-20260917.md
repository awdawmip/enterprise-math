# Coordinate migration persistent line Driver: recovery, routing, review and handoff

Status: `READY / GOVERNANCE / PUBLISHED-TASK TARGET`

## Mother question

How should the already-published coordinate-migration portfolio be continuously reconciled, routed and reviewed so that verified work is consumed once, unfinished work is resumed from its smallest unit, and representation changes never silently alter native mathematics?

## Frozen inputs and scope

The frozen portfolio is the eight publications recorded in `COORDINATE_TASK_TRIAGE_20260916/publication_manifest.json`. Consume, do not restart, the previously machine-verified three-region slice and all durable outputs that already exist. The final address contract remains representation-only: final address fields are nonnegative, inactive zeroes are codec-declared and lossless, display origin/axes are non-operational, and crossings do not universally increment.

This governance task does not itself prove a codec, accept a Result, change P000, alter Working Truth, select a physical law, or create an execution owner. It coordinates the published coordinate tasks and their evidence boundaries.

## Hard target and required outputs

Maintain a compact coordinate-line dossier that binds each of the eight current publication generations to its current result/return/review state, source pins, smallest unfinished unit and next admissible action. Preserve existing owners when valid; recover stale work from durable evidence rather than replaying completed units. Keep research-author, independent-check and Driver-decision roles distinguishable. Route exact review needs back to the smallest task-local defect rather than reopening the whole coordinate program.

The first bounded delivery is: current generation map for all eight tasks, evidence-readiness matrix for the seven upstream research tasks, explicit dependency state for integration acceptance, and one source-backed next action for each unfinished workstream.

## Research value to preserve

The coordinate migration touches many downstream surfaces while changing only address representation. Persistent line ownership prevents two opposite errors: redoing unaffected mathematics because coordinates look different, and accepting a broad migration because a narrow slice proof passed.

## Success, kill, and return criteria

Success for the first handoff is a reconciled, source-bound portfolio map with no duplicate task creation and no lost durable frontier. Keep the line open until a separate terminal disposition or replacement is recorded.

Kill any attempt to treat publication as mathematical acceptance, to convert final nonnegative addresses into a ban on signed internal displacement, to erase hidden/common-depth information without a certificate, or to restart verified work merely because the active conversation changed. If a task is blocked, record the exact missing evidence and continue all independent safe work.
