R059C established two facts that are consumed here and must not be blurred:

1. CPBC / natural-number branch recoalescence can reproduce raw-history multiplicity exactly for the frozen finite path language.
2. Under the R059C forced remote-perturbation schedule, no substantive exact macro invariant and no `MULTIPAIR_EXACT_COMPENSATION` was found across the frozen Stage-A registry.

Compressed slogan:

`EXACT AT ALIGNMENT / COUNT-DISTRIBUTED BETWEEN ALIGNMENTS`.

This is a research hypothesis, not a frozen physical fact.

# 4. Aligned macrostates without geometry

For each scale `N`, freeze a family of tagged occupied configurations

`A_{N,k}`

called **ALIGNED STATES**.

There must exist a declared adjacency-preserving relabeling / alignment-successor automorphism

`sigma_N`

such that the evaluator defines the next aligned target by

`A_{N,k+1} = sigma_N(A_{N,k})`.

This is relational successor structure only.

Do not call `sigma_N` translation, rotation, displacement, velocity, or motion vector.

Critical anti-tautology rule:

`A_{N,k+1}` may be used as an **evaluation target**, but the micro-algorithm may not contain a per-marker target map or the full target configuration as hidden input.

A candidate algorithm receives at most:

- local adjacency/occupancy state;
- finite relational channel labels when declared;
- a single global finite command/channel label if needed;
- local or compressed CPBC count state;
- finite explicit memory if the candidate class declares it.

It may not hard-code `marker_i -> target_i` for all constituents.

# 5. Macrostep and intermediate count cloud

A macrostep is a finite sequence of elementary transitions from one aligned state to the next:

`A_{N,k} -> ... -> A_{N,k+1}`.

Each elementary transition changes exactly one tagged constituent by exactly one declared adjacency transition unless a separately frozen local rule explicitly states another N1 event semantics.

The first round should prefer fixed finite macrostep event count

`L(N)`

with exact integer/symbolic specification. Variable-length termination is allowed only if the researcher can give an exact finite first-return/termination certificate; otherwise defer it.

For each intermediate event epoch `e`, define raw-history / configuration multiplicity:

`H_{N,e}(S) = number of admissible micro-histories reaching configuration S after e events`.

The implementation may never materialize all configurations at large N; it must derive a compressed exact carrier for the count state.

From `H` derive at least:

1. `TOTAL_HISTORY_COUNT(N,e) = sum_S H_{N,e}(S)`;
2. `CELL_OCCURRENCE_COUNT(N,e,x)` = total tagged-constituent occurrences at packet x across all histories at epoch e;
3. `CELL_SUPPORT(N,e,x) = 1[CELL_OCCURRENCE_COUNT>0]`;
4. `CONFIG_SUPPORT_COUNT(N,e)` when symbolically available;
5. an exact finite `COUNT_CLOUD_SIGNATURE(N,e)` suitable for comparing successive macrosteps and scales.

The count cloud is allowed to be broad for all `0<e<L(N)`.

# 7. What "same number of cells crossed" means in this task

Do **not** use total transition count as evidence of stability if the algorithm fixes the number of elementary events by definition.

Do **not** use static packet count at aligned endpoints as evidence; `UNIT_PACKET=1` makes equal-size tagged states trivial.

Compute and separate at least:

### T0 — trivial event count

`L(N)` and `(L(N)+1)*PACKET_COUNT`-type quantities.

These are control quantities only and cannot establish macro stability.

### T1 — per-history unique cell support

For a complete history gamma:

`UNIQUE_CELL_SUPPORT(gamma)`

= number of distinct carrier packets occupied/visited by the tagged object at least once during the aligned-to-aligned macrostep.

Compute exact distribution/histogram over histories when possible:

`U_N(u)=# {gamma : UNIQUE_CELL_SUPPORT(gamma)=u}`.

### T2 — whole-cloud unique support

`CLOUD_UNION_SUPPORT_COUNT(N)`

= number of carrier packets touched by at least one admissible full-history/intermediate state during one macrostep.

### T3 — cell crossing/occurrence multiplicity spectrum

For each packet x, aggregate exact history-weighted occurrence / visit counts over the macrostep and retain the multiset or phase-class vector after pulling back by the alignment relabeling.

### T4 — macrostep recurrence

Compare the full T1/T2/T3 readouts for

`A_{N,k}->A_{N,k+1}`

and

`A_{N,k+1}->A_{N,k+2}`

after the declared `sigma_N` relabeling.

The desired nontrivial statement is not "nothing changes in the middle". It is:

`ALIGNED_STEP_TRAVERSAL_SIGNATURE_RECURRENCE`.

It must be separated from recurrence that follows tautologically only because the evaluator itself copied the target by `sigma_N`.
