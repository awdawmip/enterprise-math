# R057 — Pi-Supervised Algebraic Collapse Synthesis

Status: `READY / P0 / NEW MOTHER QUESTION / SUPERVISED DISCOVERY / NOT CANONICAL`

## Mother question

Use known classical pi as a teacher to **discover** the correct discrete boundary-collapse language. The task is not required to rediscover pi blindly.

The central target is:

`teacher pi + lattice boundary packets -> fitted collapse grammar -> algebraic compression -> theorem candidates`.

Use the frozen packet as the complete mathematical and experimental specification.

## Stage 0 — freeze the evolution rules first

Before expensive synthesis create, freeze and return:

- `R057_DISCOVERY_PROTOCOL_SHA256`
- `R057_INITIAL_TEACHER_DATA_REGISTRY_SHA256`
- `R057_GRAMMAR_META_PROTOCOL_SHA256`

These hashes freeze the rules for how teacher data and grammar versions may evolve. They do **not** freeze one small operator library forever.

The meta-protocol must explicitly preserve:

- pi-supervised discovery is allowed;
- post-selection and overfitting are allowed;
- K may expand inside R057;
- operator primitives may expand inside R057;
- teacher corpus may expand inside R057;
- every expansion/version must enter the genealogy;
- fitted discovery and theorem status remain separate fields.

Stop and return the three hashes before large packet enumeration or symbolic synthesis.

## Stage A — fresh teacher corpus and cyclic packet catalog

Generate the initial teacher-circle corpus from the frozen registry and construct a cyclic/D6-aware packet catalog.

Do not inherit R054's reflection-defective sequential parser as a universal parser.

Build packet types for the initial K range and exact chord/turn invariants.

## Stage B — discrete collapse synthesis

Start with the packet's G0 discrete grammar:

- raw edges;
- endpoint chords;
- all contiguous block partitions/compositions;
- packet identity / whole chord;
- type-to-operator mappings.

Use pi directly to optimize the grammar. Post-selection is expected.

Return an early complexity-error frontier before expanding the search aggressively.

## Stage C — grammar evolution

If the frontier indicates underexpression, expand K, context, primitives or teacher data inside the same generation.

Every meaningful change must preserve genealogy:

`parent grammar -> motivating error/pattern -> change -> new score -> complexity delta`.

Do not hide target-guided changes.

## Stage D — algebraic/operator synthesis

Run the algebraic lane from the packet. Permit rational/algebraic scaling, operator mixtures, conditional selection, compositions and other versioned primitives.

Search for compact expressions that match or beat large discrete lookup tables.

Known pi algorithms may provide teacher-side structural motifs.

## Stage E — algebraic compression

For the best supervised rules, search for:

- small generator sets;
- operator relations;
- recurrences in packet length;
- `c(k)` or `c(k,w)` laws;
- modular/eventual-periodic rules;
- finite automata;
- generating functions;
- compact rational/polynomial selection laws.

The preferred deliverable is a collapse algebra, not merely a low error number.

## Stage F — scale stress and final freeze

Evaluate the final interesting grammar versions on clearly identified larger scales/phases.

This is not retroactively blind validation. Earlier versions may have been modified after earlier scale stress. Preserve version history.

Freeze one final grammar version before its final reported scale-stress table so the final score is reproducible.

## Theorem candidate layer

A fitted rule may later have a valid proof. Record separately:

- `discovery_provenance`;
- `mathematical_status`.

Do not call numerical fit a theorem. Do not downgrade a later valid theorem because the rule was originally teacher-guided.

## Runtime discipline

Checkpoint after:

1. Stage 0 hashes;
2. initial G0 packet results;
3. first meaningful complexity-error frontier;
4. any major grammar expansion;
5. algebraic compression attempt;
6. final grammar and scale stress.

If combinatorial synthesis becomes expensive, preserve the best exact frontier found so far rather than silently extending for a long interval.

Return one or more accurately scoped classes:
