## 5. Forward-derivation questions

### F0-Q1 — exact local incidence / branch arity

From the whitelisted native plane and path definitions alone, determine the exact local branching object at a triple-incidence event.

You must distinguish at least:

- current cell identity;
- incoming provenance, if required;
- admissible next single-cell states;
- sector/component typing;
- whether a coarse current-cell state is sufficient for an information-preserving local rule.

Do not assume the answer is binary, ternary, or any other fixed arity before replaying the source semantics.

Deliver a theorem or exact obstruction:

`LOCAL_NATIVE_RECOALESCENCE_SUPPORT_CLASSIFIED`.

### F0-Q2 — can current N/Boolean coefficient semantics express exact cancellation?

Take the actual minimal same-terminal multipath witness supplied by the current Path-formal BRC.

Ask whether the existing tower

`PATH_FORMAL_BRC -> N_BRC -> BOOLEAN_BRC`

can represent a nonempty same-terminal family whose post-recoalescence scalar readout vanishes while each branch remains individually nonzero.

If impossible, prove the no-go from the algebraic properties of the existing coefficient semantics.

If an extension is needed, derive the **minimal universal extension** required for such cancellation. Do not name or choose a target ring in advance.

Deliver:

`CURRENT_BRC_CANCELLATION_CAPABILITY_CLASSIFIED`.

### F0-Q3 — local reversible recoalescence classification

Using only the support object derived in F0-Q1 and any universal coefficient extension derived in F0-Q2, classify local pre-collapse update laws satisfying all of:

1. `TYPED_LOCALITY` — depends only on the declared local native incidence/provenance state;
2. `TRANSLATION_COVARIANCE` — translated copies use the same rule;
3. `BRANCH_RELABELING_EQUIVARIANCE` — arbitrary serialization/name choices do not alter the physical/readout class;
4. `COMPOSITION_COMPATIBILITY` — concatenating local path steps agrees with multiplying/composing local updates;
5. `REFINEMENT_CONSISTENCY` — temporarily refining distinguishable path alternatives and later forgetting the refinement does not create a presentation-dependent result;
6. `PRECOLLAPSE_INFORMATION_PRESERVATION` — before the declared final readout/collapse, the local enrichment must not destroy path information needed to reverse the update;
7. `NONTRIVIAL_MIXING` — if mathematically possible, classify rules beyond mere branch permutation/relabeling.

Classify **all** solutions up to the native relabeling/gauge equivalence that you derive, not a hand-picked example.

Deliver:

`LOCAL_REVERSIBLE_RECOALESCENCE_FAMILY_CLASSIFIED`.

### F0-Q4 — derive, do not assume, the scalar readout

Do not assume a square law, norm, p-norm, bilinear form, or probability formula.

Start from operational/native requirements only. At minimum test whether the following are jointly sufficient, insufficient, or inconsistent:

- `ZERO_DEFINITE`: empty/null aggregate has zero readout and an individually nonzero elementary witness has positive readout;
- `DISTINGUISHABLE_SUM_ADDITIVITY`: alternatives retained under an explicit distinguishing marker add at readout rather than cross-cancel;
- `BRANCH_RELABELING_INVARIANCE`;
- `LOCAL_CONSERVATION`: an information-preserving local branch/recoalescence update conserves total readout;
- `COMPOSITION_SCALING`: repeated identical independent local constructions have a consistent scalar scaling law;
- `FINITE_REFINEMENT_CONSISTENCY`.

If these requirements force a unique homogeneous degree/readout law, prove it.

If they leave a family, identify the free parameter(s) and give two inequivalent exact models witnessing underdetermination.

If one additional axiom is needed, state the **weakest** extra axiom you can justify and show precisely what it selects.

Deliver:

`RECOALESCENCE_READOUT_LAW_CLASSIFIED`.

### F0-Q5 — minimal dark-fiber discriminator

Using the smallest same-terminal native multipath witness available from the source whitelist, test whether the derived F0 structure can realize all of the following without altering native support:

- individually nonzero alternatives;
- same typed terminal/recoalescence fiber;
- one admissible presentation with constructive aggregate readout;
- one admissible presentation with strictly reduced aggregate readout;
- if allowed by the derived laws, a nonempty aggregate with zero readout.

The point is not to fit a continuum fringe. The point is to discriminate ordinary multiplicity/support aggregation from a genuinely nonclassical pre-collapse enrichment.

Deliver:

`MINIMAL_NATIVE_DARK_FIBER_DISCRIMINATOR`.

## 6. Required proof obligations

A Phase-A result is invalid unless all applicable obligations are discharged.

### P1. Source replay

Reproduce the local typed support and minimal commuting/multipath witness directly from the whitelist with exact references/digests.

### P2. No resurrection

Show explicitly which data are present at Path-formal, N, and Boolean layers and prove that the proposed construction never recovers data after the layer that discarded them.

### P3. Universality/minimality

Every new carrier extension or coefficient operation must be justified by a universal property, an impossibility theorem for all smaller candidates under a declared order, or a complete finite classification at the relevant local size.

### P4. Choice independence

Renaming active generators, swapping branch serialization, translating the local pattern, and cyclically transporting the sector must not change the derived physical/readout class except through an explicitly classified transport/gauge action.

### P5. Associativity/composition

The local law must compose coherently along paths of depth at least 3. A two-step coincidence is insufficient.

### P6. Positive/readout safety

If signed/cancelling intermediate data are derived, prove that the final scalar readout is well-defined and nonnegative on all states in the declared domain.

### P7. Countermodel requirement

Whenever claiming uniqueness or necessity, provide either:

- a theorem excluding the alternative class; or
- explicit countermodels showing what fails when one hypothesis is removed.

### P8. Target-leak audit

List every mathematical object not literally present in the four source files and state exactly which F0 axiom/proof step generates it.
