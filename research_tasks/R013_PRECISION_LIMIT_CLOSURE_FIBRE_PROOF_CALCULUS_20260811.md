# R013 — 精度极限闭环与 fibre proof calculus

Status: `READY / P0 / HIGH / FOUNDATION-METHODOLOGY PRESSURE TEST / NOT CANONICAL`

## 0. 为什么这是新任务，而不是继续堆 k=4 算术

本任务不是“继续把 degree-3 PTE 分类做完”，也不是把 inverse limit 重新命名成 Enterprise Math。

研究对象改为：

> **一条 Enterprise Math 研究线，能否用 task-relative precision 的 directed refinement、compatible theorem family、fibrewise proof composition、residual collapse 和 defect law 形成一个可验证的 closure certificate？**

k=4 只作为第一个 arithmetic prototype。若这个 proof organization 在 k=4 上不能形成 exact theorem，则不得直接推广到 general k。

Deep Research：**开启，但只用于 prior-art attack / de-dup**。

原则：

> **Deep Research 用来攻击我们的 closure calculus，不用来替我们产生它。**

# 3. Formal object：Precision system

在去重以后，再定义本任务实际需要的最小对象。

设 task/admissible precision index 为 directed poset `(Lambda, <=)`。

每个 `lambda` 给出 equivalence/kernel：

\[
E_\lambda \subseteq X\times X.
\]

采用统一方向约定：若 `mu` 比 `lambda` 更精细，则

\[
E_\mu\subseteq E_\lambda.
\]

因此 quotient 有 canonical bonding map：

\[
\rho_{\mu\lambda}:X/E_\mu\to X/E_\lambda.
\]

必须明确：

- `Lambda` 是谁声明的；
- admissible operation/future/observation language 是什么；
- precision family 是所有 compatible quotients、一个 cofinal subfamily，还是人为选取的 tower；
- finite state 与 infinite arithmetic domain 分开处理。

禁止把任意手挑 partition chain 叫“完整 precision system”。

# 6. Exact compiler gate：point safety 与 witness/factor safety 分层

冻结两种 gate：

## Gate A — point quotient

对于声明的 observation / transition / partial-operation language，要求相关 squares commute，或等价地 required semantics factor through quotient。

这优先归 A2/P023 strong-preservation/completeness 层。

## Gate B — factorized / relation semantics

当 coarse object 不只问 point output，而问：

- factor existence；
- join/decomposition；
- witness identity；
- branch-definedness；
- multiplicity；
- relation composition；

则 point-safe 不一定足够。

必须形式化一个 exact witness/back-lifting criterion，并用最小 counterexample 证明：

\[
\text{point-law-safe}\not\Rightarrow\text{factor/join-safe}.
\]

然后判断这个 gate 是 bounded-morphism/bisimulation/relation-lifting 的直接 specialization，还是存在真正 A3/A4-specific arithmetic residue。

# 7. Precision-coherent theorem family

不要把“不同精度下有几个 theorem”就叫 coherent。

设：

\[
X_\lambda=X/E_\lambda,
\]

输出对象也形成 directed family `Y_lambda`，有 bonding maps：

\[
\sigma_{\mu\lambda}:Y_\mu\to Y_\lambda.
\]

候选 theorem family：

\[
T_\lambda:X_\lambda\to Y_\lambda.
\]

coherence 要求：

\[
\sigma_{\mu\lambda}\circ T_\mu
=
T_\lambda\circ\rho_{\mu\lambda}.
\]

若 theorem 不是 function，而是 relation/certificate/set-valued output，给相应 typed generalization，不要强塞函数形式。

先证明这个抽象层只是 inverse-system/natural-transformation prior art；然后寻找 Enterprise Math 真正需要的新部分：proof certificates / defects / resource bounds 是否也必须形成 compatible family。

# 8. Fibre proof composition — 本任务核心候选

本任务要证明的不是一句 slogan：

`低精度先证明 -> fibre 再证明 -> 合成`。

必须给 exact calculus。

最低目标：

给 quotient/refinement

\[
X_H\xrightarrow{\rho_{HO}}X_O\xrightarrow{\rho_{OL}}X_L,
\]

若低层 theorem 给每个 low class `C` 的 shell/capacity data，而 fibre theorem 给 `C` 内 high/output classes 的局部 data，证明何种 operator 可严格合成 global theorem。

至少覆盖：

- cardinality；
- defect；
- weighted sum / semiring aggregate；
- certificate composition。

明确哪些 operator 只需要 fibre independence，哪些需要 witness compatibility / carry state。

目标是一个小而 exact 的 `FIBRE_COMPOSITION` theorem，不是一套泛泛“证明哲学”。

若它完全等价于标准 partition sum / Fubini / incidence algebra，没有额外 Enterprise condition，则按 prior art 收口。

# 9. Residual kernel

定义：

\[
E_\infty=\bigcap_{\lambda\in\Lambda}E_\lambda.
\]

必须区分：

1. finite state：descending chain 是否最终 stabilizes；
2. infinite state：intersection 与 inverse limit 的 projection kernel；
3. task language 不完备导致的 apparent residual；
4. 已证明所有 admissible precision 都无法再拆的 intrinsic residual。

只有第 4 类才允许标：

`INTRINSIC_TASK_RELATIVE_RESIDUAL_COLLAPSE`。

证明 `E_infinity != Delta` 不代表失败；但也不能只因为研究者停止加 observation 就称 intrinsic。

# 10. Precision-Limit Closure certificate

候选四条件：

## C1 Precision completeness

声明的 precision family 对允许的 refinement mechanism 是完整或 cofinal；必须明确“允许”由谁决定。

## C2 Theorem coherence

finite-level theorem family 由统一 refinement/fibre theorem 连接，不是独立结果集合。

## C3 Residual-collapse classification

`E_infinity` 已分类，并证明 remaining collapse 是 intrinsic to declared task/admissible language，而不是漏掉可用 observation/operation。

## C4 Defect convergence

capacity/branching/collision/correction/resource defect 在 refinement 下具有：

- finite stabilization；或
- exact compatible limit；或
- declared asymptotic law + controlled error。

**关键任务：寻找反例。**

必须测试：

- C1+C2+C3 但 C4 失败；
- C1+C2+C4 但 residual 未分类；
- numerical convergence 但 theorem incoherent；
- cofinal family 选择不同是否给相同 closure verdict。

只有在四条件具有明确 invariant content 后才能使用：

`PRECISION_LIMIT_CLOSED`。

否则它只能是 Driver/research checklist，不是数学 theorem。

# 11. k=4 symmetric PTE prototype

使用 equal-coarse four-factor expansion：

\[
\frac{\prod_{i=1}^4(ra+u_i)}{r}
=
r^3a^4+r^2a^3e_1+ra^2e_2+ae_3+\frac{e_4}{r}.
\]

实际 floor/output 精度只需要：

\[
(e_1,e_2,e_3,\lfloor e_4/r\rfloor)
\]

在 centered symmetric locus

\[
\{-x,x,-y,y\}
\]

有：

\[
e_1=e_3=0,
\quad e_2=-(x^2+y^2),
\quad e_4=x^2y^2.
\]

定义：

\[
n=x^2+y^2,
\qquad P=x^2y^2.
\]

translation center `c` 下 product：

\[
c^4-nc^2+P.
\]

prototype 必须完成三层：

1. **Low shell theorem**：固定 `n` 的 sum-of-two-squares shell；
2. **Fibre theorem**：固定 `n` 后，`P` 的 ordering / distinctness / adjacent-gap / span 中只选真正需要 output/capacity 的最小内容；
3. **Output collapse theorem**：
   \[
   \left\lfloor\frac{c^4-nc^2+P}{r}\right\rfloor.
   \]

然后严格验证 low/fibre/output theorem 的 composition，而不是分别做三篇算术。

不得要求完整分类所有 degree-3 PTE solutions 作为 closure 前置。

# 12. General k 只作为第二阶段 gate

只有 k=4 prototype 成功并且 prior-art attack 后仍有 residue，才测试：

\[
\Pi_j=\ker(e_1,\dots,e_j),
\quad
\Pi_0\succeq\Pi_1\succeq\cdots\succeq\Pi_k.
\]

目标不是分类所有 PTE solutions，而是判断：

- refinement fibre theorem 是否 uniform in `j,k`；
- symmetric constraints 是否自动降低 tower dimension；
- top invariant 的 radix/floor 是否给 residual collapse；
- global capacity/defect 是否可由 fibre composition 统一得到。

如果 k=4 的 proof calculus 不 uniform，则停止 general-k promotion。
