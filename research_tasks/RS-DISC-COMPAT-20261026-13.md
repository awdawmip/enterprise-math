# RS-DISC-COMPAT-20261026-13 — 尺度变化、辐射稳定性与参数保护

## 0. Mother question

即便最低阶传播调得接近相对论，微观离散性或优选方向会不会通过相互作用在低能重新产生过大的可测破缺？

父目标：OBJ-DISCRETE-EMPIRICAL-COMPATIBILITY-20261026。本项来自用户直接提出的反证与经验兼容性方向；集合内建议执行组为B，全局排序仍由已登记的默认级别决定。任务依赖：RS-DISC-COMPAT-20261026-00, RS-DISC-COMPAT-20261026-01, RS-DISC-COMPAT-20261026-05, RS-DISC-COMPAT-20261026-06, RS-DISC-COMPAT-20261026-07。

## 1. Frozen inputs and scope

原生基线是 X6 六空间轴及独立定型时间，原生120度关系不等同普通平面角。波允许非邻接/全域自洽机制；不得追加固定物理拍长或每拍一格。激活、正分支质量、相位、能量及共同余量分开定型。三维、仪器、物质和时间/能量标定属于待解释的读出层。

用户本次要求主动寻找不兼容及缺项。固定基线用于定位失败，不授予基线免于证据的地位。此任务不直接改写保护文件；应如实返回具体假设组合或桥的失败。

现有工具复用状态：REUSE_APPLIED。使用 BRC 类型区分及联合关系在允许未来操作下的观测保真条件，识别被错误压缩的状态。任何新原生数值操作遵守已固定的 BRC-only 路线；外部成熟公式只作为成功约束/条件定理，不冒充已完成原生推导。若现有接口不足，明确 EXTEND_EXISTING_TOOL 的字段和必要性。

冻结 ModelCapsule 版本、读出、参数域、随机性来源和允许操作。实验特定干扰参数须事先声明且有标定依据；每种现象临时新增任意余量函数不构成统一模型。依赖尚未返回时可完成前提/接口审计，不得把未定义接口写成物理预测。

本项专有前提：Collins等的论证针对有优选参考系等微观效应在相应有效场论中的辐射传递；不是所有量子引力路线的无条件排除。技术自然性差异本身不是已观测矛盾，但若生成项超限则形成约束。 同参数指同一参考尺度的基础参数与已声明的尺度演化规律；允许运行耦合随尺度变化，不要求每个尺度数值恒同。精细调谐须公开并受跨现象检验，但不因缺少对称保护就自动判错。

## 2. Hard target and required outputs

第一步：给实际候选机制列出被允许的低阶有效项，指出保护它们为零/很小的确切对称或结构。

1. 从原生结构到有效项的明确桥，至少完成一个代表性低阶项或条件性保留/生成证明。
2. 树级与相互作用修正的分离；标明哪些只是估量或有效理论假设。
3. 跨尺度同参数兼容表，区别真实对称保护、调参、依赖未定义UV信息三种情况。
4. 若传统有效场论不适用，提出独立可检验的尺度一致性方法，不仅写不适用。

最小交付是上述第一步的真实结果、一个精确条件障碍或一份可定位的缺项；不要求先补全整个世界模型。

## 3. Research value to preserve

检验微小离散尺度能否稳定隐藏，防止仅在自由传播层面得到虚假的安全结论。

保存推导、失败见证、模型/参数版本及准确来源范围，使另一个执行者能在不重造成功前提的情况下接续。理论不适用只结束特定定理路线；相关经验目标仍然保留。

## 4. Success, kill, and return criteria

成功须给出一项可核验的兼容预测、条件性否定、最小保真反例或准确缺项。相容判断仅限所声明协议和误差。排除判据：被允许并实际生成的低能项在固定参数下超过独立限值则排除；只把格距设小却没有保护/修正估计则不算通过；无法建立尺度桥返回缺项。
