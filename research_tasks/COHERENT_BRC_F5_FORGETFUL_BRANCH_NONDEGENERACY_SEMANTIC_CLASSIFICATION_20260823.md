## 4. Candidate condition — not an axiom

Let

`pi:C -> Z e`

be the conservative forgetful retraction from an enriched coefficient carrier to the old signed occurrence coordinate.

For an elementary two-branch refinement/mixing

`M(e,0)=(x,y)`, define:

`FORGETFUL_BRANCH_NONDEGENERACY` iff

`pi(x) != 0` and `pi(y) != 0`.

## 5. Q1 — type audit: what exactly is a branch?

Separate rigorously:

1. a concrete Path-formal witness `[p]`;
2. a formal coefficient multiplying `[p]`;
3. a marked slot used to retain a distinguishable alternative;
4. an enriched coefficient state in `C`;
5. the forgetful projection `pi` to old signed occurrence coefficient;
6. marker erasure / same-terminal recoalescence.

Determine which of these notions are actually canonical in the allowed sources and which arose only in later operational enrichments.

Required result:

`PATH_WITNESS_VS_MARKED_SLOT_SEMANTIC_BOUNDARY_CLASSIFIED`.

## 6. Q2 — derivability of branch survival

Ask whether the statement

> “a retained marked alternative is a refinement of an old concrete occurrence”

logically entails nonzero projection under `pi`.

You must distinguish at least the following possible semantics:

### S-A. Basis-refinement semantics

Every marked branch is required to refine at least one concrete Path-formal basis witness with nonzero old coefficient.

### S-B. Carrier-state semantics

A marked branch is merely a nonzero state in the enriched coefficient carrier attached to the typed terminal/slot, even if its old projection is zero.

### S-C. Mixed semantics

Only the total marked family must project to the original old occurrence/multiplicity; individual branches may have zero projection.

Determine which, if any, is forced by the canonical Path-formal/BRC bridge.

If several are models of the current semantics, prove independence by explicit semantic countermodels.

Required result:

`FORGETFUL_BRANCH_NONDEGENERACY_DERIVABILITY_CLASSIFIED`.

## 7. Q3 — no-resurrection and refinement consistency
