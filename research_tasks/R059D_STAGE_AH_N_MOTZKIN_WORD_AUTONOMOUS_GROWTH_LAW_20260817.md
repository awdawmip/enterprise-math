# 1. Frozen upstream mathematics

## 1.1 Accepted AG theorem

Let `alpha` be the unique positive root of

`3 alpha^2 + 6 alpha - 1 = 0`.

For every integer `r>=0`, Stage AG proves

`J_N(r)=floor(alpha*r+1/3)`.

Equivalent integer-only event recurrence:

with `j=J_N(r-1)` and `x=3j+2`, increment `j` at radius `r` iff

`x^2 + 6*r*x - 3*r^2 <= 0`.

The jump word

`s_r = J_N(r)-J_N(r-1)`

is the lower mechanical/Sturmian word of slope `alpha` and intercept `1/3`.

Every radial jump gap is exactly `6` or `7`.

AG also proves the exact maximal-shell criterion

`(3m-1)^2 <= 12r^2`.

## 1.2 Accepted AF Motzkin theorem

The canonical first-sector boundary word `W_N(r)` uses symbols:

- `1` : height `+1`;
- `2` : height `0`;
- `3` : height `-1`.

It is a nonnegative Motzkin excursion.

Exactly:

`#1 = #3 = J_N(r)`,

`#2 = r-J_N(r)`,

`|W_N(r)| = r+J_N(r)`.

AF proves that `B_N(r)` is an exact functional of the Motzkin height path. Use the precise AF convention from the frozen artifact; do not replace it by an informal area formula.

The count readouts are:

`D_N(r)=2r+1`,

`C_N(r)=6r+6J_N(r)`,

`V_N(r)=1+3r(r+1)+6B_N(r)`.

## 1.3 Binding no-go

`J` alone does not determine `B` or the internal word arrangement.

AF's first exact counterexample remains binding:

at `r=15`,

`J_N=J_C=2`, but `B_N=23`, `B_C=21`.

Therefore Stage AH must not pretend that the proved scalar jump skeleton already determines the full word.

# 3. Hard success criterion

Stage AH succeeds only if it proves an autonomous generator equivalent to one of the following forms.

### Preferred form A — direct word growth

`State_r = (W_N(r), auxiliary_state_r)`

and an exact deterministic map

`T(State_r, s_(r+1)) = State_(r+1)`.

The auxiliary state must be explicitly bounded/typed and may not contain a hidden copy of the next word or occupancy table.

### Allowed form B — compact autonomous state

There exists an explicit integer state `S_r`, strictly smaller than storing all source occupancy geometry, such that

`S_(r+1)=F(S_r, s_(r+1), r)`

and

`W_N(r)=G(S_r,r)`.

`F` and `G` must be exact, deterministic, finite-description algorithms.

### Allowed form C — exact independent word formula

An explicit theorem-level formula/algorithm produces `W_N(r)` directly from `r` and a fixed finite set of algebraic/integer constants, while satisfying every runtime firewall below.

A formula that scans or solves the AG source support inequality independently over the whole 2D sector for each `r` is **not** sufficient. That would be a re-expression of the resolver, not a discovered word-growth law.

# 5. Core mathematical question

For a fixed radius `r`, AG determines exactly how many up/down events occur:

`J=J_N(r)`.

AF determines the admissible language:

`W_N(r)` is a Motzkin excursion with

`#1=#3=J`, `#2=r-J`.

What exact law determines **where the `2` symbols are interleaved with the ascending `1` symbols and descending `3` symbols**?

That is the Stage-AH problem.

A useful equivalent description is allowed if proved equivalent, for example:

- column-height profile;

- bounded residual/error state;
- continued-fraction/S-adic recursion;
- local rewrite of the previous Motzkin word;
- another exact combinatorial state discovered from the frozen data.

Do not assume in advance that any one of these is correct.

### B3. Residual/error dynamical state

Search for a bounded or slowly growing exact residual whose threshold crossings place the flat symbols.

### B4. Continued-fraction / S-adic growth

`alpha=[0;overline{6,2}]`,

investigate whether the Motzkin word admits a finite substitution family or S-adic recursion driven by the same quadratic unit structure.

A substitution observed in samples is not enough; derive it from the exact integer geometry or prove it by induction.

### B5. Local word rewrite

Directly search for a finite family of exact rewrite rules

`W_r -> W_(r+1)`

conditioned on a small state and the AG jump bit.

The rule family must generalize symbolically, not merely memorize radii.
