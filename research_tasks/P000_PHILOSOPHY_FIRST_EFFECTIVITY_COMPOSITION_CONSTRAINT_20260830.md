# 哲学先行 Q17：Effectivity 的组合、旋转与自然性约束

Status: `READY / P0 / EFFECTIVITY-CONSISTENCY`

## Mother question

Q14 已经证明单个 `C3/C2` reduct 中 effectivity 不可由现有数据定义。现在不能继续在旧变量里找公式；真正的问题变成：**如果 effectivity 是一个可组合的全局语义，它在多个回路、旋转/重标号和 refinement 之间必须满足什么一致性？这些一致性会不会真正减少自由度？**

## Frozen inputs and scope

冻结 Q14 的 same-reduct no-go。任何新 law 都必须被明确标成新增候选结构，并说明它来自什么可操作的 composition / relabeling / refinement 语义；不得把 `Eff` 本身改名后作为 law。

先使用有限 `C2` loop-state spaces，从一回路到最小两回路系统。高阶 sheaf/stack 语言只有在 finite set/group-action 表达失败后才允许进入。

## Hard target and required outputs

Hard target: `P000_EFFECTIVITY_COMPOSITION_CONSTRAINT_SPACE_EXACTLY_CLASSIFIED`

1. 冻结最小的一回路/两回路 state spaces、允许 morphisms 与组合操作。
2. 分别审计 relabeling/rotation invariance、independent-composition consistency、restriction/refinement compatibility 等候选 law；每条 law 必须有独立正反模型。
3. 穷举满足每组 law 的 effectivity selections，计算自由度是否从 Q14 的两-bit 基线下降。
4. 若得到唯一 rule，证明删去任一必要 law 后唯一性消失。
5. 若自由度仍存在，给出两个满足全部已声明 law 但 effectivity 不同的 exact matched systems。
6. 不允许把经典 bundle/sheaf effectivity 作为默认输入；只能在 lower-language failure 后比较。
7. 输出 deterministic checker 与 exact finite certificates。

## Research value to preserve

这是把“缺一条公理”进一步变成“哪些结构性公理真的有解释力”的任务。它可以证明 effectivity 自由度具有组合稳定性，也可能首次找到能从更大系统约束局部 effectivity 的非平凡原则。

## Success, kill, and return criteria

有效终态：`EFFECTIVITY_SELECTION_FREEDOM_SURVIVES_COMPOSITION_AND_NATURALITY` / `COMPOSITION_LAWS_REDUCE_EFFECTIVITY_FREEDOM_EXACTLY` / `UNIQUE_EFFECTIVITY_RULE_FORCED_BY_DECLARED_CONSISTENCY_LAWS`。任何“唯一规则”若依赖直接编码目标 predicate，应按 circularity kill 返回。
