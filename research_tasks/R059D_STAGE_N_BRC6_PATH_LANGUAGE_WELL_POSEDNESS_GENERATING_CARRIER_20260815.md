## 1. Core scientific problem

Stage M showed that a fixed packet boundary and a fixed endpoint-count argmax do not determine a unique BRC6 law when different admissible finite microgrammars admit different raw histories.

The packet/path foundation explicitly allows:

- revisit;
- loop;
- immediate reversal;
- repeated adjacency;
- repeated vector step.

Therefore a fixed set of packet states or fixed `SEGMENT_PACKET_COUNT` does **not** automatically bound the number of transition events or the number of admissible raw histories.

Stage N must answer:

1. When is endpoint-history counting finite and well-posed?
2. If loops generate infinitely many histories, what exact count object replaces a single finite endpoint integer?
3. Can BRC6 be resolved on a nonempty domain without choosing an arbitrary finite horizon, arbitrary positive weights, or one preferred Stage-M microgrammar?
4. What minimum additional operational semantics are actually required when the full path language does not determine a unique vector?
