# R048 — Post-Calibration Native Capability Debt Factorization and Second-Generation Mechanism Search

Status: `READY / P0 / POST-FAILURE NEW GENERATION / TARGET DETAILS WITHHELD / NOT CANONICAL`

## 0. 母问题

R047 第一代 blind candidates 在严格 calibration 中没有任何一个到达 quantitative engineering explanation；这不是要求把工程 target 定义复制进 native 输入。

本任务只问：

> **这些失败暴露出的“缺能力”里，哪些真的是 native structure 缺失，哪些只是 N1 operation、N2 readout、metrology bridge 或评价条件？能否把它们压缩成更小的独立 debt basis，并从这个更小 basis 自然生成第二代 native mechanisms？**

第一目标是 `DEBT FACTORIZATION`，不是造一个超级 candidate。

## 1. 严格输入范围

启动阶段允许消费：

1. `AGENTS.md`；
2. `FOUNDATIONAL_LOGIC.md` / `foundational_logic.json`；
3. `native_semantics_admissibility.json` V3；
4. `research_inputs/R048_FAILURE_DERIVED_CAPABILITY_DEBT_PACKET_20260813.md`。

生成阶段禁止主动读取：

- R046 engineering atlas/kernel/interface；
- PR #534；
- R047C raw 12×4 matrix、KENG protocol details、工程 tolerance 数值；
- PR #537 的 target-specific calibration artifacts；
- classical pi 数值作为选择信号。

R047P/R047I 的旧 candidate 只能作为 **pull-only historical shoulders**：研究员明确卡住并主动请求前代失败/结构启发时才可以读取；不得 startup preselection。

## 2. Stage A — Debt factorization 必须先完成并冻结

对 packet 中 D1–D6，逐条允许：

- KEEP；
- MERGE；
- SPLIT；
- RETYPE；
- WEAKEN；
- KILL_AS_OUTPUT_COPYING；
- KILL_AS_REDUNDANT；
- MOVE_TO_CALIBRATION_ONLY；
- MOVE_TO_EVALUATION_ONLY。

必须为每条 surviving debt 给出：

- exact semantic stratum；
- theorem-critical symbols；
- typed dependency graph；
- 为什么不是经典输出定义的回填；
- 与其它 debt 的依赖/可导关系；
- minimal counterexample / independence witness（若可得）；
- 最弱合法表述。

输出一个更小的 `INDEPENDENT_NATIVE_CAPABILITY_DEBT_BASIS`。六条原始 debt 不允许自动变成六个 primitive。

Stage A freeze 后才进入 candidate generation。

## 3. Stage B — 第二代 THEORY_EXPLOSION

从冻结后的 native-side debt basis 出发，生成 **4–8 个 serious second-generation mechanisms**。

纪律：

- 不选 winner；
- 不按未知后续 calibration 得分排序；
- 不为每个 debt 单独装一个 adapter；
- 一个 candidate 若引入多个状态/算子，必须说明它们为什么从一个更小 internal principle 共同产生；
- 允许候选证明某些 debt 根本不应由 native ontology 承担；
- 保留奇怪路线和 productive failures；
- semantic illegality / immediate contradiction 才可早杀。

## 4. 每个 candidate 必须冻结

每个 `G2-M_i` 至少记录：

- exact N0 substrate；
- N0-definable derived objects；
- introduced N1 operations；
- N2/readout layer；
- state carrier；
- local/update law；
- scale/refinement semantics；
- composition/recursion closure；
- exact conservation/monotone/invariant；
- relaxation/recurrence/branching typing（若存在）；
- finite-information cost；
- free/arbitrary parameters；
- 哪些 debt 由同一个 internal mechanism 推出；
- 哪些 debt 仍 unresolved；
- internal counterexample / degeneracy；
- productive failure lesson；
- new object/question exposed；
- contamination audit；
- candidate freeze SHA-256。

## 5. 禁止的“假进展”

以下不算成功：

- 把 `measure`、`clock`、`diffusion`、`resonance` 这些工程词直接命名成 native primitive；
- 把 center/distance/radius/circle/angle/radian/continuum/Fourier/Gaussian/PDE 换名字后重新输入；
- 用 classical pi 数值接近程度选择 candidate；
- 一个 KENG/一个 adapter 的 patchwork；
- 只因为旧 R047C 某 candidate bridge debt 低就默认沿用它；
- 只给 metaphor，不给 exact finite law；
- calibration readout debt 被错误提升为 N0 debt。

## 6. 必须做的 exact pressure tests

至少包括：

1. debt independence / redundancy counterexamples；
2. candidate update closure；
3. composition/recoalescence behavior；
4. finite-information accounting；
5. small exact exhaustive checks where meaningful；
6. counterexamples against false stabilization / false conservation / false recurrence / false extensivity；
7. semantic-strength audit under Gate V3；
8. parameter-explosion audit。

有限扫描只能支持 bounded claims，不能冒充一般定理。

## 7. 必须返回的 artifacts

至少：

- `R048_REPORT.md`；
- `R048_DEBT_FACTORIZATION.json`；
- `R048_INDEPENDENT_DEBT_BASIS.json`；
- `R048_G2_CANDIDATE_SET.json`；
- `R048_NATIVE_DERIVATION_LEDGER.json`；
- `R048_INTERNAL_STRUCTURE_MATRIX.json`；
- `R048_PRODUCTIVE_FAILURES.json`；
- `R048_CONTAMINATION_AUDIT.json`；
- exact checker/tests。

## 8. Freeze gate

Candidate set 冻结时必须固定：

- IDs；
- definitions；
- parameter domains；
- update laws；
- debt-derivation claims；
- theorem/counterexample boundaries；
- hashes。

后续重新打开详细 calibration target 后，任何 candidate core 修改都必须是新 generation，不能继承本轮 freeze。

## 9. Success / kill / return criteria

优先成功：

`DEBT_BASIS_STRICTLY_COMPRESSED / DIVERSE_G2_NATIVE_CANDIDATES_FROZEN / MULTIPLE_DEBTS_DERIVED_FROM_SHARED_INTERNAL_MECHANISMS / CALIBRATION_DETAILS_NOT_USED_FOR_GENERATION`

窄成功也允许：

`DEBT_FACTORIZATION_FOUND / SOME_DEBTS_MOVED_OUT_OF_NATIVE_LAYER / G2_CANDIDATES_PARTIAL`

如果证明 packet 本身把工程结果残留成错误 debt，也可以返回：

`FAILURE_DEBT_ONTOLOGY_REPAIRED / TARGET_DERIVED_PRIMITIVE_PRESSURE_KILLED`

不得为了“推进”强行保留六条 debt 或强行选一个第二代赢家。
