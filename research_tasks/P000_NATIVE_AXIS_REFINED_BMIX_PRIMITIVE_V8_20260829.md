# P000 轴细化 mixed-support `BMix_b` 原生关系与 `J_B` 构造 V8

Status: `READY / GENERATION-8 / P0 / P000-BOUND / NATIVE-RELATION-PRIMITIVE-FIRST`

## Mother question

Gen7 已经精确证明：当前 `X_6=C_A x C_B` 及其 block-pure relation closure 不能生成 partial cross-block native relation；因此

\[
J_B=\{E_1,E_4,E_5\}
\]

仍只是 observation window，而所需

\[
\widetilde R_b:\ (E_2\ E_4)(E_3\ E_5),\quad E_1,E_6\text{ fixed}
\]

在当前 native operation language 中不可表达。

本任务不再问这个 no-go 是否成立，而问：

\[
\boxed{\text{第一个足以合法表达 partial cross-block mixing 的 native relation primitive 是什么？}}
\]

暂记为 `BMix_b`。名称只表示待分类接口，不预设它必然存在。

## Frozen inputs — 不得重做

1. P000：六个原生空间轴 `E_1,...,E_6`，时间独立；
2. FCC primary carrier 与 carrier `K4/S4` algebra；
3. axis-type bridge `beta` 与 observation windows `J_A,J_B,J_C,J_D`；
4. old clone-product `rho` 无 FCC-S4 intertwiner；
5. signed-K4/cohomology 已闭合且 carrier lift 为 split `S4 x C2`；
6. passive finite fiber 不能创造缺失的 base native motion；
7. Gen7 block-pure closure theorem；
8. `W=(S3 x S3) semidirect C2` order 72 且 `b_xi notin W`；
9. current Cartesian adjacency 在 partial cross-block relabel 下不保持；
10. Q6 stress witness 仅证明该轴置换不是由“六轴”本身禁止。

## Hard target

`P000_AXIS_REFINED_MIXED_SUPPORT_BMix_b_RELATION_AND_JB_NATIVE_SLICE_EXACTLY_CONSTRUCTED_OR_OBSTRUCTED`

## Required outputs

### A. Deeper native primitive inventory

从**实际项目已有**的 Enterprise-native 定义向下检查 Cell adjacency、局部 relation、address、粘合、stack/handle/transport 或其他已授权 primitive；不得凭名称假设不存在或存在。

输出：哪些 primitive 仍 block-pure；哪些首次具有 axis-refined semantics；是否已经隐藏存在能组合成 mixed support 的关系。

### B. Axis-refined state semantics

若要形成 `J_B`，必须定义可复核的轴细化 state/relation 接口。允许局部对象、fibered object、relation groupoid、typed handle 等，但必须明确：

- native state identity；
- 哪些数据属于 axis-local；
- 如何与 full Cell state 关联；
- omitted coordinate 不等于 zero；
- carrier readout collision 不得 quotient native state。

### C. `BMix_b` primitive

优先尝试从既有 primitives **推导** `BMix_b`。若无法推导，只允许提出一个最小 derived-model extension，并证明它不是 P000 root axiom mutation。

`BMix_b` 至少必须给出：source/target typing、support、payload transport、inverse 或 exact noninvertibility、composition domain、与 native adjacency/relation 的兼容条件。

禁止把 `BMix_b` 定义成“让 carrier b 成立的那个操作”而没有 native semantics。

### D. Genuine `J_B`

用 `BMix_b` 或证明的等价 native structure 构造/否定真正的

`J_B={E_1,E_4,E_5}` geometric Cell slice。

若构造，给出 Cell set/state object、adjacency、三轴 local relation，以及与 `J_A={E_1,E_2,E_3}` 沿共享 `E_1` 的 gluing/overlap law。

若继承现有三轴 `120°` slice strength，必须给 native transport proof；不得只凭 FCC 读出宣布。

### E. Legal `R~_b`

若 C/D 成功，构造 full-state 或 typed partial/groupoid `R~_b`，其 axis-type action 为

`(E_2 E_4)(E_3 E_5)`，固定 `E_1,E_6`。

严格检查：bijection/partiality、adjacency、support/domain、payload、inverse、`J_A -> J_B` transport。

### F. Minimal consistency / independence audit

若引入新的 derived relation，必须检验：

- 与 P000 六轴/时间规则一致；
- 与已接受 `E_1,E_2,E_3` slice 不冲突；
- 不强迫 carrier linear relations 成为 native identities；
- 不把 readout equivalence 变成 native quotient；
- 不自动使任意 `S_6` permutation 成为 native rotation。

必须给至少一个模型 witness 或 exact finite consistency certificate；若做不到，任务不得宣告构造成功。

### G. Orbit completion gate

只有 `J_B` 与 `R~_b` 均合法后，才允许构造 `R~_a` 或等价 orbit-completion，生成 `J_C,J_D`，并检查

`R~_a^3`, `R~_b^2`, `(R~_a R~_b)^4`。

任何 residue 必须来自 native composition，而不是旧 carrier sign gauge。

### H. Failure taxonomy

若失败，至少分类：

`NO_DEEPER_MIXED_PRIMITIVE_FOUND` / `AXIS_REFINED_STATE_INCONSISTENT` / `BMix_b_RELATION_INCONSISTENT` / `JB_GLUE_OBSTRUCTED` / `PARTIAL_B_EXISTS_GLOBAL_B_FAILS` / `NATIVE_RELATION_RESIDUE` / `OTHER_EXACT_OBSTRUCTION`。

给出 smallest witness 与下一项严格必要数据。

### I. Deterministic checker

至少覆盖：Gen7 regressions、primitive inventory 的有限可检部分、BMix typing/consistency、`J_B` overlap、`R~_b` legality（若存在）、no-quotient、carrier S4xC2 closure 不被误当 native group，以及任何新 relation 的最小模型 witness。

## Kill conditions

- 重做 `b notin S3 wr C2`；
- 重做 signed-K4/cohomology/binary-octahedral；
- 用 carrier permutation 直接定义 native relation；
- 只写“增加 cross-block edge”却不定义 state/relation semantics；
- 把 derived relation 升格为 P000 root axiom；
- passive hidden bit 顶替 mixed relation；
- carrier equivalence quotient native state；
- SO(6)、primitive negative axes、classical rank 降维。

## Valid terminal classes

- `BMix_b_DERIVED_AND_FULL_NATIVE_JB_b_CONSTRUCTED`；
- `MINIMAL_DERIVED_BMix_b_CONSISTENT_PARTIAL_LIFT_CONSTRUCTED`；
- `EXACT_BMix_b_EXTENSION_OBSTRUCTION_PROVED`。

无论哪一类，都必须把“P000 root ontology”与“本任务 derived native model/interface”严格分层。
