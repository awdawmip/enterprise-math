# Seed-6 退化层的全局拼接：奇异胞、支撑保持与非平坦性检验

Status: `READY / P1 / STRATIFIED-GLOBAL-GLUE / NO-FACTORIZATION`

## Mother question

第一轮已经证明：clean prime-column 矩形的 support-faithful 拼接严格是

\[
K_k\times I,
\]

自然 transport flat，且 support erasure 可以制造伪 \(H_2\)。

同时局部退化谱又证明至少存在三条彼此独立的奇异轴：

\[
\text{pairing-state identification},
\qquad
\text{rectangle resonance},
\qquad
\text{valuation/support thickness}.
\]

本任务问：

\[
\boxed{\text{当这些真实退化层被 support-faithfully 拼接时，全局结构是否仍然只是平坦乘积？}}
\]

若不是，必须指出非平坦性究竟来自哪一个精确奇异层交叉；若仍是，则给出 exact no-go/normal form。

## Frozen inputs and scope

1. 接受 clean global complex `K_k x I` 与 trivial natural holonomy。
2. 接受 support-erasure 产生的大 `H_2` 为 quotient artifact。
3. 接受四原子 pairing cell 的 `S4/V4 -> S3`、atom-level lift ambiguity 和 typed support carrier。
4. 接受局部退化三轴分类以及 `3:2` resonance。
5. 只允许 exact-support / exact-bundle identity 下的 gluing；不同 support 不得仅因数值或 role 相同就合并。
6. 允许 CW complex、link、incidence poset、groupoid、cocycle、valuation decoration 和 exact homology。
7. operator/lift history 只有在局部数据唯一或自然诱导时才可作为 intrinsic；任意选择必须标成 gauge/extra data。
8. 禁止 additive distance、因子恢复、分解性能和由 support quotient 人为制造的“曲率”。

## Hard target and required outputs

Hard target: `SEED6_DEGENERATE_STRATIFIED_GLOBAL_GLUE_CLASSIFIED`

A. 定义 `STRATIFIED_BRIDGE_COMPLEX_V1`：clean cells、degenerate cells、support/bundle labels、valuation decoration 和合法 gluing map。

B. 分类至少以下局部奇异胞在全局中的 link/valence：
- `r=s` pairing collapse；
- seed collision；
- `2r=3s` / `2s=3r` resonance；
- overlap `gcd(r,s)>1`；
- prime-power thickness；
- composite bundle intersections。

C. 计算 clean 与 mixed-strata gluing 的 `H_0,H_1,H_2` 或等价 exact invariants；任何新 homology 必须追溯到明确的 support-faithful attaching map。

D. 检查 path dependence / holonomy：
- state-only transport；
- atom-level lift；
- `V4` lift ambiguity；
- carrier-preserving transport。
必须区分 intrinsic holonomy 与 gauge/extra-data holonomy。

E. 对奇异 strata 的交叉做 exact classification。特别检查 `3:2` resonance 与 overlap/equality 同时发生时是否产生新的 cell type，而不是简单叠加两个标签。

F. 建立 quotient safety test：证明哪些 forgetful map 保留后续运算，哪些会制造伪环、伪 2-cycle 或伪 holonomy。

G. 若全局仍 flat/product-like，给出 normal-form theorem；若不 flat，给出最小 exact witness 和必要条件。

H. exact checker 至少覆盖多个 clean/degenerate mixed configurations，并主动构造 support-erasure 和 arbitrary-lift 负控制。

## Research value to preserve

本任务的价值不是“证明一定有曲率”，而是第一次在已经知道 clean 情形 flat 的前提下，把真实的 arithmetic singular strata 放进全局几何。

负结果同样重要：若所有 support-faithful 退化拼接都可化为 stratified product，则这会给进取数论一个强 no-go，迫使未来新几何寻找更深的 relation，而不是继续在 rank-one rectangle 上添加视觉复杂度。

## Success, kill, and return criteria

成功可以是：
- intrinsic non-product singular gluing；
- exact nontrivial groupoid/holonomy class；
- stratified-flat normal form；
- quotient/gauge artifact 的完整 no-go 分类。

Kill：
- support erasure 后把伪 homology 当 intrinsic；
- 任意选择 atom lift 后把结果当 canonical；
- 用整数大小或加法邻近定义 gluing；
- 跳回因子恢复或性能目标；
- 没有 link test 就称“surface/manifold”。

Return 必须包含：合法 gluing 定义、局部 link 表、全局不变量、holonomy/gauge audit、最小正/负 witness、exact checker 和下一 frontier。
