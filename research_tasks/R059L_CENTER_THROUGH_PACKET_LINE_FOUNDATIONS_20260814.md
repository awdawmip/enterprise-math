# 4. Core hypothesis family

This generation does **not** presuppose a unique answer.

It compares several exact center-only candidate notions.

## 4.1 Center-word

A finite center-word is an ordered sequence

```text
γ = (x_0, x_1, ..., x_n)
```

such that every `x_j` is a packet center and every successive pair obeys the declared center-neighbor relation.

The line, if one is eventually defined, must be represented by packet centers themselves.

There is no boundary-following object in this definition.

## 4.2 Sector-normalized two-letter word

For finite computation only, axial coordinates may D6-normalize an endpoint displacement into a cone generated by two adjacent primitive neighbor moves `u,v`:

```text
D = p u + q v,
p,q >= 0,
n = p+q.
```

A monotone center-word for this displacement uses exactly `p` copies of `u` and `q` copies of `v` and no other moves.

This word alphabet is an implementation representation of an N1 path choice, not a native angle/slope.

## 4.3 Why shortest path is insufficient

All words with the same counts `(p,q)` have the same no-backtracking word length `n`, but can have radically different orderings.

For example, a block word

```text
uuuuu...vvvvv...
```

and an evenly interleaved word can both be shortest/no-backtracking.

Therefore shortest word length alone cannot define straightness.

This failure must be made an explicit Stage-A regression target.

## 4.4 Balanced prefix discrepancy

For a word with total counts `(p,q)` and length `n`, let `N_v(j)` be the number of `v` moves among the first `j` letters.

Define exact integer prefix discrepancy

```text
Δ_j = n * N_v(j) - j * q.
```

A basic balanced-word condition is equivalent to requiring every prefix count to stay among the exact floor/ceiling realizations of its proportional share:

```text
N_v(j) ∈ { floor(j q / n), ceil(j q / n) }
```

for every relevant prefix `j`.

No floating slope is required.

Stage A must investigate whether this condition, minimax discrepancy, mechanical words, and Christoffel-type words select the same center-line family.

## 4.5 Midpoint / fractional-position condition

The user insight “the line must pass through packet centers” should also be tested through a center-only fractional-position interpretation.

At fraction `j/n`, the expected cumulative move counts are rational values `(jp/n, jq/n)`.

A candidate center-line may be required to realize one of the nearest exact integer count states according to a **count-discrepancy rule**, not according to a pre-imported Euclidean distance to a continuum line.

This is the permitted foundation-level meaning of a midpoint/fractional-position gate in the first generation.

Do not silently replace it with Voronoi nearest-point projection of a classical line.

## 4.6 Tie cases

If two center-words are symmetry-equivalent upper/lower balanced representatives, do not break the tie using an arbitrary global direction-code ordering and then call that choice native.

Prefer to retain a finite equivalence class / corridor of valid center-lines until a D6/reversal/translation-invariant uniqueness certificate exists.


This is a finite-information direction object.

# 6. Length must be typed separately from straightness

Do not define line length by summing microscopic center hops and assume that this is the geometric line length.

This task must distinguish at least:

1. `WORD_SPAN`: number of center transitions in a chosen center-word;
2. `DISPLACEMENT_CONTENT`: endpoint displacement / reduced count data;
3. `METRIC_LENGTH_READOUT`: a scalar derived only after an admitted carrier metric/Gram form is established;
4. `PRECISION_TAGGED_LENGTH`: scalar length plus the precision/resolution layer and carrier semantics under which it was read out.

A core research question is whether the six-neighbor center carrier admits a unique D6-invariant positive quadratic length form up to scale.

A candidate later theorem is:

```text
D6 invariance + equal primitive-neighbor length + quadratic/translation-compatible readout
    ⇒
Q(a,b) proportional to a² + ab + b².
```

This is **not** a Stage-0 assumption and must not be used to select the center-line word.

If later derived, the scalar readout at center spacing / resolution `δ` may take the form

```text
L_δ(A,B) = δ * sqrt(Q(B-A)).
```

Its semantic status remains N2/readout unless separately promoted.

# 7. Precision is part of length

This generation follows the account-level research axiom that precision/resolution is part of the natural quantity description rather than an afterthought.

Therefore do not require line length at two different precision layers to be numerically identical when their endpoint packets/centers differ.

Instead define a refinement contract capable of representing

```text
(precision layer, endpoint-center identities, displacement content, scalar readout if admitted)
```

and study coherence under refinement.

Possible outcomes include:

- exact scale coherence for specially aligned/refinement-compatible endpoints;
- bounded resolution-dependent variation for quantized endpoints;
- a length interval or uncertainty class rather than one infinitely precise scalar.

Do not presuppose convergence to a classical real length.

# 8. Packet shape and line length

Do not use the external boundary shape of a packet directly in the line definition.

If two packet carriers have the same center set, center-neighbor relation, symmetry, and resolution scale but different decorative/external packet boundaries, a center-through line theory should treat them identically.

Packet shape may affect line/length only insofar as it changes the admitted center carrier structure, for example:

- center spacing;
- neighbor relation;
- local symmetry group;
- refinement relation;
- later derived Gram/metric readout.

This is a deliberate regression against the R058S boundary-density trap.
