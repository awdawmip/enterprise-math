# B03｜相关校准误差与多记录的可靠解码

本版接续同一正式任务 `RS-EULER-RR-20261012-05`；对前版 `TP2-09D5188B48F8B5311C4B` 作范围补全，既有任务书与记录保留。

## Mother question

偏移b=r-a与源、参考或既往记录相关时，重复记录究竟增加多少可识别信息，怎样界定准确率？

## Frozen inputs and scope

已有max(q0,q1,q2)的最优单次解码只适用于独立偏移和均匀源；偏移边缘分布不决定一般记录通道。

保留第一代一次 E、固定读出目标、归一化正权和完整相关准备的首个域。源先验、条件化与弃样规则明示；27状态完整有理联合分布中的同源/偏移边缘异成功率对照、完整信道表、有限最优解码证书、最少补充联合统计、记录质量与扰动分类、有理区间上下界及组合误差均继续保留。

主输入为 source_refs 中冻结的候选记录器 E(j,a,r)=(j,a,r+j-a) mod 3。源、参考、记录器与共享场属于一个完整联合正权世界；通道相位、平均读出、记录正确率与正质量分别定型。原论文式正文和附件 NOTE.md 各保留自身指纹，不据标题或相同主题宣称逐字一致。

本任务承接 P000 与当前 ACTIVE 世界观：六轴离散 Cell 空间和独立时间、120°原生正角与三元闭合；内部寄存器或外部相位表示不充当新增原生坐标。涉及原生三维切片时另给选取/嵌入、第三分量语义、读出、保持关系及更新范围。

科学操作采用现行类型化 BRC，复用 `brc_relational_recorder.py` 的正权接触、保持、传递和汇合接口。需要扩展的更新先说明载体、来源、观察与对应证书；数学证明、证书设计与实际运行分别报告。执行规范由 `docs/PORTABLE_RESEARCH_PROTOCOL.md` 及其 BRC 运算入口继承。

## Hard target and required outputs

1. 由完整联合正权直接构造P(records|source)，不由边缘概率拼装。
2. 在冻结的小域内证明最优解码成功率、必要记录数或不可识别条件；给同边缘异准确率的对照。
3. 把C_RS与“标签可恢复”的关系分清：直接一致、可校正偏移、无信息分别判定。
4. 带有理噪声区间或模型不确定集合的可靠下界；扩展至N次时给明确相关假设。

## Research value to preserve

为残差记录提供能抵抗相关噪声和选择偏差的判读标准。 识别记录错误中的结构关联，避免把重复读取误当作自动获得独立信息。

## Success, kill, and return criteria

- 独立性是检查或假设项，不从每次相同比例推出。
- 重复读数能改善、无改善或变坏均可成为完成结论；计算结果有精确证书。
- 若完全未知联合噪声使解码不唯一，返回可行通道集合与最小额外校准关系。
- 不重复已完成的独立单次解码表。

每项返回列出精确命题/假设、证明或最小反例/欠定证书、实际 BRC 运行证据或未运行范围、来源与指纹、最强已验证结论和下一未解单位。科学接受状态单列。
