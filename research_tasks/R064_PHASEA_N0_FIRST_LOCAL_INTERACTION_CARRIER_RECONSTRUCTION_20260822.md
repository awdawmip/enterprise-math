## 0. Research-provenance boundary

This is a foundation-first new direction, not a continuation of a numbered downstream route.

The Phase-A evidence prior is deliberately narrow. Before the Phase-A candidate/no-go packet is frozen, the researcher may use only the allowed inputs listed in Section 1 plus ordinary finite/discrete mathematics needed to reason about them.

Do **not** use prior numbered-route taskbooks, research-result directories, Driver reviews, Driver continuity, project journals, current route catalogs, or theorem summaries as Phase-A mathematical evidence.

Do **not** search for a previously obtained interaction algebra, state count, multiplication table, sign convention, transport law, or globalization result and then reconstruct it from the foundation.

The point of this phase is independent definability evidence. If the current N0 substrate does not force a nontrivial local process law, that exact no-go is a successful result.

Phase A stops before any comparison with prior downstream research.

## 1. Allowed mathematical inputs — exhaustive for Phase A

Use only the current exact foundation and path primitives from:

1. `definitions/ENTERPRISE_THREE_POSITIVE_AXIS_OVERLAPPING_CIRCLE_CELL_PLANE_20260820.md`;
2. `definitions/ENTERPRISE_NATIVE_LINE_TRACE_FORMULA_20260821.md`;
3. `FOUNDATIONAL_LOGIC.md` and `foundational_logic.json` for foundation typing;
4. `native_semantics_admissibility.json` for admissibility/promotion strength.

Freeze the current spatial substrate only at the strength explicitly established there, including:

- `O_E=0`;
- three distinct positive native axes `E1,E2,E3`;
- three glued two-axis sectors `S12,S23,S31`;
- shared-axis identity across adjacent sector charts;
- component-typed native path/trace structure already established by the exact line-trace definition;
- finite path representatives and their intrinsic order/incidence information where the frozen definition supplies it.

Do not silently add:

- negative native axes;
- a continuum angle/phase variable;

- an external finite group or signed alphabet;
- a target state cardinality;

- an optimizer, rank rule, lexicographic selector, residual counter, or target-word selector.

Any implementation coordinate is `I0_IMPLEMENTATION_CARRIER` unless separately promoted by an admissible certificate.

## 2. Mother question

Determine whether the current Enterprise N0 substrate **by itself** canonically determines any nontrivial finite local binary interaction/composition carrier on elementary native path events.

Hard target:

`N0_DEFINABLE_LOCAL_INTERACTION_PROCESS_CARRIER_CLASSIFIED`.

A complete answer may be positive or negative.

The task must distinguish:

1. a relation already present in N0;
2. an object canonically definable from N0;
3. an operational law that requires an additional N1 choice;
4. a readout/quotient that merely compresses existing structure;
5. an arbitrary encoding that has no N0 definability certificate.

## 3. What counts as a nontrivial local interaction law

Start from elementary component-typed path events/letters and their N0-definable local context.

A candidate binary interaction law is nontrivial only if it is not merely one of:

- constant output;
- left or right projection;
- relabeling of an input;
- ordinary pre-existing path concatenation/additive trace composition;
- a table whose outputs were chosen to match an external/downstream formula.

For every candidate state or output class, provide an explicit reconstruction from N0-definable finite data.

The theorem-critical question is not whether labels can be invented. It is whether the distinctions represented by those labels are forced by N0 relations.

## 4. Classify the intrinsic local contexts first

Before proposing an algebra, enumerate/classify the smallest N0-definable local contexts for an ordered pair of elementary path events.

Possible information may include only what is actually definable from the allowed substrate, such as:

- equality/difference of native component tags;
- sector membership and shared-axis incidence;
- source-path position/order relations;
- coincidence or noncoincidence of source positions;
- other finite relational predicates explicitly derived from N0.

Do not assume this list is complete. Derive the relevant local-context language from the allowed substrate.

Then quotient local contexts by the exact N0 relabelings/automorphisms that preserve the declared substrate.

Required result:

`R064_PHASEA_LOCAL_CONTEXT_EQUIVALENCE_CLASSIFICATION.md`.

Every internal process state later used must either:

- be one of these N0-definable equivalence classes;
- be explicitly constructed from them;
- or be rejected as extra N1 semantics.

## 5. Automorphism/relabeling gate

First classify the relabeling/automorphism group actually admitted by the current three-sector N0 atlas.

Do not assume all permutations of `E1,E2,E3` are admissible unless proved from the frozen foundation. Do not assume only cyclic relabeling either; classify the exact allowed symmetry used by the theorem.

For a candidate local law `F`, test exact equivariance:

`F(g.x,g.y) = g.F(x,y)`

at the same semantic strength claimed for `F`.

If a candidate requires selecting one native axis, one sector, one orientation, or one representative with no N0 certificate, classify that dependence explicitly rather than hiding it as notation.

Required artifact:

`R064_PHASEA_AUTOMORPHISM_INVARIANCE_CERTIFICATE.json`.

## 6. Derive, classify a family, or prove a no-go

Given the N0 local-context classes, determine all binary laws satisfying the exact requirements you can justify from N0.

At minimum classify:

- existence;
- uniqueness or complete smallest family of alternatives;
- locality;
- choice-independence;
- relabeling/automorphism equivariance;
- closure under repeated application, if repeated composition is meaningful;
- whether any identity, associativity, commutativity or involution property is **derived**.

Do not impose identity, associativity, commutativity, invertibility, cancellation, sign, unit, or state-count constraints merely because they would make a familiar algebra appear.

If more than one inequivalent law survives, preserve the whole family and identify the exact missing axiom/choice separating them.

If only trivial laws are N0-definable, prove the strongest no-go and stop.

Required theorem:

`R064_PHASEA_INTERACTION_LAW_OR_NO_GO.md`.

## 7. Internal-state emergence and finite closure

If the interaction law generates internal states beyond the original elementary path-event types, classify the closure process without preselecting its cardinality.

For every generated state `s`, require a finite provenance DAG

`N0 primitives -> N0-definable local contexts -> construction steps -> s`.

Then determine:

- whether the closure is finite;
- its exact cardinality if finite;
- whether that cardinality is forced or presentation-dependent;
- whether repeated composition is closed;
- whether different generation orders give canonically equivalent state systems;
- the smallest counterexample if confluence/closure fails.

A state label with no such DAG is not evidence of an N0 state.

Required result:

`R064_PHASEA_MINIMAL_INTERNAL_STATE_CARRIER.md`.

## 8. Minimality / missing-axiom theorem

A positive result must prove minimality at the exact strength claimed.

Classify each theorem-critical ingredient as one of:

- `N0_PRIMITIVE`;
- `N0_DEFINABLE_DERIVED`;
- `NECESSARY_ADDITIONAL_N1`;
- `REDUNDANT`;
- `UNRESOLVED`.

A negative result must identify the smallest missing distinction or operation that prevents uniqueness/existence, without adding that missing axiom inside this phase.

The task must not repair a no-go by inventing a new operational primitive after seeing the obstruction.
