## A. 联合世界—读时分布是误差预算的正确对象

令 \(\Omega\) 为有限正权世界历史集，\(\mu(w)\ge0\)、\(\sum_w\mu(w)=1\)，各读数 \(z_t(w)\) 取复数或赋范向量空间且 \(\|z_t(w)\|\le1\)。令 \(Z_t=\sum_w\mu(w)z_t(w)\)。定义两个理想窗口
\[
Y^{(3)}_n=(Z_n+Z_{n+1}+Z_{n+2})/3,\quad
Y^{(2)}_{n+1}=(Z_{n+1}+Z_{n+2})/2.
\]
它们共用同一准备和时标。代数恒等式 \(Z_n=3Y^{(3)}_n-2Y^{(2)}_{n+1}\) 对任意未来序列成立，不依赖十二周期。

令 \(h_i(d)\) 是理想窗口核（i=3 对 d=0,1,2 等权；i=2 对 d=0,1 等权），允许实际观测核 \(q_{i,t}(w,d)\ge0\) 在同一世界历史及整数时间偏移上任意相关，\(\sum_{w,d}q_{i,t}(w,d)=1\)。理想联合核为 \(p_{i,t}(w,d)=\mu(w)h_i(d)\)（理想支持外为0）。设
\[
\Delta_{i,t}=\sum_{w,d}|q_{i,t}(w,d)-p_{i,t}(w,d)|.
\]
实际报告为 \(\widetilde Y_{i,t}=\sum q_{i,t}(w,d)\widetilde z_{t+d}(w)+e_{i,t}\)，其中 \(\|e_{i,t}\|\le\varepsilon_{i,t}\)、在该报告的实际支持上 \(\|\widetilde z-z\|\le\rho_{i,t}\)；此项可代表已经单独界定的动态/观测响应差异。则
\[
\boxed{
\|3\widetilde Y_{3,n}-2\widetilde Y_{2,n+1}-Z_n\|
\le 3(\Delta_{3,n}+\rho_{3,n}+\varepsilon_{3,n})
+2(\Delta_{2,n+1}+\rho_{2,n+1}+\varepsilon_{2,n+1}).
}
\]
证明：对每一报告，添加并减去同一联合核下的 \(z\)，利用 \(\|z\|\le1\) 及归一化 q，得 \(\|\widetilde Y-Y\|\le\Delta+\rho+\varepsilon\)；再应用确切反演恒等式及三角不等式。给定逐报告独立有界加性噪声，权重 3 和2 的和5 可通过相反符号的极值噪声达到；不主张带共享相关噪声时仍为最优。

该定理一次处理准备差异、非独立时钟、窗口校准及单次读数扰动；各预算必须针对联合分布而非仅边缘分布。若每个 n=0,...,N 的相应 \(\Delta,\rho,\varepsilon\) 有统一上界，即得到整个指定未来操作集合的统一保证。每个目标 n 用两份已对齐窗口报告，最迟需读取到 n+2；逐 n 直接报告的朴素资源数为 2(N+1)，不是最小值声明。

## B. 只看时间边缘的预算失败：精确有限正权反例

取三条等权世界 \(w=j\in\mathbb Z_3\)，各偏移 \(d=0,1,2\)，设 \(z_d(j)=\omega^{j-d}\)，其中 \(\omega^3=1\), \(1+\omega+\omega^2=0\)。每个固定时间的总体均相位为0。独立均匀时标 \(p(j,d)=1/9\) 的平均读数为0；相关时标 \(q(j,d)=\tfrac13 1_{d=j}\) 的平均读数为1。两种读法的时间偏移边缘都严格为均匀的 \(1/3\)，而联合 \(L^1\) 距离为 \(4/3\)。所以仅从 \(\sum_w q(w,d)=h(d)\) 无法得出任何趋零的读数误差界。这里的反例与原 temporal-aperture 文档的有关例证同源，作为本联合定理的锐化检验，不标注新 BRC 构造。

## C. 有限时间资源下的动态误差推论

额外假设观察时钟独立且固定为上述 h_i，两个准备的读数来自同一有限状态空间的归一化正权 Markov 演化：名义核 T，实际第 k 步核 T'_k；初值 \(\|\mu'_0-\mu_0\|_1\le\eta_0\)，且 \(\sup_x\|T'_k(x,\cdot)-T(x,\cdot)\|_1\le\eta_k\)。逐步 telescoping 与随机核的 L1 收缩给出
\[
\|\mu'_t-\mu_0T^t\|_1\le \eta_0+\sum_{k<t}\eta_k.
\]
于是对理想窗口的实际等权读出（另加报告噪声 \(\varepsilon_i\)）可用
\[
\Delta_{3,n}\le \eta_0+\tfrac13\sum_{d=0}^2\sum_{k<n+d}\eta_k,\quad
\Delta_{2,n+1}\le \eta_0+\tfrac12\sum_{d=0}^1\sum_{k<n+1+d}\eta_k.
\]
若每步 \(\eta_k\le\eta\)，则对全部 \(0\le n\le N\)：
\[
\boxed{\|\widehat Z_n-Z_n\|\le 3\varepsilon_3+2\varepsilon_2+5\eta_0+(5N+6)\eta.}
\]
这是可核算的有限操作时间及误差资源预算，允许某些项相关导致更好界。它不是任意长时间都很小的保证：取二状态名义 T=I、实际每步以 \(a>0\) 概率翻转两态，从状态0出发、输出 \(f(0)=1,f(1)=-1\)，名义期望始终为1，实际第 n 步为 \((1-2a)^n\)。尽管每步核 L1 偏差仅 \(2a\)，偏差随 n 增大趋于1。控制/反馈若非上述同一 Markov 和独立时钟合同，须重新界定对应 \(\Delta\) 或额外 \(\rho\)，不能直接沿用该推论。
