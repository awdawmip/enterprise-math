## 本次新增的数学信息

保留十二个 signed ports 和完整 X6。设每个 incoming p 的非空三元族 H_p 均含 p，且三个轴互异，仍按 U2 在族内均分响应预算。由实际正 BRC 分支组合得到 K_H(q,p)，定义 r(q)=sum_p K_H(q,p)。

列守恒、对角 1/3 和带输入标签的恰好 2/3 变轴仍成立；固定位置、固定线性转移、0<rho=12lambda<1 下的总响应尾界也保留。但均匀入射的首次发射变成 lambda r(q)，一般不再各向等量。

因此两条边的自身返回必须写成

    R_a^(2) = lambda² [12 + 3 sum_(occupied neighbor q) r_a(q)]。

旧的 `(12+3d_a)lambda²` 对一个具体准备成立，当且仅当该邻向集合的行和之和等于 d_a；若要求对任意邻向准备成立，则当且仅当每个 r(q)=1。这不是推翻原默认公式，而是明确它不能随任意合法关联的引入自动迁移。

进一步，对一个全局一致的三元超图 H，令每个入射均匀选取所有含它的三元组，d(p) 为该端口的关联度。证明了：

    均匀入射仍均匀发射
    ⇔ 每个行和等于 1
    ⇔ 每个关联连通分量内 d(p) 恒定。

不同连通分量可以有不同度数。证明直接使用有限正 BRC 读出和最大值论证；不借用原生欧氏向量平衡或经典传播器。完整假设、证明、量词和边界见 [INCIDENCE_REGULARITY.md](INCIDENCE_REGULARITY.md)。

可手工核对的五三元组反例为

    {+1,+2,+3}, {-1,-2,-3}, {+4,+5,+6}, {-4,-5,-6}, {+1,+4,+5}。

所有端口都有合语法的 anchored incidence，但 r(+1)=4/3、r(-1)=1。在初始相邻两单位 c,c+E1、lambda=1/48 上，真实 BRC 两步计算得到 `(1/144, 5/768)`；照搬旧邻居计数公式会给 `(5/768, 5/768)`。这是一项**条件电路公式迁移的反例**，没有宣称该超图是合法原生作用，也不是两个合法原生占位完成的非唯一性证明。见 [INCIDENCE_TRANSFER.md](INCIDENCE_TRANSFER.md) 与实际检查记录。

证书逐项区分直接前提、源内条件定理、候选关系和 UNKNOWN，并给出联合后继关系的类型及依赖图。现状属于 **SOURCE_INTERFACE_GAP**：没有证明 native 相容、native 不相容或 native 非唯一。阻断是具体的本构缺口，不是计算深度、软件安装或原作者不在线。见 [INTERFACE_CERTIFICATE.md](INTERFACE_CERTIFICATE.md)。
