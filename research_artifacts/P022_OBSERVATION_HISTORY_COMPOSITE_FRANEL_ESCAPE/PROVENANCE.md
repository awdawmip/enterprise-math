# Provenance boundary

The starting equivalence `p | F_(2M) iff T_M = 0 (mod p)` and the earlier
integer kernel `U_M` are pre-existing P022 owner-branch results.

The new checkpoint contribution is:

1. the exact four-step terminating transform from `T_M` to the double-horizon
   integer kernel `K_M`;
2. the exact rational conversion between `K_M` and the prior `U_M`;
3. the sign-free modulo-`p` companion `W_M`;
4. specialization of that companion to the Driver-routed `M=3m` boundary;
5. the root-of-unity three-section as the next active proof surface.

The classical terminating 3F2 transformation is prior art; DLMF §16.4(iii)
provides the standard transformation framework.  No novelty claim is made for
the transformation formula itself.
