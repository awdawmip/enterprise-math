## 全区域证明核
对有理叶盒`R=prod_k[L_k,H_k]`构造精确下界。函数`g_u(x)=(Z-x)/abs(u-x)`在活动坐标的合法相邻节点区间内单调，故每个固定支路`T_j`的严格有效下界为
```
lower_T_j(R) = W_j * prod_{k in I} (
    abs(U_j-U_k)/(Z-U_k)
    * min((Z-L_k)/abs(U_j-L_k), (Z-H_k)/abs(U_j-H_k))
)
```
由于`0<L_k<=v_k<=H_k<1`，函数`[(2-p²)(3-p²)]^-3`递增，且
`abs(v_k-u) <= max(abs(L_k-u),abs(H_k-u))`，
`(Z-v_r)/abs(v_k-v_r) >= (Z-H_r)/max(abs(L_k-H_r),abs(H_k-L_r))`，
所以每个活动支路有精确有效下界
```
lower_M_k(R) =
   Q*A/H / ((2-L_k^2)*(3-L_k^2))^3
   * prod_{j in J} (Z-U_j)/max(abs(L_k-U_j),abs(H_k-U_j))
   * prod_{r != k} (Z-H_r)/max(abs(L_k-H_r),abs(H_k-L_r)).
```
