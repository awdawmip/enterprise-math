# 补充：固定四标签 BRC 中“所有下一步下降”仍不等于永久吸收

2026-10-24 | 作者侧精确五轮反例；未审查，未进入 Source 状态机。

## 与主文的关系

主文证明，有限前驱 Hall 证书 K_1 要求 **所有当前动作增量非正**，并同时要求 **所有紧接的后继状态属于已验证的安全锥 K_0**。第二个条件不能省略：这里在前驱固定四标签三动作模型中给出严格反例。

沿用 V={0,1,2,3}、E={01,12,13,23} 以及

q_0=(1,665,1,333)/1000，
q_2=(333,333,1,333)/1000，
q_3=(1,1,1,997)/1000。

历史 h=222，计数 c=(0,3,0)。尽管从 c 追加任何一个允许动作，当前占有概率都**严格下降**：

Δ(c,0) = −414305561/31250000000 <0，

Δ(c,2) = −12398083173/125000000000 <0，

Δ(c,3) = −23111249741/125000000000 <0。

但先追加动作 3 后再追加 0，则从 c'=(0,3,1) 追加 0 有

Δ(c',0) = +2951045627123/125000000000000 >0。

因此词 22230 的第5轮会发生真正的残差增长。用 δ 为“恰好两个标签组成好边”的占有概率，R 为正变差减历史峰值，精确值为：

δ_2(22)=55611/125000，
δ_3(222)=6934059/15625000，
δ_4(2223)=32361222259/125000000000，
δ_5(22230)=35312267886123/125000000000000。

历史最大值 δ_2 > δ_5；第4轮 R_4=0，第5轮

R_5−R_4 = 2951045627123/125000000000000 >0。

上列五个前缀由整数容斥公式计算，并由独立的16个占有掩码 Fraction 递推逐一交叉核验（空前缀单独定义 δ_0=0）。

**严格结论**：对于固定三动作辅助模型，要求 Δ(c,a)<0 对每个允许 a 成立，不足以保证未来占有概率永久下降，也不足以保证未来残差冻结。Hall 前驱递归中的“每个后继已获永久安全证书”是实质条件，不能删去。

此例是局部负增量在未来反转的证据，不是 K_1\K_0 证人。主文的 K_1\K_0 证人属于另一个明确限定的三标签单动作模型。二者研究范围保持分离；都未经独立 Driver 审查，均不声明 P000 原生六维动力学定理。
