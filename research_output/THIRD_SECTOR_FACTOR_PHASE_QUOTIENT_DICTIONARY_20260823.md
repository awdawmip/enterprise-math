# Third-Sector Factor Phase — Theorem and Quotient Dictionary

Status: `FROZEN_INDEPENDENT_DICTIONARY`

## Arithmetic objects

For

`n=2^alpha product_{p==1 (4)}p^{e_p} product_{q==3 (4)}q^{f_q}`,

the dictionary uses:

| Symbol | Meaning |
|---|---|
| `C(n)` | split core `product_{p==1 (4)}p^{e_p}` |
| `epsilon` | `alpha mod 2` |
| `h(n)` | `2^{floor(alpha/2)} product_{q==3 (4)}q^{f_q/2}`, defined for admissible even `f_q` |
| `K(C)` | divisor/exponent-choice lattice `Div(C) ~= product_p {0,...,e_p}` |
| `J` | complement involution `d -> C/d`, or `k_p -> e_p-k_p` simultaneously for every `p` |
| `pi_p` | canonical `r_p+i s_p`, `r_p>s_p>0`, `r_p^2+s_p^2=p` |
| `Z_d` | `h(1+i)^epsilon product pi_p^{k_p} conjugate(pi_p)^{e_p-k_p}` |
| `U_2(n)` | normalized cells `(a,b)` with `a>=b>=0`, `a^2+b^2=n` |
| `t` | reverse parity factor `gcd(n,2)` for primitive `n` |
| `m` | reverse split core `n/t` for primitive `n` |

## Quotient actions

| Operation on a Gaussian representation `z` | Coordinate action | Exponent/divisor action | Already generated by |
|---|---|---|---|
| unit `-1` | simultaneous sign change | none | unit group |
| unit `i` | `(-b,a)` rotation | none | unit group |
| conjugation | `(a,-b)` reflection | `d -> C/d` | residual involution `J` |
| swap | `(a,b)->(b,a)` | `d -> C/d` after a unit | `i` plus conjugation |
| global reflection | sign/reflection variant | `d -> C/d` | unit plus conjugation |

Consequences:

- signed ordered representations modulo units are in bijection with `K(C)`;
- unit classes modulo conjugation are in bijection with `K(C)/<J>`;
- each unit/conjugation orbit has exactly one representative in `U_2(n)`;
- swap, global reflection, and conjugation are not independent post-unit quotients.

## Theorem dictionary

### T1 — existence

`U_2(n)` is nonempty iff every `q==3 (mod 4)` has even exponent.

### T2 — forward bijection

`K(C)/<J> -> U_2(n)`, `[d] -> normalize(Z_d)`, is bijective.

### T3 — representation count

With `R=tau(C)=product(e_p+1)` and `F=1` iff every `e_p` is even,

`|U_2(n)|=(R+F)/2`.

The signed ordered count is `4R`.

### T4 — fixed point

The unique fixed divisor, when it exists, is `d=sqrt(C)`.

- `epsilon=0`: fixed cell `(h sqrt(C),0)` (axis);
- `epsilon=1`: fixed cell `(h sqrt(C),h sqrt(C))` (diagonal).

### T5 — exact scale

For `d=product p^{k_p}`,

`gcd(Phi([d]))=h gcd(d,C/d)=h product p^{min(k_p,e_p-k_p)}`.

### T6 — primitive criterion

`Phi([d])` is primitive iff:

- `alpha<=1`;
- no inert prime divides `n`;
- `k_p` is `0` or `e_p` for every split prime.

For `s>=1` distinct split primes, primitive quotient-cell count is `2^{s-1}`; for `s=0`, it is one.

### T7 — factor-driven generator

Recursing over every `k_p`, retaining exactly `d<=C/d`, and normalizing `Z_d` emits every element of `U_2(n)` exactly once.

### T8 — reverse recovery

For distinct primitive quotient cells `(a,b)` and `(c,d)`:

`A=gcd(m,|ac+bd|/t)=gcd(m,|ad-bc|/t)`,

`B=gcd(m,|ac-bd|/t)=gcd(m,|ad+bc|/t)`.

Then `AB=m`, `gcd(A,B)=1`, and `A,B>1`. Units/conjugation preserve `{A,B}` and may swap its entries.

## Fixed-point and stabilizer dictionary

| Divisor orbit | Cell type | Divisor stabilizer | Nonnegative ordered multiplicity |
|---|---|---:|---:|
| `d<C/d` | generic `a>b>0` | none | 2 |
| `d=C/d`, `epsilon=0` | axis `a>0,b=0` | complement fixed | 2 |
| `d=C/d`, `epsilon=1` | diagonal `a=b>0` | complement fixed | 1 |

The complement fixed point is the only correction in the unordered count.

## Multiplicative-fiber dictionary

For `C>1`, a divisor choice is the ordered point

`d <-> (d-1,C/d-1) in M(C)`.

Complement is coordinate swap. Selecting `d<=C/d` is selecting the `x<=y` half of the ordered fiber. The full fiber `M(n)` is not the correct parameter space unless `n=C`; powers of `2` and inert square factors are shape-neutral scale data represented by `h` and `epsilon` instead.

For `C=1`, the divisor lattice remains the singleton `{1}` even though the packet defines `M` only for arguments greater than one. This handles `n=1,2`, powers of `2`, and pure inert-square shapes without inventing an `M(1)` point.

## Reverse failure dictionary

| Input condition | Outcome |
|---|---|
| two distinct primitive quotient cells | exact nontrivial coprime recovery |
| same cell through sign/swap/conjugation | trivial `{1,m}` partition |
| primitive norm with fewer than two quotient cells | no reverse input pair exists |
| equal nonprimitive scales | divide both by the common scale; recover on reduced norm only |
| unequal nonprimitive scales | no common primitive norm; theorem inapplicable |
| omit `t=2` for primitive even norm | factors share `2`, product normalization fails |
| odd inert exponent admitted | forward soundness fails; no square cell exists |
