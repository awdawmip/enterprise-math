## 目的

自由研究者不是队列执行者、接续研究者，也不是经过伪装的“有趣问题”菜单的接收者。

默认路径：

`SNAPSHOTTED PRIMITIVE SUBSTRATE -> RESEARCHER GENERATES ITS OWN QUESTION -> FROZEN AXIOM CANDIDATE -> ONLY THEN CURRENT/PRIOR-WORK COMPARISON`。

本协议降低近期信息、任务、路线、成功与失败、否定指令、周边上下文、工具可用性、表示、建议菜单，以及事后或分配后知识造成的锚定。

固定要求：

`FOUNDATION_FOR_DISCOVERY != CATALOG_OF_CURRENT_ACHIEVEMENTS`。

`NO_DEFAULT_DISCOVERY_LENS_MENU`。

`NEGATIVE_INSTRUCTION_MUST_NOT_ENUMERATE_SALIENT_FORBIDDEN_OBJECTS`。

## 上下文清洁门槛

已经存在于活动上下文中的显著路线或成果信息，模型无法真正“忘记”。

优先启动方式：

`FRESH EM-FREE CONTEXT -> PRIMITIVE-SUBSTRATE BOOTSTRAP -> AXIOM_DISCOVERY`。

`PHASE_A_CONTEXT_CLEAN_REQUIRED_FOR_BLIND_LABEL = true`。

`PREEXISTING_AGENDA_EXPOSURE_CANNOT_BE_UNREAD = true`。

候选生成前，若议程或当前成果信息已实质存在，应标记：

`BLINDNESS_STATUS = ANCHOR_EXPOSED`。

不得仅因后续指令要求忽略已见信息，就声称具有盲发现来源。

## 基础与世界观快照

开始 A 阶段实质适应之前，记录并固定：

- `FOUNDATION_SNAPSHOT_REF`：原始基础路由及实际加载的每份精确原始文件；
- 相关时记录 `WORLDVIEW_SNAPSHOT_REF`。

A 阶段针对该冻结起始包推理，不反复追赶移动中的 `main`。

后续来源变更属于 B 阶段的替代或比较证据。

## A 阶段——仅以原始基础发现

允许的上下文限于理解当前原始承诺及完整性规则所需的最小内容：

1. 自由角色的全局与项目启动入口，以及相关、受保护的 ACTIVE 世界观事实；
2. `definitions/00_FREE_AXIOM_DISCOVERY_SUBSTRATE.md`；
3. 由该基础包明确路由且实际需要的精确原始定义；
4. 候选提出相应主张时所需的基础或原生语义类型；
5. 仓库安全、身份与来源规则。

A 阶段**不得预加载** `definitions/00_CURRENT_NATIVE_FOUNDATION.md`。这是面向 TASK、Driver、当前状态查询及 FREE B 阶段的通用当前数学或当前成果路由。

不得在面向 A 阶段的禁止语句中枚举该路由的下游内容。通用边界已经足够：

> **当前下游成果、活动路线、任务或协调状态、成功与失败目录、建议问题、近期项目记忆、已有工具、实现表示、文件顺序和既有研究词汇，均不得选择 A 阶段问题；用户当前指令明确将某项作为前提时除外。**

这是信息边界，不禁止之后的比较。

## 不提供发现建议菜单

在首个候选之前，控制平面不提供默认的“值得寻找什么”、偏好不变量、公理类别、障碍家族、证明方法或概念模板清单。

即使看起来通用的清单，也可能让独立研究者集中于相同概念并制造人为收敛。

因此：

`NO_SUGGESTED_QUESTION_LIST`。

`NO_SUGGESTED_AXIOM_CATEGORY_LIST`。

`NO_SUGGESTED_DISCOVERY_LENS_LIST`。

研究者先从原始基础中自行写出实质问题。

若研究者独立选择了熟悉概念，这仍是其研究结果；控制平面没有预先植入该概念。

## A 阶段的工具

工具可以检验或枚举从基础中独立形成的问题。

禁止的倒置：

`TOOL_EXISTS_OR_IS_EASY -> THEREFORE_STUDY_THAT_OBJECT`。

允许的方向：

`RESEARCHER_GENERATES_QUESTION -> CHOOSE_MINIMAL_TOOL_TO_TEST_IT`。

独立问题实际包含相关类型化结构之后，即使候选尚未冻结，也可读取所需的精确定义、适用条件及工具资料。在已有笔记中保留问题与来源的关系。此许可不在 B 阶段之前开放整份工具或成果清单、当前工作比较或去重。使用基础与角色路由所述的 A 阶段基础包和实际精确选择读取器；错误、诊断及回退与成功读取遵守相同的信息范围。合法且相关的查询本身不是阶段转换，也不消除此前已发生的议程暴露。

因此：

`TOOL_AVAILABILITY != DISCOVERY_PRIOR`。

`IMPLEMENTATION_CONVENIENCE != AXIOM_PRIOR`。

`FILE_ORDER != RESEARCH_PRIORITY`。

`EXISTING_NAME != REQUIRED_PRIMITIVE`。

## A 阶段冻结

打开当前或既往议程、通用下游成果比较上下文之前，先冻结 `research_axiom_candidate_state_machine.json` 所要求的包。前述问题先形成、再精确查询的许可继续适用。

必需内容包括：

- 候选陈述；
- 基础与世界观快照引用；
- 原始依赖；
- 语义层；
- 不依赖路线的结构动机；
- 直接推论；
- 明显的否证方式或反例；
- `BLINDNESS_STATUS = CLEAN` 或 `ANCHOR_EXPOSED`；
- 可行时的稳定时间或哈希。

只有 `CLEAN` 能作为独立盲发现的证据。

不得在看到已有工作后改写 A 阶段措辞，仅为使候选看起来更一致、更新颖或更成功。

这是一项分配后保护：后续知识可以重新分类候选，但不能追溯制造其起源。

## B 阶段——比较与碰撞审计

冻结后，打开通用当前路由及当前或既往上下文，用于：

- 去重；
- 精确的矛盾或反例检验；
- 公理与推导定理的分类；
- 实现或载体泄漏审计；
- 当前工作比较；
- 已有工作或新颖性分类；
- 验证工具选择。

这些是候选已经存在之后的审计功能，不是 A 阶段发现提示。

碰撞属于比较结果，不得追溯把该会话改为接续研究。

## 独立自由研究复现

独立复现应当：

1. 使用彼此分离的新上下文；
2. 需要可比性时，从同一冻结的原始基础与世界观快照开始；
3. 各运行分别冻结前，不互相展示候选包；
4. 独立冻结后才比较。

`INDEPENDENT_CONVERGENCE = STRUCTURAL_INTEREST_SIGNAL_NOT_PROOF`。

`DIVERGENT_CANDIDATES = PRESERVE_BEFORE_DRIVER_SELECTION`。

共享建议或视角菜单造成的人为收敛，不是独立收敛的证据。

## 完整性边界

本协议不授权静默修改规范内容。自由研究者可以质疑当前基础并提出替代，但晋升仍由 Driver 或用户决定，并遵循正常的证据与晋升路径。

自由指发现方向的自由，不是伪造证据的自由。
