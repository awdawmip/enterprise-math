# 进取数论

> **连续统是伟大的近似，但不是自然的底层。精度不是误差，而是数本身的一部分。**

进取数论（Enterprise Math）是一项试图从**有限分辨率、离散状态、整数优先和本征前向演化**重新建立数学底层的开放研究计划。

[英文版](README.md)

> **非数学读者入口：** [进取数论眼中的世界](docs/THE_WORLD_IN_ENTERPRISE_MATH.zh-CN.md) — 不需要高等数学，从精度、时间、空间一直读到量子、宇宙与极端因果问题。

## 宣言：数学大楼的根基需要重建

我们选择把立场说清楚。

**我们认为，现有数学大楼在用于描述自然时，根基存在一个致命的抽象错误：人类把本质上离散、有限分辨率、有限信息的自然规律，长期默认抽象成了连续、无限可分、无限精度的结构。**

最典型的代表就是连续实数轴：任意两点之间永远还能插入更多点，任何区间都可以无限细分，一个“点”被赋予无限精确的位置。这个结构作为纯形式数学当然可以自洽，也已经支撑了极其辉煌的分析、几何和物理理论；但**形式上的成功，不等于它就是自然的原生结构**。

过去几个世纪，无数天才数学家在这座大楼里继续向上建造。我们认为真正的问题不在这些数学家，而在他们继承的地基：当有限精度、量子化、离散化、舍入、测量边界、不可逆性或信息损失出现时，传统路线通常先保留一个隐藏的连续世界，再把这些现象解释成近似、误差、噪声、数值截断或外部限制。

进取数论把这个顺序彻底反过来。

如果自然从来不提供无限信息，为什么描述自然的“数”要先被定义成无限精确的点？

如果尺度改变会改变哪些状态能够被区分，为什么精度只能是计算结束后的误差条？

如果一个多对一演化真的把许多状态压成同一个状态，为什么必须假设差异仍然以某个隐藏连续余量存在？

如果时间中的状态更新本来具有方向，为什么数学底层必须先假定一个可以无限细分、往往又被理想化为可逆的连续流？

我们的回答是：**不必。**

进取数论不再在这个基础问题上保持中立。我们的赌注是：

- 自然的数值状态具有有限信息；
- 精度 / 分辨率属于数值状态本身，而不是附注；
- 离散状态与整数运算可以是原语，而不是连续量的低精度替身；
- 坍缩、商、合并和信息损失可以是真正的数学演化，而不是必须被隐藏变量“补回去”的缺陷；
- 连续性若在宏观世界中成立，应当作为大尺度结构、极限行为或有效近似被**导出**，而不是在起点被默认写进本体。

这是一场可以失败的赌注。如果这些原语最终无法重建足够强的代数、几何、动力学和物理，它就应该被证明失败；如果它能做到，那么需要被重新审视的就不是某一条公式，而是我们习惯了几百年的出发点。

**我们选择孤注一掷地把这条路推到底。我们的判断是：时间和物理最终会证明，进取数论所代表的方向才是面向自然数学的未来。**

## 五个基础倒置

传统路线通常是：

```text
连续实数 / 连续空间
    ↓
选择数值精度
    ↓
舍入、离散化、网格化
    ↓
计算 / 测量 / 仿真
```

进取数论尝试建立相反的路线：

```text
有限状态 + 显式尺度 / 精度
    ↓
精确整数运算
    ↓
坍缩 / 商 / 关系 / 支撑
    ↓
本征前向动力学
    ↓
离散几何与可观察结构
    ↓
连续模型（如果需要）作为派生近似
```

这带来五个基础倒置：

1. **数不再只有 value。** 自然量至少应携带状态、尺度 / 分辨率以及其所在的物理或计算语境。
2. **精度不再是误差。** 精度决定哪些差异在当前层级上真实可区分。
3. **坍缩不再是假装可逆。** 多对一映射可以真实改变状态空间的信息结构。
4. **时间不再从可逆性出发。** 前向组合、历史合流和稳定化本身就是第一类对象。
5. **连续性不再拥有默认特权。** 连续结构必须证明自己能够从离散底层涌现或作为有效近似成立。

## 一分钟进入这套数学

在最早的核心中，整数 \(p\) 次根定义为

\[
R_p(n)=\max\{k\in\mathbb N:k^p\le n\}.
\]

因此，

\[
R_2(2)=1,\qquad R_2(200)=14,\qquad R_2(20000)=141.
\]

对应的坍缩算子是

\[
C_p(n)=R_p(n)^p.
\]

于是

\[
C_2(20000)=19881.
\]

从 19881 到 20163 的每一个整数，在平方坍缩下都映射到 19881。

传统直觉很容易追问：“丢掉的差值去了哪里？”  
进取数论首先提出另一个问题：**为什么它必须还在？**

如果当前尺度只保留完全平方这一层结构，那么同一盆地中的状态可以在这次演化后真正合并。我们先研究这个离散规则本身会产生什么数学，再决定它是否、以及如何对应自然。

## 这已经不只是一个想法

进取数论不是给传统公式换一套哲学解释。仓库已经从最早的 root / collapse 核心扩展出自己的定理族、反例族、形式化资产和可执行研究面。

已经进入 canonical `main` 的结果包括：

- **整数根与 carry 结构**：整数根超乘性、精确乘法判据和 carry 边界；
- **坍缩代数**：不同指数的完全幂坍缩何时交换，以及有限坍缩词的不动点分类；
- **尺度代数**：以整数总尺度因子建立整除投影、gcd/lcm 尺度格和路径无关结构；
- **离散除法与带类型状态**：区分商、同空间坍缩、可逆商余状态，并研究严格下降、终止与合流边界；
- **历史与不可逆性**：确定性前向映射中的历史合流、前像 multiplicity、碰撞谱和整数不可逆性观察量；
- **离散几何**：从 primitive-step graph distance 建立整数度量，而不是先嵌入连续欧氏空间；
- **稳定化理论**：良基偏序上单调向下映射的有限稳定化，以及坍缩词的稳定等价结构；
- **未来安全的精度**：研究一个粗粒度状态在后续操作与观察下何时仍然足够，以及最小修复需要恢复什么信息。

正在继续推进的研究还包括 Legendre 压力测试、有限精度证明演算、composition-safe collapse、action-language precision、root-lattice geometry、causal boundary，以及材料 / 碰撞 / 世界状态更新等工程物理实验。

这些层次的证明状态并不相同；精确状态由 [权威问题状态索引](docs/PROBLEM_STATUS.zh-CN.md) 和对应 theorem/result 文档控制。

## 我们要建的不是一个算子，而是一套底层

进取数论的目标不是把 \(C_p\) 变成另一个孤立的特殊函数，而是逐层建立一套能够自己站立的数学：

- **A0 — 离散状态代数**：整数根、坍缩、gap / basin、尺度、商余、signed / typed state；
- **A1 — 前向动力学**：composition、collision、history merge、stabilization；
- **A2 — 精度与观察**：observation、quotient、future-safe equality、minimal repair；
- **A3 — 关系状态**：不把全部结构压回单个标量值，而研究状态之间的整数关系场；
- **A4 — 支撑与对应**：多值关系、witness、common-target 与组合可保留性；
- **A5 — 本征离散几何**：从离散 primitive 与可达关系构造距离、壳层和几何；
- **应用层**：把这些结构送进数论压力测试、碰撞、材料、因果边界和世界状态演化。

最终目标是让“数—精度—代数—动力学—几何—物理”形成同一条离散底层链，而不是每次遇到离散现象都重新从连续世界向下近似。

## 自信不等于取消证据纪律

如果进取数论真的要挑战底层，它就必须比普通新想法更容易被攻击，而不是更难。

因此仓库明确区分：

1. **定义**——我们选择怎样的离散原语；
2. **已证明数学结果**——从这些原语严格推出并进入 canonical `main` 的结论；
3. **可执行 / 有限验证结果**——可用于发现、反例和回归，但不自动等于证明；
4. **物理与本体主张**——关于自然是否真的如此，必须接受实验和观测。

我们不会为了显得“谨慎”而把核心立场写成没有方向的问句，也不会为了显得“自信”而把尚未证明的东西冒充成定理。

**方向可以激进，证据必须残酷。**

## 原创不是靠不知道前人

进取数论不把 prior art 当作威胁。

如果某个工具已经存在，我们就吸收它；如果某个定理属于经典数学，我们就明确归因；如果我们的结构只是旧理论的特化，就把边界写清楚。我们要争取的原创不是“从未读过别人”，而是：

- 是否选出了不同的底层原语；
- 是否把原本分散的结构组织成新的统一体系；
- 是否由此得到新的定理、反例、算法、几何或物理预测；
- 是否能够解释传统连续框架中被当作误差或外部修补的现象。

当前各组件的历史优先性继续由 `sources.json`、`lineage.json` 与 [前人工作谱系](docs/PRIOR_ART_AND_NOVELTY.zh-CN.md) 管理。对某个具体结果声称“首次”仍然需要证据；这不妨碍我们明确地说：**进取数论正在建设一套属于自己的数学体系。**

## 来攻击它

你不需要先相信进取数论。

最有价值的贡献不是说“这个想法很有意思”，而是：

- 找出一个错误定义；
- 给一个候选定理构造反例；
- 找到一个更弱、更精确的假设；
- 证明一条开放命题；
- 找到我们漏掉的前人工作；
- 把一个稳定结果形式化进 Lean；
- 设计一个能够直接杀死物理主张的实验；
- 或证明连续结构确实无法从我们选择的离散底层恢复。

如果这条路是错的，我们希望尽快知道它错在哪里。  
如果它是对的，我们要把它一直推到足以替代旧地基的位置。

见 [参与指南](CONTRIBUTING.zh-CN.md)。

## 当前状态

进取数论仍处于 **Research Beta**。完整的几何、微积分、物理和热力学还远未完成，许多研究路线仍然开放。

但这不再意味着我们对方向没有判断。

**我们对细节保持怀疑，对证据保持苛刻，对底层方向不再退缩。**

连续数学已经证明了自己是一种伟大的工具。进取数论现在要回答一个更大的问题：

> **如果自然从一开始就不是连续的，那么数学应该从哪里重新开始？**
