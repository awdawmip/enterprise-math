# 进取数论

进取数论是一项处于早期阶段的数学研究计划，核心方向是有限分辨率、整数闭合运算以及本体上的不可逆状态坍缩。

[英文版](README.md)

## 核心思想

本项目**不**先假定一个隐藏的连续实数体系，再用整数去逼近它，而是直接从整数状态本身出发。

目前的工作方向是：

1. 整数是基本数值状态。
2. 分辨率与尺度是数值描述本身的一部分。
3. 运算应返回同一离散体系中的合法状态，而不是制造一个隐藏的分数、无理数或连续实数答案。
4. 整数平方根在本体系中被视为精确运算：

   \[
   R_2(n)=\max\{k\in\mathbb N:k^2\le n\}.
   \]

   因此，在本体系内部，

   \[
   R_2(2)=1,\qquad R_2(200)=14,\qquad R_2(20000)=141.
   \]

5. 与之对应的平方坍缩算子定义为

   \[
   C_2(n)=R_2(n)^2.
   \]

   因而

   \[
   20000\rightarrow19881.
   \]

   实际上，从 19881 到 20163 的所有状态在 \(C_2\) 下都会坍缩到 19881。
6. 前态与后态之间缺少的差值不被假定为某个隐藏余量继续存在。状态转移本身就是多对一的。
7. 因此，时间、不可逆性和熵将从不可逆映射的前向复合与前像结构出发研究，而不是预设一个可逆的微观底层。

## 本项目不是什么

进取数论目前不是一个已经得到证明的物理理论。它首先是一个研究计划：建立定义、推出定理、寻找矛盾、构造反例、比较前人体系，并检验是否能够在不偷偷恢复连续实数底座的前提下建立自洽的离散数学基础。

传统实分析、代数数精确运算、浮点运算、粗粒化和可逆微观动力学仍然是重要的对照体系，但它们不被预设为本项目的自然本体。

## 当前研究问题

- 哪些算术运算能够定义为严格闭合在整数状态上的精确映射？
- 尺度如何组合，才能不把小数重新作为隐藏原语引入？
- 传统代数恒等式中，哪些保留、哪些弱化、哪些失效？
- 哪些坍缩算子具有单调、幂等、序伴随或可组合结构？
- 纯前向、多对一的动力学能否自然产生一个描述历史合流程度的单调量？
- 当欧氏距离不再预设取值于完备连续实数轴时，几何应该如何重建？
- 能否在不假定隐藏信息被擦除的前提下，把热力学时间与熵联系到状态坍缩的前像退化度？

## 研究纪律

新增结论必须区分定义、已证明定理、计算观察、猜想和物理解释。形成新术语之前，应先检索最接近的已有数学与前人经验。与已有理论相似，只说明可能存在有价值的连接，不等于证明本项目的物理解释成立。
