# 进取数论

进取数论是一项开放研究计划，研究有限分辨率、整数优先的数学，以及本征前向的状态演化。

[英文版](README.md)

## 一分钟理解

本项目**不**先假定一个隐藏的连续实数体系，再用整数逼近它，而是研究：如果整数状态和显式尺度才是基本对象，会产生什么样的数学。

在 v0.1 核心中，

\[
R_p(n)=\max\{k\in\mathbb N:k^p\le n\}
\]

被定义为精确的整数根运算。因此，

\[
R_2(2)=1,\qquad R_2(200)=14,\qquad R_2(20000)=141.
\]

对应的坍缩算子是

\[
C_p(n)=R_p(n)^p.
\]

所以

\[
C_2(20000)=19881.
\]

从 19881 到 20163 的每一个整数，在平方坍缩下都映射到 19881。当前研究的本体解释不假定前后差值继续作为隐藏余量存在。

## 我们到底声称什么

进取数论目前有三类完全不同的陈述，不能混在一起：

1. **定义**——例如整数根和坍缩，是我们选择的数学规则。
2. **数学结果**——由这些定义推出并证明的结论。
3. **物理假说**——关于有限分辨率、不可逆性、时间和熵的更强解释，必须接受外部证据检验。

仓库的结构刻意保证：即使未来某个物理解释失败，已经成立的数学结果仍然可以保留。

## 研究测试版 v0.1

当前测试版只冻结一个刻意压缩的核心：

- 自然数状态；
- 整数 \(p\) 次根；
- 完全幂坍缩；
- 离散尺度细化与投影；
- 多对一映射的前向复合；
- 以前像整数数量作为第一种不可逆性观察量。

本测试版**尚未**冻结完整的几何、微积分、物理或热力学体系。

## 前人工作与创新纪律

项目不把“找到相邻数学”视为对原创性的威胁，而是明确记录每一项内容究竟属于采用、对照、重新解释还是组合。

机器可读登记表为：

- `sources.json`——稳定 `SRC-*` 书目与使用记录；
- `lineage.json`——来源到项目构件的关系以及创新状态。

当前整体框架的历史创新状态是 **`NOVELTY_UNVERIFIED`**。我们可以写“我们定义”“我们提出”“我们组合”，但在没有专门优先性审查前，不写“首次”或“前所未有”。

## 五分钟开始参与

你不需要先接受本项目的物理解释。

有价值的贡献包括：

- 证明一个编号猜想；
- 给某个候选恒等式找到反例；
- 改进一个定义；
- 找到与已有数学的精确对应；
- 扩展纯整数参考实现；
- 用 Lean 形式化一个已经稳定的命题；
- 维护规范文档的双语语义一致；
- 提出能够推翻某个物理假说的实验或观测。

参与方式见 [CONTRIBUTING.zh-CN.md](CONTRIBUTING.zh-CN.md)。

## 参考实现

仓库在 `src/enterprise_math/` 下提供一个刻意保持很小的 Python 参考模型。

核心规则严格限制为：

- 不使用浮点常量；
- 不使用真除法；
- 核心运算只接受并返回整数状态；
- 测试在小型有限状态空间中穷举检查 v0.1 不变量。

运行：

```bash
PYTHONPATH=src python -m unittest discover -s tests -v
```

参考实现是可执行规范和反例搜索器，不代替数学证明。
