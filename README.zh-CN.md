## 当前定位：残差保真的离散关系体系

**基础仍是离散的，但当前坐标或压缩读数不默认就是完整状态。** 两个状态即使具有相同终点或标量读数，其路径、支路关联、内部场、回路或来源仍可能改变后续行为。这种结构残差应进入相应的具类型状态，而不是成为可以随手当作噪声删除的附注。

残差保真不要求残差处处非零、很小、取实数或永远存在，也不要求永久保留全部历史。目标是**针对声明的观察和允许的后续操作，找到最小充分状态**；不预设每种模型都有有限、局部的闭合表示。精确零残差、真实多对一演化及经证明的安全商仍是合法数学对象。

无损压缩须保持声明的观察及允许的后续组合；近似压缩须说明适用范围及误差传播界，在相关时明确分辨率、时间窗口和资源。当前不可见不等于可以删除。两个标量异号不足以证明支路相消，还须在适当代数中匹配完整联合状态；正质量不是有符号幅值。

**结构或关系残差、表示或近似误差、实现或推导错误、未分类差异**应分开处理。错误要修正，未知应保留为未知。残差不自动等于能量、温度或力；离散基底标签既不自动保证所有幅值参数离散，也不授权引入隐藏的无限精度实数余量。

原生世界仍是既有 P000 框架下的**心跳世界：六个进取空间维度，加一个独立类型的时间维度**。残差状态不增加空间轴。这是项目选择的研究框架，不冒充外部科学共识；此次定位不把任何具体场模型、有限实验或未审查结果升格为世界公理。

## 重新奠基，而非拒绝工具

连续数学仍是强大的**具类型有效描述与形式工具**。精度属于状态，而不只是计算后的误差条。离散模型与连续读出的桥梁应说明适用域、尺度及关键误差传播；极限中的消失本身不是有限资源保证。

三件事必须分开：模型内推导是否有效、形式化是否表达了原目标、目标是否适用于自然。Lean 证明本身不建立物理桥梁；拒绝连续性前提，既不构成该模型内部定理的反例，也不证明相反结论。这些义务同样约束进取数论。

> **定义不继承。成功是证据。要从更小的原生逻辑解释这种成功。**

成熟概念和正确的条件数学可以保留并重新奠基。经典工程成功约束新基础，但不能把目标侧定义复制进原生前提，再把重现当成推导。一个机制解释彼此独立的观察量、尺度和干预，比拟合单个标量更有力。详细规则仍见 [FOUNDATIONAL_LOGIC.md](FOUNDATIONAL_LOGIC.md)、`foundational_logic.json` 与 `native_semantics_admissibility.json`。

## 五个基础倒置

1. **数不只有一个值：** 状态、分辨率、单位、语境，以及对声明的未来仍有效的残差区别都重要。
2. **精度是对象的一部分：** 有限分辨率不意味着全体系状态数有限，也不意味着粗读数已经完整。
3. **坍缩有明确范围：** 真实多对一更新，与用有损读数表示更丰富的状态，是两种不同主张。
4. **动力学保留有效关系：** 前向组合、支路关联、记忆与稳定化是第一类对象；可逆或有损应由具体更新决定，不能由显示方式推断。
5. **连续性是具类型工具：** 精确恢复、有限精度恢复、渐近恢复、限域恢复、系统偏差及不恢复必须区分。

研究目标不是让残差普遍消失，而是建立其**生成、传播、复合、修复、保持、可观察性和资源代价**的规律。每个有限制备下非零，不等于存在统一正下界；每个有限时间窗口各有一个有效制备，不等于存在同一个有限制备永久有效。

## 一分钟进入这套数学

最早的整数根核心定义为：

\[
R_p(n)=\max\{k\in\mathbb N:k^p\le n\},\qquad C_p(n)=R_p(n)^p.
\]

因此 \(R_2(20000)=141\)，\(C_2(20000)=19881\)。从 19881 到 20163 的每个整数都具有同一个平方坍缩像。

这项精确数学不变，但应用类型必须说明：若 \(C_2\) 是声明的真实状态更新，它就是多对一映射；若它只是用来代表更丰富过程的读数，余量 \(r=n-C_2(n)\) 可能仍为后续操作所需，这里 \(r=119\)。保留 \((C_2(n),r)\) 是精确整数记账，不是隐藏连续信息。能否丢掉 \(r\)，取决于声明的未来，而不是偏好“彻底抹去”或“永久记忆”。

## 这已经不只是一个想法

进取数论不是给传统公式换一套哲学解释。仓库已经从最早的 root / collapse 核心扩展出自己的定理族、反例族、形式化资产和可执行研究面。

已经进入 canonical `main` 的结果包括：

- **整数根与 carry 结构**：整数根超乘性、精确乘法判据和 carry 边界；
- **坍缩代数**：不同指数的完全幂坍缩何时交换，以及有限坍缩词的不动点分类；
- **尺度代数**：以整数总尺度因子建立整除投影、gcd/lcm 尺度格和路径无关结构；
- **离散除法与带类型状态**：区分商、同空间坍缩、可逆商余状态，并研究严格下降、终止与合流边界；
- **历史与不可逆性**：确定性前向映射中的历史合流、前像 multiplicity、碰撞谱和整数不可逆性观察量；
- **离散几何**：从 primitive-step graph distance 建立整数度量，而不是先嵌入连续欧氏空间；
- **稳定化理论**：良基偏序上单调向下映射的有限稳定化，以及坍缩词的稳定等价结构；
- **未来安全的精度**：研究一个粗粒度状态在后续操作与观察下何时仍然足够，以及最小修复需要恢复什么信息。

正在继续推进的研究还包括 Legendre 压力测试、有限精度证明演算、composition-safe collapse、action-language precision、root-lattice geometry、causal boundary，以及材料 / 碰撞 / 世界状态更新等工程物理实验。

这些层次的证明状态并不相同；精确状态由 [权威问题状态索引](docs/PROBLEM_STATUS.zh-CN.md) 和对应 theorem/result 文档控制。

## 我们要建的不是一个算子，而是一套底层

进取数论的目标不是把 \(C_p\) 变成另一个孤立的特殊函数，而是逐层建立一套能够自己站立的数学：

- **A0 — 离散状态代数**：整数根、坍缩、gap / basin、尺度、商余、signed / typed state；
- **A1 — 前向动力学**：composition、collision、history merge、stabilization；
- **A2 — 精度与观察**：observation、quotient、future-safe equality、minimal repair；
- **A3 — 关系与残差状态**：保留联合关系和对未来有效的区别，不把全部结构压回单个标量值；
- **A4 — 支撑与对应**：多值关系、witness、common-target 与组合可保留性；
- **A5 — 本征离散几何**：从离散 primitive 与可达关系构造距离、壳层和几何；
- **应用层**：把这些结构送进数论压力测试、碰撞、材料、因果边界和世界状态演化。

最终目标是让“数—精度—关系与残差状态—代数—动力学—几何—物理”形成同一条残差保真的离散底层链，而不是每次遇到离散现象都重新从连续世界向下近似。

## 自信不等于取消证据纪律

如果进取数论真的要挑战底层，它就必须比普通新想法更容易被攻击，而不是更难。

因此仓库明确区分：

1. **定义**——我们选择怎样的离散原语；
2. **已证明数学结果**——从这些原语严格推出并进入 canonical `main` 的结论；
3. **可执行 / 有限验证结果**——可用于发现、反例和回归，但不自动等于证明；
4. **物理与本体主张**——关于自然是否真的如此，必须接受实验和观测。

我们不会为了显得“谨慎”而把核心立场写成没有方向的问句，也不会为了显得“自信”而把尚未证明的东西冒充成定理。

**方向可以激进，证据必须残酷。**

## 原创不是靠不知道前人

进取数论不把 prior art 当作威胁。

如果某个工具已经存在，我们就吸收它；如果某个定理属于经典数学，我们就明确归因；如果我们的结构只是旧理论的特化，就把边界写清楚。我们要争取的原创不是“从未读过别人”，而是：

- 是否选出了不同的底层原语；
- 是否把原本分散的结构组织成新的统一体系；
- 是否由此得到新的定理、反例、算法、几何或物理预测；
- 是否能够解释传统连续框架中被当作误差或外部修补的现象。

当前各组件的历史优先性继续由 `sources.json`、`lineage.json` 与 [前人工作谱系](docs/PRIOR_ART_AND_NOVELTY.zh-CN.md) 管理。对某个具体结果声称“首次”仍然需要证据；这不妨碍我们明确地说：**进取数论正在建设一套属于自己的数学体系。**

## 来攻击它

你不需要先相信进取数论。

最有价值的贡献不是说“这个想法很有意思”，而是：

- 找出一个错误定义；
- 给一个候选定理构造反例；
- 找到一个更弱、更精确的假设；
- 证明一条开放命题；
- 找到我们漏掉的前人工作；
- 把一个稳定结果形式化进 Lean；
- 设计一个能够直接杀死物理主张的实验；
- 或证明连续结构确实无法从我们选择的离散底层恢复。

如果这条路是错的，我们希望尽快知道它错在哪里。  
如果它是对的，我们要把它一直推到足以替代旧地基的位置。

## 当前状态

进取数论仍处于 **Research Beta**。完整的几何、微积分、物理和热力学还远未完成，许多研究路线仍然开放。

**我们对细节保持怀疑，对证据保持苛刻，坚持有限分辨率与残差保真的基础方向。**

连续数学已经证明了自己是一种伟大的工具。进取数论要回答的是：

> **哪些区别可以安全消去，哪些必须进入状态，又怎样从它们的规律重建有限分辨率下的数学？**
