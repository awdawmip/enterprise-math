# R508 — signed BRC 辅助标量右缘三十一阶 Toeplitz 子式：全参数符号分类及阶数生成函数

日期：2026-11-03。科学输入冻结：R462@18783e01e3646c72b7aab3b16d3f565e83e6446f；前沿：R507@ff5a7f487092f3f3008479bd16ac8402763df5b0。状态：**AUTHOR_SIDE_EXACT_COMPUTER_CERTIFICATE / DRIVER_UNREVIEWED / NOT_ADMITTED**。

## 模型与定理

对每个整数 `k>=1`，置 `r=2k+1`、`C_k=binom(2k,k)/(k+1)`，定义（原始 signed BRC 辅助标量，保留原始组合系数）

```text
H_k(t)=binom(r+t,2t)*[x^r]((1-x)(1+x)^(2t)(1+x^2)^(r-t)),  2<=t<=r,
H_k(t)=0, otherwise.
D_m(k)=det(H_k(3+i-j))_(0<=i,j<m), D_0=1.
```

**定理（依赖冻结 R452/R462 的多项式前提）**：

```text
D_31(k)>0 for integers 1<=k<=14;
D_31(k)<0 for every integer k>=15.
```

因此转负从 `r=31` 开始。结合 R507，`D_30(k)>0>D_31(k)` 对 `15<=k<=37` 的所有整数成立；在 `k=6`，`D_30(k)<0<D_31(k)`。

## 无限参数证明（可执行精确整数证书）

冻结前提为固定 `t` 的 `p_t(k)=H_k(t)/C_k in Q[k]` 且 `deg p_t<=2t`。下 Hessenberg 递推给出

```text
f_0=1; f_m=D_m/C_k^m,
f_m=sum_(e=1)^m (-1)^(e-1) p_(e+2) p_2^(e-1) f_(m-e).
```

归纳得 `deg f_m<=6m`，特别是 `deg f_31<=186`。取

```text
G_31(k)=[k(k+1)(2k+1)(2k+3)]^31 (k+2),  deg G_31=125.
```

对正整数 `k`，`G_31,C_k` 均严格为正。计算 `k=1..62` 的有理数 `f_31/G_31`，取全部最简分母的最小公倍数 `L>0`，使全部62个样本成为整数。其前向差分为 `delta_j`, `j=0..61`，定义

```text
S_31(k)=sum_(j=0)^61 delta_j*binom(k-1,j).
```

程序在 `k=1..187` 的187个不同正整数点上，逐项精确核对

```text
L*D_31(k) = C_k^31*G_31(k)*S_31(k).
```

由两侧除以 `C_k^31` 得 `L*f_31=G_31*S_31`。两边均为有理多项式，前者次数至多186，后者至多 `125+61=186`；187点相等推出完整多项式恒等式。

证书同时给出 `S_31(1),...,S_31(14)` 十四个严格正整数，以及全部62个严格负整数

```text
epsilon_j=Delta^j S_31(15), j=0..61.
```

对任意整数 `u>=0`，`S_31(15+u)=sum_j epsilon_j binom(u,j)<0`，因为每个二项式非负、常数项严格为负。正因子 `C_k^31 G_31/L` 保持符号，定理得证。还能推出对全部 `k>=15`，`Delta S_31(k)<0`（由 `epsilon_{j+1}<0`）。

## 固定 k 的有理阶数生成函数（精确结构引理）

令 `h_t=H_k(t)`。由于 `h_t=0` 对 `t>r`，相同 Hessenberg 递推的普通生成函数在形式幂级数环 `Q[[z]]` 中满足

```text
F_k(z)=sum_(m>=0) D_m(k) z^m
      = 1 / Q_k(z),
Q_k(z)=1-sum_(e=1)^(r-2) (-1)^(e-1) h_(e+2) h_2^(e-1) z^e.
```

证明：将 `D_m=sum_e(-1)^(e-1)h_(e+2)h_2^(e-1)D_(m-e)` 乘 `z^m` 后求和；`Q_k(0)=1` 使形式逆存在。由 ballot-Catalan 恒等式有 `h_2>0,h_r>0`，所以 `deg Q_k=r-2=2k-1`，分式 `1/Q_k` 已约分。这给出固定 k 的全阶数精确有理表示，适用于进一步研究主导极点与跨阶数符号。
