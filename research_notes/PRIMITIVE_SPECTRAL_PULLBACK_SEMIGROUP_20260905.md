## 1. Denominator transport under phase multiplication

A primitive denominator-`e` mode has phase

\[
\theta=\frac{r\tau}{e},\qquad (r,e)=1.
\]

Applying `R_n` multiplies phase by `n`:

\[
R_n(u_{r,e})=2-2C\left(\frac{nr\tau}{e}\right).
\]

After reducing the fraction, the primitive denominator becomes

\[
\boxed{
\operatorname{den}_n(e)=\frac{e}{(e,n)}.
}
\tag{PSP-1}
\]

The possible complement `theta -> tau-theta` changes the canonical representative but not the reduced denominator.

Hence a primitive source denominator `e` maps to primitive target denominator `d` iff

\[
\boxed{
\frac{e}{(e,n)}=d.
}
\tag{PSP-2}
\]

## 2. Solve the denominator fiber

Write `e=dg`.  Equation (PSP-2) is equivalent to

\[
\boxed{
 g\mid n,
\qquad
(d,n/g)=1.
}
\tag{PSP-3}
\]

Indeed `(dg,n)=g` exactly when `g|n` and no prime left in `n/g` divides `d`.

Therefore the entire primitive denominator fiber over `d` is

\[
\boxed{
\{e:e/(e,n)=d\}
=
\{dg:g\mid n,\ (d,n/g)=1\}.
}
\tag{PSP-4}
\]

## 3. Exact primitive pullback factorization

The roots of the composed polynomial `Psi_d(R_n(u))` are precisely the finite primitive modes whose `R_n` image lies in the primitive `d` spectrum.  By (PSP-4), these are exactly the primitive spectra `Psi_(dg)` with

\[
g\mid n,\qquad(d,n/g)=1.
\]

All roots are simple.  The degree check is

\[
\boxed{
\sum_{\substack{g\mid n\\(d,n/g)=1}}\varphi(dg)
=n\varphi(d).
}
\tag{PSP-5}
\]

This identity is multiplicative in `n`.  For `n=p^a`:

- if `p|d`, only `g=p^a` is allowed and `phi(dp^a)=p^a phi(d)`;
- if `p\nmid d`, every `g=p^j`, `0<=j<=a`, is allowed and
  `sum_j phi(dp^j)=phi(d) sum_j phi(p^j)=p^a phi(d)`.

Thus no roots are missing.  After multiplying by the unique sign needed to make the left side monic,

\[
\boxed{
\operatorname{Monic}\bigl(\Psi_d(R_n(u))\bigr)
=
\prod_{\substack{g\mid n\\(d,n/g)=1}}
\Psi_{dg}(u).
}
\tag{PSP-6}

For odd `n` the phase polynomial `R_n` is monic, so no sign correction is needed.  For even `n`, `R_n` has leading coefficient `-1`; the monic correction is `(-1)^(phi(d))`, nontrivial only in the small odd-degree exceptional factors such as `d=2`.

## 4. Prime-local law

For a prime `p`, (PSP-6) becomes

\[
\boxed{
\operatorname{Monic}(\Psi_d\circ R_p)
=
\begin{cases}
\Psi_d\Psi_{pd},&p\nmid d,\\
\Psi_{pd},&p\mid d.
\end{cases}}
\tag{PSP-7}
\]

This is the local creation/propagation rule:

```text
p absent from denominator:
    old d-channel survives
    + one new pd-channel is created

p already present:
    the d-channel propagates only to the deeper pd-channel
```

For a prime power `p^a`:

\[
\boxed{
\operatorname{Monic}(\Psi_d\circ R_{p^a})
=
\begin{cases}
\Psi_d\Psi_{pd}\cdots\Psi_{p^a d},&p\nmid d,\\
\Psi_{p^a d},&p\mid d.
\end{cases}}
\tag{PSP-8}
\]

where in the second line `p|d` means the full `p^a` phase multiplication moves the channel directly `a` levels deeper.

## 5. Semigroup operator on primitive factors

Pass to the free abelian group generated by formal primitive symbols `[d]`, `d>1`.  Define

\[
\boxed{
\mathcal A_n[d]
:=\sum_{\substack{g\mid n\\(d,n/g)=1}}[dg].
}
\tag{PSP-9}
\]

Then the polynomial pullback law (PSP-6) is the multiplicative realization of `A_n`.

Because

\[
R_{mn}=R_m\circ R_n,
\]

the operators satisfy the exact semigroup law

\[
\boxed{
\mathcal A_m\mathcal A_n=\mathcal A_{mn}=\mathcal A_n\mathcal A_m.
}
\tag{PSP-10}
\]

Thus phase multiplication gives a commutative arithmetic semigroup action on primitive finite spectral denominators.

The prime-local generator is

\[
\boxed{
\mathcal A_p[d]
=\begin{cases}
[d]+[pd],&p\nmid d,\\
[pd],&p\mid d.
\end{cases}}
\tag{PSP-11}
\]

## 6. Recover previous special cases

### Dyadic tower

If `d` is even, repeated `A_2` gives only deeper powers of two:

\[
\operatorname{Monic}(\Psi_d\circ R_{2^a})=\Psi_{2^a d}.
\]

This is the full-factor version of the previously derived dyadic decimation tree.

If `d` is odd, the pullback contains every intermediate denominator

\[
d,2d,4d,\ldots,2^a d.
\]

The orientation-resolved odd-denominator theory refines this statement further by showing how one reflection channel supplies the genuinely new `2d` factor.

### Prime-adic equal-mass levels

For `p|d`, `A_(p^a)` moves the primitive factor directly to `p^a d`.  This is the primitive-factor form of the prime-adic generation filtration whose level root product is exactly `p`.
