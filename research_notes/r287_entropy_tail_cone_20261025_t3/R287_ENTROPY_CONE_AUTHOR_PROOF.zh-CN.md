## 主定理：有效无限长度线性尾部排除

**对全部整数 n>=900 以及全部 epsilon=+/-1、整数 k，只要 3*abs(k)>=2*n，就有严格不等式 P_n(epsilon,k)<Lambda_n。** 所有最大 clean 纤维的平移参数因而处于 abs(k)<2*n/3。900 只是明确的充分阈值，不声称最小。

### 证明第一步：有序来源词到简单 +/-1 步行的单射

在第 j 步记 t_j=epsilon_j*k_j，则右复合公式直接给出
t_j-t_(j-1)=epsilon_(j-1)*eta_j*c_j。
查六条边，b=0 全部满足 eta*c=+1，b=1 全部满足 eta*c=-1。因而增量必为 +/-1，已知 epsilon_(j-1) 后可由增量唯一逆推出 b_j；起始 q0、epsilon0 已知，整串来源位可逐步唯一恢复。故来源位串到 n 步增量串的映射单射；该结论甚至不要求 clean 或最终 q0。

若终点效果为 (epsilon,k)，则 t_n=epsilon*k，正增量步数必须为 (n+epsilon*k)/2。因此当此数量为0..n整数时：
P_n(epsilon,k) <= C(n,(n+epsilon*k)/2)。
不满足支持条件时左端为0。若 3*abs(k)>=2*n，取 r=(n-abs(k))/2<=n/6，并利用 C(n,r)=C(n,n-r)，得到
P_n(epsilon,k) <= C(n,r) <= 6^n/5^(n-r) <= (6/5^(5/6))^n < (79/50)^n。
中间界由非负二项式展开 (1/6+5/6)^n=1 中单项 C(n,r)*(1/6)^r*(5/6)^(n-r)<=1 导出。最后的严格界为整数比较：
79^6*5^5 - 6^6*50^6 = 30648298503125 > 0。
这是纯精确有理算术，没有浮点误差。

### 证明第二步：独立的清洁首次返回字语言

清洁 q0 到 q0 的一个首次返回原子必为两类之一：
A_a = 1^(a+1) 0 1，a>=0，长度 a+3；
B_a = 0 1^a 0 1，a>=1，长度 a+3。
因为从 q0 必达 q2，由 q2 的0去 q1，再由 q1 的1回 q0；起始为0时必须插入至少一个1以避免 00。原子都以1结尾，任意拼接自动无跨界 00；每条 clean 重置词由第一次返回时刻唯一分段。每原子生成函数为 x^3(1+x)/(1-x)，故全部 clean q0 路径人口 a_n=sum P_n 具有精确生成函数
A(x) = 1/[1-x^3(1+x)/(1-x)]
     = (1-x)/[(1+x^2)(1-x-x^2)]
     = (2-x)/[5(1-x-x^2)] + (3-x)/[5(1+x^2)]。

取 Fibonacci F0=0,F1=1,F_(n+1)=F_n+F_(n-1)。于是 a0=1，对 n>=1，
a_n=[F_n+2 F_(n-1)+d_n]/5，
其中 d_n 按 n mod4 为 (3,-1,-3,1)。记 phi=(1+sqrt(5))/2，初值检查加归纳有 F_n>=phi^(n-2) 对 n>=2；又 n>=6 时 F_n>=6。故 n>=6：
a_n >= (F_n-3)/5 >= F_n/10 >= phi^(n-2)/10。

每步 k 的奇偶反转且 abs(k) 至多增加1；故长度 n 至多 n+1 个 k 和两种 epsilon，总计不超过2(n+1)个效果。鸽巢原理得
Lambda_n >= a_n/[2(n+1)] >= phi^(n-2)/[20(n+1)]
         > (8/5)^n/[60(n+1)]
因为 phi>8/5 且 phi^2<3。此步骤不借用 R277 的精确支撑结果。

### 证明第三步：n=900 的无浮点基底加永久归纳

定义 R_n=(80/79)^n/[60(n+1)]。按 (1+1/79)^900 的二项式展开，只取 j=0..12 正项，精确大整数差为
sum_(j=0)^12 C(900,j)*79^(12-j) - 60*901*79^12
= 31897914929057460249275636 > 0。
所以 R_900>1。对 n>=78，
R_(n+1)/R_n = 80(n+1)/[79(n+2)] >=1，
因为其分子减分母 n-78>=0。由归纳 R_n>1 对每个 n>=900。
合并：
P_n(epsilon,k)<(79/50)^n
             < (8/5)^n/[60(n+1)]
             < Lambda_n。
至此全部所需量词和严格不等式均完成证明。
