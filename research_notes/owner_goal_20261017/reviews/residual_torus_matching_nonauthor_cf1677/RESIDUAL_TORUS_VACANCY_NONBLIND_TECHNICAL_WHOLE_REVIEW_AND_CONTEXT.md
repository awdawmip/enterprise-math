## 4. Bound at every legal intermediate state and the finite boundary lemma

The static inequality is the key all-word step. For ANY matching J of the
licensed events, set S={q:B_q is in J}. An A-event adjacent to a present B
cannot be present, so at most n-|N(S)| A-events are present, where

    N(S)=S union (S+e1) union (S+e2).

There are exactly |S| present B-events, with no other licensed event types.
Disjoint triples occupy 3|J| members, giving

    vacancy(J)=3n-3|J| >= 3(|N(S)|-|S|)=3|N(S) minus S|.

This statement needs no relation between the current state and an earlier
one. In particular an old A reinserted later, a B removed later, and any
failed command all remain covered. The proof never assumes a monotone word.

I checked both cases of the elementary boundary proof for
m^2/3<=|S|<=2m^2/3. A nonempty proper cyclic row contributes at least one
point to its positive-direction boundary: if translation by the unit shift
introduced none, finiteness would make the row set invariant under that
shift, and its transitive cyclic action would make the nonempty set full.
Different rows give distinct such points. Hence at least m/3 mixed rows
already give |N(S) minus S|>=m/3.

If fewer than m/3 rows are mixed, the lower size bound forces a full row:
with no full row the whole set would have at most r(m-1)<m^2/3 points.
Applying the same count to the complement forces an empty row. Each cyclic
column is then nonempty and not full, so the vertical-direction boundary
has at least m points. It too is contained in N(S) minus S. This proves the
other case and is stronger than needed. No sum of overlapping horizontal
