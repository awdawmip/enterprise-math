## 1. Existing threshold identity

Let finite Hermitian `A>0`, `D>0`, and let `B` be the old-to-future cross block. For `eta>=0` define

`M_eta(B) := [[eta^2 A, B],[B^*,D]]`.

`C=A^{-1/2}BD^{-1/2}`,

`r_B(eta) := #{j : sigma_j(C)>eta} = n_-(M_eta(B))`.

## 2. New theorem: norm-stable cross-component ablation

Split

`B=B_0+E`

and put

`H_0=M_eta(B_0)`, `H=M_eta(B)`.

Let

`eps=||E||`.

Then

`boxed: N_{H_0}((−infinity,−eps)) <= r_B(eta) <= N_{H_0}((−infinity,eps))`.

Here `N_H((−infinity,t))` counts eigenvalues of `H` strictly below `t`, with multiplicity.

### Proof

The threshold blocks differ by

`Delta_E = [[0,E],[E^*,0]]`.

Its nonzero eigenvalues are `+/- sigma_j(E)`, so

`||Delta_E||=||E||=eps`.

By the Hermitian min-max/Weyl perturbation inequality, every ordered eigenvalue moves by at most `eps`. Hence every eigenvalue of `H_0` below `-eps` remains negative for `H`, while every negative eigenvalue of `H` must come from an eigenvalue of `H_0` below `+eps`. Since `r_B(eta)=n_-(H)`, the claim follows.

### Gap corollary

If

`spec(H_0) intersect [-eps,eps] = empty`,

then

`boxed: r_B(eta)=r_{B_0}(eta)`.

Thus a component-ablation table becomes a theorem once the omitted cross component has norm smaller than the certified zero-gap of the retained threshold block.

## 3. New theorem: low-rank plus small-tail ablation

Suppose

`B=B_0+K+R`,

where

`rank(K)<=r`, `||R||<=eps`.

Then

`boxed: N_{H_0}((−infinity,−eps)) - 2r <= r_B(eta) <= N_{H_0}((−infinity,eps)) + 2r}`,

with the lower bound truncated at zero when necessary.

### Proof

The off-diagonal block perturbation generated by `K` has rank at most `2r`. For Hermitian matrices a rank-`s` perturbation changes the counting function below any fixed threshold by at most `s`. Apply this with `s=2r`, then apply the norm-stability theorem to the remaining `R` perturbation.

This separates two distinct repair costs:

- exact finite-dimensional provenance retained by the rank term;
- unresolved analytic tail retained by the `eps` spectral window.

`P_shell [sum_{1<m<=n(n+1)} w_m T_{s_m}] P_old`,

## 6. New no-whitening symbol reduction

The inertia formulation suggests avoiding a scalar symbol for `C_n` altogether.

Suppose an applicable matrix-valued pseudodifferential/Wiener-Hopf approximation gives local principal block symbols

`a(x,xi)>0`, `d(x,xi)>0`, `b(x,xi)`

for `(A,B,D)`. The threshold block then has the Hermitian `2x2` symbol

`m_eta(x,xi) = [[eta^2 a, b],[conj(b), d]]`.

At every phase-space point with positive diagonal symbols,

`m_eta has one negative eigenvalue`
`<=> det(m_eta)<0`
`<=> |b|^2 > eta^2 a d`.

Hence the dangerous local response set is

`Omega_eta = {(x,xi): |b(x,xi)|^2/(a(x,xi)d(x,xi)) > eta^2}`.

This reproduces the normalized-response threshold algebra **without constructing `A^{-1/2}` or `D^{-1/2}`**.

Consequently, if a matrix-valued Szego/Widom-type spectral-count theorem is proved applicable to the actual threshold block, the leading response-rank asymptotic should be read from the phase-space negative-inertia set of `m_eta`, with boundary/model defects retained separately.

This is a route, not yet an RH theorem: the actual block symbols and the theorem hypotheses still have to be derived and certified.
