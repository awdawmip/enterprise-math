## 输入和作用域

继续冻结 R462 科学源 `18783e01e3646c72b7aab3b16d3f565e83e6446f`，以及 R570 `106520099fb0e554080f6a4b46b482ebe7c7040d`、R571 `37b6cd3bdd09d84ebb89af6a62a8bcb207d350e2` 的 **辅助 signed BRC 标量 Toeplitz–Hessenberg** 递推。研究对象不是 X6 原生时间演化，不改变 BRC 支路、原始冻结输入或 P000。

定义 `C_n=binom(2n,n)/(n+1)`，`r=2k+1`，
`H_k(t)=binom(r+t,2t) Σ_{q=0}^{min(k,⌊(t−1)/2⌋)} binom(t−1,2q) 4^q C_{k−q}` (2≤t≤r)，其余为0。
取 `h=H_k(2)`、`d=2k−1`，`A_j=H_k(j+2)/h`（若 j>d 则为0），
`Q_k(z)=z^d+Σ_{j=1}^d (−1)^j A_j z^{d−j}`，其根（含重数）为 `λ_1,...,λ_d`，`p_m=Σ λ_i^m`，`ρ_k=max|λ_i|`，`k∈ℤ,k≥2`。

## 定理 1：全参数 p4 及角域

令
```
P4(k)=18688 k^7+108736 k^6+252932 k^5-1127884 k^4
      -7829539 k^3-19596652 k^2-29110835 k-15480446.
```
则对每个整数 k≥2，
`p4(k)=−(k+2) P4(k)/218295000`。
`p4(k)<0` 当且仅当整数 `k≥5`（k=2,3,4 时为正）。

严格正性证书：设 t=k−5≥0，则 P4(5+t) 从常数项到七次项的系数依次为
```
[1614841704, 3496977720, 2255742663, 713485781,
 127731416, 13326212, 762816, 18688].
```
因此对 k≥5 有 `p4<0`。因 p4 为实数，`p4=Σ |λ_j|^4 cos(4 arg λ_j)`，至少一个根满足 `cos(4 arg λ_j)<0`，该根非实，其共轭根也满足该不等式。此外
`ρ_k ≥ ((k+2)P4(k)/(218295000(2k−1)))^(1/4)` (k≥5)。
故
`liminf_{k→∞} ρ_k/k^(7/4) ≥ (18688/(2·218295000))^(1/4)`。

## 定理 2：全参数 p6 正性及 k^(11/6) 下界

令
```
P6(k)=7491584 k^11+41017856 k^10-53092960 k^9
       -1053547600 k^8-2415621820 k^7+12839628644 k^6
       +102755266351 k^5+342909684895 k^4+688977135565 k^3
       +875097279805 k^2+701292907192 k+259328600488.
```
则对每个整数 k≥2，
`p6(k)=(k+2) P6(k)/8939180250000 >0`。

严格正性证书：令 t=k−2≥0，则 P6(2+t) 的常数项至十一次项系数为
```
[19721834007876, 32139186704856, 21468305897955,
 7017151356765, 938146323525, 27172991535, 73920696860,
 52014935620, 15262884080, 2415412640, 205832704, 7491584].
```
所有系数严格为正，故 p6>0。由 `0<p6≤Σ|λ_j|^6≤(2k−1)ρ_k^6`，
```
ρ_k ≥ [ (k+2)P6(k)/(8939180250000(2k−1)) ]^(1/6),  k≥2.
liminf_{k→∞} ρ_k/k^(11/6)
    ≥ [7491584/(2·8939180250000)]^(1/6) ≈ 0.08650495686.
```
这在全参数尺度上强化了 R571 的 k^(3/2) 解析下界。

## 符号证明

从上面的 Catalan 与 H 定义，应用 `C_{n−1}/C_n=(n+1)/(2(2n−1))`，把 `A_j=H_k(j+2)/H_k(2)`（j=1,...,6）归约为 `R572_VERIFY.py` 中列出的六个显式有理多项式；在 k=2、3 的边界，缺项按 `H_k(t)=0` 处理，因子的零点也满足公式。

对 monic Q 的系数 `c_j=(−1)^j A_j`，Newton 恒等式为
`p_m=−Σ_{j=1}^{m−1} c_j p_{m−j}−m c_m` (m=1,...,6)，当 j>d 时 `c_j=0`。
直接代入并按有理数展开，得到定理 1、2 的 p4、p6 精确闭式。两段平移多项式正系数证书为整数恒等式（可逐系数检查）。谱半径不等式来自三角不等式 `|p_m|≤dρ_k^m`。多项式最高次数为8与12，故所列渐近常数严格成立。
