# R561｜冻结 signed BRC 辅助标量观察：固定 k=20 的半数符号密度与有限零项

## 1. 精确对象、来源与定理

沿用冻结 R462 signed BRC 标量观察（源 commit `18783e01e3646c72b7aab3b16d3f565e83e6446f`），直接接续 R560（commit `1aced918e683b086f1707c5d83750e2d3e541bd8`）。定义 Catalan 数 `C_j = binom(2j,j)/(j+1)`。在整数 `2 <= t <= 41` 上定义

```text
H(t) = binom(41+t,2t) *
       sum_{q=0}^{min(20,floor((t-1)/2))}
          binom(t-1,2q)*4^q*C_{20-q}
```

其余整数 `t` 上 `H(t)=0`。取 `D_0=1`，对 `m>=1` 取 Toeplitz–Hessenberg 行列式 `D_m=det[H(3+i-j)]`，其中 `0<=i,j<m`。

**定理（固定 k=20）：**

```text
lim_{N→∞} #{0<=m<N : D_m>0}/N = 1/2,
lim_{N→∞} #{0<=m<N : D_m<0}/N = 1/2,
#{m>=0 : D_m=0} < infinity.
```

这里的 `D_m` 是冻结 signed BRC 辅助**标量观察量**。原生 X6 动力学仍由其任务及带类型的路径/分支状态单独研究。

## 2. 39 次精确特征多项式

`h=H(2)=810078101032200>0`。按末行展开得到

```text
D_m = sum_{j=1}^{min(m,39)} (-1)^(j-1) H(j+2) h^(j-1) D_{m-j}.
s_m = D_m/h^m;     a_j = (-1)^(j-1)H(j+2)/h.
sum_{m>=0}s_m z^m = 1 / (1 - sum_{j=1}^{39}a_j z^j).
Q(y) = y^39 - sum_{j=1}^{39}a_j y^(39-j).
```

归档验证程序对 `t=2,...,41` 的40个 `H(t)` 逐一核对另一套原始整数卷积公式 `Hraw(t)`。对全部系数取有理公分母得到整系数多项式 `P=LQ`。

## 3. 全根覆盖的精确 Rouché 证书

以 SymPy `nroots` 的65位数值解仅生成39个**有理复中心** `c_i`，半径一律 `ε=10^-22`。对每个中心作精确展开 `P(c_i+w)=Σ_{j=0}^{39}b_{i,j}w^j`，以整数/Fraction 判定

```text
max(|Re b_{i,1}|,|Im b_{i,1}|)*ε >
  |Re b_{i,0}|+|Im b_{i,0}|
  + sum_{j=2}^{39}(|Re b_{i,j}|+|Im b_{i,j}|)*ε^j.
```

左侧为一次项圆周模长下界，右侧为剩余项模长上界；Rouché 保证每盘恰有一个单根。741对圆盘不相交证书覆盖全部39根，模长平方的有理数分离检查证明唯一最大模部分是简单非实共轭根对 `λ,bar(λ)`。参考近似值 `|λ|≈37.51815034579866`，其他根最大模 `≈13.068394300332095`；所有盘的剩余项/一次项上界比值小于 `1/1000`（实际最大约 `1.371×10^-20`）。

## 4. 有理相位完整排除

令 `λ=|λ| exp(iθ)`，`θ∈(π/4,π/3)`。若 `θ/π=p/q` 为最简分数，则 `λ/bar(λ)` 是 `q` 阶本原单位根；作为39个特征根的比值，其代数次数至多 `39*38=1482`，所以 `φ(q)<=1482`。由 `φ(q)>=sqrt(q/2)`，有完整上界

```text
2<=q<=2*(39*38)^2=4,392,648.
```

从精确根盘得到 `x=Re(λ)/Im(λ)` 的有理区间。使用
`atan(x)=2atan(1/3)+atan((4x-3)/(4+3x))` 和 Machin 式
`π=16atan(1/5)-4atan(1/239)`，以交错级数和严格余项界构造 `θ/π∈(lo,hi)` 的**有理数界**，区间宽小于 `10^-18`（参考约 `2.367×10^-24`）。对 `2<=q<=4,392,648` 先精确筛 `φ(q)<=1482`，得到2887个候选。对每个候选均精确验证

```text
ceil(q*lo) > floor(q*hi).
```

因此整个候选区间没有相位分子，`θ/π` 无理。

## 5. 无限阶结论

`Q` 的39个根简单且生成函数分子为1，主导对的非零留数互为共轭。存在 `A≠0` 和 `ρ<|λ|` 使

```text
s_m = A λ^m + conj(A) conj(λ)^m + O(ρ^m)
    = 2|A||λ|^m cos(mθ+arg A) + O(ρ^m).
```

因为 `θ/π` 无理，Weyl 等分布定理使余弦正负各占自然密度 `1/2`；在 `|cos|>=δ` 的项上，指数小误差最终不能改号，令 `δ→0` 即得两条密度结论，且 `h>0` 使 `D_m`、`s_m` 同号。

零项有限性：线性递推的 Skolem–Mahler–Lech 定理说明无限零集含某无限等差级数 `a+qt`。沿其上由 `qθ/π` 无理得到余弦稠密及绝对值 `>1/2` 的无穷多个项，与 `s_{a+qt}=0` 及相对指数误差趋零矛盾。
