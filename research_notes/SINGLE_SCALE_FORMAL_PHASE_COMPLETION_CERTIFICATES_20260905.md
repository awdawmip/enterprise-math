## 1. Formal-phase differential equation

The common formal phase `ell` satisfies

\[
\ell(R_2(u))=4\ell(u),
\qquad
R_2(u)=u(4-u).
\]

The decimation quadratic-differential identity gives the equivalent local first-order relation

\[
\boxed{
u(4-u)\ell'(u)^2=4\ell(u).}
\tag{SC-1}
\]

Differentiate (SC-1).  Since `ell'(0)=1`, `ell'` is a unit in the formal series ring, so division by `2 ell'` is legitimate.  This yields the linear equation

\[
\boxed{
u(4-u)\ell''(u)+(2-u)\ell'(u)=2.}
\tag{SC-2}
\]

with

\[
\ell(0)=0,
\qquad
\ell'(0)=1.
\]

## 2. Exact positive coefficient formula

Write

\[
\ell(u)=\sum_{n\ge1}c_nu^n.
\]

The constant term of (SC-2) gives

\[
c_1=1.
\]

For `n>=1`, coefficient comparison gives

\[
\boxed{
2(n+1)(2n+1)c_{n+1}=n^2c_n.
}
\tag{SC-3}
\]

Hence every coefficient is strictly positive and

\[
\boxed{
\frac{c_{n+1}}{c_n}
=\frac{n^2}{2(n+1)(2n+1)}
<\frac14.
}
\tag{SC-4}
\]

Solving the recurrence,

\[
\boxed{
c_n=\frac{2}{n^2\binom{2n}{n}}.}
\tag{SC-5}
\]

Thus

\[
\boxed{
\ell(u)
=2\sum_{n\ge1}
\frac{u^n}{n^2\binom{2n}{n}}.
}
\tag{SC-6}
\]

This identity is obtained from the finite decimation algebra; the later classical readout `ell(u)=4 arcsin^2(sqrt(u)/2)` is not required.

## 3. Exact phase identity for the first mode

Let `a_q=u_(1,q)` be the smallest positive Dirichlet spectral root, `q>=2`, and let `tau` be the first positive completion phase.

Internal phase quantization gives

\[
\boxed{
\ell(a_q)=\frac{\tau^2}{q^2}.

\tag{SC-7}
\]

Therefore

\[
\boxed{
\tau=q\sqrt{\ell(a_q)}.

\tag{SC-8}
\]

This is exact for every finite `q`.  It is not yet a finite algorithm because `ell` is infinite, but the positive coefficient structure makes finite certified truncation immediate.

## 4. Positive truncation and explicit tail

Define

\[
\ell_N(u):=\sum_{n=1}^{N}c_nu^n.
\]

For `0<=u<4`, every omitted term is positive, so

\[
\ell_N(u)<\ell(u).
\]

By (SC-4), consecutive tail terms obey

\[
\frac{c_{n+1}u^{n+1}}{c_nu^n}<\frac u4.
\]

Hence the tail is geometrically bounded:

\[
\boxed{
0<\ell(u)-\ell_N(u)
\le
\frac{c_{N+1}u^{N+1}}{1-u/4}.
}
\tag{SC-9}
\]

For the smallest mode one has `0<a_q<=2`, so the denominator is at least `1/2`.
