优先顺序：

4. 在确实已经生成并使用 BRC 状态的上游流程中，评估下游排序/统计复用收益，分别计算原始整数入口与已有状态入口的成本。

## 新推导一：旧预测的精确误差

设 K>=1、x=(K+j)^2+r，j>=0，0<=r<=2(K+j)。旧预测为

\[
\widehat k=K+\left\lfloor\frac{x-K^2}{2K}\right\rfloor.
\]

直接展开可得

\[
\widehat k-(K+j)
=\left\lfloor\frac{j^2+r}{2K}\right\rfloor.
\]

所以它只会高估。若 j<B、r<D，则最多 C 次向下修正的充分条件为

\[
(B-1)^2+D-1<2K(C+1).
\]

K=900、D=8 时，零修正覆盖 B<=43，一次修正覆盖 B<=60，两次修正覆盖 B<=74。

如果每个盆地允许完整余数 0<=r<=2(K+j)，j=0,...,B-1，则最大误差恰为

\[
1+\left\lfloor\frac{B^2-1}{2K}\right\rfloor.
\]

对整数 C>=1，整个连续盆地族最多 C 次向下修正，当且仅当 B^2<=2KC。

本轮遍历固定锚点 K=900 的全部 x∈[810000,846399]，共36400个整数：33530个预测精确、2870个高估1，减一后均等于独立整数二分根。该检查验证根恢复，不是排序性能测试。

## 新推导二：使用完整基准的残差感知预测

取样本最小值

\[
m=K^2+a,\qquad K=\lfloor\sqrt m\rfloor\ge1,\quad0\le a\le2K.
\]

把原来的 x-K^2 改成 x-m：

\[
\widetilde k
=K+\left\lfloor\frac{x-m}{2K}\right\rfloor.
\]

对任一 x=(K+j)^2+r，精确误差为

\[
\widetilde k-(K+j)
=\left\lfloor\frac{j^2+r-a}{2K}\right\rfloor.
\]

### 一步向上修正定理

令 B 是样本真实根的跨度，D 是真实平方残差的跨度，均含端点。如果

\[
(B-1)^2+D-1<2K,
\]

则每个预测值属于 {真实根−1,真实根}。因而计算候选的下一个平方；若仍不大于 x，就将候选加一，即得到精确根。

证明：
- a是样本中的一个平方残差，因此 r-a<=D-1；且0<=j<=B-1，故 j^2+r-a<2K，误差<=0。
- 0<=a<=2K，而 j^2+r>=0，故 j^2+r-a>=−2K，误差>=−1。
- 上述两式直接给出误差集合。若候选等于真根，其下一个平方大于x；若少1，下一个平方不大于x。

这一条件只依赖残差跨度，不要求残差从0附近开始。它使用最小值扫描已得到的m，基准残差a已经属于原有根—残差状态。

真实根和残差跨度用于给出适用族的成本保证。通用实现仍逐项使用平方证书：一次小修正后检查候选所在平方区间，失败则走原精确根恢复路径；K=0沿用明确分支。不得假设采样获得的跨度已经覆盖全体输入。

必要方向反例：输入[3,4]，m=3、K=1、a=2。x=4的候选为1，真实根为2，所以新公式需要允许向上修正。只沿用旧公式的向下修正会错。

### 不跨盆地的整体平移

给每个输入加同一整数c，并假设每个元素仍在它原来的平方盆地内。真实根及K不变，x和m同加c，故(x-m)/(2K)完全不变。预测、根偏差及修正次数不变；残差全体加c，规范化键r-rmin和残差跨度D不变。

对沿用这些量的确定性试探、分类和融合选择，可以得到相同的控制路径与记录次序，输出值整体加c。该性质说明基准残差参与公式的作用。

## 大K、小坐标网格：更有区分力的研究区间

仍取 x=(K+j)^2+e、j<20、e<8。K=10^6时，值约在10^12附近，完整支持集的原始数值跨度为

\[
R=2K\cdot19+19^2+8=38000369.
\]

坐标网格只有20×8=160个槽。这里普通全值域计数需要处理大量簇间空隙，BRC结构计数表保持很小；它也比百万值域的小例子更能放大表示差异。

强基线应包括：
- 先减最小值、按实际有效位数运行的基数排序。
- 普通仿射分桶，再学习每桶最小/最大值，并做桶内局部计数。
- 纯数值的重复键直方图/去重后排序输出；若利用重复值，双方都应利用。
- 比较排序作为通用入口对照。

仿射分桶加每桶偏移也可达到O(n+Σ桶宽)，在该族上可成为O(n+BD)。值得测量的BRC差异是模型恢复、局部范围学习次数、证书与总遍历成本，不能只依据160与38000369两个表大小判断实际胜负。

输入构造与分类的完整成本应写成

\[
T=T_{\rm 建立表示}+T_{\rm 坐标恢复}+T_{\rm 分类}+T_{\rm 输出}.
\]

已有状态的下游复用单列口径；原始自然数入口继续支付构造成本。更大整数实现需相应的宽乘法和精确根成本。

## 可复现的有限检查

以下JavaScript为本轮实际精确检查的核心；全部中间整数远低于2^53，乘法与整数商结果可精确核对。console输出只用于复现展示。36,400点对照的oracle是独立整数二分根。

~~~javascript
function root(x) {
  let lo=0, hi=1001;
  while (lo+1<hi) {
    const m=Math.floor((lo+hi)/2);
    if (m*m<=x) lo=m; else hi=m;
  }
  return lo;
}
const histogram={0:0,1:0};
for(let x=810000;x<846400;x++){
  const k=root(x);
  const p=900+Math.floor((x-810000)/1800);
  if(p-k<0 || p-k>1) throw new Error("overshoot");
  histogram[p-k]++;
  const corrected=p-(p*p>x ? 1:0);
  if(corrected!==k) throw new Error("correction");
}
console.log(histogram); // {0:33530,1:2870}
for(const shift of [0,900,1790]){
  let oldHits=0,newHits=0;
  for(let j=0;j<20;j++) for(let e=0;e<8;e++){
    const x=(900+j)**2+e+shift;
    if(root(x)!==900+j) throw new Error("basin");
    oldHits+=900+Math.floor((x-810000)/1800)===900+j;
    newHits+=900+Math.floor((x-810000-shift)/1800)===900+j;
  }
  console.log(shift,oldHits,newHits);
}
~~~
