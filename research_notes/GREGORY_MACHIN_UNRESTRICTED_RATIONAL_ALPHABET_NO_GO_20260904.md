## 1. Question

The rational-complement continuation allows every primitive positive rational-slope turn

\[
[b+ai],\qquad 0<a<b,\qquad\gcd(a,b)=1
\]

as a possible analytic atom.  Its natural power-series convergence coordinate is the ratio

\[
\rho=b/a,
\]

so a naive generalized Lehmer measure assigns atom cost

\[
L(a,b)=\frac1{\log_{10}(b/a)}.

Before running a large generalized-circuit search one must test whether this objective is even nondegenerate when arbitrary primitive rational atoms are admitted.

The answer is negative.

## 2. A target-free first-crossing family

Fix any integer

\[
q\ge2
\]

and let

\[
U_q=[q+i].
\]

Starting from the identity direction, multiply repeatedly by `q+i`.  Write

\[
(q+i)^j=A_j+B_j i.
\]

Define `k(q)` to be the **first** index at which

\[
\boxed{B_k>A_k>0}.
\]

The selection rule uses only exact integer comparisons; it does not use a numerical value of `pi` or an inverse tangent.

While a current slope

\[
s=B/A
\]

satisfies `0<=s<1`, one multiplication by `q+i` gives

\[
s'=rac{qs+1}{q-s}.
\]

Hence

\[
\boxed{
s'-s=\frac{1+s^2}{q-s}.
}
\]

For `0<=s<1`,

\[
\boxed{
\frac1q\le s'-s<\frac2{q-1}.
}
\]

Therefore the crossing occurs in finite integer time.

There is no exact equality `B_j=A_j` for `q>=2`: in the already-proved Gaussian valuation decomposition, `U_q` has a nonzero odd split-prime free coordinate, while the diagonal class `tau=[1+i]` has none, so no positive power of `U_q` can equal `tau`.

Summing the increment bounds until first crossing yields the purely native estimates

\[
\boxed{
\frac{q-1}{2}<k(q)\le q.
}
\]

Thus

\[
k(q)=\Theta(q)
\]

without using analytic angle selection.

\[

## 4. The residual slope is strictly smaller than `1/q`

\[

Then

\[
A=qA_0-B_0,

B=A_0+qB_0.

\[
\begin{aligned}

&=(A+B)-q(B-A)\\

\boxed{

Primitive reduction does not change the ratio, so

\boxed{

This inequality is exact and uses only the finite predecessor relation.

## 6. Why the apparent infinite acceleration is not free

The residual rational atom has rapidly growing integer coordinates.

Write

\[
q^2+1=2^{\epsilon_q}M_q,
\]

where

\[
\epsilon_q=
\begin{cases}
0,&q\text{ even},\\
1,&q\text{ odd}.
\end{cases}
\]

Thus

\[
\boxed{
M_q=
\begin{cases}
q^2+1,&q\text{ even},\\
(q^2+1)/2,&q\text{ odd}.
\end{cases}
}
\]

Every odd prime dividing `q^2+1` is `1 mod 4`, and in `q+i` its full odd norm exponent lies on exactly one member of the conjugate Gaussian-prime pair.  Hence the free oriented Gaussian valuation vector of `U_q^{k(q)}` has absolute norm exponents multiplied by `k(q)`.

Multiplication or division by the diagonal class changes only the ramified/torsion `2` coordinate.  Therefore for a primitive integer representative `(c,d)` of the residual,

\[
\boxed{
c^2+d^2\in\{M_q^{k(q)},\;2M_q^{k(q)}\}.
}
\]

A primitive sum of two squares cannot contain a higher power of `2`, which gives the displayed dichotomy.

Using the crossing-time lower bound,

\[
\log_2(c^2+d^2)
\ge k(q)\log_2M_q
>\frac{q-1}{2}
\log_2\!\left(\frac{q^2+1}{2}\right).
\]

Thus

\[
\boxed{
\log_2(c^2+d^2)=\Omega(q\log q).
}
\]

Since

\[
\max(c,d)^2\ge\frac{c^2+d^2}{2},
\]

the bit length of the largest coordinate obeys

\[
\boxed{
\operatorname{bits}\max(c,d)=\Omega(q\log q).
}
\]

So the vanishing term-count measure is purchased by an exploding arithmetic description of the second atom.

## 7. Resource-typing consequence

The earlier fixed-compute theorem explains Lehmer measure as an asymptotic **series-term exponent** when atom representation cost is treated as fixed.  The present family violates precisely that hidden uniformity assumption: as `q` grows, the atom itself contains `Theta(q log q)` bits of integer coordinate data.

Therefore

\[
\boxed{
\texttt{TERM_COUNT_OPTIMALITY}
\ne
\texttt{BIT_OPERATION_OPTIMALITY}.
}
\]

And more specifically,

\[
\boxed{
\texttt{UNBOUNDED_RATIONAL_ATOM_ALPHABET}
+
\texttt{LEHMER_ONLY_COST}
\Longrightarrow
\texttt{DEGENERATE_OPTIMIZATION}.
}
\]

Any generalized Machin Pareto problem must either:

1. restrict the allowed atom alphabet by a finite height/norm rule; or
2. charge for atom coordinate bit complexity and the arithmetic cost of using those coordinates; or
3. report both coordinates separately rather than collapsing them to one scalar.

No particular combined scalar penalty is promoted here; choosing one without an operational model would merely replace one arbitrary metric with another.
