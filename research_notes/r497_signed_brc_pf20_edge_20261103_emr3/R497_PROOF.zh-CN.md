# R497 — 冻结 signed BRC 右缘二十阶 Toeplitz 子式的两次符号转换

Date: 2026-11-03 · Research lane: EM research3 · Status: author-side exact computer-assisted proof; Driver unreviewed / not admitted. Scientific input: frozen R462 commit `18783e01e3646c72b7aab3b16d3f565e83e6446f`. Predecessor: R496 (`d685e0ffee05bef48e31d93c47e0a85dcd7e519e`, Draft PR #1708).

## 研究对象与定理

令 `k` 为正整数，`r=2k+1`，`C_k=binom(2k,k)/(k+1)`。沿用冻结 R462 的带符号 BRC 辅助标量：

```text
H_k(t)=binom(r+t,2t) * [x^r](1-x)(1+x)^(2t)(1+x²)^(r-t), if 2<=t<=r;
H_k(t)=0, otherwise;
D_m(k)=det[H_k(3+i-j)]_(0<=i,j<m).
```

这是保留有符号分支相消的辅助标量观察，研究其有限 Toeplitz/PF 必要子式。

**定理 R497**：对全部整数 `k>=1`，

```text
D_20(k)>0     1<=k<=5;
D_20(k)<0     6<=k<=118;
D_20(k)>0     k>=119.
```

负二十阶子式的全部整数参数范围恰好为 `6<=k<=118`，即奇数 `r=13,15,...,237`；从 `r=239` 起永久正性。结合 R496 的 `D_19(k)<0`（全部 `k>=7`），得到无穷参数族 `D_19(k)<0<D_20(k)`（全部 `k>=119`）。`k=6` 时 `D_19(k)>0>D_20(k)`。

## 精确整式化

在有理多项式环 `Q[k]` 内，记 `p_t(k)=H_k(t)/C_k`。沿用 R496 精确验证的公式：

```text
p_t(k)= sum_(q=0)^floor((t-1)/2)
       [4^q * binom(t-1,2q)/(2t)!]
       * prod_(h=0)^(q-1) (k-h)(k+1-h)
       * prod_(e=2-t..t+1; e not in {1-2q,...,0})(2k+e), t>=2.
```

设 `f_0=1`，`f_m=D_m/C_k^m`。由于矩阵是上带宽为一的 Hessenberg Toeplitz 矩阵，第一列展开与剩余分块给出：

```text
f_m(k)=sum_(ell=1)^m (-1)^(ell-1)*p_(ell+2)(k)
                                 *p_2(k)^(ell-1)*f_(m-ell)(k).
```

用 `p_2,...,p_22` 的有理整式构建 `f_20`，`deg f_20=120`。精确整除和全部121项系数恒等式验证

```text
f_20(k)=G_20(k)*P_20(k)/N_20,
G_20(k)=k^20*(k+1)^20*(k+2)*(2k+1)^20*(2k+3)^20,
N_20=2680475156253912208213134366160008113169074552390729387212800000000000000000000.
```

其中 `P_20` 是39次本原整数多项式，40项完整系数已保存在 `R497_EVIDENCE.json:p20_ascending`。因 `C_k>0,G_20(k)>0,N_20>0`（`k>=1`），`D_20(k)` 与 `P_20(k)` 同号。

## 覆盖无限整数域的符号证书

置 `u=k-119`，有

```text
P_20(119+u)=sum_(j=0)^39 b_j*u^j,
b_j=sum_(i=j)^39 [k^i]P_20(k)*binom(i,j)*119^(i-j).
```

精确整数平移的**全部40个 `b_j` 严格为正**，最小系数为 `192576836923918788587765742211404564267008`。完整整数系数见 `R497_EVIDENCE.json:shifted_tail_coefficients_ascending`。因此对实数 `u>=0`，`P_20(119+u)>0`，覆盖全部整数尾段。
