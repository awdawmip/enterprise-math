## 0. 本轮问题与量的类型

前沿已区分旧子格 L_old、共轭交替 L_alt、随 base 改变的紧凑循环核 Lambda_N，以及固定原生路径前缀 S_N。本轮不合并这些对象。问题从“至少换几个点”推进到“至少走多少原生单位步，能否分解成不碰撞的局部动作”。

保持 P000 六轴、锚点相对 Z^6、十二个 signed unit steps、原生平方读数 Q(z)=sum z_i^2。本文成本 ||v||_1 是实现位移 v 的最少原生单位步数，**不是把原生端点距离 sqrt(Q(v)) 改定义为 l1**。在一般多轴位移上二者不同。

除非专门写明盒约束，最终代表点允许位于任意 Z^6 位置；不能将这个优化结果冒充紧凑、连通、嵌套或同时满足全部 N 的空间选择。

## 1. 定理 T1：真实修复成本精确等于有限商图运输

令 L<Z^6 的指数为 N，C=Z^6/L，pi 为商映射。S 是 N 个不同原生 Cell，a(c)=#{x in S:pi(x)=c}。在 C 上用 +/-pi(e_i) 作为生成边，每条非平凡边成本为1，忽略自环。

定义

    d_C(c,d)=min{||v||_1: pi(v)=d-c}.

它恰是这张有限连通 Cayley 图的最短路距离。定义总修复成本

    W(S,L)=min sum_(x in S) ||F(x)-x||_1,

最小值取遍从 S 到 L 的任意完整代表集的双射 F。则

    W(S,L)=min_(bijection sigma:S->C) sum_x d_C(pi(x),sigma(x)).       (T1)

证明：任意 F 给出 sigma=pi o F，每个真实位移的成本至少为相应商距离，得到下界。反之取一个最优 sigma，为每个 x 选一个实现相应最短商路的有符号原生步骤序列，其位移为 v_x，令 F(x)=x+v_x。不同输出余类确保 F(x) 两两不同，且恰覆盖 C。因此下界可达。

所以固定 S 和 L 的问题，完全降为有 N 个带标签源与 N 个余类目标的有限整数指派。无需预先猜测最终代表点。这个下降只保住所声明的最优标量成本与余类；重构实际几何时仍保留源 x、目标余类以及选定的步骤/位移。

### 同时最少换点与最小总成本

令 delta=N-|pi(S)|。存在 T1 的最优解，恰好只改动 delta 个原点，其余各已出现余类保留一个原点。

证明：把一个最优指派看成余类间的有向多重边，节点 c 的出度为 a(c)，入度为1。某个已出现节点 c 若没有自环，设入边为 d->c、任选出边 c->e。把它们改为 c->c 与 d->e，由三角不等式总成本不增加。新产生一个自环，不破坏已有自环。有限重复后，每个已出现节点都具有一个零成本自环；其余 delta 个源恰好匹配缺失余类。原指派已最优，故成本保持最优。

等价的更小问题：每个 c 供应 (a(c)-1)_+ 个多余代表，每个空余类需要1个，用 d_C 匹配它们。可同时做到“少改点”和“总路程最短”；但下一节表明这不等于“每个点都只需短距离”。

## 2. 定理 T2：最优运输可实现为恰 W 次无碰撞的单位接力

T1 也等于整数图流问题：在上述 Cayley 图的有向边上，取非负整数流 f，要求

    out_f(c)-in_f(c)=a(c)-1,
    minimize sum_edges f(edge).

指派沿最短路展开给出流。反向，去掉正成本循环、把整数流分解成多余余类到空余类的路径，就给出不更贵的指派，故最优值相等。

现从任意最优流出发，找从多余节点通向空节点的一条简单流路径；遇到第一个空节点就停止，因此中间余类都有 Cell。沿路径从空节点向后，依次把前一节点中的一个 Cell 沿对应原生边移入当前空余类。目标余类在该瞬间没有任何 Cell，所以不可能撞上另一原生 Cell。最后从多余节点移走一个点。

扣除这条单位路径的流并更新占据数，继续。总共恰走 W 次原生单位边，最后每类恰有一个 Cell，且过程中 Cell 总数始终为 N、物理位置两两不同。

**代价没有消失**：修复需要额外的内部步骤/时间；可能移动原本不重复的代表；不保证停留在原包络盒，也不保持旧的“每次计数恰增加一个 Cell”的嵌套过程。这里没有提出力学演化律。

## 3. 定理 T3：总路程、改点数和最大位移是三个不同目标

令 R 为允许每个原点的最大单位步位移。存在满足该界的完整代表修复，当且仅当对每个余类子集 A 都有

    sum_(c in A) a(c) <= |{d in C: d_C(d,A)<=R}|.                    (T3)

这是 Hall 配对条件在重复源纤维上的精确应用：同余类的所有源拥有同一目标邻域，所以按余类汇总即可。R=0 的条件退化为已无碰撞。

实例取 L=8Z x Z^5，S 的第一坐标依次为

    0,8,1,2,3,5,6,7

且其他坐标为0。唯一多余余类为0，唯一空余类为4，delta=1。

- 只换一个原点时，它至少移动4个单位；最优总成本也是4。
- 依次执行 3->4、2->3、1->2、0->1，只用4次原生单位动作，每次目标位置都空，最终得到完整余类代表；每个被移动原点只动1步。

所以最少改点数为1，最小最大位移为1，但实现后一目标需要改动4个点。二者不能由一个“缺陷数”替代。此例是嵌入 X6 的说明例，不声称它就是已固定的 S_8。

## 4. 定理 T4：忽略原生方向会产生不可消去的平均代价

假设一个指数 N 商观察只依赖 r<6 个指定原生坐标。任何完整代表集的这 r 个坐标投影必然两两不同。设原 S_N 的这些坐标绝对值不超过 B_N=O(N^(1/6))。

在 Z^r 中，sup 范数不超过 R 的整数点至多 (2R+1)^r。取 R=((N/2)^(1/r)-1)/2，至少 N/2 个不同投影位于这个半径之外（取严格开球处理整数边界）。因此任何完整代表修复满足

    W/N >= ((N/2)^(1/r)-1)/4 - r B_N.                             (T4)

因为 r<6，右边的正主项增长快于 N^(1/6)。这排除了这类观察的有界平均修复成本。

注意这是“只看 r 个指定原生坐标”，不是说循环商群只有一个标签就天然只能一维。紧凑核 phi_b(z)=sum b^i z_i mod N 虽输出一个余数，却使用全部六个原生坐标和随规模变化的系数，不能套用忽略五轴的前提。

### 旧链与共轭链的一类素数：得到精确主常数 1/4

对 p=3 mod4，当前 L_old(p)=L_alt(p)=pZ x Z^5。商图是 p 环。令

    B_p=sum_(x in S_p) d_(Z/pZ)(x_0,0),
    H_p=sum_(c mod p) d_(Z/pZ)(0,c)=floor(p^2/4).

逐项三角不等式，对任意目标余类排列都给出

    H_p-B_p <= W(S_p,L_alt(p)) <= H_p+B_p.                         (T5)

又有 B_p<=sum_x |x_0|=O(p^(7/6))，所以沿这类素数趋于无穷时

    W/p^2 -> 1/4,
    W/p = p/4 + O(p^(1/6)).                                      (T6)

这个主项是一般证明，不是拟合。此处所有最佳位移可以沿第一轴完成，所以最优 l1 总成本也等于最优原生端点 l2 总成本。对一般商不作这种等同。

结论针对两条已固定链的第一素数步骤：共轭交替修好全部六次幂节点，并未修好这类中间节点。不能据此否定所有其他整除兼容子格族的可能性。

## 5. 精确计算及盒约束的独立价格

求解器使用已有 SciPy linear_sum_assignment 给出候选排列。随后用整数差分约束构造 alpha_i、beta_j，并逐项核验

    alpha_i+beta_j<=cost_ij,
    alpha_i+beta_(sigma(i))=cost_(i,sigma(i)),
    sum alpha+sum beta=候选总成本。

这给出独立于浮点最优性宣告的有限整数原始/对偶证书。脚本保存 p=67 两个模型的证书；其他全部证书也实际检查，可用 --full-output 导出。

对完全相同的原生路径前缀，得到：

| N | 旧/共轭链第一轴商总成本 | 紧凑循环核总成本 |
|---|---:|---:|
| 7 | 9 | 1 |
| 31 | 225 | 2 |
| 67 | 1087 | 24 |
| 127 | 3952 | 44 |
| 251 | 15583 | 112 |

两列是**不同子格**，不能描述成保持旧商关系的算法加速。紧凑核仍保留父笔记的换 base 后不满足全尺度整除包含的反例。

进一步限定全部最终代表必须处于下一个原生包络盒 B_b，正确成本矩阵应改成

    cost_B(x,c)=min{||y-x||_1:y in B_b,pi(y)=c}。

它一般不只依赖 pi(x)。本轮得到：N=65 时自由目标最优20，盒内最优26；N=67为24和28；N=80为54和90。盒内最优同样由整数对偶证书验证。

因此只用商图最短路，不能声称同时算出了盒内最优。T6 精确反例：L=8Z x Z^5，源第一坐标0与8同余；到盒内唯一余类1代表的距离分别为1与7，而自由余类距离均为1。加入盒约束改变了可安全压缩的观察。
