## 精确证明

**1. 六个根的独立存在唯一性。** 冻结 PREFIX-340 的六个有理五坐标中心以及统一盒半径 `rho=10^-8`。将规范复来源写为 `a=lambda*(x1+i*x2,x3+i*x4,x5)`（第五实坐标严格为正）。检查器从上述矩阵独立生成五个二次质量方程、Jacobian 及常数 Hessian，对每个盒核验 `J(c)` 可逆、`eta=||J(c)^-1 F(c)||_infty<10^-9`、`K<30`、`eta+K*rho²/2<rho`、`K*rho<1`。Newton–Banach 映射在盒内收缩且自映，每盒恰有一个真实来源。六盒两两分离；核验十个非零三阶子式和45个保留来源标签的有序 BRC 路径对。

**2. 从完整连续相位弧到代数端点。** 对任一来源令 `w_j=(Ua_j)_3`，则 `|w_j|²=q3=29125/29768`。设 `z=phase*w_j=x+iy`。报告精确要求 `x²+y²=q3` 且 `y>=1/2`；其他分量自动相容。令 `s=sqrt(q3-1/4)`，弧端点 `z_±=±s+i/2` 对应来源状态 `v_{j,±}=(z_±*conj(w_j)/q3)*a_j`。检查器通过整数平方根得到 `s_-<s<s_+`、`s_+-s_-=10^-12` 的**有理数严格夹逼**，传播六个有理根盒后得到十二个端点各复坐标的有向有理区间。

**3. 连续弧上界是严格的，而非网格采样。** 选固定有理中心

```
c=(0.28926878-0.47221704i,
   0.01415422-0.04647865i,
   0.07637985-0.23157621i)
```

令 `t_j=<c,a_j>/w_j=<c,a_j>*conj(w_j)/q3`，内积首变量共轭线性。有向有理区间证明六盒中 `Im(t_j)<-7/10`。沿任意完整允许弧 `z=x+i*sqrt(q3-x²)`，平方距离恰为

`||a_j||²+||c||² - 2*x*Re(t_j)+2*sqrt(q3-x²)*Im(t_j)`。

由于 `Im(t_j)<0` 且平方根项严格凹，这个函数在 `[-s,s]` **严格凸**，最大值必在 `x=±s`。检查十二端点的平方距离上界，逐项严格小于 `3264539/1250000`，得到全部连续相位的共同覆盖球。

**4. 任意球心的五端点方差下界。** 从真实根盒选择端点 `(0,-),(1,+),(3,+),(4,+),(5,-)`，配以正有理权重 `(258342,263865,81607,152532,243654)/10^6`，总和恰为1。对于任意中心 `b`，有
