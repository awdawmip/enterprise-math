## 定理 A — 漂移系数严格二维隔离

以前轮 R597 的固定根三阶一致展开为前提，定义

ℓ = -G(ζ)/F′(ζ)；

m = -[H(ζ)+G′(ζ)ℓ+F″(ζ)ℓ²/2]/F′(ζ)；

n = -[J(ζ)+H′(ζ)ℓ+G′(ζ)m+G″(ζ)ℓ²/2+F″(ζ)ℓm+F‴(ζ)ℓ³/6]/F′(ζ)。

则得到全部严格开区间：

-4.387517 < Re(ℓ) < -4.387514，-17.129121 < Im(ℓ) < -17.129117；

32.713313 < Re(m) < 32.713318，20.925232 < Im(m) < 20.925237；

-93.087448 < Re(n) < -93.087445，24.149782 < Im(n) < 24.149786。

## 定理 B — 固定共轭根对谱能量的四项系数

令 b=Im(ζ)>0、u=Im(ℓ)、v=Im(m)、w=Im(n)。沿用 R597 中有限辅助谱 μ=ζ_k/k² 及 d=2k−1，有

V_k(pair)=2(Im ζ_k)²/[(2k−1)k⁴]
          = E5/k⁵+E6/k⁶+E7/k⁷+E8/k⁸+O_ζ(k⁻⁹)，

E5=b²；
E6=b²/2+2bu；
E7=b²/4+bu+u²+2bv；
E8=b²/8+bu/2+u²/2+bv+2bw+2uv。

全部以下为严格有理数证明的开区间：

89.888444 < E5 < 89.888447；
-279.856486 < E6 < -279.856482；
550.260754 < E7 < 550.260760；
16.194578 < E8 < 16.194585。

因此第四项 E8 严格为正，四项系数符号为 (+,-,+,+)。本定理给出单个固定辅助共轭零点对的局部渐近常数，不把该观察映射提升为原生 signed BRC 的无损谱结论。

## 证明及机器检查范围

对 F,G,H,J 分别使用 R597 的精确级数多项式系数，计算所需 0–3 阶导数至 j=44。若 |z|≤12 且 j≥45，则这四族因子绝对值均由 4(j+1)^4 控制，任意 s≤3 阶导数的第 j 项由 u_j=96(j+1)^8·96^j/(2j+4)! 控制。相邻比值 u_{j+1}/u_j<1/2 且递减，故统一余项严格小于 2u_45。首次比值界由 Fraction 断言。

精确有理复球 Ball(a,b,e) 表示圆盘 |z−(a+ib)|≤e。加法和乘法按三角不等式扩张，倒数采用保守界 e/[d(d−e)]，d=max(|a|,|b|)−e>e。此界保守包住所有输入。代码首先检查 |F(c)|<10^-30、|F′(c)|>1/25、|F″(B(c,ρ))|<1、|F(c)|+ρ²/2<ρ/25，重建局部零点证书。继而直接代入 ζ∈B(c,ρ) 得到 ℓ,m,n 的有理球；对 b,u,v,w 做严格外包及全部区间断言。
