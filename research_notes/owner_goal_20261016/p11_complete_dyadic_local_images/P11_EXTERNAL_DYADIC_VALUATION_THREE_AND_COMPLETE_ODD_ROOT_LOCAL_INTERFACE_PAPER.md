    y²=x(x−P²)(x−Q²),

with the SAME fixed root order(0,P²,Q²). Its split Kummer map at ordinary points is delta(x,y)=(x,x−P²,x−Q²), product1 in squareclasses. At zero factors use the already established product-of-root-differences convention, and delta(O)=(1,1,1). Denote the full image by I2.

## 2. Complete containment proof at valuation3

Write v=v2. For an ordinary Q2 point with all three factors nonzero, prove that x is a square. The precise unit-square criterion is that an odd2-adic unit is a square exactly when it is1 mod8. Ratios are considered only after their factors have been shown nonzero.

If k=v(x)<0, all three factors have valuation k because P,Q are units. The curve equation forces3k even, so k is even. If k≤−4, both1−P²/x and1−Q²/x are1 mod8 and squares. If k=−2, each is5 mod8: indeed x=2^(−2)u with u odd, so P²/x=4P²/u and Q²/x=4Q²/u are4 mod8. The product of the two correction units is then1 mod8 and square. In either case y²=x³ times a square, so the squareclass of x is trivial. Odd negative k was already excluded by valuation parity; no negative-valuation branch is omitted.

If k>0, x−P² and x−Q² are odd units, congruent modulo8 because P²≡Q²≡1 mod8. Their product is an odd square unit. The equation again forces x square. This includes any impossible odd positive k automatically; it does not assume k even before using the square criterion.

It remains to consider x an odd unit. If x≡1 mod8, x is already square. Suppose instead x≡3 or7 mod8. Then x−P²=2u with u odd, and

    (x−Q²)/(x−P²)=1+D/(x−P²)=1+4d/u ≡5 mod8.

The equation can be written as y²=x(x−P²)²*(1+4d/u). Its unit squareclass is therefore5x, which is7 or3 modulo8, never1. Contradiction.

Finally suppose x≡5 mod8. Then x−P²=4u with u odd, and

    (x−Q²)/(x−P²)=1+2d/u.

Since d/u is odd, this unit is3 or7 modulo8. Multiplication by x≡5 gives7 or3 modulo8, never1. The same rewritten curve equation is therefore impossible. This rules out the last nonsquare odd-unit class. Notice the contrast with valuation4: there the corresponding ratio in this last branch is5 mod8, whose product with x≡5 IS a square. That is exactly why simply extending the valuation≥5 proof without treating valuation3 would skip a necessary argument.

Thus x is square in every ordinary case. At T0, TP, TQ, the first exceptional coordinates are respectively P²Q², P² and Q², all squares. Infinity has first coordinate1. Consequently the full Kummer image is contained in the vertical subgroup.
