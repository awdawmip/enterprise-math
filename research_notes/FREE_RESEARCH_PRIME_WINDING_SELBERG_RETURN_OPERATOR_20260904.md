## PSRO-T01 — Exact finite Abel decomposition of the self-energy

Let

\[
\Psi_2(M):=\sum_{n\le M}\Lambda_2(n),
\]

where

\[
\Lambda_2(n)=\Lambda(n)\log n+(\Lambda*\Lambda)(n).
\]

Define

\[
A(M):=\sum_{n\le M}\Lambda(n)\log n.
\]

Since `psi(m)-psi(m-1)=Lambda(m)`, discrete summation by parts gives

\[
\boxed{
A(M)
=\psi(M)\log M
-\sum_{m=1}^{M-1}
\psi(m)\log\frac{m+1}{m}.
}
\]

Set

\[
H(M):=\sum_{m=1}^{M-1}
\psi(m)\log\frac{m+1}{m}.
\]

Then

\[
\boxed{A(M)=\psi(M)\log M-H(M).}
\]

At the formal prime-tensor level this contains no transcendental assumption: `log n` is the prime-exponent vector `ell(n)`, and the difference `log((m+1)/m)` is `ell(m+1)-ell(m)`.

## PSRO-T02 — Exact quotient return form of the convolution energy

The ordered-pair term is

\[
B(M):=\sum_{uv\le M}\Lambda(u)\Lambda(v).
\]

Grouping by the first factor gives

\[
\boxed{
B(M)
=\sum_{a\le M}\Lambda(a)
\psi(\lfloor M/a\rfloor).
}
\]

Therefore the cumulative quadratic primitive energy satisfies

\[
\boxed{
\psi(M)\log M
+\sum_{a\le M}\Lambda(a)
\psi(\lfloor M/a\rfloor)
=\Psi_2(M)+H(M).
}
\]

This is an exact finite Selberg return balance.

Geometrically:

- `psi(M) log M` is the present saturated-winding state paired with the current log scale;
- the quotient sum is all one-step prime-power returns to smaller resolutions;
- `Psi_2(M)` is the primitive self-plus-recoalescence energy;
- `H(M)` is the exact boundary transport generated by changing the log scale one integer cell at a time.

## PSRO-T03 — Exact factorial mass of the return kernel

The first-order quotient determinant identity gives

\[
\boxed{
\sum_{a\le M}\Lambda(a)
\left\lfloor\frac{M}{a}\right\rfloor
=\log(M!).
}
\]

This is simply

\[
\sum_{n\le M}\log n
=\sum_{n\le M}\sum_{a\mid n}\Lambda(a)
\]

with the finite sums exchanged.

Thus the prime-power return weights have a deterministic total mass fixed by the full positive Krawtchouk determinant.

## PSRO-T04 — Exact centered return equation

Write

\[
\psi(q)=q+R(q).
\]

Using PSRO-T03 in PSRO-T02 gives

\[
\sum_{a\le M}\Lambda(a)\psi(\lfloor M/a\rfloor)
=\log(M!)
+\sum_{a\le M}\Lambda(a)R(\lfloor M/a\rfloor).
\]

Also

\[
\psi(M)\log M=M\log M+R(M)\log M.
\]

Hence

\[
\boxed{
R(M)\log M
+\sum_{a\le M}\Lambda(a)R(\lfloor M/a\rfloor)
=F(M),
}
\]

where the finite forcing is

\[
\boxed{
F(M):=
\Psi_2(M)+H(M)-M\log M-\log(M!).
}
\]

No limit has been taken. This identity holds at every integer cutoff `M>=2`.

## PSRO-T05 — Exact probability-kernel normalization

For `M>=2`, define

\[
q_M(a):=\lfloor M/a\rfloor
\]

and

\[
\boxed{
\omega_M(a)
:=\frac{\Lambda(a)q_M(a)}{\log(M!)}.
}
\]

Every weight is nonnegative, and PSRO-T03 gives

\[
\boxed{
\sum_{a\le M}\omega_M(a)=1.
}
\]

Thus `omega_M` is an exact finite probability distribution on prime-power return actions.

Since

\[
R(q_M(a))=q_M(a)r(q_M(a)),
\]

we have

\[
\sum_{a\le M}\Lambda(a)R(q_M(a))
=\log(M!)\,\mathbb E_{\omega_M}[r(q_M(a))].
\]

Divide PSRO-T04 by `M log M`:

\[
\boxed{
r(M)
+\alpha_M\,\mathbb E_{\omega_M}[r(q_M(a))]
=\frac{F(M)}{M\log M},
}
\]

where

\[
\boxed{
\alpha_M:=\frac{\log(M!)}{M\log M}.
}
\]

This is the normalized prime-winding return equation.

## PSRO-T06 — The return coefficient is strictly subunit but asymptotically critical

For `M>=2`, every factor in `M!` is at most `M`, with at least one factor strictly smaller, so

\[
0<\log(M!)<M\log M.
\]

Hence

\[
\boxed{0<\alpha_M<1.}
\]

Integral comparison gives

\[
M\log M-M+1
\le\log(M!)
\le M\log M-M+1+\log M.
\]

Therefore

\[
\boxed{
\alpha_M
=1-\frac1{\log M}+O(1/M).
}
\]

The return is a strict contraction at every finite cutoff, but its gap closes like `1/log M`. This explains why a naive one-step sup-norm estimate is insufficient: the forcing term expected from the quadratic energy is also of normalized order `1/log M`.

## PSRO-N01 — Why absolute-value contraction stalls

Taking absolute values in PSRO-T05 gives

\[
|r(M)|
\le\alpha_M\max_{q<M}|r(q)|
+|F(M)|/(M\log M).
\]

Under `F(M)=O(M)`, both the contraction gap `1-alpha_M` and the forcing are of order `1/log M`. This can preserve a nonzero uniform bound and does not force convergence to zero.

Therefore a successful proof must use more than positivity and the total mass of the return kernel. It must exploit at least one of:

1. overlap/recoalescence among different quotient histories;
2. phase mixing across several dilation/carry masks;
3. the ordered-pair structure of the quadratic primitive energy;
4. a strict spectral gap on a centered function space stronger than the sup norm.

This negative boundary prevents relabeling the finite subunit coefficient as an already completed PNT proof.
