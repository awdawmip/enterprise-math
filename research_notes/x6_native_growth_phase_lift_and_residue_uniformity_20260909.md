## 2. 明确构造：循环逐面反射蛇形枚举

### 2.1 一个矩形面内的蛇形

对整数盒 [0,a_0-1] x ... x [0,a_(d-1)-1]，以轴0为最快轴、轴d-1为最慢轴递归遍历：在最慢轴的第 t 层，t 偶数时按前一维序列正向遍历，t 奇数时反向遍历。于是每个点恰一次，相邻点差一个带符号单位向量，起点和终点都是盒角。

如果进入时每个坐标处于某个端角，令 c_j 为该角的 low/high 位。完成面遍历后，坐标 j 的角位恰在“所有比 j 慢的轴长度均为奇数”时翻转。最慢轴总翻转。长度为1时两个角标签重合，但保留标签作为下一次扩展的方向约定，不增加物理坐标。

这可由反向遍历的定义归纳证明；其整数 rank/unrank 递归见附带程序。

### 2.2 从一个 Cell 无限扩展

初始盒只有原点，六个角位都取 high。每轮依次扩展轴 i=0,1,...,5：

1. 当前路径终点是已填满盒的一个角。沿轴 i 的该角外侧，加一个相邻的新面。
2. 新面第一点是当前终点加一个带符号 e_i。
3. 面内其余五轴按循环次序 i+1,i+2,...,i+5 (mod6)，从快到慢做上述蛇形。
4. 更新该盒边界和终点角位，继续下一个轴。

每次扩展的新面与已有盒不交，且面内无重复，因此无限序列不重访。新面的入口与旧终点是原生邻居，面内也是原生邻居；遍历完成后又落在新盒的角，因此归纳可一直进行。

### 2.3 覆盖全空间，而非只覆盖一个象限

一次完整轮次让每条边长度加1。轮次 r 从0计数，轮前边长为 r+1。角位只依赖长度奇偶和六个位，四轮即重复。把上一小节的角位公式代入，得到精确表：

| r mod4 | 轮前 high 位 (轴0至5) | 本轮六个外扩方向 |
|---|---|---|
| 0 | 111111 | +----- |
| 1 | 011110 | -+++++ |
| 2 | 110101 | +-+-+- |
| 3 | 010100 | -+-+-+ |

四轮之后角位回到111111，长度奇偶也回到原状。每两个连续轮次中，每根轴都向正、负各扩展一次。因此

    S_((2r+1)^6)=[-r,r]^6 intersect Z^6.                (1)

更一般，每个 s>=1 都有

    S_(s^6)=B_s,

其中 B_s 是六边长度都等于 s 的整数盒；奇数 s 时中心在锚点，偶数 s 时每个坐标的中心只偏移 +/-1/2。B_s 嵌套且穷尽 Z^6。

因此 x:N_0 -> Z^6 是双射，每次差值属于 {+/-e_i}。这证明了完整的无限构造；有限检验只是实施回归，不承担无限外推。

### 2.4 不需要“保存全部已访问点”来运行

流式枚举只保留盒边界、角位、当前面与面内混合进位状态。维数固定为6，这些状态只需 O(log N) 位。验证程序为了检查不重访使用集合，不是生成器本身需要那个集合。

还可随机访问：若 k>=1，取 s=floor(k^(1/6))。第 i 个面开始前已访问体积为

    V_i=(s+1)^i s^(6-i), i=0,...,6.

找到 V_i<=k<V_(i+1)，在该面中对 k-V_i 做混合进位反射解码即可。逆映射先找到包含该点的最小 B_s，再恢复其面序号和面内编号。所有步骤是整数运算，不需要素因子分解，也不暗示解决任何分解复杂度问题。

## 3. 定理 G1：六次根占据尺度在原生单位路径上实现

设

    R_N=max_{z in S_N} sqrt(Q(z)).

若 (2r+1)^6<=N<(2r+3)^6，则由 (1) 和嵌套性，

    sqrt(6) r <= R_N <= sqrt(6)(r+1).

N^(1/6) 同时位于 [2r+1,2r+3)，故

    R_N / N^(1/6) -> sqrt(6)/2.                       (2)

这里是明确的盒形占据范围，不是球形，也不是先把 N^(1/6) 人为放在一个单 Cell 半径上。

更一般，任何含 N 个不同整数 Cell 的集合若半径不超过 R，均有

    N <= (2 floor(R)+1)^6,
    R >= (N^(1/6)-1)/2.                              (3)

因此1/6是这种不重叠六维占据的自然体积指数。本构造达到正确阶，但不声称极小化球形包络的常数。

在完整中心盒 N=(2r+1)^6 上，

    E_mu_N Q(Y)=2r(r+1),
    sqrt(E_mu_N Q(Y)) / N^(1/6) -> 1/sqrt(2).        (4)

全部中间前缀只比完整盒多一层 O(r^5) 的点，且 Q=O(r^2)，故同一极限适用于全部 N。等权占据经 N^(1/6) 归一化后收敛为 [-1/2,1/2]^6 上的均匀体积分布。可用完整盒的 Riemann 和与 O(N^(5/6)) 边界点直接证明；不主张连续旋转不变的球形分布。

### 不违背父笔记的径向单调障碍

令 I_t 为枚举前 t 步中 Q 减少的次数。每个单位步使 l1 长度恰增或减1，因而

    I_t=(t-||x_t||_1)/2.

本构造 ||x_t||_1=O(t^(1/6))，所以 I_t/t -> 1/2。新点没有重访，但是接近一半的步骤径向向内。这具体实现了先前的必要条件，而不是绕过它。

## 4. 定理 G2：固定原生余类的全前缀均匀性与精确节点

设 L 的指数为 q。有限商群阶为 q，故 qZ^6 subset L。

每个边长是 q 倍数的整数盒，在 Z^6/qZ^6 的全部余类中精确等量，从而在 Z^6/L 的 q 个余类中也精确等量。

令 s=floor(N^(1/6))。S_N 包含完整 B_s，且与之相差少于 (s+1)^6-s^6 个点。在 B_s 内截取边长 q floor(s/q) 的子盒；这个子盒精确等量，其余点总数至多

    6q(s+1)^5.

所以对任何余类 c 都有明确偏差界

    | #{z in S_N:q_L(z)=c} - N/q | <= 6q(s+1)^5.     (5)

特别地，对每个**固定** q 与 L，

    Pr_mu_N(q_L(Y)=c)=1/q + O_q(N^(-1/6)).            (6)

当 N=s^6 且 q|s 时，不需要极限：

    Pr_mu_N(q_L(Y)=c)=1/q                            (7)

精确成立。有限空间盒不是“全空间上的均匀概率”，不存在把无限离散全空间均匀化的偷换。

### 真正的 CRT 可以保留，但观察视野必须写清

对于两个固定子格 L_a,L_b，观测同一个 Y_N 的两个余类。它们的联合支持是

    image[Z^6/(L_a intersect L_b) -> C_a x C_b]。

用 (5) 对交格应用，得到这个真实兼容支持上的均匀性。

若 a,b 互素，支持就是全部 ab 个配对，每对趋于1/(ab)，在 ab|s 的盒节点精确成立。若使用此前满足 L(a) intersect L(b)=L(lcm(a,b)) 的所选家族，则共享因子的兼容关系被保留，联合支持为 lcm(a,b) 个，而不是默认全部 ab 个。

这没有把 floor 编号改造成 CRT。它是在同一真实 Cell 上另做原生商观察，保留其原来群关系。

**尺度边界：式 (6) 的模数固定。它不证明随 N 增长的 C_N、C_(N+1) 也均匀兼容；将 q=N(N+1) 代入只会得到无效的大误差界。** 父笔记的相邻商层完整平移等变障碍仍有效。

实例：N=6^6=46656 时，每个六分量 mod6 向量恰出现一次。观察 (sum_i z_i mod2,z_0 mod3) 的六个配对，各恰出现7776次，保留全部六种原生配对，而非共同相位 (floor2theta,floor3theta) 的四种支持。

## 5. 定理 G3：原生动作在长程中六轴均衡

选择循环的面内快慢轴顺序并非装饰。在边长约为 s 的一个新面中，最快轴的步数为

    (a_fast-1) product_(other four axes) a_j = s^5+O(s^4)，

其他四轴的总步数仅为 O(s^4)，进入面的另一步也为低阶。每轮六个面的最快轴各不相同，因此每根轴每轮贡献 s^5+O(s^4)。

累加到边长约为 s 的盒，误差为 O(s^5)，总步数为 s^6+O(s^5)。故对全部前缀，

    #steps along unoriented axis i / t -> 1/6.       (8)

正向减负向步数恰为 x_t 的相应坐标，为 O(t^(1/6))，所以每个有向原生方向的比例趋于1/12。

这是**长程步数频率**，不是每个有限前缀各向同性，也不是全部 native rotation dynamics 已分类。开始的64个点就有明显的轴频率不平衡，实验完整保留这些数据。

构造选择了轴循环与初始角标。若把一个全局轴排列均匀选择一次并保留，可得有限层数上 S6 等变的路径分布；不能不保留该选择就声称确定性规则本身没有任何方向先验。全对称锚点的确定性首步仍面临 T7 的无固定邻居障碍。

## 6. 定理 G4：把父笔记的历史寄存器提升到真正 Cell 上

取共同 theta in [0,1)，并定义

    X_N=floor(N theta),  Y_N=x_(X_N).

theta 均匀时，Y_N 恰服从 mu_N。由于

    X_(N+1)-X_N in {0,1}，

Y 每次不是停留，就是沿枚举路径走一条原生单位边。

相邻层的联合概率为

    P(Y_N=x_i,Y_(N+1)=x_i)=(N-i)/[N(N+1)]，
    P(Y_N=x_i,Y_(N+1)=x_(i+1))=(i+1)/[N(N+1)]。

因此不论 N 多大，

    Pr(Y_(N+1)!=Y_N)=1/2,
    E d6(Y_N,Y_(N+1))^2=1/2.                        (9)

这两个式子不应解释成未经定义的物理速度、扩散系数或力。它们是该标记占据过程的精确空间读数。

父笔记已证明相邻均匀人口至少需要2N条正权支持；这里恰用N条停留边和N条原生前进边达到它。只有在指定的路径边语言下才可称为这一局部规则的唯一解，不声称在 X6 全部邻接边上的最优输运也只能如此。

### 为什么标记过程不能强行去掉停留

网格的二部着色 chi(z)=(-1)^(sum z_i) 沿每个原生步翻转。枚举的 x_i 颜色是 (-1)^i，所以 mu_N 的颜色均值是 N 奇数时1/N、N 偶数时0。

若每个标记每一步都必须移动一条原生边，下一层颜色均值必是旧均值的相反数；但上述相邻两个均值从不满足这个要求。因此这些等权前缀分布之间不存在完全不停留的单位步标记过程。新 Cell 的枚举路径没有停留，与标记过程需要停留并不冲突。

### 精确保留历史

保留父笔记的区间

    I_N=intersection_(k<=N) [X_k/k,(X_k+1)/k)。

下一层对该区间和 j/(N+1) 分割求交，按长度比例分支，保存新交集。再用 x_j 输出真实 Cell。因为 x 是双射，该提升保持父笔记的全部有限阶段联合律。尤其

    floor(rank(Y_(mN))/m)=rank(Y_N)。                 (10)

**(10) 是枚举编号的细分恒等式，不是原生线性坐标缩放，也不是任意子格商映射。** 历史区间是内部状态，不是第七个空间坐标。

当前 Cell 能恢复当前编号，却一般恢复不了整个历史区间；此前“2->3->4”丢掉历史导致1/6细分失配的反例仍有效，只是现在每个编号都有真实格点。

## 7. 一个有限但真实的乘法覆盖桥：完整盒的 radix 法则

记 B_s=a_s+D_s，其中 D_s={0,...,s-1}^6，a_s 是本轮盒的整数下角。

标准坐标除法给出精确双射

    D_s x D_t -> D_(st),   (u,v) -> u+s v。          (11)

其逆为逐分量取 mod s 与整除 s，且

    u+s(v+t w)=(u+s v)+st w。                        (12)

所以在 N=s^6 的占据节点上，

    |B_s| |B_t|=|B_(st)|,
    B_(st)=a_(st)+(B_s-a_s)+s(B_t-a_t)，              (13)

右侧和是唯一数字分解，不是有重叠的概率云。

这是整数 radix 的经典机制在本构造中的明确落位。需要保留下角修复；它不宣称枚举编号顺序也与这套空间数字顺序一致。

**子格身份边界：这里的乘法子格是 sZ^6、标量矩阵sI，指数s^6。它不是自动等于此前高斯素数链选出的 L(s^6)。同样指数、同样相似倍率仍可能是不同子格，不能凭计数强行识别。** 因而 (13) 是六次幂节点上的正面桥，不是全部自然数的 A(n) 兼容定理。
