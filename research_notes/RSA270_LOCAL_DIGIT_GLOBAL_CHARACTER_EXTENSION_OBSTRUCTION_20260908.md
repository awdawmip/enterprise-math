## 1. Conditional lift fiber has only one new base-l digit

Let

`m=l^e`, `n=l^(e-1)`, `e>=2`,

with l odd prime. Fix an ordered previous factor residue pair `(p0,q0) mod n`, both units, and the exact target `N mod m`.

Write lifts

`p'=p0+i n`, `q'=q0+j n`, `i,j in F_l`.

The product condition modulo m is

`q0 i + p0 j = c (mod l)`

for a known c, so one digit determines the other. The ordered candidate set is an affine line with exactly l points.

Choose a primitive l-th root omega. Then

`i -> omega^i`

is already an injective one-dimensional complex encoding of the ordered local branch. If the previous factor residues are distinct, the two fibers label p versus q and this one scalar is enough information-theoretically. In a coincident/unordered fiber, a symmetric code or the previously proved weighted histogram supplies the corresponding unordered quotient with O(1) outputs.

Thus:

`CONDITIONAL NEW-DIGIT INFORMATION = O(log l) bits`

and the conditional candidate state is constant-dimensional for fixed l.

This explains why the explicit ternary decoder can use only 2--4 integer traces even though the global Galois orbit rank is exponential in e.

## 2. The local digit group

Let

`U_e=(Z/l^e Z)^*`

and

`K_e=ker(U_e -> U_(e-1))`.

For e>=2,

`K_e={1+t l^(e-1): t in F_l}`

and multiplication satisfies

`(1+t n)(1+s n) = 1+(t+s)n (mod l^e)`.

Hence

`K_e ~= (F_l,+)`.

A local digit character is just a nontrivial character of this order-l kernel. This is the natural constant-dimensional symmetry after conditioning on the previous residue fiber.

## 3. Global multiplicative extension obstruction

The full unit group is cyclic of order

`|U_e|=(l-1)l^(e-1)`.

Let `g` be a generator and let a Dirichlet character theta be determined by

`theta(g)=zeta_|U_e|^a`.

The last-layer kernel `K_e` is generated by

`g^(|U_e|/l)`.

Therefore

`theta|_(K_e)`

is nontrivial iff

`l does not divide a`.

If `l∤a`, then

`ord(theta)=|U_e|/gcd(|U_e|,a)`

has l-adic valuation exactly `e-1`. In particular

`l^(e-1) | ord(theta)`.

This yields:

**Theorem (extension-order obstruction).** Every multiplicative character modulo `l^e` that can distinguish the final lift digit has image order divisible by `l^(e-1)`.

Consequently no bounded-order family of global Dirichlet characters can see arbitrarily deep lift digits.

The field generated by the character values has degree at least

`phi(l^(e-1)) = (l-1)l^(e-2)`

(up to any additional prime-to-l part of the character order).

Thus the constant-dimensional local kernel character cannot be extended to a global multiplicative character without conductor-dependent cyclotomic growth.

## 4. Why the tempting fixed-order character idea fails

One might try to take a faithful character `chi_e` and raise it to a high l-power so that its global order becomes l or `(l-1)l` independent of e.

But every such exponent is divisible by l once e is sufficiently large. By the criterion above, the resulting character becomes trivial on `K_e` and therefore cannot see the new digit.

For l=3 this says, concretely:

- the order-6 character modulo 9 genuinely sees the first ternary lift;
- there is no order-6 character of conductor `3^e` that keeps seeing the newest digit for all e>2;
- a character primitive at conductor `3^e` must retain a 3-primary character order divisible by `3^(e-1)`.

This closes a natural but false compression route.

## 5. Local additive coordinate versus global multiplicative coordinate

For a known base unit b modulo n, any lift x in the fiber can be written uniquely as

`x=b(1+t n) (mod m)`

for `t in F_l` after fixing a lift of b. The coordinate t is additive on the kernel and is exactly the new precision digit.

The target-adaptive BRC trace is naturally localized in this additive coordinate.

By contrast, ordinary Dirichlet characters are global multiplicative coordinates on `U_e`. The theorem shows that using them to transport one local digit forces the full l-primary conductor history to remain present.

This is the precise local/global dichotomy:

`LOCAL KERNEL CHARACTER -> ORDER l / CONSTANT DIMENSION`

but

`GLOBAL MULTIPLICATIVE EXTENSION SEEING KERNEL -> ORDER divisible by l^(e-1)`.

## 6. Consequence for the remaining algorithmic route

Do not try to compress the current branch selector by replacing the faithful high-conductor character with a bounded-order global Dirichlet character. That route is impossible.

The only remaining escape from the global character explosion is to keep the previous residue fiber as explicit state and operate directly on its **additive lift coordinate**.

A successful N-only recursion would therefore have to look like

`previous residue fiber b`
` -> additive local BRC/Cartier operator on t in F_l`
` -> one branch digit`

without first extending the local digit character to all of `U_e`.

The next exact question is whether the BRC product admits such a base-conditioned additive section law. If every exact product-side implementation necessarily averages over all unit bases before reaching the target coefficient, then the global character lower bound re-enters and closes the route.
