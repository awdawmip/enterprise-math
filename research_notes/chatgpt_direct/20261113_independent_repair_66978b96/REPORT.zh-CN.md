# 一次补读在多份旧历史之间能恢复多少：独立改写、选择读取的时点与单消息容量

**研究对象。** 上一检查点的原程序把每份旧历史记成五环上的一个点。编码时根据真实守卫答复保存一条消息。编码后，各台允许执行恒等或倍增（模 5）；写者实际改写请求表，恢复方知道所用规则，写者的私有读数不传出。各台后来收到一条有向菜单边 (u,v)，执行首项业务并绑定完整键。首回执 11 表示历史在边上：当前为 u、v 时的正确后续分别是 11、u+1；边外首回执为菜单键，后续固定 12。通常可以合看各台首回执，再选某一台的原端点槽，取得一个布尔答复。一次这样的原读取花 8 条命令。每台真实准备 2346 条、改写 1222 条、原十五槽库存 1167 个成员和 16545 条候选关系。存储位数为向上取整的 log₂ 消息数；均匀合计和最坏预算分别计数。

## 1. 两台：只有最后一种动作组合会把三消息推到四消息

每台允许的变化为 0=恒等、1=倍增。对给定非空 S⊆{00,01,10,11}，编码发生在知道 S 之后、知道本次具体动作对之前。

|准许动作对集合|此型集合数|零补读最少消息|至多一读最少消息|至多两读最少消息|
|---|---:|---:|---:|---:|
|只一种|4|8|3|1|
|两种且一个坐标固定|4|15|3|1|
|两种且两个坐标都可能变化|2|25|3|1|
|任意三种|4|25|3|1|
|全部四种|1|25|4|1|

零读由每坐标可能混淆的旧点对决定。只有一个固定动作的坐标是五环；两种动作均可能的坐标是五点完全图。指定一个要区分的分量后，可用另一分量的边外回执让两条历史在其余分量的首次交付相同。单台固定码三色、两固定五环可盖全部历史需八种联合消息（原构造）；一台全需区分一台三色给出15，两台全需区分给出25。一读则还看两个动作能否同时出现，两个变换坐标各自的可能值已不足以决定最少消息数。表中15种许可集合均逐项检查。见 independent/proof.md。

上轮三桶 (x+2y) mod 5 遇到的反例：第一台恒等、第二台倍增，两份菜单都是 (0,1)。旧历史 (0,0)、(0,3)、(1,0) 在同一旧桶，首次全得 (11,11)，次项却为 (11,11)、(11,1)、(1,11)。一个布尔读数不能分三种。在所有四种动作对都可能时，任何两行两列都可同时成为端点，一消息若占某个矩形三个角，就会有同一现象。因此颜色类在行列二部图上的每个连通分量必为星，且这一条件也是充分的。同色至多 8 格，三色至多24，小于25。足够的四消息表（行 x，列 y，顺序 0…4）为 00112 / 12023 / 13032 / 21203 / 31302。只要预先排除一个动作对，把另一张三消息表的行列重新标号即够。单个固定动作同样要三种的下界来自25个方块按两色均分将出现50个同色角，而每个顶点属四个方块。

这个二部图结论已有独立文献：DeBiasio、Gyárfás、Krueger、Ruszinkó 与 Sárközy，*Monochromatic balanced components, matchings, and paths in multicolored complete bipartite graphs*，Journal of Combinatorics 11 (2020), Proposition 3.1，arXiv:1804.04195。文献给出了 st(K5,5)=4。这里给出在真实回执与原槽接口下何以恰等价、全部动作子族、费用与时序的结论。核阅公开发表全文：https://intlpress.com/site/pub/files/_fulltext/journals/joc/2020/0011/0001/JOC-2020-0011-0001-a002.pdf 。专业精确编号查询 #6901 实际发生1次供应商调用，返回 PROVIDER_ERROR，未提供题录；其原始回执与公开全文分别记录。

## 2. 同是四种消息，时点和累计费用还能精确区分

**读哪台的预约时点。** 两台独立变换。若在零份、一份、两份真实首回执到达后分别预约，最少消息数依次为 5、4、4（3、2、2 位）。预约只固定台别，留到两份回执抵达后才决定是否实际读取。若一条消息类既有以行为中心的非平凡星，又有以列为中心的非平凡星，同一组公开菜单下前者会只许读第二台，后者会只许读第一台。提前预约未看到能分辨它们的回执，只能限制每一类至多5点，宜直接记一台旧值。看见第一台的回执后，给定四色表每行每色至多出现两次，已足以确定需要读哪台。具体同消息、同菜单而必须选不同台的四条物理路径见 native/probe_site.md。

每项时序在2500个输入上分别直接执行完全两台的业务后缀；每项有50份物理准备、200次写者、5000次实际首次及5000次实际后续交付。三个程序分别为 1500/1000、1550/950、1550/950 条免读/一读；每项逐路径原命令范围 7676…7714。没有把时间较早方案的1000次概括为所有五消息方案的最小合计。

**颜色选择无法改变四消息总价中的读取项。** 在全部2500个等权输入上，任何保证至多一读的四消息表，都有且仅有950个输入必须读，1550个可免。950中，734个恰一台报边内，216个两台都报边内；总计7600条额外的原读取命令。先按首行的颜色重数规范成六种，再枚举其余四行的所有兼容集合，共64个代表；两套程序独立得到相同结果。保持的是对全体等权输入的补读数，不一定保持某个具名菜单的局部频率或命令价格。详见 opt/counting_proof.md。

## 3. 三台：压缩旧消息、节约总补读是两种目标

三台共同选或各选变换时，合计最多补读0、1、2、3次的精确定长位数在两种模型中都是 **7、4、2、0**。但台别可自由独立选择动作时，旧消息要容许的历史形状更受限。

|变换 / 补读预算|最少消息数或已证区间|复验证据|
|---|---:|---|
|共同或独立 / 0|125|任取两段不同历史，总有一个共同动作和菜单区分它们|
|共同 / 1|11至12|全 47,000 个禁止同色三元组、单类最多13点、覆盖枚举及显式编码|
|独立 / 1|**13**|单类最多10点；125点的显式13消息表|
|共同 / 2|3|三桶处理前两台，其余一台按需读；奇数点的方块计数排除两色|
|独立 / 2|3至4|方块计数下界；前两台四消息加第三台按需读；定长正好2位|
|共同或独立 / 3|1|不用旧消息，每台按需读一次|

共同变换的一读档有一个额外的整体限制：若十种消息能覆盖125点，则需至少五个互不相交的满13点类。列全250个13点类及8875个12点类并枚举其可相容的组合，发现任何这样的十类分配都不能完成覆盖，故至少十一种；显式十二消息表在31250个场景全数成功。它与独立变换必须十三种的差别已经确定。详情及枚举证明见 triple/packing.py 和 triple/triple_proof.md。

三份独立、一读的下界有两条可独立复核的路线：直接枚举110000个禁止同色三元组，并对最大单类做精确分支搜索，得到10；或用下一节的层状分组递推，得到同一个10。最多12个类只能覆盖120点。13类可达由列出的125格实表证明；表的寻找不承担下界证明。

对同一批125000个独立变换输入，13消息最优表使66660条免读、58340条各读一次；另一张16消息表使79216条免读、45784条各读一次。两者都是4位、最坏最多一读，16消息表在这批中少读12556次（100448条原命令的读取费用）。两张表的逐路径总价均为11514…11567。13这个数字最小；两张表的累计读数是其各自实付，未据此判定所有13消息表的累计最优值。

共同变换按上轮两台三桶码外加第三台时，31250条两读场景的零/一/二读数为10350/15300/5600；独立时按四消息码外加一台，125000条对应为46500/59500/19000。三台结果均注明层次：全参数空间逐个由该分量上真正执行所得的回执和费用组合，另选有代表性的台别、首回执、动作，从准备开始完整逐命令执行三机进行比对。两张独立一读表各覆盖160条从头三机路径；共同两读30条、独立两读128条、共同13消息一读40条。native/各结果中保留完整扫描的有序摘要、费用分布、每层代表，及可逐项再生程序。

三台独立两读还有精确局部判据：当三台均报在边上，同一旧消息在任意2×2×2方块中要么至多占三个角，要么恰占四个且能被某个坐标按2:2分开；其他首回执模式至多两台尚有二选一的后续，两次本地原读总足够。一条消息能安全容纳49点的公式见 triple/two_probe_criterion.md，256种局部角集及1000个可达方块均核过。这解释了为何仅凭“每类最多多少点”难以判断三种消息能否覆盖全部125点。

## 4. 任意多台：一份旧消息的精确容量及其上限

关键不是每个坐标孤立地有几种取值，而是同一旧消息里各坐标按值分成的历史集合能否互相兼容。独立晚选、至多一次补读时，相交的两个坐标值块必须有一个包含另一个。否则，选出“同时在两个块、只在第一个块、只在第二个块”的三段历史，就有一个菜单能让三个首次回执组完全相同而后续三分。反向，若禁止这样的交叉，给定全部首回执后，可达的后续输出向量至多为两种；挑一个后续不同的台读端点即可。于是所有坐标值块恰组成一个可以逐层嵌套的集合族。

由这个描述可以把每个坐标的剩余字母预算分到两支，得到最大单类容量的精确递推，不必穷举整个5ⁿ格子。对五种旧值、1至8份服务，容量依次为 **5、8、10、12、13、14、15、16**，再多份也恰为16。同一消息里的两批历史一旦被分到不同子树，每个仍能区分同支两点的坐标至少消耗一个符号给另一支；五种符号最多支持四层二叉分叉。反向，深度四二叉树有16个叶，给八对最深兄弟叶各配一个五值坐标，确能区分全部16个叶且所有值块保持嵌套。任意 q≥2 的均匀字母表，对这种层状集合的通用容量上限是2^(q−1)，达到它的最少坐标数为2^(q−2)。一般 q 的组合命题和这里五符号的真实服务对应分别记录。完整上下界与递推在 laminar/proof.md。

因此，对 n 份能独立改写的五环服务，若无论多少台都合计只给一次补读，相比保留全部旧历史，**至多省四个定长位**。这说的是单次实际读在既有强制首业务之外带来的最大额外压缩；尚未声称任意台数总能省满四位。作为对照，共同变换且总许 n−1 次补读，n≥2 时只需恰好三种消息：前两台用上一轮的三组码，其余逐台按需读；反向，若两色，则每个恒等全边内 n 维方块必须均分，因为每色至多容纳 2^(n−1) 种后续。5ⁿ 个方块每点被重复计 2ⁿ 次，强迫一个颜色类大小等于奇数 5ⁿ 的一半，矛盾。
