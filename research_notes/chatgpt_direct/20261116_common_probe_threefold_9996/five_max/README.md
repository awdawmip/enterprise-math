# 十一标签的五个最大类分层

既有五满类分类给出 14 种位置，只有一种能补成十一标签表。该位置有 200 个不同的仿射像，固定位置时有 40 种补全。不可变证据见项目 20261116_common_eleven_exact/common/five13_stratum.json（提交 d27c1a9bc08753514a9c1f60d411ad7410a3a10c）。本节从已知十一标签表取出五个十三点类作为代表，枚举其余 60 段历史的全部六类划分。按类大小递减、同大小按掩码递增，逐个检查原菜单成本。

全部 40 种补全的成本都是 11,292。在保持五个母类整体的 60 元群下，它们分成大小 10、10、20 的三个轨道。用 200 个位置提升到完整仿射群，三轨道分别有 2,000、2,000、4,000 张表，稳定子阶分别为 6、6、3。总共 8,000 张。前两个六阶轨道在上版证书中都有明确代表；eleven_equal/groups.json 给出稳定子为三阶的另一种取等表示。

predecessor/ 内五个文件逐一核对过该不可变提交的 Git blob；可用 python3 -B replay.py --only five_base 从本轮包根重算上段所用的全部 14 种位置和实际位置数。
