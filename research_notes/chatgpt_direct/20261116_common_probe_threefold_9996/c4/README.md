# 十二标签有四阶仿射对称时，最少补读 10,148 次

这里的对称是指它可以置换标签并保持整个非空消息类分区。在模五历史坐标上，对某点的四个像取平均即可找到不动点，把它平移到原点，只需处理 96 元线性群的四阶子群。按共轭归并共有六型。原菜单穷举首先生成一个类及其四阶像都不交的类轨道。若此轨道有四个标签，其代表大小 s 和单类补读成本 c 必须满足 4c+L(125−4s,8)≤10,148，其中 L 是由已证单类最小费用计算出的整数分配下界。只可能有 8 至 13 点，成本上限依次为 465、645、829、1,012、1,192、1,376。本轮重建了全部 56,152 个符合这些切割的平移代表，并扩展到所有平移。固定标签、成对标签则直接枚举点轨道上的同余类，并核对原菜单的禁止三元组。对于相同的占用历史支持和标签个数，仅保留最低成本即可准确计算最优值。

最先四型使用逐个历史轨道选支的覆盖搜索，预算 10,148 以内均无解。最后两型有一固定点和 31 个四点轨道。原点所在标签固定，余下有零、一或两个四元标签轨道。先选定原点类和全部长度 1 或 2 的标签轨道，将其余自由支持和最低已付成本登记。按标签数、历史点数及还需使用的四元组数作整数下界剪枝，四元组在各支持上要求不相交。只剩一组时直接查表，两组时枚举其中一组并查询唯一互补支持。六型只有最后一型在 10,148 可以取等。

取等表有两个固定类，大小 9 和 12、成本 632 和 1,104，一对大小 10、成本 814 的类，余下是两个四元标签轨道，分别由大小 10、成本 752 和大小 11、成本 944 的类构成，故总计 632+1,104+2×814+4×752+4×944=10,148。groups.json 的原程序回执对齐全部 31,250 个等权场景，并从准备起运行 40 条原路径。

固定取等类型的一个四阶子群，只有四种商支持组合。逐一重建同支持的全部最低成本短类与四元组相位，每种恰能提升为两张表。原始 12,000 元仿射群的正规化子对这八张表有两个轨道，每轨道四张。两个代表见 representatives.json。它们的完整稳定子均恰为所固定的四阶子群。若二者被仿射变换送到彼此，该变换必须正规化这个共同子群，故二者也处于不同的全仿射轨道。两个全轨道各有 3,000 张，全体取等表恰为 6,000 张。

使用 python3 -B replay.py --previous /path/to/the/preceding/round4/bundle 复核六种子群的完备枚举、原菜单类库和全部极小分区。使用 python3 -B native.py --round3 /path/to/the/preceding/round4/bundle/previous 核验原程序场景回执。
