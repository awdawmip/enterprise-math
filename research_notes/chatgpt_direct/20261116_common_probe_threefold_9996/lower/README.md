# 十一和十二标签的一般读数下界

复用上一版同一模型的原菜单枚举、核心类放置和按类型精确覆盖代码。对一张十二标签表，固定五个彼此不交、由十三点母类删去中心的十二点集。它们在保成本群中分十九种位置。逐一把其中任意可放回的中心填回，得到 458 个分支。将各分支余下的七个标签按大小非增排列，对余集重建全部可能合法类，按真实费用作整数精确覆盖。在总预算 9,860 下，3,074,529 个搜索结点均未能补全。于是这一预算内最多使用四个核心类（把中心原样放回所得完整母类也算核心类）。

十一标签沿用先前四核心分层；不加对称限制，对两种标签数分别列举低于目标且尚未被既有分类排除的整表大小和价格谱。对每谱固定核心类、必要时固定外围删点类，再分配余集。每个测试必须同时满足精确类大小、价格、个数和原端点一读谓词。结论和新增完整谱数见 result.json。

运行 python3 -B replay.py --previous /path/to/round4/delivery --last /path/to/round3/delivery --native /path/to/round2/delivery --jobs 6。前三个参数依次是上轮、本轮起点之前第二轮和第三轮之前的证明目录，分别需要 lower/、low/、bounds/。
