# 改进新十二标签表需要的两种改动

从三阶对称、总读数为 9,996 次的十二标签表出发，每个标签同时容许最多删除两个旧历史点，且最多增加两个新点。在旧类中枚举删点集合，在余下点上按递增次序枚举添点，并用原菜单的禁止三元组核验。把每个标签的所有可能新类列出，以历史点和标签为两类精确覆盖约束，在剩余类的最低成本及全域标签数/剩余点数最低成本下界上剪枝，检查预算 9,995。整套重分搜索共访问 426,745 个节点，未找到任何可严格改善的表。匹配标签编号后，任何严格改善有至少一个标签需删除三个点或增加三个点。

另一方面，枚举任意保留六个旧类，把余集任意重分为六个非空类。三阶稳定子将 924 种六类选择归并为 312 个代表。每个代表按各大小的实际最低成本界，从原菜单生成所需的合法类并穷尽剩余分区。全部代表均无解。因此任何严格改进都至少要替换七个旧类。运行 replay.py --previous /path/to/preceding/round4/bundle --groups /path/to/c3/groups.json 可复算两个结果。
