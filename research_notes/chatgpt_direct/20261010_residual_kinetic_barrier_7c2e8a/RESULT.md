## 2. 六空位双分组单元与 n 个不交副本

一个单元的合法事件恰为 A1=123、A2=456、B1=124、B2=356。饱和分组只有 L={A1,A2} 与 R={B1,B2}，两者全部占用及事件数相同。

从 L 到 R 的实际命令是 release(1), release(4), reserve(124), reserve(356)。反向从 R 释放1、3所属事件，再加入123、456。每条路线的空位记录都是 0,3,6,3,0，四条命令均成功。两侧任一新事件跨越两条旧事件，所以任意原命令路径的第一个异侧事件成功前至少释放两条旧事件；最小峰值恰为6。

## 4. 低门槛与指数首次到达：一般证明

令 tau 为首次达到全R的完整轮次数。令F_d为从距离d第一次到达d-1的路径族，e_d为其期望轮数。p_d=d/n，q_d=(n-d)/n。顶层F_n是一条必然向下的步骤。

在距离压缩的有效观察范围内，每条F_d路径唯一分解为零个或多个“向上一步，再首次回到d”的游程，接上一个向下步骤：

    F_d = (U_d F_(d+1))* D_d。

即计长度的正系数生成函数满足

    f_n(z)=z； f_d(z)=p_d z / (1-q_d z f_(d+1)(z))。

在z=1，递归的每一游程总量q_d<1，原one_state_recurrent_cwm给出收敛TOTAL闭包，归纳f_d(1)=1。长度一阶矩满足

    e_n=1； p_d e_d=1+q_d e_(d+1)。

这证明每层首次下行几乎必然且均值有限；依次跨越n层，E[tau]=sum_(d=1)^n e_d。它不是从有限轨迹推断无限结果。

用正的二项计数尾和检验递推，可得

    e_d = [sum_(j=d)^n binom(n,j)] / binom(n-1,d-1)。

把d与n-d+1配对，两尾和相加为2^n，分母相同。因此

    H_n := E[tau] = 2^(n-1) sum_(k=0)^(n-1) 1/binom(n-1,k)。

对n>=2，H_n>=2^n。对n>=4，中间二项系数至少binom(n-1,2)，故

    1+1/(n-1) <= H_n/2^n
      <= 1+1/(n-1)+(n-4)/[(n-1)(n-2)]。

于是 H_n/2^n -> 1。原命令首次到达数恰为4tau。

可检验比较：n5最短20命令、均值512/3；n10最短40、均值299008/63；n20最短80、均值12936558936064/2909907；n40最短160、均值150847528379754337563312128/33393321606645。四例的最小空位峰值全部为6。

在恰好n轮内成功要求每个单元恰好被选一次，最短成功前缀有n!条，每条权重n^(-n)，故Pr(tau=n)=n!/n^n。预先指定每个单元只转换一次则在n轮完成，但那是另一控制律，不是改变同一随机过程的分析结果。无自环边界链有周期2；本轮不声称定时分布收敛到均匀。均匀分布是它的平稳分布。

该指数等待是到达一个指定关系构型的稀少性，不是证明物理能垒、玻璃态或一般混合时间指数大；更不意味着其他允许控制器也必须慢。

## 5. BRC首次到达观察与长度矩扩展

有限词使用原CWM串联、重合，已命中路径按其首次命中长度停住；未命中路径继续推进。总权重满足

    sum_(k<=t) W(first_hit_at_k) + sum_d W(alive_at_t,d) = 1。

命中前缀不再延长，故其C是变长停止词的计数，不冒称全部固定长度n^t词。所需“到过目标”记录不能用末态代替：n=1时第一轮已到目标，第二轮又回原态，第二轮的末态目标概率为0而此前曾命中的概率为1。

为闭合有任意长游程的均值，本轮扩展原TOTAL观察为(W,M)，其中M=sum路径权重×路径长度。备选逐项相加，串联为

    (W,M) tensor (V,N) = (WV, MV+WN)。

总量l<1、长度矩m的游程星闭包为

    (S, m S^2)， S=1/(1-l)。

S由原one_state_recurrent_cwm实际求得；其他非负系数计算使用原CWM的TOTAL读出。计数C和最大支路M不被错误赋给无限路径族；此处一阶长度矩使用独立类型Jet.L以区别CWM.dominant。无限闭包上的人工一条汇总环只是TOTAL入口，不是原微观游程只有一条。

对每个有限截点t还核对精确余额公式

    E[tau] = sum_(k<=t) k W(first_hit_at_k)
           + t W(alive_at_t)
           + sum_d W(alive_at_t,d) h_d，

其中h_d为从距离d到目标的剩余均值。它保留了尚未完成的重量，而不是靠截断后归一化伪报恢复。
