Read [NOTE.md](NOTE.md) for all hypotheses, proofs and limits. Run `python check_u6.py` in this directory to regenerate the finite BRC evidence. Main result: under the unchanged U5 response circuit, local reactivation changes waiting but does not confine response near fixed finite material sets; a uniform extension covers material schedules in any fixed finite region. This is not a native force law, a statement about unbounded co-moving localization, or a prime criterion.
