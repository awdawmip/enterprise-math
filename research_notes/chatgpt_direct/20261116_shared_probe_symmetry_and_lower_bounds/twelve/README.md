# 十二标签补读 10,131 次

125 个历史按 groups.json 所列分成十二个非空类，labels.txt 给出同一分区的逐历史标签。在 31,250 个等权输入上，21,119 个免读，10,131 个各读一个原端点。恒等和倍增两种共同动作分别读 5,039、5,092 次。replay.py 核验每个类的禁三元组，按所有公开菜单枚举原端点，再用原程序回执复核全域，并从准备开始运行 40 个分层选出的完整原程序样本。

以原版 10,147 点表中的零起始标签编号计，释放第 2、4、7、8、9 五个旧类的 60 个历史并重新分成五类，其他七类逐点保留。释放的旧类成本为 1,296、944、1,296、944、1,116，合计 5,596。新五类的成本为 1,296、1,116、1,116、1,116、936，合计 5,580。其余七类共需补读 4,551 次。两张表替换五类后节省 16 次。

neighborhood.py 穷举从原点表中任选四类的全部 495 个选择。每次先枚举余集内所有合法的较大候选类，再按大小递减、不相交精确覆盖；类数与余点数的动态规划采用当前余集的各大小最低成本。较小候选集在有可能入解时直接枚举。按 10,146 的全表预算逐一检查，所得余集皆不能补全。因释放任意四类后也允许保留其中某些原类，任意严格改善该点表的十二标签表至多原样保留七个旧类。

从本目录运行 python3 -B replay.py --older ../previous --original ../original 和 python3 -B neighborhood.py --older ../previous。

将替换规模放宽到五类，对两张点表还可得到局部最优值。旧表的 792 个五类选择中，只有前述五个标签允许严格改善，其他选择无解，该选择的最优读数恰为 10,131。新表的 792 个五类选择均不能再严格改善。因此任何更优表至多原样保留新表的六个消息类。两次完整精确覆盖各访问 21,488,803 和 17,477,409 个搜索结点。运行 python3 -B five.py --older ../previous 复验。
