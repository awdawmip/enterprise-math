# 十三标签中 747 成本的十点类

在单类成本总和为 8,712 时，组合唯一。九个九点类成本均为 557，两个十点类分别耗费 744、747，两个十二点类各耗费 1,104。8,715 也只有一种组合，两个十点类都耗费 747，其余相同。最省十二点类有 250 个。固定第一个，用保持它的群和交换两个类的操作枚举第二个，所有不交对恰有六种类型。对每一对进行第二次归并，固定一个与之不交的 747 十点类，再对剩下的 91 点作完整精确覆盖。可改进的自由选择仅剩九个九点类及一个十点类。

成本 557 的类在每一坐标方向上，五个平行截面恰好有一个少于基数 2，其余均为 2。成本 744 的类在全部截面上等于 2。成本 747 的类在某一方向的两个截面上分别为 1 和 3，此外全部为 2。对某一截面，记当前未覆盖点数为 u，尚需 l 个类，其中九点类 a 个，747 十点类 b 个。于是 d = 2 l − u 必须满足 −b ≤ d ≤ a+b。每次选择候选类后都要满足同一不等式。若 b=0，d=1 的截面恰好需要一个九点类在其中留下单点，可在这个约束上分支。程序也可以在一个未覆盖点或只需一份的消息类型上分支。所有操作使用整数；任何一种合法区分都逐一进入分支。

`python3 -B replay.py --older /path/to/previous --group /path/to/group --costs 8712 --jobs 4` 可从原观察菜单重新检验此档。六种锚对应的第二次归并代表数为 787、424、416、1,735、516、19。每种锚的可用 747 类数均由穷举生成；归并仅使用同时保持两个核心所成无序对的群。

以上两档的全部余集均无可行分区。8,712 和 8,715 两档各访问 78,957,896 和 226,775,022 个精确覆盖结点。第二档可令参数 `--costs 8715` 单独复验，省略该参数将复验两档。
