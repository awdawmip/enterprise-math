# 成本 8,721 的两个十三标签配置

完整单类成本在 8,721 恰给出四个整表配置。本目录检查其中两个。第一个固定成本为 936、1,104、1,104 的三类，第二个固定成本为 744、1,104、1,296 的三类。固定后，余下十类都是九点类，恰有一类成本为 564，另九类各为 557。

程序从原模型重建候选类，并在 12,000 阶仿射群下先枚举两个大类的位置，再在保持这两个类的子群下枚举第三类。两组分别得到 926 和 3,234 个不等价三元组。对所有三元组作精确覆盖均无解。每个可选九点类在每个坐标方向各有一层恰占一点，其他四层各占两点。除每个历史恰覆盖一次外，可以按切片缺口和剩余成本为 564 的类数分支。typed_nines.cpp 同时核查所用类的切片形状。

将本目录放在证书的 anchors 和 group 同级，运行 python3 -B replay.py 即可核对。结果为各配置的三元组数和是否存在覆盖。
