# 十二标签的三个与五个核心分层

一个核心指出现在表中的中心删点十二类（成本 1,104）或其完整十三点母类（成本 1,296）。固定五个两两不交的中心删点集合，再枚举放回哪些中心。对规范化后 458 个余集与成本分支，按各大小的整表费用上限，从原菜单禁三元组及二点歧义重新枚举所有合法的剩余候选。每一分支的整数点权和标签权由 weights.json 给出。核对全部候选非负约化成本，再按 9,995 的费用上限做精确覆盖。共 228,753,799 个分支内合法候选、204,253 个通过权重筛选的候选和 178 个覆盖搜索节点，所有分支无解。任意严格改进 9,996 次表的方案至多含四个核心。运行 python3 -B replay.py --previous ROUND6 --jobs 3。复验会重新生成候选，临时目录需要足够空间。

同一证明另核对恰含三个核心的低预算情形。固定三个核心，在其余九类中排除额外的核心，134 个余集与成本分支共含 10,293,314 个合法候选，497,451 个通过整数权重筛，11,290,261 个精确覆盖节点。9,860 次以内全部无解。因此，任何恰含三个核心的十二标签表至少读 9,861 次。在这一分层中，程序从原菜单重新生成各大小与费用内的全部候选，展开全部仿射像，选取余集内候选时排除额外核心。可加 --scope 3/9860 或 --scope 5/9995 分别执行。
