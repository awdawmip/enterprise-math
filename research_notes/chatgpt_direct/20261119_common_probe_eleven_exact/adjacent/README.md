# 十四至二十一标签之间的逐步改派界

若旧类大小为 a、新类大小为 b，把两类配成同一标签所能保留的历史数，至多等于两种最低费用类之间的最大交集。由原菜单生成最低费用类的归一化种子，把一侧在全仿射群下展开，即可求得这些交集的确切上限。每个相关预算的取等类大小及个数由 125 除以标签数的商和余数决定。按大小给两边的类作最佳匹配，忽略不同配对的几何相容性，可以得到全域改派数的下界。

witness.json 另给出每步一对全域取等的完整分区。文件已按取得所列上界的匹配重编号，保留历史数就是对应类的交集大小之和。各预算可选不同的表。result.json 第一列是通用下界，第二列是实际达到的上界。特别地，最低费用的八点类与九点类都不包含最低费用的七点类。十六升十七时，类大小所给的单纯计数下界因此还需加强。

从包根运行 python3 -B replay.py --only adjacent。
