# 共同晚选变换的概率偏置

三台共享恒等或倍增变换。设恒等变换概率为 p，给定任一变换，125 段历史与 125 组公开菜单组成的 15,625 个二元组等权。设某张十一标签表在两种变换下分别须补读 I、D 次。它的补读概率是 [pI+(1−p)D]/15625。

均匀最优表的两变换补读数为 (5592,5700) 或其反序，分别有 4000 张。任何其余整表的费用 C=I+D 至少 11301。把 r=|2p−1| 和 A=|I−D| 代入，任一表的补读概率至少 (C−rA)/31250。两种方向的均匀最优表可达到 (11292−108r)/31250。

对于 r≤1/61，每一张其他合法表均满足 C−11292≥r(A−108)。所以在 30/61≤p≤31/61 上，十一标签最低补读概率恰为 (5646−54|2p−1|)/15625。区间内部，当 p 偏离 1/2 时恰有偏向对应变换的 4000 张取等表；p=1/2 时全部 8000 张均取等。端点也达到同一公式。本组单独的整数松弛在端点允许其他表取等，几何排除见 bias_geometry。

脚本以原菜单的 47000 个禁三元组和 250 个条件掩码枚举单类。以平移固定一个点为原点，再用全体有序点差中仿射作用下编号最小的差向量作第二点；所有其他点编号均可取大于该差。坐标置换、符号和共同缩放保持总费用与两变换差的绝对值。对每个大小、能否嵌入十三点母类、确切总费用三元组，记录最大的单类绝对差。十一类的绝对差之和给出 A 的上界。仅要求十一类大小合计 125，已经得到 A≤1611。

在 11301≤C≤11350，把各单类的绝对差在金额严格相等的条件下做最大和动态规划。沿用前轮无条件几何界：至少四个例外类，恰有四个时合计至少 42 点；各个母类之并有相应容量上界；删中心或完整母类至多五个，含删其他点的宽口径大类至多六个。恰有四个完整母类时须 C≥11365，五个完整母类已全部取等，六个以上不可行。共筛得 774 个大小与嵌入分型。松弛问题的最小正比值 (C−11292)/(A上界−108) 是 9/(657−108)=1/61，出现在 C=11301。C≥11351 时，前述全域绝对差上界给出的比值至少 59/(1611−108)，严格大于 1/61。所有判定使用整数或精确有理数。

运行 `python3 -B replay.py --previous /path/to/extracted-sixth-release`。result.json 记录各总价的差值上界及松弛分型。

十二标签的已知 9,996 次表在两种变换上的费用是 4,915 与 5,081。把三个坐标共同乘二，费用即对调。因而在十一标签公式适用的区间，采用这两个十二标签表中较好的一张，至少把每个输入的补读概率降低 (648+29|2p−1|)/15625。原菜单复验见 upgrade.py。

bias_geometry 在更大的闭区间内排除了额外等号，故本组两个端点的取等数量各为 4,000。
