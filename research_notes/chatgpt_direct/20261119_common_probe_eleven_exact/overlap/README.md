# 十三升十四时的历史改派数与完整旧类

## 保留历史的整数证书

十三标签旧表可固定为唯一仿射轨道的代表。为它补一个空标签，将十四标签新表与它的标签作一一配对。保留的历史总数是各配对交集大小之和。完全相同的配对只能来自九个旧九点类；上版已证明最多有三个。按这些配对的精确集合 F 分为 1+9+36+84=130 支。扣除已取的类后，还须选新标签覆盖剩余点，每个剩余旧标签恰配一行。另加一个虚拟点，它只属于新八点类。

在每一支，给剩余点包括虚拟点配整数权 w(x)。对每个剩余旧类 A，枚举所有容许的新候选行 C，取 b(A)=max[1000|A∩C|−Σ w(x)]，和式遍历带虚拟点的新行。移去与 F 冲突的候选，并规定剩余配对不能再有 A=C。选定配对的非负差额是 b(A)+Σ w(x)−1000|A∩C|。设 T 为固定类已保留的历史数乘 1000，加全部剩余的点权及 b(A) 之和。一张全域表若保留至少 h 段历史，它的配对差额总和必须不超过 T−1000h。dual.cpp 用这个整数预算穷举。每次选择容许配对最少的一个空点或旧标签，要求每个空点和旧标签最终恰好使用一次。该穷举直接使用发行包内的整数权，复验无需线性规划器。

history_result.json 给出阈值 h、所有 130 支的累计搜索节点数及结论。达到 85 段留存的分区在这些分支全部排空，因此任意十三、十四标签最优表之间至少要改派 41 段。另用先前包中的整数指派算法检查已知十四标签见证的全部 12,000 个仿射位置，同时检验每次匹配的原、对偶目标相等。最有利的位置保留 51 段历史，给出改派 74 段即可完成的一张表。在这个十四标签轨道中，要求完整保留一个或两个旧类时，最高留存均变为 49 段，需要改派 76 段。

单独复验本节可运行 `python3 -B replay.py --previous /path/to/previous --history-only`。

## 完整保留三个旧类的补全搜索

十三标签全域取等表构成一个仿射轨道，十四标签取等须恰有一个最低价八点类、十三个最低价九点类。固定十三标签代表，其中九个九点类可能完整保留。下述编号按旧表原有次序，仅在九个九点类中从零开始计数。原菜单重新生成 28,000 个八点候选与 24,000 个九点候选。上轮已排空保留任何四个旧类。

## 与已知十四标签轨道的距离

上轮 overlap/witness14.json 给出与十三标签表共享两个类的十四标签最优表。完整列举这张十四标签表的 12,000 个仿射像，它们每张至多保留两个十三标签原类。对 84 种任选三个十三标签旧类的方式，再从任一仿射像中选三个不与这些原类相碰的十四标签类，把其余历史任意补成十四标签最优表。每个原三元组内按新要求占用的点集及剩余八点类配额去重，共 467,671 个待补区域，全部搜索无解。若真的能完整保留三个十三标签旧类，那么与该已知轨道中每张十四标签表最多只共用两个额外类，在这三个原类中又最多能共用两个，故至少须换十个完整类。

## 不附加十四标签比较对象的搜索

对 cases.json 给出的每个编号独立穷举。编号是所选三个位下标的二进制掩码。八点候选补一个所有八点候选共用的虚拟点，于是在 126 个点上必须精确覆盖十四个九点行。每个真实坐标层有 25 个点，每行在该层恰放一个或两个真实点；全域十四行在每层恰有三行只放一个点。程序逐候选核对这个事实并跟踪十五个坐标层的剩余配额。任何层的配额耗尽后，后续行必须在该层放两个点；其配额等于余下全部行数时，每行都须放一个点。搜索选取剩下最少选择的真实点、虚拟点或恰有一个缺额的坐标层。完整整数回执保存于 result.json，未列入的三元组保留开放。十四标签全文库与上述三元组之间的距离下界使用全部 84 种选择。

## 特殊八点类的补全

能最优拆成两个四点类的八点类有 4,000 个，属于同一个仿射轨道，各自的稳定子为三阶。固定一个代表，不交的最低价九点行有 13,926 个。能在该三阶群下构成三个互不交九点行的轨道有 2,818 个。任选两个不交的完整轨道后，350,949 种余集均不能再用七行补全。因此含指定八点类的全域十四标签最优表，至多含该子群的一个完整三元九点轨道。另遍历所有 31 个非零平移子群，在能取用的 2,346 个互不交五元九点轨道上逐项精确覆盖，全部无解，故这样的表不能含任何完整平移轨道。这两条只排除具有所述局部规则的候选。

在新包附有上版完整解包 previous 的情况下运行本分组的 replay.py --previous /path/to/previous --jobs 2。复验从前版菜单资料重建候选，需要 Python 3.10+ 和支持 C++20、128 位无符号整数的编译器。此分组的若干穷举较耗时。
