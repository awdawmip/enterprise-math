# 偏置区间上的取等表

原菜单几何排除给出 39/80≤p≤41/80，即 0.4875≤p≤0.5125。47 个危险分型都不能产生另一张取等表。

三台共享晚选变换，恒等变换以概率 p 出现，倍增变换以概率 1−p 出现。固定任一变换后，125 段历史与 125 组公开菜单等权。本证书在 result.json 的闭区间上同时确认最低补读概率及取等表数量。最低补读概率为

$$\frac{5646-54|2p-1|}{15625}.$$

p 小于 1/2 时恰有 4000 张取等表，p 大于 1/2 时恰有另外 4000 张，两个端点都包含在内。p=1/2 时共 8000 张。

设一张其他合法表在两种变换下的读数为 I、D，总数 C=I+D，差额绝对值 A=|I−D|。令半径为 1/q。一张表想在任一端点达到或优于所示价格，必须有 A≥108+q(C−11292)。在 11301 到 11350 的各个总价上，以全菜单穷举得到的大小、嵌入性和单类价格逐项最大绝对差做整数最大和分配，留下可能满足这个非严格不等式的全部分型。更高总价已由全域差额上界 1611 排除。

每个留下的分型指定所有例外类和可嵌入母类的类的大小，并记录其最后一个危险总价。求出对应母类数下可达所需总容量的全部规范位置。每个分型的最小两项嵌入大小之和超过 13，故这些类所在的母类必然不同。即使取最大可能母类并，剩余例外类中也仍有必须覆盖的并外历史。按上一分组的原生搜索，先从完整原菜单大类清单选择十一或十二点例外，再以禁三元组和原观察掩码直接生成覆盖给定点的小类，检查不交、价格和嵌入容量。每个分型均按自己的最后危险总价检查一切更低费用。没有一个分支能覆盖所有母类并外历史，因此闭区间上的其他表全部严格较差。

在第七轮证书目录中运行 `python3 -B bias_geometry/replay.py --previous /path/to/extracted-sixth-release --jobs 3`。复验重新生成全部单类价格与绝对差、危险分型、仿射族代表和每个分支的原端点费用。result.json 的每个 cases 值依次为整表预算、嵌入类费用下界、母类族次数、搜索节点、候选扩展、尝试最后分配次数和整表解数。
