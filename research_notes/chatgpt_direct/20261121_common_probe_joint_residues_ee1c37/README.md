## 一、平行纤维并集确实带来新条件，但补齐整族后仍有五个精确分数点

取自由域子集H和类型系数\(a\in\{0,1\}^4\)。定义

\[
b_C=(|C\cap H|+a_{t(C)})\bmod2,
\qquad r=(|H|+a\cdot n)\bmod2.
\]

任何整数分区满足\(\sum_Cb_Cx_C\equiv r\pmod2\)，因此r=1时必有\(\sum_Cb_Cx_C\ge1\)。这同时保留历史覆盖和类数量的联合信息。

旧第4分数点被一个63点集合切掉：该集合是三个平行模五纤维与自由域的交，左端为

\[
\frac{24224479417132626104621409029}{27961409112557999812771344058}
\approx0.866354<1.
\]

在完整8,476列候选库上重新优化并恢复有理权重后，第4点得到668个正权自由类。其余四个旧精确点已通过新条件，无须替换。五点的正权自由类数依次为558、398、741、668、674。

## 三、模三条件把三个余集的排除压缩成8≤5

对任意整数q≥2，给每个历史整数系数\(\lambda_p\)，给每种类型系数\(a_t\)。记\([z]_q\)为0至q−1的标准余数。整数分区必满足

\[
\sum_C\left[\sum_{p\in C}\lambda_p+a_{t(C)}\right]_q x_C
\ge
\left[\sum_{p\in U}\lambda_p+\sum_ta_tn_t\right]_q.
\]

右端非零时，这是有效的联合余数条件。推导只用覆盖、型数量与非负整数性。

本次得到一个特别短的q=3证明。固定一个坐标方向，记一个类在五条纤维上的人数为\(h_0,\ldots,h_4\)。完整单类分类给出以下形状：

| 类型 | 所有可能的排序纤维人数 |
|---|---|
| (9,557) | (1,2,2,2,2) |
| (10,744) | (2,2,2,2,2) |
| (11,936) | (1,1,2,2,5)、(1,2,2,2,4)、(2,2,2,2,3) |
| (11,944) | (1,1,2,2,5)、(1,2,2,2,4) |

对任一指定纤维v，这几种形状直接给出

\[
\sum_{a\ne v}[2(h_a+1)]_3
\le h_v-\mathbf1_{(9,557)}-2\mathbf1_{(10,744)}.
\]

因此，更一般地，若上述四类型的数量为\(N_9,N_{10},N_{11a},N_{11b}\)，总类数为k，余集纤维人数为m，则每一个v都必须满足

\[
\boxed{m_v\ge N_9+2N_{10}+\sum_{a\ne v}[2(m_a+k)]_3.}
\]

三个余集各在某一坐标方向出现纤维人数(21,21,21,17,21)的排列。取人数17的纤维为v；这里k=10，\(N_9=2,N_{10}=5\)。其余四个纤维的模三余数条件各要求至少2，总量至少8；单类占用式求和却给出总量至多\(17-2-10=5\)。于是得到8≤5的矛盾，亦即人数17的纤维至少需要20个历史。

`verify_modular.py`从原菜单重新检查全域52,500个四类型合法类，逐类、逐坐标、逐指定纤维核对787,500个占用式；三个简化证书还分别对全部52,500列核对非负松弛和负常数−3。这里的全类完备性来自前驱完整原生枚举及仿射展开，附带重建入口。

这三个短证明解释的是已排除余集。它们与旧精确边际程序的排除范围一致，尚未提升一般十二标签下界。其余两个余集在更强联合条件下的情况继续研究。
