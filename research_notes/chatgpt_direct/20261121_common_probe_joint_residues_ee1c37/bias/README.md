# 十一标签：闭区间 1/3 至 2/3 上的精确最优公式

2026 年 11 月 21 日。沿用前驱原菜单、历史编码、共同晚选变换及全体合计至多补读一个原端点的权限。以下均为这一有限观测模型中的整数计数，不引入新的原生空间定义。

## 完整结果

恒等变换概率为 p，倍增变换概率为 1−p；给定任一变换后，15,625 个历史与菜单组合等权。在闭区间

\[
\boxed{\frac13\le p\le\frac23}
\]

上，十一标签全局最低补读概率为

\[
\boxed{P_{11}^{\mathrm{opt}}(p)=\frac{5646-54|2p-1|}{15625}}.
\]

在 p=1/2 处，忽略标签名称恰有 8,000 张取等表。该闭区间其余每一点，包括两个端点，恰有 4,000 张取等表，均属于原均匀最优表族。这里证明了公式在上述闭区间成立；尚未声称这是最大成立区间。

## 全域有限排除

令 I、D 分别为两种变换下的累计补读次数，C=I+D、A=|I−D|、r=|2p−1|。利用原仿射对称交换两种变换后，表的最小方向成本为 (C−rA)/31,250。原均匀最优表族有 C=11,292、A=108；任何其他表有 C≥11,301，完整单类谱给出全局差额上界 A≤1,611。

要在 r≤1/3 达到或击败原表族，必须

\[
A\ge108+3(C-11292).
\]

故只需考虑 C≤11,793。完整单类大小／费用／差额谱与母类容量进一步生成 530 个危险分型，其各自最高危险预算不超过 11,594。

`check_plan.py` 已从原完整单类谱重新生成并逐项核对 530 项清单。`plan_verification.json` 保存清单摘要与 SHA256。`completed_q3.json` 合并保存所有分型的完整终局，`frame_chunks_q3.json` 保存其中 50 个分型的全部 581 个不交分片（覆盖 32,690 个规范母类族次）；`result_q3_weighted.json` 汇总预算、嵌入费用下界、母类位置及计数。

P=(10,10,10,10,11,11,11),\qquad E=(13,13,13,13)

的 35 个规范位置全部由原引擎排空，合计 8,234,618 节点。

## 加权下界及 99 项几何补项

对每个未选类，从完整单类谱取 min(3c−|a|)。因为

\[
\left|\sum a\right|\le\sum|a|,
\]

已选类的 3c−|a| 之和，加上未选类的同类最小值，是整表 3C−A 的下界。只有该下界严格大于 3·11,292−108 时才剪枝，因而保留可能取等的分支。终端仍重新计算整表带符号差额。

嵌入部分的 530 项中，431 项没有费用补项；另 99 项含六个完整或删一点母类。前驱六大母类几何结论强制其中至少一个十二点类删去外点。完整嵌入单类谱恰为

\[
(12,1104,0),\quad(12,1116,0),\qquad(13,1296,0),
\]

三元组依次表示大小、费用、绝对差额。故被强制的外点删除使加权下界精确增加 3×12=36。这里使用了具体类别约束，不能仅凭一般的总费用下界便任意乘 3 加入。

`check_embedded_bound.py` 对全部 530 项及所用完整谱逐项验证这一关系；`embedded_bound_verification.json` 记录 431／99 分布、每项加权下界和具体成立条件。

母类子族容量条件、完整交叠点归属枚举及仿射规范化均沿用已验证原引擎；这些规范化不假设待搜索整表具有非恒等对称。

## 严格间隙与端点取等

对任何不属于原均匀取等族的表，记

\[
t=C-11292\ge9,\qquad d=A-108.
\]

全部 530 项排除给出 3t−d>0。由于 C 与 A 同奇偶，t 与 d 同奇偶，3t−d 是正偶整数，故至少为 2。对 0≤r≤1/3，

\[
t-rd\ge t(1-3r)+2r\ge9-25r>0.
\]

因此，任何其他表的补读概率至少高

\[
\boxed{\frac{9-25|2p-1|}{31250}}.
\]

在两个端点，这个严格间隙至少为 1/46,875。原均匀取等族中，方向相反的一半在 r>0 时也严格较差，所以端点没有新的取等表，取等数仍恰为 4,000。

## 十二标签的已兑现升级收益

前驱 9,996 次十二标签构造的两方向读数为 4,915 与 5,081。选取较有利方向后，其补读概率为

\[
\frac{4998-83r}{15625}.
\]

因此，在上述整个闭区间，十一标签最优表升级到这张已构造的十二标签表，补读概率至少减少

\[
\frac{648+29r}{15625}.
\]

这只比较已证十一标签最优值与一个有效十二标签构造，不声称已求得有偏情况下的十二标签最优值。

以下命令在本次总证据包根目录执行；`previous/` 为完整前驱证据树。需要 Python 标准库、支持 C++20、128 位整数和 POPCNT 的编译器。

```text
python3 bias/check_plan.py --baseline previous --plan bias/profiles_q3.json --output /tmp/q3-plan-check.json

python3 bias/replay.py --baseline previous --output /tmp/q3-replay --work /tmp/q3-work --denominator 3 --jobs 2
```

`check_receipts.py --baseline previous --output /tmp/q3-receipts.json` 可快速检查汇总、逐型回执及分片覆盖的一致性；它不替代实际排空搜索。

第三条默认重新生成危险清单、完整候选类、母类规范位置与全部 530 项搜索；最终关键结果须与随包记录相等。显式加 `--resume` 才可复用指定输出目录已有的完整分型回执；`--profiles` 仅提供已核对的清单缓存。`resume_chunks.py` 是准备工作完成后的分片恢复入口，改变调度而不改变搜索算法。
