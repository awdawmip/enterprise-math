# 两种新的中心化联合矩障碍

这里的点是原程序历史的有限观察编码 \(x=(x_0,x_1,x_2)\in\mathbb F_5^3\)。它不是替换原生 X6 对象的新空间；本文仅对既有观察编码的整数分区作精确计算。

## 1. 定义与完整单类分类

对历史集合 \(S\)，令

\[
\mu(S)=\sum_{x\in S}x,\qquad
Q(S)=\left(\sum x_0x_1,\sum x_0x_2,\sum x_1x_2\right),
\]

所有量均在模五中计算。当 \(N=|S|\not\equiv0\pmod5\) 时，定义

\[
\Gamma_N(S)=Q(S)-N^{-1}(\mu_0\mu_1,\mu_0\mu_2,\mu_1\mu_2).
\]

平移 \(x\mapsto x+t\) 使 \(\mu\) 增加 \(Nt\)，使 \(Q_{ij}\) 增加 \(t_i\mu_j+t_j\mu_i+Nt_it_j\)，因此中心化后的 \(\Gamma_N\) 不变。对这里的十点类，\(\mu=0\)，且 \(Q\) 也平移不变。

定义以下集合，坐标顺序为 \((01,02,12)\)：

\[
D=\{\pm e_1,\pm e_2,\pm e_3\},
\]

\[
F=\{\text{所有坐标置换及独立正负号下的 }(0,2,2)\},
\]

\[
E=F\cup\{\text{所有坐标置换及独立正负号下的 }(0,1,2)\}.
\]

这里正负号按模五解释。集合大小分别为 6、12、36。

| 合法类的（大小，费用） | 完整类数 | 结果 |
|---|---:|---|
| (9,557) | 24,000 | \(\Gamma_9\in E\)，且支持恰为 \(E\) |
| (10,744) | 12,000 | \(\mu=0, Q\in D\)，且支持恰为 \(D\) |
| (10,768) | 1,500 | \(\mu=0, Q\in D\)，且支持恰为 \(D\) |
| (11,944) | 12,000 | \(\Gamma_{11}\in F\)，且支持恰为 \(F\) |

十点类的结论沿用前驱，本次补出九点类和费用944的十一点类结论。完整性依赖前驱原生枚举的 `new_lower/class_representatives.json`。检查器用原菜单直接复核六个轨道代表的合法性和费用，再展开全部49,500个类，核对不交轨道、完整计数和每个类的联合矩。已有仿射作用保持原菜单和费用；这里没有把六个代表的抽样当作全类枚举。

## 2. 尾部分区的必要条件

设 \(U\) 被分成一个九点类 \(A\)（费用557）和 \(k\) 个十点类 \(B_i\)（费用744或768）。因为各 \(B_i\) 的 \(\mu\) 为零，\(\mu(U)=\mu(A)\)，且 \(|U|\equiv9\pmod5\)，所以

\[
\Gamma_{|U|}(U)=\Gamma_9(A)+\sum_{i=1}^kQ(B_i)\in E+kD.
\]

同理，一个费用944的十一点类加 \(k\) 个上述十点类，必有

\[
\Gamma_{|U|}(U)\in F+kD.
\]

这个加法只在上述“十点类一阶和为零”的条件下成立；一般的中心化联合矩不对任意不交并可加。

| 十点类数 \(k\) | \(\lvert E+kD\rvert\) | 包含零？ | \(\lvert F+kD\rvert\) | 包含零？ |
|---:|---:|:---:|---:|:---:|
| 0 | 36 | 否 | 12 | 否 |
| 1 | 102 | 否 | 60 | 否 |
| 2 | 124 | 否 | 110 | 否 |
| 3 | 125 | 是 | 124 | 否 |
| 4 | 125 | 是 | 125 | 是 |

零不在前述集合中还有一个直接解释：在五循环的坐标乘积图上，每个 \(D\) 元素只走一个单位步；\(E\) 中向量到零至少需三步，\(F\) 中向量到零至少需四步。因此，中心化联合矩为零的29点集合不能按 \(9+10+10\) 的指定类型分区；中心化联合矩为零的41点集合不能按 \(11+10+10+10\) 的指定类型分区。

## 3. 两个可直接复算的反例

`counterexamples.json` 保存点号、已存在的合法部分分区和最后十个点；点号为 \(25x_0+5x_1+x_2\)。

29点例子已有一个合法 (9,557) 类和一个不交的合法 (10,744) 类。未填的十个点在每个坐标方向、每个模五取值上都各出现两次，满足另一个最低价十点类的全部单坐标人数要求。全域 \(mu=(1,2,2)\)、\(Q=(3,3,1)\)，故 \(Gamma_{29}=0\)，无法完成所需分区。

41点例子已有一个合法 (11,944) 类和两个不交的合法 (10,744) 类。剩下的十个点同样在各坐标五个取值上各出现两次。全域 \(mu=(2,2,0)\)、\(Q=(4,0,0)\)，故 \(Gamma_{41}=0\)，仍无法完成所需分区。

检查器既检查联合矩排除，也在完整类型库中过滤这两个小余集的候选，另做直接不交覆盖搜索；两例分别访问2和24个节点，均无解。它还直接检查所列部分分区及剩余十点的平衡人数。这样区分了“各坐标人数可配”与“联合观察可实现”。

## 4. 复验与边界

从主证书包根目录执行：

```bash
python3 -B moments/verify.py --previous previous --output /tmp/centered_moments.json
```

验证只需要 Python 标准库，前驱文件保存在 `previous/`。这些是精确有限观察恒等式及指定尾部的排除条件；本次尚未测得它们改善完整十二标签搜索的节点数，也没有据此改变全局下界。
