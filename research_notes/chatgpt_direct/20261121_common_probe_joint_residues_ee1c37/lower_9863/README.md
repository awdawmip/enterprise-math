## 复验

默认布局为总包中的 `lower_9863/`，B 保持为相邻 `lower/`，费用 9,862 增量为相邻 `lower_9862/`，完整前驱包为相邻 `previous/`。

快速审计先检查上一费用层，再重新生成本层完整费用谱并核对全部 150 条终局和统计：

```text
python3 replay.py --previous ../previous --lower ../lower --prior-layer ../lower_9862 --mode audit
```

本目录的 `verification/` 保存实际执行该审计的结果。审计明确不宣称重新执行已完成的 901,752,673 个覆盖节点。

从原菜单生成完整种子和银行，再在新目录实际重跑本层：

```text
python3 replay.py --previous ../previous --lower ../lower --prior-layer ../lower_9862 --mode full --jobs 2
```

完整模式不使用附带的完成回执来跳过搜索；它逐项核对重建输入及全层覆盖。需要 Python 3 和支持 C++20、128 位无符号整数及 POPCNT 的编译器。未结束的分型不能计为排除。
