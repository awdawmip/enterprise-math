## 3. 联合约束族的准确范围

所有余数割均使用

\[
b_C=\left[\sum_{p\in C}\lambda_p+a_{t(C)}\right]_q,
\quad r=\left[\sum_{p\in\mathrm{free}}\lambda_p+\sum_ta_tn_t\right]_q,
\quad\sum_Cb_Cx_C\ge r\quad(r>0).
\]

余数取 \(0,\ldots,q-1\)。通过减去第 0 个纤维的公共系数，并把相应的类大小倍数加到类型系数中，可以无损规范化 \(\lambda_0=0\)。

### 3.1 单线性形式的全部加权纤维函数

任取 31 个归一化非零线性形式中的一个 \(\ell\)，并取任意函数
\(f:\mathbb F_5\to\mathbb Z/q\mathbb Z\)，令 \(\lambda_p=f(\ell(p))\)。类型系数 \(a_t\) 也独立遍历全部模 \(q\) 值。分别检验 \(q=2,3,4,5\)。

固定 \(f(0)=0\) 后，每种模数有

\[
31q^7(q-1)
\]

个右端非零的索引成员。每个纤维函数对应一个精确的 \(q\) 状态动态规划；该 DP 对给定右端余数最小化所有类型系数的左端，从而一次覆盖该右端的全部类型赋值。

| 模数 | 每帧覆盖的索引成员 | 精确 DP 余数最小值检查 |
|---:|---:|---:|
| 2 | 3968 | 496 |
| 3 | 135594 | 5022 |
| 4 | 1523712 | 23808 |
| 5 | 9687500 | 77500 |

### 3.2 双原坐标的全部加法型模 3 函数

任取两个不同的原编码坐标 \(i,j\)，分别任取一元函数 \(f,g\)，使用

\[
\lambda_p=f(p_i)+g(p_j)\pmod3.
\]

这里的完整范围是**两项一元函数之和**；它不扩张为任意 25 格的二维函数。规范化 \(f(0)=g(0)=0\) 后，三对坐标合计覆盖

\[
3\cdot3^{11}\cdot2=1062882
\]

个索引成员，通过 39366 个精确 DP 余数最小值检查完成。

上述两类模数族合计每帧 **12413656** 个索引成员、**146192** 个精确 DP 最小值检查。所有权重在公共分母下以整数计算；没有以浮点无违反代替这一核验。

### 3.3 至多三个纤维/单点的异或，连同类型位

以 155 个仿射 25 点纤维与自由集的交集、以及 101 个自由单点，共 256 个特征为基础。任取其中至多三个作对称差，并遍历全部满足右端为奇数的类型位。包含空特征集时，每帧有

\[
8\sum_{k=0}^{3}\binom{256}{k}=22371336
\]

个索引割。

配套 `portable/verify_integer_xor.py`、`portable/integer_xor.cpp` 是根任务已经验证的整数检查器的原样副本。它先以 \(2^{60}\) 向下取整提供严格整数下界，再对下界不足 1 的成员使用公共分母精确求和。最终第 1、2 帧分别只有 108、112 个回退成员，全部恰好等于 1。

两帧的模数族和 XOR 族合计覆盖 **69569984 个索引约束**。这些族相互重叠，族内也包含重复表达；这个数字不表示不同不等式的数量。

## 4. 三坐标关系确实会提供新的分离

早期 `star_joint_exact/cover_2.json` 的 296 支持点已经同时满足完整 (S)、全部单线性形式模 2/3/4/5 约束、全部双原坐标加法型模 3 约束，但被下列三坐标奇数集分离：

\[
U=\mathrm{free}\cap
\bigl([x_0=3]\mathbin{\mathrm{XOR}}[x_1=4]\mathbin{\mathrm{XOR}}[x_2=2]\bigr),
\qquad|U|=37.
\]

其精确奇偶左端为

\[
\frac{171522011904914807150345818478833199184}
{172795823802562932703984005438262925839}<1.
\]

`verify_three_axis_separator.py` 使用标准库独立验证该分离，`three_axis_separator.json` 包含完整 37 点集合、坐标和旧点指纹。这说明上述双坐标加法型约束和 (S) 不蕴含这个三坐标奇偶约束。

加入该割的完整二阶框架稳定子轨道后，在第 2 帧的**全部 8538 个候选列**上继续求解。三轮闭包得到目前的 312 支持正例。最终点也通过整个至多三特征 XOR 族，因此分离一个特定点仍不等于排除整帧。

第 1 帧始终使用全部 7953 个候选列。发现阶段的求解均为完整候选 LP；在支持上的线性方程求解仅用于恢复已有完整 LP 解的精确有理权重，没有把支持 LP 不可行当作完整 LP 不可行。

## 5. 便携复验

目录中保留发现程序和已完成的精确回执。便携入口可从任意工作目录运行：

```bash
python /path/to/integer_cuts/verify_joint_package.py \
  --previous /path/to/complete_predecessor_package \
  --work /path/to/new_replay_directory
```

`--previous` 指向包含下列原文件的完整前驱证明包：

```text
fractional/proof/verify.py
fractional/next_cuts/discovery_common.py
```

入口固定核对本文件列出的两个最终 SHA-256，再运行原程序/覆盖/类型/(S)/全部模数族核验和整数 XOR 核验。新回执与编译文件仅写入 `--work` 指定目录。正例复验无需重新枚举全候选库，也不调用 LP 求解器。

依赖为 Python、NumPy 和支持 C++20 的编译器。NumPy 只承载有界整数占用数组；大权重、DP 值、星团松弛和最后比较均使用整数或有理数。发现程序另用 SciPy/SymPy，并将 HiGHS、BLAS、OMP 限为单线程；线程设置不改变数学模型。

已有回执分别是 `all_joint_exact/direct_verification_{1,2}.json`、`all_joint_exact/xor_verification_{1,2}.json`。`package_manifest.json` 记录便携代码、固定证书和前驱入口的散列。本轮完成后没有为发布而无必要地重跑已验证的科学计算。

本轮给出的是所列联合松弛的完整六框架分类。未列入的更高阶或其他模数观察仍可继续研究；现有整数下界和最优构造结论不由这些分数点改写。同团队复验不替代正式独立 Review，状态保持 `NOT_REVIEWED`。
