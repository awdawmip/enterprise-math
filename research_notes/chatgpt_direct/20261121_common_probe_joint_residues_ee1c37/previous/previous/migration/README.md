# 从 21 到 125 标签的一条逐档最优换表链

每次加一个标签，把若干历史直接交给它，所有其余历史保留原标签。第 m+1 档的全域最优费用等于各消息类最低费用在 125 段历史上的整数分配下界。取等时类的大小只能为 125/(m+1) 的下取整或上取整。新增标签至少接收下取整这么多历史，即使新旧标签允许最有利的重新配对，此界仍成立。

从此前的 21 标签最优表出发，new_labels.json 依次列出升到 22 至 63 标签时交给新标签的点号。此后每次拆一个剩余二点类即可达到 125。每一步的新标签恰好达到上述大小下界。各类的新旧大小个数之差还给出必须更换的完整旧类个数下界，逐步核对所给同一条链，每一步也恰好取等。程序核验了全部 105 张表的覆盖、原菜单合法性及费用，结果见 result.json。

从包根执行 python3 -B replay.py --only migration。
