# 任意两档的全域最优表是否可以互相细分

考虑 13≤m<n≤125，要求同时存在两张全域最优表，使新表的每个消息类都包含在某个原消息类中。两端的预算可以相隔多档，只要求两端取到最低费用。

十四标签以上，每张全域最优表都达到按类大小计的单类成本整数分配下界，所以每个类都必须单独取等。对每一可能大小 s 检查固定一类后的整数下界，最优的大小只能是 125 除以标签数的下取整或上取整，两种大小的数目亦由总点数确定。十三标签另有完整的单轨道定理，逐个使用它的固定消息类。

原菜单给出任意两个历史的补读掩码与禁止三元组。bank.cpp 沿已归一化的点对及原生禁三元组穷举合法类，保留大小 2 至 9 的单类取等种子，再施以全部保成本仿射映射。对某个原类 C 和目标小类大小 t，枚举含 C 中最小点的大小 t 或 t+1 的全域最低价子类，递归计算剩余部分可分成多少类。取整表卷积，即知这个实际旧表能否得到所需的新标签数；可行时算法的每一项都来自真实分区。对同大小的原类取全部种子所允许的类数之并，再卷积，得到适用于所有最优旧表的必要条件。未通过这一条件的预算对全域排除。

result.json 对每个起始 m 分别给出已经构造、全域排除及仍待决定的目标 n。可行证明使用前版公开见证和 extra_tables.json 的附加表。仍待决定表示仅有分别选取单类的条件，没有给出能让这些类同时出现在一张最优表中的证书。

## 二十一标签以上的显式预算区间

下表列出给定最优旧预算 m 时，可由细分达到全域最优的新预算 n。区间均只取整数。两端并不要求中间每档也取等。

| m | 可行的 n |
|---|---|
| 21–24 | [2m,125−3m] 或 [3m,125] |
| 25–31 | n=2m 或 n≥125−2m |
| 32–41 | n=125−2m 或 n≥2m |
| 42–61 | n≥125−m |
| 62–124 | 任意 m<n≤125 |

例如 32 至 41 标签的旧类由三点类与四点类组成。若目标类大小为二或三，四点类必须分为两个二点类，三点类必须保留，因此目标数只能是 125−2m。若目标类大小为一或二，每个四点类至多产生两个二点类，每个三点类至多产生一个，所以 n 至少为 2m。相应可行范围由上述原菜单逐表复验确证。
