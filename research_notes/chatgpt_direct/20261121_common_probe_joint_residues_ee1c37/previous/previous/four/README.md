# 四台独立晚选的 56 消息表，小规模重排不能删去标签

固定此前覆盖全部 625 段历史的 56 消息表，从中选择 q 个旧类，任意把它们的并重新分为 q−1 个非空一读合法类，保留其余旧类。对 q 从 2 到 5 均无解。因此，若存在 55 消息或更小的表，至少须更换这张旧表中的六个完整旧类。

每个类的容量至多为 12，先排除大小总和超过 12(q−1) 的选择。对角平移生成五阶群，原来的 56 个类组成 11 个五元轨道及一个固定类。程序把其余选择归并后逐个求解。在一个 n 点待分区域内，任何新类都至少要有 n−12(q−2) 个点。用四坐标原模型的禁止三元组列尽所有达到这个大小的合法类，再以区域中候选最少的点为分支作精确覆盖。四台的禁止三元组等价于两个坐标在这三点上各自孤立了不同的一点，这正是两个坐标值块形成非层状相交。

重新分为更少的类时，总能继续细分其中的类，达到 q−1 个非空类。这使结论也涵盖减少多个标签的尝试。result.json 的候选行数按各归一化区域累计。四台消息数的一般界仍是 53 至 56。
