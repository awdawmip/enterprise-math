# ≤两个十三点类的十一标签等号表同样不能有对合

与 involutions 目录中的逐点枚举器相同，将总读数预算提高至 11,292，并保持最多两个十三点类的条件。对纯互换，所有类本已至多十二点，仍用 31,250 的全输入预算。三种其余对合类型的不同余集数保持 145、67、1,372，均不能补全。单轴反射的既有无条件下界为 11,328。结合已独立排除三个和四个十三点类的等号分层，所有具有非平凡对合的 11,292 读数十一标签表都恰含五个十三点类。该分层中恰好 4,000 张具有六阶循环稳定子，分两条仿射轨道，其余 4,000 张的稳定子为三阶，均无对合。

运行 python3 -B replay.py --proof /path/to/involutions --last /path/to/round3 --older /path/to/round2。proof 目录需包含本轮不动点与交换类的生成器。对这份等号证书，max_thirteen_point_classes 给出进入分层时已经假定的类数上限。
