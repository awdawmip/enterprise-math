# 四台独立晚选时，56 条消息足够

旧历史取遍 F₅⁴，编码发生在各台独立晚选恒等或模五倍增之前。全部首次回执可合看，随后至多读取一台的一个原端点。此前已证单类最多容纳十二段旧历史，因此总消息数至少为 ⌈625/12⌉=53。

取对角线 D={(t,t,t,t)}，用 (x₀−x₃,x₁−x₃,x₂−x₃) 标记 125 个轨道。certificate.json 的 11 行代表各跨互异轨道，11 行合计恰覆盖 124 个轨道。各行分别作 D 的 5 个平移，得到 55 个合法消息类。剩余轨道是以四位五进制编号后的 {54,205,361,392,548}，单独作为最后一类。分区总计 625 点，各类大小分布为 {5:1,9:5,10:10,11:5,12:35}。最优消息数区间现为 53 至 56，最优定长位数保持 6 位。

从这些代表逐类验证坐标取值块两两相离或嵌套。再让四台各取任意二端点集合，遍历 10,000 个联合菜单。在每种消息与每种首次回执的分组内，若后继不唯一，两种可能必在同一已报边内的一台上有不同原端点，故读一台即可。核验总计 6,250,000 对历史与菜单。用旧配对构造得 M(8)≤25,000+5×56=25,280 及 M(12)≤7×5⁹+65×25,280=15,315,075。

**模板局部刚性。** 取任意两份证书模板重新安排，其余九份保持各自的投影点集。给剩余 125 点空间中的每个未覆盖投影任选一个提升，询问能否用两份新模板补齐。每份至多容纳十二点，21 对的剩余点数超过 24。另 34 对穷举所有点分配及各自的五个提升，共 248,578 个结点，均无解。穷举中，若两坐标分别将三点中的不同一项隔离，则出现 L 形三个角，不能同属一个类。反之，未出现这种三元组即满足层状判据。加入点时去掉与同类两已选点形成禁止三元组的候选提升；当类中尚无点，可将第一点的第四坐标平移为零。每个投影将来可进入的每个类及全部未排除提升都逐一分支。两模板结果针对改成 11 个五平移模板、完全覆盖 125 个轨道的局部构造。全体编码的消息下界仍为 53。

**秩二投影。** 任取从四维到二维的满秩线性编码投影，两个合法消息类的像联合至多含 23 个点。十二点类的结构、七种列方向类型以及逐项有限排除见 rank_two.md。

执行 python3 -B replay.py 可重跑全菜单补读、124 轨道证书的单模板和双模板核对，以及秩二投影分类。需要 Python 3.10+ 和 C++17 编译器。

四条列方向彼此不同时，两份十二点类的投影并能达到 23 点。可复算的原四维代表点、两组十二点像集及其唯一交点（五进制编号 12）见 rank_two.json。因此取遍秩二投影及两份合法消息的最大不同像点数恰为 23。
