# 所有 Klein 四元对称都不能改善十一标签表

以总费用至多 11,291 为界，全部 25 个 Klein 四元子群归为 7 个线性共轭类型（3、3、6、3、1、3、6 个）。仿射群的四阶子群对某点的四个像取平均，即有共同不动点，故可平移至线性群。十一标签的既有费用分层容许本预算内至多两个十三点类。成对标签的代表可用 8 到 13 点，单类费用上限分别为 581、761、951、1,131、1,311、1,498；四元标签轨道的代表只能有 10、11、12 个点，单类上限依次为 842、1,027、1,207。这两个列表由原菜单的单类最小费用和剩余标签的大小约束核验。

对群 G 的固定标签直接枚举其包含的历史轨道，检查禁止三元组。对成对标签，枚举其稳定子 H 为三个二阶子群之一。在所用的每个历史轨道 Gx 里，H 都必须把它分成两个 H 轨道，标签代表恰选其中一个。首个轨道可规范化，其余全选。对四元轨道，重建符合费用范围的单类并取仿射像，要求它在三个非单位元素下的像都与自身不交。用完整支持及标签数归并，每一支持取其最低成本，并保留候选中十三点类的标记。

将一个标签轨道记录为它用掉的标签数及所用 1、2、4 点历史轨道的个数，以整数动态规划求这个放宽问题的最低费用。七个类型中，0、2、3、4、6 在根部即排除；1 和 5 仍可能满足抽象配额，遂按一个具体历史轨道的实际支持选择递归。两型分别仅须 21 和 17 次访问即排空，至多选定三个具体支持。没有一种 Klein 对称可以严格改善目前的十一标签上界。

`result.json` 记录七类的代表、数量和逐项搜索回执。命令 `python3 -B replay.py --older /path/to/round2/delivery --group /path/to/round3/group` 从原菜单和完整线性群复算。结合阶 3、4、5 的既有排除结论，改进表的稳定子只能平凡或由唯一的二阶元素组成。
