# 三台共同晚选模型中的低成本大类和累计读数下界

按三台真实首回执和二值端点答复建立原模型。一个十三点类成本为 1,296。十二点类的最小两档成本为 1,104 和 1,116。把这三类合在一起讨论。此前已公开的有限枚举给出三类的全体数目分别为 250、250、3,000。证明从十三点种子的 250 个仿射像重建全部最大类。逐个从每个最大类中删去一点，恰有一种删法得到 1,104，其他十二种得到 1,116。得到的 3,250 个十二点类互异，因而每个低成本大类的十三点母集唯一。相同母集的两个类交叠，分区中使用的母集必须各异。

## 联合容纳条件

设选择 k 个母集。每个类至多删去一个点，故其母集并集至少有 12k 个点。逐个添加母集时，13k 减并集点数单调增加。因此可以在该差超过最终母集个数时立即剪枝。利用平移、坐标置换、逐坐标反号和同时倍乘，第一母集取固定代表即可。对所有仍有可能的母集组，只需考察交点上各母集删除哪个点。程序同时计入保留全部点、删除中心、删除外围点三种成本，同一母集没有删除或删除专有点时在交叠上的投影相同。

| 不交大类数 | 过并集条件的定首母集组数 | 能选成不交类的定首母集组数 | 所有可能的类数组合 |
|---:|---:|---:|---|
| 7 | 46,550 | 10,430 | 七个十二点类中 5 至 7 个成本为 1,116，或一个十三点类加六个成本为 1,116 的十二点类 |
| 8 | 720 | 720 | 全部八个为成本 1,116 的十二点类 |
| 9 | 0 | 0 | 无 |

八母集组在上述对称群下有四种类型。每一型的删除只能发生在公共点上，删法改变交点的归属，每次留下同一 29 点余集。对四个余集依次作三类覆盖判定，均不成立。分支先枚举大小至少 10 的合法类（余集的最大类），再在它的补集上枚举至少占一半的类，最后直接检验剩余集合。因此十一消息表至多含七个上述低成本大类。

## 累计补读下界

使用先前的每种大小最低成本与类别枚举器，展开使低预算仍有可能的大小和成本类型，各个类型的展开都包含全部仿射像。下限以外的类以通配成本下界纳入动态规划，若候选组合含任何这样一个类则显式中止并要求扩大枚举范围。依据前一轮的全局下界和含五个或六个最大类的完整分类，十一消息只须检验含最多四个十三点类的新增预算组合。以上母集数目及成本联合限制进一步排除大量组合。余下每种成本组合按准确点集分支，并检查每个未占点能否由一个剩余类覆盖。判定以整数和位集进行。

在本目录运行 `python3 -B replay.py` 重建两项下界、母集支持及剩余三类覆盖检验，并核对本轮 12 标签编码的 31,250 个输入。最低读数区间内目前尚未有一般最优性证明。代码沿用前轮 [d27c1a9bc087](https://github.com/awdawmip/enterprise-math/tree/d27c1a9bc08753514a9c1f60d411ad7410a3a10c/research_notes/chatgpt_direct/20261116_common_eleven_exact) 的原观察谓词、类枚举器、下界组合完整性检查、类数限制和有限证书。在本目录运行 `python3 -B verify_twelve.py twelve_10147.txt` 可以单独核对可行表的读取次数。

另在本目录运行 `python3 -B eight_class_cost.py`，可重建四种八母集情形的十二消息结果。在每个 29 点余集上，把四个非空类按大小从大到小、同大小按点集掩码递增排序。每步枚举满足该顺序且至少占剩余点数平均份额向上取整的类。九、十点和其他大小至少七点的候选来自无漏的合法类枚举。达到较小大小时直接穷举剩余点集合并检验禁三元组。最后一类直接核实。四型的最低整表成本分别为 10,677、10,696、11,003 和 11,004，因此十二标签最优表也至多有七个上述低成本大类。

这种母集表示还恰好包括十一点类中的最低三档。对 250 个十三点母集各删两点，所得 19,500 个点集两两不同，成本 936、944、960 分别出现 4,500、12,000、3,000 次。完整类别枚举在这三档的计数完全相同。因此这三档十一点类各有唯一的十三点母集。运行 `python3 -B two_deletions.py` 可复核投影构造及每个类成本。

完整增量穷举执行 `python3 -B extended.py`，输出应与 `extended.json` 一致。十一标签的新增候选共 1,323 种，全部排除至累计预算 10,961，给出下界 10,962。十二标签排除 137 种新增候选至预算 9,824，给出下界 9,825。两档分支结点分别为 72,166,199 和 108,651,601。短档 `replay.py` 的两个下界分别为 10,959 和 9,823，完整档涵盖短档。
