# 十一标签表不可能具有初等阿贝尔八阶对称

本结论不设补读费用上限。设 G 是保持全表的初等阿贝尔 2 群，阶为 8。在五元域中可以对一点的八个像取平均，得到公共不动点。平移至原点后，G 落在 96 阶线性群。复核全部两两交换的三个对合，恰得到 4 个八阶群。它们归入两种共轭类型，第一种是三个坐标独立变号；第二种的代表由交换前两坐标、前两坐标同时变号、第三坐标变号生成，后者有三个共轭群。

两型在 125 段历史上的轨道按大小 1、2、4、8 分别有 1、6、12、8 个。一个标签轨道的标签稳定子为 H，标签数 r=8/|H|。对任何被该标签轨道覆盖的历史轨道，代表标签必须恰取其中一个 H 轨道，该历史轨道恰划为 r 个这样的 H 轨道。选出一个之后，其余由 G 的作用唯一确定。首个 H 轨道的选法可由群作用规范化，其余全部枚举，逐点用原菜单的禁止三元组核验合法性。如果 r=8，代表只能从八个八点历史轨道各取一点，八标签最多覆盖 64 点。其余三标签最多覆盖 39 点，总容量不足 125。

r=1、2、4 时，把能出现的标签轨道记为五元整数向量，由 r 和它覆盖的四种历史轨道个数组成。第一型共有 68 个不同向量，其非负整数和不能等于 (11,1,6,12,8)，故无解。第二型共有 69 个不同向量，可以满足此方程；以每个向量的最低可实现成本计算，其放宽最小值为 11,748。再固定历史点轨道 {31,34,121,124}（编号为 25x+5y+z），发现共有 493 种“标签轨道长度及实际支持”可以覆盖它。将任一相应向量从 (11,1,6,12,8) 中扣除，剩余均无法用 69 个向量非负整数组合填满，因而第二型也在所有读数下排除。

运行 `python3 -B replay.py --older /path/to/round2/delivery --group /path/to/round3/group`，从实际菜单及线性变换重建全部标签候选及群分类。独立的容量放宽和 493 个余量由递归整数动态规划处理。`result.json` 附完整回执。
