# 十二标签仅有一个六点例外时的精确费用

十一母类最多盖 119 点。如果恰有一个六点合法消息类不嵌入任何十三点母类，其他十一类必须分别落入十一个不同母类，它们的并达到 119 点。六点例外正好等于其补集。使用本轮母类覆盖搜索，列出并为 119 点的 56 个归一化族。其中 36 个族的六点补集合法，在原菜单的 12,000 个仿射自同构下仅有一个类型。

固定这个类型，每个母类必须接收仅属于它的历史，18 个共享点分别选择归属。取证明中的整数点权和每个类的常数项。对每个类的全部可选子集直接计算原菜单费用，核对常数项与所选点权的和至多为实际费用的 10,000 倍。十二个类合计 217 个选项，整数对偶下界为 104,760,000；所给分区达到 10,476 次补读。

一份表取等时，每个局部选项都应取等。穷尽等号选项的完整分配，固定族恰有 240 张不计标签名称的最优表。十一母类各自至少有七个私有点，而任意不同母类最多相交于三点，故每个非例外类的母类归属唯一。该族的仿射稳定子有两个元素，因此共有 6,000 组实际母类。这给出 1,440,000 张最优表。取等分配在族稳定子下分成 120 个大小为 2 的轨道。故全空间内有 120 个最优轨道，每个包含 12,000 张表。

运行 python3 -B replay.py --base /path/to/current/parent-proof --previous /path/to/previous-release。复验从上一版完整解包的原菜单和本轮母类覆盖源码重建点集与候选，并用纯整数验算所给分区、对偶和计数。无需 LP 或 MILP 求解器。
