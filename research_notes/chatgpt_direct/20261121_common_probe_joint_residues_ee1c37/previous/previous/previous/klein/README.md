# 十二标签的克莱因四元群边界

三台采用共同晚选变换、全场至多读一个原端点。对 31,250 个等权输入求累计补读数，并把消息标签的重新编号视为同一张表。若十二标签表在模型的 12,000 元仿射对称群中保有一个克莱因四元子群，则累计补读的最小值恰为 **10,632**。恰有 **3,000 张**达到最小值，属于一个仿射轨道。无对称限制的十二标签表已有 9,996 次的构造。这里的下界适用于保有克莱因四元对称的表。

## 七种子群

对仿射子群的四个元素作用于任意一点，将四个像在五元域中取平均，所得点由全群固定。因此每个子群都可由平移移入 96 元线性部分。完整列出两两可交换的线性对合所生成的四元群，得到 25 个子群，在该线性群的共轭作用下分为七型，型的大小依次为 3、3、6、3、1、3、6。按证书中从零开始的编号，第 1 型最低 **10,632**，第 5 型最低 **10,672**，其余五型均超过 10,672。

## 标签轨道与搜索

令四元子群作用在标签类上。一个轨道用掉 1、2 或 4 个标签。同一轨道中的类两两不交。群至少固定一个原历史，容纳该历史的标签也由群固定，因而十二标签至多含两个四元标签轨道。

- 一个固定类是若干完整历史轨道之并。逐步加点并检查原始菜单的禁止三元组，即可列出全部固定类。
- 两个互换标签的类有二阶稳定子。枚举三个二阶子群和各历史轨道的两份陪集，在每个用到的轨道里从两份中取一份。第一处选择可由全群的一个元素规范化。对固定类及所有二元标签轨道不设单类费用截断。
- 四个互换标签的类只能遇到大小为四的历史轨道，且在每个用到的轨道上各取一个点。先用此前四阶循环群证书的单类枚举预存一批低费用支持及其最低费用。对于超过该费用表范围的查询，直接在剩余的历史轨道上逐一选择代表，检查禁止三元组并按原菜单计费。若剩两个四元标签轨道，就用互补的两份支持拼接。若两份的最低可能费用都容许超出预存范围，程序穷举其余的互补划分。

先记录每个标签轨道用掉的标签数，以及它用掉的单点、双点、四点历史轨道数。按指定的四元标签轨道数作整数动态规划所得的费用，是忽略具体点位的下界。完整搜索每次选取一个仍待覆盖的单点或双点历史轨道，遍历能容纳它的固定类或二元标签轨道。如果只余四点历史轨道，也允许继续放入固定或二元标签轨道。丢弃高于预算的支路，并在保持该子群的仿射变换作用下合并相同的剩余支持。最后按上一段的补全方法结算。所有剪枝使用整数比较。逐型、逐四元标签轨道数的费用和节点回执见 `result.json`。

## 等号与原程序

获胜类型可取由 (x,y,z) → (−x,y,z) 与 (x,y,z) → (x,−y,−z) 生成的群。达到 10,632 次的表恰有两个固定类与五对互换类。代表的两个固定类分别花费 664、1,016 次，五对互换类的单类费用分别为 1,104、936、804、816、816 次。关闭支持对称归并，逐一列出费用达标的八组不相交支持。对每一组重新枚举原历史位置，每个标签轨道恰有一种实现。固定子群的 32 元正规化子在八张表上传递。每张表在完整仿射群的稳定子有四个元素，故全轨道恰有 12,000/4 = 3,000 张表。该类型的固定仿射子群共有 12,000/32 = 375 个。

`groups.json` 是一张最优表。原程序分量回执覆盖全部 31,250 个输入，其中 20,618 个免读，10,632 个各读一次。另从准备阶段完整执行 40 个分层选取的三台原程序路径。`native_result.json` 含读数分布及路径摘要。

在上轮完整解包目录作为 `ROUND5` 时，可分别执行以下命令。后一条的目录是该发布包内的第三轮依赖。

```sh
python -B replay.py --previous "$ROUND5" --jobs 2
python -B native.py --round3 "$ROUND5/previous/previous"
```
