# 至多五个拆分类能各省 960 次

在三台共同晚选变换的 31,250 个等权场景上，一次将合法消息类拆成两个非空子类，累计最多节省 960 次。此前按大小穷尽的结果表明，只有十二点母类能取到，其他大小的单次上限为 900。

本证书复查全部 160 个规范十二点种子。对每个种子穷尽二分，第一个点留在第一子类以消除子类对调；在计算中保留所有可能等于 960 的情况。8 个规范母类产生 48 个等号拆法。在 12,000 个保成本仿射变换下，它们形成一个含 375 个不同母类的轨道，每个母类都有 6 个不同的无序等号拆法。对同样的 160 个种子也跟踪全部小于 960 的拆法，包括同一母类在其他拆法已经取等的情形。只有在单类及子类成本界同时排除新的等号和更好的次大值时才略过。得到全域次大值 **914 次**。

给 375 个母类编号，两母类不交时连边。仿射群在顶点上传递，固定第一个顶点即可检查全部可能的集合大小。程序在共同邻居中按严格递增编号添加顶点，直到再无选择。包含固定母类的 1、2、3、4、5 元不交集合分别有 1、114、1,565、3,200、576 个，六元为零。把每个计数乘以 375 再除以集合大小得到全域精确计数；其中五元集合共有 **43,200** 个。result.json 含五个不交母类的明确点号、各自两子类及逐项原菜单成本。

这样得到的 k 个母类可用剩余点的单点标签补成全域表，拆分它们便节省 960k 次，全部 k=1,2,3,4,5 均可达到。在任意连续二分中，出现过的两个不同母类要么不交，要么一个严格包含于另一个，而达到 960 的母类均有 12 点。因此一次拆分序列中达到 960 的步骤至多五次。对 k≥5，总节省至多 4,800+914(k−5) 次。大于五步时这里给出上界，未断定上界能达到。

复验命令为 `python3 -B replay.py --previous /path/to/round5/finalcheck --refinement /path/to/round6/refinement`。在正式复验包内可省略 --refinement，会默认使用相邻目录 refinement 的按大小穷举结果。
