# 十一标签 q=2：完整待计算清单与安全继承范围

2026 年 11 月 21 日。此包是搜索入口与待计算清单，**不是 q=2 排除证书**。775 个危险分型中，目前没有一个完整分型因本包而被证明排空。

令 C=I+D、A=|I−D|。原均匀最优表族有 C=11,292、A=108。若在 r=|2p−1|=1/2 达到或击败该表族，须有

\[
A\ge108+2(C-11292).
\]

完整单类谱给出全局 A≤1,611，因此 C≤12,043。对这一完整费用窗，利用前驱无条件几何约束及完整单类大小／费用／绝对差额谱，生成恰好 **775 个危险 P/E 分型**；其中最高危险费用为 **11,901**。P 为不嵌入任何完整十三点母类的类大小，E 为嵌入母类的类大小。这里只应用必要条件，允许类重叠及重复的谱上界不会误删真实分割。

## 旧 q=3 回执能继承什么

q=3 排除的是 A≥108+3(C−11,292)，其阈值严格强于 q=2。故相同费用窗中的 q=3 无解回执，通常不能排除 q=2 的新增差额带。

全部 530 个共同分型的 q=2 预算都严格增加，没有预算相同的分型。`check_inheritance.py` 采用以下与加权目标无关的充分条件，严格区分可继承范围：

1. 从完整谱重新计算原 q=3 原引擎的根节点加权下界，并检查该测试通过。
2. 已完成原回执的“发出 proper 类次数”必须为零。于是从未递归进入选择了 proper 类的加权检查；其余失败原因均为几何、合法性或均匀总费用条件。
3. 只有满足上述两项的旧完整费用窗，才标为与 q 无关的排除。

按这个条件，**13 个共同分型可继承旧费用窗，只需检查新增费用窗；517 个共同分型必须同时补查旧窗中的新增差额带与新增费用窗；245 个新增分型需检查其完整候选费用窗。** 原引擎文件的 SHA256 保存在 `inheritance.json`，全部 775 个任务均有明确最低费用、最高费用及来源。每个任务仍标为 `pending`。

这里的 13 是已由所述充分条件认证的安全继承数量；不声称这是所有可能进一步提取的目标无关旧子域的最大数量。

## 从零复算清单与继承分类

`previous/` 为前驱完整证据树；`bias/` 为已完成的 q=3 主证据包。本包建议安装为 `q2_plan/`。

```text
python3 q2_plan/geometric_check.py --baseline previous --q3-proof bias --output /tmp/q2-plan --cap 12043
python3 q2_plan/check_inheritance.py --baseline previous --q3-proof bias --plan /tmp/q2-plan/profiles_q2.json --output /tmp/q2-plan/inheritance.json
```

需要 Python 标准库与支持 C++20 的编译器。两条命令已实际执行；输出与随包清单一致。主 q=3 证明和扩展区间证明不依赖完成此 q=2 计划。最大稳定区间以及 q=2 是否出现真实竞争表，仍未由此包解决。
