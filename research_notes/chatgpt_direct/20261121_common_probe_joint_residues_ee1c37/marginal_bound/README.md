# 九、十点类的统一边际费用下界

本包证明一个对**所有合法九点、十点消息类**都成立的不等式，不要求消息类属于某个截断候选库，也不要求它是母内类或非母内类。由此得到任意两母类位置的条件费用界，以及**恰有两个母内类的十二标签整表至少需要 9867 次补读**。

这里的母类是全部 250 个合法十三点类；一个类只要包含于某个母类，就叫母内类。母内类计数包括十点及更小的类，不能替换成“至少十一点的母内类数”。本包没有把条件下界 9867 宣称为十二标签的全域下界，也没有求出任一条件层的最优值。

## 1. 单类不等式与完整性

用原历史索引 \(x\in\mathbb F_5^3\) 表示 125 个旧历史。对集合 \(S\)，记

\[
h_{i,v}(S)=|\{x\in S:x_i=v\}|,
\qquad
\Delta_k(S)=\sum_{i=1}^3\sum_{v\in\mathbb F_5}
                 \max\{h_{i,v}(S)-2k,0\}.
\]

令 \(c(S)\) 是两个变换、125 种菜单的原生累计补读费用。则

\[
\boxed{\quad c(S)\ge557+3\Delta_1(S)\quad(|S|=9),\qquad
       c(S)\ge744+3\Delta_1(S)\quad(|S|=10).\quad}
\]

证明只需要一段有明确边界的完整有限核对。任一轴上，大小为 \(n\ge2\) 的集合满足

\[
\sum_v\max(h_{i,v}-2,0)
=n-\sum_v\min(h_{i,v},2)\le n-2.
\]

因此 \(\Delta_1(S)\le3(n-2)\)。九点类的右端不超过 620，十点类的右端不超过 816，费用更大的类自动满足结论。完整原生枚举在九点费用不超过 620 时输出 **14,344** 行规范种子，在十点费用不超过 816 时输出 **5,327** 行，共 **19,671** 行。复验器逐行重新核对原菜单合法性、精确费用和不等式，两个大小的最小整数松弛均为零。

这里的“完整”来自原生 `class_enumeration.cpp` 的全树遍历。费用上限只控制输出，不剪掉任何搜索后继。规范化不会丢类：在一个合法类中，选规范差最小的一对历史，平移并用坐标排列、独立变号和共同倍乘把它们化为 \(0,v\)。其余历史的原索引至少为自己的规范差，故均大于 \(v\)，于是出现在以 \(0,v\) 为前缀的有序分支。合法性、费用和 \(\Delta\) 都在这组变换下保持。规范种子可以重复表示一个轨道，重复不影响完整性。

原生菜单到禁三元组的约化及该仿射群是前驱研究的科学输入。本包按同一原始菜单重新生成 250 个菜单—变换选择和 47,000 个禁三元组，再作精确整数核对。没有使用浮点优化器或候选截断来证明本不等式。

## 2. 覆盖余集与搜索中间状态

设 \(a\) 个九点类和 \(b\) 个十点类不交地覆盖 \(U\)，令 \(k=a+b\)。逐纤维使用正部的次可加性，得到

\[
\sum_j\max(h_{i,v}(S_j)-2,0)
\ge\max\Bigl(\sum_j h_{i,v}(S_j)-2k,0\Bigr).
\]

故

\[
\boxed{\quad\sum_j c(S_j)\ge557a+744b+3\Delta_k(U).\quad}
\]

如果搜索中只知道一个必须由这些剩余类覆盖的集合 \(F\subseteq U\)，单调性仍给出安全下界

\[
\sum_j c(S_j)\ge557a+744b+3\Delta_k(F).
\]

因此可把已扣除所有剩余类基线价格后的费用余量，与 \(3\Delta_k(F)\) 比较。这个应用只在所有尚待分配的类均为九点或十点时使用；不能直接把十一点、十二点或其他大小的类套进这两个基线。

## 3. 两个大类的三个条件推论

每个完整十三点母类在每条坐标轴上的五个纤维人数为 \((5,2,2,2,2)\)。人数为 5 的坐标值组成母类中心。删去中心的十二点类费用为 1104，纤维形状是 \((4,2,2,2,2)\)；删去其他点的十二点类费用为 1116。

另有费用 1244 的 **proper 十二点类**，即不包含于任何母类的十二点类。它与中心删除类的每轴纤维形状相同，费用与几何身份却不同。其三个大纤维坐标组成的向量在本包中只叫“峰值坐标”，不把它称为母类中心。

### 两个完整十三点类

固定两个不交完整母类，剩余十个类全为九点或十点。由剩余 99 点可知，必须是一九加九十。设两母中心有 \(s\) 个坐标相同。每轴若中心坐标相同，补集的正偏差为 4；若不同，正偏差为 3。因此 \(\Delta_{10}(U)=9+s\)，总费用至少

\[
2\cdot1296+557+9\cdot744+3(9+s)
=\boxed{9872+3s}.
\]

### 一个完整十三点类与任意十二点母内类

固定母类 \(M_1\) 和一个十二点母内类 \(E\subseteq M_2\)，要求真实选择的 \(M_1\cap E=\varnothing\)。**不要求两个完整母类 \(M_1,M_2\) 不交。**剩余十个类全为九点或十点时，剩余 100 点迫使它们全是十点类。

逐纤维有 \(h(E)\le h(M_2)\)，所以

\[
h(U)=25-h(M_1)-h(E)\ge25-h(M_1)-h(M_2).
\]

若两母中心有 \(s\) 个坐标相同，仍有 \(\Delta_{10}(U)\ge9+s\)。记十二点类实际费用为 \(c_{12}\in\{1104,1116\}\)，则总费用至少

\[
1296+c_{12}+10\cdot744+3(9+s)
=\boxed{9867+(c_{12}-1104)+3s}\ge9867+3s.
\]

特别地，中心删除类达到这里的偏差恒等式，外点删除类也适用这个下界。完整父母相交的情况已包括在复验器的不交真实类枚举中。

### 一个完整十三点类与费用 1244 的 proper 十二点类

假设这两个实际类不交，剩余十个类为十点类。设母中心与 proper 类峰值坐标有 \(s\) 处相同。两个类每轴形状分别为 \((5,2,2,2,2)\)、\((4,2,2,2,2)\)，故 \(\Delta_{10}(U)=9+s\)，总费用至少

\[
1296+1244+10\cdot744+3(9+s)=\boxed{10007+3s}.
\]

本包从同一个原生完整枚举重建了全部 250 个十三点类、250 个中心删除十二点类、3000 个外点删除十二点类和 3000 个费用 1244 的 proper 十二点类，合计 **6500 个不同大类**，全部逐类重新核对原菜单。

## 4. 恰有两个母内类的整层下界

使用完整原生的“大小、是否母内、费用”目录，独立枚举 12 个非空类、总大小 125、费用基线不超过 9995、**恰有两个母内类**的所有大小分型，恰有 14 型。它们的基线价格依次为

\[
9840,9845,9912,9917,9922,9936,9961,9966,
9971,9971,9980,9985,9989,9994.
\]

只有前两型低于 9867。第一型是母内十二点加十三点、其余十个 proper 十点类；第二型是两个十三点母类、其余一个 proper 九点和九个 proper 十点类。上节分别把两型提高到至少 9867、9872。其余十二型仅靠单类最低费用已至少为 9912。大于 9995 的整表自动高于 9867，因此得到全域条件结论：

\[
\boxed{\text{十二标签且恰有两个母内类}\quad\Longrightarrow\quad c\ge9867.}
\]

同一目录也重建：费用不超过 10006 时，没有零母内类分型；一个母内类的唯一分型是十三点母类、一个 proper 十二点类和十个 proper 十点类。proper 十二点的下一档费用为 1376，已超出这个预算，故只能用 1244。上节的 10007 下界排除这唯一分型。

于是任何费用不超过 9866 的十二标签表，必须至少有三个母内类。这些类不必都达到十一点。本结论仍保留三个及更多母内类的覆盖问题，不能据此直接把十二标签全域下界提高到 9867。

## 5. 复验入口、来源与实际回执

`bindings.json` 固定原生枚举、原菜单核对器、目录枚举器、观测生成器以及本包各个输入的 SHA-256。`low_cost_seeds.txt` 是完整 1,495,322 行原生输出的精确投影。`large_class_seeds.txt` 有 112 行；为得到其中费用 1244 的 proper 十二点类，仅将原枚举的十二点**输出**上限从 1230 提高到 1244。搜索遍历、费用、合法性以及其余输出上限都保持原状。

扩展枚举输出过滤回旧上限后，必须逐字节恢复原来完整种子文件的 SHA-256；其额外 48 行都是费用 1244 的十二点规范种子。复验器还重跑完整原生母内／proper 费用目录，而非仅相信本包的 14 型列表。

在前驱包目录名为 `delivery` 时，完整独立复验命令是：

```sh
python marginal_bound/verify.py --previous delivery --full --output marginal_verification.json
```

本包 `verification.json` 是实际运行该完整模式得到的终局回执，包含所有精确检查和条件层结论。完整模式在新临时目录生成观测、编译并运行两个原生枚举器，不依赖工作目录的银行文件或搜索进程。

复用已固定的种子、只重新核对本包全部消息类和算术结论，可运行：

```sh
python marginal_bound/verify.py --previous delivery --output marginal_quick_verification.json
```

若保留原始 46 MB 种子文件，可增加 `--seeds /absolute/path/to/seeds` 校验其全文件摘要和精确投影；若保留扩展完整种子，可增加 `--extended-seeds /absolute/path/to/extended_seeds`，同时核对旧种子摘要与大类投影。快速模式不会把读取既有证书称为重新运行完整枚举。
