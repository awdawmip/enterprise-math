# 四台独立五环服务一次共享补读：显式64类证书

日期：2026-11-13。状态：作者证明与完整有限检验（非正式数学审定）。研究接续：`research_notes/chatgpt_direct/20261113_extremal_repair_66978b96/packing/proof.md`；原有活动 `RA-9498779795B8B15983061F37` 作为历史来源，本轮活动以实际新会话登记回执为准，不冒称旧会话身份或 CLAIM。

## 定理

在四台独立晚选恒等或模5倍增的五环服务中，编码须在晚选规则与菜单确定之前完成。恢复方获知全部首次交付后，总共允许至多一次对某台原端点槽的真实布尔读取。令 `M(4)` 为能正确服务全部 `5^4=625` 种旧联合历史所需最少消息种数。在此接口下：

```
53 = ceil(625/12) <= M(4) <= 64;
ceil(log2 M(4)) = 6;
full-history fixed width = 10 bits; saving = exactly 4 bits.
```

64是一个显式可行消息数；尚未证明消息数最优。

原有证明（`research_notes/chatgpt_direct/20261113_independent_repair_66978b96/laminar/proof.md`）：一个消息类能用至多一次原端点读取服务所有可能的菜单和独立改写，当且仅当其坐标/取值块两两不交或嵌套（laminar）；四坐标每类最多12段历史。故至少53种消息，即至少6定长位。

## 显式编码表

四元历史为 `(t,x,y,z)∈F_5^4`。把三元历史编码为 `v=25x+5y+z`。对角线 `D={(a,a,a):a∈F_5}` 的五个编码是 `0,31,62,93,124`。

三维对角线补集分成以下**互不相交**的12个层状类，每类10点。下面第j行的下标从0开始：

```
j= 0:   1,  2,  3,  9, 14, 24, 40, 65, 90,115
j= 1:   4, 29, 54, 95, 96, 97, 98,109,114,119
j= 2:  16, 27, 30, 33, 34, 37, 47, 66, 91,116
j= 3:   6, 28, 38, 43, 48, 55, 57, 59, 81,106

j= 5:  20, 21, 22, 49, 74, 99,103,108,113,118
j= 6:   5, 10, 15, 45, 70, 76, 77, 78, 79,120
j= 7:   8, 13, 18, 23, 25, 50, 75,101,102,104
j= 8:  11, 26, 41, 46, 61, 80, 82, 83, 84,111
j= 9:  12, 35, 36, 39, 53, 58, 68, 73, 87,112
j=10:  17, 42, 51, 56, 60, 63, 64, 71, 92,117
j=11:  19, 44, 69, 94,100,105,110,121,122,123
```

若 `(x,y,z)∉D`，唯一的类下标为j，编码消息为 `12t+j`，共60种消息，每类10点。因t恒定而直接继承三维层状性。

若 `x=y=z=a`，改由如下5行×5列四颜色网格编码（行t，列a）：

```
t=0: 0 3 3 0 0
t=1: 3 0 2 1 2
t=2: 3 1 0 2 1
t=3: 1 0 1 2 3
t=4: 2 2 0 1 3
```

消息为 `60+color[t][a]`。每个颜色的 `(t,a)` 位置形成二部星形森林，任意两个坐标取值块不发生相交却不相含；因三个坐标x,y,z的值都等于a，提升为四维后仍层状。四特殊消息分别容纳7、6、6、6点。

得到 `60×10+7+3×6=625` 个唯一归属历史，64种全非空合法消息，且不增加持久三元库存、不借未来信息或免费跨台询问。

## 有限检验与证书

本轮执行两个相互不同的精确检查：
- 编码证书：生成全部625个历史，验12个十点三维类恰覆盖对角线补集、逐消息验所有坐标取值块相离/嵌套；输出 `PASS messages=64 histories=625 all_laminar=True message_size_histogram={6:3,7:1,10:60} bits=6`。
- 原端点菜单枚举：每台10种不同无序端点对，四台共 `10^4` 种菜单，对64种消息逐一分组检查“首次在边内/边外”状态固定后，至多两种不同后续交付，可由其中一台真实端点区分；共 `64×10^4=640000` 个消息—菜单组合，全部通过。

同轮交付脚本 `n4_four_bit_certificate.py` 和 `n4_endpoints_exhaustive.py`；证书用整数及有限集合比较，未使用浮点或抽样。第二项核验是当前端点接口的穷举，未声称已经重新运行完整受保护原BRC指令内核。

## 当前连续研究前沿

四维的最优**位数**已完成。剩余有限边界：n=9与n=12能否同样达到四位节省；三台共同变化时一读需要11还是12种消息；以及在已知64类证书基础上，M(4)最少消息种数能否从64进一步降低。科学类型为有限消息编码与受限真实端点观察，不将其直接提升为P000原生空间或其他数轴定理。


## 这份构造中的局部最小性

固定上述60个 `t` 固定的十点类不改变，将25个对角线状态 `(t,a,a,a)` 单独分组。每个合法消息在 `(t,a)` 网格中必须是星形森林：坐标取值块相交而互不包含，等价于出现同色的三个L形格点，即二部图里一条长度3的路径。任意一色若只有一颗非平凡星，最多有5条边；若有至少两颗星，图最多10个非孤立顶点，边数=`顶点数-分量数`至多8。三色总计最多24格，不能覆盖25格。本轮四颜色表达到最少四色。

另将5个对角线点分别尝试加入12个旧三维十点类，共60种直接吸收，经精确层状检验全部失败。这给定了具体分组和有限变更类型的局部刚性；它不证明任意四维编码需64种消息。
