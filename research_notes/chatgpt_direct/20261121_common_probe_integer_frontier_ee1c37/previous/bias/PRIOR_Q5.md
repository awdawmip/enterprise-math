# 十一标签在变换概率偏置下的严格稳定区间

本目录延续前一发布包的三台共同晚选恒等／倍增模型。给定任一种变换，125 段旧历史与 125 组公开菜单等权；消息先于晚选变换，恢复时全体合计至多补读一个原端点。表的合法性仍要求覆盖全部两种变换。所有分区数均不区分十一种标签的重命名。

## 结论

设恒等变换的概率为 p，倍增变换的概率为 1−p。在严格稳定的闭区间

\[
\boxed{\frac{601}{1503}\le p\le\frac{902}{1503}}
\qquad
(0.3998669328\ldots\le p\le0.6001330672\ldots)
\]

上，十一标签的全局最低补读概率恰为

\[
\boxed{\frac{5646-54|2p-1|}{15625}}.
\]

p=1/2 时恰有原先分类的 8000 张均匀最优分区取等；区间内其余每一点，包括两个新端点，恰有其中 4000 张取等。p 偏向哪一种变换，就采用对该变换较省读的方向。这一结论不要求整张表具有任何仿射对称性。最大稳定区间仍未确定。

本轮的几何排除首先完整证明 2/5≤p≤3/5。它包含 393 个危险分型，按分型计 1964831 个规范母类族次、124830004 个搜索节点。所有终端覆盖数与竞争表数均为零。随后只用整数奇偶性及单类谱动态规划，把两个端点闭合到上面的更精确分数。

## 成本和差额的精确判据

对任一十一标签表，记恒等与倍增条件下的总读数为 I、D，令 C=I+D、A=|I−D|、r=|2p−1|。其补读概率至少为 (C−rA)/31250。原 8000 张均匀最优表满足 C=11292、A=108，分别有 4000 张实现 (I,D)=(5592,5700) 及其反序。前一发布证明，任何其余十一标签表都有 C≥11301。

原菜单的完整单类谱及大小分配给出全域上界 A≤1611。在 r≤1/5 的范围，其他表想达到或优于上述最低概率，必要条件是

\[
A\ge108+5(C-11292).
\]

C≥11593 时，此条件已被 A≤1611 排除。因此本轮重新检查 C=11301,...,11592 的所有大小、嵌入性及确切成本分配；没有沿用旧的 11350 截断。只有 393 个分型仍可能满足必要条件，它们各自的最后危险总价不超过 11436。

完整的十一点及十二点例外类清单的最高成本分别为 1376 和 1560，原菜单重算确认这就是相应类型的全谱最大值。本轮复用了这两个完整清单。较小例外类继续用原菜单禁三元组直接生成。

## 加权剪枝和母类容量条件

十三点合法类称为母类，不能嵌入任何母类的标签类称为例外。先按例外和嵌入类的大小列出所有候选分型，沿用前一发布的无条件容量及相容条件，再穷尽它们可能使用的全部母类位置。规范化只消除 12000 个仿射变换造成的重复，并未要求候选整表固定于任何非平凡变换。

加权分支程序以 q=5 为参数。已选例外类逐类累加 q c−|d|，其中 c 是该类两种变换总成本，d 是其带符号成本差。未选例外与嵌入类分别取完整单类谱上 q c−|d| 的最小值。这些数的和是整表 qC−|I−D| 的下界；只有当下界严格超过 q·11292−108 时才剪枝。终端仍重新计算完整分区的 C 与带符号差总和，并保留可能取等的边界。

有一个专门的额外成本不能泛化处理：当嵌入部分有六个由完整母类或删一点母类形成的大类时，旧证明迫使至少一个十二点类删去外点。删中心与删外点十二点类的成本分别是 1104、1116，而且两种的变换差都为零。因此在此特定情况下，加权嵌入下界可再加 12q。这里使用了单类谱中这两类差额为零的事实，并未对任意成本下界直接乘 q 后另行加差额。

母类 Hall 必要条件进一步检查：任取 r 个所用母类，它们去掉已用历史后的并集至少容纳 r 个最小嵌入大小之和。嵌入类究竟对应哪一个母类仍在终端完整枚举，故这个条件只作必要剪枝。所有大小、成本及差额均用整数计算。

前 108 个已完成分型保留原加权程序，余下 285 个使用加入 Hall 条件的程序；固定分配保存在 `legacy_profiles_q5.json`。两个源文件及逐分型计数均保留，完整复验按相同分配执行，避免把恢复计算误说成从未中断的一次运行。

## 核心区间内的严格间隙

这一段仅适用于 r≤1/5，即 2/5≤p≤3/5。

任意不属于原 8000 张均匀最优分区的表，令 t=C−11292、d=A−108。几何排除给出 5t−d>0。由于 C 与 A 同奇偶，5t−d 是偶整数，故至少为 2；同时 t≥9。因此

\[
(C-rA)-(11292-108r)
=t-rd\ge t(1-5r)+2r\ge9-43r.
\]

其补读概率至少比最优值高

\[
\boxed{\frac{9-43|2p-1|}{31250}}.
\]

在 p=2/5 或 3/5 时仍至少高 1/78125。这一间隙针对原 8000 张之外的所有表；原 8000 张中方向不合适的一半在 p≠1/2 时也严格较差，但差额另为 216r/31250。

## 更精确闭端点的代数推导

对可能竞争的其他表只需考虑 d>0。已有 t≥9、d≤1503 及 5t−d≥2。若 t≤300，则

\[
\frac{t}{d}\ge\frac{t}{5t-2}\ge\frac{300}{1498}>\frac{301}{1503}.
\]

若 t≥301，则 t/d≥301/1503；等号只可能是 t=301、d=1503，即 (C,A)=(11593,1611)。对这个唯一候选，总价严格固定为 11593 的 2289 个大小／嵌入分型动态规划给出 A≤977。因此候选被排除，每张其他表在 r≤301/1503 上都严格较差。

换成 p 即得闭区间 [601/1503,902/1503]，两个端点也没有额外取等表。这里没有把上一段的显式间隙公式外推到 r>1/5 的小段新增区间。

## 复验

将完整前一发布包放在本目录同级的 `previous/`。从本目录的父目录运行：

```text
python3 -B bias/check_weighted.py
python3 -B bias/weighted_replay.py --denominator 5 --jobs 2
python3 -B bias/check_endpoint.py
```

第一项把 C++ 的带符号成本与独立 Python 原菜单评分逐类对照，覆盖六张有已知方向成本的表、68 个消息类。第二项从原菜单重新生成单类谱、所有分型、完整大例外清单、母类位置及 393 个覆盖判定，并核对 `result_q5_weighted.json`。第三项重新计算唯一代数端点候选的上界并核对 `endpoint_result.json`。依赖为 Python 3 和支持 C++20 的编译器；原程序依赖均在随附前一发布包内。

只有显式加 `--resume` 时才复用 `completed_q5/` 的已完成分型回执；默认命令重算全部分型。复验入口中的固定旧／新算法清单是已完成计算的真实分配。`result_q10.json` 和 `result_q26.json` 另保存本轮较早完成的两个区间，最终结论以上述 q=5 结果及端点排除为准。
