# 保留三个固定类后，余下九个十点类的精确补全

取上一版三阶对称十二标签见证的两个十三点类和一个九点类，将这三个指定点集完整保留。它们共读 3,192 次。其余 90 个历史任意分为九个十点类，对这些新类不要求任何对称。该问题的最优总读数是 9,996，取等时恰有两个不同的无标号划分，二者均自动恢复三阶对称。

要达到或改善旧表，每个十点类至多读 6,804−8×744=852 次。从原菜单逐点生成区域内所有这样的类。weights.json 是一组以 1,000 为分母的整数点权。逐行检查点权和不超过其成本的 1,000 倍；将整表的总预算减去九十个点的权和，得到非负成本差额之和的预算。求解时先选一个覆盖选择最少的点，分支遍历全部选择，递归选所余最少的点。对每个点用能覆盖它的最低单类差额作下界，把各点下界相加再除以十。固定一个点后分八片，完整记录每种补全，点集与成本再按原菜单复算。整数点权仅用于加速，程序直接验证其全部不等式。
