# 总费用 10,148 且完整仿射稳定子恰为二阶的十二标签表

`groups.json` 给出模五三元组上的十二个消息类，点号为 25x+5y+z。其唯一非恒等仿射对称是中心反演 (x,y,z) ↦ (−x,−y,−z)。

从上轮四阶见证出发，保持两个 22 点支持，以及支持以外的所有消息类。每个支持含 11 对相反点，原来由两个 11 点消息类交换覆盖。任选每对相反点中的一点作为第一类，第二类由中心反演确定。以其中一对的方向固定两个标签的次序，穷尽每个支持的 1,024 种拆分。原菜单的禁三元组检查表明，每个支持恰有两种合法拆分，每一种的单类费用都是 944 次。两处独立选择给出四张 10,148 次的表。

逐一检查全部 12,000 个保成本仿射变换，四张无序分区的稳定子阶依次为 4、2、2、4。两张二阶表在同一仿射轨道，所以这一轨道恰含 6,000 张彼此不同的历史分区。表内标签的顺序不参加计数。原程序逐项复核 `groups.json` 的全部 31,250 个输入。

复验命令为 `python3 -B replay.py --round3 /path/to/round3/published --c4 /path/to/round5/c4/groups.json`。第一个输入目录需含 group、previous/bounds 和 original；第二个输入是上轮四阶见证。
