# 十三升十四至少要换十个旧类

十三标签全域最优表的费用为 8,721，所有取等表同属一个仿射轨道。固定这个轨道的代表即可。十四标签最优表费用为 7,660。单类最低费用的整数分配下界恰好取等，且只容许一个最低费用八点类和十三个最低费用九点类。旧表只有九个九点类可能保留。

从原菜单重建全部最低费用的八点和九点类，分别有 28,000 和 24,000 个。依次选定九个旧类中的任意四个，扣除所选各点。搜索用一个八点类和余下的九点类覆盖尚待分配的点。每次按剩余行中选择数最少的点或八点类约束分支，只继续考虑与已选行不交的类。126 种选择、95,668,112 个搜索节点全部无解。任何保留五个或更多的方案自然也会保留其中四个，故至多保留三个。另一方面，witness14.json 是与旧表恰好共用两个完整类的十四标签最优见证。最少更换数因此为十或十一，本证书保留两种可能。

从包根运行 python3 -B replay.py --only overlap。
