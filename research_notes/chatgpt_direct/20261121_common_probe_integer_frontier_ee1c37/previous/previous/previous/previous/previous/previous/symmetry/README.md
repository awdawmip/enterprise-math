# 十三种消息的中心反演对称最优表恰有一个仿射轨道

固定原点，要求反演将每个消息类映为整表中的一个类。总成本最小为 8,728，恰有 24 张最优分区（不计消息重命名）。固定原点的 96 个保成本线性变换作用在上一轮的 8,728 证书上，刚好产生这 24 张。证书只有一个反演中心。因此允许任选中心时，恰有 3,000 张最优分区，构成同一仿射轨道，每一张的稳定子阶为四。

设单类大小为 s，成本为 c。上一轮完整单类枚举与整数下界给出所有可能满足 c + D(125−s,12) ≤ 8,728 的类型。枚举其全部仿射像。满足 125 点、十三个标签、上述成本上界的类类型多重集共有 42 种。

中心反演在点集上的轨道是原点和 62 对相反点。在消息类上的轨道只有两种。一种是保持自身的类。另一种是与相反类不交的一对，其并集才作为一个整体进入精确覆盖。把这两种情形都压缩到 63 个点轨道上。若不同的无序消息类对得到相同的压缩集合，保留其重数。所有奇数大小的固定类都包含原点，且含原点的固定类必须为奇数大小。每个可行表因此有且仅有一个奇数大小的固定类。42 种类型多重集只留下 15 种固定类与成对类的配额。

以唯一的奇数固定类为锚，枚举其在 96 个原点线性变换下的轨道，计数时乘以轨道大小。在每个余集上按待覆盖的一个点轨道或只需一份的稀有类型分支，配额、互不相交和全域覆盖都是整数条件。每个分支选法唯一，每个压缩块按其重数计数，共访问 3,334,401 个搜索结点。所有总代价不超过 8,728 的解均为 8,728，同一中心下计数 24。

运行 `python3 -B inversion.py --older /path/to/preceding/proof` 和 `python3 -B orbit.py --older /path/to/preceding/proof`，输出应分别与 inversion.json、orbit.json 完全相同。上一轮的证明目录必须包含 curve/ 和 bounds/。前者重新编译完整的单类枚举器，后者从上一轮实际表读取全部点。证明适用于整表有中心反演对称的分区。

## 相邻标签数的局部重分

8728 成本证书如保留九个类、任取四类压成三类，或保留八个类、任取五类压成四类，分别 715、1287 种选择均无解。10147 成本的十二标签证书任取四类压成三类亦无解，核对全部 495 种选择。直接将若干原类的并取出，按每点可进入的类数最少者分支，颜色首次出现顺序固定，以消除消息重命名等价。与两个已有点构成原观察模型禁止三元组的位置不能加入。每个类上限为 13 点，候选容量和不足时直接剪枝，搜索无时间或结点上界。运行 `python3 -B packets.py --older /path/to/preceding/proof` 与 packets.json 比较。
