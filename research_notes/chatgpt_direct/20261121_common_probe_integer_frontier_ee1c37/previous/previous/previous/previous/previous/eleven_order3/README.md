# 三阶对称的十一标签表最少恰好补读 11,292 次

任意三阶仿射变换都有不动点（将一个三点轨道作平均），可在三台历史上归一化为循环置换坐标，允许换生成元。商空间有 5 个不动点、40 个三点轨道。每个非固定标签以三类成组，其代表恰从支持中的每个三点轨道选取一点。

先假设存在累计费用低于 11,292 的表。此前对十三点类的完整分层排除表明它最多有两个十三点类。单类费用下界与其余八个标签的尺寸约束说明，三元标签轨道的代表只能有 9、10、11 或 12 个点，相应费用上限为 691、875、1,059、1,242。原菜单的单类枚举器重建这些形状，再对仿射像取三元轨道，将相同支持归并到其最低成本。固定标签类则由五个单点轨道和四十个三点轨道的并直接生成，对每个加入的点检查禁止三元组。

0、1、2 个三元标签轨道时，先取固定类，优先覆盖尚未覆盖的不动点。仅按确定可行的容量和费用下界剪枝。固定类取毕后，分别直接检查无余点、在完整的三元支持库中查找补集、或者沿已有支持配对其余集。3 个三元轨道时只有两个固定类，这两个类之间不交且涵盖全部不动点。将合格固定类对按支持和其仿射等价去重，最终有 83 个余集。完整列举前两个三元轨道的支持，第三个由补集唯一确定。四种标签循环型均未出现严格改善。

运行 `python3 -B replay.py --older /path/to/round2/delivery --group /path/to/round3/group` 可从原菜单重建搜索并复算 `result.json`。已有十一标签表恰好达到 11,292。直接读入该表，逐类验证合法性和费用，并检查全体 12,000 个仿射映射。其稳定子为六阶循环群，含两个三阶元素。例如 (x,y,z) ↦ (−y,z,−x) 固定标签 0–4，按 (5 7 9)(6 8 10) 置换其余六个标签。因此有三阶对称的十一标签表的最小累计费用恰为 11,292。有六阶对称的族也有相同精确最小值。
