# 新表对逐平面仿射变形的刚性

考虑十二标签、成本 9,996 的三阶对称见证。以第一坐标为层，将五个坐标平面任意重新排列，并在每层内独立施加二维仿射双射。对每段历史施此双射、沿用原来标签。总共有 120×12,000⁵ 个可能的映射。使整表继续合法的映射恰好 **4,000 个**，每一个均属于原有的保成本仿射群。

完整枚举的每一层有 |GL(2,5)|×25=480×25=12,000 个双射。考虑平行于层的全局平移和另两坐标的带符号置换，它们生成 200 个保成本变换，在第一层的仿射映射上以左乘自由作用。故可先把这个映射的常数项归零，并把其矩阵在两个行的分别反号和交换下取最小代表。每个等价类恰有 200 个实际映射。层的 120 种排列都参加搜索。逐层加入历史点后，只要同一消息类含有原菜单的禁止三元组即可回溯。每个完成解重新从原菜单计算补读总数。归一化后恰有 20 个可行映射，全部成本 9,996。

反过来，已知保成本仿射群内保持第一坐标平面族的变换有 125 种平移与 32 种线性部分，共 4,000 个；它们当然每个都合法，恰好占满上述计数。此处计的是历史双射，允许同一无标号分区由两个双射生成。由于见证的三阶对称对三条坐标轴循环置换，对任意一个坐标轴选层结论相同。
