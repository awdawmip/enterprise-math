# 三阶对称的十一标签等号

至多有两个十三点类时，三阶对称十一标签表在 11,292 次以内无法覆盖全部历史。证明把预算内可能出现的三元标签组按支持归并。移动的十三点类一出现就有三个，因此这个分层中十三点类必为固定标签。每次选择固定类时跟踪已放置的十三点类数，合并余集时也保留此计数。移动标签组至多有三个。当有三个时仅剩两个固定标签，天然满足十三点类限额。

预算恰含等号时，单个移动类的大小为 9、10、11、12，成本上限为 692、876、1,060、1,242。完整生成 2,872,580 个不同移动支持，分别检查移动组数为 0 至 3 的所有情况。输出记录在 result.json。

三、四、五个十三点类另由分层证书处理。groups.json 是其中五满类的 11,292 次见证，稳定子为三阶；它不在本目录排除的至多两个最大类范围内。
