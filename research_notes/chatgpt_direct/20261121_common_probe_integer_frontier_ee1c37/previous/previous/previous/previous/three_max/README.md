# 十一标签中恰有三个十三点类时，成本至少为 11,301

此前的 15 个仿射位置代表及整数点权来自 previous/previous/previous/strata/。固定三个原样使用的十三点类后，还有 86 段历史需要分给八个非空消息类，每个类的大小至多 12。逐菜单重建禁三元组及歧义掩码，完全生成所有合法的剩余单类，并核对其整数缺额非负。缺额使用此前点权给出的 $p+1000c-\sum w_x$，其中 $p$ 在该位置固定。所有剩余类的缺额和等于整表预算的线性函数。

若总缺额上限为 $D$，按缺额从小到大、同缺额按点集掩码排序，则除最后一类外，任一被选类的缺额至多 $D/2$。其余类用完整目录分支，最后一类由补集直接检查原合法性及费用。每种大小的最低缺额在完整枚举中得到，按剩余点数及类数取整数动态规划下界。搜索总预算 11,300 时，15 种位置无一补全。故恰好三个十三点类时成本至少 11,301。

依赖目录应含 strata/。从包根中相应路径传入 python3 -B replay.py --older /path/to/round2/delivery。复验器从菜单重建每个位置的观察矩阵并核对精确回执。
