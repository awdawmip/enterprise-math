# 对上一版轨道枚举的修正

旧程序用 16 个八位查找表加速 125 位点集的仿射像，递推项读入了未显式初始化的零号表项。栈上创建某些变换时，这个数可能非零，合法的轨道支持因而可能漏列。检查新十二标签见证的正规化子像时，原程序遗漏了一个成本为 747 的十点类支持，因此该数值缺陷实际影响了候选计数。

本目录把四处相关实现的表全部置零，再从原菜单重新执行此前的完整搜索。三阶的移动支持数由 2,616,243 修正为 2,810,640。平方为中心反演的三种四阶类型，四元支持数由 501,659、517,503、546,360 修正为 519,906、539,704、566,817。另三种四阶类型相应由 71、55,774、44,591 修正为 72、64,660、52,734。克莱因四元群的本次回执与此前记录逐字段相同。

在每个扩大后的候选集中，原来的费用排除与无条件不可行结论均已重新得到。本轮十二标签三阶证书直接逐点计算仿射像，另用对固定子群正规化子的闭合性核对取等计数。
