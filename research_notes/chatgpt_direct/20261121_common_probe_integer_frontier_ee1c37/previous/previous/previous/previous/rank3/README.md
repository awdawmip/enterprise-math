# 十二标签在任何成本下均不容许初等八阶对称

任意阶 8 初等阿贝尔仿射群在五元域有公共不动点，平移后落入 96 阶单项式线性群。全部三元线性对合的直接枚举，按两两交换、独立筛选，得到四个子群，分两种共轭类型。第一型为三个坐标各自独立反号。第二型的代表由交换前两坐标、前两坐标同时反号以及第三坐标反号生成，共有三个共轭像。

两型的历史轨道大小均为 1、2、4、8，相应个数为 1、6、12、8。大小 8 的标签轨道只能在八个自由历史轨道上各取一点，其八个标签最多覆盖 64 段历史，其余四类至多再容纳 52 段，仍不足 125。因此只须枚举大小 1、2、4 的标签轨道。若一个代表标签的稳定子为 H，它须从每个涉及的历史轨道中恰取一整个 H 轨道，而且该历史轨道须被分成恰好 [G:H] 个 H 轨道。枚举这些选择，逐点检查原生禁止三元组。两型包括 5,163 和 4,081 种不同标签轨道大小加历史支持，按所用历史轨道的四种数目与标签数分成 68 和 69 种。每种保留最少读数，任取重复、用掉十二个标签且填满四种历史资源的整数动态规划给出下界 10,764 和 10,666。接着用实际支持给 27 个历史轨道作不交覆盖。每次选剩余可用标签轨道最少的一个未覆盖历史轨道，逐项覆盖。若剩余标签和历史轨道的四种容量不能用签名整数配额满足，剪掉此枝。31,250 次是全部合法方案的成本绝对上限。在这个预算下两型分别访问 431 和 1,623 个结点，全部排空。因此任何合法十二标签表的稳定子都不可能含八阶初等阿贝尔子群。在每个非恒等元素最多只能为对合的严格改善预算内，稳定子至多为克莱因四元群。
