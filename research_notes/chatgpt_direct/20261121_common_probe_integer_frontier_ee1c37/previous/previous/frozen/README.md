# 完整保留旧标签时，各个新预算的精确最少读数

发送方增加标签，同时要求从新标签可以无损还原先前的标签，等价于每个新类都是某个旧类的子集。对一个已给定的旧类 C，先从原菜单计算每个子集的补读次数。在每个待划分的子集 S 中固定编号最小的历史，枚举含此点的第一个子类 A，再递归划分 S 去掉 A 后的部分。用整数动态规划求出把 C 完整分成 j 个新类的最低成本，同时记录一个取等分区。消息合法性对取子集封闭。Python 复验器直接用原菜单逐个重算取得表内每个最低值的分区，并在各旧类之间用新标签总数作一次整数分配。

冻结表包括三个十一标签取等轨道的代表、9,996 次十二标签对称最优代表及 8,721 次十三标签全域最优代表。每种旧表的全部新预算精确费用保存在 result.json。本分组自身只使用所列轨道；全域取等分类的适用范围见包根报告。
