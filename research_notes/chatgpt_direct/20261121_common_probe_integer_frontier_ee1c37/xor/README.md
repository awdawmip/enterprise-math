# 三个基本集合的异或仍不能排除五份精确分数覆盖

本目录的结论属于既有费用9,858、固定两个删中心核心的四类型问题。自由域有101个历史，须用四种类

\[
(9,557)^2(10,744)^5(11,936)^2(11,944)
\]

覆盖。五份有理点与完整星团约束的核验见同包 `integer_cuts/full_system` 及其 `verify_combined.py`。本目录没有把有理点当作整数分区。

## 整数必要条件

设H是自由域的一个子集，a为四种类型的0/1系数，类型数量n=(2,5,2,1)。对每个候选类C，令

\[
b_C=(|C\cap H|+a_{t(C)})\bmod2,
\qquad r=(|H|+a\cdot n)\bmod2.
\]

整数分区必使\(\sum_C b_Cx_C\equiv r\pmod2\)。若r=1，则非负整数和至少为1，故

\[
\sum_C b_Cx_C\ge1.
\]

这里考虑的H，是至多三个基本集合的对称差。基本集合包括31种归一化非零模五线性形式的155条仿射纤维与自由域的交，以及101个单点，共256个。另包括空集。每个H检验全部8种令r=1的类型系数。

## 精确结果

五份有理点全部通过。每份检验

\[
8\left(1+\binom{256}{1}+\binom{256}{2}+\binom{256}{3}\right)=22,371,336
\]

个索引条件，五份合计111,856,680次。这里计的是索引检查次数；不同索引可能给出同一不等式。五点同时通过同包已经精确验证的全部完整星团约束和“任意平行纤维并集加类型系数”的奇偶族。

原先的第4点会被同一程序拒绝：两个基本纤维的异或，配类型系数(1,0,1,1)，给出

\[
\frac{24224479417132626104621409029}{27961409112557999812771344058}<1.
\]

该条件与63点平行纤维并集的旧分离等价。反例保存在 `old_point_counterexample.json`，可检验验证器确实识别这项违约。

## 没有浮点容差的核验

先把每个正权乘以\(2^{60}\)，再向下取整。对每一个割，用这些整数计算的和均为真实左端乘以\(2^{60}\)的下界；达到\(2^{60}\)便已证明该割。其余条件以有理点的公共分母进行精确整数计算。五份点仅分别有108、102、106、107、106个条件需要这一步，它们全部恰好等于1。

公共分母最大182位。Python入口要求其不超过250位，并精确检查类型总权重为(2,5,2,1)，总权重为10；因此所有精确非负和小于\(10\cdot2^{250}<2^{254}\)。C++程序用四个64位字实现256位加法、比较，并检查进位溢出。全过程不使用浮点数，也不需要优化器或外部大整数库。

从新包根运行：

```text
python3 -B xor/verify.py --witness-dir integer_cuts/full_system --parallel-module integer_cuts/parallel_family.py --work /tmp/common_probe_xor --output /tmp/common_probe_xor_result.json
```

验证旧第4点的命令应返回退出码1，并输出上述严格小于1的分数：

```text
python3 -B xor/verify.py --witness-dir previous/fractional/next_cuts/full_system --parallel-module integer_cuts/parallel_family.py --work /tmp/common_probe_xor --output /tmp/common_probe_old_point.json --frames 4
```

本结论说明这一明确的奇偶约束族仍留下精确分数覆盖。它没有排除所有奇偶割，更没有声明模三及其他余数条件无效；同包的模三证书恰好展示了更强的观察条件。
