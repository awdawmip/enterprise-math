# 五个母内类且proper总偏差为零时的父母配置归约

2026-11-21。此处是原历史观察编码内的一个有限必要条件分类；不声称已排除费用9,866，也不将父母配置可行视为整表可行。原生对象和X6观察依据继承主报告。正式独立 Review 为 `NOT_REVIEWED`。

设十二标签整表恰有五个母内类，其余七个proper类的总纤维正偏差为零。每个proper类在每条坐标取值纤维内至多有两点，七类至多覆盖14点。因此五个母内类合计必须在每条25点纤维内覆盖至少11点。

为每个母内类选择一个包含它的完整十三点父母类。一个母类的单轴纤维人数为 `(5,2,2,2,2)`。如果某条纤维没有父母中心，五个父母类在该纤维的并至多含10点，矛盾。所以每条轴的五个中心值恰好各出现一次；该结论允许父母类相交，且对任意这样的父母选择都成立。

完整原生目录的250个母类在每个中心恰有两个方向。平移和共同倍增保持该目录，且共同倍增交换原点处两个方向。选一个父母，将其中心平移为零并固定方向后，其他四个中心可写成

\[
(i,\pi(i),\sigma(i)),\qquad i=1,2,3,4,
\]

其中π、σ分别为1至4的排列。四个非锚父母各有两个方向，所以只需处理

\[
4!^2\,2^4=9,216
\]

个带锚配置。这是一个覆盖全部情况的规范化枚举，并非全部仿射轨道的去重计数；没有假设整表自身对称。

对每个配置取父母并V，逐一检查全部15条纤维的必要条件 `|V∩H|≥11`。恰有924个带锚配置通过，分布为：

若所选五个母内类的大小和为s，实际类两两不交，还必须满足 `|V|≥s`。例如s=60、59、58、57时，剩余带锚配置分别至多144、264、504、924个。这仍只是父母级必要条件；选择实际子类及覆盖余集的工作保留为下一步。

`replay.py` 从继承的完整250母类文件重新确认纤维形状、每中心两个方向、全部平移和倍增闭性，然后重新执行9,216个配置的整数计数。已实际执行的全分类在 `result.json`，包括924个幸存配置的完整掩码。

