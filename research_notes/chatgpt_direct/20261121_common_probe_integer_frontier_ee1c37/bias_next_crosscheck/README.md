## 任意合法小类与全费用量词

逐源核对 `cover_hl.cpp`、其五种大小限制变体及 `cover_hlk.cpp`。小类枚举已移除 proper 限制，也没有差额限制；保留的费用判断属于覆盖预算检查。母内尾类只限定大小及承载母类，最终穷尽所有共享点归属，再核算实际原菜单费用。`biasQ` 在这 25 个应用中全为零，额外偏置过滤没有生效。

原搜索以母类并集外的必占点为枢轴。移除小类 proper 限制后，其完整性需要另行说明。设母内大小多重集为 E，母类并集为 U，剩余 P 类总大小为 s，尚未覆盖的母并外点数为 n。则

\[
d=s-n\le |U|-\sum E\le 13|E|-\sum E=:D_E.
\]

每选定一个 P 类，d 只会减少其在 U 内的点数。所有 25 个形状都满足 `D_E < min(P 类大小)`，所以任一有效剩余类必含母并外点；原枢轴枚举及 `required = size-d` 不会遗漏完全合法但母内的小类，也不会在存在合法后继时触发“没有外点”的异常。这一严格不等式已由本检查程序逐行验证。

E 中每类至少 11 点，两个这样的不交类不能由同一 13 点母类承载，因此所选承载母类互异。所有形状另满足 `sum(E) > 13(|E|-1)`，故 `union.cpp` 达到母并目标时不可能尚未选满指定母类数。原完整母类枚举和 `frame.cpp` 的保解规范化适用；作者回执已经重新生成相应框架集，本检查核对了其完整符号范围和实际结束位置。

## 必要条件方向与独立整数复算

对给定大小/费用谱，每类最大绝对差额为 m，实际有向差额为 v。独立程序用形式变量记录 `m-v` 以及同号 H、L、K 个数；逐类相乘，只保留总损失不超过 `sum(m)-A` 的项。所有损失非负，故可安全截断。程序使用上表的直接查表界，作者程序使用反向目标差额和若干布尔不等式，两者在 2,184 个谱上逐项一致。

所有实际绝对差额独立允许正负号，形成真实整表的超集。固定总差额方向后只统计该方向的 H/L/K，不把正负混并。跨费用族仅在 E 的大小多重集及所有小类大小吻合时使用；剩余标签数恰等于该族的 q，因此 `H+L >= q` 强制剩余每个类都是同号 H/L。K 行类似：四个母内类和一个十点类之外只有六个标签槽，`K >= 1` 与 `H+L >= 5` 强制恰一个 K 加五个 H/L。故排除条件没有被外推到其他未证形状。

每一轮数值对确为继承包络上的最小精确有理比值；排除 A 后按费用/差额同奇偶将上界降低 2。费用高于 12,500 的尾部继续由继承的 `A <= 1611` 排除。端点等式 `957t = 479d` 与 `0 < d <= 1503` 仅允许 `(t,d)=(479,957)`。严格间隙的两段表达式也核对无误：旧整数界给出 `9-17r`，在 `r=1/2` 与 `r=479/957` 之间线性插值得到 `479-957r`，最后均除以 31,250。

本检查没有重新证明完整单类目录或重新枚举最大差额费用谱；这两项完整性分别继承前一证书与已读的 `trace_spectra.cpp` 和实际回执。此次独立复算针对全部已回溯谱的实际差额可行性，以及包络推进、预算和量词，不把继承证据写成本次重跑。
