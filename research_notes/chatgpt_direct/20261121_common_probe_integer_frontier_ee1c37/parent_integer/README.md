# 费用9,858谱的完整父母配置整数条件

2026-11-21。研究仍使用原125历史、31,250等权输入和一端点总补读预算。坐标是原生观察编码，母类是原菜单完整分类得到的250个十三点合法历史类。正式独立Review：`NOT_REVIEWED`。

## 范围和结论

本包只处理完整类型谱

\[
(9,557)^2(10,744)^5(11,936)^2(11,944)(12,1104)^2.
\]

任一采用此谱的整数分区，五个母内类的父母必须属于本包完整确定的200个五母集合之一。每一族的五个完整父母两两不交，合并65点。

这是对整个整数分区成立的必要条件，不能将任意五个父母逐个分数赋权后视作已经选中一个可行父母族。它提供了原逐点、类型、相容容量及模数观察之外的联合整数信息。结合另包的短加权计数矛盾，可排除此谱；此处本身不声称改善一般十二标签下界。

## 1. 原生单类事实与母中心条件

前驱完整费用/母内分类给出：费用936、944的十一点类全部母内，proper十一点类最低费用1008；费用1104的十二点类恰是删母中心的核心。费用557的九点类和费用744的十点类全为proper，且每条原坐标取值纤维内至多两点。其偏差为零的完整目录记录位于 `mother_sublevels_D/cost_defect_catalog.json`。

因此此谱恰有五个母内类和七个proper类。原250母类两两交集最多三点，故每个十一或十二点类的父母唯一。同一个父母也不可能承载两个不交的十一/十二点类；五个父母互异。

七个proper类在一条25点纤维内至多覆盖14点，所以五个母内类必须覆盖至少11点。设父母并为V，则每条纤维必须满足 `|V∩H|≥11`。单个父母的纤维人数为 `(5,2,2,2,2)`；如果某个取值纤维没有中心，五父母在其中的并至多10点。因此每条轴的五个中心值恰各出现一次。

## 2. 全部带锚父母配置

每个中心恰有两个方向的母类。选一个父母，平移其中心至原点并用共同倍增固定方向。其他四个中心必写为 `(i,π(i),σ(i))`，其中i=1,2,3,4，π和σ各为1至4的排列。四个非锚父母的方向任取，共

\[
4!^2\,2^4=9,216
\]

个带锚配置。平移与共同倍增保持原总费用、合法性和纤维占用性质，且交换原点两母方向；程序在完整250母类上直接核验该归一操作。配置计数不等于仿射轨道数，也没有假定待求整表本身对称。

逐配置检查十五条纤维父母并人数≥11，恰有924个通过。这一步的完整重算和父母掩码由同级 `zero_defect_centers/` 提供。

## 3. 从原菜单完整枚举每一个嵌入子类

对每个母类，直接枚举全部 `C(13,11)=78` 个十一点子集和13个十二点子集，共22,750个。它们由父母合法性继承原菜单合法性，费用使用原观测矩阵逐历史、逐菜单计算，不以原费用银行的数值代替计算。

得到的完整费用计数为：

| 大小与费用 | 子类数 |
|---|---:|
| (11,936) | 4,500 |
| (11,944) | 12,000 |
| (11,960) | 3,000 |
| (12,1104) | 250 |
| (12,1116) | 3,000 |

父母交集最多三点，故这些大子类不会跨母重复。随后对924个配置完整分配所需的两类(11,936)、一类(11,944)、两类(12,1104)，每父母选一个子类，要求子类两两不交且每条纤维实覆盖至少11点。

搜索每步选择可选子类最少的未分配父母，穷尽对应类型和全部子集。仅用剩余父母并不够57点、某纤维最大可能覆盖不足11点或候选与已选类相交等必要条件剪枝。对一个配置找到嵌入打包即记录其存在，不声称枚举该配置中的全部打包。

实际搜索154,424个节点，**恰四个带锚父母配置存在可行嵌入打包**，且四者父母并均有65点，即五父母两两不交。它们的正向见证也按原菜单重新计算了大小、费用、互不相交和纤维人数。

这四个配置施加125个平移及两个方向，去重后恰为200个五母集合。由于任意原分区都能按第2节归一，该目录覆盖原谱的全部父母可能性；展开是在已证完整归一后进行，未以“生成了一个轨道”替代完备性。

## 4. 对旧两个分数幸存框架的作用

旧第1框架的两核心父母中心为 `(3,0,3)` 与 `(2,1,2)`，恰能扩展到唯一五母族。任何该框架整数分区中的其余三个十一点母内类，都必须属于该族中剩余三个父母。

旧588支持点违反此必要条件：它分给其他父母的十一点类总权重为

\[
\frac{2262384400394957923580670130135217294455}
{791485270671759933571773788658764473171}>0,
\]

而所有该框架整数分区都要求此权重为零。

旧第2框架的两核心父母中心为 `(3,0,3)` 与 `(0,3,2)`，没有任何兼容五母族。因此这个条件排除该框架的整个整数候选问题，不只是分离某个分数点。其后的线性反证和全族短权证明由联合证书增量单独记录。
