# 一个费用 9,866 分型的逆向短排除

本包排除完整分型

\[
(9,557)^6(11,944)(12,1116)^5.
\]

它是已经被原完整 117 谱搜索排除的一个分型。本包提供另一条可复算的排除路径，所用新信息是父母集合与补集的整数关系；它不单独提高已经证明的一般下界。作者团队内部核验完成，尚未经正式独立 Review。

## 1. 六个父母的完整必要族

这里的母类是原生观察编码中全部 250 个十三点合法类。每个母类在每条坐标轴上的五个纤维人数为 \((5,2,2,2,2)\)，人数为五的三个取值给出其中心。每个费用 944 的十一点类和费用 1,116 的十二点类都保留所属母类的中心。相关类及其全部父母包含关系，均与已绑定的原候选库逐项核对。

六个母内类合计有 71 点。因此六个父母的并集 \(V\) 至少有 71 点。六个最低费用九点类，每个坐标纤维至多占两点，所以母内类在每个坐标纤维至少占十三点，进而父母并集在十五个坐标纤维中也至少占十三点。如果一个坐标值没有任何母中心，每个母在该纤维仅占两点，六母并至多占十二点，产生矛盾。因此六个中心在每条轴上覆盖全部五个值，取值重数必为 \((2,1,1,1,1)\)。

把第一轴的重复值平移为零，从该纤维选择一个父母作锚，并用共同倍增固定其取向。其余第一坐标依次为 \(0,1,2,3,4\)。另两轴各有 360 个以零为锚、覆盖全部五值的序列，另五母各有两个取向，共

\[
360^2\cdot 2^5=4,147,200
\]

个规范候选。候选库中十三点母类在平移与共同倍增下的闭性和这两个平移轨道，由回放入口直接重建核验。

完整枚举结果如下。

| 必要筛选 | 剩余规范项 |
|---|---:|
| 原始规范候选 | 4,147,200 |
| 六个父母不同 | 4,137,984 |
| 父母并至少 71 点 | 8,912 |
| 十五个纤维内的父母并均至少 13 点 | 4,304 |

最后 4,304 项的父母并大小分布为：71 点有 2,928 项，72 点有 1,280 项，73 点有 96 项。

## 2. 把余下问题压缩为一个“八外一点内”的九点类

六个实际母内类彼此不交，而且都保留母中心，因此六个中心 \(Z\) 不同，九点类必须避开 \(Z\)。若 \(|V|=71+k\)，六个九点类合计恰有 \(k\) 点落在 \(V\) 中，且必须覆盖 \(V\) 外的全部点。这个必要覆盖检查把 4,304 项减到 1,136 项。

再完整检查一类 \((11,944)\) 和五类 \((12,1116)\) 的不交母内打包，以及母内并在每个坐标纤维至少占十三点的条件，只剩 **672** 项。它们的 \(V\) 都恰有 **72** 点；这一步用了 **5,217,072** 个母内打包节点。这 672 项对应 672 个不同的 \((V,Z)\)。

令 \(O=X\setminus V\)，则 \(|O|=53\)。六个九点类的 54 点必须包含整个 \(O\)，并恰含 \(V\) 中一点。因此恰有一个九点类 \(A\) 含八个外点和一个内点；其余五个九点类必须全部位于 \(O\)，并分割 45 点集合 \(O\setminus A\)。全部 672 项合计只有 **143,904** 个这样的 \(A\) 候选。

## 3. 全部候选在五类覆盖的根节点失败

对每个候选 \(A\)，令

\[
\mathcal N_A=\{B: B\text{ 是完整库中的 }(9,557)\text{ 类，且 }B\subseteq O\setminus A\}.
\]

精确复算得到，对全部 143,904 个候选都有

\[
\bigcup_{B\in\mathcal N_A}B\ne O\setminus A.
\]

也就是说，每次选完这个唯一的“八外一点内”类，余下 45 点中至少有一点不能被任何可放入余集的最低费用九点类覆盖。五类覆盖搜索的每次调用都在根节点因候选并不足而返回；没有递归子节点，也没有进入后续的指定内点母内匹配。

完整结果是：`proper_union_rejects = proper_attempts = proper_cover_nodes = 143904`，`proper_size_rejects = proper_covers = embedding_attempts = found = 0`。

原整谱程序对这一分型使用了 8,880,241 个几何节点和 1,546,943 个覆盖节点。新路径的父母枚举、母内打包节点和九点类根检查是不同计数单位，应分别报告，不应相加后直接声称统一的加速倍数。

## 4. 独立回放

入口如下；输出应写入一个新的目录。

```sh
python3 -B replay.py --bank /path/to/prepared/native/bank --output /path/to/new/verification
```

所需原候选库的 SHA256 为 `5037ac43179fe73784d32e0f8011d105aeea1d0df964ef7bbfa13c7641a5f564`，是前驱低费用完整覆盖程序的 426,500 类准备库。若需要重新生成，沿用前驱 `lower/replay.py` 的准备入口，费用范围 9861–9870、核心数 0,1,2、引擎 `orbit-min`，并使用 `--prepare-only`。

本包回放会：核对全部输入与来源绑定；将完整 24,000 个 \((9,557)\) 类与原库比较，并重查其纤维人数；重建全部母类的平移/倍增闭性；重建并核对两种相关母内子类的完整包含关系；重新编译、执行 4,147,200 候选的父母规范化；逐字核对产生的 4,304 个父母项；再重新编译并完整复算逆向排除。

本包没有重新给原菜单定价，也没有重跑原 117 谱整层搜索。原菜单合法性、费用及相关类型库的完备性继承已绑定的原证据；上述父母族和逆向短排除则由本入口实际重建。`parent_centers.cpp` 与最初母子类输入由根研究者完成；逆向排除及组合回放由下界协作者完成。原候选库及其菜单与对称性证明保留前驱归属。
