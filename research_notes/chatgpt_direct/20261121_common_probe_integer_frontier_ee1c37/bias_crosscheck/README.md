## 1. 同向量词与完整母类数

`f` 是表中完整十三点类的数目，不是十二点核心数或一般嵌入母类数。固定总差额的非负方向后，`h` 只数实际有向差额 `+179` 的十一点／1,059 类；`b` 只数实际有向差额 `+142` 的十一点／1,042 类。负方向须整体反向，已有搜索分别覆盖两种符号。

检查的必要条件为：`f=1,2,3,≥4` 时，`h≤7,6,4,3`；`f≥3,h≥4` 时 `b=0`；`f≥2,h≥5` 时 `b≤1`。后两条分别来自所有四个／五个同向高差额类的不交打包；对更大的 `f,h,b` 取相应子族即可，量词可安全延伸。它们不限制正负绝对值合并后的总类数。

费用为1,059的十一点类，除实际 `+179` 外，其有向差额为 `+33,-33,-179`，均不超过33。因此 `packing_layers.cpp` 的 `(179,1)` 与 `(33,0)` 替代确为上包络。其余类别取最大绝对差额也只扩大可能集合。`f` 增加时高差额类上限单调不增，所以中间状态的剪枝不会因加入类的次序而漏掉有效整表。

## 2. 七个同向高差额类迫使 C≥11,925

任选七个该类，占77段历史、费用7,413。余下四类合计48点且每类至多13点，尺寸型恰为

\[
(9,13,13,13),\ (10,12,13,13),\ (11,11,13,13),\
(11,12,12,13),\ (12,12,12,12).
\]

前三型含至少两个完整十三点类，与 `h≤6` 冲突。第四型若十一点类 proper，其总费用至少

\[
7413+1008+2\cdot1104+1296=11925;
\]

若十二点类 proper，最低费用更高。第五型含一个 proper 十二点类时，至少为

\[
7413+1244+3\cdot1104=11969.
\]

因此费用小于11,925的反例只能使剩余四类全为嵌入类。两型在全单类谱上的总费用上界分别为11,901和11,877，正是 `seven_high_embedded.cpp` 两个全费用搜索的预算。源程序没有把它们缩成一个指定费用的端点搜索。每型1,723个规范母类位置、两种符号的四份完成回执均无覆盖，故最终对 `C<11925` 施加 `h≤6` 是必要条件。

## 3. 实际差额目录的完备性

`menu_signed.cpp` 相对于前驱 `previous/previous/bias/menu.cpp` 只增加每次枚举到的绝对差额记录、单点记录和输出格式；递归合法性与规范第二点枚举未变。对完整对称群下字典序最小的含零类，若其第二点不是同轨道最小点，固定零的变换会给出更小的类，矛盾。因此该规范化仍至少保留每类一个代表；绝对差额在允许变换下保持不变。

实际输出有2,338条 `(size,embedded,cost)` 档、45,146个绝对差额项；合并嵌入标记并取最大值，逐项等于原2,218条大小／费用上界目录。后一个一致性是交叉核对，不能单独代替前面的枚举完备性理由。将每个绝对值独立允许正负号是包含实际整表的松弛，因此以其无解作必要性排除方向正确。

## 4. 边界链与严格取等的范围

附带 `check.py` 用“相对各类最大差额的损失”生成函数，独立检查全部130个边界谱的实际差额可达性与同向计数，且核对逐步最小有理比值、谱文件哈希及谱数。15个被排除的数值边界共108谱；最后22谱只有一个仍通过必要松弛。

此外，三个提前由几何程序排除的数值对 `(11825,1173)`、`(11823,1169)`、`(11821,1165)`，从保存的全谱分别重新筛得1、1、2个候选；与四个几何源的尺寸、费用和带符号差额条件相符，八份双符号回执完成且无覆盖。特别在 `(11823,1169)`，费用1,046的十一点类必须用实际差额72，不能误用其单类最大值82；源程序使用了72。

原 q=2 结果给出 `t=C−11292≥9` 及 `2t−d≥1`，其中 `d=A−108`。新包络对所有剩余候选给出 `t/d≥525/1049`（仅需考虑 `d>0`）。未枚举的 `C≥12501` 用全域 `A≤1611` 即有比值至少 `403/501>525/1049`。因此当 `r<525/1049` 时，其他表满足 `t−rd>0`；端点只能推出非负。若端点取零，整数等式 `1049t=525d` 与 `d≤1503` 强制 `t=525,d=1049`，即上述唯一残留读数组合。已有端点未知的表述与此一致。
