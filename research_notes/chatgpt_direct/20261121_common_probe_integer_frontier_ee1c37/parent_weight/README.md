# 父母配置后的三纤维容量反证：75 > 65

2026-11-21。沿用原125段历史、原观察菜单与共同晚选变换；坐标仅为既有原生观察编码。正式独立 Review 仍为 `NOT_REVIEWED`。

本包依赖同级 `parent_integer/` 已完整证明的父母族分类，只处理费用谱

\[
(9,557)^2(10,744)^5(11,936)^2(11,944)(12,1104)^2.
\]

**该谱的全部200种可能五母族，都有一个相同形式的短整数反证。** 对原第1分数框架，加入唯一父母族的必要约束后，逐点覆盖和类型等式已经线性不可行；不需要继续加入原来的星团、模数或 XOR 约束。原第2框架没有兼容父母族。全谱的统一反证不依赖此前另外四个框架的不可行回执。

本结论只涉及上述谱，不能据此宣称其他费用谱或一般十二标签线性问题全部闭合。

## 1. 三张对角纤维

先取第一规范父母族。令

\[
H_{01}=\{x:x_0=x_1\},\quad
H_{02}=\{x:x_0=x_2\},\quad
H_{12}=\{x:x_1=x_2\}.
\]

每张纤维有25点，三张的**占用数合计为75**；三重交点按三次计算。定义

\[
h(S)=|S\cap H_{01}|+|S\cap H_{02}|+|S\cap H_{12}|.
\]

完整的最低费用类满足下列联合容量界：

| 类别 | 完整类数 | 三纤维合计占用上界 |
|---|---:|---:|
| 九点、费用557 | 24,000 | 8 |
| 十点、费用744 | 12,000 | 8 |

本包从四个原生轨道代表展开这36,000个类，逐类重新按原观察矩阵计费、检查47,000个原禁三元组及 proper 性，并与前驱完整银行逐集合核对。代表及完整类数的来源是原生完整合法类分类，见 `proper_seeds.json`；展开后的有效性和新容量不等式由本包直接检查，不能仅由类数相同倒推原分类完备性。

## 2. 父母配置使其余五类容量不足

第一规范五母并集 \(U\) 恰由两种历史构成：三坐标两两不同的60点，加上三坐标全相等的5点。五个中心组成全相等直线 \(Z\)。每个母内的其他12点都是三坐标两两不同的点。

因此任一允许母内的十一点类，只能由母中心贡献对角纤维占用，故 \(h\le3\)。两个十二点核心恰是母类删中心，故 \(h=0\)。整张表的上界于是为

\[
h(\text{全域})\le
2\cdot8+5\cdot8+3\cdot3+2\cdot0
=65.
\]

但逐点分区又要求 \(h(\text{全域})=3\cdot25=75\)，矛盾。

其余三个规范父母族由第二、第三坐标的符号反射得到。平移和共同倍增展开200个父母族，得到100个不同的三纤维权函数。本包对这100个函数、全部36,000个 proper 类直接进行了 **3,600,000次精确整数容量核验**，没有只测试第一规范位置后宣称其他位置通过。

注意：费用936的十一点类并非总删中心。例如 `parent_integer/result.json` 第一规范父母族的正向见证中，掩码 `5110217692276497038927458813953` 的936类包含原点中心。因此本证使用所有十一点类统一有效的 \(h\le3\)，没有误用更强的中心删除假设。

## 3. 等价的短权函数

令

\[
w(x)=
\begin{cases}
1,&x_0,x_1,x_2\text{ 两两不同},\\
-2,&x_0=x_1=x_2,\\
0,&\text{恰有两个坐标相等}.
\end{cases}
\]

则

\[
w(S)=|S|-h(S)=|S\cap U|-3|S\cap Z|.
\]

全部九点／557类有 \(w\ge1\)，十点／744类有 \(w\ge2\)，允许母内的十一点类有 \(w\ge8\)，十二点核心有 \(w=12\)。全域权为 \(60-2\cdot5=50\)，所需十二类的权却至少

\[
2\cdot1+5\cdot2+3\cdot8+2\cdot12=60.
\]

这就是同一个差额为10的反证。它同时说明：取得新的母配置联合信息后，反证可以压成很短的线性计数；此前复杂的分数幸存点不意味着所有联合整数方法都无能为力。

## 4. 原第1框架的整数 Farkas 证书

父母分类证明，原第1框架只能采用唯一五母族。令 \(F\) 为删去两个固定核心后的101点，\(U\) 为该五母并，\(Z\) 为其五中心。此时

\[
|F\cap U|=41,\qquad |F\cap Z|=5,\qquad w(F)=26.
\]

自由类的类型数为 \((2,5,2,1)\)，类型顺序是 \((9,557),(10,744),(11,936),(11,944)\)。给点等式乘子 \(w(x)\)，给四个类型等式乘子 \((-1,-2,-8,-8)\)。对允许的每列，列余量均非负，右端总和却为

\[
26-2-10-16-8=-10.
\]

要在**原全部7,953列**上写出证书，设 \(B\) 是父母不属于允许五母族的十一点候选列。父母分类给出有效整数条件

\[
-\sum_{C\in B}x_C\ge0.
\]

该条件的乘子只需取6。原因是任一完整母类相对 \((U,Z)\) 的交数仅有

\[
(|M\cap U|,|M\cap Z|)\in\{(6,0),(7,1),(13,1)\},
\]

各有120、120、10个。每母的权至少4，删除两点最多损失2，所以任意母内十一点类都有 \(w\ge2\)。对禁列增加6即补足所需下界8。

精确证书因此只有：

- 点乘子：\(w\in\{-2,0,1\}\)；
- 类型乘子：\((-1,-2,-8,-8)\)；
- 父母禁列条件乘子：6；
- 总常数：\(-10\)。

实际对完整银行中7,953列核验，禁列2,286，最小整数列余量为0。这个检查只需整数运算，发现阶段的浮点优化不承担真假判定。证书见 `verification/short_farkas.json`。

## 附：两坐标任意 Boolean 条件的精确变换分离

`fwt/` 另固定了一个与上述父母反证独立的方法增量。它精确验证“任意一个坐标对上的 Boolean 函数＋四种类型位”的全部奇数余数割，每个坐标对有 \(2^{27}\) 个规范索引，采用整数 Walsh–Hadamard 变换与有证明的余差界。

旧第1框架588支持点通过三个坐标对的全部 \(3\cdot2^{27}=402,653,184\) 个索引条件；旧第2框架最新298支持点恰被第一坐标对的三条割分离，其他两对全部通过。最短分离割来自22点集及两个类型位。这里没有重求完整候选LP，也没有把分离298点误写成该新割族独自排空整个LP。父母配置反证则确实处理了整个指定整数谱，并使第1框架原完整候选LP在加入父母条件后不可行。

附包的精确算法、分离式和复算入口见 `fwt/README.md`。上述新正反结果各自保留实际证据范围；一般任意点集的全部GF(2)条件仍未完成分离分类。
