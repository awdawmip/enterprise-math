# 任意两坐标 Boolean／类型奇偶割的精确变换分离

本附包保存一个完整但范围明确的方法增量；它与主包父母反证分别成立。正式独立 Review：`NOT_REVIEWED`。

## 1. 割与规范索引

自由余集 \(F\) 有101点，四类型为 \((9,557),(10,744),(11,936),(11,944)\)，类型数 \(n=(2,5,2,1)\)。任选一个坐标对，任取 \(f:\mathbb F_5^2\to\mathbb F_2\) 与类型位 \(a_t\)，令

\[
b_C=\left[\sum_{x\in C}f(x_i,x_j)+a_{t(C)}\right]_2.
\]

如果全域余数

\[
\left[\sum_{x\in F}f(x_i,x_j)+\sum_tn_ta_t\right]_2=1,
\]

则整数分区必有 \(\sum_C b_Cx_C\ge1\)。理由是非负整数余数之和为奇数，故至少为1。

把常数函数吸收进类型位的大小奇偶后，可规范为 \(f(0,0)=0\)。剩余24个函数位及4个类型位；用计数为1的最后类型位强制右端为奇数，得到每个坐标对恰 \(2^{27}=134,217,728\) 个规范索引。这是索引数，不宣称跨坐标对的所有不等式互不重复。

## 2. 无浮点误判的 Walsh–Hadamard 算法

给定正权分数点 \(w_C\)，总自由类权为10。消去右端条件后，每个类的余数是27位变量 \(y\) 的仿射线性函数 \(b_C=c_C+v_C\cdot y\pmod2\)。于是

\[
S(y)=\sum_Cw_C(-1)^{b_C},\qquad
\sum_Cb_Cw_C=\frac{10-S(y)}2.
\]

违反割等价于 \(S(y)>8\)。把带符号权聚到索引 \(v_C\)，一次 Walsh–Hadamard 变换即可同时计算全部27位变量。

最终检查不使用浮点变换。取 \(Q=2^{40}\)，用整数 \(k_C=\lfloor Qw_C\rfloor\) 替代每个正权的放大值。若正支持大小为 \(m\)，整数变换结果 \(T(y)\) 满足严格界

\[
|T(y)-QS(y)|<m.
\]

因此任何违反割都必须落在 \(T(y)\ge8Q-m\) 的阈值候选中。程序对每一个阈值候选用原精确有理权重直接计算左边；未进入候选的索引全部严格大于1。所有变换中间值的绝对值不超过 \(\sum_Ck_C\le10Q<2^{44}\)，有符号64位整数不会溢出。每次变换的主数组占1 GiB。

### 一条22点短分离割

令

\[
B=\{(0,1),(1,0),(1,1),(2,2),(2,3),(3,2)\},
\qquad U=F\cap\{x:(x_0,x_1)\in B\},
\]

则 \(|U|=22\)。取类型位 \(a=(1,0,0,1)\)。右端为

\[
22+2+1\equiv1\pmod2,
\]

故

\[
\sum_C\bigl[|C\cap U|+a_{t(C)}\bigr]_2x_C\ge1
\]

对该固定谱的所有整数分区有效。已满足前驱各完整族的298点却给出

\[
\frac{137720154417098737168856472591964873995}
{139185783306143065938396097430737963927}<1.
\]

## 4. 复算

在组合包根运行：

```text
python3 -B parent_weight/fwt/replay.py --integer-cuts integer_cuts --joint3 joint3 --work /tmp/fwt-audit --mode audit
python3 -B parent_weight/fwt/replay.py --integer-cuts integer_cuts --joint3 joint3 --work /tmp/fwt-full --mode full
```

`audit` 重新构造精确整数输入，核验保存的每个阈值候选及原有理余数，但不重跑大变换；回执会明确记为读取并检查已完成记录。`full` 重新编译并依次执行六个完整整数变换，再核对科学结果。源程序、输入文件、全部阈值输出与完成标准错误均保留在本目录。
