# 十二标签：9,866 费用层必须有至少五个母内类

2026-11-21。本包的两个新有限排除结论采用前驱原菜单程序：125 段旧历史、三台共同晚选恒等或倍增变换、全体合计最多补读一个原端点，累计成本计于 31,250 个等权输入。模五三元组沿用既有原生 X6 观察的有限读出编码。

**本包定理。**不存在恰有三个或恰有四个母内类、累计补读成本恰为 9,866 的十二标签表。

母内类是包含于一个十三点母类的任意合法类，所有大小都计入。核心的定义更窄：完整十三点类，或删去中心的十二点类。与前驱已经证明的 `E≤1` 时成本至少 10,007、`E=2` 时成本至少 9,867 结合，若成本 9,866 的整表存在，它必须有至少五个母内类。

## 母中心带来的联合人数条件

为 E 个母内类各取一个包含它的父母类，记这些父母类的并为 V。每个母类在每条原坐标轴的五个纤维上人数为 `(5,2,2,2,2)`。一条轴至多有 E 个取值是所选母类的中心值。没有中心占据的纤维中，V 的人数至多 2E，因此 V 外至少有 `25−2E` 个历史。

其余 `12−E` 个 proper 类必须覆盖所有 V 外历史，每纤维的基线是 `2(12−E)=24−2E`。每条没有中心占据的纤维至少贡献一个单位正偏差。设

\[
\Delta(C)=\sum_{j=1}^3\sum_{a\in\mathbb F_5}
\max\{|C\cap\{x_j=a\}|-2,0\},
\]

则 proper 类的总偏差至少为

\[
\boxed{\sum_{C\ {\mathrm{proper}}}\Delta(C)\ge3\max(5-E,0).}
\]

这里允许父母类相交，也允许母内类删去任意合法点；使用父母并的上界仍覆盖这些情况。`E=3` 要求偏差至少六，`E=4` 至少三。
