# 十二标签母类分解：D 增量

本包固定两项新增结论：

1. 在总费用至多 **9,995** 时，完整两母内类层又排除两种大小配置。与 C 中已完成的四种合计，十四种配置中有 **六种**完成排除；本快照其余八种仍列为待完成。
2. 若一张十二标签表恰有 **三个母内类**，则其费用不可能恰为 **9,865**。这是完整的精确费用层排除，不是对所有更高费用的排除。

母内类指包含于某个十三点母类的合法类，计入所有大小。`E` 始终使用这个完整定义。一个表的其余类为 proper 类。母类全集为原模型的全部 250 个十三点类。

所有结论属于原程序定义下的有限离散研究。本包状态为 `NOT_REVIEWED`；运行复验通过不等于外部同行审查通过。

## 一、完整 E3 精确 9,865 层

### 母类中心给出的必要偏差

每个母类在任一原坐标轴的五个纤维上人数为 `(5,2,2,2,2)`。选取三个母内类各自的父母类，记它们的并集为 `V`。另外九个 proper 类必须覆盖 `F = 全域 \ V`。

对于一个类，定义

\[
\Delta(C)=\sum_{j=1}^3\sum_{a\in\mathbf F_5}\max(h_{j,a}(C)-2,0).
\]

一般地，若有 `E≤5` 个父母类，则每个轴至多有 E 个不同的中心值。每一个未被中心占用的坐标值，其 outside 纤维人数至少为 `25−2E`，而其余 `12−E` 个类的基线为 `2(12−E)`。两者至少相差 1。因此

\[
\Delta_{12-E}(F):=\sum_{j,a}\max(h_{j,a}(F)-2(12-E),0)
\ge 3(5-E).
\]

真实 proper 并集包含 F，且正部满足次可加性，故 `Σ Δ(C)≥3(5−E)`。在 E=3 时，任何整表必须满足 **proper 类总偏差至少 6**。母内类删去了哪些点不会使这个界变弱。

## 三、新剪枝与候选完整性

### 逐费用偏差容量

沿用 C 已原生核验的混合界

\[
c(C)\ge a_s+3\Delta(C),\qquad
(a_8,a_9,a_{10},a_{11},a_{12})=(419,557,744,993,1226).
\]

对每个实际 proper 价格 c，再提取完整有限记录中的偏差上界 `d_s(c)`。较高费用使用已证解析界，不推测不存在的类别。价格支持始终取完整 proper 目录；八至十点的每价偏差上界允许同价母内类参与最大化，只会使必要条件更松。

若剩余类数向量为 n、可用额外预算为 b，定义

\[
K(n,b)=\max\sum d_{s_i}(c_i),\qquad
\sum(c_i-m_{s_i})\le b.
\]

这是整数 max-plus 动态规划。真实 proper 并集包含当前 outside 集合 F，所以 `Δ_k(F)>K(n,b)` 时可以排除。该规则没有把类的不交性放入容量；它是安全的必要条件。

Python 与实际 C++ 容量实现对十四种 E2 配置可能出现的全部 **7,773 个计数/预算查询**逐项一致。已知 9,996 整表的全部 **1,024 个 proper 尾子集**也通过该守卫。
