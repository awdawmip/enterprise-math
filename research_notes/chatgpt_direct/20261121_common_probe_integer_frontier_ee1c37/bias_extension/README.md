# 十一标签偏置：同号装填界与新区间

作者协作复算包，2026-11-21。正式独立 Review 状态：`NOT_REVIEWED`。

## 已证结论与准确边界

令 `I,D` 为一张合法十一标签表在两种共同晚选变换下各自的全域累计补读数，`C=I+D`，`A=|I-D|`，`r=|2p-1|`。沿用本项目原生历史、菜单和补读定义，不改变125段历史、31,250个等权输入及“全体合计至多补读一个原端点”的本体。

本包在前驱完整 `q=2` 排除和均匀最优表分类上继续研究，得到：

\[
0\le r\le\frac{525}{1049}
\quad\Longleftrightarrow\quad
\frac{262}{1049}\le p\le\frac{787}{1049},
\qquad
P_{11}^{\rm opt}(p)=\frac{5646-54r}{15625}.
\]

**两个新端点也包含在公式成立范围内，但端点取等表数尚未确定。**

- `p=1/2` 时仍恰有8,000张取等表。
- 新区间严格内部且 `p≠1/2` 时恰有4,000张，来自原8,000张均匀取等表族并选择较优变换方向。
- 最外端点新增取等的唯一未排除数值对是 `(C,A)=(11817,1157)`；尚未证明存在对应整表，也尚未排除。
- 因而本包没有确定最大稳定区间，也没有把前驱端点严格性沿用至新端点。

上述唯一边界对在本包有向差额松弛下仅剩一个费用谱：

\[
(9,656,120)+(11,1059,179)^5+(11,1042,142)
 +(12,1116,0)^2+(13,1296,0)^2.
\]

这里三元组分别为类大小、总费用、单类最大绝对差额；尚存该谱不等于已经存在一个分区。

对原8,000张之外的所有合法十一标签表，令 `t=C−11292`、`d=A−108`，有以下严格内部间隙：

\[
P_{\rm other}(p)-P_{11}^{\rm opt}(p)\ge
\begin{cases}
(9-17r)/31250,&0\le r\le1/2,\\
(525-1049r)/31250,&1/2\le r\le525/1049.
\end{cases}
\]

第一段由继承的 `t≥9` 与 `2t−d≥1` 线性插值得到；第二段由 `r=1/2` 的间隙至少 `1/62500` 与新区间外端点的非负间隙线性插值得到。第二段在最外端点为零，因此不推出严格取等分类。

## 可复用的同号装填定理

固定一个有向符号。记 `H` 为**proper十一点类**，总费用1059、有向差额179；记 `L` 为proper十一点类，总费用1042、有向差额142。将所有符号同时反转，结论相同。以下限制始终要求这些类两两不交、并避开指定的完整十三点类。混用正负差额不在这些命题的计数范围内。

| 已固定且两两不交的完整十三点类数 | 最多可放置的同号H数 | 穷尽范围 | 达界局部见证 |
|---:|---:|---|---|
| 1 | 7 | 一个规范母类，两个符号；完整候选库 | 已保存 |
| 2 | 6 | 固定首母类后100个第二母类，两个符号 | 已保存 |
| 3 | 4 | 15个规范三母框架，两个符号 | 已保存 |
| 4 | 3 | 35个规范四母框架，两个符号 | 已保存 |

三个母类的上界继承自前驱，本包重新复算；其余行是本轮新结果。完整母类数至少4时可任选其中4个，继承上界3。没有完整母类时，DP不人为增加装填上界。

进一步的联合限制为：

1. 在三个两两不交的完整十三点类之外，四个同号H不能再与任何同号L共同不交装填。30个符号/框架实例，共30个四H装填，全部额外L上界为0；搜索4,108节点。
2. 在两个两两不交的完整十三点类之外，五个同号H至多容纳一个同号L，而且一个可以达到。200个符号/母对实例，共33,072个五H装填，搜索2,788,683节点。`verification/local_witnesses.json` 包含实际五H加一L见证。

各行的达界是**局部不交装填**，不声称这些局部装填均可延伸为一个125点合法整表。每个保存的见证逐类按原观察菜单核算费用、有向差额、大小、proper性及禁三元合法性，并验证与母类及彼此不交。

## 七个同号H迫使整表费用至少11925

七个H占77点，总费用7413。由二母类装填上界6，整表最多含一个完整十三点类。剩余四类合计48点，每类至多13点。若没有完整十三点类，只有 `12,12,12,12`；若有一个完整十三点类，只有 `11,12,12,13`。其余尺寸组合都含至少两个完整十三点类，已被上界排除。

如果剩余四类全都嵌入完整十三点母类，四个承载母类必互异：任意两类的大小之和大于13，不能在同一个母类中不交放置。其母类并集至少48点。因此原完整母类枚举和仿射归一覆盖全部1,723个四母框架，两种符号分别搜索即可。

| 剩余尺寸 | 嵌入类费用下界 | 全嵌入整表费用上界 | 正号搜索节点 | 负号搜索节点 | 完整解 |
|---|---:|---:|---:|---:|---:|
| 11,12,12,13 | 4440 | 11901 | 469009 | 497747 | 0 |
| 12,12,12,12 | 4416 | 11877 | 338825 | 357244 | 0 |

搜索覆盖每个类型的**全部可能嵌入费用**，不是只检查某个总费用点。共1,662,825节点，两个类型、两个符号的全部1,723框架均完成。

因此至少有一个剩余类为proper。对于 `11,12,12,13`，最便宜的情况是proper十一点类费用1008：

\[
7413+1008+2\cdot1104+1296=11925.
\]

如果proper类是十二点类，下界更高。对于 `12^4`，proper十二点类至少1244，故费用至少 `7413+1244+3·1104=11969`。得到整表通用必要条件：`C<11925 ⇒ 同号H数≤6`。

## 完整实际差额目录与原生来源

`menu_signed.cpp` 的来源为前驱 `previous/previous/bias/menu.cpp`。原程序完整枚举合法类的原生观察编码：利用平移使类含原点，再用坐标置换、独立符号和共同非零倍数将第二点规范化。平移及坐标操作保持两变换累计读数，共同倍数可能交换两变换，因此绝对差额不变。

本轮仅把每个 `(大小,proper/embedded,费用)` 的“保存最大差额”扩展成“保存全部实际出现的绝对差额”。原合法子集递归、规范第二点、原菜单观察和母类判断均沿用。原生完整枚举输出2,338个有类型记录，共45,146条绝对差额条目。`signed_catalog.log` 保存各尺寸递归节点数；`verification/native_signed_catalog.stderr` 是本次复算回执。

把实际差额集取最大值，逐项精确回到原有类型最大差额目录。此项是交叉检验；**不能仅凭最大值一致推断实际差额集完整**。完整性依赖原完整枚举及上述原生仿射轨道恢复。`INPUT_BINDINGS.json` 固定原源文件SHA与原生输入SHA。

为进行必要条件计算，给目录中的每个绝对差额独立允许两个符号。这会放宽几何可实现性，故适用于安全上界。程序没有把该符号松弛称为实际整表差额目录。

## 整数DP与边界排除

`packing_layers.cpp` 在以下整数状态上动态规划：已用标签数、总尺寸亏点、总费用、**实际完整十三点类数f**、实际正179的H数。最终恰用11标签，总亏点 `11·13−125=18`。不删除任何合法尺寸候选。

H费用1059的正差额选项拆为179（增加H计数）与33（其余所有有向差额均不超过33）。其他费用类使用单类最大绝对差额作安全上界。`f=0` 没有额外装填限制；`f=1,2,3` 分别用7、6、4；`f≥4`用3。终态 `C<11925` 另用H数≤6。

完整DP覆盖 `C≤12500`，保留全部尺寸亏点18约束。大于此上限的尾部由继承的全局 `A≤1611` 排除，因为

\[
\frac{12501-11292}{1611-108}>\frac{525}{1049}.
\]

原均匀最优完整分类还表明，恰含五个完整十三点类的整表恰为原8,000张最优表，六个及以上不可能。因此考察其他表时，实际完整母类数至多4；`exact_boundary.py` 对完整费用谱应用这一继承事实，不将f作为随意指定的框架数。

按DP与继承的 `2t−d≥1` 的整数奇偶性联合上界，从最小比值 `t/d` 依次回溯**全部**可能费用谱；每个谱使用完整实际差额目录、H计数与H/L同号联合装填条件。15个数值对的108个谱全部排除后，首个剩余对为 `(11817,1157)`，有22个回溯谱，其中仅上文一个通过必要松弛。因此最小未排除比值为 `525/1049`。完整逐对谱、具体排除和迹线哈希见 `verification/exact_boundary_result.json`。

另外三组费用点需要实际几何排除，已整合到边界程序：

| (C,A) | 符号松弛后需几何搜索的费用谱数 | 完整框架与符号 | 搜索节点 | 解 |
|---|---:|---|---:|---:|
| (11825,1173) | 1 | 325个四母并集≥50框架×2符号 | 54856 | 0 |
| (11823,1169) | 1 | 22个三母并集≥38框架×2符号 | 402281 | 0 |
| (11821,1165) | 2 | 690个四母并集≥49及325个并集≥50框架，各×2符号 | 369838 | 0 |

这些搜索使用前驱完整原生覆盖程序的相同枚举结构，仅替换已完整推出的类费用/有向差额过滤和终点条件。`replay.py` 重新回溯每个费用点的全部最大差额谱，再按实际差额支持枚举每个槽位在目标总差额下可能采用的值，检查它们与几何核的类过滤一致。特别在 `(11823,1169)` 中，费用1046的十一点类必须采用差额72，不能误用它的目录最大值82。

## 复算

在含 Python 3 与支持C++20的g++环境执行：

```bash
python -B replay.py --predecessor /path/to/predecessor/artifact --output /path/to/new-verification
```

`--predecessor` 指向本项目上一轮不可变科学证据包根目录。本包的输入文件位于 `inputs/`，不依赖旧scratch的可写状态。前驱需要提供 `bias_q2/` 的已完成775分型证书及其审核脚本、原类型目录和均匀最优分类来源。本次运行路径与实际回执都保存在 `verification/receipt.json`。

复算入口执行：固定输入字节绑定；核对前驱q2回执（**不重跑已完成的大搜索**）；重新产生六个规范母类框架库并逐集合比较；重新完整枚举实际差额；重新穷尽全部装填和三组几何排除；重新运行整数DP、端点谱过滤覆盖检查及最终16轮边界追踪；逐类验证达界局部见证。

`verification/receipt.json` 中只有全部步骤实际返回成功，才写入 `complete:true`。编译标准错误、运行标准错误与每条命令均保留；源代码、输入绑定、费用谱和见证均可以检查。字节哈希用于固定版本身份，不替代数学完整性证明。
