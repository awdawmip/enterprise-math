# 只拆分一个消息类时可以省多少次补读

旧表有 m 个非空消息类，新表有 m+1 个。若新标签可以映回原标签而完整恢复旧标签，则新表恰好把某个旧类 C 拆为两个非空子集 A、B，其他类完全不变。记单类的原端点补读成本为 q(C)。任一拆分节省 q(C)−q(A)−q(B)。

对所有大小不超过十三的合法类作完整搜索。平移使第一点为原点，坐标置换、共同倍乘和逐坐标反号使第二点成为其轨道中编号最小者。对每一类，可在其所有点对中先选可达最小第二编号，再归一化该点对，其余点的编号必大于第二点。这样遍历至少包含每一仿射类的一次表示。程序使用原菜单的 47,000 个禁三元组剪去非法延拓。对每个父类遍历含第一点的那一侧的选择，恰好给每个无标号二分一个表示。若两子类大小的单类费用下界已经不能改善所求极值，可提前跳过。每项极值的父类、子类都用 Python 原菜单谓词独立核价。

按父类大小 2 到 13 排列，单次拆分的最大节省依次是 50、100、200、300、420、525、680、740、900、840、960、780。对应的子类费用和的最小值依次是 0、12、24、48、72、108、144、192、240、338、408、516。两个极值可以由不同的父类实现。达到全域最大节省的十二点父类需读 1,484 次，将其分为两个各读 262 次的六点类即可省下 960 次。把余下 113 个历史分别用单点标签表示，就得到全域可行的取等实例。

对于母表最优的限制，令 c_s 为大小 s 的单类最低成本。只有实际成本等于 c_s 的类才可能出现在达到单类分配下界的表中。对于十四到一百二十四标签，这个下界可以达到。给每个可出现的 s，仅在最低成本类上重新求最优拆分。再对照可行表逐一寻找一个取等类，得到所有预算的精确最优拆分收益。十七标签的另一张见证 optimal17.json 同时实现母表成本 5,726 和拆分节省 275。十三标签最优表只有一个仿射轨道，直接从其代表求最优拆分。

十一、十二标签的母表可能尚高于单类分配下界。固定用于拆分的父类 C，令 s=|C|，用 D(125−s,m−1) 表示其余点按单类最低价分配给 m−1 个标签的整数下界。若 C 需读 p 次、已知一般下界为 L_m，则其余类的费用至少是 max(D(125−s,m−1),L_m−p)。用这个数加上两子类实际费用，取全部合法父类与二分的最小值，得到对此预算下所有嵌套表成立的下界。若另有限制母表成本至多 U，则必须 p+D(125−s,m−1)≤U。

从包根运行 python3 -B replay.py --only refinement。result.json 保留各尺寸的极值见证、每个预算的最优拆分、适用的全域下界及分层枚举数。
