# 从十二标签对称最优表转到十三标签全域最优表

两边的所有取等表分别各属一个仿射轨道。固定十二标签表，遍历十三标签表的 12,000 个仿射像即可考察所有相对位置。对每个相对位置，逐类求交，令 w(i,j) 为旧类 i 与新类 j 的公共历史数。若两端的标签允许作最有利的一一匹配，添加的一个新标签用空旧类相配，则保留原标签的最大历史数恰等于这个方阵的最大权完美匹配值。程序用整数增广路求匹配，对每个相对位置都验证匹配目标值与一个可行对偶的目标值完全相等。整数费用 125−w 把求最大值转为求最小值。

在 12,000 个相对映射中，11,994 个没有完整公共类，其余六个各有一个。所有映射上最多保留 58 段历史原标签，故至少须改派 67 段，而且可以达到。若坚持保留一个完整类，至少须改派 78 段，也可达到。

十一标签的对称最优表有三个仿射轨道。将其分别与十二标签对称最优表比对，三个轨道最多均可保留两个完整旧类。逐轨道计算的最少改派数依次为 62、65、65。允许选择任一对称最优十一标签表时，最少改派 62 段，且可同时完整保留两个旧类。直方图按群中的仿射变换数计，同一无标号表可能由多个变换产生；极大值和极小值均不受重复影响。
