# 改进 9,996 表至少须改派十一段历史

将新表和旧表的标签任意一一对应，令 ℓᵢ 等于旧标签 i 丢失的原历史数。12 个旧类在原点集上的可合法补点数分别都是零。因此改变一个标签的点集必然丢失至少一个原历史。设改变的标签数为 t，实际改换标签的历史数为 d，则 d=t+e，其中 e 是所有 max(ℓᵢ−1,0) 之和。

给定 e≤k，每个旧类至多可丢 k+1 点。程序枚举每个旧类的删点集合，并对其余所有可合法加入的原点进行完整枚举。每个候选带有原菜单费用与自身的 max(ℓᵢ−1,0) 值。用十二个不同标签的候选对 125 点作精确覆盖，同时核对原生费用上限 9,995 和所有候选的 e 总和。k 为 0、1、2 时，依次访问 175、2,850、126,329 个节点，均无解。故任何严格改进都有 e≥3。

七类重分证明给出 t≥8，合起来即 d≥11，即使选择最有利的标签重新编号也成立。这里计数的是 125 段旧历史中改换消息标签的段数。

```sh
python -B replay.py --previous "$ROUND5"
```
