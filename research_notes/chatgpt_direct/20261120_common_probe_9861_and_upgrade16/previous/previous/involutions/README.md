# 十二标签的对合对称性与 9,996 次门槛

取三台历史坐标为模五的三元组，按 25x+5y+z 编码。此处比较的是三台共同晚选模型中全部 31,250 个等权输入的原端点累计补读数。对合可以交换消息标签，两个标签类交换时必须不交。五类对合均至少需要 9,998 次。

保成本群由全部平移、坐标独立变号、共同倍乘与坐标置换生成，阶为 12,000。任何仿射对合都有不动点，可将一点与其像相加再除以二。平移到原点后，96 元线性群内的 19 个对合分为五个共轭型。

| 对合的线性代表 | 历史不动点 | 十二标签的结果 |
|---|---:|---|
| (-x,y,z) | 25 | 9,997 次以内不可能 |
| (-x,-y,z) | 5 | 9,997 次以内不可能 |
| (y,x,z) | 25 | 单类成本与固定历史配额已给出至少 10,354 次 |
| (-x,-y,-z) | 1 | 9,996 次以内不可能；总成本必为偶数，故至少 9,998 次 |
| (y,x,-z) | 5 | 单类成本与固定历史配额已给出至少 10,026 次 |

对每个特定对合，不动标签必须由一、二点历史轨道组成。枚举每个此类历史轨道是否加入，遇上原菜单的禁三元组即剪枝，得到所有不动类及其精确读数。交换标签的读取总数是原类的两倍，覆盖点数也翻倍，历史不动点的贡献为零。用整数动态规划跟踪余下的点数、不动点数、不动标签数及交换标签对数。纯互换与带第三轴变号的互换由这一步排除。单轴反射另有一个独立的交换类最小值枚举。其中心化子在平面外的点上传递，可固定首点 (1,0,0) 并直接加点穷尽。

要使总成本至多 9,996，每个交换标签的大小、单类费用必须满足上述规划所得的截断。从原程序的读取掩码与禁三元组重建一切合法类的种子，再施以 96 个线性映射与 125 个平移。逐类验证与对合像不交，对同一占用支持保留成本最低的一种。每个字节像表均从零初始化。单轴与双轴变号在 9,997 次预算下的交换类大小与成本截断同 9,996 完全相同。单轴、双轴变号的固定历史 0 必落在唯一固定标签类，利用中心化子归并其首选，再按尚可覆盖方式最少的点逐层进行精确覆盖搜索。

中心反演的线性中心化子是整个 96 元线性群，它将 125 点分为大小 1、12、24、24、16、48 的六个轨道。每个类或交换类对记录覆盖各轨道的点数与精确成本，在同一签名上取最低费用。先枚举全部十二标签的大小与交换方式，再在大小约束下枚举所有在六个轨道上恰好填满的签名多重集。geo0 至 geo5 是顺序对应大小多重集的六个整数权重，运算中把各类成本同时乘 1000 后减去其轨道计数的加权和。总覆盖所减的常量完全确定，因此任何整数权重都正确。所有结论由整数加减、比较、原菜单生成与精确覆盖得出。生成这些剪枝权重的浮点优化不参与验证。

最后对每个签名多重集检查真实历史支持是否可以不交且填满。中心反演的 63 个历史轨道可用一个 64 位字表示。每一类行在该对合下闭合其支持。在固定签名数、交换对数与成本预算下，算法选择候选最少的剩余签名，令其中费用最小的剩余支持作为分支。全搜索的第一支持可在中心化子中归并。同费支持首次归并之后，仍保留该费用的其余支持。仅有一个标签轨道时直接查找剩余支持。对任意两个签名先算出真正不交的最小总费用，此下界可在没有共同标签的若干签名对上相加。

中心反演按 0 至 5 对交换标签分支，尺寸谱分别有 18、82、189、295、311、175 个。加入六个轨道计数后，剩下的几何谱分别有 0、0、0、811、132,176、4,969,963 个，它们都无法在预算内填满实际支持。27,487 个固定标签类逐类复算均为偶数费用，而交换标签对的费用是单类的两倍。
