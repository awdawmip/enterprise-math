# 9,996 次表的七类重分边界

固定三台共同变换模型与已证的 9,996 次十二标签构造。任选其中七个消息类，把这七类内的全部旧历史任意重分为七个合法消息类，整张表的总费用依然至少 9,996。因此任何严格改善的十二标签表至少要替换八个旧类。

共有 792 种七类选择。原表的三阶对称群把它们归为 270 个轨道。对每个代表，先减去不动的五类费用，得到严格改善时七个新类的总预算。按每种单类大小的已证最低费用，可以算出当前点集内单个候选类的最高容许费用。验证器枚举原菜单下全部达标的类，逐点检查禁止三元组并从原菜单直接累加费用。

为每个区域给出 125 个带符号整数点权和一个带符号的每标签权。对每个候选类，用单类原费用乘以 1,000，扣除它包含的点权与一次标签权。程序验证全部余数皆非负。将区域的总预算同样乘以 1,000，扣除区域总点权及七次标签权，得到所有余数的可用总额。余数超出总额的候选可以舍弃。

最后按尚未覆盖的历史中候选数最少者分支，逐个选取不交的合法类，每步核对剩余标签数、点数和余数预算。用每种类大小的最低余数做整数动态规划，并按每个未覆点可用类的最低单位余数做取整下界，两项只用于剪枝。270 个区域均不能形成预算内的七类精确覆盖。证书使用的所有分离与搜索比较均为整数。

`weights.json` 记录 270 个轨道代表的整数权重，`result.json` 给出逐区候选数与节点数。复验从原菜单、9,996 表及其对称群重新生成区域和合法类，逐项检查权重并完成精确覆盖判定。
