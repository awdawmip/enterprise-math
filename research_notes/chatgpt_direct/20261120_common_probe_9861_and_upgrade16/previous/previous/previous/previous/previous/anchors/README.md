# 十三标签最小成本组合及同心十二点类

成本 8,709 的唯一大小与成本谱为九个 (9,557)、两个 (10,744)、两个 (12,1104)，括号为类大小和累计补读数。原菜单上的合法类穷举分别产生 24,000、12,000、250 个这样的类。固定首个十二点类后，113 个不交搭档在允许更换首类的仿射等价下有六种放法。代码用整个 12,000 阶保成本仿射群验算每个轨道。

接下来在每个余集搜索全部九点类和十点类。每个最省十点类在任意坐标的五个切片各有两点。每个最省九点类在一个切片有一点，其他切片各有两点。剩余点集为 S、剩余类数为 k 时，每个切片 H 仍需要恰好 2k−|S∩H| 个九点类在 H 上只取一点。若该数越界，则排除此分支。每次从需要覆盖的历史、需求为一的切片、最后一个十点类中选择候选最少的一项，并遍历其所有可兼容类，故搜索完整。六个分支合计检查 42,025,617 个结点，全部排空。由总成本的离散谱，下一个候选为 8,712。

同样规则排除 8,719 的一个成本谱，即两个 (13,1296) 加十一个 (9,557)。两个十三点类的四种位置一共检查 2,312,641 个结点。

还可固定两个中心重合、成本均为 1,104 的十二点类。其中心由每坐标唯一一次出现四个点的切片确定。成本至多 8,728 的全部 23 种含两份 (12,1104) 的大小成本组合中，仅与此同心对不交且仍能覆盖公共中心的类可以继续。一共有 24 个 (11,936) 与 16 个 (9,576) 可选，在稳定同心对的群下各构成单独轨道。穷尽剩余五个组合后全空。因此含此同心对的十三标签表至少补读 8,729 次。

运行 `python3 -B replay.py` 重建原菜单、类库、费用谱、点对轨道以及三个完整有限搜索，并与 result.json 对照。脚本使用同级 group/generate.py 及其成本枚举器。需要 Python 3.10+ 与具备 C++17、128 位整数和 POPCNT 支持的编译环境。所有节点计数均是给定固定排序下实际递归调用数。

成本 8,717 中有一个类型为十个 (9,557)、一个 (10,747)、一个 (12,1104)、一个 (13,1296)。首选十三点类，列举与其不交的十二点类轨道，再以同时稳定该对的群归并十点类，共得到 6,361 个三元放置。余集由十个九点类覆盖的精确搜索检查 30,681,458 个结点，均不可行。单独运行 `python3 -B three.py`，结果见 three.json。

8,722 的三个成本组合中，十份最低成本九点类加三份大类的两个组合也各有完整排除。大类成本取 1,104、1,104、944 时有 2,093 个不等价摆法，余集搜索共 2,001,302 个结点。取 1,296、1,104、752 时有 3,325 个摆法，余集搜索共 16,307,663 个结点。运行 `python3 -B extra_triples.py` 可重建，精确输出见 extra_triples.json。

8,717 的第二个且最后一个成本谱是九份成本 557、各一份成本 744 和 752、两份成本 1,104。成本 752 的十点类在一个坐标上有一个单点切片、一个三点切片，其它切片恰为两点。在该类尚未选中时给剩余切片的缺量留出 −1 或 +1 的余量。搜完其全部六种十二点对位置均无解。完整谱核对见 `python3 -B slices.py` 与 slices.json。结合前述三大类分层，8,717 作为十三标签总读数全域排除。
