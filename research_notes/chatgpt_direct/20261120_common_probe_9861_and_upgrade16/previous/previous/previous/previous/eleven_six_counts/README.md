# 两个不同的十一标签六阶最优构造

在六阶仿射对称的十一标签表中，最低成本是 11,292。用保存相同支持最低读数及实现数的六阶轨道搜索，固定一个六阶子群，恰有八个取等分区。groups.json 给出两张不同的取等表。它们都以所指定的六阶子群为完整稳定子。该子群的正规化子有 24 个元素，分别生成四个不重复的取等分区。两组互不相交，至此用尽八个。

若两张表在 12,000 阶仿射群中等价，由于它们的完整稳定子相同，该等价映射必须落在正规化子，故上面两组也在全群作用下不等价。每张表的全群轨道大小为 2,000，全体十一标签六阶对称取等表共 4,000 张。旧表属于第一组。

重跑 python3 -B replay.py --previous /path/to/previous 可从原始观察文件生成枚举结果并核对两个代表及稳定子。三阶对称的最低成本也等于 11,292；本目录的取等计数须有六阶对称。
