# 其余四阶对称均不能严格改善十一标签上界

十一标签表若在三台共同变换模型的全部 31,250 个输入上总计少于 11,292 次补读，则其仿射稳定子不含任何四阶元素。已有无费用限制的排除证书处理平方为中心反演的三类。本目录覆盖其它全部四阶元素。仿射四阶变换固定任一点四个迭代像的平均值，因此平移后总可在线性群中分类。96 个保成本线性变换共有 24 个四阶元素的平方不同于 −I。按群共轭与生成元取逆归为 3 型，各含 12、6、6 个生成元。三型在 125 点上的 1、2、4 元点轨道个数分别为 (5,10,25)、(5,0,30)、(1,2,30)。

在严格改善预算内，先前分层证明容许最多两个十三点类。其余尺寸的精确单类费用下界给出长度 2、4 的标签轨道代表可用费用。固定标签是原历史点轨道的并，逐次取并并检查菜单合法性。二元轨道的代表不碰单点，在每个选中的二点轨道上取一个点，每个选中的四点轨道上取相反的两个点；其生成元像给出另一个标签，必须不交。四元代表只从四点轨道中各取一点，从原菜单重生全部可用费用的代表及仿射像。相同长度和支持下保留最低费用。对余集同时跟踪标签数、历史数、未覆盖的单点及双点轨道数、可选十三点类数；整数动态规划给出必要费用下界。先覆盖仍可选的单点或双点轨道，无此类点时再选四点轨道，均按候选数最少者分支。三型无解。

运行 `python3 -B replay.py --older /path/to/round2/delivery --group /path/to/round3/group` 可从原菜单独立重建全部候选并检查输出。与 `unconditional` 的全预算结果合用即可排除所有四阶元素。若稳定子另行排除了三阶、五阶，则每个非恒等元素都只能为二阶，稳定子因而是初等阿贝尔 2 群。
