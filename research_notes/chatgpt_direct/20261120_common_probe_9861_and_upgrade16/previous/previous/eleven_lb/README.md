# 一般十一标签表的费用下界

预算 11,118 下只剩七种例外大小分型，按各自费用上限及数量检查合计 87,404 个余集，最终搜索 197,456 个节点，全无解。故一般十一标签表至少补读 11,119 次。

每份候选表把 125 段历史分成十一类。把不能嵌入十三点母类的标签称为例外。先按所有类的大小及是否为例外分类，复用本轮母类覆盖曲线、至少四个例外以及恰四个例外合计至少 42 点的结论。每类的费用下界采用从原菜单得到的、区分可嵌入与例外的最低值。记预算为整表费用上限。对给定分型，将预算扣去其他类的最低费用，余下就是某个例外在此分型下能负担的费用上限。

对于仍可能出现的每一种例外大小列表，选一个最大的例外。枚举所有相应数目的母类，使其并集足以容纳可嵌入类需要的历史数。对每个候选母类族，再枚举符合预算的每一个最大例外。把该例外的点从各母类中扣掉。任何由若干母类组成的子族，其余下并集的大小至少应达到同样数目的可嵌入标签类中最小的大小之和。对多种可能的可嵌入大小列表，采用该下界的最小值。通过整数检验后，汇集既在母类外、又在上述例外外的待盖点集。相同点集只需检查一次。

其余例外必须以允许的大小、费用及数量覆盖待盖点。程序从原菜单穷举并重建允许的所有例外。在每个搜索节点，计算某一类至少须新盖的点数，逐类排除无法达到的候选，再选覆盖选项最少的待盖点分支。每选一类就将其与之前所选类的交集设为空，并扣除一个该大小的配额。待盖点恰好覆盖即可返回可行，尚未分配的母类内部点仍可保持自由。result.json 逐层列出原生母类族数、余集数以及剩余类搜索的结果，所有最后分支均无解。

运行 python3 -B replay.py --base /path/to/current/parent-proof --previous /path/to/previous-release。两个目录分别为本轮母类覆盖证明和含三层 previous/ 依赖的上一版完整解包。可通过 --jobs 设置并行数。搜索只依赖 Python 3 与 C++20。
