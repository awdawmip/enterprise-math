# 保留大部分旧标签时有哪些替代表

从十二标签、9,996 次补读的三阶对称取等表中选 k 个类。限定其余类完整保留，用 k 个非空合法类把这些旧历史的并集重新分完。类的排序及标签名字均忽略。利用原表的三阶对称，将 k=2、3、4、5 的选择归入同一轨道只核查一次，逐档代表数见 result.json。

程序由原菜单建立合法类与补读费用，从大类到小类穷举分区。若生成的分区只是所选原类的重排，予以跳过。两类或三类的情形将费用门槛设为 31,250，覆盖每张合法表，任意重新分区都只能得到原表。四类与五类的费用门槛分别设为 10,500 和 10,131，亦无与原表不同的解。这两项门槛指整张十二标签表的总费用。
