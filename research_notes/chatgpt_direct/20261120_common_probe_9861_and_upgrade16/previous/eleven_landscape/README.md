# 始终保持十一标签最优时，怎样从一张表换到另一张

所有带五个完整十三点类的 8,000 张十一标签取等表，五个完整类的集合有 200 种，每种给 40 张表。十一标签等号分类证明这些表已穷尽一般取等空间。两种距离分别取允许最有利重编号后改派的历史数，以及点集改变的完整旧类数。

两张表之间距离不超过 r 时，允许一步换表，每一步都使用上述取等表。若按改派历史数计，r=18 时有 2,000 个四表连通分量，r=21 时有 200 个四十表分量，恰是固定那五个完整类的所有表；r=50 时有 100 个八十表分量；直到 r=72 才能在全部 8,000 张表间互通。任一张表最近的两张不同表都改派 18 段历史，各有唯一一张改变五个完整类的位置而仅改派 50 段。按完整旧类计，连通分量数在 r=3、5、6、10 时依次为 2,000、1,000、100、1。

将三个轨道的各一个代表依次与 12,000 个仿射相对位置对比，去除同一取等表的重复表示，并沿用上轮经过整数原始及对偶最优性核验的指派算法。程序在恰好 8,000 个无标号点分区上构图。按距离递增，把一对相对位置的所有仿射像一并加入；已在同一分量的代表对，其所有仿射像也在同一分量，可直接略过。并查集逐半径输出全体连通分量的精确大小。

运行 python3 -B replay.py --previous /path/to/extracted-sixth-release。

从原菜单直接给每个取等表分解共同恒等与共同倍增的费用，4,000 张在两种变换下分别读 5,592 与 5,700 次，另 4,000 张分别读 5,700 与 5,592 次。
