# 十二标签：恰三个核心的读数下界提高到 9,881

## 已完成结论

在三台共同晚选 identity/doubling、总计 31,250 个等权原程序输入、全域至多补读一个原端点的模型中，若一张十二消息表恰含三个核心，则累计补读至少为 **9,881**。

这里的核心沿用此前定义：完整的十三点母类（费用 1,296），或删除其唯一中心后的十二点类（费用 1,104）。费用 1,116 的其他十二点删点类不算核心。本结论限定恰三个核心；不能据此单独宣布一般十二消息最优读数为 9,881。

此前这一分层仅排除到 9,860。本轮先完整排除到 9,870，再完整排除到 9,880。最终回执 `core_three_result.json` 记录的是第二个、较强的范围。

## 完备分支及单类范围

复用前轮已完整分类的 22 种三核心十二点集位置型。每个位置型逐一选择哪些中心放回，并显式排除放回点重叠，按余集及外层费用去重，得到 134 个分支。

若放回的中心数是 h，则外层三个核心共占 36+h 个历史，外层读数为 3,312+192h。余下的 89-h 个历史必须分成九个非空合法类。设某个候选类有 s 个历史，剩余八类仅使用此前完整单类最小费用表给出下界 L，则该类必须满足

    c <= 9880 - (3312+192h) - L(89-h-s, 8).

对所有分支取上限，大小 8、9、10、11、12、13 的费用上限分别是 471、644、831、1,018、1,191、1,378。大小不足 8 的类在预算内均不可能出现。前五个上限低于前轮完整枚举的截断；十三点类已经完整分类，全部费用都是 1,296。

从原菜单重建二点歧义位集和 47,000 个禁三元组，重新生成归一类并展开全部 12,000 个费用保持仿射变换，可得到这一统一上限内的 7,394,000 个合法候选类。每个分支再按实际余集和更细的费用上限筛选，排除额外的核心类，因此覆盖问题严格对应“恰三个核心”。

## 整数权重及精确覆盖

每个分支给历史点赋整数权 w_i，给每个剩余消息赋整数权 lambda。对每个候选类 C，原程序读数为 c(C)，定义

    reduced(C) = 1000*c(C) - lambda - sum(w_i for i in C).

原生 C++ 检查器逐一重算并检查 reduced(C) >= 0。对于余集 F 的任意九类分区，有恒等式

    sum(reduced(C)) = 1000*total_remaining_cost - 9*lambda - sum(w_i for i in F).

因此，目标费用预算可以直接变成整数约化费用预算。检查器在完整候选库上按未覆盖历史点分支，使用候选是否不交、剩余标签数、各大小最低约化费用及逐点下界剪枝，穷尽所有预算可行的覆盖。没有把线性优化软件的状态当作排除证明。

最终统计：

| 项目 | 数量 |
|---|---:|
| 核心放置分支 | 134 |
| 分支内合法候选，按分支累计 | 29,783,142 |
| 通过整数权重初筛的候选，按分支累计 | 1,918,540 |

## 旧权重在新增类上的实际失效和修复

没有直接假定旧权重能用于更大的单类范围。第 126 分支新增六个十点、费用 829 的类，其旧约化费用都是 -875。具体六类保存在 `invalid_previous_weights_126.json`。旧的 9,860 和本轮 9,870 范围都不包含这些新增候选，不受影响。

把该分支的消息权从 -1,265,663 下调为 -1,266,538，即减少 875，便使每一候选类的约化费用同时增加 875。随后对全部 376,619 个分支候选重新做整数检查；初筛剩余 1,272 类，精确覆盖 668 个节点，无解。修正权保存在最终回执 `weight_overrides` 中，复验器强制使用它。其余分支复用原整数权，仍对本轮全部候选重新检查非负性。

## 复验

需要前轮完整归档（本轮总复验包中的 `previous/`），Python 3 与支持 C++20/POPCNT 的编译器。运行：

    python3 -B verify_core_three.py --previous /absolute/path/to/round7 --jobs 2

该命令在新临时目录从原菜单重新生成候选、编译整数检查器、重建 134 个核心分支，并逐个比对最终回执。也可指定 `--case 126` 只复核修正权分支。

本轮实际完成了 134 分支全覆盖计算，并另外从独立临时目录重建原菜单和全部候选，复核了修正后的第 126 分支，输出与回执一致。另有 9,870 预算第 0 分支的独立重建复验。不能把这两次分支复核写成“最终全部 134 分支再次重跑”。

## 构造侧与尚未完成的计算

本轮也尝试了无表对称约束的候选类整数覆盖和模拟退火。两个限制候选库的 MILP 都到时停止，没有返回见证；三次退火合计 768,412,416 次循环尝试，最低合法费用仍为 9,996。它们不构成任何新的不可能性结论，也没有降低全域上界。

恰两个核心的整层点权覆盖还在探索。正确的中心放回选择给出 19 个分支；同中心两个母类不可同时放回。相关权重及运行状态在工作目录 `core2_9860/`，不属于本目录已经证明的三核心结论。一般十二消息下界应采用另一路已完整结束的费用层结果。
