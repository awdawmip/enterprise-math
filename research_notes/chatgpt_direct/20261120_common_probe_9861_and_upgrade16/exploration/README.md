# 未形成全域新界的构造与整层尝试

本目录保留下一轮有用的探索状态。最终已证范围由包根frontier及各证书结果决定。

## 十二标签构造

保留了两个限定候选库的MILP与模拟退火源码。MILP在各自时限内没有产生见证；三次模拟退火共768412416次循环尝试，最低合法值仍为9996。这些探索没有证明其限制库或全域不存在更好的表。`milp_10_11_0.json`、`milp_fixed012.json`记载实际状态。

发现脚本以本轮临时候选库为工作数据。正式证书重放不依赖这些库；需要继续构造探索时，应从前轮原菜单及本轮参数重建候选，再运行相应脚本。

## 恰两个核心的整层整数权

19个归一放置分支中，已保存分支0、1、2的整数权。所有已生成候选的约化费用经过整数检查，但没有任何一条完整覆盖分支结束，故这些权重不提供新的成本排除。两个广域运行在保留权重和输入后已明确停止，状态见 `unfinished_two_core.json`。

`core_two_weights.py`、`core_two_queue.py`保存发现路线，`two_core_weights/`保存参数和三个已生成整数权。原执行脚本使用其当时的工作目录名称；它们属于探索记录，不能当作已通过的主复验入口。接续时可重建数据并复用整数权，或使用已保存分数点加入更强的有效整数割。

## 仍开放的三个最优细分预算对

对(14,41)、(15,35)、(16,32)，本轮又构建了不加整表对称假设的整数覆盖模型。三个模型都固定同一仿射轨道的可细分八点类，仅用于消除坐标重复。各90秒的MILP时限未产生见证，也未完成不可行证明，因此三对保持开放。变量数分别为13926、16394、6395；第一对使用13个最低价九点类覆盖固定八点类的余集，第二对使用5个九点类与9个特定八点类，第三对使用3个七点类与12个特定八点类。未来可以继续精确覆盖或研究这些类的共同铺设约束，不能将这次时限当作排除证书。
