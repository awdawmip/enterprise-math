# 十二标签：纤维奇偶割及其与完整相容容量约束的联合边界

2026-11-20，三台共同晚选恒等／模五倍增、全体合计至多补读一个原端点的既有有限原程序模型。

本目录接续相邻 `../proof/` 的五个精确有理分数覆盖，保留其原文件不变。新的结果有两部分：

1. 一个只使用“25 是奇数”的短整数不等式，分别严格切掉此前五个满足全部星团约束的分数点。
2. 从完整合法候选库重新求解并精确恢复后，五个余集又各得到一个总价 9,858 的新分数点，**同时满足全部星团约束及全部 155 个非零模五线性形式取值纤维的奇偶约束**。

这将“某条割能分离一个分数点”和“加强后的整个松弛不可行”严格分开。一般十二标签整数下界仍由已经完成的整表排除证明给出；本目录确定新约束的作用和仍存在的缺口。

## 1. 短整数割：一个奇数纤维至少需要一次奇数占用

有限历史记为 \((x,y,z)\in\{0,1,2,3,4\}^3\)。这里是原程序历史的有限观察坐标。任选一个坐标取值纤维，例如

\[
H=\{(x,y,z):x=1\},\qquad |H|=25.
\]

若选中的消息类是一个整数分区，它们在 H 内的占用数加起来为 25。至少有一个选中类的占用数是奇数。因此对全部合法消息类均有效：

\[
\boxed{\sum_C (|C\cap H|\bmod2)x_C\ge1.}
\tag{P_H}
\]

利用逐点覆盖等式，同一个约束也可写成

\[
\boxed{\sum_C\left\lfloor\frac{|C\cap H|}{2}\right\rfloor x_C\le12.}
\]

它增加了整张分区在 H 上的奇偶信息。已有星团条件

\[
x_A\le\sum_{\substack{C\ni p\\C\cap A=\varnothing}}x_C
\quad(A\text{ 合法},\ p\notin A)
\tag{S}
\]

只要求每个被赋权的类为外点保留足够相容覆盖。这五个原点满足全部 (S) 却违反 \((P_H)\)，因而 \((P_H)\) 不能由它们已满足的线性约束推出。

## 3. 加入全部 15 条后，五个完整候选 LP 仍然可行

测试使用每个余集的**完整指定类型候选库**，不是原分数点的小支持。类型是

\[
(9,557)^2,(10,744)^5,(11,936)^2,(11,944)^1,
\]

另固定两个不交的 \((12,1104)\) 核心各权重 1。完整候选数分别为 7,953、8,538、8,718、8,476、7,958。

同时加入 15 条坐标纤维奇偶约束，五个求解均返回可行点。随后从其支持和实际取等约束建立整数系数方程，精确恢复有理权重；逐点、类型、非负性及全部 15 条不等式全部以精确算术核验。对应初始新点支持数为 112、109、110、114、110，保存在 `parity_cover_1.json` 至 `parity_cover_5.json`。

发现软件仅用于寻找这些点；其浮点状态不承担可行性证明。完整候选数与实际求解回执见 `parity_lp_result.json`，发现代码为 `parity_lp.py`。

## 4. 更强的联合可行证书：完整 (S) 加上全部 155 条纤维奇偶割

在模五有限坐标中，将非零线性形式按非零倍数归一化，代表可取

\[
(0,0,1),\qquad (0,1,a),\qquad(1,a,b),
\quad a,b\in\mathbb F_5.
\]

共有 \(1+5+25=31\) 个代表，每个取值有 5 种，产生全部 **155 个不同的 25 点取值纤维**。每一个均可使用 \((P_H)\)。这是有限历史观察的值纤维，不将其命名为原生空间平面。

对新的有理点作保持固定余集的费用保持仿射群平均，余集 2、5 另混合一个精确有理可行点，得到 `full_system/cover_1.json` 至 `full_system/cover_5.json`。五个结果都同时满足：

- 125 个逐历史覆盖等式；
- 总类权重恰为 12，指定类型权重完全不变；
- 全部合法类／外点的完整 (S) 家族；
- 全部 155 条 \((P_H)\)；
- 总成本恰为 9,858。

| 余集 | 新点余集内正权类数 | 实际检查的内部 (S) 数 | 检查的纤维奇偶约束数 |
|---:|---:|---:|---:|
| 1 | 558 | 50,802 | 155 |
| 2 | 398 | 36,170 | 155 |
| 3 | 741 | 67,310 | 155 |
| 4 | 592 | 53,800 | 155 |
| 5 | 674 | 61,252 | 155 |

内部 (S) 合计 **269,334** 项，纤维奇偶约束合计 **775** 项。完整 (S) 的零权类和固定核心部分按相邻证明中的精确论证处理。两个固定核心引起的 (S) 等号、部分纤维约束等号以及零权变量的非负边界均保留；这些点称为精确可行分数解。

## 5. 原菜单复验与使用范围

`verify.py` 只使用 Python 标准库及相邻 `../proof/verify.py` 中已给出的原菜单计算。它重新核验新证书涉及的 **2,574 个不同合法类**的原菜单合法性及费用，再检查全部有理权重、逐点覆盖、类型数、总成本、完整 (S) 与所有 155 个纤维奇偶不等式，并检查原五个点确实被指定割分离。

运行：

```bash
python3 -B verify.py --output replay_result.json
```

实际结果在 `verification_result.json` 和 `verification.log`。复验无需大候选库、SciPy、SymPy 或网络。

## 6. 本次方法结论

纤维奇偶是原分数点遗漏的一种整表联合约束，能用一条很短的不等式检测出来。把它加入以后，分数解可以重新分配权重，继续满足同样的 9,858 成本；即使补齐所有 155 个这种仿射取值纤维，再联立完整相容容量家族，也仍存在精确可行点。

因此要继续得到大于 9,858 的整数下界，需要这些约束之外的信息。可研究更高阶相容、其他子集的整数占用、联合矩或精确覆盖；本目录不对尚未检查的全部团割或所有整数割作不可行／足够性的判断。

早先的两锚点星团及奇数小点集多数团搜索没有找到分离；这些发现日志作为探索记录保留，不承担“全部一般团割均不足”的结论。找到纤维奇偶割后，已结束该无新见证的搜索。

科学前驱及原程序模型沿用 `../proof/README.md`。本目录是局部数学证据与方法进展，不建立正式独立 Review、Result 或 Foundation 晋升。

## 7. 发现程序的便携入口

精确证书复验仍使用上面的 `verify.py`，不需要重新求解 LP。以下入口用于重新发现分数点，依赖 Python 3.10 或更新版本，以及 NumPy、SciPy、SymPy；从头重建候选库还需要支持 C++20 和 `-mpopcnt` 的 C++ 编译器。求解器版本、候选顺序及时间预算可能改变发现出的分数点，保存的精确证书才是本报告实际验证的对象。

`discovery_common.py` 已包含原 `star_closure.py`、`average_stabilizer.py` 中实际使用的三个公共函数，因此不再依赖未随包的父级脚本。原菜单与仿射群定义从本包 `previous/previous/previous/previous/previous/previous/bounds/prior_bounds.py` 读取；固定类型谱和余集从本包 `lower/fractional_covers.json` 读取。默认包根目录由脚本自身位置确定，也可显式传入 `--delivery-root`，与当前工作目录无关。

完整二进制候选库是可再生成的发现缓存，没有随证书重复保存。已有 `lower/replay.py` 生成的完整 `bank` 可直接通过 `--bank` 指定。读取时检查四种所需类型的总数、掩码唯一性、类大小，以及五个余集的候选数；额外类型被忽略。

没有候选缓存时，`prepare_discovery_bank.py` 调用本包已有的原菜单全枚举与仿射展开程序，生成仅含四种所需类型的 52,500 行候选库，不执行 LP 或整表覆盖搜索。以下命令均从交付包根目录执行；输出示例使用独立临时目录：

```bash
python3 -B fractional/next_cuts/prepare_discovery_bank.py \
  --work /tmp/twelve-discovery-bank

python3 -B fractional/next_cuts/parity_lp.py \
  --bank /tmp/twelve-discovery-bank/bank \
  --output-dir /tmp/twelve-parity-discovery

python3 -B fractional/next_cuts/joint_closure.py \
  --bank /tmp/twelve-discovery-bank/bank \
  --output-dir /tmp/twelve-joint-discovery
```

最后一条命令默认从随包 `parity_cover_1.json` 至 `parity_cover_5.json` 起步，重现本轮联合闭包发现的输入。要改用第二条命令新得到的点，附加 `--initial-dir /tmp/twelve-parity-discovery`。新点若没有满足全部 155 条纤维奇偶割，联合脚本会在精确输入检查处停止；第二条命令只直接施加 15 条坐标纤维割，不能预先保证另 140 条也成立。

候选库生成入口可用 `--seeds PATH` 复用原 `low/class_enumeration.cpp` 的完整枚举结果，或用 `--cxx` 指定编译器。两个 LP 入口都可用 `--frames 1 2` 只处理指定余集，并可配置时间预算。它们必须显式指定 `--output-dir`；新证书与求解回执写入该目录，命令示例不会覆盖本包已经验证的证书。

本次包装修复只检查辅助脚本的语法、导入、命令行帮助、包相对依赖及完整候选库加载，没有重新运行 LP，也没有修改 `verify.py`、旧星团证书或五份联合系统证书。
