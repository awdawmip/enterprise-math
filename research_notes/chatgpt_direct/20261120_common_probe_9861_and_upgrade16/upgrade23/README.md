# 固定二十二标签表升级到二十三标签：最少改派恰为十六段历史

2026年11月20日 · 三台共用晚选变换、全体合计至多补读一个原端点的有限模型

## 1. 精确结论与起始表

设 `twenty_transition.json` 中的固定二十标签最优表为 (P_{20})。前轮已证：从它出发，若先最小化受改动的完整旧类数，则升到二十一标签恰有五张后继，均改动十个完整旧类，最佳重编号后均改派四十一段历史。五张表由历史坐标的末坐标平移互相得到。

对文件给出的二十一标签代表，唯一只改派五段历史的最优二十二标签升级，新增类为

\[
\{3,46,62,94,105\}.
\]

本报告固定的二十二标签表 (P_{22})，就是从这个代表逐类删去上述五点，再把五点放入新标签所得的表。完整点表保存在 `witness23.json` 的 `source_old22` 字段。

**定理。** 在所有全域最优二十三标签表 (Q_{23}) 中，允许自由重编号新旧标签时，

\[
\boxed{\min_{Q_{23}} d(P_{22},Q_{23})=16.}
\]

这里 (d) 是最佳一一标签匹配后改变标签的旧历史数。这个精确值同样适用于前述其余四张二十二标签平移像。起始表的范围是这五张表；前轮另有能沿五段改派持续升级的二十一标签表，因此起点的具体结构确实影响升级成本。

一个达到十六的二十三标签见证也已保存。原程序核验全部31,250个输入，得到27,680个免读输入、3,570个各补读一次的输入；另从准备阶段完整执行了34条三台路径。原二十二标签表需补读3,855次，所以本次升级减少285次补读，即2,280条原读取命令。两个标签预算都占五个定长位。

## 2. 最优二十三标签表的结构

沿用原菜单完整单类枚举的精确最低费用

\[
(m(1),\ldots,m(13))=(0,12,36,72,120,201,292,419,557,744,936,1104,1296).
\]

逐项有 (m(s)\ge81s-285)，等号只在 (s=5,6)。所以二十三标签整表至少需

\[
81\cdot125-285\cdot23=3570
\]

次补读，且任何取等表只能由十三个最低价五点类和十个最低价六点类组成。

完整的最低价类库有3,300个五点类、12,000个六点类。本轮对整个类库逐项检查了两个事实：

1. 每个最低价六点类恰有一个最低价五点子类。
2. 对本题的任意旧类 (O_i) 与任意最低价五／六点类 (C)，如果二者对应的五点子类不同，则 (|C\setminus O_i|\ge2)。

称这个唯一五点子类为该类的**五点骨架**；五点类的骨架就是自身。这与此前十二标签研究中“十三点或特定十二点核心”的术语不同。骨架只用于本节最低价五／六点类的分解。

旧表有二十二个不交五点骨架及十五个附点。目标最优表有二十三个不交五点骨架及十个附点，每个附点只能附给一个骨架，且每个骨架至多接收一个附点。

## 3. 为什么分类覆盖最佳重编号

如果目标表完整保留旧类 (O_i) 的五点骨架 (S_i)，则任何最佳标签匹配都必须把包含 (S_i) 的新类配给 (O_i)。

证明如下。这个正确配对至少保留五点。任意其他新类与 (O_i) 最多相交于旧附点，所以交集至多一点；任意其他旧类与含 (S_i) 的新类也至多相交于新附点，所以交集至多一点。若旧类和这个新类各自错配，交换两组配对至少增加 (5-1-1=3) 个保留点。若该新类未被匹配，改配给 (O_i) 至少增加四个保留点。两种情况都与最优性矛盾。

因此，可以用**没有被目标表保留的旧五点骨架数** (r) 分类；并非把任意指定的新标签名字当作已固定。

在一个最佳匹配下，二十三个新类中恰有一个未匹配类 (q)。其余新类记为 (C_i)，配给旧类 (O_i)。改派距离严格等于

\[
d=|q|+\sum_{i=1}^{22}|C_i\setminus O_i|.
\]

每个未保留旧骨架对应的配对都至少迁入两点，故

\[
d\ge |q|+2r\ge5+2r.
\]

如果有十五段以内的升级，必有 (r\le5)。下面两部分穷尽全部可能。

## 4. 零至四个旧骨架改变：最多只能保留一百零九段

固定要移除的 (r) 个旧骨架。所有新增的 (r+1) 个新骨架都必须在这 (5r) 个点与原十五个附点组成的区域内。程序从完整五点类库中选出区域内全部候选，再穷尽其中 (r+1) 个两两不交的类。其余二十二减 (r) 个旧骨架保持不变。

每个打包恰剩十点。这十点能否分别附给十个不同骨架，等价于一个十点对二十三骨架的二分图匹配问题。每条边都直接检查加入该点后是否属于最低价六点类库。不可能匹配的打包，保存并验证其 Hall 障碍：某组剩余点的邻接骨架数严格少于点数。

对可匹配的打包，保留的旧骨架按上一节强制配回自身；其余 (r) 个旧标签向 (r+1) 个新骨架作全部单射配对。先计算骨架中已保留的历史数 (B)。每个新类至多接收一个附点，且某附点只有回到自己的旧标签才增加一个保留点。因此，“存在可保留附点的旧标签数”给出额外保留数的整数上界。全部实际需要检查的配对都满足总保留数不超过109。

| 改变旧骨架数 (r) | 区域数 | 不交打包数 | 无附点匹配 | 有附点匹配 | 检查的旧新标签配对数 |
|---:|---:|---:|---:|---:|---:|
| 0 | 1 | 0 | 0 | 0 | 0 |
| 1 | 22 | 0 | 0 | 0 | 0 |
| 2 | 231 | 7 | 7 | 0 | 0 |
| 3 | 1,540 | 258 | 253 | 5 | 120 |
| 4 | 7,315 | 5,153 | 5,012 | 141 | 16,920 |
| 合计 | **9,109** | **5,418** | **5,272** | **146** | **17,040** |

所以 (r\le4) 时，(d\ge125-109=16)。这一层的证明只使用整数点集、二分图增广匹配、直接验证的 Hall 障碍与整数上界；没有浮点线性或整数规划结果作为下界依据。程序也包含整数最小费用匹配实现，最终这一层全部候选已被更简单的整数上界排除，未触发该补充求解分支。

## 5. 恰五个旧骨架改变：十五段预算也不可能

如果 (r=5) 且 (d\le15)，上一不等式的每一项都必须取等：

\[
|q|=5,\qquad
|C_i\setminus O_i|=2\quad\text{对五个改变骨架的类},
\]

其余类的迁入数全为零。

于是只须从完整类库中给每个旧标签保留迁入数为0或2的候选，并把未匹配类限制为五点。精确覆盖程序同时约束每个旧标签恰选一类、每个历史恰覆盖一次、总迁入预算至多10。它允许的是上述必要条件的一个超集，任何满足十五段预算的真实后继都包含在内。

逐旧标签的最低迁入费用先排除不可能的 (q)。其余3,029个五点候选全部完成搜索，共29,132个节点，无完整覆盖。搜索中还使用一个直接下界：如果剩余某历史不能出现在自己旧标签的任何可行候选里，它必定迁入别的标签，因此每个这种历史至少消耗一单位剩余迁入预算。

结合零至四骨架层，所有 (d\le15) 的最优二十三标签后继均被排除。

## 6. 十六段见证

`witness23.json` 给出全部二十三个类及最佳标签配对。一个达到最大109个保留点的配对，其未匹配新类为

\[
\{18,45,61,84,102\}.
\]

需要改派的十六段历史编号为

\[
\{2,13,15,18,45,47,59,61,64,74,82,84,91,102,108,115\}.
\]

这个见证改变十一个完整旧类。最佳标签匹配由整数 Hungarian 算法求得；验证了整数对偶不等式、列对偶非正、匹配边取等以及原始与对偶值均为109。即便不使用这个最优匹配证书，明确的十六段改派方案与前节全域十五段排除也已经给出精确等号。

原程序回执 `native23.json` 对全部31,250个联合输入核验了按类补读策略，未向解码者提供私有写入方状态。它与有限类库穷举分别检验算法见证和下界覆盖。

## 7. 对称范围与下一步

历史编号采用 (25x+5y+z)，其中各坐标属于模五历史观察状态。末坐标平移 (z\mapsto z+t\pmod5) 保持完整最低价五／六点类库，并保持固定二十标签表。它把前轮的五张二十一标签取等后继、各自唯一五段升级的二十二标签后继、以及本轮十六段见证对应起来。因此上述最少十六段结论覆盖这些五个对称起点。

对这里给出的二十三标签见证，再穷尽全部3,300个最低价五点类，发现没有只改派五段历史的最优二十四标签后继。理由与前轮的五段升级判定相同：未匹配新类已经至少含五点，如果总共只动五点，其他旧类只能各删去供给新类的点；每个六点类可删去的合法附点是唯一的。检查全部候选五点类后计数为零。因此这张具体见证的下一步至少需动六段；其他十六段后继能否选择得更利于后续升级，仍是另一个问题。
