# 已发生变化之后能否继续用旧摘要：由实际变换的拉回决定

沿用五边形首选服务。摘要 c(h) 在变化前形成；一个外部写者实际将标记表从 h 改成 F(h)，随后控制器收到**真实采用的变换 F**，收到后来的菜单 e，并得到强制复制/首项交付带来的“是否在 e 的端点”这一部分信息。变换的选择可以与历史独立任意搭配。写者读取/重建是实际、统一计价的原业务，其私有观察不作为给控制器的免费回执。目标为每个准许 F、每个 e 都正确并免除额外读取。

对给定变换族，连接两个原历史 x,y，当且仅当对某个准许的 F，F(x)、F(y) 为五边形相邻点。合法旧摘要恰好为这张**将变换后的冲突拉回原历史**所得并图的着色。必要性：取能将两历史变成相邻的同一个 F，选择连接该对的菜单，首次业务答复完全相同，却要求不同第二次交付。充分性：按 c 和已知 F 形成所有可能更新状态；若真实首键宣布“在边上”，该集合和这条边的交至多一个；若在边外，直接交付固定 12。归入同色的两历史变换后重合也是安全的。

1. 旧摘要为五边形合法三色时，无论 F 是已知的共同平移 h+t，还是反射 t−h，均可在更新后继续用。此处无需把三色本身变成一种可逐色置换的群作用：把该色的整组候选按 F 运输，再用实际业务回执排除即可。
2. F 若已在编码前确定为 h↦2h mod 5，可从一开始编码 c(2h)，仍只要三个消息。只把恒等和倍增作为编码后才确定的两个可能动作，则需五个消息：任意不同点的差是 ±1 或 ±2；前者在恒等下相邻，后者经倍增差为 ±4，即 ∓1。并图是完全图。即使恢复阶段完全知道行动 F，已经丢失的区分仍不能从确定性回执中得到。反例只涉及一个已声明程序族，不要求未知变换或隐藏动作身份。
3. 取旧色依次 0,1,0,1,2，历史 0 与 2 同色。倍增后为 0 与 4，菜单取边 (4,0)。两份真实第一交付均为 11，第二项却须分别交付 5 与 11。一位实际读取足以修复，但无读取时旧摘要不能作此区分。真实状态重建和关键回执见 ../phase/phase_notes.md。
4. 定量：一个固定的两个历史组成的无序对，在恒等/倍增两个动作中恰有一个将其变成相邻端点，对应唯一菜单。若同色，就导致两个（历史、动作、菜单）输入各要补一读；否则该对不付费。等权完整的 50 个输入上，若有 Q 个消息，则最少累计读数为 2 min Σ_c binom(n_c,2)，Σ n_c=5，n_c≥0。尽量均分各类达到；开放 0、1、2、3 位时累计为 20、8、2、0。每个冲突分支读一个现态顶点标记即够。计数遍及全部历史和菜单；恢复端始终知道实际采用的动作。
5. n 个独立分量甚至可使用同一个全局动作 F（只有恒等或全体同时倍增），仍必须给全部 5^n 种原历史不同的消息。若两向量不同，挑一个差非零的分量来决定 F，使该坐标相邻；其他坐标总可找到一条菜单边使两种候选同在边外。因菜单可作笛卡尔组合，完整已知回执可相同，而一项交付不同。全保存达到。故六份的免补读位数是 ceil(log₂ 5⁶)=14；只需支持事后公开的平移/反射时，仍与静态情形同为 9（恒等也在族中）。若事先已知唯一要做倍增，重编号即可，还原 9。六分量结论是推导，单分量实际写入另记。
6. 一般奇素数 p≥5 的环上，每种历史是一个顶点，边服务按同一规则，平移仍只需三色。如果编码完成后可能选择的乘数覆盖模 ± 的全部非零类，则对任何非零差 δ 都有准许的 a 使 aδ=±1，冲突并图是 K_p。因此完整 p 消息才能保证后续免读。编码动作早晚可改变的消息数在这族上无固定上界。

据此得到在本项目可直接检验的原则：判断旧证据能否穿过一次实际变化，要拿同一旧证据类中的任意两个来路，看准许的**同一个动作**能否把它们变成“首次回执相同、后续交付不同”的一对。不能只按动作是否已知、是否可逆，或仅看每一条边的局部候选数决定该证据的使用期限。
