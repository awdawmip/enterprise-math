## 2. 精确输入与允许语言

固定有限发生库存 I，当前装配 J 是两两不相交的三元素子集集合。每个子集是当前已预留的一个 TEST_ONLY 事件，不是发生过的整段历史。相同支撑没有额外、被操作读取的异质来源/材料标签。

固定可访问接口 B⊆I。本定理只允许：

- reserve(D)：D 是事先许可且完全包含在 B 的三元素集合；全体空闲时加入，否则留下原状态并记录阻挡。
- release(b)：b∈B；存在包含 b 的当前事件时释放整个事件，否则保持原状态。
- 观察 B 上的占用、当前总事件数，以及命令的成功/阻挡/空操作结果。

命令权重、允许性及形式代价不得依赖被隐藏的成员身份、事件来源、内场或形成历史。命令选择可以依赖已保留状态及已观察结果。输出不包含 B 外释放成员的姓名或其副作用。不允许命令访问 B 外发生、产生未声明的新通道，或把预留释放认作真实物理闭合逆演化。

库存与输入语法持续保存作来源；一个事件释放只改变当前预留，不销毁发生、不抹掉历史记录。这里的零响应与空事件、无分支仍分别定型。

## 3. 分组投影与充分性定理

定义

P_B(J)={h∩B : h∈J, h∩B非空}，kappa_B(J)=#{h∈J : h∩B为空}，
sigma_B(J)=(P_B(J),kappa_B(J))。

P 是 B 某个子集的部分分组，每组大小1至3。大小1不代表一元原子闭合，而是一个完整三元事件在操作接口上仅露出一个成员。未在任何组中的 B 元素为空闲。kappa 只保存完全不可访问事件的数量；总事件数=|P|+kappa。它不是额外空间维度。

显式更新：release(b)删除 P 中包含 b 的唯一组，kappa不变；b空闲时不变。reserve(D)在D与所有现存组不交时添加组D，kappa不变，否则保持并标阻挡。这些规则与完整 J 的更新满足

sigma_B(F_a(J)) = Fbar_a(sigma_B(J))，

且成功/阻挡标记及当前事件总数一致。证明逐类即可：事件在 B 上的所有成员恰是该非空交集；释放整事件恰好释放这整组。新事件全部在 B，故占用判断没有隐藏的外部冲突。

对任意有限命令词归纳，得到所有声明观察相同。释放后又加入、反复释放、部分命令空操作均在范围内。无需保存形成顺序，但不删除另行保留的来源证据。

BRC提升：对完整分支族，按 sigma 进行原 cwm_recoalesce；每个命令分支按原 cwm_propagate。相同 sigma 的后继 sigma、标记及权重一致，原分配律给出“先完整更新后投影”与“先投影后更新”相同。串联保持结合律，备选保持分配律。可加形式释放次数 c 的非负整数分层，串联使 c 相加，仍有同一交换图。这里 c 不是能量或物理时间。只证明任意有限词，不声称所有无限深度 CWM 总和收敛。

## 4. 指定观察语言下的纯状态最小性

不同 P 若占用集合不同，即时占用观察已区分。若占用集合相同而分组不同，存在 b,c 在一方同组、另一方不同组。执行同一 release(b)，随后观察 c 是否占用，得到不同结果。若 P 相同而 kappa 不同，总事件数即时区分。

因此任何对上述全部观察与后续命令保真的确定性纯状态压缩，都不能合并不同 sigma。这里的“最小”是信息划分意义，不是编码位数最优，也不表示每个受限事件库都实现所有分组。若观察不包含总事件数，kappa可进一步省略。

足够多的不可访问私有发生可补齐任意接口组为完整三元组；组大小 s 需3-s个私有伙伴。由此，b个可访问成员的部分分组数 a_b 满足

a_0=1，a_b=2a_(b-1)+(b-1)a_(b-2)+C(b-1,2)a_(b-3)，负下标项忽略。

取最小成员：空闲或独自露出的组给前两类；选择另一个或两个成员同组给后两项。b=0..6得到1,2,5,15,51,192,789。与单独占用的2^6=64类相比，释放语言确实需要更细的信息。六个接口成员不是六条原生轴。

## 5. 可合法缩小接口，但不能无依据扩大

若以后只访问 C⊆B，把每个旧组S替换成非空的S∩C；完全消失的旧组各给 kappa 加1。该规则满足 restrict_(B→C)(sigma_B(J))=sigma_C(J)。随后只能使用新接口许可的命令。

反例：B={1}，J={123}、J'={145}具有相同sigma。若擅自允许 reserve(267)，在J中因2已占用而阻挡，在J'中可添加。程序对此越界调用直接拒绝，而不是编造被隐藏成员。未知的未来接口变化需从保全的源状态恢复或重新取证；本商不赋予系统预知未来的能力。

## 6. 更强的残差见证：全部占用及平均两两关联相同，重组响应不同

三个互不相交的六发生模块 g=0,1,2。模块 g 的标号整体加6g。每个模块有两种完整装配：

bit0: {123,456}；bit1: {124,356}。

使用同一 TEST_ONLY 事件库，构造两种显式准备的正权输入族，各四个分支，各权重1/4：

E: 000,011,101,110；O: 001,010,100,111。

每个分支都占用全部18个发生、恰好6个事件。每个单模块的完整分组分布相同；任意两个模块的联合分组分布也相同。因此全部成员对的平均同组关系相同。不把这两个不同的联合输入称为相同完整微观态，也不宣称无选择的物理制备。

依次 release(1)、release(7)、release(13)，再尝试 reserve({3,9,15})。模块bit0使其第三成员变空闲，bit1则仍占用。最后的新三元事件仅在000分支可添加，所以

P_E(成功)=1/4，P_O(成功)=0。

每个释放真实删除一个当前预留事件；三个释放后各分支都还剩3个事件。阻挡提案保留，成功与阻挡质量之和为1。差别不是总占用、总事件数、单模块状态分布或两模块相关造成的，而是这三个模块的联合关联未被均值表达。

任意仅用上述相同粗资料给出一个共同成功概率预测v，必有max(|v-1/4|,|v|)≥1/8。此为明确测试观察下的信息损失下界，不是物理可测下界或原生能量。

纯状态中的完整两两同组关系能恢复分组（连同占用），但其跨分支平均不能恢复联合分布。这是区分“关系矩阵”与“平均关系矩阵”的准确位置。本轮并未证明所有混合输入的完整sigma分布是唯一最小概率编码；只证明它充分，并以反例否定指定的较弱摘要。
