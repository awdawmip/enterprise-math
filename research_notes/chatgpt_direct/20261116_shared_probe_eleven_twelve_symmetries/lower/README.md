# 十一、十二标签的增量全域下界

从前版已验证的原菜单模型及单类穷举出发，重新生成全部历史的禁三元组和两点歧义掩码。这里的核心指从一个十三点母类删去其中心得到、成本恰为 1,104 的十二点集。把这样的集合原样作为消息，或把其中心放回作为十三点消息，均计作一个核心类。

固定四个互不相交的核心集，在原菜单的 12,000 元仿射群下恰有 61 种位置。十一标签表在本轮预算内至多有两个完整十三点类，这是前轮十三点类分层给出的。列举哪些中心放回，得到 471 个合法分支。在每个余集上枚举合法消息类，按大小由大到小划分。各大小允许的最低费用由当前余集内实际存在的类给出。中心未放回时不要求其另成一类。11,035 次总预算下，471 条分支均无解。因此任何严格低于 11,036 次的十一标签表至多使用三个核心类。十二标签的同类枚举预算、分支数见 result.json。

其余步骤枚举在预算内可能出现的每一个大小与费用配置。每次把相同核心类型固定到全部规范代表，再从余集按剩余类数配额进行精确覆盖。成本 1,116 的十二点类来自同一族十三点母类的外周删点。在大量这种类存在的配置中，还可以固定其中一个。先按保持当前余集的仿射重命名取轨道。对任何完整分区，取其中轨道编号最小的外周删点类，把它送到规范代表，剩余类的轨道编号便可限制为不小于它。该方式枚举所有可能分区，也允许同一轨道贡献多个不同的类。所有费用均为整数。

replay.py 依赖前轮的 low/ 与原模型的 bounds/。命令为 python3 -B replay.py --last /path/to/previous --native /path/to/previous/previous，可用 --jobs 指定同时运行的覆盖进程数。

四个位置型容纳六个不交核心十二点集。对十二标签，从这六集放回中心的 256 个合法分支（每个位置型独立计数）出发，预算 10,130 共有 3,106,214 个搜索结点，全无解。因此一张严格优于前轮 10,131 次证书的十二标签表，最多能使用五个核心类。六个大类中若含成本 1,116 的类，由其他分支判定。
