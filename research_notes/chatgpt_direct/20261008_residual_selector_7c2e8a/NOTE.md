## 2. 固定三元装配与过早最优化的不相容

## 3. 新声明的可回退选择器，不是原生动力学

现在明确扩展操作语言：释放已选事件对发生的占用，或重新预留一个兼容事件。释放不毁灭输入发生；I始终不变，已发生的操作日志也不被改写。该可撤回预留语义是本轮新测试规则，不是推导出物理闭合可逆、倒转时间或无代价拆键。

一般有限事件库H，m=|H|>0，参数eta为正有理数。每个算法尝试均匀选择一个事件h；以eta/(1+eta)提议将它设为已选，以1/(1+eta)提议设为未选。已选提议仅在与其他已选事件无冲突时实现，否则保留原状态；未选提议释放h或保持其缺席。全部2m个提案及其不动/被阻断结果保留，不后选择归一化。eta只是选择器偏好，不是温度、能量或力。一次尝试不是物理时间或一次心跳。

状态J为当前兼容事件集合，U为已占用发生，R=I\U。程序逐项保留选择事件、提议位、实现效果及后继。完整尝试词由此语法保持；只有对于本冻结规则和当前J/首次到达/长期占比观察，才用有限J状态合并历史。来源敏感、解配副作用、事件时序或原生内态一旦参与未来，须重新扩展。

每个提案权重由cwm_edge及cwm_propagate形成；同一后继的替代提案用cwm_recoalesce。明确允许的total投影产生非负有理转移核。反复尝试的计数C通常增长，不声称存在有限的全深度CWM；只对W进行下述平稳分布/首次到达求和，全部有限提案仍有来源语法。

## 4. 平稳分布与有限参数的边界

该有限链的平稳total分布为

pi_eta(J)=eta^|J| / Z，Z=sum_(K compatible) eta^|K|。

证明：J与J+h之间，添加概率a=eta/[m(1+eta)]、删除概率d=1/[m(1+eta)]，满足eta^|J| a=eta^(|J|+1) d。每对邻接流量相同，所以piP=pi。任何J可先逐项释放至空，再逐项添加目标K；正有理eta确保每步有正概率，所以有限链不可约。每个状态有不动概率，因此非周期，分布趋于唯一pi。

三事件例Z=1+3eta+eta^2，pi(AC)=eta^2/Z，平稳平均未分配数为(6+9eta)/Z。有限eta下所有兼容状态都有正权；AC不是吸收态，下一尝试离开它的概率2/[3(1+eta)]>0。首次到达最优、长期多数时间处于最优、到达后永久停留是三个不同命题。停止在第一次最优需要额外的算法停止条件，不能把它默认为原生稳定。

## 5. 精确首次到达：更强闭合偏好可更慢解困

按0,A,B,C,AC排序。a=eta/[3(1+eta)]，d=1/[3(1+eta)]。转移行分别为

0: (1-3a,a,a,a,0)
A: (d,1-d-a,0,0,a)
B: (d,0,1-d,0,0)
C: (d,0,0,1-d-a,a)
AC:(0,d,0,d,1-2d)。

这些行由完整提案生成，而不是直接填矩阵。三步指定分支B -> 0 -> A -> AC的权重为d*a^2=eta^2/[27(1+eta)^3]，未分配数沿途3 -> 6 -> 3 -> 0。若只准单事件增删且每步禁止剩余增加，B没有离开路径。允许直接多事件交换会改变此边界，不能据此声称所有更新规则都需要先增加剩余。

令T_J为首次到达AC所需尝试数期望，T_AC=0。由第一步分解：

T_B=1/d+T_0；T_A=T_C=(1+dT_0)/(a+d)；
3aT_0=1+a(2T_A+T_B)。

代入a+d=1/3得

T_0=3(1+eta)(eta^2+4eta+1)/(2eta^2)，
T_B=3(eta+1)^2(3eta+1)/(2eta^2)。

这也是正BRC首次到达存活质量之和：移去目标行列后的Q满足T=(I-Q)^(-1)1。实际调用未改动的finite_recurrent_mass_analysis(Q)，取得正有理canonical_potential及整数证书Qh<h；没有另外写普通矩阵求逆作为科学后门。完整P的全深度质量不收敛，程序另行检查它不会被误标为稳定星。

有限eta下，从任何状态用至多三次指定未选提案清空，再两次指定已选提案形成AC，五步成功概率至少d^3*a^2>0。因此首次到达尾部有几何上界，期望有限。这是算法尝试上的证明，不是物理时间律。

## 6. 任意固定规模的严格改进交换都可能不足

构造2n+1个三元事件，冲突图为路径A0-B1-A1-...-Bn-An。相邻事件共用一个发生，其他发生皆私有；用私有发生补足每个事件3项。共4n+3个发生。这是发生冲突结构，不是原生空间连线、力传播距离或新轴定义。

选择全部B有n个事件。路径上最多可选n+1项，而且唯一达到者为全部A：若选了n+1个互不相邻位置，它们在长度2n+1的序列中必须恰好占所有偶数位。因此任何严格增加事件数的单次交换都必须撤回全部n个B。对任意固定k，取n>k就得到无法用至多k次旧事件撤回作严格改进的卡点。

但允许中性交换时存在明确路线：依次把B_(i+1)换成A_i，i=0,...,n-1；每次事件数仍为n且无冲突，最后加A_n得到n+1。故这里需要的是跨步保持关系并移动未配对状态，而不是每一步都立即变好。这不排除其他允许操作、并行交换或有预见的规则。

程序完整枚举n=1..6库的5,13,34,89,233,610个兼容装配，检查唯一最优、全部严格改进所需撤回数以及上述全部中性路线。一般n的结论由前段组合证明给出，不由有限枚举外推。
