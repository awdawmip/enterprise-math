## 1. Disjoint maximal unit-slack blocks

After GBB maximal-tight-cut contraction, work with positive integer capacity resources C and retained exclusive targets U, all matched; nonempty resource sets V have s(V)=c(V)-f_U(V)>=1, with f_U(V)=number of exclusive targets whose entire neighborhood lies in V, s(empty)=0. The function s is submodular (f_U is supermodular and c modular). If s(A)=s(B)=1 and A intersects B, both A intersection B and A union B are nonempty, so 2>=s(A union B)+s(A intersection B)>=2. Thus union and intersection both have slack one. Consequently the inclusion-maximal slack-one sets, called blocks, are pairwise disjoint; every slack-one set is contained in a unique block. There are at most |C| maximal blocks. Resources not covered by any block are retained, not merged into a new block.

For insertion of one new target with nonempty reduced neighborhood E, GBD gives new blocked set as the union of slack-one V containing E. By disjointness this is exactly the unique block containing E, or empty if no block contains E. Rank increases one in either case. This is an exact query at a fixed exclusive state: a per-resource block ID and one pass over E suffice, after building the blocks; a resource with no block must not be assigned a common fictitious ID. Original target identity and neighborhood are retained. Subsequent exclusive insertions change slack and require refresh; no static quotient for arbitrary changed capacity/adjacency or arbitrary future operation is asserted.

## 2. Construct blocks without exponential enumeration

Take any matching of every retained exclusive target (exists by GBB). Build directed graph with resource vertices j, one auxiliary vertex per matched target t, and sink z. Edge j->t exists when j owns t, capacity 1; t->k for every allowed resource k, capacity 2 (any integer >=2 suffices for unit-cut questions); j->z has capacity equal to unused slots at j if positive. All resources reach z, by GBC or strict slack. For fixed resource subset V, the minimum cut capacity among auxiliary vertex choices is s(V): free slots in V contribute; each target assigned inside V and having some neighbor outside V costs exactly one (exclude its auxiliary vertex); each other target costs zero by selecting it iff assigned inside V and wholly contained in V. Since all targets are matched, c(V)=occupied(V)+free(V), and f_U(V) counts exactly the occupants inside V with all neighbors inside V. This proves the formula.

A cut of capacity one has a unique outgoing capacity-one edge. Delete that edge and compute all resource vertices unable to reach z. This set contains V; if nonempty, its cut with the other unreachable auxiliary vertices has capacity at most one, and strict slack gives exactly one. Conversely every nonempty lost resource set obtained by deleting a capacity-one edge is a slack-one set by the same argument. Therefore taking the inclusion-maximal nonempty lost resource sets from all unit edges recovers exactly the maximal blocks, independent of the chosen full matching. Implemented by repeated reverse searches, O(K(V_graph+E_graph)) graph operations after matching plus maximality filtering (naive O(K^2) mask comparisons), where K is number of unit edges. Mask cost and matching not free. Polynomial construction, no speed superiority claim; dominator/bridge structure may reduce the scans.

## 3. Exact pair criterion and full subset rank quotient

Fix the contracted exclusive state. Let X be new labeled targets with nonempty reduced neighborhoods (loops with empty neighborhoods are handled separately). Joint slack on disjoint resource pools is additive, so a unit-slack set lives in exactly one bank. For x,y, both can increase rank individually. Hall formula on the contracted graph says their joint increment is one iff there exists a cut containing both neighborhoods with slack one, equivalently iff they are confined to the same maximal block. In all other cases joint increment is two. This provides all singleton/pair rank observations without testing pairs separately.

Stronger all-subset property: for any Q subset X, take any one representative for every block with at least one Q target confined to that block, leave every other target unchanged, and denote the resulting set by Qhat. Then H(U union Q)=H(U union Qhat) in the reduced graph. Proof: let y be a retained target confined to B, a unit block. For any Q containing y, the Hall deficiency objective is g_Q(V)=f_Q(V)-s(V). If V intersects B, submodularity gives s(V union B)<=s(V); if disjoint, s(V union B)<=s(V)+1 and y becomes newly counted. Hence g_Q(V union B)>=g_Q(V) always, and some maximizing cut contains B. Adding another distinct x confined to B raises deficiency by exactly one (at least one on that maximizing cut, at most one everywhere); rank therefore stays unchanged. Apply sequentially, in any order. Empty-neighborhood targets also leave rank unchanged. This proof covers all Q and any representative choice, not just full X. Preserve labels, memberships and multiplicities, as original deficiency increases by number of discarded targets; do not merge the underlying physical states or change the scientific input.

Let n_B be number of live targets confined to B, D=sum_B max(0,n_B-1). Then J_live = D + J_quotient exactly, J_quotient>=0. Proof follows by rank preservation and reduction of the number of live targets by D. This refines GBB's loop/true-competition decomposition. Pair information alone does not determine J_quotient: three unit resources a,b,c with exclusive target e={a,b,c} give singleton masks {a},{b},{c} as three distinct maximal unit blocks. New dedicated targets x={a},y={b},z={c} have all singleton ranks one and pair ranks two but triple increment two, versus three if e absent. Same singleton/pair observations and block IDs, different triple increment. This exact counterexample is checked in unit_slack.py.
