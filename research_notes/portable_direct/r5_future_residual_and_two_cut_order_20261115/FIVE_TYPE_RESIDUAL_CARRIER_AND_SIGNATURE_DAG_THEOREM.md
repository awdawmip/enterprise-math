## New theorem 1: exactly five optimizer membership types

Let `F_0,F_a,F_b,F_ab` be complete labeled optimizer families under two distinct gap contractions. Assume that each contraction weakly decreases each labeled center set's distance objective and that the **four optimum values are identical and finite**. Then

```
F_0 ⊆ F_a ∩ F_b ⊆ F_a ∪ F_b ⊆ F_ab.
```

Proof: for any optimizer S at an earlier mask, its later cost is no greater; since the common global optimum is J, its later cost must still be J. This also preserves feasibility.

Every S in F_ab consequently has precisely one of these five membership signatures; there are **no other cases**:

| Signature (bit0=F0, bit1=Fa, bit2=Fb; Fab implicit) | Exact fiber | Name |
| --- | --- | --- |
| `7` | `F_0` | old / all four |
| `6` | `(F_a∩F_b)\\F_0` | intersection surplus P |
| `2` | `F_a\\F_b` | a-only |
| `4` | `F_b\\F_a` | b-only |
| `0` | `F_ab\\(F_a∪F_b)` | joint-only surplus Q |

Thus the BRC-like **nonnegative integer branch-multiplicity carrier**
`c=(c7,c6,c2,c4,c0)` records the five disjoint labeled fibers; ordinary four cardinalities are its projection:

```
N0  = c7
Na  = c7 + c6 + c2
Nb  = c7 + c6 + c4
Nab = c7 + c6 + c2 + c4 + c0
```

This `4×5` integer matrix has rank four and kernel generated by
`(0,+1,-1,-1,+1)` in the stated coordinate order. **One scalar degree of structural residual is erased by the four counts.** This is information loss, not cancellation of signed or phase amplitudes.

One additional scalar, the exact intersection count `I=|F_a∩F_b|`, is sufficient to recover all five carrier coordinates:

```
c7=N0,  c6=I-N0,  c2=Na-I,  c4=Nb-I,
c0=Nab-Na-Nb+I.
```

It is necessary *in general* to add information beyond the four counts when all five fibers are admissible. This is an algebraic identifiability statement, not a claim that every fiber vector comes from every specific geometry. For m independent closures with the same monotonicity/common-optimum hypotheses, membership of any jointly optimal S is an upward-closed family of closure masks containing the full mask; the number of possible branch types is `Dedekind(m)-1` (for m=2: `6-1=5`). This is a type-count statement, **not** a complexity bound for finding the families.

## New theorem 2: direct residual-signature dynamic programming

Suppose each of the four optimizer families is represented by an acyclic layered graph on **common labeled states** and each accepted source-to-sink path represents a distinct optimizer exactly once; all four path languages have the same fixed length K, and the first three are sublanguages of the joint graph. For the joint graph, initialize each first-rank vertex with the three-bit mask for its membership in the other graphs. At each joint edge `u→v`, update

```
new_mask = old_mask & edge-membership(u,v) & vertex-membership(v)
D[next_rank,v,new_mask] += D[current_rank,u,old_mask].
```

Each bit is cleared as soon as a prefix cannot be extended as *that same labeled path* in its graph. Since it can never be restored, induction on path length shows that final mask bits are exactly complete-path membership. Consequently terminal sums at masks `6` and `0` are **exact |P| and |Q|**, not an inference from a scalar inclusion-exclusion identity. Retaining one predecessor per nonzero state constructs an explicit labeled witness without enumerating complete path families.

With precomputed constant-time edge/vertex membership and up to 8 signature states per vertex, the direct two-cut procedure takes `O(8·|E_ab|)` arithmetic updates and `O(8·W)` working path-count states on a streamed DAG of maximum layer width W. Arithmetic operations use potentially large integers: these are operation counts, **not bit-complexity bounds**. A non-injective path representation or unequal optimal values invalidates this theorem's direct interpretation as counts of center sets.

As a stronger direct Boolean-diamond certificate, the five coordinates satisfy the diamond exactly iff **c6=c0=0**. A four-cardinality inclusion-exclusion equality only implies `c6=c0`.
