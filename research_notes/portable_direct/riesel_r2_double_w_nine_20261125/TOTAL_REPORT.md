# R₂ 整个精确成本九密度：低阶闭合与最高阶单独计数

固定原 R₂、旧二十素数字典 P 与 Fₙ(a)=a²2ⁿ−1。保留历史研究者 EM-DIRECT-970E1C / RA-D2EC212845B63844081F9A14 的原成果归属。以下为直接数学推导及精确标量复算，未申报 Native Result 或正式 Review。

## 1. 全族答案

对整个 R₂，精确成本九的相对自然密度满足（向外舍入）：

```
[2.7661088300840, 2.7661090875960] × 10⁻⁸.
```

两端的精确有理数相差 **2.5751194466202155…×10⁻¹⁵**，相对区间宽度不足 0.00001%。约每 3615 万个 R₂ 根有一个精确成本九的根。

其中不需要用阶1260、且全局成本恰为九的部分已经完全精确：
```
P(L∖E₈) = 2.598453772533538327945843847931… × 10⁻⁸.
```
最高阶带来的真正额外部分是
```
P(T∖L) ∈ [1.6765505755046, 1.6765531506242] × 10⁻⁹.
```
L 是阶≤840时能达到九预算的根事件，E₈ 是整个八预算事件，T 是存在含阶1260的不可删九字典的事件。两部分互斥，已扣除全部更低成本及不同字典之间的同根重叠。证书给出二者并集的完整分数表达；唯一未数值化的量来自阶1260合数载体的未知素因子。

## 2. 交换两枚固定素数，封闭所有低阶分相位根

强制依次加入5、13，剩余类以 v 为坐标。若补充的尾类中存在有效期 f 被3整除，选择一个包含极小覆盖。三个 v 模3相位各至少有一个专用类：若任一相位完全由共相位类覆盖，由 CRT 这些共相位类已经覆盖全图，违反分相位类的不可删性。

在 v≡0 相位，删除全部该相位专用类，换成已在 R₂ 固定且覆盖完整相位的 **19**。在 v≡1 相位做相同操作，换成 **73**。每次都至少替换一枚，预算不增加，第三相位和所有共相位类保持不动。替换阶均不超过840。所以 **有任何低阶分相位覆盖 ⇒ 同一个根有低阶双 W 覆盖**。反向只是特例包含。这里是根事件的包含，不是宣称恰一 W 或零 W 的原始字典不存在。

因此 L=C₉∪D₉，其中 C₉ 为[全共相位](https://github.com/awdawmip/enterprise-math/blob/940f6b84a312c1b1e8735456f1d7a3707030c7a3/research_notes/portable_direct/riesel_r2_common_nine_density_20261125/REPORT.md)，D₉ 为[双 W 低阶分相位](https://github.com/awdawmip/enterprise-math/blob/53e8134dfe6f211b800f67d11460630c178c8bd1/research_notes/portable_direct/riesel_r2_double_w_nine_20261125/REPORT.md)。双 W 只有239种局部几何；同一多值决策图上已经算出了交并，并扣全局 E₈。两个归并顺序在精确分子、分母上相同。这里不需要再枚举恰一 W 或零 W 的分相位消耗，前一份双 W 报告中的剩余事项由本正规化消除。

## 3. 对最高阶增益作精确条件分解

使用已经证明的阶1260几何：两条长列须有低阶命中；短列三格每格须由适当低阶或阶1260命中。在 **根已不满足 L** 且两条长列均已占据的状态中，令 a_k 为恰有 k 个短格没有对应低阶命中的相对密度。此处不满足 L 是在整个已知低阶根谓词上取反，已包括所有别的几何替代；不能只看短格低阶缺口。a₀=0，因为不缺短格本身构成同几何的低阶覆盖。按 CRT 精确算得：

| k | a_k（相对整个 R₂） |
|---:|---:|
| 1 | 2.1101178383324783939416…×10⁻⁶ |
| 2 | 2.3594044144092654538599…×10⁻⁵ |
| 3 | 4.7765635470480994577209…×10⁻⁵ |

设 H 是三枚已证阶1260素数（2521、1711081、430839361）和未分解载体的所有不同素因子。对任意 k 个指定短格，阶1260覆盖这 k 格的概率精确为：
```
B_k(H)=Σ_{j=0}^k (−1)^j binom(k,j) · ∏_{q∈H}(1−2j/q).
```
原因是同一 q 对这 k 个槽位的根类别两两互斥，各有两枚余数；不同 q 由 CRT 独立。与已知低阶库也独立。因此
```
P(δ_P=9 | R₂) = P(L∖E₈) + Σ_{k=1}^3 a_k B_k(H)
```
是**全族**的精确表达。用三枚已知素数计算下界。此前[完全整数排除和因子计数](https://github.com/awdawmip/enterprise-math/blob/e45eb9dbc459360b87996a824d0ed0f5b043da8a/research_notes/portable_direct/riesel_r2_gain_tightened_20261125/REPORT.md)证明每个未知素因子大于10¹⁰、至多六枚；用六个不同的虚拟独立变量，每格击中概率2/(10¹⁰+1)，以单调耦合压住真实未知部分，即得上界。没有将虚拟分母当作素数。完整低阶已经无任何因子近似，且最高阶的同根替代已精确扣掉。
