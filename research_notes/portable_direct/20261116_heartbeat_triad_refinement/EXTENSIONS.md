# 均匀分步的成本与短回路观察

伴随 RESULT.md 的有限代数结果。V38 两个已保存的三轴组回路分别交换三槽中的 a=(2 3)、b=(1 2)，相应回路及其逆属于 [R757 采用的已完成宏包语言](https://github.com/awdawmip/enterprise-math/blob/ed0b15b4ba948a21150969478d8a6941db76b11f/research_notes/R757_V39_BOWTIE_NATIVE_THREE_PACKET_CLOSURE_20261113.md)。本篇从它们的可逆运输输出出发。等细步、辅助槽及扩群是数学比较条件；不能从粗包获准推出细步在心跳动力学中也获准。

## 两个相同细步的最小成本

问题是能否把忠实记录这两个换位的粗操作分别写成 X² 与 Y²，其中两个 X 是同一个元素，两个 Y 同理。此节与 RESULT.md 选择中间三轴组的规则有别。后者通常使用两个不同的、有不同起终点的更新。

**具名置换。** 固定三个原槽，要求每个粗包结束后回到原三槽集合并按来源执行给定换位，其余槽可在块末置换。总槽位最少为五。若总数为三或四，辅助部分为零或一个槽，粗换位是奇置换，平方必为偶置换。用槽 4,5 作辅助，取 X=(2 4 3 5)，Y=(1 4 2 5)。则 X²=(2 3)(4 5)，Y²=(1 2)(4 5)。整个粗群嵌入 g↦g 在旧三槽上作用，辅助两槽由 g 的奇偶性决定是否对调，由此保每条粗词的全部旧槽运输。新槽属于代数框架记录，不增加 X6 空间轴。若每个细步本身都必须保原三槽集合，限制到三槽立即给出平方根障碍。更一般地，若任意多辅助槽都要求在每个块末逐槽固定，粗动作仍为奇置换。

**抽象有限群。** 单独优化含忠实 S3 且其中 a,b 均有平方根的群阶，最小为 36。令 G 为 F₃² 与 C₄ 的半直积，生成元 k=1 对平移向量作用为 J(u,v)=(-v,u)。乘法 (w,k)(z,j)=(w+J^k z,k+j)。取 X=((0,0),1)，Y=((2,1),1)，则 A=X²=((0,0),2) 与 B=Y²=((1,0),2) 均为对合，AB 为非零的一维三阶平移。它们生成一个六元 S3。

下界证明。假设阶小于 36。因含 S3 及一个四阶元素，阶只能为 12 或 24。P=〈AB〉是 Sylow 3 子群。如果 P 正规，共轭作用给 G→Aut(P)≅C₂，将 A 送为非单位反演，而 C₂ 的平方全为单位。若 P 不正规，由 Sylow 定理恰有四个这样的子群。G 在四个子群上的传递作用核至多有 |G|/4≤6 个元素。P 的像非平凡，否则核含所有四个 Sylow 3 子群，共至少九个元素。P 的像遂由一个三循环生成；A 将其反演，在四点中固定该三循环以外的那一点，在其余三点上是换位，故为奇置换，仍不能是平方。此证只需其中一个粗换位在扩群中有平方根。标准置换开根与循环分解可参阅 [Leaños、Moreno、Rivera-Martínez](https://arxiv.org/abs/1005.1531)。此处给出本项目特定生成元及资源模型下的构造与下界，无一般优先权主张。

即使允许无限扩群，也没有乘法保持的回缩 π:G→S3 既固定旧群又读出每个细步。否则 π(X)²=a，矛盾。按完整两步块解码可保旧词；任意细前缀的乘法解码需要额外状态或更弱的观察。

## 若探测端只能读出置换类型，包词最多要多长

给同名的若干 S3 粗运输，允许一次统一的基点重标记。两套运输在这一意义下完全相同，当且仅当每个长度不超过三的有序正词在两边的置换类型相同，允许重复使用同一宏包。测试只能识别到共同重标记；如槽名已被外部固定，仍需核验具名输出本身。

证明。一字词识别单位、换位、三循环。两换位相乘为单位当且仅当它们相同，故所有出现的换位之间的等同表已确定。S3 的共轭在三个换位上给出全部置换，可用一次共同共轭把两套已出现的换位逐名对齐。两三循环相乘是否为单位区分其方向相同或相反，故所有三循环至多留下一个共同的翻转自由。若已出现的不同换位最多一个，可取保持它的奇置换共同共轭，完成翻转；若至少两个，取它们的有序积 p，这是一个三循环。对任何三循环 r，三字词 pr 的类型区分 r=p 与 r=p⁻¹。由此得到同时共轭。反向蕴含由共轭与乘法相容立得。

锐性。取 V38 的 A,B 和交换子包 C=A;B;A⁻¹;B⁻¹，比较 (A,B,C) 与 (A,B,C⁻¹)。C 与逆的有向边多重集也一致，因为交换子中每条使用的边按正反方向各一次。两组所有长至二的有名词置换类型相等。长三词 A;B;C 与 A;B;C⁻¹ 恰有一个为单位。V38 的槽元组是 axis→origin_slot 拉回，V39 路序常以正向映射表示，两者互逆；这里不依赖哪个三循环叫作正向。这个例子在已有可逆宏包语言内实现，不需许可新的单步事件。

执行：python check_extensions.py /path/to/check_nonabelian_multicircuit.py。程序从固定 V38 取具名粗运输，核对五槽块平方、36元乘法及全部三元组的结合律，验证两个平方生成的旧群与细生成群；对所有三、四元 S3 元组做完整词与同时共轭比较。三元组 216 个，在长≤2、长≤3、同时共轭三个标准下分别为 46、49、49 类；四元组 1296 个分别为 211、251、251 类。解析证明覆盖任意元组数。实际心跳时刻、辅助槽与单步的物理发生均未由本次群论推导确定。
