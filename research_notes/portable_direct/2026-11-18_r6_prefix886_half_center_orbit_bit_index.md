# PREFIX-886 — 中心纤维补码轨道折半、单模逆位索引与19位全域交叉证书

日期：2026-11-18（Asia/Shanghai）。研究线：进取数论研究6，独立具名 BRC 辅助观察器；接续 PREFIX-884/885。科学输入继续冻结于 `f42f2906d77f24085c123f3ccfe9667d41caa96d`，不修改 P000 或共享 X6 任务。

## 精确模型

令 `p≥1`，`N=2^p`。每条有序合法轨迹为 `(x,x)` 或 `(x,x XOR 2^i)`，`0≤x<N`、`0≤i<p`；各位是具名来源，时间前后有序。观察器是 `Φ(x,y)=(x mod q1,y mod q2)`，其中 `q1,q2` 为正奇数。补码 `J(x)=N−1−x` 保留 XOR 来源名称，`J(x XOR 2^i)=J(x) XOR 2^i`。中心余数 `r_j=((N−1)·2^(−1)) mod q_j`。记 `c_*` 为中心观察纤维轨迹总数，`C` 为所有观察相同的无序不同轨迹对数。PREFIX-884 给出 `C≡c_*/2 (mod 2)`；PREFIX-885 给出广义 CRT 完整中心计数。

这是六维原生 Heartbeat World 中声明为**辅助、有限、有序来源观察器**的整数模型；模余数、中心纤维相同均不作为原生 Cell/Link/Port 等价，不允许丢弃未来操作所需的来源、复合方向和关系残差。

## 定理 886-A：全部奇模数的中心补码折半

令 `L=lcm(q1,q2)`，`h=floor((N−1)/L)`，`Z=2 floor((h+1)/2)`。令 `A_i` 为满足
```
0 ≤ x < N,   x mod q1 = r1,
(x+2^i) mod q2 = r2,   bit_i(x)=0
```
的整数 `x` 的数量。则对所有正奇数 `q1,q2`：
```
c_* = Z + 2 Σ_{i=0}^{p−1} A_i
C mod 2 = (floor((h+1)/2) + Σ_i A_i) mod 2.
```

**证明。** 中心零步轨迹要求 `2x−(N−1)` 同时被 `q1,q2` 整除。该差为奇数，在 `[−(N−1),N−1]` 内，因此全部零步数恰为 `Z`。每条中心非零轨迹唯一属于来源位 `i` 和方向 `+2^i` 或 `−2^i`。补码 `J` 把 `+2^i` 轨迹一一映至 `−2^i` 轨迹，且中心余数在各端口下保持固定；故两个方向各有恰好 `A_i` 条。相加后应用 PREFIX-884 的中心奇偶式即得。全证未使用任何数据拟合。□

当 `g=gcd(q1,q2)>1` 时，因为中心条件强制 `g | (2y−2x)`，而单翻转使 `2(y−x)=±2^{i+1}`，与奇数 `g>1` 矛盾，所以所有 `A_i=0`，恢复 PREFIX-885-A。此处保留具名来源与零步的互斥计数。

## 定理 886-B：互素且 `q1q2≥N` 的单模逆位索引

假定 `gcd(q1,q2)=1`，`L=q1q2≥N`。设
```
r1=((N−1)·inv(2,q1)) mod q1,
r2=((N−1)·inv(2,q2)) mod q2,
v=inv(q1,q2)                         (q2=1 时按模1唯一类 t=0),
t_i=((r2−r1−2^i)*v) mod q2,
x_i=r1+q1*t_i                         (0≤t_i<q2).
```
则
```
A_i = 1{ x_i < N and (x_i & 2^i)=0 },
c_* = 2 Σ_i A_i,        C mod 2 = (Σ_i A_i) mod 2.
```
每组模数只求一次模逆，再进行 `p` 次乘法取模、范围检查与来源位检查；算术操作复杂度为 `O(log q2+p)`，独立于整个 `N(p+1)` 轨迹数。

**证明。** 正向翻转的中心条件等价于 `x=r1+q1t` 和 `q1t ≡r2−r1−2^i (mod q2)`。互素性保证 `t` 在模 `q2` 下唯一，取代表 `0≤t_i<q2` 得唯一 `x_i∈[0,L)`。因为 `L≥N`，区间 `[0,N)` 至多包含这个代表，无第二个 `x_i+jL`。位条件精确判定 XOR 翻转方向；且位 `i` 为0时 `x_i+2^i<N` 自动成立。这里 `L≥N` 意味 `h=0`，故 `Z=0`。将判据代入定理886-A即得。□

这个位索引是 PREFIX-885 的广义 CRT 两方向计算的严格式简化，保留复合模数 `q1q2` 和 CRT 耦合，不将联合观察还原为孤立端口。

## 新的明确有限域性质（886-C）

对 `p=32`、两个有序奇数模数各取 `[523001,524287]`，精确整数 C++17 完整循环遍历了 `644²=414736` 组。

- `gcd=1` 的 `336462` 组均有 `q1q2>N`。直接使用定理886-B **只计正向来源位**；这336462组的中心重数最大值经全域枚举是 **8**，恰有 **54** 组达到该值。由此本有限域互素模数的中心纤维至多包含4个补码成对的具名转移。
- 互素组中有 `59658` 组满足奇碰撞谱；其余 `276804` 组为偶谱。
- 非互素组 `78274` 组按886-A零步闭式计算，其中 `g≤63` 的 `75616` 组均为偶谱，`g≥65` 的 `2658` 组中 `2022` 组为奇谱。
- 合计奇谱 `61680`、偶谱 `353056`，与 PREFIX-885 的**不同计算路径**在全部414736组的各项分布一致。中心纤维重数的完整频数表也相同。该检验是一项对已有 PREFIX-885 高端证书的独立算法交叉验证，不重复计入排除总数。

极值例子：`q1=523007,q2=524027`，中心余数 `r1=278409,r2=283015`，恰有4条正向单来源轨迹（每条还有唯一补码配对），对应
```
i= 2: (1610093955,1610093959)
i=10: (1610616962,1610617986)
i=18: (1744506754,1744768898)
i=28: ( 603828487, 872263943)
```
每对均满足 `x mod q1=r1`、`y mod q2=r2`、`y=x XOR 2^i`，另外4条为 `(N−1−x,N−1−y)`。由这8条可构造至少 `binom(8,2)=28` 个不同轨迹碰撞对，作为可直接复核的具名见证。对整个互素高端有限域，定理886-B的普适符号上界为 `c_*≤2p=64`；更强的 `c_*≤8` 仅由本次完整指定范围扫描证成。
