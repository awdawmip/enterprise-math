## 1. Exact rooted cut oracle
Let P be a finite port set, c_p positive integers, E_i nonempty subsets, H_i a same-support label class, S a fixed independent prefix with counts s_i, and m_i the number of remaining labels. All supports and original labels are kept; skipped labels do not enter counts. Strict Hall means f_v(U)=sum_{i:E_i subset U} v_i <= c(U)-1 for every nonempty U subset P, where v denotes selected counts. A selected prefix and subsequent legal choices form the matroid restriction/contraction from GCN.

Given current independent v and any class i, define
  lambda_i(v)=min_{U superset E_i} [c(U)-f_v(U)].
Build a directed network with source a, sink b, class nodes j with v_j>0, and port nodes p. Edges a->j have capacity v_j; j->p for p in E_j have capacity M; p->b capacity c_p; a->p for p in E_i capacity M. Take M=1+sum c_p+sum v_j. A feasible source side with all ports and class nodes has cut capacity sum c_p<M, so no minimum cut crosses an M edge. For any fixed admissible port set U superset E_i, minimizing over class membership includes exactly all positive-count classes supported inside U, and yields cut value sum v_j+c(U)-f_v(U). Thus lambda is the max-flow value minus sum v_j. The source-reachable vertices of a terminal residual network form the inclusion-minimal minimum source side: every mincut must contain all residual-reachable vertices, and this reachable cut attains the flow. Its port projection U_i is the intersection of all minimizing port sets; conversely every minimizing port set has an optimal cut lift. Hence the oracle simultaneously returns the exact integer slack and the unique least minimizing port set.

## 2. Bulk basis and persistence theorem
Start v=s, B empty, process each active class i once, in any fixed order. Query the oracle and append a_i=min(m_i,lambda_i(v)-1) labels of that class to B, then increment v_i by a_i. This is precisely the largest legal bulk insertion: all cuts containing E_i lose a_i slack uniformly, all others are unchanged. The prefix remains independent. If a_i<m_i, the returned least minimizer U_i is now tight (slack 1) and blocks the next label. All later insertions preserve independence and therefore none can have support contained in U_i. Consequently f_v(V) remains unchanged for every V subset U_i after this point. The final B is maximal on remaining labels and hence is a basis by GCN matroid augmentation.

Persistence: at the instant of blocking, U_i is the least tight set containing E_i (the insertion shifts all rooted slacks equally). At the end, consider any tight V containing E_i. Because E_i is nonempty, U_i intersect V is nonempty. For independent v, the slack function c(U)-f_v(U) is submodular (c modular, f supermodular) and is >=1 on nonempty sets. Thus if U_i,V are tight, their intersection and union are tight. The intersection lies within U_i and has unchanged count since blocking; it was already tight then. Leastness at blocking gives U_i subset U_i intersect V, hence U_i subset V. Therefore U_i is still the least tight cut containing E_i at the final basis. No additional flow, tight-row enumeration, or later recomputation is needed. This holds for an arbitrary legal selected prefix S and arbitrary skipped labels (with m restricted to the remaining population), including loops, classes entirely inserted, and empty remaining set.

## 3. Final exchange graph from insertion-time certificates
For a nonbasis label x in a blocked class i, and any final basis label y in class j, B-y+x is legal in the minor iff every tight cut containing E_i contains E_j (GCN exchange proof; nontight cuts have at least one slack unit). By the least-tight-cut result this is equivalent to E_j subset U_i. No later basis labels enter U_i, so at blocking we may immediately join i to every currently positive B_j with E_j subset U_i. These are exactly all final basic-circuit graph edges at class level. The connected components are the finest direct-product partition respecting the original support classes by GCN's component theorem; all fundamental circuits stay in a component, the ranks add and every combination of local independent sets is independent globally. This also returns explicit exchange witnesses: store U_i and class counts, and lift to actual basis labels via original IDs. For the declared observer (all remaining label choices and finite arbitrary legal select/delete minors) decomposition is exact. Individual label objective and provenance are separately retained; no inference about phases, native paths or physical residual attribution.

At most k_active max-flow computations, rather than a basis pass plus another pass for blocked classes, and no 2^|P| explicit port-subset rows. Each network has <=|P|+k+2 vertices and <=k+sum |E_j|+2|P| arcs (before reverse arcs), with integer capacities of bit length O(log(sum c+sum v+1)). Edmonds-Karp implementation gives polynomial O(V A^2) graph operations per flow, plus graph construction, safe integer arithmetic and O(k sum |E_j|) worst-case membership checks over the blocked classes, and component union/find. The implementation does not expand capacity copies. The explicit small replay uses JS safe integers; unbounded integer implementation would need corresponding integer bit costs. Retaining all cut masks uses O(k |P|) bits with packed masks; the code uses boolean arrays, not packed physical storage. The number of flows is an exact bound, not a measured end-to-end acceleration claim. Subsequent Pareto optimization can use GCN's local fronts and convolution; it still has potentially large local/output cost. No full large-component DP or general polynomial global optimization claim.
