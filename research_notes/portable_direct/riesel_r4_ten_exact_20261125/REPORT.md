# R₄ 十预算：完全观察器与最高必要阶1440

固定历史 R₄ 的74个根坐标、旧字典 P 和 Fₙ(a)=a²2ⁿ−1。原数学对象来自 EM-DIRECT-970E1C / RA-D2EC212845B63844081F9A14。以下是直接推导与独立精确复算，不是正式项目 Review。

**定理。** 在 R₄ 上判定 δ_P(a)≤10 的最小充分模数是八组整数载体乘积的平方自由核 M。对任意正整数 N，模 N 的根余数足以判定，当且仅当 M∣N；即使观察模 N 的全部未来项，也恰是同一条件。最大必要二的乘法阶是 **1440**，由九预算的720恰好翻倍。结果不以分解载体为前提。

## 六尾类的全阶界

[十预算前缀正规化](https://github.com/awdawmip/enterprise-math/blob/a5f7005b1ebcf3b05053f7cb57ad5e1752ced159/research_notes/portable_direct/riesel_r4_ten_prefix_20261125/REPORT.md)允许使用5、13、19、73，然后在 n=32+36w 上选至多六类覆盖 B={0,3,5,8,10,15,21,23,26,28,30,31,33} mod35。沿用[原 R₄ 尾部库存](https://github.com/awdawmip/enterprise-math/blob/9b3680ea1c07b1364af5464a3469313ee616d408/research_notes/portable_direct/riesel_nine_frontier_20261124/r4/tail_proof.md)：固定活跃类为 w=1 mod2、w=1 mod3、w=2 mod4；自由 h=7 可供五行，其他自由周期 h≥9 且 h≠10。这里 h=ord_q(2^36)。

取任意包含极小的局部覆盖及某类的私有点。限制在该点所在 L 进程上，目标的有效周期 m=h/gcd(h,L)。在与公周期相容的 CRT 数位上，对于每个 p^e∥m 的每层 j=1…e，只改变第 j 个 p 进位，产生 p−1 个需要其他类覆盖的点。命中一个此类变化点且避开私有点的类，其相对期至少能观察该位（被 p^j 整除）；同一类不能见证不同变点：若两变点最近的变位层不同，同层较浅的情况必不合，若同层不同数字也无法同命中，若不同质数则同命中迫使原私有点也命中。故至少需要 Σe(p−1) 个剩余槽。取 L=35、最多五槽，推出 h≤1120。

逐个选择固定类和使用的不同 h=7 行，从孔集删掉其覆盖，令 L 为35与已选固定类周期的最小公倍数。对剩余任意目标 h，在 L 的每个相容基本格上均只命中相对期 m 的一个类，最大可覆质量是相容基本格最大个数除以 m。把目标质量、每个私有点数位要求下的最好质量和未受限制槽的最好质量相加。若这一上界仍小于缺口，就排除该 h。这是对所有素数的容量放松，故保守且不取经验素数上限。49个分支仍有泛用类，最大公周期1680。

## 完整相位谓词

精确搜索按未覆格选命中类分支，后续排除先前兄弟，逐项测试私有点。两种相反遍历得到相同67个泛用覆盖几何；合并自由槽重复、吸收超集后有42个项。写 h:{b,…} 为逐相位需求。固定类不作为额外根条件：

- 五个模七行0、1、2、3、5，每行独立选择 h=7 整行或 h=14 对应偶数半行（32项）；选择偶半行时可统一加入固定奇数类，仍至多六尾类。
- 7:{0,1,3,5} 且 35:{23,30}，或 7:{0,2,3,5} 且 35:{8,15}。
- 12:{0,8}、20:{0,8,16}、12:{0}与24:{8,20}、12:{8}与24:{0,12}、16:{0,4,8,12}，以及对20:{0,8,16}任选一槽 b 换成40:{b,b+20} 的三类。八项均可加固定2、4类，含12/24的三类还用固定3类。

对于原始二的乘法阶 d，从2^d−1除尽同时整除任一个2^(d/p)−1（p 为 d 的素因子）的素因子，再除尽固定74枚素因子。各 h 的 C(h) 是对应载体之积，非空阶由程序证书列出。h:b 命中当且仅当 gcd(C(h),a²·2^(32+36b)−1)>1。同 h 两不同相位必由不同素数提供。M=rad(∏C(h))，最大阶 d=1440。第一未来项即可恢复所有相关奇素数上的 a²，故充分。对每一个 h，可取含该槽且库存充足的项；将任意目标素数放入该槽，其余使用各自不同素数，其他全部置零。同根条件 CRT 可实现。将目标关掉后，42项构成反链，不会有其他项被剩余槽包含；将共同条件扩展到任一不含目标的 N 仍可 CRT 实现。这证明每个素因子都必要。

对于容量，h=14 可使用一个槽；h=16 有阶192的一枚及阶576的3457、816769和另一个互素非平凡因子，足够四槽；h=35 至少有870031、983431（必要时在不同槽用）；h=40 至少有37441、170251201（均试除及阶验证）。h=7,12,20 的已认证组沿用九预算，h=24 至少有两枚来自原阶864的非平凡互素分解。证明不依赖本轮新的大因子分解。

## 完整因子表、数值最小模数及精确十成本密度

在前述不依赖分解的判据之后，八组载体已完全分解。有效期 h 按 7、12、14、16、20、24、35、40 排列，分别有 **5、3、5、5、5、2、10、8** 枚不同素数。因此最小充分模数是 **43 枚素数**之积，长度 **2417 二进位、728 十进位**。全部素数以标准库纯整数递归证书核验（193 个节点），逐层回乘原载体并核每枚乘法阶。因子发现可利用 [Cunningham 主表](https://homes.cerias.purdue.edu/~ssw/cun/pmain1126.txt)的 252+、288+、432+、720+ 项；最终结论以本次直接复算为准。

素性核验使用减一 Pocklington；若减一已知部分不足，使用加一二次环验证。加一证书固定无零公因子的 D。对 n 的每个潜在素因子 r，模 r 的二次环中范数一子群大小为 r−1（分裂）或 r+1（非分裂）。对 n+1 已认证因子 F 的每个 p，模 n 核对某范数一元素的 n+1 幂为1，而其 (n+1)/p 幂的两坐标与1的差的公因子为1。因此在每个 r 上都有相应的满 p 次幂阶，F 必整除同一个 r±1。F>⌊√n⌋+1 时排除任何 r≤√n，故 n 为素数。三个加一证书和其余证书均在 lucas.json 逐项冻结。

42项可分成四个互不共享素数的子事件，周期组分别是 (7,14,35)、(12,24)、(20,40)、(16)。每个素数的相关 w 相位各占两枚根余数，按有限状态的相位占用前进。每支仅统计存在一个模板，故各模板重合的同根只计一次；反转组权重遍历得到相同有理数。四支联合密度用各自补集的乘积。九预算的已知判据也在同一空间重算，精确复得原密度 8.9428657228405933706561…×10⁻¹⁸。最终：

```
ρ_{exact 10}(R₄) = 1.2351619769638657214486613953010962895…×10⁻²¹.
```

约每 **8.0961×10²⁰** 个 R₄ 根有一个精确十成本根。此为整个 R₄ 的相对自然密度，分子和分母见 density.json。这里是 `P(≤10)−P(≤9)`，没有把新增几何或字典计数当作互斥根事件。

复算：`node replay.js`（几何、载体、实际切换）；`python verify_primes.py`（纯标准库素性及阶）；`python density.py`（精确分数）。

## 全 R₄ 最小的精确十成本根

以历史正起点 A₄ 与步长 S₄ 写 a=A₄+kS₄。全族的最小精确十成本根是 **A₄ + 229,695,347,680,564,422,140 S₄**，共 **375 位**。其新增字典为 {5,13,19,73,38737,649657,92737,21169,2627857,1009}；五枚自由素数依次对应 7:0、7:1、14:2、14:10、14:12。此根不需要阶1440。

有限完全判据允许枚举每个模板的素数槽和两个符号，将 a≡±2^{−(16+18b)} mod q 转成 k 同余。CRT 的最小非负代表是该分支中所有非负解的下界，因此严格超过候选的分支可以关闭；末端扫描上界前所有周期提升，同时排除完整九预算谓词。整合脚本正反搜索一致；独立固定槽、反向 CRT 的 `minimum.py` 从0复核到候选，只有它一个精确十根。

**即使把所有素数全部重选，最小总成本仍是30。** 整合复算以30枚素数覆盖完整20,160个指数位置；见证由30个实际整数项组成，最大指数2912。435对 gcd 全等于1，强制任意覆盖至少30枚。覆盖证和全整数见证索引见 combined-certificate.json。

若禁用四枚阶1440素数，只有 (20,40) 子事件改变。在该组的密度差乘上其他三个子事件均失败的概率，即得到真正依赖1440的部分；其密度为 7.84415920454884748806578…×10⁻²³，占所有精确十根的 **6.350712984082…%**。这个比例不是简单数含阶1440的字典，而是排除了同根上低阶字典可能替换的情形。
