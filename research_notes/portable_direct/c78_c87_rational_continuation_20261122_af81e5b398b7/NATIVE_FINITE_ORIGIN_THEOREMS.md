## 2. 全原点分区定理

设一个有限原目录包含 N 个安排，方案 d 的第 j 次读数为正有理数 g_(i,j)^(d)，i=1,...,N。每轴取同一全局原点 u_j∈[0,1)，使用原半开格约定

\[
q_{i,j}^{(d)}(u_j)=\lfloor 2^p g_{i,j}^{(d)}+u_j\rfloor.
\]

比较多个方案时，本轮给各方案使用同一个 u=(u_0,u_1,u_2)；三个轴的 u_j 可彼此独立任意选择。
同一安排的整个三标签向量进入一个共同 bucket；只有 bucket 中恰好一个原安排时，该安排才唯一。

对有理数 x 写 x=k+f，其中 k∈Z、0≤f<1。则：

- f=0 时，floor(x+u)=k，覆盖整个 [0,1)；
- f>0 时，floor(x+u)=k+1_{u≥1-f}。

所以每个标签仅在一个有理断点 1-f 变化。将同一轴上全部安排、全部所比较方案的断点合并，与 0、1 一起排序，得到有限半开区间 [a,b)。标签在其上准确不变，包括左端点 a。三个轴作笛卡尔积，整个 [0,1)^3 被有限有理半开盒无缝覆盖。

**结论：** 每个盒只需计算一个有理代表，即可准确得到所有连续原点下的唯一安排数、方案差的最小值与最大值。所有断点本身归入右侧盒，未漏掉零测边界；u=1 与 u=0 相差所有标签统一加一，故模格宽只取 [0,1) 完整。

这个命题保留全部竞争者，未把各碰撞事件当作独立事件。

### 实现中的等价优化

先按首末两个标签给原安排分组。首末已唯一的安排不受中间标签影响；只对剩余多安排组，逐个中间原点区间重新统计中间标签的单例。首末全部唯一时，可以一次覆盖该首末盒下的所有中间区间。
优化只省去确定相等的计数，完整相位盒数仍准确记录。

程序 origin_states 用 Fraction 生成断点，扫过断点时同步更新所有受影响标签。每个极值见证另用原始有理 g 重新形成三标签 Counter 核对。

## 3. 新的原有限目录严格全原点结果

固定 c=8，全部安排为 2≤W≤V≤8，总数 N=28。
固定首末库存 8、24，比较：

| 方案 | 三次库存 | 中间位置 |
| --- | --- | --- |
| Q | (8,12,24) | 1/4 |
| M | (8,16,24) | 1/2 |
| E | (8,23,24) | 15/16 |

三种方案都使用同一组全局原点 u∈[0,1)^3。每个 p 的公共分区区间数为 29、85、29，完整覆盖 71,485 个半开相位盒。

### p=12

准确遍历结果：

| 量 | 全原点最小值 | 全原点最大值 |
| --- | ---: | ---: |
| U_Q | 22 | 28 |
| U_M | 24 | 28 |
| U_E | 7 | 26 |
| U_Q-U_M | -4 | 4 |
| U_Q-U_E | 0 | 19 |
| U_M-U_E | 2 | 21 |

因此已有一个直接关于原有限库存的全称结论：

\[
\boxed{U_M(u)-U_E(u)\ge2
\quad\text{对每个 }u\in[0,1)^3.}
\]

以原全目录归一后，唯一率差至少 2/28=1/14。

极端差可以用可读有理原点实现：

- u=(1/8,29/32,601/1024)：(U_Q,U_M,U_E)=(28,26,24)，差为2；
- u=(11/32,1/64,0)：(U_Q,U_M,U_E)=(24,28,7)，差为21。

这不是渐近结论，也不是抽样八个原点的外推；每一个连续原点都已经落在被准确覆盖的有限盒内。

### 共同原点是比较条件

若允许两个方案另选两套原点，上述严格优势不成立。因为：

- 中点取 u=(0,0,0)，有 U_M=24；
- 靠端点方案取 u=(3/8,99/128,3/4)，有 U_E=26。

这时差为 -2。单独范围与共同原点差的范围已经分别保存，不能混用。

### p=13

同样的全原点分区给：

| 量 | 最小值 | 最大值 |
| --- | ---: | ---: |
| U_Q | 26 | 28 |
| U_M | 28 | 28 |
| U_E | 20 | 28 |
| U_M-U_E | 0 | 8 |

中点方案对所有原点识别全部28条；靠端点方案在一些原点也可识别全部28条，所以此时共同原点比较是非严格。

## 5. 全原点全目录识别的准确最低精度判据

设某个读数方案的原有理向量为 g_i∈Q^d，N≥2。定义

\[
d_*=\min_{i\ne k}\max_j|g_{i,j}-g_{k,j}|.
\]

则

\[
\boxed{
\text{每个原点下全部安排唯一}
\quad\Longleftrightarrow\quad
2^p d_*\ge1.
}
\]

**证明。** 两个实数 x,y 能在某个共同原点 u 下满足 floor(x+u)=floor(y+u)，当且仅当 |x-y|<1。
充分性可由长度为 1-|x-y| 的原点区间直接构造；等号 |x-y|=1 时永远相差一格。
各轴原点独立可选，所以一对读数向量能在某个原点相撞，当且仅当所有坐标差都严格小于1。
对所有原安排对取否定，就得到所述充要条件。输入有理时，若存在碰撞，见证原点也可取有理数。证毕。

因此 p 的单调性来自这个准确判据，不依赖“任意平移的粗细格必然嵌套”这一错误说法。
若 d_*=0，则不同安排的全部读数相同，没有有限精度可使全目录全原点唯一；若 N=1，则 p=0 已足够。

对 c=8、首末8与24，每个方案准确比较全部378对安排，得到：

| 三次库存 | 最小非负整数 p |
| --- | ---: |
| (8,12,24) | 14 |
| (8,16,24) | 13 |
| (8,23,24) | 15 |

完整 d_* 有理分数、实现它的安排对及 2^p d_* 的准确值在 JSON 中。
中点 p=12 时 u=(0,0,0) 只识别24条，p=13则对全部原点识别28条，所以边界严格确定。

这三个有限最小值针对“所有原点、每条安排都识别”的目标；它们不是 C78 多数识别的渐近位数系数。
