## Problem and result
GCO proved persistence along monotone basis insertion. Here two arbitrary independent count prefixes v,w on the same finite port set P, positive integer capacities c, nonempty class supports E_j, and same remaining class/label universe can differ by positive AND negative increments. Skips affect remaining population only. Define h_v(W)=c(W)-sum_{E_j subset W}v_j, lambda_v(E)=min_{W superset E} h_v(W) for a nonempty root E. Let U be the least rooted minimizing set at v (intersection of all minimizers), supplied by GCO's closure-network max flow. It exists by rooted submodularity. Let d_j=w_j-v_j, Delta(W)=sum_{E_j subset W}d_j. Define:
  O=sum_{E_j not subset U} max(d_j,0);
  I=sum_{E_j subset U, E_j not subset E} max(-d_j,0);
  B=O+I; h=h_w(U)=lambda_v(E)-Delta(U).
All sums integer. Root-contained classes occur in every rooted cut and cancel.

Theorem A (sensitivity sandwich and exact cache reuse):
  max(1,h-B) <= lambda_w(E) <= h.
If B=0 then lambda_w(E)=h and U is still the least minimizer at w.
Proof: for every rooted W, Delta(W)-Delta(U) <= B: only positive terms newly present outside U or negative terms lost inside U can contribute positively; root-contained terms cannot disappear. Thus h_w(W)-h_w(U)=h_v(W)-h_v(U)-(Delta(W)-Delta(U)) >= -B. Independence gives floor 1; using W=U gives upper bound. If B=0, U minimizes and every w-minimizer must also minimize at v, hence contain U. This is a sufficient condition, not necessary. For all rooted W strictly contained in U, old gap >=1 by integrality and leastness.

Theorem B (tight-container localization and exact repair):
If h_w(U)=1, every root-minimizer at w has slack 1, and its intersection with U is tight by submodularity and nonempty root. The least new minimizer is contained in U. Consequently the exact answer is obtained using GCO's rooted network restricted to ports U and classes supported in U, excluding all other classes. In particular, if I=0 then no proper rooted subset V of U can become tight: Delta(V)-Delta(U)<=I=0, so h_w(V)-h_w(U)>=h_v(V)-h_v(U)>=1. U remains least regardless of O. If I>0, run local flow or another exact oracle within U. This also works for an arbitrary tight container U for localization (without the I=0 reuse test unless old leastness holds). A cheap sufficient test for the tight case is equality of all inside class counts, regardless of changes outside U. The repair retains root, exact slack and exact least cut, not merely feasibility; hence every GCO exchange predicate is safe when using it in the same independent state and rooted query.

Counterexample: ports a,b with capacities 2,1; class supports {a}, {a,b}; old counts (0,2), new counts (1,1), root {a}. Both are independent (all nonempty cuts have slack>=1). Old least root cut {a,b} slack 1, new least root cut {a} slack 1. Thus equal credit at the cached cut, even with unchanged true minimum slack, does not certify the least cut or exchange relations. This also shows why the inside-negative term matters. No assertion that any failing bound forces a changed answer.

## Executed algorithm and evidence
For each old cached least minimizer: compute h,O,I via class mask checks; if B=0 reuse; else if h=1 and I=0 reuse; else if h=1 run restricted closure network; else run full rooted flow. Compare every returned least cut and slack to exhaustive raw port-cut reference for w. Old cached cut itself computed by GCO-style integer Edmonds-Karp and independently verified. No need to expand capacities. O(k) per query mask operations plus bit-length costs, plus exact fallback flow on the restricted or full graph; memory holds old cuts and counts, not all port cuts. Old cache construction is NOT counted as a new-query saving. Reuse pays when the old cut is already available; for isolated paired computations building old+new is a different baseline. No runtime or physical memory measured.
