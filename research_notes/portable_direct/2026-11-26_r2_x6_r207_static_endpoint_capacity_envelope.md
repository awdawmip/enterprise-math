## Theorem (static endpoint lower capacity envelope)

Let P be all original endpoint rays, including endpoints of disconnected component pieces, spanning the auxiliary 3D coefficient space. Fix an original root ternary-sign class C of nonzero normals r on P. Fix one child side sigma. For each labeled support, clip its actual components first, retain the first and last endpoints of the retained pieces, exactly as in R182. The retained labels and the *origin descriptors* of those endpoints are constant on C: an endpoint is either a fixed original ray p or a positive linear combination lambda*p+mu*p' (lambda,mu>0, depending on r) of the two original rays of the intersected component, since their strict root signs are opposite. Root-zero original endpoints are kept as fixed endpoints. The descriptor need not determine the moving endpoint coordinate.

For every nonzero candidate second normal q, let f(p)=sign(q dot p). For a fixed descriptor define its forced sign as f(p). For a moving descriptor define forced sign + if both signs are nonnegative and at least one is positive; - if both signs are nonpositive and at least one is negative; otherwise 0. If both signs are zero the real moving sign is zero; if opposite, 0 is merely 'not forced', not an assertion of a zero observer. The positive combination formula proves all forced nonzero signs are actual, for EVERY r in C.

Count L_+(f), L_-(f) as the number of retained support labels for which at least one retained endpoint is forced +, respectively -. The R205 root mask identity gives true child support counts n_+,n_- as the number of support labels with at least one actual +, respectively -. Hence n_+ >= L_+(f), n_- >= L_-(f) simultaneously. For a depth-five necessary capacity recursion the first subsequent split must satisfy n_+,n_- <= 15. (Here all tested states have N>5, so the relaxation cannot terminate via its small-state base.) Consequently if every realizable nonzero observer sign vector on P satisfies max(L_+,L_-) >= 16, then the entire sigma child is impossible on C, and the whole original root class is excluded by R182. The rule works for any rank of root class, no determinant event subdivision or dynamic endpoint pattern enumeration required. This is a one-sided relaxation: a passing f may not extend to a capacity-eligible moving sign vector; retain passing classes for exact follow-up. No support identity or six-pair BRC observation is collapsed; only the safe lower bound is used to reject.
