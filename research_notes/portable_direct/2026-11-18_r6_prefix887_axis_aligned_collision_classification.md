# PREFIX-887 — 具名 XOR 轨迹的单端口全域碰撞判据、阈值与19位精确分类

日期：2026-11-18（Asia/Shanghai）；研究线：进取数论研究6 / 独立 BRC 整数辅助观察器。继承 PREFIX-881～886 的轨迹与观察语义；科学输入保留冻结 pin `f42f2906d77f24085c123f3ccfe9667d41caa96d`。保留 P000、Heartbeat World 六维原生关系、来源/方向/时间的类型区分；下述整数模观察器是明确声明的有限辅助模型，不重新定义原生 Cell、Link、Port 或时间。

## 研究问题与模型

令整数 `p≥2`，`N=2^p`，具名来源为位索引 `i=0,...,p−1`。合法的**有序**轨迹只有 `(x,x)` 与 `(x,x XOR 2^i)`，`0≤x<N`。两个固定正奇数模数 `q1,q2` 的观察是 `Φ(x,y)=(x mod q1,y mod q2)`。

定义轴对齐碰撞：
- `V`（竖向）：不同轨迹 `(x,y)≠(x',y)`，终点完全相同，且 `x≡x' (mod q1)`；
- `H`（横向）：不同轨迹 `(x,y)≠(x,y')`，起点完全相同，且 `y≡y' (mod q2)`。

两种均是完整双端口观察的**真碰撞**，其保留的有序轨迹、来源位均不同或起点不同。它们只是完整碰撞集合的可独立判定的子类；无轴对齐碰撞仍可有 PREFIX-881/882 的一般整数格碰撞。

## 定理887-A：单端口轴对齐碰撞的充要条件

令 `q` 是正奇数，`p≥2`，定义
```
A_p = { q odd positive : ∃h∈{1,...,p−1}, q | (2^h−1) or q | (2^h+1) }.
```
则对**任意**另一端口的正奇数模数：
1. `V` 存在当且仅当 `q1∈A_p`；
2. `H` 存在当且仅当 `q2∈A_p`；
3. 因此一组有序模数 `(q1,q2)` 存在轴对齐碰撞当且仅当 `q1∈A_p` 或 `q2∈A_p`。

**必要性。** 对任意合法轨迹令 `d=y−x`。则 `d∈D_p={0}∪{±2^i:0≤i<p}`，其符号须服从被翻转位；用这个较大的代数候选集合只会放宽必要条件。竖向碰撞的两个轨迹终点同为 `y`，故 `x'−x=d−e` 是 `q1` 的非零整数倍；横向碰撞对应 `y'−y=e−d` 是 `q2` 的非零整数倍。若 `q>1` 为奇数，`d−e` 非零且被 `q` 整除时，`d,e` 不能一方为零，也不能是相同来源位的两个值，因为这两种差仅有二进制幂因子。于是存在不同位 `i>j`，且 `|d−e|=2^j(2^{i−j}−1)` 或 `2^j(2^{i−j}+1)`。由于 `q` 为奇数，`q | (2^{i−j}±1)`，其中 `1≤i−j≤p−1`。若 `q=1`，则 `q|2^1−1`（`p≥2`），亦属于 `A_p`。

**充分性，明确具名见证。** 设 `1≤h<p`：
- 若 `q1 | 2^h−1`：取 `V` 的两条轨迹 `(1,1+2^h)` 与 `(2^h,1+2^h)`；第一条翻转具名位 `h`，第二条翻转位 `0`。起点之差为 `2^h−1`，终点相同。
- 若 `q1 | 2^h+1`：取 `(0,2^h)` 与 `(2^h+1,2^h)`；分别翻转位 `h` 向上和位 `0` 向下。起点之差为 `2^h+1`，终点相同。
- 若 `q2 | 2^h−1`：取 `H` 的 `(0,1)` 与 `(0,2^h)`，共同起点0、两终点相差 `2^h−1`。
- 若 `q2 | 2^h+1`：取 `(1,0)` 与 `(1,2^h+1)`，共同起点1、两终点相差 `2^h+1`。

全部状态都落在 `[0,2^p)`，每条非零跃迁恰翻转所声明的一个位；余数一致。故充分。证毕。

**推论887-B（位数阈值）。** 对任意固定奇数 `q>1`，定义 `h_*(q)=min{h≥1:2^h≡1或−1 (mod q)}`。该最小值有限（`2` 在模奇数 `q` 的乘法群内有有限阶）。对任意 `p≥2`，此端口出现上述轴对齐碰撞恰在 `p≥h_*(q)+1`。该结论给出最早**可能使用的具名位宽**的完整分类；`q=1` 在 `p≥2` 恒满足定理。

## 定理887-C：19位所有有序奇数模数组合的全域轴对齐排除计数

取 `p=32`、`Q=2^19−1=524287`、两个模数各独立取正奇数 `1≤q≤Q`。共 `M=262144` 个可选奇模数、`M²=68719476736` 个有序参数对。令 `A=A_32∩[1,Q]`。

以完整整数枚举且两种不同实现交叉验证，得到：
```
|A| = 385;
|{q≤Q odd: q | 2^h−1 for some 1≤h≤31}| = 304;
|{q≤Q odd: q | 2^h+1 for some 1≤h≤31}| = 121;
intersection = 40.
```
由定理887-A及一次容斥，**恰有**下列数目的有序模数组合出现轴对齐碰撞：
```
M² − (M−385)² = 2×262144×385−385² = 201702655.
```
剩余 `68517774081` 组不属于**这一个轴对齐充分排除类**，可继续交给 PREFIX-881/882 的完整碰撞判据处理。本数是独立证书的精确覆盖数，尚未与 PREFIX-874～886 的历史碰撞排除集合交叉去重，不记作新增净排除。

**恰好19位宽的模数子域。** 若进一步要求每个模数的最高位实际为1，即 `2^18≤q1,q2≤2^19−1`，则有 `131072` 个奇模数，其中 `A` 恰有 `24` 个；同一充要定理直接给出 `2×131072×24−24²=6290880` 组有序组合出现轴对齐碰撞。此数属于上述 `201702655` 组的真子集，是更贴近固定19位宽问题的单独证书。

特别地 `q1=524287=2^19−1` 时，对任何正奇数 `q2`，两条轨迹 `(1,524289)` 与 `(524288,524289)` 就构成完全相同的双端口观察；可用作无须扫描另一端口的固定见证。
