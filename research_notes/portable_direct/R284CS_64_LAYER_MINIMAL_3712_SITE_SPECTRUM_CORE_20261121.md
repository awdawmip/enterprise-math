# R284CS — 冻结 Port 观察器64阶极值谱的唯一最小3712点核

日期：2026-11-21。状态：**AUTHOR_PROVED / EXACT_FINITE_CERTIFIED / NOT_REVIEWED**。

## 研究对象与冻结输入

研究对象仍为 R284CO—R284CR 的34位辅助 Port 圆周观察器，模数 \(P=17179869143\)，64条带标签圆弧及原65,536个互异码字 \(X\)。复用原固定输入 \(D=(1120832,6,13,1651128)\)、\(Z=(0,390139,394465,1497639)\)、SELECT=(0,1,2,4,5,6)，码字 SHA256 固定为 b6ce76b2c08b9ec6b79ec83173befd2589928ca7c636643c3eaecd40405f4ff4。

令 \(d_k(x)\) 为码字 \(x\) 到64条带标签圆弧的距离按非减排列后的第 \(k\) 项，\(k=1,\ldots,64\)。对每个固定 \(k\)，再将 \(\{d_k(x):x\in X\}\) 依**不同码字计重数**由大到小排列，第 \(r\) 名记为 \(S_{k,r}(X)\)。

问题：要求同时保留全部64个 \(k\) 的前64名数值与重数时，最少需要保留多少个原始码字？

## 一般唯一最小谱核定理

对于有限码字集合 \(X\) 与任意一族实值观察函数 \(f_k:X\to\mathbb R\)，如果对全部相关 \(k\)，原群体前 \(R\) 名与第 \(R+1\) 名之间严格分离，且前 \(R\) 名各自严格递减，那么全部 \(k\) 的前 \(R\) 名唯一取得者的并集 \(C_R\) 是**唯一包含极小、唯一最小基数**的同时保谱子集。

证明：严格降序使各名次的数值仅由单个原码字取得。任何保留第1至 \(R\) 名数值及其重数的子集必须保留这些唯一取得者；反过来，所有取得者的并集已经包含全群体原最高的 \(R\) 个值，删除其他项不会创造更高值。必要性与充分性均成立。

本模型 \(k=1\) 时全部 \(d_1(x)=0\)。只要核含至少64个码字，\(k=1\) 的前64名零值自动保持；上述唯一性判断应用于 \(k=2,\ldots,64\)。

## 冻结模型精确结论

1. 对每个 \(k=2,\ldots,64\)，**前65个**实际距离值均两两不同，因此前64名都具有唯一见证。在 \(63\times64=4032\) 个(等级,名次)见证槽中，**3392个码字各被使用1次、320个码字各被使用2次**，没有码字被使用3次以上。
2. 全部前64名见证的并集恰好为
   \[
   \boxed{|C_{64}|=3392+320=3712=\frac{29}{512}\times65536}.
   \]
   这是唯一最小的64阶保谱码字子集，占原群体 **5.6640625%**。
3. 令 \(c_r=|C_r|\)，\(1\le r\le64\)。全部64个精确 \(c_r\) 及每层新增见证数已保存为 JSON 证书。代表值：\(c_1=63,\;c_2=124,\;c_3=186,\;c_4=248,\;c_5=310,\;c_8=490,\;c_{16}=982,\;c_{32}=1922,\;c_{48}=2828,\;c_{64}=3712\)。前四项与 R284CO—R284CR 已有证据完全一致。
4. 全部4032个相邻层次截断间隔的最小值是 **1**，唯一发生于 \(k=36,r=56\)，相邻值分别为 **5,143,142,688** 和 **5,143,142,687**，见证码字分别为 **5,650,207,149** 和 **5,537,594,205**。因此随着保留阶数提高，极值见证排序的最小间隔会缩小；不应将此前63/64的低阶鲁棒间隔推广到64阶。

## 计算证据与完备性

复算程序 R284CS_top64_spectrum_checker.py 使用 R284CO 原冻结码字生成和圆弧精确距离函数（整数运算，无浮点）。遍历全部65,536码字、每码字64条圆弧，完成 **4,194,304 次距离计算**；每个 k 的前65名由最小堆保存。逐一核对 \(k=2,\ldots,64\) 的前65名严格单调，以及全部4032个前64名的唯一见证、交叉等级使用次数和64阶核规模。随后对3712点核额外执行 **237,568 次**距离计算，逐级重新生成64个保留名次并与原全群体比较。

按数值升序排列3712个码字，逐个以8字节大端无符号整数串联，SHA256 为：

a0e267546733e53951097484b32cf97ae49472fba905121c5b23612796d10b1c

证书包含全部 \(c_1,\ldots,c_{64}\)、每层不同见证数、每层最小相邻距离、全局最小间距见证、码字复用直方图及冻结输入。所有验证已在本地 Python 3 标准库执行。**Independent Review: NOT_REVIEWED**。
