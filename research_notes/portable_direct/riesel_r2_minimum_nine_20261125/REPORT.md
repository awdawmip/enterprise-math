# R₂ 的全局最小精确成本九根与总成本29

固定历史 R₂、旧二十素数字典 P 和 Fₙ(a)=a²2ⁿ−1。根族的最小正代表为 A₂、固定模数为 S₂，根按 a=A₂+kS₂、k≥0 排序，具体整数见 minimum.py。保留原科学成果归属；本报告是直接证明与精确标量复算，未申报 Native Result 或正式 Review。

## 1. 全族最小值

在整个 R₂ 上，令 δ_P 为固定 P 的最少新增素数。则精确等式为：

```
min {a∈R₂ : δ_P(a)=9} = A₂ + 91,706,206 S₂
 = 1041481530250621475104039030401232746578142688647589383362661338012872918533602728983.
```

这是一个 **85 位**整数。完整新增字典是

```
{5,13,19,73,29,43,181,211,631}.
```

在 n=8+12v 上，除固定四枚外，新素数依次可写为 631: v=2 mod15；181: v=11 mod15；211: v=10 mod35；29: v=2 mod7；43: v=4 mod7。把选定全部 29 枚素数在指数 n 的公周期 20,160 上逐项验证，覆盖每一个位置。该根不满足完整八预算谓词。

任意重选全部素数时，最少总成本依然是 **29**。搜索到29个完整整数项 Fₙ 作为见证，最大正指数 2415；直接计算 406 个两两 gcd 均为1。一枚素数至多覆盖其中一项，故任意覆盖至少需要29枚，与上界相合。见 [total_cost.json](total_cost.json)。这里的结论并非把当前字典的「29项分别不可删除」误当成可任意重选的下界。

## 2. 为什么搜索覆盖全族

[精确根密度与完备判据](https://github.com/awdawmip/enterprise-math/blob/aa1cd83afdfad7a5912df77df1e8cc6a410188c1/research_notes/portable_direct/riesel_r2_exact_nine_density_20261125/REPORT.md)给出全部 102 个自由坐标、低阶两分支和最高阶替代条件。精确九根必有一个九素数不可删字典，且不能满足任一预算≤8模板。低阶分相位在同根上总能换成双 W，因而下述三类覆盖全部可能：

1. 全共相位的42个七尾几何模板（不计已强制的 5、13）；
2. 双 W 的215个五尾局部模板（其余 24 个局部模板的预算≤8，不能见证精确九）；
3. 阶1260的三短格模板，其中至少一个短格由全部五枚已证高阶之一担任。按标记哪一个短格负责高阶展开为三项，同根上重复时合并。

对模板槽 (q,b) 的正负根号条件是 a≡±2^{−(4+6b)} mod q，因此变成关于 k 的两枚明确模 q 余数（S₂ 与所有自由坐标互素）。每个递归节点合并同余，就得到最小非负代表 x 和模数 M。每一正向补全只可能是 x+tM，t≥0；x 已达到当时严格上界就剪枝。最后一层遍历上界内所有倍移，不只考察最小代表。选哪个槽先只是排序；强制用不同素数，两个符号都保留。

第一遍用动态最少可行槽选择，找到候选后缩小上界。第二遍用固定槽序和反向 CRT 公式，从不缩小 10⁹ 的原上界；该有限区间口径为 **0≤k<10⁹**，对三类得到 22、0、1 个互异根，合并共23个。用独立的全有限库存字面覆盖法逐一检查九预算成功、八预算失败，同时与快速 E₈ 模板吻合。[independent.json](independent.json)列出全部23个指数。该区间内没有低于 91,706,206 的精确九根，故全局最小性成立，区间以外不必排除。搜索还严格确定：**真正不可替换阶1260的最小精确九根**在 k=843,067,162；它是该搜索区间内唯一含1260九字典的根，独立按阶≤840的全库存再验失败。全共相位分支另行扩大严格搜索，最小精确九位于 k=171,904,900,453,665；独立固定槽序从 k=0 查至此候选，仅有它一个共相位九模板根。

| 最小根的范围 | 指数 k | 根位数 | 任意重选的精确总成本 | 互素项最大指数 / gcd 核数 |

| 全 R₂ 有全共相位九补全 | 171,904,900,453,665 | 91 | 28 | 2480 / 378 |

第三行的完整根为 1952275477365516098195203130132815891360742062131901175877089412493073004674189600481426693。它仍然必须新增9枚（继续保留全部 P 时）；若允许重选整个字典，旧素数 **281** 可以去掉，周期6720无缺口。28个两两互素实际数列项证明再少一枚不可能。这直接展示相同预算九的两个最小代表可以有不同的总成本。最高阶最小根的完整9素数字典为 {5,13,19,73,43,181,211,631,2521}。
