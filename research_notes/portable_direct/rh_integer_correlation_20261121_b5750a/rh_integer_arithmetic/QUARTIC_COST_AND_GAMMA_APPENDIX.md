Date: 2026-11-21.

## 1. 固定有理厚度下，四次方查询的主指数为 11/12

消费窗口分支 `rh_integer_sparse/NOTES.md` 的幂网格结论：在 `theta=1/2` 时，四次方整数节点保留所需的次幂窗口量词，允许其附加修正为对数量级，而不要求该修正趋于零。

这里仅核对它与本分支端点算法合成后的成本。作如下明确限定：

- 厚度节点 `a_1,...,a_m` 是固定的正有理数；`m` 及它们的分母不随最大端点 `Z` 改变。
- 权重也是固定的，已保留 `sum nu_j=1` 及全部单位修正。
- 每次端点查询采用 `B=ceil(N^(2/3))` 的小前缀和主稿的商递推。采用线性 Möbius 筛时，主稿的算术调用量为 `O(m[N^(2/3)+K sqrt N])`，其中 `K` 是幂和 oracle 的展开/评价成本参数。
- 区间精度、整数根及大整数运算成本另计；这里不把所有精度水平的运算都当成等价的一个比特步骤。

四次方端点为 `N_j=j^4<=Z`，另加有限个边界整数。令 `J=floor(Z^(1/4))`。即使每个端点都独立重算、不共享任何缓存，也有

\[
\sum_{j=1}^{J}N_j^{2/3}
=\sum_{j=1}^{J}j^{8/3}
=O(J^{11/3})=O(Z^{11/12}),
\]

\[
\sum_{j=1}^{J}\sqrt{N_j}
=\sum_{j=1}^{J}j^2=O(Z^{3/4}).
\]

因此

\[
\boxed{
\text{四次方网格的独立端点算术调用量}
=O\!\left(mZ^{11/12}+mKZ^{3/4}\right).
}
\tag{A1}
\]

有限个附加整数端点仅增加 `O(mZ^(2/3)+mK sqrt Z)`，不改变 (A1)。若把每次幂和 oracle 调用视为单独计价的原语，则主调用计数可写为 `O(mZ^(11/12))`，同时明确保留 oracle 账目。若使用普通 Eratosthenes 倍数筛，则小前缀项还带 `log log Z`；当前脚本已改为逐合数生成一次的线性筛，所以本附录与实现采用同一成本口径。

主指数 `11/12<1` 是一个真实但有限定的合成增量。它说明在上述固定节点条件和算术成本口径下，认证四次方网格所有读出所需的调用量可以少于长度 `Z` 的逐整数展开。它并不证明网格能量本身足够小，也不自动给出所有精度目标下的位复杂度。

### 1.1 oracle、精度与位成本必须另列

实际有理区间运算还依赖：

1. 目标区间宽度和工作精度 `p`；严格舍入及 `N gamma` 的误差放大必须包含在预算中。
2. 幂和 oracle 的锚点、阶数 `K` 及明确余量。固定 `K,p` 的一次有限证书不能作为任意大 `Z` 下精度始终足够的证明。
3. 固定有理厚度的分母所决定的整数根次数、整数操作数长度，以及 Bernoulli 系数和权重的位长。

若这些数值参数随 `Z` 变化，其成本应乘入 (A1) 或单独列账。主稿 (33) 的误差残差估计可用于设计精度，但本附录没有把它升级为新的统一位复杂度定理。

尤其不能把 (A1) 未经检查地推广到 `m=ceil(log Z)` 的变动 Chebyshev 节点：那时节点与权重的表达、精度需求和幂和 oracle 常数也随 `Z` 改变。本附录没有为该族建立统一的求值复杂度。

### 1.2 非整数窗口边缘不需要新的实数端点算术 oracle

对任意 `N<=y<=N+1`，完整道路斜坡和在该单元是仿射函数。因此

\[
\boxed{
F(y)=(N+1-y)F(N)+(y-N)F(N+1)
\,+\,(N+1-y)N\log N+(y-N)(N+1)\log(N+1)-y\log y.
}
\tag{A2}
\]

最后三项就是已知的非负弦插值差 `delta_f(y)`，并满足
`0<=delta_f(y)<=1/(8N)`。

对于实数 `Y,Z`，至多补查 `floor Y,ceil Y,floor Z,ceil Z` 四个整数读出，便能使用 (A2) 或其严格曲率包络恢复边缘。若需要数值评价 `ylog y`，应对给定的 `y` 表示作有向区间评价；无需、也没有假定存在额外的实数 Möbius 端点 oracle。所有整数读出仍从原点累计，窗口前史没有被置零。

## 2. 由现有 Euler–Maclaurin 结构严格补齐 gamma

主稿已认证

\[
T_N=\mathcal H_D(N)-N\log N
=F(N)-(1+\gamma)N.
\]

现在保留同一锚点 `b=256`、阶数 `K=16`、Bernoulli 多项式粗界 `C_(2K)` 和 60 位十进制有向区间。

把主稿的幂和公式用于 `a=1`，令上端点趋于无穷，并使用 `gamma=lim_(L→∞)(H_L-log L)`，得到

\[
\boxed{
\gamma=H_b-\log b-\frac1{2b}
+\sum_{r=1}^{K}\frac{B_{2r}}{2r\,b^{2r}}+R_\gamma,
\qquad
|R_\gamma|\le\frac{C_{2K}}{2K\,b^{2K}}.
}
\tag{A3}
\]

该余量由同一个绝对可积的周期 Bernoulli 积分余项得到。`H_b` 和 `log b` 均已在原算法中计算；补齐 (A3) 只需有限个有理修正项及其余界。没有引入新的特殊函数黑箱，也没有把 `gamma` 的熟知小数直接作为输入。

这一证书应同时保留三个不同端口：

- 道路各厚度的单位修正 `-(N-1)`，已经包含在主稿 (30) 中。
- 残差背景的 `kappa_1=2log2`，负责主稿 (20) 与原 Green 累计的关系。
- 固定中心化的 `(1+gamma)N`，本附录将它加回 `T_N`。

它们用途不同，不能相互替代或重复添加。
