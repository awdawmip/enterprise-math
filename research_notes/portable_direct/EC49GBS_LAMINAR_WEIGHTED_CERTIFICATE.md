## Laminar interval dual theorem
Fix W and R=C minus W, positive integer capacities on R, finite labeled projected nonempty masks E_x, nonnegative real deletion weights w_x. Empty projected masks can be retained for free; R empty gives optimum zero. Strict Hall means f_I(V)<=c(V)-1 for all nonempty V subset R. For a weight level t>0 let A_t={x:w_x>=t}, and let rho_t be its unweighted deletion threshold. GBR proves rho_w=integral_0^infty rho_t dt via descending-weight GBQ greedy.
At every rejected label, GBQ produces a nonempty tight block V for the currently accepted labels. Maintain disjoint active blocks by merging V with every intersecting active block. Tightness persists on subsequent acceptances by feasibility and monotonicity. Intersecting tight sets have tight union: f is supermodular, c modular, and both intersection and union obey strict Hall. If V is already contained in one active block no new node is required. Otherwise close the intervals of the intersected blocks at the weight of the rejected label, and open the union block at the same weight. Remaining active nodes close at 0. At a tied weight all updates are performed before observing that layer. Zero-length intervals are allowed. At any positive level t, the active nodes (V,h,l) with l<t<=h are disjoint, tight on the accepted prefix, and cover every rejected projected mask of A_t in exactly one block. Hence
rho_t = sum_active ( f_{A_t}(V)-c(V)+1 ).
Integrating and exchanging finite sums gives the exact dual:
rho_w = sum_nodes [ sum_{x:E_x subset V} max(0,min(w_x,h)-l) - (c(V)-1)(h-l) ].
This is also a lower bound for any feasible deletion set for ANY interval family satisfying 0<=l<=h and pairwise disjoint masks whenever their intervals have positive-length intersection: apply the strict Hall deficit lower bound separately at almost every level and integrate. No tightness, ancestry, sorting or greedy replay is needed by the verifier. Equality with the cost of a feasible deletion proves optimality. Arbitrary finite real weights in theorem; exact integer weights and signed 64-bit arithmetic in code.
The distinct created block nodes are laminar: old blocks are only swallowed by new unions; otherwise disjoint. An active block is never re-created after being strictly enlarged. Add singleton leaves for ports that first enter a nonsingleton block or enter none. Every nonsingleton created block has at least two children (prior active nodes or new port leaves), so there are at most 2|R|-1 nodes if R nonempty and zero otherwise. The stored dual has O(n) masks and endpoints, irrespective of m and number of weight levels; verification by pairwise interval intersection plus label contributions costs O(n^2+nm) mask operations, plus bit complexity. This is a certificate size bound, not a solver running-time improvement. A proof of weighted optimum with compact dual is stronger than keeping every layer's block table.

## Primal strict Hall by reverse reachability
Given a complete capacitated matching of I, construct directed edges from each occupied port i to each port j in the mask of any label assigned to i. Mark every port with spare capacity, then close backwards under these edges. Strict Hall holds iff all residual ports are marked. If all are marked, any extra singleton at any port can be matched by rerouting along a simple directed path to a spare port; this implies f_I(V)+1<=c(V) for any nonempty V (choose singleton inside V). Conversely if some port is unmarked, the set U of unmarked ports contains no spare capacity and is closed under occupant edges, hence f_I(U)=c(U), violating strict Hall. Equivalently this gives a linear-size parent forest leading to free ports. Verify matching incidences/capacity, then reverse BFS O(mn+n^2) in naive bit-mask construction, or O(number of actual incidences+n) in adjacency lists. Code uses repeated bit closure, O(n^2) worst case. No exponential subsets in full frozen primal or dual verifier. Code retains only the assignment and interval nodes, regeneratable per W.
Combining both certificates yields a polynomial verification route for weighted residual emergence even when capacity is binary-encoded, with no explicit slot expansion. Zero capacity in R makes strict Hall impossible (not tested here).

## Adjacent cut obstruction
Even unit port capacity does not bound upward change of deletion threshold. Let R={i,j1,...,jk}, all capacities one, and k targets with masks {i,j_r}. All targets satisfy strict Hall (any nonempty V containing i counts at most |V|-1; excluding i counts zero). Thus rho(W)=0. Move i into W: every projected target is a singleton on a unit port, so all k must be deleted. rho(W+i)=k. A capacity-only local Lipschitz bound is false; shared incidence and coupled cuts matter. This is an auxiliary discrete matching example, not a native spatial statement.
