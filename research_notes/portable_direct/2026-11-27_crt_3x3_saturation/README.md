# 三行三列 CRT 联合前缀的整点恢复

2026-11-27 · 知情作者证明与穷尽整数复算  
Researcher-ID EM-DIRECT-8327F7 · Activity RA-184AE178188022AA92EFE075

在三个不同行余数、三个不同列余数的完整 CRT 网格上，固定非负整数行列和、真实进位总量与任意一组整数前缀读数。**存在非负实载荷即存在非负整数载荷。** 结合既有两行定理和三行四列反例，完整网格中发生联合格点孔的最小尺寸为 \(3\times4\) 或 \(4\times3\)。这里的尺寸指保留的行列标签数，每个交格均可用；允许载荷为零。去掉一个指定交格便可使 \(3\times3\) 出现格点孔，下面给出精确例子。原两行证明、三行四列反例和原始贡献归属见[上一轮资料](https://github.com/awdawmip/enterprise-math/blob/44747bef0a3135806fd916ca98e77ca32c7d67f0/research_notes/portable_direct/20261127_crt_wrap_carry_joint_prefix_difference_constraints.md)。

## 余数顺序和进位的完备有限域

设 \(M=mn\)，其中 \(m,n\) 互素。把 CRT 行、列分量除以 \(M\) 并分别由小到大排列，写成 \(\alpha+(0,a,b)\)、\(\beta+(0,c,d)\)。有 \(0<a<b<1,\ 0<c<d<1\)，其中 \(a,b\) 分母整除 \(m\)，\(c,d\) 分母整除 \(n\)。记归一化升格和为 \(t_{ij}\)（各行列变量减去各自最小值后的和），归一化余数及进位分别为 \(r_{ij}=t_{ij}-\lfloor t_{ij}\rfloor\) 和 \(\epsilon'_{ij}=\lfloor t_{ij}\rfloor\)。

在四维区域 \(0<a<b<1,\ 0<c<d<1\) 中，两个不同格的余数相碰只可能于下列 18 个超平面上：

\[
    \delta=\gamma\quad\text{或}\quad \delta+\gamma=1,
    \qquad
    \delta\in\{a,b,b-a\},\quad \gamma\in\{c,d,d-c\}.
\]

同一行或列的格不发生相碰。内部进位开关 \(t_{ij}=1\) 也在上述平面中。实际 CRT 网格避开这些平面，因为等式加上互素分母会迫使非零间距为整数。因此每个归一化开室上，余数的全序和进位向量固定。

程序用全部 18 个超平面与 6 个外边界的四元交点做精确划分。任一处理中闭多胞体的顶点必在这批交点中。对下一超平面，若兼容顶点有严格正侧，即存在全维正侧开室。把该顶点向旧开室内部点挪动足够小的距离即可证明。负侧相同。留下与各子室弱相容的全部顶点，可以逐次完成分裂。末层以相容顶点的重心作为开室代表。归一化域有 58 个不同交点和 342 个开室。

最后恢复整体平移 \(s=\alpha+\beta\)。若 \(0\le s<1\)，按归一化余数排序后，一条尾段越过 1 并移到开头，尾段上进位增加 1。尾段只能由原进位为零的格组成，且不含余数零的原点。程序枚举全部这样的尾段，包含空尾段。平移使某个余数恰为零时，排序取同一尾段。若 \(s\ge1\)，则 \(s+b+d<2\) 迫使所有原进位为零，平移后全为 1，余数顺序和归一化顺序相同。这样得到 2,052 种顺序与进位类型，覆盖任意互素模数和合法 CRT 网格。

## 从行列和降至半整数，再用配对恢复

令四个自由变量为 \(x_{00},x_{01},x_{10},x_{11}\)。其它五格由固定边际作整数仿射表示。逐格非负性、真实进位和前缀约束的系数行，因此分别是九个固定格行、进位格行之和、余数全序前缀格行之和。每个非空实可行域有极点，因为固定边际给出有界域。极点至少有四个独立有效约束；进位行若非零，总可把它扩充为所选基的一行。右端均为整数。

整数检查器遍历每种类型的全部这类四元组，逐行形成原始 \(4\times4\) 行列式。979,068 个候选四元组的绝对行列式至多 2，其中 3,828 个取 2。于是任一实可行域有半整数极点。取这样的载荷 \(x\)，分离逐格整数部分与小数部分。小数项各为 \(0\) 或 \(1/2\)。每行、列的小数部分仍有整数边际，故在对应二分图中每个顶点的度为 0 或 2。边沿偶环交替分色，小数载荷是两个单位匹配的平均，二者使用相同的活跃行列。活跃支撑只需考虑两行两列或三行三列。

对 2,052 种类型及每个活跃行列支撑，检查器直接枚举全部单位匹配。对每对继承整数真实进位的平均，要求一个整数匹配复现其真实进位以及**所有**恰为整数的前缀。给定观测只可能选这些前缀的子集。26,280 个配对都找到匹配，其中 1,716 个平均读数在某个整值坐标上严格不同于两端读数。用所找匹配替换小数部分，再加回逐格整数部分，得到满足原边际、进位和全部指定前缀的整数载荷。

## 禁用一个格即出现孔

取 \(m=3,n=4\)，行、列分量分别为 \((0,4,8)\) 和 \((0,6,9)\)。余数矩阵和进位矩阵按行是

\[
  k=\begin{pmatrix}0&6&9\\4&10&1\\8&2&5\end{pmatrix},\qquad
  \epsilon=\begin{pmatrix}0&0&0\\0&0&1\\0&1&1\end{pmatrix}.
\]

各行列和取 1。用每行所选列表示单位匹配，\((2,1,0)\) 和 \((0,2,1)\) 的平均满足 \(e=1,C(2)=1,C(9)=2\)，且 \(x_{22}=0\)。六个整数匹配中，只有 \((0,1,2)\) 满足这三项观测，它使用 \(x_{22}=1\)。因此只要禁用右下角的一个格，就出现整数读数有实解而无整数解。这个半整数载荷本身也是完整网格可行域的一个分数极点。在它的六条非零边上，固定边际使载荷沿唯一六环一维变化，进位在两个端点分别为 0 和 2，进位等于 1 固定中点。故极点半整数性、整数可行性和支撑裁剪确实是不同性质。
