# 第一百零五轮　晶格前沿补全与十二拍联合读数

固定面心立方或六方密堆积晶格，只给出占据集某个补分量的带权前沿。若前沿至隐藏点的接触总数 $D\le46$，每个保持权重的前沿同构都能唯一延拓到整个分量。第 76 轮止于 44。新增的 46 层有一个可从前沿直接读出的区别：四个隐藏点的边界恰含两套完整十二邻壳，五个隐藏点时一套也没有。六点所需的共同邻居接触方式在两个原生晶格里都无法实现。若再给出带正缺额边界点的原生坐标，按高度逐层反演就能对任意缺额恢复隐藏集。[重建定理](frontier.md) · [复算](frontier_check.py) · [逐模板结果](frontier_checked.json)

在原十二拍正权源上同时使用已知二点时间窗与三通道循环记录。时间混合权为 $\lambda$，独立通道偏移律为 $q=(q_0,q_1,q_2)$。当 $\lambda\ne1/2$ 且 $q$ 非均匀时，可从十二次名义边界上的通道分布反演源分布。以逐拍总变差的最大值衡量，两种误差合在一起的精确反演放大倍数为
$$
  \frac{\max_b q_b-\min_b q_b}{|1-2\lambda|\,|q_0+q_1\omega+q_2\omega^2|^2},
             \qquad \omega=e^{2\pi i/3}.
$$
这个系数能够在同一守恒类别的正权准备上达到。原任务书允许据公开冻结材料作限定推导；论文明确列出同钟、独立重备及环境复用的条件。[误差定理与资源预算](budget.md) · [有理复算](budget_check.py) · [预算与见证](budget_checked.json)
