# 第九十四轮　固定三平移的坏素数与守卫矩的最少实验数

**三个整数能否识别重复平方前的初值。** 对同一未知 $x$ 的独立副本分别加 $0,1,3$，连续平方 $r$ 次再读模数。至少在一个 $r\ge1$ 和某一素数幂精度 $p^k$ 下出现碰撞的奇素数，至 $X$ 仅有 $O(X^{3/4}/\log X)$ 个。因而密度一的素数可用三个固定平移同时处理所有深度和精度。用 $0,1,2$ 的情形截然不同：每个 $p\equiv1\pmod4$ 和每个 $r\ge2$ 在全部精度上都有碰撞。分界来自分圆域中根单位之差：有理坏形状与其补数都只能含素因子 2。[坏形状、素数幂与奇模数密度](translates.md) · [原式复算](translates_checked.json)

**每次读取三个矩时需要几种设置。** 在原截断平移、反射与线性概率守卫下，若长度至多 $T$ 的全部可观察量张成维数 $d_T$，则恰需 $\lceil(d_T-1)/2\rceil$ 种实际动作词设置。将末端质量两点一组反演可达此界，自适应设置亦受同一下界。在二次守卫分叉中，$T\ge2$ 时维数通常为 $\min(M+1,4T)$，仅当 $M=4T-1$ 且守卫关于内部中点对称时少一维。交错二项向量给出该层不可辨、下一步可分开的两张概率分布。[基、临界共振与实验数](guards.md) · [精确核验](guards_checked.json)
