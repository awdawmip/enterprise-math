# 第一百零七轮　谱矩的零点与重合旋转的理想类

第三轮留下了一个解析问题。原始有限谱的 Dirichlet 级数以 $\zeta(s)$ 为分母，分子是多个平移 $\zeta$ 函数的线性组合。是否会在某些非平凡零点处抵消？现已证明，对每个阶数 $n\ge1$，在开临界带内，谱级数的极点与 $\zeta$ 的零点逐点且同重数对应。所有阶共用高度 $14$ 的分子下界；从第 15 阶起，该下界可加强为覆盖整带的最高项支配。十阶分子本身在 $(0,1/2)$ 有实零点，显示“分子处处非零”与“分子不抵消分母的零点”确有不同。结论不判定 RH 的真假。[统一定理、十阶反例与相对误差](jordan.md) · [有理复算](jordan_check.py) · [严格数值包络](jordan_checked.json)
