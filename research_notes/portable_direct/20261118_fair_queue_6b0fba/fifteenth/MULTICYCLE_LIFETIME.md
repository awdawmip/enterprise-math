## 固定两条动态联系的有限变体

四体停在原正方形 $A=0,B=E_1,C=E_1+E_2,D=E_2$。AB 和 AD 始终是 A 模式，ID 0、1 分别绑定于 A；另两条边 BC、CD 在存在时均为 D 模式，以 C 为头位，绑定字分别为 $-E_2,-E_1$。保留所有六坐标、实际有向腿及来源。两个初态都在第十四轮输入的正支路上。

- **Q 树。** 原 Q 中断后用已从 CD 释放的 ID 3 重新建立 BC，空闲 ID 2 已实运回 A。现在为缺失的 CD 派这份实际库存，从其当前仓位开始出库。填回 CD 后这一支满环上 BC、CD 分别使用 ID 3、2。
- **Q 的满环。** 从同一稳定 Q 准备，直接选择由 C 侧重捕 BC 且没有中途损伤。ID 2 从 A 经 B 送到 C，CD 原有的 ID 3 在全过程仍绑定。故这一支满环上 BC、CD 分别使用 ID 2、3。[原准备记录](https://github.com/awdawmip/enterprise-math/blob/e7b9fb5084f93a9b2dbc16225629b667fb7bf46c/research_inputs/U27F_20261012/fixtures/source_Q.json)

此后两条动态边均可实际解绑和重新出生。取 $0<\lambda=\delta/49\le1/49$。**每拍先查损伤。** 每条已绑定动态边各有 $\lambda$ 的释放质量，一拍至多选择一条；释放占据该拍，记录在 C 自由，带着真实 ID 进入先到先服务队列。若没有释放，才将队首的修复推进一步；队列为空则原地等待。第二条边在第一份记录运输、申请或持有期间都可损坏，第一项的已走路径、申请或持有状态不被覆盖。

每个新释放的 ID 走 $C\to D\to A$ 入仓，再走 $A\to B\to C$ 出库；随后重复选定侧的出生许可试验，条件接受率 $p=1/49$。每次试验一拍。通过后就地预留这份 ID，再用一拍正式绑定。已通过的许可保留在实际作业上。在库位 A 起步的 Q 树省去已经完成的入仓两步。两项同时缺失时，后到的自由记录留在 C，直至轮到它；完成当前绑定后不会取消它。动态边只取固定单字，挂在 C 的持有记录至正式绑定才形成边。本研究观察拍末实际绑定图：恰在 BC、CD 同时缺失时失联。两种真实入口分别固定自己的 ID 对应，此后每次重新绑定所服务的同一份记录。其余 T05 成功终态没有用于此参数族。

这是一个显式有限变体：沿用邻体出生的几何、端口、条件接受率与真实仓位路线，另行选定两动态边、损伤在本拍服务之前、单队列及串行修复。U25 的单联系限制在此扩展为 BC、CD，U27 中断后立即停止的规则也已改变。每拍是上述工作或损伤决策机会，没有给它校准物理时间。正式前置 T05 尚无封存结果，本次绑定其已经生成且可逐项重验的条件科学材料；无原生力归因。[模型规格](REPEATED_DYNAMICS_SPEC.json)

## 一次修复失败与真正的再生点

令 $G$ 服从以 1 为起点、成功率 $p$ 的几何分布。没有另一边损坏时，刚从 C 释放的作业需 $K=6+G$ 个服务拍，Q 树当前作业仅需 $K_0=4+G$。其概率母函数分别为

$$
 \phi(z)=\frac{p z^7}{1-(1-p)z},\qquad
 \phi_0(z)=\frac{p z^5}{1-(1-p)z}.
$$

在当前仅有一边完好时，先发生整体失联的概率为 $f=1-s$，其中 $s=\phi(1-\lambda)$。从 Q 树立即开始的修复失败概率为 $f_0=1-s_0,\ s_0=\phi_0(1-\lambda)$。由于 $f_0<f$，两种作业也不能仅按“都缺一边”合并。Q 树下一拍的首次失联概率为 $\lambda$，满环则为零；这是两个成功终态拥有不同第二轮读数的直接反例。

在固定 ID 分配的类内，**两边都重新绑定且队列为空**是自然到达的再生状态。这时两份动态记录都已实际归位，控制器没有未决许可或未完成路线。在同一独立提案核下，强马尔可夫性适用。两个类之间只在忘记 ID 的特定读数上等价；本次没有重命名记录来造成再生。单次 BC 修复成功仍可留下 CD 和实际作业，故这一更宽的事件不具有再生性质。

## 首次失联的精确分布与低噪声定理

设 $T_F,T_Q$ 为从上述满环、Q 树开始的首次整体失联拍数。满环先等一次实际释放，等待 $W$ 的成功率为 $2\lambda$。之后，全程有另一条边继续工作的这一作业，要么在 $K$ 个服务拍内无新损伤并真实回到满环，要么在首次后续损伤时成为两边同时缺失。此段到两种结局的平均拍数为 $f/\lambda$，由 $\sum_{j\ge1}\Pr(K\ge j)(1-\lambda)^{j-1}$ 得到。首步更新给出

$$
 \mathbb E T_F=\frac1\lambda+\frac1{2\lambda f},\qquad
 \mathbb E T_Q=\frac1\lambda+\frac{s_0}{2\lambda f}.
$$

因此固定此服务规则时，$\mathbb E T_F\sim\mathbb E T_Q\sim 1/(110\lambda^2)$。第一次释放的概率阶为 $\lambda$，运输、试验及已通过许可尚未绑定形成的实际暴露窗均包含在 $K$ 内，第二次释放的单次修复概率为 $f=55\lambda+O(\lambda^2)$。只有一条动态边失效时仍有另一条臂连接 C，故这些正概率序列给出最低有效损伤次数。不同初态的次首项也可区分：$\lambda(\mathbb E T_F-\mathbb E T_Q)\to53/110$。

对任意 $0\le z\le1$ 与 $\lambda>0$，令 $t=(1-\lambda)z$。把单边修复按“安全完成”和“再损伤”分开的联合母函数为 $a=\phi(t)$ 与 $b=\lambda z(1-\phi(t))/(1-t)$，满环等待的母函数为 $w=2\lambda z/[1-(1-2\lambda)z]$。以 $\phi_0$ 代 $\phi$ 得 $a_0,b_0$。几何级数来自真实回到满环后的后续轮，故

$$
 H_F(z)=\mathbb E z^{T_F}=\frac{wb}{1-wa},\qquad H_Q(z)=b_0+a_0H_F(z).
$$

取 $z=\exp(-u\lambda^2)$、固定 $u\ge0$。则 $w=1-(u/2)\lambda+O(\lambda^2)$、$a=1-55\lambda+O(\lambda^2)$、$b=55\lambda+O(\lambda^2)$。两种入口下，$\lambda^2 T$ 的拉普拉斯变换均趋于 $110/(110+u)$，即 $\lambda^2 T$ 依分布趋于速率为 110 的指数分布。若用原稀释参数 $\delta$ 计阶，则期望首项为 $2401/(110\delta^2)$。

## 首次失联与长期停留份额

第一次失联后仍按同一队列运行。若作业还有 $k$ 步，另一条边在该作业第 $j$ 次准备服务时先损坏（$1\le j\le k$），这次损伤独占一拍，然后以两边缺失状态再服务 $k-j+1$ 拍，直到当前边重新绑定。此时后一个缺口及 ID 仍在，进入一个新的、从 C 起步的作业。故一次完整作业的平均拍数为 $55+f$，其中平均连通拍数为 $f/\lambda$，平均失联拍数为 $55+f-f/\lambda$。从满环的一个真正释放到下一次真实满环，需要的作业数均值为 $1/s$。将各轮工作与最初满环等待相加，得到长期失联份额

$$
 \pi_{\rm off}=
 \frac{55+f-f/\lambda}{s/(2\lambda)+55+f},
 \qquad \pi_{\rm on}=1-\pi_{\rm off}.
$$

拍初、拍末的长期份额相同。令 $\lambda\downarrow0$，则 $\pi_{\rm off}\sim\mathbb E[K(K+1)]\lambda^2=5432\lambda^2$，其中 $\operatorname{Var}G=2352$。每个具名类只有 29 个状态，状态均彼此可达：清理已有作业的正路径可达满环，而选定释放、逐步推进、在任一阶段释放另一边的路径均有正质量。因此正噪声下几乎必然无限次失联、无限次重新连通，且有正的长期连通份额。$\lambda=0$ 时从这两个已连通入口始终连通，首次失联时间为无穷。
