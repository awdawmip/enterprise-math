# 第九十七轮　二阶模幂等矩阵的迹分布与三轴切片的整数读数

**任意二阶仪器能从一个已知端点看到什么。** 令 $B^2=B$，在模 $p^e$ 且与给定秩一端点 $B\bmod p^b$ 相容的矩阵中等权抽取 $B$，$b\ge1$。对任意二阶仪器 $C$，迹 $\operatorname{tr}(CB)$ 的分布只有三种形状：常数、一个同余类上的均匀律，或两个独立均匀剩余的乘积经过平移和缩放所得的律。若连模 $p$ 端点都未知，去掉仪器的标量层后，模 $p$ 不可约、单 Jordan 块、相异分裂三种谱型分别给出精确分布。推导包含 $p=2$。例如模 16 的一个非对角仪器在 64 个相容提升上读得 $1,5,9,13$ 的次数依次为 $8,32,8,16$。等权是假定的计数模型，此项作为独立算术成果，未计入 RR133 的状态机进展。[端点坐标与乘积计数](trace.md) · [直接矩阵枚举](trace_checked.json)

**六个具名轴的两种读数能否辨认同一个整数位移。** 在同一锚点、六轴的正向约定亦已对齐时，将 H4 的两个组三轴内部差与 FCC 整格位移并读，对整个六轴整数格单射。改在素数模下读时，读数所在的格会影响结果。在本原 FCC 格内，十种无向三对三分组的末 Smith 因子五个为 1、四个为 2、一个为 5。最后一项给出两张互补三轴切片在模 5 下误合的明确例子。若正向也未标定，则十种分组扩为 160 种相对标定，其中 16 个在整数上已经有非零零空间。原输入的 Cell 身份、正向和物理端口对应均需实际标定。[具名列、模数与桥的适用条件](ports.md) · [整数矩阵复算](ports_checked.json)
