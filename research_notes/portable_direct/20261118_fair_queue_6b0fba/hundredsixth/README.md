# 第一百零六轮　Ramanujan 相位能量、分层抽样与三通道校准

对相差整数平移的完整 Ramanujan 和，从同一起点累加后再求平方能量。所有平移的逐频功率都相同，能量却取决于第一个脉冲的位置。对于奇素数 $p$，第 1 项出现脉冲时唯一最大，渐近为 $\pi^2p^2/6$；在第 $(p+1)/2$ 项时唯一最小，渐近为 $p\log2$。均匀相位的中位数约为 $0.9766745p$，平均值却按 $p\log p$ 增长。论文还给出固定平方自由 $m$、新素数 $p$ 的复合分母 $mp$ 的重尾与方差主项。[能量、分布及矩](road.md) · [复算](road_check.py) · [整数与区间结果](road_checked.json)

冻结的三段覆盖选择器，每个种子用 32 个固定位置和 32 个分层位置验证输入。对原来的四种规模，即使遍历全部 $2^{64}$ 个种子，仍有 1,021 至 1,024 个地址从不进入验证。只改动其中一个键，可让全数组最优覆盖成本从 $3$ 增至 $2^{32}+3$。在 49 个原 C++ 测例上完整输出均保持正确，研究分别核算了预检、建模和回退。[盲地址与最坏命中率](sampling.md) · [复算](sampling_check.py) · [完整结果](sampling_checked.json)

首次研究的三通道校准任务用同一份正权准备完成多次记录。固定参考和具名接线后，$d$ 个载体中有 $N$ 个接收器时，最优共同成功率等于相对偏移分布在某个 $d-N$ 维三元线性子空间上的最大质量。原门的四次接触可将一个两次记录都正确的概率从 $1/9$ 提至 $1$。删去任一载体后的所有边际即使完全相同，联合校准成功率仍可不同。[通道校准与射影几何](calibration.md) · [复算](calibration_check.py) · [可达性结果](calibration_checked.json)
