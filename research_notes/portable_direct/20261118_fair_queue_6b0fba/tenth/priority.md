## 第三帧的第一步

在 $\mathbb Z^6$ 采用原有十二个单位方向。原正方形为 $A=0,\ b=e_1,\ C=e_1+e_2,\ D=e_2$，其中 $b$ 是身体 B 的旧位置。第三帧的 B 已到 $b'=b+e_3$。ID 0 绑定在 $A$，指向 $b$，属于 AB 的 A 侧。ID 1 在 $A$ 维持 AD。ID 2 由 B 持于 $b'$。ID 3 已从 CD 解离，现于 $C$ 自由。此时唯一完整边是 AD，严格图的分量为 $\{A,D\},\{B\},\{C\}$。旧意图中 AB 的 B 侧仍要求在 $b'$ 登记 $-e_3$，几何与身份都吻合，尚未执行绑定。旧意图同时列有 CD，其模式与记录已经失效。实际发生的原身体位移、原 AB 的 A 侧和 AD 的绑定、CD 的释放位置各自保留。[真实中断](https://github.com/awdawmip/enterprise-math/blob/e7b9fb5084f93a9b2dbc16225629b667fb7bf46c/research_inputs/U27F_20261012/fixtures/interrupted_after_carry.json) · [五个工作帧](https://github.com/awdawmip/enterprise-math/blob/e7b9fb5084f93a9b2dbc16225629b667fb7bf46c/research_inputs/U27F_20261012/fixtures/carry_Q.json)

**逆向恢复。** 第一步是让 B 与持有的 ID 2 从 $b'$ 沿 $-e_3$ 实际回到 $b$。此时已有 ID 0 的 AB 又有共同端点。将 ID 2 就地转为自由，再于 $C$ 预留 ID 3，以 $C$ 为头沿 $-e_2$ 新建 BC 的 C 侧单字母记录，按原联系规则赋初始模式 D。最后自由 ID 2 从 $b$ 沿 $-e_1$ 运到 $A$。终态三条边 AB、AD、BC 分别由 ID 0、1、3 维持，ID 2 在仓位 $A$，CD 仍缺失。严格分量数依次为 $3,2,2,2,1,1,1$，最后一项为稳定观察。BC 的重建补偿了旧 BC 缺口，过程从未重新安装 CD。

**向前完成。** 第一步是把 $b'$ 处的 ID 2 登记在 AB 的 B 侧，方向 $-e_3$。从 $C$ 到 $b$ 再到 $A$，每一步都实际运送自由 ID 3。终态 AB、AD 由 ID 0、2、1 维持，ID 3 在仓位 $A$，严格分量为 $\{A,B,D\},\{C\}$。一个自由 ID 已足以在数量上预留一次单字母新联系，BC 出生却受位置阻塞，因为 $d_1(b',C)=2$。两条路线的稳定条件都是当前两腿端点吻合、每个出现位置有唯一 ID、无持有记录、全部自由库存已到 $A$；连通单独检验。

## 定理：隔离 CD 的最小库存

让 B 的位置一般化为 $e_1+v$，其中 $v$ 仅在第 3 至 6 坐标非零，$r=\|v\|_1$，其余三个身体保持原位。设每一条关系由从两端出发、在同一格点会合的两个有向字词组成，每个字母占用一份独有记录。允许任意身体对的简单边，但隔离 CD。几何上存在某个连通配置所需的最少记录数为

$$
\tau(r)=2+r+\min(2,1+r)
=\begin{cases}3,&r=0,\\4+r,&r\ge1.\end{cases}
$$

若只容许原四边循环中的边，隔离 CD 后最少记录数为 $\tau_{\rm cycle}(r)=3+2r$。

**推导。** 总字长至少是任选生成树各边的两体 $\ell^1$ 距离和。反之，每条树边取最短格路作为一侧词，另一侧取空词，便以这棵树的距离和实现。于是最少库存等于准许边的距离最小生成树权重。五条可选边的长度为 AD 为 1，AC 为 2，AB 与 BC 为 $1+r$，BD 为 $2+r$。取 AD 后可取 AB，并以 AC、BC 中较短者接入 C；按权重排序亦可先取 AC。Kruskal 的割判据给出所列最小值。只许循环边时，AD、AB、BC 是唯一生成树。这个推导对所有整数 $r\ge0$ 成立。[原始六轴与库存参数](https://github.com/awdawmip/enterprise-math/blob/e7b9fb5084f93a9b2dbc16225629b667fb7bf46c/research_inputs/U27F_20261012/fixtures/base_case.json)

$r=1$ 时库存至少为五，第三帧只有四。在固定四体位置且隔离 CD 时，任意重排与重分配均无法使其连通。允许双腿词时五份确能构造 AB 两字、AD 一字、BC 两字的树；若坚持 U21/U22 的原生相邻联系出生入口，此处唯一尚许的相邻体对是 AD，单纯增加库存仍不能在这些固定位置创建进入 $C$ 的边。相比之下，从第三帧出发恢复连通至少要移动某个身体一步，前述逆向路线只移动 B 一步，达到了这个下界。第四、五帧先在 $b'$ 显式解下已经绑定的 ID 2 才能执行同一逆行。这里的“最少一步”只计身体单位位移，其他运送与绑定都在证书中逐步计入。
