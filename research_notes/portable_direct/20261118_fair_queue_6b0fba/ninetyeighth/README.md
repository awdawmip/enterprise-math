# 第九十八轮　忠实修复的最小支撑与整数碰撞的安全深度

**六轴共轭动作要占多少个正质量细类。** 在既有单端口修复合同下，低层帧固定为恒等，保护余度为零。在一位提升中让完整修复群在细类上忠实作用，最少需要 $6p^{10}$ 个不同细类，对每枚素数都成立。单个最小非平凡轨道有 $p^{10}$ 个细类，但任选五个这样规模的轨道，仍有一个非标量修正对它们同时不可见。取六个循环矩阵及其共轭轨道便达到下界。明确改作连续 $n$ 位观察时，最少支撑变为 $6p^{10n}$。[单层证明、取等分类与多层推广](stabilizers.md) · [原生复算](stabilizers_checked.json)
