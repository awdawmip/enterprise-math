# 第一百零一轮　移动支撑的边界与取向匹配的模读数

两个上次分别在第 63、72 轮获得服务的方向，本轮各得到一个可检验的精确阈值。

- 在 Weil 形紧窗内改变支撑半径时，素数幂 2、3、4 各给出两条移动带。若有限头向量的首个非零端点导数为偶数阶 $a$，真实补块逆作用后的平方误差首项是 $c_a |h|^{2a+1}/\log(1/|h|)$。每个奇偶扇区保留 $u(1),u''(1)$ 两个读数，就可在消除移动带之后把三次展开余量控制到 $O(|h|^4)$。完整 Schur 证书仍待研究。[推导与适用区间](weil.md) · [复算](weil_check.py) · [区间结果](weil_checked.json)
- 给细见证匹配的两端各加一张整数重数表，观察配对乘积之和模 $p$。两种取向的均匀抽样律可辨，恰当每张表内部模 $p$ 互异。所有桶的带符号计数还有一个精确公共 $p$ 进阶。容量等于模数的满表另有适用于素数、素幂及合数的逐桶公式。例如满表模 5 时，一次读数在等先验下判对取向的概率为 $11/12$。[判据与满表公式](chirality.md) · [复算](chirality_check.py) · [精确直方图校验](chirality_checked.json)
