# 第一百零九轮　抗删除周期识别的最少采样数与反馈记录的最短辨识

给定标号幂，单从哪些幂彼此相等来识别阶 $r\le H$；更大的阶统一记作超范围。设计者先选采样位置，随后对手可再删 $e$ 个位置，删除的标号已知。第十轮给出了单洞与部分多洞构造。现在得到 $H/3<e\le H/2$ 整段的最少采样数。写 $H=2e+c$、$0\le c<e$，最小跨度是 $A=H+e$。当 $c\le2$，全部位置都必需；当 $c=3t+d\ge3$、$0\le d\le2$，能预先省去的位置最多恰为 $2t-\mathbf1_{d\ne2}$。两个显式区间达到上界。例 $H=59,e=20$，80 个位置只需采 69 个。证明把必要条件化为模 $r$ 与模 $pr$ 两种标号相等模式的最小删除代价，把充分条件化为等差链上的不交配对；2,145 组参数和 233,090 个目标阶另有整数复算。该子任务的登记前置仍待正式验收。[最优定理与布局](power.md) · [复算程序](power_check.py) · [核验数字](power_checked.json)

首次研究的反馈任务问，一份记录开始控制后续源动作时，预测未来读数须保存多少信息。对冻结的三动作字母表，从实际可达的 3,456 个状态出发，最小充分划分恰有 432 类。从同一未知初态连续作四次源步进，再作一次记录写入，所得读数足以辨类。允许每次看完读数再选动作，最坏情形也至少要五步。若已知记录起初就绪，则只需辨 144 类、四步。扩充一个已列明的诊断动作后，自适应有严格优势。未知守恒标签时，自适应与预先固定动作串各需 7、8 步；标签已知时各需 6、7 步。[模型、充分条件和下界](feedback.md) · [公开源接口复算](feedback_check.py) · [全部分组及读数](feedback_checked.json)
