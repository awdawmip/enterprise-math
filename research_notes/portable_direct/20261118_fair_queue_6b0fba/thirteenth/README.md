# 第十三轮：特征七的三个 Prym 商、三次高斯和与四个有限模型

截至取材时，状态机的 211 项严格就绪研究中，此前有 144 项尚未轮到。本轮选取六个不同父目标各一项，首次覆盖 X6 因子分层的有限群观察问题。累计 75 个任务、37 个父目标。本快照还余 138 项未选，其中 P1 三项、P2 一百三十五项。两个前置审计仍待正式验收。P11 的原生 Magma 请求和 m7 的指定一次性计算均无公开执行结果。[来源与就绪快照](fair_snapshot.json)

## 两项算术结论

**特征七的 Prym 四维簇。** 对指定 Prym 簇 $P$ 的极化核 $E[2]$，沿三条线作商得到三个几何上两两不同构的主极化阿贝尔四维簇。每个的最小有限定义域为 $\mathbf F_{343}$。三者均不可分解，也都不在光滑亏格四曲线的 Jacobian 轨迹上。阻碍来自四阶自同构：在三个商上，两个特征值的余切重数为 $(3,1)$；在候选曲线上，强 Torelli 定理与超椭圆模型要求 $(2,2)$。论证另用积分 Tate 模识别哪些商间同构会提升至原簇。文内列出已用的上游几何输入。[推导](theta.md) · [有限域核验](theta_check.py) · [结果](theta_checked.json)

**艾森斯坦整数上的三次高斯和。** 外稿强色散估计里的主项分别由正平方的非零立方频率、Type I 混合项及模型平方产生，三个贡献在同一规范化下以 $1,-2,1$ 相消。若移除支撑的粗糙性，所有系数可支撑在一个固定素理想 $\pi$ 的倍数上，仍有要求的特征等分布，却给原校正平方留下至少常数乘 $\mathcal Q/(N\pi+1)^3$ 的量。另得到平方自由互素指示函数的极限 Gram 核
\[
 K(b,c)=\rho_b\rho_c\sum_{d|(b,c)}(Nd)^{-1},\qquad \rho_b=\prod_{\pi|b}(1+1/N\pi)^{-1}.
\]
它把局部筛选的方差分解成各共同因子的平方和，给出允许小素因子时最佳单系数校正的主项。[逐项审计与反例](dispersion.md) · [复算程序](dispersion_check.py) · [结果](dispersion_checked.json)

本轮的两个识别结果说明了不同类型的边界。三频循环族可用一个**定向**的高阶读数消除歧义；损伤态模型只需把读数从首步延伸至第二步。在这两个模型中，阶数和时间都能被单独计量，且有达到下界的实例。
