# 第一百二十二轮　从有限读数恢复算术结构

本轮在四个不同父方向上工作，首次研究三元记录器的校准准备，复访模整数的具名端点、精度成本与 $p$ 进控制历史。另从固定高斯格分出一个独立的极化计数问题。

**具名幂等端点。** 给定公开 $N$ 和 $Y_j=L_jI+G_jB$，其中 $B^2=B\bmod N$。令 $M=N/\gcd(N,G_1,\ldots)$，端口可以恢复 $B_0=B\bmod M$。把 $\chi_{B_0}(T)$ 与 $T^{d-r}(T-1)^r$ 的系数逐一作差、取 gcd，再将素因子提升至它在 $N$ 中的全幂，即得到所有可见的秩 $r$ 素幂之积。虽然可能只读到模 $p$ 的一位，完整 $p^e$ 仍归到正确一组。保持端口的全部可见提升可通过一次同余核共轭等权抽取。在另行指定的全盲、全矩阵等权库上，奇数维时两不同素因子的局部秩至少以 $1/2$ 的概率不同；给出完整矩阵样本即可在预期 $O(1+\log\omega(N))$ 次抽样内分出全部素幂。偶数维则有无须分解的近似抽样器。对同一 $101\cdot103$，五维和六维等权样本给出不同局部秩的概率分别约为 0.50000001 与 0.00038445。原运行端口只承担其来源实际提供的读数。[逐秩分割、抽样与奇偶分界](endpoint.md) · [整数复算](endpoint_checked.json)

**同一历史接上后续列，何时首次合并。** 设 $G$ 是原有限阿贝尔 $p$ 群，$I\subset G$ 是两段历史之差的像。把相同的纵向列不断追加，两段历史在第 $t$ 次更新后合并的精确条件是 $I\subset\langle X_1,\ldots,X_t\rangle$。全部等权未来字的首次合并分布由两个商群的 Smith 型决定，即 $G/I$ 与 $G/(I+G[p])$，这里 $G$ 已定。保留差像与第一个商的抽象型仍有歧义。两个实际构造在 $G=C_8\oplus C_4\oplus C_2$ 有相同的这两项数据，但在 4,096 个等权两列字中，分别有 216 和 984 个已合并。第二个商保留了两者缺失的嵌入信息。论文还给出不放回追加的最晚合并位置。[两商群公式与首次合并](merge.md) · [原矩阵核对](merge_checked.json)

**三元写门的初始记忆。** 准备器不能看到待写源，有 $d$ 个记忆状态，每拍读到一个新的均匀三元偏移。初态为确定态时，连续 $k$ 次全部写准的最大概率是 $\min(1,d/3^k)$。同一张可逆表以 $3c+u$ 对 $d$ 的商作为输出、余数作为下一记忆，同时达到每种长度、任意数目最重误差词的精确上界。如果所有接收者共享一个均匀偏移、每拍用同一表，最佳全准率变为 $\min(3,1+\lfloor(d-1)/k\rfloor)/3$。三元五态两拍时两种供给分别达到 $5/9$ 和 $1$。原写门及其正权传播、准备表的逻辑成本均分别复算。[校准定理、共享参考与进位表](calibration.md) · [原门复算](calibration_checked.json)

**精度成本。** 在原有 98 场、385 个候选上，按行与分量的位宽差分桶，以新增两位精确更新桶内积 $J_g$。若桶的源范数为 $A_g>0$，对应的整数候选范数满足 $C_g\ge\lceil J_g^2/A_g\rceil$。已接入原宿主的证书严格排除 287 次真实失败中的 280 次，覆盖先前全部 263 次。单独在这份冻结表上加入奇偶条件又达到 282 次。候选行扫描省下 3,719 次，但要加上建索引和数字更新。另一个提前拒绝策略在 186 次拒绝时仍有数字未读，最后所有 33,529 个活跃数字却都必须读回。两棵完整概率树及六个到因子停点保持一致；六对计时各有三对更快、三对更慢。[整数范数下界与全程费用](precision_cost.md) · [原宿主复算](precision_cost_checked.json)

**高斯格的分裂整极化。** 对指定 $\mathbf Z[i]^6$ 格和固定本原非各向同性直线，把 Euler 特征数 $\chi\le X$ 的带标记分裂整极化逐个计数，每种形式各计一次。得到 $A_h(X)\sim C_hX/\sqrt{\log X}$，其中 $C_h$ 有显式局部因子。让 $X$ 先趋于无穷，所有这些直线上取最小可行补空间倍数的比例，其尖下确界为 $(1+3^{-5})/((1+3^{-4})\zeta(5))=0.95654679\ldots$。固定的正、负两标准线在 $X=10^6$ 分别有 28,105、225,278 个形式，两者之比的极限为 $41/365$。此旁支只涉及固定格的算术，正式 H0R 泛型传输保留其原前置。[极化计数与尖比例](polarizations.md) · [有限格与局部因子复算](polarizations_checked.json)
