# 第八十七轮　最优矩区间的宽度与模七倍增轨道的辨识

**1159 内部相位。** 已知相位测度前 $2n$ 个矩和支撑 $[0,1]$ 时，归一化相位的可行区间由 Gauss 与 Lobatto 求积给出。把真实密度写为 $w(u)=\operatorname{atanh}\sqrt{1-u}$ 后，区间宽度的主项为 $C(z)t^{2n}$，其中 $t=(1-\sqrt{1-z})/(1+\sqrt{1-z})$。常数 $C$ 可用四个 Gamma 函数值写出。在所有合法首模上，真实值到两端的误差均一致趋于半宽。指定有限精度时，必要和充分的矩对预算最多差一对。[常数、有限界与适用域](quadrature.md) · [原始矩复算](quadrature_checked.json)

**倍增运算的余数投影。** 对 $0\le y<M$ 逐步迭代 $y\mapsto 2y\bmod M$，每步只观察模七余数。若 $7\nmid M$，初始读数加 $k$ 步恰好确定 $y\bmod7$ 及 $\lfloor 2^k y/M\rfloor$；辨认所有初值的最少步数是 $\max(0,\lceil\log_2(M/7)\rceil)$。若 $7\mid M$，整个无限读数串只取决于初始余数。原 N1 运行还保留完整数据与带号路线：在模 77 的一次真实转移上，五个路由顶点仿射张成四维。这个样本把能从逐拍余数得到的结论，与真实路线提供的额外信息都具体定位到了同一拍。[窗口定理、同轨见证与原运行](doubling.md) · [复算回执](doubling_checked.json)
