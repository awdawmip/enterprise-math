# 第八十轮　从一次读数能复原多少隐藏信息

五胞干预和短量子寄存器用了两个不同的观测模型。前者可以设计最短的辨识动作，后者即使知道全部读数，也会在短短几个测量深度内留下指数多种等价的地址尺度。

**五胞单轨迹。** 在公开任务的两种干预上，增加一个带来源的整数计数。已知来源总额时，八个三拍词中恰有 **101** 能在同一条不重置轨迹上辨识五格的来源份数。四次计数对应二部图 $K_{3,2}$ 的一棵生成树，加上总额形成行列式绝对值为一的整数矩阵。若来源总额未知，即使可以继续做任意干预，所有读数仍只确定一条整数直线。给定各格容量且总容量为 $\mu$，最大可行解数恰为 $1+\lfloor\mu/7\rfloor$。这也解释了为什么遍历容量至 6 的全部 8,008 种双来源初态看不到这类歧义。新增计数是数学观测假设，尚无物理传感器验证。[五胞定理与最短词](trace.md) · [复算结果](trace_checked.json)

**短寄存器的尺度。** 对指定模乘调度，设全零前缀长 $t$、$Q=2^t$、工作轨道长为奇数 $d>1$。除去整体缩放，$Q<d$ 时非零支撑上能保持读数的正尺度有 $\min(Q,d-Q)-1$ 个连续参数。$Q>d$ 时只余离散的 $\binom{2j}{j}$ 个，其中 $j=\min(Q\bmod d,d-Q\bmod d)$。取 $d=2^s-1$、$t=2s-1$ 就达到中央二项式 $\binom{d-1}{(d-1)/2}$。原 61 维程序的 $N=7$ 实例中，只改一个地址便使终端报告的总变差恰为 $217/2056$；同一程序也验证了误差恰为零的非恒定地址缩放。一般输入的低成本行生成仍是开放问题。[尺度分类与查询界](gauge.md) · [复算结果](gauge_checked.json)
