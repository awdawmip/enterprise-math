# R284CQ — 第三极值见证及唯一最小186点三阶谱核

日期：2026-11-21。状态：**AUTHOR_PROVED / EXACT_FINITE_CERTIFIED / NOT_REVIEWED**。输入沿用 R284CO/R284CP 冻结的辅助 34-bit Port 观察器（非原生 X6 物理转移）。

## 精确对象和问题

设循环整数空间为 \(\mathbb Z/P\mathbb Z\)，其中
\(P=17\,179\,869\,143\)。令 \(X\) 是原冻结四阶矩阵编码的 **65,536 个互异** Port 码字，\(\{A_i\}_{i=0}^{63}\) 是冻结的 64 条带标签圆弧。\(d_k(x)\) 表示从 \(x\) 到各条圆弧的 64 个非负整数圆周距离中第 \(k\) 小者，重复标签分别计数。按实际码字 \(x\in X\) 对 \(d_k(x)\) 从大到小排列，记前三名值 \(U_k>V_k>T_k\)（只对 \(2\le k\le64\) 作这一严格性断言）。

问题：在 R284CO/R284CP 已独立锁定各等级唯一第一、第二名的基础上，精确恢复第三名及其来源，并求出保持全部 64 级前三名数值的最小码字子集。

输入不变：\(D=(1120832,6,13,1651128)\)、\(Z=(0,390139,394465,1497639)\)、\(\mathrm{SELECT}=(0,1,2,4,5,6)\)、冻结码字 SHA256 为
`b6ce76b2c08b9ec6b79ec83173befd2589928ca7c636643c3eaecd40405f4ff4`。

## 一般第三名精确认证定理

定义赤字计数
\[
F_k(r)=\#\{x\in X:d_k(x)>r\}
=\#\{x\in X:\#\{i:\operatorname{dist}(x,A_i)\le r\}<k\}.
\]
若第 \(k\) 级第一、第二名 \(U_k>V_k>0\) 已被唯一性证书锁定，则
\[
T_k=\min\{r\in\mathbb Z_{\ge0}:F_k(r)\le2\}
\]
是第三大的实际码字距离值。若还验证 \(F_k(T_k)=2\)、\(F_k(T_k-1)=3\)，则 \(T_k\) 的取得者**唯一**，而 \(F_k(T_k-1)\) 返回的三名码字经去掉前两名即可精确找出第三名。

**证明。** \(F_k(r)\) 是严格超过半径 \(r\) 的码字数量，随 \(r\) 非增。恰好两个超过 \(T_k\)，表明第三名不大于 \(T_k\)；半径少一时恰有三个超过，表明至少一个实际码字距离等于 \(T_k\)，且此等级仅有一个，故第三名恰为 \(T_k\)，见证唯一。该证明适用任何有限整数码字集和带标签圆弧集。

赤字计数由 R284CN/CP 的闭整数圆弧事件扫描计算：在圆周上对 \([a-r,a+w+r]\) 的左右端点发出 \(+1\)、右端点后一整数发出 \(-1\)；当 \(w+2r\ge P-1\) 时整条弧对全部整数位置覆盖。用排序码字的二分计数累计覆盖数小于 \(k\) 的区间，得到全域精确 \(F_k(r)\) 和必要的实际见证；没有浮点舍入。

## 冻结模型的求解结果

对每一级 \(k=2,\ldots,64\)，在 \(0\) 至已证 \(V_k-1\) 上二分赤字计数，全部精确满足
\[
\boxed{F_k(T_k)=2,\quad F_k(T_k-1)=3.}
\]

* 63 个等级的第三名**各有唯一见证**；对应 63 次第三名记录中有 62 个互异码字；
* 唯一重复出现在等级 **6 和 19**，码字同为 **3,347,474,455**；
* 第三名见证与此前全部 63 个第一名、63 个第二名见证均不重合；
* 第一、第二名两组各63点，彼此重合2点，合计124点。因此三组总并集是 \(\boxed{124+62=186}\) 点；
* 所有等级的第二—第三名距离差均为正；最小差为 **807**（等级20）。等级54的三名值依次为 **7,642,302,204 / 7,642,302,126 / 7,642,183,683**，第三名位置为 **6,683,702,379**；
* 等级1在全部65,536个码字上均有 \(d_1(x)=0\)，故前三名值均为0。

## 唯一最小三阶谱核定理

令 \(C\subset X\) 为全部 \(k=2,\ldots,64\) 的唯一第一、第二、第三名见证之并集，则
\[
\boxed{|C|=186}
\]
且 \(C\) 对每一级 \(1\le k\le64\) 均保留 \(X\) 上的前三名**按码字计重数排序的数值**。在所有有至少三个码字、且保持这套 64 级前三名数值的子集 \(Y\subseteq X\) 中，\(C\) 是**唯一的包含极小、也是唯一的最小基数集合**。

**证明。** 每级2至64的前三名均严格递减、各有唯一取得码字。若删去其中任意一个见证，该等级的相应名次便不能仍由原来唯一的取得者承担，原三级值序列必发生变化；所以任何保留全部三名数值的 \(Y\) 都包含这些见证的并集 \(C\)。反过来，\(C\) 同时包含每级的原前三名，而 \(C\subseteq X\) 不会产生更高的值，故全部前三名数值均保持。等级1全为0，因 \(|C|=186\)，其前三名同样保持。由此 \(C\) 必要且充分、唯一最小。证毕。

保留前三名极值的 **186点摘要**是一种针对该固定观察目标的无损子集，不是任意解码、全部码字分布或后续操作的无损压缩；对其他观察任务需要重新检验观察保真。

## 完成的计算和成本

`R284CQ_third_spectrum_checker.py` 通过原 R284CO 精确行列式生成器重算并核对65,536码字哈希；使用已固定 R284CO、R284CP 候选证书，进行了 **2,264 次**带标签整数半径赤字扫描（含本轮每级对既有前两名的两次一致性检查），逐级重算前三名距离并构造了186点谱核。谱核的距离表复用后只需 \(186\times64=11,904\) 次圆弧距离计算，随后可直接检验全部64级的前三名结果。

此外，在同一 Python 环境中还**独立执行了65,536×64=4,194,304 次距离求值**的全群体对照，所有等级的第三名值及唯一见证逐项相同。全群体对照属于本轮执行过的独立本地复算；已发布的主验证程序默认使用事件算法，未声称在远端 CI 独立运行。

事件法的第三名发现阶段不需为全部码字逐一求64条圆弧距离；预处理仍含生成、哈希校验和排序65,536个码字，且需要此前已证的第一、第二名候选。运行时间和跨平台性能优势另行测量。
