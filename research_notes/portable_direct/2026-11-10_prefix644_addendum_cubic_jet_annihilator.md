## 定理：基础质量零化式的三次幂消去全部二阶矩

令 `J=K[x_1,...,x_m]/(所有总次数≥3的单项式)`，K 为特征0的域（本项目取 Q），令 `I=(x_1,...,x_m)` 为 J 的正次数理想，则 `I^3=0`。取任意 `D×D` 周期转移矩阵 `Q∈Mat_D(J)`，其常数分量投影 `A=Q mod I∈Mat_D(K)`。若 `f(t)∈K[t]` 满足 `f(A)=0`，那么

```
(f(Q))^3 = 0  in Mat_D(J).
```

尤其取 `f=χ_A` 为 A 的特征多项式，Cayley–Hamilton 保证 `χ_A(A)=0`，所以

```
χ_A(Q)^3 = 0,    deg(χ_A^3)=3D.
```

若 `f=μ_A` 为 A 的最小多项式，则 `μ_A(Q)^3=0`，次数至多 `3 deg μ_A`，可能比 `3D` 更短。

**证明。** 自然环同态 `π:J→K`（令全部 x_i 为零）将矩阵 Q 映为 A。由于 π 与有限矩阵求和、乘积及标量多项式求值交换，`π(f(Q))=f(π(Q))=f(A)=0`。故 `f(Q)∈Mat_D(I)`；任意三个矩阵 `Mat_D(I)` 元素的乘积每个矩阵条目均是 I³ 中的有限和，因 `I³=0` 而整体零。由 `(f(Q))³=(f(t)³)(Q)` 得结论。对特征多项式的断言由 Cayley–Hamilton 得到。证毕。

设固定的 J 行向量 v、列向量 c，以及 `F_n=vQ^n c∈J`；若 `f(t)^3=∑_{k=0}^{3d} b_k t^k`，则所有 n≥0 都满足 **精确六分量线性递推**

```
∑_(k=0)^(3d) b_k F_(n+k) = 0.
```

在现行 BRC 双模式系统 `D=96×7=672`，因此**存在**阶数不超过 `2016` 的同系数整数/有理数递推（取 χ_A³）；若质量块 A 有更短的最小多项式，则可相应缩短。给定固定周期基础算子 Q，此性质适用于任意窗口相位的左/右端观测泛函，保持六元组全部矩分量。实际求取 μ_A、整阶递推系数、数值位成本和与二进制提升的性能比较，是后续计算单元。

**三次指数一般不可减为二次：** 一状态一变量的精确例子 `Q=[2+x]` 于 `K[x]/(x³)`，令 `A=[2]`、`f=t-2`，则 `f(Q)²=[x²]≠0`，而 `f(Q)³=[x³]=0`。这准确证明三次零化的普遍上界在此类二阶矩代数中可达到。
