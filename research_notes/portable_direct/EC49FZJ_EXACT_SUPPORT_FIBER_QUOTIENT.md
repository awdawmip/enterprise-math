## 1. Exact residual fibers
For W(r,j)=1[r in U]1[j not in H], finite nonempty support family F, at most h missing columns, after any feasible history define for each compatible U a forced-hole set B_U and allowed-hole set A_U. The exact fiber is {H : B_U subset H subset A_U, |H|<=h}. Positive observations exclude supports lacking the observed row and force the observed column live. Negative observations force the observed column missing precisely for supports containing the row. For each support discard B_U not subset A_U or |B_U|>h; if |B_U|=h set A_U=B_U. All restrictions are individual column literals plus the unchanged global cardinality bound, so the representation is exact by induction on history. A common positive anchor exists in the FZI cases. The number of labeled states is exactly sum_U sum_{i=0}^{min(|A_U-B_U|,h-|B_U|)} binom(|A_U-B_U|,i). No enumeration is needed to evaluate it.

## 2. Complete certificate by lazy fiber witnesses
Fix x=(U,H) in an anchored branch. Use the FZI full-feature certificate cost max(|T intersect U|,|L-H|)+|T-U|+|L intersect H|. Let L+ = L-H, L- = L intersect H. A different support V can agree with all selected row and column features iff (U xor V) intersect T is empty, B_V intersect L+ is empty, L- subset A_V, and |B_V union L-|<=h. In this case K=B_V union L- is itself a compatible witness. Hence an exact search can branch on one dynamically generated mismatch edge (U xor V, H xor K) per surviving support instead of precomputing every labeled competitor. Any valid extension must hit that edge; recursively branching over its features, with monotone cost pruning and memoized failed feature sets, is exhaustive. The same-support competitors are eliminated exactly by observing H-B_U, and additionally A_U-H if |H|<h. Necessity follows from singleton toggles; sufficiency follows from the cardinality constraint and the observed extra holes. The common positive anchor realizes every feasible feature certificate as in FZI. For the third-suffix roots the common known-live set P is inferred as the intersection of all live sets, and A_V is all columns outside P (or B_V for saturated fibers). The implementation uses the equivalent condition without explicitly testing L- subset A_V: L- is disjoint from P; if B_V saturated, the cardinality test forces L- subset B_V.

Corollary: if |H|<h, all free column features are mandatory. Every remaining different support V with B_V subset H and H subset A_V has the same-H rival. Any V for which B_V is not a subset H is already eliminated by mandatory live features (or a common known live constraint). Extra hole features in B_U cannot eliminate a same-H rival. Thus the old FZH same-H plus singleton certificate is exact at nonsaturated x in these anchored history fibers. More generally with arbitrary support-dependent A_V, the same proof uses the full fiber witness conditions; the simplification requires common known-live columns as in this model.

## 3. Lossless adaptive quotient
For each physical column j record the pair of support bitsets (D_j,E_j) = (supports forcing j missing, supports for which j remains optional). The remaining active supports force j live. Store active support bitset plus sorted multiset of these pairs. Saturated fibers have no optional bits. Any two histories with equal representation are isomorphic by a permutation of physical columns, keeping support labels and every observation response, including future histories. Conversely each such code defines the exact joint state family up to column labels. Query equivalence within an identical column-pair class follows immediately. This is a stronger quotient than the previous root-only compression: it is valid at EVERY descendant. Both child updates are exact set restrictions: for row support mask R, positive keeps active R minus D_j and makes j live; negative keeps active ((not R) union D_j union E_j), and for R intersect E_j moves the bit from optional to forced missing. Normalize saturation, clear inactive bits, sort. The state count formula is unchanged under normalization.

Necessary pruning: binary capacity n<=2^k; for every active support U with p optional columns the minimal state (U,B_U) has p singleton toggle rivals, so p<=k. If p=k, every first probe must be in U and address an optional column for U (and these constraints intersect over all tight supports). If strict supersets V of U admit the same B_U, all p mandatory column probes on (U,B_U) return positive and cannot distinguish V. For p=k this excludes the node; for p=k-1 the remaining single probe must use a row in the intersection of all V-U. If this intersection is empty the node is impossible. These bounds hold for any subsequent query history. A single support with p<=k is solvable by querying variable columns directly.

The recursive solver enumerates every informative row and distinct column class, prunes only the above necessary conditions and exact child capacity, and memoizes (canonical residual,k). An exhausted failure is a proof for the finite root; exceeding the call cap is UNKNOWN, not failure. The positive policy is independently replayed on all original labeled states by maintaining a column permutation and directly filtering W responses. All replayed branches assert exact singleton recovery and nonnegative remaining budget.
