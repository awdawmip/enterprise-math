## Result

## 2. Heavy offsets at q=4u-3,u>=3
Let two heavy sizes be 2q+a,2q+b with a,b>=2u, residual mass R and k=a+b+R<=8u+1. Thus R<=4u+1=q+4. Use GE: sum_e (N_e-q)_+>=q+4u+1 on each edge. Other groups with total M contribute at most (M-q)_+.
Pair {3,6}: edges 0 and 1 isolate the respective heavy group; hence a,b>=4u-3 and R<=7<=q. Reapplying GE yields a,b>=4u+1, contradiction.
Pair {3,5}: let g=3, h=5; {5,6} is its cyclic rotation (normalized shift sends 1->7,2->1,3->6,4->2,5->5,6->3,7->4). Put r1=x1,r2=x4. Edges with only h changing among the heavies give b+max(r_i,R-q)>=4u+1 for i=1,2, because the h-group size is 2q+b+r_i and others have total R-r_i. If b<=4u-4, each r_i>=4u+1-b>R-q, so k>=a+b+2(4u+1-b), giving b>=a+1>=2u+1. If b>=4u-3 the same b>=2u+1 holds. Hence R<=4u.
Suppose a=2u. At phases 0,2 only g of the heavies differs. A two-vertex cut cannot separate: g has exactly 2q+2u and residual mass<=4u<2q+2u+1. A four-vertex cut cannot separate: total differing mass <=2q+k-b<=2q+6u<4q+2u+1. A three-vertex cut must include g and a residual type of size >=q+1=4u-2 (residual mass alone too small). Its total mass constraint gives b<=k-q-2u-1<=2u+3. Thus both distinct r_i>=2u-2>R-q (<=3). The largest residual type leaves at least 2u-2 in another type, and has size <=2u+2<4u-2. Contradiction. Therefore a>=2u+1.
If b=2u+1, R<=4u-1 and R-q<=2, then both r_i>=2u, impossible. Therefore b>=2u+2, R<=4u-2=q+1.

## 3. Source-group-aware diagonal barrier: two extra successful writes
For pair {3,5} use edge 0->1. Comparison phases 2 and 3 differ from source 0 on g alone and h alone respectively among the two heavies. At phase 2 the residual last-change groups are {7}, {1,2,6}, {4}; g belongs to the first and h to the second. At phase 3 these groups are {7}, {1,6}, {2,4}; both g,h belong to the third. Empty group omitted. Every such residual group excludes at least one of types 1 and 4.
Claim each residual group has size <=q-2. If R<=q-2 immediate. Otherwise R>=q-1=4u-4, b<=k-a-R<=2u+4, so both r_i>=2u-3>=3>R-q. Since R<=q+1 each group is <=R-3<=q-2.
Set refined thresholds
 T_g=a+x7-2u, T_h=b+x2+x4-2u.
Both positive. T_h<=b+R-2u<=4u=q+3. T_g<=a+R-2u<=4u-1=q+2. In fact T_g<=q+1: if R>x7 subtract at least one; otherwise r1=r2=0 and b>=4u+1-max(0,R-q)>=4u. Then R<=2u<=q so b>=4u+1 and T_g<=2u<=q+1.
Follow any fixed order until one threshold first hit (they are attainable since each <=its heavy size). If h hits first, fewer than T_g<=q+1 g attempts: omit all. All h and residual attempts succeed. Compare to phase 3. Correct up to q untouched h in source history, and up to q-(x2+x4) further untouched h in comparison history. Correct all residual mismatches in comparison history; each group has its own q budget. Distance <=max(0,2q+b-T_h-2q+x2+x4)=2u.
If g hits first, at most T_h-1<=q+2 h attempts: omit all except at most two, let all g and residual attempts succeed. Compare to phase 2. Correct up to q untouched g in source history and q-x7 more in comparison history; correct residual mismatches in comparison history. Up to two successful h writes create extra mismatches in the h comparison group, distinct from g group and with at least two unused slots. Therefore distance <=max(0,2q+a-T_g-2q+x7)=2u. All masks respect the independently attainable last-change slots of FM. The current prefix omits at most q. Noisy read sets intersect, forcing a forbidden third-phase success. This argument uses actual per-source group capacities, not total R as a proxy. Rotation handles {5,6}. This proves the unbounded u>=3 boundary with section 1.

## 4. Exceptional q=5,u=2 (width <=37)
Enumerate all seven nonconstant histogram counts with sum<=37 (38,320,568). Constants can be removed as in GC/GI. GE's four necessary conditions retain 656,212; full six stable cut inequalities retain 315, of which three are nonheavy. For each retained histogram, test each edge via a finite directed grid of attempted counts for changing patterns. At a vertex enumerate all omission counts o_p in [0,a_p] with sum<=q; successful counts s_p=a_p-o_p. For each third phase j the exact minimum Hamming distance to its stable set equals max over resource subsets U of (mismatch mass whose allowed endpoints are contained in U)-q|U|, including empty U. Untouched nominal mismatches have source and comparison last-change endpoints; successful mismatches have comparison endpoint alone. This follows by the same capacitated bipartite assignment/min-cut argument as FM (each mismatch can be fixed on either endpoint, at most once, and all last-source masks are attainable). Matching nominal bits can be left alone: introducing errors on them cannot improve the optimum. Enumerating 256 subsets is exact. A vertex is forbidden iff some legal omission vector and third phase have distance<=2u. Pattern symmetry means counts suffice: columns with the same pattern have identical incidence, so any fixed order projects to a unit-increment count path; every such path can be realized by choosing any unused column of its next type. A protocol requires a path from zero to full counts on every edge using no forbidden vertex. Depth-first search with memoization decides this finite DAG, testing only necessary third-phase safety; no survivors suffices.
Actual C++17 runs: 315 candidates, 159 first fail edge 0, 156 first fail edge 1, 0 survive. 12,352 visited vertices, 124,316 third-phase cut queries. Thus all widths <=37 fail, while Gray gives 38. The checker enumerates all smaller widths directly rather than assuming nonconstant padding.
