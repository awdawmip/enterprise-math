## 1. 问题及精确定义

令 `S_k` 是长度 0..k 的无重复来源字，乘积按时间串接后保留每个来源最后一次出现的顺序：
[
u\star v=(u\setminus\operatorname{supp}(v))v.
]
状态数 `N_k=Σ_{r=0}^k k!/(k-r)!`，定长二进制编码下界 `B_k=ceil(log2 N_k)`。

对于每个 `r`，`P(k,r)=k!/(k-r)!`。把长度为 r 的字按字典序排序，设 `rank_r(s)` 为 0 起始的下标，定义
[
E_k(s)=\sum_{j<|s|}P(k,j)+\operatorname{rank}_{|s|}(s).
]
明确的排名算法：从可用的升序来源表开始，在位置 i，将当前来源在表中的 0-based 序号乘以 `P(k-i-1,r-i-1)`，加到本层排名并删除来源。逆算法先确定唯一长度 r，再按相同位置的基数 `P(k-i-1,r-i-1)` 连续 divmod 选择未用来源。空字编码为 0。

令 `Aff_n(Q)` 是 n 维有理总仿射作用半群，`a.then(b)=b∘a`。定义**因子化联合 BRC 直方图**的原子键：
[
(w,A,E_k(s)), \quad w\in\mathbb Q_{>0}, A\in\mathrm{Aff}_n(\mathbb Q), s\in S_k,
]
其系数为正整数重数。备选合并相同键时重数相加；串行复合的单项结果为
[
(w,A,E_k(s))\cdot(v,B,E_k(t))
=(wv,B\circ A,E_k(s\star t)),
]
重数相乘。零包是空字典；单位包是权重 1、物理恒等作用及 `E_k(())=0` 的单项包。

## 2. 定理 R197A：编码最优性与可组合性

**命题**（任意 k≥1）。`E_k:S_k→{0,...,N_k-1}` 是双射；对编码定义
[
x\diamond_k y=E_k(E_k^{-1}(x)\star E_k^{-1}(y))
]
后得到一个严格结合、有单位且能精确回答任意单来源/双来源最后出现比较的有限幺半群。其任意无损固定宽度二进制状态标记需要至少 `B_k` 位，`E_k` 恰好达到该下界。

**证明**。各长度 r 的字数为 `P(k,r)`，层间偏移互不相交，层内按逐位置可用元素排序的展开是混合进制双射，故 `E_k` 双射。一个来源在串接结果中若出现在后段，最后出现必位于后段，否则保留前段的相对顺序；故 `star` 是实际字串拼接在该观察商上的乘法，结合性、空字单位及任意后续观察保真来自拼接本身。通过 `E_k` 搬运乘法即得 `diamond_k`。全部 `N_k` 状态相互可区分（甚至完整顺序读出已能区分）；固定 B 位最多表示 `2^B` 个值，故 `B≥ceil(log2 N_k)`。QED。

## 3. 定理 R197B：与 R196 稠密提升精确同构

定义 `H_k(n)` 为上述有限正整数系数字典的集合，令 `Φ` 是 R196 的原生提升：
[
\Phi(w,A,E_k(s))=(w, A\oplus R_s),
]
其中 `R_s` 是 R195 的 d=k(k+1)/2 维来源重置仿射作用。

**命题**。`H_k(n)` 对备选合并和串行复合闭合、结合，`Φ` 是其到原生 `EffectHistogram(n+d)` 的忠实（单射）且保运算的映射；其像恰是由严格无交叉块、来源块等于某个 `R_s` 的正项生成的正有理权重/整数重数直方图。

**证明**。有限支持字典的系数加法/交叉乘法满足结合与分配，因物理仿射复合及 `diamond_k` 都结合，乘法结合。R196 已建立 `R_{s★t}=R_t∘R_s` 且 `s↦R_s` 忠实。因此 `(A⊕R_s).then(B⊕R_t)=(A.then(B))⊕R_{s★t}`。原生的正权重与重数规则同为乘法、同键累加，逐原子成立后经分配律成立。反向从物理块读取 A，从重置块唯一读取 s，再编码 E_k；故原生相同键当且仅当因子化键相同。QED。

## 4. 定理 R197C：表示与运算资源的分离

物理 `Affine(n)` 仍需要稠密 `n²+n` 个有理数槽位。因子化载体的额外*数学状态*是每个不同项一个 `B_k` 位定长来源代码，无需增加物理矩阵维数。相比之下 R196 原生稠密提升每项额外含 `2nd+d²+d` 个有理数槽位，其中 `d=k(k+1)/2`。在 `n=2,k=6` 时两者为 **11 个来源编码位**与 **546 个额外稠密有理数槽位**。这里比较的是载体中必需的信息/标量槽位，并不把 Python 字典、对象头或整数分配开销算作 11 位。

单个来源字的 `star` 用来源成员位集或集合在 O(k) 次字操作完成；所附复算程序用简单可用列表的 ranking/unranking，每次 O(k²) 次整数表操作，故编码态的每项串行复合附加 O(k²) 次字操作，且物理部分需一项 n 维有理仿射复合。若以 Fenwick 树实现可用来源秩选择与前缀计数，编/解码可降至 O(k log k) 次字操作。所有这些是**算术操作和结构表示成本**；有理分子/分母位数、整数乘法成本、排序与碰撞整理的真实时间、内存分配及 native 包执行仍需独立测量，不宣称全端到端提速。
