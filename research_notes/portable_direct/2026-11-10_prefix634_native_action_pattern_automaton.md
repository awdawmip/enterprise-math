## 2. 自动机×原生 DAG 精确定理

在已知且保留所有 action ID 的正质量 DAG 上，设前缀匹配状态 `q in {0,...,k-1}`，`seen in {false,true}`，及权重矩 `(mass,occ_mass)`。由 KMP failure function 构建确定性状态转移 `(q,a) -> (q',hit)`，其中命中后允许按最长真前后缀继续，故重叠模式按次数计入。对每条原始 DAG 动作边 `e=(s --a,w--> d)` 更新：

```text
new.mass += old.mass * w
new.occ_mass += (old.occ_mass + old.mass * [hit]) * w
new.seen = old.seen OR hit
new.q = delta(q,a)
```

初始化在每个根端口 `s`：`(q,seen,mass,occ_mass)=(0,false,r_t[s],0)`。终点求和 `Z=sum(mass)`、`M_hit=sum(mass|seen)`、`M_occ=sum(occ_mass)`。由每条有序原生动作路径在乘积图中存在唯一确定的自动机状态演化，有限分配律逐层给出

```text
Pr(出现>=1次)=M_hit/Z
E[重叠出现次数]=M_occ/Z,  Z>0.
```

对任意固定原生四点探针图，内层非末层12端口，末层28端口；每个端口至多 `2k` 个确定性自动机与 `seen` 状态。乘积图最多 `O(Lk)` 个状态与边；KMP 转移预处理对实际使用的有限动作字母表需 `O(k*|alphabet|)`，单条边固定状态转移，从而全模式查询的字段算术与存储为 `O(Lk)`，并保留原 PREFIX-629 的最小历史寄存器数量（参数记忆不变）。若 `Z=0`，报告质量0，概率无定义。路径全量展开仍按输出本身计量，分数位长另计。

两个不同深度 `i<j` 的原始动作 `a,b` 采用2个布尔位跟踪是否经过指定深度边，递推给出 `M_i(a)`、`M_j(b)`、`M_{ij}(a,b)`；`P(A_i=a,A_j=b)=M_{ij}/Z`。这直接提取跨步联合来源而不把单步边际误认为独立。

## 3. 原生全1门控特殊族的闭式期待次数

取 **全部 g_h=1、lambda>0**，模式由原生正权动作 `(485,316,52,174)` 构成，准确原生端口循环为 `29->80->52->8->29`，四条边权均为1。对 `t>=4` 的四点探针，按持续传播12端口的质量归一化后，端口29在第 `i` 个后缀层的条件质量占比满足四周期恒等式：

```text
p_t(i;29) = (1 + [ (t+i) mod 4 = 1 ])/14.
```

它来自有限12端口邻接演化的4周期以及原生全1门控下 `A(1)^4 r_t=16r_t`；在4种余数代表层 `t=4,5,6,7` 对源质量直接比较即可，随后以四步闭环归纳。

因为完整非末层每个持续端口恰有2种等权续行动作，末步恰有6种动作，模式从深度 `i<L-4` 开始的条件概率为 `p_t(i;29)/16`，而从 `i=L-4` 开始时，最后一条动作位于6分支的末层，条件概率为 `p_t(L-4;29)/48`。令 `m=L-4` 及 `S(t,m)=# {0<=i<m : t+i ≡ 1 (mod 4)}`。则所有 `t>=4,L>=4` 严格得到

```text
E[N_(485,316,52,174)]
= (m+S(t,m))/224
  + (1 + [(t+m) mod 4=1])/672.
```

当 `L<4` 时期待次数为0。特别地 `(t,L)=(960,64)` 时，精确期待次数 `113/336`，而“至少一次出现”概率为

```text
68495692540077856805 / 258254417031933722624
```

（由乘积自动机原生有理数精确计算，不以期待次数近似概率）。此例的显式全路径数 `72*2^63=664082786653543858176`，无需展开即可计算模式观察。

## 4. 精确反例：两个动作边际不能相乘

原生全1门控 `lambda=1,n=12,L=6,t=6`，令
`A=(depth0 action28:32->4)`、`B=(depth1 action340:4->56)`。完整正质量路径分布的精确总质量 `Z=86016`，两事件的质量均为3072，联合质量为1536，因而：

```text
Pr(A)=Pr(B)=1/28,

```

说明真正的跨步来源联合观察必须保留两个深度间的路径结构，单步汇总边际不足。
