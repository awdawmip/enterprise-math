## 1. Matroid and exact capacity reduction by dummy labels
Fix finite ports C, positive integer base capacities c_i, nonnegative integer upper increments h_i. All actual targets have distinct labels, nonempty masks E_x subset C, and finite nonnegative weights. Empty masks may be retained free and removed from this optimization. Strict Hall independence on a labeled set I means f_I(V)<=c(V)-1 for every nonempty V. This is a matroid: hereditary, and GBP's maximal-set packing proof applies to every restriction of the ground set, so all maximal independent subsets of any restriction have the same size (equivalently the augmentation axiom). For completeness, rejected labels of a maximal I are each contained in a tight set. Intersecting tight sets have tight union by supermodularity and strict feasibility. The maximal tight sets are pairwise disjoint. Any independent J in the restriction has at most |I| targets inside those sets by their tight capacities, plus at most the number of I targets outside because every rejected label is inside. Hence |J|<=|I|.

Let M be this matroid at full capacities c+h, on actual labels X together with a disjoint labeled dummy set D containing h_i singleton-mask labels at i. D is independent, because for nonempty V it uses h(V)<=c(V)+h(V)-1. For any released subset R of D, put K=D minus R. Strict feasibility of I in M/K is equivalent to strict feasibility at capacities c_i+|R at i|: since K is independent, I is independent in the contraction iff I union K is independent in M. The latter cut inequality subtracts precisely the unreleased singleton counts. This identity preserves actual labels and masks and works on every restriction of X.

Write r_R(A)=r_M(A union K)-|K| for actual subset A. r_0 and r_D denote base and full rank. For R subset T, the greedy actual retained set in M/(D minus R) is contained in that of M/(D minus T), when the same total label order is used. Indeed label x is selected by prefix-rank increment iff it is not in closure of earlier actual labels plus K. Decreasing K only shrinks closure, so a previously selected x remains selected. Equivalently by submodular marginal inequalities, acceptance at lower capacity implies acceptance at higher capacity. This holds for every prefix, including zero-weight labels and fixed tie-breaking.

## 2. Released-credit matroid and multiple-port shared-budget theorem
For fixed A subset X, set N_A=(M/A)|D and L_A=N_A^* (matroid dual on D; A need not be independent). Dual rank gives
r_{L_A}(R)=|R|-r_{N_A}(D)+r_{N_A}(D minus R)
= r_R(A)-r_0(A).
Thus every rank gain as a function of released dummy labels is itself a matroid rank. This gives monotonicity, integer diminishing returns, and exact max at budget k:
max_{|R|<=k} r_R(A) = r_0(A)+min(k,r_D(A)-r_0(A)).
Crucially a common nested release chain works for ALL prefixes of any fixed actual-label order. Let A_p be prefix p. At release set R, adding a remaining dummy e yields gain
g_p(e)=1-[r_M(A_p union K)-r_M(A_p union (K minus {e}))].
Each g_p is 0 or 1, and nondecreasing in p by rank submodularity. Starting at R empty, select at each step a dummy whose first positive prefix gain is earliest (if all gains zero, arbitrary). If a prefix's released-credit rank is below its total rank, augmentation in L_{A_p} guarantees some remaining dummy increases it. Therefore the earliest unsaturated prefix can be increased, and the selected dummy increases every later unsaturated prefix as well (earlier saturated prefixes cannot increase). Induction gives for all p,k,
r_{R_k}(A_p)=min(r_0(A_p)+k,r_D(A_p)),
where R_k is nested and |R_k|=k, 0<=k<=|D|. This proves simultaneous optimality for every prefix and budget. No common release chain for all arbitrary subsets A is claimed.

## 3. Two sweeps recover all weighted optima AND actual retained labels
Order actual labels by nonincreasing nonnegative weight, ties by a fixed label order. Let B_0 and B_infty be greedy bases at base and full capacities. By section 1 B_0 subset B_infty. List B_infty minus B_0 in the common order as x_1,...,x_s. Prefix rank difference d_p equals the number of these extra labels in A_p. Section 2 shows the greedy retained set at the optimal release chain at budget k is EXACTLY
B_k = B_0 union {x_1,...,x_min(k,s)}.
Consequently the optimal retained weight is F(k)=w(B_0)+sum_{a<=min(k,s)} w(x_a). This follows from prefix rank increments (or GBR layer formula); nonnegative weights make using at most k and exactly k equivalent when k<=|D|. Minimum weighted deletion cost is total actual weight minus F(k). For k>|D| use k=|D|. The GBT one-port marginal integrals equal the weights of the high-capacity greedy-only labels, in order; no quadratic integration across weight layers and no additional actual-label replay for each budget. Unlike GBT, multiple adjustable ports can compete for one integer unit budget, subject to individual caps h_i. The one-port GBT actual label witness is a special case.

## 4. Recover a physical port-capacity allocation for a chosen budget without expanding all dummy slots
For I=B_k, I is independent at full capacity. In N=(M/I)|D, greedily retain a maximal independent dummy subset K. Then I union K is independent in M, and |D minus K|=|D|-r_N(D)=|I|-r_0(I). This is minimum release count for that specific I. Since I is attained at budget k by section 2, the count is <=k (indeed equals min(k,s): r_0(I)=|B_0| because it contains the base basis and cannot exceed the base rank of X). Release remaining slots arbitrarily if exactly k are required, within upper caps.
All dummy labels at one port have identical mask. To compute K, process ports in any fixed order and keep the largest number of that port's remaining dummies consistent with I and the previously kept dummies. Feasibility is monotone in this count, so binary search on [0,h_i] using strict Hall feasibility of I at full capacities minus kept counts is exact. At termination K is maximal, hence maximum cardinality in N. This avoids expanding the potentially huge number of dummy labels in the constructive allocation. Strict Hall feasibility can use GBQ/GBS capacity-level methods; for a complete current match, GBS inverse reachability verifies strictness.
