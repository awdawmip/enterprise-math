## 1. Multi-block rank-corner theorem

Let N=(M/S)|F where S is the current independent prefix. In the auxiliary strict-Hall model, every nonempty port set V has a quota c(V)-1 for the labels supported in V; all future labels have nonempty support. Partition a portion of F into disjoint nonempty classes H_1,...,H_k with identical support within each class; permutations within each H_i fix other labels and preserve all independence constraints (also after contracting S). Let Q be any subset disjoint from their union. Write H_J=union_{i in J}H_i, R_i subset H_i, t_i=|R_i|, R=union R_i, t(J)=sum_{i in J}t_i. No independence of R is needed for the first identity.

For any such choices,

    r_N(Q union R) = min_{J subset [k]} (r_N(Q union H_J) + t([k] minus J)).        (1)

Proof: For one class H, contract an arbitrary set U disjoint from H. The rank of H in N/U is r_N(U union H)-r_N(U). All permutations of H induce automorphisms of the restriction, hence its rank on a t-subset is min(t,r_N(U union H)-r_N(U)): permute a basis to contain any set of at most that size, and use monotonicity otherwise. The contraction rank formula gives r_N(U union R_i)=min(r_N(U)+t_i,r_N(U union H_i)), including dependent U or R_i. Apply this identity successively for each of the disjoint classes; at each binary branch the remaining classes still have the required free permutation symmetry. Expanding the nested minima gives (1) exactly. This generalizes the one-block GCE numerical identity to a vector of simultaneous counts.

Set Q=empty in (1). Since r_N(R)<=t([k]), equality, and hence independence, holds iff

    t(J) <= r_N(H_J) for every J subset [k].                                  (2)

If (2) holds, contraction yields

    r_{N/R}(Q) = min_{J subset [k]} (r_N(Q union H_J) - t(J)).                   (3)

Empty J is included; all expressions in (3) are nonnegative for legal R. Thus a batch of k distinct supports has a joint piecewise-affine rank response, with at most 2^k exact corner terms. It depends on the chosen labels only through the vector t, and not on the order of contraction. This does not assert that a small selection of corners suffices, or that a bound polynomial in k holds.

## 2. Basis-free state and exact dominance

When the *entire* remaining suffix is partitioned into h support classes, define rho(J)=r_N(H_J) for every subset of class indices, including rho(empty)=0. Equation (2) reconstructs all feasible remaining labeled subsets via their count vectors. Conversely every rho(J) is the maximum attainable cardinality using only classes in J, so it is determined by the feasible count family. For two states on the same suffix, feasible labeled family inclusion is equivalent to pointwise rank-table dominance: sufficiency is (2); necessity follows by choosing a basis of the dominated state's union H_J. Equality of tables is equivalent to exact equality of the remaining feasible families. It follows that the GCB objective Pareto elimination using retained real value, retained auxiliary cost saving and pointwise rank dominance is still exact. The raw input labels remain stored; a deterministic top-weight choice within each of the two objective types of one class preserves at least one original optimal witness, as in GCE.

Process a single class H_i: admissible t<=rho({i}), and for each remaining class-index set K the child table is

    rho'(K)=min(rho(K), rho(K union {i})-t).                                   (4)

For an entire processed batch P, use (3) with Q=H_K:

    rho'(K)=min_{J subset P}(rho(K union J)-t(J)).                             (5)

Equations (4)-(5) are closed in the stored rank values. No cached basis, quota scan, additional independence test or greedy rank query is necessary for the transition itself. In a binary mask ordering where the first class is the low bit, (4) reads just adjacent entries 2K and 2K+1. The table can be initialized by a greedy extension of a cached basis for a smaller class-union set. For one processed class, each count needs 2^(h-1) scalar minima; objective choices with the same t reuse the result. Initialization costs at most sum_i 2^i |H_i| direct independence calls in the implemented increasing-index construction, since each class is the highest bit of 2^i masks (zero-based i); also include rank/basis table allocation, mask widths, direct independence oracle cost, dominance comparisons and actual witness recovery. The implementation uses exact small bit masks; this is not a large-label machine implementation.

This is a distinct tradeoff from GCC/GCF. GCC's joint-support-closure coordinates are often much fewer than all subsets of distinct support classes; the latter include unions of classes which are not closed under containment of their support. Full class-subset table cardinality 2^h-1 is an exponential worst-case cost, not a universally safe replacement for the support-closure representation. In particular, an omitted joint term in (5) must not be inferred redundant from the independent per-class margins alone. Example: unit capacities at three ports with edge classes ab,bc,ca (one label per class), every singleton and pair is forest-independent but the triple has rank 2. The three count coordinates t=(1,1,1) pass all proper-subset inequalities and fail (2) for the full set. This is an auxiliary relation example, not a native spatial assertion.

Observer scope: exact finite remaining labeled insertion/skip choices, their ranks, full all-budget optimum and at least one attaining original witness. Arbitrary future new support classes, reverse deletion, all optimal histories, provenance not already retained, and native state identity are outside this quotient. Preserve original relation masks/labels and separate typed observer bridges.
