## 定理：所有偶数 m 的精确四周期系数

对任意固定偶数 m≥2，令
`D_m = -i H'_{0,m}(i) + 220(1-i)H_{1,m}(i) +220H_{2,m}(i)-440H_{h,m}(i)`。
则原失败生成函数 `G_m(q)=sum_{N>=0} F_m(N)q^N` 在 q=i 的 Laurent 主部恰为

```math
G_m(q) = A D_m (1-q/i)^(-23) + O_m((1-q/i)^(-22)).
```

以下为 **全体偶数 m** 的闭式：

```math
D_{4t+2}=(t+1)(436t+656-2i),\quad t\ge 0,
D_{4t+4}=(t+1)(t+2)(436+220i),\quad t\ge 0.
```

特别地，所有偶数 m 的 D_m 均非零。q=±i 这一**共轭极点对自身**对系数序列的贡献为

```math
\frac{2A}{22!}\operatorname{Re}\!\left(D_m i^{-N}\right)N^{22}
+O_m(N^{21}).
```

这里的 O 仅针对 q=±i 两个极点；完整 F_m(N) 仍含 q=1、q=-1 和其它单位根贡献。在这个精度下保留原始四周期分量，需要可区分 N mod4 的观察状态：由于 Re D_m>0 且 Im D_m≠0，N≡0与2，以及 N≡1与3 的四周期主系数均相反且非零。奇数 m 的 N^23 四周期结论继承前驱，不在此重证。

## 证明

**第一步（极点阶数和局部系数）。** 在 q=i 令 s=1-q/i。对自由价格集 E，4|p 的因子 (1-q^p)^(-1)=(ps)^(-1)+O(1)，其余因子取 (1-i^p)^(-1)。G0 自由价格219..314中有24个4的倍数，局部24阶系数为 A。G1 的自由集合 {215}∪{222,...,314}有23个4的倍数，首项常数相对 A 是220(1-i)；G2的自由集合 {214}∪{222,...,314}的相对常数为220；Gh的自由集合222..314的相对常数为440。前驱剩余五项的自由4倍数不超过20（S4及其交集）或更少（S3相关）。对偶数 m，前驱有 H0,m(i)=0，所以 G0 的首个非零候选项恰为 `A*(-i H'0,m(i))*s^(-23)`。三项其余首项按容斥符号合并，得到 D_m。

**第二步（局部多项式的 m-生成函数）。** 设 `J_p=i^p`、`H_j(z)=sum_{m>=1}H_{j,m}(i)z^m`。逐项交换有限组合系数求和可得

```
H_j(z)=z/(1-z) * product_{p in Sj} (1-z J_p)^(-1).
\sum_{m>=1}[-i H'0,m(i)]z^m
 = -H_0(z)* sum_{p in S0} (p z J_p)/(1-z J_p).
```

**第三步（交集 h 的有理生成函数）。** 分组 x=n214、y=n215、t=n216+n217+n218、u=n219+n220+n221。t 的有权生成函数为 `[(1-z^2)(1-iz)]^(-1)`。u 的有权重数是 `v_u=1_{u≡0,1 (mod4)}`，可以按 `v_u=(1/2)1^u+((1-i)/4)i^u+((1+i)/4)(-i)^u` 无损拆分。另 x 的权为 α=-1，y 的权为 β=-i。

对任意复权 α,β,γ，定义
```
M(a,b;z)=(1-ab z^2)/[(1-az)(1-bz)(1-abz)]
T(a,b,c;z)=(1-abc z^3)/[(1-abc z^2)(1-az)(1-bz)(1-cz)]
S(a,b,c;z)=M(b,c;z)/(1-az)+M(a,c;z)/(1-bz)
             +M(a,b;z)/(1-cz)-T(a,b,c;z).
```
其中 M 恰为 `sum_{y,u>=0}b^y c^u z^max(y,u)`；T 恰为 `sum_{x,y,u>=0} a^x b^y c^u z^(x+y+u-min(x,y,u))`。前两类加法来自两个失败条件的最大下限，T 是三项交集；因此严格的容斥生成函数为
```
H_h(z)= z/[(1-z)(1-z^2)(1-iz)] *
 {S(-1,-i,1)/2+(1-i)S(-1,-i,i)/4+(1+i)S(-1,-i,-i)/4}.
```

**第四步（闭式与系数抽取）。** 定义 `D(z)=sum_{m>=1}D_m z^m`，用上式和 H_j(z) 代入，精确化简其偶数部分 `[D(z)+D(-z)]/2` 得

```
sum_{m>=2, m even} D_m z^m =
 [(656-2i)z^2+(872+440i)z^4+(216+2i)z^6]/(1-z^4)^3.
```
由 `(1-z^4)^(-3)=sum_{t>=0}binom(t+2,2)z^(4t)`，按 m mod4 展开即得上述 D_{4t+2}、D_{4t+4}。因两种情况下实部严格为正且虚部不为0，故23阶极点非零。

最后，`[q^N](1-q/i)^(-23)=i^(-N) binom(N+22,22)`，加上 q=-i 的共轭极点，得到所列 N^22 四周期项。证毕。
