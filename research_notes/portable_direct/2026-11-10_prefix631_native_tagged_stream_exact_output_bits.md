## Theorem 1 — Sharp exact path-output cardinality

For **lambda>0 and all gates strictly positive**, the nonzero length-L suffix tensor contains exactly

```
K(t,L)=72*2^(L-1)        (t>=4, L>=1).
```

The count does **not** depend on total history age `t` or on the values of the strictly positive gates. For **nonnegative** gates including zero, `K(t,L)<=72*2^(L-1)`; this upper bound is attained, so it is sharp.

**Proof from original native action graph.** For a positive gate, all and only the original 384 nonzero typed edges are enabled. Among 96 ports, 64 have six nonzero outgoing actions, 32 have none. Write `D` for the latter (dead endpoints) and `U` for the 32 live ports with **exactly two** outgoing edges to live ports. The other 32 live ports have four such edges. Exact STAR adjacency gives the stronger closure certificate:

- each port in `U` has precisely six positive outgoing actions: **two into U** and **four into D**;
- no port in `D` can extend a positive path;
- for this four-point input, `r_t` at each `t>=4` has precisely **12 nonzero ports in U** and no nonzero ports in the other 32-live class. Its remaining 16 nonzero entries are in D.

The last statement is a finite-support identity: compute the exact four supports for `t=4,5,6,7` below, then use the original `A(1)^4 r_2=16 r_2` certificate to propagate support in period four; strictly positive gates induce the same Boolean transition graph as gate one. Starting from each of the 12 live predecessor ports, exactly six choices exist for the *final* path step, and exactly two choices exist for each preceding step. Therefore each emits `6*2^(L-1)` distinct full paths. Dead predecessor entries emit none. The count follows. Gate-zero transitions only delete edges/support from the positive graph.

## Theorem 2 — Exact mass histogram and bit-output cost for a canonical family

Fix `lambda=1` and `g_k=1` for every gate, and `t>=4`. Every original positive edge then has weight one. Among the 12 recurrent source ports, exactly **10 carry mass `2^(t-1)`** and **two carry mass `2^t`**. Thus the complete length-L output has the **exact** mass histogram:

```
mass 2^(t-1):  60*2^(L-1) entries
mass 2^t:      12*2^(L-1) entries.
```

If each path mass is printed separately as a canonical unsigned base-two integer, its total mass-field length is exactly

```
B_mass(t,L)=(72*t+12)*2^(L-1) bits.
```

Full per-path port-label sequences require `Theta(L*2^L)` additional fixed-width label bits. Consequently **explicit** full-tensor output in this precisely specified encoding costs `Theta((t+L)*2^L)` bits. For fixed `L`, `t`-bit numbers prevent age-independent *bit* output time even when the arithmetic operation count of PREFIX-630's reconstruction is `O(L)`. These are output-representation costs; implicit/compressed output is a different observer and may share repeated masses.

**Proof of the all-one mass identities.** Write `r_s=A(1)^s E(d)`. Direct exact action enumeration certifies `r_6=16r_2`. Since one fixed original operator is repeated, for any `s>=2` one has `r_(s+4)=A(1)^(s-2)r_6=16r_s`. Directly check each of the four base residue cases `s=4,5,6,7`: each has 10 recurrent masses `2^(s-1)`, two masses `2^s`, plus 16 dead-port masses. Scaling by `16=2^4` proves this histogram for all `t>=4`. Every positive path has mass equal to its source mass in this all-one family, and each recurrent source yields the same `6*2^(L-1)` paths. Counting both mass classes proves the bit formula.

## A streaming interface that matches the declared observer

Use a depth-first iterator over original port/action edges, carrying `(path_prefix, mass, depth)`. At an intermediate depth, follow **only edges into U**, because a dead destination cannot reach the required full length. At the final step, follow all six original positive outgoing edges and output the complete labelled path and exact mass. Gate-zero edges are skipped. Keep a path stack of at most `L+1` labels, current exact prefix mass, and the original recovered 96-port `r_t`; output is streamed, not accumulated. For all strictly positive gates, this emits exactly `72*2^(L-1)` entries in `O(2^L)` typed edge visits plus `Theta(L*2^L)` serialization of path labels. Auxiliary *word* storage for enumeration is `O(L)`, excluding the fixed original state, fixed graph, and exact scalar bit lengths.

At zero gates some U-to-D or U-to-U actions disappear; the same iterator remains exact by testing the true original coefficient of each edge. The 32+32 graph partition is based on the potential-positive graph, so it remains a sound pruning criterion for all nonnegative gates.
