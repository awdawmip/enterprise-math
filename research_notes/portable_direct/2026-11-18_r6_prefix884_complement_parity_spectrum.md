## 1. 模型与语义边界

令 `p≥1`，`N=2^p`，有 `p` 个带具名索引的二元来源位。合法**有序**心跳是 `(x,T_i(x))`，其中 `i=*` 表示 `T_*(x)=x`，而 `i=0,…,p-1` 表示 `T_i(x)=x XOR 2^i`。每条轨迹保留具体旧状态、时间次序与来源名称。两个端口取正奇数 `q1,q2`，观察为 `(x mod q1, T_i(x) mod q2)`。令 `c(r,s)` 为观察余数对 `(r,s)` 的原轨迹重数；`C` 为观察相同的无序不同原轨迹对数。

这是 Heartbeat World 原生六维空间及独立时间之上的有限具名观察器，不是对 X6 Cell/Link/Port 或未来来源历史的状态缩并。P000、复合关系背景、来源顺序、时间语义保持不变。

## 2. 定理 884-A：完整二阶矩恒等式

令 `M=N(p+1)`。则

```text
C_p(q1,q2) = sum_{r=0}^{q1-1} sum_{s=0}^{q2-1} binom(c(r,s),2)
           = (sum_{r,s} c(r,s)^2 - M)/2.
```

证明：每条具名轨迹恰属于一个观察纤维；每一纤维含 `c` 条轨迹，构成 `binom(c,2)` 对不同轨迹。全体轨迹数量为 `M`，所以 `sum c=M`。直接展开二项式即得。此恒等式提供独立于 PREFIX-883 整数格公式的完整枚举验证口径。

## 3. 定理 884-B：补码观察谱的精确反射与奇偶不变量

定义 `J(x)=N-1-x`。因为 `N=2^p`，有 `J(T_i(x))=T_i(J(x))`，包括零步。因此轨迹上的 `J` 是一个没有固定轨迹的对合，且诱导观察端口反射：

```text
R1(r) = (N-1-r) mod q1,
R2(s) = (N-1-s) mod q2.
c(r,s) = c(R1(r),R2(s)).
```

由于 `q1,q2` 都是奇数，各端口反射各有唯一固定余数

```text
r* = (N-1) / 2 mod q1,
s* = (N-1) / 2 mod q2,
```

其中除以 2 表示在奇数模数中乘 `2^{-1}`。令 `c*=c(r*,s*)`，则 `c*` 为偶数，并有

```text
C_p(q1,q2) mod 2 = (c*/2) mod 2.
```

证明：`J` 将每一个非固定观察纤维一一对应到另一个等重数纤维，故这些纤维的碰撞对总数成偶数。唯一固定观察纤维内的轨迹也由无固定轨迹的 `J` 两两配对，因此 `c*` 偶。于是 `binom(c*,2) ≡ c*/2 (mod 2)`，得到结论。该校验只需枚举一个旧状态余数类，约 `O(p N/q1)` 次具名转移运算；无须重算完整 `C`。

注：`J` 是观察器的具体代数对称，并不声称是 P000 原生时空的全局对称。

## 4. 定理 884-C：双向精确占位碰撞数下界

定义 `f_q(m)`：把 `m` 个标号对象放入 `q` 个桶所得无序同桶对数的最小值。若 `m=uq+v` 且 `0≤v<q`，则

```text
f_q(m)=q*binom(u,2)+v*u.
```

证明：若两桶大小相差至少 2，把大桶一件移入小桶会严格减少同桶配对数。因此最小值在各桶差至多 1 时取得，直接计算即得。

写 `N=t*q1+r`，`0≤r<q1`。每个旧端口余数纤维恰有 `t` 或 `t+1` 个旧状态，且每个状态产生 `p+1` 条带具名来源的合法轨迹。按第二端口的至多 `q2` 种后观察值放桶，得到

```text
L12 = r*f_q2((t+1)(p+1)) + (q1-r)*f_q2(t(p+1)).
C_p(q1,q2) ≥ L12.
```

由于任意合法 XOR 翻转可逆，时间反转 `(x,y)↦(y,x)` 把 `(q1,q2)` 与 `(q2,q1)` 的碰撞对一一对应，故 `C_p(q1,q2)=C_p(q2,q1)`，从而也有 `C≥L21`（交换 q1、q2 的前式）。最终得到 `C≥max(L12,L21)`。该式是 **碰撞对数量** 的闭式保证，而不只判断是否发生碰撞。
