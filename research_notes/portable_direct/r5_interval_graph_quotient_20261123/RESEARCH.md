## 定理 1：任意预算的精确团载体

设 `H` 是任意有限的**有标签**假设集合，`N_h(k)` 为整数，`τ≥0` 为整数。对每个动作 `k` 定义无向图

`G_k(H)=(H,E_k),  {h,i}∈E_k ⇔ |N_h(k)-N_i(k)|≤τ.`

对于双倍响应 `z`，记真实联合支撑 `S_k(z)={h∈H: z∈I_h(k)}`，其包含极大元组成 `F_k`。则

`F_k = MaxClique(G_k(H))`.

因此，对上述固定响应观察、标签、动作成本和未来的任意自适应查询，整个 `{(k,G_k(H))}` 是精确的状态转移充分载体；任意整数错误预算 `f≥0` 的 Bellman 最坏成本及最优策略值均可从各动作最大团族恢复，不需要中心的绝对数值。这是**声明观察范围内的因子化定理**。

**证明。** 若 `h,i∈S_k(z)`，则两个长度相同的闭区间同时含 `z`，故两中心差绝对值至多 `τ`；于是每个可实现支撑是图中的团。反过来，图中任意团的区间族两两相交；实线闭区间的 Helly 性质给出共同交点。团中每个标签在该点都匹配；若团极大，则同一点不可能另有可加入标签，故该最大团就是一个实际响应支撑。对于任意实际支撑，它包含在某个最大团内。若 `S⊆T`，选择 `S` 使每个不在 `S` 中的假设错误计数至少与选择 `T` 一样大，剩余可能世界不多于 `T`；删去被支配支撑不改变最坏分支。归纳至任意有限 `f` 的递推，得到同一 Bellman 值和最优决策成本。□

注意：*所有*团构成可实现支撑族的向下闭包；一个非极大团未必能作为**恰好等于它**的响应支撑出现。这里所需的是极大支撑与最大团之间的一一对应。

## 定理 2：增补一个标签的完全无损更新

固定一个动作 `k`。已知旧标签集 `H` 的最大支撑族 `F`；添加新标签 `v`，只需取得它对旧标签的**带标签邻居位图**

`N=N_k(v)={h∈H: |N_h(k)-N_v(k)|≤τ}`.

记 `Max_⊆` 为按包含关系极大化有限集合族（允许空集），新最大支撑族恰为

`F' = {C∈F : C⊈N} ∪ { {v}∪D : D∈Max_⊆({C∩N : C∈F}) }.`

**证明。** 不含 `v` 的旧极大团 `C`，恰在 `v` 与 `C` 的全部点相邻时不再极大；这正是 `C⊆N`。含 `v` 的新极大团移去 `v` 后，是诱导子图 `G_k(H)[N]` 的一个极大团。该图的所有团均包含在旧图某个极大团 `C` 中，所以诱导图极大团正是 `{C∩N:C∈F}` 的包含极大元。两类互斥且穷尽。□

因而重复应用该式便可把六标签、八标签支撑升级到九标签及以上。保留原动作价格 `k` 和每次新标签的邻居位图即可；**仅保存旧最大支撑而丢弃新增邻接关系并不足够**。此公式在每个动作内精确保留联合支撑，而不是拼接两个边缘七标签推断。

## 定理 3：整数舍入稳定域（有限集合、所有错误预算）

给定全部待用动作和标签对，设 `d_{k,h,i}=|N_h(k)-N_i(k)|`，定义非负整数阈值裕量

`Γ = min_{k,h<i} { τ-d  (d≤τ);  d-τ-1  (d>τ) }`.

当每个整数中心改变至多 `b`，整数阈值 `τ` 改变至多 `q`（改变后仍非负），且 `2b+q≤Γ` 时，所有标记的 `G_k` 均保持不变，故定理 1 的每个 `V_f` 完全不变。证明只需分别使用 `d'≤d+2b` 与 `d'≥d-2b` 检查 `d'≤τ'` 的两个方向，然后应用定理 1。这里 `Γ` 是可计算的**充分裕量**，不是必需或最优舍入精度的宣称；仅适用于确定中心与阈值观测的该有限动作集。

## 端点方向校正

原笔记把 `z=2N_h-τ` 的“左端点”与前向窗口 `N_h≤N_j≤N_h+τ` 写在同一等价句中；逐项代入可见，**左端点实际给出后向窗口** `N_h-τ≤N_j≤N_h`。前向窗口由**右端点** `z=2N_h+τ` 给出。两种窗口集合在删除非极大掩码后都恰好等于最大团族，因此原作者的前向窗口 C++ 与左端点 Python 可以相符；校正影响的是中间端点解释，不改变已证的最大支撑约化。例如 `N=(0,1,2)`、`τ=1` 时，左右窗口的未极大化集合不同，最大族却同为 `{{0,1},{1,2}}`。
