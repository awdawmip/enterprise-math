## Dynamic component update

Let U be the fixed matchable exclusive set after GBB tight-cut reduction, with fixed integer resource capacities and labeled adjacency. Define r(Q)=H(U union Q)-|U|. As in GBH this is a matroid rank (contract the independent U from the transversal matroid on cloned slots). Process additional targets in an arbitrary fixed insertion order. Maintain the greedy basis B by retaining every successful augmentation and never replacing its target labels; only their matched slots may change. Maintain a disjoint-set partition generated by fundamental circuits of all rejected targets.

When x is inserted:
* If r(X+x)=r(X)+1, x is a coloop in the new restriction: every basis must contain x, since the old ground set has rank r(X). B+x is the new basis. Each prior fundamental circuit remains the unique circuit contained in (B+x)+y for any old nonbasis y. Thus old components do not merge; add singleton x.
* If r(X+x)=r(X), B stays a basis, and all old fundamental circuits remain unchanged. Find the new circuit D_x by GBH alternating reachability from x in the maintained matching, traversing owners including U. Union x with every old component meeting D_x. No other components change, by GBH's unique finest rank-additive partition theorem. A loop joins no old component.

This proves exact insertion-only maintenance for every prefix, including all prefix subset ranks. Component sets only coarsen under inclusion of old labels, although their stored representative roots may change. Old fundamental circuits need not be searched again. Given the maintained matching, if P new insertions contain d failures, the circuit work is at most O(d(E+m+n)) plus disjoint-set updates and requested output materialization; this counts explicit adjacency and vertices at final size. Matching costs, contraction, input widths and query serialization are separate. Recomputing all prefixes repeats old circuits; final-only computation already avoids that repetition. Deletions, edge/capacity changes and basis exchanges that alter the basis labels are outside this update rule.

## Exact static component rank coordinate

For each connected component A, let n=|A| and k=r(A). For Q subset A:
1. k=0 or k=1 gives r(Q)=min(k,|Q|), because a connected nontrivial component has no loops (a loop is its own component).
2. n-k=0 or 1 also gives r(Q)=min(k,|Q|). The free case is immediate. If nullity is 1, choose a basis in A: there is exactly one nonbasis element, and its fundamental circuit must contain every element of A, since any basis element outside that circuit would be a singleton component by GBH. Thus A is a circuit, all proper subsets independent.
3. If k=2 and case 1/2 does not apply, partition A into parallel classes by r({x,y})=1. There are no loops; parallelism is an equivalence by submodularity. A subset hitting two distinct classes contains an independent pair and has rank 2; a nonempty subset of one class has rank 1. Thus r(Q)=min(2,number of classes meeting Q). Classification may use exact pair rank against each existing class representative. General components retain their exact masks and matching oracle.

By GBH additivity, these component formulas yield the exact rank and nullity for every labeled subset of a fixed ground set. The representation retains all labels and multiplicity. In particular, a fixed population of uniform components is fully represented for this observer by (A,k_A) for each component A. This does not encode matching witnesses, edge/slot identity, or arbitrary future insertion. Counterexample: with resources a,b of unit capacity and U empty, old x can use only a in state 1, only b in state 2. Both have identical static rank observer U_{1,1}. Insert new y allowed only a: ranks are 1 and 2 respectively. Retain original masks and live matching for dynamic work. No information loss beyond explicitly scoped static rank query is certified.
