## 2. Productive reachability forest (general graph lemma)
Fix one bridge group with common e and H=G[D_e]. Mark each selected auxiliary vertex by its class label j. (More generally H is any finite directed graph with marked vertices and root sets E_i.) Put Q={u in H: u can reach a mark in H}. Compute Q once by reverse traversal from all marked vertices in H. In the following routine, ignore unproductive vertices, and use a disjoint-set structure on original class labels only. Initialize owner(u) unset for u in Q. For each blocked root i, traverse from E_i intersect Q. On first visit to u set owner(u)=i, and scan its outgoing edges in H once; if u is marked j, union i,j. On encountering an already owned vertex u, union i,owner(u), and do not expand u again. If E_i has no productive vertex, add no unions.
Claim: the resulting components equal those of the full bipartite root-to-reachable-mark incidence (interpreted on original class labels). Proof:
* Each marked visit is an actual root-mark incidence. Each collision of roots i and i' at productive u has a common reachable mark j (paths from both roots to u and from u to j); hence the collision lies in a true incidence component. No false merge.
* For any true root-mark incidence i->j, choose a path from a root vertex to that mark. Every vertex on the path is productive. First processing of the root vertex either assigns it to i or joins i to its owner. Every edge along the path is eventually scanned by its first owner, or was already scanned. Inductively the owner of each vertex on the path is in i's component; at the mark the owner joins j. Thus all true incidence edges are recovered at the component level. No lost merge.
Union the resulting forests across all bridge groups. Because groupwise operations generate the same connectivity equivalence as each group's full incidence, the union equals the GCN finest block-preserving component partition. If one class appears on both root and selected sides, use the same original label. Unmarked/isolated classes are retained individually. GCN then applies its exact direct-sum and Pareto convolution theorem under its original separable objective assumptions.

The forest represents component connectivity ONLY, not all individual exchanges; even roots in the same component can have different exchange neighbors. For the declared full exchange/least-cut observer, retain original final graph, bridge index, roots, selected aux label map and basis counts. Recover an individual root's precise reachable marks or ports by lazy traversal of G-e (section 1 and GCS), without asserting that the forest itself preserves these observers. No arbitrary future mutation is certified; rebuild/revalidate under GCP/GCU as applicable. This is a scope-typed joint relation quotient, not deletion of the original relation source.

Counterexample to merging merely overlapping root reaches: two unit ports a,b, prefix one label with support {a,b}, assigned to a; residual distinct classes with supports {b} and {a,b}, each one available. Both are loops in the contracted strict-Hall model (the full cut is tight). Both roots choose unit bridge b->t (b has remaining capacity 1; root b cannot lie in the smaller bridge region of a). Reachable sets share b, yet B is empty, so the two residual classes must not merge. Productive pruning correctly makes both empty. This also distinguishes sharing a bridge or reachability from actual exchange connectivity.

## 3. Complexity and measurement limits
Given final quotient and GCT index, group classification uses root support scans and marked ancestor tests. One reverse adjacency construction O(M+N). For each group, seed scan over selected marks, reverse traversal from marks in D_e (checking outside incoming edges), forward traversal from roots restricted to Q. Each productive vertex's outgoing list scanned at most once per group, even when many roots reach it. Group arrays O(N) and global retained graph O(N+M); no SCC closure bitsets or all-root witness materialization in the component route. In the straightforward implementation each group initializes 2N array slots and checks all selected marks; nested groups can repeat work. Root scans, bridge index, auxiliary mapping (one pass over G.add), graph construction, union/find, output and optional lazy observer recovery all have costs. With standard rank/size + path compression DSU, each union/find is amortized inverse-Ackermann; actual replay uses path halving without union-by-rank and does not claim that bound for its implementation. The forest can avoid quadratic closure bitsets on large DAGs, but no general wall-clock superiority over GCV is claimed.
