# 三角矩尺度预算：2026-11-22 续研

## 结果

旧每层条件 `sum(t_p)_+^2 <= C(A)^2/X` 可以改为

\[
\sum_{p\in\text{一层}}h_p^3(t_p)_+^2\le C(A)^2X^2
\]

（临界权重 `1/n^2`）。准均匀层等价于允许 `sum(t_p)_+^2` 达到 `C(A)^2X^2/delta^3`。这是明确的充分条件弱化，没有宣称该算术条件在实际道路上已经证明。

由通用单侧源界，完整块 `delta<=X^(3/4)` 的层自动可付；长为 b 的截断尾块自动阈值进一步为 `delta<=X b^(-1/4)`。若 `b<=X^(4/5)`，整个短尾的真实曲率余项已经可付，根本无需设置尾块内部三角抵消假设。这个 4/5 与相位除数截断的指数承担不同对象。

真实 dyadic 样值的插值 J 作为骨架，闭窗口范数直接计入 A、B。所有未自动支付的层满足新条件、骨架有次幂预算、细余项可付且匹配量词统一时，闭窗正部能量为次幂。
