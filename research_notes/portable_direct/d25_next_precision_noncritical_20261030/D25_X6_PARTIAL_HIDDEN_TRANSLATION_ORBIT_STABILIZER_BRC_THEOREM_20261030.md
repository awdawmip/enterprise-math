## 1. 模型与精确问题

设 `p` 为素数，`L>e>=1`，`n=L-e`，`R=Z/p^L Z`，`A=Z/p^n Z`。取 `1<=r<=5`、`z=(q,h) ∈ R^(6-r) × R^r`，且 `q` 至少含坐标 `q_1`。观察者 `Q(q,h)=q`，原始来源总体是每个固定 `q` 下的**全部带标签** `h∈R^r`。

令 `f:A^r→A` 为一个固定函数（整系数多项式的模 `p^n` 诱导函数是其重要特例）。给定非负整数步长 `s_i`，定义

```
T_f(q,h)=(q+p^e f(h mod p^n)e_1, h)  (mod p^L),
U_i(q,h)=(q, h+p^{s_i}e_i)          (mod p^L),
```

其中 `e_1` 是**可观察数组的第一坐标单位向量**，不是物理作用方向断言。`U_i` 的组合可正向重复，因工作于有限加法群，生成其整个循环子群。

写 `t_i=min(s_i,n)`、`A^r=G`、

```
H = ∏_{i=1}^r p^{t_i} A  ⊆ G.
```

于是 `H` 恰为隐藏平移在模 `p^n` 下产生的有限子群。`s_i>=n` 时该坐标在 `H` 中恒为零，即使它仍可改变完整来源标签的高位。

对于 `a=h mod p^n`，定义带固定索引的**未来探针签名**

```
S_a : H → A,     S_a(v)=f(a+v).
```

每个 `S_a(v)` 可以从原始来源复位后的一条 `Q(T_f U_v z)` 探针读出：观察增加量 `p^e S_a(v)`。`U_v` 代表合法 `U_i` 的合成。此处复位分支探针不等于单条不可复位真实时间轨迹。

## 2. 定理 A：完整未来观察关系 = 签名逐点相等

**定理 A。** 对同一个初始可观察值 `q`，原始来源 `h,h'` 在全部有限操作字 `{T_f,U_1,...,U_r}*` 的可观察结果上相等，当且仅当

```
S_{h mod p^n}(v)=S_{h' mod p^n}(v)  对每个 v∈H.
```

**证明。** 必要性：所有 `T_f U_v` 都是允许的带复位探针，因此观察增量相等。`p^e x=p^e y` 在 `R` 中当且仅当 `x=y` 在 `A` 中。充分性：任意有限操作字中的 `U_i` 仅将各候选隐藏来源增加同一个 `v∈H`，而 `T_f` 仅对观察第一坐标累加 `p^e f(a+v)` 并保持隐藏来源；初始观察相同，签名相等使每一次 `T_f` 的观察增量一致。按操作字长度归纳即可。证毕。

定理并不把具有相同观察的原始状态认作同一个物理来源；它只给出声明的未来观察语言下的等价商。

## 3. 定理 B：全部部分平移的轨道—稳定子整数谱

`H` 通过平移签名自变量作用于 `A^H`：`(u·S)(v)=S(v+u)`。对于 `G/H` 的每个陪集 `C=a+H`，其**签名轨道**

```
Ω_C={S_{a+u}:u∈H}={u·S_a:u∈H}
```

不依赖代表元。定义 `P_C={u∈H:S_a(v+u)=S_a(v) 对所有 v∈H}`。它是 `H` 的子群，且对同一陪集选取任何代表元都不变。

将全部 `G/H` 陪集依据同一个签名轨道 `Ω` 分组。记：

```
m_Ω = #{C∈G/H: Ω_C=Ω},
P_Ω = 任何这样的 C 的 P_C,
```

其中 `P_Ω` 的大小与选取无关。

**定理 B（精确来源谱）。** 对每个固定 `q` 和每个上述非空签名轨道 `Ω`：

```
该 Ω 贡献的不同未来观察纤维个数 = |H| / |P_Ω|,
每个这样的纤维包含的原始带标签来源数 = p^(e r) m_Ω |P_Ω|.
```

因此，完整纤维谱是多重集合

```
{ (size=p^(e r)m_Ω|P_Ω|, count=|H|/|P_Ω|) : Ω },
```

当不同 `Ω` 产生同样 `size` 时，应将对应 `count` **相加**，不能覆盖。

**证明。** `H` 的平移作用是有限群作用。固定一个陪集 `C`，由轨道—稳定子公式，`|Ω_C|=|H|/|P_C|`；从 `C` 到 `Ω_C` 的每个签名各有 `|P_C|` 个模 `p^n` 的原像。若 `m_Ω` 个不同输入陪集产生同一个 `Ω`，每个签名在所有这些陪集中合计有 `m_Ω|P_Ω|` 个模 `p^n` 来源。每个这样的来源 residue 恰有 `p^(e r)` 个不同的完整 `R^r` 来源标签，所以得到公式。不同轨道绝不会共用同一签名。证毕。

**整数来源守恒**独立地给出

```
Σ_Ω (|H|/|P_Ω|)·(p^(e r)m_Ω|P_Ω|)
 = p^(e r)|H|Σ_Ω m_Ω
 = p^(e r)|H||G/H|
 = p^(Lr).
```

这显式区分两个来源：`|P_Ω|` 是同一平移陪集内部的周期碰撞，而 `m_Ω` 是不同输入陪集的签名轨道重合。只计算“每个陪集内周期群”，忽略 `m_Ω`，一般会漏算跨陪集来源合并。

**恢复既有单位平移结论。** 所有 `s_i=0` 时，`H=G`，输入陪集只有一个，故 `m_Ω=1`。其稳定子恰为全域多项式平移周期群 `P_n(f)`，定理 B 化为此前 `p^(er)|P_n(f)|` 来源/纤维与 `p^(nr)/|P_n(f)|` 个纤维。此步骤是与已完成成果的相容性证明，并非重新建立该成果。

**带权 BRC 扩展。** 若来源 `h` 自带非负整数标签质量/计数 `w(h)`，某个观察签名 `σ` 的精确推前质量为 `M_σ=Σ_{h:S_{h mod p^n}=σ}w(h)`。定理 B 的统一纤维**基数**成立，但 `M_σ` 未必等于 `p^(er)m_Ω|P_Ω|`，除非每个原始来源贡献的计数都为 1。不同源支路仍须保留必要的配对及来源，不能把质量守恒解释为对路径顺序、时刻或联合关系的原生保真证明。

## 4. 定理 C：无限参数族的非均匀 BRC 精确闭式

设 `p` 是任意奇素数、`e>=1`、`L=e+1`（故 `n=1`）、`r=2`。令 `f(X,Y)=X Y(Y-1) mod p`。隐藏平移第一坐标选择任意 `s_X>=1`，第二坐标选择 `s_Y=0`；在合法 `0<=s_i<L` 范围内总可取 `s_X=1`。则 `H={0}×F_p`。

**定理 C。** 对每个固定 `q`，完整未来观察纤维的**全部整数谱**精确为

```
(纤维大小 p^(2e),   纤维数量 p(p-1)),
(纤维大小 p^(2e+1), 纤维数量 1).
```

**证明。** 对模 `p` 来源 `(x,y)`，签名是 `S_(x,y)(j)=x(y+j)(y+j-1)`，`j∈F_p`。若 `x=0`，全部 `p` 个不同 `y` 的签名都是恒零函数，形成唯一的模 `p` 纤维，大小 `p`。若 `x≠0`，假设 `(x,y)` 与 `(x',y')` 产生相同签名。两边是关于 `j` 的次数至多 2 的多项式，`p>=3`，在 `p` 个域元素上相等因此是同一个次数 `<p` 的多项式。比较 `j²` 系数得 `x=x'`，比较 `j` 系数得 `x(2y-1)=x(2y'-1)`；`2x` 为单位，故 `y=y'`。此外 `x≠0` 的签名不可能为恒零，因为最高系数是 `x`。于是非零 `x` 的 `p(p-1)` 个来源各自形成大小 1 的模 `p` 纤维。每个模 `p` 来源有 `p^(2e)` 个完整隐藏来源提升，乘入即得闭式。证毕。

来源总量为

```
p(p-1)·p^(2e) + 1·p^(2e+1) = p^(2(e+1)) = |R²|.
```

精确示例：`p=3,e=2,L=3` 的 729 个来源，产生 6 个 81 元纤维和 1 个 243 元纤维；`p=5,e=2,L=3` 的 15,625 个来源，产生 20 个 625 元纤维和 1 个 3,125 元纤维。前者复用了 PR 之前的特殊见证，新内容是**所有奇素数及任意 e 的闭式证明**，避免再次将该见证当成新发现。

**三探针边界（仅 `p=3` 的规范单 `T_f` 可重置探针族）。** 模 3 的平移 `j∈{0,1,2}` 三条 `Q(T_f U_Y^j z)` 可区分全部 7 个模 3 签名。任何选取两条不同 `j` 的此类探针都不足：在 `F_3` 中任意两个不同 `j` 相差 `±1`；可以选择某个 `y` 使 `y+j` 在这两个位置恰为 `0,1`，从而任何 `x≠0` 的这两个读数仍全为零，与 `x=0` 来源碰撞，剩下的第三条读数却非零。本下界**不**适用于一次分支中多次 `T_f` 累加后观察的任意字，也不证明自适应策略的最优性。
