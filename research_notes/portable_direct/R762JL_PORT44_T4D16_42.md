## Theorem

Let the six axes be A={0,1,2,3,4,5}; the 15 Ports are pairs of axes and the 20 support labels are triples of axes. For a triple {a,b,c}, an event is one edge among Ports ab,ac,bc. Let N_{p,V}(n)>0 mean that some connected nonempty even-degree event multigraph has exact support event counts n, exact positive-degree Port set V, and specified Euler start p in V.

Choose any four distinct support labels T. Define n_S=3 if S in T, otherwise n_S=2. This is exactly the terminal histogram (t,d,s,z)=(4,16,0,0) of total size 44.

**Claim.** For every such T and every locally possible active Port set V, there exists j in T and a connected even-degree 42-event witness of exact counts n−2e_j, exact active set V and any specified Euler start p in V. This retains all 20 positive support labels and each support's count parity. The existence of a legal 44-event witness is not needed as an additional hypothesis for the finite certificate construction.

## Exhaustive proof

1. Because every triple support is positive, if two inactive pair-Ports shared an axis, the triple containing them would have only one active Port and no possible event-edge. Hence the inactive Port set M is necessarily a matching of disjoint pair-Ports in the six axes, of size at most 3. There are precisely 76 possible matchings of sizes 0–3.
2. Permuting the six axes preserves allowed event edges, support multiplicities, Port degrees and connectivity. The 4,845 subsets T of size 4 have exactly 21 orbits under S6 (720 permutations). Pick one canonical representative of each orbit. For that T, check all 76 inactive-Port matchings. Every labelled (T,M) is transported from one such pair (T_rep,M_rep) because *all* M are checked for the chosen T_rep.
3. For each of 21×76=1,596 cases, the attached exact certificate specifies the reduced support j and 60 integer edge multiplicities in [0,3]. The standalone verifier reconstructs the entire orbit and matching enumeration and checks that the file has exactly one certificate per expected case, with no missing or extra entries. For each certificate, it verifies exact counts n−2e_j for all 20 supports, total length 42, strictly positive even degrees precisely on V, zero degrees on M, and connectedness of the active Port graph.
4. All 1,596 exact certificates passed. Any S6 relabeling carries each certificate to the corresponding labelled input; a connected even-degree graph has an Euler circuit beginning at every active Port p. This gives the theorem for all 4,845×76=368,220 labelled T/M combinations (and all their possible p).
