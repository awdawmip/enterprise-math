## Theorem: universal nonnegative-weight frontier
For a finite distinguishable state set S and fixed unit-cost binary physical queries, let L_d(S) be the inclusion-minimal sets of states NOT uniquely identified by depth d among all complete identification trees. Empty S is allowed formally. Define mininc to delete strict supersets. Then L_d(S)={empty} for |S|<=1, L_0(S)={S} for |S|>=2; for d>=1, |S|>=2,
L_d(S)=mininc union over nonconstant q of {A union B : A in L_{d-1}(S intersect q), B in L_{d-1}(S minus q)}.
Proof: every informative first query gives the two disjoint conditional populations, and every pair of attainable child loss sets concatenates to an actual full identification tree. A constant query can be deleted without worsening any state's depth; any early stop with unresolved states can be extended, without increasing losses. By induction every attainable loss set contains a minimal attainable one, and replacing each child by its minimal subset can only reduce the union. Hence the recurrence is exact. Conditional duplicate partitions (including answer complement) can be deduplicated for this objective; a physical query representative remains available for witness reconstruction. No state/label equivalence beyond the stated observer is asserted.

For all nonnegative state weights w, E_d(S;w)=min_{A in L_d(S)} sum_{x in A} w_x, and V_d=W(S)-E_d. This follows because replacing a loss set by a subset cannot increase nonnegative loss. Moreover every member A of this antichain is necessary for exact representation over all nonnegative weights: take w=1 on S minus A and 0 on A. A costs zero and every other antichain member costs at least one. Thus no member may be deleted in a representation restricted to these attainable loss masks.

## Exact obstruction dual
For T subset S, D(S,T)>d iff T meets every A in L_d(S). Therefore the complete inclusion-minimal obstruction antichain B_d(S)=blocker(L_d(S)), the minimal hitting sets. Conversely L_d(S)=blocker(B_d(S)): if X contains a member of an antichain F then X hits every minimal hitting set of F; otherwise S minus X hits every member of F, so contains a minimal hitting set disjoint from X. The conventions blocker(empty family)={empty}, blocker({empty})=empty family handle the endpoints. The incremental blocker algorithm starts at {empty}; for each edge A, retain hitting candidates, or add each element of A to each non-hitting candidate, then mininc. Induction over edges proves completeness. This is the full rank dual of FZZ, not only its rank-truncated observer. Its output size and worst case remain exponential.
