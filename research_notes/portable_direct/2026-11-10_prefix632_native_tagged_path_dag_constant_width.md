## 1. 精确问题与观察

原生模型具有 48 个 STAR 相位、96 个带源/靶端口、576 条有原始标签的动作，六轴权重 `(1,1,1,1,0,0)`，四点探针 `d=e_4+e_11+e_14+e_32`。设 `r_t=A(g_t)...A(g_1)E(lambda*d)`，`t>=4,L>=1,lambda>0,g_i>=0`。目标是恢复 `[t+1,t+L]` 的**全部正质量**原生有序动作路径及其每条精确流量，路径携带开始端口、每一步原始 action ID、每一步目标端口。把所有路径汇总到同一端口不是本次观察。

## 2. 新的常宽四相位闭环证书

在所有门控严格正的原生动作图上，四个周期性递推支持集（按 t=4,5,6,7）为：

```
R4={4,5,8,9,28,29,52,53,56,57,80,81}
R5={8,9,28,29,52,53,56,57,76,77,80,81}
R6={8,9,28,29,32,33,52,53,76,77,80,81}
R7={4,5,8,9,28,29,32,33,52,53,80,81}
```

原生 576 动作的完全有限邻接核验给出四个关系 `R4→R5→R6→R7→R4`：每个 `R_j` 中的 12 个端口恰有 **2 条原始正权动作**进入下一递推集，另有 **4 条**进入无后继正权动作的终止端口。12 个递推端口经一次完整的末步动作所能到达的终点端口并集恰有 **28** 个。四个集合的作用方式完全由原生图确定，不依赖正门控的数值。

证明：先从四点探针按原生动作直接构造 t=4..8 的布尔正权支持，逐项验证上述四个集合及邻接关系；正门控只改变边权不改变正权支撑，由四步循环归纳所有 `t>=4`。对含零门控，支撑及正质量边为严格正参数模板的子集，以下规模上界仍成立。

## 3. 精确 DAG 表示定理

按时间分层，把重复抵达同一原生端口的路径共享同一后续计算顶点，但**保留每一条原始 action ID 边**；第0层的 12 个顶点附带各自真实源端口质量，后续每层边附带原生门控因子/定权因子。带标签的完整路径与 DAG 中的根至末层有序边序列逐一对应；路径质量严格等于根质量乘沿途原生边权。共享未来状态不合并过去的路径身份。

当从第一步到最后一步的门控均严格正时（包括到时刻 t 的探针前缀），**精确**计数为

```
N_nodes(t,L) = 12L + 28
N_edges(t,L) = 24L + 48
K_paths(t,L) = 72 * 2^(L-1).
```

其中层0至 L-1 各有12个可延伸顶点，末层有28个不同目标端口；前 L-1 层各有24条继续边，最后一层有72条动作边。全部原始动作身份与有序端口标签保留。若某些门控为零，可以用正支撑裁剪，节点数、边数及非零路径数均不超过对应表达式。

**复杂度与数值语义：**原生动作表为固定常数，给定 t 时刻的真实 r_t 与随后 L 个门控，DAG 构造占 `O(L)` 机器字/固定维度算术运算，独立于显式路径总数；它仍需存储12个精确源质量及各步门控。实际比特存储另计这些整数/有理数的分子分母长度与分层标签。对于门控为有理数的实验，全部权重使用 `fractions.Fraction` 精确计算；模型内实数参数上的结构证明不依赖有理性。

## 4. 可计算的尾部计数与随机访问

定义 `C_L(p)=1`（仅对末层完成状态），从后向前：

`C_j(p)=sum_(a:p→q, weight(a,j)>0) C_(j+1)(q)`，根总数为 `sum_(p:r_t[p]>0) C_0(p)`。

同时定义 `M_L(p)=1`，`M_j(p)=sum_(a:p→q) weight(a,j)*M_(j+1)(q)`；则 `sum_p r_t[p] M_0(p)` 恰好等于所有独立带标签路径的流量总和，也等于完整原生末态端口质量之和。

对按起始端口和原始 action ID 字典序排列的 `[0,K)` 号路径：先使用各根的 `C_0` 定位根，再在每一步依有序出边的后继 `C_(j+1)` 跳过整段路径编号，返回完整原始动作序列与各项精确流量。预处理 `O(L)` 固定维算术运算，单次精确 `unrank` 使用 `O(L)` 次计数比较/加减及权重乘法（大整数与有理数**位成本另计**）。显式列出全部路径仍至少需要相应数量的输出步骤，保留 PREFIX-631 的输出下界。
