## 1. 记号与单位端口

令整数 `m>=1`、`h>0`，置

\[
v_{m,j}=(-1)^{j+1}\binom mj,\qquad
w_{m,j}=v_{m,j}/j,\qquad H_m=\sum_{j=1}^m1/j.
\]

对 `n>=2`，多厚度读出为

\[
D_{m,h}(n)=\frac1h\sum_{j=1}^m w_{m,j}R_{jh}(n).
\tag{1}
\]

若包括 `n=1`，必须使用

\[
\widehat D_{m,h}(n)=\frac1h\left[
\sum_{j=1}^m w_{m,j}R_{jh}(n)-H_m\mathbf1_{n=1}\right].
\tag{2}
\]

否则单位输入会产生错误的 `H_m/h` 端口。以下对 `n>=2` 记不同素因子数为 `r=omega(n)`，素因子对数为 `ell_1,...,ell_r>0`，并记

\[
L_n=\sum_{i=1}^r\ell_i=\log\operatorname{rad}(n).
\]

同一素因子的幂不改变道路的素因子集合；平滑求和仍逐个保留不同整数及其不同的权 `y/n-1`。

## 2. 一个显式正核给出完整道路的混合差分算子

定义

\[
\boxed{
\Psi_{m,h}(t)
=\frac1h\sum_{k=1}^m\frac{(1-e^{-ht})^k}{k}
=\int_0^t\big[1-(1-e^{-hu})^m\big]\,du,
\qquad t\ge0.
}
\tag{3}
\]

对有限和求导即得第二个表达式；也可由二项式恒等式得到

\[
\Psi_{m,h}(t)
=\frac1h\sum_{j=1}^m w_{m,j}(1-e^{-jht}).
\tag{4}
\]

因此

\[
\Psi(0)=0,\quad
\Psi'(t)=1-(1-e^{-ht})^m\in(0,1],\quad
\Psi''(t)=-mh e^{-ht}(1-e^{-ht})^{m-1}\le0,
\]

\[
0\le\Psi(t)\le t,\qquad
\lim_{t\to\infty}\Psi(t)=H_m/h.
\tag{5}
\]

这个一变量核是正的、递增且凹。**这并不使其任意阶混合差分具有同一符号。** 后文给出严格的负值与多次变号实例。

### 定理 1：Möbius 核表示与混合导数表示

对全部 `n>=1`，有

\[
\boxed{
\widehat D_{m,h}(n)=-\sum_{d\mid n}\mu(d)\Psi_{m,h}(\log d).
}
\tag{6}
\]

对 `n>=2`，定义 `Delta_ell f(t)=f(t+ell)-f(t)`，则

\[
\boxed{
D_{m,h}(n)=(-1)^{r+1}
\Delta_{\ell_1}\cdots\Delta_{\ell_r}\Psi_{m,h}(0)
=(-1)^{r+1}\int_0^{\ell_1}\!\cdots\!\int_0^{\ell_r}
\Psi_{m,h}^{(r)}(u_1+\cdots+u_r)\,du_r\cdots du_1.
}
\tag{7}
\]

**证明。** 将 (4) 代入 (6)，使用
`sum_(d|n) mu(d)=1_(n=1)`，恰得 (2)，包括其单位修正。另一方面

\[
\sum_{d\mid n}\mu(d)f(\log d)
=\sum_{S\subseteq\{1,\dots,r\}}(-1)^{|S|}
f\left(\sum_{i\in S}\ell_i\right)
=(-1)^r\Delta_{\ell_1}\cdots\Delta_{\ell_r}f(0).
\]

逐次使用微积分基本定理即得积分表示。这里每个非空素因子子集都在有限和中，没有删去联合方向。□

令正误差原函数

\[
I_{m,h}(t)=t-\Psi_{m,h}(t)
=\int_0^t(1-e^{-hu})^m\,du.
\tag{8}
\]

因为 `Lambda(n)=-sum_(d|n)mu(d)log d`，上面的证明同时给出

\[
\boxed{
D_{m,h}(n)-\Lambda(n)
=(-1)^r\Delta_{\ell_1}\cdots\Delta_{\ell_r}I_{m,h}(0).
}
\tag{9}
\]

对素数幂 `(r=1)`，这还原为已有的正偏差积分

\[
0<\Lambda(p^k)-D_{m,h}(p^k)
=I_{m,h}(\log p).
\tag{10}
\]

式 (7)–(9) 将一般联合层接到同一个核，避免为每个 `r` 另作无结构的 `log n` 粗估计。

## 3. 所有联合层的精确级数、首项和有限余量

定义

\[
B_{r,k}(\ell_1,\dots,\ell_r)
=\left.\Delta_{\ell_1}\cdots\Delta_{\ell_r}t^k\right|_{t=0}.
\]

由多项式展开与子集抵消，

\[
\boxed{
B_{r,k}=
\sum_{\substack{\alpha_1,\dots,\alpha_r\ge1\\
\alpha_1+\cdots+\alpha_r=k}}
\frac{k!}{\alpha_1!\cdots\alpha_r!}
\prod_{i=1}^r\ell_i^{\alpha_i}.
}
\tag{11}
\]

故 `B_(r,k)=0` 当 `k<r`，而 `0<B_(r,k)<=L_n^k` 当 `k>=r`。特别地，`B_(r,r)=r! prod ell_i`。式 (11) 是正项公式，可避免直接相减大量子集值造成的消去误差。

记 `S(q,m)` 为第二类 Stirling 数。其指数生成式给出

\[
(1-e^{-x})^m=m!\sum_{q=m}^{\infty}
(-1)^{q+m}S(q,m)\frac{x^q}{q!}.
\]

积分并代入 (9)，得到对每个有限 `h` 绝对收敛的精确展开

\[
\boxed{
D_{m,h}(n)-\Lambda(n)
=\sum_{q=m}^{\infty}(-1)^{q+m+r}
\frac{m!S(q,m)}{(q+1)!}\,h^q B_{r,q+1}.
}
\tag{12}
\]

### 3.1 可算的统一截断余量

截到 `q=K>=m`，令 `q_*=max(K+1,r-1)`、`x=mhL_n`。由 `m!S(q,m)<=m^q` 及 `B_(r,q+1)<=L_n^(q+1)`，

\[
\boxed{
\left|\text{式 (12) 在 }q>K\text{ 的余项}\right|
\le L_n e^x\frac{x^{q_*}}{(q_*+1)!}.
}
\tag{13}
\]

证明中只需

\[
\sum_{q=q_*}^{\infty}\frac{x^q}{(q+1)!}
\le\frac{x^{q_*}}{(q_*+1)!}
\sum_{s=0}^{\infty}\frac{x^s}{s!}.
\]

这里 `m!S(q,m)` 是从 `q` 个标号位置到 `m` 个标号值的满射数，因此不超过 `m^q`。若一个有限 jet 看不到 `r>K+2` 的层，式 (13) 仍显式保存该层的误差；不能把它变成无条件删除规则。

### 3.2 首项按 omega(n) 分层

固定 `m,n`，当 `h` 趋于零时：

\[
\boxed{
2\le r\le m+1:\quad
D_{m,h}(n)=(-1)^r\frac{h^m}{m+1}B_{r,m+1}
+O_{m,n}(h^{m+1}).
}
\tag{14}
\]

\[
\boxed{
r>m+1:\quad
D_{m,h}(n)=(-1)^{m+1}m!S(r-1,m)
h^{r-1}\prod_{i=1}^r\ell_i+O_{m,n}(h^r).
}
\tag{15}
\]

前式取 (12) 的 `q=m`；后式使用首个不为零的 `B_(r,q+1)`，即 `q=r-1`。这同时给出准确的首个厚度幂次 `max(m,r-1)`。两式在 `r=m+1` 的边界相容。

| 层 | 小厚度下首项符号 | 首个厚度幂次 |
|---|---|---|
| `r=1`，看 `D-Lambda` | 负 | `h^m` |
| `2<=r<=m+1` | `(-1)^r` | `h^m` |
| `r>m+1` | `(-1)^(m+1)` | `h^(r-1)` |

另一方面，由 (1) 及 `R_(jh)(n) -> 1`，对每个固定 `m,n>=2`，

\[
D_{m,h}(n)=H_m/h+O_{m,n}(e^{-h\min_i\ell_i}/h)
\quad(h\to\infty).
\tag{16}
\]

所以任一小厚度下为负的层，向大厚度延拓时至少有一个零点。对其它层，首项为正并不排除中途变负。

## 4. 两个不同素因子：任意阶、任意正厚度都严格为正

### 定理 2

若 `n=p^alpha q^beta`，其中 `p != q`、`alpha,beta>=1`，则对所有 `m>=1,h>0`，

\[
\boxed{
D_{m,h}(n)
=mh\int_0^{\log p}\!\int_0^{\log q}
e^{-h(u+v)}(1-e^{-h(u+v)})^{m-1}\,dv\,du>0.
}
\tag{17}
\]

这由 (7) 和 `Psi''` 的明确符号立即得到。特别地，`Lambda(n)=0` 的这一层，在多厚度读出中**并未消失**。

记 `ell_1=log p,ell_2=log q`。由 `1-e^(-hs)<=hs`，

\[
\boxed{
D_{m,h}(n)\le\frac{h^m}{m+1}
\big[(\ell_1+\ell_2)^{m+1}-\ell_1^{m+1}-\ell_2^{m+1}\big].
}
\tag{18}
\]

证明是将 (17) 的被积函数上界为 `mh^m(u+v)^(m-1)` 后作两次有限积分。这比统一的 `h^m L_n^(m+1)/(m+1)` 少了两个纯幂项，且与 (14) 的首项相等。

当 `m>=2`，`x(1-x)^(m-1)` 在 `[0,1]` 上最大值取于 `x=1/m`，故还有

\[
\boxed{
D_{m,h}(n)\le h(1-1/m)^{m-1}\ell_1\ell_2.
}
\tag{19}
\]

`m=1` 时相应界为 `h ell_1 ell_2`。

三个不同素因子也有一个任意阶的充分定向条件。对 `m>=2`，置 `x=e^(-ht)`，

\[
\Psi'''(t)=mh^2x(1-x)^{m-2}(1-mx).
\]

因此

\[
\boxed{r=3,\quad hL_n\le\log m\quad\Longrightarrow\quad D_{m,h}(n)<0.}
\tag{20}
\]

积分盒内部有正体积使不等式严格。下面二阶专用结构给出更强且覆盖所有 `r>=3` 的定向条件。

## 5. 二阶：精确符号阈值与高联合层的尖锐包络

### 5.1 精确因式分解与唯一阈值

由于 `R_(2h)=R_h prod_(p|n)(1+p^(-h))`，

\[
\boxed{
D_{2,h}(n)=\frac{4R_h(n)-R_{2h}(n)}{2h}
=\frac{R_h(n)}{2h}
\left[4-\prod_{p\mid n}(1+p^{-h})\right].
}
\tag{21}
\]

于是：

- `r=1` 或 `r=2` 时，`D_(2,h)(n)>0` 对所有 `h>0` 成立。
- `r>=3` 时，乘积严格递减，从 `2^r` 下降到 `1`，故存在唯一 `h_*(n)>0`，满足乘积等于 `4`。`h<h_*` 时 `D<0`，`h=h_*` 时 `D=0`，`h>h_*` 时 `D>0`。

这是真实完整道路的符号结论，不依赖 Ramanujan 截断，也不把厚度外推系数的符号误认为输出的符号。

对 `0<x<1`，`1+x>2sqrt(x)`，所以

\[
\prod_{p\mid n}(1+p^{-h})>2^r e^{-hL_n/2}.
\]

因此有方便的统一条件

\[
\boxed{
r\ge3,\quad hL_n\le2\log2
\quad\Longrightarrow\quad D_{2,h}(n)<0.
}
\tag{22}
\]

对指定的 `r`，更宽的充分条件是 `hL_n<=2(r-2)log2`。

若需要逐整数定位阈值，令 `q_r=4^(1/r)-1`，则

\[
\boxed{
\frac{r\log(1/q_r)}{L_n}
\le h_*(n)\le
\frac{\log(1/q_r)}{\min_i\ell_i}.
}
\tag{23}
\]

左界来自 `log(1+e^(-x))` 的凸性及 Jensen 不等式；右界来自每个 `ell_i>=min ell_i`。阈值也可直接通过 (21) 的单调乘积求解。

### 5.2 保留全部素因子的高层尖锐界

二阶核满足

\[
\Psi_{2,h}^{(r)}(t)
=(-h)^{r-1}\big[2x-2^{r-1}x^2\big],\qquad x=e^{-ht}.
\tag{24}
\]

若 `r>=3`，令 `c=2^(r-1)>=4`。二次函数 `2x-cx^2` 在 `[0,1]` 的最小值为 `2-c`，最大值为 `1/c`，故绝对值最大为 `c-2`。代入 (7) 得

\[
\boxed{
|D_{2,h}(n)|\le(2^{r-1}-2)h^{r-1}
\prod_{p\mid n}\log p,\qquad r\ge3.
}
\tag{25}
\]

这对所有 `h>0` 成立，不要求 (22)。当固定 `n` 而 `h` 趋于零，(24) 中的括号在积分盒上一致趋于 `2-2^(r-1)`；结合 (7)，或等价地由 (15)，可得

\[
\frac{-D_{2,h}(n)}{h^{r-1}\prod_{p\mid n}\log p}
\longrightarrow 2^{r-1}-2.
\tag{26}
\]

所以对这类包络，常数是尖锐的。

对 `r=2`，由 (18)–(19) 得

\[
\boxed{
0<D_{2,h}(n)\le
\min\left\{h^2\ell_1\ell_2(\ell_1+\ell_2),\quad
\frac h2\ell_1\ell_2\right\}.
}
\tag{27}
\]

旧统一界为 `h^2 L_n^3/3`。由 `prod ell_i <= (L_n/r)^r`，(25) 与旧界的比值至多

\[
3(2^{r-1}-2)r^{-r}(hL_n)^{r-3}.
\tag{28}
\]

例如 `r=3` 的该比值至多 `2/9`；`r=4` 至多 `(18/256)hL_n`。高联合层具有更高的 `h` 幂次，把它们一律按 `L_n^3` 处理会损失这部分结构。

## 6. 用真实符号构造单边修正，并把连续窗口归到一个端点

固定 `h>0`，记 `r_y(n)=(y/n-1)_+`，定义

\[
\mathscr G_h^{[2]}(y)=\sum_{n\ge2}D_{2,h}(n)r_y(n)
-y\log y+(1+\gamma)y
=2\mathscr G_h(y)-\mathscr G_{2h}(y),
\]

\[
G(y)=\sum_{n\ge2}\Lambda(n)r_y(n)
-y\log y+(1+\gamma)y.
\tag{29}
\]

每个 `y` 的和都是有限和。系数和 `2-1=1`，故固定中心项恰保留一次。此式是完整道路的标量线性组合，原始输入并没有被换成素数幂人口。

如果 `h log y <= 2 log 2`，则对所有 `n<=y`：

- `omega(n)=1`：`D-Lambda<0`，负误差来自 (10)。
- `omega(n)=2`：`D-Lambda=D>0`。
- `omega(n)>=3`：`D-Lambda=D<0`，由 (22)。

据此定义非负包络

\[
\eta^-_n(h)=
\begin{cases}
h^2L_n^3/3,&r=1,\\
0,&r=2,\\
\min\{h^2L_n^3/3,\ (2^{r-1}-2)h^{r-1}\prod_i\ell_i\},&r\ge3,
\end{cases}
\tag{30}
\]

\[
\eta^+_n(h)=
\begin{cases}
\min\{h^2\ell_1\ell_2L_n,\ (h/2)\ell_1\ell_2\},&r=2,\\
0,&r\ne2.
\end{cases}
\tag{31}
\]

素数幂项也可用正积分 `I_(2,h)(L_n)` 替换其粗包络以进一步缩小修正；(30) 保持了最直接的幂函数计算。定义

\[
C_h^\pm(y)=\sum_{2\le n\le y}\eta_n^\pm(h)(y/n-1).
\tag{32}
\]

### 定理 3：单边完整道路比较

若 `h log y <= 2 log 2`，则

\[
\boxed{
\mathscr G_h^{[2]}(y)-C_h^+(y)
\le G(y)\le
\mathscr G_h^{[2]}(y)+C_h^-(y).
}
\tag{33}
\]

**证明。** 在 `mathscr G^[2]-G` 的完整有限和中，正误差只能来自 `r=2`，负误差只能来自 `r=1` 或 `r>=3`；分别用 (30)–(31) 包络后相加。所有 ramp 权非负，故不等式方向不变。□

`eta^-` 的 `r=2` 条目为零，只是因为这一层不妨碍当前所需的单边上界。其完整正贡献仍在 `mathscr G^[2]`，在反向比较中也仍由 `C^+` 明确记录。这不是删除联合层，也不是证明该层对正部能量无害。

### 定理 4：单个有限端点给出整个实数窗口的桥

固定 `0<theta<1`、`2<=Y<=Z` 及 `h>0`。若

\[
\boxed{
h\log Z\le2\log2,\qquad
C_h^-(Z)\le\tfrac12 Z^\theta,
}
\tag{34}
\]

则对每个实数 `y in [Y,Z]`，

\[
\boxed{
G(y)\le\mathscr G_h^{[2]}(y)+\tfrac12 y^\theta.
}
\tag{35}
\]

**证明。** 对固定整数 `n`，函数 `r_y(n)y^(-theta)` 在 `y<n` 时为零，在 `y>=n` 时导数为

\[
\frac{1-\theta}{n}y^{-\theta}
+\theta y^{-\theta-1}>0.
\]

因此非负系数之和 `C_h^-(y)/y^theta` 单调不减。用端点条件得到 `C_h^-(y)<=y^theta/2`；第一个条件保证定理 3 在整个窗口内适用。□

这减少了误差预算中的保守损耗：不再把有利的正误差也按负误差付费，也不把高联合层一律用 `log^3 n` 控制。给定有限 `Z` 时，(30) 中每项关于 `h` 单调不减，故 `C_h^-(Z)` 亦然；可以在方向允许区间 `0<h<=2log2/logZ` 内用单调搜索选择较厚的 `h`，再用严格区间算术认证 (34)。这里的标量搜索不会估计或消去任何无限尾。

### 6.1 一个严格的全窗口实例，厚度超过旧统一公式五倍

取

\[
[Y,Z]=[25,125],\qquad\theta=3/4,\qquad h=149/1000.

## 8. 可继续使用的结果与仍未解决的问题

本稿给出的可调用接口是：

- 用 (6)–(9) 在完整道路上保持所有联合素因子的有限差分结构，单位端口自动正确。
- 用 (12)–(15) 对任意阶数追踪每一 `omega` 层的首项及可算余量，避免把有限接触消去误读成原生方向消失。
- 对二阶使用 (21) 检查真实符号，使用 (25)、(27) 计算比统一对数幂更小的包络。
- 当目标只需要固定 `G` 的上界时，使用 (30)–(35) 的单边修正；只需认证一个有限端点就能覆盖整个连续窗口。

这些结果没有证明所选道路组合的正部能量在任意远窗口上满足次幂条件。带负权重的组合仍可能具有新的正部；已知的单个厚度正部界不能自动控制它。正核 (3) 也没有提供这种缺失的能量界，因为完整 Möbius / 联合差分仍可变号。

对项目源中的原始 `Q_a`、完成平方能量及其 RH 等价判据，本稿没有改写、合并或证明新的无穷尾结论。§6 的有限修正只解决桥接误差这一环；无限尺度正部能量及其量词仍是后续研究目标。
