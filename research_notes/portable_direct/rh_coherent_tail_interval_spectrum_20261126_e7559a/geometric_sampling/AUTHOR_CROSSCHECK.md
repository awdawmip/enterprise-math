## 2. 本轮实际运行

执行：

```bash
python research_round6/geometric_sampling/construct_atomic_moment_counterexample.py
```

输出 `atomic_moment_prefix.json`。脚本以准确 `Fraction` 构造到64阶，重新读取输出表示，再计算最终有限测度的64个矩；残差全部为准确有理零。还核对正质量、全部半径的严格顺序和环域范围，以及二次幂阶数的正质量见证。

最初运行因 Python 对大整数十进制转换的默认4300位限制停止在结果编码阶段；增加对受控本地构造的整数编码许可后，同一精确计算成功完成。此为编码大小限制，没有改变递推、输入或认证算术。
