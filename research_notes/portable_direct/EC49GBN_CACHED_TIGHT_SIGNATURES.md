## 1. Unique deficit carrier and cached local signatures
Let g be the GBJ normalized monotone integer submodular port observer with GBL additive factors C_l and canonical sparse envelopes P_l. Successful insertion E gives g'(S)=min(g(S),g(S union E)-1). Fix a greedy integer base b of g', so b(C)=g(C)-1 and b>=0. Define a_l=min_{(W,v) in P_l}(v-b(W)); d_l=min over the same rows with E intersect C_l subset W. By GBM, sum a_l>=0, sum d_l>=1. Since g_l(empty)=0, a_l<=0 (some zero-weight row covers empty; b>=0); hence a_l=0. Each d_l>=a_l=0 and d_l<=g_l(C_l)-b(C_l) since the full local mask occurs in every envelope and is eligible. The full-mask differences are nonnegative (b independent in g) and sum to one. Therefore sum d_l=1 and d_l=g_l(C_l)-b(C_l) for every l. Exactly one old factor carries the missing unit. This is a basis-dependent location, not an invariant physical defect.

Let T_l^0 be the family of local rows attaining a_l; T_l^1 the eligible rows attaining d_l. Both are nonempty. At b, the tight global inequalities of the first branch are precisely products of T_l^0; for the second branch (whose right side subtracts one) precisely products of T_l^1. This follows from equality of sums of nonnegative deviations from the local minima. All other inequalities have at least one integer unit of slack. A unit exchange b-e_i+e_j with b_i>0 and b_j<c_j violates an inequality iff it is tight and contains j but not i. For a port t in C_l define sigma_l^h(t)={W in T_l^h:t in W}, h=0,1. Thus for each branch h:
* Same old factor: exchange is feasible for this branch iff sigma_l^h(j) subset sigma_l^h(i).
* Distinct old factors l,m: exchange is feasible for this branch iff sigma_m^h(j) is empty OR sigma_l^h(i)=T_l^h. Indeed the two local masks can be selected independently in a product.
The exchange is feasible iff both tests pass. Union of endpoints of feasible unit exchanges gives the unique finest new additive whole-port partition by GBL. No global product or scan of all local rows per candidate is needed. After this step GBM local reconstruction recovers the exact g' restrictions and preserves every future insertion observer by induction. GBN code tests the partition stage; it reconstructs old local envelopes from the dense reference on each prefix, not a fully integrated GBM updater.

## 2. Smaller possible signature representation
For each branch and local family, record union U_l^h, intersection I_l^h and K_l^h(j)=intersection of masks containing j (set K=C_l if no such mask). Within a factor exchange passes iff i in K_l^h(j); across factors iff j not in U_m^h or i in I_l^h. This follows directly by quantifying the same forbidden witness. This gives at most two families of O(sum_l |C_l|^2) bits, excluding index overhead, independent of envelope size after building the certificate. It is an ephemeral exchange certificate at b,E, not a replacement for the port observer. Implemented version uses bitsets over rows, not the compressed intersection implementation. Precompute signatures by scanning L=sum |P_l| rows (straightforward O(nL) mask/bit operations with n ports), plus greedy queries. Each eligible exchange now uses two constant-count bitset checks, with width cost proportional to the local tight-family sizes; the intersection form would instead use port-width masks. Union/find, reconstruction, input conversion and witness recovery are separate costs. No timing advantage claimed yet.

Additional exact consequence: for a fixed order with prefixes S_i, g(S_i union E)-g(S_i) is a nonincreasing nonnegative integer by submodularity, initially positive and finally zero. Therefore the new greedy base equals the old greedy base minus one unit at the first prefix where that marginal is zero. Proof: g'(S_i)=g(S_i)-1 exactly at such zero-marginal prefixes; the difference of successive prefix values changes only at the first such index. Can reuse an old basis in the same order.
