## 2. 自由探索应该进入哪里

按实际研究方式登记即可，不按每次想法变化产生新表单：

| 实际工作 | 合适位置 |
|---|---|
| 已经读过项目成果的发散研究、自由选题、换角度推导 | 已有知情研究身份和 Activity；现有模式名是 TASK_RESEARCH，Task ID 可空 |
| 明确实施原始基底下的 FREE discovery | FREE_AXIOM_DISCOVERY；保留实际曝光历史，按 Phase A 使用基础及获准的精确来源 |
| FREE 阶段形成的候选或未完成推导 | 带真实状态和固定来源的科学笔记；候选 ID 描述冻结对象，Activity 描述研究关联 |
| 冻结后的比较、查重和审计 | Phase B；结果为派生定理时沿已有派生成果/后续任务入口，不因出自 FREE 就冒充新公理 |
| 需要共享领取、正式 Result 或独立 Review 的工作 | 原有 Task/CLAIM/Result/Review 路径，按真实权限和状态推进 |

FREE 的来源隔离保护实验条件。更换会话 ID、填写模式或完成登记都不会清除既有知识。当前知情对话因此没有注册一个声称干净的新 FREE 身份。此次修复也没有新增同一 SID 的 FREE→TASK 转换接口；正式执行阶段的模式关联仍需现有 Source 角色/活动路径正确处理，不能靠放宽 prepare 门禁掩盖。

候选协议现在明确，“BLIND_CANDIDATE 不能直接进入规范 main”的规则针对数学内容接纳；带状态的原始候选和审计材料可以在已授权的 research_notes 等位置保存。保存材料不需要先伪造 Task、CLAIM 或 Result。

### 当前不等于对最新原文复核

原生 `current=true` 表示场里的当前版本绑定。它不表示：

- 已检查最新 Source 是否更改了前提、结论或证明状态；
- GitHub 新提交或 source bundle 刷新已自动提炼新理解；
- 笔记已有独立 Review 或定理接纳。

这次两条新理解在保存后的同轮原生召回中可见；这是本次功能观察，不是对所有未来提交的自动更新时限承诺。共享实现当前候选的 encounter/reuse 改进以及 stitch 等接口也不能因存在于分支就当成已部署。

维护入口已加入现有 PORTABLE、CONTINUATION 和贡献指引：接续、引用旧结论、疑似重推、来源或条件变化时按需读取；在有意义的成果批次或交接边界，由 Host 根据实际来源与附近已有理解决定保留、修订或新增。无需每步变形、试值、每条回复或单纯 HEAD 变化都写一条笔记；笔记维护也不阻塞科学文件保全。

## 5. 如何处理同一东西的不同角度证明

判断重复首先比较对象、假设、量词、参数/观测范围与结论。证明方法不同，并不自动成为不同定理。规则已加入原来的研究协议段落，无逐引理新增表单：

| 实际差异 | 后续处理 |
|---|---|
| 同一命题、同一范围，已有可用证明 | 核对条件后引用已有证明 |
| 同一命题，另一种证明有简化依赖、独立核验等价值 | 作为原结果的证明变体保存与关联，保留实际作者和核验独立性 |
| 减弱假设、扩大参数范围、强化量词或结论 | 链接旧结果，写明增量并证明新增部分 |
| 更正旧前提、发现反例或收窄范围 | 修订当前理解和入口，保留旧证据及更正关系 |
| 来源或范围尚不清楚 | 回原文核对，不凭表达相似自动删掉或合并 |

Riesel 是明确实例：统一锐阶梯是某旧同余类中满足 3|a 的根的下界，并存在同一根与嵌套字典取等；原始固定根的 2056 项窗口下界 1791 是另一个范围，原根全程有限覆盖仍未决。同一 25 通道轨迹支持每个有限成本的无限根族，也不意味着一个根具有无限成本。

三角矩材料已复用旧 Green 核与恒等式，同时给出另一种论证路线、放宽尺度条件并排除独立最小值筛选。辅助命题、构造和有限证书已经完成，不等于无界真实匹配窗口的统一估计已经完成。后续应消费已有结果，推进正文列明的剩余量词与骨架预算。

这些样例足以证明同步与范围提示有实际改进空间，不能据此估算整个项目的重复证明比例，也不能把有目的的另一种证明一概当成浪费。
