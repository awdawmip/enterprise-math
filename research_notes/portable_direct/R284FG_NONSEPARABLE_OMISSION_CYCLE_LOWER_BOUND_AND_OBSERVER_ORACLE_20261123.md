# R284FG — 跨代漏写四代码的非分组通用下界、最小强制译码判据与十三位见证

日期：2026-11-23（Asia/Shanghai）。状态：AUTHOR_PROVED / EXACT_FINITE_CHECKED / NOT_REVIEWED。来源：R284FF@9fba343351b5586dbf9f7689bd82487eb68d7310、R284FD@70017ca0eac9aa46cabb633c675da9f15b410b0c、R284EW@1e1f5752966d021f66d0d67a394b0b0b95938558。沿用 R284CO 冻结科学输入，不变更 P000、ACTIVE 世界观及现有 BRC/进取坐标系。此结果仅属辅助二进制发布信道；不将其冒充 X6 动力学定理。

## 模型

四个互异固定目标字 c_0,c_1,c_2,c_3 属于 {0,1}^n，按模4顺序循环；初始物理字为 c_0。第 i→i+1 次发布只尝试差异位 D_i=supp(c_i xor c_{i+1})，每位按该边预定次序恰好尝试一次；最多 q_i 个位置可以漏写，漏写保持该位置的旧物理值，其他位置被置为下一目标位。未主动清除的历史残差保留。每次读数最多 u 个任意且彼此独立的瞬时翻转。译码器无状态，输出 0、1、2、3 或 RETRY。每次发布完成的所有可达物理状态和合法读错必须返回真实代际。任意发布前缀不能成功返回第三代，同一发布内不能先成功返回新代、再返回旧代；写者可无限期停在任一前缀。整数 u,q_i≥0。

## 定理 A — 无分组假设的容量必要界

任意符合上述完整观察契约的四代码都满足：

```
d(c_i,c_{i+1}) ≥ 4u+q_i+1  (i=0,1,2,3)
d(c_0,c_2), d(c_1,c_3) ≥ 2u+1
n ≥ 5u + ceil((q_0+q_1+q_2+q_3+6)/4).
```

特别地，统一预算 q_i=q 时，**n ≥ 5u+q+2**。这是任意固定四代码、任意预定逐位写入次序、任意无状态译码器的普适下界，不依赖独立重复组或 Gray 结构。q=0 时退化为 R284EW 的 5u+2 锐界；q=1,u=1 时给出 8 位下界，和 R284FE 的14位分组可达上界之间仍有空隙。

**证明（相邻边）。** 固定一条边，令其差异位数 d。经全部无漏写历史，c_i 是合法稳定旧代；从其出发、前 t 个差异位无漏写成功后，物理前缀 x 与 c_i 的距离为 t。若 t≤2u，两个半径 u 汉明球 B_u(x) 与 B_u(c_i) 相交，因此存在被稳定端点正确性强制译为旧代 i 的读数字，同时该数字距 x 不超过 u。

从这个前缀继续完成发布，在尚未尝试的 d−t 位中使最多 q_i 位漏写，可得合法稳定新代物理字 z，且 d(x,z)=max(0,d−t−q_i)。若 d−t≤q_i+2u，则 B_u(x) 与 B_u(z) 相交，产生被稳定端点强制译为新代 i+1 的另一读数字。两次读取错误独立，写者停在 x 时先返回新、再返回旧，即违反无回退。

只要 d≤4u+q_i，就能选整数 max(0,d−q_i−2u)≤t≤min(d,2u)，同时满足以上两条件。故必须 d≥4u+q_i+1。特别地 d=0 也由稳定阶段互异识别直接排除。对角码字本身都是零漏写历史中的稳定字，两个半径 u 的纠错球必须不交，故距离≥2u+1。

最后六个无序码字距离之和至少是
4(4u+1)+Σ_i q_i+2(2u+1)=20u+Σ_i q_i+6。
每个二进制坐标在四标签中若有 j 个1，其对六对距离的贡献为 j(4−j)≤4，故六距离总和≤4n，整理即得位数下界。证毕。

## 定理 B — 完整端点与中间过程的可判定性

给定四码字、初态、预算及各边写入次序，令 S_i 为**任意多轮合法完整发布后**可达的稳定物理字集合。其有限计算方式：从 (0,c_0) 起，按每次完整发布中所有 ≤q_i 个漏写位置选择闭包，直到阶段—物理字对不再增加。令 A_i=并集_{s∈S_i} B_u(s)，这是在稳定第 i 代时可能出现的所有读数字。

存在合法无状态译码器，当且仅当同时满足：
1. 四个 A_i 两两不交；
2. 每条从 S_i 出发的合法逐位发布轨迹上，每个物理前缀 x 的 B_u(x) 与 A_j 对第三代 j∉{i,i+1} 均不交；
3. 同一条轨迹上不存在时刻 t≤t'，使 B_u(x_t)∩A_{i+1} 和 B_u(x_{t'})∩A_i 同时非空。

证明：稳定正确性强制任意译码器在 A_i 上返回 i，因此任何上述碰撞都会形成错误代际或先新后旧。反过来，当三条满足时，取**最小强制译码器** D(y)=i 若 y∈A_i、其余为 RETRY；稳定端点由定义正确，轨迹上的所有成功输出均合法且不回退。阶段—物理字至多 4·2^n 种，全部合法轨迹和读数字选择有限，因而该判定是完全有限、对无限代漏写历史正确的精确算法。此判据将 R284FD 的稳定端点 BFS 扩展到一般 u、边预算与完整中间读数；并非声称所有任意 n 的最优化都已完成。

## 精确新见证 — 完成端点可译仍可能回退

取 n=13，u=q_i=1，码字（十进制位掩码）为
(c0,c1,c2,c3)=(0,1751,5436,7003)，每条边按差异位从低到高写入。穷尽四个稳定阶段的可达物理字数为 (80,90,80,90)，其半径1读出集合 A_i 的大小为 (428,478,428,478)，**六对 A_i 两两不交**。故单纯检查完整端点会误把该码判为可用。

合法历史如下，括号注明漏写位：0→1751（无）→5564（目标5436，漏写bit7）→7131（目标7003，无）→144（目标0，漏写bit4）；此时真实阶段0。下一轮往目标1751写入，依次成功写bit0、bit1、bit2、bit4，物理前缀变为 x=151（无本轮漏写）。同一物理前缀可在两次独立读取中依次得到：
- y_new=215，d(151,215)=1，且阶段1稳定可达字727满足 d(215,727)=1，故必须输出1；
- y_old=135，d(151,135)=1，且阶段0稳定可达字133满足 d(135,133)=1，故必须输出0。

因此写者完全不动也允许读出 **1→0** 回退，不存在符合契约的无状态译码器。此十三位例子仅否定该具体代码和写序，并不证明所有13位代码不可能。它说明优化非分组码不能只检查稳定纠错球分离。
