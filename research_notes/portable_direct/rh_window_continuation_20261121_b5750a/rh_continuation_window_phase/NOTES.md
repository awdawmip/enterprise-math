## 2. 每个整数单元的精确结构

取固定的有限厚度族 `a_j>0` 与实权重 `w_j`，假设

\[
\sum_{j=1}^m w_j=1,\qquad F(y)=\sum_jw_jG_{a_j}(y).
\]

在单元 `[N,N+1]` 上定义

\[
A_{j,N}=\frac1{a_j}\sum_{2\le n\le N}\frac{R_{a_j}(n)}n,
\qquad B_{j,N}=\frac1{a_j}\sum_{2\le n\le N}R_{a_j}(n),
\]

\[
d_N=1+\gamma+\sum_jw_jA_{j,N},\qquad b_N=\sum_jw_jB_{j,N}.
\]

于是有**精确恒等式**

\[
\boxed{F(y)=y(d_N-\log y)-b_N\quad(N\le y\le N+1).}
\]

在右端点新进入的 `n=N+1` 项为零，故这个闭单元公式与相邻单元的端点值相容。窗口从 Y 开始只限制能量积分区间；`d_N,b_N` 仍含从2到N的全部既有贡献，不能在 Y 处把这些端口重新归零。即使有负权重，仍有

\[
\boxed{F''(y)=-1/y<0\quad(N<y<N+1).}
\]

这不是从采样数据猜测凹性，而是直接由全部道路有限和导出的结构。整数处的导数可以跳跃；以下论证每个单元单独使用凹性。

更具体地，给定固定厚度和固定线性观察量，任何左端前史的贡献都是 `y A_prefix-B_prefix`，所以在后续新增道路项仍完整提供时，这两个累计端口精确保留该观察量的全部前史作用。若后续允许再选厚度权重，应分别保留各厚度的端口，或另证所用压缩对这些晚选操作安全。这里的二端口是此标量观察量的作用分解，不是对完整原生联合状态的无损性主张。

## 3. 整数端点给出的连续窗口能量证书

令 `[Y,Z]` 是有限窗口，`1<=Y<Z`。把它按所有内部整数切成单元 `[l_k,r_k]`，因此每段长度不超过 1。令 `L(y)` 是 `F` 在这些端点的分段线性插值。

### 3.1 通用曲率包络

在任一单元 `[l,r]` 上，

\[
\boxed{
L(y)\le F(y)\le L(y)+\frac{(y-l)(r-y)}{2l}
\le L(y)+\frac{(r-l)^2}{8l}.
}
\]

证明：`F-L` 在两端为零且二阶导数为 `-1/y`，由凹性知其非负。令

\[
q(y)=\frac{(y-l)(r-y)}{2l}.
\]

`[q-(F-L)]''=-1/l+1/y<=0`，且两端为零，所以 `q-(F-L)>=0`。证毕。

该误差包络独立于 `a_j`、`w_j`、整数层上的道路质量以及模态数。其来源完全是保留下来的共同中心项 `-y log y`。曲率余量与权重无关，并不意味着端点求值的舍入或输入误差不会被大权重放大；后者须通过真实端点包络另行传播。

### 3.2 单侧能量上下界

固定 `theta>0`，记

\[
\|f\|_{\theta;Y,Z}^2=\int_Y^Z|f(y)|^2y^{-2\theta-1}\,dy,
\quad E_+(f)=\|f_+\|_{\theta;Y,Z}^2.
\]

定义

\[
\varepsilon_{Y,Z}^2
=\sum_k\left(\frac{(r_k-l_k)^2}{8l_k}\right)^2
\frac{l_k^{-2\theta}-r_k^{-2\theta}}{2\theta}.
\]

由正部函数的单调性和 1-Lipschitz 性，

\[
\boxed{
E_+(L)\le E_+(F)
\le\bigl(\sqrt{E_+(L)}+\varepsilon_{Y,Z}\bigr)^2.
}
\]

因为 `y<=l+1<=l(1+1/Y)`，还得到不依赖 Z 的简洁界

\[
\boxed{
\varepsilon_{Y,Z}
\le\frac{1+1/Y}{8\sqrt{2\theta+2}}Y^{-\theta-1}.
}
\]

证明是把每段误差界放大为 `(1+1/Y)/(8y)`，再对 `y^(-2theta-3)` 积分。

因此，对固定 `theta,lambda` 和每个窗口内部固定的厚度/权重族，以下两条次幂窗口条件等价：

\[
\forall\alpha>0\ \forall Y_0\ \exists Y\ge Y_0:
\quad E_+(F;Y,Y^\lambda)\le Y^\alpha,
\]

与把其中 `F` 换成整数端点插值 `L` 的条件。一个方向由 `E_+(L)<=E_+(F)` 直接得到；另一个方向对目标指数 `beta` 使用插值条件的 `alpha=beta/2`，再把有限阈值提高，使曲率余量被 `Y^beta` 吸收。

这把连续窗口中的未知起伏变成了明确可控的余项。任意远窗口的量词仍需数学证明，有限证书不替代这个无限尺度要求。

### 3.3 插值正部积分只需初等函数

在每段令 `L(y)=p y+q`。正部支撑由两个端点符号及可能的唯一零点 `-q/p` 精确确定。在正区间上，

\[
\int (p y+q)^2 y^{-2\theta-1}dy
=p^2J_{2-2\theta,0}+2pqJ_{1-2\theta,0}+q^2J_{-2\theta,0},
\]

其中

\[
J_{r,k}(y)=\int y^{r-1}(\log y)^kdy.
\]

特别地，`J_(r,0)=y^r/r`（`r!=0`），`J_(0,0)=log y`。所以无需把正部平方替换成完整平方，也无需对连续窗口作未经误差控制的密集采样。

若端点本身只有严格区间包络 `[F^-_k,F^+_k]`，分别插值得 `L^-<=L<=L^+`，则同样有

\[
E_+(L^-)\le E_+(F)
\le\bigl(\sqrt{E_+(L^+)}+\varepsilon_{Y,Z}\bigr)^2.
\]

这是把有理/区间端点计算升级成整个实数窗口证书的接口。

## 4. 跨厚度相干与精确 Gram

在某整数单元上写 `G_(a_j)(y)=y(d_j-log y)-b_j`。令 `p=2-2theta`、`q=1-2theta`、`r=-2theta`。跨厚度乘积的原函数为

\[
\begin{aligned}
P_{jk}(y)={}&d_jd_kJ_{p,0}-(d_j+d_k)J_{p,1}+J_{p,2}\\
&-(d_jb_k+d_kb_j)J_{q,0}+(b_j+b_k)J_{q,1}
+b_jb_kJ_{r,0}.
\end{aligned}
\]

这里

\[
J_{r,1}=y^r\left(\frac{\log y}{r}-\frac1{r^2}\right),
\quad
J_{r,2}=y^r\left(\frac{(\log y)^2}{r}-\frac{2\log y}{r^2}+\frac2{r^3}\right)
\]

对 `r!=0`；`r=0` 时统一用 `J_(0,k)=(log y)^(k+1)/(k+1)`，因此 `theta=1/2` 等边界无形式奇点。

逐单元求和

\[
M_{jk}=\sum_{[l,u]}[P_{jk}(u)-P_{jk}(l)]
=\int_Y^ZG_{a_j}(y)G_{a_k}(y)y^{-2\theta-1}dy
\]

给出正半定 Gram 矩阵，且

\[
\boxed{\left\|\sum_jw_jG_{a_j}\right\|^2=w^TMw.}
\]

全部交叉项、常数项及中心项都在矩阵内。这里的矩阵控制完整平方，正部能量满足 `E_+(F)<=w^TMw`；这个充分上界未被宣称为必要条件。

### 4.1 单侧能量不能由一个固定 Gram 矩阵代表

最简单的常数族 `f_t(y)=t` 已有 `E_+(f_t)=W(t_+)²`，其中 `W>0`，它在 `t` 与 `-t` 下不对称；固定二次型却对称。因此正部能量一般不能等同于固定的完整平方 Gram。实际道路中，§6 进一步给出了同类信息缺失的完整窗口反例。

## 5. 权重和为零的厚度缺陷：保留负权重所需的额外量

取一项 `G_(a_*)` 为锚，定义

\[
D(y)=F(y)-G_{a_*}(y).
\]

由于 `sum w=1`，共同的 `-y log y+(1+gamma)y` 精确抵消，故在每个整数单元上

\[
\boxed{D(y)=p_N y+q_N.}
\]

因此 `E_+(D)` 可以用 §3.3 精确计算，没有曲率余量。由 `(u+v)_+<=u_++v_+`，

\[
\boxed{
\sqrt{E_+(F)}\le\sqrt{E_+(G_{a_*})}+\sqrt{E_+(D)}.
}
\]

对二阶组合 `F=2G_h-G_(2h)`，取锚 `G_h` 后，`D=G_h-G_(2h)`。所需额外信息正是两个厚度之间的带符号变化，而不是各厚度分别取正部后剩下的数值。

这是一个明确的充分控制方向；是否存在沿匹配厚度窗口的统一界仍需证明。取正部后逐厚度删除负值会丢失这项信息，§6 给出实际道路上的严格证据。

## 6. 真实道路、完整幂窗口上的严格反例

令

\[
h=\frac1{10},\quad 2h=\frac15,\quad [Y,Z]=[25,125]=[25,25^{3/2}].
\]

脚本 `verify_positive_window.py` 给出了**全有理包络证书**，证明对每个实数 `y in [25,125]`：

\[
\boxed{
G_{1/10}(y)<0,\qquad G_{1/5}(y)<0,\qquad
2G_{1/10}(y)-G_{1/5}(y)>\frac16.
}
\]

计算得到的保守统一界更强：

- `G_(1/10)(y) < -0.2810870593`；
- `G_(1/5)(y) < -2.2595864000`；
- `2G_(1/10)(y)-G_(1/5)(y) > 0.1765211690`。

这些小数仅是严格有理结果的向外显示；脚本中的符号判断没有浮点运算。

取 `theta=3/4`，于是

\[
E_+(G_{1/10})=E_+(G_{1/5})=0,
\]

而

\[
\boxed{
E_+(2G_{1/10}-G_{1/5})>\frac1{9000}>0.
}
\]

所以不存在仅依赖这两个原生正部范数、且在两者都为零时也为零的通用上界，来控制这个带负权重的外推正部。特别是任意有限常数的 `C_1||G_h,+||+C_2||G_2h,+||` 都不能作通用上界。

**范围：**这证明一个实际有限窗口的表示障碍。此处固定厚度并未被宣称满足先前误差桥的匹配厚度选择，因而它不反驳匹配厚度下的渐近窗口准则，也不否定外推方法本身。它确定了外推还需控制的额外相关信息。

### 6.1 证书如何覆盖所有实数点

1. 对 `p^(-1/10)`，在十进制网格 `S=10^24` 上找整数 `q` 满足 `q^10<=p S^10<(q+1)^10`。于是 `S/(q+1)<=p^(-1/10)<=S/q`。平方包络给 `p^(-1/5)`，道路乘积逐项保留。
2. 对整数对数，先作二进制范围缩减，再使用
   `log((1+z)/(1-z))=2 sum_(k>=0) z^(2k+1)/(2k+1)`，其中 `0<=z<=1/3`。取32项，剩余量上界为 `2z^(2K+1)/((2K+1)(1-z²))`，全为有理数。
3. 对 Euler 常数，使用 `M=1000` 的精确调和和以及
   `H_M-log M-1/M<gamma<H_M-log M`。该界由定义 `gamma=lim(H_n-log n)` 和逐单元积分估计直接得到。
4. 以这些包络计算全部101个整数端点。两个原生 `G` 的单元上界是相邻端点上界的较大值加 `1/(8N)`；每个这样的上界均小于0。外推后的 `F` 凹，故每个单元上 `F` 不低于端点较小值；全部端点下界大于1/6。
5. `sqrt(5)>559/250` 可由平方有理数验证，故
   `integral_25^125 y^(-5/2)dy = (2/3)(1/125-1/(625 sqrt5)) > 1/250`。
   与 `F>1/6` 合并即得 `E_+(F)>1/9000`。

证书实际还给出 `E_+(F)>0.0001513206829028` 的严格下界。全部端点包络和计算参数保存在 `positive_window_certificate.json`。

## 8. 精确单元正部公式（可选直接路径）

对 `f(y)=y(d-log y)-b`：

- `b>0` 且 `b<exp(d-1)` 时，正部支撑为两根之间，根为
  `-b/W_(-1)(-b exp(-d))` 与 `-b/W_0(-b exp(-d))`；
- `b>=exp(d-1)>0` 时无正区间；
- `b=0` 时正区间为 `(0,exp(d))`；
- `b<0` 时唯一正根为 `-b/W_0(-b exp(-d))`，正区间从0到该根。

这些区间与实际整数单元相交即可。其平方原函数由 §4 的 `j=k` 给出。Lambert W 只是求根表示，数值证书可以完全使用 §3 的端点包络，不依赖特殊函数的区间实现。
