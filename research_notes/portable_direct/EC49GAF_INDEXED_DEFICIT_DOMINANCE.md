## Exact index
At a fixed GAE reduction domain encode (M,C) by x=M|(C<<k). Visit records in order (loss, popcount(x), key). Every strict dominator of a distinct key precedes that key, because its loss is lower, or its loss is equal and its bit set is a strict subset. Equal keys already retain minimum loss. For each retained record allocate one bit i; A is all retained bits, P_j marks retained records containing coordinate j. A retained subset of x exists iff A intersect (intersection over j not in x of complement P_j) is nonempty. This follows coordinate by coordinate, and the GAE loss condition holds from sort order. Retaining only prior nondominated keys is sufficient by transitivity. Thus this inverted-bitset index produces exactly the same dictionary as quadratic GAE dominance, including ties. Its bit operations have length proportional to the number of retained records; no subquadratic worst-case time guarantee is claimed. No raw state label was removed except by proved GAE dominance.
