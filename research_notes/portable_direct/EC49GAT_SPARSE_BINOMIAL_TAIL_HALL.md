## Theorem
Let n be the number of targets, d a nonnegative integer budget, and two disjoint banks each have classes j=0,...,d of capacity C(d,j). Each target's permitted classes in each bank form an integer interval (possibly empty). Match targets at most once. The scope is abstract Hall capacity, with target identities retained; no physical tree equivalence asserted.

For n>0 call class rich if C(d,j)>=n and scarce otherwise. By symmetry and monotonicity up to the center, rich classes form an integer interval (possibly empty) [a,d-a]. Let P be targets whose permitted interval in either bank intersects this rich interval. Every member of P can be assigned to an adjacent rich class simultaneously: arbitrarily select one for each target, since no class can receive more than n targets. Remaining targets have no rich neighbors. In any optimal matching P contributes at most |P| and other targets match solely in scarce classes. Combining the rich assignment with an optimal scarce-only matching attains this bound. Thus H=|P|+H_scarce, exactly. This is a simultaneous GAS saturation elimination using binomial structure, no target overlap or double credit.

For n>=2 let t=ceil(log2 n). If d>=2t, C(d,t)=product_{i=0}^{t-1}(d-i)/(t-i)>=2^t>=n, so only j<t or j>d-t may be scarce, at most 2t per bank. If d<2t, d+1<=2t directly. Hence at most 4 ceil(log2 n) scarce classes across two banks, independent of d; for n=1 none, n=0 capacity zero. The same proof for m banks yields 2m ceil(log2 n). For d>=n>=2, C(d,1)=d>=n, so only four endpoint slots remain across two banks. The recurrence c_0=1, c_{j+1}=c_j(d-j)/(j+1) stops at first rich or midpoint. Each pre-stop c_j<n, hence intermediate products have O(log n+log(d+1)) bits and only O(1+log n) iterations. Given interval endpoints, rich intersection costs O(n) comparisons, scarce adjacency construction O(n(1+log n)) comparisons, with capacities <n; augmentation still has its own graph/target cost. This bound is not a complexity claim for physical search or constructing the intervals.
