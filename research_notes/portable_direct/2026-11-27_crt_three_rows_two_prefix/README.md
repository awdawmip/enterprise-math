## 任意宽度降到四列和五列

采用原 CRT 代表、真实进位 \(\epsilon_{ij}=\lfloor(\omega_i+\nu_j)/M\rfloor\) 和严格前缀 \(C(h)=\sum_{k_{ij}<h}x_{ij}\)。给定实数相容的观测值，取固定边际和三项附加等式之非空有界多胞体的一个极点 \(x\)。写 \(x=\lfloor x\rfloor+y\)，其中 \(0\le y_{ij}<1\)。于是 \(y\) 的各边际、进位和两项前缀仍为整数。若 \(y=0\) 即结束。

将 \(y\) 的非零格视作行列二分图的边。其每个活跃顶点度数至少为二，因为单条严格分数边无法给出整数边际。若活跃行至多二，沿用[两行真实进位与任意前缀定理](https://github.com/awdawmip/enterprise-math/blob/44747bef0a3135806fd916ca98e77ca32c7d67f0/research_notes/portable_direct/20261127_crt_wrap_carry_joint_prefix_difference_constraints.md)，在对应完整子网格回补整数表。若三行活跃而活跃列至多三，由两行定理的转置或[完整 \(3\times3\) 定理](https://github.com/awdawmip/enterprise-math/blob/f8267f9722ef1917c6ee517035442da7472f9d44/research_notes/portable_direct/2026-11-27_crt_3x3_saturation/README.md)回补。

现在三行活跃，设活跃列数为 \(s'\ge4\)，非零边数为 \(E\)。图必连通，因为任一成分至少需要两行，而总共只有三行。零边际流动空间的维数是 \(E-(s'+2)\)。在该空间内，进位和两项前缀的线性测量必须单射。若有非零方向落入三项测量的核，沿此方向对原极点 \(x\) 作足够小的正负扰动都可行，因为该方向只动严格正的格。故

\[
2s'\le E\le s'+5,\qquad s'\le5 .
\]

四列需要检查 \(E=8,9\)，五列只需检查 \(E=10\)，且五列每列边际恰为一。这样任意原列数都降到了固定规模。回补可以使用活跃行列构成的完整子网格，最后加回原来的 \(\lfloor x\rfloor\)。

## 有限观察型别

在所取子网格按行、列代表升序排列。设两个切点 \(0<h_1<h_2<M\)；相同或端点切点可由已证的单前缀结论处理。把提升和 \(\omega_i+\nu_j\) 按五条阈值 \(h_1,h_2,M,M+h_1,M+h_2\) 划成类别 \(0,\ldots,5\)，等号归上侧。测量的三个格系数只依赖类别。

| 类别 | 真实进位 | 前缀 \(h_1\) | 前缀 \(h_2\) |
|---:|---:|---:|---:|
| 0 | 0 | 1 | 1 |
| 1 | 0 | 0 | 1 |
| 2 | 0 | 0 | 0 |
| 3 | 1 | 1 | 1 |
| 4 | 1 | 0 | 1 |
| 5 | 1 | 0 | 0 |

类别沿每行、每列非减。同一行或列的提升和值域严格小于 \(M\)。一格若从第 \(j\) 类跨到第 \(j+4\) 类，必须跨越距离为 \(M\) 的两条相应阈值，因此同一行列内的类别差至多三。程序穷举满足这两条规则的全部矩阵。只需要它们覆盖实际 CRT 型别，因而无须判断每个矩阵是否真可由互素模数实现。

## 用整数环基穷尽分数载荷

对每个允许的分数支撑取一棵生成树。每条非树边配一条基本交替环，令该非树边系数为 \(+1\)。给定整数行、列边际，生成树上可以用叶消元得到一个允许负值的整数参考表。减去这个参考表后，任意分数表都由环系数决定，且非树边坐标正是各环系数。将三个测量施于环基，得到整数矩阵 \(D\)，行是测量，列是环。

极点条件保证 \(D\) 满列秩。由克拉默法则，每个环系数的分母整除全部非零满秩子式绝对值的最大公因数 \(d\)。若 \(d=1\)，分数部分为空。若 \(d>1\)，把非树边系数模一限定到 \(\{1/d,\ldots,(d-1)/d\}\)，按环向所有格展开并逐格模一。只保留支撑正好相同、三项读数均为整数的表。原来的 \(y\) 必在其中。最后直接穷举具有该表整数边际的全部非负整数表，检验三项读数能否同时复现。

| 活跃列数 | 类别矩阵 | 分数支撑 | 最大非零子式公因数 | 需回补的分数表 | 格点孔 |
|---:|---:|---:|---:|---:|---:|
| 4 | 27,062 | 150 | 3 | 4,452 | 0 |
| 5 | 114,680 | 210 | 4 | 28,680 | 0 |

四列的分数支撑按边数分为 54 个八边、96 个九边。五列的支撑均有十边。复算总计 33,132 个需回补的分数表，全部找到整数原像。程序的型别、秩、符号、余额和检查总数均有整数检查。算术和穷尽性配合上述降维给出任意宽度的结论。

## 完整四行四列的两个前缀反例

取 \(m=4,n=7,M=28\)，行分量 \((0,7,14,21)\)，列分量 \((0,4,16,20)\)。规范余数按行是

\[
 k=\begin{pmatrix}
 0&4&16&20\\
 7&11&23&27\\
 14&18&2&6\\
 21&25&9&13
 \end{pmatrix}.
\]

进位只在右下 \(2\times2\) 块为一。各行和列和均为一，切点取 \(3,17\)。按行所选列表示单位匹配，\((0,1,2,3)\) 的 \((e,C(3),C(17))\) 为 \((2,2,4)\)，\((2,3,0,1)\) 的读数为 \((0,0,2)\)。平均给出实数原像 \((1,1,3)\)。

若有整数原像，进位一要求后两行恰有一行使用后两列；前两行也恰有一行使用后两列。\(C(3)=1\) 必须在 \(x_{00},x_{22}\) 中恰选一格。

- 若选 \(x_{00}\)，则行 1 使用后两列之一，余数为 23 或 27。后两行之一使用列 1，余数为 18 或 25。这两个格均不进入 \(C(17)\)。
- 若选 \(x_{22}\)，则行 3 使用前两列之一，余数为 21 或 25。列 3 必由前两行之一使用，余数为 20 或 27。这两个格也都不进入 \(C(17)\)。

故 \(C(17)\le2\)，与观测 3 矛盾。三行定理及其转置说明完整网格的两前缀孔至少需要四行四列，本例达到最小尺寸。结合[同行的六行单前缀定理](https://github.com/awdawmip/enterprise-math/blob/53c03736fa32eefa8d6d1d3b2b526bf2f342c8ac/research_notes/portable_direct/CRT_SIX_ROWS_ONE_PREFIX_20261127.md)，完整 (4×4) 的最少附加前缀数恰为二。另可直接穷举固定数据的 24 个整数表复核。

~~~python
from itertools import permutations

rows = (0, 7, 14, 21)
cols = (0, 4, 16, 20)

def readout(word):
    lifted = [row + cols[j] for row, j in zip(rows, word)]
    residues = [s % 28 for s in lifted]
    return (sum(s >= 28 for s in lifted),
            sum(k < 3 for k in residues), sum(k < 17 for k in residues))

assert readout((0, 1, 2, 3)) == (2, 2, 4)
assert readout((2, 3, 0, 1)) == (0, 0, 2)
assert all(readout(word) != (1, 1, 3) for word in permutations(range(4)))
~~~
