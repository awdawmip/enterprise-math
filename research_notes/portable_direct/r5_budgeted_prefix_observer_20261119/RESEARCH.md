## 模型

Ω 是有限非空响应集合，A 是有限动作字母，T_a:Ω→Ω 是确定性全函数，L:Ω→2^[n] 是具名支持标签，边费用 c_a:Ω→Z_{\ge0}。固定非负整数预算 B，候选集合 S⊆Ω，x∈S，Y=S\{x}≠∅。

动作词 w=a_1...a_t 的前缀 w_j 按时间顺序作用在初始状态 z 上。令 z_j=T_{w_j}(z)，C_z(w_j)=Σ_{i=1}^j c_{a_i}(z_{i-1})，C_z(ε)=0。给定每个前缀的正向需求 Q_j⊆[n]，定义

Obs_B(S;w;Q_0,...,Q_t) = [∃z∈S: C_z(w)≤B 且 ∀j=0..t, Q_j⊆L(z_j)]。

由于边费用非负，末端总费用不超过 B 等价于所有前缀均不超过 B。同一初始 z 必须实现整条轨迹。w 和 Q_j 事先固定；不把负向查询分支、任意自适应 Bellman 策略自动纳入该观察者。

## 定理 BCPT1 — 预算保真删除充要条件

删去 x 保持所有 Obs_B 真值，当且仅当

∀w∈A*: C_x(w)≤B ⇒ ∃y_w∈Y:
  C_{y_w}(w)≤B 且 ∀j≤|w|, L(T_{w_j}x)⊆L(T_{w_j}y_w)。

证明：删除不能产生新见证。如果原查询由 x 见证，右式给出同一初始 y_w，预算可行，并在每个前缀上覆盖 x 的全部需求；因此仍真。原来由其他 z 见证则更直接。反向，对任意 x 预算可行的 w，令 Q_j=L(T_{w_j}x)；原式由 x 见证，删后仍真便要求上述同一 y_w。空需求合法，因此纯资源可行性也被保存。证毕。

## 定理 BCPT2 — 有限完备 BFS、最廉价同像支路

构造乘积状态 (u,d,V)。u 是 x 当前像，d 是 x 累计费用，V 把每个仍存活的保留候选当前像 v 映射到该像的最小累计费用 e∈{0,...,B}。初态 u=x,d=0，仅保留 L(x)⊆L(y) 的 y，费用0。每次选择动作 a：

1. 若 d+c_a(u)>B，则该转移的 x 轨迹不属于待保持的预算观察，可忽略。
2. 否则更新 u'=T_a(u)，d'=d+c_a(u)。对每个 (v,e)，尝试 v'=T_a(v)，e'=e+c_a(v)；淘汰 e'>B 或 L(u')⊈L(v') 的候选。
3. 对相同 v' 的多个候选，仅保留最小 e'。若 V' 为空，则此前动作词接 a 是失败证书；否则 BFS 搜索未见状态。

理由：若两个候选到同一 v'，其未来全部确定性迁移、标签和每步费用增量完全相同；较小费用的候选可以完成较大费用候选未来全部预算可行的路径，因此按当前像最小资源合并无损。逐前缀归纳证明 V 恰表达所有可能原始替代见证中的非支配者，V 为空恰是 BCPT1 失败。

若 N=|Ω|，搜索状态数不超过 N(B+1)(B+2)^N，故有限终止，并给出最短失败动作词；如失败，长度不超过此保守上界。全部费用为0时退化为此前 PT 判据。这是精确资源下的支路合并，不能跨不同当前状态直接合并。

## 定理 BCPT3 — 预算安全性可以反复改变

即使各边费用只有0或1，安全性也不随 B 单调变化。取 Ω={0,1,2}、S={1,2}、x=2、Y={1}，所有状态标签均为 {1}。两个动作 a、b 定义如下：

| 状态 z | T_a(z) | c_a(z) | T_b(z) | c_b(z) |
|---|---:|---:|---:|---:|
| 0 | 0 | 0 | 0 | 0 |
| 1 | 0 | 0 | 2 | 1 |
| 2 | 0 | 0 | 0 | 1 |

B=0 时 x 的预算可行词要么为空词，要么先走 a，此时 x、y 同到0，故安全。B=1 时词 bb 对 x 费用1、对 y 费用2，删除不安全。B=2 时任何词要么先走 a 同到0，要么先走 b 后 x 到0、y 到2；若接着走 a 则同到0，若接着走 b 则 y 共费2也到0，之后完全重合。因此安全。B=3 仍安全。该见证同时保持非空的具名正向需求 {1}。

机制：增大 B 一方面允许 x 走更多轨迹，另一方面解锁 y 的替代轨迹；两种效应作用方向相反。
