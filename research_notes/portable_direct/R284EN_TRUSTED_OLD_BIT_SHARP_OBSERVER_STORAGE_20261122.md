## 定理 1：指定旧来源位的锐门槛

对于可信 `T=a`、`T=b`、`T=a xor b`，单靠 `T` 与数值观察就能区分所有状态的最大 `E` 如下：

| 可信旧位 T | 同一 T 的类别配对 | 两读 D：最大 E | 四端口 F：最大 E |
|---|---|---:|---:|
| a（索引第12位） | 0–2、1–3 | **4696** | **4715** |
| b（索引第14位） | 0–1、2–3 | 29 | 29 |
| a xor b | 0–3、1–2 | 4644 | 4663 |

证明：R284EM 已证在 `E<=8656` 时同一完整标签 `L` 内任意两个不同源状态不可能有相同带误差数值输出；跨标签类别 `u,v` 能共用整数观测向量，当且仅当相应端口的精确 `L_infty` 最小间隔 `m_p(u,v)<=2E`。对指定的可信 `T`，只需检查两条位于相同 `T` 纤维内的类别边。最小间隔 `m_T` 导出无额外存储的锐条件 `2E<m_T`，所以最大整数误差为 `floor((m_T-1)/2)`。达到下一整数 `E` 时，R284EM 中达到最小距离的见证源状态对给出不可消解的相同接收观测。该证明同时涵盖全部 65536 状态及所有有界噪声。

## 定理 2：任意可信单比特函数的最优剩余存储长度

设 `n_{p,1}^*(E,k)` 是在所有 `g:{0,1}^2->{0,1}` 中选择一个可信旧比特，同时最优化另一个最多有 `k` 次任意翻转的存储码字长度。在上述模型及 `0<=E<=8656` 下：

```
n_{D,1}^*(E,k) = 0       if 0 <= E <= 4696
                   2k+1  if 4697 <= E <= 8656

n_{F,1}^*(E,k) = 0       if 0 <= E <= 4715
                   2k+1  if 4716 <= E <= 8656
```

任意 `k>=0` 都严格成立。选择 `g=a` 可以达到两个分段的上界；在零额外存储允许的最大误差处，即 D 的 `E=4696` 和 F 的 `E=4715`，`g=a` 及其逐位取反是**仅有的两个**可行可信比特函数（在四种标签类别上的真值掩码分别为 `0b1010` 和 `0b0101`）。

证明：

1. 在 D 的 `E=4696`，以及 F 的 `E=4715`，四标签混淆图的边恰为 `0–1,1–2,2–3`。这是连通路径 `P4`，它仅有两种互补的二着色，所以零额外存储的可信单比特只能是 `a` 或 `1-a`。因混淆图随 E 只增加边，`a` 对所有更低 E 亦可行。
2. D 在 `E=4697` 首次新增 `0–2` 边；F 在 `E=4716` 首次新增同一类别边。两者都出现三角形 `0–1–2–0`。任何二值 `g` 必把三角形的某两个顶点编码为相同可信位；对应两个**实际源状态**可产生完全一致的数值观测。它们的不可信二进制码字须有汉明距离至少 `2k+1`，否则两半径 `k` 汉明球交叠。这给出 `n>=2k+1`；更大的 E 继续成立。
3. 选择可信 `a` 后，同一 `a` 纤维只剩两个可能的来源标签类 `b=0,1`。用 `0^(2k+1)` 或 `1^(2k+1)` 编码 `b`，它们距离 `2k+1`，可纠正 `k` 次任意翻转。先结合可信 `a` 恢复完整 `L`，再用 R284EM 的同标签无混淆定理恢复源索引。达到下界。

这个结论的最优量词是：**可信旧位只允许由两位 R/W/RW 不变来源标签 `(a,b)` 确定，且它本身可靠**。对任意随源索引变化的其他单比特旁路、不可靠旧位、随机噪声或其他更新群，不据此推断同一最优性。

## 信息守恒与资源比较（原误差 E=8656）

| 可信正确来源位数及内容 | 另需容错存储 n(k) | k=1 时另需位数 | 不同可靠性资源的总原始位数 |
|---|---:|---:|---:|
| 0 | 3k+2（R284EM） | 5 | 5 |
| 1，旧位 a | **2k+1** | **3** | 1 个可信位 + 3 个可翻转存储位 |
| 2，旧位 a,b | **0** | **0** | 2 个可信位 |

“从5位变为3位”只是降低**可翻转存储**容量，代价为保留1位错误率归零的可信旧来源信息。不能把可信存储与普通可翻转存储的位数当作相同成本。若旧位也可能翻转，重新按 R284EL/R284EM 的误差模型编码；已知历史本身不会恢复旧位正确性。对于整个 R/W/RW 更新族，可信 `a` 不需刷新；更新影响源索引的第0/6号位，原来源位仍可使用。

与 BRC 的关系是一个精确定义的**来源纤维保真**示例：压缩 `(a,b)` 至 `a` 是在声明的数值端口、误差界和未来翻转族下经证明可用的压缩；门槛后的残余 `b` 必须以可靠度匹配的存储形式保留。这个定理的 Port 编码不自动嵌入进取 X6 原生坐标。
