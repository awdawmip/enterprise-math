## 关键增量

原 CRT 方法统计每个素数的局部空集/单例剩余类，再作联合计数。本轮证明这两种局部计数都有数字/赋值闭式。因此所有 `k>=2` 的完整 `H_k mod 4` 已可精确判定，不能再把这项计算问题作为尚未完成的任务。

反射对的奇数贡献在模 4 下不能丢弃。`k=449` 时只有 `N_223,N_225` 为奇数，而中心 `N_224` 是 `0 mod 4`，最终 `H_449=2 mod 4`。已经用原枚举器和新公式对全部 449 列作了精确对照。

真正剩余的结构问题是非中心奇列何时存在、能否始终限于最近邻，以及最近邻条件对应的参数族。定位猜想目前开放，见 `THEOREM.md` 第 9 节；既有扫描只作为线索，不是普适定理。

## 复算

仅需 Python 标准库。在本目录执行：

```bash
python compressed_counts.py 449 --modulus 4
python verify_compression.py
```

第二条会更新 `verification.json` 和 `k449_comparison.json`，并打印核验摘要。已执行范围：原 CRT 全列对照 `2<=k<=128` 及 `k=449`；203 张独立局部直方图对照；`2<=k<=10` 全周期实际二项式整除对照。本次完成执行耗时约 59 秒，该数值只是运行记录。
