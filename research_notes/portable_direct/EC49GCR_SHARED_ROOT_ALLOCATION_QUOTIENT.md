## 1. Root-independent allocation
Let P be a finite port set, c_p positive integral capacities, E_j nonempty supports, and v_j nonnegative integral legal prefix counts, i.e. h_v(U)=c(U)-sum_{E_j subset U} v_j >=1 for every nonempty U. Define h_v(empty)=0. The GCO/GCQ network with no forced root, source->class capacity v_j, class->supported port M=1+sum c, port->sink c_p, has maximum flow sum v: its cut value minimized at fixed port side U is sum v+h_v(U), and U=empty attains sum v. Thus all source-class edges can be saturated simultaneously. Extract an integer allocation A_jp>=0 supported on E_j, with row sum v_j and column sums <=c_p. Let z_p=c_p-sum_j A_jp. One allocation suffices for every nonempty root E, not only a root from the support-class list.

## 2. Exact root quotient
For every U subset P,
 h_v(U) = sum_{p in U} z_p + sum_{j:E_j not subset U} sum_{p in U} A_jp.
Proof: substitute c_p=z_p+sum_j A_jp, and cancel the full row sum v_j for E_j subset U. This is an identity on all cuts, including empty, and not just at an optimizer. It preserves the observation h_v, the rooted minimum credit, every rooted optimal port side and the canonical least rooted side. It does not identify distinct labeled allocations or purport to preserve physical state.

Build a root-independent directed quotient graph with ports and auxiliary class nodes, port p->sink capacity z_p, port p->class j capacity A_jp when positive, class j->every p in E_j capacity M, then force E by source->root port M. At fixed rooted U a class with E_j not subset U must be outside (an M edge would cross), paying sum_{p in U}A_jp; an inside-supported class can be inside at zero cost. Every minimum cut avoids M edges since the full port side costs sum z <=sum c. Therefore its value is exactly lambda_v(E)=min_{U superset E}h_v(U), rather than sum v+lambda_v(E). Residual source reachability gives the least source side and its port projection is the least rooted optimum: every rooted optimum has an extension attaining its cut value, and residual reachability belongs to every minimum source side. This proves allocation-choice invariance of both value and canonical port witness.

Classes with v_j=0 can be dropped. Singleton support classes contribute zero to the second sum for every U and can also be dropped. For E_j={p,q}, replace the class node by arcs p->q capacity A_jp and q->p capacity A_jq (drop zero arcs). For every U this exactly reproduces the penalty: if both or neither are inside no arc crosses; if only p is inside the penalty is A_jp, and symmetrically. Higher arity retains the auxiliary node to preserve joint support rather than counting multiple outside endpoints. Parallel arcs can optionally be merged, not used in this replay. A single reusable quotient topology per state and fresh root forcing suffices; root-specific flows need not be cached.

An integer zero-start root query needs at most lambda_v(E) successful augmentations, since each increases flow by >=1; lambda_v(E)<=sum z=sum c-sum v. A common baseline flow once per state plus these query augmentations is an alternative to one GCQ flow certificate per root. This bound is value-sensitive, not a bit-complexity bound; standard sparse Edmonds-Karp retains polynomial graph-size complexity. Storage of sparse A plus shared incidence graph is O(|P|+k+sum_j|E_j|) entries (plus integer bit lengths), with root query working graph of the same order. This is a representation bound; the replay uses dense per-class allocation rows for convenience and does not measure actual bytes.

## 3. Root-independent sibling update
For legal sibling counts w on the same universe, trim each row of A by (v_j-w_j)_+ along existing positive allocation entries. This leaves a feasible unrooted flow of value sum_j min(v_j,w_j). In the new unrooted allocation network the maximum is sum w by section 1. Therefore the exact amount still required is Pplus=sum_j(w_j-v_j)_+ and at most Pplus successful integer augmentations are needed to repair the shared allocation. This one update serves every root in the sibling. Root-specific flow materialization, root-specific certificate storage and forced root capacity changes are unnecessary for this alternative. Retain the resulting allocation, not just its total flow or slack sum: the rooted least cut may change even at equal credit, as GCQ shows. The old GCP cut-reuse test remains independently applicable and can short-circuit some root queries. Its joint integration is not benchmarked here.
