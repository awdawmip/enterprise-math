## Precise model and theorem

Let S_0,...,S_{m-1} be an ordered family of **three-element** subsets of the six named native axes {0,...,5}; write h_t in Z^6 for the 0/1 incidence vector of S_t. Assume |S_t intersect S_{t+1}| >= 2 for 0<=t<m-1. This holds for the candidate named-Port word P_0,...,P_m, P_m=P_0, where each consecutive pair of 2-Ports shares exactly one axis and S_t=P_t union P_{t+1}: successive supports both contain the intervening Port P_{t+1}. These are composite three-support events, NOT primitive P000 three-force closure.

Set L=sum_t Z h_t and H=sum_t h_t.

**Theorem HP1 (2-saturation for any Port-adjacent support family).**

    L intersect 2 Z^6 = 2 L.

In particular:

    H belongs to 2L  iff  H has all coordinates even.

For any legal closed named-Port history, R762HO's obstruction to zero BRC displacement on an odd number k of complete repetitions is **exactly coordinate parity**, with no further hidden integer-lattice mod-2 class. Thus if H has an odd coordinate then Z_k=0 for every odd k; if H has all coordinates even then Z_k>0 for every sufficiently large odd k, using the constructive integer-lattice argument already established in R762HO. This does not assert that Z_1>0 for every coordinate-even word.

## Proof of HP1

Let D be the integer span of the consecutive differences h_t-h_{t-1} for t=1,...,m-1. Since consecutive supports are 3-subsets sharing at least two labels, each nonzero difference equals e_a-e_b for two distinct native axes a,b.

Make an undirected graph G on the six native axes, with edge {a,b} for each such nonzero difference. The integral lattice generated by its oriented edges is exactly

    D = {d in Z^6 : sum_{i in C} d_i = 0 for every connected component C of G}.

To see this, the component-sum equations are necessary for every edge difference. Conversely, choose a spanning tree of each component; integer flow along its tree edges represents every integer vector whose sum over that component is zero. Therefore D is saturated in Z^6 and, specifically, D intersect 2 Z^6=2D.

Every h_t differs from h_0 by an integer combination of consecutive differences, and conversely every difference is a combination of the h_t. Hence

    L = Z h_0 + D.

For x in L intersect 2Z^6, write x=a h_0+d, a in Z, d in D. Summing its six coordinates gives sum_i x_i = 3a because each edge difference has total coordinate sum zero and h_0 has exactly three ones. The left side is even, so a is even. Consequently d=x-a h_0 has even coordinates. Since D intersect 2Z^6=2D, write d=2d' with d' in D. Then x/2=(a/2)h_0+d' belongs to L. This proves L intersect 2Z^6 subset 2L; the reverse inclusion is immediate. QED.

**Constructive certificate:** If H is coordinate-even, m is even because sum_i H_i=3m. Then b=H/2-(m/2)h_0 is integral, and its sum over each component C of G is zero: the count |S_t intersect C| is independent of t. Sending the integer b-coordinates along each component's spanning tree produces edge-difference coefficients, hence explicit integer a_t satisfying H/2=sum_t a_t h_t. These are positive-weight source counts, not cancellation of BRC mass.
