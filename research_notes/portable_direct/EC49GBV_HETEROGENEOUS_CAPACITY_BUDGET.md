## 1. Exact reformulation and the obstruction to the uniform-budget law
Let X be actual labels with nonempty masks and nonnegative reward v_x, positive integer base capacities c_i, nonnegative integer increments h_i. Let D be GBU's singleton dummy labels at maximum capacities; each dummy e has nonnegative release cost a_e. D is independent in the strict Hall matroid M at c+h. A retained actual set I with released dummy set R is feasible iff I union (D minus R) is independent in M. Write K=D minus R, C(K)=a(D)-a(K), P(I)=v(I). The budget-B maximum P among independent I union K with C(K)<=B is F(B). A nonnegative-reward feasible optimum may be extended to a basis without increasing C or decreasing P; D is itself feasible at B=0. Zero-cost dummies can be released unconditionally and zero-reward actual labels omitted for computing values. Retain their original identities separately if future label queries matter. Below assume positive costs and positive rewards after these reductions. All proofs allow finite real weights; exact implementation uses integers/rational comparisons.

Independent singleton example: each of n ports has c_i=1, h_i=1 and one actual target solely at i. Its retention requires releasing the unique dummy of that port, and then it can be retained. This is precisely 0-1 knapsack with costs a_i and rewards v_i. Therefore the unequal-cost version is weakly NP-hard (standard knapsack), unlike GBU's unit-cost rank law. With costs (2,3), rewards (3,4), at budget 2 the unique optimal actual set is {1}, at budget 3 it is {2}. No nested family of globally optimal actual labels, nor single ordered-prefix solution for every budget, exists in general. The same obstruction defeats a universal common allocation chain. This is a restriction of the exact GBU observer, not a changed Hall feasibility definition.

## 2. Exact supported frontier by a parametric greedy order
For lambda>=0 define H(lambda)=max over independent I union K of [P(I)-lambda*C(K)]. It equals max matroid weight under scores v_x on actual labels, lambda*a_e on dummy labels, minus lambda*a(D). Greedy is exact (prefix ranks, GBR/GBU). For every feasible budget solution P<=H(lambda)+lambda*B.

For lambda>0 only actual-dummy relative positions can change as lambda increases; actual labels are sorted by descending v, dummies by descending a, each with fixed internal tie order. Start at lambda=0+ with all actuals before all dummies. End with all dummies before actuals, hence C=0. The finite breakpoints are lambda=v_x/a_e. At each breakpoint move tied dummies ahead of tied actuals by adjacent swaps; all intermediate orders remain nonincreasing in the combined scores at that lambda. There are at most |X||D| crossings in total, and each pair crosses once.

Adjacent swap lemma: swapping two adjacent elements x,e in a greedy order can change the selected basis only by swapping x for e (or leave it unchanged). Greedy inclusion is the difference of two successive prefix ranks. Every prefix set is unchanged except the one ending at the first swapped position; the two affected increments sum to the same value. Therefore if a change occurs the earlier selected label is replaced by the now-earlier label; all others are unchanged. On this path, every changed swap replaces an actual label x by a dummy e of equal score v_x=lambda*a_e. Consequently cost C decreases by a_e and reward P decreases by v_x. All intermediate bases at the breakpoint maximize the same exact Lagrangian. This yields a monotone cost/reward path of supported optima, not all nondominated integer optima. The initial basis is optimal at lambda=0, and the final basis has C=0. If the initial basis is feasible at B, it is already exact. Otherwise the path contains a first changed swap that crosses the budget.

## 3. One-exchange certificate and error interval
Let (C_-,P_-) be the state immediately before that swap, and (C_+,P_+) the state immediately after, so C_+<=B<C_-. Let x be the removed actual label and e the inserted dummy. Then C_- - C_+=a_e, P_- - P_+=v_x, lambda=v_x/a_e. The latter state is a genuine feasible allocation, and
  P_+ <= F(B) <= U(B)=P_+ + lambda*(B-C_+) < P_+ + v_x.
All arithmetic may be exact rational. The upper bound is from greedy optimality at lambda, the strict last inequality from B<C_-. U(B) is the fractional interpolation of the two supported states; indeed it is the optimum of the convex relaxation that mixes feasible independent sets at average cost <=B: the mixture of the endpoints attains U(B) and the same Lagrange bound proves optimality. No fractional physical allocation is claimed. If weights are integers, floor U(B) is a valid exact upper bound. If P_+=floor U(B), the integer optimum is certified without extra search. For weighted deletion cost total v-F(B) the interval reverses endpoints. All original masks, label identities and actual allocation are kept; this is a bounded observer of optimal reward, not a sufficient state for arbitrary future operations.

The brute replay below checks this certificate against all independent actual/dummy subsets on small models. It also verifies the adjacent-swap locality and equal-score invariant. The explicit implementation recomputes greedy from each order, not an incremental matching executor. With GBU/GBR capacity-level independence oracle, the path can be traversed using at most 1+|X||D| greedy passes plus sorting and order maintenance; each pass checks at most |X|+|D| labels. If implementing by re-sorting at all breakpoints, also count O(|X||D|*(|X|+|D|)*log(|X|+|D|)) order work, and O(|X||D|) stored ratios if all are materialized. These bounds are in expanded dummy size. ## 4. Two consequences (symbolic, not yet implemented)
(a) For a fixed actual subset A, GBU proves r_R(A)-r_0(A)=r_{L_A}(R), L_A=((M/A)|D)^*. To obtain a specified rank gain k at minimum release cost, select the k cheapest independent dummy labels in L_A by increasing-cost matroid greedy; if k>rank L_A it is unattainable. Any R reaching k contains an independent k-subset, so nonnegative costs justify restriction. Rank tests can use the GBU contraction formula. This is exact for fixed unweighted rank even with nonuniform costs. It does not assert the same cheapest chain for every actual subset/prefix simultaneously.

(b) The one-exchange gap gives a value PTAS for heterogeneous costs in the explicit finite matroid representation. For epsilon in (0,1), set t=ceil(1/epsilon). Enumerate all choices H of at most t actual labels. If the optimal set has fewer than t labels, one enumerated H is the whole optimal set; test it by minimum-cost completion (maximize kept dummy cost greedily in M/H), and keep the best feasible result. Otherwise some H is its t highest-reward labels. Require H, contract H, discard all remaining actuals of reward greater than min_{x in H} v_x, retain tied labels. If H is not independent at maximum capacity or its minimum release cost exceeds B, skip it. For the correct H neither occurs. The same breakpoint argument applies in the contraction even if D is not independent there: at lambda large greedy maximizes kept dummy cost, so minimum feasible release cost is attained, and the path must reach budget B. Fixed reward v(H) adds to both bounds. The residual gap is at most min reward(H)<=OPT/t. Thus taking the best feasible output of all guesses gives reward >=(1-epsilon) OPT. The runtime is polynomial in explicit finite input for fixed epsilon (O(|X|^t) guesses times a polynomial path construction); this is not an FPTAS or a measured speedup. For each chosen solution one can recover the actual retained and released labels and verify original strict Hall feasibility by GBQ/GBS. A small absolute error in retained reward need not yield a small relative error in deletion cost.
