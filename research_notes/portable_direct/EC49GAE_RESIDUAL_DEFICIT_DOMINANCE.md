## Theorem and proof

Use GAD's finite distinguishable population S, fixed binary unit-cost physical observations, partition B_i, nonnegative weights w, budget k. Define total weight W(C) and deficit E_d(C)=W(C)-V_d(C), with E_d(empty)=0. For C' subset C and d' >= d >=0, E_{d'}(C') <= E_d(C): restrict an optimal tree on C to C', delete constant observations, retain all short identified states still in C', and possibly identify more. Every missing target in the restricted tree belonged to the original missed set. This proof includes zero-weight competitors.

For a block chain store (M,C,L), occupied absolute slots M, exact residual C, and accumulated lost weight L=sum over peels P at slot t of E_{k-t}(P). Equal keys (M,C) keep minimum L. Permit gaps in slots, and permit empty global residual. Let t=max M (0 for empty); after merging disjoint masks by union and adding losses, the optimal global deficit equals the minimum of
 L + min( e_stop(C), min_{initially mixed q} [ E_{k-t-1}(C intersect q) + E_{k-t-1}(C minus q) ] ),
where e_stop(C)=W(C) if |C|>=2, zero otherwise. Omit inner mixed option if t=k. Unlike GAD the mixed option permits constant q on C. The relaxation is exact for unrestricted capacity: GAD's optimal tree supplies an admissible contiguous nonempty-residual profile, yielding one inequality. Conversely execute profiles in slot order, moving earlier to remove gaps, attach optimal conditional trees to peeled branches, and skip constant queries on the actual residual (including the last peel if it exhausts the population). Every surviving branch has at least the assigned budget. At interruption execute the mixed query if informative, otherwise use its nonempty conditional tree directly. Empty residual contributes no missed weight. At an unresolved terminal complete the tree arbitrarily. Thus actual missed weight is no larger than the profile value, proving equality. Nonnegative weights ensure no penalty from earlier identification.

Dominance: at the same local recursion domain and earliest slot, or same set of merged blocks, discard record (M2,C2,L2) if M1 subset M2, C1 subset C2 and L1<=L2. Any external disjoint slot choice remains compatible; merged residual only shrinks, maximum occupied slot cannot increase, and every terminal deficit (including each fixed mixed query option) is monotone in the required direction by the restriction lemma. For the mixed option its previously legal budget remains legal. Hence minimum unchanged. This works recursively because prepending the same peel adds a common loss and slot, preserving dominance. Unlike using credit alone, loss accounts for removed targets. Both allowing noncontiguous masks and allowing constant/empty tails are essential to this proof; no claim of preservation of GAD's restricted no-mixed-spine strategies in all populations. Exact residual labels remain unless this one-sided order applies. This is a residual-fidelity compression via an explicit loss observer, not an equality of raw states or a new BRC foundation result.
