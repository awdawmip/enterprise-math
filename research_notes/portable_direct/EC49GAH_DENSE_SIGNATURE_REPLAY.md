## Exact conditional quotient and witness transport

Let S be a finite distinguishable population with fixed binary unit-cost physical observations Q. For an ordered subset I=(i_0,...,i_{n-1}) of surviving state labels, pack every observation mask into n dense bits, remove constant masks, identify a mask p with its complement f XOR p (f=2^n-1), and sort the distinct representatives min(p,f XOR p). Call the resulting tuple sigma(I). A cache key is (n,sigma(I),d) for remaining depth d. State order is retained; no claim of full permutation canonicalization. The equivalence holds only for the fixed-observation, complete-identification, unit-cost observer and its budgeted missed-set/weighted objectives.

Theorem: the key determines the full dense minimal missed-set antichain L_d and a dense witness for every member. For any other ordered population with identical key, each witness lifts to a physical decision prefix with exactly the same dense missed set. For arbitrary nonnegative weights transported in the same state order the exact optimal deficit is unchanged.

Proof. For n<=1 the frontier is {empty}, and for d=0,n>=2 it is {all}. Otherwise each effective physical observation induces a split {a,f XOR a}. Complement only exchanges answer labels. For either branch, restricting each signature mask to that ordered subset and packing again yields its exact signature: previously constant masks remain constant, and previously complementary masks restrict to complementary masks. Thus child keys depend solely on the parent key. Apply GAG's union/minimality recurrence, retaining one generating triple (a,u,v) for each surviving loss mask, with u,v the dense child loss masks. A union is lifted from disjoint branch populations, so exact loss membership is preserved. When an actual physical query is required, choose a representative whose restricted packed mask is either a or f XOR a. In the latter case exchange the two recorded child subtrees. Continue recursively with the corresponding surviving ordered labels; the depth decreases. Every generated tree prefix therefore has the same loss mask, with singleton leaves identified and unresolved leaves at exhausted depth. It extends to a complete tree because Q separates the original population. Conversely any physical tree maps to such dense splits. Hence attainable minimal loss masks and representative recovery are exact. No equality of physical state identities or stronger observables follows.

A second exact cache is local to one physical query table and keyed by the actual ordered subset I; it stores sigma(I) and the physical query index and answer orientation for each split. Since the same physical table and surviving ordered labels determine every representative, repeated requests may reuse it. This cache must not be shared between unrelated physical query tables without their own identity/map. It preserves actual answer labels, not only branch counts.
