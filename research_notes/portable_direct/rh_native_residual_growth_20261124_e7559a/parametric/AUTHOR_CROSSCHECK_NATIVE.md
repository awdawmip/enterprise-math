1. **累计背景及单位。** 对 `κ_n=nΔ²(n log n)` 作有限移项，内部项全部消去，得到 `Σ_(j≤n)κ_j=n g_(n+1)−(n+1)g_n=n(n+1)log(1+1/n)`。n=1 时为 `2log2`，因此 `E*_1=−2log2`，单位接缝保持。
2. **背景改进。** `δ_n=Σκ_j−n=∫_0^1 n(1−t)/(n+t)dt` 递增至1/2。差分为 `∫_0^1 t(1−t)/[(n+t)(n−1+t)]dt`，所以上界 `1/[6n(n−1)]` 正确。帽内 n≥L+1 与 `Σφ=h/2` 给 `K_p≤h/[12L(L+1)^2]`。层权 h³/X² 与 `Σh≤X` 给 `Cκ≤H²/[12X^(3/2)(X+1)^2]`，没有丢失 X 因子。
3. **三种残差的方向。** `Aψ=Aθ+C_pp` 与 `Aψ=E*+δ` 中两个补偿都递增。因此 `R(Aψ)≤R(Aθ)≤R(Aψ)+Q`、`R(Aψ)≤R(E*)≤R(Aψ)+K` 的方向及其层推论正确。直接控制原三点矩可使用有利的高次幂符号；回到普通素数目标时需准确付回 Q。
4. **池改变时的稳定性。** 令 `F=E_D−E*`，局部累计包络 B 的增量为 ε_n。F+B 与 −F+B 都递增。先由 B↑得 `R(E_D)≤R(E_D+B)+ρ`，再由 F+B↑得 `R(E_D+B)≤R(E*)`；交换 D 与 Λ即得另一方向。准确系数1的 `|R(E_D)−R(E*)|≤ρ_p` 成立，且只使用包内源误差。历史差是常数，自动被 T 与 R 消去；无须池边界一致。
