# 二幂窗口、二幂长度与完整整数桥接

日期：2026-11-28（Asia/Hong_Kong）。作者：EM-DIRECT-E7559A / TASK_RESEARCH。

本稿延续第7轮 Source `0e5235516cd970ce846b642549fee6d194f18ae3` 的二幂长度入口，在固定 X6 轴上的辅助标量观察范围推导。原完整整数背景、单位、合数和窗口端点保留。本文为作者解析证明，未形成独立 Review。本轮最后加强为只取普通素数正亏缺的版本。

## 1. 新问题及精确边界

前驱证明所有充分大整数 X 上的 K_theta(X)=X^{o(1)} 与 RH 等价，并特别保留了窗口位置量词。本文证明，可以进一步只检查 X=2^k。新增依据是逐尺度二分均值控制，以及窗口之间原统计没有看见的准确整数源跳跃。仅由前驱把各长度合成一个谱隙的方式，不能删去窗口位置量词；这里给出新的完整论证。

定义 theta(y)=sum_{p<=y} log p，F(n)=n-theta(n)。对 X=2^k、k>=1，令 I_k={X,...,2X-1}，以及

\[
J_k(d)=\sum_{u=X}^{2X-1-d}[F(u+d)-F(u)]^2,
\qquad
K_k=\max_{d=1,2,4,\ldots,X/2}\frac{J_k(d)}{Xd}.
\tag{1.1}
\]

另定义真正定向的统计

\[
J_k^+(d)=\sum_{u=X}^{2X-1-d}[F(u+d)-F(u)]_+^2,
\qquad K_k^+=\max_{d=1,2,\ldots,X/2\atop d\text{为二幂}}
\frac{J_k^+(d)}{Xd}.
\tag{1.2}
\]

正部在完整区间的普通素数质量和整数背景作差以后形成。内部统计仍保留全部允许的整数中心 u。它不包括横跨 2X-1 到 2X 的一步。

## 2. 二分均值的离散临界嵌入

**引理 2.1。** 设 h=2^k、k>=1，实向量 z=(z_0,...,z_{h-1})，并置

\[
\mathcal K(z)=\max_{d=1,2,\ldots,h/2\atop d\text{为二幂}}
\frac1{hd}\sum_{i=0}^{h-1-d}(z_{i+d}-z_i)^2.
\]

则对每个 i，

\[
|z_i-\bar z|\le\frac{k}{2}\sqrt{h\mathcal K(z)},
\qquad
\max_i z_i-\min_i z_i\le k\sqrt{h\mathcal K(z)}.
\tag{2.1}
\]

**证明。** 任取标准二分树中的区间 Q={a,...,a+2d-1}，其左右半区均值 m_L,m_R 满足

\[
m_R-m_L=\frac1d\sum_{i=a}^{a+d-1}(z_{i+d}-z_i),
\]

\[
|m_R-m_L|^2\le\frac1d\sum_{i=a}^{a+d-1}(z_{i+d}-z_i)^2
\le h\mathcal K(z).
\]

任一子区均值与父区均值之差至多 sqrt(h K)/2。沿包含 i 的 k 层链望远镜相加，得第一式；两个点分别比较总体均值即得第二式。h=1 时方差和振幅皆零，可单独约定。证毕。

这里没有使用上一轮的无权合并 sum_d J(d)。保留每个长度各自的除数 d 是取得端点控制的关键。log h 支付属于从均方到单点的这一步，不改变前驱局部 Green 根预算无额外 sqrt(log h) 的结论。

### 2.2 一侧嵌入：保留方向的平移平均链

对任意 h=2^k 的 z，把 K 定义中的差分平方换成差分正部平方，记为 K^+(z)。则对全部 0<=i<j<h，

\[
\boxed{(z_j-z_i)_+\le(k+1+\sqrt2)\sqrt{hK^+(z)}.}\tag{2.2}
\]

当 i=0、j=h-1 时，可以改用更锐常数 k。

**证明。** 在任何标准或平移后的长 2d 二幂区间内，

\[
m_R-m_L\le\frac1d\sum_{v\in L}(z_{v+d}-z_v)_+
\le\sqrt{J_+(d)/d}\le\sqrt{hK^+}.
\]

于是沿区间最左分支有 m_I-z_left<= (log_2 |I|)sqrt(hK^+)/2，沿最右分支有 z_right-m_I 同界。注意这两式只取各自允许的方向，未把一侧支付当作绝对值。

对任意 i<j，取 d=2^floor(log_2(j-i+1))，A=[i,i+d)、B=[j-d+1,j+1)。令 g=j-i+1-d，0<=g<d。若 g=0，两条端点链已给所需界。否则把 g 分解成不同二幂 delta，逐次将长 d 的窗口向右平移 delta。所有中间窗口都在 [i,j] 内。每一步

\[
m_{Q+\delta}-m_Q\le\sqrt{J_+(\delta)/d}
\le\sqrt{hK^+}\sqrt{\delta/d}.
\]

由于 sum_{delta bit of g}sqrt(delta/d)<sum_{r>=1}2^{-r/2}=1+sqrt2，合并两条端点链得到(2.2)。全块首尾情形 g=0 直接得到常数 k。证毕。

## 3. 真实整数源准确补上窗口之间的一步

对一般整数序列 F，定义桥跳跃

\[
b_{k+1}=F(2^{k+1})-F(2^{k+1}-1).
\]

由引理，对于 2^k<=n<2^{k+1}，

\[
\boxed{
|F(n)|\le |F(2)|+\sum_{j=1}^{k-1}|b_{j+1}|
+\sum_{j=1}^{k}j\sqrt{2^j K_j}.
}
\tag{3.1}
\]

证明只需逐块连接左端值：块内振幅不超过 j sqrt(2^j K_j)，块末到下一块左端的差准确为 b_{j+1}。最后一块从左端走到 n，使用同一个振幅界。

对 F(n)=n-theta(n)，因 2^{j+1}>=4 是合数，准确有 b_{j+1}=1。因此

\[
\boxed{
|n-\theta(n)|\le 2-\log2+(k-1)
+\sum_{j=1}^{k}j\sqrt{2^j K_j},
\quad 2^k\le n<2^{k+1}.
}
\tag{3.2}
\]

若 M_k=max_{1<=j<=k}K_j，则进一步

\[
|n-\theta(n)|\le 2-\log2+k-1
+(2+\sqrt2)k\sqrt{2^k M_k}.
\tag{3.3}
\]

此处用了 sum_{j<=k}j2^{j/2}<=k2^{k/2}/(1-2^{-1/2})。常数不求最佳。

在一侧版本中，前面各完整块用锐的首尾常数 j，最后一个部分块用(2.2)，得到

\[
\boxed{
F(n)\le 2-\log2+(k-1)
+\sum_{j=1}^{k-1}j\sqrt{2^jK_j^+}
+(k+1+\sqrt2)\sqrt{2^kK_k^+},
\quad 2^k\le n<2^{k+1}.
}\tag{3.4}
\]

对累计 von Mangoldt 误差 n-psi(n)，桥跳跃准确为 1-log2，也可作同样接续。普通素数版本的桥跳跃 1 正是保留合数背景产生的信息。一侧上界实际只需要每个桥跳跃不超过 1；完整整数背景减去非负素数质量已经提供这项上界。本处仍记录二幂边界作为合数时的准确值，以区分原源事实与一般序列的未付桥漂移。

### 不控制桥跳跃会发生什么

对任意常数列 c_k，令 F 在每块 I_k 内恒等于 c_k。于是全部 K_k=0，但 F 可以增长任意快；未观察跳跃为 c_{k+1}-c_k。故对于任意源类，桥不能省略。本文没有将实际普通素数源替换成任意块常数列；该例只显示内部统计所遗漏的信息及(3.1)的修复位置。

## 4. 只取二幂窗口和二幂长度的 RH 等价判据

**定理 4.1。** 对(1.2)的真实普通素数正亏缺统计，以下三项等价：

\[
\boxed{
\mathrm{RH}
\quad\Longleftrightarrow\quad
\forall\varepsilon>0,\ K_k^+\ll_\varepsilon 2^{\varepsilon k}
\quad\Longleftrightarrow\quad
K_k^+\ll k^2.
}
\tag{4.1}
\]

无符号 K_k 也满足同样等价式，但(4.1)已经只需要普通素数正亏缺。

**从定向次多项式统计到 RH。** 由(3.4)，若 K_j^+<=C_eta 2^{eta j}，则

\[
F(n)\ll_\eta (\log n)n^{(1+\eta)/2}.
\]

因为 eta>0 可任意选择，对每个 epsilon>0 均有

\[
\theta(n)\ge n-O_\varepsilon(n^{1/2+\varepsilon}).
\tag{4.2}
\]

对实 x>=2，theta(x)=theta(floor x)，x-floor x<1，所以同一下界成立。高次素数幂非负，psi>=theta，故 x-psi(x)<=x-theta(x)；这个方向不需另付素数幂绝对值费用。

固定任意 a 属于 (1/2,1)，选择 C 使 G(x)=Cx^a-[x-psi(x)]>=0 对全部 x>=1 成立。对 Re s>1，Stieltjes 分部积分给

\[
\int_1^\infty G(x)x^{-s-1}\,dx
=\frac{C}{s-a}-\frac1{s-1}-\frac1s\frac{\zeta'(s)}{\zeta(s)}.
\tag{4.3}
\]

右侧在每个实 s>a 处全纯：s=1 的两个主部准确相消；正实 s 处 zeta 无零点（s>1 由正项级数，0<s<1 由正的交错 eta 级数及负的分母 1-2^{1-s}）。

使用以下非负 Mellin 事实：非负局部可积函数的 Mellin 积分若具有有限实收敛边界 sigma_c，则在实 sigma_c 必有奇点。其证明可直接把变换在 sigma_0>sigma_c 处沿左方向作 Taylor 展开；系数为非负的 log x 矩，若实边界也有全纯邻域，Tonelli 与该 Taylor 级数会推出在边界左侧的积分收敛，矛盾。该论证也覆盖 abscissa=-infinity 的平凡情形。

由于 G 初始至多 O(x log x)，其收敛边界不超过1；(4.3)在所有实 s>a 无奇点，所以边界至多 a。故该 Mellin 积分在 Re s>a 全纯。若 zeta 有 Re rho>a 的零点，则右侧在 rho 有非零留数 -m_rho/rho，矛盾。a 可任意趋向1/2，配合标准反射对称得到 RH。

**从 RH 到 O(k^2)。** 复用前驱已核对的 Selberg 估计 J_psi(X,d)<<Xd log^2X，1<=d<=X；整数长度下单位分段积分与离散中心统计准确接续。普通素数/高次幂分解仍给 J_theta<=2J_psi+576Xd。对 X=2^k 与全部 d=2^j<X 即得 K_k^+<=K_k<<k^2。O(k^2) 显然蕴含次多项式界。证毕。

使用的外部输入仍是 Languasco--Zaccagnini, arXiv:1212.5704v2, 式(22) 所载 RH 条件下 Selberg 界；原文由前驱实际核对，本轮重新定位同一输入。新证明不依赖最右实部是否被取得、不需要零点线性独立、不使用原几何端点采样的未决断言。

## 5. 对原研究目标的意义和成本

该定理把全位置充分均方输入的窗口起点也压到二幂，保留全体整数中心。它不把原实际层定向亏缺自动升级成无条件上界；(4.1)说明这里仍有准确 RH 强度。与每块只有恒定个 q* 锚点的开放问题相比，本统计在每个允许长度上读取全部中心，信息范围不同。

截至最大起点 X=2^K，共 K 个窗口、K(K+1)/2 组长度统计，内部差分的总项数准确为

\[
\sum_{k=1}^{K}\sum_{j=0}^{k-1}(2^k-2^j)
=(K-2)2^{K+1}+K+4.
\tag{5.1}
\]

它们只需完整源前缀到 2^{K+1}-1，另需这些已知复合整数边界的准确跳跃。前缀已给定后计算为 O(2^K K) 次差分/平方累加，空间可按一个窗口流式安排。普通素数取得、认证 log、输入表示长度、精度及结果恢复另计；没有端到端子线性声明。

### 5.1 短长度直接读成完整整数空段

对任何长度 d，正亏缺至多 d，故 J_k^+(d)/(Xd)<=d(1-d/X)。特别地，次多项式短长度本身不会造成该判据的幂次增长。

当 d<=log X 时，包内任何一个素数的 log 质量已经不小于 d。因此准确有

\[
J_k^+(d)=d^2 N_0(X,d),\qquad
N_0(X,d)=\sum_i(r_i-d+1)_+,
\tag{5.2}
\]

其中 r_i 是完整整数串 X+1,...,2X-1 中所有最大非素数连续段的长度，包含两端截断段。式(5.2)仍保留合数背景，且空段计数包含全部允许中心。它只在显示的短长度条件下成立；更长区间必须保留实际素数对数质量与同区间抵消。
