## 定理一：所有门槛的本原五次单位根首项

记 `F_m^(5)(N)` 为生成函数中 **全部四个本原五次单位根** 的部分分式贡献，不包括其他频率。定义

```
P5 = product(220,225,...,310)  (19 factors)
A5 = 1/(5^19 P5).
m = 5k+r, k>=0, r in {1,2,3,4,5}.
```

则对每个固定的 `m>=1`：

```
F_m^(5)(N) = A5*(k+1)*N^18/18! * V_r(N mod 5) + O_m(N^17),
```

其中 **无遗漏的五类精确有理向量**（位置顺序 N mod 5 = 0,1,2,3,4）为

| r | V_r |
|---|---|
| 1,3 | (306/43, -306/43, -1, 0, 1) |
| 2 | (2, -2, -263/43, 0, 263/43) |
| 4,5 | (2, -2, -1, 0, 1) |

每个向量非零、五项之和为零。全部本原五次根的最高极点阶恰为 19，故非平凡五周期以 `N^18` 阶出现。上式允许单独某个 `N mod 5` 上的五周期首项为零，并不影响整体非零与最小周期为 5 的结论。

### 证明

对非空 `I subset {0,...,4}`，设 `U_I=union_{j in I}S_j`。容斥项为

```
H_{I,m}(x) * product_{p in P\U_I}(1-x^p)^(-1),
```

其中 `H_{I,m}` 是受门槛约束的有限局部多项式。因此任一本原五次单位根 `q` 的极点阶至多等于剩余自由价格中 5 的倍数的个数。枚举全部 31 个非空 I：仅 `I={0}` 和 `I={1}` 的上界为 19，其他所有 I 至多 18；`S2` 至多 18，`S4` 至多 17，`S3` 至多 6。

令 `s=1-x/q`，令 `H_{j,m}(q)=sum_{sum_{p in Sj}n_p<m} q^(sum p*n_p)`。`S0` 的自由集合 `E0={219,...,314}` 含 19 个 5 的倍数，且在其他四个非零模5余数中，余数 4 多一个。于是其19阶 Laurent 首系数为

```
A0(q)=1/[5^19 P5 (1-q^4)].
```

`S1` 的自由集合 `E1={215} union {222,...,314}`，故相对首系数之比精确为

```
R(q)=lim_(x->q) [(1-x^219)(1-x^220)(1-x^221)/(1-x^215)]
    =(44/43)*(1-q^4)*(1-q).
```

于是19阶首系数是 `A0(q)[H0,m(q)+R(q)*H1,m(q)]`。

逐项对 `m` 求局部阈值母函数，利用 `q^5=1`、`1+q+q²+q³+q⁴=0`：

```
sum_{m>=1} H0,m(q) z^m
  = z/[(1-z)(1-z^5)]
  = z(1+z+z²+z³+z⁴)/(1-z^5)^2,

sum_{m>=1} H1,m(q) z^m
  = z/[(1-z)(1-z^5)(1-zq)(1-zq^(-1))]
  = z[1+(1+q+q^(-1))z+z²]/(1-z^5)^2.
```

从 `(1-z^5)^(-2)=sum_{k>=0}(k+1)z^(5k)` 精确读出：
- 所有 r 的 `H0,5k+r(q)=k+1`；
- r=1,3 时 `H1,5k+r(q)=k+1`；
- r=2 时 `H1,5k+2(q)=(k+1)(1+q+q^(-1))`；
- r=4,5 时 `H1=0`。

因 `(1-q)(1+q+q^(-1))=q^4-q²`，除去公共因子 `(k+1)A5`，每个本原五次根对应的首系数可写成

```
B_13(q)=1/(1-q^4)+(44/43)*(1-q),
B_2(q) =1/(1-q^4)+(44/43)*(q^4-q²),
B_45(q)=1/(1-q^4).
```

在 `Q[q]/(1+q+q²+q³+q⁴)` 中有

```
1/(1-q^4)=(1-3q-2q²-q³)/5.
```

以及对任意整数 j，

```
sum_(q primitive fifth) q^j = 4 if 5|j, else -1.
```

故直接计算 `sum_(q primitive fifth) q^(-N)B_r(q)`，即得到表中三个向量。非零 Fourier 分量对应真五周期；乘 `binom(N+18,18)=N^18/18!+O(N^17)` 完成证明。

## 定理二：截至 N^18 的最小成本残差模数恰为 60

对每个固定正整数 m，存在一个系数依赖 `N mod 60` 的准多项式 `Q_{m,60}(N)`，使

```
F_m(N)=Q_{m,60}(N)+O_m(N^17).
```

此精度下的**最小正整数定长周期模数为 60**：任何模数 `D` 若允许周期系数多项式逼近 `F_m` 且误差为 `O_m(N^17)`，必有 `60 | D`。

证明：全部价格落在长度101的整数区间，对于任意原根阶 d>=6，自由价格中 d 的倍数至多 `ceil(101/d)<=17`；受限局部多项式不增加极点阶。因而所有阶数至少19（即对系数产生 `N^18` 以上贡献）的根的阶数仅可能为 1,2,3,4,5。它们的部分分式展开截取次数至少18即给出模60表示。另一方面既有可复用定理对每个 m 均有非零二次（`N^47`）、三次（`N^31` 或 `N^30`）、四次（`N^23` 或 `N^22`）本原根分量，本轮证明五次（`N^18`）亦非零。不同单位根的指数-多项式序列在精度 `O(N^17)` 下不能互相替代（按有限 Fourier 平均隔离各指数频率），故必须同时包含各阶数，`lcm(2,3,4,5)=60`，得证。

此为“在截断精度 `O_m(N^17)` 下可用的最小模数”。不是声称完整未经截断的准多项式只有60周期；更高阶本原根将进入更低幂次，且完整60类系数表尚未展开。
