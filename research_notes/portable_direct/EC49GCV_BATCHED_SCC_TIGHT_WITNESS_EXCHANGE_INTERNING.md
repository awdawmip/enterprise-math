## 1. Batched recovery theorem
In a fixed final common allocation quotient G of a legal strict-Hall prefix, all vertices reach sink t. For a nonempty port root E of credit one, GCT identifies the smallest marked unit-bridge region D_e containing E. D_e comprises exactly the vertices that cannot reach t after deleting edge e, and its only outgoing edge in G is e: any outgoing edge to its complement different from e would give a path to t in G-e, a contradiction. The least tight port cut is U(E)=Reach_{G-e}(E) intersect P (GCS/GCT). Thus it is enough to use the induced graph H=G[D_e] without e, not the full graph.

Group deferred roots by that actual edge e, not by a merely containing tight cut. Condense H into its SCC DAG L. Let P(C) be the bit mask of original ports in SCC C. In reverse topological order define
 W(C)=P(C) OR (OR_{C->D} W(D)).
Induction over the DAG proves W(C) is precisely the port projection of the full reachable set from C. For any root E in this bridge group, put S(E)={C(p): p in E}. Then the exact least tight witness is
 U(E)=OR_{C in S(E)} W(C).
This preserves every labeled basis exchange E_j subset U(E), not just credit one. Different root supports sharing a bridge need not have the same least cut (GCU counterexample); equality must be certified by SCC signatures or resulting masks, never presumed from the bridge alone.

Optional stronger canonicalization: delete from S(E) every SCC reachable from another member of S(E). The resulting antichain is exactly the set of minimal SCCs of the reachable upward-closed set under the reachability order (C <= D iff C reaches D). Thus two such canonical signatures are equal iff the full SCC closure is equal. In the uncompressed GCR quotient, for a fixed deleted bridge, a reachable positive-row auxiliary vertex must be reached via an incoming port-to-class edge that was not deleted; every root is a port and there are no other incoming edges to an auxiliary vertex. Therefore the projected reachable port set determines the full reached auxiliary set as well. Canonical signature equivalence is consequently also equivalent to equal port witnesses in this specific quotient. The implemented replay instead caches raw distinct-SCC signatures and interns exact port masks; it does not yet minimize signatures by reachability.

Construction cost for one group with region n_e vertices and m_e edges: one induced adjacency construction, SCC passes, and DAG construction, O(n_e+m_e) graph operations if the region is enumerated directly (the replay checks all V vertices for membership). Bitset closure adds O((s_e+a_e) ceil(|P|/w)) word operations and O(s_e ceil(|P|/w)) storage for s_e SCCs and a_e condensation arcs; root classification, signature sorting, mask unions and requested output cost are separate. A general all-groups worst case can repeat work across nested regions. Singleton groups in the replay fall back to GCT BFS; no general performance claim for small groups.

## 2. Exact exchange-star quotient
Fix the final greedy residual basis counts B and exact least cuts U_i for each blocked class i. GCN/GCO join i to every selected basis class j for which E_j subset U_i. For a group I of blocked classes having equal exact port cut U, the neighbor set J(U)={j:B_j>0 and E_j subset U} is identical. Evaluate this set once. If J is nonempty, pick j0 in J and replace the complete bipartite incidence between I and J by the star joining each i in I to j0 and each other j in J to j0. Both have exactly the same connected components, so all combined components and GCN direct-sum/Pareto conclusions remain exact. The original labeled exchange predicate is reconstructed from U and B, not from the star edges. If J is empty, add NO edges: equal empty-neighbor witnesses must not merge distinct loops/classes. This distinction is essential for the finest block-preserving partition. All source support labels and prefix/basis distinction remain intact. The lease is for the final fixed state and component/exchange observation; arbitrary future mutations require revalidation.

For q equal witnesses and b positive basis classes the full class containment tests drop from qb to b, with at most q+|J|-1 star unions when J nonempty (including harmless self-unions if a class is on both sides). The actual implementation interns masks across bridge groups and across earlier nondeferred cuts. It retains the previous replay's direct labeled-exchange and complete independent-subset partition audits.
