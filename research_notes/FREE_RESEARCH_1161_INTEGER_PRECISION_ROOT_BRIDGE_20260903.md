## 2. Rational square-root precision cell theorem

For `x=p/q>0`, `p,q in N_{>0}`, and binary precision `m in N_0`, define

\[
\rho_m(x)=\left\lfloor 2^m\sqrt{x}\right\rfloor.
\]

Then

\[
\boxed{
\rho_m(p/q)
=
\operatorname{root}_2\left(
\left\lfloor \frac{p\,2^{2m}}q\right\rfloor
\right),
}
\]

where `root_2` is the existing natural-number floor square root.

Proof: put `y=2^m sqrt(p/q)`. For every nonnegative real `y`,

\[
\lfloor y\rfloor
=
\left\lfloor\sqrt{\lfloor y^2\rfloor}\right\rfloor.
\]

Indeed, if `k=floor(y)`, then `k^2 <= y^2 < (k+1)^2`; since the endpoints are integers,

\[
k^2\le \lfloor y^2\rfloor <(k+1)^2.
\]

The defining integer-root basin therefore returns exactly `k`.

Equivalently, `k=rho_m(p/q)` is certified by the denominator-cleared finite inequalities

\[
\boxed{
qk^2\le p2^{2m}<q(k+1)^2.
}
\]

Thus one finite square-root precision state consists only of an integer `k` plus an exact integer inequality certificate.

## 3. Exact precision projection and one-bit detail

The root cells form an exact projective chain:

\[
\boxed{
\left\lfloor\frac{\rho_{m+1}(x)}2\right\rfloor=\rho_m(x).
}
\]

Hence there is a unique bit

\[
\varepsilon_m(x)\in\{0,1\}
\]

such that

\[
\boxed{
\rho_{m+1}(x)=2\rho_m(x)+\varepsilon_m(x).
}
\]

This is exactly the existing binary precision decomposition at scale chain

\[
1\mid 2\mid 4\mid 8\mid\cdots.
\]

For rational `x=p/q`, the next detail bit is decided by one integer comparison:

\[
\boxed{
\varepsilon_m=1
\iff
q(2\rho_m+1)^2\le p\,2^{2m+2}.
}
\]

So the finite-precision square root is not a hidden real scalar. It is an integer state plus a sequence of locally certified binary refinements.
