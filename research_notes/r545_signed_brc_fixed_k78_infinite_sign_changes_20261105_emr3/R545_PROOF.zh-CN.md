# R545｜固定 k=7、8 的 signed BRC Toeplitz 行列式无限次双向换号定理

日期：2026-11-05（Asia/Shanghai）。分类：作者侧精确计算辅助证明，独立数学审阅待完成。

## 1. 对象、来源与定理

沿用冻结 R462 signed BRC 科学输入 commit 18783e01e3646c72b7aab3b16d3f565e83e6446f，以及已发表作者侧 R540 的 H=B 代数恒等式、R541 的有理生成函数和 R544 的复根隔离方法（不可变前沿 commit 13f87f5f3d5a1da6ffc64f5210c204d32ab269b6）。这是一项冻结模型内部的精确标量观察量研究；P000 与 ACTIVE 世界观保持原状。

设 k∈{7,8}，r=2k+1，Catalan 数 C_k = binom(2k,k)/(k+1)。对于整数 2≤t≤r，定义

\[
H_k(t)=\binom{r+t}{2t}[x^r](1-x)(1+x)^{2t}(1+x^2)^{r-t},
\]

其他 t 值定义为 0。令 D_0(k)=1，并令 D_m(k) 为 m×m Toeplitz–Hessenberg 整数矩阵 (H_k(3+i-j))_{0≤i,j<m} 的行列式。

**定理 R545**：对于 k=7 与 k=8 分别成立

\[
\#\{m\ge 0:D_m(k)>0\}
=\#\{m\ge 0:D_m(k)<0\}
=\infty.
\]

## 2. 有理阶数生成函数

继承 H=B 恒等式：H_k(t)=binom(r+t,2t) × Σ_{q=0}^{min(floor((t-1)/2),k)} binom(t-1,2q)4^q C_{k-q}。令 p_t=H_k(t)/C_k，d=2k-1，f_m=D_m(k)/C_k^m。由 Toeplitz–Hessenberg 展开：

\[
\sum_{m\ge 0}f_m z^m
=\left(1-\sum_{j=1}^{d}(-1)^{j-1}p_{j+2}p_2^{j-1}z^j\right)^{-1}.
\]

相关特征多项式及其有理尺度形式为

\[
P_k(X)=X^d-\sum_{j=1}^{d}(-1)^{j-1}p_{j+2}p_2^{j-1}X^{d-j},
\]

\[
Q_k(y)=P_k(p_2y)/p_2^d
=y^d-\sum_{j=1}^{d}(-1)^{j-1}(p_{j+2}/p_2)y^{d-j}.
\]

精确参数：k=7 时 C_k=429、p_2=2380、d=13；k=8 时 C_k=1430、p_2=3876、d=15。R545_VERIFY.py 从完整整数系数重新构造 Q_k，固定的六位有理小数圆心仅用于定义待核根盘。

## 3. 完整根隔离

R545_VERIFY.py 中每个圆盘半径 ε=1/1000。对每个有理复中心 c，取 Q_k(c+w)=Σ_{j=0}^{d} b_j w^j。程序用 Fraction 和 isqrt 构造复有理数模长的向下界 L 与向上界 U（步长 10^{-8}），并严格核验

\[
U(b_0)+\sum_{j=2}^{d}U(b_j)\epsilon^j<L(b_1)\epsilon.
\]

全部 28 个圆盘（k=7:13 个；k=8:15 个）均通过；左、右两侧的比值严格小于 1/50。全部 78+105=183 对圆盘由精确有理距离下界证明两两不交。Rouché 定理使每个盘恰有一个简单根，根盘数等于次数，因此覆盖所有根。

最大模根恰为每组前两个非实共轭圆盘中的根：

* k=7：中心 3.177694 ± 3.914665i。所有主导根在 y 尺度的模长严格大于 126026431/25000000 >5；所有其他根严格小于 3417839/1000000 <7/2。因此在 X 尺度主导模长 >11900，其余模长 <8330。
* k=8：中心 4.036005 ± 5.081137i。所有主导根在 y 尺度的模长严格大于 324400649/50000000 >32/5；所有其他根严格小于 1911693/500000 <39/10。因此在 X 尺度主导模长 >24806，其余模长 <15117。

两个主导盘均离实轴至少 ε，故主导根为非实单根。

## 4. 从共轭主导根到无限阶双向换号

所有根互异且非零。对上述有理生成函数作部分分式展开：

\[
f_m=\sum_{j=1}^{d} A_jX_j^m,\qquad
A_j=X_j^{d-1}/P'_k(X_j)\ne0.
\]

把两主导共轭根记为 X=ρe^{iθ}、其共轭，残数 A=|A|e^{iφ}。存在常数 B<∞ 使

\[
f_m=2|A|\rho^m\cos(m\theta+\phi)+R_m,\qquad
|R_m|\le B\tau^m,\quad \tau<\rho.
\]

可以取 τ=8330（k=7）或 τ=15117（k=8）。因主导根非实，e^{iθ}≠1 且 e^{2iθ}≠1。令 x_m=cos(mθ+φ)，等比级数的 Cesàro 均值给出平均 x_m→0、平均 x_m²→1/2。若最终所有 x_m≥−1/4，则 (x_m+1/4)(1−x_m)≥0 导出 x_m²≤(3/4)x_m+1/4，与第二均值相矛盾。若最终所有 x_m≤1/4，则 (1/4−x_m)(1+x_m)≥0 同样矛盾。故 x_m>1/4 和 x_m<−1/4 各无限次成立。R_m/ρ^m→0，最终不会改变两类子序列的符号。C_k^m>0，所以 D_m(k) 两种严格符号各无限发生，证毕。
