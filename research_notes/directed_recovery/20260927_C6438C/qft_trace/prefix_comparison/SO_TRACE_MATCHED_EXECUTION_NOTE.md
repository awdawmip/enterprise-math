# Actual matched prefixes: cheaper cold certificate, slower warm route

The single predeclared six-pair execution passed every numerical equality check. **The new SO route was slower in all six warm calculation comparisons.** The result is retained without rerunning or selecting timings. This is author execution evidence in shared context, not formal admission or an asymptotic simulation result.

The executed source is `6a0c553244df66005af4c66e2333e318ae831c9b0905cdaf952f4495221eed47`. The frozen design remains an accurate record of its compile-only pre-execution state; this separate note records the subsequent authorized run. Neither frozen policy/bank nor the old comparison source was modified.

## What was compared

Each `(N,a)=(21,2),(21,4),(65,3)` program uses `t=4`, epsilon `1/3` and positive history `1000`. After actual complete 61-column admission and the existing exact six-coordinate codec, both routes share one program's paid modular caches. Old and new certificate banks are built and recorded separately. An old-route prefix warmup is paid for each program. Each measured engine starts with an empty Gram cache. The two paired orders are old/new then new/old, serially in one process.

Every pair agrees in raw conditional plans, final positive mass, selected word IDs, charges, bits, all retained signed correlation matrices, the full actual observer stream and all scientific/policy counters. Different certificate IDs and cursor schemas are intentional. Both factory and inverse table instances remain warm: every measured run has zero newly computed modular columns and zero new column adder-digit replays. No complete output law, random sampling or new TV estimate is inferred.

## Concurrency limitation

The run had already started when a coordination request asked to wait for a sibling's serialization. It was not discarded or restarted. Filesystem metadata records this execution log creation at `2026-09-27 05:03:27.848615 UTC`, sibling one-window summary final write at `05:03:33.672162 UTC`, and this summary final write at `05:03:51.905513 UTC`. The sibling reported its native work and large JSON/gzip serialization complete at that final write, with no subsequent large-file read until this run ended.

Thus the beginning of the whole run overlapped the sibling's finishing work. No per-phase UTC trace or controlled process isolation was recorded, so this overlap cannot be quantitatively assigned to a route or subphase. The alternating order and unchanged arithmetic still make the observed regression useful, but the small experiment is not a controlled performance distribution. All original results are preserved.
