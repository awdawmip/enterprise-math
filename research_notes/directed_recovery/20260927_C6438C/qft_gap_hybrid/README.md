# Structural hybrid signed-gap observer

One actual bounded run combines previously executed endpoint formulas, a typed
interior divisibility-zero certificate, and the frozen direct difference formula.
All 31 historical signed answers agree. The new production cost is **36,970
digit replays**, comprising 3,790 endpoint, 32,987 direct and 193 routing digits.
With positive fresh verification and all paid failed-certificate replays, the
complete recorded total is **84,535 digits**. One shared native full-adder kernel
observation supplies columns for those replays; one core call is not the whole
cost.

For strict g>=1, 0<=k<g, R>=1 and 0<=r<R, the scalar answer is the sum of
(-1)^(bit_k(x)+bit_k(y)) over 0<=x,y<2^g with y-x=r modulo R. The new source
routes highest/lowest bits to the unchanged endpoint observer before doing any
new routing arithmetic. For interior bits it constructs U=2^k and divides U by R
through the actual typed runner. A zero remainder certifies that every signed
residue histogram cancels; the returned zero itself has a typed subtraction
receipt. Otherwise the unchanged direct observer computes both displacement
orientations. Inputs, signed answers and the external raw scale 4^-g remain
unchanged. Routing uses structure, not fixture indices.

The run contains 20 endpoint, ten direct and one zero request. Eight invalid
inputs and 15 certificate mutations were rejected; eleven mutations incurred
and retained complete fresh replay. Three disjoint runner streams preserve all
nested evidence and are charged once each. The two nonzero interior cases cost
9,799 and 23,356, including routing overhead of 42 and 126. The sole positive
interior-zero example has R=1 and costs 25. A mixed-route query sequence within
one observer was not executed. See hybrid_gap/HYBRID_EXECUTION_NOTE.md for the
complete table, limits and the metadata-only full cost readback.

The approximately 7.356-second whole-checker time is not a matched performance
benchmark. This result does not establish full-QFT or Shor dequantization,
arbitrary-mask contraction, bounded matrix-valued Gram state, or free order and
address discovery. No phase propagation or residual projection occurs in this
standalone scalar observer. The unchanged dependency algorithms retain their
original contracts.
