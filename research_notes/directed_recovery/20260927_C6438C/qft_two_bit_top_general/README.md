# Two selected sign bits, highest bit selected, arbitrary supplied modulus

The actual unique checker and complete author/peer saved-record reviews pass.
The bounded scope and measured cost disadvantage are retained in the frozen
evidence; publication and backup metadata are produced separately.

This unit implements an actual typed scalar signed-correlation observer for
`g >= 2`, `0 <= ell < k = g-1`, every positive supplied modulus `R`, and a
canonical residue `0 <= r < R`. It removes the predecessor's `2^ell | R`
admission restriction for this highest-selected-bit family. The proof and API
are TOP_BIT_GENERAL_MODULUS.md and top_bit_general.py; the schema is
`BRC_TOP_BIT_GENERAL_MODULUS_V1`. The raw normalization remains `4^-g`.

The two displacement orientations are split at half the full interval. Each
nonempty segment uses two neighboring degree-three floor-moment tables and
an exact combined integer division by three. There are at most eight top-level
tables per residue, not eight arithmetic operations. The implementation retains
signed outputs, negative offsets, empty segments and half-modulus multiplicity.
Its frozen source header records its earlier code-only preparation; the actual
executed status is established by STARTUP_GUARD.json, the checker, summary and
complete saved execution record.
