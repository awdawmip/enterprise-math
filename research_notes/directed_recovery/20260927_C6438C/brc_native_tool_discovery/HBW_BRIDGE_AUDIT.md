## Finding

time, residual state and observer-scoped quotient discipline. Its current
carry-peak first-hit implementation does **not** supply a factor-event observer.

declared native X6 program has a smaller future-sufficient carrier. No such
general compression or computational advantage is established here.

## Why the old peak cannot substitute for a factor event

Let A be any integer unimodular six-by-six matrix. For every prime p,
A Z_p^6 = Z_p^6. Every product of such arrows therefore has canonical column
lattice equal to the identity lattice, and p-Smith spread zero. This follows
directly from integer A and integer A inverse; it needs no numerical example.

In particular, all shears I+(u-1)E_12 have the same existing peak state, whereas
gcd(u-1,N) need not be the same. More basically, the peak state retains the
linear action but erases affine endpoint/translation information; different
modular endpoint differences can have different gcd observations. The source
explicitly disclaims recovery of these erased data. A new observer cannot be
applied after this quotient without a new sufficiency proof.

Supplying an unknown prime divisor p of N to a p-local observer would itself
supply a factor. Using a known prime instead is legitimate, but no source theorem
identifies its carry-spread event with an unknown-factor event. Simultaneous
Smith/gcd diagnostics over all primes must include their own construction and
arithmetic costs; these names do not make factor discovery free.

This is a failure of the **specified carry-peak quotient for the new observer**,
not a lower bound on HBW, BRC or all factoring algorithms.

## A genuine native-coordinate bounded candidate, not yet implemented

Inputs: odd N>1, a declared unit c modulo N, a finite horizon T, exact positive
branch weights, source pins and resource budget. No factor, order, orbit table,
or answer-dependent event geometry is input. Compute c inverse and
k=c+c inverse modulo N with the already typed arithmetic, charging admission.
Fix an integer representative of k and the integer matrix

`M = [[0,1],[-1,k]] direct-sum I_4`,
`M^-1 = [[k,-1],[1,0]] direct-sum I_4`.

These are actual integer-linear native-X6 macro-arrows, with determinant one.
They can be written as an ordered two-axis shear and signed axis interchange;
that does not turn an integer shear into one free primitive Cell step. Primitive
path length, macro-operation count and bit-operation cost remain distinct.
The last four zero displacement components describe the chosen two-axis
invariant subspace; they do not stand for unknown or projected coordinates.

Start from raw first coordinates (z,w)=(2,k). At a declared beat use the original
microscopic histogram `2[1/4]` for the identity outcome and `[1/4]` each for M and
M inverse. Thus the updates are

`(z,w) -> (w,kw-z)` or `(kz-w,z)`.

Modulo N, the induction invariant is

`z=u+u^-1`, `w=cu+c^-1 u^-1`,

where the conceptual lift changes by u->cu or c^-1u. This is a fixed-c random
walk. It must not be silently identified with the previously executed
time-varying square schedule. A future schedule of powers of M requires its own
typed construction, chronology and costs.

The reduction of the two raw coordinates modulo N is an exact quotient only
for the declared integer-linear future and modular observations. Full raw
coordinates/carry fibers must be retained or reconstructed if a future request
observes native raw length, displacement or the unbounded world trajectory.

New factor port: compute `g=gcd(z-2,N)` and absorb only if 1<g<N, with the actual
factor value and first-hit beat retained. It is a valid factor witness because

`z-2 = (u-1)^2/u (mod N)`.

It is **not** the old gcd(u-1,N) observation: prime-power valuations can double,
and g=N can conceal an old proper factor. A small validation unit should retain
the true lift and compare both declared laws, rather than assume they coincide.
Every successful g is validated by typed exact division. Absorbed paths use
`[1]`, not another quarter-weight step. The complete histogram, not only total
mass, accompanies every allowed recoalescence.

Suggested future finite test: reuse at most the already declared small moduli,
fixed c and horizon three, compare exact native-coordinate and lifted modular
updates with complete histograms, verify every returned factor, and include
prime-power saturation and zero-success cases. No run is authorized or performed
by this note. A scientific run needs the normal source/guard/typed-source checks;
mathematical continuation of this candidate does not require any particular
tool or original author to be available.

## What this candidate can and cannot improve

The two-coordinate update avoids per-state inversion after the charged setup,
but it is the familiar split Lucas/Chebyshev recurrence expressed as a genuine
HBW program. It is not claimed as a new factoring algorithm or a nonsplit
Lucas p+1 method. The discriminant is `(c-c^-1)^2` modulo N, so the split nature
and original multiplicative subgroup remain explicit.

In fact,

`w-c^-1 z = (c-c^-1)u (mod N)`.

If c-c^-1 is a unit, the pair (z,w) reconstructs u exactly. Hence this version
does not by itself reduce the number of unit states. If its gcd with N is
proper, setup already gives a factor; if the gcd is N, c^2=1 and the program
degenerates. Single-trace merging instead needs the separate trace-or-factor
stopping certificate and may change the old law. Root extraction is not free.

All these M arrows are unimodular, so the existing carry-peak implementation
reports zero spread at every prime for the entire candidate. Its first-hit
solver would correctly compute the wrong-for-factoring event. The new modular
marked-section observer is therefore an explicit missing interface, not an
already available HBW tool hidden under a different name.

Failure conditions include: nonunit admission; no proper gcd before T; saturation
g=N; full support growth; an attempted quotient that loses marked-section or
future information; UNKNOWN frontier; or total representation/typed arithmetic
cost exceeding the relative-coordinate baseline. Bounded finite-state star or
Krylov analysis requires the finite carrier to have been acquired first and may
cost more than direct finite-horizon propagation. No polynomial-time, runtime
advantage, generic unknown-order closure or physical speedup follows.

The constructive research target is now precise: give a cheap future-sufficient
quotient or direct first-hit evaluator for this modular marked-section event,
with factor witnesses preserved and without acquiring the whole orbit. That is
where a new BRC/HBW tool would add information, rather than merely new notation.
