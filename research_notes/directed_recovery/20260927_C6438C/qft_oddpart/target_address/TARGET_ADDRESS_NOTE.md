# Paid target addresses from a replayed modular order

Status: AUTHOR_ACTUAL_TYPED_BOUNDED / SHARED_CONTEXT / NOT_ADMITTED.
This is the address-recovery component needed to query whole-period native correlations. It does not grant a free discrete-log oracle, execute an ideal propagator, or establish a general factoring advantage.

## Interface

`recover_target_address(order_certificate,z)` first performs complete fresh typed order-certificate replay. It consumes only a `CERTIFIED` result. Its JSON-compatible record has top-level `status` (`MEMBER` or `NONMEMBER`), `r`, `R`, `q`, `s`, `inputs={N,b,z}`, the supplied `order_certificate`, the actual fresh `order_replay`, full `evidence`, and separate `metrics`.

For MEMBER, `0<=r<R` and actual `b^r=z mod N`. For NONMEMBER, r is null and the evidence identifies the rejecting arithmetic stage. Canonical nonunit targets return NONMEMBER with a typed Euclidean trace. Invalid target types/ranges, incomplete order certificates and failed bindings raise `TargetAddressError` with available evidence. Already executed failed order replay is retained and included in the cost.

`verify_target_address(record)` reruns both order discovery and address recovery, strictly compares scientific and deterministic resource evidence, and returns `{'verified':True,'replay':fresh_record}`. Consume the fresh record. JSON roundtrips are supported; ordinary Python boolean/integer equality is not used for certificate equivalence. Only process-dependent native cache-call deltas are excluded from strict canonical-JSON comparison. Verification is deliberately paid work, not a hash-only acceptance shortcut.

## Correctness with no cyclic ambient-group assumption

Let the replayed exact order of b be `R=2^s q`, q odd. The modular unit group may be noncyclic.

First compute `gq=b^(2^s)` and `yq=z^(2^s)` using actual typed columns. The exact order of gq is q. Consecutive powers at exponents `0,...,q-1` therefore identify a unique `rq` with `gq^rq=yq`, or certify that no such exponent exists. Any genuine z in the subgroup generated by b must pass this test and has r congruent to rq modulo q.

Next compute `g2=b^q` and `y2=z^q`. The exact order of g2 is `2^s`. For s>0 let `eta=g2^(2^(s-1))`. Starting at e=0, the j-th bit test is

`(y2*g2^(-e))^(2^(s-1-j))`.

If z is a genuine member and e contains its already recovered low j bits, this value is one or eta, according to its next bit. The algorithm rejects any other value. It adds either zero or `2^j` through typed integer arithmetic, keeping `0<=e<2^(j+1)`. At the final j=s-1 step the exponent applied in the test is one; passing and updating e gives the exact equality `y2=g2^e`. For s=0 the target's two-part projection must simply equal one.

Typed CRT then combines `r=r2 mod 2^s` (where r2=e) and `r=rq mod q`. When q>1 the implementation computes

`k=((rq-e) mod q)*(2^s)^(-1) mod q`, and `r=e+2^s*k`.

The reduction, subtraction, inverse, product, sum and range comparison use actual typed arithmetic. The modulus-q inverse uses a separate lazy modular table with full provenance and setup cost. For q=1, r=e is an explicit shortcut; no invalid modulus-one inverse is constructed.

The implementation finally computes actual `b^r` and compares it with z. This is a useful redundant executable check, **not** a logical requirement caused by a noncyclic ambient group. Indeed, once both projection equalities are established for the same CRT r, the unit `w=z*b^(-r)` obeys `w^q=w^(2^s)=1`; coprimality and Bézout give w=1. The full bit-lift checks already establish the second projection equality. Every early NONMEMBER condition is impossible for a true subgroup member. The final mismatch branch is retained defensively but was not reached in the declared valid arithmetic cases.

## Arithmetic and cost

All modular multiplication, powers, inverses, unit tests and CRT residue arithmetic use the frozen typed BRC interfaces. Exponent bits, loop indices and equality select or route actual columns. No ordinary modular pow/remainder/gcd generates a scientific answer. No phase word or residual coordinate is changed; this component works only on exact modular label addresses.

The address stage uses O(q+s^2+log N) logical modular actions: a q-cycle projection search, binary lifting with paid inverse-prefix and test powers, projection and final powers, plus typed CRT. This is polynomial in q, not log q. Fresh order replay adds its own O(n+q+log q) actions. Every new table pays actual inverse/permutation setup and a separate replay; exact bit operations, stored traces and verification remain additional costs.

The record separates `address_only_adder_digit_replays`, `order_replay_adder_digit_replays`, and their sum. It retains each actual table instance within each independent run, even if another call used the same multiplier. Within one factory, deliberate cache reuse and all column requests are counted. A full certificate verifier pays another complete order/address run. Stored original order certificates are provenance, not newly executed work; the fresh `order_replay` is the charged work.
