## Verified result

The symbolic theorem in `SINGLE_WALKER_QUERY_REDUCTION.md` reduces exact
readout sampling to two full signed amplitude-row queries per round, an
actual native feedback action, and a bounded rational local draw. It carries
one work label with the correct conditional row-norm distribution; it does
not reconstruct an independent norm sampler after each selected bit.

`single_walker.py` implements that coupling using an explicit point-query
interface and a naive memoized two-parent row recurrence. It never calls
the supplied program's `initial()` or `branches()` to obtain a state map.
The query cache can nevertheless grow to cover an orbit at many depths;
there is no polynomial query-count theorem or overall speedup claim.

The final bounded checker completed with 1,611 actual BRC core calls. For
N=21, a=2, t=4, separately at D=6 and D=61, it checked every one of the 15
positive parent prefixes and all 30 child-history edges. For every child,
every work-label mass generated by the enumerated latent Markov transitions
equalled the corresponding full actual native child's row squared norm.
The complete terminal joint law was equal across the two carrier encodings.
Nonzero residual coordinates occurred in this exhaustive joint-law check.

These comparisons are with the same actual native words, not an ideal QFT
distribution. The imported direct-word t4 bank carries its existing error
bound 1/2. This is not a default-width factorization-success experiment.

## API and actual arithmetic

The public row interface is:

```python
oracle = PointRowOracle(admitted_program, history=(), query_budget=1000)
row = oracle.query(depth, label)  # RawRow(values: tuple[int, ...], den: int)
oracle.apply_feedback(depth, row)
oracle.combine(left, right, sign=1, halve=True)
oracle.append(bit)
```

`SingleWalker(program, oracle=oracle)` accepts an alternative exact row
implementation satisfying the same complete-row/history contract. It uses
`transition_plan(oracle, latent, auxiliary_bit)`, preserves its proposal
across interruptions, and returns a terminal readout when complete. The
inherited classical postprocessor may be supplied explicitly; the default
is labelled `INSTRUMENT_ONLY`.

Every program first admits the complete actual 61-column native words,
their two-H4 contraction, and typed lazy modular/inverse permutations. Six
coordinates are permitted only after the existing complete-word codec check.
Point-query row additions and local quadratic norms use actual signed
`PositivePathObserver` endpoint differences and retain their graph/kernel
receipts. Exact denominator alignment, basis/zero wiring and the inherited
factor 1/2 are separately identified. Feedback uses the word's actual
`apply_numer` in the unchanged temporal order. A zero row may skip a linear
action; no nonzero residual is projected away.

The reciprocal norm expression is the inherited exact conditional observer,
not amplitude renormalization. The inherited `choose` interface consumes
one conditionally uniform `rng.randrange(denominator)` at a nontrivial
rational draw. The new fair proposal coin consumes additional random calls.
Reusing an old seed therefore does not mean preserving an old simulator's
trajectory. Software pseudorandomness is not presented as physical randomness.

## Interruption and negative controls

A zero query budget halts after retaining the already drawn auxiliary coin,
with the original history and latent label unchanged. Raising the live
object's budget resumes the same proposal. A subsequent exhausted random
source retains the computed local plan, again without committing a bit.
Continuing with a supplied source completed the readout. Returned records
are event-list snapshots and remain unchanged after continuation.

Five negative controls reject a boolean auxiliary bit, a zero-row latent
label, an unavailable future depth, a boolean history bit and a label outside
the carrier. The prototype offers live-object continuation only; it does
not claim a durable cross-process sampler cursor. No interruption is silently
converted into a completed readout or factorization.

The first successful run is preserved in `prior_live_event_snapshot/`.
It exposed a record-ownership issue: an interrupted result held the live
event list and could acquire later events after resume. The final code copies
the container on return, and the checker asserts both earlier interruption
records remain empty after the recovered run. The probability algorithm was
unchanged; all bounded checks were rerun under the corrected source hash.
