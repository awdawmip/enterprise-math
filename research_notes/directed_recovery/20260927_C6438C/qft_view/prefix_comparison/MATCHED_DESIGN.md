## Separately paid setup

Record all native bank/program admission and the one cold SO bank, including
complete native replay/observer evidence. Then time one first standalone
`_derive_token` call **after** an actual bank binding check. This is a pure host
encoding operation on the admitted immutable bank view. Record its elapsed time,
zero-native-call assertion, source-bound token hash, three segment byte lengths
and the preexisting admitted-view byte length. The standalone token is never
injected into a measured engine. Each new engine still executes its ordinary

This one token observation is not an isolated cold-system benchmark or process
memory measurement. Segment payload sizes exclude allocator/object/transient
overhead. A reduction in repeated encoding may increase persistent storage.

## Matched schedule and measurements

For each fixture, run one paid old-SO prefix to populate the shared native and
typed modular caches. Its full evidence and costs are retained separately. Then
use two pairs, in the fixed orders `(old,new)` and `(new,old)`: six pairs/twelve
measured engines total. Each engine starts at empty history with an empty Gram
cache. Both factory and already-created inverse instances must have zero new
computed columns and zero new column digit replays during each measured run.
This is a measured warm-modular condition, not free modular setup.

The calculation window includes constructor, four public `advance` calls and
one terminal `mass` call. A second window measures the public `evidence` call.
The through-evidence interval includes the intervening counter/inventory/UTC
capture gap, which is also reported explicitly. Deep-copy detachment and final
JSON/gzip output are outside those windows. Per-run UTC brackets support later
comparison with any unexpected concurrent activity. Whole-checker elapsed time
is separate and includes paid setup/preconditioning and checks before final
serialization.

Every pair must exactly match conditional plans, terminal mass, numeric ledger,
complete retained signed covariance matrices, entire observer streams, actual
native calls, Gram/policy counters and guard-call topology. Cross-version cursor
bytes are intentionally different. The new route must report only fast accepts
on these unchanged programs; constructor checks and actual frozen-check method
calls are distinct from logical complete binding comparisons. All native
propagation, signed residuals and temporal gate order remain unchanged.

Save complete calls, every warmup/run, cold bank evidence, standalone token
observation and final tables by concrete factory/inverse instance. Programs and
tables are shared across routes: count their final setup/column/verification
costs once, never once per cumulative engine report. Reconcile the entire native
call stream as admission + one cold bank + paid warmups + measured engines. The
standalone token and metadata guards do not become native arithmetic receipts.

Before running, reject any existing success, summary or failed-execution output
in this independent directory. During execution, immediately register every
constructed engine and retain all completed runs, warmups, current pair and
completed pairs. Unexpected failure saves a distinct raw gzip with source hashes,
stage, traceback, available attached evidence, the full actual call stream and
the reviewed per-field LIVE snapshot. Failure capture invokes no scientific
method. Incomplete constructors and unsnapshotted mutable program-table receipts
remain the already stated failure-capture limit; complete successful output
contains final table instances. Never erase a failed result or silently replace
an unfavorable sample.

The parent will coordinate an execution window without other planned scientific
runs or large JSON/gzip I/O. This is coordination, not a claim of controlled OS
load. If overlap nevertheless occurs, retain and disclose it without replacing
the run. Do not infer a performance gain from the previous 36-versus-205 cold-bank
comparison, from correctness-run wall time, or merely from fewer old method
invocations. Report observed paired timings even if the new route is slower.

The result will be six bounded fixed-prefix comparisons. It will not establish
asymptotic speedup, full-history law timing, independent statistical trials, a
general Gram-query compression or polynomial Shor dequantization.
