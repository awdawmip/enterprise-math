# Segmented complete binding checks

The versioned adapter preserves the complete native binding check while avoiding an additional whole-wrapper JSON serialization on its fast path. Its one correctness run passes full matrix, observer, ledger, interruption/retry and strict restoration checks. A separate predeclared matched run finds a shorter calculation time for the new adapter in all six retained pairs. These are bounded implementation results; neither the scientific query count nor the asymptotic Shor/QFT complexity changes.

For one original SOTraceBank passing the canonical-wrapper gate, the adapter derives three immutable byte segments from the actually admitted bank. Each outer entry performs the inherited adaptive check, checks the original bank and token identity, and compares all newly constructed program-view bytes. A mismatch uses the frozen SO check without updating the token. The admission gate and bank-object rule can reject inputs the earlier API accepted; the equivalence statement is restricted to that fixed admitted bank.
