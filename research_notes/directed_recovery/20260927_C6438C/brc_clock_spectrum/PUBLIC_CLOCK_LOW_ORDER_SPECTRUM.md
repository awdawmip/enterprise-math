## 2. 一般的有限域多项式归约

先重用 public-clock 定理，而不是重新宣布其为新结论。对局部素数 r∈{p,q} 设

```
sigma_r=(k²−4|r),  L_r=r−sigma_r,
j=sigma_p sigma_q, d=gcd(L_p,L_q).
```

局部特征根 λ 满足 `λ+λ⁻¹=k`，属于大小 L_r 的循环 torus；regular 性排除 λ=±1。由 `p≡sigma_p (mod L_p)` 直接有

`gcd(E,L_p)=gcd(E,L_q)=d`。

d 为偶数。令 m=d/2，定义本稿的**规范化多项式**

```
U_0(X)=1, U_1(X)=X,
U_(n+1)(X)=X U_n(X)−U_(n−1)(X).
```

因此 U_n 是次数 n、首一的整系数多项式。它不是以 U_0=0 开始的另一套 Lucas 编号；`U32` 在本文始终指这里的 U_32。

由递推直接归纳，不使用三角函数，得到

```
(λ−λ⁻¹) U_(m−1)(λ+λ⁻¹) = λ^m−λ^(−m),
V_m(λ+λ⁻¹) = λ^m+λ^(−m).
```

在这个 torus 中，正返回等价于 `λ^d=1`，故等价于 `U_(m−1)(k)=0`。负返回等价于 `λ^d=−1`，故等价于 `V_m(k)=0`：证明时写 `a=L_r/d`，幂 E/d 在大小 a 的像群上可逆；若 a 奇，两种负方程都无解；若 a 偶，E/d 为奇数，幂自同构固定唯一二阶元素 −1。

所以在**固定局部类型、固定 d 的分析域**，平方自由 N 上精确有

```
D_+ = gcd(N, U_(d/2−1)(k)),
D_- = gcd(N, V_(d/2)(k)).                           (1)
```

这里 d 来自分析，不是提供给盲算法的免费已知量。式 (1) 只在上述平方自由域从局部零集提升为精确整数 gcd；没有声称它在任意素数幂上自动保留原返回估值。

## 3. J_D=−1：两个交叉类型全部闭合

### 3.1 类型 (sigma_p,sigma_q)=(+1,−1)

此时 `L_p=p−1,L_q=q+1,d=66`。两边 L 的二部均为 2，故 L_r/66 都是奇数，**负返回全空**。正返回恰为

`U_32(k)=0 modr`。

等价地，非例外局部阶属于 `{3,6,11,22,33,66}`。由于 66|L_r 且 r>66，μ_66 的 66 个元素互异，去掉 ±1，再按反演两两配对，得到恰 **32 个不同 regular trace 根**。U_32 的次数正好是 32，因此没有额外根或重根。

### 3.2 类型 (sigma_p,sigma_q)=(−1,+1)

此时 `L_p=p+1,L_q=q−1,d=4`。正返回只可能为阶 4，等价于 `U_1(k)=k=0`；各局部类型恰有一个这样的 trace。

p 侧 L_p 的二部为 16，L_p/4 偶，因此负返回有解。q 侧 L_q 的二部为 4，L_q/4 奇，因此负返回无解。式 (1) 给出 p 侧负返回恰为

`V_2(k)=k²−2=0 modp`，

即 λ 的阶恰为 8，反演配对后有 **两个** regular trace。其 k²−4=−2 非零。

### 3.3 为什么能合并为不显式写局部类型的公式

从 `66|(p−1),(q+1)` 可得 `gcd(66,p+1)=gcd(66,q−1)=2`。所以 U_32 的根在 p 处只能属于 split 类型，在 q 处只能属于 nonsplit 类型；不可能偷偷出现在 3.2 的对型中。

k=0 的 discriminant 为 −4。由二部条件 p≡3 mod4、q≡1 mod4，它的类型恰为 p 处 nonsplit、q 处 split。

`k²−2=0` 会产生阶 8 特征根；p 的 split torus 二部为 2，故它的根只能在 p 的 nonsplit 类型中。q 的两个 torus 二部最多为 4，故 q 处没有该多项式根。以上均是符号群论推论，没有实际枚举根或生成新的参数。

因此，对所有 regular 且 J_D=−1 的 k：

```
D_+ = gcd(N, k U_32(k)),
D_- = gcd(N, k²−2).                                (2)
```

## 4. 整个单曲线公共时钟的精确输出集合

先前已闭合的 J_D=+1 分支，两同型的 d 都是 2，故 (1) 成为 `U_0=1,V_1=k`。合并得到

| 公共字符 | 正主读出 D_+ | 负主读出 D_- |
|---|---|---|
| J_D=+1 | 1 | gcd(N,k) |
| J_D=−1 | gcd(N,k U_32(k)) | gcd(N,k²−2) |

**这是整个声明域上的终端观察等价，不只是候选必要条件。** 得到 proper factor 的集合是上述任意一项 gcd 严格介于 1 与 N 的 k；所有 gcd=1 或只有正返回 SAT 的情况均不算成功。负主读出始终不 SAT，重用 common-d 的两个商不可能同时为偶这一原定理。

这张表说明了一个可用的压缩对象：本 fixture 的巨大指数返回观察可以由次数至多 33 的多项式共同理想表示。它只改变等价读出的表达式；**没有扩大一次参数提案的成功集合**。本稿未执行这些多项式，也没有因事后知道 cross-gcd 小就把它们冒充盲运行已经采用的优化。

## 5. 精确成功计数与低阶率界

下面指定一个与实际固定 k=3 不同的数学抽样实验：k 在全部 regular 模 N 参数中均匀分布，每个参数按其实际 J_D 选择 E=N−J_D，并计算两个主读出。没有把实际一次固定参数改说成随机样本。

记

```
C_p+=(p−3)/2, C_p−=(p−1)/2,
C_q+=(q−3)/2, C_q−=(q−1)/2.
```

在指定局部类型后，CRT 给两边独立的均匀 trace 参数。单边分成“正返回、负返回、无返回”三类，两边类别不同恰好至少得到一个 proper 主因子；两边同正只给 SAT，同无给 UNIT。各类型的完整计数为：

| 类型 | p 侧三类数量 (+,−,无) | q 侧三类数量 (+,−,无) | 成功参数数 |
|---|---|---|---|
| (+,+) | (0,0,C_p+) | (0,1,C_q+−1) | C_p+ |
| (−,−) | (0,1,C_p−−1) | (0,0,C_q−) | C_q− |
| (+,−) | (32,0,C_p+−32) | (32,0,C_q−−32) | 32(C_p++C_q−−64) |
| (−,+) | (1,2,C_p−−3) | (1,0,C_q+−1) | C_p−+3C_q+−4 |

例如最后一行从总数中扣除“两边同正”1 个，以及 `(C_p−−3)(C_q+−1)` 个同无；这保留了一个正、一个负时的成功，不把两个符号当独立试验。

因此 J_D=+1 分支的成功数是 `(p+q−4)/2`，J_D=−1 分支的成功数是 `(33p+35q−4242)/2`。前者的总参数数为 `((p−2)(q−2)+1)/2`，后者为 `((p−2)(q−2)−1)/2`，所以各条件成功率分别为

```
(p+q−4) / ((p−2)(q−2)+1),
(33p+35q−4242) / ((p−2)(q−2)−1).                    (3)
```

不按字符筛选时，整个 regular 时钟的精确成功率为

```
P_regular = (17p+18q−2123) / ((p−2)(q−2))
          < 18/(p−2) + 18/(q−2).                    (4)
```

式 (4) 是一个有具体低阶谱来源的率界，不能由“两个 Jacobi 位看起来均衡”取代。对具有这一结构且两素数增长的族，单个均匀 regular 提案的率趋零；它不约束所有自适应、非均匀选择器，也不是关于所有 BRC 算法的下界。

如将算法扩为在全部模 N 参数中均匀提案，并包括其实际 setup discriminant gcd，恰一侧 k=±2 给出 `2(p−2)+2(q−2)` 个 proper setup 参数，两侧同时非 regular 的四个参数只给 SAT。于是相同声明算法的总成功率为

`P_all = (19p+20q−2131)/(pq)`。                     (5)

这只是明确计入 setup 的完整抽样合同；本轮没有运行均匀 sampler、重试器或这些计数的数值实验。若加入第二字符筛选或依赖历史的选择规则，必须使用原 joint-character 精确纤维法重新加权，不能直接复用 (3)–(5)。

## 6. 对下一原生几何工具的具体要求

### 6.1 可保留的正向工具义务：终端返回理想的短证书

当前已有能力是：实际 typed 原生算术、有序相邻迹合成、primitive joint-return gcd、factor division 证书。式 (1)–(2) 为它们提供一个明确的**观察专用代数编译目标**，不要求恢复全轨道或全返回序列。

一个可向新工具迁移的通用接口是：对公开 N、参数 k、时钟规则和指定 signed 终端观察，给出短表达式 f 及可核验的理想等价证书，使

`(tau,w)=(f)` 于声明的模 N 环/regular 局部化中成立。

可检验的充分证书是 `tau=f a, w=f b, f=c tau+d w` 的源绑定 straight-line identities；若出现分母，必须保留并计费其单位证书。这样 gcd 的精确值与因子见证会保留，而非仅保 Boolean 支持。本稿的有限域零集证明只在平方自由域给出了该目标的实例化，不是已经构造出任意 N 上上述环证书。

真正未完成的是：**如何在不知道 p、q、局部 d 或阶时，得到尺寸和验证成本受控的短证书。** 展开 E 次多项式、枚举未知阶或免费调用 root solver 不算解决。即使证书让相同终端观察更便宜，它仍须和提升成功集合的工具分开计量。

### 6.2 提升命中率必须改变什么

对于相同 torus、相同时钟和相同 parameter law，任何保真坐标桥、conic lift、字符重编码或原生记录优化都保留本稿的成功集合与率。要超出 (4)，必须至少改变以下一项，并证明改变后的条件：

1. 提案分布确实集中到返回纤维的非对称部分，而其生成不依赖已知因子/阶；仅宣布拒绝不合字符样本还不够，须算接受成本及重加权率。
2. 指数/未来操作产生新的局部消去理想，并给出未知奇部被覆盖的证明；在固定指数上重复更快的幂计算不会产生这一性质。
3. 使用真正改变局部群大小的几何族，例如已讨论的椭圆曲线族，证明其公开参数及指数计划带来可用的不同返回集合；不能把标准 ECM 换名后宣称新通用优势。

这给后续实现一个有判别力的目标：先证明一个 factor-blind 家族级分离合同，再落实其原生可组合观察和费用。它保留沿原生 BRC 完成目标的方向，同时避免把一个表示层改进误报为未知奇数阶问题已解决。
