# 实际 BRC 全加器组成的完美幂与 Wilson 素性预检

Status: AUTHOR_EXECUTED / SHARED CONTEXT / UNREVIEWED / NOT_ADMITTED.
Researcher `EM-DIRECT-C6438C`; activity `RA-CAAAC604CB513AEA8BBC1DFC`.

本模块为完整 Shor 因数接口补两类原有结构性缺口：奇素幂不能通过互素底数的半阶 gcd 分裂；素数不能由有限次未找到因数来认证。它不把普通整数库重新命名为 BRC，也不试除 N 来代替 Shor 分裂。

## 1. 唯一算术原语及类型边界

`typed_integer_prechecks.py` 导入本轮 `sparse/sparse_modular.py` 的 `native_adder`、`add_unsigned`。后者实际调用冻结 `stage78.full_adder_columns()`，由实际正 BRC 核取得全部 8 个输入三元组的 `(sum_bit,carry_bit)` 列，然后组成每一位的数字变换。每个加法保留输入、位宽、每格输入码、输出位和 carry，包括最终 carry。

新模块只组合这些列、位接线、显式控制和保留的循环历史。没有调用 Python 乘法、幂、除法、余数作为科学算术返回值；位宽/循环索引及根区间初始上界属于有限控制元数据。右移、左移、逐位反码和拼接是明确的位接线，不是新动力学。Python 大整数仍作为这些离散编码的宿主容器，不把宿主机器自动宣称为物理 BRC。

这是正的确定标签变换，完整来源作为 trace 保留；不是声称每个压缩端点运算本身可逆，也不擦除此前有符号振幅或残差。Wilson 与根二分仅处理经典输入标签，不读取 Shor 未测量态。

## 2. 无符号乘、比较和余数

### 乘法

`multiply(l,r)` 从 0 开始，对 r 的每个二进制位执行已认证加法 `acc+(l<<bit)` 或保留显式旁路。每步保留原 acc、位、接线值和新 acc。归纳不变量为

`acc_j = l * (r 的低 j 位)`。

完整位宽 `bit_length(l)+bit_length(r)` 足以保存所有部分和；任何最终 carry 都是错误。零输入按空和/零标签处理。输出因此等于整数乘积，证明中的乘号不是实现里另行执行的参考乘法。

### 比较

固定声明位宽 w，把 right 逐位取反；实际执行 `left+not(right)`，再实际加 1。模 `2^w` 的结果是差的低位，两个加法的 carry 之或恰指示 `left>=right`。在正确位宽内，低位差为 0 加上非负标志当且仅当两输入相等。整个减法借位信息随两份全加器 trace 保留。

### 二进制长除法

`divide(v,m)` 要求 m>0。从最高输入位起，位接线把当前余数变为 `z=2r+bit`。由归纳 r<m，z<2m；上述实际比较/减法确定商位，并只需减一次 m。每步保留输入位、旧余数、减法 trace、商位和新余数。

归纳不变量是“已读输入前缀 = 已得商*m+余数，且 0<=余数<m”。终点给 v 的正确商与余数。实现没有调用宿主 `%` 或 `divmod` 来生成此输出。m 不必互素；这很重要，因为 Wilson 会处理非单位，不能滥用只对互素乘数合法的置换编译器。

`power` 用同一乘法按已知指数位做 square-and-multiply，保留乘法及平方的完整嵌套 trace；未知 Shor 阶从未成为输入。

## 3. 完美幂的完整搜索边界

若 `N=b^e`，b>=2、e>=2，则 `e<=floor(log2 N)`。`perfect_power(N)` 仅枚举这些指数，按降序对每个 e 二分根 b；没有枚举候选除数。

初始 lo=2、`hi=2^ceil(bit_length(N)/e)`，严格覆盖每个可能整数根。中点之和、幂、比较和上下界的一单位变化全部由以上实际全加器组合生成，并在证书中保留。函数 `b -> b^e` 对 b>=2 严格递增，所以排除的一侧确实不含根；有限整数区间每轮缩小。每个指数失败时区间空，遍历所有指数仍失败才返回 `NOT_A_PERFECT_POWER`。

成功返回 `{base,exponent}`，其证书直接给出实际幂恰为 N。base 可能仍是合数，例如 225 返回 15^2；完整分解驱动必须继续递归分解 base 并放大重数。这里不会擅自把 base 称为素数。

此算法在输入位长 n 下只做多项式个有界位长加/乘/比较；本轮主要目标是正确性和来源完整，不给未实测的精细 bit-complexity 常数。

## 4. Wilson 精确素性合同及证明

`wilson_primality(N)` 用上述乘法及长除法依次计算

`r_j = j! mod N`，`j=2,...,N-1`，起点 r_1=1。

每一步只保存模余数作为下一次输入，但完整乘积、商、余数、全加器 trace 都在证书中。终点用实际减法/比较检查 `r_(N-1)=N-1`。成立返回 `PRIME`，否则返回 `COMPOSITE`。

正确性是 Wilson 判据，这里给出所需完整方向：若 N 为素数，在非零剩余类的乘法群中，把每个元素与其逆元配对；自逆元仅 1 和 -1（N=2 单独同样成立），故乘积为 -1。反之，如果阶乘与 N 同余 -1，则它与 N 互素；若 N 合成，存在一个严格介于 1 与 N 的素因子 p，它已出现在阶乘的因子中，导致 p 同时整除阶乘与 N，矛盾。因此判据当且仅当素数。

证明中存在的 p 不由程序求出。程序判定合数时**不返回因数**，因此没有用 Wilson 来替代 Shor 的非平凡分裂。余数记录本身不是没有理由就可信的“素性标记”；必须结合完整 trace 的 replay 和上述判据使用。

该 baseline 使用 `N-2` 次模乘，时间随输入位长指数增长，完整证书也可很大。它弥补全输入终止语义与素性证据，完全不声称提升分解效率。以后可以用同一证据合同替换为更有效且真实实现的素性算法，不必更改 Shor 输出语义。

## 5. 接入递归驱动的必守条件

- 处理 0/1/负号等外部整数约定后，每个正的待分解节点 N>=2 可以先去 2、检测完美幂、核查 Wilson 素性。
- 素数叶只接受通过 `verify_precheck` 的 `PRIME` 证书。完美幂结果只缩小到 base，并递归传播指数。
- 剩余已证合数且非完美幂的节点交 Shor 因数寻找；每个返回因数还必须以实际整数余数检查严格非平凡及整除关系。
- 有限 Shor 尝试耗尽只能产生待分解 cofactor。它既不是素性证据，也不能被删除或计作已完成叶。
- 汇总须由已认证乘法/幂验证“已得素因子幂 × 未分解 cofactors = 原输入绝对值”；只有待分解集合空且所有叶证书完整时才能称完整分解。
