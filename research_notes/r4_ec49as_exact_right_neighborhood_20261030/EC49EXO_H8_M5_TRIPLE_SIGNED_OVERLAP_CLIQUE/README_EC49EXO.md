## 2. 新解析引理：同长度合法操作词的最后两级必分离

**引理 O1（带符号原生码）**。任意两个不同的合法操作词，如果展开后的原生步骤总长度同为 L，则其最长公共原生步骤前缀长度 ≤ L−2。

**证明**。每种操作码长度为2或4，且不同操作码的前两个有符号原生步骤两两不同。因此从共同原生步骤前缀可唯一解码完整操作。设两词第一次不同操作开始于第 t+1 个原生步骤，t 为偶数，第一差异在该操作的前两原生步骤内发生。若公共前缀达到 L−1，则第一次差异仅能发生在最后一个原生步骤。这要求不同操作均在 t=L−2 开始，均具有长度2，且前一个步骤相同；但七个操作的前两个步骤两两不同，且长度2的四个码 `a,b,f,g` 首步骤本身两两不同，矛盾。即公共前缀≤L−2。□

由 EC49EXN 的定理 N2，同一完整键在不同窗口的代表路径更强地满足公共前缀≤L−3。该命题以窗口 h（操作数）不同为前提。O1 因此给出一个键内部全体不同观察代表路径在深度 L−1 和 L 上的强制分离约束。

## 3. 新解析引理：不同 BRC 键的精确直方图交叠上界

**引理 O2（全符号重叠）**。对于两个正步完整键 `K=(u,v,w,0,0,0)`、`K'=(u',v',w',0,0,0)`，由 EC49EXN 的 N1，全部合法返回词的原生全符号直方图分别为 `(u,v,w;u−2,v,w)` 与 `(u',v',w';u'−2,v',w')`。它们的公共有符号原生前缀长度不超过

\[
I(K,K')=2\bigl(\min(u,u')+\min(v,v')+\min(w,w')\bigr)-2.
\]

**证明**。公共前缀每个有符号符号都必须同时消耗两条词的相应符号供给。对六种符号累加 `min` 供给即得上界；在 `u,u'≥2` 的合法域内，负1符号的贡献 `min(u−2,u'−2)=min(u,u')−2`。此界只用于安全剪枝；不假定给定直方图的任意原生排列都是合法操作词。□

## 4. 可复用的逐层最大加权不相容团下界

固定一个完整键安排，将相同键合并成五组。对于第 i 个完整键组，设原生长度 `L_i=2(u_i+v_i+w_i−1)`，被复用的窗口数为 `k_i`，全部窗口所要求的不同观察签名代表数为 `m_i=Σ_{h:K_h=K_i} (4 if T4 else 2)`。

定义每个原生步骤前缀深度 d≥1 所必需的、在该键组内互不相同的原生前缀节点个数

\[
q_i(d)=\begin{cases}
0,& d>L_i,\\
m_i,&L_i-1\le d\le L_i,\\
k_i,&d=L_i-2,\\
1,&1\le d\le L_i-3.
\end{cases}
\]

成立原因：O1 强制同长度不同操作词在最后两级全部分离；N2 强制跨窗口相同键在最后三级分离；在其余较早层保守只计一个节点。

对每一深度 d，在五个键上建立无向**不相容图** `G_d`：当两个不同键 `K_i,K_j` 满足 `I(K_i,K_j)<d` 时连边。这样的两组任意原生路径都无法在深度 d 共用一个前缀节点。若 `C` 是 `G_d` 的任意团，则该层至少包含 `Σ_{i∈C} q_i(d)` 个彼此不同的节点。

设

\[
\lambda_d=\max_{C\text{ clique of }G_d}\sum_{i\in C}q_i(d).
\]

由于前缀树每一层节点数即其当层原生有符号步骤边数，得到 **EC49EXO 逐层下界定理**：

\[
\boxed{E\ge B(K_2,\ldots,K_8)=\sum_{d=1}^{\max_i L_i}\lambda_d.}
\]

五个不同键仅有31个非空子集，`λ_d` 可用精确整数枚举所有团。此式对该模型的任何观察签名代表路径集合成立，省去逐词前缀树的昂贵优化；它不要求键组间前缀独立。
