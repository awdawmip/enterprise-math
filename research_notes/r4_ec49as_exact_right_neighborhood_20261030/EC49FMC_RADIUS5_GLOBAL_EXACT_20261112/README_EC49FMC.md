For each root, form the trie of all remaining ordered signed microsteps; terminal vertices carry the observed demand labels. A bottom-up dynamic program maintains for each demand-bitmask the minimum number of selected trie edges. It combines terminal selection and child-subtree choices by bitwise union and additive edge costs; a nonempty selected subtree incurs its entering edge exactly once. Induction on tree height proves the table's exactness. Upward closure gives the least cost satisfying any requested subset of that root's labels.
