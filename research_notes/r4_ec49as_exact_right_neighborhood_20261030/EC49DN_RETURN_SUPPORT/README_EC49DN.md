## 原生输入和定理

使用 EC49DM 验证器中的五个**有序原生有符号路径操作**（整数 `i` 表示沿第 i 条原生六轴的正向一步，`-i` 表示负向一步）：

- `a=(-1,-1)`，六维位移 `-2E1`；
- `b=(-2,-2)`，六维位移 `-2E2`；
- `c=(1,2,-1,-2)`、`d=(2,1,-2,-1)`，六维位移均为 0；
- `e=(3,1,1,-3)`，六维位移 `+2E1`。

给定任意前缀位移 `D=(D1,...,D6) ∈ Z^6` 和恰好 h 个未来操作的有序词 `w∈{a,b,c,d,e}^h`，返回条件为 `D+δ(w)=0`。

**返回支撑锥定理（任意 h≥0）**：

```text
R_h = { D=(2k,2b,0,0,0,0): k integer, b nonnegative integer, |k|+b <= h }.
|R_h| = (h+1)^2.
```

特别地，**D=-2E2=(0,-2,0,0,0,0) 不属于任何 R_h**。故对于任意前缀长度 n、任意 h、任意严格正权 BRC 参数以及全部历史 A/B 有序子串和前后缀交界观察，返回条件将全部观察矩阵元素筛为 0：

```text
rank O_exact(h; D=-2E2,n) = 0
rank O_cumulative(1..h; D=-2E2,n) = 0.
```

真实前缀 `(-2,-2)` 的 n=2 位移就是 `-2E2`；零秩来自**未来返回操作不可达**，不是历史前缀集合为空。原 EC49DN 提出的 n=2,4,6,8,10 中是否出现满正秩的问题，对此特定未来语言被定理严格判为结构性无返回；这里不将恒零读出解释为有信息的“最早饱和”。

## 完整解析证明

设 `A=#a,B=#b,E=#e,C=#c,F=#d`，这些非负整数之和为 h。按六条原生轴分别相加，

```text
δ(w)=(-2A+2E, -2B, 0,0,0,0).
```

返回要求 `D1=2(A-E), D2=2B, D3=...=D6=0`。若 `D1=2k,D2=2b`，则 `A-E=k`、`B=b`，所以 `A+E>=|k|`、`h>=|k|+b`，且 `b>=0`。必要性得证。

反之，若 `D=(2k,2b,0,0,0,0)` 且 `b>=0,h>=|k|+b`，令 `A=max(k,0), E=max(-k,0), B=b, C=h-|k|-b, F=0`；得到合法的恰好 h 个操作的返回词，充分性得证。对 `k=-h,...,h` 逐一取 `b=0,...,h-|k|`，位移纤维数为 `Σ_k(h-|k|+1)=(h+1)^2`。这一结果**不使用** EC49DE/DM 中待独立审核的六特征秩引理。

## 正权 BRC 总质量的精确生成函数

原生 BRC 对正向 `+Ei` 乘以严格正数 `x_i`，负向乘以 1。因而 `a,b` 权重为1，`c,d` 各为 `x1*x2`，`e` 为 `x3*x1^2`。以形式变量 `u,v` 仅记录**六维位移中的前两分量**，有：

```text
W_x(h,D) =
  [u^(-D1) v^(-D2)]
  (u^(-2) + v^(-2) + 2*x1*x2 + x3*x1^2*u^2)^h
```

（`D3..D6` 有非零者定义为0）。在 `D=(2k,2b,0,0,0,0)` 时，令 `t=#e`、`A=t+k`、`L=h-b-k-2*t`，得**有限封闭和式**：

```text
W_x(h,D) = sum_{t>=max(0,-k), L>=0}
  h! / [(t+k)! b! t! L!] * (2*x1*x2)^L * (x3*x1^2)^t,
where L=h-b-k-2*t.
```

将 `x` 替换为 `y` 得双 BRC 第二通道，全部权重取1得返回词数。这是总质量/支撑读出；不含 A/B 历史标签及跨交界端口，因此**不能**从非零质量推断完整有序标签观察秩；但零返回直接使全部标签读出为零。
