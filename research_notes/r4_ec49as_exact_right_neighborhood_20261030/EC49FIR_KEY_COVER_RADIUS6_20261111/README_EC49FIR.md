## Proof: exact cache-key cover

For each of the 94 catalogue complete keys `k` and frozen observation `i`, define `C(k)` as the subset of the 24 observations admitting *some* legal operation word with that key. The unmodified nine-state BRC catalogue contains **178,850** legal operation words. For a six-position set `Q`, let `K_F` be the keys of the 18 fixed words and `r=7-|K_F|`.

A six-observation replacement exists at the **key/observation level**, disregarding prefix cost, iff the labels Q are covered by `K_F ∪ N` for some set `N` of at most r new keys. Necessity is direct, and sufficiency follows by selecting a legal word for each covered label. The exact coverage test stores the six-bit mask reached by up to j new catalogue keys and iterates `S → S ∪ C(k)`. For each released *original* key k, rerun this finite test while excluding k. If no cover exists, k is mandatory in any legal seven-key completion. If all r released original keys are mandatory, the completed seven-key set is exactly the original set.

## Proof: singleton signed-prefix lower bound

In that forced-seven-key class, the legal-word catalogue contains exactly 9,838 words. Let `F(Q)` be the fixed prefix union (a prefix-closed set). For each label i, `L_min(p,i)` is the minimum full native microstep-prefix length among legal words with original keys realizing i and extending signed prefix p. Then the **exact** one-word minimum additional-prefix cost is
```
m_F(i) = min( min_{w legal for i} |P(w)|,
              min_{p in F(Q)} [L_min(p,i) - |p|] ).
```
The minimum is exact because intersection of any candidate path with F(Q) is an initial segment. If any of the six labels has `m_F(i) > 93-|F(Q)|`, the complete replacement costs at least 94. The original witness gives an admissible 94-cost upper bound, yielding equality.
