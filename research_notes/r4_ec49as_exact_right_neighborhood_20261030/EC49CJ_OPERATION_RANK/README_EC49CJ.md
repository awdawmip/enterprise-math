## 定理 A：任意正整数 h 的完整抽象模型精确秩

对于任意 h≥1，在九态DFA与六维端点及三个独立有类型通道组成的完整形式状态空间上，严格成立：

    rank_Q O_(S^h)   = 3 * (5*h*h + 13*h + 4)/2
    rank_Q O_(S^≤h) = 3 * (3*h*h + 7*h + 1)

这是所有 h 的解析定理，不依赖仅检验 h≤4 的数值外推。

证明：给定目标端点 d=(2i,2j,0,0,0,0) 且 i,j≥0、k=i+j≤h。任何实现该 d 的操作词恰含 i 个 a、j 个 b，其余为 c/d。定义六个布尔观测函数：

    x=1(qA=2), y=1(qB=2),
    X=1(qA>0), Y=1(qB>0), 1, xy.

将四个真实操作词逐字作用于DFA可得首次作用后的完成位：

    a,b : (x,y)
    c   : (1,Y)
    d   : (X,1).

首次操作后，子状态只能是0或2；以后 a、b 不改变完成位，c 设置 A 完成，d 设置 B 完成。逐端点分块：

* k=0：至少一次 c/d；标签指示函数张成 span_Q{1,X,Y}，秩3。取全 c、全 d 以及相应终态标签即可见三维。
* k=h：只有 a/b；终态始终为 (x,y)，全部四标签张成 span_Q{1,x,y,xy}，秩4。
* 1≤k<h，恰好h次：至少含一个c/d。读出行落在 span_Q{1,x,y,X,Y}。比较在 a/b 之前与之后应用 c/d 的词，四标签可以分别区分 x、y、X、Y，加上常数，因此秩5。
* 1≤k<h，累计至多h次：另外包含不使用c/d、长度恰为k的 a/b 词，四标签再提供独立的 xy，秩6。

该六元函数集在9个DFA状态上独立：x、X通过qA=0,1,2区分，y、Y通过qB=0,1,2区分，xy具有双变量耦合，无法被单变量函数线性表示。每端点其余读出均在对应张成空间。不同目标d为不同输入坐标纤维的直和，三个通道的状态也独立；正的非零后缀权重仅将各观测行作非零倍缩放，不改变秩。

边界 k=h 共有h+1个端点；内部 1≤k<h 共有 (h-1)(h+2)/2 个；原点是一个。于是每通道恰h次秩：

    3 + 4(h+1) + 5(h-1)(h+2)/2
    = (5h²+13h+4)/2.

累计至h次则是：

    3 + 4(h+1) + 6(h-1)(h+2)/2
    = 3h²+7h+1.

乘三个彼此独立的有类型通道完成证明。因 O=R∘T 蕴涵 ker(T)⊆ker(O)，任何充分线性可加表示维数至少rank(O)；取输出行空间坐标实现等号，故也是抽象最小维数。

验算值 (h=1,2,3,4)：恰h次 = 33,75,132,204；累计至h = 33,81,147,231。此前EC49CH/CI中的33、75、81是同一定理的特例。

## 定理 C：滚动 h=3 的一步更新需要新增84维

记 T3 = O_(S^≤3)，U_s 为将固定完整操作s追加到所有当前路径上。由有序拼接：

    T3 ∘ U_s = O_(s S^≤3).

存在良定义的有理线性状态更新 L_s 满足 T3∘U_s = L_s∘T3，当且仅当 ker(T3)⊆ker(T3∘U_s)。这由核包含判据及线性商映射的普遍性质直接证明。

对真实路径长度所有偶数n≥12，一步联立读出的精确秩由逐纤维有理消元和n=12的模非零真实路径子式证明：

    (T3,T3∘U_a): 195,  新增48
    (T3,T3∘U_b): 195,  新增48
    (T3,T3∘U_c): 159,  新增12
    (T3,T3∘U_d): 159,  新增12
    (T3,全部四个T3∘U_s): 231, 新增84.

末行的所有后缀并集正是S^≤4，且对n=12的15个端点的非零模子式给出真实最小维数231。这里的84维是在该输入空间中预测“再进行一步”的精确最小附加线性信息，不能据此声称可以无限递归更新。

严格反例：n=8令 p=(+E1)^8，r=(+E3)^8，两者所有S^≤3读出皆为0，因为 p 最多抵消6个E1，r的E3分量不变；统一追加a后再观察a³，p·a⁴返回原Cell、标签00、三个通道权重为(256,6561,1)；r·a⁴仍未闭合，三通道全0。故T3并不满足单步更新保真核条件。
