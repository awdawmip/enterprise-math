## 解析定理 A：形式秩393、453

所有可返回目标是 `D6={(2i,2j,0,0,0,0):i,j≥0,i+j≤6}`，共28个纤维。每一纤维对9个 DFA 状态列出所有后缀/标签的精确0/1行向量。置 `k=i+j`，单通道形式秩为：k=0时3；1≤k≤5时，`S^6` 为5、`S^≤6` 为6；k=6时4。逐行有限域消元得到相应值（由本轮独立检查器重新覆盖）；0/1矩阵至多9列，相关整数子式绝对值≤9!<1,000,003，所以模1,000,003秩等于有理秩。28个空间纤维直和，三个类型通道再次直和，故

```
rank_Q O_(S^6)   =3*(3+20*5+7*4)=393
rank_Q O_(S^≤6) =3*(3+20*6+7*4)=453
```

这**不是**宣称任意短的真实路径已经达到形式状态秩。

## 解析定理 B：n=14真实秩为381和441

本轮使用精确整数路径加权/DFA生成各目标真实有序14步证书。26个非极端纤维的显式非零模子式使其达到形式上界；极端 `(12,0,0,0,0,0)`、`(0,12,0,0,0,0)` 各只有6维，而形式每个12维。

严谨上界：以极端12E1为例，14步必须含12个+E1加一次正负抵消对，或13个+E1和一个-E1；可以返回的唯一六操作词是 a^6，仅有负E1，故不新增A/B。00标签的3个类型通道最多张成3维；A-only、B-only、AB标签都需要唯一那对+E2/-E2，因而各标签的正权向量固定，至多各1维。合计至多3+1+1+1=6。交换E1/E2得另一极端。实际6个路径的非零模子式使上界达到。故真实秩严格为

```
rank_Q O_(S^6, n=14)   =393-2*6=381
rank_Q O_(S^≤6, n=14) =453-2*6=441
```

其余26纤维的真实路径子式为下界，不是单纯采样无反例。

## 解析定理 C：n=16全部饱和，且为最早长度

在上述26个非极端纤维，把各14步证书路径前缀加上(+E3,-E3)。位移零，连接处不产生A/B，原有A/B标签不变；两个权通道各乘3、路径计数不变。三通道作非零对角变换，所有已证书化子式仍非零。
