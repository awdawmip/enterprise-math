## Question and exact model

Each word uses one positive-integer complete BRC key `K=(x,y,z)`; different paths may use different keys, with the ordinary native ordered signed-X6 microstep prefix-union cost. This is a **two-window subproblem**, not the original twenty-two-demand mother objective.

## Theorem A — universal two-key upper bound

For all integers `4<=a<b`, there are explicit eight-word constructions using **exactly two distinct complete cache keys** with cost at most
```text
U(a,b) = min(4*a+16+8*(b-a), 4*b+30).
```
Both terms are achieved by specific constructions, so `C_min(a,b) <= U(a,b)` for the unrestricted-key problem and the <=2-key problem.

*Extension family.* For any h>=4 take the four source words
```text
sig4: f e g^(h-3) c       sig2: f e g^(h-3) d
sig8: g f e g^(h-4) c   sig1: g f e g^(h-4) d.
```
They share `K_h=(4,h-2,1)`, achieve cost `4h+16`, and have four distinct terminal native paths. For window b, append `g^(b-a)` to each window-a word. The nine-state observer signature is unchanged and the full key is `K_b=(4,b-2,1)`. Each of the four distinct terminal paths acquires `2(b-a)` new signed-X6 microsteps, all new to the previous prefix union: total `4a+16+8(b-a)`.

*Independent-optimum family.* Instead use the four displayed source words independently at each of the two windows. The larger-window prefix union alone costs `4b+16`. At each of the two shared long trunks, the earlier-window pair splits into a c-ending and a d-ending branch where the later trunk continues with g. The c-branch adds four new native-prefix edges; the d-branch shares its first +2 microstep with g but diverges at the second microstep, adding three. This is `7+7=14` additional edges: combined cost `4b+30`.

The crossover is `b-a=4`: the extension construction is shorter for gaps 1,2,3; the independent-optimum construction is shorter for gaps >=4. These are upper constructions, not a universal lower-bound claim.
