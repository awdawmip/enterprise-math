## New usable lower-bound interface

For a depth `d`, define a feasible coalition `A⊆{0,...,4}` exactly when `∩_{i∈A}P_i(d)≠∅`. The finite theorem means that coalition feasibility is completely determined by pair and **triple** intersections for this catalog; explicit four/five intersection tests may be omitted *after* this certificate is accepted at its stated source pin.

For the existing EC49EXY conservative per-fiber distinct-prefix requirements `q_i(d)`, the integer multicover relaxation
`min sum_{A feasible, A nonempty} x_A` subject to `sum_{A contains i} x_A >= q_i(d), x_A in Z_{>=0}`
is a valid **per-depth lower bound** on physically realized distinct prefixes. Reuse the existing `q_i(d)` and original observation-matching inputs; distinguish this relaxed bound from complete native-path realizability and from a global 76-edge exclusion certificate.

A simple immediate inequality: if a three-fiber coalition `{i,j,k}` has empty triple intersection, every physical prefix serves at most two of them, hence the number `N_d` of realized depth-`d` prefixes obeys
`N_d >= ceil((q_i(d)+q_j(d)+q_k(d))/2)`.
This is a strict higher-order structural constraint, although its numerical value need not improve the previous bound in every schedule.
