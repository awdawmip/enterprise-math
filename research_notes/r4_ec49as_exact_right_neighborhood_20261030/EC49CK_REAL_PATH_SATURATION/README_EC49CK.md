## 2. 定理 A：h=5 的精确抽象秩

由 EC49CJ 的逐目标端点 DFA 行空间定理，任意 h≥1 有

```
rank_Q O_(S^h)    = 3*(5h²+13h+4)/2;
rank_Q O_(S^≤h)   = 3*(3h²+7h+1).
```

因此 `h=5` 两种形式空间秩分别为 **291** 和 **333**。全部后缀只观察21个相对 Cell 目标纤维：

`D_5={(2i,2j,0,0,0,0):i,j∈N, i+j≤5}`。

各纤维内，DFA行空间秩是 `k=i+j=0` 时3，`k=5` 时4，`1≤k<5` 时对恰好5次为5、对最多5次为6；乘三个独立有类型通道。对不同空间端点的读出是直和，故得到以上值。这里“抽象”的输入允许独立形式状态 `(z,q,t)`，短的真实原生路径不一定能填满它。

## 3. 定理 B：真实路径 h=5 的最早饱和长度严格等于14

对长度 n 的**全部真实原生六轴有序路径**构成的有理线性包，精确结果为：

| n | `rank_Q O_(S^5,n)` | `rank_Q O_(S^≤5,n)` |
|---:|---:|---:|
| 12 | **279** | **321** |
| 14 | **291** | **333** |

且对于每个偶数 n≥14，两个秩一直分别为291和333；所有奇数 n 两个秩均为零。因此 `n_sat(5)=14` 是不限制n奇偶时的最早饱和长度，不只是一次有限采样的经验阈值。

**证明的上界/缺口部分。** 对 n=12 的极端目标 `d=(10,0,0,0,0,0)`：任何路径至少使用十次 `+E1`，另外恰好两步只能形成同一轴的一个正负抵消对。若末端 A/B 标签非00，必有一次 `+E2` 和一次 `-E2`，所以其三个有类型读数来自固定权重向量 `(3·2^10,2·3^10,1)`，分别在01、10、11三类每类至多一维。00类在三个有类型通道内至多三维。因此整个极端纤维的有理秩最多 `3+1+1+1=6`，而抽象边界要求12维，至少亏6。对调1、2轴得到另一个极端目标 `d=(0,10,0,0,0,0)` 同样亏6。其余19个纤维的整数满秩子式均在素数 `p=1000003` 下非零；两个极端纤维有各6条真实路径给出6秩非零子式。故对 n=12 的真实有理秩 **恰为** 291−12=279、333−12=321，而不仅是模p下界或计算估计。

**满秩证书。** 对 n=14，21个端点的四标签、三个BRC类型通道，针对 `S^5` 和 `S^≤5` 分别选择了291和333条字面真实长度14路径。每端点一个方阵，其每行是实际后缀/标签/通道读出、每列是字面路径，21个方阵行列式模 `1000003` 全部不为零。因此整数行列式非零，有理秩至少291/333；由定理A上界达到等号。证书由 `VERIFY_EC49CK.py` 精确路径生成和 `RECHECK_EC49CK_INDEPENDENT.py` 独立逐字串/权重/行列式复核。完整字面路径保存在项目本目录 `EC49CK_CERTIFICATES.tar.xz.b64`（解码后tar.xz含四份JSON），不是随机模拟的证明替代。

**所有更大偶数长度。** 在任一真实路径最前面插入原生回路 `(+E3,-E3)`，其位移为零，且不制造 A/B 子串或跨边界 A/B。它将每条路径的两个 BRC 通道同时乘3，计数不变，因此所选路径形成的读出矩阵每个通道整体按非零常数缩放，秩不下降。重复插入给出所有偶数 n≥14 的满秩证书。奇数 n 时路径相对位移各分量之和为奇数，但所有目标 `D_5` 的分量和均为偶数，不可能被任何后缀闭合，故读出为零。此前更小偶数n不足饱和，由相同回路的可达嵌入，秩随偶数长度单调不减，且 n=12 仍缺12维。证毕。

## 4. 定理 C：任意h的必要下界，及 h=4 一步滚动增量

对任何整数 h≥1，`S^h` 或 `S^≤h` 的真实路径首次饱和长度若存在，必满足

`n_sat(h) ≥ 2h+4`。

证明：边界纤维 `d=(2h,0,0,0,0,0,0)` 抽象秩为每通道4，总12维。n<2h不能到达；n=2h仅有 `(+E1)^{2h}` 一条路径，秩最多1；n=2h+2只有上述同轴一对抵消步，三类非00在每类各至多1维，00至多3维，合计最多6<12；奇数长度始终因位移奇偶性不可达。故在 n≤2h+2 均不可能饱和。这里证明的是**必要下界**，尚未证明所有 h 均达到它；本轮严格证明 h=5 达到。

累积窗口 `S^≤4` 在 n=12 已饱和，秩231；`S^≤5` 秩在 n=12 为321，在 n=14 为333。因为 `S^≤4 ∪ ⋃_{s∈S}sS^≤4 = S^≤5`，保留对全部四种操作的一步滚动预测时，相比静态四次窗口最小线性状态，n=12 必须增加 **90** 维；n≥14 则增加 **102** 维。这个数是声明观察与下一步操作集合的最小**联合读出**容量，不等于已经建立可无限滚动的有限维更新器。

- 真正执行六轴路径权重的精确整数分支DP，按目标反向可达锥剪枝；缓存的 `min_{d∈D_5}||z-d||_1` 是整数精确几何条件，奇偶条件对偶数 n 与偶数目标自动满足。并不是用其它传播器代替BRC。

- 逐字面路径（包括跨拼接边界）独立扫描 `(+E1,+E2)`、`(+E2,+E1)`；各块重新构造整数读出矩阵、验证模p秩和非零行列式。模p满秩只用来证明有理秩**下界**；有理秩上界来自第2节解析定理和第3节抵消对计数上界。

- 无权路径数、两加权通道是不同类型，且A/B是独立标签；未声称原生 `endpoint_weight` 自身直接实施标签筛选。结论只在声明模型/观察/有理线性加性状态范畴内成立，不涉及物理时间、原生相位相消或无限未来最小记忆。
