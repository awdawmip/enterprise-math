## 定理：精确交换图、单操作秩与联合六维核
固定 h≥1 和偶数历史长度 n≥2h+6；记 N_h=(h+1)(h+2)/2。
对 e∈S 定义右移 T_e: Y_(h+1,n)→Y_(h,n+len(e))：
    (T_e y)_w = y_(ew),  w∈S¹∪…∪Sʰ.
严格交换等式是 T_e(O_(h+1)(p))=O_h(pe)，即使两历史长窗口读数相同也可无歧义计算更新后的短窗口。未引入除已观测长窗口以外的隐含全历史恢复。

精确有理秩和核为：
    rank(T_a)=rank(T_b)=3(4N_h-1);
    rank(T_c)=rank(T_d)=6N_h;
    rank(T=(T_a,T_b,T_c,T_d)) = D_(h+1)-6 = 9h²+39h+27;
    dim ker(T)=6.
令 π_h 为长窗口到当前短窗口的原坐标投影，则 ker(T)∩ker(π_h)=0，因而 rank(π_h,T)=D_(h+1)。六维信息对四种下一次更新后的所有短窗口都不可见，但在当前窗口仍可见；它不能从未来观测自动恢复，除非当前也被保存。该结论是有限窗口的加性有理线性最小态，而非无界递归固定容量定理。

## 全 h 解析证明
所有操作具有非正 E1/E2 的净位移。返回目标纤维是 d=(2i,2j,0,0,0,0)，i,j≥0，k=i+j。每个操作正权非零，附加词的通道乘子不改变 DFA 行秩；依 EC49CN 对 n≥2h+6 的真实路径载体饱和，各目标的三个带类型通道独立。

记 F_A=1[qA=2], F_B=1[qB=2], u_A=1[qA=0], u_B=1[qB=0]。在八个真实可达 DFA 状态上，四个联合完成标签的行空间是 span{1,F_A,F_B,F_AF_B}（维数4），加 u_A,u_B 为维数6。

单前缀 a/b 从负步开始并以负步结束，抹去尚未完成的等待状态，只保留完成旗标。在余后缀 v∈S¹..Sʰ 的 k=0 纤维，后续 c/d 只能生成 span{1,F_A,F_B}（秩3）；k≥1 时可选全负后缀 a^i b^j（长度k≤h）生成四个联合完成标签（秩4）。余后缀有 N_h 个目标纤维，因此每类型为 3+4(N_h-1)=4N_h-1 维。

单前缀 c 使 A 永久完成，B 的完成性仅取决于此前 qB是否非0；单前缀 d 对称。每个余后缀纤维的读数行空间最多2维；k=0 可选 c/d，k≥1 可选全负后缀，均达到2，故每类型为 2N_h 维。

联合 T 的所有读数正好是完整操作词长为2..h+1的读数。在其目标 k 纤维上逐一精确求秩：
    k=0：cc,dd 等生成 span{1,u_A,u_B}，秩3；
    k=1：ac/ad 等生成 1,F_A,F_B，ca/da 等生成 u_A,u_B，
         因至少包含一次 c/d，缺失 F_AF_B，故秩5；这种目标仅两个；
    2≤k≤h：长度k≥2的全负词保留四个完成标签，插入 c/d 给 u_A,u_B，秩6；
    k=h+1：只能全负词，秩4。
这些表达在八个状态上均可直接精确求秩。N_h=Σ_(k=0)^h(k+1)，故单类型秩
    3 + 2·5 + 6(N_h-3) + 4(h+2) = 6N_h + 4h + 3.
乘独立三通道得 3(6N_h+4h+3)=D_(h+1)-6。相比完整长窗口，只有 k=1 两目标各缺一个 DFA 联合相关方向，故联合核恒六维。

核生成方向在这两个纤维的每个通道均可写成
    Δ = δ_(qA,qB)=(0,0) - δ_(2,0) - δ_(0,2) + δ_(2,2).
Δ 对 1,F_A,F_B,u_A,u_B 均消失，而对 F_A F_B 的作用为1。所有词长至少2的回原点观察因而无法区分 Δ，长度1的 a 或 b 能区分。三通道独立且两位移纤维独立，得到6个基向量，π_h 在其核上的限制单射，证毕。
