# BRC Newton fiber-sum operation-safe quotient

Date: 2026-09-04
Mode: TASK_RESEARCH
Status: research candidate; no Foundation promotion in this note
Parents: WBRC-T55; T6_OPERATION_SAFE_QUOTIENT reuse principle

## 1. Question

WBRC-T55 gives the exact affine pushforward of one Newton Taylor atom:

(sigma,k,a) -> (rho,k,a),

where

rho = sigma theta^(k-r).

The residual Newton jet aggregates all atoms with the same residual scale rho and Taylor degree k.  This immediately raises a semantic compression question:

> once the Newton observer is fixed, exactly which source-level provenance may be forgotten without changing the complete residual jet or any later deterministic Newton operation?

This is an operation-safe quotient problem, but it is not the finite deterministic-state partition problem implemented by `src/enterprise_math/operation_quotient.py`.  Here the source state is a finite rational linear coefficient state and the observation map is a fiber-sum linear map.  The T6 reuse is conceptual: quotient exactly by equality of future-observable state.

## 2. Finite source Taylor carrier

Fix:

- a finite set I of source Taylor atom positions;
- for each i in I, a source Newton scale sigma_i in S_rad;
- a Taylor degree k_i >= 0;
- a fixed selected-root multiplicity r;
- a fixed Newton scale theta in S_rad.

Let the coefficient vector be

A=(a_i)_{i in I} in Q^I.

Define

rho_i = sigma_i theta^(k_i-r)

and the residual coordinate

c_i=(rho_i,k_i).

Let C be the finite set of distinct coordinates c_i.

## 3. Fiber-sum observer

Define the linear map

Pi : Q^I -> Q^C

by

Pi(A)_c = sum_{i:c_i=c} a_i.

The residual Newton polynomial at scale rho is

Q_rho(y)=sum_k Pi(A)_(rho,k) y^k.

Thus Pi(A) is exactly the coefficient form of the complete residual Newton jet after scale pushforward and before dropping zero scale polynomials.

## 4. Exact equivalence theorem

For source states A,B the following are equivalent:

1. their complete residual Newton jets are identical;
2. Pi(A)=Pi(B);
3. for every residual coordinate (rho,k), the corresponding fiber sums agree.

Hence define

A ~_Newton B iff Pi(A)=Pi(B).

This is the exact observer equivalence for the complete residual Newton jet.

## 5. Kernel generated by within-fiber transfers

For each nonempty fiber F_c choose one anchor i_c in F_c.  For every j in F_c\{i_c}, define the elementary transfer vector

t_{c,j}=e_j-e_{i_c}.

Then

ker Pi = span_Q { t_{c,j} }.

Proof:

- every t_{c,j} has zero sum in its one fiber and is therefore in ker Pi;
- if D in ker Pi, then in fiber c the anchor coefficient is minus the sum of the non-anchor coefficients, so

  D|_{F_c} = sum_{j != i_c} D_j (e_j-e_{i_c}).

Therefore the only source-level freedom forgotten by the residual jet is rational redistribution of coefficient mass inside one fixed (rho,k) fiber.

Dimension:

rank Pi = |C|,

dim ker Pi = |I|-|C|.

## 6. Quotient is canonically the residual coefficient carrier

By the first isomorphism theorem,

boxed:
    Q^I / ker Pi  ~=  Q^C.

Under this isomorphism, a source Taylor state class is represented exactly by its residual Newton coefficient table.

This gives a precise mathematical meaning to the provenance-loss statement in WBRC-T55.

## 7. Coarsest full-residual-observer-safe quotient

Any equivalence relation E on Q^I that preserves the **complete residual jet** must refine the kernel equivalence:

A E B  =>  Pi(A)=Pi(B).

Necessity is immediate because Pi itself is the declared observation.  More explicitly, if one residual coefficient differs at c=(rho,k), the coordinate probe

O_c(A)=Pi(A)_c

distinguishes the source states.

Conversely equality under Pi is sufficient for every deterministic downstream operation F whose input is only the residual Newton jet:

Pi(A)=Pi(B)
=> F(Pi(A))=F(Pi(B)).

This includes, whenever their typed domain conditions are satisfied:

- semantic zero removal;
- scale ordering;
- edge-fiber extraction;
- contact-order/root analysis;
- later `rational_newton_step` / selected-root continuation;
- any further deterministic composition of such operations.

Thus `ker Pi` is the coarsest exact quotient for the **full residual-jet observer** and all future operations that factor through it.

## 8. Two coordinates must remain distinct

### Different residual scales cannot merge

If rho_1 != rho_2 but k is the same, merging the coordinates would lose the residual scale spectrum.  A direct coordinate probe distinguishes them, and later Newton scale ordering can distinguish them operationally.

### Different Taylor degrees cannot merge

If rho is the same but k_1 != k_2, the residual polynomial shape changes.  For example coefficients at y^0 and y^1 have different contact orders at y=0 and therefore different later Newton behavior.

Hence the correct fiber key is exactly

boxed:
    (residual scale rho, Taylor degree k),

not scale alone and not degree alone.

## 9. Source splitting and relabeling invariance

A source atom may be split into several labeled atoms in the same (rho,k) fiber provided their coefficients sum to the original coefficient.  The residual Newton state is unchanged.

Likewise source labels and enumeration order are invisible after Pi.

This is a quotient of **algebraic source provenance**, not of explicit positive branch provenance before determinant/characteristic compression.

## 10. Signed-compression boundary

Taylor/characteristic coefficients can be signed.  A pair +a and -a in the same fiber can cancel completely under Pi even though both source atoms are nonzero.

This is not signed/amplitude branch cancellation.  It occurs in the algebraic compression layer after the positive branch semantics have already been mapped to characteristic/Taylor data.

## 11. Edge-only observer is strictly coarser

This theorem is for the **complete residual Newton jet**.  If an observer asks only for the next edge polynomial (rho=1), all rho<1 fibers are currently invisible and a strictly coarser quotient is possible.

Likewise a one-step-only observer may be coarser than an observer that preserves the full residual jet for later recursion.

Do not promote the full-residual quotient as minimal for weaker observer contracts.

## 12. Relationship to T6

T6 `operation_quotient.py` computes the coarsest finite partition refinement for deterministic endomaps and a finite observation partition.  The present theorem is a linear/fiber specialization with a different executable carrier:

- T6: finite set states + deterministic maps;
- T56 candidate: finite rational coefficient space + linear fiber-sum observation.

No change to T6 is proposed.  A future Foundation tool, if extracted, should remain under T0_BRC and record `REUSE_PRINCIPLE_FROM_T6` rather than pretend the existing T6 executable directly solves this linear problem.

## 13. Exact validation requirements

The dedicated checker must:

1. enumerate finite source-position layouts with rational valuation scales and Taylor degrees;
2. construct Pi and its fibers independently of production `rational_newton_pushforward`;
3. verify production residual jets equal Pi aggregation;
4. exhaust within-fiber transfer generators and confirm they leave the residual jet unchanged;
5. decompose arbitrary zero-fiber-sum difference vectors into anchor transfers;
6. verify rank Pi=|C| and kernel dimension |I|-|C| by exact rational row reduction;
7. verify coordinate probes distinguish every altered fiber sum;
8. give explicit different-scale and different-degree no-merge witnesses;
9. verify source splitting/relabeling invariance;
10. construct equal-Pi source states and run a valid later `rational_newton_step`, confirming identical future results;
11. freeze an edge-only observer witness showing that the full-residual quotient is not claimed minimal for weaker observations.

## 14. Hard boundaries

- FIBER_SUM_QUOTIENT != SOURCE_BRANCH_PROVENANCE_RECOVERY.
- FULL_RESIDUAL_MINIMALITY != EDGE_ONLY_MINIMALITY.
- DIFFERENT_SCALE_COORDINATES do not merge.
- DIFFERENT_TAYLOR_DEGREES do not merge.
- ALGEBRAIC_COEFFICIENT_CANCELLATION != SIGNED_BRANCH_MASS_CANCELLATION.
- T6_REUSE_PRINCIPLE != T6_EXECUTABLE_REUSE.
- No infinite-dimensional, arbitrary coefficient-field, or generic linear-systems novelty is claimed.
