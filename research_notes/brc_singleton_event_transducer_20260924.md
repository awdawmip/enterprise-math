## 2. Signed singleton displacement

Define three provenance-preserving local observables:

`H_p(j)=1_((p-1)|2j)`  (harmonic-endpoint port),

`beta_p(j)=2j+1-H_p(j)-D_p(j)+C_p(j)`.

Hence define the signed singleton displacement

`Delta_p(j):=beta_infty(j)-beta_p(j)`.

The exact formula is

`Delta_p(j)=H_p(j)+D_p(j)-C_p(j)`.

This scalar is only a post-observer summary. The typed triple `(H,D,C)` is the BRC carrier and must be retained whenever later arithmetic needs to distinguish endpoint, denominator, and coefficient-cancellation provenance.

### Visibility interval

`G_p(j)=2j+2`,

`B_p(j)=beta_p(j)+1=G_p(j)-Delta_p(j)`.

## 3. Class `19 mod 24`: endpoint and denominator events only

Then `p == 3 (mod 8)`, so `(2/p)=-1`, while `v_2(p-1)=1`. Consequently `ord_p(2)` has exactly one factor of `2`; after squaring,

`ord_p(4)` is odd.

An element of odd order cannot have a power equal to `-1`. Therefore

`C_p(j)=v_p(1+4^j)=0`

Hence the exact singleton classifier is

`Delta_p(j)=H_p(j)+v_p(j)`.

## 4. Class `13 mod 24`: cancellation is a fixed-depth pruning state
