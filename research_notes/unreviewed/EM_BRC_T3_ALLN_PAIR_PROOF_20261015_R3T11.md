# Exact lower-bound proof (unreviewed BRC T=3)

Definitions: source indices I={0,...,n-1}; each allowed operation G_j=I minus {j} secretly resets one source. Residual total D is nonincreasing. Feedback after an operation is [D>=3]. Output is the universal predicate that all terminal hidden paths satisfy D>=Q. No initial feedback is observed.

**Q=1, n>=3.** Compare X=(1,...,1) and Y=(1,...,1,2). Until all n sources have been reset, D>=1 in both states; thus no strategy with <=n-1 moves can distinguish them. For n-move separation, apply G_0 for n-1 moves followed by G_1, continuing only along feedback bits 1 repeated n-2 times, then 0 and 0. For Y choose hidden sources 1,2,...,n-1,0. The first n-2 resets leave mass 3, the heavy reset leaves mass 1, and the last reset leaves mass 0. For X, source 0 cannot reset during the first n-1 moves, hence early stopping is safe. Any X path reaching move n has mass >=3 after move n-2, hence >=2 after move n-1 and >=1 after move n. X is universally safe; Y has an unsafe path. Therefore this pair first separates at depth n.

**Q=2, n>=2.** Compare X=(1,...,1,3) and Y=(1,...,1,2). For either state to become unsafe within <=n-1 moves, the last heavy source and >=n-2 distinct light sources must have been reset. Before the first heavy reset at least one light remains, so both states report HIGH (Y mass >=3, X mass >=4). After that heavy reset, their residual configurations coincide; identical subsequent secret selections yield identical feedback and unsafe terminal status. Every unsafe path on either side therefore has a feedback-compatible unsafe counterpart on the other side. Hence all policies of depth <=n-1 have equal universal safety outcomes. For length n, perform G_(n-1) n-1 times and then G_0, proceeding only on feedback 1 repeated n-2 times then 0. In Y choose light sources 0,1,...,n-2 followed by the heavy source. Its penultimate mass is 2, final mass 0 (unsafe). X has heavy mass 3 throughout the first n-1 operations, so never follows the penultimate LOW branch and stops safely. This pair first separates at n.

These are exact all-n **pair-depth lower bounds** H_n>=n, NOT a proof of a whole-space upper bound H_n<=n. The model is an external positive-support BRC Boolean observer, not a native six-axis dynamics theorem.
