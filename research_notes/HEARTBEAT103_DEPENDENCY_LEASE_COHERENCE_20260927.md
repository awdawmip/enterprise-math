## 1. Exact dependency reuse and executed lifecycle repair

For a trusted actually certified bank B, let A_B(m) be its raw signed integer numerator action and d_B(m) its existing positive denominator. For w=(m1,...,mk) in execution order, F_B(w,x)=A_B(mk)...A_B(m1)x and d_B(w)=product_j d_B(mj). Complete descriptors include exact class, scalar types/values, immutable payloads and source, plus the actual root descriptor and direction scale for fused powers. Method identity/code is verified separately. Descriptors are compared as complete canonical bytes; dictionary hashes only locate candidates.

If corresponding ordered descriptors in two valid banks agree, every single-step raw action and denominator agrees. Induction gives F_B(w,x)=F_C(w,x) and d_B(w)=d_C(w) for every full integer row x. No commuting or nominal-phase quotient occurs. This is sufficient, not necessary/minimal operator equivalence. Changing unused bank entries does not invalidate that word's proof. Changing actual root4 changes both level4 and its actual squared level3; other unchanged dependencies can share across t8/t10/t12/t14 or independently reconstructed identical banks.

A Registry interns complete descriptors into monotone, never-recycled tokens. A row key is the ordered token sequence plus the complete signed 61-component row. A SharedMemo is tied to one exact Registry instance: unrelated registries may both number a token 1. Release decrements descriptor references and revokes only that lease; independently issued equal leases survive. All descriptors may be removed without making surviving old row entries alias newly assigned tokens.

An actual Stage102 hole was reproduced: an instance-level apply_numer replacement left the class method unchanged, so the old LiteralBankHandle.check_all passed. The new BankLease checks the actual bound receiver/function, instance namespace, function code/defaults, fused row validator, and the existing complete scalar/payload/root binding. A detected supported scientific mismatch revokes before cache lookup. Restoring bytes or clearing the cache does not revive that lease. Reissue uses a trusted builder with actual complete-column certification; arbitrary pre-registration hand-edited banks are not admitted by a checked counter.

Final code passed 2196 full-basis row comparisons and 15 rejecting cases. The cases include instance/class/function-code replacement, denominator/root changes, equal-content tuple replacement, bool aliases, missing t12 coverage, irreversible revocation, and a foreign registry on the same memo. Four direct fused forward/inverse checks on two banks produced 54 new actual BRC core calls in the safety run. These are correctness guards, not a sandbox against arbitrary hostile Python mutation. Imported helpers, metadata and module globals remain trusted; execution is single-threaded, with no scientific mutation inside a sample or after obtaining an already-prepared child object.

On a cache hit the exact prior F_B value is returned; on a miss the unchanged actual function executes. Finite-sequence induction preserves full fields, external signed/denominator factors, conditional probabilities and, for the same tape, random requests and RNG states. Eviction and clearing change recomputation, not the residual field.
