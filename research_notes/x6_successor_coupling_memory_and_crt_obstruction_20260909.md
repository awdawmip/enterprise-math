## 0. 问题、已恢复成果与类型边界

本轮接续父笔记的最小未完成单元：在 C_n <- C_(n(n+1)) -> C_(n+1) 中，如何选择加一的分支；要求什么对称性、保留什么状态、付出多少分支/精度成本。

沿用 X6 的锚点相对 G=Z^6、signed native steps 与 Q(z)=sum z_i^2；不改变 P000。普通自然数加法仍满足 1+1=2。父笔记的 index 家族 L(n)、整除输运和3/6素数闭合不重做、不提升地位。

必须分开两种接口：

1. **原生子格的商观察** C_n=G/L(n)，使用父笔记的真实商映射、共同平移作用及其 CRT 关系。
2. **显式有序编号观察** R_n={0,...,n-1}，把编号按区间位置排列。这只是一个附加的顺序/相位模型，不自动是 C_n 的原生度量或其自然商映射。

两个集合都含 n 个元素，不能据此把它们的乘法细分、概率测度、邻接和群作用识别为同一结构。下文的“局部”专指有序编号 j=i 或 i+1，不指 X6 的一个单位 Cell 步。

## 1. 定理 S1：相邻商层的共同平移等变核只能完全遗忘旧余类

设 G 是阿贝尔群，L_n、L_(n+1) 的有限指数分别是 n、n+1，C_k=G/L_k。则

    L_n+L_(n+1)=G,
    G/(L_n intersection L_(n+1)) ~= C_n x C_(n+1).

证明：和子群的指数整除 n 与 n+1，故为1；标准商映射的核为交集，且由和子群等于 G 得满射。父笔记的族还给出交集 L_(n(n+1))。

因此，G 对 C_n x C_(n+1) 的共同平移作用是传递的。要求随机核满足

    K(c+g,d+g)=K(c,d)  for every g in G

时，它在所有 (c,d) 上取同一常数。每行和为1，故唯一可能是

    K(c,d)=1/(n+1).

结论：只观察当前商余类、并保留这个完整平移等变条件，不能得到有预测性的加一核。确定性等变映射同样不存在，因为它需要 L_n subset L_(n+1)，与指数不整除矛盾。

若共同层 C_(n(n+1)) 上使用均匀测度，两个投影的联合分布也是

    Pi_n(c,d)=1/[n(n+1)],

即独立均匀。这是明确的观察/对称性排除，不是对所有隐藏状态或物理局部运动的排除。甚至微观固定平移 x -> x+v 本身可以是局部的，而在均匀共同层上投影后仍失去上述跨模数相关性。不能把“商观察不局部”偷换为“实际运动不局部”。

## 2. 定理 S2：两个均匀人口的最小正权分支数为 m+n-gcd(m,n)

设 P 为 m 个源状态与 n 个目标状态的非负耦合，边际各为均匀分布。在正权支持的二部图中，每个连通分量若有 r 个源顶点、s 个目标顶点，则总质量守恒给出

    r/m=s/n.

写 g=gcd(m,n)。存在正整数 a，使 r=a*m/g、s=a*n/g。所有分量的 a 之和为 g，因此分量数至多 g。每个连通分量的边数至少为顶点数减1，故

    #positive_edges >= m+n-g.

上界由标准同一相位/区间重叠耦合达到：

    P_(m,n)(i,j)
      = length([i/m,(i+1)/m) intersection [j/n,(j+1)/n)).

两套分割共有 m+n-g 个非空共同小区间；每个小区间对应一个不同的正权配对。由此得到精确最小值，不是一个仅对所选样本有效的估计。

当目标是 n+1 时，最小值是 2n，而不是 n(n+1)。但这是**改成稀疏的非均匀联合测度**，只保持两边各自的均匀边际；绝不是把独立均匀 CRT 人口无损压缩成2n条原始配对。

分支类型与等权微观个体也不同：若要求每个微观个体等权且两个边际精确均匀，微观人口数必须同时被 n、n+1 整除，至少 n(n+1)。2n 是带权类型数，不是等权人口数。

## 3. 定理 S3：指定“停留或进一格”后，均匀加一核被唯一确定

在有序编号 R_n 上要求 j in {i,i+1}，并要求源、目标分别均匀，联合权重只能是

    P_n(i,i)   = (n-i)/[n(n+1)],
    P_n(i,i+1) = (i+1)/[n(n+1)]       (0<=i<n).

证明：目标0只能由源0供给，确定 P(0,0)=1/(n+1)；源0的行和再确定 P(0,1)，如此沿路径依次确定全部边。所给式直接满足所有边际。

条件概率是

    K_n(i,i)   = (n-i)/(n+1),
    K_n(i,i+1) = (i+1)/(n+1).

这是经典初始红、蓝各一球的 Pólya urn 计数转移：R_n 中的 i 对应前 n-1 次抽取中的红球数。这个经典身份不作原创宣称。本项目的用途是用它检验一个明确的 successor 候选。

例 n=2，联合整数权重（公分母6）为

    [2,1,0]
    [0,1,2].

每行总质量1/2，每列1/3，只保留4条正权边；它不是6个配对等权的 CRT 联合层。

### 可量化的观察差异

与独立均匀 Pi_n 的总变差距离为

    TV(P_n,Pi_n)=1-2/(n+1)=(n-1)/(n+1).

证明：独立分布每格质量1/[n(n+1)]；P_n的2n个正权格均不小于此值，所以两者重叠总质量为2/(n+1)。这也是任何仅支持于这2n格的概率分布与 Pi_n 的总变差下界。

因此，规模增大时两种细粒度联合观察差异趋近1，不能把稀疏改测度说成对全 CRT 分支的微小误差。某个更粗几何观察是否近似，仍须另证。

### 有序度量下的局部性

把 i 放在区间中点 x_i=(i+1/2)/n，j 放在 y_j=(j+1/2)/(n+1)。直接求和给出

    E_(P_n)(x-y)^2
      =(2n^2+2n-1)/[12 n^2(n+1)^2].

它为 O(n^-2)，所有允许位移也小于1/n。标准交换交叉边的证明说明该单调耦合对一维平方代价最优：把交叉边上的相同质量挪到不交叉边，会严格减少代价。这是常规一维有序输运事实，不是新的原生 X6 定理。

## 4. 定理 S4：逐步使用正确单步核，仍可能破坏乘法细分

取一个共同相位 theta in [0,1)，令

    X_n(theta)=floor(n theta).

若 theta 均匀，每一层 X_n 均匀，且每对相邻层的联合律恰为上一节 P_n。但是这些单步联合律不能证明 X_n 本身是 Markov 的。

相位模型还满足有序细分恒等式

    X_(mn)=m X_n+floor(m {n theta}),
    floor(X_(mn)/m)=X_n.

若丢掉相位/历史，直接把 K_2 和 K_3 相乘，得到从R2到R4的条件矩阵

    [1/2, 1/3, 1/6, 0]
    [0, 1/6, 1/3, 1/2].

它有总概率1/6违反 floor(X_4/2)=X_2。而共同相位的真正条件矩阵为

    [1/2, 1/2, 0, 0]
    [0, 0, 1/2, 1/2].

两种联合分布的总变差距离也为1/6。

一个有历史的最小证书是：事件 X2=0、X3=1 等价于 theta in [1/3,1/2)，它强迫 X4=1。若只保留 X3=1，则 theta in [1/3,2/3)，X4=1、2各占一半。相同当前观察产生不同条件未来，正是 T6/BRC 要求保留修复坐标的情形。

这里并不否定 Pólya urn 的合法性；它是另一种合法的全路径概率模型。错误只发生在把两种模型相同的单步边际，误当成它们具有相同的全路径/乘法观察。

## 5. 正面修复：只保存历史允许的相位区间，而不是不断平均掉它

保留截至 n 的全部观察等价于保留半开区间

    I_n=[a_n,b_n)
       = intersection_(1<=k<=n) [X_k/k,(X_k+1)/k).

在共同均匀相位模型中，条件于这段历史的 theta 正好在 I_n 上均匀。下一步最多两个候选 j=X_n 或 X_n+1。定义

    J_j=I_n intersection [j/(n+1),(j+1)/(n+1)),
    Pr(j | I_n)=length(J_j)/length(I_n),
    I_(n+1)=J_j.

这是真实的条件概率更新，不是为修复结果而臆造的 martingale。归纳地，每条可行历史的概率等于其区间长度，区间中的 theta 仍均匀；因而恢复共同相位模型的全部有限维联合律，特别是上一节的二倍细分恒等式。

更新只用有理数比较与长度比，每个状态最多2条正权分支。有限阶段不必储存一个无限精度实数。区间端点的分子、分母至多 n，可以用 O(log n) 位储存这四个整数；这不是常数位内存，也不声称精确随机抽样或遍历整个状态人口的时间为常数。

这个修复保留的是后续条件观察所需的历史区间，不是宣称任意路径的全部有序物理历史都已被安全压缩。允许操作仅为同一相位的整数倍 floor 观察及相应细分/更新。

## 6. 定理 S5：有限观察视野的最小确定性修复区间恰为 Farey 分割

给定H，要求一个状态能够确定同一theta的全部 X_1,...,X_H。所有变化点是

    {k/n: 1<=n<=H, 0<=k<=n}.

约分后就是H阶Farey分数。相邻分数之间的半开区间内，全部观察恒定；任意两个不同区间被某个k/n隔开，因此至少有一个X_n不同。故最粗的观察保持分割，恰有

    S_H=sum_(n=1)^H phi(n)

个区间，取phi(1)=1。这个最小性严格限定于所声明的**全部截至H的floor观察**，不推广成所有物理算法的状态下界。

这是把经典 Farey 计数用于本轮的 T6 修复对象，而不是发现了新的 Farey 计数公式。经典渐近式 S_H~3H^2/pi^2 可从列出的一手文献核对；有限修复定理不依赖该渐近式。

精确例子：S_10=32，S_20=128，S_40=490，S_60=1102，S_100=3044。

增加第H层时新增phi(H)个精度分界，素数H新增H-1个，而合数层也有自己的新分界。不能删掉合数观察，也不能把这个精度人口计数擅自解释为原生素数的唯一生成机制。

无限视野不能用固定有限个确定性状态区分所有theta：若theta<eta，取n使n(eta-theta)>1，即有floor(n theta)!=floor(n eta)。有限有理区间实现则可随视野增长逐步细化。

另一个成本口径：若要用一个有限**等权**微观人口同时生成所有1..H层的均匀边际，人口数必须是lcm(1,...,H)的倍数；该下界由均匀网格theta=t/lcm(1,...,H)达到。等权微观人口数与带不等概率权重的Farey区间类型数不是同一成本。

## 7. 修复后的加法与乘法仍须保留进位

共同相位模型中，令 r_n={n theta}。则精确有

    X_(m+n)=X_m+X_n+floor(r_m+r_n),
    X_(mn)=m X_n+floor(m r_n).

两条式子展示了必须保留的交互量。删掉小数/相位残量后，整数编号本身一般不能回答它们。有限区间方法通过必要时细分来读取这些量，不是假装已知一个点值残量。

这只是有序观察模型中的加法/乘法读出兼容；不能替代父笔记的原生子格整除映射。

## 8. 最重要的防混用结论：共同相位修复不保留原来的全部 CRT 结构

以2、3为例，原生共同商C6到C2 x C3的配对是满射双射，支持有6个元素；共同相位的(X2,X3)只支持4个配对。

即使给R6编号a=0,...,5，令到R2、R3的有序投影分别为floor(a/3)、floor(a/2)，也只有

    (0,0), (0,1), (1,1), (1,2)

四种配对。因此不存在简单重新编号，让这些区间floor投影同时等于原有的两个CRT商投影。

对任意互素m,n>1，相位支持为m+n-1<mn，而原生CRT支持为mn，同样排除。这个障碍在群作用/分支支持层，先于任何浮点误差。

三者目前不能无条件并存：原始CRT商及其均匀/共同平移对称；有序局部successor；丢掉历史后的单状态无记忆实现。不同放松给出不同合法模型，不得在一次推导中偷换。

具体下一单元不是继续拟合一个标量半径，而是明确**需要哪一种均匀性**：原生占据/体积均匀、每个算术商余类均匀，还是所选有序观察均匀。此后才研究把相位区间作为单独的内部状态与原生Cell动作耦合，并对实际X6度量给界。本轮没有完成该原生桥接。
