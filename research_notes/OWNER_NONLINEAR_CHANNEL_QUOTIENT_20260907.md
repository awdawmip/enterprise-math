**结论。** 对下述完整非负有理六通道质量域，只要每个平均操作在观察值上可诱导

冻结一次既有通道标架，令 `C={0,...,5}`，

`X=Q_{>=0}^6`, `L(x)=sum_c x_c`,

`(A_i x)_i=x_i`, `(A_i x)_c=(L(x)-x_i)/5` 对 `c≠i`。

这就是原几何笔记的 C6 通道平均矩阵，列为输入、行为输出。空间仍采用六条原生
轴及十二个 signed primitive steps；C6 的六个质量分量不是新增空间坐标。
本题考察的操作是质量 carrier 上的 A_i，不把带有空间平移的完整
`(z,x) -> (z±E_i,A_i x)` 误说成幂等。

给定任意集合 Y 和映射 `q:X->Y`。对每个 i，要求存在映射 `R_i:Y->Y` 满足

`q A_i = R_i q`，且 R_i 单射。要求双射当然也足够。实际上只需 R_i 在 q(X)
上的限制单射，因为因子化已经保证 `R_i(q(X))⊆q(X)`。不假设 Y 的任何代数或
拓扑结构，不预设 q 满射，不预设各 R_i 交换。

## 2. 幂等加单射：可见操作在实际像上恒等

由公式立即得到 `L A_i=L`、`A_i²=A_i`。对任何 x，

`R_i(R_i(q(x))) = q(A_i²x) = q(A_i x) = R_i(q(x))`。

等式两边都是对 R_i 的求值，其输入 `R_i(q(x))` 与 `q(x)` 都属于 q(X)。单射
因此给出 `R_i(q(x))=q(x)`。于是

`R_i|q(X)=id`，`q A_i=q`。

这里无需对 q 使用满射性；也没有把 R_i²=R_i 从实际像无依据地扩展到 Y。
因此所有由这些 A_i 构成的有限词在 q 上都是恒等。这里说的是任意有限词的
代数恒等，不涉及无限路径极限或收敛。

## 3. 同质量 fiber 的至多五步 gate 连通

若 `L(u)=L(v)` 且 `u_i=v_i`，直接代入 A_i 公式可得 `A_i u=A_i v`。结合上一节，

`q(u)=q(A_i u)=q(A_i v)=q(v)`。

称这种关系为一个 gate 见证。它是两个输入有共同 A_i 像，不是声称通过实际
平均动力学把 u 有向地走到 v。

现在取任意 `L(x)=L(y)`，构造 `x=x^(0),...,x^(m)=y`。若当前点 u 不等于 y，
因为差的总和为零，必同时存在 donor a 与 receiver b，使
`u_a>y_a`、`u_b<y_b`。令

`t=min(u_a-y_a, y_b-u_b)>0`，`v=u-t e_a+t e_b`。

这是精确正有理转移。它保持总质量，且只修改 a、b 两个通道，修改后的值不越过
各自目标。因此每个中间坐标始终位于最初 x_c 与最终 y_c 之间，特别地仍非负。
至少一个尚未等于目标的坐标在这一步到达目标，已到达目标的坐标不会再被选择。
最后一步同时消除一项正差与一项负差；初始最多六项非零差，因此

`m <= (初始不匹配坐标数)-1 <= 5`。

每步选一个 `i∉{a,b}`，这在真实六通道集中总能做到，不添加辅助通道。
于是 `u_i=v_i`、`L(u)=L(v)`，构成一个 gate，故 `q(u)=q(v)`。串接 m 个
等价关系得到 `q(x)=q(y)`。这证明 q 在每个完整总质量 fiber 上恒定。

一种完全确定的算法是每次取最小编号 donor、最小编号 receiver，再取不在二者
中的最小 gate。取

`x=(5,0,0,0,0,0)`，`y=(0,1,1,1,1,1)`，

算法的五个转移依次为 `0->1,...,0->5`，每次 t=1；gate 依次为 `2,1,1,1,1`。
全部原矩阵共同像逐项保存在本工作包的 `certificate.json`。五步是该双通道转移
模型的统一最坏上界，并且这个例子必须向五个最初为零的目标通道分别转移质量，
所以在此模型中不能减少为四步。没有声称任意宽泛 gate 关系也必须用五步。

## 4. 任意集合的完整分类及边界

非负域上可取截面 `s(t)=(t,0,0,0,0,0)`，定义 `f(t)=q(s(t))`，t∈Q_{>=0}。
上一节给出 `q(x)=f(L(x))`。由于 L 满射到 Q_{>=0}，f 唯一。

反过来，任意 `f:Q_{>=0}->Y` 所定义的 `q=f∘L` 都满足 `qA_i=q`；取所有
`R_i=id_Y` 即符合单射乃至双射要求。因此这确为充要分类。f 可以非线性、
非单射、不连续，例如 `f(t)=t²`、`f(t)=1_{t>1}`；它们可以重编码或进一步合并
总质量，不能区别等总质量的通道分布。对任意集合值观察不使用“维数”语言。

若 q 不满射，只能断言 R_i 在 q(X) 上恒等。举例令
`Y=({mass}×Q_{>=0}) disjoint_union {a,b}`、`q(x)=(mass,L(x))`，令 R_i
固定所有 mass 标签并交换 a、b，便是非恒等双射且仍满足合同。更一般地，任何
固定 q(X) 的单射可在未观察到的补集上有非恒等行为。若 q 满射，则 R_i 必在
整个 Y 上恒等。

零质量 fiber 只有零向量，证明与空见证直接适用；未使用除以总质量。边界坐标
为零也允许，不会在质量转移中产生负坐标。若改用严格正域 `X=Q_{>0}^6`，
各 A_i 保持该域；上述中间坐标位于两个严格正端点之间，仍严格正。取截面
`s(t)=(t/6,...,t/6)`，t∈Q_{>0}，同样得到唯一的任意集合因子化。

单射假设不能省略。若仅要求操作能下降，取 q=id_X、R_i=A_i 即满足因子化，
却保留完整分布；R_i 确实不是单射。完整 carrier 也不能任意缩为一个不支持
中间转移的子集后套用本证明。第三个未变通道是 gate 构造的关键；在只有两个
通道的类似定义中，每个 A_i 都是恒等，任意 q 均可通过合同，所以不能照搬
“总质量”结论。

## 5. 对 BRC 信息保留的精确范围

本定理从一开始的 X 就只是通道总质量向量。它没有证明把任意 BRC 对象投影到 X
是安全的，也没有删除直方图、分支标识、路径顺序或内部寄存器。

实际复用原 `paths/observe`，对每个非零输入通道放一条等于该通道质量的正分支。
取 `x=(1,0,0,0,0,0)`、`y=(1/2,1/2,0,0,0,0)`，选 gate i=2。原 A_2 重算
两者得到相同通道质量：i=2 为零，其他五通道各为 1/5。但结果 BRC 直方图分别是

`5[1/5]` 与 `10[1/10]`，

CWM count 分别为 5、10，质量均为 1。现有 WeightHistogram 的实际结果明确不同。
即使 A_i 在质量矩阵层幂等，保留微观分支的操作也不因此幂等。这是本定理不能
跨 carrier 提升的具体阻碍，符合 joint-observer preservation 合同。
