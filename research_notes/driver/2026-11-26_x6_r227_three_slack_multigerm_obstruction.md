## General multiple-germ lemma

A state contains distinct wall labels, each with either all retained nonempty open projective segments or a single oriented endpoint germ (a,b), represented by arbitrarily short positive open intervals (1-epsilon)a+epsilon b. Each state has a necessary meaning: a finite correct linear tree on some positive-length neighborhood of each germ and all full open segments. For any finite tree, all finitely many query signs on each germ stabilize at sufficiently small epsilon, with lexicographic sign sign(q.a) or sign(q.b) if zero. A support-root cut is exact on the full segments and germ labels, and a germ with both signs zero is discharged. The same neighborhood can be shrunk finitely many times. Active support necessity applies to every open germ, hence the usual capacity C=2^d-1. In a non-support query no active label is discharged; a germ cannot duplicate because it has an eventually constant nonzero sign. A full label may duplicate; let D denote these labels. Then |D|<=s-1, s=C-m. An unduplicated full label retains all its open components (possibly endpoints zero, which do not change the open interval). Each duplicated label has at least one strict endpoint in each sign side of its components, so choose one oriented germ per side, independently for each label. This relaxes compatibility but includes the true restriction. Existing germs can be arbitrarily assigned to either branch, relaxing their actual signs; no germ needs to duplicate. For the full segments use the previous weak extreme-ray reduction only when their endpoints span R^3, otherwise pass conservatively: a representative cross-product ray weakens every full-endpoint sign of the true query, so its duplicated labels are a subset of D; at most one full label is erased (a nonzero ray cannot vanish on two distinct support planes). Enumerate every D of size <=s-1 containing the weak duplicated labels; restore any erased unduplicated label on either side; every other unduplicated label is forced by its retained nonzero weak sign. Allocate existing germs independently and test the two children, each with all intact components and one endpoint germ for each label of D. Independent child germ choices only enlarge possible trees. By induction on d every false return excludes a true tree, including states where several germs occur in a nontight subtree. The implementation returns true conservatively for slack>3, rank-deficient full endpoint span or m<=d. For slack=3, b<=2, child slack sum=2-b, so two duplications force both children tight; with one duplication a nontight child is allowed. Constant queries cannot evade capacity in the nontrivial enumerated states; a non-support query with one empty side is included if capacities permit. Signs and clipping use exact BigInt. No global arbitrary quadratic or first-linear-root conclusion.
