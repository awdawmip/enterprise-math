## Lemma: two-slack capacity

For a strict reached region, let m=C-2, C=2^d-1, c=(C-1)/2. A pure-linear depth-d subtree must first use an active support or a nonsupport cut. Support cuts are clipped exactly, recursively. A nonsupport cut duplicates at most one label because m+b<=2c. If b=0, each component stays intact, one strict child has c labels and the other c-1. Enumerate the full-component partitions by the same weak extreme-ray / one-erased-label restoration argument from the prior proof. If b=1, both children have c labels; each contains c-1 intact distinct labels and one copy of the same duplicated label. A nonconstant linear restriction on a segment has a strict sign at at least one closure endpoint whenever it has that sign somewhere in its interior. Thus each copy has a nonzero-length one-sided open segment germ adjacent to some endpoint (possibly different components). Each intact label keeps all of its open components. Apply the weak extreme-ray argument to all original endpoints: at most one whole label can vanish, no new duplication can appear. Choose the unique potential duplicated label, ignore its extreme-ray signs, and restore a possible erased other label to either side. Require c-1 other labels on each side. Every true non-support partition is included. The enumeration may admit impossible partitions; this is a relaxation. For the duplicated label try every oriented endpoint germ separately in each child, deliberately ignoring compatibility across children and with the extreme-ray signs. The true pair of germs is included, so independent branch failure for every germ implies genuine impossibility.

## Germ handling

An oriented germ (a,b) is the interval x=(1-epsilon)a+epsilon b for arbitrarily small positive epsilon in homogeneous coordinates; endpoints distinct projective rays. For a linear q its strict sign for sufficiently small epsilon is sign(q·a), or sign(q·b) when q·a=0. Both zero iff it is the germ support. In a tight state m=C every query must be an active support, and each child must be tight with no label duplication. Only finitely many fixed support queries can appear, hence any finite candidate sequence has a common positive epsilon neighborhood on its germ; lexicographic signs are exact for that neighborhood. The true tree on the original clipped intervals must work on these germs. A germ is never used in a nontight nonsupport query, because in a tight subtree all children remain tight. The recurrence cuts full components exactly and routes germs lexicographically. Base m<=d returns conservatively possible; m>C impossible. For m<C-2 and for rank-deficient nonsupport endpoint cones return possible. Every rejected state is therefore an obstruction to arbitrary real linear trees with the actual output contract.
