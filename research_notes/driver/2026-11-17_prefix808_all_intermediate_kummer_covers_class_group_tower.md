## The intermediate tower

Let h>=2, a=(1,0,0,1), b=(0,1,1,0), and

    D_h = K[U0,U1,U2,U3,z0,z1] / (z0^h-U0U3, z1^h-U1U2).

For every positive divisor d|h, let C_d be the homogeneous degree-zero part for the total z-exponent grading modulo d, equivalently the μ_d-invariant subring (diagonalizable-group-scheme interpretation also in characteristics dividing d). Thus C_h=R_h is the original observation ring, C_1=D_h, and C_g with g=gcd(h,2) is the canonical cover in the pinned notes.

For every chain e|d|h, there are finite inclusions

    C_h ⊆ C_d ⊆ C_e ⊆ C_1.

Each inclusion C_d⊆C_e has generic field degree d/e. Neither geometric separability nor étaleness is assumed.

## Theorem 1 — complete class groups and pullback kernels

For **all** e|d|h and every field K,

    Cl(C_d) ≅ (Z/hZ)^2 ⊕ Z/dZ,

with chosen toric coordinates [e0],[e1],[b]. The finite toric morphism Spec(C_e) -> Spec(C_d) induces the coordinatewise map

    (x,y,z mod d) |-> (x,y,z mod e).

Consequently its *exact* divisor-class sequence is

    0 -> Z/(d/e)Z -> Cl(C_d) -> Cl(C_e) -> 0,

where the kernel is generated by **e[b]_d** and has order d/e. These are genuine pullback maps, not arbitrary isomorphisms of finite abelian groups. They compose strictly as reductions throughout the tower.

### Proof

Let C be the nonnegative orthant in R^4 and

    L_d = Z^4 + { (i a + j b)/h : i,j in Z, i+j ≡ 0 (mod d) }.

Because d divides h, reducing exponents modulo h and extracting the integral part of a,h and b,h gives the monomial description C_d=K[C ∩ L_d]. Normality follows from saturation of C∩L_d in L_d. For d=h this is the previously pinned lattice L_h=Z^4+Z(a-b)/h.

For every d, the four coordinate facets have **the same primitive lattice normals hε_i**: integrality is clear from the denominators h, and (a-b)/h ∈ L_h ⊆ L_d has coordinate values ±1/h, proving primitiveness. The toric divisor exact sequence therefore gives

    Cl(C_d) = Z^4 / ( h Z^4 + H_d ),
    H_d = { i a + j b : i+j ≡ 0 (mod d) }.

The four vectors (e0,e1,a,b) form a unimodular integral basis of Z^4. In this basis H_d = Z(a-b)+Z(d b), while h a and h b already lie in H_d (as d|h). Thus the first two coordinates contribute independent Z/h summands, while the a,b plane has the elementary relation a=b and d b=0, giving Z/d.

For e|d, L_d⊆L_e; the lattice normals agree, hence each toric boundary divisor pulls back with ramification index one. The induced map on free toric divisor groups is the identity Z^4 -> Z^4, and therefore on the quotient it is precisely reduction of the last coordinate modulo e. Its kernel is e(Z/d)[b], cyclic of order d/e. QED.

## Theorem 2 — exact split criterion and extension-class order

The above short exact sequence of **abelian divisor-class groups** splits if and only if

    gcd(e,d/e) = 1.

More sharply, under the canonical identification

    Ext^1_Z(Z/eZ,Z/(d/e)Z) ≅ Z/gcd(e,d/e)Z,

the nonsimple cyclic-coordinate extension has class **1 modulo gcd(e,d/e)**, and hence extension-class order exactly gcd(e,d/e).

### Proof

Write n=d/e. The first two Z/h summands split identically. The remaining extension is the literal canonical sequence

    0 -> Z/n --(1 |-> e mod d)--> Z/d --(mod e)--> Z/e -> 0.

A section must lift 1 mod e to an element x mod d such that x≡1 (mod e) and ex≡0 (mod d). The second condition is equivalent to n|x. A simultaneous solution exists precisely when gcd(e,n)=1 (including e=1). For the extension class, lift 1 in Z/e to 1 in Z/d: multiplication by e yields e in the embedded kernel, i.e. generator 1 in Z/n. Its image in (Z/n)/e(Z/n) represents 1 modulo gcd(e,n), proving both the class and its exact order. QED.

Thus e is a **unitary divisor** of d precisely when this class-group step splits. In particular, all intermediate steps split when h is squarefree; repeated prime-power levels give explicitly non-split steps. The canonical-cover case d=h,e=gcd(h,2) specializes to split iff 4 does not divide h, recovering the earlier result without replacing it.

## Exact finite regression (not the proof)

For 2<=h<=72 and **every** divisor chain e|d|h, 951 ordered triples were enumerated. For each, the cyclic kernel was checked by direct residue enumeration:

    ker(Z/d -> Z/e) = {x mod d : x mod e=0}

has size d/e, and the existence of x with x=1 mod e and e*x=0 mod d was compared against gcd(e,d/e)=1. **951/951 matched**; 0 mismatches.

Reproducer (Python 3; exact integers only):

```python
from math import gcd
tested = 0
for h in range(2,73):
    for d in range(1,h+1):
        if h%d: continue
        for e in range(1,d+1):
            if d%e: continue
            ker = [x for x in range(d) if x%e == 0]
            lifts = [x for x in range(d)
                     if x%e == 1%e and (e*x)%d == 0]
            assert len(ker) == d//e
            assert bool(lifts) == (gcd(e,d//e)==1)
            tested += 1
assert tested == 951
```
