Let K be any field, h>=2, e|d|h, n=d/e, and
D_h=K[U0,U1,U2,U3,z0,z1]/(z0^h-U0U3,z1^h-U1U2).
Let C_t denote total-z-exponent-zero invariants modulo t for every t|h; C_h=R_h. Put A=U0U3=z0^h and B=U1U2=z1^h in all C_t.

## Theorem — finite free Kummer form on the two principal opens

For every e|d|h there are **canonical presentations with explicit named generators**

    C_e[A^{-1}] = C_d[A^{-1}][w_A]/(w_A^n-z0^d),
    w_A=z0^e,

    C_e[B^{-1}] = C_d[B^{-1}][w_B]/(w_B^n-z1^d),
    w_B=z1^e.

In particular C_e is a **finite locally free C_d-module of rank n on D(A) union D(B)**. For the corresponding finite morphism Spec(C_e)->Spec(C_d), its restriction over that open is

- **étale everywhere on the open** if char(K) does not divide n;
- **nowhere étale on that open** if char(K) divides n.

Its generic field extension has degree n, and is separable exactly if char(K) does not divide n. This statement is about the indicated open; it makes no maximal-open or joint-zero flatness assertion.

### Proof

The invariant exponent lattice of C_t is

    L_t=Z^4+{(i a+j b)/h : i+j=0 (mod t)},
    a=(1,0,0,1), b=(0,1,1,0).

For e|d we have L_d contained in L_e with cyclic quotient of order n: the weight map (i,j) |-> (i+j)/e mod n has kernel L_d and the class of e*a/h (equivalently z0^e) generates. Also e*b/h (z1^e) generates the same cyclic quotient. This is the same exact exponent-lattice calculation used in the class-group tower.

On D(A), z0^h=A is invertible, so all integral powers of z0^h, and every degree-zero monomial of C_d after A-localization, can be used. Given any monomial of C_e[A^{-1}] of weight i+j divisible by e, choose k in {0,...,n-1} with (i+j)/e congruent to k modulo n. Divide the monomial by (z0^e)^k. Its total z-exponent is now divisible by d. If a negative z0 exponent arises, multiply numerator and denominator by a suitable power of z0^h=A to obtain an element of C_d[A^{-1}]. Thus 1,w_A,...,w_A^{n-1} span the extension. Their exponent classes in L_e/L_d are distinct, so they are linearly independent as C_d[A^{-1}]-module elements. The only required relation is w_A^n=z0^d, a unit on D(A), yielding the first presentation. The B-localization proof is identical with z1.

The derivative of the monic defining polynomial T^n-z0^d at w_A is n*w_A^{n-1}. Since w_A is a unit, this is a unit if char(K) does not divide n, and zero if char(K) divides n. The monogenic Kähler differential module has presentation

    Omega_(C_e[A^{-1}]/C_d[A^{-1}]) = (C_e[A^{-1}])/(n*w_A^{n-1}) dw_A.

Therefore étaleness on D(A) follows from finite freeness plus vanishing differentials, and nonétaleness when the displayed differential module is nonzero. Repeat for D(B). The field extension is generated by w_A and has degree n because the n distinct lattice-weight cosets are independent over Frac(C_d); its minimal polynomial is T^n-z0^d, hence separability holds exactly when n is nonzero in K. QED.

## Integral regression and boundaries

For all 951 triples e|d|h with 2<=h<=72, enumerate residue pairs (i,j) modulo h satisfying i+j divisible by e and assign weight class (i+j)/e modulo n. Each of the n classes has exactly as many pairs as the weight-zero subgroup modulo d. Thus **951/951 cyclic quotient/rank tests match**, no discrepancy. This finite check validates the combinatorial coset count, not the universal proof.

Exact Python reproducer:

```python
count = 0
for h in range(2, 73):
    for d in range(1, h+1):
        if h % d: continue
        for e in range(1, d+1):
            if d % e: continue
            n = d // e
            counts = [0] * n
            base = 0
            for i in range(h):
                for j in range(h):
                    if (i+j) % e == 0:
                        counts[((i+j)//e) % n] += 1
                    if (i+j) % d == 0:
                        base += 1
            assert counts == [base] * n
            count += 1
assert count == 951
```

For d=e the rank is one and the map is the identity, including all characteristics. For h even, d=h and e=gcd(h,2), the local statements specialize to the existing canonical-cover Kummer description.
