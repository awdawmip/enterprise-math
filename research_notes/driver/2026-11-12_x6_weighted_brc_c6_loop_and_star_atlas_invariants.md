## 4. Theorem C — equal four-STAR loop masses have a weaker, exact K4 balance law

Write `x_i:=w_(+i)w_(-i)>0`. The one-circuit loop mass factor on STAR S is `W_S=(prod_(i∈S) x_i)^2`. Label the six axes as K4 edges `AB,AC,AD,BC,BD,CD`, so a STAR consists of the three edges incident to its vertex. Then **the four W-values are equal if and only if**

`x_AB=x_CD,   x_AC=x_BD,   x_AD=x_BC`.

**Proof.** Put `a=x_AB,b=x_AC,c=x_AD,d=x_BC,e=x_BD,f=x_CD`. Since all x are positive, equality of the four squared STAR loop factors is exactly `abc=ade=bdf=cef`. Equating A with B,C,D gives `bc=de`, `ac=df`, `ab=ef`. Consequently `d²=(de)(df)/(ef)=c²`, so d=c by positivity, and substitution gives e=b, f=a. The converse is direct. QED.

Use the existing valid local orientation `a=(+L1,-L3,+L6,-L1,+L3,-L6)` (any equivalent triad ordering works). The following checker enumerates the *full finite declared branch population* for m=1 and 2:

from collections import Counter
a=(1,-3,6,-1,3,-6)
expected=lambda m:Counter({x:2*m for x in (1,-1,3,-3,6,-6)})
def micro(r,b):
    ar=a[r%6]; nxt=a[(r+1)%6]
    return (-ar,nxt) if b=="I" else (nxt,-ar)
def valid_nb(w):
    return all(v!=-u for u,v in zip(w,w[1:]))
for m,answer in [(1,(64,21,18)),(2,(4096,377,322))]:
    totals=[0,0,0]

        word=tuple(x for r,b in enumerate(bs) for x in micro(r,b))
        assert len(word)==12*m
        assert Counter(word)==expected(m)
        assert sum(1 if z==i else -1 if z==-i else 0 for z in word for i in ())==0
        open_nb=valid_nb(word)
        closed_nb=open_nb and word[-1]!=-word[0]
        totals[0]+=1; totals[1]+=int(open_nb); totals[2]+=int(closed_nb)
    assert tuple(totals)==answer, (m,totals)
