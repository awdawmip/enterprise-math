## Statement with all characteristics included

Let `h>=2`, `K` any field, `R=K[U0,U1,U2,U3]`, `A=U1*U2`, `B=U0*U3`. Let `S` be the finite free rank-`h` commutative `R`-algebra with ordered basis `(1,V1,...,V_(h-1))` and exact multiplication
```
V_i V_j = A V_(i+j)     if i+j<h;
          A B           if i+j=h;
          B V_(i+j-h)   if i+j>h.
```
All claims refer to this actual Reeve ambient-observer algebra, not to an unspecified normalization within `Frac(R)`.

**Theorem 1 (integral trace and discriminant).** The regular trace `Tr=Tr_(S/R)` obeys
```
Tr(1)=h;     Tr(V_i)=0 (1<=i<h).
Tr(V_i V_j)=h*A*B if i+j=h, and 0 otherwise (1<=i,j<h).
```
Thus the trace Gram matrix is `(h) direct_sum (hAB*J_(h-1))`, where `J_(h-1)` is the anti-identity, and the discriminant in this specified integral basis is
```
disc(S/R;1,V1,...,V_(h-1))
   = (-1)^((h-1)(h-2)/2) * h^h * (A B)^(h-1).
```
In particular the discriminant ideal is generated by `h^h(AB)^(h-1)`. The polynomial formula already makes sense over `Z[U0,U1,U2,U3]`; after passage to `K` the integer `h` is interpreted in `K`.

**Theorem 2 (exact trace-to-dual defect).** Put `omega=Hom_R(S,R)` and let `epsilon_0,...,epsilon_(h-1)` be the dual basis. The natural trace map `tau:S -> omega`, `tau(s)(t)=Tr(st)`, has
```
tau(1)=h epsilon_0;    tau(V_i)=hAB epsilon_(h-i) (1<=i<h).
coker(tau) ~= R/(h) direct_sum (R/(hAB))^(h-1)
```
as `R`-modules (the stated summands can be zero when their defining element is a unit). If `char(K)` divides `h`, then `tau=0` even though `S` is finite free and the relative dualizing module is locally invertible on `D(A) union D(B)`. If `char(K)` does not divide `h`, the defect is `(R/(AB))^(h-1)`.

**Theorem 3 (exact relative étale locus).** The finite flat map `Spec(S) -> Spec(R)` is étale precisely over
```
D(AB) if char(K) does not divide h;   the empty set if char(K) divides h.
```
Here this is the open set in the base over which the whole finite morphism is étale. For `h>=3` the relative Gorenstein locus `D(A) union D(B)` (as previously proved) is strictly larger than the étale locus if `char(K)` does not divide `h`. For `h=2` the morphism is Gorenstein everywhere while still ramified along `V(AB)`; when `char(K)=2` it is nowhere étale. This separates finite-flatness, Gorenstein duality, and trace separability.

## Proof

Multiplication by `V_i` permutes the residue labels `0,...,h-1` modulo `h`, with a nonzero scalar weight on each image: `V_i*1=V_i`, and the displayed table covers all other basis vectors. For `i != 0 mod h`, no basis vector maps to a nonzero multiple of itself, hence every diagonal entry of its regular-representation matrix is zero and `Tr(V_i)=0`. Multiplication by `1` is the identity, hence `Tr(1)=h`. Taking traces in the exact table yields the three cases of Theorem 1. The Gram matrix has one `h` block and one `hAB` times an anti-identity of size `h-1`; its determinant is the displayed signed product.

For Theorem 2, the Gram matrix is precisely the coefficient matrix of `tau` with respect to the named free bases. The anti-identity only permutes target basis vectors. Thus `tau` is equivalent over `R` to the diagonal matrix `diag(h,hAB,...,hAB)`, giving the explicit image and cokernel. No division by `h`, `A`, or `B` was used.

For Theorem 3, when `h` is invertible, the determinant of the trace form is a unit at a base point exactly when `AB` is a unit there. A finite locally free algebra is étale exactly where its trace pairing is perfect (the standard finite-projective separability criterion). Alternatively, on `D(A)`, writing `T=V1/A` gives the *actual* monogenic chart `S_A=R_A[T]/(T^h-B/A)` with derivative `h*T^(h-1)`; it is étale precisely on `D(AB)`, and the symmetric `D(B)` chart gives the same conclusion. At `A=B=0` the geometric fiber has a square-zero span of the `V_i`, so is not étale. If `char(K)` divides `h`, the trace form vanishes everywhere by Theorem 1, hence there is no étale base point. QED.

## Exact independent finite check

The following reproducer uses formal polynomials rather than floating point and checks every Gram coefficient and determinant for `h=2,...,12`; this is an auxiliary test, not the universal proof.

```python
import sympy as s
A,B=s.symbols("A B")
for h in range(2,13):
    def prod(i,j):
        if i==0: return {j:s.Integer(1)}
        if j==0: return {i:s.Integer(1)}
        n=i+j
        return {n:A} if n<h else ({0:A*B} if n==h else {n-h:B})
    tr=[s.expand(sum((prod(i,j).get(j,s.Integer(0)) for j in range(h)),s.Integer(0))) for i in range(h)]
    gram=s.Matrix([[s.expand(sum((v*tr[k] for k,v in prod(i,j).items()),s.Integer(0))) for j in range(h)] for i in range(h)])
    expected=s.zeros(h)
    expected[0,0]=h
    for i in range(1,h): expected[i,h-i]=h*A*B
    assert gram==expected
    assert s.expand(gram.det(method="domain-ge")
      -(-1)**((h-1)*(h-2)//2)*h**h*(A*B)**(h-1))==0
```

The 11 cases were locally executed successfully. The general proof is integral and applies in every characteristic.
