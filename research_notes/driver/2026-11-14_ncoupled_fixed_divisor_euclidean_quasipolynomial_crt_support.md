# N-coupled: fixed-divisor Euclidean quotients retain finite CRT rank support

## 1. Exact grammar and theorem

Fix finitely many integer straight-line expressions in the public input `N`. An expression is built from `N` and fixed integers by `+`, `-`, `*`, and *exact Euclidean quotient and remainder by fixed positive integers*:

`Q_d(x)=floor(x/d)`, `R_d(x)=x-d Q_d(x)`, where every divisor `d>=1` is constant and independent of `N`. Quotient and remainder may be nested; the expression length, constants, and output matrix dimensions are fixed. The input-dependent integer produced by one of these fixed expressions may feed another expression. Matrices are populated by such expressions. One may choose **one whole output leaf** from a finite pre-fixed collection by an otherwise arbitrary global selector `sigma(N)`, without adding fresh numerical operands to that leaf.

Let `N=pq` with distinct odd primes. Then there exists a **single precomputable finite set of positive integers `C`**, depending only on the expressions, such that, for every allowed `N`, if any chosen matrix has different ranks modulo `p` and `q`, then some `c in C` satisfies

`1 < gcd(N,c) < N.`

Further, there is a finite set of primes `S` depending only on the fixed expressions such that for `p,q notin S`, **every leaf's matrix has equal ranks at both hidden channels**. No rank-asymmetry family outside that finite prime support is generated by this grammar, despite the ordinary floor/remainder steps not being ring homomorphisms.

This result concerns fixed divisors only. An input-dependent divisor, an unboundedly growing program, an externally injected numeric initial state, or an operator using a hidden-CRT-local branch is outside this statement.

## 2. Quasipolynomial closure lemma

Every such integer expression `E(N)` has a finite period `M>=1` and rational polynomials `P_0,...,P_{M-1} in Q[X]` with

`E(n)=P_r(n)` whenever `n == r (mod M)`, for all integer `n`. This is an **exact** quasipolynomial representation, not asymptotic.

Proof by structural induction. Integer constants and `N` use period 1. Addition, subtraction and multiplication preserve the property after taking a common multiple of periods. For `Q_d(E)`, let `E(n)=P_r(n)` on residue `r mod M`. Choose one positive integer `L` clearing every coefficient denominator of every `P_r`, and put `H=M*L*d`. For `n==s (mod H)`, `n` and `s` have the same old residue `r`, and

`P_r(n)-P_r(s)` is a multiple of `d`,

since `n-s` is divisible by `H`, every difference `n^j-s^j` is divisible by `H`, and the polynomial coefficients lie in `L^(-1)Z`. Thus the Euclidean remainder `u_s=P_r(s) mod d` is constant on this finer class, and

`Q_d(E(n))=(P_r(n)-u_s)/d`.

This is a rational polynomial on each residue class `s mod H`. Also `R_d(E(n))=u_s` there. Hence the class is closed under arbitrarily nested **fixed-depth** quotients/remainders. No size bound on `n` was invoked.

## 3. Fixed integer matrices and determinantal witnesses

Take a common period `M` for every entry of every output matrix at every leaf. On `n==r (mod M)`, each such matrix equals a rational-polynomial matrix `P_{l,r}(n)`. Choose a single positive integer `L` clearing every coefficient denominator of all those finitely many polynomials, and define

`B_{l,r}(X)=L P_{l,r}(X) in Mat(Z[X]),    A_{l,r}=B_{l,r}(0) in Mat(Z).`

For an actual `N=pq` in that residue class, `B_{l,r}(N)-A_{l,r}` is entrywise divisible by `N`. If `p,q` do not divide `L`, multiplication by `L` is invertible over both fields, whence

`rank_Fp(P_{l,r}(N))=rank_Fp(A_{l,r} mod p)`,

and the analogous identity holds at `q`.

Let `k=rank_Q(A_{l,r})`. For each `1<=t<=k` take the positive `t`-th determinantal divisor `Delta_t(A_{l,r})` (gcd of its absolute `t`-minors). Include **all** these fixed integers in `C`, and also each prime divisor of `L`. If an input prime divides `L`, that prime itself is a fixed proper-gcd witness for `N=pq`. Otherwise suppose the two channel ranks are `a<b`. Set `t=b`. The minor criterion gives

`p | Delta_b(A_{l,r}),   q does not divide Delta_b(A_{l,r}),`

so `gcd(N,Delta_b(A_{l,r}))=p`. This proves the exact certificate statement, uniformly over an arbitrary global leaf selector. It also handles cases where **both** channels are below generic rational rank; the top divisor alone is not enough there.

Let `S` be the finite set of primes dividing the members of `C`. For `p,q notin S`, every matrix `A_{l,r}` has its rational rank at both primes, by its top nonzero minor divisor. Therefore no leaf can exhibit unequal ranks, proving the stronger uniform statement.

The finite collection `C` is existentially and effectively defined by fixed expressions, although its size and its entries need not be computationally small. This is a structural support/gcd reduction, **not** a claim about practical factorization cost.

## 4. A non-ring example with an actual asymmetric input

Take the two fixed nested-quotient scalar expressions

`f(N)=floor(N/4)+1,   g(N)=floor((floor(N/4)+1)/3),`

and the diagonal matrix `D(N)=diag(f(N),g(N))`. Write `r=N mod 12`. The exact expression on that residue class is

`12 D(N)=diag(3N + 3(4-(r mod 4)),  N + 12*[r>=8]-r),`

where the indicator is 1 for `r=8,9,10,11` and 0 otherwise. Thus `L=12` and

`A_r=diag(3(4-(r mod 4)),  12*[r>=8]-r).`

For `N=65=5*13`, `r=5`, so `D(65)=diag(17,5)`, `A_5=diag(9,-5)`. The channel ranks are 1 modulo 5 and 2 modulo 13. Here `Delta_1(A_5)=1` and `Delta_2(A_5)=45`; `gcd(65,45)=5` gives a pre-fixed support witness. The quotient/remainder operations genuinely use integer rounding, but the hidden-channel asymmetry remains static-support equivalent.

## 5. Independent finite regression

The following Python 3 checker uses exact integer arithmetic. It tests all 120 pairs of distinct odd primes below 60 for the above diagonal example, checks the exact residue-class identity at the two hidden primes, and checks that every unequal-rank case has a fixed support witness. The full domain of this *regression* is declared explicitly.

```python
from itertools import combinations
from math import gcd

primes = [
    p for p in range(3, 60, 2)
    if all(p % d for d in range(3, int(p**0.5) + 1, 2))
]

def values(n):
    return n // 4 + 1, (n // 4 + 1) // 3

def fixed_matrix(n):
    r = n % 12
    return 3 * (4 - r % 4), (12 if r >= 8 else 0) - r

checked = unequal = witnessed = 0
for p, q in combinations(primes, 2):
    n = p * q
    vals = values(n)
    rank_p = sum(v % p != 0 for v in vals)
    rank_q = sum(v % q != 0 for v in vals)
    a, b = fixed_matrix(n)
    assert (12 * vals[0] - a) % n == 0
    assert (12 * vals[1] - b) % n == 0
    checked += 1
    if rank_p != rank_q:
        unequal += 1
        candidates = (2, 3, gcd(abs(a), abs(b)), abs(a*b))
        assert any(1 < gcd(n, c) < n for c in candidates)
        witnessed += 1
print(len(primes), checked, unequal, witnessed)
```

Executed output: `16 120 14 14`. This bounded computation is a regression for the example. The all-input statement follows from Sections 2-3.
