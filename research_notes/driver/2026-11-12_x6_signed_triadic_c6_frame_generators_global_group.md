## 1. Explicit generator on every ordered triad

Let `e_1,...,e_6` denote the six signed native coordinate basis labels. For pairwise distinct `i,j,k`, define `R_(i,j,k)` by its action on the basis:

```text
e_i -> -e_k
e_k -> -e_j
e_j -> -e_i
e_l ->  e_l        for l not in {i,j,k}
```

Extend `R` `Z`-linearly to signed displacements and affinely around a *chosen pivot Cell* `P` via `P+z -> P+R(z)`. This is a signed permutation matrix with exactly one `±1` in each row and column, hence is a bijection of the genuine native Cell-coordinate set and preserves signed primitive adjacency and `G(z)=sum z_l^2`.

On the six signed unit directions selected by the triad it acts in a six-cycle:
```text
+e_i -> -e_k -> +e_j -> -e_i -> +e_k -> -e_j -> +e_i.
```
Consequently `R^3=-I` on the three selected basis axes, `R^3=I` on the three omitted axes, and `R^6=I` globally. The six-cycle is the exact oriented local `C6` phase action of this **candidate signed-frame family**. Changing the ordering of the selected axes replaces its local phase orientation by the corresponding inverse, up to relabeling.

Write `D_S` for the diagonal sign-flip that negates exactly the three axes in `S={i,j,k}` and fixes the rest. Then
```text
R_S^3 = D_S,       D_S^2 = I,
R_S D_S = D_S R_S,
R_S D_S = P_S,
```
where `P_S` is a *pure unsigned* 3-cycle on those three labels. Thus each local `C6` generator simultaneously contains a 3-axis half-turn and a pure 3-cycle in its powers.

## 2. Theorem — global group generated over all 20 selected triads

For each of the `binom(6,3)=20` unordered three-axis sets choose any one of its two cyclic orientations (equivalently, the indexed order `i<j<k` suffices) and let `H` be the subgroup of `GL(6,Z)` generated by their `R_S`.

Then

```text

                |H| = 2^6 * (6!/2) = 23,040.
```

It is precisely the subgroup of signed permutation matrices whose **underlying unsigned axis permutation is even**. The ambient signed-permutation matrix group `B6=(C2)^6 ⋊ S6` has order 46,080, so `H` has index 2 in `B6`. Its order and parity classification are exact for this specific constructed generator family, not a proposed universal classification of all physical X6 rotations.

**Proof.** Each `R_S` has an underlying 3-cycle, so all products project to `A6`. Its third power is `D_S`, the diagonal sign-flip on S. Encode diagonal sign-flips as vectors in `F2^6`. The twenty weight-three indicator vectors span `F2^6`: subtract two triples with two labels in common to obtain the flip on any chosen two labels (choose two other labels distinct from the chosen pair); then add an appropriate two-label flip to a triple vector to obtain a singleton flip. These singletons generate every diagonal sign pattern, hence `(C2)^6 ≤ H`. As `R_S D_S` is a pure unsigned 3-cycle for every triad, `H` also contains all 3-cycles, which generate `A6`. The two subgroups together give `(C2)^6 ⋊ A6 ≤ H`, and the initial parity containment supplies the reverse inclusion. QED.

For a restricted **single fixed triad**, the local group generated by one R is exactly C6, not the global 23,040-element family. This last statement is a conditional group-extension calculation.

## 4. Supplementary exhaustive finite test

The universal classification follows from the group proof above. Its finite confirmation enumerates the generated group exactly as signed six-component images of the basis. A signed image tuple `p=(p_1,...,p_6)` represents `e_i -> sign(p_i)e_|p_i|`. Multiplication is ordinary function composition.

```python
from itertools import combinations
from collections import deque

identity = (1,2,3,4,5,6)
def compose(p,q):
    return tuple((1 if x>0 else -1)*p[abs(x)-1] for x in q)
def gen(i,j,k):
    p=list(identity)
    p[i],p[j],p[k] = -(k+1),-(i+1),-(j+1)
    return tuple(p)
def power(g,n):
    r=identity
    for _ in range(n): r=compose(g,r)
    return r

gens=[gen(*s) for s in combinations(range(6),3)]
assert len(gens)==20
assert all(power(g,6)==identity for g in gens)
assert all(sum(x<0 for x in power(g,3))==3 for g in gens)
seen={identity}; queue=deque([identity])
while queue:
    g=queue.popleft()
    for h in gens:
        a=compose(g,h)
        if a not in seen:
            seen.add(a);queue.append(a)
assert len(seen)==23040
```

Exact execution in the current Driver check produced `20` generators, all local order 6, all local cubes negating exactly three axes, and **23,040 distinct generated signed permutations**. This finite enumeration is a verification of the construction, not a replacement for the universal group-theoretic argument.

**Proof of the three-STAR claim.** Any two STARs intersect in exactly their common K4 edge, so their underlying unsigned 3-cycles share exactly one label and move altogether five labels. Such two 3-cycles generate `A5` on those five labels (a standard elementary finite permutation lemma; for instance `(1 2 3)` and `(1 4 5)` generate `A5`). A third STAR contains the unique sixth edge label and two labels from those five. Conjugating its underlying 3-cycle by the `A5` subgroup, which acts 2-transitively on five labels, generates every 3-cycle containing the sixth label. Together with `A5`, these are all of `A6`.

Each `R_S^3` flips the three axes of S. The just-proved `A6` projection can be lifted to *pure* axis permutations because `R_S R_S^3` is a pure 3-cycle on S, and its generated subgroup is `A6`. The reverse containment follows because each generator projects to an even unsigned permutation. This proves the full group equality. QED.
