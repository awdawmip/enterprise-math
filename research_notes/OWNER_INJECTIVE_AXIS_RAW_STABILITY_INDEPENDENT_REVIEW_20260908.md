## 1. 固定合同与实际复用

在同一外部 anchor、同一带实际六轴标签的 raw X6 chart 中，先按空间 Cell 聚合，再 Jordan 抵消，写成

`f = sum_(q in S) w_q delta_q - n`,

其中 `S` 有限，`w_q>0` 为有理权，`n>=0` 有限且 `n(S)=0`。令

`P=sum_q w_q`, `N=sum n`, `M=P+N=||f||_1`,

`D=sum_(I subset [6], |I|=3) ||M_I f||_1`。

这里包含全部二十张实际 raw 三轴边缘，不取平均，不以最大单表范数代替总和。减号是两侧正总体之间的分析账本，不能作为负 BRC primitive。若以联合坐标编码 raw，必须同时保留 can3 与实际共同 offset；单独 can3 不满足本论证。

基本假设是存在一条**实际物理轴** `a`，使 `q -> q_a` 在 `S` 上单射。这里不限 `|S|`；单射指该轴上不同正点具有不同整数坐标值，不是通过任意混合六坐标而造出的新轴。

核心局部复用来自已有 `OWNER_ONE_POSITIVE_STABILITY_20260907.md` 第 2、5 节：一般 product 的单正投影账本在辅助参数 `(n,k)=(5,2)` 下恰给出 `10P_s-2N_s`。五轴与二轴在此是保留一条原物理轴后用于证明的切片/观察参数，不是新 native 空间或维数。

## 2. 每个 a-fiber 的精确单正账本

把二十张表分为含 `a` 的十张 `V` 和不含 `a` 的十张 `U`，均以范数之和表示。对每个出现的 `a` 坐标值 `s`，将对应切片记为 `f_s`。所有表都保留实际地址，因此

`V = sum_s sum_(J subset [6]\{a}, |J|=2) ||M_J f_s||_1`。

这是保留 `s` 标签后的逐纤维范数相加，不是先删除 `a` 再允许不同切片抵消。

若该 fiber 含正点，单射假设保证它恰含一个，记其余五坐标为 `r_s`，其质量为 `P_s>0`，负侧总质量为 `N_s`。对每个二轴集合 `J` 定义

`A_(s,J) = sum_(z: z_J != (r_s)_J) n_s(z)`。

唯一正投影地址上的净质量是 `P_s-N_s+A_(s,J)`，其余投影地址全非正。因此精确有

`||M_J f_s||_1 = |P_s-N_s+A_(s,J)| + A_(s,J)`.

如果一个负点在剩余五轴中有 `h>=1` 个坐标不同于 `r_s`，它避开正投影地址的二轴表数为

`k(h)=10-binomial(5-h,2) >= 4`，

并且等号当且仅当 `h=1`。小于二的上标按零处理。`h>=1` 来自 Jordan 负支撑与正点不交，而非单位步长假设。

交换有限求和，得到

`sum_J A_(s,J) = sum_z k(h(z)) n_s(z) >= 4 N_s`。

用 `|x|>=x`，该正 fiber 对 V 的贡献满足

`V_s >= 10(P_s-N_s)+2 sum_J A_(s,J) >= 10P_s-2N_s`。

更精确的非负间隙是

`V_s-(10P_s-2N_s)`

`= 2 sum_z (k(h(z))-4)n_s(z)`

`  + 2 sum_J max(N_s-P_s-A_(s,J),0)`。

这同时记录后续取等所需的两类条件：每个实际负点必须只改一个剩余坐标，而且每张单正地址的净质量不能为负。

若 fiber 没有正点，则整个切片非正；十张二轴表各有范数 `N_s`，所以严格有 `V_s=10N_s`。

令 `N_empty` 为所有无正点 a-fiber 上的负质量。相加得到

`V >= 10P-2N+12N_empty`。

这一步没有任何正支点总数限制。

## 3. 十张不含 a 的表及全质量界

每张不含 `a` 的三轴边缘，其总质量都是 `P-N`。三角不等式逐表给出

`U >= 10|P-N|`。

因而

`D >= 10P-2N+10|P-N|+12N_empty`。

等价地，

- 若 `P>=N`，则 `D >= 4M+16(P-N)+12N_empty`；
- 若 `N>=P`，则 `D >= 4M+4(N-P)+12N_empty`。

特别地，

`D >= 4M`。

对于非零差，`D>0`，所以可以写 `M/D<=1/4`。零差只记录两边为零，不形成 `0/0`。`N=0` 无须除法；若 `S` 为空则 `f<=0`，实际更强地有 `D=20M`。已有单正与双正更精细结论继续保留；这个定理不放宽旧程序的 `p<=1` 或 `p<=2` guard。

以上还表明，非零差若达到 `D=4M`，必有 `P=N` 和 `N_empty=0`。不可能靠不同 fiber 的正负质量缺口互相抵消这两个非负损失。

## 4. 三正的 41 个模板与整体 sharp 见证

对恰三个不同正点，模板中的 D 型轴恰表示三个该轴坐标两两不同。因此 `nD>=1` 当且仅当存在本定理需要的单射轴。已有模板论文的分类中，这类有效模板共有 41 个；余下 16 个 `nD=0` 模板未被这条假设覆盖。

这里复用已审模板分类与其手工计数，不重跑类型枚举。57 仍只计无权正支撑几何；权向量须同步搬运并保留模板 stabilizer。不能由本定理推断所有 41 个模板各自都以 `1/4` 为最优常数或都可取等，更不能推出一般 p3 已解决。

对整个“有单射正支撑轴”的类，`1/4` 确为 sharp。取两条实际不同的轴 `a,b`；其余四轴固定任意共同整数坐标。要求

`a0,a1,a2` 两两不同，`b0!=b1`，`w2,w3>0`，`w1=w2+w3`。

正侧为

`w1 delta_(a0,b0) + w2 delta_(a1,b1) + w3 delta_(a2,b1)`，

负侧为

`w1 delta_(a0,b1) + w2 delta_(a1,b0) + w3 delta_(a2,b0)`。

省略的四个坐标相同。六个列出的 Cell 两两不同，正负无 Jordan 重合。每条 a-fiber 正负质量相等；两条 b-fiber 也由 `w1=w2+w3` 保持正负质量相等。

包含 `a,b` 的三轴表共有四张，每张能分开所有六个 Cell，故各有范数 `M`。其余十六张表若只保留 a、只保留 b、或两者都不保留，分别由行平衡、列平衡或总质量平衡而为零。因此

`D=4M`。

这给出一个 `nC=4,nD=1,nP23=1` 的三正模板中的真实取等族。所有坐标差可以是任意非零整数；没有使用相邻、单位步、距离或 native 动力学解释。权可为任意满足上述关系的严格正有理数，无须归一化。

## 5. 固定单射轴下三正取等流：精确定理

现在固定恰三个正点

`q_i=(a_i,r_i), i=1,2,3`，

其中 `a_i` 两两不同，`r_i` 为剩余五个实际 raw 坐标，正权为 `w_i>0`。令

`R={r_1,r_2,r_3}`，

这里 R 是**去重后的坐标集合**，并令

`W_r=sum_(j:r_j=r) w_j`。

对任意允许的有限负总体 n，以下等价：

1. `D(f)=4M(f)`；
2. 负总体恰可写成

   `n=sum_i sum_(r in R) c_(i,r) delta_(a_i,r)`，

   其中所有 `c_(i,r)>=0` 为有理数，且同时满足：

   - `c_(i,r)=0`，除非 `Ham(r,r_i)=1`；
   - 每行 `sum_r c_(i,r)=w_i`；
   - 每列 `sum_i c_(i,r)=W_r`。

行平衡已推出 `P=N`；可以把它显式附列，但不需要额外归一化。Hamming 距离一只表示恰一个实际坐标值不同，绝不意味着数值相差一或 native 路径长度一。c 是已经聚合到实际 Cell 的非负质量，不是原始分支流量；同一个 r 的重复正标签不得拆成不同列或不同负 Cell。

### 必要性

由第 3 节的质量间隙，取等先强制 `P=N`、`N_empty=0`，随后必须有 `U=0`、`V=8P`。第 2 节的逐项非负间隙于是都为零。因此：

- 每个负点处在某个正 a-fiber；
- 它与该 fiber 正点的五坐标只相差一轴；
- 对该 fiber 的每个二轴 J，`w_i-N_i+A_(i,J)>=0`。

把 a 聚合掉，记五坐标差

`g=sum_i w_i delta_(r_i) - (pi_([6]\{a}))_*n`。

U 的十张表正是 g 的全部三轴边缘。`U=0` 表示它们全部为零，而 Jordan 后 `p(g)<=3`。

这里可复用已 main 的零缺陷正支撑下界：非零五坐标数组的全部三轴边缘若为零，正支撑至少八点，因此 g 必为零。也有不引入额外定理的短证明：若 g 非零，总质量零使它有一个负点 z；对每个实际正点选择一条将它与 z 区分的坐标轴，所选轴的并至多三条，再扩充为三条实际轴。该三轴投影在 z 地址没有正贡献，却有严格负贡献，故该表不为零，矛盾。正支撑为空的情形由总质量零立即排除。

所以 `g=0`。这不仅是总质量平衡，而是完整五坐标逐地址平衡：所有负投影都落在 R，且列和必须为 `W_r`。

对固定 i，可用的负投影至多是 `R\{r_i}` 中两个不同的 r；每个只与 `r_i` 相差一轴。因此这些负点改变的轴总共至多两条。在其余五轴中，可以选一个避开所有改变轴的二轴集合 J。对这张表，`A_(i,J)=0`，于是上面的逐表等号条件给出 `N_i<=w_i`。

最后，全局 `sum_i N_i=N=P=sum_i w_i` 强制每一行都满足 `N_i=w_i`。这样行、列以及 Hamming 支撑条件全部得到，且没有把负点数或“每行质量相等”偷偷当作假设。

### 充分性

假设存在上述非负 c。列平衡直接给出 `g=0`，故 `U=0`。每行 `N_i=w_i`，而行中每个负点与 `r_i` 只差一个坐标，故

`sum_J A_(i,J)=4w_i`。

单正账本在行等质量时化为 `||M_J f_i||_1=2A_(i,J)`，所以 `V_i=8w_i`。相加得到

`D=V=8P=4(P+N)=4M`。

这证明了完整的必要充分性。它仍是纸面质量证书，没有提供或执行求流 API、LP、模板遍历或消费者。

## 6. 所要求的退化、重复与带权边界

- 若 `r_1=r_2=r_3`，则每一行都没有 Hamming 一邻居，严格正的行和要求不可能满足，因此这个固定正支撑不存在非零 `D=4M` 的取等负总体。基本不等式仍成立。
- 若 R 恰有两个值，例如 `r_2=r_3!=r_1`，则两值若不是 Hamming 一邻居，仍不可能取等。若是邻居，三行的去向被强制，列平衡要求 `w_1=w_2+w_3`，恰回到第 4 节见证。重复的 `r_2,r_3` 是同一列，列目标为 `w_2+w_3`。
- 更一般地，只要某个正权行在 R 中没有允许邻居，行和就不可能满足。不能凭总质量相等或另两行的可行性跳过该行。
- 实际坐标值不必为 0、1，也不必相邻；判断只用同一实际坐标轴上的相等/不等。换字典标签只属于证明重编码，不能追加 native 位移、旋转或度量结论。
- 带权向量与 q_i 的对应必须保留。等质量只是 `N=P`，不能据此把 w_i 全部置为相等、独立排序，或把重复 r_i 的各个 w_i 混为同一 a-fiber 的正点。
- p3 取等刻画使用了 `p(g)<=3` 和每行至多两个不同邻居。这两步不能直接推广为任意 p 的同一 flow 刻画。任意 p 的结论仅是第 3 节已经证明的不等式。
- 原输入若经聚合抵消后少于三个正点，必须转入实际较小 p 合同。空间结论不恢复微观分支、路径、历史或未保留的几何量。
