## 精确模型

设 U=A/8，其中高斯整数矩阵 A 的五行依次为：

- (4,4,0)
- (0,-4,4)
- (-5+3i,0,-3+i)
- (-2-2i,4+4i,2+2i)
- (-2,0,5+2i)。

每个 Port j 的来源标记路径为 v[j,k]=U[j,k]a[k]，其正质量 Q_j(a)=sum_(k,l) v[j,k] conj(v[j,l])=|(Ua)_j|²。九项有序来源路径对保留到读出边界，不能由当前证明推论未来操作下可安全删除来源。固定 q=(1/2,1/4,5/32,13/8,29/64)。共享十项误差≤1的实、虚参考报告：R_4=(sqrt(13/8),0)，其它四 Port 为(0,0)。S 是满足全部五项准确质量和十项参考约束的**所有** a∈C³；MEB²(S) 在辅助实六维欧氏空间测量。

## 定理（完整连续纤维，而非四个相位代表）

**24/13 ≤ MEB²(S) ≤ 475/124−sqrt(5/2) < 707/310 < L=1062562/458329。**

证明：

1. 精确共轭矩阵乘法 A* A=diag(62,64,63)，故 U*U=diag(31/32,1,63/64)。于是 sum Q_j = (31/32)|a1|²+|a2|²+(63/64)|a3|² ≥ (31/32)||a||²。由于 sum q=191/64，所有准确读数来源满足 ||a||²≤191/62；不依赖任何四轨道完备性假说。
2. 取固定包围球球心 c=U_4*=((-1+i)/4,(1-i)/2,(1-i)/4)，有 ||c||²=3/4。对 p=(Ua)_4，准确读数给出 |p|²=13/8；报告误差给出 |Im p|≤1 与 Re p≥sqrt(13/8)−1>0。因此 Re p≥sqrt(5/8)，于是 ||a−c||²=||a||²+3/4−2 Re p≤191/62+3/4−2sqrt(5/8)=475/124−sqrt(5/2)。**同一个显式球覆盖所有轨道和每个合法连续相位**。
3. 精确比较 5/2−(31/20)²=39/400>0，故上述球半径平方严格小于 475/124−31/20=707/310。且 L−707/310=5355617/142081990>0。
4. 相位弧也可完整刻画：对任意 Q(a)=q 的来源令 r=sqrt(13/8)、p=(Ua)_4、b=a conj(p)/r，其合法共同相位恰为 exp(iθ)b，|θ|≤α，其中 sinα=sqrt(8/13)、cosα=sqrt(5/13)。其它四 Port 的模长平方均小于1，对零报告自动合法；第四 Port 两分量分别限制 |sinθ|≤1/r 与 cosθ>0，弧内实部误差 r−sqrt(5/8)<1。
5. 非空与下界：取 a0=(0,1+i,1)，准确读数为 q，Port4 幅值 p0=(1+5i)/4，||a0||²=3。令 b0=a0 conj(p0)/r、a±=(sqrt(5/13)±i sqrt(8/13))b0；二者在同一报告中合法，且 ||a+−a−||²=96/13，所以 MEB²(S)≥24/13。
