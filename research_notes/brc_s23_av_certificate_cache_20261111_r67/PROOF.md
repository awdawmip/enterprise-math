# R67 — Cached exact subtree exclusions across persistent versions

Research date: 2026-11-11. Frozen scientific input: `43ec6098b1330ae86d0a7863be336c5d97f6ef34` (unchanged). Status: author derivation and exact finite crosschecks; independent review pending. Model: auxiliary rational circle observer, not a change to P000/native X6 or the native BRC substrate.

## Definitions and observer
Fix rational anchor `0<theta0<1`, `m>=2`, observation `(j,x)`, original historical label `z`, and a closed parameter interval `I=[L,U]` containing `theta0`. The cyclically ordered phases `{v theta}` for `v=0,...,m-1` form original-labelled half-open historical arcs. Each source is a separately erasable labelled event `(t,b)`. A persistent treap stores exact `({t theta0},t,b)` and immutable subtree phase/time extrema and event count. At `theta`, the observer returns the maximum source time with `{x+(t-j)theta}` in target arc `A_z(theta)`, or the empty value. Historical coincidences and exact half-open boundary equalities have their own endpoint semantics; the stable-order interval certificate returns `INCONCLUSIVE` if its required noncollision condition fails.

The full source carrier retains `(t,b)`, rather than discarding branch identity after reading out the latest time. This is the BRC observer/future-operation preservation principle: two branch sets can have the same latest-time output and different responses to deleting a branch.

## Theorem 1: interval containment

Suppose a sound R65/R66 closed integer-lift rectangle certificate has established, for one fixed immutable event subtree `C` and query signature `q=(theta0,j,x,m,z,nxt)`, that

```
forall theta in I, forall (t,b) in C: {x+(t-j)theta} notin A_z(theta).
```

If the originally labelled historical cyclic order is constant throughout `I`, **the exact same exclusion conclusion holds for every closed rational subinterval `I' subseteq I` without repeating the rectangle test.**

Proof: restriction of the universal quantifiers to `I'` is valid. The R65/R66 integer separation inequality is a sound sufficient premise: source phase lifts and target arc lifts lie within closed real intervals; strict separation excludes every common integer translate, hence every source-target intersection at every parameter including the endpoints. The proof allows changes in the internal order of sources. QED.

## Theorem 2: cross-version cache soundness

Let `V1` and `V2` be two persistent roots obtained by immutable path copying, splits, merges, source insertion or branch-specific deletion. If a subtree object `C` is **the exact same immutable object** under both roots, its event members and four extrema are unchanged. An exclusion certificate previously established for `(C,q,I)` remains valid under the new root for the same exact query signature `q` and any contained interval `I'`.

Proof: immutable sharing preserves the extensional event set and its exact aggregates; apply Theorem 1 to that set. Changed ancestors receive new objects and cannot inherit certificates keyed to their former identity. A branch added *outside* `C` may change the newest qualifying source, so the whole-root nominal winner must be recomputed separately. The algorithm caches only subtree exclusions and recomputes the winner and necessary current-root visits. QED.

The executable `check_r67.py` uses `Cache.data[(node, (theta0,j,x,m,z,nxt))]` with `@dataclass(frozen=True,eq=False)`: node keys have Python object identity; the cache holds them strongly, and each positive parent interval is stored as exact `Fraction` endpoints. A cached positive result is used only if `parent_L <= query_L <= query_U <= parent_U`. An unverified or inconclusive test is never cached as positive.
