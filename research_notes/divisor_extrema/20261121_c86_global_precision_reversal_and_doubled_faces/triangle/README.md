# C86 三角窗分支复算说明

## 主要结果

在 C85 的同一辅助单位余体积 Haar 格模型下，本分支证明：

1. 有限诱导 Farey 图无长无弦圈；对来自凸窗的实际方向集，准确三角面数为 \(e-D+1\)。
2. 面积 \(A<4\) 时，准确符号修正为
   \[
   \Psi=R-\tau-\Pi+Q_P+Q_T.
   \]
3. \(Q_P\) 在 \(2<A<4\) 上有准确一维初等函数积分；\(Q_P=0\) 对 \(A\le2\) 成立。
4. \(Q_T\) 的首次可能面积为 \(8/3\)，所以
   \[
   \Psi=R-\tau-\Pi+Q_P\qquad(0<A<8/3).
   \]
5. 在原有 C85 外层网格和区间算术精度上，得到
   \[
   \frac{8879797996758579248357681281004993}{2^{112}}
   \le\kappa_3\le
   \frac{9325116056440067185142329372765413}{2^{112}}.
   \]
   显示小数约为
   \[
   [1.71018688620671388655486,\ 1.79595202479841387041990].
   \]
   因而严格可写为 \(\boxed{1.7101<\kappa_3<1.7960}\)。

以上是原读数问题经既有桥接后的一条辅助解析分支，不声称改变或替代原生定义，不声称解决全部原生库存问题。理论推导、程序运行、项目内交叉检查与外部同行复核分别记录；本包不声称已完成外部同行复核。

## 文件导航

完整证明依次阅读：

- CHORDAL_CORRECTION.md：弦图证明、面数、实际符号重数及初步下界。
- DOUBLED_FACE_INTEGRAL.md：QP 准确一维积分、归一化、概率夹逼和有向积分误差。
- QT_SUPPORT.md：QT 首次支持 \(A=8/3\) 的完整极值证明和达到构型。

完整最终证书为 doubled_face_certificate.json；早期只使用非负修正的过渡证书为 chordal_lower_certificate.json。最终证书准确记录执行参数、源文件 SHA-256 和有理数端点。小数只用于显示。

## 复算命令

完整最终积分复算：

    python /mnt/data/C86/triangle/certify_doubled_face.py

在本次环境下实际运行约 81 秒；机器差异不影响数学语义。该命令覆盖准确小面积项、全部中间面积单元、短方向下界、行上界、Π 和 QP 的整单元有向包围，以及已有证明尾项。它输出并覆盖最终 JSON 证书。

只核对符号代数、达到构型、已保存证书绑定与严格端点：

    python /mnt/data/C86/triangle/verify_doubled_face.py

该快速检查另外复用原有限 Farey 检查：1069 个源点实例验证普遍图恒等式，其中 1022 个单双符号实例验证本分支的准确重数。有限检查不被当作普遍证明，快速检查也不冒称重新运行了全部积分网格。

## 沿用来源

## 明确保留的问题

当前并未把 \(8/3<A<4\) 上的 \(Q_T\) 积分完全求值。这里使用的是已证明的 \(0\le Q_T\le\tau\)，因此 \(\kappa_3\) 区间的剩余宽度包含真实未积掉构型的贡献，而不只是数值网格误差。继续处理 QT 是后续解析方向；没有把未核实的候选积分纳入当前证书。
