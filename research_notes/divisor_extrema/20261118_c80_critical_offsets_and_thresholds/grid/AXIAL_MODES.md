# 临界相邻两库的实际一阶轴向模

令 \(m\) 和 \(A=\{m=1\}\) 如 PHASE_GEOMETRY.md，记 \(S(x)=\int {\bf1}_A(x,y)\,dy\)。对于有限读数，\(S\) 是紧支撑的阶梯函数。在全部横向事件处作分部积分给出
\[
 |\widehat V(1,0)|=\frac1{2\pi N}\left|\sum_t \Delta S(t)e^{2\pi i t}\right|.
\]
交换两轴即得 \(|\widehat V(0,1)|\)。实际的单格宽方块与左下角定义相差普遍的整数平移，模长不受影响。实值函数的正负频率系数互为共轭，故两对轴向一阶模的方差份额是 \(2(|\widehat V(1,0)|^2+|\widehat V(0,1)|^2)/\sigma^2\)。

**计算误差。** 首先将真实输出以区间算术夹至 \(Q^{-1}\) 格，\(Q=2^{40}\)。每个单位方块的对称差面积至多 \(4/Q\)，归一后对任一 Fourier 模的绝对误差至多 \(4/Q\)。取整后的扫描按整数长度求全部 \(\Delta S\)，每次方块边事件都在长度为一的区间内改变截面，故 \(\sum|\Delta S|\le2N\)。用四段二进制查表组成格点的单位复数。表中实部与虚部以 45 位十进制区间运算夹至 \(1/B\)，\(B=2^{60}\)。每次复数定点乘法的舍入模误差小于 \(2/B\)，每个表项模误差小于 \(2/B\)。四步累积误差小于 \(32/B\)（一步将旧误差乘至多 \(1+2/B\)，另加 \(4/B\)）。代入上式后模长附加误差小于 \(12/B\)。JSON 给出了向外取整至 \(10^{-12}\) 的区间，方差分母使用前一次独立求得的严格标准差区间。脚本同时通过三组小点集的两个轴向直接相位枚举和逐区间指数积分对照。

复算命令如下。除 C++17 和 Python 外，本项还使用 Python 的 mpmath 区间四则与三角函数。

~~~sh
g++ -O3 -std=c++17 -o sweep sweep.cpp
python profile_modes.py 32 512 --output profile_modes.json
~~~
