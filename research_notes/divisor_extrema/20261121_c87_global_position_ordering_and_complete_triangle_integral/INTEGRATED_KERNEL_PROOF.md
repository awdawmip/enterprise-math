# C87：径向积分核在整个位置轴上的严格正性

## 结论与对象

本文件的辅助核记作 \(\mathcal H\)，程序中仍沿用变量名 H。它是 C86
准确有限 Mellin 归约的十分区代数函数，不是原实验的观察量 \(H(0,1)\)。
所有原安排和相关整数竞争者都已由既有桥接与 C86 全面积恒等式保留。

令

\[
\gamma=1/20,\quad \rho=2+\gamma=41/20,\qquad
A(x)=\int_0^1r^\gamma\mathcal H(r,x)\,dr.
\]

本轮证明

\[
\boxed{A(x)>x^2/200\quad(0<x\le1).}\tag{1}
\]

证明由覆盖 \((0,1/8]\) 的准确展开，以及覆盖 \([1/8,1]\) 的整区间证书组成。
不存在未处理的轴邻域，也没有用有限取点正性替代完整区间正性。

## 1. 轴邻域的解析证明

在 \(x\le1/8\) 上，C86 有限数据的所有项为
\(w|a+(b+cr)x|^\rho\)，其中 \(a\in\{0,1/2,1\}\)。非零底数项的
常数与一次系数在各径向分区内准确消去；零底数项准确给出 \(x^{2+\gamma}\)。
因此，完整径向积分满足

\[
\left|\frac{A(x)}{x^2}-a_2-b_2x^\gamma\right|\le Ex,
\qquad E=\frac{9318931}{47520000},
\]

\[
a_2=\frac{211}{244}2^{-1/20}-\frac{101}{122}4^{-1/20}+\frac{23}{61},
\quad -0.432249976<b_2<-0.431787736.
\]

利用 \(b_2>-433/1000\) 和完整三阶 Taylor 余项，得到

\[
\frac{A(x)}{x^2}\ge
a_2-\frac{433}{1000}(1/8)^\gamma-E/8
>0.0251629959085>1/40.
\]

全部系数消去、余项、积分误差和整数根包围见
[ENDPOINT_AXIS_PROOF.md](positions/ENDPOINT_AXIS_PROOF.md) 及其执行证书。

## 2. 剩余完整区间上的有向包围

将径向区间按 \(r_i=i/96\) 分割。所有径向分界
\(1/3,1/2,2/3\) 都是网格边界。横向待证区间为 \([l,h]\)，
中心 \(x_c=(l+h)/2\)，半宽 \(d_x=(h-l)/2\)。

每个径向单元的正测度是 \(r^\gamma dr\)。其质量 m 和准确重心 μ 为

\[
m=\frac{20}{21}(r_b^{21/20}-r_a^{21/20}),\qquad
\mu=\frac{\frac{20}{41}(r_b^{41/20}-r_a^{41/20})}{m}.
\]

程序给出有理节点 \(r_0\) 与有向位移界 \(|r_0-\mu|\le\epsilon\)。
其断言同时检查节点确在径向单元内。

### 2.1 完全位于单一公式区的单元

设完整矩形上的导数界为 \(G_r,M_{rr},M_{xx}\)。先在固定 x 下对 r
作带权重心 Taylor 积分，再在固定 \(r_0\) 下对 x 作 Taylor 展开，得到

\[
\int_{r_a}^{r_b}r^\gamma\mathcal H(r,x)dr
=m\{\mathcal H(r_0,x_c)+\mathcal H_x(r_0,x_c)(x-x_c)\}+R(x),
\]

\[
|R(x)|\le m\left(
\frac{M_{rr}(r_b-r_a)^2}{8}
+\frac{M_{xx}d_x^2}{2}+G_r\epsilon\right).\tag{2}
\]

径向 \(1/8\) 来自支持长度为 \(r_b-r_a\) 的概率测度方差不超过长度平方的
\(1/4\)，以及 Taylor 余项的 \(1/2\)。不需要混合导数消去。

不同内部单元的有符号一次斜率先求和，再对总斜率取绝对值。这保留真实消去，
同时仍是对整个 x 区间的严格误差包围。

### 2.2 跨越公式分界的单元

跨区条件只可能是 \(s=rx\) 跨过 \(1/3,1/2,2/3\)。程序枚举所有与
完整矩形相交的 s 分区。每个公式都延拓到该矩形，再用中心梯度和完整 Hessian
界得到分片梯度上界 \(G_r,G_x\)。

C86 已准确证明函数值在所有分区界连续；法向一阶导数并非处处连续。因此这里只用
连续性及分片梯度沿水平、垂直线段积分，得到

\[
|\mathcal H(r,x)-\mathcal H(r_0,x_c)|
\le G_r(r_b-r_a)+G_xd_x.\tag{3}
\]

该单元不加入一次斜率，而将式 (3) 全部计入余项。这覆盖分界在单元内部移动、
在节点相交及在矩形边界相交的情况。

### 2.3 完整公式上的导数界

每项为 \(w|a+bx+crx|^\rho\)。双仿射参数绝对值的最大值在四角达到。
令其最大值为 M，取 \(Q_0=\max(1,M)\)，则 \(M^{1/20}\le Q_0\)。
直接微分并求和给出所有一阶、二阶导数的有理上界。
\(|z|^{41/20}\) 的二阶导数在 z=0 仍连续，所以参数为零处没有漏项。
完整公式及其来源核对保留在 [KERNEL_REGULARITY.md](inputs/c86/phase/KERNEL_REGULARITY.md)。

## 3. 区间接受条件与实际结果

把所有径向单元合并，得到中心区间 C、总斜率区间 S 和非负余项上界 E₀。
完整 x 区间的 A 值包含于

\[
C+[-E_0-|S|d_x,\ E_0+|S|d_x].
\]

若所得下端严格大于 \(h^2/200\)，则整个 \([l,h]\) 都满足式 (1)。
未满足的区间二等分后继续计算。代码接受条件允许等号；本次全部实际端点都有严格裕量。

实际生成器执行 117 次区间试算，最后接受 60 个闭区间，首端为 1/8，末端为 1，
相邻端点准确相等，无任何间隙。其最小已证比值为

\[
\min_{[l,h]}\frac{\text{A 的完整区间下端}}{h^2}
>0.0059420874287408>1/200.
\]

运行中的 293,423 次二十次根候选均通过上下两个准确整数幂比较。
随后使用分母 \(2^{112}\) 的有向区间运算。浮点数只提出根的候选整数，
没有参与符号决定或误差接受。

证书保存每个完整区间、中心、斜率、总误差、输入哈希及完整覆盖清单。
与轴邻域证明合并即得式 (1)。

## 4. 证明的实际强度

这是对径向积分后 A 的严格正性。它足以由 C86 准确位置恒等式推出
I 的严格凹性与全部位置排序，见 [GLOBAL_POSITION_THEOREM.md](positions/GLOBAL_POSITION_THEOREM.md)。
本文件没有把 \(\mathcal H\) 在其余区域的逐点正性作为前提，也没有用
独立竞争者近似、遗漏远端分支或改变原观察量。

完整生成命令：

```bash
python certify_integrated_kernel.py
```
