# C87 三角窗分支：完整 QT 积分与常数证书

## 完成的研究结果

C86 留下的 \(8/3<A<4\) 双符号中心面贡献 \(Q_T\)，现已化为一个完整、显式、处处非负的二维积分。源层和端点横坐标的积分先化为凹分段直线 \(K(h)\) 的正部平方积分；该函数只有四个结点，故最后一条 h 积分可以准确完成。剩余两参数为 \(u,t\)，无遗漏扇区、边界或结点交换单元。

由此，原有
\[
\Psi=R-\tau-\Pi+Q_P+Q_T\qquad(0<A<4)
\]
在整个指定面积段都有可直接复算的显式积分。这里的“显式”指有限初等被积函数与完整有界积分域，不把尚存二维积分称为 A 的初等闭式。

核心证明：

- QT_POSITIVE_INTEGRAL.md：归一化、全部支持域、两个 Jacobian、四结点非负公式、对称性、角支持排除及整单元区间方法。
- qt_positive_integral.py：上述公式的 112 位有向整数区间实现。

所有定义仍承接原 H(0,1) 问题经既有桥接后的辅助 Haar 格模型，不改变原生 X6、原读数或完整竞争者范围。基础来源是 C86 不可变提交 16aa076c692d75590549e13aad3128eb34cb285f。

## 实际完成的常数证书

完整生成器已经实际执行，得到
\[
\frac{8879799718450538658554682430737307}{2^{112}}
\le\kappa_3\le
\frac{9259117095632433299866803560123257}{2^{112}}.
\]
显示小数为
\[
[1.71018721779252385043805,\ 1.78324108730662770168686].
\]
因此严格可写为
\[
\boxed{1.7101<\kappa_3<1.7833.}
\]
上下端均严格优于 C86 的保存证书；主要数值改善在上端。下端改善较小，因为大多数相应面积单元中，既有短方向下界强于新增面数下界。

证书保留 C86 的面积网格 \(1/1024\)、面积缓存网格 \(1/64\)、QP 每段 64 个中点单元和 112 位算术。新增 QT 采用每轴 64 个完整矩形单元。在结点可能交换顺序的单元内，程序枚举所有区间相容排列；未用中点排序代替完整单元。

当前程序在 \(8/3<A<4\) 上使用完整 QT 公式给出的上界，与 C85 的上界相交；没有另行重复保留 C86 的 \(R-\Pi+Q_P\) 上界。这不影响本证书的有效性，且本次实际最终区间已经严格改善 C86。因此没有为可选数值优化另行重跑或加密网格。

## 复算

完整积分复算：

    python /mnt/data/C87/triangle/certify_qt_complete.py

本次实际执行耗时约 234.83 秒，机器速度可不同。程序覆盖全部面积单元、保留的头尾项、Π 和 QP 包围以及新增 QT 整单元包围，并输出准确有理数端点。

快速复核：

    python /mnt/data/C87/triangle/verify_complete_qt.py

该命令执行两条独立消元路线的准确有理数比较：原源层 s 的截断平方公式，与新增 h 的非负凹折线公式。1150 个源参数实例中有 464 个非零，实际覆盖 11 种结点顺序；另核对 1150 个反射恒等式、1150 个有向点包围，以及四个跨结点或支持边界的完整参数框及其 36 个准确样本点。随后核对保存证书的分块求和、全部八个源文件绑定和最终严格端点。

快速复核不重新运行完整积分网格；有限检查不代替 QT_POSITIVE_INTEGRAL.md 的普遍解析证明。

## 保留的局限

本轮已经消掉 C86 在 \(8/3<A<4\) 上未计算的 QT 构型贡献。常数区间的剩余宽度仍包含既有其他面积范围的不等式、外层独立单调包围和有向数值包围；本结果不声称已确定 \(\kappa_3\) 的精确值，也没有处理 \(A\ge4\) 时可能出现的多个双符号方向的新重数。
