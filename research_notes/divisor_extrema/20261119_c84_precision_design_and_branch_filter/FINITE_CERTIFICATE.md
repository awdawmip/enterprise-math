# C84　F₃(1/3) 的严格数值外包

将 `FINITE_FORMULA.md` 的一维准确积分用定向整数区间运算计算，本轮得到

$$\boxed{0.397047162<F_3(1/3)<0.397047924.}$$

区间宽为 0.000000762，小于 10⁻⁶。上述有限小数是向外舍入的严格界。程序中更细的准确有理端点是

$$\frac{263883101692472359019620819430994367}
{664613997892457936451903530140172288}
\le F_3(1/3)\le
\frac{527767215462603718608186112179604965}
{1329227995784915872903807060280344576}.$$

本结论依据一维积分的解析证明、下面的误差外包和实际执行的整数证书；没有使用普通浮点求积的经验误差。

## 1. 两个有理积分区间

在 a=1/3 时，A=2/3，式 (1) 的分点为 z=5/3。左支改用

$$q=\sqrt{z^2-8/3},\qquad 0\le q\le1/3,\qquad dz=(q/z)dq.$$

右支为 5/3≤z≤2。因此两个积分区间长度都准确等于 1/3。每支分成 2048 个等长有理小区间，每格宽为 1/6144。

左支 q=0 与右支 z=5/3 的首格，使用整个函数值区间乘格宽。其余 4094 格使用中点值，并以区间自动微分计算整格二阶导数的绝对上界 M。若格宽为 h，则准确中点误差为

$$\left|\int_{x_0}^{x_0+h}f(x)dx-hf(x_0+h/2)\right|\le Mh^3/24.$$

函数在这些闭格上光滑，所有原函数的对数参数有严格正下界。首格允许可积端点的二阶导数无界，因而没有套用该误差式。

## 2. 区间算术的严格方向

每个区间端点是整数除以 2¹²⁰。加、减、乘、除、整数幂分别用整数商向下或向上舍入；sqrt 下界为整数 isqrt，下界平方若未达到上端输入，便增加一单位得到上界。

log 对一个正端点先作二进制范围缩放 x=2^k u，1≤u≤2。令 w=(u−1)/(u+1)，使用 48 项正项级数：

$$\log u=2\sum_{j=0}^{47}\frac{w^{2j+1}}{2j+1}+R,
\qquad 0\le R\le\frac{2w^{97}}{97(1-w^2)}.$$

log 2 由同一公式预先包围。对于区间输入，log 的单调性允许分别包围两个端点。

atan 的实际输入均位于 [0,1/2]。48 项交错和 S₄₈ 满足

$$S_{48}\le\arctan x\le S_{48}+x^{97}/97.$$

π 采用准确恒等式

$$\pi=16\arctan(1/5)-4\arctan(1/239).$$

atanh 使用 log 的准确差式。所有级数项、余项、范围缩放和组合都继续按同一整数区间规则计算。普通浮点数只用于 JSON 中的说明性小数显示，不进入任何包围端点或积分误差。

## 3. 消除显示公式的可去端点奇点

内原函数含有 log(r−D)，但实际出现的是有限乘积。置 f(x)=x log x、f(0)=0，则例如

$$L^-_0(r,D)=f(r+D)-f(r-D)-2D,$$

$$L^-_2(r,D)=\frac{(r^2-rD+D^2)f(r+D)
-(r^2+rD+D^2)f(r-D)}3
-\frac{2r^2D}3-\frac{2D^3}9.$$

所需奇次 atanh 原函数也用同样的乘积重写。这些恒等式与 `FINITE_FORMULA.md` 的原函数相同。

当一个区间含 x=0 时，直接利用 x log x 在 (0,1/4] 单调递减得到值域 [h log h,0]；其他正区间用普通区间乘法包围。代码还保留粗通用界 x log x≥−1。右支使用已由积分域证明的 r−D≥0，将区间依赖造成的负下端截为零，这不会删除任何真实值。

区间二阶自动微分严格应用乘积、倒数、平方根、log、atan 和 x log x 的一、二阶导数公式。自变量的一阶导数为 1、二阶导数为 0，其余参数恒定。

## 4. 证书与实际执行

完整认证命令：

```bash
python finite/certify_one_third.py --grid 2048 --output finite/one_third_certificate.json
```

实际执行退出 0；共 4096 格，4094 格中点外包、2 格直接值域外包，运行约 64.14 秒。准确整数结果见 `finite/one_third_certificate.json`。

另行运行

```bash
python finite/verify_certificate.py
```

7 项检查通过：36 对准确有理数的基本运算、5 组整数平方根、7 组 log 与独立 120 项 Fraction 级数的包含关系、5 组 atan 的同类检查、已知准确一二阶导数、保存证书的有理端点与向外小数，以及新计算的每支 8 格粗外包。粗外包包含已保存细界；它没有被称为重新生成 2048 格证书。

这一严格界比 C83 的探索性二维求积增加了明确数值误差控制。40 位一维探索值 0.3970475447220514… 位于证书内，但证书的正确性不以该小数为前件。
