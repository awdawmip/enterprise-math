## 1. 本次补充完成的缺口

前一检查点给出素数组合扇形的收敛与发散条件，但扇形影响有限不能保证完整网络也有限。本补充在不改变完整乘法图、不删除重叠关系的情况下，给出一个真正作用于完整网络的上界。继续同一有限正权W=prod_f(1+t_f B_f)，0<=t_f<1，旧参数不随前缀N重新调参。

## 2. 单边翻转的配对证书

取待观察闭环C中的一条边e。翻转这一条sigma_e，记tau=F_e sigma。它在所有完整赋值之间是双射，且必使sigma_C反号。仅包含e的作用项变化，因此

W(F_e sigma)/W(sigma)=prod_(f contains e)(1-t_f B_f)/(1+t_f B_f)。

令
c_e(N)=prod_(f contains e)(1-t_f)/(1+t_f)>0。

逐个正概率分支有W(F_e sigma)>=c_e W(sigma)。把正环符号分支与负环符号分支配对求和，得到
P(C=-1)>=c_e P(C=+1)，
chi_C(N)<= (1-c_e(N))/(1+c_e(N))。

此证明覆盖完整网络的所有其他面、所有重叠关系和全部边变量；没有依赖扇形中条件独立。它是派生的概率比证书，不是把负符号当负质量。若同一个固定边e满足sum_(f contains e)t_f<infinity，且每项t_f<1，则无限乘积c_e有严格正极限，故这个固定闭环不能趋于完全相容。该条件充分，不声称必要；不等于所有原生物理相互作用必须满足这个和。

## 3. 同图、同素数、同旧局部参数的两种整体极限

定义面最高整数M_f=upq（面f=(u,up,upq,uq)）。因M_f>=6，以下两个完整网络都保持正有理权重：

U：t_f=1/2，对所有面相同；
D：t_f=(1/2)(6/M_f)^2=18/M_f^2。

旧面C0=(1,2,6,3)在两者中t0均为1/2。前缀整数、素数集合、密度和所有连接完全相同；区别仅是较大联合关系的权重是否衰减。两种权重都是本轮明确的模型假设，尚未由原生作用或实验拟合选定。

U模型由前一检查点定理给chi_C0(N)->1。

D模型选择旧环上的边e=(3,6)。包含它的面恰好是原面C0与以每个素数q>=3构成的面(3,6,6q,3q)。前者给因子1/3，后者t_q=1/(2q^2)。因此
c_e(N)=(1/3)prod_(3<=q<=N/6,q prime)(1-1/(2q^2))/(1+1/(2q^2))。

使用对0<=s<1的(1-s)/(1+s)>=1-2s，及有限乘积prod(1-a_i)>=1-sum a_i，得到
sum_(q prime>=3)1/(2q^2) <= (1/2)sum_(n>=3)1/n^2 <= (1/2) integral_2^infinity x^-2 dx =1/4。

故全部N下c_e(N)>=1/6，进而

1/2 <= chi_C0(N) <= 5/7 <1。

下界来自非负耦合单调性及固定旧参数1/2。旧参数按M_f固定，故D模型的前缀相干也单调，极限存在，仍属于[1/2,5/7]。

这解决的是完整网络的非完全相容证书，不只是一个子网络上界。它没有证明相干降到0、机械稳定、物体寿命或某个物理临界指数。两个相同素数密度的完整网络有不同固定局部极限，说明密度本身不能选择这里的结果。
