# 高库存偏离与最后两块的精确比较

沿用 C63 的记号与已经证明的带势函数高段引理。第一个内部隙的偏差是 s = 1−b₀ ≤ 1，其势 W_start ≤ 1。非基准边是 (s,m) ≠ (0,1)，每经过一边，s′ = s+1−m。用 G 表示同一 r 的基准边最大绝对斜率，L 表示当前边最小绝对斜率，Q=W_next/W_now。

**引理。** 若 r≥64 的前缀含至少一条非基准边，则完整日程的 TV 严格大于 252 倍的基准 TV。

（1）截面 r=63 库存 2≤c≤96 且 c≠64 时，使用 C64 有限截面证书的 WD/U>600。各高段非基准边 L/(GQ)>21/10，基准边的总失真大于 377/378。最终比大于 (377/378)(21/10)600>252。

（2）截面库存 c≥97 时，s_cut=c−64≥33。每种非基准边使 s 至多增加一，基准边使 s 不变，故含至少 32 条高段非基准边。C63 §4 给出 W_cut D/U>2，合并得比大于 2(377/378)(21/10)³²>252。

（3）截面库存 c=64 时，考虑最后一条高段非基准边。后面的基准边使偏差保持 0，故这条边末端 s′=0，从而 c−m=r、s=m−1。这条边不可能有 m=1。

- 若 m=0，则 s=−1，c=r，Q=16，ρ−1=3r/(3r+1)>9/10。此时 7≤τ≤63，τ/(τ+4)²≥1/80，G≤1/(100r²)，故 L/(GQ)>100r²(9/10)/(80·16)≥288。
- 若 m=2，则 c=r+2，s=1，Q=1。在 ρ 的三个乘积因子中，(K+4(c−j))/(K+c−j) 随库存 c−j 增加，因此 ρ≤[(6r+9)/(3r+3)]³/16≤(131/65)³/16<3/5。又由 C63 附录 A 的全范围界 τ/(τ+M)²≥(2/5)16⁻²=1/640，M=max(1,ρ)，故 L/(GQ)>100r²(2/5)/640=r²/16≥256。
- 若 m≥3，C63 附录 A 证明 c−m≤r 时满足 |ρ−1|≥1/10，故 L/G≥4r²16⁻ᵐ。此边势函数给出 1/Q=16ᵐ⁻²(3r+m+1)!/(3r+3)!。后一个阶乘比至少为 3r+4，故 L/(GQ)≥r²(3r+4)/64≥12544。

其余高段非基准边 L/(GQ)>21/10>1。高段基准边的累计失真大于 377/378。库存 64 的基准后缀其最小与最大斜率之比大于 99/100，任何不同后缀有 D/U>14。因此两种情况下最终比均大于 (377/378)256(99/100)>252。三种情形覆盖全部可能。

**最后两块。** 进入 r=2 时库存为 3。记 A、B、C 三种后缀（r=2 隙，r=1 隙，尾隙）为 (1,0,0)，(0,1,0)，(0,0,1)。三者在每个 k≥3 都允许共同前缀。对于同一对输入 u,v，最终 TV 是最后第三个状态坐标变化的绝对值。将第三坐标写成 (pu+q)/(hu+t)，依次得到整数四元组

- A = (−115,124096,−51520,27872768)
- B = (207,12152,24426,1074896)
- C = (828,87776,267237,11696360)。

直算：A、B 最末状态第三坐标是 (1−u)/8；C 尾隙的一次 5 给到 3/7、3/4、12/13 三个似然。由此组合前两个可见块的原映射。对于任意两套四元组 i,j，TV 之比为 |det i / det j| h_j(u)h_j(v)/(h_i(u)h_i(v))，其中 h_i(x)=h x+t；一次分式在 [0,1] 上单调，把 h_j/h_i 的两个端点分别平方即可夹住该比。于是
```
78046315776/5227114445 ≤ Δ_B/Δ_A ≤ 4598546819328/293363639465,
289253836505088/12381284877025 ≤ Δ_C/Δ_A ≤ 1311003893219328/53439389550625.
```
两组界分别严格落在 (14,16)、(23,25)，对任意不同输入成立。输入不同时，端点平方界实际上也是严格的。
