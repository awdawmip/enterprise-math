# 复算 C74

在本目录运行 `python3 reproduce.py`，默认重跑八项：逐因子三态对照及 503 行证书的范围、计数和格式检查；已知首落点的单次穿越（首落点至 100）；用两次外库存校准作精确反演；Gamma 系数递推；近同步行的二分与小规模穷举；外层碰撞方程与末扰动；实数舍入宽度和两个指定读数的准确间距。默认模式读取已附的大库存证书，另从原始三态路径逐词核对小库存。实测环境为 Python 3.12，默认模式另需支持 C++17 的编译器。

运行 `python3 reproduce.py --full` 还会按顺序重新编译并计算全部 503 个新库存的排序证书、三个同首落点的区段和合计结果。该模式需要 GMP C++ 开发库和约 1.6 GB 可用内存，较耗时。所有生成的输出都同归档逐字节比较。枚举大库存的结果按库存独立汇总，各库存内的指纹直接排序查找相等项。完整程序与区段命令亦见 FINITE_STOCKS.md、SAME_LANDING.md。主证明、旧结果的固定链接和有限与渐近的适用范围见 C74_RESEARCH_NOTE.md。

补充行数表使用单调性，仅在最接近 1 的两项上比较准确分数；前 63 行另逐项交叉核验。两次离散积分的方向和有理区间反演数据均来自同一原模型。单调积分部分存在相邻整数库存发生次序互换的实例，其读数差正负都有，不计作相等。研究包所附有限证书属于作者复算，科学认定仍待外部独立复核。
