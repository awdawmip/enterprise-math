# C82 复算与文件入口

## 阅读顺序

1. `C82_RESEARCH_NOTE.md`：完整结论、适用范围、有限数据及未解问题。
2. `CROSS_PHASE.md`：三项观测组 (G,B1,B2) 几乎处处单射；三次有限读数排除远片；三个原点的相位消去。
3. `LATTICE_LIMIT.md`：近距格的 Haar 极限；F2、F3 的定义；大余体积闭式；固定首末两库存的严格收益。
4. `HIGH_PRECISION.md`：原 Jacobian 因子式；边界积分；L^(-1/10) 主项及严格常数界。
5. `FIBER_STRUCTURE.md`：全部原像数、非退化折叠、峰值和密度。

`HAAR_CLOSED_FORM.md` 是与主证明独立计算的尾部常数交叉推导。`SOURCE_PINS.json` 保留直接数学前件及所读不可变来源。

## 复算

需要 Python 3、NumPy、SymPy。全部小数仅用于结果展示；有理证书使用标准库 Fraction，Jacobian 恒等式用符号约分，物理读数使用定向二进制区间。

在解压后的 C82 目录运行：

```bash
python verify.py
```

它重算尾部有理积分与系数，检查 Jacobian 恒等式，重建原像和峰值的有理证书，核对有限目录的结构及两库/三库计数关系，并重算 c=4、16 的完整目录与 378 次原生路径包围。输出 `checks.json`。这是一组可复算的代数、程序和证书检查，不是解析证明的形式化证明器。

完整重算五个有限目录：

```bash
python finite/three_readings.py 4 16 64 256 1024 --output finite/three_readings.json
python verify.py
```

在本轮环境，该完整枚举已经执行结束，原始结果随包提供。共 558,558 条安排，每条三个库存，八组 0/半格偏移。`interval_bits=176` 表示有向区间内部精度；`p` 才是实验中的读取位数。精度不足以确定格号时程序会拒绝该格，不能把未定区间当作近似格号。

小库存的 `native.py` 从原始三态路径直接构造有理数，`critical_bins.py` 来自 C81 的有限读数区间实现；`SOURCE_PINS.json` 记录原件来源。两者执行路径不同，原生路径检查因此可检验有限谱实现是否仍计算相同的 H(0,1)。

## 核对清单的边界

`checks.json` 记录本次真正执行的范围与环境；`SHA256SUMS` 供文件一致性核对。程序成功只支持其列出的检查。极限、相位消去、Haar 均匀分布的适用性和负矩可积性由相应数学文档证明，并作了项目内并行复推。外部同行复核尚未进行。

本包不宣称新的单库存准确读数无碰撞枚举范围，也不把八个格原点说成整个原点环面的有限穷举。三库的全部原点一致性来自解析证明。
