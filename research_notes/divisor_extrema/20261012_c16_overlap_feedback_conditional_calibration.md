## 2. 两个相邻六面单元的完整外层因子

取不同奇素数p,q，在4pq的全部约数上保留交换面。这是两段重复2与p、q的组合，12个节点、20条边、11个面；面边界秩9、闭合关系维数2。保留两个相邻底面：A=(1,2,p)，B=(2,2,p)，符号a,b。

两个六面单元各含一个底面，且共享一个非底面。对外层符号求和，得到相对于底面的有效因子

 F_theta(a,b)=1+theta^5(a+b)+theta^8 ab。

证明：C12正填充展开中，空填充给1；单个六面单元除掉底面有5个外面；同时选择两个单元时，共同面出现两次并在模2边界中消去，除掉两个底面共剩8个外面。四种边界1、A、B、A+B的系数依次为1、theta^5、theta^5、theta^8；边符号来源的共同倍数与a,b无关。闭合关系核维数2证明没有遗漏其它填充。

若错误地把两次反馈独立相乘，则ab系数是theta^10，不是theta^8。差值theta^8(1-theta^2)>0是共享结构带来的额外联合项。这里的模2消去是相位边界读出，不把正质量相消。

最小算术见证是4*3*5=60；底面分别为1-2-6-3与2-4-12-6。单个30单元的旧环读数是34/65(theta=1/2)，60约数棱柱内是554/1057，严格更大。后者不是完整1..60前缀的全部读数；完整前缀还保留其它关系。

## 3. 在同一完整网络内改进C15下界

对每个观察p，令Q=floor(M/(2p))。
 n2=pi(floor(Q/2))-1{Q>=4}-1{Q>=2p}；
 n1=pi(Q)-1{Q>=2}-1{Q>=p}-n2。

n2是满足4pq<=M的第三素数q!=2,p个数，n1是只能保证2pq<=M的剩余个数。为每个n2保留两相邻单元，为n1保留一个单元。不同q的外侧节点/边互不重合，只共享底部两面和底部图；因此给定底部后才可以分别消去，不假定无条件独立。

定义x=theta^5，y=theta^8，Fpp=1+2x+y，Fpm=1-y，Fmm=1-2x+y，均严格正。保留底面本身的权重后，旧面a的两类总质量为

 Zplus=(1+theta)(1+x)^n1 [(1+theta)Fpp^n2+(1-theta)Fpm^n2]；
 Zminus=(1-theta)(1-x)^n1 [(1+theta)Fpm^n2+(1-theta)Fmm^n2]。

令l2=(Zplus-Zminus)/(Zplus+Zminus)。n2=0时未出现的第二底面只是可消去的常数因子，公式精确退化为C15旧扇形；不宣称4p>M时该面已真实存在。

完整网络联合观察满足
 L_old <= L_new:=product_{p in P_N} l2(p) <= Xi_N(M) <= U_old。

证明：每个旧扇形都是本次子图的子结构，新子图又是完整前缀的子结构；新增非负关系对旧环的GKS单调性给单环比较。再以GKS乘积关联不等式得到联合下界。不同p的子图可以重叠，不把它们的概率当独立。随M增大，单个q由没有单元到单单元再到双单元，始终是增加关系，故L_new单调，首次门槛可以使用整数二分及前后相邻证书。

固定theta=1/2，目标Xi>=1/2，新旧充分门槛为：
 N30,K3：1378 ->1342；
 N100,K9：10034 ->9454；
 N1000,K57：224734 ->213526；
 N10000,K408：3811826 ->3603902。

C15必要界保持，因此本轮真实首次跨越区间分别为[121,1342]、[430,9454]、[7898,213526]、[122978,3603902]。它们是保守数学证书，不是实际临界点或实验置信区间。新上限只缩小数个百分点，不宣称已经逼近真正阈值。

## 4. 无穷尺度的充分侧常数也严格收紧

记r=(1-theta)/(1+theta)，B5=ln((1+x)/(1-x))，D2=ln(Fpp/Fpm)。由Fmm<=Fpm及分母保留正项，

 Zminus/Zplus <= [2r/(1+theta)] * ((1-x)/(1+x))^n1 * (Fpm/Fpp)^n2。

因此n1+n2=pi(Q)+O(1)、n2=pi(Q/2)+O(1)，令
 B_overlap=(B5+D2)/2。

有D2>B5，因为
 Fpp(1-x)-Fpm(1+x)=2(y-x^2)=2theta^8(1-theta^2)>0。
故B_overlap>B5。

令M/N~c ln N ln ln N。Q>=floor(M/N)，素数定理使上面指数的最弱渐近为c B_overlap ln N。用负事件并集界处理K~N/(3 ln N)个观察环，可得
 c>1/B_overlap => Xi_N(M)->1。

结合C15不变的必要侧，对于任何固定0<v<1：
 1/ln((1+theta)/(1-theta)) <= liminf M_*(N;v)/(N ln N ln ln N)
 <= limsup M_*(N;v)/(N ln N ln ln N) <=1/B_overlap。

theta=1/2时B5=ln(33/31)，D2=ln(91/85)，新充分侧系数为2/ln(3003/2635)，严格小于旧1/ln(33/31)。本轮保留符号对数，没有新增普通对数/根号或物理传播器数值运算。

这不是精确临界系数，也没有证明临界响应宽度。它说明重复2与第三质数的交叠可以系统改进旧的独立单元估计，而不用更换局部theta或附加衰减律。

## 5. 条件观察：先区分局部强度，再约束环境

取一条特殊边e=(p,2p)，p>=5。所有包含它的面为f0=(1,2,p)及(p,2,q)，q为不等于2且2pq<=M的素数。面数
 d=1+pi(floor(M/(2p)))-1{M>=4p}。

写B_j=sigma_e A_j，其余三边的乘积A_j不含e。当d>=2时选择一个jref!=0为参照，定义规范不变观察
 B=B_jref，C_j=B_j B_jref=A_j A_jref，j!=jref。

C_j不含特殊边。条件固定所有C_j后，变换sigma_e到B是逐赋值双射；非关联面的权重与B无关。故即使对其余所有边继续求和，仍有精确条件核
 P(B=b | C=c) proportional product_j(1+theta_j c_j b)，c_jref=+1。

每种相对条件都有正支持：原面f0的对边(1,2)，以及其余面(p,2,q)的对边(pq,2pq)，在该关联面族中分别只属于一面，可以逐个设置所需相对符号。不是把不可能的Bianchi赋值当可干预边界。

两种协议：
 H0：所有C_j=+1；
 H1：只有C_0=-1，其余相对符号为+1。

记录同一参照闭环B的正负概率比R0、R1。令h_j=(1+theta_j)/(1-theta_j)，则
 R0=product_j h_j； R1=R0/h_0^2；
 因而R0/R1=((1+theta_0)/(1-theta_0))^2。

两个条件读数先识别局部theta_0，外层其它关系的未知权重在比值中消去。这一局部识别在非均匀theta_j下仍成立。解也可写成(O-1)theta_0^2-2(O+1)theta_0+(O-1)=0，O=R0/R1；在0<theta_0<1唯一。代码使用原始正BRC幂的单调比较返回有理区间，不采用普通开方求值。

只有再确认所有关联面theta_j都等于该theta时，才可从R0=h^d识别整数面数d。异强度模型中R0只给乘积作用，不唯一决定数量。本轮反例：theta_0=1/2、另一面1/4，R0=5、R1=5/9，仍识别theta_0=1/2，但不能把5当成某个整数次3^d。

该协议涉及条件相位符号读出，不是任意两个绝对可见度。它是联合分布的条件辨识，不主张外层在物理时间中瞬时改变局部。能否以实际装置制备/选择这些条件，是独立的物理缺口。
