# C85 三角分支：复算入口

## 最终结果

本轮三角分支的最终严格外包是

\[
\frac{8582640364445688146560089200591674}{2^{112}}
\le\kappa_3\le
\frac{10166032737163568038796686356009924}{2^{112}},
\]

因此可直接引用

\[
\boxed{1.6529<\kappa_3<1.9580<2.}
\]

两个精确端点的显示小数约为
1.65295640797925298261447 与 1.95790668641242496709704。
显示小数不替代 JSON 中的有理端点。

证明依次是：

- `EXACT_TO_TWO.md`：准确公式扩展到面积 A<2；完整有限分类为 8 个正规形、34 个源点。
- `FAREY_UPPER.md`：方向图和 Euler 计数把五项式作为上界延伸到 A<4。
- `MIDDLE_ROW_BOUNDS.md`：两行公式在更大短方向范围中的准确贡献，以及格行相位上界。
- `PARALLELOGRAM_UPPER.md`：单位平行四边形的准确一维积分与进一步的图面上界。

## 重算

在本目录执行：

```bash
python classify_small_triangles.py
python certify_extended.py
python certify_middle_bounds.py
python certify_farey_parallelogram.py
python verify_triangle85.py
```

前三份证书保留了依次收紧的实际研究增量，最终数值使用
`parallelogram_certificate.json`。最终生成器完整运行了面积网格、短方向网格、
平行四边形积分和 256 项正有理尾级数，实际一次耗时约 37 秒。
快速验证器只重算有限分类、证书精确求和、字节绑定与有理比较，明确不重算积分网格。

`c84_interval_kernel.py` 是 C84 原证书代码的逐字节复制。其 Git blob 为
`64cb09dc3ff3c537c5604a55a2e06ba26a952a5e`，SHA256 为
`5abd803e6f952455ed0e138fac12ecc5f3c6b3594cfb357f4e0522b87e0033ed`。

## 后续准确问题

准确公式目前覆盖 A<2；A≥2 的四点构型仍造成上下界间的理论差距。
`explore_identity.py` 是构型探索程序，不参与最终数值证书，也不构成某个更大面积
区间的完整分类证明。它发现把全部实际平行四边形简单逐项扣除会重复计算符号三元组；
本轮最终采用的图面不等式正是通过“每面最多两个实际符号三元组”控制这一问题。

进一步取得准确式，可以研究含一个双符号方向的三角面重数修正及其四点窗积分。
本次严格数值来自已经写明并执行的上述界，不依赖这个后续方向。
