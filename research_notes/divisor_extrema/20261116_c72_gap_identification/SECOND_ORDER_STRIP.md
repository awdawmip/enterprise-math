# 两块模型中首落点的二阶分界及全库存条带

库存为两个 23 块和 c 个 5（含保留给共同末尾的两个 5），末尾仍是 557、575、755。合法词由两块后的剩余库存标记为 (v,w)，其中 2 ≤ w ≤ v ≤ c。对每个固定的末端列，令 Z_c(v) 为给定 v、使 w 取遍合法值时在原两端制备得到的概率比集合。本笔记比较实直线上的闭区间 I_c(v) = conv Z_c(v)。三列各自适用。两次原始 H 可复原其全体端点的最小值和最大值。

## 准确的充分条件

取 K=5，按 C68 的块表示
```
ρ(c,v) = 4 ∏_{i=v}^c (4i+5)/[4(i+5)],
f_v(t) = (ρ + τt)/(1+τt),          0<t≤4.
ρ(c,v+1)/ρ(c,v) = 1+15/(4v+5).
```
对 2 ≤ v < c 设 ρ⁺=ρ(c,v+1)，并写 (x)_m=x(x+1)…(x+m−1)。令
```
R(c,v)=(448/15) (v+1)(4v+5)/(v+4) · (v+5)_15/(c+6)_15.
```
这正是 (4τ/ρ)(4v+5)/15。因而当 ρ⁺<1，
```
f_v(4)<ρ⁺  ⇔  R(c,v)(1−ρ⁺)<1.                     (1)
```
这等价于将 f_v(4) 的准确分母乘出后比较两边。所有 u≥v+1 的端点都至少为 ρ⁺，因为 f_u(t) 位于 ρ(c,u) 与 1 之间且 ρ(c,u) 随 u 增加。故 (1) 使任一列同所有更大首落点分离；若每个 2≤u≤v 均满足 (1)，也能排除全部更小首落点。已知 v 后，公共首块可逆，按 C67 的末块定理，剩余的 w 由两次原 H 唯一确定。此过程同给定库存的所有合法竞争词比较。

固定 v 后若 ρ⁺<4/5，则 R(1−ρ⁺) 随 c 严格下降：R(c+1,v)/R(c,v)=(c+6)/(c+21)，而 ρ⁺(c+1)/ρ⁺(c)=1−15/[4(c+6)]。将两者乘出，下降等价于 ρ⁺/(4(1−ρ⁺))<1。因此一次检验同时控制全部更大库存。配套程序在 c=2501 对每个 v 用整数分数检验 ρ⁺<4/5 和 (1)，满足者恰为 2…1149。v=1149 的左端在 (0.9935,0.9936)，v=1150 在 (1.0064,1.0065)。结合 C71 的 c≤2500 单个原 H 全枚举，每个 c≥2 的所有首落点 v≤min(c,1149) 的两块词都可用两次原 H 在该库存全族唯一识别。这一检验的界为 1149，实际可识别域仍可更大。用原判据 R<1，在 c=2501 只直接给出 1131。

### 使用三条实际末列后，条带扩至 1196

固定 v，令 M(v) 为 1 与剩余单块所有合法 w、所有三列输出 t 的最大值。这个数与初始 c 无关。将 (1) 中的 4 换为 M(v)，充分条件成为 (M(v)/4)R(c,v)(1−ρ⁺)<1，随 c 的单调性相同。程序 finite_cap_check.py 由 C67 原三列的准确有理数公式计算 M(v)：在给定 v 下从 w=v 降序枚举，每个 w 对应的 ρ₂ 随降序递减。只要 ρ₂ 不大于已记录最大值（初值为 1），所有剩余输出均在 1 和对应的 ρ₂ 之间，故可停止。程序在 c=2501 逐一核验 v=1150…1196。到 v=1196，M(v)≈2.2319701411，新检验左端在 (0.99945,0.99946)；v=1197 时左端在 (1.01182,1.01183)。结合此前的 2≤v≤1149 与 C71 有限证书，**对每个 c≥2 且 2≤v≤min(c,1196)，两个原始 H 在全部同库存词中唯一确定 (v,w)**。新判据在下一点停止，未排除更大的两块词也能反演。两个程序均用 Python 标准库 Fraction 做全程精确比较。

## 单列可达凸包的二阶临界系数

令 θ=15/16、κ=15/64、a=(15/1792)^(1/16)、b=a^(19/4)/4。若
```
v=a c^(15/16)+d c^(45/64)+o(c^(45/64)),
```
则每一指定列的两个相邻可达凸包 I_c(v)、I_c(v+1) 在 d<b 时严格分离，在 d>b 时内部相交。相交结论仅针对凸包。

证明使用 C68 的相邻中心比例及准确升阶乘。由于 1/v=o(c^(−κ))，固定平移的 Gamma 比估计（或直接对 ρ 的乘积取对数求和）及有限积展开给出
```
ρ⁺=4a^(15/4)c^(−κ)(1+o(1)),
R=1+(16d/a)c^(−κ)+o(c^(−κ)),
R(1−ρ⁺)=1+(16d/a−4a^(15/4))c^(−κ)+o(c^(−κ)).
```
d<b 时 (1) 成立。要覆盖更小的落点，在 u≤v 上用
```
R(c,u)/R(c,u−1) ≥ (u+19)/(u+4)=1+15/(u+4),
ρ(c,u+1)/ρ(c,u)=1+15/(4u+5).
```
前一不等式因为 (u+1)(4u+5)/(u+4) 是递增正函数。因此 R(c,u)(1−ρ(c,u+1)) 大于前一 u 项，只要 ρ(c,u+1)<1/2：将两项乘出，用 R(c,u)/R(c,u−1)≥1+15/(u+4)，及 ρ(c,u)≤ρ(c,u+1)<1/2 即得。详细地，比值大于一等价于 (r−1)(1−ρ(c,u+1)) > ρ(c,u+1)−ρ(c,u)，其中 r=R(c,u)/R(c,u−1)；左边至少 15(1−ρ(c,u+1))/(u+4)，右边至多 15ρ(c,u+1)/(4u+5)。在上述窗口 v=o(c)，故所有 u≤v 统一满足此条件。对于任意 d<b 及充分大的 c，所有首落点直到上述 v 的完整词均全族唯一。

若 d>b，还须控制可达值逼近 f_v(4) 和 ρ⁺ 的速度。对 K=3 的剩余单块选择 w=v（不消耗 5 的中隙）。对应 ρ_2=4+O(1/v)、τ_2=O(1)；其终端三列均为 O(v^(−3/4))，所以所选定列的输出为 4+O(v^(−3/4))。另一端取 w=2；末端列有界，ρ_2=O(v^(−9/4))、τ_2=O(v^(−45/4))，故输出为 O(v^(−9/4))。首块的导数在 0≤t≤4 上至多 τ_v；τ_(v+1)/τ_v=1+O(1/v) 来自准确参数的有限积比。记 Δρ=ρ⁺−ρ。在此窗口 τ_v/Δρ→1/4，而且
```
(f_v(4)−ρ⁺)/Δρ = [R(1−ρ⁺)−1]/(1+4τ_v).
```
因为 τ_v→0，右边在 d>b 时为一个正常数乘 c^(−κ)(1+o(1))。可达端点相对 Δρ 的误差分别为 O(v^(−3/4))、O(v^(−9/4))，均是 o(c^(−κ))。故 v 的高端点严格越过 v+1 的低端点。反向排列则因 v 的低端点为 ρ+o(Δρ)、v+1 的高端点至少 ρ⁺ 而自动成立，给出严格的区间内部重叠。

首阶 c^(15/16) 与 a 来自 C68。二阶纠正来自使用准确的 1−ρ⁺。常数 a≈0.7416040252，b≈0.0604306660（以准确式为准）。边界 d=b 未由本条二阶命题判定；不同离散词是否碰撞也不由凸包重叠推出。本研究没有给出所有两块词全库存单射的阈值。
