## 条件定理：m=49 的全正整数参数符号

设整数 `k≥1`，`r=2k+1`，`C_k=binom(2k,k)/(k+1)>0`。定义
```text
H_k(t)=binom(r+t,2t)*[x^r](1-x)(1+x)^(2t)(1+x^2)^(r-t)  (2<=t<=r),
H_k(t)=0 (其他整数 t).
D_m(k)=det(H_k(3+i-j))_(0<=i,j<m),  D_0=1.
```
在冻结 R452/R462 的固定 t 多项式引理下，`p_t(k)=H_k(t)/C_k` 对整数 `k≥1` 由次数不超过 `2t` 的有理多项式给出（与 t 的自然有限支撑兼容）。

则四十九阶子式对全部正整数 `k` 有严格符号：
```text
D_49(k) > 0 : 1 <= k <= 5 或 10 <= k <= 95；
D_49(k) < 0 : 6 <= k <= 9 或 k >= 96。
```
因此，`r=13,15,17,19` 负，`r=21,23,...,191` 正，从 **r=193** 起永久严格为负；全部正整数参数上没有零点。

与 R525 相邻阶结论结合：
```text
D_48(k) < 0 < D_49(k)   (10 <= k <= 13),
D_48(k) > 0 > D_49(k)   (k >= 96)。
```

## 证明：有限精确恒等式 + 无限尾部 Newton 正负证书

令 `f_m(k)=D_m(k)/C_k^m`。Toeplitz–Hessenberg 递推为
```text
f_0=1;
f_m = sum_{a=1}^m (-1)^(a-1) p_(a+2)(k)*p_2(k)^(a-1)*f_(m-a)(k).
```
每一项次数上界为 `2(a+2)+4(a-1)+6(m-a)=6m`，因此在上述冻结引理下 `deg f_49 <= 294`。

取始终正的多项式
```text
G(k)=[k(k+1)(2k+1)(2k+3)]^49*(k+2),   deg G=197。
```
计算 `k=1,...,98` 上 `f_49(k)/G(k)` 的精确约分分母，并令这些分母的最小公倍数为 `L>0`。以整数差分构造 `delta_j=Delta^j [L f_49/G](1)` (`j=0,...,97`)，定义
```text
S(k)=sum_{j=0}^{97} delta_j * binom(k-1,j),  deg S<=97。
```
由于 `deg(GS)<=197+97=294`，只需在 295 个不同 `k` 上核验 `L f_49(k)=G(k)S(k)`。 `R526_VERIFY.js` 使用 BigInt 对 `k=1,...,295` 全部核验
```text
L*D_49(k) = C_k^49 * G(k)*S(k)。
```
两边归一化后均为次数不超过 294 的有理多项式，故 **295 点恒等式检查推出对所有正整数 k 的多项式恒等式**；这一无限步依赖冻结的固定 t 多项式引理。 `R526_EVIDENCE.json` 保存完整 `L`、98 项原点差分、分段符号与尾部差分。

证书显示 `S(1),...,S(5)>0`、`S(6),...,S(9)<0`、`S(10),...,S(95)>0`。将 `S` 展开于 `k=96` 原点：
```text

S(96+u) = sum_{j=0}^{97} epsilon_j * binom(u,j)  (u∈Z_{>=0})。
```
证书中 **全部98项 epsilon_j 严格为负**，且 `binom(u,j)>=0`、`epsilon_0<0`，故 `S(96+u)<0` 对全部非负整数 `u` 成立。由 `L,C_k,G(k)>0` 得到定理，完成正整数参数的穷尽分类。
