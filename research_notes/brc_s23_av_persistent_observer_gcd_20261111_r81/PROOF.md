## Definition and problem

Let E be a finite **set of distinct identities** (t,branch) with integer source time t. Integer observer time j, integer original-label coefficients a,b, rational fixed x and parameter theta define phases `{a theta}`, `{b theta}`, `{x+(t-j)theta}`. The directed half-open arc from the first boundary to the second uses R77 semantics, including a wrap and an EMPTY arc when the boundaries coincide. Winner W is the lexicographically largest qualifying (t,branch) or NONE. R80 computes the common phase-return divisor

`g(E,j,a,b)=gcd(|a|,|b|,{|t-j|:(t,branch) in E}).`

The question is how to update this divisor after arbitrary insertion/deletion (including separate branch deletion) and answer different j without rescanning all source times or discarding historical versions.

## Theorem A — observer-independent gap summary

Let T be the **distinct source times** of E, listed `t_1<...<t_m`. For m>=1, set anchor `tau=t_1` and `D=gcd(t_2-t_1,...,t_m-t_(m-1))`, with D=0 for a singleton. Then for every integer j and a,b,

`g(E,j,a,b)=gcd(|a|,|b|,D,|tau-j|).`  (A)

For T empty, the original definition is `g=gcd(|a|,|b|)`; the winner is NONE. In particular, for fixed a,b and nonempty T, setting `H=gcd(|a|,|b|,D)` yields `g(E,j,a,b)=gcd(H,|tau-j|)`, so this numeric divisor depends on j only through its residue mod H when H>0. This is a property of the *period divisor*, not a claim that the winner output is invariant under observer-time change.

**Proof.** The ideals of integers generated by `{t_i-j}` and by `{tau-j,t_(i+1)-t_i}` coincide: each t_i-j is the sum of tau-j and consecutive gaps; conversely each gap is the difference of two consecutive shifted times. Their nonnegative gcds coincide. Adding |a|,|b| preserves equality. Repeating a time with different branch IDs only adds an identical integer and does not affect the gcd. QED.

**Phase-return sharpness.** If g>0, `1/g` is the least strictly positive shift Delta leaving **every labelled phase separately** unchanged for all theta: every slope m in `{a,b,t-j}` must satisfy `m Delta in Z`. Bezout gives `g Delta in Z` and Delta=1/g satisfies all constraints. A particular winner may have a shorter period; the theorem concerns the complete labelled phase vector.

## Theorem B — fully persistent augmented ordered-time index

Maintain a persistent AVL keyed by each **distinct** integer time. A key stores a nonempty immutable branch-identity set. Each immutable subtree stores `(min_time,max_time,gap_gcd,count)`; an empty child contributes zero to gcd. For node time t, left child L and right child R, define

`G(node)=gcd(G(L), G(R), t-max(L) if L, min(R)-t if R).`

The node minimum, maximum, count and height are recomputed from its children. Then for every historical root:

1. Iterating the tree yields exactly the retained (t,branch) identities.
2. G(root) is the gcd of every adjacent time gap of the corresponding distinct times.
3. Formula (A) answers an arbitrary observer j using only root metadata and a constant number of gcd operations, without scanning the source set.
4. Path-copy insertion/deletion changes only its search path and local rotation paths. Deleting one branch keeps its time node until the final branch disappears. Old roots remain valid.

**Proof.** The ordered adjacent gaps of a subtree are precisely its left-subtree gaps, an optional left-to-root gap, an optional root-to-right gap, and right-subtree gaps. Taking gcd yields the displayed recurrence. Structural induction establishes the min/max/count/G invariants. AVL rotations change local shape but preserve the sorted represented times; reconstruction computes the new exact summaries. Path copying does not mutate predecessor roots. QED.

For m distinct times, the implemented immutable AVL visits O(log(m+1)) nodes per update, plus copying the changed immutable branch set at that time (O(b_t) in this Python checker, where b_t is branch count). GCD operands have at most B input bits; each visit performs a constant number of exact gcds, not O(1) bit-time. A balanced branch tree could replace the checker’s branch-set copy if O(log(b_t+1)) branch updates are required. The root summary is an O(1)-count metadata lookup, not a claim of constant integer-bit cost. Constructing all normalized R80 source coordinates may still cost Omega(|E|); this theorem eliminates the **divisor-discovery scan**, not every query cost.

## Theorem C — version-correct reuse and precise invalidation

The period divisor is a summary of a source version plus (j,a,b). A certificate that refers only to an **unchanged immutable subtree's own sources**, with the same observation signature and covered parameter interval, remains valid for that subtree. A whole-version winner or exclusion certificate requires the new members to be handled as well, even when g is numerically unchanged.

Three exact distinctions:

1. **Extrema insufficient.** With (a,b,j)=(12,24,0), times {4,8} and {4,6,8} have the same min/max (4,8), but g is 4 and 2 respectively.
2. **Scalar gcd cannot invert deletion.** The sets {4,6} and {4,10} both have g=2; deleting time 4 leaves g=6 and g=2 respectively. Full retained time-gap structure resolves both.
3. **Unchanged g does not validate an old global winner certificate.** For any positive integer q, set (a,b,j,x)=(q,2q,0,0), theta=3/(10q). Source set {(4q,0)} has g=q and W(theta)=NONE. Inserting (5q,0) preserves g=q but changes W(theta) to (5q,0), since the new fractional phase is 1/2 inside [3/10,3/5), while the old phase is 1/5 outside it.

Consequently, a persistent R76 global-max index and the new persistent all-time gap-GCD index are **complementary**; keeping only per-class maxima or a previous scalar g is not enough to recover an exact deletion-sensitive common period.
