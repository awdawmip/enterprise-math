# R542｜signed BRC 固定 k=3、4 的全部 Toeplitz 阶数严格正性

日期：2026-11-05（Asia/Shanghai）。作者侧精确代数证明；独立数学审阅及原生任务接纳尚未取得。

## 0. 来源、对象与命题

科学输入冻结：R462 commit `18783e01e3646c72b7aab3b16d3f565e83e6446f`；R540 的 H=B 形式恒等式，R541 的固定 k 有理阶数生成函数，已在 Draft PR #1708 的 R540/R541 材料中给出。本结果直接使用原始 signed BRC 系数，不对 P000、ACTIVE 世界观或冻结科学输入作改动。

对整数 k≥1 设 r=2k+1，C_k=(1/(k+1)) binom(2k,k)；对 2≤t≤r 定义

```
H_k(t) = binom(r+t,2t)[x^r](1-x)(1+x)^(2t)(1+x^2)^(r-t),
H_k(t)=0 (t不在上述范围),
D_m(k)=det(H_k(3+i-j))_(0≤i,j<m), D_0(k)=1.
```

R540 的作者侧证明将 H_k(t) 等同于 ballot–Catalan 形式
`binom(r+t,2t) sum_{q=0}^{min(floor((t-1)/2),k)} binom(t-1,2q)4^q C_(k-q)`。R541 的有理生成函数（由 Toeplitz–Hessenberg 第一行展开直接推导）为

```
F_k(z) = sum_(m≥0) D_m(k)/C_k^m z^m
       = 1/[1-sum_(a=1)^(2k-1) (-1)^(a-1) p_(a+2)(k) p_2(k)^(a-1) z^a],
p_t(k)=H_k(t)/C_k.
```

**R542 定理：对全部整数 m≥0，D_m(3)>0 且 D_m(4)>0。** 证明为有限个有理数不等式加 Rouché 定理与严格的部分分式界；不通过有限阶数试验外推。

由 `F_k(z)=1/prod_i(1-lambda_i z)`，其中 lambda_i 为 P_k 的复数根（计重）。

## 2. 以有理圆盘隔离全部复根

对每个 k 使用下表 d 个复有理中心，统一半径 `epsilon=1/10`；每个中心及其共轭均逐项列出：

```
k=3:
 c0=237.122
 c1=57.813+33.070i       c2=57.813-33.070i
 c3=96.626+105.937i      c4=96.626-105.937i

k=4:
 c0=755.966
 c1=148.322+67.276i      c2=148.322-67.276i
 c3=203.227+145.134i     c4=203.227-145.134i
 c5=392.468+452.340i     c6=392.468-452.340i
```

将精确有理系数的 `P_k(c+w)` 写为 `a_0+a_1w+...+a_dw^d`。随附 `R542_VERIFY.py` 使用 Fraction + isqrt 构造全部复数模长的有理上下界，在上述每一个圆盘核验

```
|a_0| + sum_(j=2)^d |a_j| epsilon^j
       < (|a_1| epsilon) / 100.
```

形式化的实际核验条件是 `100*left < right`，其中 `left=U(a_0)+sum_(j>=2)U(a_j)epsilon^j`、`right=L(a_1)epsilon`。U、L 分别为通过整数平方根取得的有理上界、下界，所有输入与比较都是精确有理数。由于 `left<right`，Rouché 定理说明各盘各含一根；圆盘两两不交且共有 d 个，故全部根均被覆盖、互异。圆盘 `c0` 关于实轴对称并只含一个根，因此其根 `alpha` 为实根且严格正。

严格得到 `alpha>237`（k=3）及 `alpha>755`（k=4）；其余根模长分别全部严格小于 `144` 与 `600`。故 alpha 是唯一最大模根。

## 3. 分式残数的统一支配证书

对于简单根 lambda_j，部分分式系数为

```
A_j = lambda_j^(d-1)/P_k'(lambda_j).
```

由于 P_k 是实系数、alpha 的其余根全部形成共轭对，

```
P_k'(alpha) = prod_(j>0) (alpha-lambda_j)>0,
```

所以 `A_0>0`。对任意两圆心设置有理边界

```
L_ij ≤ |c_i-c_j| ≤ U_ij,
L_i  ≤ |c_i|     ≤ U_i,
```

并使用 `L_ij>2epsilon`、`alpha>c_0-epsilon`，得到全有理严格界

```
A_0 ≥ (c_0-epsilon)^(d-1) /
      prod_(j>0) (U_0j+2epsilon) =: LOWER,

|A_i| ≤ (U_i+epsilon)^(d-1) /
        prod_(j≠i) (L_ij-2epsilon) =: UPPER_i   (i>0).
```

这些界由复数的三角不等式以及被隔离根所在的圆盘直接推出，分母均严格正。随附源码精确验证以下更粗但易检查的**有理数证书**：

| 参数 | 正实根残数下界 | 其他残数模长之和上界 | 根模长严格分离 |
|---|---|---|---|
| k=3 | `A_0>305/100` | `sum_(i>0)|A_i|<220/100` | `alpha>237>144>max_(i>0)|lambda_i|` |
| k=4 | `A_0>452/100` | `sum_(i>0)|A_i|<369/100` | `alpha>755>600>max_(i>0)|lambda_i|` |

于是对任意 m≥0，

```
D_m(k)/C_k^m = [z^m]F_k(z) = sum_i A_i lambda_i^m
  ≥ A_0 alpha^m - sum_(i>0)|A_i||lambda_i|^m
  ≥ (A_0-sum_(i>0)|A_i|)alpha^m > 0.
```

因为 C_k>0，原始行列式 `D_m(k)>0` 对 k=3、4、所有 m≥0 成立。证毕。
