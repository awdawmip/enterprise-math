# R121-AP — Arithmetic-progression phase lifts reduce any number of S23 times to two integer variables

## Statement and domain

Let `m >= 2` be an arbitrary integer; let `N,d,j,a,c` be integers with `d != 0`; let `x` and the endpoints of a bounded nonempty rational interval `J` be rational. Consider the m times

`t_i = N + i*d`,  `i=0,...,m-1`.

At each time use the original directed half-open S23 arc predicate

`M_t(theta) = 1[ frac(x+(t-j)*theta) in [frac(a*theta),frac(c*theta))_directed ]`.

As in R120, partition only by the old historical eligibility cuts and, when needed, by floors and order of `a*theta,c*theta,(a-c)*theta`. Within an open rational atom `J=(l,h)` all eligibility bits inherited from the old history are constant; each prescribed new bit `b_i in {0,1}` admits at most two rational-affine real segments `[L_i(theta),U_i(theta))` inside `[0,1)`. Singleton atoms are evaluated directly with rational arithmetic.

Define the **universal progression lift vocabulary**

`P_m = { (floor(alpha+i*beta))_{i=0}^{m-1} : 0 <= alpha,beta < 1 }`.

Let `H=m(m-1)/2`. Then:

1. `|P_m| <= 1+H*(H+1)/2 = O(m^4)`. The vocabulary is independent of `N,d,j,a,c,x`, can be generated by an exact rational line-arrangement algorithm, and includes all half-open boundary signatures.
2. A prescribed vector `b=(b_0,...,b_{m-1})` is attained at some `theta in J` if and only if, for at least one vocabulary vector `q in P_m` and one choice of up to two eligible real segments for every `b_i`, there are integers `n,k` and `theta in J` satisfying

   `x+(t_i-j)*theta-U_i(theta) < n+i*k+q_i <= x+(t_i-j)*theta-L_i(theta)` for each `i`.

   Every feasible system returns an exact rational witnessing `theta`.
3. By the same exact common-slack elimination as R120, each such system reduces to **one rational integer-linear feasibility problem in exactly two integer variables (n,k)**, with `O(m^2)` resulting inequalities and polynomial binary coefficient length. Thus one prescribed m-bit signature needs at most `2^m |P_m|` two-variable integer-programming calls, and **all** possible signatures need at most `4^m |P_m|` such calls. With an exact fixed-dimensional ILP solver the total bit-time is `4^m poly(m,L)` for input bit length L, using the arrangement enumeration, with no expansion proportional to `|N|` or `|d|`. Here the exponential factor is in the **number of new times**, which may itself be variable.

This improves the generic extension of R120: the number of integer dimensions stays **two for arbitrary m** when the new times form one integer arithmetic progression. For a fixed `m`, bit-time is polynomial in the input binary length. This is a reduction and complexity consequence of standard two-dimensional integer programming, not a claim that the accompanying small-case enumerator implements Lenstra.

## Proof

### A. Exact affine floor identity

Set `Y_0=x+(N-j)*theta` and `D=d*theta`. For any real `theta`, write

`Y_0 = n + alpha, D = k + beta`

where `n=floor(Y_0), k=floor(D)` and `0<=alpha,beta<1`. Since `Y_i=Y_0+iD`,

`floor(Y_i) = n+i*k+floor(alpha+i*beta) = n+i*k+q_i`.

This identity is exact for negative integers, wrapped phases and all rational endpoints. In particular **every actual** `theta` has some `q in P_m`, proving completeness of the candidate lift set.

For a chosen bit segment, `M_{t_i}(theta)=b_i` in that segment exactly when the fractional phase `Y_i-floor(Y_i)` lies in `[L_i(theta),U_i(theta))`. Rearrangement yields

`Y_i-U_i(theta)<floor(Y_i)<=Y_i-L_i(theta)`.

Therefore every true m-bit witness supplies a feasible system with the actual `n,k,q`. Conversely, if any chosen system has integer `n,k`, its inequalities ensure `Y_i-(n+i*k+q_i)` lies in the chosen subinterval of `[0,1)`, so `n+i*k+q_i=floor(Y_i)` automatically and every prescribed original S23 bit holds. We do **not** assume separately attainable bits are jointly attainable; all inequalities share one `theta`, `n`, `k`.

### B. Polynomial-size lift vocabulary

For `i>=1`, the nonnegative integer `floor(alpha+i*beta)` changes only on the straight lines

`alpha+i*beta=h`,  `h=1,...,i`,

inside the half-open square `[0,1)^2`. There are `H=sum_{i=1}^{m-1} i=m(m-1)/2` such lines. Their planar arrangement has at most `1+H+H*(H-1)/2=1+H*(H+1)/2` open two-dimensional chambers: inserting each line yields at most `1+` its intersections with earlier lines new chambers. Every chamber has one constant vector `q`.

An exact point on a line uses the higher-side floor value. Increase `alpha` by an arbitrarily small positive rational amount while keeping `alpha<1`; this retains every floor value at an equality and crosses none of the finitely many other thresholds. If the original point is on the lower square boundary, an arbitrarily small positive perturbation of `beta` also realizes the same tuple in an open chamber. Hence **boundary tuples add no new vocabulary values**. For constructive enumeration, intersect the lines with each other and the unit-square boundaries; sweep an exact rational sample `beta` between consecutive intersection heights; then sample `alpha` between the resulting ordered rational line intercepts. The produced open samples cover every chamber, hence all of `P_m`. Rational numerator/denominator lengths and the arrangement size are polynomial in `m` (a simple sweep need not be output-optimal).

### C. Two-integer exact reduction

Fix `q` and one real-segment choice for each bit. Each inequality in A is rational-affine in `theta` with integer unknowns only `n,k`. Introduce a common continuous slack `epsilon>0` for strict lower bounds and `l<theta<h`, with `epsilon<=1`. The feasible `(theta,epsilon)` polygon for each fixed `(n,k)` is compact after allowing `epsilon>=0`. Clear rational denominators; choose `M>=1` bounding integer coefficients of `theta,epsilon` in all the inequalities. A positive maximum `epsilon` occurs at a vertex. The active-row determinant has absolute value at most `2M^2`; Cramer's rule shows every positive vertex `epsilon` is at least `1/(2M^2)`. Hence an open feasible system is equivalent to the closed system with `epsilon_0=1/(2M^2)`. (The integer unknowns occur in the right-hand sides and do not alter this denominator bound.)

With `epsilon=epsilon_0` fixed, Fourier–Motzkin elimination of the **single real variable** `theta` pairs every lower with every upper affine bound, leaving `O(m^2)` rational linear constraints on `n,k`. They have polynomial binary length in the original coefficients, `m`, and endpoint denominators. Conversely an integer point in this projected polygon yields rational `theta` between its exact lower and upper bounds, which verifies the original inequalities. There are at most `2^m` segment selections for one specified bit vector; another `2^m` bit vectors for exhaustive signature discovery. Standard fixed-dimensional integer programming (Lenstra 1983) applies to each two-variable system, independent of `m`, `N` and `d`.

### D. Consequences and explicit cases

For `m=2,3,4,5`, the exact line-sweep implementation generates respectively `2,4,8,14` lift vectors. For `m=5` the naive unrestricted finite-second-difference labels allow up to `3^3=27` vectors; the actual universal floor vocabulary has only 14. The theorem's general upper bound at `m=5` is `56`, so the bound is a uniform worst case, not the observed cardinality.

The same two-integer mechanism extends to a finite union of arithmetic-progression new-time blocks: each block introduces two integer variables, so the dimension is at most twice the number of blocks, rather than the number of times. Whether a better block-coupled reduction exists is open.

## Reproducibility and validation scope

`check_r121.py` uses Python 3 standard-library `Fraction` only. For `a=j=0,c=1,0<theta<1`, it constructs the exact line vocabulary; independently enumerates **all** phase transition singleton and open rational atoms for `m=2,...,5`; and checks each resulting attained bit vector against the exact `n,k,q` inequality reduction, using exhaustive *bounded* small integer pairs only. Every returned rational witness is evaluated directly in the original directed S23 arc. The deterministic run completed 72 randomized instances, 2,382 singleton/interior phase samples, 721 verified bit-vector witnesses and the exact vocabulary sizes `{2:2,3:4,4:8,5:14}`. Three additional `100+` decimal-digit signed-`N,d` forward certificates verify the affine floor identities without enumerating phase cuts.

The proof covers arbitrary allowed `a,c,j` after R120's old-atom arc decomposition; the implemented exhaustive cross-check specializes to `a=j=0,c=1`. The small-case code is an exact enumerator, **not** a generic polynomial-time two-variable ILP implementation. The bit-complexity statement uses the published fixed-dimensional ILP theorem. No native Cell/Link/Port admissibility or mathematical independent review is claimed by the auxiliary result.
