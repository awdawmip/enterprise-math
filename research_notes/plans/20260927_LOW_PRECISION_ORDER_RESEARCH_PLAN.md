## 二、统一数学对象与接口合同

### 1. 固定原生过程

先固定实际 BRC 载体、初态、模乘调度、反馈顺序、完整残差和读出规则。已有实数载体下：

\[
x=v_h(z),\qquad y=T_hv_h(P_i^{-1}z),
\]

\[
S=\|x\|^2+\|y\|^2,\qquad
C_h(z)=\frac{2\langle x,y\rangle}{S},\qquad
p_+(h,z)=\frac{1+C_h(z)}2.
\]

现有实数坐标使用实内积；若以后扩展到复载体，分子必须改为 \(2\operatorname{Re}\langle x,y\rangle\)，并重新证明对应关系。

第一版保留原工作标签提议和更新机制，只替换读出比特的生成接口。任何块压缩、标签重抽或拒绝机制，都作为另一套完整转移核单独证明。

\(S=0\) 时不定义比值：证明其在精确提议下不可达，并为程序异常规定有限退出。不得用小常数替换分母后仍声称精确。

### 2. 同时研究两类读出接口

**接口 A：带证书的对比度近似。**

输入为公开实例、原生程序版本、历史 \(h\)、标签 \(z\)、精度及失败预算；输出：

- \(\widehat C\in[-1,1]\)；
- 确定性误差证书，或有明确条件的概率保证；
- 构造、查询、认证和位复杂度；
- 无法满足预算时的明确失败结果。

**接口 B：直接随机读出。**

寻找有界随机变量 \(U\in[-1,1]\)，使

\[
\mathbb E[U\mid h,z]=C_h(z).
\]

随后以 \((1+U)/2\) 生成比特，其平均转移核即为精确读出核。这里不要求先把方差降至很小，但必须证明有界性、条件无偏性和全部采样成本。

首个候选归约是：

\[
q(j)=\frac{x_j^2+y_j^2}{S},\qquad
U_j=\frac{2x_jy_j}{x_j^2+y_j^2}.
\]

它满足 \(\mathbb E_qU_j=C\)，但**如何取得 \(q\) 的样本和对应坐标**仍是待解决的问题。内部维数小也不意味着这些坐标可便宜取得。

两类接口均禁止免费使用完整支持集、阶、因数或已解出的模乘地址。缓存命中与查询顺序不得改变声明的数学对象；随机状态必须进入完整过程定义。

### 3. 建立从局部误差到最终答案的合同

对裁剪后的随机估计量 \(\widetilde C\)，条件单步核误差为

\[
\delta_i(h,z)=
\frac12\left|C_h(z)-\mathbb E[\widetilde C\mid h,z]\right|.
\]

因此，分子和分母分别无偏，不足以证明比值无偏；裁剪后的偏差也必须重新分析。

若每轮以至少 \(1-\alpha_i\) 的条件概率保证误差不超过 \(\eta_i\)，则在相同提议和更新机制下，建立并核验

\[
\operatorname{TV}(P_{\mathrm{native}},\widehat P)
\le \sum_i(\eta_i/2+\alpha_i).
\]

允许坏历史集合时，另计其在精确过程下的质量。改变提议、标签更新或引入截断失败时，另计相应转移误差。

使用 \(m\) 份样本联合解码时，对整个样本批次分配预算，不能每份重复使用同一总预算。最终只可推出

\[
p_{\mathrm{approx,decode}}
\ge p_{\mathrm{native,decode}}-\varepsilon_{\mathrm{batch}}.
\]

原生过程的成功率必须独立研究。若已证明下界 \(p_0>0\)，默认令批次误差不超过 \(p_0/4\)；没有下界时，仅报告分布逼近结论。

## 三、研究工作包与十二周安排

设置三条可并行的理论线：**直接读出、结构压缩、联合解码**。各线先交出独立接口，再组合；独立复核者不由相应结论的主要作者兼任。

| 时间 | 工作包与具体任务 | 交付物及验收条件 |
|---|---|---|
| 第1—2周 | **基础合同与前沿去重。** 固定源码及证据版本；核查两臂恒等式、完整联合律、零质量处理、RP3/RP7适用范围；列出各科学操作的实际 BRC 入口。 | 一份命题—假设—来源—状态表；完整过程定义；未闭合接口清单。有限字库、固定维数结果不得直接外推到任意规模。 |
| 第3—4周 | **直接读出构造。** 并行研究有界无偏读出和有证书近似；展开能量坐标采样归约；研究精确或高精度对比度查询是否仍可恢复阶。 | 至少一个候选算法的完整伪代码、误差合同和成本式，或一个明确障碍。困难性归约必须使用允许生成的原生查询，不能任意添加参考臂。 |
| 第3—6周 | **落点条件与有序权重的联合压缩。** 研究时间顺序兼容的分支程序、未来读出等价类和带符号块；分别计算表示宽度、构造成本及中间收缩宽度。 | 可构造的压缩规则及健全性证明，或针对所选表示模型的宽度/信息损失见证。只压缩 QFT 核不通过。 |
| 第5—8周 | **低精度联合解码。** 以 Seifert/Ekerå 的短寄存器求阶为外部理论起点，分析原生输出与其所需数论关系的对应；保留标准宽度后处理对照。 | 至少一个带明确假设的“精度—样本数—解码成本—成功率”定理。不能把原生样本未经证明地替换为理想 Shor 样本。 |
| 第7—10周 | **组合与反例。** 选择通过前期门槛的读出、表示和解码接口组成完整算法；将所有失败、认证和重启纳入资源式。只对新接口做必要小例检查。 | 一个完整正向结果，或一份指出组合失败位置的严格障碍报告；包括代表性正例、反例和未决项。 |
| 第11—12周 | **独立审查与定稿。** 审查证明、隐藏答案依赖、误差量词、无限族适用性和位复杂度；复核关键证据。 | 完整研究报告、可复核证明包、最小验证包，以及由实际结果决定的后续任务。 |

三条理论线的具体攻点如下。

**直接读出线：减少必须取得的信息。**

- 先尝试直接产生正确比特，再研究必须显式估计对比度的情形。
- 分别审查“任意合法查询”与“真实采样高质量历史上的查询”，避免将通用精确行归约误当成所有近似接口的下界。
- 将抵消程度、分母控制、随机拒绝率和证书构造成本写成显式参数。
- 以 BGL 为已有采样归约的基线，新增贡献集中在查询构造和成本。其原文并未提供免费的振幅查询器。[BGL](https://arxiv.org/abs/2112.08499)

**结构压缩线：保留影响未来读出的关系。**

- 对每次合并明确保留的标签、重数、符号、残差和后续操作。
- 优先尝试：可计算字符给出的确定读出证书；具有可构造后缀等价关系的落点分支程序；父块闭合的非对跖带符号族。
- RP7 的对跖无合并结论作为必须解释的反例，不作为性能候选。
- 同时计费“发现分组、成员判断、父块访问、收缩和误差认证”。低秩 QFT 只能解决其中一部分。[QFT 低纠缠原文](https://arxiv.org/html/2210.08468v3)

**联合解码线：把不完美样本变成可验证答案。**

- 分开处理寄存器长度、设计性门截断、局部读出误差和状态表示误差。
- 首轮研究固定取舍参数 \(s\in\{1,2,4\}\)、长度 \(L=n+\lceil n/s\rceil\)；它们是待分析方案，不预设成功。
- 样本数由证明所需信息量和失败预算决定；没有充分定理的配置保留为条件性结果。
- 计入格维数、规约、枚举、候选筛选和验证成本。主要文献入口为 Ekerå 2021 Appendix A。[原文](https://eprint.iacr.org/2018/797)

**阶段转向规则：**

- 第4周仍只能调用完整行的候选，保留为正确性基线，停止宣称信息接口缩小已带来加速。
- 第6周仍依赖完整支持枚举、指数认证或未解决的归一化采样，将其转为障碍研究。
- 第8周无法建立原生信息与解码条件的桥梁，分别交付采样理论和条件性解码理论，不强行合并。
- 非零残差本身不触发淘汰；真正的转向依据是语义错误、不可控误差或明确资源障碍。

## 四、验证方案与完整成本账

### 理论审查

每项结论必须回答：

1. 对所有实例、某个无限族，还是有限样本成立？
2. 是最坏情况、平均情况，还是对精确采样过程的质量加权保证？
3. 构造和验证是否也高效，而不仅是证书短？
4. 原生字库、反馈字长、内部维数和整数位长是否随 \(n\) 增长？
5. 使用阶或因数只是分析记号，还是已进入算法输入、选参或筛选？
6. 与既有结果相比，新增结论究竟在哪里？

特别地，\(a^R\equiv1\pmod N\) 只验证阶倍数。精确阶需要完整素因子检验或等价证书；取得该证书的成本必须计入。直接输出满足 \(1<d<N\)、\(d\mid N\) 的因数，可以独立验收为分解成功。

### 必须覆盖的反例

| 类别 | 检验内容 |
|---|---|
| 读出边界 | 同相、反相、正交、共同尺度变化、零质量和极小质量 |
| 随机估计 | 比值偏差、裁剪偏差、共享随机性及缓存导致的条件偏差 |
| 质量认证 | 精确过程具有显著质量、近似过程却很少访问的区域 |
| 相干压缩 | 相同范数而不同相位；单行保留破坏信息；块接受后不重抽标签造成联合律错误 |
| 结构成本 | 内部秩很小但落点判定昂贵；小宽度描述存在但无法高效构造 |
| 数论输出 | 大阶多峰、容易阶与困难阶分离、阶倍数通过模幂却不能提取因数 |
| 历史对照 | 高斯和幽灵因数、单位群零点、背景相减和低概率分支成本 |

高斯和相关测试以符号推导及已有证据为主；不将带符号背景差直接解释为概率，也不把“零点可见”解释为有效样本已可获得。

### 最小计算验证

所有新增科学计算遵守实际 typed BRC 约束，不新增经典三角函数、高精度传播器或理想 QFT 数值参考运行。

- 复用既有小例，只有接口或主张改变时才重验相关部分。
- 对新转移核检查完整小规模 bit/work 联合律，不能只检查输出频数。
- 覆盖不同指数、相反符号、零伙伴、拒绝、随机源耗尽和查询顺序。
- 历史经典数据保留原模型标签；外部文献算法用于符号比较。缺少合适 BRC 接口时，先证明或扩展接口。
- 不把有限测试通过、执行包可恢复或作者复算等同于独立科学审查。

### 统一资源式

以取得可验证答案的成本为主指标：

\[
\mathbb E[T_{\mathrm{factor}}]
=
T_{\mathrm{prep}}
+
\frac{\mathbb E[T_{\mathrm{batch}}]}
{\Pr[\text{该批次返回非平凡因数}]}.
\]

使用该式前核验独立重启、有限期望费用和预处理复用条件。批次费用包含：

- 字库及表示构造；
- 查询、模乘、相干求和和随机采样；
- 误差证书生成与检查；
- 失败、拒绝、重启和无效样本；
- 联合解码、候选验证；
- 内存字节数、最大整数位长及证据存储。

必须分别报告每次尝试、每个存活样本和每个有效答案的成本。
