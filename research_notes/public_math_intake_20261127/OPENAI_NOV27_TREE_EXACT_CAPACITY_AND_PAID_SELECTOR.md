## Exact feasible budgets on a fixed terminal-spanning tree
Let F be any field, T a finite tree with at least two terminal vertices, each edge length ell_e a positive integer. Prune nonterminal leaves; hence every remaining edge separates nonempty terminal sets. Multiple ports at a vertex are allowed, at least two distinct terminal vertices. L=sum_e ell_e>0. Fix N=2^m labels (m>=0 integer) at every port. Branch t may use arbitrary local F-tensors and one independent contracted index per tree edge of dimension at most 2^b_{t,e}, b_{t,e} nonnegative integer. All branch tensors are summed to the N-label full diagonal. W_t=sum_e ell_e b_{t,e}. Local tensors, storage, selector transmission and evaluation costs are not charged in W_t. This is precisely the Nov26 external model restricted to a fixed tree.

Theorem 1 (edge budgets): exact feasibility iff sum_t 2^min_e b_{t,e} >= N.
Necessity: remove the edge minimizing b for that branch. This is a legal terminal separation, so its flattening rank is at most the bond dimension, and its partition rank no greater. Sum over branches, using the Nov26 cited Naslund diagonal partition rank theorem (Lemma 11, arXiv:1701.04475), obtains N<=sum_t 2^min_e b_{t,e}. Sufficiency: partition the N labels into disjoint sets H_t, each of size n_t<=2^min_e b_{t,e}; empty sets allowed and represented by zero. On each edge of branch t transmit an index of dimension max(1,n_t). At each vertex enforce all incident indices and the local external labels to agree with the same H_t label (use the corresponding injections at terminal ports). For each diagonal entry in H_t exactly one internal assignment contributes 1, and every off-diagonal entry contributes zero. Sum reconstructs the full diagonal over any F, including F2. All capacity bounds respected. Leaf-pruning does not affect the lower bound; ignored extra edges can have dimension 1. This proof uses the same diagonal-copy tensor construction, not a new native triadic force claim.

Corollary 1 (scalar budgets w_t): feasibility iff sum_t 2^floor(w_t/L)>=N for nonnegative budgets w_t. Necessity by L min_e b_{t,e}<=W_t<=w_t; sufficiency by uniform per-edge b_t=floor(w_t/L) and Theorem 1. Thus the Nov26 packing bound is sharp on every fixed tree, not only the previous two/three-port examples. It is a constructive exact feasibility test, not a generic tree lower-bound inference for graphs with cycles.

Corollary 2 (different cost objectives, A>=1 branches; empty branches allowed):
- Minimum worst-branch cost is L max(0,m-floor(log2 A)). Proof: with common b, A2^b>=2^m, and balanced label blocks attain.
- Minimum sum of branch costs is L ceil(log2(max(1,N-A+1))). Proof: let k_t=min_e b_{t,e}. For nonnegative integers x,y, 2^x+2^y<=2^(x+y)+1 by (2^x-1)(2^y-1)>=0. Induct to N<=2^sum k_t + A-1. Achieve with A-1 singleton branches (or N singleton branches if A>=N) and one branch for the remaining max(1,N-A+1) labels, using uniform edge capacities. These are distinct optimization objectives. For N=8, A=3: worst W=2L (e.g. 3,3,2 labels) while min total W=3L (6,1,1). Their minimizers need not coincide. Neither objective includes selector, preprocessing or local tensor cost.

## Prefix selector accounting
Assume a branch selector must be conveyed coherently to every terminal over the same tree and its bit string is prefix-free with length l_t (nonnegative integers). Assume residual local index budget b_t=min_e b_{t,e} and charge selection L l_t in addition to W_t. Let B=max_t(l_t+b_t). Kraft inequality sum_t 2^-l_t<=1 gives
N<=sum_t 2^b_t<=2^B sum_t 2^-l_t<=2^B.
Consequently max_t(W_t+L l_t)>=L m. In a fixed tree with shared selector paid once per edge, branch splitting cannot reduce the worst-case joint selector-plus-residual transport cost below the unbranched diagonal-copy construction. For 2^s equally sized branches, 0<=s<=m, a fixed s-bit selector and m-s residual bits attain Lm. This is a separate explicit cost model: it does not cover pre-shared branch information, externally supplied selectors, amortized batch reuse, coherent signed superpositions without a decodable classical selector, or adaptive interaction with a different communication model. Such information sources require their own cost accounting. No free selector assumption hidden.
