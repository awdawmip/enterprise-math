## 0. 本轮解决的问题

父节点证明：固定 `epsilon>0` 时，可以用一个正的局部几何常数换取每个活动素数块小于 `1+epsilon` 的条件化代价，得到开前沿

`6 gamma > 1 + beta + epsilon + alpha`。

它还留下两个可能方向：让局部坏种子比例随素数衰减以逼近 `epsilon=0`，或在较早层使用二阶重叠。

本轮先证明一个负面障碍：**若坚持一个固定正的 prime-power 局部几何常数，则在 residue degree `f=6` 的惰性素数块、倒数第二层 `s=5`，坏种子比例本身有正的下界，不能仅靠 `p -> infinity` 自动趋于零。**因此“保持原固定常数，同时让每块条件化代价免费趋于1”的路线不成立。

随后采用不同策略：不再用同一个 `epsilon` 控制所有素数，而是一次性固定一个随素数缓慢减小的预算 `epsilon_p`。这样牺牲了 prime-power 的统一常数，但条件化算术主项获得**有界平均**。最重要的结果是：同一个永久概率空间、同一套不回退的全整数格族，可以同时实现全部严格开区域

`6 gamma > 1 + beta + alpha`，

并在临界等号处给出精确的迭代对数修复条件

`6 delta + eta > 1`。

普通自然数算术、P000、六轴原生 Cell、`Q(z)=sum z_i^2`、全部合数联合观察、四个已冻结种子均不变。额外七阶整数操作 `U` 仍不是原生等距旋转。

## 2. 定理 V1：固定正局部几何常数时，惰性 `f=6` 块的坏比例不会自动消失

考虑 `ord_7(p)=6` 的素数。在基块 `r=0`，`Phi_7` 在 `F_p` 上不可约，局部商是六维不可约空间；倒数第二层为 `s=5`。父节点已经证明，此时每个不同项目化短向量见证恰对应一个不同的坏种子原子。

固定任意常数 `h>0`，令

`H=floor(h p^(5/6))`,

并取原生整数盒

`B_H=[-H,H]^6 intersect Z^6 \ {0}`。

当 `p` 足够大时 `H<p/2`，所以模 `p` 后没有非零盒向量变成零。记 `n_l` 为每条 `P^5(F_p)` 项目直线中盒向量的数量，`T=sum_l n_l=#B_H`，`R=# {l:n_l>0}`。Cauchy--Schwarz 给

`R >= T^2 / sum_l n_l^2`.                                  (1)

### 2.1 项目碰撞能量降到二维比例格

对 `a in F_p^*` 定义

`Lambda_a={(x,y) in Z^2 : y = a x (mod p)}`,

其行列式为 `p`。令

`M_a(H)=#(Lambda_a intersect [-H,H]^2)`。

除去全零对，六坐标逐项选择给

`sum_l n_l^2 <= sum_(a in F_p^*) M_a(H)^6`.                (2)

令 `lambda_a` 是 `Lambda_a` 的第一 sup-norm 逐次极小值。经典二维逐次极小值格点计数给

`M_a(H) <= C [1 + H^2/p + H/lambda_a]`                    (3)

其中 `C` 是绝对常数。可由方盒的两项逐次极小值计数与 Minkowski 第二定理推出；这里不把该经典二维估计作为项目新工具。

### 2.2 极短比例格的斜率数只有二次量级

若 `lambda_a<=L<p`，存在非零 `(x,y)` 满足 `max(|x|,|y|)<=L` 和 `y=a x (mod p)`。此时 `x` 不能为0模 `p`，所以 `(x,y)` 决定 `a=y/x mod p`。因此

`#{a:lambda_a<=L} <= (2L+1)^2-1 = O(L^2)`.                 (4)

按 `lambda_a` 的二进尺度分组，得到

`sum_a lambda_a^(-6)=O(1)`.                               (5)

将 (3) 的六次方代入 (2)，用 `(u+v)^6<=32(u^6+v^6)` 类型常数吸收，得到

`sum_l n_l^2
  <= C_h [ p(1+H^2/p)^6 + H^6 sum_a lambda_a^(-6) ]
  = O_h(p^5)`,                                             (6)

因为 `H asymp h p^(5/6)`。

另一方面 `T asymp_h p^5`。由 (1)：

`R >= c_h p^5`                                             (7)

其中 `c_h>0` 只依赖固定的 `h`。而 `#P^5(F_p)=(p^6-1)/(p-1) asymp p^5`。所以这些短向量命中**正比例**的项目种子原子。

只要方盒被包含在某个固定正比例的欧氏短向量球中，即得到：倒数第二层的坏种子比例存在依赖该固定几何常数的正下界。因而对于 `f=6` 的大素数块，固定正局部几何常数不能让坏比例自动趋于0。

标准的等差数列素数定理/Dirichlet 定理保证 `p == 3,5 (mod 7)` 这两个 `ord_7(p)=6` 类中有无穷多素数；本项目不把这项经典素数分布事实作为新结论。

**范围边界：**这排除的是“固定正局部常数 + 每块独立条件化代价趋1”的直接路线。它不排除跨素数相关选择、全局非乘积测度或其他几何机制。

## 3. 定理 V2：任意可求和的 dyadic 素数预算都给出有界平均条件化主项

令 `eta_j` 是任意固定正数列，满足

`0<eta_j<=5/123`,  `sum_(j>=1) eta_j < infinity`.           (8)

对每个素数定义

`j(p)=ceil(log_2 p)`,
`epsilon_p=eta_(j(p))`.                                    (9)

在每一个局部块 `(p,r)` 上，使用父节点参数化的好种子集合 `G_(p,r)(epsilon_p)`。其局部几何常数为

`kappa_p=(sqrt(6/7)/3)*[2epsilon_p/(5(1+epsilon_p))]^(1/6)>0`, (10)

好种子比例大于 `1/(1+epsilon_p)`，故条件化代价小于 `1+epsilon_p`。

因为所有 `epsilon_p<=5/123`，相应半径参数不超过父节点 `r=1/2` 的旧门槛。四个已冻结种子原本通过更强门槛，因此自动属于这些新的好集合，无需重新选择。

### 3.1 关键可求和性不需要素数定理

在 dyadic 素数带 `2^(j-1)<p<=2^j` 内，

`sum_p 1/p <= (# integers in band)/2^(j-1) <=1`.           (11)

所以

`sum_p epsilon_p/p <= sum_j eta_j < infinity`.             (12)

另有 `sum_p 1/p^2<infinity`。定义

`F_*(n)=product_(p|n)(1+epsilon_p)(1+1/p)`.                (13)

它次乘：`F_*(mn)<=F_*(m)F_*(n)`。

定义非负平方自由乘性函数

`g_*(p)=epsilon_p+(1+epsilon_p)/p`,
`g_*(p^a)=0 (a>=2)`.                                      (14)

逐素数展开得到精确卷积

`F_*(n)=sum_(d|n)g_*(d)`.                                 (15)

而

`sum_p g_*(p)/p
 =sum_p epsilon_p/p + sum_p (1+epsilon_p)/p^2 < infinity`. (16)

因此 Euler 乘积

`C_*=product_p [1+g_*(p)/p]`                               (17)

收敛到有限正数，并且对全部 `X>=1`

`sum_(n<=X)F_*(n)
 =sum_d g_*(d) floor(X/d)
 <= C_* X`.                                                (18)

这是本轮最关键的改进：**条件化算术主项的平均从任意小的对数幂进一步降到真正的 `O(X)`。**概率空间已经一次性固定，不再依赖之后想证明哪个 `gamma,beta,alpha`。

## 4. 一个完全精确、可执行的预算表

为避免只给存在性，固定

`ell(j)=1+floor(log_2 j)`,
`eta_j=min(5/123, 1/[j ell(j)^2])`.                        (19)

则 (8) 成立。事实上，按 `2^t<=j<2^(t+1)` 分组，

`sum_(j in block) 1/[j ell(j)^2] <=1/(t+1)^2`,             (20)

故总和小于2。

一些实际值：

- `epsilon_2=epsilon_3=epsilon_5=epsilon_7=5/123`；
- `epsilon_13=1/36`；
- `epsilon_17=epsilon_19=epsilon_31=1/45`；
- `epsilon_43=1/54`；
- `epsilon_277=1/144`；
- `epsilon_1009=1/160`。

该表只依赖素数本身，一次定义后不会随目标合数 `N` 改动。

还能给 (17) 一个粗显式界。由 (20) 得 `sum_p epsilon_p/p<2`；又

`sum_p (1+epsilon_p)/p^2 < (128/123) sum_(n>=2)1/n^2 <128/123`。

所以 `log C_*<4`，从而可取

`C_*<e^4`.                                                  (21)

常数非常粗，但足以证明平均有界。

## 5. 定理 V3：同一个永久族同时满足整个严格开前沿

保留父节点的混合短向量期望接口。设

`k(N)=floor(log_2 N)`,
`E_N(gamma)={lambda1(M(N)) < N^(1/6)/(sqrt42*k(N)^gamma)}`. (22)

在新的条件化乘积测度下，活动素数的因子被 (13) 控制。再用仅对该布尔存在观察安全的 `z<->-z` 商，得到

`mu(E_N(gamma)) <= F_*(N)/(128 k(N)^(6gamma))`.            (23)

常数128对指数前沿不重要，但这里保留精确观察类型。

固定 `beta,alpha>=0` 和 `C>0`，要求同一起点 `N` 同时保护

`1<=m<=C k(N)^alpha`.                                     (24)

由次乘性和 (18)：

`mu(exists m in window: E_(mN)(gamma))
 <= const * F_*(N) k(N)^(alpha-6gamma)`.                  (25)

令 `c_k` 为 `2^k<=N<2^(k+1)` 中窗口失败的起点数。再用 (18)：

`E[ k^beta c_k / 2^k ]
 <= const * k^(beta+alpha-6gamma)`.                       (26)

因此若

`6 gamma > 1 + beta + alpha`,                              (27)

右侧关于 `k` 可求和。与前几轮相同的非负损失论证得到

`#{N<=X: window failure}=o(X/(log X)^beta)`.               (28)

### 5.1 “一个族”而不是每组参数一个族

新的乘积测度 (19) 与 `beta,gamma,alpha,C` 无关。对每一组有理参数且满足严格 (27) 的性质，失败集合都是零测集。可数相交后仍是满测集；再与四个固定旧种子的正概率柱集相交，仍非空。

对任意实参数的严格 (27)，可以选取一个更强的有理四元组：更大的 `beta,alpha,C`、更小的 `gamma`，并保持严格余量。因此存在**同一张永久冻结种子表**，保留四个旧锁定，并同时满足全部实参数开区域 (27)。

这比父节点“先固定一个 `epsilon` 再得到一个开区域”更强：现在概率空间本身也不需要随目标指数调整。

### 5.2 两个直接边界

当 `beta=1`：

- 单目标 `alpha=0`：同一族对任意 `gamma>1/3` 都满足 `o(X/log X)` 例外界；
- 固定 `gamma=3/8`：同一族可同时支持任意 `alpha<1/4` 的多项式乘数窗口。

例如 `alpha=6/25` 时余量为

`6*(3/8)-2-6/25 = 1/100`.                                 (29)

## 6. 定理 V4：临界幂次可以到达，但必须支付可求和的迭代对数

若恰好位于幂次临界面

`6gamma = 1 + beta + alpha`,                               (30)

则 (26) 只剩调和级数 `1/k`，当前非负一阶矩方法不再可求和。

给几何下界再增加

`(log k)^delta`

的分母，并把窗口改为

`m <= C k^alpha/(log k)^eta`,                              (31)

则 (26) 变成

`const / [k (log k)^(6delta+eta)]`.                        (32)

因此只要

`6delta + eta > 1`,                                        (33)

临界幂次仍可实现。

特别地：

1. `beta=1,alpha=0,gamma=1/3`：任意 `delta>1/6` 都给出

   `lambda1 >= N^(1/6)/[sqrt42*k^(1/3)(log k)^delta]`

   除 `o(X/log X)` 个指数外成立。

2. `beta=1,gamma=3/8,alpha=1/4`：不额外削弱几何 (`delta=0`) 时，只要 `eta>1`，即可同时保护

   `m <= C k^(1/4)/(log k)^eta`。

3. 一般临界面上，几何迭代对数损失与窗口迭代对数削减可以按 (33) 相互交换。

**不能删除最后这层对数后宣称临界已闭合。**即使算术平均已经 `O(X)`，当前第一矩二进损失在无修复的临界面仍是 `1/k`。要取得完全未削弱的等号，需要真正的相关性/最大不等式或另一种全局结构输入。

## 7. 显式预算下仍保留有量化的 prime-power 几何

变量预算牺牲了父节点的统一正 prime-power 常数，但不是完全失控。

由 (19)，对所有 `j>=1`

`epsilon_p >= (5/123)/[j(p) ell(j(p))^2]`.                 (34)

又因 `epsilon_p<=1`，

`2epsilon_p/[5(1+epsilon_p)] >= epsilon_p/5`.              (35)

所以 (10) 给

`kappa_p >= C_pp / [j(p)^(1/6) ell(j(p))^(1/3)]`,          (36)

其中

`C_pp=(sqrt(6/7)/3)*123^(-1/6)>0`.                        (37)

因此对所有 prime-power 指数 `N=p^a`，包括中间层和闭合理想层，

`lambda1(M(p^a))
 >= C_pp N^(1/6)/[(k(N)+1)^(1/6)
                  (1+floor(log_2(k(N)+1)))^(1/3)]`.        (38)

闭合理想层本来有更强常数；(38) 是统一写法。

所以从“固定常数”退让后，prime-power 仍只有很慢的对数/迭代对数损失。预算表 (19) 不是唯一选择；任何满足 (8) 的带预算都可以使用，较慢的可求和预算还能调整 prime-power 的具体损失形状。
