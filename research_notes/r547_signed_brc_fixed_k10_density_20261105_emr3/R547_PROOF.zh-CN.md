# R547｜冻结 signed BRC：k=10 无限阶双向换号与符号正下密度

日期：2026-11-05（Asia/Shanghai）。类别：作者侧精确代数证明、可执行有理数证书。冻结科学输入：R462 commit `18783e01e3646c72b7aab3b16d3f565e83e6446f`。接续已保存 R546 commit `38e4af26eceed759fe12110032bb3b630e0fe449`。

## 定理

设 `k=10,r=21,C_j=binom(2j,j)/(j+1)`，`H_k(t)=binom(r+t,2t)[x^r](1-x)(1+x)^(2t)(1+x²)^(r-t)`，定义域 `2<=t<=r`，域外 `H_k(t)=0`。令 `D_0(k)=1`、`D_m(k)=det(H_k(3+i-j))_(0<=i,j<m)`。

**定理 A：** 对正、负号阶数集合均有正下密度：
```
liminf_(N→∞) #{0<=m<N:D_m(10)>0}/N >= 1/6,
liminf_(N→∞) #{0<=m<N:D_m(10)<0}/N >= 1/6.
```
特别地，两个符号各出现无穷次，跨阶数无限换号。

**通用引理 B（本轮新增）：** 对任意实序列 `s_m=A lambda^m+conj(A)conj(lambda)^m+sum_j B_j mu_j^m`，若 `A≠0`，`lambda` 非实，`|lambda|>max_j |mu_j|`，且剩余根有限，则 `s_m>0` 和 `s_m<0` 的下渐近密度各至少 `1/6`。它可复用于 R543–R546 已经隔离出单一最大模非实共轭对的 `k=5,6,7,8,9`，以那些已有的精确根证书为前提。

## 1. 原始有限输入与生成函数

对于全部 `t=2,...,21`，R547_INDEPENDENT.py 从原始多项式直接抽系数，并独立核对了
```
H_10(t) = binom(21+t,2t)*sum_{q=0}^{min(floor((t-1)/2),10)}
          binom(t-1,2q)*4^q*C_(10-q).
```
有 `C_10=16796`，`p_t=H_10(t)/C_10`，`p_2=8855`。设 `f_m=D_m(10)/C_10^m`，则 Toeplitz–Hessenberg 首行展开给出
```
f_0=1,
f_m=sum_{j=1}^{min(m,19)} (-1)^(j-1)*p_(j+2)*p_2^(j-1)*f_(m-j).
```
令 `a_j=(-1)^(j-1)*p_(j+2)/p_2`。归一化特征多项式
```
Q_10(y)=y^19-sum_{j=1}^19 a_j*y^(19-j).
```
在 `X=p_2*y` 下，对应 `f_m` 的特征根 `X_i=p_2*y_i`。完整精确系数由 R547_VERIFY.py 的 `normalized(10)` 从整数和 Fraction 重建。

## 2. 精确 Rouché 证书

在 R547_VERIFY.py 逐项列出的 19 个有理复中心 `c_i` 上，取 `epsilon=1/1000`。对 `Q_10(c_i+w)=sum_{j=0}^{19} b_ij*w^j` 作精确 Fraction 泰勒展开。通过整数 `isqrt` 得到复模的严格有理下上界 `L(z)<=|z|<=U(z)`，对每个根盘分别核验：
```
U(b_i0)+sum_{j=2}^{19} U(b_ij)*epsilon^j < L(b_i1)*epsilon.
```
19 个不等式全部成立，最大左右比严格 `<1/39`。所有 171 对中心距离严格大于 `2*epsilon`。因此每盘有恰一个简单根，19 盘穷尽全部根。

首对中心 `6.033407511 ± 7.862167698 i`。严格有理模长界显示这对非实共轭根满足 `|y_±|>9`；其余 17 个根满足 `|y_j|<5`。因此 `|X_±|>79695`，`|X_j|<44275`，并且所有根非零（`a_19≠0`）。浮点根求解仅用于提出候选中心，任何证明判据均使用有理数。

## 3. 下密度引理与定理证明

全部 `X_i` 是简单非零根，所以生成函数的部分分式展开给出
```
f_m=sum_i A_i*X_i^m,   A_i=X_i^18/P'_10(X_i)≠0.
```
设主导 `X_+=rho*exp(i theta)`、`A_+=|A|exp(i phi)`。那么
```
f_m=2|A|rho^m*cos(m theta+phi)+R_m,
|R_m|<=B*44275^m,  B=sum_(remaining)|A_j|<infinity.
```
`X_+` 非实，故 `exp(i theta)≠1` 且 `exp(2i theta)≠1`。令 `x_m=cos(m theta+phi)`；有限等比和严格推出 `avg_N x_m→0`、`avg_N x_m²→1/2`（无需假定 `theta/pi` 无理）。

令 `g_-(x)=(x+1/4)(1-x)=-x²+3x/4+1/4`。当 `x>=-1/4` 且 `|x|<=1` 时，`g_-(x)>=0`；全域有 `g_-(x)>=-3/2`。因此
```
avg_N g_-(x_m) >= -(3/2)*#{m<N:x_m<-1/4}/N.
```
左边极限为 `-1/4`，遂 `liminf #{x_m<-1/4}/N >=1/6`。完全对称地，用 `g_+(x)=(1/4-x)(1+x)=-x²-3x/4+1/4`，得到 `liminf #{x_m>1/4}/N >=1/6`。

又 `|R_m|/rho^m<=B*(44275/rho)^m→0`；充分大阶数时，`x_m>1/4` 保证 `f_m>0`，`x_m<-1/4` 保证 `f_m<0`。有限前缀不改变下密度。`C_10^m>0`，于是定理 A 成立。上述论证同样证明通用引理 B。
