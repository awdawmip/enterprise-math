## Theorem W1 — all one-step threshold experiments match

For *either* J=j, the conditional Z1 distribution is P(0,1|j)=(2/5,3/5) and Q(0,1|j)=(3/5,2/5); P(J=j)=Q(J=j)=1/2. Consequently for **every** real threshold tau,

  R_j(tau)=sum_z [P(Z1=z|J=j)-tau Q(Z1=z|J=j)]_+

is independent of j; in particular R_0(1)=R_1(1)=1/5. Indeed both P and Q conditional kernels are independent of H and J, so summing out H proves every component of this identity, not merely one sampled cost or likelihood threshold. Z1 is itself genuinely informative: L1(0)=2/3, L1(1)=3/2. Equality of one-step conditional ROC/threshold families is therefore exact.

For any subset C⊆{0,1} selected to continue at t=1, define W_C=P(J∈C)=Q(J∈C) and theta_C=P(H=A|J∈C)=Q(H=A|J∈C). At t=2 J is ERASED, so every path chosen in C must use the same Z1-dependent action.   B(C,c)=W_C{1/5+2[3theta_C/10-c]_+-2c}, B(empty,c)=0.

The universal base time cost is -2c. The old observer can select only C=empty or C={0,1}; the refined observer can choose any of the four subsets. At c=1/8 the four exact B values are:
