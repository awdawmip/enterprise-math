## 2. Exact sampling and interval law

For ordered nonnegative integer terminal weights w_i with sum Q, let F_m=sum_(i<m)w_i. Choose J uniformly in0..Q-1 and return the unique i with F_i<=J<F_(i+1). Exactly w_i choices return i. Thus binary search on cumulative masses samples the complete distribution without division by small conditional-prefix probabilities.

If L_m<=F_m<=U_m, decide left when J<L_m and right when J>=U_m; otherwise refine the SAME J. Exact refinement gives the same inverse-CDF map. Monotonic intersections max_(j<=m)L_j and min_(j>=m)U_j remain valid even when independently computed centres are nonmonotone. Approximate dual coefficients need not themselves define a positive distribution: each certified decision agrees with one actual positive state.

Do not discard a threshold merely because it is uncertain. Repeatedly redrawing ambiguous Bernoulli thresholds from a squeeze[L,U] would give success probability L/(L+1-U), generally not p. Range rejection in uniform-integer generation is a different, proved construction.

At cut s, F_m=sum C_bc(g)K_bc(g), with numerator-only state and common Q=9^T. n_b=sum_w A_b(w)^2 and2|K_bc(g)|<=n_b+n_c bound dropped terms by sum |C_bc(g)|*(n_b+n_c)/2. Pair transpose/inverse terms so the bound is integral. Refinement adds a group's true signed contribution and removes only its already paid absolute bound. No omitted K is inspected to construct this generic row-norm bound; it can therefore be loose.

For fresh fixed enclosures, the probability of initially needing refinement is bounded by the measure of the relevant ambiguous threshold intervals, intersected with each node's true quantile range. This is an uncertainty-mass bound, not a time bound or a claim that certificates are cheap. Rare leaves are retained; expensive boundary construction can still dominate.

## 3. Exact subtree improvement

At a node of mass n, compute only left-block mass ell. Right mass is n-ell, using actual BRC subtraction. For local rank J, take left with unchanged J when J<ell; otherwise take right with rank J-ell. This is a bijection of parent ranks with disjoint child ranks, so each leaf receives exactly its mass. No ell/n or rare-prefix reciprocal occurs.

Only left-block events receive a new backward pullback; right values follow by conservation. Geometry, demanded K contractions and nodes are shared. This is familiar additive partition/caching reuse, not new quantum physics.
