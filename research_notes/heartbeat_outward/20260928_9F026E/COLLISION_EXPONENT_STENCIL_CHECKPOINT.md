## 4. Universal formal-exponent template and proof

For a suffix beginning at absolute tick t, put q=a^(2^t) moduloN. The three local selected-port work factors are q,q^2,q^4. Compile over formal integer exponent e with local increments1,2,4 instead of first substituting a modulus. Let W_i(u,r;e) be the signed integer impulse numerator at relative endpoint u, final port r, exponent e, from input port i. Define

    B_ij(Delta,d;u,r)=sum_e W_i(u,r;e)*W_j(u-Delta,r;e-d).

Then for any declared diagonal visible event E,

    H_E(x,i;y,j;g)
      =sum_(d:q^d=g) sum_(u,r) B_ij(y-x,d;u,r)*1_E(x+u,r).

Proof: expand the two finite path sums. Equal visible outputs force the same final port and x+u=y+v, hence Delta=u-v. Equal work values require w*q^e=g*w*q^f, equivalent to q^(e-f)=g because all multipliers are units. Group by d=e-f,u,r. Every colliding exponent fibre is summed, never reduced to one representative or replaced by absolute values. This is a finite algebraic pushforward, not an isometric identification of arbitrary pure work states.

Same final port cancels the last local increment4, so only d=-3,-2,-1,0,1,2,3 occurs.
