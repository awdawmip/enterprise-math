# R5 下一研究单元：两处相互作用碰撞上的真正暴露面

母问题：严格正有理双律树的完整历史与无持久随机种子 LR 策略具有相同全部四维有符号支撑函数，但真实四维可达像不等。本轮新证书：RESEARCH.md 的暴露面秩三定理；正有理六叶算例有 1/2304 的受限子族秩三 minor，却可被全策略终端声明以 swap=1/30 修复，故不能冒充母问题的反例。

设计至少两个相互作用的同刻 LR 碰撞信息集（或三来源共享且具有两个自由决策层的精确拓扑）。保留 Q/P 叶质量和所有完整时间/声明决策。枚举具有两个二元自由变量 x,y 的压缩纯策略四角，计算三列 u,v,w 的精确有理 3x3 minor；如非零求其有理核法向 lambda。经完整 Bellman/全部确定性计划证明 lambda 暴露最大面，而且所有影响输出的其余压缩行为已经固定。特别检查末端标签的误差交换，若有额外最优自由度先证明它不能修复中点，否则淘汰该候选。

独立为每个完整历史确定性四维向量求非负有理压缩确定性凸组合，或给出覆盖全部有符号方向的符号定理。只有两道证书均通过，才能采用 (B00+B11)/2 与 minor 给出真正的全实数不可实现性证书。证书必须保留原始树、精确源版本、代码与输出；独立 Driver 评审及原生 Owner/CLAIM 在正式准入前按控制协议另行核验。
