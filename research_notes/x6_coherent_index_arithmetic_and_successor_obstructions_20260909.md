## 0. 本轮问题与不变边界

上一轮已完成 index-2 三步闭合分类，下一单元是：不同素数的操作如何兼容，以及乘法的 index 历程能否直接等同于普通逐次加一。

## 1. 定理 A：径向不回落的单位 successor 必然线性远离锚点

设 x_0=0，x_{t+1}-x_t 属于 {+/-e_i}，并要求 Q(x_{t+1})>=Q(x_t)。
一次第 i 坐标的带符号步骤 epsilon 给出

    Q(x+epsilon e_i)-Q(x)=2 epsilon x_i+1.

此差值为非零奇数。它为正当且仅当 |x_i+epsilon|=|x_i|+1。
所以每步的 l1 范数都增加1，严格得到

    ||x_t||_1=t,
    t/sqrt(6)<=||x_t||_2<=t.

这排除了同时具有以下三性质的路径：每次加一恰为一个原生单位步；半径永不减小；半径是 O(t^(1/6))。

不是只在 n=2 处有壳层误差：即使允许任意常数和渐近误差，**径向单调的单位路径也不能实现六维占据密度尺度**。

更一般，任何单位路径令 I_t 为使 Q 减少的步数，O_t 为增加的步数，则

    O_t+I_t=t,
    O_t-I_t=||x_t||_1,
    I_t=(t-||x_t||_1)/2.

若一条拟议稠密枚举满足 ||x_t||_2<=C t^(1/6)，则

    I_t >= t/2-(sqrt(6)C/2)t^(1/6).

因此长程至少近一半的步骤必须径向内行。径向内行不等于沿原边折返或重访同一 Cell；本式是必要条件，不是存在性构造。

## 2. 定理 B：S6 不变的 index-2 子格，不提供 S6 等变的单矩阵输运

上一轮唯一 S6 固定的 index-2 子格是 sum_i z_i=0 mod2。不能由此宣称存在与全部轴置换可交换的整数 index-2 矩阵。

若 A 与六轴的每个置换矩阵可交换，共轭置换使其所有对角元相等、所有非对角元相等，故

    A=aI+bJ, a,b in Z,
    det A=a^5(a+6b),

J 为全一矩阵。若 |det A|=2，则 |a|=1，且 |a+6b|=2；后者与 a+6b=+/-1 mod6 矛盾。

结论：在输入/输出采用同一个 S6 坐标作用的前提下，不存在 S6 等变的 index-2 整数输运。

这是严格区分“像子格不变”和“选定基/输运等变”的例子，不是否定 S6 对称性，也没有新增原生旋转公理。

## 3. 一个更具体的固定输运障碍：所选高斯闭合不能兼容固定 index-3 矩阵

固定三对轴，令

    C=diag(B2,B2,B2), B2=[[1,-1],[1,1]].

有 C^T C=2I，det C=8。写 J0=C-I，则 J0 是三块 [[0,-1],[1,0]]，J0^2=-I。
若一个整数矩阵 D 与 C 可交换，则它与 J0 可交换；按这三对轴组成的高斯整数坐标，D 是一个 3x3 的 Z[i] 矩阵。
所以其六维整数行列式是高斯行列式的范数：

    det_R D=|det_C D|^2=a^2+b^2.

它不可能为3。用 mod3 即可验证：a^2+b^2=0 mod3 强迫 a,b 都被3整除，范数因此被9整除。

因此不存在 |det D|=3 且 DC=CD 的整数 D。

适用范围仅是这个明确选定的 C。没有证明所有可能的 index-8 闭合矩阵都排斥 index-3；也没有证明任意状态依赖、分支关系或有理输运模型均不可能。这正是下一节改用状态依赖接口的动机。

## 4. 定理 C：用各素数的嵌套子格链，构造全部正整数的兼容 index 几何

先声明额外选择，不把它冒充内生定律。对每个素数 p，选一条链

    Z^6=L_p(0) > L_p(1) > L_p(2) > ...,
    [L_p(k):L_p(k+1)]=p.

对**每个正整数 n**定义

    L(n)=intersection_{p|n} L_p(v_p(n)); L(1)=Z^6.

### C1. 精确 index 与整除兼容

不同素数的局部商群阶互素。中国剩余型映射给出

    Z^6/L(n) ~= product_{p|n} Z^6/L_p(v_p(n)),
    [Z^6:L(n)]=n.

一种不依赖循环商假设的证明：L_p(k) 的指数是 p^k，故包含 p^k Z^6。取有限共同模数 M=product p^k，按各 p^k 的普通 CRT 分解 (Z/MZ)^6，各局部约束只作用于其本地分量。因此映射满射且核为所写交集。

并且

    n|m => L(m) subset L(n),
    L(m) intersection L(n)=L(lcm(m,n)).

后一个公式来自每个局部链的嵌套性：两个约束取指数较大的那个。没有抹去合数背景，而是为每个合数保留真实的联合子格。

### C2. 单素数矩阵必须依赖当前状态

为每个 L(n) 选一组整数列基 A(n)，A(1)=I，并固定该选择规则。定义

    T_m(n)=A(n)^(-1) A(nm).

因为 L(nm) subset L(n)，T_m(n) 是整数矩阵，且 |det T_m(n)|=m。
采用**右侧坐标输运**约定后，有精确式

    T_m(n) T_l(nm)=T_{ml}(n),
    T_p(n) T_q(np)=T_q(n) T_p(nq).

证明就是中间基矩阵精确消去；相同最终整数的不同乘法顺序得到同一个 A(n_final)。这不是要求固定 T_p 与固定 T_q 可交换。

若沿序列 m1,...,mr 从 n 出发，全部相对矩阵相乘严格为

    A(n)^(-1) A(n*m1*...*mr).

这是已声明选择下的整除范畴上的一致输运，不等于完整原生几何的全部 holonomy 为零。

### C3. 基选择的范围

可在非闭合点使用列 Hermite 标准形作可复现基；闭合点则使用下节明确构造的相似基。HNF 是选基规则，不是原生几何定律；相似子格的 HNF 通常不再具有标量 Gram。

构造给出存在性与可检查接口，但没有给出最优形状、统一条件数界或大整数快速分解算法。源整数 n 在该确定性所选子格族中可以重建 A(n)，不意味着 n 能重建原始全分支人口的任意形状与历史。

## 5. 把上一轮的3/6素数周期嵌入同一全部整数构造

固定坐标对 (1,2),(3,4),(5,6)，这是显式额外结构。

对 p=2 或 p=1 mod4，固定 p=a_p^2+b_p^2 的一个表示，令

    B_p=[[a_p,-b_p],[b_p,a_p]], B_p^T B_p=pI2.

当 k=3r+s，0<=s<3，令 L_p(k) 由三个2x2块生成：前 s 块用 B_p^(r+1)，其余用 B_p^r。
每步 index p，且 k=3r 时相似倍率平方是 p^r。

对 p=3 mod4，写 k=6r+s，0<=s<6；令前 s 个坐标基乘 p^(r+1)，其余乘 p^r。
每步 index p，k=6r 时为 p^r Z^6，相似倍率平方 p^(2r)。

令 c_p=3（p=2或1 mod4）、c_p=6（p=3 mod4）。若全部 v_p(n) 都是 c_p 的倍数，则各局部闭合基相互可交换：前类在同一三对轴上是复数乘法，后类是标量。

它们的乘积基包含于全部局部子格且行列式为 n。由 C1 的 index 等式，它恰好生成 L(n)，并满足

    A(n)^T A(n)=n^(1/3) I6.

所以此前的局部闭合不再只是各自孤立例子：它们已经可以在一个整除兼容的全部整数模型里同时实现。
例如 n=2^3*3^6=5832 时 q=n^(1/3)=18；n=2^3*5^3=1000 时 q=10。

一般“Z6 的相似乘子 q 恰为两平方和”属于 Conway–Rains–Sloane 的经典结果（Theorem 2），不是本项目原创。本节的贡献层次是把具体局部链、CRT交集与状态依赖相对矩阵接为一个可执行模型。

这里并没有让每个 n 都变成相似子格：不符合经典 index 资格的 n 仍不可能整体各向同性。

## 6. 最小的2/3例子：不是改乘法，而是改当前坐标下的3操作

仅写前两个坐标，其余四轴恒等。取

    A(2)=B=[[1,-1],[1,1]],
    A(3)=D=[[3,0],[0,1]],
    A(6)=D B=[[3,-3],[1,1]].

A(6) 的像满足 x=0 mod3 与 x+y=0 mod2，恰为两局部约束的交集。
固定 B,D 并不交换，但

    T_3(2)=B^(-1) D B=[[2,-1],[-1,2]],
    T_2(3)=B,
    B T_3(2)=D B.

因此“先2后3”和“先3后2”完全相同，代价是第二步的矩阵根据当前基改变。两个3操作的 index 都精确为3，普通算术没有改变。

这是单个方便基的展示，不要求它与验证器在所有非闭合点选择的 HNF 字节相同；两者像子格一致，各自内部的菱形恒等式精确成立。

## 7. 定理 D：加一不是同一种整数 index 嵌套操作

设 A(n) 为任意 index n 的整数基，试图用整数 U_n 满足

    A(n+1)=A(n) U_n.

则

    |det U_n|=(n+1)/n.

n>1 时不为整数，所以不存在这样的整数 U_n。这不依赖上一节具体选择。

因此“+1”和“乘p”不能都无区别地解释为同一类子格嵌套。n=1 的第一步恰好例外，不能凭1到2的可行性推广到整个自然数序列。

### D1. 精确修复：共同细分层

在 C 节的选定族中，因为 gcd(n,n+1)=1，

    L(n) intersection L(n+1)=L(n(n+1)).

令 C_n=Z^6/L(n)，则有规范商映射构成的 span

    C_n <- C_{n(n+1)} -> C_{n+1},
    C_{n(n+1)} ~= C_n x C_{n+1}.

左侧映射每个纤维有 n+1 个元素，右侧每个纤维有 n 个。它把两个 index 层关联起来，但不是凭空得到一个唯一 successor。

固定旧余类后，新余类仍有 n+1 个可能值。若先在共同层采用均匀分布，再仅凭旧余类投影到新余类，得到的是独立均匀输出，不是确定性的算术 successor。

在保留所有坐标平移作用的语言下，也不存在 C_n->C_{n+1} 的平移等变函数：这种函数需要稳定子包含 L(n) subset L(n+1)，进而要求 n+1 整除 n，矛盾。

所以仍需明确的 section、额外状态、占据集生成规则或完整关系载体。有限集合的不交并可以实现计数加法，但并不会自动成为当前这套六维格的原生加一动力学。

### D2. 一般共享因子的修复

在同一所选局部链模型中，从 C_{mn} 到 C_m 与 C_n 的联合观察，其像大小为 lcm(m,n)，纤维大小为 gcd(m,n)。

这是 quotient map C_{mn}->C_lcm 的精确计数，不能把联合观察的像误当成拥有 mn 个独立状态。此处保留合数 n 和共同层本身，而不是只留下各素数的总数。

## 8. 防止“换定义就解决”的两个基准

若要求 A:N0->M6(Z) 保持普通矩阵加法且 A(1)=I，则 A(n)=nI，行列式 n^6；这不可能同时表示 index n（n>1）。

但“所有兼容算术都不可能”也不成立。固定整数投影 P=e1*(1,1,1,1,1,1)，P^2=P，取

    F(n)=I+(n-1)P.

则 det F(n)=n，F(m)F(n)=F(mn)。若定义

    X boxplus Y=X+Y-(I-P),

就有 F(m) boxplus F(n)=F(m+n)，零元为 F(0)=I-P。

这只是自然数半环的显式搬运：它偏好一根轴，特征值为 n,1,1,1,1,1，n>1 时不可能各向同性。它说明“能够编码算术”远弱于“给出内生、均衡、原生的几何实现”。
