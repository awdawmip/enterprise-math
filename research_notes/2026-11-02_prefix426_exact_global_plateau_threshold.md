## 全局证明

取 `r=|u|²,s=|1+u|²,a=(s−r−1)/2,b=Im u`。双基准盒为 `r∈[1−ε,1+ε],s∈[2−ε,2+ε]`，且 `r−a²>0`，所以每一对 (r,s) 精确对应 `u=a±i√(r−a²)` 两个来源。写 `H=(5+9i)/2+(3+7i)u/2`。直接展开：

```
J_±(r,s)=|H|²=7−5r+39s/2 ∓4√(r−a²).
∂rJ_-=−5+2(1+a)/√(r−a²)<0;
∂sJ_-=39/2−2a/√(r−a²)>0;
∂rJ_+=−5−2(1+a)/√(r−a²)<0;
∂sJ_+=39/2+2a/√(r−a²)>0.
```

这里 `|a|≤β` 与 `√(r−a²)>99/100` 使四个不等式对全部连续参数严格成立。负相位的 J 唯一最小于 `(r,s)=(1+ε,2−ε)`，取值为上面 J；正相位的 J 唯一最大于 `(r,s)=(1−ε,2+ε)`，其值为 `J_+=41+49ε/2−4√(1−ε−ε²)`。

对每个固定 u，`z4=H+4iv` 且 `|v|≤1/1000`。由三角不等式及严格等号条件，强度最小和最大分别为 `(√J−1/250)²`、`(√J+1/250)²`，唯一的 v 分别为 `+iH/(1000√J)`、`−iH/(1000√J)`。在整个盒上 `J_-^{min}>44.89`、`J_+^{max}<37.21`；所以负相位强度始终 >41，正相位始终 <41。

还需比较两相位绝对偏差。由于

```
J_-^{min}+J_+^{max}<82+5×10^{-6},
√J_-^{min}−√J_+^{max}>6.7−6.1=0.6,
```

令 `d=1/250`，则 `(√J_-^{min}−d)²+(√J_+^{max}+d)² < 82+5×10^{-6}−2d(0.6)+2d²<82`。因此仅有双基准和圆盘约束时，全来源唯一绝对偏差最小值为负相位来源 `(u*,v*)`，数值为 `κ_sat`。

恢复联合测量只会收缩可行集；要仍取得 `κ_sat`，必需且只需唯一的 `(u*,v*)` 通过联合条件。原始矩阵的精确展开为

```
I4=J+Ax+By+16t, k=|z5|²−709/32=c+Px+Qy+53t/8,
h=|1+v|²−1=2x+t, t=x²+y², c=709(s−2)/64,

P=[245(1+a)+123b]/16, Q=[−123(1+a)+245b]/16,

```

在 u* 上有 `x*=−A/(8000√J),y*=−B/(8000√J)`、`c=−709ε/64`、`AP+BQ=T`，所以精确得 `k*=−η_sat`，而 `h*=β−(36−28ε−12w)/(4000√J)`。有理严格界给出 `η_sat>1/50`、`|h*|<1/1000`。候选通过所有条件等价于 `η≥η_sat`。当 η 低于阈值，候选不可行，紧致可行集存在最小值且严格大于 `κ_sat`；例如 `u=−i,v=0` 始终提供非空可行集。定理 A 成立。

阈值导数精确为

```

η_sat'=709/64 + [T'−T J'/(2J)]/(8000√J).
```

由 `0.49<w'<0.51`、`44.89<J<49`、`1200<T<1300` 得 `−700<T'−TJ'/(2J)<0`，于是 `11<η_sat'<709/64`。端点根隔离由精确 `Fraction`/整数 `isqrt` 向外包络给出。
