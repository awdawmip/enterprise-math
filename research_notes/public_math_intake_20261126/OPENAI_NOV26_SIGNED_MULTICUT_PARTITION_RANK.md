## Correcting the proof-method boundary, not the bound
Nov25 proves sum_t 2^floor(W_t/S) >= 2^m by nonnegative integer branch support disjointness. Its signed example I=J-X shows disjointness fails, not that the inequality fails. Today the same inequality is established over EVERY field, for any finite number r>=2 of terminals, without nonnegativity.

External known theorem: Eric Naslund, The partition rank of a tensor and k-right corners in F_q^n, JCTA 174 (2020), 105190, Lemma 11, DOI https://doi.org/10.1016/j.jcta.2019.105190 ; arXiv https://arxiv.org/abs/1701.04475 . Diagonal tensor over any field with N nonzero diagonal entries has partition rank N. This is prior mathematics, not a new EM theorem attributed to OpenAI. The new deduction here is its application to branch-dependent geometric cut budgets in the preceding intake model. Checked publisher statement of Lemma 11. No formal Lean verification claimed.

## Theorem (signed, branch-dependent multi-cut)
Let F be any field, r>=2 ports, label set L of size N=2^m, coordinates z_i in a chosen relative chart Z^6 (external comparison model). For each t=1..A a finite tensor network with local F-valued tensors and independent contracted edge indices of finite dimension d_e<=2^b_e, b_e nonnegative integers; each edge moves along one axis with integer length ell_e, possibly zero local edges. Assume the sum of the branch tensors equals the full r-port diagonal tensor D(x_1,...,x_r)=1 if all labels coincide, 0 otherwise, entrywise over F. No cross-branch constraints outside this sum are free. Define S=sum_a(max_i z_ia-min_i z_ia)>0 and W_t=sum_e ell_e b_e. Then:
    sum_t 2^floor(W_t/S) >= N.
More precisely with c_t(C)=sum_{edges crossing C} b_e for each terminal-separating integer coordinate cut C,
    N <= sum_t min_C prod_{edges crossing C} d_e <= sum_t 2^min_C c_t(C) <= sum_t 2^floor(W_t/S).
In particular if every W_t<=w, floor(w/S)+log_2 A>=m. For A=2^s, w>=S max(0,m-s). This is a field-valued exact output theorem, not preservation of unobserved provenance.

Proof. For every branch t and any terminal-separating cut C, fix all crossing indices. The remaining factors split into two tensors on the nonempty terminal sets on the two sides. Thus each fixed assignment supplies a partition-rank-one term (or zero), with at most prod d_e assignments. Partition rank is subadditive under addition, even when each summand uses a different terminal partition. By Naslund Lemma 11 the full diagonal has partition rank N, so N<=sum_t partition_rank(T_t)<=sum_t min_C prod d_e. There are S unit coordinate cuts between extrema. A single axial edge crosses at most ell_e such cuts. Therefore sum_C c_t(C)<=W_t and integer min_C c_t(C)<=floor(W_t/S). Combine. This is why the sign-cancellation objection does not obstruct the bound. No rank of a sum across DIFFERENT cuts has been asserted; partition rank, not ordinary matrix rank, is the key.

Self-contained r=3 verification of the cited rank step: all bipartitions are slices. Suppose D decomposes into r1,r2,r3 terms sliced in its first, second, third variable, respectively. If r1>=N the result is immediate. Otherwise the annihilator of the r1 first-variable vectors has dimension d>=N-r1. Choose d coordinate positions for which projection of that subspace is bijective (independent pivot rows of a basis matrix); choose a vector with all d projected coordinates 1. This works also over F2 and has >=d nonzero coordinates. Contract D in the first variable with it; the resulting diagonal matrix has rank >=N-r1. The first slices vanish and each remaining slice gives at most rank one. Hence r2+r3>=N-r1. Upper bound N is the diagonal expansion. For r=2 use ordinary rank. For r>=4 use the cited established partition-rank theorem (not merely slice rank).

## Sharpness and stronger geometry
The preceding 2- and 3-terminal prefix-split tree constructions still attain the bound over arbitrary F (each nonzero entry has exactly one contributing assignment). That does not establish sharpness for all r or restricted native path graphs.

Weighted cut-packing corollary: in any declared ambient graph with edge lengths ell_e, choose nonnegative weights lambda_C on terminal-separating cuts satisfying sum_{C crossed by e} lambda_C <= ell_e for every allowed edge (or along its declared path). Let L=sum_C lambda_C>0. Then W_t>=sum_C lambda_C c_t(C)>=L min_C c_t(C), giving N<=sum_t 2^floor(W_t/L). Coordinate cuts with weights 1 recover S. A legal-path graph with stricter geometry can admit a different packing; no assertion that L equals a Steiner tree length or that the physical cost is W. This extends to a fixed finite family of cuts with explicit valid edge accounting, not to freely varying geometry across branches.
