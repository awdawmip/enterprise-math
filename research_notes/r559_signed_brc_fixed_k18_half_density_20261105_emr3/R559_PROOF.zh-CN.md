## 1. 模型、冻结输入与命题

继续 R558 的辅助 Toeplitz–Hessenberg 标量模型。科学输入冻结为 R462: `18783e01e3646c72b7aab3b16d3f565e83e6446f`，前沿 R558: `efc43ca257cd22506a2b80b133c39cfb52d89656`。本结果只关于该有限支路签名 BRC 的辅助标量可观察量，并不推定原生 X6 动力学。P000 与 ACTIVE 世界观原样保留。

固定 k=18，r=2k+1=37。定义 C_j=binom(2j,j)/(j+1)。对 2<=t<=37，
```
H(t) = binom(37+t,2t) * [x^37](1-x)(1+x)^(2t)(1+x^2)^(37-t)
     = binom(37+t,2t) * sum_{q=0}^{min(18,floor((t-1)/2))} binom(t-1,2q) 4^q C_(18-q).
```
其他 t 令 H(t)=0。定义 D_0=1，
```
D_m = det [ H(3+i-j) ]_(0<=i,j<m).
```
**定理（作者侧）：** 对上述精确模型，严格正值和严格负值索引集合的自然密度都为 1/2，且零项 m 的集合有限：
```
lim_{N->infty} #{0<=m<N:D_m>0}/N
= lim_{N->infty} #{0<=m<N:D_m<0}/N = 1/2;
#{m>=0:D_m=0}<infty.
```

## 2. 精确递推和全部代数根隔离

末行展开给出对每个 m>=1 的有限递推
```
D_m = sum_{j=1}^{min(m,35)}(-1)^(j-1)H(j+2)H(2)^(j-1)D_(m-j).
```
本轮 h=H(2)=39286260713700>0，令 s_m=D_m/h^m，a_j=(-1)^(j-1)H(j+2)/h。
故
```
sum_(m>=0) s_m z^m = 1/(1-sum_(j=1)^35 a_j z^j);
Q(y)=y^35-sum_(j=1)^35 a_j y^(35-j).
```
Q 是有理多项式。运行验证器将它乘以公分母获得整数系数。对全部 36 个 t=2,...,37，验证器独立比较上述 Catalan 公式与原始有符号系数卷积 Hraw，全部精确一致。

## 3. 主导辐角无理性

写 λ=|λ|exp(iθ)，θ位于 (π/4,π/3)。若 θ/π=p/q（最简），则 λ/bar(λ)=exp(2πip/q) 为 q 阶单位根。因此 φ(q)≤d(d-1)=35·34=1190。利用 φ(q)≥sqrt(q/2)，给出 q≤2·1190²=2832200。

使用 atan(x)=2atan(1/3)+atan((4x-3)/(4+3x))、Machin 的 π=16atan(1/5)-4atan(1/239) 和交错级数的有理余项包络，从精确根盘推出严格有理界 θ/π∈(L,U)，满足
```
1/4 < L < U < 1/3,  U-L < 10^-18.
```
枚举 2≤q≤2832200 中全部 φ(q)≤1190 的 **2311** 个候选周期，对每一项以整数运算确认
```
ceil(q L) > floor(q U).
```
因区间 (qL,qU) 不含整数，从而 θ/π 无理。此证明不需要构造高次根比值结果式。

## 4. 无限阶结论

所有根简单，且生成函数分子为1，主导两极点残数 A 与 bar(A) 非零；次主导根模长<11。故存在固定非零 A，
```
s_m = A λ^m + bar(A) bar(λ)^m + O(11^m)
    = 2|A||λ|^m cos(mθ+arg A)+O(11^m).
```
由 θ/π 无理，Weyl 等分布给出余弦正负各占自然密度1/2；相对误差 O((11/|λ|)^m) 仅可能在零点附近改变符号，该邻域密度上界随宽度趋零。因此 D_m 的严格正负密度均为1/2（h>0）。

零项有限性：Skolem–Mahler–Lech 定理说明线性递推的零项集合是有限集与有限个无限等差级数的并。若零项无限，则存在 a,q 使 s_(a+qt)=0 对所有 t>=0 成立。归一化的主导余弦于是随 t 趋零；而 qθ/π 无理，该子序列仍等分布并无限次有 |cos|>1/2，矛盾。
