## 1. 命题、量词和观察边界

取任意有限列表的正似然比 `0<r_1<...<r_k`（重复比值可预先按其标号质量合并），两组非负终端 **Q** 到达质量 `m=(m_i)`, `n=(n_i)`，满足双律终端总质量守恒：

```
sum_i m_i = sum_i n_i,      sum_i r_i m_i = sum_i r_i n_i.    (M)
```

对应 P 到达质量为 `r_i m_i` 和 `r_i n_i`。每一终端比值处允许使用即时随机二元判定，以概率 `x_i∈[0,1]` 判定 Q。同一策略同时用于 P、Q；只观察两种概率律下的终止时间和判定，不额外观察终端 r。记其同一终止时刻的判定 Q 双律质量可达集合为：

```
Z(m) = { sum_i m_i x_i (1,r_i) : 0<=x_i<=1 }  subset R^2.
```

坐标顺序为 `(Q(D=Q),P(D=Q))`。定义最坏旧终端选择在新质量下的最佳共同判定修复误差：

```
D(m->n) = sup_{z in Z(m)} inf_{w in Z(n)} ||z-w||_infinity.
```

**定理（有限阈值精确式）。** 在 (M) 下，令 `delta_i=m_i-n_i`，及各终端 LR 阈值 `r_j` 上的带标 call 残差

```
S_j = sum_i delta_i max(r_i-r_j,0).
```

则对于任意非负实数质量、任意有限正实数终端 LR，严格成立：

```
D(m->n) = max(0, max_j S_j/(1+r_j)).                         (1)
```

因此 **所有旧终端随机化决策均能被新的共同即时随机核完全修复，当且仅当全部 `S_j<=0`**。给定正的最大值，存在纯阈值旧决策 `x_i=1_{r_i>r_j}` 达到最坏修复误差；最优对偶法向为 `(-r_j,1)/(1+r_j)`。精确判定仅需有限个 LR 阈值，无需穷举旧策略或搜索连续法向。

此处 D 是固定的 `m,n` 的有向、最坏终端决策误差；若 m,n 由前期动态随机决策产生，仍须单独证明这些可达质量及前期动作的合法耦合。本式不自动给出任意 N>=4 全过程的全局 minimax 常数。

## 2. 完整证明

**支持函数。** 对任意 `(u,v)∈R^2`，由区间线段 Minkowski 和，

```
h_m(u,v) = sum_i m_i [u+v*r_i]_+.
```

由有限维紧凸集包含与对偶范数公式，`Z(m) subset Z(n)+epsilon B_infinity` 当且仅当对所有法向有 `h_m-h_n <= epsilon(|u|+|v|)`。所以

```
D(m->n) = max(0,sup_(u,v)!=0
                   (sum_i delta_i [u+v*r_i]_+)/(|u|+|v|)).
```

**约为一维阈值。** 当 `v=0`，双律零阶质量守恒使支持差为零。对于 `v!=0`，令 `t=-u/v`，`C(t)=sum_i delta_i(r_i-t)_+`。当 `v>0`，支持差为 `v C(t)`；当 `v<0`，它为 `|v| sum_i delta_i(t-r_i)_+`。利用 `(t-r)_+-(r-t)_+=t-r` 和 (M)，后者同样等于 `|v|C(t)`。且 `|u|+|v|=|v|(1+|t|)`。因此

```
D(m->n)=max(0,sup_(t in R) C(t)/(1+|t|)).
```

**有限化。** 在 `t<=r_1` 与 `t>=r_k`，(M) 使 `C(t)=0`；仅需正区间 `[r_1,r_k]`。每个相邻 LR 区间上 `C(t)=A-B t`，从而 `C(t)/(1+t)` 的导数为 `-(A+B)/(1+t)^2`，符号恒定。因此极大值位于区间端点之一，恰为公式(1)。

**对偶见证及可达性。** 若某阈值 `r_j` 达到严格正最大值，则在法向 `(-r_j,1)` 上，旧集合支持点可以用纯策略 `x_i=1_{r_i>r_j}` 取得。对所有新集合内的 w，有 `||z-w||_infinity >= S_j/(1+r_j)`。由支持包含式得到对每个旧点的反向上界，故精确取等。阈值为零时只需 (M) 和包含式。证毕。

**概率意义。** 在这个终止时刻，由 (M) 使每一律的终止总质量不变；判定 P 质量误差是判定 Q 质量误差的负数。故每一律的两判定终止分布 TV 恰是对应单坐标绝对偏差，两律最大 TV 等于这里的 `||z-w||_infinity`。其它停止时刻必须由外部构造独立保持，才可将本值认作全路径 `(T,D)` 误差。

## 3. 多碰撞残差组合的非加性精确反例

取 `r=(1/2,1,3/2,2)`，所有 Q 质量以 `1/40` 为单位。以 `n=(3,3,3,3)/40` 为公共新终端质量，两个独立零阶/一阶守恒残差为

```
delta_A=(1,-2,1,0)/40;  delta_B=(0,1,-2,1)/40.
m_A=(4,1,4,3)/40;      m_B=(3,4,1,4)/40;
m_AB=(4,2,2,4)/40=n+delta_A+delta_B.
```

全部质量严格正，三组旧/新均满足 (M)。按式(1)，

```
D(m_A->n)=1/160,  D(m_B->n)=1/200,
D(m_AB->n)=1/160 < 1/160+1/200=9/800.                 (2)
```

该例说明两处不同 LR 阈值的可修复性由**聚合后 call 残差的最大值**确定，而不是将各碰撞各自最坏误差机械相加。反向 `D(n->m_A)=0` 也展示双律决策修复的方向性；无损条件即所声明观察者下的凸序包含，并不等同终端路径来源完全恢复。
