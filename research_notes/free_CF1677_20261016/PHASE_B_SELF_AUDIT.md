## Paper pressure checks and precision repair

No enumeration, experiment, executable consumer or formal proof has run. The following are direct paper checks, not independent validation.

H=0: both histories include their common current Cell, all future words are empty, and the quotient is the unique class. The implicit-current-cell mask uses zero history bits.

H=1: B_1 consists of the current Cell and its twelve signed coordinate neighbors, so the upper mask has twelve bits. A sharper exact same-time control is available here. Start and end at 0 with T=24. Every nonempty subset S of the twelve neighbors is realized by making one two-step excursion 0->v->0 for every v in S, then padding to twelve excursions by repeating any one member of S. The visited set is exactly {0} union S, all histories have the same clock, and a one-step probe to v reads its membership in S. Conversely any nontrivial history ending at 0 contains at least one neighbor of 0. Therefore the exact number of H=1 signatures for this fixed start/end/time population is 2^12-1=4095; it needs twelve fixed-capacity binary state bits. The original lower construction gave only a weak two-signature witness at H=1, which is compatible with this stronger control.

Construction parity check: targets c_z have first coordinate odd, other coordinates even; attachments have second coordinate odd; the special coordinate-2 connector has either second or third coordinate odd at every intermediate point. The fixed skeleton therefore never visits a target. Dummy excursions are executed for every target before the selected excursion, so the non-target visited set does not depend on the bit string. Every selected excursion has length two, preserving the clock. The finite spanning-tree DFS includes every attachment and returns to its initial attachment. Its path length is at most 8(K-1), yielding the asserted T<=12K-4 after the entrance/exit and excursions.

Precision repair to the frozen counting sentence: the invariant statement is that there must be at least 2^K distinct retained machine states. The phrase 'an encoding of at most m bits has at most 2^m states' is to be read as an m-bit fixed-capacity memory register, or as fixed-length padded storage with no separately supplied variable-length/terminator side channel. An arbitrary variable-length code whose length is free side information has up to 2^(m+1)-1 strings of length <=m; that convention would change the stated bit inequality by at most one bit and leaves the state-cardinality theorem and Theta(H^6) order unchanged. The original file remains unmodified. The reviewed formulation should state the machine-state cardinality first and explicitly use fixed-capacity binary memory for the bit bound.
