## 1. Goal

The normalized equal-resultant theorem already gives an exact G1 half-root operation, but one question remained:

> can the choice of the “near identity” square root be defined purely at finite discrete rotation-state strength, without importing a continuous angle or the target value of `pi`?

The answer is yes for a cyclic orientation quotient. The rule is simply: among the two square roots in the doubled cyclic resolution, choose the one with smaller Cayley-graph distance to the identity; if the two distances tie, retain both branches.

The unique tie occurs at the half-turn.

## 2. Dyadic cyclic refinement tower

For an even integer `N>=2`, write

\[
G_N=C_N=\langle g_N\mid g_N^N=e\rangle.
\]

Refine direction resolution by the canonical injective homomorphism

\[
\iota_N:G_N\hookrightarrow G_{2N}
\]

defined by

\[
\boxed{
\iota_N(g_N^k)=g_{2N}^{2k}.
}
\]

This doubles the available direction-state resolution while preserving every old state.

For the #1158 six-gate candidate the first step is

\[
C_6\hookrightarrow C_{12},
\]

followed by

\[
C_{12}\hookrightarrow C_{24}\hookrightarrow C_{48}\hookrightarrow\cdots.
\]

No real angle is required to define this tower.

## 3. Every embedded state has exactly two square roots

Fix

\[
x=g_N^k,
\qquad 0\le k<N.
\]

A square root of the embedded state is an element

\[
y=g_{2N}^j
\]

such that

\[
y^2=\iota_N(x).
\]

On exponents this is

\[
2j\equiv2k\pmod{2N},
\]

so

\[
j\equiv k\pmod N.
\]

Therefore the two and only two roots are

\[
\boxed{
R_N(x)=\{g_{2N}^{k},\;g_{2N}^{k+N}\}.
}
\]

They are antipodal in `G_(2N)`.

## 4. Purely discrete distance to identity

Use the standard Cayley graph of `C_(2N)` generated by `g_(2N)` and its inverse. Define

\[
\delta_{2N}(g_{2N}^j,e)
=
\min(j\bmod2N,\;2N-(j\bmod2N)).
\]

For the two roots above with `0<=k<N`,

\[
\delta_{2N}(g^{k},e)=k,
\]

while

\[
\delta_{2N}(g^{k+N},e)=N-k.
\]

Hence exactly one root is closer to the identity unless

\[
k=N-k.
\]

For even `N`, this occurs iff

\[
\boxed{k=N/2,}
\]

which is exactly the half-turn state in `C_N`.

Thus:

\[
\boxed{
\text{the half-turn is the unique state whose two refined square roots are equally close to identity.}
}
\]

This is the finite-group version of the normalized-resultant antipodal singularity.

## 5. Shortest-root refinement relation

Define the discrete refinement relation `H_N` by:

- if `k<N/2`, retain only `g_(2N)^k`;
- if `k>N/2`, retain only `g_(2N)^(k+N)`;
- if `k=N/2`, retain both roots.

Equivalently,

\[
H_N(x)
=
\operatorname*{argmin}_{y^2=\iota_N(x)}\delta_{2N}(y,e).
\]

Then every retained branch satisfies

\[
\boxed{y^2=\iota_N(x)}
\]

exactly, while the relation is single-valued everywhere except at the half-turn.

No circumference, real angle, trigonometric function, or target `pi` is used to select the root.

## 6. Inversion equivariance

Let the turn-sense involution be group inversion

\[
S_N(x)=x^{-1}.
\]

The Cayley distance is inversion-invariant:

\[
\delta(y^{-1},e)=\delta(y,e).
\]

Also

\[
(y^2)^{-1}=(y^{-1})^2.
\]

Therefore

\[
\boxed{
H_N(S_Nx)=S_{2N}H_N(x)
}
\]

as a set-valued relation.

Away from the half-turn this is ordinary function equivariance. At the half-turn the two retained roots are exchanged by inversion.

Thus the two-sheeted seed and all later branchwise refinements are generated by one exact finite `S`-equivariant rule.

## 8. Character trace gives the nested radical after the finite state is chosen

Now, and only now, attach a one-dimensional unitary/algebraic character to the finite cyclic state. Let `z` denote the character value of a retained state and define its real trace coordinate

\[
c(z)=\frac{z+z^{-1}}2.
\]

If `w` is a retained square root of `z`, so

\[
w^2=z,
\]

then

\[
c(z)
=
\frac{w^2+w^{-2}}2
=
2c(w)^2-1.
\]

Therefore

\[
\boxed{
c(w)^2=\frac{1+c(z)}2.}
\]

On the shortest-root branch the real trace is the identity-near root, so after choosing the positive longitudinal coordinate one gets

\[
\boxed{

\]

Hence the Viète nested radicals are the real traces of the finite shortest-square-root refinement tower.

## 9. Equivalent uniqueness theorem in the Enterprise J readout

At the two-component G1 algebraic readout write a unit state as

\[
v=(c,s),
\qquad c^2+s^2=1.
\]

A square root `w=(C,S)` satisfies

\[
C^2-S^2=c,
\qquad
2CS=s,
\qquad
C^2+S^2=1.
\]

Therefore

\[
C^2=\frac{1+c}{2},
\qquad
S^2=\frac{1-c}{2}.
\]

For `c>-1`, imposing the **identity-hemisphere condition**

\[
C>0
\]

selects exactly one root:

\[
\boxed{
C=\sqrt{\frac{1+c}{2}},
\qquad
S=\frac{s}{2C}.
}
\]

This is precisely the normalized equal-resultant root

\[
B(v)=\frac{(1+c,s)}{\sqrt{2(1+c)}}.
\]

At `c=-1`, `C=0` and the two roots remain `S=+/-1`.

Thus the finite shortest-root rule and the G1 normalized equal-resultant rule are two representations of the same refinement semantics:

\[
\boxed{
\text{square root} + \text{move toward identity} \Longrightarrow B\text{ uniquely, except at the half-turn where both sheets remain.}
}
\]
