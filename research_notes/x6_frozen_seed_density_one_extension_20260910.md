## 0. 问题与结论强度

前轮只给出单个合数、有限目标集的存在性；目标数 K 增加会损失 K^(1/6)。本轮处理同一套局部种子如何永久固定，随后无限延伸，而不是为每个新指数重新选一个有利的格。

主要结论：任何有限组通过前轮粗几何筛选的种子，都能不改动地延伸成一套全整数族。它保留所有指数上的整除、gcd/lcm 和尖锐 U-未来信息规律；所有素数幂仍具有统一形状界。在全部整数中，除一个计数为 o(X/log X) 的例外集以外，最短向量具有 N^(1/6)/(sqrt(42)*floor(log2 N)^(2/3)) 的下界，六个独立方向的上界只损失对数幂。给出逐项固定、无回退、有限可计算的选择方法，但没有运行完整无限选择器或声称它高效。

这不是所有整数上的统一常数定理，也不是常数平均移动成本定理。例外指数仍保留为完整格与联合观察，不删除、不换名、不合并。密度一的好指数集合未证明对乘法封闭。

P000、原生 Q(z)=sum z_i^2、六轴、原生单位步不变。U 仍是额外的七阶整数操作，不是原生等距旋转。辅助概率仅用于选择种子；不是对空间 Cell 随时间的物理随机化。

## 1. 同一个概率空间：先限制到局部好种子

沿用 R=Z[x]/(1+x+...+x^6)、各素理想 P_p、f_p=ord_7(p)，令 f_7=1。在每个 (p,r) 块 I=P_p^r、I/IP_p 的全部非零对偶直线集合 E_(p,r) 中，定义 G_(p,r) 为同时满足所有中间层

    lambda1(F_s(ell)) >= (D*p^s)^(1/6)/sqrt(42),
    D=[R:I], 1<=s<f_p

的种子。闭合端点继承理想界。前轮已证明

    |G_(p,r)|/|E_(p,r)| >= a=59/64.                    (1)

这个集合有限可决定：用完整有限球枚举排除 42^3 Q(z)^3 < D p^s 的非零向量，全部比较可以用整数执行。可判定不等于具有实用复杂度。

在可数乘积 Omega=product_(p,r) G_(p,r) 上使用独立均匀乘积测度 mu。f_p=1 的块没有非平凡选择，可以省略。每个 omega 是一次永久固定的种子表，定义父笔记的 M_omega(N)。对每个 N 只读取其各素数当前未闭合层的种子；同一块不得在不同合数中另选。

不管 omega 怎么选，代数结果仍是

    [R:M_omega(N)]=N,
    M_omega(m) intersect M_omega(n)=M_omega(lcm(m,n)),
    M_omega(m)+M_omega(n)=M_omega(gcd(m,n)).             (2)

所有相对整数乘法菱形和最小未来核计数 N_h 均原样成立。又因每块种子属于 G，所有素数幂指数同时满足父笔记的统一 lambda1、lambda6 界。

有限冻结 C 指定有限组 (p,r) 的实际种子，每个均属于 G。它是正概率柱集；q_C=mu(C)>0。允许冻结的不是每个目标的独立最优值，而是共同的真实种子。相互矛盾的要求不构成这样的柱集。

## 2. 条件筛选的代价必须计入，不能沿用未筛选平均

设 T(N) 为尚未闭合的素数集合，a_p=f_p r_p+s_p，0<s_p<f_p，delta_p=f_p-s_p。父笔记在全部种子上给出

    E_all Z_N(Rho) <= (3/c0)^6 * (Rho^6/N) * Theta(N),
    c0=sqrt(6/7), Theta(N)=product_T (1+p^(-delta_p)),

其中 Z_N(Rho) 计数 M(N) 中长度严格小于 Rho 的非零向量。

现在分布变成 G 上均匀。一个有限集合上的非负随机量在条件于 G 后，期望至多放大 1/a。固定 N 涉及的未闭合块相互独立，所以严格得到

    E_mu Z_N(Rho) <= (3/c0)^6 * (Rho^6/N) * A(N),
    A(N)=a^(-|T|)*Theta(N).                            (3)

不能因为每个 G 的比例很高就把该放大因子丢掉。特别地，条件于无穷多个好块不需要用一个可能为零的全局接受概率除法；这里从各 G 的乘积测度出发，对每个 N 只比较有限个坐标。

由于 delta_p>=1、p>=2，每个活动素数的因子不超过

    (64/59)*(1+1/2)=96/59<2。

若 tau(N) 为正因子数，则

    A(N)<=2^|T(N)|<=tau(N)。                           (4)

这是刻意粗的整数主项界，不调用素数分布或渐近独立假设。它允许我们在无限多个合数间分配预算。

## 3. 定理 D1：同一冻结族的密度一几何界

对 N>=2 定义 k(N)=floor(log2 N)>=1，并取

    rho_N=N^(1/6)/(sqrt(42)*k(N)^(2/3))。

坏事件 B_N 是 lambda1(M_omega(N))<rho_N，等价于存在非零 z 属于该格且

    42^3*k(N)^4*Q(z)^3<N。                            (5)

注意这是精确整数判定；2/3 是本次选择预算造成的对数损失，不是新的空间维数或自然尺度指数。

由 (3)(4) 及 (3/c0)^6/42^3=1/64，

    mu(B_N)<=tau(N)/(64*k(N)^4)。                     (6)

定义第 k 个二进区间中的坏指数个数

    b_k(omega)=#{N:2^k<=N<2^(k+1), B_N occurs},

以及非负损失

    H(omega)=sum_(k>=1) k*b_k(omega)/2^k。              (7)

不同 N 的坏事件可以强相关；以下只用有限求和的线性期望及非负级数，不假设它们独立。

因子计数恒等式与分组调和和给出

    sum_(n<=2^(k+1)) tau(n)
      =sum_(d<=2^(k+1)) floor(2^(k+1)/d)
      <=2^(k+1)*(k+2)。

于是

    E_mu[k*b_k/2^k] <= (k+2)/(32*k^3),
    E_mu H <=5/32<infinity。                          (8)

最后一个有理上界只使用 sum k^-2<2、sum k^-3<3/2。更重要的是，有显式尾界

    E_mu[H-H_K] <= (K+1)/(32*K^2), K>=1。             (9)

其中 H_K 仅求和到第 K 个二进区间。该界来自两个递减幂级数的积分上界。

因此 H 在 mu-几乎处处有限，也在每个正概率有限冻结 C 的条件分布下几乎处处有限；后者的条件尾界至多为 (9)/q_C。这里确实建立了同一乘积空间和同一 H，不把每个目标分别存在的好选择拼成一个虚假的全局选择。

当 H(omega)<infinity，必有 k*b_k/2^k ->0，故

    b_k=o(2^k/k)。                                    (10)

把截至 X 的区间拆为 k<=floor(log2 X)/2 与其余区间，前者点数至多 O(sqrt(X))，后者用 (10) 的统一尾控制求几何级数，得到

    #{N<=X:lambda1(M_omega(N))<rho_N}=o(X/log X)。     (11)

这证明一套永久固定的全整数族，在密度一的指数上满足所给形状下界。它没有证明不存在例外，也没有给出例外全部出现在哪个有限范围内。所有素数幂由 (1) 的更强界保证，本身不会属于这里的坏集。

### 六个方向与运输的对应上界

对非例外指数，父笔记的 Minkowski 第二定理给出

    lambda6(M_omega(N)) <= C6*N^(1/6)*k(N)^(10/3),
    C6=(384/pi^3)*42^(5/2)。                           (12)

六个独立短向量所张子格的平行六面体舍入给出覆盖半径 <=3 lambda6。因此真实余类图直径和任意 N 个原点的平均无盒约束修复成本满足

    W(S_N,M_omega(N))/N
      <=3*sqrt(6)*C6*N^(1/6)*k(N)^(10/3)。             (13)

没有推出 O(1) 平均代价；也没有保留每次只增加一个 Cell 的嵌套代表或严格一步时间。形状良好的指数集未证明对乘法封闭；(2) 的实际代数兼容则仍对包括例外在内的全部指数成立。

## 4. 定理 D2：有限旧选择可以不回退地、有效地延伸

(11) 已给出存在性。下面再说明可以逐项定义一套永久选择，而不需要猜出一个无限随机实数。

把所有非平凡块按首次使用指数 p^(f_p r+1) 递增排列，跳过已冻结块；同值用固定字典序。有限上界内只涉及有限个块。每块 E、G 可通过精确有限枚举得到。

给定一个有限柱集 C 和下一个块 b，设 g=|G_b|。每个候选子柱集 C_e 的概率为 q_C/g。选择一个可计算的 K，使

    (K+1)/(32*K^2) / (q_C/g) <= epsilon_j,
    epsilon_j=2^(-j), j=1,2,...。                     (14)

H_K 只依赖有限个块，坏事件 (5) 也可精确决定，所以每个

    m_e=E[H_K | C_e]

可以通过有限整数/有理枚举计算。选取 m_e 最小的种子，同值按字典序，永久固定它。因为这些 m_e 的均值为 E[H_K|C]，(9)(14) 给出

    E[H | C_selected] <= E[H | C]+epsilon_j。           (15)

这一步不比较未经计算的无限实数，也不需要一个已固定种子以后被改动。对任何有限前缀，条件期望总预算至多 E[H|C_initial]+1。

对固定 L，充分长的种子前缀已经固定 H_L 所需的全部坐标，所以在最终种子序列 omega 上

    H_L(omega)<=E[H|C_initial]+1。

对 L 取上确界，H(omega)<infinity，故 (11) 成立；所有旧选择被保留。

这是有效可计算的存在性构造，不是实用算法。有限枚举可能极大，尾界还会除以越来越小的柱集概率。本轮没有运行此无限选择器的端到端实现，更没有生成无限种子表。程序实际执行的是下一节的有限成本扩展，不能把二者冒充同一个计算。

### 更一般的预算族

把 k^4 替换为 k^gamma，gamma>2，把 H 的权改成 k^beta，0<beta<gamma-2，同一证明给出例外计数 o(X/(log X)^beta)，以及 lambda1 的对数损失 k^(gamma/6)。本轮选 gamma=4、beta=1，目的是保留简单的有理尾界；不主张这些指数最优。
