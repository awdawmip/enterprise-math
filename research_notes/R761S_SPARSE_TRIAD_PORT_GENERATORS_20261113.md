## Theorem 1 — exact incidence/component classification

For every finite family E of 3-supports on I, G(E) is precisely the direct product of the alternating groups A_C on its support-hypergraph connected components C of size at least 3 (fixing singleton components). In particular, G(E)=A6 if and only if the support hypergraph is connected on all six ports.

**Proof.** Each cycle moves points only inside its own hyperedge/component and has even parity, so G(E) is contained in the componentwise product of alternating groups. To prove the reverse inclusion, order the edges of a connected component so that, after the first, each added edge meets the previously reached vertex set. Start with one triple: its two oriented cycles generate A3. If a new triple meets the old m-vertex set in two vertices and introduces one new vertex, the old A_m and the new cycle generate A_(m+1); the m=3 base case is checked directly on the four points (two 3-cycles sharing two points generate A4). For m>=4, conjugating by A_m moves the two old points through all ordered distinct pairs, producing all 3-cycles using the new point, which together with A_m generate A_(m+1). If the added triple meets the old set in exactly one vertex and introduces two new vertices b,c, A_m acts transitively on old vertices, so conjugation gives (i b c) for all old i. For distinct i,j, products (i b c)(j b c)^(-1) produce a 3-cycle involving i,j,b. These generate A_(m+1) on the old points plus b (with the m=3 base included); the original new triple then adds c by the preceding two-overlap case. An added triple entirely within the old set changes nothing. Induction yields A_C for every component, and disjoint component groups commute. QED.

## Theorem 2 — minimum supports for full A6

Two triple supports involve at most five different ports if their hyperedges intersect (otherwise they generate A3 x A3, not A6). Therefore at least three supports are necessary. Three suffice, for instance
