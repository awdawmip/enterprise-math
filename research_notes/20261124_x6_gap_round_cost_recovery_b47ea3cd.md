## 4. 新推论一：全部读取次数—批次数 Pareto 前沿

一个资源点受支配，是指另一个处处正确的协议在 Q、R 两个坐标均不更大，且至少一个严格更小。

**定理。** 全部不受支配的资源点为：

| P | 完整 Pareto 前沿 (Q,R) |
|---|---|
| 0 | (0,0) |
| 1–3 | (1,1) |
| 4–10 | (2,1) |
| 11–20 | (3,1)、(2,2) |
| 21–62 | (3,1) |
| 63 | (5,1)、(4,2)、(3,3) |
| 64–81 | (5,1)、(4,2) |
| 82–136 | (6,1)、(4,2) |
| ≥137 | (6,1)、(5,2) |

**证明。** R=1 与 R≤2 的最小 Q 已由上一节给出。除 P=63 外，至多两批已达到不限批数的最小读取次数 A(P)，所以增加批次不能产生新的不受支配点。P=63 时，三项完全顺序查询最多使用三批，故 (3,3) 可达；两批三项不可行，固定四项不可行，又排除了支配该表中三个点的可能。超过三批仍至少读取三项，因而被 (3,3) 支配。P=0 的候选集只有零；其余区间至少一次非空读取。证毕。

这给出了完整二维资源选择，而不是仅比较固定查询与完全自适应查询两个端点。

## 5. 新推论二：允许提前停机的精确最坏综合成本

设每项读取具有相同成本 \alpha>0，每批另有相同成本 \beta≥0。定义

\[
T(\mathcal A)=\max_{a\in\mathcal S_P}
  \{\alpha q_{\mathcal A}(a)+\beta r_{\mathcal A}(a)\},
\qquad
T^*(P;\alpha,\beta)=\inf_{\mathcal A} T(\mathcal A).
\]

这是统一单项费用、统一批次费用的模型。若将它解释为实际耗时，还须实测接口满足该计价形式；本式不计解码计算、输入构造和其它通信费用。下界允许每条分支不同长度及提前停止。

**定理。**

| P | T* |
|---|---|
| 0 | 0 |
| 1–3 | \alpha+\beta |
| 4–10 | 2\alpha+\beta |
| 11–20 | min(3\alpha+\beta, 2\alpha+2\beta) |
| 21–62 | 3\alpha+\beta |
| 63 | min(5\alpha+\beta, 3\alpha+3\beta) |
| 64–81 | min(5\alpha+\beta, 4\alpha+2\beta) |
| 82–136 | min(6\alpha+\beta, 4\alpha+2\beta) |
| ≥137 | min(6\alpha+\beta, 5\alpha+2\beta) |

### 5.1 一般区间的完整下界

令 F=F(P)、A=A(P)，且 B(P)=A。任取正确协议，设其首个非空批次大小为 k。

- k≥F：任一输入已经付出至少 \alpha F+\beta。
- A≤k<F：固定首批不足以辨识全部输入，故至少一个实际分支继续，且在该同一分支上 q≥k+1≥A+1、r≥2；其成本至少 \alpha(A+1)+2\beta。
- k<A：不限批数的读取下界保证至少一个分支 q≥A。因为首批不足 A，该分支 r≥2，成本至少 \alpha A+2\beta。

因此

\[
T(\mathcal A)\ge\min(\alpha F+\beta,\alpha A+2\beta).
\]

固定一批的最优策略与至多两批、A 项的策略分别达到这两个上界的较小值。若 F=A，固定策略直接达到 \alpha A+\beta。由此得到 P≠63 的全部行。

这里每个必要下界都落在同一个真实分支上，未假设最大读取次数和最大批次数必然发生于同一个输入。

### 5.2 P=63 的提前停机问题

此时 F=5、B=4、A=3。仍按首批大小 k 分类：

- k≥5：成本至少 5\alpha+\beta。
- k=3 或4：固定首批不够，某分支必须续读；该分支至少四项、两批，成本至少 4\alpha+2\beta。
- k=2：如果所有分支最多三项，首批两项后至多再有一项，即形成至多两批三项策略，与 B=4 矛盾。故某分支至少四项，且至少两批，成本至少 4\alpha+2\beta。
- k=1：若出现第三批，该实际分支至少三项、三批，成本至少 3\alpha+3\beta；若没有第三批，则全策略至多两批，必有至少四项的分支，成本至少 4\alpha+2\beta。

故每个正确策略都满足

\[
T(\mathcal A)\ge
\min(5\alpha+\beta,\,4\alpha+2\beta,\,3\alpha+3\beta).
\]

而

\[
4\alpha+2\beta=
\frac{(5\alpha+\beta)+(3\alpha+3\beta)}{2}.
\]

两个端点策略已可实现，所以

\[
T^*(63;\alpha,\beta)=\min(5\alpha+\beta,3\alpha+3\beta).
\]

因此，P=63 的两批四项方案仍是一个真正的 Pareto 点，但在线性成本下只有临界并列价值：

- \beta<\alpha：三项三批最优；
- \beta>\alpha：五项一批最优；
- \beta=\alpha：三种资源点均以 6\alpha 并列。

“最多允许两批”是另一种明确约束，届时两批四项仍然有独立用途。本推论没有否定它的批次上限价值。

### 5.3 全部成本切换点

P=11–20、64–81、≥137 的选择在 \beta=\alpha 切换。P=82–136 的选择在 \beta=2\alpha 切换；在该区间增加一批可以节省两项读取。

这完整解决了本节定义的线性最坏成本模型，无需再次枚举原候选空间。

## 7. 新推论三：保持待辨观察者即可转移策略

设完整源状态为 s，保留全部支路、符号、占用、环境及历史；设

\[
v(s)\in\mathcal S_P
\]

是本次要恢复的无向位移。源读取操作可以改变不影响 v 的内部状态，无须要求整个 s 冻结。

### 7.1 上界迁移条件

对所用策略实际要求的每个标签读取、批次以及批间合法变化，假设：

1. 标签 ij 的回执准确等于 d_{ij}(v(s))，并保留标签名称；
2. 每个可达后继 s' 满足 v(s')=v(s)，已知预算 P 与标签含义保持；
3. 一个批次的选择只依赖此前允许返回的信息；本批回执返回前不能改选本批；
4. 原策略需要的批次在相应状态合法，且读取／批次成本按同一口径计数。

**结论。** 原 gap 协议产生的每一步回执与固定 v(s_0) 下完全相同，故所有已证构造、读取上界和批次上界原样转移。

**证明。** 对读取／批次序列归纳。首步由条件1给出固定初始 v 的准确回执；条件2维持该 v，因而下一步仍读取相同目标。条件3保证下一批选择与原策略相同，条件4保证该操作可执行且计数不变。归纳至终点，原解码器恢复 v(s_0)。证毕。

这允许读取改变日志、资源指针或其他内部字段，只要其对本次观察目标的作用保持。完整源状态不能因此被统一压成 v；若后续问题使用那些内部字段，仍保留原记录和操作范围。

### 7.2 下界转移需要的额外条件

上界对 \mathcal S_P 的任意已知子集仍然成立；精确下界不会自动转移到较小源状态族。

若要继承完整最优值，还须证明：

- 源问题覆盖旧下界所需的全部候选／碰撞见证；覆盖全部 \mathcal S_P 是一个充分条件；
- 允许给算法的信息正是已知 P、具名 gap 回执及其历史，没有另一个更强观察量或通过查询合法性泄露状态的通道；

这里“信息与操作一致”须由统一的、保持目标和费用的交互模拟证明：旧 gap 算法在共同公开初始上下文中，仅用已允许回执即可逐步模拟源协议的完整可见历史与自适应后继。目标投影 s↦v(s) 本身不提供这个模拟器。模拟成立时，更便宜的源协议才会导出更便宜的旧协议，与下界矛盾。若源接口是同候选、同目标、同计价下的受限子模型，旧下界继续成立；旧上界则需另证其策略在受限接口中可执行。若增加主动控制或额外观察，需按实际接口重新判定下界。完整充分条件与反例构造见本轮下界深化稿。

### 7.3 Boolean-BRC 候选支路的精确过滤恒等式

对本次声明的支路总体 B⊆\mathcal S_P，收到标签 ij 的值 r 后，保留

\[
F_{ij,r}(B)=\{a\in B:d_{ij}(a)=r\}.
\]

同一目标上的批量读取满足

\[
F_{ij,r}\circ F_{kl,t}
=F_{kl,t}\circ F_{ij,r},
\qquad
F_{ij,r}^2=F_{ij,r}.
\]

因为两边都恰好保留同时满足相应回执的原候选。批次因此是有限 Boolean 支持载体上的交集过滤，保留候选身份；若原问题另外携带权重或 provenance，过滤其原条目而不将其替换为总量。
