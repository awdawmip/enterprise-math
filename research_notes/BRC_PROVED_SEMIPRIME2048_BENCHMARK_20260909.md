# BRC：六个经证明的 2048 位半素数与实际计时

本轮构造了六个特意满足既有捷径条件的半素数，每个乘积都恰为 2048 位。十二个因子分别通过 FLINT 的证明型素性接口；新进程从仅含 N 的输入中恢复的因子对，与这些素数逐一相同。Intel Core i5-4690K / Python 3.14.6 上，固定候选包的预热后单次平均成本中位数为 11.02–16.16 微秒。全部样本的构造及素性证明另耗时 32.5788586 秒。

这是有意构造的正例性能实验。它证明这些条件族可在该位数上快速处理，不估计随机 RSA 模数的命中率，也不构成公开 RSA-2048 挑战的分解。前四组因子位数为 1023/1025，后两组为 1022/1026；没有声称双方均为 1024 位或独立随机生成。没有生成实际 RSA 密钥。

## 六组样本

令 J=floor(sqrt(N))、R=N-J²、A=(J+1)²-N。D 表示 R<J，U 表示 R>J。以下 h 都由对应状态的残差计算，并经整除与乘积检查后返回。完整的十进制 p、q、N、J、R、A 保存在配套样本 JSON 中。

| 样本 | 状态 | 人工构造关系 | 命中的残差候选 h | p/q 位数 | N 位数 |
|---|---|---|---|---|---|
| case_01 | D | q=4p+5 | R+1 | 1023/1025 | 2048 |
| case_02 | D | q=4p+9 | R+4 | 1023/1025 | 2048 |
| case_03 | U | q=4p+7 | A−4 | 1023/1025 | 2048 |
| case_04 | U | q=4p+11 | A−9 | 1023/1025 | 2048 |
| case_05 | D | q=16p+11 | (R+1)/3 | 1022/1026 | 2048 |
| case_06 | U | q=16p+13 | (A−4)/3 | 1022/1026 | 2048 |

这里沿用前一记录的构造式：D 为 q=a²p+2ac+b，从而 J=ap+c、R=bp−c²；U 为 q=a²p+2ac−b，从而 J+1=ap+c、A=bp+c²。本轮预先固定的 (状态,a,b,c) 为 (D,2,1,1)、(D,2,1,2)、(U,2,1,2)、(U,2,1,3)、(D,4,3,1)、(U,4,3,2)。生成后逐项验证根边界、D/U 标签、p≠q、p*q=N 及位数。

六组旧中心 gcd(N,J*(J+1)−N) 都为 1，而残差修正都成功。这只描述本次规定正例，不能据此推算总体成功率。

## N-only 实际运算

复用既有 `brc_residual_candidate_families_20260908.py` 中的 `_complete(N)` 和 `_complete(N,gated=True)`。二者都运行先前固定的完整候选检查逻辑：b∈{1,3,5,7}，D 的 c∈{1,2,3}，U 的 c∈{2,3,4}；按奇偶性、商的整数性及适用条件过滤，并在验证一个真因子后返回。没有向查询提供实际命中的 b、c、a、状态、根或因子。

五个新 Python 进程仅打开单独的输入文件，其中每行只有不透明样本 ID 和十进制 N。每次查询接收一个 Python 整数 N。计时包含整数开方、两残差与状态准备、固定候选枚举、适用的筛选、可选根余数检查、divmod 与乘积复核；排除样本构造、素性证明、导入、文本解析、文件校验、进程启动和 JSON 输出。工作进程不导入 FLINT。查询源码在两轮研究之间没有改变。
