# R427｜signed BRC 行多项式三阶 Toeplitz：左端解析转正与有限行完整 PF₃ 证书

日期：2026-10-31。性质：AUTHOR_SIDE_EXACT / EXACT_INTEGER_CHECKED / DRIVER_UNREVIEWED / NOT_ADMITTED；研究对象仅为辅助 signed BRC 组合读出，不是原生 X6 动力学。P000 与 ACTIVE 世界观未修改。

## 定义和定理

对整数 r≥4，2≤s≤r，定义
\[
\delta_{r,s}=[t^r](1-t)(1+t)^{2s}(1+t^2)^{r-s},\quad H_{r,s}=\binom{r+s}{2s}\delta_{r,s}.
\]
记 a_j=H_{r,j+2}（0≤j≤r−2），其他整数 j 的 a_j=0。半无限 Toeplitz 矩阵为 T(r)=(a_{j-i})_{i,j≥0}。

**定理 A（无限参数解析结果）**：对
\[
L_r=\det\begin{pmatrix}a_1&a_2&a_3\\a_0&a_1&a_2\\0&a_0&a_1\end{pmatrix}
=a_1^3-2a_0a_1a_2+a_0^2a_3,
\]
有 L_4=−1568，且 **每个整数 r≥5 均严格 L_r>0**。这只处理左端一个特定三阶子式，并不证明所有三阶子式对任意 r 均非负。

**定理 B（有限行完整性）**：对每个 5≤r≤24，完整半无限矩阵 T(r) 的全部一、二、三阶子式非负，即该行系数序列为 PF₃。这里无限多个矩阵位置由下面的支撑引理归约为有限、确切枚举，不是任意窗口的有限采样。对 r≥25 尚无相同结论。

## 定理 A 的解析证明

原始 signed 卷积的 Catalan 核（R426 中证明，本轮从原始式交叉复算）为
\[
\delta_{r,s}=[z^r]z(1+2z)^{s-1}C(z^2),\qquad C(u)=\sum_{h\ge0}\frac{\binom{2h}{h}}{h+1}u^h.
\]
令 b_j=a_j/a_0（a_0>0）。只展开 s=2,3,4,5，并使用 Catalan 邻项比，可得以下均为精确有理多项式的表达式。

r=2k，k≥2 时：
\[
\begin{aligned}
b_1&=2(k-1)(2k+3)/15,\\
b_2&=(k-1)(k+2)(2k+3)(8k-9)/420,\\
b_3&=(k-2)(k-1)(k+2)(2k+3)(2k+5)(4k-3)/4725.
\end{aligned}
\]
代入 L_r/a_0^3=b_1^3−2b_1b_2+b_3，通分得到
\[
\boxed{L_{2k}/a_0^3=(k-1)(2k+3)(24k^4-36k^3-56k^2-31k-6)/23625.}
\]
记 x=k−3，括号恒为 24x⁴+252x³+916x²+1253x+369；所以 k≥3 时严格为正。k=2 时括号=−196，且 a_0=30，故 L_4=−1568。

r=2k+1，k≥2 时：
\[
\begin{aligned}
b_1&=(k+2)(4k+1)/15,\\
b_2&=(k-1)(k+2)(2k+5)(8k+5)/420,\\
b_3&=(k-1)(k+2)(k+3)(2k+5)(32k^2-16k-33)/18900.
\end{aligned}
\]
从而
\[
\boxed{L_{2k+1}/a_0^3=(k+2)(192k^5+1392k^4+5330k^3+10253k^2+10246k+4087)/94500>0.}
\]
最后一个不等式对 k≥2 显然成立。

这里两种等式的左、右侧均为 k 的次数不超过 6、只有常数整数分母的有理多项式。验证程序对每种奇偶式分别检查 k=2,…,8 七个不同整数的精确分数恒等式；次数界加七点严格证明这两条代数恒等式，对无穷多个 k 有效。配合 Catalan 系数展开即完成定理 A，独立于有限 r 样本的归纳外推。

## 定理 B 的完整有限证书和支撑约化证明

固定 r，设 n=r−2，则 a_j 只有 0≤j≤n 时可能非零。任取 h×h（h≤3）Toeplitz 子式，其升序行、列分别为 i_0<…<i_{h−1}、j_0<…<j_{h−1}。非零行列式需要存在一项非零的排列积，其非零边必须满足 0≤j−i≤n。对交叉的两条边 (i_p,j_q),(i_q,j_p)（i_p<i_q 且 j_p<j_q），若原边都合法，交换后 (i_p,j_p),(i_q,j_q) 仍合法：下界由 j_p≥i_q、j_q>j_p 保证，上界由 j_p<j_q≤i_p+n 保证。反复消除交叉，即得到 **排序后的对角匹配** 0≤j_l−i_l≤n；不满足者行列式为零。

若相邻行间距超过 n，其非零列支撑区间严格分离。该子式要么为零，要么按升序行列切割为较低阶子式的无符号乘积；故只需检查所有相邻行间距 1,…,n 的未分裂小块。Toeplitz 共同平移可把首行置 0，且排序列 j_l 必须在 [i_l,i_l+n] 中。这样，枚举 2×2 所有 (0,g) 与合法二列、3×3 所有 (0,g_1,g_1+g_2) 与合法三列，已经无遗漏地覆盖所有可能非零的未分裂子式。1×1 因所有非零 a_j>0 成立；分裂项由较低阶归纳为非负。

纯 Python 标准库整数脚本 R427_VERIFY.py 用上述条件做彻底判号：对 r=5,…,24 共检查 59,185 个 2×2 和 16,616,469 个 3×3 **未分裂且有排序匹配的**子式，均严格为正；其余零项和分裂项按引理均非负。因此这些行在完整半无限 Toeplitz 意义上都属于 PF₃。

精确程序另从原始 (1−t) 卷积对 r=4,…,512 的 a_0,…,a_3 与解析比值核对，并核对其 Catalan 核；这只是交叉验证而非无界定理的证明来源。输出证据 JSON 的 SHA256：a5700ce107294edb1fe1625bf6e5a8b8a5dc90d849bf97682e76074829826475。
