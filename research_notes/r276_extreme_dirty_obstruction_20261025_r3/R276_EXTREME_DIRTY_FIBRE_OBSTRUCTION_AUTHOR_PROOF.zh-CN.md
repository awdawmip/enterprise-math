# R276｜BRC 六通道：dirty 全域支配的无穷反例与边缘纤维精确公式

## 1. 研究对象及主定理

仅处理 R268—R275 的正权、原始有序二进制来源词、完整仿射效果 BRC 辅助自动机。从 q=0、(ε,k)=(+1,0) 出发，来源位 x 的转移 (q',η,b) 如下：

| q | x=0 | x=1 |
|---|---|---|
| 0 | (2,-1,-1) | (2,+1,-1) |
| 1 | (0,-1,-1) | (0,+1,-1) |
| 2 | (1,+1,+1) | (2,+1,-1) |

右侧有序仿射复合为 (ε,k)⋆(η,b)=(ηε,ηk+b)。包含相邻 00 的词为 dirty，其余为 clean。C_n^q(ε,k) 与 D_n^q(ε,k) 分别计数长度 n、终态 q、完整效果 (ε,k) 的 clean 和 dirty 词，均保留原始路径正整数重数。R275 的 P_n=C_n^0。

**定理 R276-A。** 对每个 n≥4，设 g_n^+=(+1,-(n-2))、g_n^-=(-1,-(n-2))。在固定通道顺序 [C^0,C^1,C^2,D^0,D^1,D^2] 下：

- 在 g_n^+，六通道计数精确为 (1,1,n-3,0,0,1)；
- 在 g_n^-，六通道计数精确为 (1,1,n-4,0,0,2)。

这给出无限多层真正的逐完整效果反例：尽管 P_n(g_n^±)=1，却有 D_n^0(g_n^±)=D_n^1(g_n^±)=0。故不存在 N 使 n≥N 时 dirty q0、dirty q1 对 **所有效果** 逐点支配 P_n。该障碍不否定仅在最大 P_n 效果上建立支配、进而 B_n=Λ_n 的可能性。

## 2. 可逆增量标记与一缺陷分类

定义 t=εk。对六条来源边逐项代入，若 ε'=ηε，则 Δt=t'-t=ε'b∈{±1}。所有 q 均满足同一个确定性表：

| 当前 ε | Δt=+1 的来源位 | Δt=-1 的来源位 |
|---|---|---|
| +1 | 0 | 1 |
| -1 | 1 | 0 |

从固定初态出发，每个增量序列 δ_1,...,δ_n ∈{±1}^n 唯一确定来源词，反之亦然。

在 g_n^+ 上，t=-(n-2)，故 n 个增量恰好有一个 +1。其出现位置 j∈[1,n] 是唯一自由选择：
- j=1：必为 0001^(n-3)，末 ε=+1，dirty，终态 q=2。
- 2≤j≤n：必为 1^(j-1) 0 1^(n-j)，末 ε=+1，全部 clean。唯一的 0 发生于 q2→q1。按 n-j=0、1、≥2，末态依次是 q1、q0、q2。

故全部 n 个词穷尽该效果，通道计数为 (1,1,n-3,0,0,1)。

在 g_n^- 上，t=+(n-2)，恰好有一个 -1，位置 j∈[1,n]：
- j=1：必为 1001^(n-3)，末 ε=-1，dirty，终态 q2。
- 2≤j≤n：必为 0 1^(j-2) 0 1^(n-j)，末 ε=-1。j=2 时为 001^(n-2)，dirty，终态 q2；所有 j≥3 的词 clean，且 n-j=0、1、≥2 时终态依次是 q1、q0、q2。

故六通道计数为 (1,1,n-4,0,0,2)。n=4 时 n-4=0 是正确的空区间边界。两类中已列出全部 n 个缺陷位置，来源位由 Δt 与当前 ε 唯一确定，故没有遗漏、重计或有符号抵消。这是适用于全部 n≥4 的解析分类证明，不依赖有限枚举外推。

## 3. 对 R275 之后研究的限定

R274 与 R275 的作者侧定理分别证明 clean q1 全长度支配 P_n、clean q2 在 n≥12 全长度支配 P_n。本轮说明不能照搬「对所有效果点态支配」去证明 dirty q0/q1 的非瓶颈性。应改研究 P_n 的峰值集合 S_n={g:P_n(g)=Λ_n}，其中 Λ_n=max_g P_n(g)。

精确剩余问题是：是否存在明确 N，使每个 n≥N **至少存在一个** g∈S_n，D_n^q(g)≥Λ_n 对 q=0,1,2 同时成立？配合已证明的 clean 支配才推出 B_n=Λ_n。此处“至少存在一个峰值效果”不能换为“所有效果”。
