## 范围及最终定理

沿用固定的15条有序前缀、8终端、严格正的有限 N=3 P/Q 双律概率树。参数 0<s_a,s_b<1/2；完整历史策略可用每个已观察的有序路径；压缩策略只见 z=(t,r)，r=P(h)/Q(h)，每次只能用即时独立随机数，不能持有隐藏种子。两律使用同一个策略，终止判定 D∈{P,Q}；观察者是两律各自完整的 (T,D) 联合分布，不观察终端 r。

定义 K*=sup_{s_a≠s_b} sup_{完整历史 π} inf_{共同压缩 σ} max(TV_P,TV_Q)/|s_a-s_b|，参数始终限于 (0,1/2)^2。

**定理（精确闭合）**：对全部实数参数及全部允许的行为策略 π，存在一个共同压缩策略 σ，使 P、Q 两律的完整停止时间分布分别**严格相同**，并且

    TV(L_P^π(T,D),L_P^σ(T,D)) ≤ |s_a-s_b|/48,
    TV(L_Q^π(T,D),L_Q^σ(T,D)) ≤ |s_a-s_b|/48.

这个统一系数不可再降低，因而 **K*=1/48**。证明中的另一结论：当下述残差 τ≥0 时，在固定前时间占用平均后甚至可以完全无损重现两律 (T,D) 分布；只有 τ<0 的方向需要终端校准。

## 1. BRC 路径残差的精确值

唯一非平凡的非终端压缩状态碰撞是 ax 与 bu，均处于 (t=2,r=1)。其原始 Q 到达上限分别为 1/4 和 1/8，令实际未决策到达质量 w_a∈[0,1/4]、w_b∈[0,1/8]；由于 r=1，这两质量在 P 下相同。两个后继 Q 核为 q_s=(s,1−2s,s)，后继 r=(1/2,1,3/2)，继续概率为 c_a、c_b。

在真实非对角概率树上，于 t<3 的每个压缩状态使用原策略的 Q 到达质量平均的同一随机动作核。这对其它状态精确复制，对碰撞状态以 w_a,w_b 加权；因此所有 t≤2 的双律 (T,D) 质量精确保留。

令 k=w_aw_b/(w_a+w_b)（总质量0时定义 k=0），τ=k(c_a−c_b)(s_b−s_a)。按 t=3 的同一 r 汇总的 Q 到达质量从 m_old 变为 m_new，满足

    (m_new−m_old)_{r=1/2,1,3/2} = τ (1,−2,1).      (1)

r=1/3、2 的其它到达质量未改变；对应 P 质量变化是各分量乘 r。两律的总 t=3 质量均不变，因为 1−2+1=0 和 1/2−2+3/2=0。由 xy/(x+y) 对两个非负变量单调及 w_a≤1/4,w_b≤1/8 得 0≤k≤1/12，故 |τ|≤|s_a−s_b|/12。

## 2. 新的终端 zonotope 凸序修复证明

终端同一 r 的 Q 到达质量为 m_r。若压缩策略在该终端状态以概率 x_r∈[0,1] 判定 Q，则 (Q(T=3,D=Q), P(T=3,D=Q)) 的完整可达集合为二维紧凸集

    Z(m) = { sum_r m_r x_r (1,r) : 0≤x_r≤1 }.

原完整历史策略即便在同一 r 下使用不同叶行动，按原 Q 到达质量平均后，其旧目标向量也属于 Z(m_old)，因为在该 r 下的 P 到达质量恰为 Q 质量的 r 倍。任意 Z(m_new) 中的点都能以终端即时独立随机核实现。

对所有实数法向 (u,v)，其支持函数为 h_m(u,v)=sum_r m_r [u+v r]_+，其中 [x]_+=max(x,0)。由式(1)精确得到

    h_new(u,v)−h_old(u,v) = τ Φ(u,v),              (2)
    Φ(u,v)=[u+v/2]_+−2[u+v]_++[u+3v/2]_+
          =( |v|/2 − |u+v| )_+ ≥0.               (3)

此外 **Φ(u,v)≤(|u|+|v|)/4**。验证：若 |u+v|≥|v|/2 左端为0；否则令 z=|u+v|<|v|/2，由 |u|≥|v|−z 可得 4Φ=2|v|−4z≤2|v|−z≤|u|+|v|。u=−v≠0 处常数1/4尖锐。

若 τ≥0，则对所有法向 h_old≤h_new，故 Z(m_old)⊆Z(m_new)：不需要终端误差。若 τ<0，由式(2)及以上不等式，设 ε=|τ|/4，得到

    h_old(u,v)≤h_new(u,v)+ε(|u|+|v|)  对每个(u,v)成立。

L∞ 单位正方形 B∞=[−1,1]^2 的支持函数为 |u|+|v|，故由紧凸集的支持函数包含定理得

    Z(m_old) ⊆ Z(m_new) + (|τ|/4) B∞.          (4)

因此可选择**同一**终端压缩判定概率 x_r，使双律两个终端 Q 判定质量各自误差≤|τ|/4。上述选择只是有限二维凸可行性问题，无额外记忆或潜在跨时种子。由于两律 t=3 总停止质量分别精确保留、其它所有时间 (T,D) 质量也精确保留，各律整个终止联合分布的 TV 恰等于自身终端 Q 判定质量的绝对误差，故

    TV_P,TV_Q ≤ max(0,−τ)/4 ≤ |τ|/4 ≤ |s_a−s_b|/48.

这证明对全部实数历史行为策略成立的全参数上界；有限程序不是这项普遍证明的替代物。

## 3. 独立核对已公布下界，闭合 K*

在 (s_a,s_b)=(2/5,1/3)，已公布的历史策略 π* 在 root,a,b,ax,bv 继续；ay 判定 P、bu 判定 Q；终端 axL,axM,bvT 判定 Q，axH 判定 P。对偶函数为

    J = 90 P(T=2) + 90 P(T=3,D=P)
        +17 Q(T=2) + 90 Q(T=3,D=Q).

所有共同压缩策略均满足 J≤985/8，但该完整历史策略达到 987/8。压缩碰撞处 stop 的最大贡献为 90×107=9630 （以 Q 根质量分母240计），两个历史共同 continue 也是 60×108+30×105=9630；非碰撞 ay 与 bv 最大分别为 60×197=11820 和 90×90=8100，因此压缩上界为 (9630+11820+8100)/240=985/8。完整历史可在 ax continue、bu stop 得 60×108+30×107=9690，从而达到987/8。t<2 的提前停止对 J 得0，后续所有收益非负；随机策略的目标对局部动作核分别仿射，因此纯 Bellman 上界覆盖任意实数随机化。

两律在 J 内对应的有界终止函数振幅各为90，故差距1/4意味着对任意压缩策略有

    1/4 ≤ 90 TV_P + 90 TV_Q ≤ 180 max(TV_P,TV_Q),

即 maxTV≥1/720；而 |s_a−s_b|=1/15，推出 K*≥15/720=1/48。与上一节上界相合，**K*=1/48**。在该见证下 w_a=1/4,w_b=1/8,c_a=1,c_b=0，τ=−1/180；式(4)的误差正是1/720，且已有合法压缩随机核达到该值。此为全参数、全历史策略、全压缩器量词下的精确常数，而不仅是某一预设算法的尖锐性。
