## 定理 A：单整数最优阶单词键

对十二字母自由幺半群 A*，定义正整数
[
C(\varepsilon)=1,\qquad C(wi)=12C(w)+(i-1),\quad i\in\{1,\ldots,12\}.
]
写 m=|w|，d_r=i_r−1∈{0,…,11}，则
[
C(w)=12^m+\sum_{r=1}^{m}d_r 12^{m-r},\qquad 12^m\le C(w)<2\cdot 12^m.
]
可直接以 C 的十二进制 `1 d₁ … d_m` 作为自定界源键。逆解码：当 C>1，反复取 `d=C mod 12`，令 `C=floor(C/12)`，逆序恢复 `i=d+1`，直至 C=1。故 C 在所有有限词上单射，且一次追加仅作 `×12+(i−1)` 的精确整数更新。对任意 u,v，
[
\boxed{C(uv)=12^{|v|}(C(u)-1)+C(v).}
]
长度 m 的码字共有 12^m 个，占用至多 `ceil(m log₂12)+1` 位（m=0 为1位），而任何对固定长度 m 的全部词均单射的二进制定长标签都至少需要 `ceil(m log₂12)` 位。本构造至多多 1 位，不依赖浮点、随机碰撞假设或不定精度截断。

**证明。** 迭代仿射递推得到进位表示和上下界。模12给出唯一尾字母，整数除12逐次收缩至唯一的首位标记1；由此得到单射。把 u,v 的基数表示拼接即得复合律。按鸽巢原理 12^m 个不同词要求至少 12^m 个不同定长比特串，得到位数下界。■

注意 C 是记忆标签而非原生第七空间坐标；其位长随词长线性增长，实际任意精度整数乘除开销必须计入具体工程预算。

## 定理 B：冻结 BRC 中的精确同系数排列纤维

固定两种不同的非零冻结支路 K_a,K_b (a≠b)，整数 n≥1，令 s=n(a+b)。设
[
\mathcal W_{a,b,n}=\{w: |w|=2n,\;\#_a(w)=\#_b(w)=n\}.
]
这一族恰好有 `binom(2n,n)` 个合法层级消耗为 s、终端为 B₀ 的有序来源词。**每个词**在 U_s 中的 signed 多项式贡献均等于
[
\boxed{P_{a,b,n}(t)=(K_a(t)K_b(t))^n B_0(t).}
]
故交换支路位置而不改变计数，所有依赖交换型变量的来源总权、类型门、次数向量与静态 B/D 线性标量观察，都将这一族的不同词合并。在将各字母可交换化的形式观测中，该来源类别的合并系数为
[
\boxed{\binom{2n}{n}(K_aK_b)^n B_0.}
]

**证明。** 将 n 个 a 和 n 个 b 任意排序，前缀消耗均为正且总消耗 s，因此在冻结来源递推树里，每个排序对应唯一一条合法到达 B₀ 的历史。交换型标量环 `Z[t]` 中 K_a 与 K_b 可交换，乘积与排序无关。合并类别的系数等于单项系数乘词数。■

取冻结原始 a=1、b=2，单对来源系数为
[
(K_1K_2)B_0=-2t+3t^2+25t^3+32t^4+12t^5.
]
当 n=2 时，层级 s=6 中恰有 6 条不同的四步来源历史，具有同一 signed 贡献 `(K₁K₂)²B₀`。这把 R612–R615 看到的两条历史同贡献现象扩展为任意 n 的精确指数规模排列纤维。
