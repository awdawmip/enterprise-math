## 2. Order alone cannot select a midpoint

A midpoint selector would have to depend only on the ordered interval and therefore be invariant under every order automorphism that fixes its endpoints.

Consider the ordered interval `[0,1]` with only its order retained. There are increasing order automorphisms fixing `0` and `1` that move `1/2`. For example, any strictly increasing piecewise-linear bijection of `[0,1]` fixing the endpoints but sending `1/2` to `1/3` preserves the complete order relation.

Hence no interior point is distinguished by the order structure alone.

Equivalently, if a rule

\[
M(a,b)\in(a,b)
\]

were definable solely from the order and natural under order isomorphism, then every endpoint-fixing order automorphism `f` would satisfy

\[
f(M(a,b))=M(f(a),f(b))=M(a,b).
\]

But an endpoint-fixing order automorphism can move any proposed interior point. Contradiction.

Therefore

\[
\boxed{
\text{LINEAR ORDER + ENDPOINTS DOES NOT CANONICALLY DETERMINE A MIDPOINT.}
}
\]

The same argument excludes a canonical dyadic subdivision generated from order alone.
