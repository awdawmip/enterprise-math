## 2. 先限制到可实现关系像

沿用原同一 unit-capacity 模型、分组 A={0,1}, B={2,3}，令

```text
W(c) = (c0-c2, c0-c3, c1-c2, c1-c3)
K_A = {(a,-a,b,-b): a,b are integers}
g_a = (1,1,-1,-1),  g_b = (-1,1,-1,1)
L = W(K_A) = Z g_a + Z g_b
```

所有 W(c) 都满足 w1+w4=w2+w3，故落在秩三的整数群

```text
H = {w in Z^4 : w1+w4=w2+w3}.
```

反之，对任意 H 中的 w，取 c=(w1,w3,0,w1-w2)，直接得到 W(c)=w。因此 im(W)=H；该限制不是样例观察。

定义 r(w)=w1-w2-w3+w4。r:Z^4→Z 满射、ker(r)=H，且 r(e1)=1，故 Z^4=H⊕Z e1。由于 L⊂H，原环境商确实多保留一个不属于可实现像的自由方向：

```text
Z^4/L ≅ (H/L) ⊕ Z.
```

## 3. 实际商恰为一个自由坐标与一个二阶剩余

定义

```text
u(w) = w2+w3 = w1+w4,
tau(w) = (w2-w1) mod 2.
```

两者都在 L 上为零。映射 (u,tau):H→Z⊕Z/2Z 满射：给定整数 u 和 tau∈{0,1}，可取 w=(tau,0,u,u-tau)。

若 u=0 且 tau=0，则 w3=-w2、w4=-w1，且

```text
a=(w1+w2)/2, b=(w2-w1)/2
```

为整数，并有 w=a g_a+b g_b。因此其核恰为 L，得到

```text
H/L ≅ Z ⊕ Z/2Z,
Z^4/L ≅ Z^2 ⊕ Z/2Z.
```

这里除以2仅用于满足已证偶性条件后的纸面整数表示，并未引入新的原生求值算子。若实现此证明，应继续使用现行精确整数/规范 DIV 合同。

在实际 c 上，u=(c0+c1)-(c2+c3)，tau=(c2-c3) mod2=(c2+c3) mod2。可见两不变量均由粗分组总量决定。在一个固定粗状态内，完整的 H/L 类也固定。

## 4. 商类不决定细代表的四重支持真值

对具体细状态，令 Q_R(c) 表示四个交叉关系均满足 |w_i|≤R。原见证保留：

```text
c+ = (5,5,5,5),  W(c+)=(0,0,0,0);
c- = (0,10,0,10), W(c-)=(0,-10,10,0).
```

二者的粗总量都是 (10,10)，且

```text
c- - c+ = (-5,5,-5,5) ∈ K_A,
W(c-) - W(c+) = -5 g_a -5 g_b ∈ L.
```

因此它们在 H/L 以及 Z^4/L 中同类，但 Q_0(c+) 为真、Q_0(c-) 为假。结论比“一个粗交叉标量不够”更精确：任何仅依赖这整个商类的函数，都不能恢复该细代表的 Q_0 真值。

这并不证明任意允许读取细状态的编码至少需要两个标量；例如一个特定 Boolean 查询可以直接保存其真值。保留“隐藏像秩二”的事实，必须与“最小语义编码维数”分开。原四重 guard 也不能未经降维证明便套用 rank-one 单带纤维公式。
