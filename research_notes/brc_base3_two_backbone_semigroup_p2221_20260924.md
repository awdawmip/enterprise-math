- if L does not cancel q=853, then `a(A) <= a(L)` coordinatewise;
- if L cancels q=853, then `a(A)+a(C) <= a(L)` coordinatewise.

Consequently the two-generator semigroup generated by A and C dominates every admissible atom in the complete `3|L` sector.

#### Proof

If L does cancel 853, the sum `a(A)+a(C)` is negative on every row of `U_3`: A supplies every row except 853, while C supplies 853 (and supplies an additional negative copy at q=13). QED.
