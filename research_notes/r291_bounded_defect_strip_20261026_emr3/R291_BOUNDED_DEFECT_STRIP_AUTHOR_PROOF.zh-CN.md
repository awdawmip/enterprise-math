## 2. 本轮严格支配带（无限参数、有限缺口）

对 `ε∈{+1,-1}`，令

```text
Δ_m^ε(x) = Σ_{n≥0}[P_n(ε,-m)-P_n(ε,-m-2)]x^n = x^(m+2)G_m^ε(x²).
```

**本轮经精确有限证书核定，**

```text
For every integer m ≥ 11 and 0 ≤ j ≤ 50,000:
    P_(m+2+2j)(-1,-m) > P_(m+2+2j)(-1,-m-2).

For every integer m ≥ 13 and 0 ≤ j ≤ 50,000:
    P_(m+2+2j)(+1,-m) > P_(m+2+2j)(+1,-m-2).
```

**量词边界：** `m` 没有上界；`j` 有有限界 50,000。因此这是无限多个 `(n,m)` 的精确严格支配关系，但**不是**固定 `m` 对全部 `n` 的非负性证明，也不是全局峰值证明。

此前 R290 仅核对两个关键基底的 `0≤j≤400`。本轮将该精确检查范围扩大至 `0≤j≤50000`，并明确利用正权一阶传播，将有限系数证书推广至无限多个平移参数 `m`。这里不将 R288 的一阶传播本身冒称新发现；新证据是更大的严格正性带和独立的线性复杂度无界整数校验程序。

## 3. 无限 m 传播的形式证明

根据 R290 已验证有限范围且作者侧代数推导完整的核公式（原始来源推广仍待独立审查），在 `y=x²` 下，取非负整系数级数

```text
h = y⁴+(y+2y²+y³+y⁴)h+y(1+y)²h²,
w=(1+y)(1+h)∈ℕ[[y]],  w(0)=1.
G_m^- = w^(m-1)(1-yw)/(1+y), m≥2;
G_m^+ = w^(m+1)(1-y+y²-yw)/(1+y), m≥1.
```

直接相除即得既有一阶传递关系 `G_(m+1)^ε=wG_m^ε`。因为 `w∈ℕ[[y]]` 且常数项为1，对基底 `(m_-,m_+)=(11,13)`，任意 `m≥m_ε`、任意 `j≤50000`：

```text
[y^j]G_m^ε = Σ_(a=0)^j [y^a]w^(m-m_ε) · [y^(j-a)]G_(m_ε)^ε
            ≥ [y^j]G_(m_ε)^ε >0.
```

于是若两个固定基底在 0..50000 各个整数系数均为正，即可推出第2节的无限 `m` 带状定理。该证明没有使用极限、浮点数，也不需要扫描无穷多个 `m`。

## 4. 有限底座的独立精确系数证书

为避免 `h` 的 O(J²) 卷积迭代，本轮复用 R285 的代数微分递推（全程 JavaScript BigInt）。设

```text
g(y)=sqrt((1-3y+y²)/(1+y+y²)),    f_n=−[y^n]g,
f_0=−1,   f_n=0 for n<0.
```

由精确微分恒等式（见 R285），对所有 `n≥0`：

```text
(n+1)f_(n+1)=(2n−2)f_n+(n−1)f_(n−1)+(2n−2)f_(n−2)−(n−3)f_(n−3).
```

设 `A=1+2y²−y³`、`C=1−y³`、`E=(1−y)(1−3y+y²)`，精确有

```text
w(y)=[A−Cg]/(2y).
```

定义多项式 `P_0=1,Q_0=0`，递推

```text
P_(r+1)=A P_r−E Q_r;
Q_(r+1)=A Q_r−C P_r.
```

因为 `C²g²=(1−y)²(1−3y+y²)(1+y+y²) / (1+y+y²)=(1−y)²(1−3y+y²)`，且此处 `E=(1−y)(1−3y+y²)`，我们应检查 `C²g²=CE`：`C=(1−y)(1+y+y²)=1−y³`，于是 `C²g²=C·E`，代入展开正确。
故恒等式 `(A−Cg)^r=P_r+Q_rg` 对全部整数 `r≥0` 成立。**这给出有限多项式滤波器与单条整数递推，不需要 O(J²) 大整数乘积。**

两个基底的精确公式为

```text
(1+y)G^-_11 =
[2P_10−P_11+(2Q_10−Q_11)g] / (2^11 y^10).

(1+y)G^+_13 =
[2(1−y+y²)P_14−P_15+
 {2(1−y+y²)Q_14−Q_15}g] / (2^15 y^14).
```

程序逐个生成 `j=0..50000` 的 `H_j=[y^j](1+y)G`，要求所有分子严格被所列 `2^11` 或 `2^15` 整除，再通过 `G_j=H_j−G_(j−1)`（`G_-1=0`）计算两组**全部**基底系数。所有 **100,002 项**均严格正；每组最小值为1，未发现零或负值。每组终点 `j=50000` 的数都有20,894个十进制数字（证据 JSON 保留前后48位，避免冗余复制所有超长数字）。
