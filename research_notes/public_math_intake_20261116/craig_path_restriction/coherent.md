## 相干读出的尺度极限、刚性及最佳近似

沿用 [PREFIX-436 的第一个有向方格模型](https://github.com/awdawmip/enterprise-math/blob/c4d450536bf71ed87fd74555295ec60485262f0a/research_notes/portable_direct/2026-11-02_prefix436_signed_x6_c4_holonomy_and_q_lucas.md) 和[上一轮的均匀标签群扩张](https://github.com/awdawmip/enterprise-math/blob/c80629763b20a2737ec02c67c036b957fe0256c4/research_notes/public_math_intake_20261116/CRAIG_LATTICE_REFINEMENT_C4_PATH_RESPONSE.md)。只动 X6 中选定的两轴，从同一原点到细终点 (m,m)，端口及方向固定。令 M=m²。每条最短有序步词包含 m 个横步和 m 个竖步，K(w) 记录横步出现在竖步之前的有序对数，取 0,…,M。每个竖步的相位分箱增量等于它出发时的横坐标，水平步保持分箱。不同末步分支的相同分箱按重数合并。分支权是非负实数。复值字符是单独的辅助观察。本节研究归一化相干和，并保留各标签原有的字符意义。

令 r_M 是正向循环次序中单位圆上紧随 1 的 8M 阶单位根，q=r_M²，s=r_M^M=(1+i)/√2。于是 q^M=i，各尺度使用相容选根。这是对有限相位标签的顺序和取值的说明，计算不调用三角函数。

### 1. 等权的全部细路径趋向哪一个相干读数

全部路径等权时记 Z_m=E[qᴷ]，定义 T=2K−M。反序映射把 K 换为 M−K。因此 Z_m=s(1−δ_m)，其中

    δ_m = E[1−Re(r_M^T)] = E[|1−r_M^T|²]/2。

各层方向都是 s，尺度改变体现在模长。两个旧端点路径的等权读数恒为 Z_old=(1+i)/2=s/√2。

**全尺度界及首项。** 对每个正整数 m 都有

    (2m+1)/(24m²) ≤ δ_m ≤ (2m+1)/(6m²)。

存在可用实分圆数有理区间逼近的常数 C，使

    m·δ_m → C/3，
    |Z_m−Z_old| → 1−1/√2。

下面给出逐项误差与证明。

**弦长。** 令 r=r_M。对 0≤t≤M，有

    t/(2M) ≤ |1−r^t| ≤ t/M。

因为 r^(2M)=i，且 1,r,…,r^(2M−1) 都在闭第一象限，每项在单位对角线 s 上的正交投影至少 1/√2，和的模至多 2M、至少 2M/√2。几何级数与 |1−i|=√2 给出 1/(√2 M)≤|1−r|≤1/M。再次用于 t 项的几何级数即得所需弦界。负 t 共轭后模相同。上一轮已证 V=E[T²]=m²(2m+1)/3。将弦界平方后取期望得到全尺度界。对所有 m，Re(r^T)≥1/√2，因此 Z_m 的方向定义明确。

**四阶矩。** 令 F(z)=Σ_w z^K。在两种末步之间作 BRC 分支分解，F_(a,b)=F_(a−1,b)+z^a F_(a,b−1)，边界为一。由递推或代入检查，F_(m,m)=∏_(j=1)^m [m+j]_z/[j]_z，其中 [a]_z=Σ_(k=0)^(a−1)z^k。为避免在单位根处除零，以下只在 z=1 进行有限代数求导，所有 [j]_1=j。记 D=z d/dz，D⁴ log F 在 1 的值为 K 的四阶累积量。用从 0 至 a−1 的均匀权计算，[a]_z 的二阶累积量为 (a²−1)/12、四阶为 −(a⁴−1)/120。后者直接由 Σkʲ（j≤4）求四阶中心矩后减去三倍方差平方可得。将四阶式在分子分母间相减，并用 Σ[(m+j)⁴−j⁴]=m³(2m+1)(3m+2)，得到

    E[T⁴] = 3V² − (2/15)m³(2m+1)(3m+2)。

**可复算的首项。** 置 c_M=M²|1−r_M|²，弦界给出 1/2≤c_M≤1。单位根 u 与非负整数 t 满足

    t²−|Σ_(j=0)^(t−1) uʲ|²
    = (1/2)Σ_(j,k=0)^(t−1)|uʲ−uᵏ|²
    ≤ |1−u|² t²(t²−1)/12。

最后一步用 |uʲ−uᵏ|≤|j−k|·|1−u| 后对平方求和。用 t=|T|，乘 |1−r_M|²/2，得

    0 ≤ c_M(2m+1)/(6m²)−δ_m ≤ (E[T⁴]−V)/(24M⁴)。

现取任意正整数倍 L=dM。相容选根给出 r_L^d=r_M，从而 c_M=c_L |Σ_(j=0)^(d−1) r_L^j|²/d²。用同一有限和不等式及 |1−r_L|≤1/L，可得 0≤c_L−c_M≤1/(12M²)。令 C=sup_N c_N，对任意 M,N 取 L=lcm(M,N)，即有 0≤C−c_M≤1/(12M²)。这给出了不依赖细化序列的极限和显式截断误差。特别地，

    0 ≤ C(2m+1)/(6m²)−δ_m
      ≤ (2m+1)/(72m⁶)+(2m+1)²/(72m⁴)。

右侧是 O(m⁻²)，由此得到上述首项。所有常数均来自有限循环标签的复数字符与 BRC 有序步词分布。没有引入原生物理相位或实数场演化。

### 2. 任意重新加权，哪些细路可以精确保住旧读数

保持每条路径自己的相位 qᴷ，令细路径带任意非负权重，总和为一。记 Z 为相干读数，p 为 0<K<M 的总权重，即两条旧有序路径之外的细路径权重。m≥2 时，给定 p 的最小误差为

    min |Z−Z_old| = p[Re(q)+Im(q)−1]/√2。

这里允许部分细路赋零权。若要求每条细路严格正权，该式依然是 p∈(0,1) 时的下确界。中间支路都有正权时通常不能达到等号。本模型 m≥2 时 M≥4，存在不在端点或近端点的中间支路，故在全支撑条件下无法达到该下确界。精确保持原 Z_old 要求 p=0、两条旧路各占 1/2。下文还可计算每条支路有正下界时的精确代价。

**证明。** 所有 z=q^K 均在闭第一象限的单位圆弧上。令 f(z)=Re(z)+Im(z)。两端点的 f 都是 1。内部点 z=a+ib 满足 a,b>0、a²+b²=1，所以 f(z)>1。f(z)/√2 是单位对角线 s 方向的投影。对内部格点，f 的最小值取在 K=1 或 M−1。可从 (f(z))²=1+2ab 验证：走向中点直至 a=b，a−b 单调减至 0，故 ab=[1−(a−b)²]/2 单调增。另一侧由 k↔M−k 对称。于是任意 Z 的投影比 Z_old 的投影至少多 p[f(q)−1]/√2。给端点 K=0,M 各权 (1−p)/2，给 K=1,M−1 各权 p/2，两边对称，差向量平行 s，恰取该下界。这四种路径实际存在，其中 K=1 可用 Y^(m−1) X Y X^(m−1) 实现，其反序给 K=M−1。

该极小误差还有直接的有理尺度界。令 t=r_M，则

    [Re(q)+Im(q)−1]/√2 = √2·Im(t)·[Re(t)−Im(t)]。

因 Re(t)≥1/√2，得到 Im(t)=|1−t|√[(1+Re(t))/2]≥1/(2M)。m≥2 给 M≥4，|1−t|≤1/M，Im(t)≤1/M，Re(t)≥1−1/(2M²)，从而 Re(t)−Im(t)>1/2。故极值严格大于 p/(4M)（p>0），至多为 2p/M。因此即使 p=1，只用新增细路，以近端点支路对称配权也可用 O(m⁻²) 误差逼近旧相干值。若全部细路均匀，则 p→1，但第 1 节证明了读数与旧值保持正的极限距离。这区分了“赋给新增支路的权重总量”和“权重落在哪些有序支路”。

**每条新增细路都必须有可比较权重时的精确代价。** 设 B=binom(2m,m)，要求每条细路的权重至少 λ/B，其中 0≤λ≤1。令 U 为全部细路的均匀分布，P=1−2/B 是其中分给内部标签的质量，D=|Z_m−Z_old|，g=[Re(q)+Im(q)−1]/√2。给定内部总质量 p 时可行域恰为 λP≤p≤1−2λ/B。将每条支路的 λ/B 从其权重中扣去，余下质量为 1−λ，其中内部质量为 p−λP。前述对角线投影证明同时给出精确值

    min |Z−Z_old| = λD + (p−λP)g。

均匀底权的偏移已经平行 s，剩余内部量对称放入 K=1,M−1，剩余端点量等分，恰取等号。若只固定 λ 而允许选择 p，极小值就是 λD。故全部细路各自至少获得均匀权的固定比例 λ>0 时，误差下确界趋于 λ(1−1/√2)>0。只要求每条路有正权则可令 λ 随 m 或随给定的逼近精度趋零。这一差异可精确量化，分支数多本身不构成正的尺度极限误差。

更多信息可从粗响应的公开线性分离式保留。由于 z=q^K=a+ib，f(z)−1=2ab/(a+b+1)。在本象限有 b=|1−z|√[(1+a)/2]≥|1−z|/√2。应用前述弦界于 t=2k 对 0≤2k≤2M 仍成立（第一象限投影的原证明覆盖至 2M），得到 Im(q^k)≥k/(√2 M)，并由反序对称得到 Re(q^k)≥(M−k)/(√2M)。于是任意细路概率分布都给出

    |Z−Z_old| ≥ E[K(M−K)/M²] / [√2(1+√2)]。

支路数保留在 [signed_brc.py 的 shortest_path_multiplicity](https://github.com/awdawmip/enterprise-math/blob/c4d450536bf71ed87fd74555295ec60485262f0a/experiments/x6_signed_native_spatial_v16_20260905/signed_brc.py)，有序面积、辅助字符及其可复合的按箱观察来自上述扩张。等权分布与近端点再配权分别是本节声明的两种外加观察条件。读出下降并不授予共享任务、原生动力学或物理归因。

### 复算范围

配套的 check_coherent.py 固定核对原 BRC 模块的 Git blob，整数直方图逐层计算 m=1,…,32，复核 11,472 个分箱、两端与近端的唯一路径性，以及二、四阶矩。m≤8 还按竖步位置子集独立枚举。对 m=1,2,4,8 的精确字符比较仅用分数区间、整平方根和分圆半角的代数恒等式，再对读数、余项界以及最优证书的正值及量级作包围检查。有限检查中的 δ 区间为 m=1 时 [292893218,292893219]/10⁹，m=2 时 [123004562,123004563]/10⁹，m=4 时 [56436867,56436868]/10⁹，m=8 时 [26966769,26966772]/10⁹。全尺度结论另由上文恒等式和不等式证明。
