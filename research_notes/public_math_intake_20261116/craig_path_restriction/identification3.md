# 从有限层确定极限读数：刚性、最坏误差和有限尺度修正

进取数论，2026-11-16。研究笔记，含证明与有限复核，待独立审阅。接续[来源删步模型](README.md)。在 X6 两条固定正轴上，每层的有序最短路径由 N 个 X 和 N 个 Y 组成。μ_N 是这些路径的概率分布。给定一条细路，分别从两类原始位置等权选 k 个，按原顺序保留。假定每层都能由任意更细层这样得到。保留的原始位置区分各 BRC 来源。

A_N 是路径中 X 先于 Y 的有名步对占全部 N² 对的比例。χ(x) 从 1 沿第一象限单位圆弧到 i，在 x=j/m 时取正向 4m 阶单位根的 j 次幂。Z_N=Eχ(A_N) 是本研究选定的辅助读数。Craig 的格点研究提供了逐层比较并控制修正的思路。下列概率核、极限与误差的论域是上述二色辅助模型。平衡二色词的均匀删步核及其极端边界已有 Choi–Evans 的完整描述。Hàn、Kiwi、Pavez-Signé 研究了由短子词计数检测词的均匀性。经典的矩匹配和最佳逼近对偶可见 Wu–Yang §2.2。本工作把这些工具应用到完整粗层观测、辅助相位以及有限层的可复算误差。[Craig](https://arxiv.org/abs/2610.09093) · [Choi–Evans](https://arxiv.org/abs/1605.03512) · [Hàn 等](https://arxiv.org/abs/2003.03664) · [Wu–Yang](https://arxiv.org/abs/2104.07317)

## 二层何时定出全部路径概率

令 p=μ₁(XY)，d=μ₂(XXYY)+μ₂(YYXX)，h=1−√(1−2|p−1/2|)。可实现的精确区间是

    d_min(p) = 1/3 + 2h² − 4h³/3 ≤ d ≤ 1。

上、下边界的每一点都唯一决定整座相容塔。上边界是两种完全分离路径的混合；下边界由带早段和晚段的唯一排序模型实现，且 Z_∞=χ(p)。例如 p=7/8、d=2/3 给出有偏的唯一模型。只知道 d=1/3 也强制 p=1/2 和所有层全部路径等权，此时 Z_∞=(1+i)/√2。任一严格内部点、任一事先指定的 k，都存在一对全支撑塔具有该坐标，在前 k 层逐个词完全同概率，极限相位却不同。完整边界、可行域构造以及反例见[二层分类](witness3.md)。

这个分类也能用于有限精度数据。记 μ_k* 为相同 p 的下边界模型，g_h(t)=min(2t,h,2−2t)，σ=sgn(p−1/2)。在 Choi–Evans 的极端排序分量中，令 F,G 为两类位置的分布函数，F+G=2t，D=F−G。由两次有名抽样的计数关系 E∫D dt=p−1/2、2E∫D²dt=d−1/3；这里期望包含极端分量的混合。边界模型 D*=σg_h 将 x²−2h x 在允许的有符号区间逐点取到最小。更精确地，投影到区间的平方差不等式以及总体相同的平均值给出

    E ∫(D−D*)² dt ≤ (d−d_min(p))/2。

耦合实际和目标模型各 k 个有名位置，每个位置与其目标位置使用同一均匀分位数，不同有名位置独立（条件于分量）。跨色的一对先移动 X，再移动 Y。各次另一色位置独立，密度≤2，变序概率至多 2(E|X−X*|+E|Y−Y*|)。一维最优运输的分位数面积公式给 E|X−X*|=∫|F−F*|=½∫|D−D*|，另一色相同。对至多 k² 对求并、对分量取平均并用 Cauchy–Schwarz，可得

    TV(μ_k, μ_k*) ≤ min(1, √2 k² √(d−d_min(p)))。

与完全均匀 U_k 比较时可单独使用 d。目标两类位置的密度都等于一，上述两次移动的密度界可分别取 2、1，得 TV(μ_k,U_k)≤min(1,3k²√(d−1/3)/(2√2))。就此均匀目标而言，平方根指数最佳。用密度 1±ε(2t−1) 定义两色排序，|ε|<1，则 p=1/2−ε/3，d−1/3=4ε²/15，第 1 层 TV=√(5/12)√(d−1/3)。投影到第 1 层只会减小总变差。证明给出全体尺度的指数，常数未声称最优。

## 完整 k 层观测的精确辨识能力

令 ν 为 A_N 的极限分布。[匹配矩的证明与算法](boundary3.md)给出 h_r=∫xʳ dν。它等于第 r 层将两色有名步均匀一一配对后，所有 r 对都为 X 在 Y 前的概率。所以完整 μ_k 定出 h₀,…,h_k。反过来，实现任意概率律 ν 有一个很小的模型：先抽 θ~ν，每个 X 独立以概率 θ 排在所有 Y 前，否则排在所有 Y 后。其 N 层为 X^L Y^N X^(N−L)，L 条件于 θ 服从 Bin(N,θ)。这些层删步相容，A_N=L/N 趋向 θ，且完整 k 层在每条词上的概率都是 θ 的至多 k 次多项式的期望。

对实连续 f，记 E_k(f)=min_{deg P≤k} max_{0≤x≤1}|f(x)−P(x)|。令 D_k(f) 为任意两个具有相同完整 μ_k 的相容塔之间，极限 ∫f dν 的最大差的绝对值，允许共同的 μ_k 变化。则

    D_k(f) = 2 E_k(f)。

上界由两塔的 k 阶及以下矩一致。对于下界，除非 f 本身是多项式，最佳逼近的误差在 k+2 个点交替达到 ±E_k。取 v_j=1/∏_{m≠j}(x_j−x_m)。这些符号交替的权重消去所有至多 k 次多项式，这是 Lagrange 插值的最高项系数恒等式。正负质量相等，各自归一化得到两套概率，期望差的绝对值达到 2E_k。上面的早/晚排序实现两套概率，还使所有 k 层词的概率逐项相同。全支撑限制下，混入同一任意小的均匀质量，故上确界保持。针对某一给定的表，实际直径可以更小乃至为零。

若 f(x)=x^{k+1}，记 n=k+1。区间 [0,1] 上首一的移位 Chebyshev 多项式为 2^{1−2n}T_n(2x−1)，故 D_k(x^{k+1})=4^(−k)。例如 k=2，以概率 1/3、2/3 取 0、3/4，或以概率 2/3、1/3 取 1/4、1。两塔 p=1/2、h₂=3/8，共同 μ₂ 为 XXYY 与 YYXX 各 3/8、XYYX 为 1/4。三阶矩恰差 1/16。若 ζ 为第一象限贴近 1 的十六阶根，则辅助复读数差的模为 |(1−ζ)³(1+ζ)|/3，严格夹在 0.038840 与 0.038841 之间。

## 极限相位的不确定性究竟有多大

写 D_k 为 Z_∞ 的复平面最坏直径，正交投影给出 D_k=2 max_{|u|=1} E_k(Re(conj(u)χ))。这里先把两个向量在其差的方向上投影，再用实值定理。设 y=2x−1，s=(1+i)/√2，令 a>0 为[从有限单位根极限得到的系数](boundary3.md)，χ((1+y)/2)=s exp(iay)，0<a≤1。各方向实函数的第 n 阶导数的模至多 aⁿ。对 T_n 的 n 个零点作实多项式插值，首一节点多项式的范数为 2^{1−n}，实插值余项给

    D_k ≤ U_n = 4aⁿ/(2ⁿ n!) ≤ 4/(2ⁿ n!)，    n=k+1。

下界可以匹配首项。取 T_n 的 n+1 个极值节点 y_j，定义 ℓ=2^{1−n}[y₀,…,y_n] 为归一化的 n 阶差商。ℓ 消去低于 n 次的多项式，其权重交替，且 |ℓ(T_n)|=1，故其总变差为一。取 u=s iⁿ，g=Re(conj(u)χ)，则 g 的 n 阶导数为 aⁿ Re exp(iay)。差商的单纯形积分公式给

    2ℓ(g)= U_n E[Re exp(iaY)]，
    Y=Σ λ_j y_j，(λ₀,…,λ_n) 在标准 n 维单纯形上均匀。

这里节点关于 0 对称，Σ y_j²=(n+2)/2（n≥2），Dirichlet 二阶矩给 E Y²=1/[2(n+1)]。Re exp(iu)≥1−u²/2 从二阶导数界即得。ℓ 的正负部按上节实现为路径模型，遂有

    [1−a²/(4(n+1))] U_n ≤ D_k ≤ U_n，   D_k/U_n → 1。

更精确的[最坏投影与二层区间](phase2.md)把任意 k 的方向最大化化为一个固定方向上的实最佳逼近，并将 D₂ 夹在宽度 10⁻²² 的有理区间。本节的四点简单例约为 0.038840，真正的 D₂ 约为 0.03884242445。两个数由不同的节点得到。第八层不必求最佳节点，完整表一旦相同，极限复读数的距离至多 1/46,448,640；第十层则至多 1/20,437,401,600。

观测表有误差时，设两张 k 层表的 TV≤η。对每个 1≤j≤k，均匀抽 j 对不同名的 X/Y，比对每对是否 X 在前，把结果记作 +1 或 −1 并求乘积。该统计在 [−1,1]，其极限矩为 ∫(2x−1)^j dν（由有/无放回抽样的耦合证明）。故两塔该矩之差≤2η。代入中心字符展开给

    |Z_∞−Z'_∞| ≤ 2η Σ_{j=1}^k a^j/j! + 2 Σ_{j>k} a^j/j!。

这一式给出了有限误差输入的显式保证。精确相等的数据使用上面的最佳逼近界。

## 同一模型在逐层细化时的误差

对给定一座塔，记 B=μ₂(XYYX)+μ₂(YXXY)，C=μ₂(XYXY)+μ₂(YXYX)。极限方差与 N 层方差的差额为 R_N=Var(A_N)−Var_ν(x)=B/(2N)+C/(4N²)。任一无界相容族均有 R_N/(2√2)≤|Z_∞−Z_N|≤2R_N；沿嵌套细化序列的所有后续复值修正，绝对值之和至多 2R_N。只要二层给分离的两条词以外的路径正概率，B>0，读数距离的衰减就恰为 Θ(1/N)。[逐层方差和双侧界](secmom3.md)

进一步，[一阶系数与两层外推](firstorder3.md)求出这个 1/N 项的复数系数，并据此消去它。第 N 层和 2N 层同时可算时，可用 2Z_{2N}−Z_N 作二阶近似。这里的 N 是在同一模型中实际算到的尺度；前节的 k 是已知完整概率表的深度，两种误差各回答一个不同问题。

甚至可用三层消掉前两项而不先拟合两项系数。条件在 Choi–Evans 的极端分量上，令 t 是该分量的单对成功率。展开 E(A_N−t)^j，在 j 个带位置的中心比较上分别按同色来源的相等关系分组。若有孤立的比较（其两端都没有与其它比较共享），对应期望为零。其余型的相交连通分量数至多 ⌊j/2⌋，每个连通块边数 e 的二部图至多 e+1 个不同来源。每一型的贡献为一个有界系数乘 (N)_r (N)_s/N^{2j}，r、s 为两色的不同来源数。所以这些中心矩都是 1/N 的有限多项式，起始次数至少为 ⌈j/2⌉，固定 j 时界与分量无关。将 χ 在 t 处展开至五阶，其六阶余项由 E(A_N−t)⁶ 控制。再对分量取平均得 Z_N=Z_∞+a₁/N+a₂/N²+O(N⁻³)。于是

    (Z_N−6Z_{2N}+8Z_{4N})/3 = Z_∞ + O(N⁻³)。

权重仅作用于已经算出的三个读数。附带的程序对二尺度外推及其显式界作区间核验；三尺度公式在这里由有限矩多项式证明。

## 回到 X6 的原始最短路

均匀选定到达六维整数终点的一条最短 BRC 路径，每一轴按终点确定的步符号编码。以 m_i>0 记实际使用的第 i 轴步数，A_ij 是 i 步在 j 步之前的有名步对比例。用反对称系数 λ_ij 描述要合并的观测，记 s_i=Σ_j λ_ij。等权排列各类有名步，再抹去标签，每个颜色词有相同数量的具名来源。独立均匀排序键是对这一有限排列的取样表示。利用每个比较关于其两个端点的一阶投影，并把其余项作为均值为零的退化项，[X6 投影专篇](x6_projection3.md)得到精确恒等式

    Var[Σ_{i<j} λ_ij A_ij] = (Σ_i s_i²/m_i + Σ_{i<j} λ_ij²/(m_i m_j))/12。

取不同三轴，T=A₁₂+A₂₃+A₃₁−1。每个有名三元组在此循环中恰有一或两次“在先”，故 0≤T≤1。三轴各用 N 步时，E T=1/2、Var T=1/(4N²)；单个 A_ij 的方差是 (2N+1)/(12N²)。在同一 χ 上，令 s=(1+i)/√2，C=a²。词反转使 T−1/2 对称；二阶字符余项与四阶矩控制给出

    1−Eχ(T)/s = C/(2N²)+O(N⁻⁴)。

允许其余三个坐标取任何终点，且每个所选轴的取向由其实际最短步确定。这将“跨尺度修正能否取消”落实在现有 X6 计数核可直接枚举的一个有向循环量上。这里约束是固定终点、等权最短路；加权或含回步的演化需另作推导。三轴边的系数在每个顶点收支相等是消去一阶方差的确切原因。
