# 从二层六项概率求出所有细层的二阶读数

2026-11-16。固定 X6 的两条选定正轴，外加比较规则为在 N 个 X、N 个 Y 中各均匀选择 k 个具名步，保留它们原有的先后次序。本篇讨论经此操作相容的任意步词分布 μ_N。起点、路径载体和辅助相位取自[前次研究](https://github.com/awdawmip/enterprise-math/blob/25b4d0e92c20c363e8ee01fbd4ac5bea076bd3da/research_notes/public_math_intake_20261116/craig_path_restriction/README.md)。记 A_N 为所有 N² 个横竖步对中，横步在前的比例。J_N=E[A_N(1−A_N)]。

## 二层表的三个系数

从 μ₂ 提取三个量。p 为 A₂ 的均值。b 是 XYYX、YXXY 的总概率。c 是 XYXY、YXYX 的总概率。另记 d=P₂(XXYY)+P₂(XYXY)/2。上一轮已经证明 p=E A_N 与尺度无关。本轮得到对每个 N 的恒等式

    E[A_N²] = d + b/(2N) + c/(4N²)
    Var(A_N) = d−p² + b/(2N) + c/(4N²)
    J_N = (b/2)(1−1/N) + (c/4)(1−1/N²).

等式首先适用于 N≥2 的有限细层及其派生二层，即使 μ_N 集中在任一条给定细词。对包含第一层的相容族，N=1 的同一公式也成立。无限层要求相容以及层列无界，允许只沿二倍塔或其他无界子列。极限方差为 d−p²，极限交错程度 J∞=b/2+c/4，有限尺度的剩余量恰为 b/(2N)+c/(4N²)。

**证明。** 给定一条颜色词，在每一颜色内另取均匀随机命名。令 I_ij 表示具名 X_i 在 Y_j 之前。对不超过两个名字每色的联合提问，其概率可以直接从二层表读取。令 x=E[I₁₁ I₁₂]，y=E[I₁₁ I₂₁]，d=E[I₁₁ I₂₂]，p=E[I₁₁]。每一行给定相应二层词后，四个量的读数如下表。按 μ₂ 加权即得无条件值。

| 二层颜色词 | p | x | y | d |
| --- | ---: | ---: | ---: | ---: |
| XXYY | 1 | 1 | 1 | 1 |
| XYXY | 3/4 | 1/2 | 1/2 | 1/2 |
| XYYX | 1/2 | 1/2 | 0 | 0 |
| YXXY | 1/2 | 0 | 1/2 | 0 |
| YXYX | 1/4 | 0 | 0 | 0 |
| YYXX | 0 | 0 | 0 | 0 |

将 A_N=Σ I_ij/N² 平方。有序的两项指标分别有 N² 组完全相同、N²(N−1) 组仅共享 X、N²(N−1) 组仅共享 Y、N²(N−1)² 组完全不同。对各类用 p,x,y,d 得到 E[A_N²]=d+(x+y−2d)/N+(p−x−y+d)/N²。逐行核对，x+y−2d=b/2 且 p−x−y+d=c/4，命题得证。

这里的 d−p²≥0 是无限可延拓的必要条件，由 Var(A_N)≥0 取极限得出。在单个有限细词派生出的二层表上，这一条件并不自动成立。例如仅在 N=2 取 YXYX，则 p=1/4、d=0。

## 从第二层到极限，J 最多和最少能放大多少

若二层含任一内部词，J₂>0。对一族无限相容细化，恒有

    4/3 < J∞/J₂ ≤ 2.

上端常数可达到，下端常数是下确界。由公式直接得 J₂=b/4+3c/16。因此 J∞≤2J₂，等号等价于 c=0。对下端，差 J∞−(4/3)J₂=b/6。要把下端不等式强化为严格，只需证明无限可延拓时 b=0 会推出 c=0。

若 b=0，每个正概率的 N 层词均无 XYYX 或 YXXY 子序列。其首个 X 与末个 X 之间最多一个 Y，首个 Y 与末个 Y 之间最多一个 X。假如又有 XYXY 子序列，大词可以使用的两个内段必分别只有一个 Y、一个 X。更明确地，枚举相同字母的连续段：五段就包含 XYXYX 或 YXYXY，前者的第一、五位之间有两个 Y，后者的第一、五位之间有两个 X，均违背禁词。出现交错子序列至少四段，故恰有四段。四段 X…Y…X…Y 的中间两段必须各长一，反向颜色次序同理。于是出现交错的细词只可能是 X^(N−1) Y X Y^(N−1) 或其换色词，产生交错子词的选法各有 (N−1)² 个。除以 binom(N,2)² 得 c≤4/N²。令 N 无界即得 c=0。因此只要 J₂>0，必有 b>0，且 J∞−J_N 的主项确为 b/(2N)。一个无限相容族不能只留下 c/(4N²) 的非零尾项。

**两个极值构造。** 将每个具名步独立分入预设的有序块，再在同块内随机排列，便得到按具名删步相容的路径族。下列构造的每块都只有一种颜色。

- 三块 X、Y、X。固定 t∈(0,1)，每个 X 独立以概率 t 进前块，以概率 1−t 进后块，全部 Y 在中块。因此 c=0 而 b>0，恰有 J∞/J₂=2。
- 四块 X_low、Y_low、X_high、Y_high。每个 X 到 high 概率 u，每个 Y 到 low 概率也是 u，所有选择相互独立。两层的 XYYX 要求两个 X 分居两块并且两个 Y 都在低块，YXXY 类似。XYXY 要求两种颜色都各自分居两块，YXYX 无法发生。故 b=4u³(1−u)、c=4u²(1−u)²，J∞/J₂=4(1+u)/(3+u)。让正的 u 趋于 0 即逼近 4/3。若要求一切有限步词都严格正权，可混入比例 o(u²) 的均匀路径族，仍逼近同一个下确界。

## 何时二层数据已经决定准确的极限响应

把兼容的第一象限分圆字符记为 z(t)，原标签比例 t∈[0,1] 时 z(0)=1、z(1)=i。在有理 t 上由共同的相容正根定义，对无理自变量用连续延拓。[已有的根弦界](https://github.com/awdawmip/enterprise-math/blob/25b4d0e92c20c363e8ee01fbd4ac5bea076bd3da/research_notes/public_math_intake_20261116/craig_path_restriction/coherent.md)在共同分母上给出

    |s−t| ≤ |z(s)−z(t)| ≤ 2|s−t|.

具体而言在分母 M 上每个标签步对应 8M 阶首正根 r 的两个幂次，0≤j≤2M 时 j/(2M)≤|1−r^j|≤j/M，因为该段所有幂都在闭第一象限。上述界也保证有理标签的延拓唯一。

令 Z_N=E[z(A_N)]。同一个删步耦合中 E[A_k|W_N]=A_N，所以 E[(A_N−A_k)²]=Var(A_k)−Var(A_N)。相干读数也得到平方误差量级的逐层界

    |Z_k−Z_N| ≤ 2[Var(A_k)−Var(A_N)]。
    |Z_N−Z∞| ≤ b/N+c/(2N²)。

这里 Z∞ 对每一无界相容层列都存在。证明只用有限分圆格上的二阶差分。令 H 同时被 k² 和 N² 整除，u 为 4H 阶首正根，σ=(u−u⁻¹)/2。曲线上任一对实际标签 x,y 均处在该格上，l=H(y−x) 为整数。对 l≥0，先将 uˡ−1−l(u−1) 写作 (u−1)Σ_{a=0}^{l−1}(uᵃ−1)，其模至多 l(l−1)|u−1|²/2。又有 |u−1−σ|=|u−1|²/2，故 |uˡ−1−lσ|≤l²|u−1|²/2。负 l 对 u⁻¹ 作同样计算。因 |u−1|≤2/H，可得

    |z(y)−z(x)−z(x)Hσ(y−x)| ≤ 2(y−x)²。

取 x=A_N、y=A_k，并先在固定细词上求条件均值，线性项恰好为零。对细词取平均即得第一条界。随着两个尺度增大，右侧趋零，故存在极限，令细层趋无界得到第二条界。对所有相容族还能得到同一个方向的正下界。取 s₀=(1+i)/√2，F_j=Re(conj(s₀)uʲ)，0≤j≤H。整段第一象限弧在该方向上的投影 F_j≥1/√2。对内部 j，F_(j−1)−2F_j+F_(j+1)=−|u−1|²F_j。因此 G_j=F_j+|u−1|²j²/(2√2) 的二阶差分非正。折线插值 G 在整个区间凹。在固定细词下取 j=HA_k，其条件均值 HA_N 也是整数。凹性给出 G_(HA_N)≥E[G_(HA_k)|W_N]。移项、对细词平均，再用 |u−1|≥1/H，得到

    [Var(A_k)−Var(A_N)]/(2√2)
       ≤ Re(conj(s₀)(Z_N−Z_k)) ≤ |Z_N−Z_k|
       ≤ 2[Var(A_k)−Var(A_N)]。

故沿细化，响应在单位对角线方向单调上升。任意细化链 k₀<k₁<…<k_r 上，Σ |Z_(kᵢ₊₁)−Z_(kᵢ)| ≤2[Var(A_(k₀))−Var(A_(k_r))]，故无界链上全部相邻层修正绝对可求和，余项由二层表精确量化。对 J₂>0 的任一无限相容族，b>0，而 Var(A_N)−Var∞=b/(2N)+c/(4N²)。上述两侧界因此推出 |Z_N−Z∞| 严格为 Θ(1/N)，包括极限落在圆盘内部的情况。对 J₂=0 则每层只有两条端点词，响应恒定。

另取 A'_N 为同层且独立的副本，1−|Z_N|²=E|z(A_N)−z(A'_N)|²/2。弦界给出 Var(A_N)≤1−|Z_N|²≤4 Var(A_N)。令 N 趋于无界可得

    d−p² ≤ 1−|Z∞|² ≤ 4(d−p²).

因此 |Z∞|=1 当且仅当 d=p²。在这个可由二层当场检查的情形，E[(A_N−p)²]→0，故 Z∞=z(p)。特别在六个二层词等权时，p=1/2，d=1/4，b=c=1/3，任意无限相容延拓都趋于同一响应 (1+i)/√2，和第一层响应 (1+i)/2 的极限距离严格等于 1−1/√2。这里仅假定第二层均匀。每一层的方差亦必然都等于 (2N+1)/(12N²)。如果 d>p²，上式直接证实极限读数落在单位圆内部。该判断给出模损的界，完整位置仍可能依赖更高阶来源信息。
