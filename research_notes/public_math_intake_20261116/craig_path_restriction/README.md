# 哪些细路径可以归入同一条粗路径

2026-11-16 · 进取数论 · 作者侧证明和精确复算，待独立审阅。接续 Craig 格点比较方法在 X6 两条选定正轴上的[首轮研究](https://github.com/awdawmip/enterprise-math/blob/c80629763b20a2737ec02c67c036b957fe0256c4/research_notes/public_math_intake_20261116/CRAIG_LATTICE_REFINEMENT_C4_PATH_RESPONSE.md)。该文给出固定原路径的相位嵌入和等权全部细路的方差。本次研究同一个有向辅助模型的粗路归属、正权和相干响应。

[后续研究：二层识别的精确界、六轴循环方差与极限分布](identification3.md) 给出了完整删步塔的刚性判据、二层最坏相位直径和 X6 等权最短路径上的具体应用。

令 W_N 为含 N 个横步 X、N 个竖步 Y 的有序路径族。保留来源的每一个选择都单独计作 BRC 分支。I(w) 是横步先于竖步的步对数，A_N=I(w)/N²。在本篇，给定细词后，从两类出现位置分别等权选 k 个，按原先后顺序得到粗词。选中的具体原位置构成来源凭据。这个删步核是本次声明的辅助比较规则，与沿格边等段嵌入旧路的几何映射分开定型。

| 检验对象 | 已得结果 |
| --- | --- |
| 均值和方差 | 每条细路的 A_N 精确等于删步后 A_k 的条件均值。多记一个由行、列次序差计算的数 E，即能恢复所有粗层的条件方差。 |
| 全部粗词读数 | 下文给出任意 N≥k 的满秩子矩阵和必要线性读数维数。在固定层只查询各粗词概率时，子词计数向量就是最粗充分记录。 |
| 有偏路径权 | 若每层用 q_m 的 I 次幂，再按同类均匀删步，所有整数层或二倍层的相容解都只有 q_m=1。可用有权的具名步排序得到另一族处处正权、任意偏置的相容模型。 |
| 相干响应 | 全部细路等权时，归一化相干和的极限是 (1+i)/√2，与原来的 (1+i)/2 相距 1−1/√2。按层单独调权可以改变极限。要求各层同时相容时，下文给出二层即能检验的误差下界和完整分类。 |

## 任意粗层的全部词概率需要多少信息

对 u∈W_k，写 D_u(w) 为从 w 中抽出 u 的来源选法数。转移概率为 D_u(w)/H，H=binom(N,k)²。依次保留 k、j 个与直接保留 j 个同律。因此，对固定 N 和最大的目标层 k，只要查询各 j≤k 的个别词输出概率或其任意有界函数的期望，D 的整行足够。若语言允许直接查询每个 k 词，则两条具有不同 D 行的细路必被区分。即使比较一串嵌套抽取后的颜色词联合分布，先抽 k 之后的随机过程仍能在该粗词上接续。若用户查询原始位置，需保留随分支选出的来源编号。D 只统计颜色词。

**满秩定理。** 对每个 N≥k≥1，矩阵 (D_u(w)) 的列秩恰为 binom(2k,k)。归一化后的可达分布的仿射包维数恰为 binom(2k,k)−1。因此，若要对任意细路径正概率混合保留所有粗词概率，而且只允许线性统计及仿射重建，就需要这么多个独立变化的读数。该结论没有给任意非线性编码或单个整数的位数下界。

**证明。** 对每个粗词 u，用 w_u=X^(N−k) u Y^(N−k) 构造一条细路。令 X_i、Y_j 分别指粗词 u 内该颜色的第 i、j 次出现。任何抽取保留的第 i 个 X 在细词中的位置至迟是原 u 中 X_i 的位置（被删的 X 总共只有 N−k 个）。第 j 个保留的 Y 则至少在原 Y_j 的位置。因此粗词 u 中每一个 X_i 在 Y_j 前的关系都保留在输出 v 中。若新增了任何一个这种关系，I(v)>I(u)。若一个也没增加，所有跨颜色顺序一致，同色顺序由编号给定，故 v=u。将各列及上述行按 I 排序，等面积内部任意同序排列，所得方阵为上三角。

设 a 是 u 的起首连续 X 个数，b 是其末尾连续 Y 个数。对角项更有精确式
     
    D_u(w_u) = binom(N−k+a,a) binom(N−k+b,b) > 0。

设 u 中一个非起首的 X 段从第 i 个 X 开始。紧在段首之前的原 Y 必须在输出中仍先于所选 X_i。由于所选的这个 Y 只能比其原位置更晚，X_i 必须落在原 X_i 处或其右边。上述上界又保证它至迟在原 X_i 处。所以该段第一个 X 固定。段中其余 X 依次出现在紧邻的位置，递增性与同一上界使整段逐位固定。作时间反向并交换 X、Y，同理固定全部非末尾的 Y。于是剩余自由度恰为在最前面 N−k+a 个 X 中取 a 个、最后面 N−k+b 个 Y 中取 b 个。若只为证明满秩，选择中间整个 u 就已给出正对角。行和恒为 H，满线性秩遂给出上述仿射维数。举例 k=2 有六种粗词，五个独立变化的线性读数就足够，四个在上述问题域内不足。

**实际计算。** 单个粗词 u 的来源计数可在细词上从左到右更新。设 C_j 为此前前缀中得到 u 的 j 字前缀的选法数，初始化 C_0=1，其余为 0。遇到新步 σ 时按 j 从大到小，对 u_j=σ 的 j 作 C_j←C_j+C_(j−1)。不选该步和选该步形成两个来源分明的分支。该算法用 O(Nk) 次整数更新和 O(k) 个计数器，逐项算全粗层用 O(Nk binom(2k,k)) 次更新。目的为获得计数，单条来源仍可用保留位置回放。二元词的子序列计数与组合学中的 subsequence deck 相关。这里保留子词恰含 k 个 X 和 k 个 Y，并给出在此均衡限制下的证明。[相关文献](https://www.aimsciences.org/article/doi/10.3934/amc.2021032)

## 最早在哪一层会认不出原路径

以两横、两竖的全部六种粗词作观察。按 XXYY、XYXY、XYYX、YXXY、YXYX、YYXX 排列其来源计数。对 N=2,3,4,5,6 的全部步词逐条枚举，来源计数向量的不同取值数依次是 6、20、70、252、920，对应原路径数 6、20、70、252、924。N=6 首次出现碰撞，916 个向量各对应一条细路，另外四个向量各对应两条。以下两条 12 步路径的六个计数都为 (48,42,42,42,39,12)，总数 225。

    XYYXXXYXYYYX
    YXXXYXYYYXXY

改为各留三步，查询粗词 XXYYXY。第一条出现 0 次，第二条出现 54 次，总选法各为 400。若保存三横三竖全部 20 个词的计数，该层 924 条原细路可全部分辨。以上首次碰撞结论覆盖逐层穷举的范围。任意更大 N 的恢复门槛另有其组合学问题。

更早也能区分“知道方差”和“知道全部分布”。N=3 时，XYXYYX、XYYXXY 的 (A,E) 同为 (5/9,16/81)，故删至 k=2 后均值、方差相等。输出 YYXX 的概率依次为 0、1/9。这个检测与只检查原始单个面积标签相比，又排除了一阶和二阶共同造成的混同。

## 删步相容性对复响应施加的统一限制

设 μ_N 是一族可经上述删步核恢复 μ_k 的路径概率。可考察所有整数层，或含 1、2 的任意无界嵌套层列。记 J_N=E[A_N(1−A_N)]。所有概率、抽法和量词针对这个辅助模型。末端标签的复值由第一象限四分之一圆弧上的字符给定，步对数从 0 到 N² 时，相位从 1 走到 i。定义 Z_N 为单条路径相位对 μ_N 的平均。第一层为 XY 的概率记 p，则 Z_1=(1−p)+ip。

**定理。** 任意 N≥k 属于该层列时，有 J_N≥J_k，且

    |Z_N−Z_1| ≥ J_N / [√2(1+√2)]。

若二层六种词中任何内部词（I=1,2,3）获得正概率，则 J_2>0，以上差值从二层起统一大于等于 J_2/[√2(1+√2)]。在本模型内，各层相容且 Z_N 沿无界子序列趋向 Z_1，当且仅当每层仅支持极端词 X^N Y^N 与 Y^N X^N，前者的权重固定为 p。

**证明。** 给定细词，E[A_k|w]=A_N(w)。β(t)=t(1−t) 是凹函数。直接展开条件方差得更强恒等式

    J_N−J_k = E[Var(A_k | W_N)] ≥ 0。

设 z=q^I 的实部、虚部分别为 a,b，令 L(z)=a+b。两个端点的 L=1，故 L(Z_1)=1。在四分之一圆弧上，本包的[弦长界](coherent.md)给出 b≥A_N/√2，a≥(1−A_N)/√2。由 a²+b²=1，得到 L(z)−1=2ab/(a+b+1)≥β(A_N)/(1+√2)。取期望并沿单位对角线投影，即得误差下界。

若某层路径有 0<I<N²，则必存在一个 XY 次序步对和一个 YX 次序步对，合用至多两个 X、两个 Y。把它们补至两横两竖，可获得 0<I_2<4 的内部二层词，对应抽法概率严格为正。因此 J_2=0 时各层都只支持两端。其混合权由 k=1 的一致性固定。这两端路径每层的字符读出分别恒为 i、1，确实实现 Z_N=Z_1。反过来若 Z_N 沿无界子序列趋于 Z_1，单调下界迫使 J_2=0。于是虽可在每层分别偏重最靠近端点的新细路，使误差降为 O(1/N²)，一旦还要逐层恢复同一份具有内部路径的二层分布，就不能沿用这些逼近配权。例：若二层六词均匀，J_2=7/48，所有相容细化的误差至少 7/[48√2(1+√2)]。
