# 哪些二层数据能唯一决定全塔

沿用[具名删步定义](https://github.com/awdawmip/enterprise-math/blob/25b4d0e92c20c363e8ee01fbd4ac5bea076bd3da/research_notes/public_math_intake_20261116/craig_path_restriction/deletion.md)。W_N 含 N 个 X、N 个 Y 的所有最短有序步词。D_(N,k) 分别均匀抽取各 k 个具名位置，保留先后。给定各层的路径概率 μ_N，要求每一粗层由细层按此核抽取所得。下文允许所有整数层或无界层列，对未列的有限层也可以用更细一层抽取，合成恒等式使其定义唯一。U_k 表示 W_k 上的均匀分布。

## 一个可由二层读出的均匀性判据

令 d=μ₂(XXYY)+μ₂(YYXX)，即二层中两个极端路径的总概率。对任何上述相容塔，都有 d≥1/3。等号成立当且仅当所有层均为 U_k。只要二层六词等概率，就已确定完整路径塔。在上篇的[归一化辅助相干观察](https://github.com/awdawmip/enterprise-math/blob/25b4d0e92c20c363e8ee01fbd4ac5bea076bd3da/research_notes/public_math_intake_20261116/craig_path_restriction/coherent.md)下，极限确切为 (1+i)/√2，与等权双端点读数 (1+i)/2 的距离恰为 1−1/√2。

**每条有限细路的证书。** 给定 w∈W_N，N≥2。以横纵已走步数除 N 记 F,G，沿格边作线性插值。参数 t=(F+G)/2 从 0 到 1。令

    H(w)=∫(F−G)² d(F+G)。

这是可用有理数求出的有限格边之和。第 j 步若横纵步数差由整数 h 变为 h'，贡献为 (h²+hh'+h'²)/(3N³)。为求它的二层含义，从 w 中抽两 X 一 Y 读到 XYX 的概率记 P，再抽一 X 两 Y 读到 YXY 的概率记 Q。对任一被选 Y，两 X 要分别在它前后。按该 Y 所在位置的横步比例 F 计数，有

    (1−1/N)P=2∫F(1−F)dG，
    (1−1/N)Q=2∫G(1−G)dF。

若先降到二层再各自删去一个相应步，六个二层词的 P+Q 依 XXYY、XYXY、XYYX、YXXY、YXYX、YYXX 顺序恰为 0、1、1、1、1、0。令 d(w) 为从 w 降到二层时两极端词的概率之和，得到 P+Q=1−d(w)。另有 ∫FdG+∫GdF=1。令 B=∫F²dG+∫G²dF。对 F²G、FG² 沿格边作乘法分部求和，得 2∫FG d(F+G)=2−B。故 H=2B−4/3。合并得逐词等式与塔平均等式

    H(w)=d(w)−1/3+(1−d(w))/N，
    E H(W_N)=d−1/3+(1−d)/N。

H 非负，让 N 沿相容塔增大即 d≥1/3。这一步需要无界延拓。单独某个固定层的极端词频率可以低于 1/3。

**为什么等号同时强制所有有限层。** 记 h(w)=max|F−G|。D(t)=F−G 为斜率 ±2 的折线，两端为 0。在绝对值取到 h 的点向两侧各走 h/2，绝对值至少为 h−2|Δt|。积分并乘 2 得 h³≤3H/2。

给定 w，把每个 X 或 Y 的位置均摊在这一格边的 t 区间上，F、G 正好是两种颜色位置的累积分布。分别有放回抽 k 个位置时，用独立均匀标记和 F、G 的广义逆映射取样。因 F(t)+G(t)=2t，两种逆映射都将标记移动至多 h/2。按原均匀标记排序得到 U_k 的词。逆映射排序若改变了颜色词，至少有一对不同色标记距离至多 h，概率上界为 2k²h。同时有放回抽法与所规定的无放回具名来源抽法可耦合，两类中任一类重复抽中同一边的概率至多 k(k−1)/N。排序标记仅用于证明随机次序的有限分布；来源核及所有检验数值均从有限 BRC 步词算出。

取 w∼μ_N，利用凹性 E[h]≤(3E[H]/2)^(1/3) 和项目核的相容性，可得总变差界

    TV(μ_k,U_k) ≤ k(k−1)/N + 2k²[3(d−1/3+(1−d)/N)/2]^(1/3)。

让 N→∞，得 TV(μ_k,U_k)≤2k²[3(d−1/3)/2]^(1/3)。当 d=1/3，各固定层均是 U_k，反向由 U₂ 的六个词直接计算。类似地 A_N=I(w)/N²=∫F dG 且 ∫G dG=1/2，所以 |A_N−1/2|≤h。用上篇的单位根弦长界，在任一共同有限分母上有 |χ(a)−χ(b)|≤2|a−b|，χ 从 1 到 i。于是任意相容塔的相干和 Z_N 都满足

    |Z_N−(1+i)/√2| ≤ 2[3(d−1/3+(1−d)/N)/2]^(1/3)。

上篇给出了精确均匀情形更快的 1/N 收敛率。本节的界用于允许二层资料偏离均匀的其他配权。Hàn、Kiwi、Pavez-Signé 已研究三字子词对二元词准随机性的刻画，及一般极限词的有限强制性。本节给出当前均衡、逐色无放回的随机塔接口中两端点总质量的明确判据、精确有限修正与全层概率误差界。[原始论文](https://arxiv.org/abs/2003.03664)

## 任意有限观察深度都存在不能区分的全支撑塔

对每个 k≥1，存在两套在所有词上都有正概率的相容塔。两套模型在每个 n≤k 的完整词分布一致，而在 k+1 层已经分开。若以辅助相位之和作读出，它们在无限细化后的读数差也有确定的非零值。这个存在性与上一节均匀二层的唯一性相容，构造采用另一组二层分布。

取 r=k+1。第一套在偶数 j∈[0,r]、第二套在奇数 j∈[0,r] 取 θ=j/r，分别赋概率 binom(r,j)/2^(r−1)。给定 θ，每个原始具名 X 独立标记为“前”或“后”，“前”概率为 θ。先排列带“前”标记的 X，再排所有 Y，最后排带“后”标记的 X。同块内部具名步可另作均匀排序。忽略块内名字后，得到词

    X^a Y^n X^(n−a)，其中 a∼Binomial(n,θ)。

任何单独选择的 X 名字子集上的标记仍为独立同参数标记。各标记块内均匀排序保证忘掉名字后，随机选择各色具名子集等价于逐色均匀删步。因此对固定 θ 及混合后的两套分布，相容性逐层成立。对两侧再各掺入同一个比例 λ∈(0,1) 的均匀塔，各有限词质量均至少 λ/binom(2n,n)。

**一层不差地找到首次分歧。** 第 n 层任一块词的概率为 E[binom(n,a)θ^a(1−θ)^(n−a)]，只用到 θ 的前 n 阶矩。当 0≤m<r，Σ_j(−1)^j binom(r,j)j^m=0，这是 r 阶有限差分消去所有次数小于 r 的多项式。m=r 时该和为 (−1)^r r!。因此前 k 层每个词概率相等。在 n=r，比较每个 a 的块词概率，未掺均匀部分时其差为

    (−1)^a binom(r,a)r!/[2^(r−1)r^r]。

故第 r 层两侧的总变差为 (1−λ)r!/r^r，确实严格为正。

**相干读数差。** 块词的 I=na，所以 A_n=a/n。对有理标签 t，写 χ(t) 为沿 1 到 i 的相容有限单位根字符。给定 θ，E|a/n−θ|≤√[θ(1−θ)/n]。将这两个有理数放入同一有限分母，前述弦长界推出 E[χ(a/n)|θ]→χ(θ)。令 z 为紧随 1 的 4r 阶单位根，则 χ(j/r)=z^j。两侧均匀成分相同，故

    lim(Z_n^even−Z_n^odd)=(1−λ)(1−z)^r/2^(r−1) ≠ 0。

均匀成分各自有已证明的极限，因而两侧的极限均存在。所有用到的模型参数、步对标签、有限层词概率都可取有理数，单位根只用于早已声明的复值观察。

**最小具体实例。** k=2、r=3、λ=1/2。偶数节点为 0、2/3，概率为 1/4、3/4；奇数节点为 1/3、1，概率为 3/4、1/4。二层六词按上文顺序，两侧共同概率依次为

    (1/4, 1/12, 1/4, 1/12, 1/12, 1/4)。

两塔均将概率赋给所有路径。三层总变差恰为 1/9。极限相干读数之差为 (1−z)^3/8，z 为紧随 1 的十二阶单位根。对此二层样本，即使以无限精度读取全部六种概率，也不能单独还原极限相位。

**复算。** [核验程序](check_witness3.py) 调用上轮 [check_weighted.py](https://github.com/awdawmip/enterprise-math/blob/25b4d0e92c20c363e8ee01fbd4ac5bea076bd3da/research_notes/public_math_intake_20261116/craig_path_restriction/check_weighted.py) 所载入口，按 Git blob 核验 [signed_brc.py](https://github.com/awdawmip/enterprise-math/blob/c4d450536bf71ed87fd74555295ec60485262f0a/experiments/x6_signed_native_spatial_v16_20260905/signed_brc.py)，用 shortest_path_multiplicity 核对六轴位移 (N,N,0,0,0,0) 的完整分支数。在 2≤N≤6 的全部 1,272 个均衡步词上逐一以精确有理数比较格边能量与具名二层子集计数，核验强制统计量、峰值及面积不等式；另验证匹配深度 k=1,…,7 的 28 个完整低层分布、七个首个分歧层的总变差、84 个全支撑粗化分布及相位差的二项式完整系数。证明的适用性限定于所声明的辅助次序与相位观察。

## 一层偏置与二层极端词质量的精确可行域

记 p=μ₁(XY)，d=μ₂(XXYY)+μ₂(YYXX)。以下给出所有可能的二元观测值，并刻画位于边界的全塔。定义

    b=|p−1/2|， h=1−√(1−2b)，
    d_min(p)=1/3+2h²−4h³/3。

一列所有尺度相容的路径律可实现 (p,d)，当且仅当 0≤p≤1 且 d_min(p)≤d≤1。对给定 p，下、上边界分别唯一决定全塔。每个严格内部点允许多种实现，甚至可以使两套模型先在任意指定的有限层深度内完全相同，随后相干极限仍有分歧。

**最小值。** 逐词有 A_N−1/2=∫₀¹ D(t)dt。这由 A_N=∫FdG，∫(F−G)d(F+G)=2A_N−1 和 d(F+G)=2dt 得出。由于逐个细词的 XY 抽样比例就是 A_N，故 E∫D=p−1/2。设 σ=1 当 p≥1/2，其他情形取 σ=−1，并置 c(t)=2 min(t,1−t)，g(t)=min(h,c(t))。每条路径满足 −c(t)≤D(t)≤c(t)。g(t) 是常数 h 在此区间的最近点，故逐点有

    (σD−h)² ≥ (g−h)²+(σD−g)²。

这里交叉项非负，因为若 c≥h 则 g=h，若 c<h 则 σD≤g<h。直接对两段长度 h/2 的斜坡和中段积分可得 ∫g=h−h²/2=b，∫g²=h²−2h³/3。积分取期望，利用两者均值相同消去线性项，并代入逐词能量恒等式，得到

    2 E∫(D−σg)²dt ≤ d−d_min(p)+(1−d)/N。

左侧非负。让 N→∞ 得必要下界，d≤1 源于 d 的概率含义。

**达界的具名分支构造。** 当 p≥1/2，给每个 X 独立地以概率 h 标为“早”，给每个 Y 独立地以同概率 h 标为“晚”。所有早 X 在前，所有晚 Y 在后，其余具名步在中间均匀交错。同块的名字也均匀排序，因此内在标签和相对顺序在删除独立来源子集后保持同律。当 p<1/2，反转全部步词以交换两种端点。只研究颜色词时，选中的早 X 数 s 和晚 Y 数 l 独立服从 Binomial(N,h)，其后均匀排列含 N−s 个 X、N−l 个 Y 的中段。

单个 X 早于 Y 的概率为 1−(1−h)²/2。计算 d 时记 u=1−h。二层反向极端词 YYXX 要求四个名字全在中段，故概率 u⁴/6。对正向极端词，若中段有 a 个 X、b' 个 Y，则它们全体均匀交错时正向极端事件的条件概率为 1/binom(a+b',a)。将 a,b'=0,1,2 依据两套 Binomial(2,u) 权重求和，再加 u⁴/6，整理为 1/3+2h²−4h³/3，即达下界。以概率 p 选取全层均为 X^N Y^N 的塔、余下选其反序塔，则达到上界 d=1。按固定比例混合这两个具有相同 p 的边界塔，全部介于二者之间的 d 均可实现。

**边界唯一性及偏离边界的稳定界。** 达到上界时 μ₂ 只支持两极端词。细层若含内部词，就有正概率采出交错的二层词，故全塔亦只支持两端点，权重由 p 固定。考察下边界，令 e=sup|D−σg|。差函数的 Lipschitz 常数至多 4，端点为 0。如果峰高为 e，在其左右各 e/4 范围内，绝对值至少 e−4|Δt|。故 e³≤6∫(D−σg)²dt。

以目标分布函数 F_*(t)=t+σg(t)/2、G_*(t)=t−σg(t)/2，各独立抽 k 个位置按次序形成目标 k 层词。两函数连续且为分段线性，比率由三段常数斜率给定，当 σ 为正时早段只出 X、中段两色均匀、末段只出 Y。直接拆为各段采样即前述具名构造。端点 h=0 或 1 时只需使用非空段。由 F=t+D/2、G=t−D/2，F、G 与相应目标累积分布函数的最大差均为 e/2。给定细词先用有放回采样，从 F、G 独立取各 k 个位置。当只替换其中一个位置的分布并保持其他位置的取值，每一种颜色词事件的指示随这个位置穿过其他 2k−1 个点而至多跳变 2k−1 次。因此这次替换影响该事件的概率至多 (2k−1)e/2。两边的位置分布都是连续的，逐一替换 2k 次并加上重复源边的概率，得到

    TV(μ_k, μ_k^*) ≤ k(k−1)/N + k(2k−1)[3(d−d_min(p)+(1−d)/N)]^(1/3)。

适用范围是各 k、N 在相容塔中且 k≤N。取 d=d_min(p) 并沿任意无界 N 让右侧趋零，证明每个 k 层唯一。对 p=1/2，h=0，目标即均匀塔。对任意达下界的 p，能量界还给 A_N→p 的均方收敛，故既有辅助相位的极限是正向四分之一弧在参数 p 处的值。若 p 为有理，正是前述有限单位根。一个可无浮点复核的有偏例为 h=1/2，得 p=7/8，d_min=2/3。此时二层极端词总权即使大于 1/3，也能结合一层偏置精确地强制整个路径分布。

配套程序另在 h=0、1/4、1/2、3/4、1 验证两条边界公式的正向构造，并枚举 1≤k≤N≤5 的 75 个完整粗层分布。反序对称给出相反方向。


**全部内部点的二义性。** 对严格内部点 x=(p,d) 及任意固定可见深度 k≥2，取前文具有相同前 k 层、所有词正质量、相干极限不同的两塔 ν_even、ν_odd，记其共同二元观测为 y。因为 x 为内部点，存在 ε∈(0,1)，使 x₀=(x−εy)/(1−ε) 仍在已确定的可行域。用两个边界构造的混合得到一个具有参数 x₀ 的共用塔 μ₀。该塔的两种边界成分各自有上述相干极限，混合后极限也存在。令 μ_±=(1−ε)μ₀+εν_±。这两塔全支撑，均实现 x，在任意 n≤k 的完整词分布相同，而其相干极限的差是前述非零差乘 ε。结合上下边界唯一性，(p,d) 确定全塔、或仅确定其归一化相干极限的充要条件，在这个可行域内均为 x 位于边界。此处的内部结论是每个参数点至少有一对具有该性质的塔，并不把任意给定的全部高阶资料都断言为可扰动。
