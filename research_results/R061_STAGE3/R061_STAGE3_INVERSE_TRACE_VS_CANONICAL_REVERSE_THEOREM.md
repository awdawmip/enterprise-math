# R061 Stage 3 — Inverse Trace versus Canonical Positive-Axis Reverse

Researcher-ID: `EM-R061S3-2F9622`

## Theorem

Let `P != Q`. Write `T_f=T(P->Q)` for the frozen Stage 2 canonical positive-axis trace, `T_r=T(Q->P)` for the independently decoded canonical positive-axis reverse trace, and `INV(T_f)=T(P->Q)^(-1)` for reverse traversal of the same trace/path representatives through inverse carrier morphisms.

Then, in the frozen typed language,

`INV(T_f) != T_r`

for every nonzero segment. Equality occurs only for the zero trace `P=Q`.

This is a trace-typing theorem, not a length theorem.

## Proof

A nonzero canonical positive-axis trace is generated from one translated positive sector or axis presentation and uses only the frozen positive generator family. Its groupoid inverse reverses those same center transitions and therefore contains inverse morphisms.

The canonical reverse `T_r` is not formed by groupoid inversion. Stage 2 reverses the endpoint order and performs a new positive-axis decode

`D_r = M(1,1,1)-D_f`, `M=max(D_f)`.

It starts from translated incidence at `Q` and is generated by the positive generators selected by `D_r`.

No frozen native relation identifies an inverse generator with a positive-generator word. Doing so would either restore a native negative axis or promote the carrier relation to a native vector identity, both explicitly forbidden. Hence a nonempty inverse trace and a canonical positive trace cannot be the same typed trace.

For the zero segment the word is empty, no inverse generator occurs, and the two constructions coincide.

## Length-symmetry is a different locus

For `D=(A,B,C)` with `min(D)=0`,

`ell_r^2-ell_f^2 = M(3M-2(A+B+C))`.

Thus nonzero gauge symmetry holds exactly when `2(A+B+C)=3M`. Since a nonzero canonical triple has one zero component, if the active components are `M>=m>0`, this becomes `M=2m`.

Therefore the nonzero reversal-symmetric locus consists of cyclic/permuted sector traces of type `(2k,k,0)`, `k>=1`.

Even there `INV(T_f) != T_r`. Example: `D_f=(2,1,0)`, `D_r=(0,1,2)`, and both gauges are `sqrt(5)`, but the two positive traces live in different translated sector types and neither is the inverse-generator trace.

## Mandatory witnesses

- Axis unit: `D_f=(1,0,0)`, `ell_f=1`; `D_r=(0,1,1)`, `ell_r=sqrt(2)`. `INV(T_f)` is one reversed carrier-edge trace; `T_r` is the positive `S_23` `(1,1)` trace.
- Equal-component sector: `D_f=(a,a,0)`, `D_r=(0,0,a)`. Forward is an open-sector trace, reverse is a positive-axis trace.
- Translated `3-4-5`: `D_f=(3,4,0)`, `ell_f=5`, path fiber cardinality `35`; `D_r=(1,0,4)`, `ell_r=sqrt(17)`, canonical reverse path fiber cardinality `5`; the inverse fiber has cardinality `35`.

The checker exhausts all `6480` nonzero ordered pairs on the Stage 2 `81`-vertex patch and finds zero nonzero coincidence.
