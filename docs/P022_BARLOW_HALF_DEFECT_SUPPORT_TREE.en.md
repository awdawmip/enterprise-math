# P022 — Prime-Halving Support Tree for the Half-Index Franel Defect

Status: `ACTIVE RESEARCH NOTE / EXACT SUPPORT SUPERSET + LOCATION BOUNDS`  
Owner: `program/p022-geometry-v2`  
Depends on: central-binomial A-elimination; Franel half-index family; integer midpoint companion  
Open target: prove or falsify support avoidance for `p = 5 or 23 (mod 24)`.

## 1. Why the old support question was too large

For

\[
p\equiv5,23\pmod{24},\qquad m=(p-1)/2,
\]

the half-index witness satisfies `p|F_m` and `2m-1=p-2` is composite, so the canonical pure Franel defect `D_m` exists.

To obtain

\[
v_p(D_m)=v_p(F_m),
\]

we need every earlier Franel factor used by the central-binomial elimination to be a `p`-adic unit.

A brute-force formulation compares the support with all of

\[
F_1,\ldots,F_{m-1}.
\]

The central-binomial recursion shows that this is unnecessary.

## 2. P022-LI33 — prime-halving tree

The exact identity

\[
\frac{A_n}{A_{n-1}}=\frac{2(2n-1)}n,
\qquad A_n=\binom{2n}{n},
\]

uses an odd prime `q` through

\[
j=(q+1)/2.
\]

Expressing `q` in the A-basis introduces only the adjacent indices

\[
j,\ j-1,
\]

and recursively expands the smaller integer `j`.

Therefore define the **prime-halving tree** of a positive integer `v` by:

1. start from the odd prime factors of `v`;
2. for each node `q`, recurse through the odd prime factors of `(q+1)/2`;
3. attach A-index candidates `(q+1)/2` and `(q-1)/2`.

For the half defect, the exact canonical support is contained in

\[
\boxed{
\{1,m-1\}
\cup C(p-2)
\cup C(m),
}
\]

where `C(v)` is the index set generated by this tree.

Cancellations may make the exact support smaller; the tree is a rigorous support superset.

## 3. P022-LI34 — polylogarithmic support complexity

Every child prime `r` of a node `q` satisfies

\[
r\le\frac{q+1}{2}\le\frac{2q}{3}
\qquad(q\ge3).
\]

Thus every root-to-leaf path has logarithmic depth.

At any fixed depth, the product of all odd-prime nodes with multiplicity is no larger than the product at the preceding depth and hence no larger than the starting integer.  Since every node is at least `3`, the number of nodes per depth is also logarithmic.

Consequently

\[
\boxed{|C(v)|=O((\log v)^2),}
\]

and the half-defect support candidate set has size

\[
\boxed{O((\log p)^2).}
\]

So support avoidance is not an `O(p)` scan problem.  It is an incidence problem between a polylogarithmic arithmetic tree and the companion-zero set.

## 4. P022-LI35 — target arithmetic-progression location bounds

The two target residue classes give stronger explicit bounds.

### Case `p = 5 (mod 24)`

Here `p-2` is odd and divisible by `3`, so every odd prime factor of `p-2` is at most `(p-2)/3`.  Also

\[
m=(p-1)/2
\]

is even, so every odd prime factor of `m` is at most `(p-1)/4`.

All descendants are smaller than their roots.  Hence every non-adjacent candidate support index satisfies

\[
\boxed{j\le\frac{p+1}{6}.}
\]

### Case `p = 23 (mod 24)`

Again `p-2` is divisible by `3`.  Now `m` may itself be prime, so the worst A-index from the `m` side is

\[
(m+1)/2=(p+1)/4.
\]

Thus

\[
\boxed{j\le\frac{p+1}{4}.}
\]

in this residue class.

The exceptional support index `m-1` is always safe because `F_m=0 (mod p)` and adjacent Franel zeros are impossible.

## 5. P022-LI36 — dangerous companion offsets live only in the far tail

Put

\[
d=m-j.
\]

Combining the location bounds with the integer companion criterion

\[
p\mid F_{m-d}\iff p\mid H_d
\]

gives:

- if `p=5 (mod 24)`, any non-adjacent dangerous support zero must satisfy
  \[
  \boxed{d\ge(p-2)/3;}
  \]
- if `p=23 (mod 24)`, it must satisfy
  \[
  \boxed{d\ge(p-3)/4.}
  \]

Thus all near-midpoint companion zeros are automatically irrelevant to the canonical half-defect elimination in the target APs.

## 6. Exact incidence formulation

If a candidate support index `j=m-d` comes from a prime-halving node `q`, then

\[
j=(q+1)/2\quad\text{or}\quad j=(q-1)/2.
\]

Hence necessarily

\[
\boxed{q=p-2d-2\quad\text{or}\quad q=p-2d.}
\]

A dangerous cancellation therefore requires both:

1. `p|H_d` in the universal integer companion;
2. one of the residual primes `p-2d` or `p-2d-2` lies in the prime-halving tree generated from `p-2` or `m`;
3. the corresponding candidate survives exact coefficient cancellation.

This is the current exact arithmetic frontier.

## 7. Negative boundary

A forced midpoint can have very early extra zeros without threatening the half defect.

For example, `p=173` has zero alphabet

\[
\{4,86,168\},
\]

but its exact A-elimination support does not contain `4`.

Conversely the broader non-target prime `p=157` has a zero at `16`, and `16` is in its canonical elimination support; this cancels the midpoint valuation.  Therefore forced midpoint alone is insufficient.
