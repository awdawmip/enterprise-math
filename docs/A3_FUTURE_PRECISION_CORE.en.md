## 4. Guard quotient module

The representative-independent predicate state is

\[

## 5. Canonical hidden-subgroup refinement

Choose an exact basis

\[
H:\mathbb Z^d\cong L_P.
\]

Inside each parent block assign hidden labels

\[
W_i-W_a=H\lambda_i,
\qquad \lambda_i\in\mathbb Z^d.
\]

For any subgroup `M <= Z^d`, group coordinates by

\[
\lambda_i-\lambda_j\in M.
\]

The resulting coset partition `R_M` is the unique coarsest refinement with child hidden image contained in `H(M)`. If an arbitrary refinement has exact image `H(M)`, the canonical `R_M` has exactly the same image and is no finer.

Thus minimum-precision search can move from raw set partitions to a finite family of hidden subgroups generated by the finite hidden-label differences.

## 6. Reachable behavior, not syntactic branches

For a fixed coarse fiber `y`, let `R_y` be its actually reachable branch patterns and let `E` be the declared coarse-effect map.

Branch identity can be erased iff

\[
\boxed{E|_{R_y}\text{ is constant}.}
\]

Define state-local effect ambiguity

\[
\boxed{a_E(y)=|E(R_y)|.}
\]

Unreachable branches do not create precision obligations.

## 7. Complete rank-one and rank-two state-local solvers

### Rank one

With hidden image `Z h`, fine coordinates carry integer hidden labels `lambda_i`. Modulus-`q` refinement groups labels by `lambda_i mod q` and is the canonical coarsest refinement forcing the child image inside `q Z h`.

A finite visibility bound makes the search finite. The resulting solver returns the minimum task-exact relation-rank cost and the complete minimum frontier over **all partition refinements**.

The minimum frontier can be a non-unique antichain.

### Rank two

Fine coordinates carry `Z^2` hidden labels. Partition-realizable hidden images are exactly the distinct subgroup closures generated by finite hidden-label differences. Each subgroup has a canonical coset partition and exact rank-0/1/2 reachability checker.

Four-coordinate Bell-partition oracles independently verify both subgroup search-space completeness and final minimum-frontier completeness.

## 8. Task precision can be strictly below predicate visibility

Exact examples show

\[
\boxed{\Delta d_{task}=1<2=\Delta d_{guard-visible}}
\]

\[
\boxed{\Delta d_{task}=1<3=\Delta d_{guard-visible}}

The refinement only needs to remove effect-distinguishing reachable branches; it does not need to expose every predicate score explicitly.

## 9. State-local, finite-workload, and global all-state precision

These are distinct optimization levels:

\[
\boxed{\text{state-local minimum}\neq\text{finite-workload minimum}\neq\text{global all-state minimum}.}
\]

Finite workloads require one common refinement to be safe on multiple base-score cosets. Strict examples have per-state minimum cost `1` but common cost `2`.

For a finite scalar band `|w^Tc+b|<=R`, the whole-domain theorem is stronger: if the task is nonconstant on `Z^k`, a globally exact partition must make the scalar observable itself descend. State-local residue shortcuts do not replace global visibility.

## 10. Hidden finite-band theorem

For a scalar hidden fiber

\[
z_0+q\mathbb Z,
\]

define

\[
\rho_q(z_0)=\min_{t\in\mathbb Z}|z_0+qt|.
\]

For `|z|<=R` and `q>0`:

- `rho_q(z_0)>R`: the entire fiber is exactly false;
- `rho_q(z_0)<=R`: the same fiber contains both true and false states;
- a nontrivial hidden fiber can never be uniformly true for a finite band.

A3-to-A4 radius support is a downstream specialization of this theorem.

## 11. Two-guard typed quotient state

For two guards with rank-one hidden image `L=Z h`, write `h=d p` with primitive `p`. Then

\[
\boxed{\mathbb Z^2/L\cong\mathbb Z\oplus\mathbb Z/d\mathbb Z.}
\]

An explicit unimodular transform yields one free integer and one torsion residue. They form a complete hidden-score coset invariant and are computable symbolically from coarse block totals.

For support guards `R-z` and `R+z`, the free invariant is fixed at `±2R`; the changing fiber information is only a finite hidden residue.

## 12. Typed precision certificate, not one scalar

Current partition precision includes at least:

**Relation state**
- relation rank;
- relation quantum;
- relation translation period.

**Future predicates**
- hidden guard rank;
- guard quotient free rank;
- Smith invariant factors;
- torsion factors/order.

For a refinement,

\[
0\le d_P-d_R\le\Delta d_{relation}.
\]

Yet relation precision can improve with `d_P=d_R`, e.g. rank-one mod-2 refinement adds finite torsion detail without changing hidden rational rank.

Thus precision cannot be represented faithfully by one dimension/rank scalar.
