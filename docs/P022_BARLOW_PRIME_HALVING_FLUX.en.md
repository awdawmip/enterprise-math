## 1. Why support-avoidance is stronger than necessary

For the composite-boundary midpoint family

\[
p\equiv5,23\pmod{24},\qquad m=(p-1)/2,
\]

the canonical pure Franel defect can be written

\[
D_m=
\frac{F_m\,\Psi(m)}{2F_{m-1}\Psi(p-2)}.
\]

The forced midpoint gives

\[
p\mid F_m,
\qquad
p\nmid F_{m-1}.
\]

Therefore

\[
\boxed{
v_p(D_m)-v_p(F_m)
=
v_p\Psi(m)-v_p\Psi(p-2).}
\]

It is enough for the two transfer valuations to agree. Requiring every earlier factor to be a p-unit is only one strong way to make both sides zero.

This matters because a future support collision need not kill the one-unit defect route: signed valuation contributions may cancel.

## 2. Recursive prime-halving edge multiplicity

For an odd prime `q`, put

\[
h_q=(q+1)/2.
\]

The canonical central-binomial recursion is

\[
E(q)=E(h_q)-E(2)+e_{h_q}-e_{h_q-1}.
\]

For a positive integer `x`, let `w_q(x)` count how many copies of the odd prime `q` occur over the entire recursive factor-and-half DAG, including descendants reached through repeated maps

\[
q\mapsto(q+1)/2
\]

followed by ordinary factorization.

Then every prime occurrence contributes one oriented adjacent edge

\[
h_q-1\longrightarrow h_q.
\]

## 3. P022-LI35 — the canonical exponent vector is an edge divergence

For every index `j>=2`,

\[
\boxed{
E(x)_j
=
\sum_qw_q(x)
\left(
\mathbf1_{h_q=j}-\mathbf1_{h_q-1=j}
\right).
}
\]

The only coordinate not represented by these edge divergences is `j=1`, where powers of two and the `-E(2)` terms accumulate.

This is harmless for every odd valuation prime because

\[
F_1=2
\]

is a p-adic unit.

## 4. P022-LI36 — exact Franel transfer valuation as DAG flux

Define the Franel valuation gradient across the edge generated by `q`:

\[
\nabla_p(q)
:=
v_p(F_{h_q})-v_p(F_{h_q-1}).
\]

Pairing the divergence formula with the valuation function yields

\[
\boxed{
v_p\Psi(x)
=
\sum_qw_q(x)\nabla_p(q).}
\]

Thus the Franel transfer valuation is a signed flux through the prime-halving DAG.

Because adjacent Franel zeros cannot occur in the legal range, an edge can never have both endpoints p-divisible. Each nonzero gradient therefore records an isolated crossing into or out of a p-adic zero layer.

## 5. P022-LI37 — half-defect correction is a difference of two fluxes

Define

\[
\Phi_p(x)=\sum_qw_q(x)\nabla_p(q).
\]

Then

\[
\boxed{
v_p(D_m)
=
v_p(F_m)+\Phi_p(m)-\Phi_p(p-2).}
\]

Consequently

\[
\boxed{
v_p(D_m)=v_p(F_m)
\iff
\Phi_p(m)=\Phi_p(p-2).}
\]

This is the exact valuation-preservation target.

Support avoidance implies both fluxes vanish and is therefore sufficient, but no longer appears as the logically necessary conjecture.

## 6. Relation to the integer companion and collision DAG

The integer midpoint companion detects which edge endpoints are zero modulo `p`. If `j=m-d`, then

\[
p\mid F_j\iff p\mid H_d.
\]

The prime-halving DAG reduction says `j` can influence the flux only if an adjacent prime

\[
2j-1=p-2d-2
\quad\text{or}\quad
2j+1=p-2d
\]

actually occurs in the recursive ancestor set.

Hence the current hierarchy is:

1. `rank > support ceiling` — cheap sufficient safety;
2. no companion-hit / ancestor-prime endpoint collision — stronger sufficient safety;
3. if collisions occur, compute the signed edge gradients and multiplicities;
4. the exact theorem target is flux balance, not set disjointness.

This prevents a future support collision from being misclassified as an automatic failure of the low-order identifiability route.

## 7. Executable checks
