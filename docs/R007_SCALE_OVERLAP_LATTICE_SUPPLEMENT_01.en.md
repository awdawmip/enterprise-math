# R007 Scale-Overlap Lattice Supplement 01

Status: `PROVED WIP / CROSS-ROUTE SUPPLEMENT / NOT CANONICAL`

Scope: continuation of `RS-R007-SCALE-COLLAPSE-DESCENT-NOGO`; bridge to P023/P024 and R005A/R005B.

This note records a second structural layer of R007. The first-stage no-descent theorem concerns a fixed quotient and a fixed perfect-power collapse. Here the state itself is a finite family of uniform scales, and the central object is the overlap geometry of those scale layers.

## 1. Weighted scale-overlap nerve

For a positive integer scale `d`, write

\[
I_{d,i}=\left(\frac{i}{d},\frac{i+1}{d}\right),
\qquad 0\le i<d.
\]

For a finite nonempty scale family `S`, define the scale-overlap nerve `N(S)`:

- vertices are the colored cells `(d,i)` with `d in S`;
- a set of vertices is a simplex when the corresponding open intervals have a common positive-length intersection;
- every full-color maximal simplex is weighted by the rational length of that common intersection.

The full-color maximal simplices are exactly the atomic intervals cut out by the union of all grid boundaries.

This one weighted object will carry both the gcd meet and the lcm join, but in different ways.

## 2. Connectivity constructs the gcd meet object

Let

\[
g=\gcd(S).
\]

The points that are grid boundaries for every scale in `S` are exactly

\[
\frac{k}{g},\qquad 1\le k<g.
\]

Hence the union of all open scale cells is `(0,1)` with those common boundaries removed, so it has exactly `g` connected components. Every finite nonempty intersection of scale cells is an interval. The standard good-cover nerve theorem therefore gives

\[
\mathcal N(S)\simeq \bigsqcup_{k=0}^{g-1}(0,1).
\]

In particular,

\[
\beta_0(\mathcal N(S))=\chi(\mathcal N(S))=g,
\qquad
\beta_j(\mathcal N(S))=0\quad(j\ge1).
\]

There is a stronger object-level statement. Since `g | d` for every `d in S`, each `d`-cell lies in one and only one `g`-cell. Its component label is

\[
\pi_{d\to g}(i)=\left\lfloor\frac{i}{d/g}\right\rfloor.
\]

Overlap edges never cross a `g`-boundary, and the cells inside each `g`-block form one connected component. Thus the ordered component quotient is canonically

\[
\boxed{\pi_0\mathcal N(S)\cong R_g,}
\]

and the map from each input scale `R_d` to this quotient is exactly the canonical divisibility projection `R_d -> R_g`.

So the overlap geometry constructs the gcd as the actual meet-scale object, not merely as a component count.

### 2.1 Colored simplex counts

For a nonempty subfamily `T subseteq S`, let `A(T)` be the number of atomic intervals after overlaying the grids in `T`. Boundary-set intersections are gcd grids, so inclusion-exclusion gives

\[
\boxed{
A(T)=
\sum_{\varnothing\ne U\subseteq T}
(-1)^{|U|+1}\gcd(U).
}
\]

The number of simplices whose color set is exactly `T` equals `A(T)`. Therefore the complete colored f-vector is determined by subset gcd data.

Example:

\[
S=\{6,10,15\}
\]

has pairwise component counts `2,3,5`, yet the three-scale nerve is connected because `gcd(6,10,15)=1`. Its f-vector is

\[
(f_0,f_1,f_2)=(31,52,22),
\]

so

\[
31-52+22=1.
\]

Thus pairwise disconnected fields need not remain disconnected after higher multiscale gluing.

## 3. Rational atom metric recovers the lcm join

Let the atomic interval lengths of the overlaid grids be

\[
\ell_1,\ldots,\ell_m\in\mathbb Q_{>0}.
\]

Then

\[
\boxed{
\operatorname{lcm}(S)
=
\operatorname{lcm}igl(
\operatorname{den}(\ell_1),\ldots,
\operatorname{den}(\ell_m)
\bigr),
}
\]

where every denominator is taken after reduction.

### Proof

Put

\[
L=\operatorname{lcm}(S).
\]

Every source boundary is an `L`-grid boundary. Write all distinct sorted boundaries as

\[
0=\frac{b_0}{L}<\frac{b_1}{L}<\cdots<\frac{b_m}{L}=1
\]

with integers `b_j`. The atom lengths are

\[
\ell_j=\frac{a_j}{L},
\qquad
a_j=b_j-b_{j-1}>0.
\]

The integer boundary coordinates contain every multiple of `L/d`, for each `d in S`. Therefore the subgroup of `Z` generated by all boundary coordinates has gcd

\[
\gcd_{d\in S}\frac{L}{d}=1,
\]

because for every prime dividing `L`, at least one input scale realizes the maximal exponent of that prime. Adjacent gaps and boundary coordinates generate the same subgroup, so

\[
\gcd_j a_j=1.
\]

The reduced denominator of `a_j/L` is `L/gcd(L,a_j)`. Prime-by-prime, the lcm of these reduced denominators has exactly the full valuation of `L`, because the `a_j` have gcd one. Hence it is `L`.

### 3.1 Uniformization is a reflector

Uniform partitions are not closed under ordinary joins inside the lattice of finite rational interval partitions. For example, the common refinement of scales `2` and `3` has nonuniform atom lengths rather than being the uniform `6`-partition.

For any finite rational interval partition `P`, however, there is a unique least uniform refinement `U(P)`: take the lcm of the reduced denominators of all rational boundary points. Thus `U` is the least-uniform-majorant reflector onto uniform partitions.

For uniform input scales,

\[
\boxed{
\mathsf U\!\left(\bigvee_{d\in S}\mathcal P_d\right)
=
\mathcal P_{\operatorname{lcm}(S)}.
}
\]

By contrast, the ordinary meet of uniform input partitions stays uniform:

\[
\boxed{
\bigwedge_{d\in S}\mathcal P_d
=
\mathcal P_{\gcd(S)}.
}
\]

So the uniform-scale world is meet-closed, while ordinary joins generally leave it and require a canonical uniformization closure to return.

## 4. The divisor-lattice scale envelope

Write

\[
g=\gcd(S),\qquad L=\operatorname{lcm}(S).
\]

Every input scale lies in the divisibility interval `[g,L]`. For every prime `p`, put

\[
m_p=\min_{d\in S}v_p(d),
\qquad
M_p=\max_{d\in S}v_p(d).
\]

Then

\[
\boxed{
[g,L]_{\mid}
\cong
\prod_p[m_p,M_p].
}
\]

A prime direction with `m_p=M_p` is locked across the family; a direction with `m_p<M_p` genuinely varies. Its depth span is `M_p-m_p`. The number of varying prime directions is the product dimension of the scale envelope, and

\[
|[g,L]_{\mid}|
=
\prod_p(M_p-m_p+1)
=
\tau(L/g).
\]

This sharpens the informal statement “different prime factors are different collapse dimensions”: a direction is a dimension of the current scale family only when its prime exponent actually varies inside that family.

## 5. Two-scale forest geometry and Euclidean leaf coding

For two scales `d,e`, let `B(d,e)` be the bipartite positive-overlap graph. Put

\[
g=\gcd(d,e),
\qquad
d'=d/g,
\qquad e'=e/g.
\]

Then

\[
\boxed{
\#\pi_0 B(d,e)=g,
\qquad
|E(B)|=d+e-g.
}
\]

The graph is a forest of `g` isomorphic tree components. Assume `d'<=e'`. In each component, every internal `d'`-grid boundary lies inside a unique `e'`-cell; that fine cell has degree two and bridges two adjacent coarse cells. There are exactly `d'-1` such bridge cells. All remaining `e'-d'+1` fine cells are leaves. Hence each component is an alternating subdivided path with leaf bundles attached to the `d'`-side vertices, and

\[
\boxed{
\operatorname{diam}(	ext{component})=2d'
=\frac{2\min(d,e)}{\gcd(d,e)}.
}
\]

When `g=1` and `e=qd+s`, `0<s<d`, the fine-side leaf multiplicities satisfy

\[
\lambda_i(d,e)-(q-1)=\lambda_i(d,d+s).
\]

After removing the forced left-endpoint leaf, the residual binary decoration is

\[
w_i=
\left\lfloor\frac{(i+1)s}{d}\right\rfloor
-
\left\lfloor\frac{is}{d}\right\rfloor,
\]

a rational lower mechanical word. Its one-position gaps recursively encode the next Euclidean quotient/remainder and hence the continued-fraction data.

The relation between mechanical/Christoffel/Sturmian words and Euclidean/continued-fraction recursion is classical prior art. The R007 specialization is the exact appearance of that coding as the leaf decoration of the scale-overlap forest.

## 6. Prime splitting semantics

Since

\[
\#\pi_0B(n,d)=\gcd(n,d),
\]

define the first disconnect scale

\[
D(n)=
\min\{2\le d\le n:B(n,d)\text{ is disconnected}\}.
\]

Then

\[
\boxed{D(n)=\operatorname{spf}(n).}
\]

Thus

\[
\boxed{
n\text{ is prime}
\iff
B(n,d)\text{ is connected for every }2\le d<n.
}
\]

For a prime direction `p`,

\[
\boxed{
\#\pi_0B(n,p^k)
=p^{\min(v_p(n),k)}.
}
\]

So `p` is a split direction and `v_p(n)` is its splitting saturation depth.

The binary split observable

\[
\chi_d(n)=\mathbf 1\{\gcd(n,d)>1\}
\]

satisfies

\[
\boxed{
\chi_d=\bigvee_{p\mid d}\chi_p
=\chi_{\operatorname{rad}(d)}.
}
\]

Prime powers deepen an existing direction but do not create a new binary split direction. Scanning scales in increasing order and marking the future `n` for which `B(n,p)` disconnects reproduces the semantics of the sieve of Eratosthenes. This is a structural reformulation, not a speedup claim.

## 7. Provenance no-descent: overlay does not determine meet

Let the true state be a finite scale family `S`. Define

\[
Q(S)=\text{the unlabeled overlay partition},
\qquad
H(S)=\gcd(S).
\]

The visible overlay can be strictly finer while still losing the layer relation needed by `H`.

Example:

\[
S_1=\{6\},
\qquad
S_2=\{2,6\}.
\]

The `2`-grid is already contained in the `6`-grid, so

\[
Q(S_1)=Q(S_2),
\]

including identical atom lengths. Hence the lcm/join remains recoverable and equals `6`. But

\[
H(S_1)=6,
\qquad
H(S_2)=2.
\]

Therefore meet/common-scale does not descend through the layer-forgetting overlay quotient.

### 7.1 Exact repair width over a uniform overlay

Fix the visible overlay `P_M`. Any hidden scale must divide `M`, and the boundary `1/M` forces the scale `M` itself to be present. Therefore the hidden fiber consists exactly of all subsets of `Div(M)` containing `M`, so it has

\[
\boxed{2^{\tau(M)-1}}
\]

provenance states.

The possible future gcd values are exactly all divisors of `M`:

\[
\boxed{
H(Q^{-1}(P_M))=\operatorname{Div}(M).
}
\]

Thus the coarsest one-shot repair for the future task “answer the common scale” has exactly `tau(M)` classes; storing the gcd is sufficient. A fixed-length worst-case code therefore needs

\[
\left\lceil\log_2\tau(M)\right\rceil
\]

bits, not the full provenance state.

For `g | M`, the number of hidden families with exact repair value `g` is

\[
\boxed{
C_M(g)=
\sum_{h\mid M/g}
\mu(h)\,2^{\tau(M/(gh))-1}.
}
\]

This is ordinary Möbius inversion on the divisor lattice. It quantifies how much provenance remains deleted even after the task-relative repair is restored.

For squarefree `M` with `k` prime factors, `tau(M)=2^k`: the one-shot gcd repair needs only `k` fixed-length bits, while the full provenance fiber has `2^{2^k-1}` states.

## 8. Future language enlarges the required state

The small repair above is specific to a one-shot gcd query. If layers have stable identities and the future language may delete arbitrary named layers before observing the remaining gcd, then the predictive state becomes much finer.

By deleting all layers except layer `i`, the future can observe

\[
\gcd(\{d_i\})=d_i.
\]

Hence any two states differing in any labeled layer scale are behaviorally distinguishable. Under this richer future language, full per-layer scale data is required.

This gives a finite exact example of the P023/P024 principle: the required state is determined by the future operation language, not by a scalar notion of present “precision.”

## 9. Deletion-horizon filtration from gcd to lcm

For a labeled family

\[
S=(d_1,\ldots,d_m),
\]

and deletion budget `0<=h<=m-1`, define

\[
E_h(S)
=
\operatorname{lcm}_{|D|\le h}
\gcd(S\setminus D).
\]

For each prime `p`, sort the layer valuations:

\[
a_{p,(1)}\le\cdots\le a_{p,(m)}.
\]

Then

\[
\boxed{
v_p(E_h)=a_{p,(h+1)}.
}
\]

Indeed, to raise the surviving minimum beyond the `(h+1)`-st order statistic one must delete at least `h+1` lower layers, while deleting the `h` lowest layers attains that statistic.

Therefore

\[
\boxed{
E_0\mid E_1\mid\cdots\mid E_{m-1},
}
\]

with endpoints

\[
\boxed{
E_0=\gcd(S),
\qquad
E_{m-1}=\operatorname{lcm}(S).
}
\]

This is a deletion-horizon chain from meet to join.

### 9.1 Envelope is not joint reachability

The chain only stores prime-direction marginal order statistics. It does not preserve which prime depths occur together in one layer.

For example,

\[
S_1=\{6,10,15\},
\qquad
S_2=\{30,2,15\}
\]

have the same sorted valuation multiset `{0,1,1}` in each of the prime directions `2,3,5`, hence both have

\[
(E_0,E_1,E_2)=(1,30,30).
\]

But after one deletion their exact reachable gcd sets differ. For `S_1`, deleting exactly one layer gives `{2,3,5}`; for `S_2` it gives `{1,2,15}`.

So a coordinatewise capability envelope must not be confused with a jointly reachable future state.

## 10. Capability ideals and exact reachable closure

Define the defect set of a candidate common scale `c` by

\[
\operatorname{Def}_S(c)=\{i:c\nmid d_i\}.
\]

The scale `c` can divide the gcd of some state reachable after at most `h` deletions if and only if all defect layers can be deleted:

\[
\boxed{
c\in\mathcal C_h(S)
\iff
|\operatorname{Def}_S(c)|\le h.
}
\]

Thus

\[
\mathcal C_h(S)
=
\{c\mid\operatorname{lcm}(S):|\operatorname{Def}_S(c)|\le h\}
\]

is a divisor-lattice order ideal, with

\[
\mathcal C_0\subseteq\cdots\subseteq\mathcal C_{m-1}.
\]

Its join is the deletion envelope:

\[
\boxed{E_h=\bigvee\mathcal C_h.}
\]

The envelope is lossless for joint divisibility capability exactly when the ideal is principal:

\[
\boxed{
\mathcal C_h=\operatorname{Div}(E_h)
\iff
E_h\in\mathcal C_h
\iff
|\operatorname{Def}_S(E_h)|\le h.
}
\]

To classify exact reachable gcd outputs, define supporter layers

\[
\operatorname{Supp}_S(c)=\{i:c\mid d_i\}
\]

and, whenever the supporter set is nonempty,

\[
\Gamma_S(c)
=
\gcd\{d_i:i\in\operatorname{Supp}_S(c)\}.
\]

Then `Gamma_S` is extensive, monotone in divisibility order, and idempotent. Moreover,

\[
\boxed{
c\text{ is the exact gcd of some nonempty surviving subfamily}
\iff
\Gamma_S(c)=c.
}
\]

With deletion budget `h`, the exact reachable set is therefore

\[
\boxed{
R_h(S)
=
\{c:\Gamma_S(c)=c,\ |\operatorname{Def}_S(c)|\le h\}.
}
\]

The hierarchy is

\[
\boxed{
R_h=\text{closed exact outputs},
\qquad
\mathcal C_h=\downarrow R_h,
\qquad
E_h=\bigvee R_h.
}
\]

## 11. Formal Concept Analysis boundary

The closure `Gamma_S` is not a new general closure mechanism. It is an instance of the standard Galois-connection machinery of Formal Concept Analysis (FCA).

Take the layer indices as objects and prime-power divisibility conditions `p^a` as attributes; layer `i` has attribute `p^a` exactly when `p^a | d_i`. Then:

- the extent of a candidate divisor is its supporter set;
- taking all attributes common to those supporters produces the gcd closure `Gamma_S`;
- the condition `|Supp_S(c)| >= m-h` is a minimum-support threshold;
- `Gamma_S`-fixed candidates at that threshold correspond to closed frequent divisibility patterns.

FCA closure operators, concept lattices, and frequent closed-itemset algorithms are mature prior art. Existing algorithms should be consumed for large-scale enumeration rather than reimplemented inside R007. Relevant general prior-art landmarks include the standard FCA/Galois-connection literature and algorithms for constructing concept lattices and frequent closed itemsets.

The R007-specific contribution is the translation from scale-layer deletion futures and common-scale observables into this divisibility incidence context, together with the overlap-geometry connection to the same gcd/lcm scale objects.

## 12. Boundary statements and next formalization targets

The following distinctions must remain explicit:

1. `gcd = component quotient` and `lcm = atom-denominator uniformization` are structural reformulations, not faster arithmetic algorithms.
2. Mechanical/Christoffel/continued-fraction recursion and FCA/Galois closures are prior mathematics.
3. Divisor-only freedom at a prime scale does not imply full all-scale naturality; non-divisor levels can still obstruct an operation.
4. `E_h` is a join envelope, not necessarily an exact reachable common scale.
5. An unlabeled overlay can preserve lcm while irreversibly losing gcd provenance.
6. Minimal repair is always relative to the declared future language.

Recommended formalization order:

- Lean: two-scale overlap component/gcd theorem;
- Lean: Farey bridge-descent and one-step extension theorem from the main R007 line;
- Lean or finite-order formalization: provenance no-descent and exact repair width over `P_M`;
- reusable theorem layer: deletion-horizon capability ideal and `Gamma_S` closure;
- cross-route consumption by R005A/R005B without claiming algorithmic speedup or general FCA novelty.
