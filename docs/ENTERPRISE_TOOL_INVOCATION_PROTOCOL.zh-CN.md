# Enterprise Math 工具与方法选择协议

[英文正文](ENTERPRISE_TOOL_INVOCATION_PROTOCOL.md) · 机器规则：`tool_invocation_policy.json`

状态：ACTIVE / AUTONOMOUS METHOD SELECTION PROTOCOL

## 方法自主，目标与证据约束

复用已有工具是有益的默认选择，不是研究前置条件，也不是固定思考顺序。模型围绕任务目标、用户明确假设、范围及验收标准，自主选择、重排、跳过或替换研究方法。可为数学洞见、性能、简洁性或独立验证采用替代实现，即使其输入输出与旧工具相同；无需先证明能力缺口，无需例外申请。任务书由助手提出的研究步骤是参考方案，不限制模型自主思考；用户明确要求的实验条件及盲实验隔离不因此取消。

## 比较与真实性

只有实际声称方法新颖性或接纳共享可复用工具时，才需要相关、充分的既有工作比较。无需为每次启动、推导、继续或保存成果预先遍历全部目录、完成固定表单。

识别旧工具不等于使用过；实际运行、定理应用、组合、扩展、能力缺口和 `ALTERNATIVE_APPROACH_CHOSEN` 分开记录。已有实现不能运行时不得声称运行过，也不能把环境缺失说成数学能力缺口。需要比较时，在现有成果中简短说明选用或不用的原因即可。

输入输出相同不自动否定结构、证明或效率上的贡献，也不证明新颖性。仅换名、包装、领域实例通常分类为别名、特化或 facade，而非新的数学机制。可保留有用的同接口替代方案，按实际贡献分类。

## 角色及盲实验

TASK、Driver、Steward 自主决定研究和审查顺序；重大新颖性或共享工具决策使用相关证据，不强制先复用、证明缺口或逐项回答清单。工具目录、方法索引、源码是可按需选择的证据来源，不是必须按顺序读完的步骤。

FREE A 及用户明确要求的 TASK 来源白名单、盲实验和冻结点继续生效。不能为了查重提前暴露禁止的工具词汇或成果。冻结后，在实际提出新颖性或共享工具主张时进行比较，不把立即查重变成继续研究的前置条件。普通任务不能自创盲实验豁免来源或真实性要求。

## 归集与语义边界

当结果改变共享工具能力或路由时，更新相关 registry/inventory；没有这类变化时，无需为了完整性新增工具或分类记录。工具接纳、复用事实和新颖性是不同事实。

保留定理/工具真实 owner 与现行权限。工具只能在其真实前提、语义类型和有效范围内使用；例如不能凭空添加观测、擅自丢弃有意义差异或把诊断结论提升为唯一修复。P000、用户假设、证据真实性和来源隔离不变。
