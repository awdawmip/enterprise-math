# A3 Guard-Image Lattice Supplement 07 — Canonical Hidden-Subgroup Refinement and a Complete Rank-Two Task Solver

Status: `RESEARCH WIP / GENERAL SUBGROUP-REFINEMENT THEOREM + COMPLETE RANK-TWO STATE-LOCAL SOLVER`

## 1. The general form behind rank-one modulus refinement

In Supplement 06, a rank-one parent hidden lattice

\[
L_{parent}=\mathbb Z h
\]

was refined by subgroups `q Z h`, and splitting hidden labels by residues modulo `q` gave the canonical coarsest partition.

The same structure holds in arbitrary hidden rank.

Let

\[
L=W(K_P)\subseteq\mathbb Z^r
\]

have rank `d`, and choose an exact integer basis isomorphism

\[
H:\mathbb Z^d\xrightarrow{\cong}L.
\]

## 2. A3-G26 — Hidden coordinate labels

Fix an anchor `a` in each parent block `B`. For every `i in B`,

\[
W_i-W_a\in L.
\]

Because `H` is a `Z`-basis, there is a unique

\[
\boxed{\lambda_i\in\mathbb Z^d}
\]

with

\[
\boxed{W_i-W_a=H\lambda_i.}
\]

Set the anchor label to zero. Changing the anchor translates every label in that parent block by the same vector, so pair differences and subgroup cosets are invariant.

## 3. A3-G27 — Canonical Hidden-Subgroup Refinement Theorem

Let

\[
M\le\mathbb Z^d
\]

be any integer subgroup. Inside each parent block define

\[
\boxed{i\sim_M j\iff\lambda_i-\lambda_j\in M.}
\]

Because `M` is a subgroup, this is an equivalence relation. Let its classes form the refinement

\[
\boxed{R_M.}
\]

If `i,j` remain in one `R_M` block, then

\[
W_i-W_j=H(\lambda_i-\lambda_j)\in H(M),
\]

so

\[
\boxed{W(K_{R_M})\subseteq H(M).}
\]

Conversely, if a refinement `R` satisfies

\[
W(K_R)\subseteq H(M),
\]

then any two coordinates in one `R` block have label difference in `M`, hence every `R` block lies inside an `R_M` class. Therefore

\[
\boxed{R\preceq R_M.}
\]

Thus `R_M` is the unique coarsest partition refinement whose hidden image is contained in `H(M)`.

## 4. A3-G28 — Exact-image preservation

Suppose an actual refinement `R` has exact hidden image

\[
\boxed{W(K_R)=H(M).}
\]

By G27, `R` refines `R_M`, hence

\[
H(M)=W(K_R)\subseteq W(K_{R_M}).
\]

The containment part of G27 gives the reverse inclusion, so

\[
\boxed{W(K_{R_M})=H(M).}
\]

Therefore any refinement that realizes one hidden subgroup has a canonical partition that is no finer and realizes exactly the same hidden guard lattice. For a fixed current fine state, both child fibers have the same score coset

\[
g+H(M).
\]

Any state-local task whose ambiguity depends only on reachable coarse effects is therefore equally safe or unsafe on the arbitrary refinement and its canonical replacement.

## 5. A3-G29 — Partition-realizable hidden subgroups form a finite family

Every child image is generated by coefficient differences inside child blocks. In parent hidden coordinates, every such generator belongs to the finite set

\[
\boxed{
D=\{\lambda_i-\lambda_j:\ i,j\text{ lie in one parent block}\}.
}
\]

Hence every refinement image subgroup

\[
M_R=H^{-1}(W(K_R))
\]

is generated by a subset of `D`.

Conversely, if

\[
M=\langle D_0\rangle,
\qquad D_0\subseteq D,
\]

then every endpoint pair of a generator in `D_0` lies in one `R_M` equivalence class, so the child image contains `D_0` and therefore `M`; G27 gives the reverse containment. Thus

\[
\boxed{W(K_{R_M})=H(M).}
\]

Therefore

\[
\boxed{
\{\text{partition-realizable hidden images}\}
=
\{\langle D_0\rangle:D_0\subseteq D\}
\text{ after subgroup deduplication}.
}
\]

The family is finite. It can still be exponential in the worst case; no universal polynomial enumeration claim is made.

## 6. Executable rank-two specialization

For `d=2`, Supplement 02 supplies exact integer bases. Subgroups of `Z^2` are represented canonically as:

- rank zero: `()`;
- rank one: one canonical step;
- rank two: a canonical HNF-style basis pair.

The branch adds:

- `canonical_z2_subgroup`;
- `z2_subgroup_contains`;
- `rank_two_guard_labels`;
- `rank_two_canonical_sublattice_refinement`;
- `rank_two_label_differences`;
- `rank_two_realizable_image_subgroups`.

Rather than enumerate all set partitions, the reference implementation starts from the zero subgroup, adds finite hidden-label differences, canonicalizes after every addition, and deduplicates equal subgroup closures.

## 7. A3-G30 — Complete rank-two state-local minimum task precision

Fix:

- a rank-two parent partition `P`;
- the current fine state's base guard scores `g`;
- a fixed parent-level branch-effect map
  \[
  E:\{F,T\}^r\to\mathcal Y.
  \]

Enumerate the distinct realizable coordinate subgroups

\[
M_1,\ldots,M_s.
\]

For each subgroup:

1. construct its unique coarsest canonical partition `R_(M_a)`;
2. inspect the resulting hidden rank `0,1,2`;
3. rank zero gives one current pattern;
4. rank one uses the exact switch sweep and branch-erasure report;
5. rank two uses Supplement 02's exact integer halfplane solver and branch-erasure report;
6. record
   \[
   \Delta d_a=|R_(M_a)|-|P|.
   \]

Then

\[
\boxed{
\Delta d_{min}=\min_{a:\,R_(M_a)\text{ safe}}\Delta d_a
}
\]

is the minimum state-local task-exact relation-rank gain over **all partition refinements**.

Indeed, any safe refinement `R` has an exact image `H(M_R)`; G28 replaces it by a no-finer canonical `R_(M_R)` with the same current score coset and therefore the same reachable-effect ambiguity.

As in rank one, the minimum frontier may contain multiple incomparable canonical partitions.

## 8. Four-slot rank-two strict precision-separation example

Take guards

\[
w^{(1)}=(0,1,2,0),
\qquad
w^{(2)}=(0,1,2,1).
\]

For the single-block parent, the hidden labels in the standard `Z^2` basis are

\[
\boxed{(0,0),\ (1,1),\ (2,2),\ (0,1).}
\]

Their differences generate the full parent image

\[
\boxed{L_{parent}=\mathbb Z^2.}
\]

At fine state `c=(0,1,0,0)`, the base scores are

\[
g=(1,1).
\]

The parent full-rank fiber realizes all four Boolean patterns. Assign a different branch effect only to `(T,F)`.

Choose the diagonal subgroup

\[
M=\mathbb Z(1,1).
\]

Its canonical coset partition is

\[
\boxed{R_M=\{\{0,1,2\},\{3\}\}.}
\]

The child score coset

\[
(1,1)+t(1,1)
\]

realizes only `(F,F)` and `(T,T)`, so `(T,F)` disappears and the task is exact with

\[
\boxed{\Delta d_{task}=1.}
\]

All four hidden labels are distinct, so exact guard visibility requires the singleton partition and

\[
\boxed{\Delta d_{guard}=3.}
\]

Hence

\[
\boxed{\Delta d_{task}=1<3=\Delta d_{guard}.}
\]

Rank two therefore exhibits the same strict task-versus-guard precision separation, with an even larger gap.

For the four-coordinate example, the test suite performs two complete Bell-partition audits.

Thus the subgroup search omits no partition-realizable hidden lattice.

### Minimum-frontier oracle

This independently checks both search-space completeness and optimizer completeness.

## 11. Meaning in general hidden rank

G26–G29 do not depend on `d=2`. For arbitrary hidden rank,

\[
\boxed{
\text{partition refinement}
\longleftrightarrow
\text{finite-label-generated subgroup }M\le\mathbb Z^d
\longrightarrow
\text{canonical coset partition }R_M.
}
\]

What remains implementation-specific is efficient subgroup canonicalization/membership and branch reachability in general `d`.

Combined with Supplement 03, a future general solver can use established HNF/SNF for subgroup representation and fixed-dimension ILP for reachability, while A3 supplies the canonical subgroup/refinement semantics and the minimum relation-rank objective. A3 should not duplicate a general lattice/ILP library.

## 12. Current boundary

The complete solver is still:

- state-local;
- for one fixed parent-level branch-effect language;
- over a finite fine coordinate set.

It does not yet synthesize one global coarse program valid over many parent coarse states.

Subgroup enumeration can remain exponential in the worst case; the theorem replaces Bell-partition search with behaviorally meaningful subgroup search but does not claim a universal complexity improvement.
