## 1. From a scalar gcd to a lattice index

Stage 31 defines `rho_gen` for a rank-one unit relation by taking the gcd of all accessible scale factors. The higher-rank replacement is the subgroup index inside a declared relation lattice.

Let

\[
\Lambda\subseteq\operatorname{im}_{\mathbb Z}B
\]

be a relation subgroup with integer basis

\[
\boxed{g_1,\ldots,g_k.}
\]

At ambient access radius `R`, define

\[
\boxed{S_R=Z_R(B)\cap\Lambda.}
\]

Write each state `t in S_R` in exact basis coordinates

\[
t=\sum_{i=1}^k z_i(t)g_i,
\qquad
z(t)\in\mathbb Z^k.
\]

The subgroup generated by the accessible relation states is complete exactly when the coordinate vectors `z(t)` generate all of `Z^k`.

## 2. P025-T88 — maximal-minor index criterion

Let

\[
C_R=\langle z(t):t\in S_R\rangle\subseteq\mathbb Z^k.
\]

If the coordinate vectors have rational rank below `k`, then `C_R` has infinite index in `Z^k`.

If they have full rank `k`, then the finite index is

\[
\boxed{
[\mathbb Z^k:C_R]
=
\gcd\{|\det M|:M\text{ is any }k\times k\text{ minor of the coordinate generator matrix}\}.
}
\]

Therefore

\[
\boxed{
C_R=\mathbb Z^k
\iff
\operatorname{rank}_{\mathbb Q}C_R=k
\text{ and }
\gcd(\text{maximal minors})=1.
}
\]

This is the standard determinantal-divisor criterion for a full-rank sublattice of `Z^k`.

## 3. P025-D20 — higher-rank relation-generator radius

Define

\[
\boxed{
\rho_{\rm gen}(B,\Lambda)
=
\min\{R:\langle Z_R(B)\cap\Lambda\rangle=\Lambda\}.
}
\]

Using any integer basis of `Lambda`, P025-T88 gives an exact finite test at each radius.

The definition is basis-independent. Changing the basis multiplies coordinate vectors by a unimodular matrix and therefore preserves rational rank and maximal-minor gcd one.

## 4. P025-T89 — finiteness and a direct-basis upper bound

Every basis vector `g_i` lies in `im_Z B`, so it has finite ambient access radius

\[
\kappa_B(g_i)<\infty.
\]

Let

\[
R_{\rm basis}=\max_i\kappa_B(g_i).
\]

At radius `R_basis`, every declared basis vector is directly accessible and hence generates `Lambda`. Therefore

\[
\boxed{
\rho_{\rm gen}\le R_{\rm basis}<\infty.
}
\]

So the generator radius always exists for a finitely generated relation subgroup.

The upper bound depends on the chosen basis; `rho_gen` does not.

## 5. Rank-one recovery

When `k=1`, every accessible state has one integer coordinate `z(t)`. The maximal minors are just those integers, and the index criterion becomes

\[
\boxed{
\gcd\{|z(t)|:t\in S_R\}=1.
}
\]

Thus Stage 31 is exactly the rank-one specialization of Stage 32.

## 6. Shared-prime relation example

For blocks `(2,4,6)` and relation

\[
4\cdot2+4-2\cdot6=0,
\]

Stage 30 gives the rank-one relation subgroup generated by

\[
\boxed{g=(2,8,8).}
\]

No nonzero relation state is accessible at radius one. At radius two, `g` itself is accessible. Hence

\[
\boxed{\rho_{\rm gen}=2.}
\]

## 7. Rank-two abc example

For `2+3=5`, the block derivative matrix is the identity and

\[
\Lambda=\{(u,v,w):u+v=w\}.
\]

Take basis

\[
\boxed{g_1=(1,0,1),\qquad g_2=(0,1,1).}
\]

Both are accessible at radius one, so

\[
\boxed{\rho_{\rm gen}=1.}
\]

## 8. P025-N13 — generator completeness can precede direct access to a chosen basis

The direct-basis upper bound is not intrinsic.

Take ambient matrix `B=I_2`, no relation constraint, so

\[
\Lambda=\mathbb Z^2.
\]

Choose the deliberately long unimodular basis

\[
\boxed{g_1=(10,1),\qquad g_2=(11,1).}
\]

Direct access to these basis vectors requires radii `10` and `11`, so

\[
R_{\rm basis}=11.
\]

But at radius one, the ambient accessible set already contains

\[
e_1=(1,0),\qquad e_2=(0,1).
\]

Their coordinates in the chosen basis are

\[
\boxed{[-1,1],\qquad[11,-10].}
\]

The determinant is

\[
(-1)(-10)-11= -1.
\]

Hence these two radius-one states already generate all of `Z^2`.

Therefore

\[
\boxed{
\rho_{\rm gen}=1
<
R_{\rm basis}=11.
}
\]

So generator completeness is about the subgroup generated by **all** states currently accessible, not whether a preferred coordinate basis has individually entered the ball.

## 9. Architectural consequence

The generator-completeness layer is now basis-free and works in every finite relation rank:

\[
\boxed{
\text{ambient access ball}
\to
S_R=Z_R\cap\Lambda
\to
\langle S_R\rangle
\to
[\Lambda:\langle S_R\rangle]
\to
\rho_{\rm gen}.
}
\]

This is distinct from:

- first nonzero/nondegenerate access;
- direct access to a chosen primitive/basis state;
- intrinsic word geometry generated by radius-one relation-compatible states.

These notions can coincide in special systems but should not be identified by definition.

## 10. Prior-art / ownership boundary

Lattice index via maximal minors, sublattice generation, and unimodular basis invariance are standard integer-lattice mathematics.

P025 does not claim them as new. The project-side contribution under test is their use as an exact finite-precision generation-completeness layer inside the arithmetic derivative-image access geometry.

This is adjacent to A4 split-completeness and A5 intrinsic geometry, but Stage 32 does **not** re-derive the generic split-completeness/geodesicity theorems already present in those routes.
