# A3 Guard-Image Lattice —— 多 Guard Hidden Score Geometry

状态：`RESEARCH WIP / INTEGER-LATTICE ENDPOINT THEOREMS + EXECUTABLE RANK TOOLS`

## 1. 目标

A3 binary threshold theorem 只含一个 guard：

\[
w^Tc+b\ge0.
\]

若 future program 同时依据多个 integer linear guards 分支，简单把“每个 guard 可见/不可见”逐个处理会遗漏 guard 之间的耦合。

真正的 hidden 对象是 partition kernel 在整个 guard-score space 中的整数像格。

## 2. 定义

partition matrix：

\[
A:\mathbb Z^k\to\mathbb Z^\ell,
\qquad
K_A=\ker_{\mathbb Z}A.
\]

有 `r` 个 integer linear guard scores，行向量组成：

\[
W\in\mathbb Z^{r\times k}.
\]

固定一个 coarse state `y=Ac`。同一 fiber：

\[
c+K_A.
\]

其 guard-score vectors 为：

\[
Wc+b+W(K_A).
\]

定义：

\[
\boxed{L_G:=W(K_A)\subseteq\mathbb Z^r.}
\]

称为 **guard-image lattice**。

它精确描述 coarse 世界看不见的 fine motion 能怎样改变全部 guard scores。

## 3. A3-G01 —— coordinate partition 的生成元

coordinate partition 的 kernel 有 canonical basis：每个 coarse block 选 anchor `a`，对同 block 其他 coordinate `i` 使用

\[
e_i-e_a.
\]

因此 `L_G` 的生成元只是 guard coefficients 的 block 内差：

\[
\boxed{
W(e_i-e_a)
=
(w_i^{(1)}-w_a^{(1)},\ldots,w_i^{(r)}-w_a^{(r)}).
}
\]

不需要枚举任何 integer state。

## 4. A3-G02 —— rank 0 = guards 全部 descend

\[
\operatorname{rank}L_G=0
\]

当且仅当：

\[
W(K_A)=0.
\]

即每个 guard score 在 coarse fiber 上恒定，所以所有 guard rows 都 factor through `A`。

对 coordinate partition，这等价于：每个 guard 的 coefficients 在每个 coarse block 内常数。

因此 single-guard 的 `visible` case 是 multi-guard 的 rank-0 特例。

## 5. A3-G03 —— full-rank hidden lattice 命中全部 orthants

若：

\[
\operatorname{rank}L_G=r,
\]

则 `L_G` 是 `Z^r` 的 full-rank sublattice，所以 quotient group：

\[
\mathbb Z^r/L_G
\]

有限。

因此存在某个整数：

\[
d\ge1
\]

满足：

\[
\boxed{d\mathbb Z^r\subseteq L_G.}
\]

现在固定任意 coarse fiber 的 base guard score：

\[
g\in\mathbb Z^r.
\]

对任意 strict sign pattern：

\[
\sigma\in\{-,+\}^r,
\]

逐坐标选择足够大的 signed integers `n_i`，使：

\[
\sigma_i(g_i+d n_i)>0.
\]

而：

\[
dn\in L_G.
\]

所以：

\[
\boxed{
(g+L_G)\cap O_\sigma\neq\varnothing
\quad\text{对每个 strict orthant }O_\sigma.
}
\]

因此：

> **若 hidden guard-image lattice 在 guard space 中 full-rank，则每一个 coarse fiber 内都实际出现全部 `2^r` 个 strict sign patterns。**

这完全是整数格结论，不需要连续极限。

## 6. A3-G04 —— full-rank branch-erasure consequence

考虑由 `r` 个 guard signs 选择 branch 的 finite piecewise affine program。

当前先额外假设：每个 branch affine map 都已经 individually descend 到当前 partition。

若 `rank L_G=r`，每个 coarse fiber 都出现所有 branch sign patterns。因此 whole program exact 当且仅当所有**可达** branch coarse affine effects 相同；full-rank 情形下可达集合就是全部 sign patterns，所以：

\[
\boxed{
\bar T_\sigma=\bar T_\tau
\quad\forall\sigma,\tau\in\{-,+\}^r.
}
\]

此时整个 guard vector identity 都可擦除。

反之，只要两个 branch coarse effects 不同，由于同一 coarse state 的 fiber 内能同时实现这两个 patterns，就得到两个不同 coarse outputs，quotient 不 exact。

这严格推广 binary hidden-guard erasure 的“全部 branch 都实际可达”部分。

注意：本文当前把“每个 branch individually descend”作为显式前提；不在本阶段未经证明把 restricted-region exactness 自动提升为 global branch descent。

## 7. A3-G05 —— partial rank 不能只看 rank

若：

\[
0<\operatorname{rank}L_G<r,
\]

rank 只告诉我们 hidden score variation 的自由度数，不告诉 affine lattice 穿过哪些 orthants。

例如 `r=2`：

- lattice generated by `(1,1)` 沿 diagonal 变化；
- lattice generated by `(1,-1)` 沿 anti-diagonal 变化。

两者 rank 都为 1，但对同一个 base coset，可达 sign patterns 完全不同。

所以：

\[
\boxed{
\text{partial-rank multi-guard future precision}
\text{不能由一个 guard-rank 标量决定。}
}
\]

真正对象仍是：

\[
g+L_G
\]

及其与 threshold orthants/polyhedra 的整数交。

这也是下一阶段必须保留的负边界。
