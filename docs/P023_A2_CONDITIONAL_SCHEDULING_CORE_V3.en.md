This document isolates the task-order and dependency consequences of exact finite repair geometry. Dynamic programming, closure systems, mixed-radix coding, and greedy counterexamples are established mathematical/algorithmic ideas; no historical-priority claim is made for those general ingredients.

## 1. Conditional task cost

Let `X` be finite and let a finite task family be represented by partitions `E_1,...,E_m`. If tasks in `S` are already retained, write `C_S=cap_{i in S} E_i`, with the empty intersection equal to the universal one-block relation.

For a new task `j`, define

\[
\boxed{\rho(j\mid S)=\rho(C_S,E_j).}
\]

This is the minimum alphabet needed to add task `j` while keeping all tasks in `S`. If `S subseteq T`, then

\[
\boxed{\rho(j\mid T)\le \rho(j\mid S).}
\]

More retained context cannot increase the extra repair needed for the same task.

## 2. Order-dependent acquisition

For an order `sigma=(sigma_1,...,sigma_m)`, let

\[
\rho_r=\rho(\sigma_r\mid\{\sigma_1,\ldots,\sigma_{r-1}\}).
\]

The final joint relation `E_*=cap_i E_i` does not depend on order, but the sequential worst-case capacity

\[
\boxed{P_\sigma=\prod_r\rho_r}
\]

can depend on order. Exact counting gives

\[
\boxed{|X/E_*|\le P_\sigma.}
\]

For integer base `B>=2`, put `L_B(n)=min{ell:n<=B^ell}`. The sequential symbol cost is

\[
\boxed{C_B(\sigma)=\sum_r L_B(\rho_r),}
\]

and every order obeys

\[
\boxed{L_B(|X/E_*|)\le C_B(\sigma).}
\]

Thus final-state depth and acquisition depth are distinct quantities.

## 3. Exact equality criterion

At stage `r`, every realized context block branches into at most `rho_r` subblocks. Then

\[
|X/E_*|=P_\sigma
\]

if and only if every stage has **uniform branching**: every currently realized context block has exactly `rho_r` realized extensions. Branch-dependent splits create formal product capacity that no actual state uses.

## 4. Scheduling slack has two exact defects

Let `D_*=L_B(|X/E_*|)`. Then

\[
\boxed{C_B(\sigma)-D_*=S_{\rm radix}(\sigma)+S_{\rm inc}(\sigma)}
\]

where

\[
S_{\rm radix}=\sum_rL_B(\rho_r)-L_B(P_\sigma)
\]

and

\[
S_{\rm inc}=L_B(P_\sigma)-L_B(|X/E_*|).
\]

Both are nonnegative integers. `S_radix` is separate-digit packing overhead; `S_inc` is unrealized incidence-capacity overhead.

## 5. Two exact normalizations

A schedule produces one local repair digit at each stage. Give each realized local child a digit `0,...,rho_r-1`.

### Mixed-radix normalization

The digit tuple is packed bijectively into `[0,P_sigma)`. This removes `S_radix` without changing the stagewise product state.

### Realized-support normalization

Only some packed codes are realized by states in `X`. Ranking the realized codes bijectively gives `[0,|X/E_*|)`. This removes `S_inc`.

Therefore the entire scheduling slack consists of two exact removable representational defects, not an undefined information loss.

## 6. Greedy is not generally optimal

There exists a five-state three-task system in which tasks `A,B` each cost one binary symbol from the empty context, while richer task `C` costs two. A cheapest-next greedy rule chooses `A` or `B` first and pays total cost `3`. Choosing `C` first costs `2` and makes both `A` and `B` zero-cost consequences.

Hence

\[
\boxed{\text{locally cheapest next task need not minimize total acquisition cost}.}
\]

The exact finite scheduler is therefore a subset/closure-state dynamic program rather than a universal greedy rule.

## 7. Zero-cost dependency closure

Define

\[
\operatorname{cl}(S)=S\cup\{j:\rho(j\mid S)=1\}
\]

and iterate to a fixed point. This closure is extensive, monotone, and idempotent. It removes tasks already determined by current precision, so an exact scheduler may work on closure-fixed task sets rather than all raw subsets. But this closure is not generally matroidal: exchange can fail.

## 8. No intrinsic dimension from coordinate count

The same final partition can be generated by different inclusion-minimal task sets of different cardinalities. Binary tasks `A,B` and a bundled task `C=(A,B)` can have both `{C}` and `{A,B}` as inclusion-minimal generating sets for the same final precision.

Therefore the number of task coordinates in a minimal basis is not an intrinsic dimension of the final precision state. Keep separate:

\[
\boxed{D_B=L_B(|X/E_*|)}
\]

(final-state depth),

\[
\boxed{g(\mathcal T)=\min\{|S|:\operatorname{cl}(S)=\mathcal T\}}
\]

(task-language generator number), and

\[
\boxed{A_B(\mathcal T)=\min_\sigma C_B(\sigma)}
\]

(acquisition depth). Only the first is determined by the final partition alone.

## 9. Bounded one-direction repair gives an approximation theorem

For two tasks `E,F`, if `rho(E,F)<=R`, then taking `E` first has base-`B` cost at most

\[
L_B(|X/(E\cap F)|)+L_B(R).
\]

Thus a uniformly bounded directed repair factor gives a uniformly bounded additive approximation to intrinsic final-state depth even when the opposite order is occasionally cheaper.

## 11. Scope boundary

This is a theorem about finite declared task/observation interfaces. It does not say that nature executes an optimal code, that task order is physical time, or that a chosen interface defines ontology. Program owners may specialize the calculus; they should not duplicate the generic scheduling theorem.
