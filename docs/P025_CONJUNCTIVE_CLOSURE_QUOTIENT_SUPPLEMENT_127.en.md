## 1. Unary implication is still overprecise

Supplement 126 constructs the largest unary membership-implication preorder induced by a finite exact-state family

\[
\Omega\subseteq2^P.
\]

Every exact state becomes an ideal of the semantic quotient poset. But unary implication need not capture higher-order conjunction laws among labels.

Stage 127 derives the exact conjunction quotient.

## 2. P025-D50 — extent and conjunctive closure

For a required label set \(S\subseteq P\), define its exact-state extent

\[
\boxed{
E_\Omega(S)
:=
\{X\in\Omega:S\subseteq X\}.
}
\]

Define the closure

\[
\boxed{
\operatorname{cl}_\Omega(S)
:=
\bigcap_{X\in E_\Omega(S)}X,
}
\]

with the empty intersection interpreted as the full label universe \(P\).

This convention is consistent: if no exact state contains \(S\), then no exact state can contain \(P\), because any state containing \(P\) would also contain \(S\).

## 3. P025-T277 — closure-operator laws

For all \(S,T\subseteq P\):

1. extensivity:
   \[
   S\subseteq\operatorname{cl}_\Omega(S);
   \]
2. monotonicity:
   \[
   S\subseteq T
   \Longrightarrow
   \operatorname{cl}_\Omega(S)
   \subseteq
   \operatorname{cl}_\Omega(T);
   \]
3. idempotence:
   \[
   \operatorname{cl}_\Omega(\operatorname{cl}_\Omega(S))
   =
   \operatorname{cl}_\Omega(S).
   \]

Moreover every exact state \(X\in\Omega\) is closed:

\[
\boxed{\operatorname{cl}_\Omega(X)=X.}
\]

So the exact-state family sits inside the closure system generated by arbitrary intersections of exact states.

## 4. P025-T278 — exact operation quotient for conjunction futures

The key identity is

\[
\boxed{
E_\Omega(S)
=
E_\Omega(\operatorname{cl}_\Omega(S)).
}
\]

Indeed every state containing \(S\) contains their intersection `cl(S)`, while `S subseteq cl(S)` gives the reverse implication.

Therefore

\[
\boxed{
E_\Omega(S)=E_\Omega(T)
\iff
\operatorname{cl}_\Omega(S)
=
\operatorname{cl}_\Omega(T).
}
\]

Thus the closure is the exact semantic normal form for the full truth vector of a conjunction query across all exact states.

This is the coarsest query quotient induced by the declared exact-state family.

## 5. P025-T279 — semantic implication preorder is the unary fragment

For labels \(x,y\in P\),

\[
\boxed{
x\preceq_\Omega y
\iff
x\in\operatorname{cl}_\Omega(\{y\}).}
\]

So Supplement 126 is recovered by restricting the full closure operator to singleton queries.

Unary relation geometry is therefore one layer of the complete conjunctive theory, not the whole theory.

## 6. Strict higher-order compression

Take

\[
P=\{a,b,c\}
\]

and

\[
\Omega
=
\{\{a\},\{b\},\{a,b,c\}\}.
\]

Then

\[
\operatorname{cl}(\{a\})=\{a\},
\qquad
\operatorname{cl}(\{b\})=\{b\},
\]

so `a` and `b` are not unary-equivalent and remain incomparable in the semantic implication poset.

But

\[
\boxed{
\operatorname{cl}(\{a,b\})
=
\{a,b,c\}
=
\operatorname{cl}(\{c\}).}
\]

Hence

\[
\boxed{
\{a,b\}
\sim_{\rm conjunction}
\{c\}
}
\]

although the unary poset does not reduce `{a,b}` to one of its members.

The semantic implication quotient has width two, while the full conjunction language already identifies this two-label query with a one-label query.

## 7. Raw query-state collapse

There are formally

\[
2^{|P|}
\]

raw conjunction queries.

The exact semantic query-state count is instead

\[
\boxed{
|\operatorname{Fix}(\operatorname{cl}_\Omega)|,
}
\]

the number of closed sets.

In the three-label example above, eight raw queries collapse to only four closure classes:

\[
\varnothing,
\{a\},
\{b\},
\{a,b,c\}.
\]
