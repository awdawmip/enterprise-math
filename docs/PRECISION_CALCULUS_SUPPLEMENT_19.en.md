## 1. From unary predictive closure to an operation language

Supplement 18 solved the finite unary problem. For one deterministic endomap

\[
F:X\to X
\]

and observation

\[
O:X\to Y,
\]

future-observation refinement computes the largest `F`-compatible equivalence contained in `ker(O)`.

P018-C17 explicitly left open the multi-ary case. A binary operation

\[
\mu:X\times X\to X
\]

can depend on hidden detail in either input, and a family of operations can create **mixed contexts** not visible when each operation is studied separately.

The correct general object is therefore not a generalized carry scalar. It is the congruence closure problem for the operation language that the precision state is required to support.

Let

\[
\Sigma=\{\mu_s:X^{k_s}\to X\}_{s\in S}
\]

be a finite finitary operation signature on a finite state set `X`, and let

\[
E=\ker(O).
\]

## 2. P018-T169 — Exact multi-ary descent is exactly kernel congruence

Status: `PROVED / EXECUTABLE / PARTIALLY LEAN-FORMALIZED`

For one `k`-ary basic operation

\[
\mu:X^k\to X,
\]

the following are equivalent:

1. the formula

   \[
   \bar\mu(Ox_1,\ldots,Ox_k)
   :=O(\mu(x_1,\ldots,x_k))
   \]

   is well-defined on the image of `O`;
2. whenever every input coordinate is observationally equal,

   \[
   O(x_i)=O(y_i)\quad(1\le i\le k),
   \]

   the outputs are observationally equal:

   \[
   \boxed{
   O(\mu(x_1,\ldots,x_k))
   =
   O(\mu(y_1,\ldots,y_k)).
   }
   \]

Equivalently,

\[
\boxed{E=\ker(O)\text{ is compatible with }\mu.}
\]

If `O` is surjective onto `Y`, the descended operation on `Y` is unique.

For an entire signature `Sigma`, every basic operation descends exactly iff `E` is a `Sigma`-congruence.

This is classical quotient-algebra mathematics. The P018 consequence is exact:

> **A precision state is autonomously sufficient for a declared operation language exactly when its precision equivalence is a congruence for that language.**

No floating tolerance or error budget can replace this well-definedness condition when exact operation closure is required.

## 3. P018-T170 — One-coordinate translations are enough

Status: `PROVED / EXECUTABLE / BINARY CORE LEAN-FORMALIZED`

For a `k`-ary operation `mu`, fix every coordinate except coordinate `i`. This gives an elementary one-hole translation

\[
\tau(z)
=
\mu(a_1,\ldots,a_{i-1},z,a_{i+1},\ldots,a_k).
\]

For an equivalence relation `R`, full `k`-coordinate compatibility with `mu` is equivalent to preservation by every such elementary translation.

The nontrivial direction is finite telescoping across coordinates. If

\[
x_i\,R\,y_i
\quad\forall i,
\]

replace one coordinate at a time:

\[
\mu(x_1,\ldots,x_k)
\;R\;
\mu(y_1,x_2,\ldots,x_k)
\;R\;\cdots\;R\;
\mu(y_1,\ldots,y_k).
\]

Transitivity of `R` gives the full result.

Thus a finite multi-ary congruence problem can be reduced to a finite family of unary one-hole translations when `X` and the signature are finite.

## 4. P018-T171 — Contextual closure is the greatest congruence inside a precision equivalence

Status: `PROVED / CLASSICAL SYNTACTIC-CONGRUENCE SPECIALIZATION`

Let `T_1(Sigma)` be the set of all elementary one-hole translations of the basic operations with arbitrary fixed state parameters. Let `M(Sigma)` be the monoid generated by these translations and the identity under composition.

Define

\[
\boxed{
\operatorname{Ctx}_\Sigma(E)
=
\{(x,y):
(c(x),c(y))\in E
\text{ for every }c\in M(\Sigma)\}.
}
\]

Then:

1. `Ctx_Sigma(E)` is an equivalence relation;
2. `Ctx_Sigma(E) subseteq E`;
3. it is preserved by every elementary translation, hence by every basic operation;
4. therefore it is a `Sigma`-congruence;
5. if `R subseteq E` is any other `Sigma`-congruence, then every context preserves `R`, so

   \[
   R\subseteq\operatorname{Ctx}_\Sigma(E).
   \]

Hence

\[
\boxed{
\operatorname{Ctx}_\Sigma(E)
=
\text{the greatest }\Sigma\text{-congruence contained in }E.
}
\]

This is the classical syntactic-congruence construction in the present finite-precision notation. Historical priority is not claimed.

## 5. P018-T172 — A finite context-refinement recurrence computes the closure

Status: `PROVED / EXECUTABLE`

Set

\[
R_0=E.
\]

For any equivalence `R`, define one refinement step

\[
\boxed{
\Gamma_\Sigma(R)
=
R
\cap
\bigcap_{\tau\in T_1(\Sigma)}
\tau^{-1}(R).
}
\]

Then recursively

\[
\boxed{R_{n+1}=\Gamma_\Sigma(R_n).}
\]

Each `R_n` is an equivalence relation and

\[
R_{n+1}\subseteq R_n.
\]

Moreover,

\[
\boxed{
R_{n+1}=R_n
\iff
R_n\text{ is a }\Sigma\text{-congruence}.
}
\]

The forward direction follows because a fixed point is preserved by every elementary translation; T170 then gives full multi-ary compatibility. The reverse direction is immediate because every translation preserves a congruence.

`R_n` can also be read as observational agreement under every composition of at most `n` elementary translations. This is a finite **operation-context depth**, generalizing the future-time depth of Supplement 18.

## 6. P018-T173 — Finite contextual closure stops by `N-c0`

Status: `PROVED / EXECUTABLE`

Assume

\[
N=|X|
\]

and the original observation partition `E` has `c_0` blocks.

Every strict step

\[
R_{n+1}\subsetneq R_n
\]

strictly refines the partition and therefore increases the number of blocks by at least one. Equality has `N` blocks and is always a congruence.

Thus the first fixed-point depth `h_Sigma` satisfies

\[
\boxed{
h_\Sigma\le N-c_0.}
\]

No infinite term limit is required in the finite case.

The executable pressure test includes a four-state binary algebra attaining this bound exactly.

## 7. P018-T174 — The stable finite relation is exactly the syntactic/contextual congruence

Status: `PROVED / EXECUTABLE`

Let `R_*` be the first stable partition from T172–T173.

Because `R_*` is a congruence and `R_* subseteq E`, maximality of T171 gives

\[
R_*\subseteq\operatorname{Ctx}_\Sigma(E).
\]

Conversely, the contextual congruence is contained in `R_0=E` and is preserved by every elementary translation. Induction therefore gives

\[
\operatorname{Ctx}_\Sigma(E)\subseteq R_n
\quad\forall n,
\]

hence in particular

\[
\operatorname{Ctx}_\Sigma(E)\subseteq R_*.
\]

Therefore

\[
\boxed{R_*=\operatorname{Ctx}_\Sigma(E)=\operatorname{Syn}_\Sigma(E).}
\]

A classical potentially infinite context definition has therefore been reduced, for finite `X` and finite signature, to a bounded finite state refinement.

## 8. P018-T175 — The closure quotient is the canonical smallest exact operation state

Status: `PROVED STRUCTURAL CONSEQUENCE / EXECUTABLE`

Because `R_*` is a `Sigma`-congruence, every basic operation descends to

\[
X/R_*.
\]

Because `R_* subseteq ker(O)`, the original observation also factors through this quotient.

Now let `R` be any other exact quotient-state refinement satisfying

\[
R\subseteq\ker(O)
\]

and making every operation in `Sigma` well-defined. Then `R` is a `Sigma`-congruence, so T171 gives

\[
R\subseteq R_*.
\]

Hence `X/R` has at least as many states as `X/R_*`, and its quotient map factors onto the canonical closure quotient.

Thus

\[
\boxed{X/R_*}
\]

is the coarsest / fewest-state exact quotient refinement of the original precision that supports the full declared operation language.

This is a **state sufficiency theorem**, not a claim that every computational protocol must encode the state label literally.

## 9. P018-T176 — Minimal uniform detail alphabet has an exact size

Status: `PROVED / EXECUTABLE`

Suppose we insist on representing the repaired state as

\[
\boxed{(O(x),D(x))}
\]

where `D(x)` takes values in one reusable finite detail alphabet `D`.

For each observation value `y`, let

\[
m_y
=
\#\{R_*\text{-blocks contained in }O^{-1}(y)\}.
\]

Within one observation fiber, different `R_*` blocks must receive different detail labels. Therefore

\[
|D|\ge \max_y m_y.
\]

Conversely, labels can be reused across different observation fibers, so `max_y m_y` labels suffice.

Hence

\[
\boxed{
|D|_{\min}=\max_y m_y.
}
\]

This is an exact finite information count for a uniform `(coarse,detail)` state representation.

## 10. P018-T177 — Unary predictive closure is exactly the one-operation special case

R_{n+1}=E\cap F^{-1}(R_n),

\boxed{

The unary and multi-ary routes are not separate theories; the former is the simplest operation-language instance of the latter.

## 11. P018-T178 — Exact radix-quotient addition forces the full remainder as state detail

Status: `PROVED / EXECUTABLE`

Let

\[
Q_r(n)=\left\lfloor\frac nr\right\rfloor,
\qquad r\ge2.
\]

Consider natural-number addition as the operation language.

Take two distinct states in the same quotient fiber:

\[
x=qr+u,
\qquad
y=qr+v,
\qquad 0\le u<v<r.
\]

Choose the additive one-hole context

\[
\boxed{c_t(z)=z+t,\qquad t=r-1-u.}
\]

Then

\[
Q_r(x+t)=q,
\]

while

\[
Q_r(y+t)=q+1.
\]

Thus **every two distinct residues in one full quotient fiber are context-distinguishable**.

Consequently the greatest addition congruence contained in `ker(Q_r)` is equality:

\[
\boxed{
\operatorname{Syn}_{+}(\ker Q_r)=\Delta.
}
\]

Every full quotient fiber therefore needs all `r` distinct substate labels. By T176,

\[
\boxed{|D|_{\min}=r.}
\]

The canonical choice

\[
D(n)=n\bmod r
\]

is therefore not merely convenient: among exact per-state refinements of the form `(Q_r(n),D(n))` supporting arbitrary addition, a detail alphabet with fewer than `r` labels is impossible.

Once residues `u,v` are retained, the carry

\[
\kappa_r(u,v)=\left\lfloor\frac{u+v}{r}\right\rfloor
\]

is derived interaction data. It is **not** an additional independent per-state coordinate.

This gives a sharper interpretation of the earlier carry line:

\[
\boxed{
\text{remainder = minimal operand state detail; carry = derived cross-input transport.}
}
\]

## 12. P018-T179 — Supporting more operations can only require more detail

Status: `PROVED / EXECUTABLE`

Let

\[
\Sigma\subseteq\Sigma'.
\]

Every `Sigma'`-congruence is automatically a `Sigma`-congruence. Therefore the greatest congruences inside the same observation equivalence satisfy

\[
\boxed{
\operatorname{Syn}_{\Sigma'}(E)
\subseteq
\operatorname{Syn}_{\Sigma}(E).
}
\]

So enlarging the allowed operation language can only refine the exact state representation; it can never justify throwing away detail.

This yields a mathematically precise form of **context-dependent precision**:

> the minimum sufficient precision of a state depends not only on what is observed now, but on which operations the state must support exactly.

This directly matches the project's `value + precision + context` research ontology without changing the protected worldview record.

## 13. P018-T180 — Contextual closure is monotone in observation and preserves meets

Status: `PROVED / EXECUTABLE`

For a fixed operation signature, if

\[
E_1\subseteq E_2,
\]

then

\[
\boxed{
\operatorname{Syn}_\Sigma(E_1)
\subseteq
\operatorname{Syn}_\Sigma(E_2).
}
\]

A finer static observation cannot produce a coarser exact contextual state.

More strongly, for any family of observation equivalences,

\[
\boxed{
\operatorname{Syn}_\Sigma\!\left(\bigcap_i E_i\right)
=
\bigcap_i\operatorname{Syn}_\Sigma(E_i).
}
\]

Proof: the right-hand side is a congruence contained in every `E_i`, hence in their intersection; conversely the greatest congruence inside the intersection is contained in the greatest congruence inside each `E_i`.

Thus product/multi-channel observation refinement is compatible with contextual closure: close each observation channel and intersect, or first combine the observations and then close—the final exact equivalence is the same.

## 14. P018-C18 — Separate operation closures do not compose by simple intersection

Status: `COUNTEREXAMPLE / MIXED-CONTEXT BOUNDARY`

Observation meet preservation in T180 must **not** be confused with operation-signature composition.

Take

\[
X=\{0,1,2,3\}
\]

and observation partition

\[
E=\{\{0,1,2\},\{3\}\}.
\]

Define two unary operations

\[
f=(0,0,1,0),
\qquad
g=(0,3,0,0),
\]

meaning, for example, `f(2)=1` and `g(1)=3`.

For `f` alone, `E` is already closed:

\[
\operatorname{Syn}_{\{f\}}(E)=E.
\]

For `g` alone,

\[
\operatorname{Syn}_{\{g\}}(E)
=
\{\{0,2\},\{1\},\{3\}\}.
\]

Therefore the intersection of the two separately closed relations still identifies `0` with `2`.

But the mixed context

\[
g\circ f
\]

separates them:

\[
g(f(0))=0,
\qquad
g(f(2))=3.
\]

Hence the joint closure is equality:

\[
\boxed{
\operatorname{Syn}_{\{f,g\}}(E)
\subsetneq
\operatorname{Syn}_{\{f\}}(E)
\cap
\operatorname{Syn}_{\{g\}}(E).
}
\]

So the exact state required by a combined operation language cannot in general be obtained by independently closing each operation and merely intersecting the results. **Mixed nested contexts matter.**

## 15. P018-T181 — P018-Q117 is resolved for finite finitary quotient-state refinement

Status: `RESOLVED FOR FINITE STATE + FINITE FINITARY SIGNATURE`

For a finite state space, finite finitary operation signature, and finite-precision observation, the canonical exact state refinement required to make all declared operations autonomous is:

\[
\boxed{
\text{iterate elementary-context partition refinement until the first fixed point.}
}
\]

The result:

- is reached in at most `N-c0` strict refinement steps;
- is exactly the classical greatest/syntactic congruence inside the original observation equivalence;
- makes every basic operation descend exactly;
- is the coarsest / fewest-state exact quotient refinement preserving the original observation;
- yields the exact minimum uniform detail-alphabet size `max_y m_y` for `(observation,detail)` state coordinates;
- contains Supplement 18 unary predictive closure as a special case.

Therefore P018-Q117 is resolved **in the quotient-state sufficiency sense** for finite finitary algebras.

## 16. P018-C19 — Minimal exact state does not settle minimal transport encoding

Status: `DESIGN BOUNDARY`

T175–T181 identify the smallest exact **state quotient/refinement**. They do not prove that every implementation of an operation must transmit or recompute the entire refined state label in the same representation.

Radix addition already shows the distinction:

- full residue is unavoidable per-operand state detail;
- carry is a compact derived interaction term;
- the exact state theorem and the exact transport/cocycle theorem answer different questions.

For more general algebras, a noncongruent coarse observation may admit useful structured extension/transport laws that are smaller than a naive table of all refined-state interactions even though the underlying exact state distinctions are fixed by `Syn_Sigma(E)`.

Thus the next problem is not “what is the minimal exact state?” in the finite finitary setting—that is answered here. The next problem is:

> **Q119 — when can the required contextual state refinement be implemented through structured, composable interaction data (carry/cocycle-like or otherwise), and what is the minimum transport complexity?**

No claim is made that every such structure is cohomological.

## 18. Current foundational feedback

The candidate finite-precision hierarchy can now be sharpened:

\[
\boxed{
\text{static observation equivalence}
\to
\text{declared operation signature}
\to
\text{contextual/syntactic congruence closure}
\to
\text{minimal exact state}
\to
\text{optional structured transport data}.
}
\]

This separates three questions that were previously easy to blur:

1. **What can the observer distinguish now?** — static precision.
2. **What distinctions must survive every allowed operation context?** — exact state sufficiency / congruence closure.
3. **How can interactions between sufficient states be encoded efficiently?** — carry/cocycle/transport layer.

The second question now has a canonical finite answer for finite finitary algebras. The third remains open and should not be answered by mechanically calling every defect a cocycle.
