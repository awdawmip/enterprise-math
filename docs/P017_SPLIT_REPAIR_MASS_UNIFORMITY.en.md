# P017 — Uniform Dyadic Split-Repair Mass

Status: `PROVED OWNER RESEARCH`  
Owner: P017 / `program/p017-legendre`  
Consumes: exact P017 cofactor windows; P018 two-root quotient-basin transport; classical Jacobsthal and continued-fraction discrepancy results  
Boundary: this theorem concerns composite least-prime shells and their cofactor-root repair burden. It does **not** prove Legendre's conjecture.

## 1. The quantity

Fix a square-basin index \(k\ge2\). For each prime \(p\le k\), consider the actual least-prime shell

\[
\mathcal L_p(k)
=
\{n:\ k^2<n<(k+1)^2,\ \operatorname{spf}(n)=p\}.
\]

Write \(n=pq\), and retain only the cofactor square-root index \(R_2(q)\).

P018 implies that, for fixed \(k,p\), the cofactor root can take at most two adjacent values. Define

\[
I_p(k)=
\begin{cases}
1,&\text{both root values are actually realized by }p\text{-rough cofactors},\\
0,&\text{otherwise}.
\end{cases}
\]

Define the active split-repair mass

\[
\boxed{
S(k)=\sum_{\substack{p\le k\\p\ {\rm prime}}} I_p(k).
}
\]

Equivalently, \(S(k)\) counts the least-prime shells that genuinely need the binary residual root coordinate.

## 2. Exact boundary arithmetic

Put

\[
a=\left\lfloor\frac{k^2}{p}\right\rfloor,
\qquad
m=R_2(a)+1,
\qquad
\tau=pm^2-k^2.
\]

The exact open cofactor window is

\[
W_p(k)
=
\left[
\left\lfloor\frac{k^2}{p}\right\rfloor+1,\,
\left\lfloor\frac{k(k+2)}p\right\rfloor
\right].
\]

Cut \(W_p(k)\) at the next square boundary \(m^2\). The exact numbers of raw quotient slots below and above that boundary are

\[
\boxed{
L_p(k)
=
\left\lceil\frac{\tau}{p}\right\rceil-1,
}
\]

and

\[
\boxed{
U_p(k)
=
\left\lfloor\frac{2k-\tau}{p}\right\rfloor+1.
}
\]

Hence a raw two-root split occurs exactly when

\[
\boxed{
p<\tau\le2k.
}
\]

Actual splitting additionally requires at least one \(p\)-rough quotient in each nonempty branch.

## 3. Beatty core

The upper branch is nonempty exactly when

\[
pm^2<(k+1)^2.
\]

Together with \(pm^2>k^2\), this is equivalent to

\[
\boxed{
k=\lfloor m\sqrt p\rfloor.
}
\]

Thus the raw candidate indices for fixed \(p\) lie on the Beatty sequence generated by \(\sqrt p\).

For a dyadic block

\[
K<k\le2K,
\]

the number of such Beatty candidates is

\[
\boxed{
\frac{K}{\sqrt p}+O(1).
}
\]

The remaining question is how many candidates are removed by the lower-boundary condition or by \(p\)-rough realizability.

## 4. Uniform rough-gap input

Let

\[
P_{<p}
=
\prod_{\substack{r<p\\r\ {\rm prime}}}r,
\]

and let \(H_p\) be the least positive integer such that every interval of \(H_p\) consecutive integers contains an integer coprime to \(P_{<p}\), equivalently a \(p\)-rough integer.

If \(r=\pi(p-1)\), then \(H_p\) is the Jacobsthal function of the primorial of the first \(r\) primes.

Iwaniec's classical Jacobsthal theorem gives

\[
h(r)\ll(r\log r)^2.
\]

Together with the standard prime-counting bound \(r\log r\ll p\), this gives the uniform consequence

\[
\boxed{
H_p\ll p^2.
}
\]

This is prior mathematics. P017 uses it only as a uniform occupancy certificate for the moving cofactor branches.

## 5. Endpoint localization of every realizability failure

Take one Beatty candidate

\[
k=\lfloor m\sqrt p\rfloor
\]

and write

\[
\delta=m\sqrt p-k\in(0,1).
\]

Then

\[
\boxed{
\tau
=
pm^2-k^2
=
\delta(2k+\delta).
}
\]

Also define the upper square-boundary defect

\[
D=(k+1)^2-pm^2.
\]

Then

\[
\boxed{
D
=
(1-\delta)(2k+1+\delta).
}
\]

Suppose \(K<k\le2K\). If the lower branch contains no \(p\)-rough integer, then its length is \(<H_p\), hence

\[
\tau\le pH_p
\]

and therefore

\[
\boxed{
\delta
\le
\frac{pH_p}{2K}.
}
\]

If the upper branch contains no \(p\)-rough integer, then similarly

\[
D\le pH_p
\]

and

\[
\boxed{
1-\delta
\le
\frac{pH_p}{2K}.
}
\]

Thus every Beatty-core candidate that fails actual splitting has \(\{m\sqrt p\}\) inside two endpoint intervals of total length

\[
O\!\left(\frac{pH_p}{K}\right).
\]

This is the uniform replacement for L082's fixed-\(p\) Pell constants.

## 6. Uniform square-root rotation discrepancy

The continued fraction of \(\sqrt p\) is periodic, and every noninitial partial quotient is at most \(2\lfloor\sqrt p\rfloor\).

For any interval \(J\subset[0,1)\) and any consecutive block of \(M\) multipliers, the standard Ostrowski/Denjoy--Koksma decomposition therefore gives

\[
\boxed{
\#\{m:\{m\sqrt p\}\in J\}
=
M|J|
+
O(\sqrt p\log(2M)).
}
\]

The implied constant is absolute.

A short proof route is: decompose \(M\) into convergent-denominator blocks by the Ostrowski expansion; Denjoy--Koksma bounds the interval discrepancy on each denominator block by its bounded variation; the sum of the Ostrowski digits is \(O(\sqrt p\log M)\) because the partial quotients are \(O(\sqrt p)\) and the convergent denominators grow at least as Fibonacci numbers.

No randomness is assumed.

## 7. Uniform fixed-prime dyadic lower bound

For \(K<k\le2K\), the relevant multiplier block has length

\[
M=\frac{K}{\sqrt p}+O(1).
\]

Apply Section 6 to the two failure intervals from Section 5. The number \(E_p(K)\) of Beatty candidates in the dyadic block that fail actual splitting satisfies

\[
E_p(K)
\ll
M\frac{pH_p}{K}
+
\sqrt p\log K.
\]

Therefore

\[
\boxed{
E_p(K)
\ll
H_p\sqrt p
+
\sqrt p\log K.
}
\]

Using \(H_p\ll p^2\),

\[
\boxed{
E_p(K)
\ll
p^{5/2}
+
\sqrt p\log K.
}
\]

Hence, uniformly for growing \(p\) in the range used below,

\[
\boxed{
\sum_{K<k\le2K} I_p(k)
\ge
\frac{K}{\sqrt p}
-
C\left(p^{5/2}+\sqrt p\log K+1\right)
}
\]

for one absolute constant \(C\) after the finitely many small cases are absorbed.

## 8. P017-SRMU-T01 — Polynomial dyadic mean growth

Status: `PROVED`.

There exist constants \(c>0\) and \(K_0\) such that, for every \(K\ge K_0\),

\[
\boxed{
\sum_{K<k\le2K}S(k)
\ge
c\,\frac{K^{7/6}}{\log K}.
}
\]

Equivalently,

\[
\boxed{
\frac1K
\sum_{K<k\le2K}S(k)
\gg
\frac{K^{1/6}}{\log K}.
}
\]

### Proof

Choose

\[
Y=c_0K^{1/3}
\]

with a sufficiently small fixed \(c_0>0\). Since \(S(k)\) contains every prime contribution with \(p\le Y\),

\[
\sum_{K<k\le2K}S(k)
\ge
\sum_{p\le Y}
\sum_{K<k\le2K}I_p(k).
\]

Section 7 gives

\[
\sum_{K<k\le2K}S(k)
\ge
K\sum_{p\le Y}\frac1{\sqrt p}
-
C\sum_{p\le Y}p^{5/2}
-
C\log K\sum_{p\le Y}\sqrt p
-
C\pi(Y).
\]

Standard prime-counting estimates give

\[
\sum_{p\le Y}\frac1{\sqrt p}
\gg
\frac{\sqrt Y}{\log Y},
\]

\[
\sum_{p\le Y}p^{5/2}
\ll
\frac{Y^{7/2}}{\log Y},
\]

and

\[
\sum_{p\le Y}\sqrt p
\ll
\frac{Y^{3/2}}{\log Y}.
\]

The main term is therefore

\[
\gg
c_0^{1/2}
\frac{K^{7/6}}{\log K}.
\]

The first error has the same power of \(K\), but its coefficient is \(O(c_0^{7/2})\). Choose \(c_0\) small enough that this is at most half of the main coefficient. The remaining errors are \(o(K^{7/6}/\log K)\). This proves the theorem. ∎

## 9. P017-SRMU-C01 — Polynomial pointwise limsup

From the dyadic mean theorem,

\[
\boxed{
\max_{K<k\le2K}S(k)
\gg
\frac{K^{1/6}}{\log K}.
}
\]

Consequently there are infinitely many basin indices \(k\) for which

\[
\boxed{
S(k)
\gg
\frac{k^{1/6}}{\log k}.
}
\]

Thus the active binary root-repair support is not merely unbounded; it attains polynomial scale along an infinite sequence.

## 10. Repair-spectrum consequence

Inside every least-prime shell, the cofactor root has at most two values. Therefore, for the factor-to-root refinement, every local split multiplicity is \(1\) or \(2\).

Consequently \(S(k)\) is simultaneously:

- the number of factor blocks that genuinely split;
- the increase in factor/root joint class count over the factor-only class count;
- the second binomial repair-spectrum mass.

The arithmetic theorem above therefore gives the same dyadic lower bound for all three quantities.

This interpretation is an A2 consumer statement. The proof of T01 itself is purely P017 arithmetic plus classical rough-gap/discrepancy inputs.

## 11. P017-SRMU-T02 — Rough-gap exponent transfer principle

The argument isolates a reusable transfer law.

Suppose, instead of the current Jacobsthal input, one has a uniform \(p\)-rough gap guarantee

\[
\boxed{
H_p\ll p^\theta
}
\]

for some fixed \(\theta>0\).

Then Section 7 becomes

\[
E_p(K)
\ll
p^{\theta+1/2}
+
\sqrt p\log K.
\]

Choose

\[
Y=c_0K^{1/(\theta+1)}.
\]

The same summation gives

\[
\boxed{
\frac1K
\sum_{K<k\le2K}S(k)
\gg
\frac{K^{1/(2(\theta+1))}}{\log K}.
}
\]

Thus any improvement in the uniform rough-gap exponent transfers mechanically into a stronger split-repair mass exponent.

For the currently available Jacobsthal exponent \(\theta=2\), this becomes the \(1/6\) theorem above.

## 12. What this theorem does not say

The theorem does **not** imply a pointwise asymptotic formula for \(S(k)\).

It does **not** upgrade the fixed-prime finite-pattern independence theorem to a growing prime cutoff.

It does **not** say that a positive fraction of all prime shells split in each basin.

It does **not** prove that every square basin contains a prime.

It proves a different structural statement: a binary local repair coordinate can remain uniformly bounded in alphabet size while the number of coarse blocks on which that repair is genuinely active has a polynomial dyadic lower bound.

## 13. Prior-art boundary

The following ingredients are classical prior mathematics:
