## 1. Why the nonnegative defect of T88 is not general enough

Supplement 09 studies collapse/refinement holonomy

\[
\chi_{p;e:d}(n)\ge0,
\]

so it can begin with

\[
\mathcal T_m(a,h),
\qquad h\in\mathbb N.
\]

But P009-C02 already proves that general collapse/project schedules are nonconfluent. The terminal difference between two paths does not have a fixed sign.

General path holonomy should therefore be an **oriented state difference**, not a nonnegative loss.

This forces a distinction between two questions:

1. whether base states themselves admit negative values;
2. whether the oriented difference between two nonnegative states may be negative.

The second question naturally uses `Z`, but does not answer the first.

## 2. P018-T93 — Collapse/project scheduling holonomy takes both signs for every `p>=2`

Status: `PROVED`

Fix `p>=2` and `r>=2`. For a natural-number state define the oriented scheduling difference

\[
\boxed{
H_{p,r}(m)
=
C_p(Q_r(m))-Q_r(C_p(m))
\in\mathbb Z.
}
\]

The first term corresponds to

\[
\text{project}\to\text{collapse},
\]

and the second to

\[
\text{collapse}\to\text{project}.
\]

Even with `r=2` fixed, `H_(p,2)` takes both positive and negative values for every `p>=2`.

### Positive witness

Take

\[
m=2.
\]

For every `p>=2`,

\[
C_p(2)=1,
\qquad
Q_2(2)=1,
\qquad
C_p(1)=1.
\]

Hence

\[
\boxed{H_{p,2}(2)=1-0=1.}
\]

### Negative witness

Take

\[
m=2^p.
\]

Then

\[
C_p(2^p)=2^p,
\qquad
Q_2(C_p(2^p))=2^{p-1}.
\]

On the other hand,

\[
Q_2(2^p)=2^{p-1}<2^p,
\]

so its integer `p`-th root is still `1`, giving

\[
C_p(2^{p-1})=1.
\]

Therefore

\[
\boxed{H_{p,2}(2^p)=1-2^{p-1}<0.}
\]

∎

### Meaning

General operation-scheduling nonconfluence therefore cannot be encoded by a natural-number-valued “loss” if path orientation is to be retained.

## 3. P018-T94 — Signed defect transport is controlled by the same carry formula

Status: `PROVED`

Fix `m>=1`. For arbitrary

\[
a,h\in\mathbb Z,
\]

use the Euclidean decompositions of Supplement 08:

\[
a=mA+u,
\qquad
h=mH+v,
\qquad
0\le u,v<m.
\]

Define signed defect transport by

\[
\boxed{
\mathcal T_m^{\mathbb Z}(a,h)
=q_m(a+h)-q_m(a),
}
\]

where `q_m` is Euclidean/floor quotient with nonnegative remainder.

Then

\[
\boxed{
\mathcal T_m^{\mathbb Z}(a,h)
=q_m(h)+\kappa_m(\rho_m(a),\rho_m(h)).
}
\]

### Proof

Since

\[
a+h=m(A+H)+(u+v),
\]

and the canonical residues satisfy

\[
u+v=m\kappa_m(u,v)+(u\oplus v),
\]

we have

\[
q_m(a+h)=A+H+\kappa_m(u,v).
\]

Subtract `q_m(a)=A`. ∎

### Carry and borrow in one formula

When `h<0`, `q_m(h)` may be negative while `rho_m(h)` remains a canonical residue in `0,...,m-1`.

For example, for `h=-1`,

\[
-1=m(-1)+(m-1).
\]

Thus

\[
\mathcal T_m^{\mathbb Z}(a,-1)
=-1+\kappa_m(\rho_m(a),m-1).
\]

If `rho_m(a)>0`, the carry term is `1` and transport is `0`; if `rho_m(a)=0`, carry is `0` and transport is `-1`.

The cases traditionally called “no borrow” and “borrow” are therefore generated by the **same signed Euclidean carry formula**.

Hence

\[
\boxed{
\text{carry / borrow}
=\text{two orientations of one signed defect transport phenomenon}.
}
\]

## 4. P018-T95 — Signed defect transport preserves cross-scale coherence

Status: `PROVED`

=
\mathcal T_m^{\mathbb Z}
\bigl(
q_n(a),
\mathcal T_n^{\mathbb Z}(a,h)

\]

### Proof

Euclidean floor quotient by positive integers satisfies

\[
q_m(q_n(x))=q_{mn}(x).
\]

Also,

\[
q_n(a+h)
=q_n(a)+\mathcal T_n^{\mathbb Z}(a,h).
\]

The calculation of T89 then applies verbatim. ∎

Signed transport therefore preserves canonical precision-chain composition.

## 5. P018-T96 — Exact invisibility window for a signed defect

Status: `PROVED`

Fix `m>=1` and `a,h in Z`. Let

\[
u=\rho_m(a)\in\{0,\ldots,m-1\}.
\]

Then

\[
\boxed{
\mathcal T_m^{\mathbb Z}(a,h)=0
\iff
-u\le h<m-u.
}
\]

### Proof

Transport vanishes exactly when

\[
q_m(a+h)=q_m(a).
\]

Writing `a=mA+u`, this is equivalent to

\[
mA\le mA+u+h<m(A+1),
\]

or

\[
0\le u+h<m.
\]

Rearrange. ∎

A coarse fiber's invisible range for signed difference is therefore not a symmetric real-valued error bar around zero. It is the finite integer window

\[
\boxed{[-u,\ m-u)}
\]

determined by the current residue.

Crossing the right boundary produces a positive coarse change; crossing the left boundary produces a negative coarse change / borrow.

## 6. P018-T97 — Signed holonomy does not require natural-number states to become signed states

Status: `PROVED COORDINATE FACT / ESTABLISHED ALGEBRAIC INTERPRETATION`

For any two natural-number endpoints

\[
x,y\in\mathbb N,
\]

use the standard embedding

\[
\iota:\mathbb N\hookrightarrow\mathbb Z
\]

to define the oriented path difference

\[
\boxed{
H(x,y)=\iota(y)-\iota(x)\in\mathbb Z.
}
\]

Then

\[
H(x,y)=0\iff x=y,
\]

and

\[
\boxed{H(y,x)=-H(x,y).}
\]

Thus the base state space may remain

\[
\mathbb N
\]

while the path-comparison layer uses

\[
\mathbb Z.
\]

### Established algebraic interpretation

`(Z,+)` is the standard Grothendieck group completion of `(N,+)`. Here that mature structure is used only to express a foundational type distinction:

\[
\boxed{
\text{state type}\ne\text{oriented difference type}.
}
\]

Therefore “negative path defects are needed” is **not** evidence that negative values must belong to the physical base-state ontology.

P006's signed physical-state extension remains an independent question; the P018 signed defect layer does not decide it.

## 7. P018-T98 — Further coarsening of a P009 nonconfluence holonomy is exactly signed transport

Status: `PROVED`

Fix `p>=2`, `r,s>=1`, and a natural state `m`.

Let the two P009 scheduling paths first meet at one common scale with outputs

\[
A=Q_r(C_p(m)),
\qquad
B=C_p(Q_r(m)).
\]

Their oriented holonomy is

\[
H=B-A\in\mathbb Z.
\]

If both outputs are then subjected only to the same further quotient `q_s`, the new endpoint difference is

\[
\boxed{
q_s(B)-q_s(A)
=
\mathcal T_s^{\mathbb Z}(A,H).
}
\]

### Proof

Since `B=A+H`, substitute directly into the definition of signed transport:

\[
q_s(A+H)-q_s(A).
\]

∎

General signed P009 nonconfluence and the nonnegative collapse holonomy of Supplement 09 therefore share one transport framework.

The difference is only that:

- the special T11/T90 holonomy is known to be nonnegative;
- general P009 scheduling holonomy may have either sign.

## 8. Direct feedback into P006: separate signed state from signed defect

P006 asks whether natural states themselves should carry signs and whether negative-number roots should follow ordinary order or magnitude semantics.

This stage studies something different: even if every state remains a nonnegative integer, the oriented difference between two legal paths naturally lives in `Z`.

The foundation should therefore not argue:

> “Because a defect may be negative, the state space must be the integers.”

A cleaner layering is:

### State layer

\[
X_d\subseteq\mathbb N
\]

or whatever finite state object the project ultimately chooses.

### Difference / defect layer

When a state coordinate has cancellative additive structure, put oriented differences in its group completion. For the current natural-number coordinate this is

\[
\mathbb Z.
\]

### Signed physical-state layer

Only when the physical/algebraic problem itself requires negative states should P006 decide whether the base-state ontology is extended.

This prevents a comparison tool from silently rewriting the ontology of state.
