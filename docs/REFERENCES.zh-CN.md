# 相邻前人工作与术语

本文记录与进取数论局部结构接近的外部数学和计算研究。这些资料都不能证明本项目的本体解释。引用它们的目的，是避免重复发明术语，在定义真正一致时借用已有定理，并明确进取数论究竟在哪一步提出了更强或不同的主张。

## 一、整数平方根

Python 标准库把整数平方根定义为满足 \(a^2\le n\) 的最大整数 \(a\)。

参考资料：
- https://docs.python.org/3/library/math.html#math.isqrt

与本项目的关系：

这个不等式定义可以直接借用。传统文档还会把它解释成“精确实数平方根向下取整”，但进取数论不需要把那个实值解释作为基本定义。

## 二、有序集合上的内算子与闭包算子

序理论研究单调、幂等并具有投影性质的映射。闭包算子通常是单调、幂等并向上扩张；其序对偶是向下收缩的内算子。

形式化参考：
- https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/Order/Closure.lean

与本项目的关系：

坍缩映射 \(C_p(n)=R_p(n)^p\) 满足单调、幂等和向下收缩，因此与内算子结构高度接近。把这种算子进一步解释成自然状态的本体坍缩，是本项目额外提出的物理假说。

## 三、代数数的精确运算

FLINT 可以使用整数最小多项式与隔离区间精确表示代数数。Sage 对二次数域还有专门实现，内部可以用整数三元组表示 \((a+b\sqrt D)/c\)。

参考资料：
- https://github.com/fredrik-johansson/flint/blob/main/doc/source/qqbar.rst
- https://github.com/sagemath/sage/blob/develop/src/sage/rings/number_field/number_field_element_quadratic.pyx

与本项目的关系：

这些体系证明了“精确符号运算”并不要求保存无限小数展开。进取数论进一步追问：传统代数实数本身是否还需要作为隐藏的基本对象存在。

## 四、不可逆动力系统中的前像熵

现有动力系统研究已经发展出通过前像结构衡量不可逆性和复杂度的理论。前像熵类不变量专门对不可逆映射产生非平凡信息，并可用于衡量一个系统偏离可逆性的程度。

参考资料：
- https://www.cambridge.org/core/journals/ergodic-theory-and-dynamical-systems/article/abs/preimage-entropy/56C8283787288DCDD4462FA2727E7454
- https://www.cambridge.org/core/journals/ergodic-theory-and-dynamical-systems/article/on-preimage-entropy-folding-entropy-and-stable-entropy/012FED8E4A51761352CDA5A4F4723C97

与本项目的关系：

这是目前与“一个现在可以具有许多不同过去”这一结构最接近的成熟数学邻域。进取数论首先保留整数形式的前像数量，不预设传统对数熵就是基本量。

## 五、逻辑不可逆与可逆计算

Landauer 与后续 Bennett 等人的工作把逻辑不可逆、信息擦除、可逆计算以及热力学代价联系起来。

参考资料：
- Rolf Landauer，1961 年，关于计算过程不可逆性与发热的经典论文。
- Charles H. Bennett 关于可逆计算与 Landauer 原理的系列工作。

与本项目的关系：

这条研究线很重要，但概念上与进取数论并不相同。进取数论正在检验一个更强的本体：自然转移本身可能就是多对一的，而且不预设任何隐藏余量状态继续存在。因此，项目不能简单把自己的坍缩映射描述成传统意义上的“信息擦除”。

## 六、粗粒化作为对照体系

统计物理经常通过投影或粗粒化更细的微观描述来解释宏观不可逆，而更底层的动力学仍可能保持可逆。

与本项目的关系：

进取数论明确检验另一种假说：多对一演化可以是基本自然规律，而不仅是观察者看不全造成的现象。因此，粗粒化既是重要参照，也是潜在竞争解释。

## 七、术语纪律

当进取数论中的新结构与已有数学定义真正一致时，应优先使用已有数学术语，把项目专有名称保留给额外的解释层。

例如：

- 不等式定义的根运算直接称为“整数平方根”；
- 序理论性质一致时描述为“类似内算子的结构”；
- 在发明新的熵名称之前优先使用“前像数量”“前像结构”；
- 只有在表达“多对一转移本身就是自然本体”这一更强假说时，才使用“本体坍缩”。
