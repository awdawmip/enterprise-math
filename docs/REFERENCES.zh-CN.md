# 来源索引与相邻前人工作

## 1. 规范引用体系

原来的自由格式参考文献表已经升级为来源谱系系统。

- `sources.json` 是规范的机器可读书目，并记录每个来源具体怎样被使用。
- `lineage.json` 记录每个来源影响哪个进取数论构件，以及关系属于采用、组合、重新解释、对照还是启发。
- `docs/PRIOR_ART_AND_NOVELTY.zh-CN.md` 用人类可读方式解释思想谱系与暂定创新边界。
- `docs/CITATION_POLICY.zh-CN.md` 规定新增引用以后怎样登记和持续维护。

稳定来源引用使用 `[SRC-*]` 编号。

## 2. 当前主要前人工作家族

当前登记表覆盖：

- 整数平方根与序定义的向下除法；
- Galois 伴随与 closure / interior operator；
- fixed-point、scaled-integer、block-floating 与 exact-real 算术；
- 代数数的有限精确表示；
- 对物理实数本体的有限信息批评；
- 离散时空与 causal set；
- 逻辑不可逆与可逆计算；
- Mori-Zwanzig 投影与粗粒化；
- preimage entropy 与 folding entropy；
- 开放量子系统中的前向动力学半群。

完整核验书目位于 `sources.json`；本文刻意不再重复所有 URL。

## 3. 引用规则

引用一个来源，是因为它支持某个明确的思想谱系陈述，而不是因为它“主题差不多”。

主要前人工作图必须说明：

1. 前人真正建立了什么；
2. 进取数论直接复用了什么；
3. 进取数论改变或拒绝了什么；
4. 哪些内容绝不能归因成进取数论的发明；
5. 剩余项目主张到底属于数学、组合框架还是物理假说。

## 4. 更新规则

任何实质性的新前人工作，都必须在同一个研究变更中更新来源登记表和谱系图。

如果新来源会缩小某个创新主张，就必须同步缩小主张。

找到更早的前人工作属于项目进展，因为它能让体系更精确，并避免虚假的原创性表述。
