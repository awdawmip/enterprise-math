# P022 — Prime-Halving DAG Reduction of Half-Defect Support

## 1. Canonical central-binomial expansion as a prime-halving DAG

Let

\[
A_j=\binom{2j}{j}.
\]

For an odd prime `q`, define

\[
h=(q+1)/2.
\]

The exact identity

\[
q=\frac h2\frac{A_h}{A_{h-1}}
\]

gives the canonical exponent recursion

\[
E(q)=E(h)-E(2)+e_h-e_{h-1}.
\]

Thus every occurrence of an odd prime `q` creates one adjacent endpoint pair

\[
\frac{q-1}{2},\quad\frac{q+1}{2},
\]

and the only recursive continuation goes into the strictly smaller integer `(q+1)/2`.

For a positive integer `x`, define `Q(x)` recursively:

1. include every odd prime divisor `q|x`;
2. for each such `q`, include `Q((q+1)/2)`.

This is a finite Pratt-like prime-halving DAG because the integer argument strictly decreases.

## 2. P022-LI34 — universal endpoint envelope

Every nontrivial support index of the canonical expansion `E(x)` must be an endpoint generated by some prime in `Q(x)`:

\[
\boxed{
\operatorname{supp}(E(x))\setminus\{1\}
\subseteq
\left\{
\frac{q-1}{2},\frac{q+1}{2}:q\in Q(x)
\right\}.
}
\]

In particular, any support index `j>=2` satisfies the universal necessary condition

\[
\boxed{
2j-1\text{ or }2j+1\text{ is prime}.
}
\]

This statement is independent of P022: it is a structural fact about the chosen central-binomial basis recursion. P022 uses it as a specialization tool rather than claiming a new generic basis theory.

## 3. Apply the DAG to the half-defect relation

For the target family

\[
p\equiv5,23\pmod{24},\qquad m=(p-1)/2,
\]

the composite-boundary relation has canonical support contained in

\[
\boxed{
\{1,m-1\}
\cup
\operatorname{Endpoints}(Q(m))
\cup
\operatorname{Endpoints}(Q(p-2)).
}
\]

The point `m-1` is automatically Franel-nonzero modulo `p` because the forced midpoint `m` is zero and adjacent zeros are impossible.

Therefore every possible support collision below the midpoint must occur at an endpoint of one of the two finite prime-halving DAGs.

## 4. Combine with the integer midpoint companion

Let `H_d` be the pure-integer midpoint companion. For `0<d<m`,

\[
p\mid F_{m-d}\iff p\mid H_d.
\]

Write

\[
j=m-d.
\]

Then

\[
2j-1=p-2d-2,
\qquad
2j+1=p-2d.
\]

Hence a left Franel zero can threaten the A-support only if

\[
\boxed{
p\mid H_d}
\]

and simultaneously

\[
\boxed{
\{p-2d-2,p-2d\}
\cap
\bigl(Q(m)\cup Q(p-2)\bigr)
\ne\varnothing.
}
\]

This is the **companion-hit / ancestor-prime collision condition**.

It is necessary for a support collision. It is not sufficient, because the endpoint coefficient may cancel in the exact exponent vector.

## 5. Two-stage automatic pruning

The reduction yields two cheap filters before any exact support evaluation:

1. **edge eligibility:** if both `2j-1` and `2j+1` are composite, `j` cannot lie in any nontrivial central-binomial support at all;
2. **ancestor eligibility:** if the adjacent prime exists but is not in `Q(m) union Q(p-2)`, the midpoint defect cannot use that endpoint.

In the target-prime pressure test below `5000`, the earlier rank-ceiling theorem left 22 difficult cases. The universal edge test removes 8; the exact ancestor-set test removes the remaining 14. Thus every tested case is certified support-safe without testing the full Franel table against the final exponent support.

Those counts are finite evidence only. The durable theorem is the endpoint envelope and the exact collision reduction above.

## 6. Examples

### `p=173`

Here `m=86` and the earliest zero is `j=4`, so the coarse rank ceiling is silent. Abstractly `j=4` is edge-eligible because

\[
2j-1=7
\]

is prime. But

\[
Q(86)\cup Q(171)=\{3,11,19,43\}\text{ plus their recursive ancestors},
\]

and `7` is absent. Therefore the zero at `F_4` cannot occur in the canonical support.

### `p=389`

One early zero is `j=25`. Here

\[
2j-1=49,\qquad2j+1=51
\]

are both composite. Thus this zero is excluded before the target DAG is even built.

## 7. New arithmetic frontier

The support-avoidance conjecture is now reduced to a sharply stated infinite collision problem:

> Can a forced-midpoint companion hit `p|H_d` occur at an offset for which `p-2d-2` or `p-2d` belongs to the prime-halving ancestor set generated from `m=(p-1)/2` or `p-2`?

This is substantially narrower than the old statement “no earlier Franel zero lies in the A-support”. It involves two fixed combinatorial/arithmetic objects:

- one universal integer recurrence `H_d`;
- one deterministic prime-halving DAG from ordinary factorization.

A proof of global nonintersection would prove support avoidance for the entire target family. A counterexample would identify the first genuine place where the canonical correction can acquire p-adic valuation and would then require signed-coefficient analysis rather than invalidating the whole defect route.
