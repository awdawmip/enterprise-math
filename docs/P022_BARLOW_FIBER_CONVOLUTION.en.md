## 1. Complete fiber state

For any finite observation quotient `O`, let

\[
c_s(O)=\#\{y:|O^{-1}(y)|=s\}.
\]

The finite profile

\[
\boxed{C_O=(c_1,c_2,\ldots)}
\]

is the complete multiset of fiber sizes.

P011 already proves that this profile and the full collision spectrum

\[
(J_1,J_2,\ldots)
\]

determine each other by finite binomial inversion.  The present P022 specialization determines exactly how `C_O` is generated by checkpoint geometry and, conversely, how much checkpoint geometry `C_O` recovers.

## 2. Segment fiber profile

A length-`ell` prefix-imbalance segment has fibers

\[
\binom{\ell}{0},\binom{\ell}{1},\ldots,\binom{\ell}{\ell}.
\]

Define

\[
\boxed{
B_\ell(s)=\#\left\{j:\binom{\ell}{j}=s\right\}.
}
\]

Examples are

\[
B_1:\{1:2\},
\quad
B_2:\{1:2,2:1\},
\quad
B_3:\{1:2,3:2\},
\]

and

\[
B_4:\{1:2,4:2,6:1\}.
\]

## 3. P022-FC01 — independent segments compose by multiplicative convolution

For finite functions on positive integers define

\[
\boxed{
(f\star_\times g)(n)=\sum_{ab=n}f(a)g(b).
}
\]

This is finite multiplicative/Dirichlet convolution.

If independent observation segments have fibers of sizes `a` and `b`, their product observation has fiber size `ab`.  Therefore for final-observing segment lengths

\[
\ell_1,\ldots,\ell_m,
\]

\[
\boxed{
C_O=B_{\ell_1}\star_\times\cdots\star_\times B_{\ell_m}.
}
\]

If an unobserved tail of length `u` remains, every fiber size is additionally multiplied by

\[
2^u.
\]

The tail scales the fiber-size axis; it does not add another constrained-segment convolution factor.

## 4. P022-FC02 — power moments are characters

For integer `r>=1`, define

\[
\Phi_r(f)=\sum_s f(s)s^r.
\]

Then

\[
\boxed{
\Phi_r(f\star_\times g)=\Phi_r(f)\Phi_r(g).
}
\]

For one segment,

\[
\Phi_r(B_\ell)
=
\sum_{j=0}^{\ell}\binom{\ell}{j}^r
=F_r(\ell).
\]

Therefore the ordered equal-observation tuple moment is

\[
\boxed{
M_r=2^{ru}\prod_jF_r(\ell_j),
}
\]

recovering the higher-collision factorization as a character evaluation of the complete profile algebra.

## 5. P022-FC03 — P011 collision spectrum is an equivalent encoding

P011 defines

\[
J_k=\sum_s c_s\binom{s}{k}.
\]

Its canonical binomial inversion recovers `c_s` from all `J_k`.  Hence

\[
\boxed{
C_O\longleftrightarrow(J_1,J_2,\ldots).
}
\]

Equivalently, the P011 collision polynomial

\[
K_O(t)=\sum_{k\ge1}J_k t^k
\]

is a complete encoding of the checkpoint quotient's fiber-size profile.

## 6. P022-FC04 — final-observing profile uniquely recovers the segment-length multiset

This is stronger than the earlier bounded identifiability search.

For every positive segment length `ell`:

1. exactly two segment fibers are singletons,
   \[
   B_\ell(1)=2;
   \]
2. for `ell>=2`, the smallest non-singleton fiber size is exactly
   \[
   \binom{\ell}{1}=\ell;
   \]
3. the multiplicity of this smallest nontrivial size is
   \[
   \beta_2=1,
   \qquad
   \beta_\ell=2\quad(\ell\ge3).
   \]

These facts make the convolution factorization triangular in increasing fiber size.

### Step 1 — recover segment count and total length

For `m` final-observing segments, every segment must choose one of its two singleton fibers in order for the product fiber to remain `1`. Thus

\[
\boxed{c_1=2^m.}
\]

So `m` is recovered exactly.

The microscopic domain size is

\[
\sum_s s c_s=2^N,
\]

so the total prefix length `N` is also recovered.

### Step 2 — triangular recovery

Assume all numbers of segments of lengths `<n` are already known.  Convolve their exact profiles to obtain `P_<n`, and let `m_<n` be their count.

In the full profile coefficient `c_n`:

- every still-unknown segment of length `>n` must choose a singleton, because its smallest nontrivial fiber exceeds `n`;
- already-known shorter segments contribute the computable term
  \[
  2^{m-m_{<n}}P_{<n}(n);
  \]
- a length-`n` segment contributes size `n` only when exactly one such segment chooses its smallest nontrivial fiber and every other segment chooses a singleton.

Therefore the residual is exactly

\[
\boxed{
R_n
=
c_n-2^{m-m_{<n}}P_{<n}(n)
=
t_n\beta_n2^{m-1},
}
\]

where `t_n` is the number of length-`n` segments.

Hence

\[
\boxed{
t_n=\frac{R_n}{\beta_n2^{m-1}}}
\]

is uniquely determined.

Proceeding through `n=2,...,N` recovers every nontrivial segment count, and finally

\[
t_1=m-\sum_{n\ge2}t_n.
\]

Thus

\[
\boxed{
C_O
\Longleftrightarrow
\{\ell_1,\ldots,\ell_m\}
}
\]

for final-observing schedules, where the right side is a **multiset**, not an ordered tuple.

## 7. P022-FC05 — the unobserved tail is also identifiable

Now allow a final unobserved tail of length `u`.

The constrained-segment profile before tail scaling always has singleton fibers.  Multiplying every fiber size by `2^u` therefore makes the smallest represented fiber size exactly

\[
\boxed{2^u.}
\]

So

\[
\boxed{
u=v_2(\min\operatorname{supp}C_O).}
\]

Divide all fiber sizes by `2^u`.  The normalized profile is the final-observing convolution profile of the observed segments, so FC04 recovers their segment-length multiset.

Therefore the general selected-layer result is

\[
\boxed{
C_O
\Longleftrightarrow
(\{\ell_1,\ldots,\ell_m\},u).
}
\]

Combining with P011:

\[
\boxed{
K_O(t)
\Longleftrightarrow
(\text{observed segment-length multiset},\text{hidden tail length}).
}
\]

This is an exact inverse relation inside the Barlow checkpoint specialization.

## 8. What remains lost: segment order

Multiplicative convolution is commutative and associative.  Therefore the complete fiber profile and collision polynomial cannot recover the order of segment lengths.

For example,

\[
(1,2,3)
\]

and

\[
(3,2,1)
\]

have the same complete profile and collision polynomial, but correspond to different checkpoint locations

\[
(1,3,6)
\]

and

\[
(3,5,6).
\]

Thus

\[
\boxed{
\text{full collision statistics recover unordered checkpoint geometry, not ordered placement.}
}
\]

This is the sharp current identifiability boundary.

## 9. Lower collision orders need not identify the geometry

FC05 requires the **complete** fiber profile or equivalently the complete P011 collision polynomial.  A single low-order statistic can alias different checkpoint geometries.

The pair-collision supplement supplies exact fixed-`N`, fixed-`m` examples with identical `J_2` but different segment multisets, image sizes, `J_3`, and full profiles.  Therefore the complete-spectrum hypothesis above is substantive rather than cosmetic.
