## 1. Primitive order

Do not start from a scalar precision parameter. Given:

- a finite raw state set `X`;
- a current discrete observation `O:X->Y`;
- a declared set `G` of causal operation generators;

ask which raw distinctions can be forgotten while every finite future operation word still produces the exact same observation.

Define

\[
\boxed{
x\equiv_G y
\iff
O(w(x))=O(w(y))
\quad\forall w\in\langle G\rangle.}
\]

Here `⟨G⟩` is the operation monoid generated by finite composition; the identity is the empty future.

Write

\[
\boxed{E_G=\equiv_G.}
\]

This is the minimum exact causal state for task language `G`.

## 2. OC-01 — Coarsest future-safe quotient

`E_G` has three immediate properties:

1. it refines the current observation kernel;
2. every `g in G` preserves `E_G`;
3. every other observation-safe equivalence through which all generators descend must refine `E_G`.

Equivalently,

\[
\boxed{
E_G
=
\bigcap_{w\in\langle G\rangle}
\ker(O\circ w).
}
\]

Thus `E_G` is the coarsest exact deterministic future-state summary.

## 4. OC-03 — Enlarging the future language can only refine the minimum state

If

\[
G\subseteq H,
\]

then

\[
\boxed{E_H\subseteq E_G.}

More possible futures mean fewer distinctions can be forgotten forever.

This does not contradict the fact that safe-operation sets of arbitrary pre-existing quotients need not be comparable. The monotonicity here concerns minimum quotients generated from the same current observation by future closure.

## 6. OC-05 — Operation-language coupling defect

Separate minimization gives

\[
E_G,\qquad E_H.
\]

Their static common refinement is

\[
E_G\wedge E_H.
\]

But the joint task allows mixed `G/H` words, so only

\[
\boxed{
E_{G\cup H}\subseteq E_G\wedge E_H
}
\]

holds in general, and the inclusion may be strict.

### Four-state witness

Let `X={0,1,2,3}`, with only state `3` currently visible:

\[
O(0)=O(1)=O(2)=0,
\qquad O(3)=1.
\]

Let

\[
g:0\mapsto0,\ 1\mapsto0,\ 2\mapsto1,\ 3\mapsto0,
\]

and

\[
h:0\mapsto0,\ 1\mapsto3,\ 2\mapsto0,\ 3\mapsto0.
\]

Neither `g`-only nor `h`-only futures distinguish `0` from `2`, but the mixed word does:

\[
2\xrightarrow{g}1\xrightarrow{h}3,
\qquad
0\xrightarrow{g}0\xrightarrow{h}0.
\]

Define the class defect

\[
\boxed{
\Xi_0(G,H)
=|X/E_{G\cup H}|-|X/(E_G\wedge E_H)|.
}
\]

Using the P011 collision spectrum, define for `k>=1`

\[
\boxed{
\Xi_k(G,H)
=J_k(E_G\wedge E_H)-J_k(E_{G\cup H}).
}
\]

All these collision coordinates are nonnegative. `J_0=#classes` is bookkeeping rather than a collision coordinate and is therefore kept separate as `Xi_0`.

## 9. OC-08 — The full safe-operation envelope almost determines the quotient

For equivalence relations `E,F` on the same raw set, except for one extreme degeneracy,

\[
\boxed{
E\ne F
\Longrightarrow
\mathrm{Safe}(E)\ne\mathrm{Safe}(F).
}
\]

The unique degeneracy is the pair:

- discrete equality;
- indiscrete total collapse.

Both admit every raw endomap.

If the current observation `O` is nonconstant, every admissible causal state must refine `ker O`; the indiscrete total collapse is therefore excluded. Hence among `O`-refining partitions,

\[
\boxed{
\mathrm{Safe}(E)=\mathrm{Safe}(F)
\Longrightarrow E=F.
}
\]

So, in the finite discrete regime, a full zero-cost operation envelope together with a nonconstant current observation uniquely determines the causal state quotient.

A physically declared operation language is normally only a small subset of `Safe(E)`, so a small observed operation set does not determine a unique state ontology.

\[
\boxed{
