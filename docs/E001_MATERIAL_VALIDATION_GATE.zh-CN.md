# E001 材料验证门槛——测量尺度、固定域与留出误差

状态：`ACTIVE ENGINEERING GATE / NOT FOUNDATION`

归属：`agent/e001-material-foundation`

## 1. 为什么需要这道门槛

全数据点拟合只能说明表示能力，**不能**单独证明预测价值。因此材料基准必须拆开实验表示、材料模型精度、校准和评估。

要求流程：

`声明测量尺度 -> 固定基准域 -> 仅训练集校准 -> 留出评估`。

只报告最漂亮的样本内曲线，不再构成完整工程证据。

## 2. 必须分开的三种尺度

至少区分：

1. **测量尺度**——实验量如何记录，例如整数计数 `v` 配合尺度因子 `100`，精确代表声明单位中的有理量 `v/100`；
2. **基准域**——模型预期工作的物理/计数区间；
3. **模型精度 `A`**——有限整数材料曲线可使用的状态分辨率。

不存在把 `A` 与实验尺度因子自动等同的规则。两者即使数值相同，也没有特殊语义。

`material_measurement.py` 已显式记录这层分离。当前单位字符串只是不可解释的元数据；本路线不假装已经提供完整量纲代数。

## 3. 固定域防泄漏规则

训练/测试切分不得重新定义材料坐标系。形变区间必须在切分前声明；无论留出端点还是内部点，从校准集中删除它都不能改变“形变计数 -> 有限状态格”的映射。

只有训练集的**响应值**允许影响离散输入根次数、输出硬化次数和整数输出尺度。留出目标值只能用于评估。回归测试会大幅修改一个留出目标值，并要求训练得到的模型保持不变。

## 4. Treloar 确定性验证检查点

同一组 25 点 Treloar 单轴基准 [SRC-TRELOAR-1944-RUBBER] / [SRC-THERMALCANN-2023-TRELOAR-DATA] 采用确定性交错五折切分：

`test_fold(i) = {index : index mod 5 = i}`。

每一折都固定使用 `[100,761]` 的计数域。

对当前基准的独立重算得到以下留出 RMSE：

| 模型 | 五折 RMSE |
|---|---:|
| Neo-Hooke | ~0.7999 |
| Mooney-Rivlin | ~0.6351 |
| Yeoh-2 | ~0.3142 |
| Yeoh-3 | ~0.1244 |
| E001 integer，`A=128` | ~0.2145 |
| E001 integer，`A=2048` | ~0.1842 |
| E001 integer，`A=8192` | ~0.1804 |

这进一步强化了负边界：有限整数曲线族已经不是玩具，但在 Treloar 单轴留出数据上目前仍**没有击败 Yeoh-3**。

## 5. 精度同时也是容量控制

随着有限状态增加，样本内误差继续下降，但留出误差改善更小，而且最优曲线结构开始变得不那么稳定。

在 `A=128` 时，当前五个验证折全部选择 `G4/H2`，只有输出尺度略有变化。精度提高后，四折偏向 `G8/H3`，而包含高形变端信息的一折在当前搜索盒中可能选择更复杂的 `G12/H4`。

工程解释：

> 更高精度开放了更多材料区别，也就开放了更多拟合自由度；这些自由度必须在留出数据上证明自己值得付出成本。

这只是 E001 当前压力测试观察，不是关于进取数论的一般统计定理。

## 6. 真实材料主张的强制报告契约

在被更严格协议替代前，至少必须报告：

1. 观测数据来源/溯源；
2. 精确测量尺度和单位标签；
3. 固定工作/基准域；
4. 模型精度 `A`，并与拟合材料参数分开；
5. 训练/全数据误差；
6. 确定性留出或外部测试误差；
7. 拟合/搜索盒和并列结果处理规则；
8. 可比的成熟基准模型；
9. 负结果和已知科学边界。

不能仅因为更高精度下训练 SSE 更小，就提升该模型的工程等级。
