# Causal Absorption Program — Making Traditional Mathematics a Derived Shadow of Enterprise Math

Status: `ACTIVE RESEARCH CORRECTION / CROSS-ROUTE PROGRAM`

This note corrects a structural drift in the current research:

> **Enterprise Math must not keep traditional mathematical objects as ontology and merely attach `precision / quotient / scale` annotations.**

The order must be reversed.

## 1. Foundation order

The research order is now:

\[
\boxed{
\text{state}
\to
\text{causal operations}
\to
\text{future distinguishability}
\to
\text{collapse}
\to
\text{derived observable / precision / geometry}.
}
\]

Consequently:

- precision is an output of causal collapse, not a prior label;
- dimension is a structural count of remaining distinguishable freedoms, not a declared coordinate count;
- distance must arise from primitive operation cost / causal program length / distinguishability depth, not an a priori norm;
- topology must arise from causal distinguishability filtrations or operation stability, not a preselected family of open sets;
- matrices, rank, kernel, Smith/Hermite forms, and ILP are computation languages first. They enter core ontology only after an exact causal derivation.

## 2. Absorption test

A traditional tool `T` may enter the Enterprise Math core only after being classified.

### A. `CAUSAL_DERIVED`

`T` is derived exactly from explicit states + operation language + future observations.

### B. `SHADOW_FORMULA`

An Enterprise Math object exists first; `T` is only a closed form or traditional name in a special regime.

Example: under standard unit-step integer geometry, `L1` is a closed form for shortest primitive program length, not a primitive norm.

### C. `COORDINATE_TOOL`

`T` is retained only for computation, compression, proof, or coordinates.

HNF/SNF/matrix forms may remain useful without becoming ontology.

### D. `EXTERNAL_COMPARISON`

If `T` requires a hidden real completion, continuous limit, externally declared epsilon/precision axiom, or other structure not generated internally, it remains a comparison tool.

## 3. First-stage absorbed structures

### Quotient / congruence

The primitive question is not "which quotient should we take?" but:

> Which distinctions can no allowed future ever observe?

Future equivalence is generated first; a quotient is only the encoding of those equivalence classes. A2/P023 owns the current general mother theory.

### Kernel / rank / observability

For an integer-linear future language:

\[
K_*=\{\eta:WB_\omega\eta=0\text{ for every finite future word }\omega\}
\]

is defined by causal invisibility.

Then:

- kernel = permanently invisible integer motion;
- rank = number of independent freedoms that some future can distinguish;
- an observability matrix = a coordinate table of future experiments pulled back to the present.

Thus linear algebra becomes a computational shadow of causal distinguishability.

### Basis

A basis is not assumed as a spatial coordinate frame.

A **causal probe basis** is a smallest family of concrete future experiments such that equality on those probes already implies equality under every allowed finite future experiment.

Its cardinality equals the causal visible rank.

### Ultrametric-like structure

Keep the integer primitive

\[
s(x,y)=\text{first future depth that distinguishes }x,y.
\]

Then

\[
\boxed{s(x,z)\ge\min(s(x,y),s(y,z)).}
\]

A conventional real-valued ultrametric, if ever useful, is only a monotone recoding of this causal depth.

### Topology

The depth-`t` indistinguishability classes

\[
U_t(x)=[x]_{\sim_t}
\]

form a clopen basis. Neighborhood therefore means:

> states still indistinguishable from `x` at some finite future depth.

The T0 quotient of this topology is exactly the stable future-equivalence quotient.

### Metric / norm

P012 already exhibits a successful absorption pattern:

\[
d(x,y)=\text{shortest primitive operation length from }x\text{ to }y.
\]

Standard `L1` is only the closed form for one generator family. A general norm may enter core only after being shown to be an exact causal word-cost formula.

## 6. Research-discipline change

From this note onward on this research line:

1. Do not add a new "precision coordinate" merely because a traditional invariant exists.
2. First identify the future distinction or operation obligation that gives the invariant causal meaning.
3. If no causal meaning is available, keep it in tooling/prior-art rather than core.
4. Every borrowed traditional theorem must be labeled as either proving something about our causal object or silently reinstalling the traditional object as foundation; the latter is not allowed.
5. Prefer proving that traditional mathematics is a special shadow of Enterprise Math over proving that Enterprise Math is compatible with traditional mathematics.
