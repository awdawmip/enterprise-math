# P018 缺陷 / 进位前人工作附录

状态：`PRIOR-ART APPENDIX`  
范围：进位 cocycle、section defect，以及成熟 extension theory 与 P018 专门 precision transport 之间的边界

## 进位与上同调

Daniel C. Isaksen 2002 年论文 *A Cohomological Viewpoint on Elementary School Arithmetic* 从上同调角度研究初等算术，并明确把进位放入 cocycle / group-extension 语言中。[SRC-ISAKSEN-2002-CARRY]

因此，进取数论**不**声称以下内容属于项目发明：

- 用 cocycle 编码进位；
- 用 group extension 理解进位；
- 改变 section 时局部 cocycle 按 coboundary 型修正变化；
- 标准的 nonsplitting / section-obstruction 语言。

## 当前项目专门检验的内容

P018 只把上述成熟代数语言作为更大有限精度问题中的一层。项目真正要检验的是：

1. 运算与投影不交换时，能否把非交换量保留成精确有限缺陷，而不是误差项；
2. 能否把依赖表示的局部缺陷与在合法 chart change 后仍保留的结构性缺陷分开；
3. 纯 canonical precision path 在精确 chart transport 后是否必然 flat；
4. collapse-then-project 与 project-then-collapse 这类真实 operation scheduling 是否具有有限、可组合的 defect transport law；
5. 这些可搬运缺陷能否反哺 P017 及其他有限状态问题的可复用证明证书。

当前整合的历史创新状态继续保持 `NOVELTY_UNVERIFIED`。它的价值由是否产生新的定理杠杆和跨问题复用来判断，而不是由 “cocycle”“holonomy” 或 “atlas” 这些术语本身来判断。
