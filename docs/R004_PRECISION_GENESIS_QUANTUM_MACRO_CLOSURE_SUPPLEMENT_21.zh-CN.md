补充 20 已把“保住指定线性 target quotient”写成 p-adic missing-target module。本补充证明两个既有 A3 对象其实已经是该接口的实例：weighted exterior relation field 与 guard-image lattice。

这里不主张一般 exterior algebra、Smith normal form、有限 module duality 或 p-adic projective geometry 为新数学。

## 1. A3 exterior map 本身就是 structural target

固定整数 capacity vector `m=(m_1,...,m_d)`。A3 weighted relation field 为

`E_m(c)=m wedge c`，

坐标为

`(E_m(c))_(i,j)=m_i c_j-m_j c_i`。

它本身就是线性 target map。因此 m 固定后，补充 20 的所有 Structural Target Cut theorem 都可以直接消费它。

## 2. Exterior Smith law

令 `g=gcd(m_1,...,m_d)`，假设 `m != 0`，写成 `m=g u`，其中 u 为 primitive integer vector。

primitive integer vector 可扩张为 unimodular basis，因此经 unimodular domain change 后 u 可变成 `e_1`；在 `wedge^2 Z^d` 上诱导的变换同样 unimodular。于是 `c -> m wedge c` 的矩阵 Smith-equivalent 于

`g*(c_2,...,c_d,0,...,0)`。

故其所有非零 Smith invariants 都恰好等于

`g,g,...,g`（共 `d-1` 个）。

这把此前 determinant-token identity 推进成完整 integer invariant-factor description。

## 3. p-adic relation-field profile

在 `R=Z/p^K Z` 上，令

`s=min_i nu_p(m_i)`，并 cap 在 K。

若 `s=K`，relation field 为零。否则写

`m=p^s u`，

其中 u mod p primitive。则

`ker(E_m)=R u + p^(K-s) R^d`，

并且

`im(E_m) ~= (Z/p^(K-s) Z)^(d-1)`。

因此 A3 relation field 的 exact p-group exponent profile 为

`(K-s,...,K-s)`（共 `d-1` 项），

integer exponent mass 为

`(K-s)(d-1)`。

对 integer capacity vector，`s=nu_p(gcd(m_i))`。所以 capacities 的公共 p-adic content 会减少 relation depth，但不会改变 `d-1` 个 relation directions。

定义 capped A3 relation-digit deficit

`Gamma_(p,K)^A3(m)=(d-1)*min(K,nu_p(gcd(m_i)))`。

primitive normalization `m/gcd(m_i)` 会同时清除所有 prime axes 的公共 precision deficit。

## 4. 相同 profile 不等于相同 relation semantics

若 u,v 在 R 上都 primitive，则两个 exterior fields 都有完全相同的 exponent profile

`(K,...,K)`（`d-1` 项）。

但 `E_u` 能通过 `E_v` factor，当且仅当

`ker E_v subseteq ker E_u`。

两个 kernel 都是 primitive rank-one lines，因此这等价于

`R v=R u`，

也等价于

`v=alpha u`，其中 `alpha` 为 R 中 unit。

所以 relation rank / exponent profile 只描述 representation capacity，不能识别 projective direction 或 typed semantics。

## 5. Projective agreement depth

对 primitive u,v 定义

`rho_(p,K)(u,v)=min(K,min_(i<j) nu_p(u_i v_j-u_j v_i))`。

则 `rho>=r` 当且仅当 u,v 在模 `p^r` 的 primitive projective space 中代表同一条 line。

证明：选 u 的一个 unit coordinate。若全部 2x2 minors 在 `p^r` 下为零，则 v 每个 coordinate 都等于 u 对应 coordinate 的同一个 unit multiple；逆命题显然。由于“mod `p^r` 为同一 primitive projective line”本身具有传递性，`rho>=r` 构成 nested equivalence relations。

定义整数 projective defect distance

`d_(p,K)(u,v)=K-rho_(p,K)(u,v)`。

于是

`d(u,w)<=max(d(u,v),d(v,w))`。

所以 `d_(p,K)` 是 primitive projective directions mod `p^K` 上的 integer ultrametric。

## 6. Target-defect distance = projective distance

把 current observation 取成

`E_v=v wedge -`，

target 取成

`E_u=u wedge -`。

因为 v primitive，

`ker E_v=R v`。

同一 current fiber 内 target variation 为

`E_u(R v)=R(u wedge v)`。

cyclic submodule generated by `u wedge v` 的 exponent depth 为

`K-rho_(p,K)(u,v)`。

由补充 20 的 defect/guard duality，missing-target module 具有同样 profile。因此

`Delta(E_v -> E_u)=d_(p,K)(u,v)`。

也就是说，用一个 primitive A3 relation representation 替代另一个时必须补回的 p-adic structural precision，精确等于它们在 projective capacity-direction space 上的 ultrametric distance。这个 metric 不是外加的，而是 compiler 自己的 target-defect mass。

## 7. Guard-image duality

令 A 为 current linear coarse observation，W 为 R 上 A3 guard matrix，定义

`K_A=ker A`。

补充 20 对 exact guard-score visibility 给出的 missing-target module 为

`D_(A,W)=(Row(A)+Row(W))/Row(A)`。

在 finite perfect pairing 下，

`Row(A)=Ann(K_A)`，

而

`Row(A)+Row(W)=Ann(K_A cap ker W)`。

所以 D 是

`K_A/(K_A cap ker W)`

的有限对偶。由第一同构定理，

`K_A/(K_A cap ker W) ~= W(K_A)`。

因此

`D_(A,W) ~= W(K_A)^vee`

在 finite-dual 意义下成立，两边具有完全相同的 invariant p-group exponent profile。

这把 Structural Target defect module 精确识别成 A3 既有 guard-image lattice 的 dual representation。

## 8. 这条桥解决什么、没有解决什么

它统一的是**hidden guard freedom 的数量与类型**：

- guard descend 当且仅当 `D=0`；
- rank-one hidden guard 对应 nonzero cyclic defect profile；
- full-rank hidden guard 对应 guard-direction rank 全开的 defect module；
- 每个 hidden direction 的 p-adic depth 被保留，不再只压成 rank scalar。

但 piecewise program exactness 不能被简化为 `D=0`。A3 已证明：guard hidden 时，只要所有 reachable branches 诱导同一个 coarse effect，branch identity 可以被安全擦除。branch-effect equality、reachable sign patterns 与 threshold orthants 仍属于 A3 自己的 typed piecewise semantics。

Defect module 只量化 hidden guard degrees of freedom，不决定 program 如何使用这些 freedom。
