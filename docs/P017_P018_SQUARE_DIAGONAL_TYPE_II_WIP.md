# P017×P018 square-diagonal Type-II / rough-core interface

Status: `PROVED_WIP interfaces / analytic targets open`

This note records the endpoint reached after the boundary-carry, quotient-channel,
and fixed-cutoff square-phase languages have been compressed.  It does **not**
claim Legendre's conjecture.

## 1. Exact half-cutoff identity

For `k>=10`, let

\[
R_{1/2}(k)
=
\#\{1\le r\le 2k:\gcd(k^2+r,P_{\lfloor k/2\rfloor})=1\}.
\]

Every composite counted by `R_{1/2}` is exactly `pq` with

\[
k/2<p\le k<q<2k+4,
\]

and `p,q` prime.  Therefore

\[
\pi((k+1)^2)-\pi(k^2)
=R_{1/2}(k)-H_{1/2}(k),
\]

where `H_{1/2}` is the terminal balanced-semiprime tail.

For each high prime `p`, the possible odd cofactors are explicit.  Put
`a=k-p` and

\[
a^2=2pu+v,\qquad 0\le v<2p.
\]

Then

\[
q_1=k+a+2u+2,\qquad r_1=2p-v,
\]

and the only possible second cofactor is `q_1+2`, present exactly when
`r_1<=2a`.  Hence

\[
H_{1/2}(k)
=
\sum_{k/2<p\le k}
\left(
1_{\mathbb P}(q_1(p))
+
\varepsilon_k(p)1_{\mathbb P}(q_1(p)+2)
\right),
\]

with `epsilon_k(p)` a purely geometric `0/1` shell condition.

The same candidates are generated by the reciprocal odd-successor map

\[
\Phi_k(x)=\text{least odd integer strictly greater than }k^2/x.
\]

For every terminal edge `pq` in the square interval,

\[
q=\Phi_k(p)\text{ or }\Phi_k(p)+2,
\qquad
\Phi_k(q)=p.
\]

## 2. Deterministic shadow and counterexample saturation

Ignore cofactor primality and let `C_k` be the set of offsets generated by all
one/two reciprocal candidates from high primes `p in (k/2,k]`.  Then

\[
\boxed{
\operatorname{PrimeOffsets}(k)
=
\operatorname{HalfRoughOffsets}(k)\setminus C_k.
}
\]

The nontrivial direction is that a shadow state which is also half-rough has
prime cofactor: a composite `q<2k+4` has a prime factor at most
`sqrt(2k+3)<=k/2` for `k>=10`.

Thus a Legendre counterexample is equivalent to exact shadow saturation

\[
\operatorname{HalfRoughOffsets}(k)\subseteq C_k.
\]

This is a compressed counterexample signature, not a contradiction.

## 3. Fixed-cutoff square phase cannot see lift height

Fix `z,H` and set

\[
S_{z,H}(x)=
\#\{1\le r\le H:\gcd(x^2+r,P_z)=1\}.
\]

If `x^2=k^2 (mod P_z)`, then `S_{z,H}(x)=S_{z,H}(k)` exactly.  For every odd
prime `p<=z` not dividing `k`, the two local choices `x=+k,-k (mod p)` are
independent; CRT gives

\[
2^{\#\{3\le p\le z:p\nmid k\}}
\]

distinct sign-twisted classes modulo `P_z` with the same fixed-cutoff survivor
pattern.

Therefore the Archimedean fact that the distinguished root is the literal small
integer `k` is not encoded in fixed-cutoff square-phase data.  Any future proof
using this distinction must explicitly use the moving diagonal

\[
x=z,\qquad H=2x,
\]

or an equivalent operation whose allowed cutoff/horizon changes with the lift.

## 4. Exact Type-II terminal target

Define the nonnegative von-Mangoldt correlation

\[
\mathcal B(k)
=
\sum_{k/2<n\le k}
\Lambda(n)
\left(
\Lambda(\Phi_k(n))
+
\varepsilon_k(n)\Lambda(\Phi_k(n)+2)
\right).
\]

Every terminal prime-prime edge contributes at least
`log(k/2) log(k)` to `mathcal B(k)`.  Prime powers or composite first arguments
only add nonnegative weight.  Hence

\[
\boxed{
H_{1/2}(k)
\le
\frac{\mathcal B(k)}{\log(k/2)\log k}.
}
\]

Consequently the analytic estimate

\[
\mathcal B(k)\ll k
\]

would imply the log-saving terminal bound

\[
H_{1/2}(k)\ll k/\log^2 k.
\]

This isolates a binary prime correlation along a reciprocal/floor map.  Runbo
Li, *On some problems of primes with the floor function*, arXiv:2308.16301,
proves asymptotics when `floor(x/n)` is prime for integer `n` in a range that
includes the square-root scale, but that result does not impose primality on
`n` itself.  The present terminal target needs both prime directions.

## 5. Rough-core target and the linear-sieve barrier

The exact finite capacity certificate already gives

\[
R_{1/2}(k)
>
[\pi(k)-\pi(\lfloor k/2\rfloor)]
+
\operatorname{Twin}(k,2k+4)
\quad\Longrightarrow\quad
\pi((k+1)^2)-\pi(k^2)>0.
\]

Thus the remaining core problem is a **pointwise square-anchored lower bound**
for `R_{1/2}(k)`.

This is intentionally not labelled a routine linear-sieve task.  Peter J.
Campbell, *On the Existence of Integers with at Most 3 Prime Factors Between
Every Pair of Consecutive Squares*, arXiv:2603.10356v2, proves a `P_3` in every
consecutive-square interval using explicit Richert weights and a linear sieve.
In the explicit lower linear sieve recorded there, the lower function satisfies

\[
f(s)=0\qquad(0<s\le2).
\]

The same paper explicitly identifies an upgrade from `P_3` toward `P_2` as
beyond that weighted-sieve framework and points to bilinear-capable sieve input
as the relevant missing type of information.

At the present half cutoff `z=k/2`, an interval of length `2k` with the ordinary
absolute remainder treatment does not even place the lower sieve near a
positive `s>2` regime.  Therefore merely optimizing the same local-density or
Bonferroni/linear-sieve language is not the intended continuation.

Ofir Gorodetsky, *The variance of integers without small prime factors in short
intervals*, arXiv:2111.00853, gives strong variance/almost-all information for
rough numbers, but the unconditional ranges stated there are far from the
pointwise square-diagonal regime `X=k^2`, `H=2k`, `y=k/2`; in particular the
paper records almost-all bounds with `y<=X^{1/20}` from earlier sieve-weight
technology, whereas here `y` is of order `X^{1/2}`.

## 6. Active frontier

The carry/refinement/Fourier representation is no longer the active target.
The square-diagonal branch now has two explicit analytic interfaces:

1. **rough core:** prove a pointwise lower bound for `R_{1/2}(k)` that uses the
   moving self-reference `x=z=k`, rather than a fixed-wheel phase norm;
2. **terminal Type II:** control `mathcal B(k)`, equivalently the binary
   prime-preservation of the reciprocal odd-successor staircase.

A successful result on only one side is useful but not yet a Legendre proof.
The strongest next step would connect the moving-cutoff rough core to a
bilinear/divisor-switching estimate so that the same new input controls both
interfaces rather than treating them independently.
