# 进取数论研究回流与底层维护

当前规则：2026-11-13。数学问题保持开放，研究方法、深度和步骤由研究者判断。本规则取代此前 steward 不得成为主要研究者、必须登记 FQ 并停止深究、固定双轨交接和固定闭环的要求。

底层维护者、驾驶员和研究者都可以按数学价值深入已有材料，追溯旧问题、归纳结构、综合路线、检查反例、及时纠错与复用成果。已有工具的词匹配只是发现提示，不是充分性判断或排他清单；可以沿精确定义、源文献、适用范围和已有任务关联寻找其他方法。

研究回流是可选支持，不是每轮必经流程。FQ、Feedback Packet、分类、阶段标签和协作交接都按需要使用；没有固定模板、数量、顺序、评分或完成凭据。发现值得深究的问题可以自己研究，也可以协作，不因缺 FQ、Packet、审计阶段或历史状态被禁止。空关联数组不表示没有成果，也不要求补造任务。

GitHub 是科研资料正本。有新成果解决、纠正、推广旧问题或给出可复用规律时，按实际价值更新相关旧入口、定义说明、工具路由或任务旁注，附真正使用的来源和适用范围；不必在两个地方复制正文。候选联系、已证明结论和已否定边界分别如实标注。控制面关联提示只帮助发现，不证明数学、不领取任务、不改变 owner。原不可变报告和审核不回写；可用新的说明保留更正与出处。

形式化证明暂缓，Lean 不作为普通推进或验收默认要求。需要验证时采用命题所需的可复查人工证明或复算。不将漂亮猜想、数值结果或成功回执冒称普遍定理；定义、量词、假设、最弱适用范围和失败边界按内容需要保留。

研究者持续外部观察可沿已有 Driver/steward 工作自然进行，不增加定时任务，不要求每轮全库回溯或重复扫描。`foundation_backflow.json` 保存可选关联；精确 Task 的普通 continuation 可返回匹配提示，不增加启动必读。已知 H0N/H0O、GEO6 关联只记录原来源中的后继关系，不替数学研究作新的结论。

既有真实身份、贡献历史、科学隔离和活跃 owner 保持。允许数学探究不等于改授原生角色、取得他人 CLAIM 或提升候选为 Foundation 真理；正式共享写入仍使用自身已有权限和并发归属检查。Phase A 盲态规则不因回流提示而泄漏后续研究。需要协作或正式任务时可用现有 #82/#164/#240 与任务发布入口，不强制先走一遍行政流程。
