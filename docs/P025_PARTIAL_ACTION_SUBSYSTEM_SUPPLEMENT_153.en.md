## 1. Setup

Let `P_gate` be the helper dependency poset, `I` a legal ideal, and let

\[
Q\subseteq P_{gate}
\]

be the declared labelled helper-action family.

Each action `q in Q` is partial:

\[
F_q(I)=I\cup\{q\}
\]

when `q` is enabled, and undefined otherwise.

We ask when the projected state

\[
\pi_Q(I)=I\cap Q
\]

supports the entire legality-sensitive future language generated by these actions.

## 2. Predecessor-closed action family

Assume `Q` is an order ideal of `P_gate`: every helper ancestor of a declared action is also declared/visible.

Stage 152 gives current enabledness factorization:

\[
q\text{ enabled in }I
\iff
q\text{ enabled in }I\cap Q.
\]

When enabled,

\[
\pi_Q(F_q(I))
=
(I\cup\{q\})\cap Q
=
(I\cap Q)\cup\{q\}.
\]

Therefore

\[
\boxed{
\pi_Q\circ F_q
=
F_q^Q\circ\pi_Q
}
\]

as partial maps, including exact agreement of enabledness/domain membership.

## 3. All action words factor

Because every generator partial operation commutes with projection and preserves legality, induction on word length gives:

- a declared `Q`-word is executable from global ideal `I` iff it is executable from projected ideal `I\cap Q`;
- when executable, the final projected state is exactly the result of executing the word in the induced subsystem;
- every prefix legality decision also agrees.

Hence

\[
\boxed{
I\mapsto I\cap Q
\text{ is sufficient for the complete legality-sensitive }Q\text{-word future.}
}
\]

## 4. Current enabledness is already future-complete

By Stage 151 applied inside the induced poset `Q`, the labelled enabled frontier of `I\cap Q` reconstructs that projected ideal exactly.

Therefore, for predecessor-closed `Q`, the **current visible enabledness signature** already determines the complete future behavior of every word over the declared helper actions:

\[
\boxed{
\text{current }Q\text{-enabled frontier}
\Longleftrightarrow
I\cap Q
\Longrightarrow
\text{all }Q\text{-action futures}.
}
\]

No extra history/refinement coordinate is needed.

## 5. Nonclosed support fails immediately

If `Q` is not predecessor-closed, hidden predecessors can change whether a visible action is enabled while `I\cap Q` remains fixed. Stage 152 supplies an eight-way example with `Q={h5}`.

Thus the projection can fail to respect a declared generator at **word length one**. No deeper future closure can repair that projected subsystem without adding hidden dependency state/support.

## 6. Operation-language support closure

For this helper system, a natural self-contained action language is therefore not an arbitrary syntactic set `Q`, but a dependency-closed support:

\[
\boxed{Q\leadsto\downarrow Q.}
\]

This support closure is a semantic cost of the operation language itself.
