## 1. The compressed lattice has its own exact arithmetic core

Supplement 20 reduces the current norm/Wronskian witness language to

\[
\Lambda_{abc}
=
\{(u,v):
 u\in A\mathbb Z,
 v\in B\mathbb Z,
 u+v\in C\mathbb Z\},
\]

where

\[
A=A(a),\qquad B=A(b),\qquad C=A(c)
\]

are the raw block derivative image generators, with value zero for a unit block.

The Wronskian is

\[
W(u,v)=a v-b u.
\]

The next question is purely arithmetic:

> What is the positive generator of `W(Lambda_abc)`?

It has a three-term closed formula.

## 2. Lift to one relation row

For non-unit blocks write

\[
u=A x,
\qquad
v=B y,
\qquad
u+v=C z.
\]

The additive condition becomes

\[
\boxed{A x+B y-C z=0.}
\]

Let

\[
\boxed{G=\gcd(A,B,C).}
\]

After dividing the relation row by its content, use the primitive row

\[
\boxed{
\alpha=\left(\frac A G,\frac B G,-\frac C G\right).
}
\]

On `(x,y,z)`, the Wronskian functional is

\[
\boxed{
\beta=(-bA,aB,0).
}
\]

Because `c=a+b`, the three `2x2` minors of `[alpha;beta]` are, up to sign,

\[
\boxed{
\frac{cAB}{G},
\qquad
\frac{bAC}{G},
\qquad
\frac{aBC}{G}.
}
\]

## 3. P025-T60 — exact Wronskian image generator

The standard determinantal-divisor identity for a primitive relation row gives

\[
\beta(\ker_{\mathbb Z}\alpha)
=
D\mathbb Z,
\]

where `D` is the gcd of the `2x2` minors. Therefore

\[
\boxed{
D
=
\frac{\gcd(cAB,bAC,aBC)}{G}.
}
\]

Equivalently,

\[
\boxed{
W(\Lambda_{abc})=D\mathbb Z.
}
\]

This is the exact positive generator of all arithmetic Wronskian values available to additive block-value witnesses.

### Prior-art boundary

The determinantal-divisor statement is standard integer linear algebra and was already used in Supplement 04. The new project-side point is only that after the block-value quotient its three minors collapse to these explicit block-ideal expressions.

## 4. P025-T61 — compact absorption-floor formula

Let

\[
M=m(a)m(b)m(c).
\]

Pasten's residual divisibility gives `M|D`. Hence

\[
\boxed{
\eta_{\min}
=
\frac{D}{M}
=
\frac{\gcd(cAB,bAC,aBC)}
{G\,m(a)m(b)m(c)}.
}
\]

Thus the absorption-floor language no longer needs the full prime-coordinate rows, the cross-prime minor table, or even the separate block radicals and normalized contents once the three raw derivative image ideals are known.

The sufficient arithmetic state is now

\[
\boxed{(a,b,c;A,B,C)}
\]

with residual normalization recoverable from the actual integers when they remain part of the relation state.

No claim is made yet that this is the P023-coarsest possible state.

D=12.
\]

This is exactly

\[

## 6. P025-T62 — index of the non-unit compressed lattice

Assume all three blocks are non-unit, so `A,B,C>0`.

In `(x,y)` coordinates the condition

\[
A x+B y\equiv0\pmod C
\]

is the kernel of a map

\[
\mathbb Z^2\to\mathbb Z/C\mathbb Z.
\]

The image subgroup generated by `A` and `B` modulo `C` has cardinality

\[
\frac{C}{G}.
\]

Therefore this kernel has index `C/G` in `Z^2`.

Scaling `(x,y)` to `(u,v)=(Ax,By)` contributes index `AB`, so

\[
\boxed{
[\mathbb Z^2:\Lambda_{abc}]
=
\frac{ABC}{G}.
}
\]

This is a compact relation-lattice density invariant. It does not determine the block access metric `K(u,v)` and therefore does not by itself determine `mu` or `nu`.
