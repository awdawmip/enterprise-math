# 前人工作、思想谱系与暂定创新边界

## 1. 目的

进取数论必须能够回答：每一个重要构件究竟从哪里来。

对每个重要组成部分，我们明确区分：

- 哪些是已经存在的前人工作；
- 哪些定义或定理被我们直接采用；
- 哪些只作为结构邻居或对照；
- 进取数论如何组合或重新解释这些构件；
- 哪些部分属于本项目自己的假说；
- 某项“创新”是否真的完成了历史优先性验证。

总原则从严：**优先假设相似的前人工作值得认真对待，不预设历史优先权属于我们。**

机器可读的来源记录位于 `sources.json` 和 `lineage.json`。下文使用的稳定来源编号具有规范意义。

## 2. 关系词汇

我们使用六种关系标签。

- `ADOPT`——实质采用已有数学定义或结果。
- `EXTEND`——保留引用核心的同时增加更强数学结构。
- `REINTERPRET`——形式对象相同，但赋予不同基础或物理解释。
- `COMBINE`——把分别已有的思想组合成一个结构。
- `CONTRAST`——把引用工作作为竞争解释或刻意不同的路线。
- `INSPIRE`——引用工作影响研究方向，但并不是定义成立所必需的逻辑前提。

这些标签描述思想谱系，不是版权关系。

## 3. 算术谱系

### 3.1 整数根

整数平方根的“最大整数”定义是已有数学与计算实践：当前 Python 文档把整数平方根定义为满足 \(a^2\le n\) 的最大整数 \(a\)。[SRC-PYTHON-ISQRT]

Mathlib 也已经提供一般自然数 `Nat.nthRoot` 的形式化，并在正指数条件下证明 `a ≤ Nat.nthRoot p b ↔ a^p ≤ b` 的序刻画，同时包含完全幂精确恢复及相关整数根定理。[SRC-MATHLIB-NTHROOT] 因此，进取数论的 Lean 层直接复用 `Nat.nthRoot`，不另造平行的形式化根实现。

进取数论**采用这个不等式定义**，但改变其基础语义。普通数值文档也会把同一个运算说成“精确实数平方根的向下取整”；进取数论不要求把那个隐藏实数根当作基本对象。

因此：

- **前人工作：**整数平方根、一般自然数整数根及其形式化序刻画；
- **我们的组合：**把序定义的整数运算提升为该状态空间的根运算原语；
- **不是我们的发明：**算法、最大整数定义、`Nat.nthRoot` 以及已有的序论定理；
- **项目新增：**在选定的基础语义中，整数结果本身就是精确结果，而不是对更真实底层值的近似。

### 3.2 向下除法与序伴随

Mathlib 把向下除法形式化为满足 \(a c\le b\) 的最大状态 \(c\)，并明确把它识别为 Galois connection 中的右伴随。[SRC-MATHLIB-FLOORDIV]

这为进取数论的一般形式

\[
F^\downarrow(n)=\max\{k:F(k)\le n\}
\]

提供了很强的现成数学先例。

因此我们复用“序伴随”语言，不为它重复发明新术语。

### 3.3 尺度整数与定点算术

“整数 + 尺度”表示早已有大量先例。NIST 记录过把给定十进制输入转换成整数表示后进行精确加、减、乘的方案。[SRC-NIST-INTEGER-DECIMAL] 现代 block floating / scaled fixed-point 工作也能利用整数运算完成大量数值内核，并使用显式共享指数。[SRC-KOHL-BFP]

还有 exact-real 路线使用尺度整数和隐式分母，通过提高精度来保持传统实数语义。[SRC-BRIGGS-EXACT-REAL]

所以进取数论**不**声称“整数 + 尺度”表示是新发明。区别在基础层：

- 定点、block floating 和 exact-real 体系通常仍保留外部目标值或精度语义；
- 进取数论研究：整数状态和有限尺度是否可以本身就是基本语义，而不需要一个无限完成的实数作为隐藏目标。

### 3.4 精确符号代数作为对照

FLINT 可以用整数最小多项式和隔离区间精确表示代数数。[SRC-FLINT-QQBAR] Sage 可以用整数三元组表示 \((a+b\sqrt D)/c\) 形式的二次数域元素。[SRC-SAGE-QUADRATIC]

这些工作直接否定了一个过于简单的说法：“无理数必须靠无限多位小数才能被精确表示。”这一点进取数论接受。

然后我们提出另一个问题：即使精确对象可以有限符号表示，是否仍必须把传统无限精确代数实数当作底层本体。

## 4. 有限信息与离散物理谱系

### 4.1 对实数物理本体的有限信息批评

Gisin 论证普通实数包含无限信息，并提出 finite-information numbers 作为更合适的物理替代。[SRC-GISIN-2018] Del Santo 与 Gisin 随后把“所有物理量都拥有预先确定的无限位数字”称为 `principle of infinite precision`，并发展 finite-information quantities 的经典物理解读。[SRC-DEL-SANTO-GISIN-2019]

这构成进取数论拒绝“物理上实际存在无限精度”的直接前人思想。

进取数论不把这一批评据为原创。我们的不同步骤是继续研究整数闭合、显式尺度的算术与坍缩动力学，而不是直接采用这些论文中的 FIQ 形式体系。

### 4.2 离散时空

Snyder 在 1947 年已经给出 Lorentz 不变的离散时空例子。[SRC-SNYDER-1947] causal set 理论后来把局部有限偏序集作为微观时空候选，并研究连续时空如何在适当尺度成为近似。[SRC-CAUSALSET-1987]

因此，离散性、局部有限、因果偏序以及尺度相关的连续近似都不是新概念。

进取数论目前把它们作为**物理邻居和压力测试对象**，而不是直接采用它们的时空定义。

## 5. 不可逆谱系

### 5.1 逻辑不可逆与可逆计算

Landauer 研究没有单值逆的逻辑函数，并把逻辑不可逆与物理耗散联系起来。[SRC-LANDAUER-1961] Bennett 进一步说明，保存中间结果可以让通用计算逐步保持逻辑可逆。[SRC-BENNETT-1973]

这两条路线非常重要，因为它们准确暴露了我们假说的分叉点。

进取数论**不是**在重新发现普通的信息擦除。它检验更强的可能性：自然状态演化本身就是多对一，而不要求存在类似 Bennett “保存历史”的隐藏可逆完成。

### 5.2 投影与粗粒化

Zwanzig 用投影形式推导带记忆效应的宏观不可逆输运方程。[SRC-ZWANZIG-1961] Mori 发展了相关的投影算符框架来研究输运、集体运动和布朗运动。[SRC-MORI-1965]

这是我们必须正面对照的一条成熟路线：

\[
\text{更细动力学}\rightarrow\text{投影后的宏观动力学}.
\]

进取数论刻意检验更强的替代方案：

\[
\text{基本状态}\rightarrow\text{基本的多对一状态}.
\]

这种更强本体解释只是项目假说，绝不是 Mori-Zwanzig 文献已经证明的结论。

### 5.3 前像熵与折叠熵

利用前像结构量化非可逆性已经形成成熟研究路线。[SRC-NITECKI-PRZYTYCKI-1999] [SRC-CHENG-NEWHOUSE-2005] Ruelle 把 folding 类熵与非平衡熵产生联系起来。[SRC-RUELLE-1996] 后续工作进一步明确研究“非可逆性如何贡献熵”，并在特定条件下联系前像熵与 folding entropy。[SRC-WU-ZHU-2021]

所以进取数论不声称“多个前像和熵有关”是我们的新发现。

我们目前更基础、更窄的设计选择是：先使用整数

\[
M_t(x)=|[x]_t|
\]

以及其他整数值观察量，再决定是否需要把对数、测度或实值熵提升为原语。

### 5.4 物理中的前向半群

前向动力学半群在开放量子系统中早已是标准工具。1976 年 Gorini-Kossakowski-Sudarshan 和 Lindblad 的工作给出了重要的完全正量子动力学半群生成元结构。[SRC-GKSL-1976] [SRC-LINDBLAD-1976]

进取数论只把“半群”借作“不要求逆映射时的时间复合”结构邻居，并不把我们的坍缩动力学等同于 GKSL/Lindblad 模型。

## 6. 进取数论究竟怎样组合

当前组合可以分成五层。

1. **序定义的整数运算**——整数根和向下伴随被当作精确状态映射，而不是隐藏连续答案的近似。[SRC-PYTHON-ISQRT] [SRC-MATHLIB-NTHROOT] [SRC-MATHLIB-FLOORDIV]
2. **显式有限尺度**——保留整数加尺度的工程经验，但不预设无限实数完成是物理基本值。[SRC-NIST-INTEGER-DECIMAL] [SRC-KOHL-BFP] [SRC-GISIN-2018] [SRC-DEL-SANTO-GISIN-2019]
3. **把坍缩作为代数算子**——用单调、幂等的序投影语言研究 \(C_p(n)=R_p(n)^p\)。[SRC-MATHLIB-CLOSURE]
4. **把本征多对一动力学单列为假说**——明确区别于可逆计算和“可逆微观 → 粗粒宏观”的解释。[SRC-BENNETT-1973] [SRC-ZWANZIG-1961] [SRC-MORI-1965]
5. **先研究前像退化整数，再研究对数熵**——把已有 preimage / folding entropy 作为数学邻域，但首先保留整数原语。[SRC-CHENG-NEWHOUSE-2005] [SRC-WU-ZHU-2021]

因此，目前真正值得检验的创新候选是**这些构件构成的整体基础框架及其推论**，而不是其中任一孤立部件。

## 7. 暂定创新主张

仓库目前允许使用以下表述。

### 7.1 项目组合创新

**EM-NOV-001。** 我们提出一种整数优先语义：整数根是精确原语，而不是隐藏实数根经过取整后的视图。

**EM-NOV-002。** 我们把显式尺度与整数状态语义结合，同时不要求无限精确实数完成作为隐藏物理值。

**EM-NOV-003。** 我们同时把完全幂坍缩算子作为序论投影来研究，并把它作为本征多对一自然转移的候选。

**EM-NOV-004。** 我们优先研究整数前像数量及相关整数观察量，而不是先把对数熵提升为基础原语。

### 7.2 物理假说

**EM-NOV-005。** 我们检验基本动力学是否可能真正是多对一，而不是只在粗粒化或信息擦除以后才显得不可逆。

这是一条物理假说，不是已经成立的结果。

### 7.3 历史创新状态

**进取数论整体的历史创新状态目前是 `NOVELTY_UNVERIFIED`。**

我们还没有完成足够穷尽的文献调查，不能声称此前没有人建立过等价框架。在达到这个证据门槛以前，只使用：

- “我们定义”；
- “我们提出”；
- “我们组合”；
- “我们研究”；
- “在目前已经记录的检索范围内，我们尚未发现等价整体组合”。

没有专门的优先性证据审查，不得使用“首次”“前所未有”“从未有人提出”等表述。

## 8. 绝不能错误归因给我们的内容

以下内容不得被写成进取数论的发明：

- 整数平方根或一般自然数整数根；
- Euclidean / floor division；
- Galois 伴随；
- closure / interior operator；
- fixed-point 或 scaled-integer 算术；
- 代数数的有限精确符号表示；
- 对无限精度物理实数的批评；
- 离散时空或 causal set；
- 逻辑不可逆或可逆计算；
- Mori-Zwanzig 投影/粗粒化；
- 动力学半群；
- preimage entropy 或 folding entropy。

我们的责任是把这些谱系引用清楚，并精确说明自己的使用究竟改变在哪里。

## 9. 更新规则

本文档是项目的持续基础设施。

任何新的外部来源，只要实质影响了定义、证明思路、术语选择、物理对照或创新边界，就必须：

1. 在 `sources.json` 中新增稳定 `SRC-*` 记录；
2. 在 `lineage.json` 中把它连接到一个或多个 `EM-COMP-*` 构件；
3. 如果它改变了人类可读的谱系或创新边界，同步更新本文档的中英文版本；
4. 更新实际依赖该来源的规范技术文档；
5. 结论强度不得超过证据；
6. 保留旧的来源谱系，不因为新前人工作“不方便”就删除历史。

`tools/check_references.py` 与引用完整性工作流负责强制执行其中可机器检查的部分。
