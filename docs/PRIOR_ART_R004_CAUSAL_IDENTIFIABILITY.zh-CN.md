# Prior Art — R004 / FQ-007 有限反事实完备化

状态：`L4 CANONICAL CANDIDATE / PRIOR-ART CALIBRATION`

本文将有限 counterfactual-completion no-go 与既有数学进行校准。Enterprise Math 不主张发明 contingent plans、auxiliary-randomness functional representation、convex mixing 或 deterministic latent completion。

## 1. 完整 contingent plans 与 extensive-form strategy representation

Kuhn 的 extensive-game 框架是 complete contingent strategies 以及在相应博弈论假设下 pure/mixed/behavior strategy representations 关系的经典 prior-art 参考。 [SRC-KUHN-EXTENSIVE-GAMES-1953]

R004 使用的是不同的 project-native 对象——面向 relation/support 与 rational-kernel processes 的有限 action-indexed counterfactual master tree——但“在 realized path 尚未确定之前就选定完整 contingent response plan”这一一般思想不属于新颖性主张。

Enterprise Math 的主张更窄：在声明的有限 relation/support 构造中，deterministic-master outcomes 的并集与 raw A4 relation-word support 精确相等；在声明的 total-rational 构造中，一个 ex-ante master measure 精确复现全部有限时域 word laws 以及 deterministic adaptive visible-history laws。

## 2. Auxiliary randomness 的 functional representation

概率论与信息论中的 functional-representation results 广泛研究了如何用 deterministic function + auxiliary randomness 表示随机输出。Li 与 El Gamal 的 strong functional representation lemma 是一个现代校准点。 [SRC-LI-ELGAMAL-SFRL-2017]

R004 的 total-rational master compiler 被视为其有限 state/action 声明环境中的初等 finite recursive/product-coupling specialization，而不是新的通用 functional-representation theorem。

## 3. 哪些内容是 project-local

项目本地贡献是把这些标准思路精确接入 Enterprise Math 已有边界：

- FQ-004：exact state、present observation 与 declared-future-safe equality 继续保持区分；
- FQ-006：partial-operation legality/disabledness 继续显式保留；
- A4：multivalued relation/support 继续保持 relation-valued，而不是静默替换成函数；
- FQ-007：只问这些有限 operational structures 本身是否足以识别 ontic online generation。

经过验证的 no-go 答案是：只要相应 hidden counterfactual completion 仍然 admissible，它们本身就不够。

## 4. 哪些内容没有被导入为公理

Bell-locality、measurement independence、Bell/CHSH inequalities、common-cause factorization、bounded latent capacity 以及其他 substantive causal/physical restrictions，不会仅因为它们可能阻碍某些 hidden completions 就被自动采用。

这些内容可以作为 prior-art examples 或 application-specific admissibility laws，但选择哪一种必须获得有限 completion theorem 之外的独立正当性。

## 5. Novelty 边界

不对下列一般数学内容主张新颖性：

- complete contingent plans；
- mixed/behavior strategy representation；
- random-seed 或 auxiliary-randomness determinization；
- finite product couplings；
- deterministic response tables 的 convex mixtures；
- 作为数学表示技术的一般 hidden-variable completion。

可发布的 Enterprise Math 内容，是有限 project-native T01–T03 构造、其 exact-arithmetic executable cross-checks，以及经过严格限制的 Foundation 结论：在声明有限时域语言中，只要 unrestricted admissible latent completion 仍然存在，generative identifiability 就不能由纯 finite operational syntax 得到。
