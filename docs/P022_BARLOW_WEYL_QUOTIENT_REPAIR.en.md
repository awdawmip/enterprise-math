## 1. The hidden symmetry behind coordination history

Let the two labelled signed prefix drifts at time `t` be

\[
(x_t,y_t)\in\mathbb Z^2.
\]

The coordination-history observation retains only

\[
\boxed{
q(x_t,y_t)
=\operatorname{sort}(|x_t|,|y_t|)
=(a_t,b_t),
\qquad0\le a_t\le b_t.
}
\]

This is not an arbitrary compression.  Let `W` be the signed-permutation group on two coordinates, generated by

- sign flip of the first coordinate;
- sign flip of the second coordinate;
- exchange of the two coordinates.

This is the order-eight hyperoctahedral reflection group, equivalently the Weyl group of type `B_2/C_2`.

Two integer states lie in the same `W`-orbit exactly when their sorted absolute coordinate pairs agree.  Hence

\[
\boxed{
q:\mathbb Z^2\to\mathbb Z^2/W
}
\]

is represented canonically by the discrete chamber

\[
\boxed{0\le a\le b.}
\]

Therefore the P022 coordination history is exactly a **time-labelled path in a finite reflection-group orbit space**.

## 2. P022-WQ01 — chamber walls are the repair boundaries

The chamber has two wall types.

### Coordinate wall

\[
a=0.
\]

At a labelled state where one signed coordinate is zero, flipping the sign of that zero coordinate changes nothing.  The sign label is therefore invisible on the wall.

When the next microscopic step leaves zero, the two possible signs become distinct again.  One binary orientation label must be restored.

If both coordinates are zero, two independent sign reflections are simultaneously invisible and the first departure releases two bits.

This is exactly the existing zero-departure count `E`.

### Diagonal wall

\[
a=b>0.
\]

At equal absolute coordinates, exchanging the two labelled channels does not change the chamber state.

If the next coarse state becomes unequal,

\[
(a,a)\to(c,d),\qquad c<d,
\]

then the quotient no longer records which labelled side took the smaller or larger successor.  One binary side-label bit must be restored.

This is exactly the existing diagonal-split count `B`.

Thus

\[
\boxed{
E=\text{coordinate-wall symmetry releases},
\qquad
B=\text{diagonal-wall symmetry releases}.
}
\]

The two typed repair coordinates are the two reflection-wall mechanisms of the chamber quotient.

## 3. P022-WQ02 — exact path-lift multiplicity

Take a legal chamber path

\[
h=(q_1,q_2,\ldots,q_N).
\]

A **labelled lift** of `h` is a microscopic signed two-channel path

\[
((x_1,y_1),\ldots,(x_N,y_N))
\]

whose orbit representative at every time equals `q_t`.

Consider one transition from a fixed labelled lift of the previous chamber state.

- each zero coordinate of the previous chamber state creates two sign-distinct microscopic departures with the same next coarse transition;
- if the previous state is diagonal and the next chamber state is split, there are two possible assignments of the unequal successors to the labelled channels;
- away from these symmetry-breaking events, the labelled continuation is forced by the current labelled lift and the coarse transition.

Therefore every coordinate-wall release multiplies the number of path lifts by `2`, and every diagonal split multiplies it by `2`.

Induction over the time-labelled path gives

\[
\boxed{
|\operatorname{Lift}(h)|
=2^{E(h)+B(h)}.
}
\]

This is exactly the previously derived microscopic fiber formula.

So the event-driven repair theorem can be restated geometrically:

> **the repair dimension is the logarithmic binary branching count of lifting a path through the discrete reflection-group quotient.**

The finite primitive statement remains the lift cardinality `2^(E+B)`; no logarithm is required as stored state.

## 4. P022-WQ03 — repair is not terminal orbit size

A single terminal `W`-orbit has size at most eight:

\[
|W|=8.
\]

More precisely, for chamber representative `(a,b)`:

\[
|W\cdot(a,b)|
=
\begin{cases}
1,&a=b=0,\\
4,&a=0<b,\\
4,&0<a=b,\\
8,&0<a<b.
\end{cases}
\]

But the fiber of a **history** can be arbitrarily larger.

For example, the chamber path

\[
(1,1)\to(0,0)\to(1,1)\to(0,0)\to(1,1)
\]

has terminal orbit size `4`, while every departure from the origin releases two fresh sign labels.  Hence

\[
E=6,\qquad B=0,
\]

and

\[
\boxed{|\operatorname{Lift}(h)|=2^6=64.}
\]

Thus

\[
\boxed{
\text{terminal symmetry ambiguity}
\ne
\text{path-history ambiguity}.
}
\]

Repeated return to a quotient singular wall can erase an old label and allow a **new independent label** to be born when the path leaves again.

This explains why event repair accumulates with boundary encounters even though the instantaneous symmetry group is finite.
