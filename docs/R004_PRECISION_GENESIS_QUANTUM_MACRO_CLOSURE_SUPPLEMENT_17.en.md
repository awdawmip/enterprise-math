This supplement unifies both obligations into one typed adequacy clutter.

## 1. Semantic reconstruction closure

Fix the full compiled carrier

`Q* = Compile_G(P0)`.

For retained generators `S subseteq G`, let

`Rec_Q*(S)`

denote the declared quotient-level reconstruction closure generated by the descended retained generators on `Q*`.

The reconstruction algebra depends on the typed semantics:

- total operations: term / transformation-monoid closure;
- semiring-valued relations: semiring polynomial closure under declared finite addition/composition;
- semantic factor maps: derived weaker channels may be reconstructed by the declared homomorphism;
- richer A3/A4 witnesses: only the reconstruction interfaces explicitly justified by those owners may be used.

No generic semantic closure is inferred from carrier equality alone.

Let `Req` be the set/family of descended future objects that the task explicitly requires to remain available.

Define semantic adequacy by

`Psi_sem(S)=1 iff Req subseteq Rec_Q*(S)`.

This predicate is monotone under retained-generator inclusion.

## 2. Carrier and semantic adequacy are distinct

Carrier adequacy remains

`Psi_car(S)=1 iff Compile_S(P0)=Q*`.

Supplement 15's discrete-observation swap example proves the two predicates need not coincide: if `P0=Q*` is already discrete, a nontrivial swap operation may be carrier-redundant but semantically required and unreconstructible from the empty instruction set.

Thus the compiler must keep two certificates:

- world-generation certificate (`Psi_car`);
- future-reconstruction certificate (`Psi_sem`).

## 3. R004-COMP-T28 — typed adequacy predicate

Define the joint adequacy predicate

`Psi(S)=Psi_car(S) AND Psi_sem(S)`.

It is monotone on `2^G`.

A retained set `S` is an **adequate primitive instruction set** exactly when `Psi(S)=1`.

This formalizes the semantic-actions versus primitive-instruction distinction:

- the full requested future language is the semantic action surface;
- `S` is a primitive instruction set if its generated quotient algebra reconstructs that action surface while also generating the same safe carrier.

## 4. R004-COMP-T29 — semantic cuts

Define the minimal semantic deletion cuts

`C_sem = Min_subseteq {H subseteq G : Psi_sem(G\H)=0}`.

Each semantic cut has a finite failure certificate: at `G\H`, at least one required descended object `r in Req` is absent from `Rec_Q*(G\H)`, while restoring any deleted generator from a minimal cut restores full semantic adequacy.

Unlike carrier cuts, semantic cuts need not correspond to a coarser state partition. The carrier may remain exactly `Q*` while a requested operation/relation table becomes unreconstructible.

## 5. R004-COMP-T30 — joint cut decomposition

Let `C_car` be the minimal carrier-cut clutter from Supplement 16.

Because joint failure is the disjunction

`NOT Psi = (NOT Psi_car) OR (NOT Psi_sem)`,

and both failure families are upward-closed under deletion, the minimal joint deletion cuts satisfy

`C_joint = Min_subseteq ( C_car union C_sem )`.

So the two failure families combine without inventing a third obstruction type. Dominated cuts disappear automatically.

A joint cut certificate is typed:

- carrier cut -> canonical forbidden-world partition `P_H` with exact kill set `H`;
- semantic cut -> explicit required descended object missing from the retained quotient algebra;
- if one deletion set causes both failures, either certificate may witness inadequacy, while minimal-union reduction keeps only inclusion-minimal cut edges.

## 6. R004-COMP-T31 — primitive instruction sets are transversals

A retained set `S` is jointly adequate iff it intersects every edge of `C_joint`.

Therefore

`B_primitive = Tr(C_joint)`

for inclusion-minimal adequate primitive instruction sets.

Standard blocker duality again gives

`C_joint = Tr(B_primitive)`

when both sides are reduced to inclusion-minimal clutters.

This is hypergraph duality prior art. R004's contribution is the typed decomposition of the compiler's adequacy predicate into carrier and semantic failure certificates.

## 7. Concrete three-operation example

Take exact states `{0,1,2}` and initial observation

`P0={{0,2},{1}}`.

Use unary operations

`g0=(0,0,0)`,

`g1=(0,0,1)`,

`g2=(0,0,2)`.

The full language compiles to the discrete carrier `Q*`.

Carrier cuts:

`C_car={{g1}}`.

So the unique minimal Carrier Basis is `{g1}`.

But on the final discrete quotient, require all three descended operation tables to be reconstructible under composition with free identity. `g0` is generated by `g1^2`, but `g2` is not generated by `g1` alone. Semantic cuts are

`C_sem={{g1},{g2}}`.

Hence

`C_joint={{g1},{g2}}`,

and the unique minimal adequate primitive instruction set is

`{g1,g2}`.

This exact example separates "what generates the world" from "what is needed to reproduce the requested future algebra".

## 8. Reconstruction pruning before obstruction dualization

Supplement 15 proved that a quotient-level reconstruction certificate compatible with further coarsening implies carrier redundancy. The new cut formulation explains how to use that result algorithmically:

1. compute `Q*`;
2. perform sound algebraic reconstruction pruning on `Q*` (operation terms, semiring relation polynomials, semantic factor maps, or owner-certified richer reconstruction);
3. build `C_car` on the remaining candidate generators;
4. build `C_sem` for the explicit requested action surface;
5. reduce `C_joint=Min(C_car union C_sem)`;
6. enumerate/solve minimal transversals only on this reduced generator clutter.

This can drastically reduce the generator universe before the combinatorial dualization step.

## 9. Exact validation

For all triples of distinct 3-state total unary operations and every initial partition, **14,625** full instances were checked.
