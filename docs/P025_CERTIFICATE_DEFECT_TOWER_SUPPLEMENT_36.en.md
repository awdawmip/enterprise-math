## 1. From an index profile to an exact finite target-membership state

Let

\[
C=H(\Lambda)
\]

be the complete labelled certificate image and

\[
C_R=H(\Gamma_R)
\]

the subgroup generated by relation-compatible states accessible through radius `R`.

Assume `C_R` has reached the full rational certificate rank. Then `C_R` and `C` have the same rational span, so

\[
\operatorname{Sat}(C_R)=\operatorname{Sat}(C).
\]

Define the finite radius-dependent obstruction group

\[
\boxed{
\mathcal D_R
=
\operatorname{Sat}(C)/C_R.
}
\]

The terminal intrinsic group from Stage 35 is

\[
\boxed{
\mathcal D_\infty
=
\operatorname{Sat}(C)/C.
}
\]

## 2. P025-T96 — exact certificate-target membership through a finite quotient

Let

\[

\[

No enumeration of the full certificate lattice is required once the quotient is known.

## 3. P025-T97 — natural quotient tower under increasing radius

Because

\[
C_R\subseteq C_{R+1}\subseteq C,
\]

there are natural surjections

\[
\boxed{
\mathcal D_R
\twoheadrightarrow
\mathcal D_{R+1}
\twoheadrightarrow
\mathcal D_\infty.
}
\]

Their kernels are

\[
\ker(\mathcal D_R\to\mathcal D_{R+1})
\cong
C_{R+1}/C_R,
\]

and

\[
\boxed{
\ker(\mathcal D_R\to\mathcal D_\infty)
\cong
C/C_R.
}
\]

Therefore the Stage-34 access defect is exactly the kernel size

\[
\boxed{
J_H(R)
=
|C/C_R|.
}
\]

Certificate completeness means the map to the terminal intrinsic quotient has become an isomorphism:

\[
\boxed{
C_R=C
\iff
\mathcal D_R\cong\mathcal D_\infty
\text{ through the natural quotient map}.
}
\]

It does **not** require `D_R` to become the zero group.

This is a structural boundary absent from a scalar index-only description.

## 5. Exact arithmetic nonsplit example: `4+11=15`

Consider

\[
4+11=15.
\]

For the normalized Wronskian certificate, the complete image is

\[
\boxed{C=2\mathbb Z.}
\]

Thus the intrinsic terminal defect is

\[
\boxed{
\mathcal D_\infty
=\mathbb Z/2\mathbb Z.
}
\]

At radius one, the reachable normalized Wronskian values generate

\[
\boxed{C_1=4\mathbb Z.}
\]

Hence

\[
J(1)=[2\mathbb Z:4\mathbb Z]=2
\]

and

\[
\boxed{
\mathcal D_1
=\mathbb Z/4\mathbb Z.
}
\]

The exact sequence is

\[
\boxed{
0
\to
\mathbb Z/2
\to
\mathbb Z/4
\to
\mathbb Z/2
\to
0.
}
\]

This extension is not

\[
\mathbb Z/2\oplus\mathbb Z/2.
\]

So access defect and intrinsic defect each have order two, but the total certificate obstruction is cyclic of order four.

At radius two,

\[
C_2=2\mathbb Z=C,
\]

so the access kernel disappears and

\[
\boxed{
\mathcal D_2
=\mathcal D_\infty
=\mathbb Z/2.
}
\]

This gives an actual arithmetic witness to the nonsplitting boundary.
