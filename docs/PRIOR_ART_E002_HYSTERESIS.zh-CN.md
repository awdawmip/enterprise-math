# E002 前人工作边界：迟滞、量化与开关控制

## 1. 范围

本文记录 E002 当前使用的最接近控制工程前人工作。它并不试图给出迟滞或继电器控制的完整历史，而是防止进取数论仅仅因为用有限精度语言重新表述某个机制，就把已经成熟的控制方法误当成自己的发明。

E002 整体解释的历史新颖性目前仍为 `NOVELTY_UNVERIFIED`。

## 2. 迟滞量化器与抖振

Ceragioli、De Persis 与 Frasca 研究了量化平均一致性中的不连续性与迟滞，并明确引入迟滞量化器来应对不希望发生的抖振 [SRC-CERAGIOLI-DEPERSIS-FRASCA-2011-HYSTERESIS]。

因此，E002 不声称“给量化阈值规则增加记忆以压制反复切换”这一做法是新的。

E002 的差别只可能存在于语义和结构上：它询问坍缩目标区域的宽度是否已经由被表示状态的精度给出，并进一步把观测规则与状态保持响应分开。这个解释是否具有额外工程价值，仍必须相对于成熟的迟滞量化器方案继续证明。

## 3. 带迟滞的量化控制

De Persis 与 Mazenc 研究带时延的量化非线性控制，并在量化控制机制中加入迟滞以防止抖振 [SRC-DEPERSIS-MAZENC-2010-QUANTIZED-HYSTERESIS]。

这与 E002 非常接近，因为两条路线都同时出现了有限量化与迟滞行为。因此，E002 不能把“量化加迟滞”这个组合本身包装成新发现。

进取数论更窄的问题是：精度是否被当成显式有限状态坐标，而不仅仅是控制器的近似或调参工具；以及当这个精度状态丢弃信息以后，能否对未来充分性义务给出精确有限推导。

## 4. 迟滞开关控制与极限环

Kasis、Monshizadeh 与 Lestas 研究电网一次调频中的开关负载，明确区分抖振和其他动力学行为，并说明迟滞策略可以避免抖振，但系统仍可能保留极限环行为 [SRC-KASIS-MONSHIZADEH-LESTAS-2021-ONOFF]。

这对 E002-T09 尤其重要。E002 证明的是自己这个有限确定性恒温器映射最终必然周期化，并不声称一般性地首次发现了迟滞开关系统可能振荡。

该工作同时提供了一条重要概念警戒线：抑制抖振并不是收敛定理。

## 5. 进取数论的边界

目前能够稳妥主张的 E002 内容，不是继电器规律本身，而是把下面这组结构放到已有迟滞工程面前做压力测试：

```text
内在被表示精度
+ 目标中心坍缩
+ 状态保持响应
+ 精确整数噪声/切换证书
+ 任务相关未来充分性修复
```

如果精度参数只是在事后重新调出来，以复制一个传统死区，却没有任何独立成立的分辨率含义，那么这条路线应当被视为没有产生新的解释价值。只有当同一个有限精度坐标还被传感、表示、执行或世界引擎的其他独立部分共同要求时，它才更值得继续研究。

在完成专门的历史优先权检索之前，不提出任何“首次”主张。
