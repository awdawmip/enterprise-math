## 1. Compact endpoint response state

Stage 104 shows that the finite endpoint-area future can be generated by

\[
\boxed{
\Gamma=(A;L_1,\ldots,L_a;Q_1,\ldots,Q_b)
}
\]

together with the static labelled merged-threshold order.

Here:

- `A` is the current activation area;
- `L_i` is the old-block span of candidate threshold `U_i`;
- `Q_j` is the merged old+candidate threshold rank of future node `v_j`.

Stage 105 turns both the response state and the action words themselves into endpoint normal forms.

## 2. P025-T239 — endpoint action-word normal form

A valid action word may:

- insert each candidate threshold `U_i` at most once;
- append the predeclared future nodes in their fixed order.

For endpoint semantics, the word matters only through

\[
\boxed{(I,t),}
\]

where:

- `I subset {1,...,a}` is the final set of inserted candidate thresholds;
- `0<=t<=b` is the number of appended future nodes.

All threshold insertion orders and all interleavings with the `t` node appends give the same final threshold set and the same future-node prefix, hence the same endpoint activation matrix and area.

Thus every valid action word collapses to one endpoint normal form `(I,t)`.

## 3. P025-T240 — exact endpoint class count

There are

\[
2^a
\]

candidate-threshold subsets and

\[
b+1
\]

possible future-prefix lengths. Therefore the number of endpoint classes is exactly

\[
\boxed{2^a(b+1).}
\]

This is generally far smaller than the number of raw valid interleavings.

For a fixed endpoint with `k=|I|` selected distinct thresholds and `t` node appends, the number of valid words collapsing to that endpoint is

\[
\boxed{
\frac{(k+t)!}{t!}.
}
\]

The `k` threshold actions are distinct, while the relative order of the `t` sequential node actions is fixed.

## 4. P025-T241 — `Gamma` is complete for the endpoint-area future

For any endpoint normal form `(I,t)`, Stage104 evaluates the exact final area from `Gamma`.

Conversely, the full endpoint-area response family recovers the generator coordinates.

For each candidate threshold,

\[
L_i=A(\{i\},0)-A.
\]

For each future node increment, first recover the old-threshold contribution using the empty candidate set. Then compare the same increment with each singleton candidate set to recover which candidate thresholds are crossed. Their total plus the old-threshold increment gives the merged rank `Q_j`.

Therefore

\[
\boxed{
\Gamma
\Longleftrightarrow
\text{all endpoint-area responses in the declared envelope}.
}
\]

So `(A;L_i;Q_j)` is an exact compact response normal form for this future language.

## 5. Negative boundary — endpoint semantics is not trace semantics

The endpoint collapse must not be overextended.

Consider current threshold

\[
T=\frac14,
\]

current node value

\[
\rho_0=\frac12,
\]

candidate threshold

\[
U=\frac34,
\]

and future node

\[
v_1=1.
\]

Then:

- `+T ; +J` has area trace
  \[
  \boxed{(1,3)};
  \]
- `+J ; +T` has area trace
  \[
  \boxed{(2,3)}.
  \]

Both words have the same endpoint normal form and the same final area `3`, but different intermediate responses.

Hence

\[
\boxed{
\text{endpoint commutation}
\not\Rightarrow
\text{trace commutation}.
}
\]

## 6. P025-CE40 — exact arithmetic trace boundary

The same phenomenon occurs inside the P025 dyadic pressure model.

Take `(q,p)=(3,41)` at exponent `2`, with

\[
\rho_0=\frac1{22},
\qquad
\rho_1=\frac{13}{22},
\]

old threshold

\[
T=\frac1{25},
\]

and candidate threshold

\[
U=\frac{11}{20}.
\]

Then:

\[
+T;+J:\quad \boxed{(1,3)},
\]

while

\[
+J;+T:\quad \boxed{(2,3)}.
\]

The final endpoint is identical, but the first observation differs.

So the negative boundary is not a synthetic Boolean artifact.

## 7. Future-language split

Stage105 therefore separates two action languages:

### Endpoint language

Future query:

> what is the final area after this finite action word?

Then `(I,t)` is the word normal form and `Gamma` is a complete response state.

### Trace language

Future query:

> what area is observed after every action prefix?

Then the endpoint normal form is insufficient; action order survives because intermediate observations are part of the declared future.

The correct quotient is therefore language-relative even when the underlying final state is the same.

## 8. Architectural meaning

Stage105 converts a long action history into two distinct objects:

1. an **endpoint word quotient** `(I,t)`;
2. an **endpoint response quotient** `Gamma`.

Neither should be silently reused for trace-sensitive tasks.

This supplies an exact pressure test for any architecture that proposes to collapse operation words: the observable must specify whether only endpoints or full intermediate traces are future-relevant.
