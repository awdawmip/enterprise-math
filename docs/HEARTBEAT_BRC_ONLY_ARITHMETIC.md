## 执行规则

1. 本研究线涉及科学运算时，必须实际走有来源、类型和观察范围的 BRC 接口。不再仅将 BRC 当作优先考虑项；在本范围内，旧的“BRC 不适用时直接换用其他数值方法”不再授权回退。
2. 不展开 π 的代数或数值运算，不以经典 π、三角函数及其常规展开生成原生输入、状态更新或残差。不以矩阵指数、普通 Taylor／Padé／Cayley 或提高精度绕过这条要求。历史表达式可以作为待审来源保留，本次没有计算它们。
3. “全部使用整数／分数”“精度很高”“类名里有 BRC”均不构成 BRC 使用证明。每次实际调用保留准确源码版本、入口、输入载体、支路身份、相位／符号、观察与未来操作范围、输出和残差证书。已有 BRC 内部合法的整数／分数实现并未被禁止；禁止的是拿普通算术冒充其语义。
4. 正权 BRC 的数量与质量不能代替复振幅或有符号抵消。所需相位接口未确认时，保留原始状态及符号关系，先定位或补齐适当的 BRC 扩展；不取绝对值，不改名回退，不预设该扩展已经存在。
5. 区分：原生模型结构残差；BRC 表示／求解／截断缺陷；原生与经典表示之间的映射缺陷；经典计算舍入。来源未分离则记为 UNKNOWN，不宣布为真实残差，也不宣布为纯噪声。BRC 计算通过本身也不自动等于物理机制成立。
6. 旧结果和原始证据不删除。经典模型内部的确切恒等式或区间证书可以保留原有模型内强度；但没有原生到 BRC 对应证明的数值不再用于确认原生残差、瞬传、宏观尺度或 Shor 增益。它们标为 NATIVE_ATTRIBUTION_PENDING_BRC_REVALIDATION，而不是统称错误。
7. 本次仅做源码静态检查、文件与结构验证，没有重新执行物理模型、π／三角运算或普通高精度参考。该约束已记录不等于全仓库所有执行器已有自动拦截。
