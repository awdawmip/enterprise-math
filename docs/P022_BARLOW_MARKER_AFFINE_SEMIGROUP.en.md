# P022 — Exact Positive-Depth Cancellation Classification for Half-Defect Markers

Status: `ACTIVE RESEARCH NOTE / EXACT COEFFICIENT-GEOMETRY CLASSIFICATION`  
Owner: `program/p022-geometry-v2`  
Depends on: sparse zero-boundary flux, crossing lattice  
Prior-art boundary: additive/numerical-semigroup and Bezout arguments are classical; P022 owns only the Franel/prime-halving specialization.

## 1. Problem

The exact marker is

\[
\kappa_p=z_m+\sum_i z_i c_i,
\]

where

\[
z_m=v_p(F_m)>0,
\qquad
z_i=v_p(F_{j_i})\in\mathbf N_{>0},
\]

and the `c_i` are the nonzero signed zero-boundary crossing coefficients.

Ask the deliberately weaker quotient-state question:

> from `z_m`, the crossing coefficients, and only the fact `z_i>=1`, is exact cancellation even possible for some positive depth vector?

This is weaker than evaluating the actual Franel depths, but stronger than the gcd-only crossing lattice.

## 2. P022-LI41 — no crossings or all-positive crossings are automatically safe

If there are no nonzero crossings, then

\[
\kappa_p=z_m>0.
\]

If

\[
c_i>0
\]

for every nonzero crossing, then

\[
\kappa_p=z_m+\sum_i z_i c_i>0.
\]

So cancellation is impossible in both cases.

## 3. P022-LI42 — all-negative crossings are an exact numerical-semigroup problem

Suppose

\[
c_i=-a_i,
\qquad a_i>0.
\]

Write

\[
z_i=1+n_i,
\qquad n_i\in\mathbf N_0,
\]

and let

\[
A_0=\sum_i a_i.
\]

Then

\[
\boxed{
\kappa_p
=z_m-A_0-\sum_i n_i a_i.
}
\]

Thus some positive depth vector can cancel the midpoint **if and only if**

\[
\boxed{
z_m-A_0\in\langle a_1,\ldots,a_r\rangle,}
\]

where the right side is the additive numerical semigroup generated by the crossing magnitudes.

Immediate consequences:

- `A_0>z_m` -> cancellation impossible;
- `A_0=z_m` -> the minimum-depth assignment already permits cancellation;
- `A_0<z_m` -> the residual must lie in the numerical semigroup.

## 4. P022-LI43 — mixed signs collapse exactly back to the gcd lattice

Now suppose at least one `c_i>0` and at least one `c_j<0`. Put

\[
g=\gcd(|c_1|,\ldots,|c_r|).
\]

After writing `z_i=1+n_i`, the variable part of the correction is generated with nonnegative multiplicities by the same signed integers `c_i`.

A finitely generated additive monoid containing both positive and negative integers is the full subgroup

\[
\boxed{g\mathbf Z.}
\]

Reason: Bezout gives an integer representation of every multiple of `g`. If some coefficient multiplicity is negative, pair that generator with a generator of the opposite sign and add a zero-sum relation. Repeating this raises every multiplicity to a nonnegative value without changing the represented integer.

The fixed base correction

\[
\sum_i c_i
\]

is itself divisible by `g`. Therefore the set of all corrections realizable by **some positive depth vector** is exactly

\[
\boxed{g\mathbf Z.}
\]

Hence

\[
\boxed{
\exists(z_i\ge1):\ \kappa_p=0
\iff
g\mid z_m.
}
\]

So for mixed signs, positivity adds no protection beyond the crossing-lattice congruence. This is an exact statement, not a heuristic.

## 5. Complete coefficient-only classification

The possibility of cancellation from coefficient geometry and positive-depth information alone is therefore:

| crossing class | cancellation possible for some positive depths? |
|---|---|
| none | never |
| all positive | never |
| all negative `c_i=-a_i` | iff `z_m-sum a_i` lies in `<a_i>` |
| mixed signs | iff `gcd(|c_i|)` divides `z_m` |

This table is complete at the declared information level. If it says “possible”, the actual Franel depths may still fail to realize the required combination; more precision is then needed.

## 6. Exact examples

### `p=369581`

The only crossing coefficient is

\[
c_8=-2,
\]

while

\[
z_m=1.
\]

Thus `A_0=2>1`, so cancellation is impossible for **any** positive value of the earlier depth. The exact marker is separately `-1`.

### `p=157`

The broad forced-midpoint control has

\[
c_{16}=-1,
\qquad z_m=1.
\]

Thus `A_0=z_m=1`; cancellation is permitted at minimum depth, and the exact Franel depths do realize it:

\[
v_{157}(D_{78})=0.
\]

### `p=518220701`

The transfer-boundary scan proves that the only earlier crossing zero is `j=50` with

\[
c_{50}=+1.
\]

Therefore the marker is positive for every possible midpoint depth:

\[
\kappa_p=z_m+z_{50}>0,
\]

even though the crossing-lattice modulus is `g=1`.

## 7. Precision interpretation

For the future Boolean query

`is kappa_p nonzero?`,

the full p-adic depth vector is required only after the complete coefficient-geometry test becomes inconclusive.

The resulting legal compression hierarchy is:

1. coefficient sign class;
2. for all-negative crossings: `(z_m, {a_i})` through numerical-semigroup membership;
3. for mixed crossings: only `(z_m mod g)` survives at this information level;
4. actual signed p-adic depths are retained only when the coefficient quotient admits cancellation.

This is a precise P022 instance of task-relative precision: the correct retained state depends on the declared future query, not on one universal notion of “more detail”.
