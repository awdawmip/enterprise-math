## 1. The crossing lattice discards positivity

The exact marker is

\[
\kappa_p=z_m+\sum_i z_i c_i,
\]

where

\[
z_m=v_p(F_m)>0,
\qquad
z_i=v_p(F_{j_i})\in\mathbf N_{>0},
\]

and every `c_i` is a nonzero signed zero-boundary crossing coefficient.

The gcd certificate uses only

\[
\sum_i z_i c_i\in g_p\mathbf Z.
\]

But the coefficients `z_i` are not arbitrary integers: every one is **positive**. This creates an affine-semigroup restriction.

## 2. P022-LI41 — positive crossing coefficients can never cancel the midpoint

If

\[
c_i>0
\]

for every nonzero crossing, then

\[
\kappa_p
=
z_m+\sum_i z_i c_i
>0.
\]

So a same-sign positive crossing family is automatically safe.

## 3. P022-LI42 — all-negative crossings reduce exactly to a numerical semigroup

Suppose

\[
c_i=-a_i,
\qquad a_i>0.
\]

Since every earlier zero depth is at least one, write

\[
z_i=1+n_i,
\qquad n_i\in\mathbf N_0.
\]

Let

\[
A_0=\sum_i a_i.
\]

Then

\[
\boxed{
\kappa_p
=z_m-A_0-\sum_i n_i a_i.
}
\]

Therefore there exist positive earlier depths capable of making the marker vanish **if and only if**

\[
\boxed{
z_m-A_0\in\langle a_1,\ldots,a_r\rangle,}
\]

where the right side is the additive numerical semigroup generated by the crossing magnitudes.

In particular:

- if `A_0>z_m`, cancellation is impossible immediately;
- if `A_0=z_m`, the minimum-depth assignment `z_i=1` already reaches the cancellation level;
- if `A_0<z_m`, the residual depth must be representable by the crossing magnitudes.

This is strictly stronger than the gcd test in many small-depth cases.

## 4. `p=369581`: nonzero without computing the correction

The explicit target-family counterexample has one crossing coefficient

\[
c_8=-2,
\]

and midpoint depth

\[
z_m=1.
\]

Thus

\[
A_0=2>1=z_m.
\]

Consequently no positive value of the earlier depth `z_8` can make the marker zero:

\[
\boxed{\kappa_p\ne0.}
\]

This conclusion precedes the exact evaluation `kappa_p=-1` and uses less state than the full p-adic depth vector.

## 5. `p=157`: the dangerous boundary is exact

For the broad forced-midpoint control prime

\[
p=157,
\]

the only crossing coefficient is

\[
c_{16}=-1
\]

and

\[
z_m=1.
\]

Hence

\[
A_0=z_m=1.
\]

The residual is zero, which always belongs to the numerical semigroup. Positivity data therefore permits cancellation. The exact Franel depths are both one, and the marker really does vanish:

\[
\boxed{v_{157}(D_{78})=0.}
\]

Thus the affine-semigroup certificate is sharp on this control pair.

## 6. Mixed-sign boundary

If both positive and negative crossing coefficients occur, positivity alone yields a signed affine-semigroup problem rather than an ordinary numerical semigroup. This note does not replace that richer state by a false one-dimensional test.

The hierarchy is now:

1. no crossings -> exact nonzero marker;
2. gcd/crossing lattice mismatch -> nonzero marker;
3. same-sign positive crossings -> nonzero marker;
4. same-sign negative crossings -> exact numerical-semigroup cancellation test using only coefficient magnitudes and midpoint depth;
5. mixed signs or an inconclusive one-sign semigroup test -> retain richer signed depth information.

## 7. Precision interpretation

For the future language consisting only of the Boolean query

`is kappa_p nonzero?`,

the full vector of earlier p-adic depths is often unnecessary. Depending on the coefficient geometry, progressively smaller states suffice:

- no-crossing flag;
- `(z_m,g_p)`;
- sign class plus `(z_m,A_0,{a_i})`;
- full signed zero-depth vector only when the compressed certificates are inconclusive.

This is another exact P022 example of task-relative precision: a stronger state is retained only when the declared future query cannot factor through the smaller one.
