## 2. P2-R17 — Exact super-root modular-arc threshold

Let `q_0` be the largest odd integer satisfying

\[
mq_0\le K^2.
\]

The value `q_0` is allowed to be `-1` when `m>K^2`. Define the lower-bound residue

\[
\boxed{R_m(K)=K^2-mq_0.}
\]

Then

\[
0\le R_m(K)<2m,
\]

and, because `q_0` is odd,

\[
\boxed{
R_m(K)=(K^2+m)\bmod 2m,
}
\]

where the right side is the least residue in `[0,2m)`.

### Theorem

For every `K<m<=U`,

\[
\boxed{
O_m(K)
=
\mathbf 1_{\{R_m(K)\ge2(m-K)\}}.
}
\]

Equivalently,

\[
\boxed{
O_m(K)
=
\mathbf 1_{\left\{
\left\{\frac{K^2+m}{2m}\right\}
\ge1-\frac Km
\right\}}.
}
\]

### Proof

The first odd quotient above the lower endpoint is `q_0+2`. It is positive because `K^2/m>=0` implies `q_0>=-1`. Therefore

\[
O_m(K)=1
\iff
m(q_0+2)\le U.
\]

Using `mq_0=K^2-R_m` gives

\[
m(q_0+2)-U
=
K^2-R_m+2m-(K^2+2K)
=
2(m-K)-R_m.
\]

Thus the upper-end condition is exactly `R_m>=2(m-K)`. Dividing by `2m` gives the fractional-part form. ∎

### Exact centered discrepancy

Let

\[
\psi(x)=\{x\}-\frac12.
\]

Then the convention at integer points gives the exact identity

\[
\boxed{
O_m(K)-\frac Km
=
\psi\!\left(\frac{K^2+m}{2m}\right)
-
\psi\!\left(\frac{K^2+2K+m}{2m}\right).
}
\]

Thus the prior sawtooth representation is precisely the Fourier expansion of one moving arc of length `K/m` on the finite phase circle.

## 3. P2-R18 — Odd-modulus quadratic-excess law

Assume in addition that `m` is odd. Then

\[
\boxed{
R_m(K)=a^2\bmod 2m.
}
\]

Indeed,

\[
(K^2+m)-a^2
=m(2K-m+1),
\]

and the second factor is even when `m` is odd.

Therefore

\[
\boxed{
O_m(K)
=
\mathbf 1_{\{a^2\bmod2(K+a)\ge2a\}}.
}
\]

Put

\[
j(a)=\left\lfloor\frac{a^2}{2(K+a)}\right\rfloor
\]

and

\[
F_j(a)=a^2-2j(K+a).
\]

For the unique layer `j=j(a)`,

\[
0\le F_j(a)<2(K+a),
\]

and the carry vanishes exactly when

\[
\boxed{
0\le F_j(a)<2a.
}
\]

So every odd super-root miss is an integer point in a thin width-`2a` corridor immediately above the quadratic root

\[
F_j(a)=0.
\]

## 4. P2-R19 — At most one odd miss per quadratic layer

For odd `m=K+a`, the parity of `a` is fixed:

\[
a\equiv1-K\pmod2.
\]

### Theorem

For each integer `j>=0`, there is at most one positive integer `a` of this parity satisfying

\[
0\le F_j(a)<2a.
\]

### Proof

If `j=0`, the condition is `0<=a^2<2a`, hence `a=1`.

Let `j>=1` and suppose `a` satisfies the corridor. Since `F_j(a)>=0`, `a` lies at or above the positive root

\[
\alpha_j
=
j+\sqrt{j^2+2jK}.
\]

In particular `a>2j`. The next integer of the required parity is `a+2`. One has

\[
F_j(a+2)-F_j(a)
=4(a+1-j).
\]

Because `a>2j`,

\[
4(a+1-j)>2(a+2).
\]

Hence

\[
F_j(a+2)>2(a+2),
\]

and every later same-parity integer is even farther above the corridor. Thus the layer contains at most one miss. ∎

### Exact candidate scheduler

For `j>=1`, let `a_j` be the least positive integer satisfying

\[
a_j\equiv1-K\pmod2,
\qquad
 a_j\ge j+\sqrt{j^2+2jK}.
\]

Then layer `j` contributes a miss if and only if

\[
F_j(a_j)<2a_j.
\]

Thus the odd super-root zero set is generated by one parity-rounded quadratic-root candidate per layer, followed by one exact inequality check.

## 5. P2-R20 — Deterministic near-root halo

If

\[
a^2<2(K+a),
\]

then `j(a)=0` and the odd-modulus law gives

\[
O_{K+a}(K)=1
\iff
 a^2\ge2a.
\]

Therefore, throughout the explicit near-root halo

\[
\boxed{
2\le a<1+\sqrt{1+2K},
\qquad K+a\text{ odd},
}
\]

one has

\[
\boxed{O_{K+a}(K)=1.}
\]

The only possible odd-modulus miss in the `j=0` layer is `a=1`, occurring when `K+1` is odd.

This is stronger than a density statement: apart from that single parity-dependent boundary point, every odd modulus in an additive strip of width asymptotic to `sqrt(2K)` has a binary carry hit.

## 6. P2-R21 — Near-root zero count and weighted L1/L2 bounds

Let `A>=1`, and let

\[
\mathcal M_{K,A}
=
\{m:K<m\le K+A,\ m\text{ odd}\}.
\]

The function

\[
a\longmapsto\frac{a^2}{2(K+a)}
\]

is strictly increasing for `a>0`. Hence every `a<=A` has

\[
j(a)\le
J_{K,A}
:=
\left\lfloor\frac{A^2}{2(K+A)}\right\rfloor.
\]

P2-R19 therefore gives

\[
\boxed{
\#\{m\in\mathcal M_{K,A}:O_m(K)=0\}
\le1+J_{K,A}.
}
\]

Now write

\[
r_m(K)=O_m(K)-\frac Km.
\]

If `O_m=1`, then

\[
|r_m|=\frac{m-K}{m}=\frac a{K+a}\le\frac aK.
\]

If `O_m=0`, then `|r_m|=K/m<1`. Consequently, for arbitrary complex coefficients with `|b_m|<=1`,

\[
\boxed{
\left|
\sum_{m\in\mathcal M_{K,A}}b_m r_m(K)
\right|
\le
1+J_{K,A}
+rac{A(A+1)}{2K}.
}
\]

The corresponding second moment obeys

\[
\boxed{
\sum_{m\in\mathcal M_{K,A}}|r_m(K)|^2
\le
1+J_{K,A}
+rac{A(A+1)(2A+1)}{6K^2}.
}
\]

### Consequences

For `A=c\sqrt K` with fixed `c`, both bounds are `O_c(1)`. Thus the raw binary-carry discrepancy has uniformly bounded `L1` and `L2` mass in every fixed-multiple square-root halo above the root.

More generally, for `A=o(K)`,

\[
\sum_{m\in\mathcal M_{K,A}}|r_m(K)|
=O\!\left(1+\frac{A^2}{K}\right),
\]

and

\[
\sum_{m\in\mathcal M_{K,A}}|r_m(K)|^2
=O\!\left(1+\frac{A^2}{K}+\frac{A^3}{K^2}\right).
\]

These estimates are coefficient-uniform and require no exponential-sum cancellation.

## 7. Prime-lift consequence

When prime-lift factorization `m=pd` is injective and the induced coefficient sequence satisfies `|b_m|<=1`, P2-R21 applies immediately to the portion of the double remainder with

\[
K<pd\le K+A,
\qquad pd\text{ odd}.
\]

Hence an additive `O(sqrt K)` super-root layer costs only `O(1)`, not one unit per modulus. The first genuinely analytic super-root difficulty begins only after the deterministic quadratic-excess halo is exhausted.

This does not control a multiplicative power strip such as `m<=K^(1+eta)` with fixed `eta>0`; there `A` is much larger than `K`, and the layer count no longer saves a power. It does, however, remove the immediate root boundary and supplies a sharp local input for any switched/bilinear decomposition.
