# Future Semimodule Termination Boundary: Finite Presentation Is Not Finite Closure

Status: `RESEARCH BRIDGE / NONCANONICAL`

The common future recurrence

`L_(h+1)=L_h + sum_a L_h A_a`

and the exact plateau certificate

`L_(h+1)=L_h => permanent closure`

hold across several coefficient systems.  They do **not** imply that every finite state/action presentation reaches a finite semimodule plateau.

## Sharp natural-number counterexample

Take the two-state 0/1 relation with adjacency

`A=[[1,1],[0,1]]`

and constant natural path-count observation

`C=(1,1)`.

Then

`C A^h=(1,h+1)`.

The N-semimodule generated by rows through horizon h is strictly smaller than the next one for every h.  The new row still has first coordinate one; any nonnegative integer combination of earlier unit-first-coordinate rows that also has first coordinate one must select exactly one old row, so it cannot produce the new second coordinate.

Thus a finite two-state, one-action world has an infinite strict reconstructive N-semimodule chain.

## Three different finiteness questions

The same example separates three notions.

### 1. Finite world presentation

The entire future language is generated by one finite `2x2` matrix and one observation row.

### 2. Finite state-equality precision

Current count row `(1,1)` merges the two sources.  Horizon-one row `(1,2)` distinguishes them.  No later row can refine a two-state partition further.

### 3. Finite reconstructive coefficient closure

The natural semimodule nevertheless keeps receiving a new irreducible generator `(1,h+1)` at every horizon.

Therefore finite presentation and complete state identification do not imply finite positive-coefficient reconstructive closure.

## Boolean and integer coefficient comparisons

Apply the coefficient map `N -> B`, `n |-> [n>0]`.  Every count row becomes `(1,1)`, so Boolean reachable-support precision never separates the sources.

Extend scalars instead to the integer group envelope.  Rows `(1,1)` and `(1,2)` give `(0,1)` by subtraction, so the Z-row module is already all `Z^2` at horizon one and is permanently closed.

The Z-envelope preserves exact-count state equality because it is generated from the same literal count rows, but it strengthens reconstruction by permitting subtraction.  Negative intermediate coefficients are analysis coordinates, not negative physical path counts.

The same finite matrix also gives a finite recurrence presentation:

`r_(h+2)=2 r_(h+1)-r_h`.

So a finite recurrence/generator representation can coexist with an infinite N-semimodule basis requirement.

## Architecture consequence

When a coefficient system is chosen for future semantics, three questions must be answered separately:

1. Is the action/observation presentation finite?
2. Does the induced state-equality kernel stabilize?
3. Does the chosen coefficient-semimodule reconstruction state stabilize?

A proof for one does not automatically answer the others.

For current Enterprise Math coefficient specializations:

- `Z`: Noetherian module + Smith/HNF arithmetic closure;
- finite modular rings: finite-index HNF closure;
- Boolean semiring: finite join-semilattice closure;
- `N`: no generic finite semimodule plateau, even for a finite relation.

This is standard semimodule and matrix-recurrence mathematics.  The project value is preventing an invalid cross-coefficient termination inference.
