## 1. Why a fixed horizon is not enough

At a fixed total length `N`, any rule can be sequentialized by storing enough prefix history. Therefore successful recursion at one fixed `N` does not prove that one low-dimensional law generates arbitrary dimension.

Let `A` be a finite alphabet of local LEGO-slot symbols and let

\[
O:A^*\to V
\]

be a declared discrete observation on every finite word.

## 2. UR-01 — Horizon-independent future residual equivalence

For prefixes `p,q`, define

\[
\boxed{
p\equiv_\infty q
\iff
O(ps)=O(qs)\quad\text{for every finite suffix }s\in A^*.
}
\]

Thus no future slot count or suffix can ever distinguish `p` and `q` for the declared task.

## 3. UR-02 — Append operation descends automatically

If `p~q`, then for every symbol `a`,

\[
\boxed{pa\equiv_\infty qa.}
\]

Indeed, for every suffix `s`, `O((pa)s)=O(p(as))=O(q(as))=O((qa)s)`. Therefore the quotient itself carries the uniform update

\[
\boxed{[p]\xrightarrow{a}[pa].}
\]

The state transition is generated by future equivalence rather than postulated as an automaton ontology.

## 4. UR-03 — Observation descends

Taking the empty suffix shows `p~q => O(p)=O(q)`, so

\[
\bar O([p])=O(p)
\]

is well-defined. Starting at `[empty]` and appending the input word symbol by symbol reaches `[w]`, from which the exact observation `O(w)` is read.

## 5. UR-04 — Coarsest exact dimension-uniform deterministic state

Let another deterministic summary

\[
h:A^*\to S
\]

have the properties that `h(pa)` depends only on `h(p)` and the new symbol `a`, and that `O(p)` is exactly readable from `h(p)`.

If `h(p)=h(q)`, deterministic updates imply `h(ps)=h(qs)` for every suffix `s`, hence exact readability gives `O(ps)=O(qs)`. Therefore

\[
\boxed{h(p)=h(q)\Longrightarrow p\equiv_\infty q.}
\]

Every exact uniform generator must refine `A^*/equiv_infty`. Thus this quotient is the coarsest deterministic causal state for the arbitrary-dimensional task.

If the quotient is finite, a genuinely finite-type dimension-uniform generator exists. In Boolean-language special cases this is the same mathematical structure captured by classical Myhill–Nerode residual-state theory; automata terminology is a traditional shadow/tool here, not the project ontology.

## 6. Class count is representation-independent capacity

If `C` continuation classes must be represented exactly, any encoding needs at least `C` distinct code states. A single nonnegative integer register therefore needs a range reaching at least `C-1` in the most compact injective representation.

A syntactically simple update such as

`state <- 2*state + bit`

can therefore hide exponential causal memory in one integer. Register count or formula length is not a valid complexity measure by itself.

## 7. Raw residual complexity and structural complexity must be separated

Integer observations often carry already-settled bulk value. For

\[
O:A^*\to\mathbb Z,
\]

define the normalized residual

\[
\boxed{\widehat\Sigma_p(s)=O(ps)-O(p).}
\]

Prefixes are structurally equivalent when these normalized future increments agree for every suffix. Runtime state may then split as

\[
\boxed{(\text{current bulk value},\ \text{structural continuation type}).}
\]

This is exact integer factorization and directly reflects the project distinction `value != relation structure`.

## 8. Examples

### Binary sum

For `O(w)=sum_i w_i`,

\[
\widehat\Sigma_p(s)=\sum_i s_i
\]

is independent of `p`. The bulk channel is the current integer sum and the structural continuation quotient has one class.

### Finite-range local grade

If total grade is a sum of fixed `q`-slot local integer windows, accumulated grade is bulk while the future increment depends only on at most the last `q-1` raw symbols. Future equivalence may compress those suffixes further.

### Full-history integer code

If a binary word is encoded by `O(wx)=2O(w)+x`, appending a suffix multiplies the old prefix code by a power of two. Subtracting the current code does not remove history dependence, so normalized structural residuals still distinguish the prefixes. One integer register has not made the causal state small.

## 10. Complexity examples

### Parity

Binary parity has at most two continuation classes for every horizon: a global-looking rule with bounded causal memory.

### Copy constraint

For a binary word of length `2n` whose second half must equal the first half, every one of the `2^n` midpoint prefixes accepts a different unique suffix. Therefore

\[
\boxed{C_{2n,n}=2^n.}
\]

This is genuine exponential future-state capacity. One integer register can only hide it in an exponentially growing code range.

### Full word identity

If the terminal observation is the full word, no distinct histories may be safely merged; all higher P011 collision coordinates of the prefix-to-future-class collapse vanish.

## 11. Fixed local-grade impossibility boundary

For an alphabet of size `A`, a fixed `q`-window integer grade with values in `[g_min,g_max]` and width `R=g_max-g_min` has, at depth `d>=q-1`, an exact raw state description using accumulated bulk grade plus the last `q-1` symbols. Therefore its continuation state count is bounded by

\[
\boxed{
A^{q-1}\bigl((d-q+1)R+1\bigr).
}
\]

The suffix factor is constant in `d` and the bulk-grade factor is linear. A task such as the midpoint copy constraint requiring `2^d` classes therefore eventually exceeds the bound for every fixed `q,R`. Such a task cannot be swallowed by any fixed finite-range bounded-grade LEGO law; either interaction range or structural state capacity must grow with dimension.
