# 接受研究结果并保留任务未完成状态

`RESULT_ACCEPTED_TASK_OPEN_CONTINUATION` 消费一份真实的 `ACCEPTED/NONE`
科学审核，该审核针对原始 `NO_GO` 值保持不变的研究结果。它分别记录科学结论的
适用范围和尚未解决的原始过程义务，不把结果重新解释为 `PASS`，不认证原始过程，
不完成任务或关闭父目标，不出版后续任务，也不重新开放执行。

该决策要求当前任务出版版本、既有的当前 Driver／会话／DA 与精确的结果／审核权威绑定、
全部六项既有后续门，并且不得新增任务或保留 `REQUIRED` 门。首份不可变审核在写入前，
仍须预检其显式后续方案。第二份审核使既有的精确集合接入、参照核查与综合裁定流程重新开启。
综合裁定必须消费完整的当前规范集合，并固定原始记录。

实际科学 Driver 提供 `accepted_result_scope`，其内容必须是选定的已接受不可变报告中的
唯一逐字引文。`scope_evidence` 标明该不可变 `scientific_review_id`，并以精确路径、
Git 对象哈希和 SHA256 固定其报告及完整接口。由 DR 固定的完整报告必须包含一个
`ENTERPRISE_MATH_ACCEPTED_RESULT_SCOPE_BINDING_V1` HTML 注释块。其九个精确字段
绑定科学 Driver、结果／出版版本、历史定位信息、整个接口的内容固定值、精确适用范围引文的
SHA256、`FULL_DOCUMENT`，以及涵盖的 `scope`、`statement`、`hypotheses`、`unresolved` 字段。
哈希针对正文引文的精确 UTF-8 字节计算，不做规范化，也不添加换行；注释块只存哈希，
因此不会重复那段唯一引文。解析器拒绝未知或重复的 JSON 键、缺失或多个注释块，以及混用版本。

接口绑定由该不可变科学报告提供。仅凭接口 JSON 中的 `reviewer` 字符串，不能证明科学作者的
认可。接续者不能通过更新自己的规范输入或当前 Source 清单，替换接口内容或选用另一段
适用范围引文。报告没有绑定的旧 DR 不适用于这个新分支；原报告和既有路线保持不变。
不能在该旧 DR 的哈希之下追加新报告。

写入器使用既有的 `artifact_pin` 与 `verify_source_snapshot` 合同，核验当前 Source
包含相应文件，再记录实际的 `scope_source_snapshot`。Native 快照不包含 Git 历史，
因此必须使用其真实的当前受信加载器清单。单独记录的 `historical_source_commit`
只是原始出版的来源定位信息，并不表示本次运行时重新核验了历史目录树。接口必须标明科学审核者
以及精确的结果／出版版本；其适用范围、陈述、全部假设和尚未解决边界必须作为完整文档一起消费。
代码核验身份和字节，不判断定理是否成立，也不从措辞推断原始过程时序。获授权的当前接续 Driver
可以在自己的 DA／会话下固化同一份适用范围证据，并保留科学作者身份；无需复用原会话。

`result_continuation` 的精确类型化字段列于 `research_driver_followup_contract.json`。
原始过程状态保持 `UNKNOWN`，每项显式的 `ORIGINAL_PROCESS_PROVENANCE` 义务也保持
`UNKNOWN`，同时保留实际未解决事项及证据引用。产物是否存在、自报过程干净与实际读取时序，
是不同事实。不能因为时序未知就推断文件缺失。

规范任务状态是 `ACCEPTED_RESULT_TASK_INCOMPLETE`，且 `terminal=false`。
调度将其冻结为 `AWAITING_TASK_CONTROL_CONTINUATION`，并路由至当前 Driver 的控制工作。
新发出的任务全局 `CLAIM`、执行或接纳执行、基于完成状态的依赖放行，以及并行结果综合裁定，
都不能使任务变为 `READY` 或 `DONE`。明确处于活动状态的独立执行群组通道，继续沿用各自既有的
权威生命周期。父目标的活性／最终结束门仍须独立满足。未来证据需要单独的获授权控制动作；
该不可变数据包不会自动升级为任务完成。

此仓库补丁不等于服务部署。客户端发送新决策前，Native 适配器必须公布并验证其结构规范，
提供精确的已出版产物和真实的当前受信 Source 对象清单，保留当前 DA／会话／贡献检查与
Source CAS，并在所有运行时投影中呈现新的非终局状态。若适配器属于另一仓库或发布版本，
便构成部署依赖。在该发布得到核验之前，现有 Native 客户端必须继续使用已公布的枚举值。
