# 前人工作附录 —— P020 良基稳定化

状态：`CANONICAL PRIOR-ART APPENDIX`  
更新日期：2026-08-09

## 1. 良基归纳与递归

P020 直接复用 mathlib 中关于良基关系和 `WellFoundedLT` 归纳的形式化基础设施，固定版本来源为 `Mathlib.Order.WellFounded`。[SRC-MATHLIB-WELLFOUNDED]

**前人贡献。** 良基归纳/递归属于成熟数学，所引 mathlib 模块提供了相关形式化基础设施。

**进取数论的使用。** P020 把这些成熟工具应用到单调、向下收缩的状态自映射，证明普通有限迭代会到达初态下方的最大不动点。

**不主张内容。** 进取数论不把良基归纳、良基递归或其底层序论主张为项目发明。

## 2. 有限函数迭代

P020 使用 mathlib 的 `Nat.iterate` / `f^[n]` 作为普通重复函数作用的形式化表达。[SRC-MATHLIB-FUNCTION-ITERATE]

**前人贡献。** 函数有限迭代及其基本代数是成熟数学；所引 mathlib 模块提供正式 API。

**进取数论的使用。** P020 的存在定理显式证明：存在某个有限自然数 `n`，使 `F^[n] x` 已经是初态 `x` 下方最大的原始不动点。因此“有限稳定化”本身是定理内容，不只是实现层比喻。

**不主张内容。** 函数迭代记号与基本规律不是进取数论的发明。

## 3. 与 P008 序伴随基础的关系

P020 还把稳定化算子与 P008 已经归还前人信用的 Galois/interior 框架连接起来。[SRC-MATHLIB-GALOIS-CONNECTION]

P020 证明稳定化后的映射单调、向下、幂等，并且与原单调向下映射具有完全相同的不动点。这给出了连接 P008 interior/coreflection 视角的精确桥梁，但并不把成熟的内算子理论重新包装成项目创新。

## 4. 创新边界

当前构件 `EM-COMP-016` 分类为 `PROJECT_SYNTHESIS`。

本阶段允许主张的项目贡献仅是以下结构的明确组合：

- 良基有限下降；
- 普通有限函数迭代；
- 选择初态下方最大不动点；
- 把单调向下映射完成为幂等稳定化算子；
- 与进取数论既有 P008/P019 语义的连接。

这一精确组合的历史创新性尚未经过专门优先性审查，因此不作“首次”“前所未有”等优先权主张。
