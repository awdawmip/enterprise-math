# 新成果进入研究记忆的简短工作流

日期：2026-11-21。适用：TASK、Driver、冻结后 FREE B 及知情工程检查。此文是可选使用说明；当前对话能调用的能力以实际工具目录和运行回执为准。

## 保存了什么

| 载体 | 记录的事实 |
| --- | --- |
| Enterprise Math Source | 科学正文、推导、程序或证据已保存到指定不可变提交和路径，内容能够读回。 |
| Nollm 工作记忆 | Host 形成的理解已保存，含原命题的条件、科学状态和固定来源，可被后续对话读取。 |
| Activity／长期知识 | 相应过程或跨项目知识已按各自规则关联、同步。 |
| Result／Review／Foundation | 相应正式接纳或审查程序达到自己的实际状态。 |

各项独立报告。记忆尚未提炼不改变 Source 已保存的事实；工作记忆可保留有明确状态的作者证明、计算证据、猜想和反例。保存理解不授予新的科研身份或正式接纳。

## 取得已有理解

- 已知笔记 ID：`em_memory_show(note_id)`。
- 已知字面术语：`em_memory_find(term)`，这是辅助字面扫描。
- 探索原生关系场：从 `em_memory_walk({})` 开始，按所见候选继续，始终传完整 `choices`；`has_more=true` 时追加字符串 `"next"` 翻页。最终选择一个物理入口。
- 需要核对结论或应用前提：`em_memory_source(note_id, number)` 按从1开始的来源编号展开，或使用固定 `commit:path#Lfirst-Llast`。

页宽省略时由支持该能力的运行库规划；显式页宽范围为1至8。旧部署仍可能采用固定默认页宽。`pages_left` 是导航逻辑页预算；召回结果中的 `budget_exhausted` 表示邻域遍历被截断，应判断返回的条目和仍需展开的证据。

FREE A 保留现行反锚定与具体问题触发规则；本知情研究记忆场不成为其默认成果菜单。已有任务的冻结输入、来源边界和研究方法自主权继续适用。

## 新定理、反例或发现进入

科学材料按现行 Source 保存入口落地后，Host 可根据当前问题读取相关证据，形成一段独立、有意义、可回到原文的理解。正文首行供菜单辨识，正文准确保留实际命题、前提、原成果归属和科学状态；表达多少由内容决定，不采用固定填表配额。

以 `em_memory_save` 保存，使用新的不可变 `note_id` 和实际读过的固定 `sources`。新增理解用 Host 选择的 `at=[q,r]`；工具返回的 `cell=[layer,q,r]` 多了首个层坐标。保存回执不确定时，用原 `note_id` 读回后再判断下一步。科学论证仍由原来源承担。

截至本次审查，提交 Source、Activity 或正式 Result 并不会自动完成这一步语义提炼；入口由 Host 主动调用。开发中的增量来源提醒也应只提供待读材料，语义、位置与联系仍由 Host 判断。

## 修订与跨线关系

若新证据改变同一理解，用新 ID 和 `revise=原当前ID` 保存；若是不同命题或扩展，可保存新理解并保留各自条件。旧版本及原来源继续可读。`current` 表示工作场当前绑定，不能代替对来源版本和科学状态的判断；维护候选还显式返回 `current_scope=working_memory_field`、`source_freshness=not_checked`。

支持连接维护的候选提供：

- `em_memory_stitch(link_id, from_id, to_id)`：由 Host 选择两个当前笔记所在的物理格，形成有向连接。
- `em_memory_links(link_id)`：查看原连接 ID 的实际原生端点；可用于回执不确定后的核对。
- `em_memory_unstitch(link_id)`：撤销该连接。

`via="connected"` 的召回可沿原生连接取得目标格内容。目标同格其他理解也可能出现；几何连接是取材线索，跨线推理要由带条件的关系说明与原证据支持。原位修订会让连接继续通向当前版本，因此前提改变后应由 Host 判断是否保留、重写关系说明或撤销连接。

这些维护工具与自动页宽、续页能力需要配套运行库、Python 后端和网关目录。2026-11-21 的独立检查区分了线上 v23 的实际调用与候选本地测试，详见 [Nollm 审查](https://github.com/awdawmip/Nollm/pull/7) 和 [后端候选](https://github.com/awdawmip/em-research-mcp/pull/112)。
