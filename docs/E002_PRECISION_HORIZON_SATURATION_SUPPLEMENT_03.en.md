## 1. Question

Stage 2 found the arbitrary-horizon safe width

\[
g=\gcd(w,|a_1|,\ldots,|a_m|)
\]

for centered cell width `w=2d-1` and physical action alphabet `A`. It therefore needs `w/g` future-distinguishable subcells inside each original cell.

This supplement asks two stricter engineering questions:

1. if only action words of length at most `h` matter, how much detail is actually required before the arbitrary-horizon fixed point?
2. does finite actuator clipping change the Stage-2 divisibility criterion?

## 2. Finite-horizon reachable residues

Write the centered state as

\[
e=wq+r-c,
\qquad c=(w-1)/2,
\qquad0\le r<w.
\]

For an action word `v`, write its total increment as

\[
\Sigma(v)=k_vw+s_v,
\qquad0\le s_v<w.
\]

Then

\[
\boxed{Q_w^c(e+\Sigma(v))=q+k_v+\mathbf1_{r+s_v\ge w}.}
\]

Let `W_h` be all action words of length at most `h`, including the empty word, and define

\[
\boxed{S_h=\{\Sigma(v)\bmod w:v\in W_h\}.}
\]

The sets satisfy

\[
S_0\subseteq S_1\subseteq\cdots,
\qquad0\in S_h.
\]

## 3. E002-T20 — Exact finite-horizon class count

Two details `r,r'` in one original width-`w` cell have identical coarse quotient futures for every word of length at most `h` exactly when

\[
\mathbf1_{r+s\ge w}=\mathbf1_{r'+s\ge w}
\quad\text{for every }s\in S_h.
\]

Each nonzero reachable residue contributes one distinct boundary

\[
w-s.
\]

Therefore the detail fiber is split into exactly

\[
\boxed{c_h=|S_h|}
\]

future-distinguishable classes.

### Proof

For a fixed word, the displayed transport formula shows that only its carry bit can distinguish two details in the same original cell. Residue zero never carries. Distinct nonzero residues give distinct thresholds on the ordered integer detail fiber. `|S_h|-1` distinct thresholds create `|S_h|` nonempty consecutive classes. ∎

## 4. E002-T20a — Scalar minimal repair

Because these boundaries are totally ordered, the full carry vector compresses to one integer rank

\[
\boxed{
\rho_h(r)=
\#\{s\in S_h\setminus\{0\}:r+s\ge w\}.
}
\]

The pair

\[
\boxed{(q,\rho_h(r))}
\]

is the coarsest repaired state for the declared horizon-`h` quotient-output language: equal ranks give all equal word carries, while unequal ranks are separated by at least one reachable residue threshold.

This is an arithmetic specialization of P023 task-relative repair.

## 5. E002-T21 — Finite stabilization to the gcd repair

Let

\[
g=\gcd(w,|a_1|,\ldots,|a_m|).
\]

The subgroup of `Z/wZ` generated by the action residues is

\[
H_A=\{0,g,2g,\ldots,w-g\}
\]

with

\[
|H_A|=w/g.
\]

The sets `S_h` stabilize in finitely many steps exactly at `H_A`. Hence

\[
\boxed{c_h\nearrow w/g}
\]

by finite stabilization, with no infinite-resolution limit.

Moreover the first stable horizon obeys

\[
\boxed{h_*\le w/g-1.}
\]

### Proof

Every word residue lies in `H_A`. If `S_(h+1)=S_h`, then `S_h` is closed under adding every generator. Since it contains zero, it already contains the whole generated finite monoid, which inside the finite group `Z/wZ` is `H_A`. Thus before stabilization each round adds at least one residue. Starting from one residue and ending at `w/g` gives the bound. ∎

Stage-2 gcd precision is therefore the finite fixed point of an explicit horizon-indexed precision-growth process.

## 6. E002-T22 — One repeated action

For one action `a`, let

\[
P=\frac w{\gcd(w,|a|)}.
\]

The residues

\[
0,a,2a,\ldots,(P-1)a\pmod w
\]

are distinct and the next one returns to zero. Therefore

\[
\boxed{c_h=\min(h+1,P)}
\]

or equivalently

\[
\boxed{
c_h=\min\left(h+1,\frac w{\gcd(w,|a|)}\right).
}
\]

So one repeated actuator exposes exactly one additional within-cell class per extra future step until the full gcd-safe state is reached.

For several actions growth may be faster. At `w=15`, `A={6,10}` gives

\[
1,3,6,9,12,14,15,15,\ldots
\]

classes at horizons `0,1,...`, while the final gcd alone records only the terminal value `15`.

## 7. Saturated integer translation

Define

\[
\operatorname{clip}_{L,U}(x)=\max(L,\min(U,x)),
\qquad L\le U,
\]

and

\[
F_{a,L,U}(e)=\operatorname{clip}_{L,U}(e+a).
\]

## 8. E002-T23 — Exact saturation criterion

The saturated translation descends through the centered width-`w` quotient if and only if

\[
\boxed{
w\mid a
\quad\text{or}\quad
Q_w^c(L)=Q_w^c(U).}
\]

### Aligned case

If `a=kw`, each input centered cell translates exactly onto one centered cell. Clipping may leave it unchanged, collapse it to one saturation endpoint, or truncate one or both ends. Any active clipping endpoint that intersects the translated cell lies inside that same cell. Hence all fine states from the input fiber retain one common coarse output.

### One-cell saturation case

If `Q_w^c(L)=Q_w^c(U)`, every clipped output is already in one coarse cell, so any physical increment is coarse-safe for this output language.

### Necessity otherwise

Assume `w` does not divide `a` and write `a=kw+s`, `0<s<w`. Every translated input cell straddles one centered-cell boundary, and as the input cell varies these crossings cover every centered boundary. If `Q_w^c(L) != Q_w^c(U)`, the unsaturated interval `[L,U]` contains some boundary first-point `B` with `L<B<=U`. Choose the input cell whose translated image crosses `B`. Two fine states from that same input fiber map to `B-1` and `B`; neither is clipped and their output quotients differ. Thus fiber constancy fails. ∎

## 9. Saturation boundary

For any nontrivial saturation range spanning more than one precision cell,

\[
\boxed{F_{a,L,U}\text{ is coarse-safe iff }w\mid a.}
\]

So ordinary actuator clipping neither breaks precision-locked translation nor rescues a misaligned translation. The only exception is coarse-trivial saturation whose whole output range already collapses to one precision cell.

For a finite saturated action family with a common nontrivial clipping range, the Stage-2 odd-divisor precision spectrum therefore remains unchanged.

## 10. Combined E002 hierarchy

The three stages now separate cleanly:

1. **response:** finite target precision plus persistence produces hysteresis-like behavior, but black-box relay behavior is classically reproducible;
2. **actuation closure:** the target fiber is an exact centered quotient, and a physical action family selects its arbitrary-horizon safe precision by gcd;
3. **future horizon:** the exact amount of detail needed before that fixed point is `|S_h|`, while saturation preserves the divisibility law unless it trivializes the output.

The reusable principle is

\[
\boxed{
\text{declared precision quotient}
+
\text{declared future operation language}
\longrightarrow
\text{coarsest future-safe precision state}.
}
\]

P023 owns the general quotient theorem; E002 supplies explicit translation-control formulas.
