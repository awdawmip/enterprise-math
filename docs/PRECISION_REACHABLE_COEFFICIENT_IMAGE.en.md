# Reachable Coefficient Image and Carrier-Minimal Semiring Precision

Status: `RESEARCH BRIDGE / NONCANONICAL`

A coefficient semiring can contain elements that the declared unweighted relation world can never generate.

These unreachable carrier states are a form of representation overprecision independent from state partition or successor-correlation precision.

For unweighted relations, the exact reachable coefficient algebra is canonical: it is the natural image of the semiring unit.

## 1. Unweighted relations generate only the natural image

Let K be the chosen coefficient semiring.

Every raw relation edge contributes exactly `1_K`.

A local target-block weight is therefore

`n * 1_K`

for some natural successor count n.

Define

`K_nat = { n*1_K : n in N }`.

This is exactly the image of the canonical semiring homomorphism

`eta_K:N->K`.

## 2. K_nat is a subsemiring

For natural m,n:

`eta(m)+eta(n)=eta(m+n)`,

`eta(m)*eta(n)=eta(mn)`.

Also

`eta(0)=0_K`,

`eta(1)=1_K`.

Hence `K_nat` is closed under zero, one, addition and multiplication.

It is the unique smallest subsemiring of K containing `1_K`: any subsemiring containing one must contain every repeated sum `n*1_K`.

Thus K_nat is not an arbitrary compression heuristic. It is the canonical reachable coefficient algebra of the unweighted world law.

## 3. Branching never leaves K_nat

Every local branching coefficient is a raw successor count mapped by eta, so it lies in K_nat immediately.

Recursive branching refinement never creates any other coefficient value: it repeatedly counts raw successors of a current behavioural type and applies eta again.

Therefore replacing K by K_nat changes no unweighted branching signature or state kernel.

## 4. Terminal trace folds never leave K_nat either

Terminal traces multiply and add local coefficients.

Because K_nat is a subsemiring, every path-count coefficient generated by these folds remains inside K_nat.

Thus the same replacement preserves:

- every literal word trace;
- every observed trace partition;
- every coefficient morphism whose relevant action is restricted to the reachable image.

The executable branch verifies this explicitly for the Boolean×modular family.

## 5. Product semirings can have coefficient-carrier overprecision

A categorical product K×L contains every pair `(k,l)`.

But an unweighted raw relation enters the product only through diagonal natural counts

`n -> (eta_K(n),eta_L(n))`.

So the operational coefficient carrier is the image of this one natural map, not the full Cartesian product.

This is a first and purely algebraic kind of product overprecision:

> coefficient pairs outside the natural image are unreachable even before any state/branch semantics is considered.

They can always be removed for the declared unweighted world.

## 6. Modular products compress to the compatible CRT image

For

`K=Z/MZ x Z/NZ`,

the natural image is

`{(n mod M,n mod N):n in N}`.

Its size is

`lcm(M,N)`.

This image is the compatible-residue subring and is isomorphic to

`Z/lcm(M,N)Z`.

Thus full product carrier size

`M*N`

compresses to

`lcm(M,N)`.

When M,N are coprime, `lcm=MN`, so CRT product has no coefficient-carrier redundancy.

When they share factors, the categorical product contains unreachable incompatible residue pairs.

This gives a coefficient-carrier explanation of the earlier modular lcm theorem.

## 7. Boolean × modular product compresses to M+1 states

Consider

`B x Z/MZ`.

The full product carrier has

`2M`

elements.

The natural image is:

- exact zero: `(0,0)`;
- positive residue classes: `(1,r)` for every `r in Z/MZ`.

So reachable carrier size is

`M+1`.

The unreachable elements are

`(0,r)` with `r!=0`,

exactly `M-1` states that no positive/raw natural count can realize.

## 8. Zero-aware modular semiring

The reachable Boolean×mod-M image can be represented directly as a semiring with:

- one true zero Z;
- M positive residue classes `P_r`.

Operations are:

`Z+x=x`,

`P_r+P_s=P_(r+s mod M)`,

`Z*x=Z`,

`P_r*P_s=P_(rs mod M)`.

The important point is that `P_0` is **not** the true zero. It means a positive count divisible by M.

This is the algebraic reason Boolean support extends pure modular local-count capacity from M-1 to M: it separates

`0`

from

`positive multiple of M`.

The executable `zero_aware_modular_semiring` uses the canonical pair representation

`(0,0)` or `(1,r)`.

## 9. Full product and zero-aware semiring have identical unweighted branching semantics

Every raw local coefficient is in the natural image.

The zero-aware operations agree exactly with full Boolean×mod-M operations on that image.

Therefore, at every branching horizon:

`zero-aware branching partition`

equals

`full Boolean x mod-M product branching partition`.

The owner regression checks this exhaustively on all two-state relation pairs for several moduli.

## 10. Terminal traces are also identical

Because both semirings agree on the reachable subsemiring and trace folds never leave it, every literal terminal trace is identical under:

- full Boolean×mod-M product;
- zero-aware M+1-state semiring.

This is verified over multiple words/moduli.

So the carrier compression preserves both structural and trace semantics, unlike task-dependent removal of branch correlation.

## 11. Two different kinds of product overprecision

The recent branching generations expose two independent mechanisms.

### Coefficient-carrier overprecision

The ambient product semiring contains coefficient elements unreachable from the primitive world weights.

Repair:

`replace ambient K by natural-image subsemiring K_nat`.

This is safe for every unweighted branching/trace task using that coefficient algebra.

### Structural correlation overprecision

Even reachable product child types can preserve which K- and L-behaviours belong to the same successor.

For independent readout tasks this pairing can be unnecessary.

For shared compositional operation tasks it can be required.

Repair depends on the declared continuation semantics, not only on coefficient reachability.

These two forms of overprecision must not be conflated.

## 12. Capacity is preserved under carrier minimization

The zero-aware M+1-state semiring and full Boolean×mod-M product have the same natural count code:

`0 -> Z`,

`n>0 -> P_(n mod M)`.

Therefore both have local exact-count capacity M.

So removing unreachable carrier states does not reduce the reflection synergy gained by joining Boolean support and modular residue.

The same principle holds generally: the natural-image subsemiring preserves every distinction the ambient semiring makes on natural counts.

## 13. Scope boundary: weighted raw relations

The theorem assumes raw relation edges carry only the unit coefficient.

If a world law declares primitive edge weights beyond `1_K`, those values can enlarge the reachable coefficient algebra.

The correct generalization is then:

`subsemiring generated by the actual primitive coefficient set`,

not merely the subsemiring generated by one.

So coefficient carrier minimality is world-law relative.

## 14. Compiler rule

For an unweighted relation coefficient interface:

1. choose the semantic coefficient capabilities required by the task;
2. form a convenient ambient semiring/product if needed;
3. restrict immediately to the natural-image subsemiring;
4. only then run branching/compositional state refinement.

This removes algebraically unreachable state before paying any state-partition cost.
