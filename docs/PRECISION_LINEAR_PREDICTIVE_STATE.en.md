# Minimal Linear Predictive State for Exact Weighted Traces

Status: `RESEARCH BRIDGE / NONCANONICAL`

A discrete quotient is not the only possible exact state representation. Once the declared future language is restricted to linear terminal weighted traces, an exact weighted branching machine can often be compressed further into a lower-dimensional rational predictive state.

This is a representation-type change, not another partition refinement.

## 1. Exact weighted branching machine

Assume a finite exact weighted quotient has already been recovered. Let it have b discrete quotient states, integer action matrices

`B_a in Z^(b x b)`,

and current observation rows

`C in Z^(c_0 x b)`.

For a literal word w, terminal weighted outputs are

`C B_w`.

The entire infinite trace language is therefore controlled by the rational row space

`W = span_Q { C B_w : all words w }`.

## 2. Finite invariant row-space closure

Starting from the rows of C, repeatedly add their images under right multiplication by every action matrix.

If one step adds no rational rank, the row space is action-invariant and no longer word can add a new trace direction.

With b quotient states and initial observation rank c_0, stabilization occurs after at most

`b-c_0`

strict rank increases.

Let

`r=dim_Q W`.

Choose an integer row basis

`R in Z^(r x b)`

from the generated word rows.

## 3. Induced predictive actions

Because W is invariant, for every action a there is a unique rational matrix

`T_a in Q^(r x r)`

satisfying

`R B_a = T_a R`.

Because the current observation rows belong to W, there is a rational decoder

`H in Q^(c_0 x r)`

with

`C = H R`.

For discrete quotient source j, define its predictive state by

`s_j = R e_j in Q^r`.

Then

`s -> T_a s`

is the exact predictive update and

`output = H s`

is the exact current output.

## 4. Exact word theorem

For every source j and word w:

`R B_w e_j = T_w R e_j`,

and therefore

`C B_w e_j = H T_w s_j`.

So the r-dimensional predictive machine reproduces every terminal weighted word trace exactly.

The owner helper verifies both the state-intertwining equation and emitted observation equality, rather than merely comparing final state partitions.

## 5. Minimality among linear predictive states

Suppose another linear state map

`S:Q^b -> Q^d`

is sufficient for the same complete terminal trace language, meaning every row `C B_w` factors through S.

Then every `C B_w` lies in the row span of S. Hence

`W subseteq rowspan(S)`

and

`r=dim W <= rank(S) <= d`.

Therefore r is the least possible dimension of any linear predictive representation over Q for the declared trace language.

This is a genuine minimal-state theorem, but only inside the declared **linear** representation class.

## 6. Linear quotient is not a set partition

The map

`R:Q^b -> Q^r`

quotients the entire vector state space by the unobservable linear subspace

`N = intersection_w ker(C B_w)`.

Its kernel is a vector subspace, not merely an equivalence relation generated by identifying some discrete basis states.

Two raw states are trace-equivalent when their basis vectors receive the same predictive vector, but the linear quotient also represents arbitrary superpositions/weighted distributions compactly.

This is why linear predictive dimension can be much smaller than the number of trace-distinct discrete source classes.

## 7. Sharp weighted-fan dimension witness

Take ten source states `x_1,...,x_10` plus one terminal state z, all with the same present observation.

One action has weighted edges

`x_i -> z` with weight i,

and no outgoing edge from z.

Exact weighted branching immediately has eleven distinct states: local weights are `1,...,10,0`.

The terminal traces also distinguish all eleven sources:

- empty word gives the common current observation;
- one action gives values `1,...,10,0`.

Yet the complete trace row space is spanned by only

`(1,1,...,1)`

and

`(1,2,...,10,0)`.

Thus

`b=11`,

but

`r=2`.

The eleven exact source states become distinct vectors of the form `(1,i)` in one two-dimensional predictive space.

This proves that discrete state-class count and algebraic state dimension are different precision resources.

## 8. Count-correlation witness

On the earlier exact-count branch-correlation world:

- exact weighted branching has six discrete behavioural classes;
- p/q must be separated at the branching level because their successor future-count grouping differs;
- terminal count traces merge p/q;
- the invariant trace row space has rational rank4.

So the same world exhibits

`branching discrete state size = 6`

versus

`linear terminal predictive dimension = 4`.

This is the linear counterpart of continuation debt: weaker future semantics admits a different and smaller state type.

## 9. Relation to trace-equivalence partitions

Each quotient basis state j receives predictive vector `R e_j`.

Equality of these vectors is exactly equality of all terminal linear traces, because R spans the full future observation row space.

Thus the ordinary terminal trace-equivalence partition can be recovered as equality fibers of the predictive-state map.

But retaining the vector itself is stronger as a representation technology: it also supports exact linear evolution of weighted distributions.

## 10. Composition with bounded local-law reflection

The previous generation showed that a small finite local code can reconstruct the exact integer weighted quotient machine.

Once those exact action matrices are recovered, the linear predictive compiler consumes only:

- the exact quotient matrices B_a;
- the quotient observation rows C.

It does not need access to the original raw relation.

The branch cross-checks a mod3-reflected primitive weighted machine against its directly exact matrices and obtains identical row-space closure, predictive action matrices and observation decoder.

Therefore the complete pipeline is:

`bounded local code`

`-> exact local reflection`

`-> exact weighted branching machine`

`-> minimal linear predictive trace state`.

## 11. Three different state notions are now explicit

### Branching/compositional state

Enough structure to execute the weighted relation interface itself on successor state classes.

### Terminal answer partition

Only enough to identify which discrete source states have the same complete terminal answers.

### Linear predictive state

A minimal-dimensional linear representation capable of evolving and emitting the complete terminal trace language.

They solve different future-language contracts and must not be ranked by one scalar “precision level.”

## 12. Representation tradeoff

Moving from b discrete branching states to r linear coordinates can reduce structural dimension, but moves information into exact coordinate values and rational transition matrices.

The weighted fan makes the tradeoff sharp: arbitrarily many distinct source values fit in two coordinates because one coordinate carries the varying integer weight.

Thus:

`fewer state dimensions`

does not imply

`less numeric range`,

just as earlier work showed that smaller numeric modulus can be compensated by richer compositional structure.

State dimension, coefficient range, branching correlation and execution interface are separate resources.

## 13. Prior-art boundary

Weighted automata minimization, observability subspaces, linear realization, Krylov spaces and Hankel-rank style state compression are standard prior mathematics/CS. No generic novelty claim is made.
