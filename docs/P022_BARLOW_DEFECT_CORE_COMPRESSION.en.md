## 2. Nonzero support graph

Let

\[
M=(v_p(D))
\]

be the `89 x 89` defect valuation matrix, where columns are the tail defect and composite `D_n` through `n=150` and rows are the 89 `F3` primes already used by the current certificate.

Forget the actual nonzero integer values temporarily and form the bipartite support graph:

- one vertex for each valuation row;
- one vertex for each defect column;
- an edge whenever the valuation is nonzero.

A row of degree one means one selected prime currently sees exactly one remaining defect.  A column of degree one means one remaining defect is seen by exactly one remaining selected prime.

Either case gives an immediate exact determinant pivot.

## 3. P022-DC01 — singleton support peeling

Apply the following deterministic operation repeatedly:

1. if a remaining row has exactly one nonzero entry, pivot on that entry and remove its row and column;
2. otherwise, if a remaining column has exactly one nonzero entry, pivot on that entry and remove its row and column;
3. stop when neither exists.

If the pivot value is `a`, Laplace expansion gives

\[
\det M=\pm a\det M'.
\]

So this operation is an exact determinant reduction; it is not Gaussian approximation or numerical rank detection.
