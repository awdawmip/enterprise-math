# P002 —— 坍缩差的紧上界

状态：`PROVED / LEAN-CHECKED T01–T02`  
开放问题：`P002`  
范围：普通数学

## 1. 坍缩差定义

对 \(p\ge1\)，定义比较量

\[
G_p(n)=n-C_p(n).
\]

它表示坍缩前后两个显式状态之间的整数差。它只是一个由两个状态比较得到的关系量；这个定义并不声称坍缩以后该差值还作为隐藏状态继续存在。

令

\[
k=R_p(n).
\]

则 \(C_p(n)=k^p\)，而 T001 给出

\[
k^p\le n<(k+1)^p.
\]

Lean 表示为 `EnterpriseMath.CollapseGap.collapseGap`；盆地内紧上界由 `maxGapInBasin` 表示。

## 2. 盆地内紧上界

### P002-T01 —— 坍缩差紧上界定理

状态：`PROVED`

对任意 \(n\in\mathbb N\)、\(p\ge1\)，令 \(k=R_p(n)\)，则

\[
0\le G_p(n)\le (k+1)^p-k^p-1.
\]

该上界是紧的，并且等号恰好在盆地最后一个状态取得：

\[
G_p(n)=(k+1)^p-k^p-1
\iff
n=(k+1)^p-1.
\]

### 证明

因为 \(C_p(n)=k^p\le n\)，所以

\[
G_p(n)=n-k^p\ge0.
\]

又因为 \(n<(k+1)^p\) 且状态均为整数，

\[
n\le (k+1)^p-1.
\]

两边减去 \(k^p\)，得到

\[
G_p(n)\le (k+1)^p-k^p-1.
\]

减法后的等号成立，当且仅当 \(n=(k+1)^p-1\)。该状态仍属于 \(k^p\) 的盆地，所以这个上界确实能够达到。证毕。

形式化：已由 `EnterpriseMath.CollapseGap.collapseGap_le_max` 通过 Lean 检查；紧等号刻画由 `collapseGap_eq_max_iff` 核验。

## 3. 与盆地大小的关系

T008 已给出

\[
|B_{p,k}|=(k+1)^p-k^p.
\]

因此紧上界也可以写成

\[
\boxed{\max_{n\in B_{p,k}}G_p(n)=|B_{p,k}|-1.}
\]

平方情形下，

\[
|B_{2,k}|=2k+1,
\]

所以

\[
0\le G_2(n)\le2k.
\]

当 \(k=141\) 时，盆地是 \(19881,\ldots,20163\)，最大比较差为

\[
20163-19881=282.
\]

## 4. 盆地内每一个偏移恰好出现一次

### P002-T02 —— 盆地 gap 坐标双射

状态：`PROVED`

固定 \(p\ge1\) 与 \(k\in\mathbb N\)，映射

\[
n\longmapsto G_p(n)=n-k^p
\]

把盆地

\[
B_{p,k}=\{k^p,\ldots,(k+1)^p-1\}
\]

双射到

\[
\{0,1,\ldots,(k+1)^p-k^p-1\}.
\]

### 证明

每一个盆地状态都能唯一写成

\[
n=k^p+g
\]

其中

\[
0\le g\le (k+1)^p-k^p-1.
\]

对这样的状态都有 \(C_p(n)=k^p\)，因此

\[
G_p(n)=g.
\]

逆映射就是 \(g\mapsto k^p+g\)。证毕。

形式化：盆地状态的精确恢复由 `EnterpriseMath.CollapseGap.basin_state_eq_pow_add_gap` 核验；双射以 `∃!` 形式由 `existsUnique_basin_state_with_gap` 通过 Lean 检查——每个允许 gap 坐标在固定盆地中恰好对应一个状态，逆状态就是 `k^p+g`。

所以，gap 可以作为**盆地内部显式状态之间的外部比较坐标**，而不需要把坍缩映射改写成保存余量的二元状态转移。

## 5. 纯整数闭式

由二项式定理，

\[
(k+1)^p-k^p-1
=
\sum_{j=1}^{p-1}\binom pj k^j.
\]

因此，对每个固定正指数 \(p\)，紧上界都是 \(k\) 的整数多项式。

例如：

\[
p=1:\quad 0,
\]

\[
p=2:\quad 2k,
\]

\[
p=3:\quad 3k^2+3k,
\]

\[
p=4:\quad 4k^3+6k^2+4k.
\]

这里不需要任何实数近似或渐近估计。

形式化状态：本轮尚未把这一未编号二项式闭式推论提升到 Lean；`LEAN-CHECKED T01–T02` 只精确指向上面的两个编号 P002 定理单元。

## 6. 与本体解释的边界

P002 不能把旧的“隐藏余量”思路偷偷带回来。

这个定理只是说明两个显式状态 \(n\) 与 \(C_p(n)\) 之间存在整数差 \(G_p(n)\)，并且该差值可以作为比较坍缩前盆地状态的位置坐标。

它并没有把项目中的状态转移

\[
n\longmapsto C_p(n)
\]

改写成

\[
n\longmapsto (C_p(n),G_p(n)).
\]

物理理论是否需要保留额外变量，是另一个物理假说问题。本文研究的普通数学坍缩映射仍然是多对一的。

## 7. P002 解决结论

P002 可以完整解决为

\[
\boxed{
G_p(n)\le (R_p(n)+1)^p-R_p(n)^p-1
}
\]

且等号恰好发生在下一个完全 \(p\) 次幂之前的最后一个整数状态。

同一结论也就是“盆地大小减一”；并且 gap 坐标把盆地中每一个位置恰好枚举一次。
