# Legendre 压力测试——补充 07

状态：`ACTIVE RESEARCH NOTE`  
范围：围绕平方盆地公共中心的跨状态镜像分离，以及由此得到的横向素数资源必要条件。  
结论纪律：**本文不声称证明了 Legendre 猜想。**

## 1. 一种不同性质的盆地结构

此前各补充主要研究支撑乘积、Möbius 尾部以及半尺度对偶。这些工具仍然有效，但下一步若要越过 parity obstruction，必须出现真正跨状态的约束。

记

\[
M=k(k+1).
\]

平方盆地可以精确写成

\[
I_k=M+\{1-k,\ldots,k\}.
\]

对每个

\[
1\le r\le k-1,
\]

两个状态

\[
M-r,\qquad M+r
\]

都严格位于 \(k^2\) 与 \((k+1)^2\) 之间，称为镜像对。

没有配对的两个状态是

\[
M=k(k+1)
\]

与

\[
M+k=k(k+2),
\]

当 \(k\ge2\) 时二者都显然为合数。因此除去平凡的 \(k=1\) 情形，任何素数见证都必须出现在镜像对中。

## 2. L026 —— 锚点筛对镜像对全进全出

状态：`PROVED`

令 \(A_k\) 为小锚点素数的乘积，即所有满足 \(p\le k\) 且 \(p\mid M=k(k+1)\) 的素数之积。

对每个 \(1\le r\le k-1\)，由于 \(A_k\mid M\)，直接有

\[
\gcd(M-r,A_k)
=
\gcd(r,A_k)
=
\gcd(M+r,A_k).
\]

所以

\[
\boxed{
\gcd(r,A_k)=1
\iff
\gcd(M-r,A_k)=\gcd(M+r,A_k)=1.
}
\]

锚点消去不可能只删除镜像对的一侧：一个镜像对要么两侧都通过锚点筛，要么两侧同时失败。

## 3. L027 —— 横向镜像支撑严格分离

状态：`PROVED`

令 \(p\le k\) 为横向素数：

\[
p\nmid M.
\]

因为 \(M=k(k+1)\) 总是偶数，所以 \(p\neq2\)，即 \(p\) 为奇素数。

反设 \(p\) 同时整除镜像两侧：

\[
p\mid M-r,
\qquad
p\mid M+r.
\]

于是

\[
p\mid2r.
\]

因 \(p\) 为奇素数，得到

\[
p\mid r.
\]

再结合 \(p\mid M-r\)，推出

\[
p\mid M,
\]

与横向性矛盾。

所以

\[
\boxed{
\operatorname{Supp}_{\mathrm{tr}}(M-r)
\cap
\operatorname{Supp}_{\mathrm{tr}}(M+r)
=arnothing.
}
\]

这比“大模数在短区间里不能命中两次”更强：**无论横向小素数有多小，同一个横向素数都绝不可能同时出现在同一镜像对的两侧。**

## 4. L028 —— 存活合数镜像对至少消耗两个不同横向资源

状态：`PROVED CONDITIONAL CONSEQUENCE`

假设

\[
\gcd(r,A_k)=1,
\]

因此镜像对通过锚点筛。

若

\[
M-r,\qquad M+r
\]

两者都是合数，因为它们均位于平方盆地中，根视界引理保证两侧都至少存在一个不超过 \(k\) 的素因子。

镜像对已通过锚点筛，因此这些小素因子不可能是锚点素数，只能是横向素数。

再由 L027，两侧横向支撑不交。因此一个存活合数镜像对至少需要两个不同的横向小素数资源：

\[
\boxed{
\omega_{\mathrm{tr}}(M-r)
+
\omega_{\mathrm{tr}}(M+r)
\ge2.
}
\]

而且更强地，两侧是两个非空且互不相交的支撑集合。

例如 \(k=20\)、\(M=420\)、\(r=17\) 时，

\[
M-r=403=13\cdot31,
\qquad
M+r=437=19\cdot23.
\]

其中只有 \(13\) 与 \(19\) 不超过 \(k\)，它们恰好是两侧不同的横向资源。

## 5. L029 —— 盆地级横向入射必要条件

状态：`PROVED AS A NECESSARY CONDITION; NOT A CONTRADICTION`

定义通过锚点筛的半径集合

\[
S_k
=
\{1\le r\le k-1:\gcd(r,A_k)=1\}.
\]

定义全部存活镜像状态上的横向小素数总入射数

\[
J_k
=
\sum_{r\in S_k}
\left(
\omega_{\mathrm{tr}}(M-r)
+
\omega_{\mathrm{tr}}(M+r)
\right).
\]

若 Legendre 猜想恰好在这个 \(k\) 上失败，则由于两个未配对状态本来就是合数，所有镜像状态都必须为合数。由 L028，必有

\[
\boxed{
J_k\ge2|S_k|.
}
\]

这只是一个“假设存在反例时必须满足”的必要条件。我们目前**没有**证明与它矛盾的上界。

### 按素数重新编号

同一个 \(J_k\) 还可以不按状态，而按横向素数计数。对每个横向素数 \(p\le k\)，定义

\[
N_p(k)
=
\#\left\{
r\in S_k:
 p\mid M-r\ \text{或}\ p\mid M+r
\right\}.
\]

L027 保证对固定半径，两种情况不会同时发生。因此

\[
\boxed{
J_k
=
\sum_{\substack{p\le k\\p\nmid M}}N_p(k).
}
\]

这是一个真正的盆地级资源账：左侧按状态编号，右侧按横向素数编号。

若想仅凭 L029 证明 Legendre，还需要超越第一阶入射总数。朴素的素数容量和预计过大；真正缺失的是不同横向素数如何在同一侧发生重叠，同时又必须遵守另一侧支撑分离的二阶约束。

## 6. 与此前支撑公式的区别

L023–L025 用公共锚点决定一个大支撑乘积是否命中盆地；L026–L029 则直接约束**两个不同状态**，而且对很小的素因子也成立。

新的结构是

\[
\boxed{
\text{半径通过锚点筛}
\Longrightarrow
\text{两侧状态同时存活}
\Longrightarrow
\text{两侧横向支撑严格不交}.
}
\]

这一性质研究任何单侧状态时都看不到。

## 7. 下一步目标

L029 的一阶资源不等式大概率不足以单独完成证明。下一步应研究每个镜像对一侧内部的碰撞结构，同时保留另一侧严格不交这一跨状态约束。

可以定义对级 collision gain

\[
\Gamma_r
=
\bigl(\text{两侧横向素数入射数}\bigr)
-
\bigl(\text{实际被覆盖的两侧状态数}\bigr),
\]

然后研究镜像分离是否能对

\[
\sum_{r\in S_k}\Gamma_r
\]

给出比普通单区间容斥更强的全盆地界。

四支撑半尺度图与 smooth-cofactor 闭包仍可作为高碰撞状态的局部结构；镜像分离则提供此前缺失的跨状态限制。

## 8. 可执行验证

`src/enterprise_math/mirror.py`、`src/enterprise_math/mirror_incidence.py` 及其测试在有限范围内检查：

- 平方盆地严格分解成 \(k-1\) 个镜像对与两个已知合数状态；
- 锚点 gcd 在半径和镜像两侧完全相同；
- 所测试镜像对的横向支撑全部严格不交；
- 通过锚点筛的合数镜像对两侧都有非空且不交的小素数支撑；
- 按状态统计与按横向素数统计的总入射数完全相等。

L026–L029 均由初等整数论证得到；有限测试只验证参考实现。
