## 1. Cubic response does not imply cubic state

Stage108 proves that quadratic rank energy has genuine third-order action interaction.

It would be a mistake to infer that the system must store a cubic response tensor as its state.

Stage109 returns to the underlying incidence geometry and constructs a common generator that works for both the linear area observable and the quadratic-energy observable.

## 2. P025-D50 — full labelled merged-rank path

Merge old thresholds and candidate thresholds into one labelled total order

\[
H_1<\cdots<H_m.
\]

For every current node `rho_c` define

\[
P_c:=\#\{\ell:H_\ell\le\rho_c\}.
\]

For every future node `v_j` define

\[
Q_j:=\#\{\ell:H_\ell\le v_j\}.
\]

Since node values are nondecreasing,

\[
\boxed{
P_0\le\cdots\le P_h\le Q_1\le\cdots\le Q_b.
}
\]

This weakly increasing integer path is the full merged-rank generator.

## 3. P025-T248 — rank-path reconstruction of selected column ranks

Fix a candidate-threshold selection set `I`.

For a node with merged rank `q`, the active merged thresholds are exactly the first `q` labels.

The **selected** threshold rank of that node is therefore

\[
\boxed{
\#\{\text{old labels in the first }q\}
+
\#\{\text{candidate labels in the first }q\text{ whose indices lie in }I\}.
}
\]

Thus the merged rank plus the static labels reconstructs the final selected threshold rank of every current or future node.

## 4. P025-T249 — one path generates both area and quadratic energy

Once every selected column rank is reconstructed, both observables follow immediately:

\[
A=\sum r_j,
\]

\[
E=\sum r_j^2.
\]

Therefore the same full merged-rank path generates:

- every activation-area endpoint response;
- every quadratic-rank-energy endpoint response;
- the full Stage108 cubic response polynomial by evaluation on independent action selections.

No explicit second-order or third-order response tensor needs to be stored as primitive state.

## 6. P025-T250 — Ferrers path state count

With `m` merged thresholds and `n` total declared node positions (current plus future), a completely unconstrained incidence matrix has

\[
2^{mn}
\]

Boolean states.

A monotone threshold/node incidence state is determined by a weakly increasing rank path of length `n` taking values in `0,...,m`.

Hence the number of compatible generator states is exactly

\[
\boxed{
\binom{m+n}{n}.
}
\]

This is again the Ferrers/lattice-path count.

## 7. Response order versus generator dimension

Stages108–109 now give a particularly sharp separation:

- quadratic energy response jet: exact worst-case order `3`;
- common incidence generator: one weakly increasing scalar rank per node.

Therefore

\[
\boxed{
\text{high response interaction order does not imply a high-order primitive state tensor}.
}
\]

The response tensor is a derived object produced by applying the observable algebra to a lower-dimensional incidence generator.
