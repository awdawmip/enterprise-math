## 1. Why the critical shell needs another integer layer

Supplement 08 identified the real PRE_HORIZON reciprocal interval generated by
one consecutive cofactor-prime gap `a<b`:

\[
\frac{U}{b}<q\le \frac{A}{a},
\qquad
A=k^3,
\quad
U=(k+1)^3-1.
\]

Its real width becomes positive at the critical scale

\[
b-a=3a^{1/3}+O(1).
\]

That is not yet the integer event needed by the divisor-witness language.  A
positive real interval can contain no integer, and an integer interval can still
contain no prime.

The exact knife-edge therefore has three successive questions:

1. does the real reciprocal interval open?
2. does it contain an integer q?
3. does its terminal integer block contain a prime q?

This supplement solves the first-to-second transition exactly and compresses the
third to one predecessor prime.

## 3. B30 — exact integer reciprocal window

The integer condition

\[
\frac{U}{b}<q\le\frac{A}{a}
\]

is equivalent to

\[
\left\lceil\frac{C}{b}\right\rceil\le q\le m.
\]

Therefore every integer in the reciprocal window has the terminal form

\[
\boxed{q=m-j}
\]

with

\[
\boxed{
0\le j\le J,
\qquad
J=m-\left\lceil\frac{C}{b}\right\rceil.
}
\]

Equivalently,

\[
\boxed{
J=\left\lfloor\frac{bm-C}{b}\right\rfloor.
}
\]

A negative J means the real reciprocal interval contains **no integer at all**.

This is the first correction to the real-window phase diagram: real activation
and integer activation are distinct precision levels.

## 4. B31 — exact depth activation thresholds

For a fixed terminal depth `j`, put

\[
q_j=m-j.
\]

Let the right prime gap length be

\[
g=b-a.
\]

The integer q_j is captured exactly when

\[
(a+g)q_j\ge C.
\]

Hence its least activating gap length is

\[
\boxed{
G_j(a,k)
=
\left\lceil\frac{C}{m-j}\right\rceil-a.

In particular the first integer endpoint `m` appears at

\[
\boxed{
G_0(a,k)
=
\left\lceil\frac{(k+1)^3}{\lfloor k^3/a\rfloor}\right\rceil-a.
}
\]

This is the exact integer activation threshold.  It is strictly stronger than
merely asking for positive real width.

## 5. B32 — quotient jump plus reciprocal carry

Write the next Euclidean state as

\[
C=a(m+d)+r',
\qquad 0<r'<a.
\]

Then

\[
\begin{aligned}
G_0
&=\left\lceil\frac{a(m+d)+r'}{m}\right\rceil-a\\
&=d+\left\lceil\frac{d(a-m)+r'}{m}\right\rceil.
\end{aligned}
\]

Thus

\[
\boxed{
G_0=d+\eta,
\qquad
\eta=\left\lceil\frac{d(a-m)+r'}{m}\right\rceil.
}
\]

The first term is not a new object.  Because `a>F_3(k)>k+1`, `a` does not divide
`C`; therefore

\[
\boxed{
d
=\left\lfloor\frac{C}{a}\right\rfloor-\left\lfloor\frac{A}{a}\right\rfloor
=H_{3,a}(k).
}
\]

So the critical right-gap threshold is exactly:

\[
\boxed{
\text{cubic basin hit-count jump}
+
\text{reciprocal carry}.
}
\]

The generic full-width carry theorem from Checkpoint 1 then gives

\[
H_{3,a}(k)
=\left\lfloor\frac{3k^2+3k}{a}\right\rfloor
+arepsilon_{3,a}(k),
\qquad
\varepsilon_{3,a}(k)\in\{0,1\}.
\]

Therefore the exact knife-edge has a three-layer integer decomposition:

\[
\boxed{
G_0
=\left\lfloor\frac{3k^2+3k}{a}\right\rfloor
+arepsilon_{3,a}(k)
+\eta_{a,k}.
}
\]

The leading constant 3 is now seen directly as the cubic width term; the
critical integer teeth are carried by two boundary corrections.

## 6. B33 — carry teeth: integer activation need not be monotone

The real activation threshold

\[
\frac{3a(k+1)}{k^2}
\]

is decreasing with k.  The integer threshold G_0 need not be.

Exact example:

\[
a=239.
\]

For PRE states `k=30,...,37`, the integer endpoint thresholds are

\[
\boxed{27,26,24,24,23,22,21,22.}
\]

The threshold reaches 21 at k=36 and then rebounds to 22 at k=37, even though
k=37 is the final PRE state (`F_3(37)=234<239`).

Thus the real PRE activation interval is monotone, but the **integer** activation
profile has carry teeth.  Any exact knife-edge theorem must preserve this local
carry rather than replacing it by one smooth real threshold.

## 8. B35 — unit-cost threshold ladder

For consecutive terminal coordinates `q` and `q-1`,

\[
\frac{C}{q-1}-\frac{C}{q}
=rac{C}{q(q-1)}.
\]

In PRE_HORIZON,

\[
m<\frac{A}{a}<\sqrt A<\sqrt C.
\]

Hence for every relevant `q<=m`,

\[
q(q-1)<C,
\]

so

\[
\frac{C}{q-1}-\frac{C}{q}>1.
\]

Taking ceilings gives

\[
\boxed{G_{j+1}\ge G_j+1.}
\]

Consequently

\[
\boxed{G_j\ge G_0+j.}
\]

This is the **paired-gap budget law**:

> every one-unit move left from the quotient endpoint costs at least one extra
> unit of right cofactor-prime gap.

Near the critical terminal shell, where `q(q-1)>C/2`, the same calculation gives

\[
G_{j+1}-G_j\le2.
\]

Thus in that region one unit of left prime lag costs either one or two units of
right-gap surplus.

\[

So lower-band **existence** again compresses to one boundary prime, exactly as

## 10. B37 — fixed-slack finite-state theorem

Let

\[
H=g-G_0
\]

be the integer right-gap surplus above depth-zero activation.

If H<0, no integer q exists.

If H>=0 and a prime Q=m-ell is captured, then by the unit-cost ladder

\[
G_{\ell}\ge G_0+\ell.
\]

Since capture requires `G_ell<=g=G_0+H`, necessarily

\[
\boxed{\ell\le H.}
\]

Therefore, at fixed additive right-gap surplus H, the lower PRE existence query
can only depend on the bounded terminal block

\[
\boxed{
\{m-H,m-H+1,\dots,m\}.
}
\]

The size of this block is independent of the arithmetic scale a.

For the yes/no query even that block can be compressed to the predecessor prime
Q and its lag ell.

This is the main precision result of the supplement:

\[
\boxed{
\text{fixed critical-gap surplus}
\Longrightarrow
\text{bounded prime-lag state}.
}
\]

The unresolved difficulty is not an unbounded witness alphabet.  It is the
primality of a bounded terminal block along the moving quotient orbit

\[
\boxed{
m_k=\left\lfloor\frac{k^3}{a}\right\rfloor.}
\]

## 11. The new research target

The critical shell has therefore changed type.

Before this supplement it looked like a generic short-prime interval problem.
After integer compilation it is:

\[
\text{cubic quotient orbit }m_k
\quad+\quad
\text{hit-count / carry state}
\quad+\quad
\text{bounded predecessor-prime lag}.
\]

For fixed O(1) surplus above the exact integer threshold, only O(1) terminal
integers per k can matter, while k itself runs through an O(a^{1/3})-scale shell
near the horizon crossing.

This is **not** the standard fixed-parameter Beatty or Piatetski–Shapiro setting:
the denominator a varies with the cofactor prime gap.  A dedicated sieve or
exponential-sum analysis of the quotient orbit may therefore be more natural
than applying arbitrary-interval prime theorems yet again.
