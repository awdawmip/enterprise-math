# A3 Guard-Image Lattice — Hidden Score Geometry for Multiple Guards

Status: `RESEARCH WIP / INTEGER-LATTICE ENDPOINT THEOREMS + EXECUTABLE RANK TOOLS`

## 1. Goal

The A3 binary-threshold theorem uses one guard

\[
w^Tc+b\ge0.
\]

With several integer linear guards, treating each guard as merely visible or hidden loses the coupling between guard scores.

The correct hidden object is the integer image of the partition kernel in the complete guard-score space.

## 2. Definition

Let

\[
A:\mathbb Z^k\to\mathbb Z^\ell,
\qquad
K_A=\ker_{\mathbb Z}A.
\]

Let the `r` guard rows form

\[
W\in\mathbb Z^{r\times k}.
\]

For a fixed coarse state `y=Ac`, the fine fiber is `c+K_A`, and its guard scores are

\[
Wc+b+W(K_A).
\]

Define

\[
\boxed{L_G:=W(K_A)\subseteq\mathbb Z^r.}
\]

This **guard-image lattice** exactly records how coarse-invisible motion can change all guard scores.

## 3. A3-G01 — Generators for coordinate partitions

For each coarse block choose an anchor `a`. The coordinate-partition kernel has the canonical basis `e_i-e_a` for the other coordinates `i` in that block.

Hence the guard-image generators are simply within-block coefficient differences:

\[
\boxed{
W(e_i-e_a)
=
(w_i^{(1)}-w_a^{(1)},\ldots,w_i^{(r)}-w_a^{(r)}).
}
\]

No integer states need to be enumerated.

## 4. A3-G02 — Rank zero means all guards descend

\[
\operatorname{rank}L_G=0
\]

iff `W(K_A)=0`, so every guard score is constant on each coarse fiber and every guard row factors through `A`.

For coordinate partitions this is exactly the block-constant coefficient criterion.

The visible single-guard case is therefore the rank-zero endpoint.

## 5. A3-G03 — A full-rank hidden lattice hits every orthant

If

\[
\operatorname{rank}L_G=r,
\]

then `L_G` is a full-rank sublattice of `Z^r`, so `Z^r/L_G` is finite. Therefore some integer `d>=1` satisfies

\[
\boxed{d\mathbb Z^r\subseteq L_G.}
\]

Fix any base guard score `g` in any coarse fiber and any strict sign pattern `sigma in {-,+}^r`. Choose the integer components of `n` with sufficiently large signed magnitude so that every component of `g+d n` has the requested sign. Since `dn in L_G`,

\[
\boxed{(g+L_G)\cap O_\sigma\ne\varnothing}
\]

for every strict orthant `O_sigma`.

Thus every coarse fiber realizes **all `2^r` strict sign patterns**.

## 6. A3-G04 — Full-rank branch-erasure consequence

Consider a finite piecewise-affine program whose branch is selected only by the `r` guard signs. Assume at this stage that each affine branch already descends individually to the current partition.

If `rank L_G=r`, every branch sign pattern is realized in every coarse fiber. Therefore the whole program is exact iff all reachable branch coarse affine effects are identical; in the full-rank case the reachable set is all sign patterns:

\[
\boxed{
\bar T_\sigma=\bar T_\tau
\quad\forall\sigma,\tau\in\{-,+\}^r.
}
\]

Then the entire guard-vector identity can be erased. If two coarse branch effects differ, a single coarse fiber realizes both patterns and therefore produces different coarse outputs.

The individual-branch descent assumption remains explicit here; this note does not silently promote restricted-region exactness into global branch descent.

## 7. A3-G05 — Partial rank cannot be summarized by rank alone

If

\[
0<\operatorname{rank}L_G<r,
\]

rank gives only the number of hidden score degrees, not the orthants crossed by the affine lattice.

For `r=2`, a rank-one lattice along `(1,1)` and one along `(1,-1)` have the same rank but can realize completely different sign patterns from the same type of base coset.

Therefore

\[
\boxed{
\text{partial-rank multi-guard precision cannot be determined by a guard-rank scalar alone.}
}
\]

The actual object is the affine lattice `g+L_G` and its integer intersection with threshold orthants/polyhedra.

## 9. Relationship to other routes

General behavioral quotient mathematics remains owned by A2/P023. The A3 specialization is the explicit integer lattice `W(K_A)` generated by coefficient differences inside coordinate-partition blocks.

If A2/P023 already owns a more general finite-guard reachable-branch theorem, A3 should depend on it rather than duplicate the mother result.
