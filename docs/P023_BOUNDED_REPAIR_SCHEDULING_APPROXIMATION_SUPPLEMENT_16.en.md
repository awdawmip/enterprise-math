# P023 — Bounded-Repair Scheduling Approximation, Supplement 16

Status: `PROVED RESEARCH NOTE`  
Owner: A2 / P023  
Depends on: P023-S12 directed repair depth and P023-S14 conditional scheduling  
Discipline: this is an elementary integer coding bound. The project role is to convert a structural bound on directed repair into a rigorous additive guarantee for finite task acquisition.

## 1. Two-task setup

Let `E,F` be two finite precision tasks on the same finite state set `X`.

Write

\[
N_E=|X/E|,
\qquad
N_F=|X/F|,
\qquad
N_*=|X/(E\cap F)|.
\]

Fix integer alphabet base `B>=2` and

\[
L_B(n)=\min\{\ell:n\le B^\ell\}.
\]

The exact two orders have costs

\[
C_{E\to F}=L_B(N_E)+L_B(\rho(E,F)),
\]

and

\[
C_{F\to E}=L_B(N_F)+L_B(\rho(F,E)).
\]

The final joint-state cardinality lower bound is

\[
D_*=L_B(N_*).
\]

## 2. P023-S16-T01 — Bounded directed repair gives an additive schedule guarantee

Status: `PROVED`.

If

\[
\boxed{
\rho(E,F)\le B^c
}
\]

for an integer `c>=0`, then

\[
\boxed{
C_{E\to F}
\le
D_*+c.
}
\]

### Proof

The joint quotient refines `E`, so

\[
N_E\le N_*.
\]

Hence

\[
L_B(N_E)\le L_B(N_*)=D_*.
\]

The repair assumption gives

\[
L_B(\rho(E,F))\le c.
\]

Adding the two inequalities yields the claim. ∎

Thus a small directed repair factor is not merely a local statement; it gives a global additive approximation guarantee for the corresponding two-task schedule.

## 3. P023-S16-T02 — Any strict reverse-order advantage is bounded by c

Status: `PROVED`.

Let

\[
C_{\min}=\min(C_{E\to F},C_{F\to E}).
\]

Since every exact schedule must at least name all final joint classes,

\[
C_{\min}\ge D_*.
\]

Combining with T01 gives

\[
\boxed{
C_{E\to F}-C_{\min}
\le c.
}
\]

Therefore even when `F -> E` is the better exact order, choosing `E -> F` loses at most `c` base-`B` symbols.

## 4. P023-S16-T03 — The one-symbol case is rigid

Status: `PROVED`.

Suppose

\[
\rho(E,F)\le B.
\]

Then

\[
C_{E\to F}\le D_*+1.
\]

If the reverse order is strictly cheaper, integer-valued costs force

\[
\boxed{
C_{F\to E}=D_*,
\qquad
C_{E\to F}=D_*+1.
}
\]

So a strict reverse-order advantage is **exactly one symbol**, never more.

This gives a strong robustness property even though exact order optimality can vary from instance to instance.

## 5. P023-S16-T04 — Multi-task prefix version

Status: `PROVED`.

Consider an order

\[
E_{\sigma(1)},\ldots,E_{\sigma(m)}
\]

with stage repair factors `rho_j` as in S14. Suppose that for every stage after the first,

\[
\rho_j\le B^{c_j}.
\]

Let `N_*` be the final joint class count. The first task has at most `N_*` classes, hence

\[
L_B(|X/E_{\sigma(1)}|)\le L_B(N_*).
\]

Therefore

\[
\boxed{
C_B(\sigma)
\le
L_B(N_*)+
\sum_{j=2}^m c_j.
}
\]

Thus a schedule with uniformly small conditional repairs is automatically close to the final cardinality lower bound, independent of how large the raw state space is.

This gives a useful proof heuristic: search for an order whose later conditional repair factors admit structural bounds.

## 6. Relation to dependency closure

If a later task lies in the S15 dependency closure of the current context, then its repair factor is one and one may take

\[
c_j=0.
\]

So closure-derived zero-cost tasks contribute no additive approximation penalty.

S15 and S16 therefore complement one another:

- closure removes tasks whose conditional repair is exactly zero depth;
- bounded-repair approximation controls the remaining nonzero transitions.

## 7. Number-theory feedback: P017

P017 L064 proves

\[
\rho(P,R)\le2.
\]

Taking base `B=2` gives `c=1`. Hence factor-first acquisition of least-prime plus cofactor-root precision is universally within one binary symbol of the final joint-class lower bound.

P017 Supplement 25 records the resulting L066 theorem and its consequence that any strict root-first advantage is exactly one bit.

## 8. Research-tool rule

When exact task-order optimization is expensive:

1. identify a candidate first task `E`;
2. prove a structural bound on `rho(E,F)` or on each later conditional repair;
3. convert those bounds into an additive integer guarantee via S16;
4. only run exact DP if the remaining additive slack matters to the theorem;
5. do not replace the guarantee by a heuristic claim of exact optimality.

This distinguishes **certified near-optimality** from unproved greedy preference.

## 9. Prior-art and novelty discipline

The inequality is elementary coding arithmetic. Approximation guarantees from bounded branching are not claimed as new mathematics.

The project-specific value is the fact that the branching factor is not guessed or externally supplied: it is the exact P023 conditional repair multiplicity generated by the declared precision tasks.
