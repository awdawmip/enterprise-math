## 1. Why the previous geodesic-defect observable collapses on native graph geometry

The historical A3↔A4 bridge introduced, for a radius family generated by an integer metric `rho`, the radius-one graph `G_1` and the defect

\[
\Gamma(x,z)=d_{G_1}(x,z)-\rho(x,z).
\]

That observable is useful when the declared direct metric and the represented unit-step geometry may disagree.

For P022's **native unweighted graph metric**, however, the radius-one graph is the original graph itself. Therefore

\[
\boxed{\Gamma\equiv0.}
\]

More generally, if `d` is the shortest-path metric of any connected unweighted graph and

\[
R_r=\{(x,z):d(x,z)\le r\},
\]

then for every `r,s>=0`,

\[
\boxed{R_r;R_s=R_{r+s}.}
\]

Indeed, the forward inclusion is the triangle inequality. For the reverse inclusion, take a shortest path from `x` to `z` of length at most `r+s` and choose an intermediate vertex after at most `r` steps; the remaining suffix has length at most `s`.

This is a standard shortest-path fact, not a novelty claim. Its architectural consequence is important:

> **P022 should not compare SC/FCC/HCP/root-lattice candidates by `Gamma` when `rho` is simply each candidate's own unweighted graph metric. Existence-only geodesic structure has already collapsed.**

The next discriminating layer is **multiplicity**.

## 2. P022-GM01 — geodesic interval layers are the minimum-budget count coefficients

For graph endpoints `x,z`, write

\[
d=d(x,z).
\]

For `0<=a<=d`, define the geodesic interval layer

\[
I_a(x,z)=\{y:d(x,y)=a,\ d(y,z)=d-a\}.
\]

The count-enriched two-stage support coefficient at the minimum total budget is exactly

\[
\boxed{H_{xz}(a,d-a)=|I_a(x,z)|.}
\]

Thus the existence statement says only that every layer is nonempty, while the integer sequence

\[
\boxed{\mathcal I(x,z)=(|I_0|,|I_1|,\ldots,|I_d|)}
\]

records how much represented geodesic choice remains at each depth.

At full primitive depth `d`, the coefficient of the all-one cost vector

\[
(1,1,\ldots,1)
\]

is exactly the number of shortest paths from `x` to `z`. Denote it by

\[
g(x,z).
\]

Therefore native graph geometry has the hierarchy

\[
\text{distance}
\longrightarrow
\text{interval-layer multiplicity}
\longrightarrow
\text{full shortest-path multiplicity}.
\]

All three are finite integer observables.

## 3. P022-GM02 — exact shortest-path count in the `A_p` root lattice

Use the standard P022 working lattice

\[
A_p=\{v\in\mathbb Z^{p+1}:\sum_i v_i=0\}
\]

with primitive moves `e_i-e_j`.

For an endpoint displacement `v`, let

\[
r=d_G(0,v)=\sum_{v_i>0}v_i=\sum_{v_j<0}(-v_j).
\]

Every shortest path consists of exactly `r` unit transfers from currently negative coordinates to currently positive coordinates.

The destination-coordinate sequence has multiplicities `v_i` over positive coordinates, hence

\[
\frac{r!}{\prod_{v_i>0}v_i!}
\]

possible orders. Independently, the source-coordinate sequence has multiplicities `-v_j`, hence

\[
\frac{r!}{\prod_{v_j<0}(-v_j)!}
\]

possible orders. Pair the two sequences time-step by time-step. This gives

\[
\boxed{
g_{A_p}(v)=
\frac{(r!)^2}
{\left(\prod_{v_i>0}v_i!\right)
 \left(\prod_{v_j<0}(-v_j)!\right)}.
}
\]

No real-valued geometry or probability is used.

### Same shell, different internal geometry

Already in `A_3` at graph radius two:

\[
(2,-2,0,0)\quad\Rightarrow\quad g=1,
\]

\[
(1,1,-2,0)\quad\Rightarrow\quad g=2,
\]

\[
(1,1,-1,-1)\quad\Rightarrow\quad g=4.
\]

All three endpoints have the same native graph distance `2`, but their shortest-path multiplicities differ by a factor of four.

So the shell cardinality alone is not the complete finite geometry.

## 4. P022-GM03 — exact `A_p` geodesic interval profile

Let the positive coordinate magnitudes of `v` be

\[
p_1,\ldots,p_a
\]

and the negative magnitudes be

\[
n_1,\ldots,n_b,
\]

with both sums equal to `r`.

Define integer polynomials

\[
P_v(t)=\prod_{i=1}^a(1+t+\cdots+t^{p_i}),
\]

\[
N_v(t)=\prod_{j=1}^b(1+t+\cdots+t^{n_j}).
\]

A geodesic intermediate state at layer `k` independently chooses how much of the positive demand and negative deficit has been resolved, with both totals exactly `k`. Therefore

\[
\boxed{
|I_k(0,v)|=[t^k]P_v(t)\,[t^k]N_v(t).
}
\]

This immediately yields the preceding radius-two examples:

- `(2,-2,0,0)` → `(1,1,1)`;
- `(1,1,-2,0)` → `(1,2,1)`;
- `(1,1,-1,-1)` → `(1,4,1)`.

The profile is palindromic under path reversal, but its interior values retain endpoint direction/type information that native distance erases.

## 5. P022-GM04 — simple-cubic comparison

For standard-axis adjacency on `Z^d`, let

\[
r=\sum_i|v_i|.
\]

The shortest-path count is the usual exact multinomial count

\[
\boxed{
g_{SC}(v)=\frac{r!}{\prod_i|v_i|!}.}

This gives P022 a like-for-like comparison: same notion of native graph distance, but different finite path multiplicity structure.

## 6. P022-GM05 — total shortest-path multiplicity over a shell

Distance shells contain endpoints with different multiplicity. Define the shell-total geodesic count

\[
T(r)=\sum_{d(0,v)=r}g(v).
\]

This is an integer total, not a probability or entropy by itself.

### `A_p`

Let `n=p+1`. Suppose an endpoint uses exactly `a>=1` positive coordinates and `b>=1` negative coordinates. Choose the two disjoint coordinate sets, then sum all multinomial path counts over positive compositions of `r` and negative compositions of `r`.

The sum of multinomial counts over positive compositions into `a` nonempty labels is the number of onto maps from `r` ordered time slots to `a` labels:

\[
a!\,S(r,a),
\]

where `S(r,a)` is a Stirling number of the second kind. Hence

\[
\boxed{
T_{A_p}(r)=
\sum_{\substack{a,b\ge1\\a+b\le p+1}}
\binom{p+1}{a}\binom{p+1-a}{b}
\,a!S(r,a)\,b!S(r,b)
}
\]

for `r>=1`, with `T_{A_p}(0)=1`.

### Simple cubic

If exactly `k` coordinate axes are active, choose the axes, choose their signs, and count onto axis-label sequences. Therefore

\[
\boxed{
T_{SC_d}(r)=
\sum_{k=1}^{\min(d,r)}
\binom dk 2^k k!S(r,k)
}
\]

for `r>=1`, with `T_{SC_d}(0)=1`.

These formulas are exact finite combinatorics. Historical/independent priority has not yet been audited.

This does **not** establish that FCC is physically preferred. It establishes a mathematically stronger discriminator than nearest-neighbor count or native-distance existence:
