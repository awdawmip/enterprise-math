## 1. Problem

Stage 06 gives the exact `k`-stage frontier by enumerating represented chains and Pareto-pruning their cost vectors. Direct path enumeration is conceptually correct but grows rapidly with depth.

The key question is whether already-compressed frontier state can be extended without reconstructing discarded paths.

Yes.

## 2. B28 — antichain convolution theorem

Let

\[
F^{(p)}_{xy}\subset\mathbb N^p
\]

be the exact `p`-stage frontier from `x` to `y`, and

\[
F^{(q)}_{yz}\subset\mathbb N^q
\]

the exact `q`-stage frontier from `y` to `z`.

For vectors `u in N^p` and `v in N^q`, write concatenation as

\[
u\Vert v\in\mathbb N^{p+q}.
\]

Define the frontier convolution

\[
\boxed{
(F^{(p)}\star F^{(q)})_{xz}
=
\operatorname{ParetoMin}
\bigcup_y
\{u\Vert v:u\in F^{(p)}_{xy},\ v\in F^{(q)}_{yz}\}.
}
\]

Then

\[
\boxed{
F^{(p+q)}_{xz}
=(F^{(p)}\star F^{(q)})_{xz}.
}
\]

### Proof

Every represented `(p+q)`-stage chain has a unique state `y` at the split point after stage `p`. Its prefix and suffix cost vectors belong to the full cost sets underlying `F^(p)_xy` and `F^(q)_yz`.

Each prefix cost is coordinatewise dominated by some Pareto-minimal prefix `u`; each suffix cost is dominated by some Pareto-minimal suffix `v`. Therefore the whole chain cost is dominated by `u||v`.

Conversely every frontier point `u` and `v` is itself realized by some represented prefix/suffix chain, so `u||v` is realized after concatenating at `y`.

Taking Pareto minima therefore yields exactly the `(p+q)`-stage frontier.

## 3. B29 — associativity of canonical frontier composition

Frontier convolution is associative at the canonical antichain level:

\[
\boxed{
(F^{(p)}\star F^{(q)})\star F^{(r)}
=
F^{(p)}\star(F^{(q)}\star F^{(r)}).
}
\]

Both sides equal the unique exact frontier `F^(p+q+r)` of represented chains of total depth `p+q+r`.

Therefore finite-depth support evolution admits an antichain-valued associative composition law.

This does not make arbitrary A4 relations into A3 relation states; it is a computation law inside the A3-generated metric-support subclass.

## 4. B30 — dominated-prefix erasure is future-safe for existence/budget semantics

Suppose two prefix cost vectors of the same depth satisfy

\[
u\preceq v.
\]

For every possible future suffix cost `w`,

\[
\boxed{u\Vert w\preceq v\Vert w.}
\]

Therefore any future budget vector that accepts a continuation of `v` also accepts the corresponding continuation of `u`.

Hence a dominated prefix can **never become necessary again** for any later existential staged-budget query.

This proves an online P023-compatible compression rule:

> after each stage, discard every dominated path-cost vector and retain only the Pareto antichain; future antichain convolution remains exact for all later existence/budget queries.

No hidden path identity needs to be restored for this language.

## 5. Dynamic recurrence

Let the one-stage matrix be

\[
F^{(1)}_{xy}=\{(\rho(x,y))\}.
\]

Then

\[
\boxed{
F^{(k+1)}=F^{(k)}\star F^{(1)}.
}
\]

So arbitrary finite-depth frontiers can be generated by repeated frontier convolution with Pareto pruning after every step.

The reference implementation is deliberately finite and exact. It is not yet an optimized multiobjective shortest-path engine.

## 6. B31 — negative boundary: Pareto compression loses witness multiplicity

The frontier preserves **existence under every budget**. It does not preserve how many represented intermediate witnesses satisfy a budget.

Consider equal capacities `10`.

### System A

Totals

\[
(0,9,20)
\]

represent normalized positions `0,0.9,2`.

For endpoints `0,2`, the intermediate costs are

\[
(0,2),\quad(1,2),\quad(2,0),
\]

so the Pareto frontier is

\[
F=\{(0,2),(2,0)\}.
\]

At budget `(2,2)`, there are three represented witnesses.

### System B

Totals

\[
(0,9,11,20)
\]

add a second internal state at normalized position `1.1`.

The additional cost is

\[
(2,1),
\]

which is dominated by `(2,0)`. Therefore the Pareto frontier remains exactly

\[
F=\{(0,2),(2,0)\}.
\]

But budget `(2,2)` now has four represented witnesses.

Thus two systems can have identical staged existence frontiers but different witness multiplicities:

\[
\boxed{
F\text{ is not future-safe for witness-count / multiplicity languages.}
}
\]

If the declared future language includes A4 witness spectra, overlap counts, or any quantity depending on the number/identity of common targets, additional state is required.

## 7. Compression hierarchy sharpened

The legal state now depends on the exact observable language:

### Existence-only staged budgets

Pareto antichain is sufficient and dominated paths may be erased online.

### Labeled witness identity

Retain enough witness identity to answer the requested identity-sensitive operations.

### Witness multiplicity / spectra

Retain count-enriched information; plain Pareto frontier is insufficient by B31.

This matches the earlier A4 distinction between relation truth, witness count `W_k`, and group/event spectra.

## 8. Connection to E001

E001 engineering often cares first about whether a collision/common target exists, while later diagnostics may count candidate witnesses or materialized target memberships.

B30/B31 gives a precise boundary:

- an existence-only broad phase may safely Pareto-prune dominated budget paths;
- a diagnostic that measures witness multiplicity must not reuse that pruned state as if it were count-complete.

## 9. Connection to P023 and A3 piecewise refinement

B30 is a positive future-safety theorem because the future language is explicitly fixed and dominance is preserved by every allowed continuation operation.

This is different from arbitrary partition refinement. The A3 piecewise result shows that adding uncontrolled detail can expose branch effects without exposing the selector, breaking exactness.

So the project-wide lesson is not “prune more” or “refine more”; it is:

\[
\boxed{
\text{identify the future algebra, then prove the state transform is a congruence for it.}
}
\]
