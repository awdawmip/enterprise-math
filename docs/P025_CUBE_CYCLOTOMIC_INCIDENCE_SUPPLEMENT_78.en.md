## 1. A congruence signature has an exact finite fiber bound

Stage 77 shows that if the repeated cyclotomic part is supported on `k` distinct primes with full prime-power modulus

\[
M=\prod_{i=1}^k r_i^{e_i},
\qquad e_i\ge2,
\]

then the labelled prime ratio `p/q` is restricted to exactly

\[
2^k
\]

CRT root-of-unity classes modulo `M`.

Fix a prime-base height

\[
1\le p,q\le P.
\]

Ignore primality and the cyclotomic equation for the moment; count all labelled integer pairs satisfying only the congruence signature. This gives an unconditional envelope.

## 2. P025-T152 — exact integer-pair envelope

Fix `q`. For one allowed ratio root `zeta`, the condition

\[
p\equiv\zeta q\pmod M
\]

selects one residue class modulo `M`. Among `1<=p<=P`, one residue class contains at most

\[
\boxed{
\left\lfloor\frac{P-1}{M}\right\rfloor+1
}
\]

integers.

There are at most `P` values of `q` and exactly `2^k` allowed root classes. Therefore

\[
\boxed{
N(P;M,k)
\le
2^k P
\left(
\left\lfloor\frac{P-1}{M}\right\rfloor+1
\right).
}
\]

The ambient labelled integer-pair universe has size `P^2`, so one may take the minimum with `P^2`.

Primality of `p,q`, the inequality `p>q`, and the original condition `M|Phi_3/Phi_6` can only reduce the count.

## 3. Two regimes

### `M<=P`

The envelope is

\[
\boxed{
N(P;M,k)
=O\!\left(2^k\left(\frac{P^2}{M}+P\right)\right).
}
\]

Thus the leading ratio-space density is controlled by approximately

\[
\frac{2^k}{M}.
\]

### `M>P`

Each root class contributes at most one `p` for each `q`, so

\[
\boxed{N(P;M,k)\le2^kP.}
\]

The signature has collapsed the quadratic pair universe to a one-dimensional finite envelope before primality is used.

## 4. P025-C23 — each repeated cyclotomic prime has a universal compression cost

Stage 76 proves every repeated cyclotomic prime satisfies

\[
r_i\equiv1\pmod6,
\]

so

\[
r_i\ge7.
\]

Because `e_i>=2`,

\[
\boxed{M\ge49^k.}
\]

There are only `2^k` CRT root choices. Hence the modulus-to-choice compression factor obeys

\[
\boxed{
\frac{M}{2^k}
\ge
\left(\frac{49}{2}\right)^k.
}
\]

So every additional independent repeated cyclotomic prime costs at least one factor `49/2` in the labelled ratio-state space, before using any distribution theorem for primes.

This is a finite-state statement, not an asymptotic prime theorem.

## 6. Precision interpretation

Stage 77 supplied a finite quotient label. Stage 78 attaches an exact upper bound on the size of its fiber inside a finite universe.

Thus the congruence state carries two distinct resources:

1. **semantic precision:** which repeated cyclotomic divisibility pattern is retained;
2. **incidence precision:** how much of the prime-base search universe remains compatible with that label.

The root-choice count `2^k` measures ambiguity; the modulus `M` measures exclusion. Their ratio is the natural finite compression coordinate for this future search task.

This is closely analogous to the earlier P025 distinction between quotient-state complexity and incidence sparsity, but now at a deterministic congruence level rather than an imported density theorem.
