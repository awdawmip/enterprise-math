## 1. Why the scalar witness radius is still too coarse

Supplement 01 defined the first usable witness radius

\[
\mu(a,b,c)=\min\{\|x\|_\infty:x\in T(a,b)\setminus T^\circ(a,b)\}.
\]

This answers one future question:

> how far must the integer witness search open before any non-degenerate relation-adapted certificate appears?

It does **not** measure how tightly the witness absorbs the multiplicity information forgotten by radical collapse.

The classical Mason–Stothers proof and Pasten's arithmetic-derivative construction both use more than mere non-degeneracy: a repeated-factor residual is absorbed into a common Wronskian. This suggests a second exact integer cost on the same witness.

The purpose of this supplement is to test that richer future language before promoting any scalar notion of witness precision.

## 2. Arithmetic derivative and canonically scaled Wronskian

Fix a primitive positive integer triple

\[
a+b=c,\qquad \gcd(a,b)=1,
\]

with prime-coordinate set

\[
S=\operatorname{supp}(abc).
\]

For an integer coordinate vector

\[
x=(x_p)_{p\in S},
\]

Pasten's finite-support arithmetic derivative is

\[
d_x(n)
=
 n\sum_{p\mid n}\frac{v_p(n)}p x_p.
\]

The relation-adapted witness lattice is

\[
T(a,b)=\{x:d_x(a)+d_x(b)=d_x(c)\}.
\]

Define the actual arithmetic Wronskian

\[
\boxed{
W_x(a,b)=a\,d_x(b)-b\,d_x(a).
}
\]

Unlike the primitive normal used only to recover the degeneracy hyperplane, this Wronskian has a **canonical arithmetic scale**. That scale must not be divided away when the future language observes `|W|`.

Let

\[
M(a,b,c)
=
 m(a)m(b)m(c),
\qquad
m(n)=\frac{n}{\operatorname{rad}(n)}.
\]

## 3. P025-T11 — every non-degenerate Wronskian absorbs the full multiplicity residual

For every additive witness `x in T(a,b)`,

\[
\boxed{
M(a,b,c)\mid W_x(a,b).
}
\]

Consequently, for every non-degenerate witness,

\[
\boxed{
\eta(x)
=
\frac{|W_x(a,b)|}{M(a,b,c)}
\in\mathbb N_{>0}.
}
\]

We call `eta(x)` the **absorption redundancy** of the witness.

### Proof

For every positive integer `n`,

\[
m(n)\mid d_x(n).
\]

Indeed, each term

\[
\frac{n}{p}v_p(n)x_p
\]

contains every prime power of `m(n)=prod p^(v_p(n)-1)`.

Also `m(n)|n`. Hence `m(a)` and `m(b)` both divide

\[
W_x(a,b)=a d_x(b)-b d_x(a).
\]

Because `x` is additive for `a+b=c`,

\[
d_x(c)=d_x(a)+d_x(b).
\]

Therefore

\[
W_x(a,c)
=a d_x(c)-c d_x(a)
=a d_x(b)-b d_x(a)
=W_x(a,b),
\]

so `m(c)` divides the same Wronskian as well.

The primitive abc condition makes `a,b,c` pairwise coprime, hence `m(a),m(b),m(c)` are pairwise coprime. Their product therefore divides `W_x(a,b)`. ∎

### Meaning

`eta=1` means the Wronskian carries exactly one unit of the compulsory residual scale. Larger `eta` means that the certificate carries extra arithmetic scale beyond the residual that must be absorbed.

This is not an error term and not a floating-point quality score. It is an exact positive integer quotient.

## 4. P025-T12 — the unavoidable absorption floor is a determinantal divisor

Let

\[
\widehat\alpha\in\mathbb Z^S
\]

be the primitive additive normal from Supplement 01, so

\[
T=\ker_{\mathbb Z}\widehat\alpha.
\]

Let

\[
\beta_{\rm raw}\in\mathbb Z^S
\]

be the **un-normalized** Wronskian row satisfying

\[
W_x(a,b)=\beta_{\rm raw}\cdot x.
\]

Define the scaled exterior signature

\[
\boxed{
\Omega
=
\widehat\alpha\wedge\beta_{\rm raw}
\in\bigwedge^2\mathbb Z^S.
}
\]

Let `cont(Omega)` be the gcd of the absolute values of all Plücker coordinates of `Omega`.

Then

\[
\boxed{
\beta_{\rm raw}(T)
=\operatorname{cont}(\Omega)\,\mathbb Z.
}
\]

In particular the minimum possible positive absorption redundancy is

\[
\boxed{
\eta_{\min}(a,b,c)
=
\frac{\operatorname{cont}(\Omega)}{M(a,b,c)}.
}
\]

### Proof

Because `alpha_hat` is primitive, an integer unimodular change of coordinates sends it to the first coordinate row `e_1`. Under that change,

\[
T\cong\{(0,y_2,\ldots,y_s):y_i\in\mathbb Z\}.
\]

The Wronskian image on `T` is then the subgroup generated by the remaining transformed coefficients of `beta_raw`; hence it is `d Z`, where `d` is their gcd.

The gcd of all `2x2` minors of the two-row matrix `[alpha_hat; beta_raw]` is invariant under unimodular column operations. After sending `alpha_hat` to `e_1`, those minors are exactly the remaining Wronskian coefficients, up to sign. The same gcd is therefore

\[
d=\operatorname{cont}(\widehat\alpha\wedge\beta_{\rm raw}).
\]

By P025-T11, every value in this image is divisible by `M`; since `d` generates the image, `M|d`. Dividing by `M` gives the claimed minimum positive `eta`. ∎

### Prior-art boundary

This is standard Smith-normal-form / determinantal-divisor / exterior-algebra mathematics applied to the Pasten witness lattice. P025 does not claim those algebraic facts as new.

The project-specific pressure-test point is that the same exterior object used projectively in Supplement 02 now has a **content** that becomes observable once the future language asks about Wronskian magnitude.

## 5. N03 — projective witness geometry and absorption-aware geometry are different precision tasks

Supplement 02 used

\[
\left(S,\widehat\alpha,
[\widehat\alpha\wedge\beta]
\right)
\]

to recover the saturated flag

\[
T^\circ\subset T.
\]

For that task, scaling the second row is irrelevant: it does not change the degeneracy hyperplane inside `T`.

The absorption observable is richer. Replacing a Wronskian row by

\[
\beta\mapsto\lambda\beta+\mu\widehat\alpha
\]

preserves the same hyperplane in `T`, but on `T` it changes Wronskian magnitudes by `|lambda|`.

Therefore:

\[
\boxed{
\text{projective flag precision is sufficient for witness geometry, but not generically for Wronskian-scale cost.}
}
\]

For the absorption language one must retain the **scaled** restriction of the Wronskian functional, equivalently the content-bearing exterior signature `Omega` up to global sign, together with whatever state is needed to recover `M`.

This is another direct instance of the P023 rule:

> a representation that is exact for one future language can become too coarse when the future language is enriched.

## 6. P025-D02 — two-axis witness cost

For every non-degenerate witness define

\[
\boxed{
C(x)=
\left(
\|x\|_\infty,
\eta(x)
\right)
\in\mathbb N_{>0}^2.
}
\]

The first coordinate is geometric/search cost in the prime-coordinate lattice. The second is arithmetic absorption redundancy.

Order these cost pairs componentwise:

\[
(r,e)\preceq(r',e')
\iff
r\le r'\text{ and }e\le e'.
\]

Let

\[
\boxed{
\mathcal P(a,b,c)
=
\operatorname{Min}_{\preceq}
\{C(x):x\in T\setminus T^\circ\}
}
\]

be the **absorption-aware Pareto witness frontier**.

This is not a claim that Pareto order is new mathematics. A3/A4 work already uses Pareto antichains for weaker future languages, and finite-antichain compression is standard order theory. P025 consumes that structure here instead of creating a parallel mother theory.

## 7. P025-T13 — the full Pareto frontier is finite and complete for bounded two-cost certificate queries

Consider the future query language

\[
H_{K,E}(a,b,c)
=
1_{\exists x\in T\setminus T^\circ:
\|x\|_\infty\le K,\ \eta(x)\le E}.
\]

Then:

1. `P(a,b,c)` is finite;
2. for every `K,E`,
   \[
   \boxed{
   H_{K,E}=1
   \iff
   \exists(r,e)\in\mathcal P
   \text{ with }r\le K,e\le E;
   }
   \]
3. the truth values of all rectangle queries `H_(K,E)` determine the Pareto frontier uniquely.

### Proof

The set of cost pairs lies in `N_{>0}^2`. If Pareto-minimal points are ordered by increasing first coordinate, their second coordinates must strictly decrease; a strictly decreasing sequence of positive integers is finite. Hence the frontier is finite. This is the two-dimensional case of Dickson's lemma.

A feasible witness is dominated by some Pareto-minimal feasible cost, so rectangle feasibility is determined by the frontier. Conversely, the set of threshold pairs `(K,E)` for which the query is true is the upward closure of the witness cost set; its minimal elements are exactly `P`. ∎

### Architectural meaning

An infinite lattice of candidate derivations can therefore have a finite exact semantic summary for this declared bounded-cost future language.

The summary is not the entire witness set and is not a single scalar. It is a finite antichain of task-relevant cost tradeoffs.

## 8. P025-N04 — scalar `mu` loses real witness tradeoffs

### Example A: `2+3=5`

The additive relation on prime coordinates `(2,3,5)` is

\[
x_2+x_3-x_5=0,
\]

and

\[
W_x=2x_3-3x_2.
\]

Here `M=1` and `eta_min=1`.

There is a radius-one witness, for example

\[
x=(0,1,1),
\qquad
(\|x\|_\infty,\eta)=(1,2).
\]

But the first perfectly absorbing witness can be taken as

\[
x=(1,1,2),
\qquad
(\|x\|_\infty,\eta)=(2,1).
\]

Hence

\[
\boxed{
\mathcal P(2,3,5)=\{(1,2),(2,1)\}.
}
\]

The scalar radius says only `mu=1`; it cannot answer whether one can simultaneously require `eta<=1`.

### Example B: `2+7=9`

Exact enumeration together with the determinantal absorption floor gives

\[
\boxed{
\mathcal P(2,7,9)
=
\{(1,3),(4,2),(5,1)\}.
}
\]

So the cost tradeoff can contain more than two levels.

### Example C: `5+7=12`

Here

\[
M=2,
\qquad
\eta_{\min}=2,
\]

and

\[
\boxed{
\mathcal P(5,7,12)
=
\{(1,6),(2,2)\}.
}
\]

Thus even unlimited search cannot reach `eta=1`: the relation lattice itself imposes an irreducible absorption overhead.

This separates two phenomena that scalar witness radius conflates:

- **search hardness** — how far one must move in the lattice;
- **absorption obstruction** — how tightly the arithmetic functional can match the compulsory multiplicity residual.

## 9. Constructive finite certification of the infinite frontier

The executable reference does not enumerate the infinite witness lattice.

It first computes

\[
\eta_{\min}
=
\frac{\operatorname{cont}(\Omega)}M
\]

exactly from the scaled exterior signature. It then expands finite `L_infinity` balls until a witness attaining `eta_min` is found.

At that moment the Pareto frontier is complete: every unseen witness has strictly larger norm and has `eta>=eta_min`, so it is dominated by an already-seen absorption-optimal point or cannot create a new lower-left corner.

This gives a finite termination certificate for the small-support reference oracle.

## 10. P025-T14 — Mason's polynomial margin splits into absorption slack plus capacity slack

The same two-stage structure is visible exactly in the classical polynomial proof.

Let

\[
D
=
\deg a+\deg b+\deg c
-
\deg\operatorname{rad}(abc)
\]

be the degree of the multiplicity residual `abc/rad(abc)`, let

\[
w=\deg W(a,b),
\]

and let

\[
C=\deg a+\deg b-1.
\]

The classical proof gives

\[
D\le w\le C.
\]

For the bound on `c`, the exact theorem margin is

\[
\deg\operatorname{rad}(abc)-\deg c-1
=C-D.
\]

Insert the actual witness degree `w`:

\[
\boxed{
\deg\operatorname{rad}(abc)-\deg c-1
=
\underbrace{(w-D)}_{\text{absorption slack}}
+
\underbrace{(C-w)}_{\text{capacity slack}}.
}
\]

Both terms are non-negative.

This identity is elementary algebra extracted from the classical Wronskian proof; it is not claimed as a new Mason–Stothers refinement.

### Why the split matters to P025

It makes the proof bottleneck explicit:

1. **residual -> witness:** how much larger is the witness than the compulsory repeated-factor residual?
2. **witness -> capacity:** how much of the available Wronskian capacity is actually used?

In the integer route, `eta=|W|/M` is a multiplicative analogue of the first question, while the lattice norm/Geometry-of-Numbers bound controls the second side. Pasten's work already shows that sufficiently strong improvement of the witness-size side is equivalent to abc; P025 does not claim that bridge as new.

## 11. Consequence for the Enterprise Math precision architecture

The P025 progression is now:

\[
\text{radical support}
\to
\text{multiplicity residual}
\to
\text{relation-conditioned witness flag}
\to
\text{scalar witness radius}\ \mu
\to
\boxed{\text{multi-cost Pareto witness precision}}.
\]

The key correction is:

\[
\boxed{
\text{there is no reason for certificate precision to be intrinsically one-dimensional.}
}
\]

Which witness distinctions must survive depends on the declared certificate language:

- only non-degenerate existence -> flag geometry may suffice;
- only radius thresholds -> `tau_K(mu)` may suffice;
- radius + absorption thresholds -> a Pareto antichain is the exact semantic shadow;
- actual Wronskian values -> the scaled functional must be retained more fully.

This is precisely the task-relative precision principle, now obtained from a classical number-theoretic proof mechanism rather than imposed as an architectural preference.
