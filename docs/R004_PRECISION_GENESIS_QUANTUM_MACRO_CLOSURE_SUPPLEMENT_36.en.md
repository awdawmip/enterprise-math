# R004 precision genesis — Supplement 36: p-adic precision-native covering ISA

Status: `PROVED_WIP + EXECUTABLE_REFERENCE + PRECISION-RESOURCE SPECIALIZATION`
Parent: `R004_PRECISION_GENESIS_QUANTUM_MACRO_CLOSURE_SUPPLEMENT_35.en.md`

Supplement 35 identified the full additive finite-field primitive-ISA problem with linear covering codes. This supplement lifts the same compiler question to the precision-native ring `R_K=Z/p^K Z` and asks how the minimum primitive storage changes as K increases.

General linear-code theory over finite chain rings and projective Hjelmslev geometry are prior mathematics. The project-local result is the exact precision/resource interpretation.

## 1. Ring null-program model

Let `H:R_K^s -> R_K^r` be a surjective R_K-linear primitive-action map. The null-program module is `C=ker H`. Because `R_K^r` is free/projective, the sequence splits and C is a free direct summand of rank `s-r`.

For a semantic action y, its primitive readout depth is the minimum Hamming support of a coefficient word e with `H e=y`, equivalently the Hamming distance of a representative to the coset code C. The worst readout depth is therefore the Hamming covering radius of this R_K-linear null-program code. At K=1 this reduces exactly to Supplement 35.

## 2. Precision monotonicity

Define `L_(p,K)(r,D)` as the minimum s for a surjective R_K-linear ISA with worst readout depth at most D.

Reduction modulo `p^K` maps every `(K+1)`-precision covering ISA to a K-precision covering ISA of the same length and no larger support words. Therefore

`L_(p,K)(r,D) <= L_(p,K+1)(r,D)`.

Higher p-adic precision never makes a fixed-depth primitive ISA cheaper.

## 3. Ring Hamming-volume lower bound

Put `q=p^K`. The number of coefficient words of support at most D is

`V_(p,K)(s,D)=sum_(j=0)^D binom(s,j)(q-1)^j`.

Since there are `q^r` semantic actions, `V_(p,K)(s,D)>=q^r` is necessary.

For fixed `D<r`, the elementary bound `V <= (D+1)s^D q^D` gives the purely integer growth law

`(D+1)s^D >= p^(K(r-D))`.

Thus fixed readout depth below r forces primitive storage to grow exponentially with the precision cap K.

## 4. Exact one-step storage

Depth one means every nonzero semantic vector lies in the cyclic submodule generated by one primitive column.

Primitive vectors of `R_K^r` number `p^(Kr)-p^((K-1)r)`. Each free rank-one line contains `p^K-p^(K-1)` primitive generators, and primitive vectors lie on unique free rank-one lines. Hence

`L_(p,K)(r,1)=p^((K-1)(r-1))*(p^r-1)/(p-1)`.

Therefore

`L_(p,K+1)(r,1)=p^(r-1)L_(p,K)(r,1)`.

Every extra p-adic precision layer multiplies one-step primitive storage by exactly `p^(r-1)`.

## 5. Exact one-null-program regime

Set `s=r+1`, so the null-program module has rank one. The optimum rank-one null code has a generator whose every coordinate is a unit; by coordinate unit scaling it is the repetition line `<(1,...,1)>`.

Let `q=p^K`, `n=r+1`. Choosing the repetition scalar equal to the most frequent coordinate value gives at least `ceil(n/q)` matches, and balanced words attain this bound. Therefore

`D_one-null=n-ceil(n/q)`.

The depth gain relative to a bare basis is `ceil((r+1)/p^K)-1`. Once `p^K>=r+1`, one extra null instruction gives zero improvement in worst-case readout depth.

A redundancy relation useful at low precision can therefore become execution-useless after precision refinement.

## 6. Minimal phase-change example

Take p=2, semantic rank r=3 and target depth D=2.

At K=1, four primitives suffice: the binary one-null repetition code has radius 2.

At K=2 (`R=Z/4`), every s=4 ISA has one-dimensional null module and the theorem above gives radius at least 3. An identity-normalized exhaustive search checked all 1,953 s=5 candidate extra-column pairs and none cover `R^3` at depth 2.

The six-column ISA

`(1,0,0), (0,1,0), (0,0,1), (0,1,1), (0,1,2), (1,1,3)`

does cover every element of `(Z/4)^3` with at most two primitive instructions.

Hence `L_(2,1)(3,2)=4` and `L_(2,2)(3,2)=6` in the declared ring-linear ISA model.

Precision refinement changes the minimum primitive storage itself, not only the bit depth of existing primitives.

## 7. Algebra type matters

Alphabet cardinality `p^K` alone does not determine this compiler. `Z/p^K` is a finite chain ring, not the finite field of the same cardinality when K>1. Projective directions, null modules and admissible scalar actions depend on the declared algebra.

Thus the resource law is typed:

`precision + algebra + future readout depth -> primitive storage requirement`.

## 8. Prior-art boundary

Linear codes over finite chain rings and projective Hjelmslev geometry are established mathematics. Covering radii for modular-ring codes are also prior research, though different metrics are often used.

R004 does not claim ring coding theory. Its under-test addition is the precision-native primitive-ISA reduction, the exact D=1 / one-null specializations, and the interpretation of K as a resource-changing precision layer.

## 9. Next frontier

The next problem is precision lifting: given an ISA valid at K, determine which primitive columns can remain at K+1, which directions must be born, whether minimum ISAs can be nested across precision layers, and when anticipatory storage is required. This is the precision-lift analogue of temporal instruction retirement.
