# P011 补充 —— 经典熵作为整数碰撞谱的派生变换

状态：`PROVED COMPARISON`  
父问题：`P011`

## 1. 目的

P011 刻意在引入对数或概率之前，先构造纯整数不可逆性观察量。

这并不意味着既有熵概念不重要，而是意味着它们应该在有限纤维结构已经明确之后，作为**派生比较量**进入。

本文对有限、初始历史等权的确定性映射给出精确翻译。

## 2. 等权历史概率模型

设

\[
F:X\to Y,
\qquad |X|=N,
\]

并在历史上取均匀分布

\[
\Pr[X=x]=\frac1N.
\]

对可达输出 \(y\)，pushforward 概率为

\[
p_y
=
\frac{m_F(y)}N,
\]

其中

\[
m_F(y)=|F^{-1}(\{y\})|.
\]

所以普通输出概率分布是在整数纤维大小已经确定之后才得到的。

## 3. P011-E01 —— 二阶碰撞概率是 \(J_2\) 的仿射函数

状态：`PROVED`

独立均匀抽取两条历史，它们拥有相同 \(F\)-像的概率是

\[
P_{\rm same}
=
\sum_y p_y^2.
\]

由于

\[
\sum_y m_F(y)^2
=
N+2J_2(F),
\]

所以

\[
\boxed{
P_{\rm same}
=
\frac{N+2J_2(F)}{N^2}.
}
\]

因此，P011 的原始整数历史对碰撞数量，在归一化成有理数之前，已经完整携带通常 collision probability 的二阶矩信息。

## 4. P011-E02 —— Rényi-2 熵是 \(J_2\) 的对数变换

状态：`PROVED COMPARISON`

输出分布的二阶 Rényi entropy 为

\[
H_2(F)
=
-\log\sum_y p_y^2.
\]

利用 P011-E01，

\[
\boxed{
H_2(F)
=
-\log\left(\frac{N+2J_2(F)}{N^2}\right).
}
\]

因为确定性后复合下 \(J_2\) 前向单调不减，所以可达输出标签的 \(H_2\) 单调不增。

等价地，派生量

\[
L_2(F)=\log N-H_2(F)
\]

单调不减，可以解释为相对于“\(N\) 条历史全部可区分”的 Rényi-2 型信息损失。

进取数论**不**把 \(H_2\) 或 \(L_2\) 当作基本量；第一层仍然是 \(N\) 与整数碰撞数量。

## 5. P011-E03 —— Shannon entropy 由纤维大小分布决定

状态：`PROVED COMPARISON`

输出 Shannon entropy 为

\[
H_1(F)
=
-\sum_y p_y\log p_y.
\]

代入 \(p_y=m_y/N\)，得

\[
H_1(F)
=
\log N
-
\frac1N\sum_y m_F(y)\log m_F(y).
\]

因此

\[
\boxed{
\log N-H_1(F)
=
\frac1N\sum_y m_F(y)\log m_F(y).
}
\]

这是作用在精确整数纤维大小多重集合上的一个实值/对数泛函。

完整 P011 碰撞谱可以通过整数二项反演恢复该多重集合，所以一旦选择对数约定，完整整数谱也就精确决定 \(H_1\)。

## 6. P011-E04 —— 完整整数谱决定所有对输出概率多重集合对称的泛函

状态：`PROVED`

P011-T05 可以从整数碰撞谱 \((J_1,\ldots,J_N)\) 重建

\[
c_r(F)=\#\{y:m_F(y)=r\}.
\]

因此，它能够重建概率多重集合

\[
\{p_y\}_y
=
\left\{\frac{m_F(y)}N\right\}_y.
\]

所以，任何只依赖输出概率多重集合的量，都被整数谱决定，包括：

- Shannon entropy；
- 有限阶 Rényi entropy；
- 整数 \(q\ge2\) 的 power sums \(\sum p_y^q\)；
- collision probabilities；
- 任何纤维大小频率的对称统计量。

这并不意味着所有这些量都能由某一个低阶 \(J_k\) 单独表示。真正完备的是**完整谱**。

## 7. 为什么单独 \(J_2\) 不完备

不同纤维大小多重集合可以拥有相同的历史对碰撞数量。

在足够大的 \(N\) 上，可以存在不同整数划分，使

\[
\sum_y\binom{m_y}2
\]

相同，但高阶 \(J_k\) 不同。

所以二阶碰撞是很好的标量探测器，却不能替代整个碰撞层级。

高阶系数不是装饰，它们正是二项反演能够完整重建的原因。

## 8. 多对一前向动力学下的方向

对确定性后复合 \(G\circ F\)：

- 所有 \(J_k\)（\(k\ge2\)）单调不减；
- collision probability \(\sum p_y^2\) 单调不减；
- Rényi-2 输出 entropy 单调不增；
- Shannon 输出 entropy 也单调不增，因为均匀源的确定性 coarse-graining 不会增加输出 Shannon entropy。

在进取数论的表达顺序中，整数命题是结构上更前的一层：先有划分块合并，再在其上附加概率模型和对数，就得到概率/熵单调性。

## 9. 与 preimage/folding entropy 文献的关系

进取数论已经记录利用前像结构研究 entropy 的成熟前人工作：

- `SRC-NITECKI-PRZYTYCKI-1999`；
- `SRC-CHENG-NEWHOUSE-2005`；
- `SRC-RUELLE-1996`；
- `SRC-WU-ZHU-2021`。

这些文献说明“非可逆性/前像结构与熵之间存在联系”早已有系统研究。P011 不能把这种联系本身宣称为新发现。

项目特有的是方法顺序：

1. 先记录精确有限纤维；
2. 先把整数碰撞数量 / 碰撞多项式作为第一层观察量；
3. 只有在需要比较时，才加入归一化概率和对数熵。

## 10. 解释边界

这里没有证明“进取数论坍缩产生热力学熵”。

若要把整数碰撞谱连接到物理热力学，还必须额外给出：

- 物理 ensemble 解释；
- 能量/Hamiltonian 结构；
- 时间/过程模型；
- 适合该模型的热力学 entropy 或 entropy production 定义；
- 实验比较。

因此，P011 支持的是 entropy **comparison**，而不是历史合流与热力学熵之间的恒等定理。
