# Causal Continuation Kernel — Minimal Sufficient Witness State for Coupled Fiber Composition

Status: `CROSS-ROUTE RESEARCH WIP / EXACT FINITE THEOREM + EXECUTABLE REFERENCE`

Ownership: A3 relation-quotient specialization. The general future-safe equivalence mother theorem remains owned by A2/P023.

## 1. Problem

For one coupling layer the anonymous multiplicity

\[
\kappa(r)=\#\{\text{joint witnesses above coarse/marginal class }r\}
\]

fully records the current forgetting-fiber size. In multi-stage composition, however, two witnesses in the same `r` may have different future continuations. Hence anonymous `kappa(r)` is generally too coarse, while permanent raw witness identity is generally too fine.

## 2. Continuation type

Fix the actually allowed future operation/observation language from the current stage onward. For a current witness `w`, let its remaining future signature be

\[
\Sigma^+(w).
\]

Define

\[
\boxed{w\sim_+w'\iff\Sigma^+(w)=\Sigma^+(w')}
\]

and denote the equivalence class by `tau(w)`. `tau` is not an externally declared type; it is generated by future indistinguishability.

## 3. Typed continuation kernel

With current coarse class `r(w)`, define

\[
\boxed{\kappa(r,\tau)=\#\{w:r(w)=r,\ \tau(w)=\tau\}.}
\]

The anonymous kernel is merely

\[
\boxed{\kappa(r)=\sum_\tau\kappa(r,\tau).}
\]

Witness identity may be forgotten inside one `(r,tau)` class because those witnesses have identical remaining futures.

## 4. Exact composition

Suppose one witness of continuation type `tau` has `p(tau,z)` next-stage continuation witnesses to target `z`. Then

\[
\boxed{N(r,z)=\sum_\tau\kappa(r,\tau)p(\tau,z).}
\]

This is direct witness counting. Ordinary sum-product matrix multiplication appears only after coordinates are assigned to continuation types.

## 5. When anonymous multiplicity is enough

Keeping only `kappa(r)` plus one induced future profile for each `r` is exact iff

\[
\boxed{\#\{\tau:\kappa(r,\tau)>0\}=1\quad\forall r.}
\]

If the unique type in `r` is `tau_r`, then

\[
N(r,z)=\kappa(r)p(\tau_r,z).
\]

The profile `p(tau_r,z)` is stored once. Summing the same profile over all fine witnesses and then multiplying by `kappa(r)` would count the coarse-fiber size twice.

## 6. Minimal counterexample

Two systems may both have `kappa(r)=2` while one has two witnesses of type `tau_a` and the other has one `tau_a` and one `tau_b`. If `tau_a` continues only to `z0` and `tau_b` only to `z1`, their next futures differ although anonymous multiplicity is identical.

Conversely, four raw witnesses split as two `tau_a` and two `tau_b` need only the inventory

\[
\kappa(r,\tau_a)=2,\qquad\kappa(r,\tau_b)=2,
\]

not four persistent identities.

Thus in general

\[
\boxed{\text{anonymous multiplicity}<\text{continuation-type multiplicity}<\text{raw witness identity}}
\]

in information granularity.

## 7. Relation to P021/P023

P021 witness necessity becomes sharper: distinguish witnesses only while some allowed future can still distinguish them. P023 provides the general future-safe quotient criterion; this note is its finite coupled-fiber counting realization.

For finite deterministic systems the continuation types can be compiled automatically by partition refinement: start from the current observation partition and repeatedly refine a state by its current observation together with the classes reached by every declared one-step action. The stable partition is the coarsest future-safe continuation partition.

## 8. Boundary

This is an exact finite deterministic / finite-multiplicity result. It does not automatically establish corresponding statements for infinite fibers, continuous measures, quantum amplitudes, or undeclared universal future languages.
