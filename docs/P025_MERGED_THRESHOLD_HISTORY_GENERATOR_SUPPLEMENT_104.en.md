## 1. A second-order tensor can still have a smaller generator

Stage 102 represents finite-history area responses using

\[
(A;L_i;R_j;C_{ij}).
\]

Stage 103 compresses the mixed block `C` by Ferrers geometry.

Stage 104 observes a stronger fact: `R_j` and the entire corner column `C_{*,j}` are generated by the **same scalar threshold order**.

They should therefore not be treated as independent response coordinates.

## 2. P025-D47 — labelled merged threshold order

Merge the existing thresholds

\[
T_1<\cdots<T_s
\]

and candidate thresholds

\[
U_1<\cdots<U_a
\]

into one strictly ordered labelled sequence

\[
\boxed{H_1<\cdots<H_{s+a}.}
\]

Each `H_l` remembers whether it came from the old-threshold family or the candidate-threshold family, together with its family index.

For a future node value `v_j`, define its merged rank

\[
\boxed{
Q_j:=\#\{\ell:H_\ell\le v_j\}.
}
\]

## 3. P025-T236 — one merged rank generates an entire Stage102 future column

The active merged thresholds at `v_j` are exactly the first `Q_j` labels.

Therefore:

- the number of **old** labels among the first `Q_j` is exactly `R_j`;
- the set of **candidate** labels among the first `Q_j` is exactly the set of candidate thresholds crossed by `v_j`;
- hence the candidate membership vector is exactly the full corner column `C_{*,j}`.

Thus

\[
\boxed{
Q_j
\Longleftrightarrow
(R_j,C_{*,j})
}
\]

when the labelled merged threshold order is part of the declared schema.

No information is lost.

## 4. P025-D48 — merged history generator signature

Keep the candidate old-block spans

\[
L_i=\#\{r:\rho_r\ge U_i\}
\]

from Stage100, but replace the Stage102 future tuple `(R_j,C_{*,j})` by merged ranks `(Q_j)`.

Define

\[
\boxed{
\Gamma
=
\left(
A;
(L_i)_{i=1}^{a};
(Q_j)_{j=1}^{b}
\mid
\text{labelled merged threshold order}
\right).
}
\]

This is a generator representation of the full second-order history response.

## 5. P025-T237 — direct history-area evaluation from the generator

Let `I` be the selected candidate-threshold subset and let `t` future nodes have been appended.

Start with

\[
A+\sum_{i\in I}L_i.
\]

For each future node `v_j`, inspect the first `Q_j` merged labels:

- every old-threshold label contributes one active cell;
- a candidate label contributes one active cell iff its family index lies in `I`.

Summing these contributions for `j<=t` gives the exact final area.

Therefore `Gamma` predicts every history that Stage102 predicts, without storing an explicit mixed corner matrix.

## 6. Equivalence to the expanded second-order signature

The executable compiler verifies both directions:

\[
\boxed{
\Gamma
\Longrightarrow
(A;L_i;R_j;C_{ij})
}
\]

by labelled-prefix decoding, and

\[
\boxed{
(A;L_i;R_j;C_{ij})
\Longrightarrow
Q_j=R_j+\sum_i C_{ij}.
}
\]

So the merged-rank representation is an exact generator coordinate system for the same finite-history area future language.

This is an instance of the generator-versus-expanded-response distinction already encountered in earlier P025 precision work.

## 7. P025-T238 — adaptive future generator state count

Let the old orbit maximum be

\[
M:=\rho_h.
\]

Suppose `q_0` merged thresholds already satisfy

\[
H_\ell\le M.
\]

These are forced active at every future node.

Let

\[
w:=(s+a)-q_0
\]

be the number of unresolved merged thresholds.

The residual future ranks

\[
Q_j-q_0
\]

form a weakly increasing sequence of length `b` with values in

\[
0,1,\ldots,w.
\]

Hence the exact number of compatible future merged-rank states is

\[
\boxed{
\binom{w+b}{b}.
}
\]

The unconstrained tuple count would be

\[
(w+1)^b.
\]

If `w=0`, the future generator is completely forced and has one state.

## 8. Why this does not erase the second-order theorem

Stage 102 says the endpoint area, viewed as a function of independent row/column action selections, contains genuine mixed products `x_i y_j`.

Stage 104 does **not** remove those action interactions. Instead it shows that the state needed to generate all their coefficients is smaller because those coefficients come from one total-order incidence relation.

Thus:

- **interaction order** concerns the action-response algebra;
- **generator dimension** concerns the minimal structured state used to produce those responses.

They are different notions.
