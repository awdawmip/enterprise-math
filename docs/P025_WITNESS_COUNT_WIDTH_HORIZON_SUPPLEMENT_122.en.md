## 1. Question

Supplement 121 shows that counts for every ideal recover the exact witness multiplicity function by zeta inversion. Supplement 119 shows that raw queries normalize to antichains. The remaining question is therefore:

> how large must antichain query arity become before exact witness-count recovery is guaranteed?

## 2. P025-T269 — width is a sufficient count-recovery horizon

Let

\[
w:=\operatorname{width}(P).
\]

Every ideal \(K\in J(P)\) is generated by its maximal boundary

\[
\partial K=\operatorname{Max}(K),
\]

and

\[
|\partial K|\le w.
\]

Therefore if the declared count future includes every antichain query of arity at most \(k\) with

\[
k\ge w,
\]

then it includes the count

\[
c(K)=c(\partial K)
\]

for every ideal \(K\).

Stage 121 zeta inversion then recovers the exact multiplicity vector.

Hence

\[
\boxed{
k\ge\operatorname{width}(P)\Longrightarrow\text{exact witness multiplicity recovery}.}
\]

## 3. P025-T270 — the width horizon is worst-case sharp

For every integer \(w\ge1\), take \(P\) to be a \(w\)-element antichain. Then every subset is an ideal.

Define two Boolean witness families:

\[
\mathcal F_{\rm even}
=
\{I\subseteq P:|I|\text{ even}\},
\]

\[
\mathcal F_{\rm odd}
=
\{I\subseteq P:|I|\text{ odd}\}.
\]

Fix a proper required set

\[
S\subsetneq P.
\]

At least one element remains free outside \(S\). Among all supersets

\[
I=S\cup T,
\qquad
T\subseteq P\setminus S,
\]

exactly half have even cardinality and half have odd cardinality. Therefore

\[
\boxed{
c_{\rm even}(S)=c_{\rm odd}(S)=2^{w-|S|-1}.}
\]

Thus the two exact families agree on every query of arity

\[
|S|\le w-1.
\]

But for the full set \(P\), only one superset exists, namely \(P\) itself, so

\[
\{c_{\rm even}(P),c_{\rm odd}(P)\}=\{0,1\}.
\]

Hence for every \(k<w\), bounded-arity count queries can fail to distinguish two different exact witness families.

Therefore

\[
\boxed{
\operatorname{width}(P)
\text{ is the exact worst-case witness-count recovery horizon}.}
\]

## 4. Chain consequence

If \(P\) is a chain, then \(w(P)=1\). Counts for the empty query and all singleton antichain normal forms already provide the full zeta table on \(J(P)\), hence recover every witness multiplicity exactly.

So width-one geometry is stronger than the Stage-120 existential result: pointwise **counts**, not just support, recover exact family identity and multiplicity.

## 5. Existential versus counting saturation

Supplement 120 showed that existential joint-membership semantics saturate at width. Stage 122 shows something stronger:

\[
\boxed{
\text{the same width horizon also suffices for exact multiplicity recovery}.}
\]

But the meaning of saturation differs:

- existential future: beyond width there are no new joint truth values;
- counting future: at width the entire witness multiplicity state becomes invertible.

The common horizon comes from operation normalization by antichain boundaries, not from the strength of the observable itself.

## 6. Architectural consequence

The result separates three ideas:

1. **query geometry** determines the maximum essential arity;
2. **observable strength** determines what can be reconstructed once that geometry is fully queried;
3. **exact family identity** can require strictly richer values at the same essential query coordinates.

Thus arity precision and value precision are independent resources.
