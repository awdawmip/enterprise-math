## 1. Why P024 exists

P023 answers the abstract question:

> given a represented relation and a declared future operation/observation language, what is the coarsest relation that is sufficient for that future?

E001 and E002 then exposed a more arithmetic question that P023 deliberately does not answer:

> when the state is an integer and the future operations are translations, what exact shape does that coarsest relation take?

The answer depends not only on the gcd of the action magnitudes.  It depends first on the **reachable action language** itself.

One-sided translation languages can retain numerical-semigroup holes.  Genuinely two-sided languages complete to an additive group.  Finite cyclic phase spaces perform that group completion automatically even when the supplied generators are used only in the forward direction.

P024 isolates that arithmetic layer.

It does **not** replace P023.  P023 owns the generic quotient theorem.  P024 derives exact integer boundary geometry for a translation specialization.

## 2. Ordered threshold observations

Let the fine state be

\[
x\in\mathbb Z.
\]

Let

\[
B=\{b_1<\cdots<b_r\}\subset\mathbb Z
\]

be a finite set of observation boundaries.  A boundary `b` lies between the integer states `b-1` and `b`.

Define the ordered interval observation

\[
\boxed{
O_B(x)=\#\{b\in B:b\le x\}.
}
\]

Thus `O_B` records which interval cut out by `B` contains `x`.

Let the action alphabet be a finite set

\[
A\subset\mathbb Z.
\]

Every action translates the state by its integer label.  For horizon `h`, let

\[
M_h
=
\left\{
\sum_{j=1}^{k}a_j:
0\le k\le h,
\ a_j\in A
\right\}
\]

be the cumulative translations realized by words of length at most `h`.

For arbitrary finite future words, write

\[
M=\langle A\rangle_{\mathbb N}
\]

for the additive submonoid generated by `A`.

## 3. P024-T01 — Reachable-boundary orbit theorem

**Status: PROVED.**

Define the horizon-`h` boundary orbit

\[
\boxed{
\mathcal C_h=B-M_h
=\{b-m:b\in B,\ m\in M_h\}.
}
\]

For two states `x<y`, the following are equivalent:

1. `x` and `y` have identical `O_B` observations after every action word of length at most `h`;
2. for every `m in M_h`,
   \[
   O_B(x+m)=O_B(y+m);
   \]
3. no future-visible boundary lies between them:
   \[
   \boxed{
   (x,y]\cap\mathcal C_h=\varnothing.
   }
   \]

Therefore the coarsest horizon-`h` predictive precision cells are exactly the maximal integer intervals cut out by `C_h`.

### Proof

For one cumulative translation `m`,

\[
O_B(y+m)-O_B(x+m)
=
\#\{b\in B:x+m<b\le y+m\}.
\]

Because this count is nonnegative, the two observations are equal exactly when the set on the right is empty.

The inequality

\[
x+m<b\le y+m
\]

is equivalent to

\[
x<b-m\le y.
\]

Thus equality for every reachable `m` is equivalent to the absence of every translated cut `b-m` from `(x,y]`. ∎

### Interpretation

Precision is not being chosen by an external tolerance after the fact.  Once the observation boundaries and allowed future actions are declared, the future action language **moves those boundaries backward onto the present state space**.  The resulting boundary orbit is the exact set of distinctions that can still matter.

## 4. P024-T02 — Horizon growth is boundary-orbit growth

**Status: PROVED.**

Because every word of length at most `h` is also a word of length at most `h+1`,

\[
M_h\subseteq M_{h+1}.
\]

Hence

\[
\boxed{
\mathcal C_h\subseteq\mathcal C_{h+1}.
}
\]

So increasing the future horizon can only add cuts and refine precision cells; it can never merge cells already distinguished by a shorter future.

This is the integer-boundary specialization of P023 future-language monotonicity.

## 5. P024-T03 — One-sided threshold precision is a numerical-semigroup partition

**Status: PROVED.**

Take one threshold `theta` and positive actions

\[
A=\{a_1,\ldots,a_m\}\subset\mathbb N_{>0}.
\]

Then

\[
M=\langle A\rangle\subset\mathbb N
\]

is a finitely generated additive semigroup containing zero.

Consider the `L` integer states immediately below the threshold:

\[
I_{\theta,L}
=
\{\theta-L,\ldots,\theta-1\}.
\]

At horizon `h`, every positive reachable displacement

\[
s\in M_h\cap\{1,\ldots,L-1\}
\]

introduces exactly one cut inside this window, at `theta-s`.

Therefore the exact predictive class count is

\[
\boxed{
C_h(L)
=
1+
\left|M_h\cap\{1,\ldots,L-1\}\right|.
}
\]

For arbitrary finite future words,

\[
\boxed{
C_\infty(L)
=
1+
\left|M\cap\{1,\ldots,L-1\}\right|.
}
\]

For a state whose positive distance to the boundary is

\[
t=\theta-x,
\]

a canonical within-window rank is

\[
\boxed{
\rho_h(t)
=
\#\{s\in M_h:0<s<t\}.
}
\]

Thus the one-sided predictive precision is determined by **actually reachable cumulative displacements**, not merely by their gcd.

## 6. P024-T04 — Exact group-completion over-refinement defect

**Status: PROVED.**

Let

\[
g=\gcd(a_1,\ldots,a_m).
\]

The additive group generated by `A` is `g Z`.  If one replaces the actual one-sided monoid `M` by that group completion, the `L`-state threshold-side window is cut at every positive multiple of `g` below `L`, so it has

\[
\boxed{
C_{\rm grp}(L)
=
\left\lceil\frac{L}{g}\right\rceil
}
\]

uniform gcd cells.

Define the relevant semigroup holes

\[
\boxed{
H_{A,L}
=
\{kg:1\le kg<L,\ kg\notin M\}.
}
\]

Then

\[
\boxed{
C_{\rm grp}(L)-C_\infty(L)
=|H_{A,L}|.
}
\]

### Proof

There are exactly

\[
\left\lfloor\frac{L-1}{g}\right\rfloor
\]

positive multiples of `g` below `L`.  Every reachable positive element of `M` below `L` is one of those multiples.  The difference between the full gcd cut set and the actually reachable cut set is therefore exactly the missing multiples `H_{A,L}`.  Adding the common initial cell to both counts gives the formula. ∎

### Exact minimality criterion

The uniform gcd refinement is already minimal on the width-`L` window if and only if

\[
\boxed{
H_{A,L}=\varnothing.
}
\]

So gcd can be a safe refinement while still preserving distinctions that the declared one-sided future can never recover.

### Minimal witness

Let

\[
L=7,
\qquad
A=\{4,6\}.
\]

Then `g=2`, but below `7` the reachable positive displacements are only

\[
\{4,6\}.
\]

The displacement `2` is a semigroup hole.  Hence

\[
C_\infty(7)=3,
\qquad
C_{\rm grp}(7)=4.
\]

## 7. P024-T05 — Conductor-localized irregular precision layer

**Status: PROVED from standard numerical-semigroup conductor theory.**

Normalize the positive generators by their gcd:

\[
S
=
\left\langle
\frac{a_1}{g},\ldots,\frac{a_m}{g}
\right\rangle.
\]

The normalized generators have gcd one, so `S` is a numerical semigroup.  Let `c(S)` be its conductor: the least nonnegative integer such that every integer `n>=c(S)` lies in `S`.

Then every missing group-completion cut has displacement strictly smaller than

\[
\boxed{
g\,c(S).}
\]

Equivalently, once the distance from the threshold is at least `g c(S)`, every gcd-spaced boundary is actually reachable.

Thus a one-sided action language induces

\[
\boxed{
\text{finite irregular boundary layer}
+
\text{asymptotically uniform gcd cells}.
}
\]

The irregular layer is not an arbitrary patch.  Its missing cuts are exactly the numerical-semigroup gaps.

This gives a concrete arithmetic realization of P023's broader conclusion that the coarsest safe precision may require **regular scale plus localized bounded detail** rather than a globally uniform scalar scale.

## 8. P024-T06 — Genuine two-sided action languages equal their group completion

**Status: PROVED.**

Let

\[
D=\{\delta_1,\ldots,\delta_m\}\subset\mathbb Z\setminus\{0\}
\]

contain at least one positive and at least one negative action, and let

\[
g=\gcd(|\delta_1|,\ldots,|\delta_m|).
\]

Let

\[
M_D
=
\left\{
\sum_i n_i\delta_i:n_i\in\mathbb N
\right\}
\]

be the action monoid generated by nonnegative word counts.

Then

\[
\boxed{
M_D=g\mathbb Z.
}
\]

### Proof

Every generated sum is divisible by `g`, so `M_D subseteq g Z`.

Bézout gives an integer coefficient vector representing `g`.  Because `D` has both signs, there also exists a relation

\[
\sum_i z_i\delta_i=0
\]

with every coefficient `z_i` strictly positive: for each positive/negative generator pair, take the obvious positive two-term zero relation and sum these pairwise relations.

For any target `kg`, take an integer Bézout representation of `kg` and add a sufficiently large multiple of the strictly positive zero relation.  All coefficients become nonnegative while the represented sum is unchanged.  Thus every `kg` belongs to `M_D`. ∎

### Uniform single-threshold coordinate

For a threshold `theta`, define

\[
\boxed{
K_{\theta,g}(x)
=
\left\lceil\frac{\theta-x}{g}\right\rceil.
}
\]

Then

\[
\boxed{
x<\theta\iff K_{\theta,g}(x)\ge1}
\]

and every declared translation `delta` acts exactly by

\[
\boxed{
K(x+\delta)
=
K(x)-\frac{\delta}{g}.
}
\]

Because the future action monoid is all of `g Z`, distinct `K` values are finitely distinguishable by translating one of them to the threshold boundary.  Therefore `K` is the coarsest arbitrary-future single-threshold state for the declared translation language.

Paired `+a/-a` magnitudes are sufficient but not necessary.  The real condition is genuine two-sided reachability.

## 9. P024-T07 — Finite periodicization automatically group-completes a monoid

**Status: PROVED.**

Let `G` be a finite group and let `S` be a submonoid of `G` containing the identity.  Then

\[
\boxed{S\text{ is automatically a subgroup of }G.}
\]

### Proof

Take `s in S`.  Because `G` is finite, `s` has finite order `n`.  In additive notation,

\[
-s=(n-1)s.
\]

The right-hand side is a nonnegative repeated monoid sum of `s`, so `-s in S`.  Thus `S` is closed under inverses. ∎

### Cyclic corollary

In

\[
\mathbb Z/w\mathbb Z,
\]

let action residues be generated by integers `a_1,...,a_m`, even if the action words use only nonnegative repetition counts.

The reachable residue monoid is automatically the subgroup

\[
\boxed{
\{0,g,2g,\ldots,w-g\}\pmod w,
\qquad
g=\gcd(w,a_1,\ldots,a_m),
}
\]

with exactly

\[
\boxed{w/g}
\]

residues.

This is the missing structural explanation behind E002 Stage 2: once within-cell phase is periodicized modulo the cell width, repeated forward actions can realize modular inverses.  Numerical-semigroup holes that survive on the unbounded integer chain cannot survive in a finite cyclic phase group.

## 10. P024-T08 — Chain-versus-cycle precision dichotomy

**Status: PROVED for the additive integer/cyclic scope above.**

For the same integer action magnitudes, two state topologies can produce different future precision structures:

### Unbounded ordered chain

For one-sided positive translations on `Z`, the generated future language is a numerical semigroup.

- unreachable positive multiples of the gcd can remain permanent holes;
- those holes remove future-visible threshold cuts;
- the coarsest predictive cells can therefore be nonuniform near observation boundaries.

### Finite cyclic phase

After quotienting phase modulo `w`, the same nonnegative action-word language lives in a finite group.

- the generated monoid automatically closes under inverses;
- reachability becomes the gcd subgroup;
- semigroup holes disappear through periodic wraparound.

Therefore

\[
\boxed{
\text{action magnitudes alone do not determine precision.}
}
\]

The precision geometry depends jointly on

\[
\boxed{
\text{state topology}
+
\text{future action monoid}
+
\text{observation boundaries}.
}
\]

This is the foundational reconciliation of the E001 and E002 engineering results.
