\[
rq\le q_\mu(n;h)<rq+r.

\[

∎

## 10. P019-T06 — Standard-axis `Z^d` L1 shells are generated from the one-dimensional kernel

Status: `PROVED`

\[

\[
\boxed{

=
\sum_{j=1}^{\min(d,r)}

}
\]

### Combinatorial proof

For a point with exactly `j` nonzero coordinates:

1. choose the `j` coordinates: `binom(d,j)`;
2. choose the sign of each nonzero coordinate: `2^j`;
3. compose total L1 radius `r` into `j` positive integers: `binom(r-1,j-1)`.

Summing over all possible `j` proves the formula. ∎

Equivalently, the one-dimensional shell kernel

\[

\qquad
a_1(r)=2\ (r>0)

has generating function

\[
A_1(z)=\frac{1+z}{1-z},

\[
\boxed{A_d(z)=A_1(z)^d.}

Thus P019 exactly realizes the current dimensional-lifting program in which higher-dimensional shell counts are generated by repeated convolution of a one-dimensional kernel.

## 14. Reciprocal singularity, event horizon, and center boundary

Schwarzschild diagonal coordinates contain `1/f`. If the external comparison factor `f` is represented only through `q_lambda`, then at a resolved horizon

\[
q_\lambda(h;h)=0.
\]

P007/P018 already show that a many-to-one quotient/projection coarse state does not possess a canonical inverse lift. In the integer semantics, asking directly for `1/q` at that state is therefore first an **undefined/noncanonical inverse-recovery request**, rather than a requirement to add a physically real infinite number to the primitive state space.

This structurally aligns with horizon-regular Eddington–Finkelstein representations that avoid `1/f`.

It does not yet prove that P019 has explained the Schwarzschild coordinate singularity. A coordinate-invariant reconstruction remains open.

Also distinguish:

- `n=h>0`: `q_lambda` is well-defined and equals `0`;
- `n=0`: the primitive definition would divide by radial state `0` and is outside its domain.

Thus the horizon and the center are different kinds of boundaries in the current arithmetic.

The extension `U_lambda(0)=0` is only an absorbing boundary condition for the primitive dynamics; it does not remove the fact that `q_lambda` itself is undefined at the center.

## 15. Physical falsification and unfinished gates

P019 can move beyond an integer toy model / structure match only after passing the following gates.

### F1 — Rotational isotropy

Standard-axis `Z^3/L1` has only a finite discrete symmetry group. Interpreted literally as physical space, it would produce preferred-direction signals. P016 already treats such effects as a major kill-test class.

Therefore `4h^2+2` is a benchmark, not the final spatial ontology.

### F2 — Coordinate covariance

The current `n,h` are explicit radial-coordinate states. A coordinate-independent causal graph or invariant definition is required; otherwise the model may be only a coordinate rewriting.

### F3 — Quantitative redshift / geodesic recovery

T04 gives discrete clock states and T05 preserves only an outgoing sign. A physical model must generate quantitative predictions for gravitational redshift, propagation, orbits, lensing, and related observables without a hidden real-valued calculation.

### F4 — Mass-to-horizon dimensional interface

The map

\[
M,G,c,\text{unit scale}
\longmapsto h
\]

has not been defined. It must use explicit typed units and integer scales rather than evaluating hidden-real `2GM/c^2` and rounding afterward.

### F5 — Free-fall horizon crossing

In external GR, a freely falling observer does not encounter a local physical singularity at the horizon. P019 must represent that behavior or the zero observation may incorrectly create a material wall.

### F6 — Einstein dynamics

This stage does not rederive the Einstein field equations and provides no discrete curvature-energy law.

### F7 — Black-hole thermodynamics

`S_3(h)=4h^2+2` proves only quadratic growth of a boundary-state cardinality. It does not derive:

- the Bekenstein–Hawking coefficient `1/4`;
- Planck-area normalization;
- thermodynamic entropy;
- Hawking temperature;
- the generalized second law.

### F8 — Quantum/information questions

No Hawking radiation, Page curve, unitarity result, or information-loss theorem has been derived.

### F9 — Charged, rotating, and dynamical horizons

Schwarzschild is only the first pressure test. Reissner–Nordström, Kerr, collapse/merger, and dynamical horizons must be tested separately.
