Supplement 34 supplied one explicit binary storage/update/readout family. The unrestricted storage-vs-readout optimization is not a new R004 combinatorial problem: it is exactly the linear covering-code length problem.

## 1. Parity-check / primitive-ISA duality

Let the additive semantic action space be `F_p^r`. Let s primitive instructions be the columns of a surjective matrix `H:F_p^s -> F_p^r`. An instruction word is a coefficient vector `e in F_p^s`; its net semantic effect is `H e`.

The **null-program code** `C=ker H` contains instruction words with zero net semantic effect.

Then semantic rank is the codimension r of C; primitive storage is code length s; independent null-program count is `dim C=s-r`; shortest primitive readout of semantic action y is the minimum Hamming weight in the syndrome/coset `H e=y`; and worst-case readout depth is exactly the covering radius `R(C)`.

Therefore the minimum primitive storage at semantic rank r and worst readout depth D is exactly the q-ary linear covering-code length function `ell_p(r,D)`.

Covering-code theory, length functions and saturating sets are prior art. R004 claims only this typed compiler interpretation and its fail-closed boundary.

## 2. Sphere-covering lower bound

The number of coefficient words of support at most D is

`V_p(s,D)=sum_(j=0)^D binom(s,j)(p-1)^j`.

Covering every semantic action requires `V_p(s,D)>=p^r`. For p=2 this is the previously derived sphere bound `sum binom(s,j)>=2^r`.

## 3. Exact depth-one endpoint

If D=1, each nonzero projective semantic direction requires a primitive representative:

`ell_p(r,1)=(p^r-1)/(p-1)`.

For p=2, scalar multiples are trivial and this becomes `2^r-1`.

## 4. Exact one-null-program regime

Set `s=r+1`, so the null-program code has dimension one. To minimize covering radius its nonzero null word must have full support; coordinate scaling normalizes it to the repetition line generated by `(1,...,1)`.

For `n=r+1`, the covering radius is

`R_one-null = n-ceil(n/p)`.

Hence `ell_p(r,D)=r+1` throughout

`(r+1)-ceil((r+1)/p) <= D < r`.

For `D>=r`, a basis already gives `ell_p(r,D)=r`. Binary specialization: one redundant primitive gives covering radius `ceil(r/2)`.

## 5. Short-program ambiguity

For a radius-D covering ISA, there are `V_p(s,D)` short coefficient words but only `p^r` semantic actions. The average number of depth-`<=D` instruction words per semantic action is `V_p(s,D)/p^r`.

Define integer short-word excess

`A_word=V_p(s,D)-p^r`.

If `A_word=0`, every semantic action has exactly one short representation. If positive, short-program ambiguity is unavoidable for that `(s,D)` covering.

## 6. Exact-small binary checkpoints

Primary covering-code / saturating-set classifications give the exact radius-2 staircase for semantic ranks 3 through 7:

`ell_2(3,2)=4`, `ell_2(4,2)=5`, `ell_2(5,2)=9`, `ell_2(6,2)=13`, `ell_2(7,2)=19`.

Independent R004 normalized enumeration also checked the r=5 lower point: forcing a standard basis, all 2,600 candidates at `(r,D,s)=(5,2,8)` fail, while the 9-column construction `[1,2,4,8,16,3,5,6,31]` has radius 2.

For `(r,D)=(7,3)`, normalized exhaustive search found all 7,140 candidates at s=9 fail, all 280,840 candidates at s=10 fail, while `[1,2,4,8,16,32,64,96,57,97,71]` has radius 3. Thus exact finite enumeration establishes `ell_2(7,3)=11` within the declared linear binary ISA model. Historical novelty of this numerical value is not claimed.

## 7. Why Supplement 34 is not optimal

At r=7 and D=3, the k-local construction with k=3 stores `7+21+35=63` primitive vectors, while the covering-code ISA needs only 11. Locality-by-weight is therefore a transparent construction family, not the terminal storage optimizer.

## 8. Typed fail-closed boundary

The covering-code reduction is valid only when primitive effects combine linearly over the declared finite field, only the final net semantic action matters, instruction ordering/intermediate side effects are irrelevant, and a null-program codeword is genuinely semantically null.

If branch effects, intermediate guards, witness identity, noncommuting operations or history-sensitive legality matter, `ker H` is not automatically a null-program semantics. The compiler must return to the generic typed future-language / certificate machinery rather than forcing a covering-code representation.

## 9. Research consequence

For the full additive semantic surface, R004 should consume mature covering-code and saturating-set constructions as a backend. The project-local frontier is no longer to solve `ell_p(r,D)` from scratch; it is to determine which typed future languages admit this additive ISA reduction, how precision birth spectra interact with code columns/null programs, and how code-derived primitive surfaces compose with the broader Representation Compiler.
