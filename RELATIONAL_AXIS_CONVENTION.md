# Enterprise Math Relational Axis Convention

Status: `PROJECT_LEVEL_AXIS_AND_ORIENTATION_FREEZE`
Date: `2026-08-16`
Mode: `REFOUND, NOT REJECT`

This file is the canonical convention for the current relational coordinate carriers, transfer axes, directed transfer states, and the special two-dimensional relational planes appearing inside the three-dimensional carrier.

## 1. Semantic types

Always distinguish:

- `COORDINATE_CARRIER`: a relational coordinate slot `Xi`;
- `TRANSFER_AXIS`: an unoriented pair relation between two coordinate carriers;
- `DIRECTED_TRANSFER_STATE`: one orientation of a transfer axis, represented by `e_i-e_j`;
- `RELATIONAL_PLANE`: a rank-two submodule generated by declared transfer relations.

A coordinate carrier is not itself a transfer axis.

Axis names and `+/-` signs are chart / serialization conventions. They do not encode physical preference or a BRC winner.

## 2. Two-dimensional convention

Use three coordinate carriers

`X1, X2, X3`

with affine relation

`X1 + X2 + X3 = K`.

The displacement module is

`Lambda_2 = {(d1,d2,d3) in Z^3 : d1+d2+d3=0}`,

of rank 2.

Freeze the three unoriented transfer axes `U,V,W` with positive directed states

- `+u = e1-e2 = ( 1,-1, 0)` : donor `X2` -> recipient `X1`;
- `+v = e2-e3 = ( 0, 1,-1)` : donor `X3` -> recipient `X2`;
- `+w = e3-e1 = (-1, 0, 1)` : donor `X1` -> recipient `X3`.

Negative directions are additive inverses.

Exact relation:

`u+v+w=0`.

Thus the two-dimensional directed state set is

`D6={+/-u,+/-v,+/-w}`.

### 2.1 Visualization convention

If a later Euclidean visualization draws the three **unoriented axis lines** as a symmetric three-line family, the lines may appear 60 degrees apart while the chosen positive directed vectors `u,v,w` are cyclically balanced and correspond to directions 120 degrees apart. In such a drawing one visual line arrow may therefore point opposite to an initially expected Cartesian-style orientation.

This is only a visualization consequence of the frozen algebraic signs `u+v+w=0`; Euclidean angle is not made native by this convention.

## 3. Three-dimensional convention

Use four coordinate carriers

`X1, X2, X3, X4`

with affine relation

`X1 + X2 + X3 + X4 = K`.

The displacement module is

`Lambda_3={(d1,d2,d3,d4) in Z^4 : d1+d2+d3+d4=0}`,

of rank 3.

There are `C(4,2)=6` unoriented transfer axes and 12 directed transfer states.

Preserve the two-dimensional names `u,v,w` and add `p,q,r`:

- `+u = e1-e2 = ( 1,-1, 0, 0)` : `X2 -> X1`;
- `+v = e2-e3 = ( 0, 1,-1, 0)` : `X3 -> X2`;
- `+w = e3-e1 = (-1, 0, 1, 0)` : `X1 -> X3`;
- `+p = e1-e4 = ( 1, 0, 0,-1)` : `X4 -> X1`;
- `+q = e2-e4 = ( 0, 1, 0,-1)` : `X4 -> X2`;
- `+r = e3-e4 = ( 0, 0, 1,-1)` : `X4 -> X3`.

The six unoriented axes are `U,V,W,P,Q,R`, and

`D12={+/-u,+/-v,+/-w,+/-p,+/-q,+/-r}`.

Exact relations include

`u+v+w=0`,

`u=p-q`,

`v=q-r`,

`w=r-p`.

The full directed family is equivalently

`{e_i-e_j : i != j, 1<=i,j<=4}`.

## 4. A2 six-direction relational planes inside 3D

Not every geometric plane in the three-dimensional visualization is a six-direction plane.

The canonical six-direction relational planes are the rank-two `A2`-type submodules obtained by choosing any three of the four coordinate carriers. There are exactly

`C(4,3)=4`

such carrier-triple planes.

They are:

1. `Pi_123`: axes `U,V,W`, with directed cycle
   `u+v+w=0`.

2. `Pi_124`: axes `U,Q,P`, with directed cycle
   `u+q-p=0`.

3. `Pi_134`: axes `W,R,P`, with directed cycle
   `-w+r-p=0`.

4. `Pi_234`: axes `V,R,Q`, with directed cycle
   `v+r-q=0`.

Each such plane contains exactly three unoriented transfer axes and their inverses, hence six directed rays/states.

For a chosen cyclic orientation `(a,b,c)` satisfying `a+b+c=0`, the corresponding symmetric planar visualization has the three positive cyclic directions interleaved with their negatives. Around the center the sign pattern is therefore the alternating six-ray pattern

`+ - + - + -`

up to cyclic shift and global sign reversal.

This alternating statement is scoped to these `A2` carrier-triple relational planes and their declared oriented visualization. It is **not** a theorem about an arbitrary plane cut through the 3D carrier.

## 5. Other relational planes

A plane generated by two disjoint carrier-pair axes can instead be `A1 x A1`-type and contain only two unoriented transfer axes / four directed states.

Canonical disjoint-pair controls are:

- axes `U` and `R` from pairs `{1,2}` and `{3,4}`;
- axes `W` and `Q` from pairs `{1,3}` and `{2,4}`;
- axes `P` and `V` from pairs `{1,4}` and `{2,3}`.

Thus an arbitrary plane must not be assumed to carry the six-direction `+ - + - + -` structure.

## 6. General pair-transfer pattern

For a `d`-dimensional relational carrier represented by `d+1` coordinate carriers with one affine sum relation, the pair-transfer family is

`{e_i-e_j : i != j}`.

It has

- `(d+1)d` directed transfer states;
- `d(d+1)/2` unoriented transfer axes.

This is an algebraic counting pattern only. It does not establish physical dimensionality.

## 7. Firewalls

Do not infer from this convention alone:

- Euclidean length, angle, norm, or metric;
- physical direction preference;
- a BRC selector preference from a `+` sign;
- physical probability from branch multiplicity;
- that every plane in a 3D visualization is an `A2` six-direction plane;
- that the optional tetrahedral / close-packed visualization is itself the native definition.

The authoritative native content here is relational: coordinate carriers, affine sum constraint, integer displacement module, pair-transfer axes, directed transfer states, exact algebraic relations, and scoped relational-plane typing.
