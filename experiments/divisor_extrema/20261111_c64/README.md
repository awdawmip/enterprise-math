# C64　复算

先读 C64_RESEARCH_NOTE.md。计算环境为 Python 3.10 或更新版本；有限排名与原始三态复核仅用标准库，符号系数及渐近核验另用 SymPy。在本目录运行：

    python3 verify.py

程序重算 C63 截面、2 至 64 的有限排名、全库存高段所需的有限截面、2 至 10 的原三态逐词核对、正质量 BRC 路径及渐近常数，并与随附结果逐项比较。完整证明中的一般不等式、有限排名的递推覆盖和任意固定名次的稳定性均在正文论证。supplement/high_1000.md 为同一截面的 1,000 倍加强界；其余附记给出高段和等极限斜率的另一套展开。

原始 C63 复算包随本包附入，内含其依赖的 C62 原始程序。项目 Git 记录同时保存本轮的证明和新增代码证据；库中的 C63 复算包可补齐单独从 Git 下载新增代码时需要的旧证书。
