# C63　库存带内的逐点最小值与二元间隙中的第二小值

沿用 C62 第 3 节的完整平衡日程和参考状态总变差。设内部间隙开始时还剩 r 对可见的 23、c 个 5 和一个 7，本隙消耗 m 个 5。记 s=c−r−1。下一内部间隙的偏差为 s'=s+1−m。第一内部间隙的偏差为 1−b₀。最后一个内部间隙 r=1 之后还有 bₖ=s−m 个提前进入的 5。每次可行消耗满足 c−m≥2。

以下端点比较使用绝对割线斜率。对于 F(u)=X/[X+Z+(Y−Z)u]，其中 (X,Y,Z) 与 (7q₀,q₁,q₂) 成正比，其在 [0,1] 上的绝对导数范围为

    X|Y−Z|/(X+max(Y,Z))²  ≤ |F'| ≤  X|Y−Z|/(X+min(Y,Z))².

每对输入的绝对割线斜率都在这个范围内，即使方向翻转也适用。第一块之后的两个输入是 1 和 0。可将连续映射的端点差分解为绝对割线斜率之积。

## 定理 1　库存带

对于每个 k≥2，在所有内部间隙都满足 |c−r−1|≤2 的日程中，Aₖ=(523)^{k−1}23 唯一取得最小总变差。该类容许一个内部间隙消费多达五个 5。

**证明。** 当 r≥2 时，正常转移是 (s,m)=(0,1)，Aₖ 的相应转移正是 C62 的 gᵣ。其余可行转移满足

    min |F'| > 3/(100r²),    max |gᵣ'| ≤ 1/(100r²).                (1)

后一式见 C62 (4.2)。前一式的 18 项整系数证书及核验方法见下节。一般日程在缺陷之后也可能再次经过正常转移，输入端点却已改变。因此须估计正常转移的累积失真。写 gᵣ(u)=1/(1+aᵣ+bᵣu)，βᵣ=−bᵣ/(1+aᵣ)。由 C62 (4.1) 后的系数式，

    0 < βᵣ < 3/[4(3r+1)(3r+2)] < 1/(12r²),
    min |gᵣ'| / max |gᵣ'| = (1−βᵣ)².

所有 r≥2 中任意一部分的正常因子之积至少 1−2Σᵣβᵣ≥5/6，这里使用 Σ_{r≥2} r⁻² ≤ Σ_{r≥2} [r(r−1)]⁻¹ = 1。

在 r=1 处 (s,m) 只有六种，包括 s=0,1,2 和 0≤m≤s。每种情形均有 min |F'|>1/100。若有末尾隐藏消耗 ℓ=s−m，给状态 (7,u,1−u)/8 的条件权记作 (l₀,l₁,l₂)。末态的第二个坐标为 u l₁/[7l₀+l₂+(l₁−l₂)u]。两条件分布的 TV 至少为这个坐标的绝对差，故相对于 |u−v|/8 的放大因子至少 8l₁/(7l₀+l₂)。此下界在 ℓ=0,1,2 时依次是 1、26/17、3536/1745。Aₖ 在 r=1 的绝对斜率上界为 33/1568。

若 k≥3 且日程不同于 Aₖ，至少有一个 r≥2 为非正常内部转移。否则第一内部间隙 s=0 迫使 b₀=1，以后每一步均消耗一个 5，直到 r=1 时库存为 2，只能 m=bₖ=0。故由 (1) 及终端估计，任何不同日程与 Aₖ 的 TV 比严格大于 (5/6)·3·(1/100)/(33/1568)>1。k=2 直接用以下二元定理的终端三项比较；总共只有三个日程。证毕。

## 整系数证书

令 K=2r+1, D₁=K+c−m, D₂=K+4(c−m)，并置

    B₀=(D₁−1)∏_{j=0}^m (4K+c−j),
    B₁=(D₂−1)∏_{j=0}^m (K+c−j),
    B₂=(D₂−1)∏_{j=0}^m (K+4(c−j)).

C62 的条件似然消去公共库存因子后，X=28B₁B₂, Y=B₀B₂, Z=4^m B₀B₁。枚举 −2≤s≤2, 0≤m≤5, |s+1−m|≤2，排除 (0,1)，共 18 项。每次代入 r=x+max(2,1+m−s)，后者恰好兼顾最小 r 与 c−m≥2 的条件。令 ε 为 x=0 时 Y−Z 的符号。下列三整系数多项式的所有系数严格为正：

    ε(Y−Z),
    100r² X ε(Y−Z)−3(X+Y)²,
    100r² X ε(Y−Z)−3(X+Z)².

于是 (1) 在每个整数库存成立。附带的 check_local_extrema.py 使用精确多项式展开，检验每个系数；无需截断 x 或扫描有限 r。local_extrema_certificate.json 记录逐项符号与次数。

## 定理 2　二元日程的第二小值

当各间隙满足 bⱼ∈{0,1}，恰有两个零间隙。Aₖ 在此类中仍唯一最小。对于每个 k≥4，唯一第二小值由

    (b₀,…,bₖ)=(1,…,1,0,1,0)

取得，其中开头有 k−2 个 1。其 TV 与 Aₖ 的比严格小于 17。将第一个缺陷提前到还剩至少三对可见块的日程，比 Aₖ 至少大 24 倍（严格不等式）。

**证明。** 内部间隙前的 s 是到此为止已出现的零间隙数。在 r≥2 的第一个偏离 Aₖ 的转移及其之后，每个转移 (s,m) 都属于

    (0,0), (1,0), (2,0), (1,1), (2,1).

以相同的 X,Y,Z 和 r=x+2 验证这五项的绝对导数下界 >1/(50r)。只需将上一节第二、第三个多项式中的 100r² 和 3 改成 50r 和 1，所有系数仍严格为正。每项与正常转移上界之比 >2r。首次偏离之前两日程有相同的输入端点。

r=1 时，对非 Aₖ 日程，(s,m,bₖ) 只可能为 (1,0,1), (1,1,0), (2,1,1)。内部最小绝对斜率依次是 11760/654481, 30/1331, 66885/2573056。第一和第三项还要乘末尾隐藏消耗放大因子的下界 26/17。三项均严格超过 33/1568，因而均严于 Aₖ。这也覆盖 k=2 的两个竞争者。若第一个偏离涉及 r≥3，后续 r=3、2 给出的比大于 6·4=24。

当 k≥4，只余两种直到 r=2 才产生偏离的日程。二者在 r=2 时都是 (s,m)=(0,0)，因此进入最后一步时端点相同。最后取 m=1、bₖ=0 的绝对斜率最多 165/6962；取 m=0、bₖ=1 的有效绝对斜率至少 (26/17)(11760/654481)=305760/11126177，严格更大。前者相对 Aₖ 的比不超过

    [(28152/1234321)/(55913/34560000)] · [(165/6962)/(75/3718)]
     = 6469632000/390606491 < 17.

因 17<24，前者在整个二元类中唯一第二。证毕。

归属与范围：该处二元第二小值仅对 bⱼ∈{0,1} 成立。库存带定理用于排除库存偏差至多 2 的全部竞争者，其余日程的次序仍需另外比较。
