## 模型与参数

平稳隐藏符号 `xi_n=±1` 各半，`P(xi_(n+1)=t | xi_n=s)=(1+rho*s*t)/2`，`X_n=sum_(j=1)^n xi_j`。观测量是 `V_n=Var(X_n)`、第四累积量 `K_n=E[X_n^4]-3V_n^2` 和带符号标准化量 `gamma4=K_n/V_n^2`。当 `V_n=0`，标准化量未定义。

普通参数为

    -1, -0.999999, -0.9999, -0.999, -0.99, -0.9, -0.75, -0.5,
    -0.4, -0.3, -0.2, -0.1, 0, 0.1, 0.25, 0.5, 0.75, 0.9,
    0.99, 0.999, 0.9999, 0.999999, 1

另取 `rho*=sqrt(3)-2` 加 `-10^-2,-10^-4,-10^-6,0,10^-6,10^-4,10^-2`。代数表达式是临界参数的定义；数值轨迹使用 50 位 Decimal 平方根，另用 80 位独立重算。没有把普通 binary64 近似参数冒充精确临界点。

## 稳定第四累积量递推

直接以两个约 `O(n^2)` 的原始矩相减，会损失临界点的 `O(1)` 第四累积量。为此保留

    a_n = E[X_n xi_n]
    h_n = E[X_n^3 xi_n] - 3 V_n a_n

令 `t=rho*a_n`，所有右端都使用旧状态，则

    a_(n+1) = t+1
    V_(n+1) = V_n+2t+1
    h_(n+1) = rho*h_n-6t^2-6t-2
    K_(n+1) = K_n+4rho*h_n-12t^2-8t-2

初始 `a_0=V_0=h_0=K_0=0`。推导只用 `xi^2=1`、条件均值 `E[xi_(n+1)|xi_n]=rho*xi_n` 和二项式展开。特别地，原始三阶混合矩满足 `b'=rho*b+3V+3rho*a+1`，代入 `h=b-3Va` 消去增长项；四阶展开同样消去 `3(V')^2`。这不是将预期的渐近式代入数据。

所有长轨迹用 50 位十进制递推。CSV 保留 17 个有效十进制数字；抽样摘要保留完整计算精度。拟合使用 binary64，故机器级拟合残差不解释为精确数学不等或统计显著性。

## 两阶渐近系数与临界定律

固定 `|rho|<1`，令 `D=(1+rho)/(1-rho)`。精确方差为

    V_n = nD + v0*(1-rho^n),    v0=-2rho/(1-rho)^2=(1-D^2)/2.

倾斜转移矩阵的特征值满足

    lambda^2-(1+rho)cosh(z)*lambda+rho=0,
    lambda_+(0)=1, lambda_-(0)=rho.

平稳初态满足 `M_0(z)=1`、`M_1(z)=cosh(z)`，因而

    M_n(z) = A(z)*lambda_+(z)^n + (1-A(z))*lambda_-(z)^n,
    A(z) = (cosh(z)-lambda_-(z))/(lambda_+(z)-lambda_-(z)).

对 `log lambda_+`、`log A` 在零点求二阶与四阶导数，得到

    B = D-3D^3,
    k0 = (D^2-1)(15D^2+1)/4
       = 4rho*(4rho^2+7rho+4)/(1-rho)^4,
    K_n = nB+k0 + exponentially decaying polynomial transients.

这里 `k0` 是长期第四累积量的常数边界项，不是 `K_0`。稳定递推的几何级数求和也独立给出相同常数。于是

    gamma4_n = C/n + E/n^2 + O(n^-3) + exponentially small transients,
    C = 1/D-3D,
    E = k0/D^2-2B*v0/D^3
      = (D^2-1)(3D^2+5)/(4D^2)
      = 4rho*(2rho^2-rho+2)/((1-rho)^2*(1+rho)^2).

这些渐近式针对**固定参数**。靠近 `rho=±1` 时，边界系数及衰减时间变大，不能将其当作在整个参数区间统一成立的有限时公式。

在 `rho*=sqrt(3)-2`，有 `D=1/sqrt(3)`、`B=C=0`、`v0=1/3`、`k0=-1`，所以

    gamma4_n ~ -3/n^2,
    gamma4_n = -3/n^2 + 2sqrt(3)/n^3 + O(n^-4) + exponential transients.

这提供了同一相关机制内部的不同衰减幂：一般参数的时间 `n^-1` 首项在一个代数临界参数精确消失，余下 `n^-2`。由于此处 `V_n~n/sqrt(3)`，它对应 RMS 宽度 `ell=sqrt(V)` 的 `gamma4~-ell^-4`，不能混称为时间和宽度都“反平方”。

## 固定拟合协议与误差含义

候选在运行前由 `PROTOCOL.md` 指定：常数、`C/n`、`C/n^2`、`C/n+D/n^2`、带固定符号的自由幂律。训练窗为 `1..16`、`129..512`、`2049..8192`、`8193..32768`，每窗留出是其右端下一点到 `65536`。各窗的留出会重叠，是同一轨迹的多尺度诊断，不能作为多个独立验证集。

前四种拟合在有定义的带符号观测上做普通最小二乘，二项设计矩阵先按列归一化以改善条件数；所有系数只由训练数据决定。自由幂律只在训练数据非零且同号时拟合 `log|gamma4|=log|A|+beta*log n`，保留训练符号。训练变号或过零时明确记录 `EXCLUDED_TRAIN_SIGN_CHANGE_OR_ZERO`；留出符号不参与排除判断，留出变号仍作为预测失败计分。不同目标函数的候选均在原始带符号量上报告统一留出误差。

每个拟合记录 RMSE、最大绝对误差、错误符号个数和定义域计数。`normalized_rmse=RMSE/RMS(留出观测)`，`normalized_max_absolute_error=max|误差|/max|留出观测|`；零分母记 `null`。它们是确定性近似误差，**不是 p 值、置信区间或概率保证**。
