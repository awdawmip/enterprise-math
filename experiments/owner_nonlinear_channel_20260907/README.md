# Arbitrary-set reversible observations of six-channel averaging

This is a finite consumer of the existing geometry kernel, BRC observers and T6.
The mathematical note proves that every observation of the nonnegative rational
six-channel mass vector with injective descendants for all A_i has the form
`q=f(total_mass)`. No linearity, continuity, measurability or surjectivity is used.

`make_gate_witness(x,y,strictly_positive=False)` constructs at most five
two-channel transfers for equal-total endpoints. `verify_gate_witness` binds
the supplied endpoints and recalculates both sides of every gate using the
original geometry matrices. A witness step means `A_i(before)=A_i(after)`;
it is an equivalence argument, not a directed physical path from before to after.
The verifier checks the finite chain, not an arbitrary observation q's contract.

All masses are exact integers or Fractions; bools, floats and numeric subclasses
are rejected. The strict-positive option keeps every intermediate coordinate
positive. Zero mass is admitted in the default nonnegative cone and gives an
empty identity witness. Returned witnesses contain immutable tuples.

`brc_gate_observation` uses one positive initial branch for each nonzero channel
mass and reuses the old paths/observe operations. That declared lift is not
recovery of arbitrary microbranches. Equal matrix images can have different
weight histograms. `finite_gate_descent_check` actually calls T6 on the closed
finite domain generated by the supplied points and one idempotent gate; it
does not claim to enumerate the infinite rational cone.
