# 研究记忆模式比较与验收包

状态：**提案；未部署；未进行模型性能比较。**

本目录将“怎样比较”写成可执行的实验约定，提供一个小型声明合同检查器。它不创建研究规则，不要求每次数学研究运行测试，也不改变模型、调度或研究者身份。

## 本次已经完成什么

- 形成七种主模式、四个受控比较维度和七类任务的机器可读计划。
- 提供公开合成开发例与声明检查器。
- 运行 38 项针对性检查，全部通过。
- 运行合成有效例的 CLI 检查，输出 DECLARED_CONTRACT_ONLY。

本次没有调用主模型或辅助模型，没有构建检索索引、训练模型或运行 Nollm 导航。38 项通过证明的是检查器对这些声明场景的行为，不是任何记忆模式的效果、真实隔离能力或数学正确性。所有真实模式及可选变体均保持 NOT_RUN。

## 文件

| 文件 | 用途 |
| --- | --- |
| evaluation_plan.json | 模式、受控轴、任务族、数据隔离、指标与验收设计 |
| validate_evaluation.py | 检查一次运行或配对比较的声明合同 |
| fixtures/synthetic_valid_run.json | 公开合成开发例，没有真实题目、答案、科学结果或计费数据 |
| test_validation.py | 对关键合法与失败场景的针对性检查 |

## 比较对象

| 模式 | 主要变化 | 需要单独记录 |
| --- | --- | --- |
| M0 当前合规入口 | 现有启动与精确查找 | 真实当前基线，不能故意弱化 |
| M1 有界长上下文 | 预先装入合规材料 | 装入规则、遗漏材料、上下文和后续回源费用 |
| M2 平面条目与词法检索 | 结果级卡片、精确符号和关键词 | 与原文的条件保真及条目维护成本 |
| M3 向量／混合检索 | 更广的候选召回与重排 | 编码模型、索引更新与额外推理成本 |
| M4 有类型关系 | 依赖、复用、候选类比的展开 | 关系类型、映射、未匹配条件和证据状态 |
| M5 Nollm 原生导航 | LLM 放置、Surface 选入口和几何展开 | 放置与导航成本、入口依据、原生命中和备用检索贡献 |
| M6 训练辅助模型 | 前提选择、排序或条件识别 | 训练资料、未训练对照、主模型保持不变、训练与服务成本 |

M5 需要备用直接检索时，作为混合变体报告；备用查到的证据不得记作原生几何召回。M6 如果还额外完成推理，则将新增推理计算作为另一项干预，避免把全部收益归给记忆。

M5 的轨迹区分三件事：加载共同必需基础、原生选择后经 Access 读取所选来源，以及额外直接检索结果。额外直接检索即使写成 route=direct，也计入备用检索。原生选择需要先发生且列出所选来源；仅显示标题不能支持完整返回结论。

另有 M2_FREE_A_VIEW 可选变体：它使用词法检索后端，但只索引当前允许的基础与精确定义、条件、工具；输出按已形成问题精确触发。其构建和排序也不能用本次相对盲实验所隔离的额外成果。检查器包含它与 M0 的合法配对，不能仅凭后端名为 M2 就认定不合规。

这些模式不能直接混成一张单一排行榜。应先区分：

1. 同一检索机制下，原文和结果条目的表示差异。
2. 同一成果条目下，检索机制的差异。
3. 同一候选池下，训练助手的增量。
4. TASK、知情综合探索、相对盲 FREE A 与连续更新四种使用场景。

其中 M4 的关系材料需要特别处理。若图模式额外得到人工或模型归纳的关系事实，而平面和向量模式没有这些事实，比较就同时改变了内容和导航。纯导航对照应冻结共同的关系材料，让平面和向量模式也能读取等价关系文本，只改变遍历能力；也可以把新增关系作为单独的整理干预，并在完整系统比较中计入建图和维护成本。同样，M0 原文入口与成果卡片方案通常属于表示或完整系统比较，不能只称为检索器对照。

## 科学资料和评测资料的放置

Enterprise Math 和 Nollm 目前均为公开仓库。适合放在其中的是通用代码、公开科学来源、公开合成测试和经过检查的汇总报告。

账户私有知识、对话、未公开训练样本、真实评测答案及评分细则，不应进入这些公开仓库，包括分支、PR、Issue、CI 日志、附件和 Git 历史。

真正未见题的答案应放在研究执行器、检索器、记忆构建者和训练任务实际无权读取的位置。单独目录、分支或名字中包含 hidden 不能实现隔离。如果执行器已有 GLOBAL_KNOWLEDGE 全库读取权，把答案放在该库另一个目录也不构成盲测隔离。可使用独立评测身份和受限 artifact store，向研究执行器只提供冻结的允许语料视图。

公开历史题可以用于开发和回放。若模型可能已经通过预训练、先前会话或开放网络接触答案，应如实标注这种不确定性。隔离当前工具访问不能证明参数中没有相同知识。

## 怎样取题与冻结

按研究族和证明依赖分组，再按时间切分。一个定理的多份改写、同源推论和近重复版本不能分别进入训练和测试。

历史回放只开放当时可用的科学资料。后续加强、纠错、最终证明、评分答案和正确来源标签均不进入候选池、图构建、几何布局或模型训练。

现行治理和安全要求仍按当前要求执行；冻结科学语料不意味着恢复过期控制权限或旧安全规则。

评测应接受多种正确的前提与证明路径。参考答案用于判断是否有效，不能规定模型只能按其中一条路线思考。

任务覆盖：

- 术语、记号或语言变化后的精确查找；
- 跨线可用结果与相似但不适用的结果；
- 有限／无限、正／有符号、观察合同、量词和噪声差别；
- 不可回答、缺输入或缺来源；
- 增量新增、修订、撤回和依赖变化；
- 冷启动、暖缓存和中断后继续；
- 相对盲问题提出与知情综合探索。

## FREE A 的验证边界

当前规则允许模型在自主形成相关问题后、候选冻结前精确读取必要定义、条件和工具。检查器有专门合法例，避免把这一能力误禁。

FREE A 可直接继承的基础类型限于 foundation 和 current_governance；TASK 可用的 task_input 不能借用这一通道进入 FREE A。候选池、索引构建与可见输出均执行该区别。

相对盲路径不提供完整成果目录、结果比较或以本次声称未额外暴露的非必需成果集合训练的选题助手。字段 trained_on_project_results 仅指这一集合；现行必须继承的基础即使已经包含较早结果，也继续保留，不因该字段被排除。一个曾接触相关成果的会话，不能通过清空提示词重新标为没有接触。上述边界只决定这项评测属于何种曝光条件，不妨碍知情探索继续使用成果。

暴露不只包括正文读取。标题、摘要预览、错误消息和工具输出都可能透露已有结果。声明检查统一覆盖 read、title_preview、preview、error_output、tool_output 和 source_exposure，要求声明来源与可见主体；携带来源但类型未知的事件被明确拒绝。它仍无法证明日志外没有泄漏，真实运行需要独立的工具权限与轨迹核验。

## 怎样验收

### A0：明确合同和隔离

对明确的机械条件和合成哨兵案例，要求零个已观察到的违反，例如答案进入研究候选池、私有内容导出公开文件、错误的源版本或把候选类比标成已证明迁移。

这不是对全部自然语言问题作零错误保证。真实权限隔离还必须由运行时拒读测试验证。

### A1：结果质量

预先定义严重条件错用的判定，验证正确前提召回、假设保留、版本与状态忠实，以及缺条件时的处理。

统计上使用按研究族配对的区间和预先确定的非劣界。误差容忍度由任务后果决定，不能事后按结果选择。已知关键不兼容哨兵应逐项正确处理。

### A2：实际收益

在质量可接受时，比较有效复用、总成本和时延的前沿。允许某种模式只在特定任务族有收益，保留基线擅长的任务。

成本包括主模型、辅助模型、检索、索引、嵌入、几何放置、训练、更新和失败重试。未报告的费用保留未知，不能当作零。若摊销一次性成本，应同时公布摊销工作量与未摊销总数。

### A3：自由探索

让不知模式归属的评阅者判断问题结构、可研究性、实质差异和热点集中。词语距离、问题数量或图边数不能单独代表创造性。

相对盲与知情探索分别评估。后台连接者的建议有价值，也会改变曝光条件。

### A4：有限范围接入

先记录式试用，再按实际结果决定是否改变默认。记忆服务不可用时，直接读源和独立研究仍然可用。验收得分不自动改变科学地位、正式任务状态或生产制度。

## 运行检查器

在本目录执行：

~~~sh
python3 -m unittest -v test_validation.py
python3 validate_evaluation.py fixtures/synthetic_valid_run.json
~~~

配对比较的输入使用 {"intervention":"memory_only","runs":[...]}：

~~~sh
python3 validate_evaluation.py comparison.json --comparison
~~~

memory_only 在此指固定助手的内容表示或导航干预。检查器比较具体允许来源的身份、版本、类型、科学／治理角色、分类与可用时间，也比较完整曝光条件及助手配置；相同的 source_snapshot_id 字符串不够。训练助手的开关或配置变化应单列 intervention=learned_helper，并固定候选池。纯导航对照还须按上文协议冻结共同的语义材料，检查器不尝试自动证明自然语言材料语义等价。

声明检查涵盖源版本、时间切分、训练族泄漏、答案权限声明、FREE A 暴露与索引构建、Nollm 选择与回源顺序、备用来源归因、公开导出以及源状态保持。针对合法与非法配对、额外直接读取、预览泄漏及错误构建均有合成检查例。

它看不到未声明的网络请求、模型训练历史或真实凭据能力，也不理解自然语言证明的真假。因此输出始终明确为 DECLARED_CONTRACT_ONLY，不能当作运行时隔离、性能或数学验收回执。
