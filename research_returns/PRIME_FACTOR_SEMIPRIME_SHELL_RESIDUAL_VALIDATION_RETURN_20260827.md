For each semiprime factor pair \(p\le q\), shell membership was tested using exact integer inequalities

\[
X<pq\le \left\lfloor X\frac{d+a}{d}\right\rfloor
\]

for the registered rational width \(a/d\). Primary data were deterministic prime tables; no floating-point primality or probabilistic factorization was used.

The scale trim was implemented by the exact inequality

\[
p^4>X,

which is equivalent to \(p>X^{1/4}\) without a floating boundary decision.

The density-flat coordinate was frozen as

\[
u=\frac{\log p}{\log X},\qquad
z=\frac{\log\!\left(3u/(1-u)\right)}{\log 3},
\qquad \frac14<u\le\frac12.
\]

This is the normalized CDF coordinate for the first-order shell intensity proportional to \(1/(u(1-u))\) on \([1/4,1/2]\). The primary profile used 24 fixed bins in \(z\).

Null A used 512 within-stratum permutations of exact observed q-channel counts, stratified by eight coarse logarithmic p bands, p mod 30, and q mod 30. Null B used 4096 independent cyclic phase surrogates of the Null-A-standardized profiles. The family-wise statistic was the maximum absolute 24-bin cross-scale aggregate.

## 6. Failure-mode audit: the null destroys deterministic local-density coupling

The coarse-band Null A preserves coarse p density and mod-30 channel totals, but within a coarse band it permutes exact q-interval channel counts across p positions. The exact shell interval

\[
X/p<q\le(1+\eta)X/p
\]

has a p-dependent length, and the q-prime intensity also varies smoothly with q. Consequently, even after the first u-flattening transform, there remains a deterministic fine-bin trend tied to the exact p-to-q interval map.

Permuting counts across those p positions destroys this trend. The apparent residual then appears as a systematic deviation from a null that has erased a component the task explicitly required us to control.

To pressure-test this directly, a residue-free first-order surrogate was constructed at each eligible exact p:

\[
E_p=\frac{q_{\rm hi}-q_{\rm lo}+1}
{\log\sqrt{q_{\rm lo}q_{\rm hi}}}.
\]

This surrogate uses only the exact shell interval and first-order local prime density; it contains no new arithmetic phase and no observed q-residue texture.

Applying the same coarse permutation diagnostic to this smooth surrogate gives:

- correlation between the observed discovery residual profile and the first-order surrogate profile: `0.7994652267495472`;
- surrogate score at the frozen bin under the same coarse-permutation comparison: `+1.6426651545793152`.

The deterministic first-order surrogate therefore produces the same phase more strongly than the observed data.

Next, the smooth expected profile was normalized to the exact observed scale-trim total for each cell and subtracted before variance normalization. At the already-frozen bin:

\[
A_{\rm corrected}=-0.08189962537054353,
\]

instead of the original `+0.840494...`.

The two already-opened holdout composites become

\[
-0.21042020050780783,\qquad
-0.6003357533701266.
\]

Thus the frozen positive feature not only loses significance; it reverses sign after preserving/removing the deterministic first-order density trend that the original null erased.

This is sufficient to classify the effect as a density/shell-geometry artifact rather than a cross-scale arithmetic residual.
