## New theorem: unmediated raw writes defeat metadata-only exact certification

Let `C` be the certified carrier. Suppose a guard has previously certified `supp(x) ⊆ C` and later decides whether that certificate is still valid using only mutation metadata `M`. If there exists any allowed write to a coordinate `j ∉ C` that changes `x_j` from zero to a nonzero value while leaving `M` unchanged, then no decision rule based only on `M` can be an exact zero-error certificate.

Proof: compare two executions from the same certified state. Execution A performs no write. Execution B performs the unmediated write `x_j ← ε` with `ε ≠ 0`. By assumption both executions present identical metadata to the guard, but `supp(x) ⊆ C` is true in A and false in B. The same guard decision cannot be correct for both.

Thus a mere generation counter does **not** bypass R10's complement-scan lower bound when raw writes can bypass it.

## Sufficient exact write-barrier contract

The lower bound can be bypassed only by changing the information model. It is sufficient that:

1. every external write to state and Source is mediated by one trusted barrier;
2. the barrier inspects every changed coefficient exactly and permanently latches dense fallback when a nonzero value is written outside `C`;
3. no raw mutable view escapes that barrier; exposing one immediately revokes the metadata certificate and forces full exact recertification or dense fallback;
4. fixed-RK4 internal mutations may remain uninstrumented only under the already-consumed carrier-closure proof and the no-external-mid-stage-mutation condition;
5. an escape latch is conservative and cannot be cleared merely because a later write happens to zero the coefficient; sparse mode resumes only after exact recertification.

Under these assumptions, external-mutation certification costs `O(number of coefficients actually written through the barrier)` instead of `O(|C^c|)` on every passing step. This does not contradict R10 because trusted write mediation supplies extra information that R10 explicitly excluded.
