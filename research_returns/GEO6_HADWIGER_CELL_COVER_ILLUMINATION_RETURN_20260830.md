## 1. Declared finite Cell probe

For `n >= 1` axes and refinement multiplicity `m >= 1`, define

`K_(n,m) = {o} ∪ {b(i,eps,j) : 1 <= i <= n, eps in {+1,-1}, 1 <= j <= m}`.

`o` is a distinguished central Cell. The relation graph has one relation from `o` to every `b(i,eps,j)`; hence

`∂K_(n,m) = K_(n,m) \ {o}`.

This is a finite relational Cell object, not a Euclidean convex body.

Define the positive half-shell template

`T+_(n,m) = {o} ∪ {b(i,+1,j) : i,j}`.

A sign pattern `sigma in {+1,-1}^n` acts by

`R_sigma(o)=o`,
`R_sigma(b(i,eps,j)) = b(i, sigma_i * eps, j)`.

Each `R_sigma` is an exact automorphism of the declared relation graph.

For a declared allowed pattern family `Sigma`, define the cover number

`C_Sigma(n,m) = min |S|`

over finite `S ⊆ Sigma` such that

`K_(n,m) ⊆ ⋃_{sigma in S} R_sigma(T+_(n,m))`.

If no such `S` exists, write `C_Sigma(n,m)=∞`.

### Directional illumination variant

A direction pattern `sigma` illuminates

`L_sigma(n,m) = {b(i,-sigma_i,j) : i,j}`.

Define `I_Sigma(n,m)` as the minimum number of direction patterns whose illuminated sets cover `∂K_(n,m)`, again `∞` if impossible.

This is a native finite relation/direction predicate on the declared probe. It does not import Euclidean rays, norms, convexity, volume, or homothety.

## 2. Pattern-separation lemma

For `Sigma ⊆ {±1}^n`, define its coordinate-polarity separation number

`s(Sigma) = min{|S| : S ⊆ Sigma and for every coordinate i, {sigma_i : sigma in S}={+1,-1}}`,

with `s(Sigma)=∞` if no such subfamily exists.

### Lemma

For every `n,m >= 1`,

`C_Sigma(n,m) = I_Sigma(n,m) = s(Sigma)`.

### Proof

A transformed template contains exactly the `sigma_i` polarity block on axis `i`; therefore covering both boundary blocks `+` and `-` on every axis is equivalent to requiring both signs in every coordinate projection of the chosen patterns. The central Cell is present in every transformed template and adds no constraint.

For illumination the illuminated polarity is `-sigma_i`; global sign negation does not change the condition “both signs occur”, so the same separation condition is necessary and sufficient.

The refinement index `j` is passive under every declared action. Once one polarity on axis `i` is selected, all `m` subcells of that polarity are selected simultaneously. Therefore `m` never changes the incidence problem. QED.

This gives an exact refinement theorem, not merely a finite census.

## 3. Six-dimensional rotation-action classification

Set `n=6`.

### A. One-step two-axis half-turn family

Let `Sigma_elem` consist of the identity pattern plus patterns having exactly two negative coordinates. Interpret the nontrivial patterns as the declared one-step `180°` half-turns in a chosen two-axis coordinate plane of this finite probe.

Then

`C_elem(6,m) = I_elem(6,m) = 3` for every `m >= 1`.

**Upper certificate.**
Use the three disjoint half-turns on axis pairs

`(1,2)`, `(3,4)`, `(5,6)`.

Every axis is negative in one chosen pattern and positive in the other two, so both polarities are covered/illuminated.

**Lower certificate.**
Two sign patterns cover all polarities iff they are coordinatewise antipodal. In `Sigma_elem`, negative Hamming weights are only `0` or `2`, while antipodes have negative weights `6` or `4`. Hence no antipodal pair exists and two operations cannot suffice.

So the bound `3` is sharp.

### B. Composition closure of the same half-turns

Let `Sigma_even` be the group generated by all two-axis half-turn patterns. Equivalently it is the set of sign patterns with an even number of negative coordinates.

Because the native axis count here is `6`, global inversion has even parity and is generated explicitly by

`R_(1,2) R_(3,4) R_(5,6) = -I`

on this sign probe.

Hence

`C_even(6,m) = I_even(6,m) = 2` for every `m >= 1`.

**Upper certificate.**
The identity and global inversion select complementary polarities on all six axes.

**Lower certificate.**
A single transformed half-shell contains only one of the two polarity blocks on every axis, so one operation can never cover or illuminate the full signed shell.

Thus `2` is sharp.

### C. Sign-preserving axis actions

Any action family that only permutes axes while preserving every sign leaves `T+_(6,m)` invariant as a set. Therefore no negative boundary block is ever reached:

`C_sign-preserving(6,m) = I_sign-preserving(6,m) = ∞`.

This remains true even if the sign-preserving permutation family is very large.

### D. Full sign family (comparison envelope only)

If every sign pattern is declared admissible, then an antipodal pair exists and both numbers are `2`.

This is only a comparison envelope. The task does not infer from it that arbitrary independent sign flips are canonical P000 rotations.
