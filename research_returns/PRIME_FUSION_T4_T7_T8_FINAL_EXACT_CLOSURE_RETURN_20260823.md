## 3. Independent proofs and exact counterexamples / controls

### 3.1 T4 / V4 — primitive pointed quotient collapse

Write

`A = Z[i]`,

`B = Z[omega]`, with `omega^2+omega+1=0`,

and use the accepted product decomposition

`R ~= A x B`, `xi |-> (i,omega)`.

Set

`alpha = a+b i`,

`beta = a+b omega`.

Under the product decomposition the principal ideal generated by `a+b xi` goes to

`(alpha) x (beta)`.

Therefore there is an explicit quotient isomorphism

`R/(a+b xi)  ->  A/(alpha) x B/(beta)`

obtained by taking the two fixed product projections and then quotienting. This step is structural; it does not use cardinality.

#### 3.1.1 Stronger Smith-normal-form theorem

Let

`d=gcd(a,b)`.

Multiplication by `alpha=a+b i` on the basis `(1,i)` of `A` is represented by

`M_N = [[a,-b],[b,a]]`.

Its determinant is

`det(M_N)=a^2+b^2=N`.

The gcd of all matrix entries is exactly `d`. Hence the rank-two Smith normal form has invariant factors

`d, N/d`.

Thus, as an additive group,

`A/(alpha) ~= Z/dZ x Z/(N/d)Z`.

Likewise multiplication by `beta=a+b omega` on `(1,omega)` is represented by

`M_C = [[a,-b],[b,a-b]]`.

Its determinant is

`det(M_C)=a^2-ab+b^2=C`,

and the gcd of its entries is again exactly `d`. Hence

`B/(beta) ~= Z/dZ x Z/(C/d)Z`

as an additive group.

Since `a=d a_0`, `b=d b_0`, one has

`N/d = d(a_0^2+b_0^2)`

and

`C/d = d(a_0^2-a_0 b_0+b_0^2)`,

so the first Smith invariant divides the second in both cases.

Therefore:

**Component Cyclicity Theorem.** For every nonzero integer pair `(a,b)`, each of the two component quotient additive groups is cyclic iff

`gcd(a,b)=1`.

Thus the source primitivity hypothesis is the exact cyclicity criterion.

#### 3.1.2 Explicit Gaussian quotient map in the primitive case

Assume now `gcd(a,b)=1` and `a,b>0`.

Then

`gcd(b,N)=1`, because `N == a^2 (mod b)`;

and similarly

`gcd(b,C)=1`, because `C == a^2 (mod b)`.

Define

`s_N == -a b^{-1} (mod N)`.

Then

`s_N^2+1 == 0 (mod N)`.

Define the ring map

`phi_N : A -> Z/NZ`

by

`phi_N(x+y i)=x+y s_N`.

It is surjective because constants map identically, and

`phi_N(alpha)=a+b s_N=0`.

To prove the kernel exactly, suppose

`x+y s_N == 0 (mod N)`.

Multiplying by `b` gives

`b x-a y == 0 (mod N)`.

Hence

`v=(a y-b x)/N`

is an integer.

Also

`b(a x+b y) = a(bx)+b^2 y == (a^2+b^2)y == 0 (mod N)`.

Since `gcd(b,N)=1`,

`u=(a x+b y)/N`

is an integer. Direct multiplication gives

`(a+b i)(u+v i)=x+y i`.

Hence

`ker(phi_N)=(a+b i)`.

Therefore

`A/(a+b i) ~= Z/NZ`

as rings, not merely as sets of equal cardinality.

#### 3.1.3 Explicit Eisenstein quotient map in the primitive case

Define

`s_C == -a b^{-1} (mod C)`.

Then

`s_C^2+s_C+1 == 0 (mod C)`.

Define

`phi_C : B -> Z/CZ`

by

`phi_C(x+y omega)=x+y s_C`.

Again it is a surjective ring map and kills `beta=a+b omega`.

If

`x+y s_C ==0 (mod C)`,

then

`b x-a y ==0 (mod C)`.

Thus

`v=(a y-b x)/C`

is integral. For

`u=((a-b)x+b y)/C`,

multiply the numerator by `b`:

`b((a-b)x+b y) == a(a-b)y+b^2 y == C y ==0 (mod C)`.

Since `gcd(b,C)=1`, `u` is integral. The multiplication matrix above gives

`(a+b omega)(u+v omega)=x+y omega`.

Therefore

`ker(phi_C)=(a+b omega)`

and

`B/(a+b omega) ~= Z/CZ`.

Combining the two explicit quotient maps,

`R/(a+b xi) ~= Z/NZ x Z/CZ`.

#### 3.1.4 CRT and pointed carrier

For a primitive cell the accepted prerequisite gives

`gcd(N,C)=1`.

Hence with `H=NC`, the CRT map

`Z/HZ -> Z/NZ x Z/CZ`,

`t |-> (t mod N, t mod C)`

is a ring isomorphism.

If `uN+vC=1`, its inverse is explicitly

`(x,y) |-> x(vC)+y(uN) (mod H)`.

Also primitive `a,b` imply `gcd(b,H)=1`, so

`r == -a b^{-1} (mod H)`

is defined. Its reductions are exactly

`r mod N = s_N`,

`r mod C = s_C`.

Thus the distinguished image of `xi=(i,omega)` under the cyclic CRT quotient is exactly the pointed residue `r`.

Moreover `r^2+1=0 mod N` and `r^2+r+1=0 mod C`, so

`F(r)=(r^2+1)(r^2+r+1)=0 mod H`.

This proves the source statement at pointed-ring strength.

### 3.2 T7 / V7 — reconstruction from `(H,e)`

Let `e mod H` be idempotent and define

`N=gcd(e,H)`,

`C=gcd(e-1,H)`.

#### 3.2.1 Universal idempotent split lemma

For every prime power `p^k || H`, idempotence gives

`p^k | e(e-1)`.

But

`gcd(e,e-1)=1`.

Therefore the full prime power `p^k` divides exactly one of `e` or `e-1`.

Consequently the prime-power factors of `H` partition between `N` and `C`, so automatically

`NC=H`

and

`gcd(N,C)=1`.

Hence both of these source assumptions are redundant once `e` is known to be idempotent.

Equivalently, `e` is the unique CRT idempotent satisfying

`e == 0 (mod N)`,

`e == 1 (mod C)`.

#### 3.2.2 Necessity of the two squares

For a positive primitive cell with channels `(N,C)`, the accepted exact identities are

`U=3N-2C=(a+b)^2`,

`V=2C-N=(a-b)^2`.

Thus `U,V` are perfect squares.

Also

`N-C=ab`.

For `a,b>0`, this gives

`N>C`.

If the cell is interior relative to the diagonal, `a!=b`, so

`V=(a-b)^2>0`,

which is equivalent to

`N<2C`.

Thus `C<N<2C` is exactly the positive/interior orientation range.

#### 3.2.3 Sufficiency and exact reconstruction

Assume `e` is idempotent,

`C<N<2C`,

and

`U=3N-2C`, `V=2C-N`

are perfect squares.

Put

`x=sqrt(U)`,

`y=sqrt(V)`.

Since

`U == V == N (mod 2)`,

the two square roots have the same parity. Therefore

`a=(x+y)/2`,

`b=(x-y)/2`

are integers.

Furthermore

`U-V=4(N-C)>0`,

so `x>y`, hence `b>0` and `a>0`. The strict upper inequality gives `V>0`, so `a!=b`.

Now

`a^2+b^2=(x^2+y^2)/2=(U+V)/2=N`.

Also

`ab=(x^2-y^2)/4=N-C`,

so

`a^2-ab+b^2=N-(N-C)=C`.

Finally, if `d=gcd(a,b)>1`, then `d^2` divides both `N` and `C`, contradicting the already automatic `gcd(N,C)=1`. Hence

`gcd(a,b)=1`.

Thus a positive primitive interior unordered cell exists, and the displayed formula recovers it exactly up to swapping `a,b`.

#### 3.2.4 Stronger minimal-hypothesis theorem

The source theorem is correct, but it is not minimal.

**Positive reconstruction theorem.** Let `H>=1`, let `e mod H` be idempotent, and define `N,C` by the two gcds above. Put

`U=3N-2C`,

`V=2C-N`.

Then a positive primitive unordered cell exists with channels `(N,C)` iff

1. `N>C`, and
2. `U` and `V` are perfect squares.

No separate assumptions `NC=H` or `gcd(N,C)=1` are needed.

Why no upper inequality is needed for merely positive cells: if `V` is a square then `V>=0`, hence automatically `N<=2C`. Equality gives `V=0`, i.e. the positive diagonal cell. If strict interiority is required, add exactly

`V>0`, equivalently `N<2C`.

Thus the historical `C<N<2C` contributes:

- `N>C`: positivity/orientation and is theorem-critical;
- `N<2C`: exclusion of the diagonal only, once the square gate is already imposed.

### 3.3 T8 / V8 — dual-prime finite quotient characterization

Let

`Q=R/(a+b xi)`.

From the accepted product decomposition and the explicit quotient step already used above,

`Q ~= A/(a+b i) x B/(a+b omega)`.

For every nonzero cell, the two component quotient cardinalities are exactly

`|A/(a+b i)|=N`,

`|B/(a+b omega)|=C`,

because they are the absolute determinants of the multiplication matrices `M_N,M_C`.

#### 3.3.1 Dual-prime implies product of distinct prime fields

If the cell is dual-prime, then `N` and `C` are primes.

A finite unital quotient ring of prime cardinality `p` is necessarily `F_p`. Therefore the fixed, canonically labelled product decomposition gives

`Q ~= F_N x F_C`.

The primes are distinct. In the source interior domain, this is immediate from

`N-C=ab>0`.

More generally, if `N=C`, then `ab=0`; on an axis `N=C` is a square, so it cannot be a prime greater than `1`.

Hence

`H=NC`

is a square-free semiprime.

#### 3.3.2 Square-free semiprime total cardinality implies dual-prime

Conversely, suppose

`H=NC=pq`

with distinct primes `p,q` and both channel factors nontrivial.

Because `N,C>1` and their product is exactly `pq`, necessarily

`{N,C}={p,q}`.

Thus both channels are prime and the cell is dual-prime.

No primitive-coprimality input is actually needed for this cardinality implication.

Likewise, if an abstract ring isomorphism

`Q ~= F_p x F_q`

with `p!=q` is given, then

`|Q|=pq=H=NC`.

With nontrivial channels this again forces

`{N,C}={p,q}`,

so the cell is dual-prime.

#### 3.3.3 Stronger theorem: primitive/interior are algebraically redundant

On the nonzero nonnegative cell family, even the explicit assumption `N,C>1` can be omitted from the equivalence.

Indeed:

- if `N=1`, then `a^2+b^2=1`, so `(a,b)` is an axis unit and `C=1`, giving `H=1`;
- if `C=1` with `a,b>=0`, then
  `C=(a-b)^2+ab=1`, whose only possibilities are axis units or `(1,1)`; hence `H` is `1` or `2`.

Therefore a square-free semiprime `H=pq` with two distinct primes automatically has `N,C>1`.

This yields the stronger algebraic statement:

**Dual-prime quotient theorem.** For every nonzero nonnegative cell,

`N and C are distinct primes`

iff

`H=NC is a square-free semiprime`

iff

`Q` is abstractly isomorphic to `F_p x F_q` for two distinct primes `p,q`.

Whenever these conditions hold, primitivity is automatic: if `d=gcd(a,b)>1`, then `d^2` divides both `N` and `C`, impossible for two distinct primes. Interiority is therefore not needed for the algebraic equivalence; it only restricts the geometric domain and fixes the usual `N>C` orientation.

#### 3.3.4 Canonical labels versus abstract product order

The abstract ring type

`F_p x F_q`

only supplies the two field factors as an abstract unordered pair. The notation's first/second factor is not by itself a channel label.

The labels `N` and `C` come from the fixed product decomposition

`R ~= Z[i] x Z[omega]`

and its two quotient projections, equivalently from the corresponding canonical central idempotents.

For example, the dual-prime cell `(1,2)` has

`(N,C)=(5,3)`

and canonical quotient

`F_5 x F_3`,

but abstractly this ring is equally describable as

`F_3 x F_5`

by swapping product coordinates. That swap does not change the ring but does erase the source channel ordering unless the canonical projection data are retained.

Thus the source T8 statement is valid because it explicitly attaches the prime factors to the canonical channel components; an arbitrary abstract isomorphism alone must not be treated as that labelling datum.
