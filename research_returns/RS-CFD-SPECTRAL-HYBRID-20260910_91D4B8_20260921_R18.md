## New exact result 1: viscosity plus classical RK4 cannot delete a Source=0 mode by itself

Consider one retained Fourier coefficient after the solver's fixed mask/Nyquist policy, and write its Source=0 semilinear evolution as

`du_k/dt = -lambda_k u_k + N_k(u)`, with `lambda_k = nu |k|^2 >= 0`.

Let `h>0` and `x = h lambda_k >= 0`. For classical RK4 the homogeneous multiplier is

`R(-x) = 1 - x + x^2/2 - x^3/6 + x^4/24`.

It has the exact sum-of-squares identity

`24 R(-x) = x^2 (x-2)^2 + 8 (x-3/2)^2 + 6`.

Hence, for every `x>=0`,

`R(-x) >= 1/4 > 0`.

Therefore, if the projected nonlinear contribution of this target mode is exactly zero at all four RK4 stages, then

`u_{n+1,k} = R(-x) u_{n,k}`,

so an initially nonzero coefficient cannot become exactly zero. In exact arithmetic its norm is at least one quarter of its pre-step norm. Repeating the argument shows that a Source=0 trajectory confined to a subspace in which the target-mode nonlinear term vanishes at every stage preserves that mode's exact support for every finite number of RK4 steps.

This closes the narrow semantic gap in the R17 construction: on its nonlinear-free transverse mode geometry, removing the Source removes the support-shrink mechanism. The R17 cancellation cannot be reinterpreted as pure viscous decay.

## New exact result 2: any Source=0 mode loss requires a weighted nonlinear cancellation

The previous statement can be sharpened without assuming the whole nonlinear term vanishes. Let `N_1,...,N_4` denote the projected nonlinear contribution of the same Fourier mode at the four classical RK4 stages. Direct expansion of the RK4 stages gives

`u_{n+1,k} = R(-x)u_{n,k} + h (b1 N_1 + b2 N_2 + b3 N_3 + b4 N_4)`,

where

- `b1 = (4 - 4x + 2x^2 - x^3)/24`,
- `b2 = (4 - 2x + x^2)/12`,
- `b3 = (2 - x)/6`,
- `b4 = 1/6`.

Define the weighted nonlinear correction

`C_k = h (b1 N_1 + b2 N_2 + b3 N_3 + b4 N_4)`.

If an initially nonzero Source=0 coefficient disappears exactly at the end of the step, then necessarily

`C_k = -R(-x) u_{n,k}`.

Thus at least one stage has nonzero projected nonlinear contribution and, for any norm,

`||C_k|| = R(-x)||u_{n,k}|| >= ||u_{n,k}||/4`.

This yields a direct sufficient no-loss gate:

`h sum_j |b_j| ||N_j|| < R(-x)||u_{n,k}||  =>  u_{n+1,k} != 0`.

Because `R(-x)>=1/4`, the simpler but more conservative condition

`h sum_j |b_j| ||N_j|| < ||u_{n,k}||/4`

also certifies that this mode cannot disappear during that RK4 step.

The result does **not** assert that nonlinear incompressible Navier-Stokes cannot re-sparsify under Source=0. Instead it identifies the exact mathematical route that any such loss must take: weighted nonlinear cancellation. A saturation snapshot still cannot be used by itself to set R16's future opportunity cap `M=0`.
