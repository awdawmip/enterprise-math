# 心跳：全局自洽瞬间（暂行 v0.1）

Status: ACTIVE_PROVISIONAL_USER_NAMING。用户2026-09-22直接命名；可修订的工作定义，不是已证明的物理定理，不修改P000。

> **一次心跳，是所声明系统在同一时刻、连同边界和作用源共同满足模型关系的完整自洽状态。**

简称“心跳”，强调状态时称“心跳态”，记作 H_n。从 H_n 到 H_(n+1) 的关系叫“心跳间演化”，对应的时间差叫“心跳间隔”。一次心跳本身不是这一段演化，不是一次迭代，也不默认等于一秒、固定频率或最小时间量子。

## 统一类型

| 符号/名称 | 定义 |
|---|---|
| n，心跳序号 | 被记录的自洽瞬间的顺序；不是求解器循环次数 |
| t_n，物理时间标签 | 由具体动力模型给出；无物理校准时保留为模型时间 |
| k，求解迭代号 | 对同一个 H_n 的暂定解修正；未形成下一物理时刻 |
| z，晶胞地址 | 六个原生整数位移/登记的无损地址；不同于材料身份 |
| q,p，材料状态 | 材料位置、姿态、动量及必要内态；本原型q仅为有效读出 |
| chi,pi_chi，场状态 | 当前场和影响未来的动量、相位、分支或记忆 |
| r_struct，结构残差 | 接触、支路或场匹配中真实保留的非零差异 |
| e_solve，求解残差 | 方程未解准的数值缺陷，必须标精度；不是物理力来源 |

“全局”必须说明范围。有限模型中的全局，是全部已建模变量和明确的边界/作用源；不是声称计算了实际整个宇宙。删去的外部影响要有响应关系、记忆或误差预算；不能把边界未知的片段称为全局闭合。

## 自洽不是静止

一个心跳允许速度、加速度、能量交换和结构残差均非零。所要求的是所有变量属于同一个相容状态，力与加速度/约束/场响应按所选规则一致，而不是把所有净力置零。基态、平衡态、全局最低能量均为需另外声明的子问题，不由这个命名自动得到。

同一候选场可经多次求解迭代，先前暂定变量可修正；已固定的真实初态/边界不得被偷偷改写。多解时保留分支及选择规则，不把求解器偶然返回的根认作唯一物理状态。收敛失败留下候选及缺陷，不拒绝研究对象。

## 受控输入与观察输出

当前杆—晶胞场研究仅将初始联合准备、施力位置/方向/强度/持续时间以及可控耦合作为输入。角度、两端位移、质心及场变化是输出；初始姿态可以作为初始条件。支点、夹具和角度伺服是新增物理装置，需要反力与做功，不可隐含。

未来所需的场动量、材料身份、路径相位、内部重建关系和原始来源必须保留。同一杆姿态而场动量不同，未必是同一次完整心跳。相对读出相同也不证明晶胞地址相同。

## 计算状态

精确数学状态与数值验收的近似状态分开。有限计算采用 `CANDIDATE` / `NUMERICALLY_VALIDATED` / `EXACT_MODEL_CERTIFICATE` 等明确状态；验收阈值是计算配置，不是世界公理。数值能量误差很小不等于连续轨迹误差同样小。

旧记录里的“拍”、门步骤、逻辑层、接触次数、时钟位置保留原语义，不追溯性重命名为本定义的心跳。现有“心跳世界”仍为原生六轴空间加独立时间；本定义不规定固定演化程序。
