## 1. Scope

This definition freezes the native straight-line semantics already validated for one origin-based native right sector and cyclically transported to the three sectors.

The underlying plane remains:

- native origin `O_E=0`;
- three positive native axes;
- adjacent positive axes form one native right angle of `120 degrees`;
- circle cells have center spacing `1` and radius `1/sqrt(3)`;
- neighboring circle cells overlap and the cover has no gaps;
- instantaneous discrete state is one circle cell.

## 2. Typed objects

Fix one native right sector `S_ij`.

Define:

- `V_ij(a,b)` — native coordinate/triple-intersection vertex with component address `(a,b)`;
- `C_ij(a,b)` — the circle cell in the sector-local affine center chart corresponding to the same integer pair;
- `T_{a,b}^{(ij)}` — native line identity;
- `LINE_PATH_REPRESENTATIVE` — one single-cell trajectory realizing that identity.

The coordinate vertex and terminal cell are not the same physical point/object.

Freeze:

`VADDR != CADDR`.

The typed line endpoint is

`END_E^(ij)(a,b)=(V_ij(a,b),C_ij(a,b))`.

The vertex/component object owns native length; the cell owns the discrete terminal state.

## 3. Origin incidence and affine center chart

The origin is a triple cell-boundary intersection and not a cell.

For every fixed open sector `S_ij`, exactly one of the three cells incident to `O_E` has its center in that sector.

Define the unique type-changing start incidence

`Sigma_O^(ij): O_E -> C_ij(0,0)`.

This is not a center-to-center jump.

Let

`s_ij=ctr(C_ij(0,0))-O_E`.

Then

`ctr(C_ij(a,b))=V_ij(a,b)+s_ij`.

The offset `s_ij` is constant; no guessed numeric `+1`, `-1` or half-step correction is used.

## 4. Native line identity

For `a,b in N_0`, freeze

`T_{a,b}^{(ij)}=[X_i^a X_j^b]`

under the equivalence relation generated by

`X_i X_j ~ X_j X_i`.

This relation preserves the native positive-axis component content.

The local carrier has a genuine commuting diamond realizing the two orders

`X_i X_j`

and

`X_j X_i`

as distinct single-cell paths with the same typed terminal cell and the same native component trace.

Thus a line identity is stronger than a carrier endpoint.

Freeze:

`ENTERPRISE_LINE_IDENTITY = NATIVE_COMPONENT_TRACE`.

## 5. Linearizations and path fiber

Let

`Sh_{a,b}(X_i,X_j)=[u^a v^b](uX_i+vX_j)^(a+b)`

be the exact set/sum of all words containing `a` copies of `X_i` and `b` copies of `X_j`.

Freeze the realization fiber:

`Realize_E(T_{a,b}^{(ij)})={Sigma_O^(ij);w : w in Sh_{a,b}(X_i,X_j)}`.

Every member is a single-cell trajectory in the sector-local affine cell chart.

Cardinality:

`|Realize_E(T_{a,b}^{(ij)})|=binom(a+b,a)`.

Freeze:

`ONE_NATIVE_LINE_IDENTITY_CAN_HAVE_MANY_DISCRETE_PATH_REPRESENTATIVES`.

`ENTERPRISE_LINE_PATH_FIBER = TRACE_LINEARIZATIONS_WITH_NATIVE_INCIDENCE`.

## 6. Native length

Inside `S_ij`, adjacent positive axes are Enterprise-orthogonal even though the carrier drawing opens by classical `120 degrees`.

Therefore

`L_E(END_E^(ij)(a,b))^2=a^2+b^2`.

In particular:

`L_E(END_E^(ij)(3,4))=5`.

The number of cell-center transition letters in one `(3,4)` path is `7`; this is not the native line length.

Freeze:

`NATIVE_LINE_LENGTH != PATH_LETTER_COUNT`.

## 7. Same endpoint is not automatically the same line

The triangular carrier may contain a reverse-third-family nearest-center shortcut to the same carrier endpoint. For the smallest interior witness `(1,1)`, the carrier path `-X_k` reaches the same center as `X_iX_j`/`X_jX_i`.

However, the carrier relation behind that shortcut is not a native Enterprise vector/component identity.

Therefore the shortcut is classified as

`CARRIER_ONLY_SHORTCUT_NOT_NATIVE_LINE`

relative to `T_{1,1}^{(ij)}`.

Freeze:

`SAME_ENDPOINT_PATH != SAME_LINE_PATH` in general.

Line membership is decided by native component trace, not minimum jump count.

## 8. Scalar-to-line formula

For any nonnegative integer `N`, define the exact coordinate decomposition fiber

`D_N={(a,b) in N_0^2 : a^2+b^2=N}`.

Then the sector-local native line formula is

`LINE_E^(ij)(N)=disjoint_union_{(a,b) in D_N} Realize_E(T_{a,b}^{(ij)})`.

If `D_N` is empty, no integer-addressed line branch exists at that squared native length.

For `N=25`:

`D_25={(0,5),(3,4),(4,3),(5,0)}`.

In one fixed sector the path counts are

`1 + 35 + 35 + 1 = 72`.

The `(3,4)` branch is one native length-5 line identity with exactly `35` discrete path representatives.

## 9. Composition and scaling

Trace identities compose by component addition:

`T_{a,b}^{(ij)} * T_{c,d}^{(ij)} = T_{a+c,b+d}^{(ij)}`.

Scaling obeys

`(T_{a,b}^{(ij)})^k=T_{ka,kb}^{(ij)}`.

Representative concatenations lie inside the larger trace; closure under adjacent component-preserving commutations yields the full realization fiber.

## 10. Three-sector covariance and axis gluing
