# 初始圆全单位不变量 — 历史定义

Status: `SUPERSEDED / HISTORICAL_PROVENANCE`

Superseded by: `definitions/ENTERPRISE_THREE_POSITIVE_AXIS_OVERLAPPING_CIRCLE_CELL_PLANE_20260820.md`

本文件曾把初始圆/原点对象冻结为同时具有 unit radius / diameter / perimeter / area 等不变量的 foundational object。

当前 circle-cell foundation 已改变对象类型：

- origin `O_E=0` 是三重 cell-boundary intersection；
- origin 不是 circle cell；
- native cells 是以离散圆心标识的 overlapping circle cells；
- nearest center spacing = `1`；
- cell radius = `1/sqrt(3)`；
- circle cells gap-free cover the plane。

因此旧“初始圆全单位”不变量不能继续作为当前 native geometry 的定义或校准 premise。

本文件只保留历史/provenance 和负结果追踪用途；任何依赖旧 initial-circle ontology 的结论，在当前 foundation 下默认需要重新类型化或重新推导。原始完整文本保留在 Git 历史中。
