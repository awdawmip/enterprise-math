## 1. Coordinate carriers versus transfer axes

Three-dimensional relational space is represented by four coordinate carriers

`X1, X2, X3, X4`

with affine sheet constraint

`X1 + X2 + X3 + X4 = K`.

The associated displacement module is

`Lambda_3 = {(d1,d2,d3,d4) in Z^4 : d1+d2+d3+d4=0}`,

which has rank 3.

The four coordinate carriers are **not** the six spatial axes.

A transfer axis is the unoriented pair relation generated by `e_i-e_j`. Therefore the number of axes is

`C(4,2)=6`,

and each axis has two orientations, giving 12 directed transfer states.

## 2. Frozen axis names and positive orientations

Preserve the existing two-dimensional names `u,v,w` on the first three coordinate carriers and add `p,q,r` for the three pair relations involving `X4`.

Positive orientations are frozen as follows:

- `+u = e1-e2 = ( 1,-1, 0, 0)` : donor `X2` -> recipient `X1`
- `+v = e2-e3 = ( 0, 1,-1, 0)` : donor `X3` -> recipient `X2`
- `+w = e3-e1 = (-1, 0, 1, 0)` : donor `X1` -> recipient `X3`
- `+p = e1-e4 = ( 1, 0, 0,-1)` : donor `X4` -> recipient `X1`
- `+q = e2-e4 = ( 0, 1, 0,-1)` : donor `X4` -> recipient `X2`
- `+r = e3-e4 = ( 0, 0, 1,-1)` : donor `X4` -> recipient `X3`

Negative orientation is exact additive inversion:

`-a = -(+a)` for `a in {u,v,w,p,q,r}`.

Thus:

- `-u = e2-e1`
- `-v = e3-e2`
- `-w = e1-e3`
- `-p = e4-e1`
- `-q = e4-e2`
- `-r = e4-e3`

## 3. Six unoriented axes

The six spatial transfer axes are therefore

`U = span_Z{u}`
`V = span_Z{v}`
`W = span_Z{w}`
`P = span_Z{p}`
`Q = span_Z{q}`
`R = span_Z{r}`.

Equivalently, they correspond to the six unordered carrier pairs

`{1,2}, {2,3}, {1,3}, {1,4}, {2,4}, {3,4}`.

## 4. Exact algebraic relations

The first three preserve the frozen two-dimensional cycle:

`u+v+w=0`.

The three new axes satisfy

`u = p-q`
`v = q-r`
`w = r-p`.

Hence only three independent vector directions are required to span `Lambda_3`, as expected for dimension 3.

## 5. Naming and orientation firewall

The chosen names and `+/-` orientations are a **serialization / chart convention**, not a physical preference and not a BRC selector law.

No axis is physically privileged by the names `u,v,w,p,q,r`.

Under a permutation of the four coordinate carriers, the six axes and their orientations must be transported by the induced permutation of the pair relations. A permutation may map a named positive axis to another named positive or negative axis depending on orientation.

The frozen semantic distinction is:

- `COORDINATE_CARRIER`: one of `X1..X4`;
- `TRANSFER_AXIS`: one of the six unoriented pair relations `U,V,W,P,Q,R`;
- `DIRECTED_TRANSFER_STATE`: one of `+/-u,+/-v,+/-w,+/-p,+/-q,+/-r`.

## 6. Optional geometric visualization

A later Euclidean embedding may visualize the four coordinate carriers through tetrahedrally balanced reference vectors and the six transfer axes through pair differences. Such an embedding is calibration/readout only unless independently refounded.

This convention does not freeze Euclidean angle, norm, length, or physical direction semantics.

## 7. Canonical A2 six-direction relational planes

The six-axis carrier contains exactly four canonical three-carrier rank-two relational planes:

- `Pi_123`: `u+v+w=0`;
- `Pi_124`: `u+q-p=0`;
- `Pi_134`: `-w+r-p=0`;
- `Pi_234`: `v+r-q=0`.

Each contains three unoriented transfer axes and six directed states. In a symmetric planar visualization, a chosen cyclic triple satisfying `a+b+c=0` is interleaved by its negatives, producing the cyclic ray-sign pattern

`+ - + - + -`

up to cyclic shift and global sign reversal.

This statement is scoped to these `A2` carrier-triple relational planes. It is not a rule for an arbitrary plane cut through a three-dimensional visualization.

## 8. A1 x A1 controls and arbitrary-plane firewall

Disjoint carrier-pair axes give canonical two-axis / four-direction controls:

- `U` with `R`;
- `W` with `Q`;
- `P` with `V`.

Therefore an arbitrary plane must not be assumed to contain three transfer axes or the six-ray `+ - + - + -` pattern.
